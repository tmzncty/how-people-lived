# 中国，1982–2005：成年期变了，但它的次序出人意料地有序

这份笔记是刻意用来纠偏的。

经济与制度的急剧变化容易诱使我们假定：到 2000 年代初，青年成年期已经完全个体化了。

一项结构性人口分析提示了一个更复杂的故事。

## 来源与人口

费利西亚·田（Felicia Tian）的研究使用：

- 1982 年人口普查
- 1990 年人口普查
- 2000 年人口普查
- 2005 年 1% 人口抽样调查

并把 **18–30 岁**人口作为综合队列处理。

它考察三个维度：

1. 时点
2. 次序
3. 异质性

来源：

- Felicia Tian，"Transition to adulthood in China in 1982–2005: A structural view"，《Demographic Research》34（2016），第 451–466 页：https://www.demographic-research.org/articles/volume/34/16

## 变化最大的是什么：求学与就业的时点

研究发现，在此期间完成学业与进入劳动力市场都明显推迟。

这与本仓库中的其他证据相符：

- 高等教育变得普遍得多；
- 大学日益成为一个家庭规划问题；
- 子女在求学期间经济上依赖家庭的时间更长；
- 对某些群体而言，首次进入劳动力市场的时间后移。

参见：

- [`../../topics/when-did-university-become-an-ordinary-life-option.zh-CN.md`](../../topics/when-did-university-become-an-ordinary-life-option.zh-CN.md)

要点在于，额外的学校教育不只是改变了文凭。

它改变了**成年期的时间表**。

## 变化较小的是什么：结婚与生育的时点

田发现，相对于完成学业与进入劳动力市场那明显得多的推迟，结婚与生育只是小幅推迟。

这一点很重要，因为它意味着生命历程并不是简单地均匀拉长。

相反，某些较早的阶段被拉长了，而较晚的家庭里程碑却相对地靠近。

这可能压缩以下各事之间的时段：

- 离开学校；
- 找到稳定工作；
- 解决住房；
- 结婚；
- 生育一个孩子。

于是一个成年人可能面对*更多*彼此分开的任务，却没有得到按比例更多的时间去完成它们。

这或许正是这一过渡让人感到拥挤而非从容的原因之一。

## 次序仍然高度有序

研究得出结论：通往成年期的路径相对而言是有结构的，并遵循一个高度有序的次序。

可以看到一定程度的个体化，尤其是在城市居民中，但整体模式并不像标准生命历程次序的彻底瓦解。

这对本仓库至关重要。

不要写成：

> 市场改革 → 每个人都选择自己独特的次序。

更宜写成：

> **成年期中越来越多的方面各自单独管理，而关于其先后次序的强预期依然保留。**

## 一个有用的模型：解绑而不脱序

较早的城市成年期可以在制度上被捆绑为一体：

**工作 + 住房 + 福利 + 退休前景**

较晚的成年期可能要求分别管理：

- 教育
- 工作
- 城市
- 住房
- 婚姻
- 养老金

但社会可理解的次序仍可能看起来是：

**学校 → 工作 → 婚姻 → 生育**

因此，生命历程可以同时是：

- 更市场化的；
- 经济上更个体化的；
- 地理上更流动的；
- 却仍然被强烈地排序。

这比把它描述为从集体主义到个体主义的简单转变更为精确。

## 城市与乡村的路径并不相同

研究发现城市居民的个体化程度更高。

这与以下事实一致：城市青年更多地接触到：

- 更长的学校教育；
- 多元化的劳动力市场；
- 市场化住房；
- 不断变化的职业流动；
- 消费信贷与新的通信技术。

与此同时，农村青年可能把耕作、迁移、家庭劳动与家庭义务结合起来，其方式并不符合一个纯粹的都市独立模型。

参见：

- [`1990s-rural-youth-life-horizons.zh-CN.md`](1990s-rural-youth-life-horizons.zh-CN.md)

## 为什么这对「独立」很重要

一个人可以在职业选择上变得更独立，却仍然按一个被强烈预期的时间表进入婚姻。

一个人可以为工作远离子女父母，却仍把收入寄回家。

一对伴侣可以用父母的钱建立自己的居所。

这意味着成年期的若干维度彼此分离，却并未在社会意义上变得互不相关。

参见：

- [`../../topics/what-counted-as-independence.zh-CN.md`](../../topics/what-counted-as-independence.zh-CN.md)

## 为什么这对住房很重要

如果结婚时点只略有变化，而市场住房变得更重要，那么年轻成年人在进入劳动力市场后就会面临迅速解决住房的强烈压力。

这就造成一种潜在的不匹配：

**较晚形成的稳定挣钱能力 + 持续不变的结婚时点 + 昂贵的住房**

这是父母的资金转移可能变得日益重要的一条路径。

来自中国城市的较晚证据显示，父母为成年子女购房提供支持已变得非常普遍。

来源：

- https://www.sciencedirect.com/science/article/pii/S0264275123001221

## 为什么这对父母很重要

更长的教育意味着父母要更长时间地供养子女。

如果结婚与住房在进入劳动力市场后不久就紧随而来，父母的支持可能还会继续延伸到：

- 首付
- 婚礼
- 育儿

因此，成年人的独立可以被推迟或被重新定义，其原因不是年轻人什么都不做，而是一个社会意义上完整的成年期的门槛变得更贵了。

## 一份更好的成年期时间线

未来的数据集不应只记录一个成年年龄，而应记录：

| 事件 | 时点 |
|---|---|
| 离开学校 | |
| 开始全职工作 | |
| 第一份稳定工作 | |
| 离开父母家 | |
| 结婚 | |
| 独立住所 | |
| 购置住房 | |
| 第一个孩子 | |
| 停止接受父母经济支持 | |
| 开始定期赡养父母 | |

然后追问这些里程碑之间的间隔是在拉大还是在缩小。

## 我们知道什么

来自 1982–2005 年的结构性研究：

- 完成学业的时点后移；
- 进入劳动力市场的时点后移；
- 结婚时点仅小幅后移；
- 生育时点仅小幅后移；
- 城市居民表现出一定程度的个体化增强；
- 整体过渡仍然有结构、且高度有序。

## 我们不应推断什么

不要推断：

- 每个年轻人都遵循众数次序；
- 城市与乡村路径相同；
- 2005 年之后结婚并未进一步推迟；
- 该研究直接测量了私人愿望；
- 有序的次序意味着低压力或低选择。

## 研究空白

- 按性别与城乡身份划分的确切里程碑年龄
- 2005–2025 年该次序的延续情况
- 首次购房时点
- 父母资金转移的时点
- 第一次自愿换工作
- 迁移时点
- 成年子女何时开始向父母反向转移
- 关于年轻成年人认为婚前必须完成哪些事的质性访谈

核心教训是：

> **中国 1982 至 2005 年的成年期过渡，在求学与就业上变得更晚，在城市中变得稍多个体化，在资金上也变得更复杂——却没有丧失一个出人意料地强的社会次序。**
