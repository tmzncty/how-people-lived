## 比较维度

每个世代最终应在以下维度上可比：

| 维度 | 问题 |
|---|---|
| 童年物质生活 | 住房、食物、家庭物品、交通 |
| 学校 | 预期辍学年龄、考试路径、家庭投入 |
| 第一份工作 | 分配、市场搜索、迁移、工作流动 |
| 住房 | 家庭住房、分配、购买、租赁、父母支持 |
| 婚姻/家庭 | 时间、同住、经济前提、第一个孩子 |
| 沟通 | 信件/电话/PC/移动/AI |
| 消费 | 哪些物品标志改善或常态 |
| 中年 | 子女投入、父母照料、住房、事业、个人储蓄 |
| 祖辈照料 | 照料强度、持续工作、转移 |
| 晚年 | 子女、雇主养老金、社会保险、储蓄、同住 |
| 历史断裂 | 战争、改革、互联网、疫情、AI |

## 家庭支持警告

代际同住下降并不意味着家庭支持消失。

基于人口普查的研究报告了 65 岁以上与成年子女同住的比例从 1982 年的约 **69.4%** 降至 2010 年的 **51.7%**。

与此同时，研究记录了：

- 单独居住但附近；
- 财务转移；
- 频繁接触；
-  substantial 孙辈照料。

因此，后期生活的"独立"应以与年轻成人独立相同的方式分解。

## 不要强迫对称

并非每个世代都有相同的有意义里程碑。

对某些世代，决定性问题是学校获取。

对另一些，是第一份工作是否终身。

对另一些，是住房是否必须购买。

对另一些，是认知工作是否现在与 AI 分担。

对老年人，中心问题可能不是 60 岁是否意味着养老金支持的退休、持续工作、孙辈照料、老人照料，还是这些的结合。

比较应保留这些不对称，而非假装每个世代面对相同的问题态度不同。
