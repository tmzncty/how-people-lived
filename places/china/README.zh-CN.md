# 中国

本目录通过**特定人群、地点、出生世代与时期**来重建中国的日常生活，而不是给出一个单一的国家刻板印象。

本项目有意把政治年表放在次位。制度与政策只在确实改变了上学、工作、住房、迁移、婚姻、家庭消费、退休或日常基础设施的地方出现。

## 核心规则

> **不存在单一的历史上的“中国人”。**

只要证据允许，始终区分：

- 城市 / 农村；
- 地区；
- 受教育程度；
- 职业；
- 性别；
- 家庭资源；
- 迁移者 / 非迁移者；
- 在相关场合区分单位就业 / 非单位就业；
- 年龄与出生世代。

同一年里，一个上海学生、一个农村少年、一个县城学徒、一个外来务工者和一个城市职工，面对的可能是完全不同的生活菜单。

## 历史断裂与人生视野笔记

### 1935–1955

- [中国，1935–1955：同一世代，几种截然不同的未来](china-1935-1955-life-horizon-shift.zh-CN.md)

追踪战前的教育与职业可能、城乡分岔、战时流离、内迁就学、战后恢复、婚姻规则、教育与城市单位生活。

### 1982–2005 结构性成年过渡

- [中国，1982–2005：成年变了，但顺序仍出乎意料地有序](transition-to-adulthood-1982-2005.zh-CN.md)

这篇基于普查的笔记是对一切过于简单的现代化叙事的重要校正。完成学业与进入劳动力确实推后了，但结婚与生育推后得少得多；城市个体化有所上升，而整体顺序仍然高度有序。

### 1985–2005

- [中国，1985–2005：生活菜单变宽的时代——也更难穿行](china-1985-2005-life-horizon-shift.zh-CN.md)

追踪单位就业、劳动力流动放宽、农村外出务工、高等教育扩张、家庭收入、住房与就业脱钩、手机、电脑与婚期变化。

### 打包式成年 → 组装但仍有序的成年

- [中国，约 1980 年代至 2000 年代：从打包式成年到组装式成年](from-bundled-to-assembled-adulthood.zh-CN.md)

较早的城市成年往往可以强力打包在：

**工作 + 住房 + 福利 + 本地社会网络 + 养老前景**

之后的成年则越来越多地要求分别协调：

**教育 + 雇主 + 城市 + 住房 + 婚姻 + 对父母的义务 + 退休保障**

但这并没有抹掉旧的顺序。更准确的说法是：

> **被分别管理的项目变多了，而“上学 → 工作 → 结婚 → 生育”仍然是一个有力的脚本。**

## 文学使用

中国文学应当用仓库其他地方相同的物质复原方法来读。

当故事里出现自行车、单位、宿舍、火车旅行、收音机、电视、冰箱、电话、大学名额、分配的房间、外出务工、商品房、父母出的首付、考研、公务员考试、平台工作、网课、远程面试、视频会议、AI 助手或退休时，问一问：

1. 这对故事所写的人群有多普遍？
2. 它要花多少钱？
3. 什么基础设施支撑着它？
4. 什么更旧的系统仍与它并存？
5. 拥有它或能用到它，对这个人的未来意味着什么？
6. 它解决、制造或推迟了哪些别的人生项目？
7. 它改变了成年的顺序，还是主要让原有顺序变得更昂贵？
8. 这个人物是在奔向一个稳定的终点，还是在保留日后改向的能力？
9. 这项技术或制度是在什么年龄进入这个人物的生活的？

目标不是把文学变成统计。

而是复原当年的读者无需解释就能理解的那个实践世界。
