# 中国的千禧一代日常生活

这个文件夹用的是**同龄群史**的方法，而不是把“千禧一代”当成一个照搬进来的固定人口学身份。

锚点是大约 **1985—1995** 年出生的人，尤其是“1990 年前后出生”这个有用的思想实验。

主要序列是：

- 1990 年代后期的童年；
- 个人电脑互联网 2000 年代的青春期；
- 2010 年代初智能手机／移动互联网转型期的青年期；
- 被新冠疫情打断的成年早期。

## 为什么这个同龄群有用

一个 1990 年前后出生的人可以记得：

- 流媒体之前的电视；
- 个人手机之前的固定电话；
- 家庭宽带普及之前的网吧；
- 永远在线的移动社交媒体之前的 QQ；
- 流媒体曲库之前的 MP3 文件；
- 完全基于 App 的出行之前的纸质车票；
- 移动支付变成环境要素之前以现金为主的日常生活；
- 网上购物从“新鲜事物”变成“本来就有”的过程；
- 从“打电话能找到人”到“在网上一直能被找到”的转变。

这让这个群体特别适合用来重构**从按时刻表、绑定地点的信息，走向环境化的数字生活**这一转变。

## 关键的研究规则

不要把这里变成一个怀旧展厅。

每一件怀旧物品都应当回答：

1. 它解决了什么问题？
2. 它有多贵？
3. 谁用得起／用得上？
4. 它取代了什么更早的做法？
5. 它后来又被什么更新的做法取代？
6. 过渡期有多长？
7. 它怎样改变了时间、隐私、友谊、距离或无聊？

目标不是证明过去更好。

而是找回**一场发生在一个人有生之年内部的技术转型的质地**。
