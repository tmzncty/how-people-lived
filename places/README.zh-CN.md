# 地点与时期

历史的生活是地方性的。

一项技术可能在某个城市是寻常的，在某个村庄却罕见；一条铁路可能改变一条走廊，却让另一个地区继续依赖更旧的运输方式；一件家用电器作为发明可能已有数十年历史，却仍然缺席于某个特定人口的大多数家庭。

因此本目录把地点与时期明确写出。

[`indonesia/kawah-ijen-sulfur-miners-labor-tourism-2010-2026.zh-CN.md`](indonesia/kawah-ijen-sulfur-miners-labor-tourism-2010-2026.zh-CN.md)

## 未来的地点条目应如何组织

一个地点条目不应试图一次性概括整个社会。

宁可选择一个具体的范围，例如：

- 城市家庭
- 农村家庭
- 工厂工人
- 学童
- 职员
- 铁路乘客
- 租户家庭
- 农场家庭
- 寄宿公寓住户

然后指定一个足够窄的时期，使基础设施与消费条件在条目内部不会变得面目全非。

## 鼓励比较，排序不是重点

跨地点比较有助于揭示不均衡的普及与不同的物质系统。它不应被简化为一条"先进"与"落后"的单一阶梯。

一项技术可以解决某一种劳动，同时制造对另一种基础设施的依赖。更旧的系统在当地条件下可以仍然高效。不同的家庭安排可能以不同方式分配劳动。

有用的问题是：

> **在这里、在这个时候，是什么系统让寻常生活得以运转？**
