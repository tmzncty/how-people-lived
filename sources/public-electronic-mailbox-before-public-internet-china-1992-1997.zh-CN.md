# 在公共 Internet 之前先有“公共电子信箱”：中国 1992—1997 的异步数字通信证据升级

> **定位：这是对 `topics/before-mass-internet-access-ladder-china-france-1980s-1997.zh-CN.md` 的证据升级与机制补丁，不是另造一套“中国互联网起源史”。**
>
> 既有专题已经区分“网络存在—机构联网—有限国际通信—全功能 Internet—公共接入—普通人可及—大众化”。本 note 补一个此前尚未单独展开的中间层：**一个人或机构可以已经拥有可收取异步数字消息的“电子信箱”，却仍然不是后来意义上的 Internet 用户。**

## 1. 本轮问题

常见叙事很容易把 1990 年代初压成两种状态：

```text
1994 年以前：没有 Internet，所以没有电子邮件生活
1994 年以后：Internet 接通，所以开始有电子邮件
```

现有材料不支持这种二分。

更精确的问题是：

1. 1994 年全功能国际 Internet 连接之前，是否已经存在**面向社会提供**的电子信箱服务？
2. 这些服务和科研机构的国际电子邮件实验有什么不同？
3. 它们又和后来 Internet email / Webmail 有什么不同？
4. 对普通生活而言，“有公共电子信箱服务”离“大多数家庭可以发 email”还有多远？
5. 1995 年以后，旧电子信箱网络和 Internet 是替代关系，还是曾经并存、互联和共同分发同一内容？

本轮答案是：

> **公共电子信箱服务确实早于中国大众 Internet；但“服务向社会开放”与“普通家庭广泛使用”之间仍有巨大距离。更准确的历史不是邮件从 0 变成 1，而是异步数字邮箱先在封闭/专用服务中存在，再与 Internet 邮件和 Web 逐渐发生网关、并存与界面迁移。**

## 2. 1992 年北京：已经有“像投信、取信一样”的公共电子信箱

1992 年 6 月 28 日《人民日报》新闻简报记录，北京公用电子信箱系统于 6 月 26 日开通：

- 系统由电信部门建立；
- 与用户计算机连接；
- 用户可以把信息送入别人的信箱；
- 收信者用密码打开自己的信箱取出信息；
- 开通时已有“一百多个用户”。

当前可访问文本是历史报纸的数字转录页，本轮没有取得原版报纸图像，因此把它视为**同时代报纸文本的可靠 locator / 转录证据**，而不是已核验版面原件。

来源：

- 《人民日报》1992-06-28，《北京市公用电子信箱系统开通》数字转录：<https://cn.govopendata.com/renminribao/1992/06/28/1/>

### 2.1 它改变了什么？

这条材料至少证明，1992 年中国城市电信体系内已经存在一种面向用户的异步数字通信服务，其生活逻辑非常接近“邮箱”：

```text
发送者不要求收件者同时在线
→ 消息先存入远端信箱
→ 收件者以后再凭密码取出
```

因此，本轮加入一个窄机制：

### `mailbox-before-Internet` — Internet 之前的数字邮箱

**异步数字消息并不以全功能 Internet 为必要前提。**

对生活史来说，这比“某条 X.25 链路已经运行”更接近实际使用层，因为它已经出现：

- 个人/组织可拥有一个持续存在的收件空间；
- 通信不再要求双方同时在电话两端；
- 内容可以先存后取；
- 身份验证开始通过“账号/信箱 + 密码”完成。

但是，一百多个用户恰恰也说明它距离大众化极远。

### 2.2 它不证明什么？

这条新闻不能被写成：

- “1992 年普通北京家庭已经普遍使用电子邮件”；
- “1992 年中国已经接入 Internet”；
- “这些信箱就是今天的 `name@domain` Internet email 地址”；
- “每个‘用户’都是一个自然人家庭用户”。

报道只写“用户”，并未给出个人/单位构成，也没有给出开户费、通信费、终端要求、调制解调器要求、使用地点和日常频率。

因此准确状态是：

```text
公共服务存在：已证实
有真实用户：已证实（100+）
用户构成：不知道
普通家庭可负担性：不知道
大众常态：明确不能由现有证据推出
```

## 3. 上海 1992—1995：同一城市里，ChinaMail 与 Internet 曾经同时处于千户级

上海市政府保存的《上海通志干部读本》把上海电子信箱和 Internet 分成两个不同的增值电信业务条目。其记录为：

### 电子信箱（MHS / E-Mail）

- 1992 年 6 月：上海市长途电信局电子信箱系统试运行；
- 1993 年 4 月：与福州等地联通；
- 1994 年：与北京、美国 Telemail、日本 ATI、新加坡 stems、意大利 omega400 的 **X.400** 网络互联，并与韩国、青岛等测试联通；
- 1995 年 7 月：加入全国联网，与北京等 9 城市构成子系统，并与北京互为国际出口备用路由；
- 地方志称由此建成中国电子信箱系统 **ChinaMail**；
- 1995 年上海用户为 **0.13 万户（约 1300 户）**。

### Internet

同一节紧接着记录：

- 1995 年初，中国公用计算机互联网上海节点建成；
- 1995 年 5 月 17 日开放国际 Internet 业务；
- 1995 年上海 Internet 用户为 **0.11 万户（约 1100 户）**。

来源：

- 上海市政府，《上海通志干部读本》，PDF 第 322—323 页（PDF 内页码；文本抽取对应 P321–P322）：<https://www.shanghai.gov.cn/shanghai/newshanghai/%E4%B8%8A%E6%B5%B7%E9%80%9A%E5%BF%97.pdf>

### 3.1 这里最重要的不是“谁用户更多”

1300 与 1100 看起来很诱人，但不能拿来宣布：

> “1995 年 ChinaMail 比 Internet 更普及。”

理由包括：

- 两个业务的“用户/户”统计口径未必完全相同；
- 一个账号是否对应一个单位、家庭或个人并不清楚；
- 年内开放月份不同；
- 不能从上海外推全国。

这个同页记录真正能安全证明的是：

> **1995 年上海的公共 Internet 并没有瞬间清空旧的电子信箱体系；ChinaMail 与 Internet 是可以同时存在、分别统计、规模都仍很小的两套服务。**

这让原来的“网络可及性阶梯”多出一个重要横向维度：

```text
时间不是只有一条升级线。
同一年里可能并存：
X.400 / MHS 电子信箱
+ 公用分组数据网
+ 全功能 Internet
+ 电话、传真、寻呼
```

普通人面对的是**渠道组合**，不是教科书式协议替换。

## 4. 新机制：`addressable absence` —— 人不在线，仍有一个数字位置可以等消息

此前仓库已经讨论：

- 寻呼机让人“可被找到但不能直接通话”；
- 语音信箱让声音可以等人回来；
- CFido 让用户短暂拨号下载信包，再离线阅读和写作。

公共电子信箱提供了另一个不同机制：

### `addressable absence` — 可寻址的缺席

一个人/单位即使当时没有和发送者同步连接，消息仍然可以被放进一个**持续存在、受密码保护的数字容器**里。

这里真正变化的是：

```text
通信地址
从“此刻有人接听的线路”
逐渐变成
“即使人不在，也继续存在的数字收件位置”
```

这和 Internet 是否已经大众化是两个问题。

一个社会可以先形成很小规模的“可寻址数字缺席”，很多年以后才形成普遍的 Internet 在线生活。

## 5. 新机制：`service identity before Internet identity` —— 有数字账号，不等于有 Internet 身份

今天看到“电子信箱”很容易自动脑补成：

```text
name@example.com
SMTP / POP / IMAP
Webmail
全球 Internet 可达
```

这会产生严重后见之明。

1990 年代初的公共电子信箱可能属于：

- MHS / X.400 体系；
- 电信运营商自己的账号与地址空间；
- 特定城市/全国业务网；
- 与其他邮件系统通过网关互联，而不是天然处在开放 Internet address space 内。

因此本轮加入：

### `service identity before Internet identity`

> **“我在一个电子通信服务里有账号/信箱”可以早于“我拥有一个全球 Internet 邮件身份”。**

这和前面银行卡研究里的“凭证可携早于账户可携”有相似结构：可见表面已经很现代，但后台可达范围仍由具体网络和网关决定。

## 6. 1995 年以后不是简单替代：同一份电子报可同时走 Internet、图文电视和 ChinaMail

一篇 2000 年关于中国网络新闻传媒的回顾记录，1995 年 10 月 20 日《中国贸易报·电子版》开播时，内容同时经由三条渠道传播：

1. 国际互联网；
2. 中央电视台图文电视；
3. 全国电子信箱信息服务系统 ChinaMail。

来源：

- 新浪科技转载/刊载的 2000 年材料，《资料：中国网络新闻传媒新阵列形成》：<https://tech.sina.com.cn/news/it/2000-04-19/23203.shtml>

这条证据不是 1995 当天原始系统日志，因此证据等级低于同年原始页面；但它提供了一个非常重要的近同时代结构证据：

### `parallel digital distribution` — 平行数字分发

同一信息产品不必“从旧网络迁移到新网络”以后旧网络才消失。

更现实的过渡可能是：

```text
一份内容
├─ Internet / Web
├─ ChinaMail
└─ 图文电视
```

不同用户根据自己现实拥有的终端、账号和网络进入同一内容。

这与 CFido 专题里的 `transport coexistence` 相互支持，但这里的新增点不是再命名“共存”，而是：

> **用户的数字身份和收件位置本身也处在多个地址空间中；同一内容可以被投影到这些不同地址空间，而无需所有受众先迁到 Internet。**

## 7. 海外对照：CompuServe 也证明“电子邮件用户”可以早于“Internet 用户”

1989 年 7 月《Washington Post》回顾美国消费联机服务时写道：

- CompuServe 与 The Source 在 1979 年面向个人计算机用户推出商业联机服务；
- 用户通过电话线连接后可以收发电子邮件；
- 到 1989 年，CompuServe 宣称已有超过 50 万订户；
- 当时 CompuServe 仍按连接时间收费，并要求电脑/终端、modem 和通信软件。

来源：

- Lawrence J. Magid, “Information Services Companies Develop New, Improved Products,” *The Washington Post*, 1989-07-17: <https://www.washingtonpost.com/archive/business/1989/07/17/information-services-companies-develop-new-improved-products/689795d6-b914-4e63-a597-f0a35ec54682/>

后出的 CompuServe 历史资料又把 **1989 年**标为其 proprietary email system 与 Internet email 打通的重要节点。这里应把“后来公司史/回顾”与 1989 同期新闻分开使用。

来源：

- CompuServe current historical/about page: <https://www.compuserve.com/home/about.jsp>
- 后来历史回顾（仅作 gateway date 辅助）：<https://www.aol.com/news/compuserve-earns-state-historical-recognition-110140253.html>

### 7.1 跨国共同点

美国 CompuServe 和中国公共电子信箱共同说明：

> **“在线服务中的邮箱”不等于“Internet 邮箱”。**

两者都可以先在封闭或专用服务内部形成：

- 账号；
- 密码；
- 异步收件；
- 离线的人以后再取消息；
- 后来再通过 gateway 扩大可达范围。

### 7.2 不应抹掉的差异

不能因为结构相似就把两边写成同一种社会普及轨迹。

1989 年 CompuServe 已是数十万订户级的消费商业联机服务；北京 1992 年公用电子信箱开通时报道只有一百多个用户，上海到 1995 年 ChinaMail 也只是千户级。

因此真正有意义的跨国差异是：

> **同一种“非 Internet 异步数字邮箱”机制，可以在一个国家已经进入较大规模消费市场，在另一个国家仍主要处于极窄的电信增值服务层。协议类别并不决定社会普及速度；终端分布、价格、电话线、电脑拥有、市场组织和服务入口才决定它何时进入普通生活。**

## 8. 对“1994 前/后”的时间线修正

这一轮以后，中国早期数字通信最好至少写成：

```text
1987：科研机构有限功能国际电子邮件
     ↓
1988 起：CNPAC 等分组数据网络
     ↓
1992：城市公用电子信箱已出现真实用户
     ↓
1993：CHINAPAC 等公用数据通信进一步扩展
     ↓
1994-04-20：全功能国际 Internet 连接
     ↓
1995：ChinaMail / X.400 与公共 Internet 在城市中并存
     ↓
1995—1997：公共 Internet 服务扩展，但家庭可及和大众化仍滞后
```

重点不是把 Internet 重要性降低，而是恢复**不同通信能力在不同日期出现**的事实。

1994 年仍然是“全功能 Internet 国际连接”的清晰制度/技术边界；它只是不能承担“此前所有数字通信均不存在”的含义。

## 9. 这改变了哪些普通生活问题？

### 9.1 通信方式

新增一种此前没有充分独立列出的路径：

```text
纸信 / 电报 / 电话
并不是直接跳到 Internet email
中间还存在公共电子信箱、X.400/MHS、封闭联机服务等异步数字邮箱
```

### 9.2 信息获取

如果电子刊物、数据库或通知通过电子信箱系统分发，一个人可能已经接收“数字出版物”，但仍从未访问 Web。

### 9.3 就业与单位生活

目前没有足够证据证明 1992—1995 普通求职者广泛通过 ChinaMail 求职，因此**本轮不把它写成普遍就业渠道**。

更可能的早期影响来自单位、机构和专业用户，但用户构成仍待补。

### 9.4 社交关系

“邮箱可等人回来”的结构允许异步通信，但现有中国材料不足以证明普通个人把 ChinaMail 大规模用于交友或私人通信。

### 9.5 线上/线下身份

账号 + 密码 + mailbox 已经构成一种持续数字身份，但不能自动等同于今天的 Internet identity。

### 9.6 历史可见性

Web archive 天生更容易让后人看到 1995 年以后的网站，却可能让此前/同期的 X.400、MHS、专用邮箱网络显得“不存在”。

因此：

> **历史可见性向 Web 倾斜，不等于当时所有数字生活都发生在 Web。**

## 11. 反例与后见之明风险

### 风险 A：把“公用”误读成“大众”

电信业务名称里的“公用/公共”主要说明服务性质或面向社会开放，并不证明普通家庭广泛采用。

1992 北京只有一百多个用户，就是最直接的警告。

### 风险 B：看到 “E-Mail” 就自动补成 Internet SMTP 邮箱

地方志同时写 “MHS 或 E-Mail”，并明确记录 X.400 互联。不能把今天的协议和地址格式倒投回去。

### 风险 C：用 1995 Internet 的出现宣布旧邮箱网络立即死亡

上海同年分别记录 ChinaMail 与 Internet 用户；《中国贸易报》又被记述为同时经三种数字渠道分发。

### 风险 D：把专业/单位用户写成普通家庭

当前中国材料对用户职业、家庭/单位性质仍不足。除非找到开户表、用户调查、广告、教程或个人日记，否则不要把“用户”写成“家庭消费者”。

### 风险 E：把海外消费规模当成中国应有轨迹

CompuServe 只证明另一条历史路径确实存在，不证明中国“本来也应该”沿同样速度发展。

## 12. 尚未确定

下一轮若继续这条线，最有价值的不是再写一篇概念史，而是找以下原始材料：

- 1992 北京公用电子信箱开户办法、资费表和终端要求；
- 北京一百多个早期用户的个人/单位构成；
- 1992—1995 上海 MHS / ChinaMail 用户手册；
- ChinaMail 地址格式、登录软件、拨号接入号和实际 UI；
- 1995 上海“0.13 万户”与 Internet“0.11 万户”的原始统计表及口径；
- 1995《中国贸易报·电子版》在 ChinaMail 内的实际消息格式；
- ChinaMail 与 Internet email 的 gateway 何时、如何开放，是否保持原账号标识；
- 同时代个人用户关于“电子信箱而非 Internet email”的日记、BBS、教材或操作记录。

## 13. 与重点矩阵的连接

| 矩阵项 | 本轮新增 |
|---|---|
| 教育 | 暂无足够普通学生使用证据；保留为缺口 |
| 就业 | 不宣称已成为大众求职渠道 |
| 住房 | 无直接新增 |
| 婚姻家庭 | 暂无普通家庭使用强证据 |
| 迁移 | 理论上可异步跨地通信，但实际普通迁移者使用证据不足 |
| 照护 | 无直接新增 |
| 非正规劳动 | 无直接新增 |
| 长期中断 | `addressable absence` 使短期不在线不再等于消息不可达 |
| 证件与记录 | 账号 + 密码形成服务内数字身份；非 Internet 身份 |
| 通信方式 | **公共电子信箱 / X.400 / MHS 被补进邮政—电话—Internet 之间的真实路径** |
| 互联网平台 | 明确“电子邮箱服务存在”与“Internet/Web 平台存在”不是同义 |
| 信息获取 | 同一电子内容可投影到 ChinaMail / Internet / 图文电视 |
| 社交关系 | 异步数字通信能力存在；大众私人使用尚未证实 |
| 未来预期 | 暂无强第一人称未来想象，不制造 |
| 线上/线下身份 | **service identity before Internet identity** |
| 平台消失与记忆保存 | **Web 保存偏差会系统性压低非-Web 数字生活的历史可见性** |

---

## 14. 本轮对“人怎么活着”的最小修正

这一轮真正改变的不是“把中国联网日期提前两年”。

更重要的是：

> **一个人可以先学会“有一个数字地方等着收消息”，很多年以后才学会“上 Internet”。**

1992 年的公共电子信箱已经包含账号、密码、存储和异步收取；1995 年上海的 ChinaMail 与公共 Internet 仍并排存在；类似的 CompuServe 历史又表明，这种“邮箱先于开放 Internet”的路径并非中国特例。

所以普通人的数字生活史不应只有：

```text
没上网 → 上网
```

而应允许：

```text
没有数字地址
→ 在某个封闭/公共电信服务中拥有邮箱
→ 邮箱通过网关扩大可达范围
→ Internet 地址与 Web 界面逐渐成为主流
→ 邮箱最终看起来像“Internet 本来就有的东西”
```

最后那一步最容易制造后见之明，也最值得继续考古。
