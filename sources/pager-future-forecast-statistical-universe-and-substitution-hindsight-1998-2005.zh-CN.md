# 1999 年的人并不知道 BP 机会在五年内消失：寻呼未来预测、统计口径冲突与技术替代的后见之明风险（1998—2005）

## 0. 这份 source note 补什么

本仓已有：

- `topics/communication-and-the-cost-of-living-far-away.md`；
- `topics/from-please-page-me-to-why-didnt-you-reply-reachability-pagers-mobile-phones-and-presence-states-china-1984-2026.zh-CN.md`。

前者讨论通信怎样降低异地生活成本，后者已经完整讨论 BP 机、手机、OICQ/QQ presence 与“可达性主权”。因此本文**不再另写一部寻呼史**。

本文只补一个此前没有被钉牢的时间感问题：

> **如果把自己放回 1999 年底，一个普通消费者、学生、通信从业者或研究者，是否真的已经能够知道“BP 机马上会被手机淘汰”？**

答案是否定的。

后来的技术谱系很容易把历史压成：

`固定电话 → BP 机 → 手机 → QQ / 微信`

仿佛后一项一出现，前一项的死亡就已经显而易见。

但 1999 年的同期材料显示，当时仍有人相当认真地预测：

- 寻呼用户继续大幅增加；
- 农村、学生和专业用户仍是增长市场；
- 高技术含量的新寻呼系统可以延续行业生命；
- 手机虽然增长很快，但购买力约束会使其难以迅速覆盖同一人群。

真正值得保留的不是这个预测“错得有多离谱”，而是：

> **技术替代在后来看来可以非常整齐，在当时人的未来里却往往是多条仍可能继续生长的路线。**

## 1. 1999-12-08：同期专家仍然给寻呼业一个扩张型 2005

### 证据 F1：光明日报 / 新浪同期报道

1999-12-08，《光明日报》的一篇报道《寻呼业仍大有可为》由新浪保存到今天：

- https://tech.sina.com.cn/news/computer/1999-12-08/12840.shtml

报道采访南京邮电学院通信工程系王世顺。文章明确记录：

- 当时有人已经因为手机中文短信、资费下降以及美国寻呼公司倒闭而判断无线寻呼前景不妙；
- 受访者反而对寻呼业保持乐观；
- 文中给出的当时寻呼用户数约为 7000 万；
- **预计 2005 年寻呼用户可达到 1.3 亿**；
- 文中同时称手机用户约 3800 万、年底可能超过 4000 万，并认为到 2005 年手机同样达到 1.3 亿的可能性“不大”；
- 建议重点发展农村用户、大中小学生和股民等专业用户，并走高技术路线。

**证据等级：B（同期报刊采访）。**

这不是国家统计口径，也不是抽样调查，不能拿“7000 万”去覆盖其他统计序列；1.3 亿更是预测而不是事实。

但它在研究“同时代人的未来想象”时非常强，因为它把一个后来失败的未来保存了下来。

### 1.1 后见之明风险

今天很容易说：

> “1999 年手机已经起来了，谁都该知道 BP 机没前途。”

F1 直接否定这种写法。

1999 年底至少存在一种当时并不荒谬的判断：

```text
手机继续增长
+
寻呼凭低成本继续覆盖学生 / 农村 / 专业市场
+
寻呼向高功能系统升级
→ 两种个人移动通信长期并存
```

这个未来后来失败了，不等于它在 1999 年就是“明显错误”。

## 2. 国家统计局序列：在同一套口径里，替代确实发生得极快

### 证据 F2：国家统计局《中国统计年鉴 2005》

国家统计局 2005 年年鉴“邮电业务量”长期序列：

- https://www.stats.gov.cn/sj/ndsj/2005/html/P1640C.HTM

以及“邮电业务基本情况”：

- https://www.stats.gov.cn/sj/ndsj/2005/html/P1639C.HTM

表中单位为“万户”。按该序列：

| 年份 | 年末无线寻呼用户（万户） | 年末移动电话用户（万户） |
|---|---:|---:|
| 1995 | 1739.2 | 362.9 |
| 1996 | 2536.2 | 685.3 |
| 1997 | 3254.6 | 1323.3 |
| 1998 | 3908.2 | 2386.3 |
| 1999 | 4674.5 | 4329.6 |
| 2000 | 4884.3 | 8453.3 |
| 2001 | 3606.4 | 14522.2 |
| 2002 | 1872.1 | 20600.5 |
| 2003 | 1057.6 | 26995.3 |
| 2004 | 395.2 | 33482.4 |

### 证据 F3：2005 年 12 月通信行业统计月报

信息产业部/现工信部保存的 2005 年 12 月统计月报：

- https://www.miit.gov.cn/gxsj/tjfx/txy/art/2020/art_b18e780c481745239acd2fc69364e2a3.html

给出：

- 移动电话用户：39342.8 万户；
- 无线寻呼用户：97.1 万户；
- 无线寻呼比上年末减少 298.1 万户。

**F2/F3 证据等级：A（政府统计表）。**

它们证明的只是**这一统计体系里的序列**，不是“市场上一切曾经被叫作寻呼用户的数字都必须与它相同”。

### 2.1 用同一序列比较，1999 的 2005 未来发生了完全不同的结果

如果只在 F2/F3 的统计宇宙内比较：

```text
2000 无线寻呼：4884.3 万
→ 2005：97.1 万
```

而移动电话：

```text
2000：8453.3 万
→ 2005：39342.8 万
```

这不是缓慢的世代替换，而是非常陡的基础设施退出。

因此，1999 年的“2005 年寻呼 1.3 亿”预测不仅没有实现，现实方向几乎相反。

## 3. 但不能马上说“后来资料里的 8400 万就是错的”：统计宇宙本身有冲突

### 证据 F4：中国电信博物馆后来的机构史

中国电信博物馆 2023 年通信史文章：

- https://museum.chinatelecom.com.cn/yj/txkp/202303/t20230327_73688.html

写道：

- 1998 年国内寻呼机用户“突破 6546 万”；
- 2000 年“全国寻呼用户达到 8400 万户”；
- 2002 年以后，寻呼机构曾尝试网上寻呼、Web 网页寻呼、网上秘书、电子邮件等业务；
- 2005 年 8 月、9 月用户又快速下降；
- 2007 年多数地区无线寻呼网络退出。

**证据等级：C/B 边界：后来机构史整理，可用于研究后来机构如何叙述行业，不应在未解决来源口径前覆盖同期统计表。**

### 3.1 这两个序列不能直接拼在一起

国家统计局序列：

- 1998：3908.2 万；
- 2000：4884.3 万。

中国电信博物馆后来的行业史：

- 1998：6546 万；
- 2000：8400 万。

差异已经大到不能用四舍五入、年内月份差异解释。

因此永久保留：

> **`same metric label != same statistical universe`**

即使都写“寻呼用户”，也可能涉及：

- 不同运营主体是否被纳入；
- 公用网 / 专用网是否同时统计；
- 注册用户、在网用户、付费用户、设备保有量是否混用；
- 行业汇总与国家统计报表来源是否不同；
- 年末数、年中数、历史峰值是否被后来叙述压成同一年；
- 后来机构史是否引用了另一套行业来源。

**本轮没有找到足以判定 6546 万 / 8400 万来源宇宙的原始统计表。以上只是待核解释，不是结论。**

因此 canonical topic 里以后若同时出现这些数字，应该按 source family 并列，而不是挑一个“看起来更像历史常识”的数字当唯一真值。

## 4. 2000：寻呼不只是被手机替代，它的词汇还迁进了 Internet

### 证据 F5：腾讯历史档案保存的 2000 年文本

腾讯公司当前历史文章：

- https://www.tencent.com/zh-cn/articles/80257.html

页面标注日期为 2000-05-27，并说明 2000-05-28《人民日报》转载。文中在 QQ 同时在线用户首次突破 10 万时，把 QQ 称为：

> “国产免费网上寻呼软件”

这里要特别谨慎：

- 当前腾讯 URL 是今天仍在线的公司历史页面；
- 本轮没有取得 2000 年该页面的 archive capture；
- 因而它可以作为**保存下来的历史文本线索**，不能拿来复原 2000 年腾讯网页的 HTML、DOM、charset 或视觉界面。

但“网上寻呼软件”这个词仍然很有解释力。

### 4.1 术语迁移不是网络层连续

这不等于：

`QQ = 无线寻呼网的 Internet 版本`

也不等于 QQ 消息经过传统无线寻呼台。

它说明的是：当时的人需要解释一种新的即时通信方式时，**“寻呼”仍然是足够熟悉的社会技术类别**。

旧技术可以出现三种不同命运：

1. **硬件 / 网络退出**；
2. **用户行为被别的基础设施接管**；
3. **旧术语迁移到新媒介，帮助人理解新系统。**

因此技术史不能只画设备替代图，还要画概念迁移图。

## 5. 海外对照：1998 年美国也有人认为“两向寻呼”会开一个新时代

### 证据 F6：RCR Wireless，1998-03-23

- https://www.rcrwireless.com/19980323/archived-articles/two-way-to-bring-more-users-and-money-to-industry

同期行业报道把 two-way paging 描述为可能把寻呼行业带到更高用户和收入水平的新阶段，并引用预测：窄带 PCS 用户到 2001 年大幅增长，寻呼收入同期翻倍。

### 证据 F7：RCR Wireless，1998-08-17 / 1998-08-31

- https://www.rcrwireless.com/19980817/archived-articles/carriers-approach-two-way-with-different-strategies
- https://www.rcrwireless.com/19980831/archived-articles/bellsouth-tackles-two-way-market

报道直接使用“new age of paging”一类语言，并介绍可收发较长文本、电子邮件、全国漫游、送达 / 阅读确认的双向寻呼设备与网络。

**证据等级：B（同期美国行业媒体）。**

### 证据 F8：Washington Post，2004-03-30

- https://www.washingtonpost.com/archive/business/2004/03/30/pager-firms-will-merge/f369f409-2455-45c9-bd14-a66c5a3f3aa8/

到 2004 年的回顾里，美国 paging 用户已经从 1998 年约 4500 万峰值下降到约 1200 万，而移动电话用户超过 1.57 亿。

**证据等级：B（后来但接近转折期的报刊回顾）。**

### 5.1 跨国结论

所以“1990s 末有人认为寻呼不会消失，而会升级为双向数据通信”并不是中国特有误判。

美国行业同样曾经投入：

- two-way paging；
- e-mail integration；
- acknowledgement / guaranteed messaging；
- nationwide roaming；
- 更小、更便宜的双向终端。

而后来的主导路线却是蜂窝移动电话 / 移动数据。

共同机制是：

> **当旧网络已经拥有大量用户、站点、营业体系和熟悉的使用习惯时，历史行动者往往有充分理由先想象“升级旧系统”，而不是直接想象它会归零。**

中国需要另外解释的是：

- 寻呼规模和运营主体结构；
- 公用电话作为回拨物理层；
- 手机价格 / 资费下降速度；
- 短信与 OICQ/QQ 等新通信路径；
- “网上寻呼”这一术语和业务尝试。

## 6. 它怎样改变“同时代人的未来想象”研究

### 6.1 新增一类样本：失败的基础设施未来

目前 future-horizon 研究很容易偏向：

- 人准备买什么房；
- 找什么工作；
- 考不考公；
- 是否留在城市。

但基础设施本身也有未来想象。

1999 年的学生如果花钱买 BP 机，她不是在购买一个“明知五年后必死的过渡技术”。

从她当时能获得的信息看，可能同时存在：

- 寻呼仍然便宜；
- 周围同学正在使用；
- 手机仍贵；
- 公用电话仍能完成回拨；
- 专家和行业仍讨论寻呼继续扩张、双向化、数据化。

所以一个后来很短命的消费选择，在当时完全可能是理性的。

### 6.2 `retrospective inevitability / 后见必然性` 风险

以后写任何技术转折，都需要问：

> **当时人有没有理由认为旧系统还会存在五年、十年？**

若答案是“有”，就不能用后来胜出的技术去重写他们当时的决策。

### 6.3 `stranded life infrastructure / 搁浅的生活基础设施`

当技术替代速度远高于家庭资产更新速度时，会出现一种生活成本：

- 刚买的设备迅速失去网络；
- 已付的服务费 / 号码 / 联系习惯失去价值；
- 名片、广告、通讯录里的地址需要重写；
- 家庭和单位必须重新协调“以后怎么找到我”。

本文只提出这个研究方向，本轮还没有得到足够微观材料去估计普通家庭的实际搁浅成本，因此暂不把它写成强结论。

## 7. 证据强度与反例

| Claim | 证据 | 等级 | 边界 |
|---|---|---|---|
| 1999 年存在认真看多寻呼业至 2005 的预测 | F1 | B | 专家采访，不代表社会共识 |
| NBS 序列中寻呼 2000 后极快下降 | F2/F3 | A | 只在该统计口径内成立 |
| 后来机构史给出明显更高的 1998/2000 用户数 | F4 | C/B | 原始统计宇宙未解决 |
| 2000 年保存文本把 QQ 称为“网上寻呼软件” | F5 | B/C | 当前 live-origin 历史页，不是 verified 2000 capture |
| 美国 1998 也存在双向寻呼扩张预期 | F6/F7 | B | 行业媒体与商业预测，不代表全体消费者 |
| 美国寻呼后来也快速衰退 | F8 | B | 美国制度与市场不能直接替代中国 |

### 反例

- 1999 年 F1 开头本身就说，已经有人因手机发展和美国寻呼公司倒闭而判断寻呼前景危险；因此当时并非“所有人都看多”。
- 手机用户在 NBS 序列里 1999 年已接近寻呼、2000 年反超；不能反向塑造一个“没人看见手机来临”的故事。
- 两向寻呼在部分专业、医疗、应急场景并未立刻消失，所以“消费大众市场衰退”不等于所有 paging use case 同时归零。

## 8. 尚未确定

1. 中国电信博物馆所用 6546 万（1998）和 8400 万（2000）的原始统计表、统计单位与覆盖范围；
2. 国家统计局“无线寻呼用户”是否排除了某些地方 / 专用 / 非部属运营体系；
3. 1999 年 F1 中“现有 7000 万”的具体来源；
4. 1998—2001 普通学生、农民工、个体经营者更换 BP 机为手机的真实设备成本与时间；
5. 同一人双持 pager + mobile 的持续时间；
6. “网上寻呼”作为术语在媒体、运营商、OICQ/QQ 用户语汇中的消失时间。

这些都不应用后来常识自动补齐。

---

## 9. 对核心问题的增量

这一轮改变的不是“BP 机最后被手机替代”这个已知事实，而是对**时代时间感**的理解：

> **普通人活在尚未淘汰的技术里，也活在尚未失败的未来里。**

2005 年的人回看 1999 年，很容易把 BP 机看成过渡物；1999 年的人却可能刚刚看到一个拥有数千万用户、仍有人预测继续扩张、还在尝试双向化和 Internet 化的通信体系。

因此研究“人怎么活着”时，不能只记录最后胜出的基础设施。

还必须保存那些当时足以影响购买、职业、联系方式和迁移安排，后来却突然失去未来的系统。
