# 未登记同居、事实婚姻、共享住所与关系凭证：中国 1989–2023

> 状态：交叉研究切片。重点不是判断“同居好不好”，而是把**共同生活事实、婚姻登记、社会承认、共同住所、共同时间、财产与照护安排**拆成不同变量，观察普通人的家庭路线怎样偏离“恋爱—领证—同住—生育”的单一路径。
>
> 与 `tmzncty/old-web-archaeology` 的交叉点：2000 年代中文 Web 中“事实婚姻 / 非法同居 / 同居关系 / 试婚”等词汇与法律分类并不稳定对应；旧页面如果脱离页面日期和当时法律版本，很容易制造时间错置。

## 0. 去重说明：为什么这一包不是既有婚姻专题的改名

仓库已经覆盖：

- 婚姻与婚育时间；
- 离婚后的家庭重组；
- 两地夫妻 / 分址家庭；
- 全职父亲与照护型职业中断；
- 陌生人择偶、相亲和婚恋平台；
- 独居、迁移、租房与通信基础设施。

但现有专题没有把下面这个状态本身单独建模：

```text
两个人已经共同居住、共同消费、互相照护，甚至被周围人当作夫妻
!=
两个人已经取得婚姻登记意义上的配偶身份
```

这和上一轮“结婚以后也可能不住在一起”的分址家庭恰好构成镜像。

两轮合起来，需要把过去常被压成一个变量的“家庭状态”至少拆成三根轴：

```text
relationship credential / 关系凭证：已登记 / 未登记 / 其他制度化形式
space / 空间：同住 / 分址
shared waking time / 共同清醒时间：高重叠 / 低重叠
```

于是：

```text
marriage credential != co-residence
co-residence != marriage credential
same address != shared daily time
```

这不是语义游戏，而会改变一个普通人的住房、财产、照护、职业、迁移和时间安排。

## 1. 证据清单与等级

### A. 最高人民法院民一庭：事实婚姻效力的制度沿革

现存法院系统页面：

- 山东法院网，2021-11-10，《事实婚姻的效力》；
- 单位作者标为“最高人民法院民事审判第一庭”，来源标为《最高人民法院民法典婚姻家庭编司法解释（一）理解与适用》；
- <https://www.sdcourt.gov.cn/jningweisfy/385991/385992/7914350/index.html>

证据等级：**A-/B+：法院系统转载的最高法民一庭解释性材料**。它不是 1994 年原始法规页面，但适合确认规则沿革。

材料明确区分：

- 1989 年《同居案件若干意见》前后对事实婚姻的态度变化；
- 1994-02-01 《婚姻登记管理条例》第 24 条以后，未经登记而以夫妻名义共同生活的关系在民事婚姻效力上发生关键变化；
- 2001 年婚姻法及司法解释以后，又对 1994-02-01 之前已经符合结婚实质要件的关系作有条件承认，并强调补办登记。

本包不把“1994 年以后所有同居都违法”写进结论。后续司法解释的用语和处理方式发生过变化，且“有配偶者与他人同居”与两个无配偶者共同生活不是同一法律问题。

### B. Yu & Xie 2015：全国代表性数据中的婚前同居扩散

Jia Yu & Yu Xie, *Cohabitation in China: Trends and Determinants*, Population and Development Review 41(4), 2015：

- DOI: <https://doi.org/10.1111/j.1728-4457.2015.00087.x>
- Wiley 摘要：<https://onlinelibrary.wiley.com/doi/abs/10.1111/j.1728-4457.2015.00087.x>

证据等级：**A-：同行评审、全国代表性数据的统计研究**。

摘要可安全支持：

- 1980 年以前出生的中国成年人中，婚前与未来配偶同居者约 7%；
- 后来出生队列中婚前同居快速增加；
- 教育、家庭背景、地区经济发展等因素与同居概率相关。

注意：这是统计上的 union-history / premarital-cohabitation 研究，不是同时代日记，也不能用于推出某一年“全国青年同居率”。

### C. 2008 深圳《试婚，距离婚姻到底有多远》：同时代第一人称

深圳特区报 / 深圳新闻网，经搜狐存活：

- 2008-10-13，《试婚已成常见社会现象 并非磨合婚姻最佳选择》；
- <https://news.sohu.com/20081013/n259997866.shtml>

证据等级：**B+：同时代媒体直接/间接采访，多名当事人第一人称；不是概率样本。**

记者称直接或间接采访三十多对所谓“试婚”男女，出现了多条不同路径：

1. 目睹父母失败婚姻后，希望先共同生活再决定是否登记；
2. 有离婚经历、害怕再次进入婚姻；
3. 因房租和生活成本搬到一起；
4. 有明确结婚意愿，但买房、婚礼或户籍等现实安排使登记延迟；
5. 共居后实行 AA 制，刻意保存一定财务边界；
6. 生育以后才发现“共同生活事实”和“登记身份”在子女、户籍、财产等制度接口上不能互相替代。

一名 28 岁研究生白领与同龄女友认识三个月后搬到一起。两人租两房、添置家具，但租金和家当各自记账。受访者把它理解为：双方有结婚意愿，但还不愿在认识时间很短时立即领取不可轻易退出的正式凭证。

这不是“同居=不婚”的证据。恰恰相反，2008 这批自述中相当多的人仍把结婚放在未来，只是把共同生活插进了恋爱和登记之间。

### D. 2009 “蚁族”调查：拥挤住房中的未婚同居

中国青年报 2009-11-18，现存凤凰网转载：

- <https://news.ifeng.com/society/5/200911/1118_2579_1441442_1.shtml>

证据等级：**B：同期调查与现场描述，样本是特定的大学毕业生聚居群体，不代表所有青年。**

报道中的调查对象 93% 未婚；未婚者中 49% 没有恋人；与异性同居者占调查对象 23%。现场还记录十几平方米的集体宿舍里“四个男人和一对情侣”共同居住的极端拥挤例子。

这里最重要的不是 23% 这个数字本身，而是：

> **同居既是一种亲密关系安排，也可能嵌在低成本、多人共享、迁移型住房结构里面。**

不能把它只写成观念开放。

### E. 2017–2019 九城市流动青年深访：同一种“同居”有多种进入机制

张亮，2020-07-05，澎湃研究所《“90后”流动青年未婚同居的动因与特征》：

- <https://www.thepaper.cn/newsDetail_forward_7879728>
- 田野时间：2017-06 至 2019-04；
- 9 个城市；
- 94 位正在同居或近期有同居经历的 90 后乡—城流动青年。

证据等级：**A-/B+：明确方法的质性生命史访谈；发表时间略晚于田野，但访谈本身属于 2017–2019 的同期/近同期自述。**

研究至少拆出以下路线：

- **婚姻前奏型**：只有觉得对方是未来配偶才搬到一起；
- **订婚后同居型**：双方父母/家乡习俗已经认可婚约，登记尚未完成；
- **恋爱必要步骤型**：年轻时认为恋爱了就自然一起住，进入时并未考虑结婚；
- **工作时间协调型**：倒班、加班、休息日错开，不同住就几乎没有相处时间；
- **迁移/住房便利型**：辞职离开宿舍、换城市、去伴侣工作地时，同居直接成为住房解决方案；
- **收入缓冲型**：失业或暂时无工作的一方通过伴侣收入维持生活；
- **成本约束型**：也有人因为工资低、房租高、工作不稳定而推迟搬出宿舍，不进入同居；
- **意外怀孕推动型**：原先分开居住，怀孕以后加速共同居住和婚事。

这些类型非常重要，因为：

```text
observed cohabitation state
!=
same intention
!=
same economic position
!=
same future horizon
```

### F. 2022 深圳“时差情侣”：住在一起也可以几乎见不到

深圳微时光，2022-12-20/21：

- <https://www.sohu.com/a/619417313_355785>
- <https://www.huxiu.com/article/747894.html>

证据等级：**B：同期媒体第一人称/人物访谈。**

一名受访者朝九晚六，男友夜班到凌晨三点；另一对同城同居情侣也因一方长期加班，实际一周能共同清醒相处的时间非常有限。

因此新增：

> **same-site temporal separation / 同址时间分居**

也就是：

```text
同城
+
同一住所
+
同一张床
!=
共享日常时间
```

空间距离被消灭以后，劳动时间制度仍然可以重新制造“异地恋式”的亲密关系。

### G. 2023 百合佳缘 × 后浪研究所：成本成为公开的同居动机之一

2023-08-22/23 多家媒体转载同一份 2320 人调查：

- 新浪：<https://news.sina.com.cn/sx/2023-08-22/detail-imziaace4578338.shtml>
- 南方都市报转载：<https://www.sohu.com/a/714192335_161795>

证据等级：**C+：平台/媒体调查，样本招募、加权与总体代表性不足，不可当全国比例。**

该调查报告称，受访者中有人把节省房租（27%）和分摊生活费（17.6%）列为同居原因，并称只有不到一半是为了“婚前体验共同生活”。

安全用法：

> 到 2023 年，平台化婚恋公共话语已经能公开把“省房租 / 分生活成本”与爱情、婚前磨合并列为同居理由。

不安全用法：

> “27% 的中国年轻人同居是为了省房租。”

分母只能是该调查参与者。

### H. 海外对照 1：英国——共同生活不自动生成“common law marriage”

英国议会 Hansard，2019-03-15，Cohabitation Rights Bill 辩论：

- <https://hansard.parliament.uk/lords/2019-03-15/debates/03B0DD3A-19D3-4BE5-ACC6-C2AE2537EE7E/CohabitationRightsBill>

证据等级：**A：议会同期记录。**

辩论援引当年的 British Social Attitudes 数据称，英格兰和威尔士仍有 46% 的受访者相信同居会形成所谓 common-law marriage，但这一身份并不存在；共同生活者在财产、继承等领域并不自动获得婚姻/民事伴侣的完整地位。

对照意义：

> **共同生活事实与正式关系凭证之间的错位不是中国特有。**

### I. 海外对照 2：法国——制度可以主动创造“婚姻之外的正式凭证”

法国司法部、INED：

- 法国司法部 PACS 统计页：<https://www.justice.gouv.fr/documentation/etudes-et-statistiques/pactes-civils-solidarite-pacs>
- INED，PACS 20 周年：<https://www.ined.fr/fr/tout-savoir-population/memos-demo/focus/20-ans-pacs-essor-considerable/>

证据等级：**A：政府 / 国家人口研究机构。**

PACS 于 1999 年建立。司法部数据显示，早期每年约两万份，2016 年已超过 19 万份；INED 也指出 PACS 后来成为大量异性伴侣采用的制度形式。

这提供一个重要反例：

```text
现代亲密关系制度
!=
只能在“结婚”与“完全无凭证同居”之间二选一
```

法国建立了一个独立的正式民事结合凭证。不能把法国路径直接投射为中国将来必然走向，但它说明“关系凭证的种类”本身就是制度变量。

## 2. 新的生命路径类别：共享一个家，但没有同一种“关系状态”

“未婚同居”如果只做一个 checkbox，会掩掉至少五种不同人生。

### 2.1 事实婚姻 / 社会婚姻在先，登记缺失

某些较早时期的伴侣：

```text
举行婚礼 / 以夫妻名义生活 / 共同生育
→ 周围社会已经把两人当夫妻
→ 国家登记记录可能不存在
```

司法处理又会因为**关系形成时间**和是否符合结婚实质要件而不同。

这是一种：

> **social-legibility / state-legibility split — 社会可识别与国家可识别分裂**。

### 2.2 婚姻前奏：先共同生活，再决定是否登记

2008 深圳的“试婚”和 2017–2019 流动青年访谈都说明，这条路线可以是：

```text
恋爱
→ 同住
→ 看生活是否能磨合
→ 登记 / 分手
```

它不是拒绝婚姻，而是在婚姻之前插入一个可退出的生活阶段。

### 2.3 已经订婚，但登记还没完成

在部分流动青年的经历里：

```text
恋爱 / 相亲
→ 双方家庭认可或订婚
→ 同住
→ 以后再登记
```

社会和家族可能已经把两人视作“准夫妻”，国家记录仍是未婚。

### 2.4 同居首先是一项城市生活基础设施

轮班、房租、宿舍、辞职、换城市会让情侣发现：

```text
继续分开住
→ 见面时间极少 / 两份房租或住宿摩擦更高
```

于是：

```text
亲密关系
+
住房需求
+
劳动时间
→
共同居住
```

这不是纯观念史。

### 2.5 共同生活不一定以婚姻为当前目标

田野中有年轻受访者把同居理解成“恋爱自然就住一起”，进入时根本没有想以后结不结婚。

2023 平台调查也至少证明，公开话语里“同居=为了结婚”已经不是唯一可表达的理由。

但本轮证据**不足以**估计中国有多少伴侣把同居当长期、终身的婚姻替代方案。

## 3. 新机制一：certificate-status discontinuity / 凭证状态不连续

婚姻登记不是“感情已经很深”的连续刻度，而是一道离散接口。

一个家庭可能在登记前一天和登记后一天：

- 住同一套房；
- 用同一个厨房；
- 一起养孩子；
- 一起给老人汇钱；
- 周围人都叫他们夫妻。

但制度状态发生跳变。

历史上甚至还存在更强的日期门槛：

```text
关系形成于 1994-02-01 前
+
符合实质要件
→ 可能按事实婚姻处理

关系形成于之后
+
没有登记
→ 不会仅凭共同生活自动变成登记婚姻
```

因此需要固定：

> **household continuity != credential continuity**

和：

> **identical-looking household != identical legal status**。

## 4. 新机制二：共同住所把住房、工作与关系绑定起来

### 4.1 同居可以降低某些成本

- 两个人不必各租一套房；
- 一方辞职或换工作时，伴侣住房可以成为临时落点；
- 对倒班者，共同住所可以增加哪怕短暂的相处机会。

### 4.2 也可以制造新的依赖

2017–2019 深访中，有女性在辞职后较长时间由同居伴侣承担生活；也有男性因为收入不稳定、住宿舍压力更小而推迟共同租房。

因此：

```text
cohabitation as cost sharing
!=
cohabitation as equal economic independence
```

同一项“省房租”可能意味着：

- 双方平等合并预算；
- 一方暂时给另一方提供 unemployment buffer；
- 一方因此降低退出关系的经济能力。

这些后果不能从“是否同居”一个变量里直接读出。

## 5. 新机制三：same address != shared time

分址家庭专题已经证明：

```text
夫妻关系存在
!=
每天同住
```

这一轮补上反方向：

```text
每天回到同一地址
!=
拥有共同日常
```

2017–2019 流动青年说，因为制造业 / 服务业倒班，两人本来很难正常约会，所以搬在一起。

但 2022 深圳案例进一步显示，极端的班次错位可以让同居本身也无法恢复共同时间：

```text
A 下班
≈
B 上班

B 回家
≈
A 睡觉
```

因此真正需要研究的是：

> **shared waking overlap / 共同清醒时间**

而不只是“是否同一户”。

这是劳动制度进入亲密关系的一种非常具体方式。

## 6. 新机制四：一个人的同居意义会随着年龄改变

2017–2019 田野里有一个非常清楚的时间感差异：

- 更年轻时，有受访者认为“喜欢就在一起，不喜欢就分开”，进入同居时不想几年后的事；
- 年龄上升以后，同一类人开始把一年两年的关系失败理解成真实的时间成本，强调“到年龄了”才会在有结婚计划时进入共同生活。

因此：

> **relationship form != fixed future meaning**

同一个人 19 岁时和 28 岁时做出同居选择，可能不是同一套未来模型。

可以用：

> **relationship horizon compression / 关系未来期限压缩**

来描述：随着自认的适婚时间逼近，关系被要求更快回答“是不是要结婚”。

这和仓库中的 `eligibility clock` 有相似结构，但不是同一种制度门槛：这里主要是社会、家庭和个人时间感，而不是招考规则自动关门。

## 7. 对四段“未来”的补充

### 7.1 2005–2012：扩张型未来——在恋爱和婚姻之间插入一个阶段

2008 深圳同时代访谈很适合作为样本：

- 有人想先试着过日子；
- 有人怕重复失败婚姻；
- 有人等买房 / 婚礼；
- 有人只是觉得两份房租不划算。

扩张不是“人人乐观”，而是：

> **脚本中可以多出一个阶段，且退出路径仍被想象为可用。**

### 7.2 2015–2019：拥堵型未来——共同生活成为时间 / 住房协调工具

2017–2019 流动青年材料特别重要，因为很多人并不是纯粹为了“更自由”同居。

工作班次、宿舍、换城、房租和职业不稳定都参与决定。

于是：

```text
恋爱路线扩张
+
住房与劳动时间拥堵
→
共同居住既是亲密选择，也是物流方案
```

### 7.3 2020–2022：偶发型未来——同址也可能失去共同日程

2022 深圳“时差情侣”说明，在疫情前后就业/班次变化以后，一些情侣即使仍住在一起，日常关系也会被新工作时间切碎。

本轮证据只支持个案层面的“工作节奏改变后共同时间减少”，**不支持把全国情侣的时间错位都归因于疫情。**

### 7.4 2023–2026：防守型未来——成本理由变得公开可说，但不能从平台问卷推出全国心理

2023 平台调查把：

- 省房租；
- 分摊生活费；
- 婚前了解；
- 恋爱本身

放进同一套原因清单。

它至少说明一个语义变化：**把亲密关系当作生活成本配置的一部分，已经可以公开说出来，而不必伪装成唯一的“奔着结婚去”。**

但由于平台样本不透明，本轮只把它当“当时可表达的动机”，不把它当全国青年进入所谓防守型未来的比例证据。

---

## 8. 海外比较改变了什么

### 8.1 英国：社会称呼也可能制造虚假的制度可见性

“common-law marriage”被大量普通人使用，但英格兰和威尔士并不存在“住够几年就自动成为配偶”的一般规则。

这和中国的“事实婚姻”特别容易被今天的搜索者混为一谈，但两国法律结构不同。

因此：

```text
same colloquial idea — “住在一起像夫妻”
!=
same legal institution
```

### 8.2 法国：国家也可以增加关系凭证的种类

PACS 说明另一种现代化路线：

```text
无凭证同居
→ PACS
→ 婚姻
```

可以形成多种正式程度，而不是只有二元开关。

所以中国未婚同居的增长不应被写成一个普遍的“世界最终都会去婚姻化”的单向阶段论。

真正可比较的是：

- 各国有多少种关系凭证；
- 住房 / 财产 / 继承 / 子女 / 税收怎样挂到不同凭证上；
- 人们是否误以为共同生活本身会自动生成权利；
- 同居是婚姻前奏、长期替代还是经济/时间安排。

## 9. 证据边界与反例

### 9.1 不把“同居增加”写成“婚姻消失”

Yu & Xie、张亮的材料都与这种简单叙事不一致。很多同居明确以结婚为目标。

### 9.2 不把“试婚”当客观学术分类

2008 媒体使用“试婚”是当时话语。研究包保留这个词作为历史 actor category，但分析时改用：

- premarital cohabitation；
- engaged cohabitation；
- marriage-directed cohabitation；
- convenience/economic cohabitation。

### 9.3 不把 2009 “蚁族”23% 推成城市青年比例

它是特定毕业生聚居群体。

### 9.4 不把 2023 平台问卷当人口调查

样本招募、加权、非响应和用户构成都不足够透明。

### 9.5 不把“没有结婚证”自动等于“完全没有任何法律保护”

财产共有、子女权益、反家暴等具体领域有各自规则；本包只强调“共同生活不会自动等同于完整的登记婚姻身份”。

### 9.6 不把共同居住浪漫化

共同生活可以提供住房和情感缓冲，也可能增加经济依赖、退出困难、隐私和照护负担。

## 10. 这改变了“人怎么活着”的哪一点理解

过去最容易画出的标准脚本是：

```text
恋爱
→ 结婚登记
→ 搬到一起
→ 共同生活
→ 生育
```

真实生命历程可以是：

```text
恋爱 → 同居 → 登记
恋爱 → 订婚 → 同居 → 登记
恋爱 → 同居 → 分手
恋爱 → 共同租房 → 一方失业 → 另一方暂时托底
恋爱 → 同居 → 怀孕 → 加速婚事
结婚 → 两地分居
同居 → 同一地址但班次错开 → 几乎没有共同清醒时间
```

因此真正应该追踪的是若干状态轴，而不是一个“已婚 / 未婚”字段：

```yaml
relationship_credential:
  registered_marriage: yes/no
  other_formal_union: if applicable
social_recognition:
  families_recognize_union: yes/no/unknown
  public_spouse_identity: yes/no/unknown
residence:
  same_dwelling: yes/no/intermittent
shared_time:
  waking_overlap: high/medium/low/unknown
economic_arrangement:
  separate / pooled / asymmetric-support / unknown
future_intention:
  marriage-directed / open-ended / no-marriage-plan / unknown
```

**同一个家，不一定对应同一种家庭。**

## 11. 与 old-web-archaeology 的交叉问题

2000 年代中文 Web 留下大量：

- “非法同居”；
- “事实婚姻”；
- “试婚”；
- “同居关系”；
- “有配偶者与他人同居”。

它们不是同义词，也不是跨年份稳定不变的法律分类。

因此搜索旧网页时必须防止：

```text
page contains “事实婚姻”
!=
subjects legally counted as spouses

page title contains “非法同居”
!=
that phrase was still the governing legal category on the page date

self-description “老公/老婆”
!=
registered spouse
```

## 12. 后续最值得追的缺口

1. 找到 1980s–1990s 地方婚姻登记、妇联或法院材料，量化“以夫妻名义生活但未登记”的地区与城乡差异；
2. 找到 2007–2010 的论坛 / 博客原帖，而不仅是媒体采访，观察当事人自己是否使用“试婚 / 同居 / 老公老婆 / 事实婚姻”等词；
3. 对 2017–2019 深访中的住房类型、单位宿舍、班次、迁移路径做更细的物质生活编码；
4. 继续寻找 2023–2026 高质量第一人称，区分“暂缓登记”“长期不婚同居”“为了住房成本共同生活”；
5. 若做国际比较，优先比较中国、英格兰/威尔士、法国三种不同的 relationship-credential architecture，而不是只比较同居率。

## 13. 饱和判断

本轮发现了此前仓库中没有独立建模的：

- **未登记共同生活 / 婚姻登记分离的生命路径类别**；
- **关系凭证状态不连续**；
- **同址时间分居**；
- **共同住所作为轮班、迁移、失业与房租协调基础设施**；
- **年龄改变同居的未来期限**；
- **法国 PACS 所展示的关系凭证多元化反例**。

因此本轮不计入“连续无新增”运行；阶段性饱和计数保持 **0/3**。
