# 研究饱和与去重审计：Life Horizons × Old Web 交叉线（2026-09-12）

> 状态：阶段性研究过程记录，不是 closure。
>
> 目的：在继续扩张专题以前，重新检查当前仓库是否还存在真正未覆盖的生活路径类别、制度接口、时代时间机制或通信 / Internet 转折机制；若候选问题已经被既有专题覆盖，则停止另开近义文件，转向补一手证据、做跨专题综合或验证历史 artifact。

## 1. 本轮为什么不再强行开一个新生活史专题

本轮重新读取：

- `ROADMAP-life-horizons.md`；
- `INDEX-life-horizons.md`；
- `METHODOLOGY.zh-CN.md`；
- 当前 `main` 的完整 topic tree；
- 最近提交；
- `tmzncty/old-web-archaeology` 的 `ROADMAP.md`、`RESEARCH_PLAN.md` 与 `docs/METHOD.md`。

然后对若干看似可能成为“新题目”的方向做了反向查重。

结果不是“没有题目可想”，而是：**许多题目已经存在，只是命名不同。**

这意味着当前最大的研究风险已经从“漏掉普通人的生活路径”部分转向：

1. 把同一机制拆成越来越多近义文件；
2. 用新的术语包装旧结论；
3. state model 越来越细，但原始证据增量越来越小；
4. old-Web 侧留下大量 candidate locator / state-gap note，却没有同步把核心 M1 artifact 做实；
5. 主题数量增长本身制造一种“研究仍在快速扩张”的错觉。

因此本轮把“不另开重复专题”视为有效研究产出。

## 2. 本轮候选探针与去重结果

### 2.1 残障 / 无障碍 / 数字独立

初看是核心矩阵中的潜在空缺，但仓库已经有：

- `topics/from-hearing-proxy-to-text-and-video-independence-deaf-communication-accessibility-and-life-path-executability-china-2002-2026.zh-CN.md`
- `topics/from-human-readers-to-screen-reader-independence-visual-impairment-assistive-technology-and-interface-executability-china-1953-2026.zh-CN.md`

old-Web 侧也已有：

- `docs/DEAF_COMMUNICATION_SMS_CHAT_FORUM_SIGN_VIDEO_CAPTION_AND_ACCESSIBILITY_STATE_GAPS_2002_2015.md`

后者已经把 1960s 美国 TTY 前史、2002 中国短信终端、2005 “聋人在线”、2007 QQ / SMS / relay 等接进普通人的通信、求职和制度可执行性。

**结论：不是新生活路径类别。** 后续若推进，应补盲人早期中文 Web 的历史 artifact、浏览器 / screen reader 兼容证据，或把不同障碍类型做比较，而不是再开“数字无障碍改变生活”总论。

### 2.2 兼职 / 零工 / 第二份收入

仓库已有：

- `topics/from-labor-service-companies-to-online-classifieds-odd-jobs-and-local-opportunity-addressability-china-1979-2026.zh-CN.md`
- `topics/day-labor-daily-reentry-income-latency-and-standby-life-china-1991-2025.zh-CN.md`
- `topics/from-second-work-to-witkey-task-markets-digital-piecework-and-modular-livelihood-china-1988-2026.zh-CN.md`
- `topics/multiple-jobholding-side-work-income-stacking-and-schedule-multiplexing-china-1989-2026.zh-CN.md`
- `topics/secondary-work-gig-routes-and-enacted-job-portfolios-china-1982-2026.zh-CN.md`

old-Web 侧也已经有校园兼职、日结 / 零工信息板、威客任务市场的状态差专题。

**结论：不是新类别。** 真正的增量应是 longitudinal life history：同一个人何时把副业转成主业、何时又返回工资劳动；或者用调查数据估计多重就业的生命周期位置，而不是再做一个“平台让兼职可搜索”的专题。

### 2.3 “过去突然变得可搜索” / 数字声誉 / context collapse

海外侧本轮检查了 Deja News / Google Groups 的 Usenet 搜索史。2001 年 Google 收购 Deja 的 Usenet archive；到当年末，Google Groups 已把可搜索档案扩展到 1981 年。同期用户很快发现，十多年前原本只在分散 newsgroup 中出现的帖子突然可以按关键词和作者重新找到，并公开表达对旧帖重新暴露的不安。

这确实是一个重要的全球旧网机制：

```text
PUBLIC_AT_POSTING_TIME
!=
EASILY_SEARCHABLE_YEARS_LATER
```

但本仓已经有：

- `from-address-books-to-searchable-pasts-*`
- 多个校友 / 同学录 / searchable-past 专题；
- `from-pseudonyms-to-identity-portfolios-online-offline-identity-compartmentalization-*`
- `from-paper-resume-to-searchable-candidate-profile-*`
- `personal-homepages-self-publishing-and-platformed-public-identity-*`
- 搜索引擎与 retrieval labor 专题。

**结论：当前只能实质强化“历史可见性 / 搜索改变公开性”这一既有机制，尚不足以证明中国材料中存在一个未被已有专题吸收的新生活路径类别。** 如果未来找到 2000s 中文第一人称材料，明确描述旧论坛 / 博客 / 校内内容被招聘者、伴侣、家人或同事搜索并改变现实选择，再考虑建立一个窄专题；在此之前不另开文件。

海外比较记录：

- Google, 2001-02-12, acquisition of Deja Usenet archive, contemporaneously reposted in Google Groups: https://groups.google.com/g/news.admin.net-abuse.usenet/c/Ep2SvF48aEw/m/fEPNnyyEylEJ
- WIRED, 2001-04, `Google Restores Deja View`, contemporaneous interviews with users surprised by old posts becoming much easier to retrieve: https://www.wired.com/2001/04/google-restores-deja-view/
- Google Groups, 2001-12, announcement of a 20-year archive exceeding 700 million posts and reaching back to 1981: https://groups.google.com/g/alt.music.j-s-bach/c/1ljVLPaYn7M

证据等级：前两项分别可作为 **A/B**（Google 同期公告文本 / 同期媒体采访），第三项为 **A/B 边界**：同期 Google announcement text preserved inside Usenet / Groups context，可证明当时 Google 如此宣称；不独立证明“complete”这一质量判断。

## 3. 当前最明显的重复专题簇

以下不是说文件“没有价值”，而是说明后续不宜继续以近义标题横向扩张。

### 3.1 铁路客票 / 移动可执行性

至少已经包括：

- `from-station-queue-and-telephone-booking-to-12306-*`
- `from-ticket-window-queues-to-pre-reservation-*`
- `from-ticket-window-to-virtual-waitlist-*`
- `from-ticket-window-to-waitlist-and-reservation-*`
- `railway-ticketing-mobility-executability-*`
- `ticketability-railway-booking-*`
- `return-trip-executability-*`
- `bookability-travelability-and-reversible-mobility-planning-*`

核心结论已经稳定：席位是稀缺 mobility slot；远程查询 / 支付 / 候补改变排队和计划方式，但不会自动创造运力；`ticket issued != travel executed`。

**后续优先级：** 合并 syntheses、补 12306 历史 capture、补 2000s 电话订票 / 代售点第一人称，不再另开第九个票务机制文件。

### 3.2 汇款 / 分布式家庭财务

至少已经包括：

- `from-carrying-cash-home-*`
- `from-money-orders-to-mobile-transfers-*`
- `from-postal-remittance-to-mobile-transfer-*`
- `from-postal-remittances-to-instant-family-transfers-*`
- `from-sending-money-home-*`
- `money-across-distance-*`
- `money-over-distance-*`
- `remittance-infrastructure-*`（多篇）
- `remitting-home-*`

核心结论已经稳定：人、钱与家庭预算逐渐解耦；电子化可以发生在消费者 Web 之前；代际资金流长期可能双向；支付实时化不会消除 recipient-side executability、诈骗与家庭责任问题。

**后续优先级：** 回到 ROADMAP 的 child-to-parent flow reversal，做 cohort / household-data 层面的定量或生命史比较，而不是再加支付渠道专题。

### 3.3 婚恋 / 可搜索伴侣

已经有多篇 personals / online dating / matchmaking / searchable courtship / relationship optionality 的高度重叠文件。

核心结论已经稳定：报刊先扩大陌生人可寻址性，Web 把候选人结构化为可搜索 profile；发现 / 联系 / 见面 / 关系 / 婚姻是不同状态；平台扩大候选池但不保证现实关系。

**后续优先级：** 回到 ROADMAP 的 “what made marriage economically possible?”，综合住房、收入、父母支持、托育和迁移，而不是继续研究“如何认识对象”。

### 3.4 医疗挂号 / 照护导航

已有 `care-path-addressability`、`from-queueing-for-a-number`、`from-walk-in-queue`、`from-window-queue`、`hospital-appointment`、`hospital-registration`、`medical-appointment` 等多篇。

核心结论已经稳定：远程挂号把身体排队转成电话 / Web / App 的 slot management；患者、操作者、代理人不是同一身份；slot reservation 不等于实际看诊；数字渠道必须保留 fallback。

**后续优先级：** 做真实跨城照护 life history、代理劳动分工和 continuity outcome，而不是再加预约 state chain。

### 3.5 家政 / paid domestic service

已有多篇 care outsourcing / household as workplace / platform matching / cross-household time transfer 的重叠文件。

**后续优先级：** 深挖具体雇佣关系、职业轨迹与家政劳动者自己的未来想象，而不是继续以雇主侧“时间被买回来”为唯一视角。

### 3.6 二手流通 / 可逆消费

已有 flea market、resale platform、asset liquidity、household reset、reversible ownership 等多篇。

**后续优先级：** 选择一个清晰 material object（例如毕业搬家时的大件家具 / 数码产品）做 transaction chain 与 life-course comparison，不再另开“二手让消费可逆”的总论。

### 3.7 同学录 / 旧关系重新可寻址

已有 address books、classmate books、alumni directories、SNS、searchable past 等多篇。

**后续优先级：** 比较“恢复联系方式”与“真正恢复关系”的长期结果，或研究平台关闭后的 social graph memory loss。

### 3.8 Internet café / shared access

已有 public access Internet cafés、shared terminal、session-based digital life 等多篇。

**后续优先级：** 具体历史 capture / 计费软件 / 实名接口 / 设备与浏览器环境，而不是再证明“拥有电脑之前可以租一段上网时间”。

## 4. 核心矩阵覆盖审计

按用户定义的重点矩阵，目前已经不是“某大类完全空白”的阶段。

| 维度 | 当前覆盖判断 | 仍值得补的不是“新总论”，而是 |
|---|---|---|
| 教育 | 强 | 代际 / 地区差异、真实失败路径、跨制度衔接 |
| 就业 | 强 | longitudinal job sequence、非正规→正规 / 正规→非正规转换 |
| 住房 | 强 | 多次搬家序列、婚育 / 照护与住房耦合 |
| 婚姻家庭 | 强 | 经济可执行性综合，而非继续做 search / matching |
| 迁移 | 强 | 完整 household migration sequence、返乡再迁出 |
| 照护 | 强 | 具体家庭内部分工、长期结果 |
| 非正规劳动 | 强 | 收入波动、保障、身份切换的长期序列 |
| 长期中断 | 强 | 不同 holding state 的实际 re-entry 成功率 / 路径 |
| 证件与记录 | 很强 | 多系统记录冲突、旧 cohort 清理、低频高后果失败 |
| 通信方式 | 很强 | 通道叠加 / 退出，不再需要按媒介逐个开总论 |
| Internet 平台 | 很强 | 平台死亡、迁移、private-state 丢失的 artifact 研究 |
| 信息获取 | 很强 | 推荐 / 搜索 / AI 之间的 source sovereignty 比较 |
| 社交关系 | 很强 | contact recovery != relationship recovery 的结果研究 |
| 未来预期 | 中强 | 仍需持续补 2007–2010、2018–2019、2023–2026 同时代第一人称 |
| 线上 / 线下身份 | 强 | context collapse 的中国同期材料仍可补 |
| 平台消失与记忆保存 | 强框架、artifact 偏弱 | verified captures、WARC/WACZ、平台退场后的实际资料损失 |

因此，项目已经具备用户设定的“核心矩阵跨时期覆盖、Internet 前史 / 大众化 / 平台化阶段覆盖、若干海外对照”的**结构性前提**。

尚不能据此直接 closure，因为用户定义的是 **连续 3 次无实质新增**，而不是“一次审计觉得很多”。

## 5. 下一阶段最值得做的四类工作

### 5.1 从“新题目”切换到“证据升级”

如果既有专题已经提出 state chain，下一次优先寻找：

- 同时代第一人称；
- 原始表单 / 手册 / 帮助页；
- 实际历史 capture；
- 失败个案；
- 同一个人跨多年状态变化。

没有这些，不应仅靠再命名一个 `X portability / Y executability` 文件制造增量。

### 5.2 完成 ROADMAP 仍明确提出的 synthesis 问题

优先：

1. **What made marriage economically possible?**
   - 使用已有住房、父母支持、工资、托育、迁移、婚恋专题做综合；
   - 不再把“认识谁”当作主要瓶颈。
2. **migrant worker c.1995 / c.2005 integrated comparison**
   - dormitory / wages / communication / remittances / return plans 已分别有材料；
   - 下一步应把这些拼回同一个人的一年，而不是继续拆基础设施。
3. **child-to-parent support flow reversal**
   - 用家庭调查 / cohort 资料识别“开始挣钱”“象征性给钱”“真正成为净支持者”之间的差异。

### 5.3 继续补“同时代人的未来想象”，但必须防止 hindsight

仍应优先寻找：

- 2007–2010：五年后、买房、职业、异地、结婚、出国等当时规划；
- 2018–2019：稳定 / 跳槽 / 城市 / 房贷 / 生育 / 现金缓冲；
- 2023–2026：退路、考证、储蓄、低承诺选择、多路线并存。

这里的增量来自**当时的人自己怎么写未来**，不是研究者再发明一个时代标签。

### 5.4 与 old-Web 侧同步把 artifact 做实

很多 life-history 专题已经把“Web 改变了什么”说清楚；真正薄弱的是旧网页事务状态的可复核 artifact。

应把下一批工作转为：

- 打开并核验历史 capture；
- 记录 original / memento / datetime / replay / charset / subresource；
- 比较 ≥2 个时点；
- 明确 modern replay 与 historical browsing 的差异；
- 对动态事务页面承认 private/live state 无法由 archive 自动恢复。

## 6. 本轮的饱和计数

本轮经过候选探针与全树去重，没有发现一个能够同时满足以下任一条件的新研究单元：

- 新的生活路径类别；
- 新的制度接口；
- 新的时代时间感机制；
- 新的通信 / Internet 转折机制；
- 新的跨国结构差异；
- 能实质改变现有结论的一手证据。

检查到的海外 Deja / Usenet 搜索史能够强化“公开内容后来变得可搜索”这一既有机制，但目前不足以构成新的中国生活史类别。

因此本轮记为：

**连续无实质新增：1 / 3。**

这不是阶段 closure。下一轮仍应运行，但必须继续优先：

1. 去重；
2. artifact / 一手证据升级；
3. synthesis；
4. 只有真正出现新机制时才重新归零计数。

若后续连续两轮也无法找到上述类型的实质增量，并且没有暴露新的矩阵空缺，则应按既定规则写阶段性 closure / synthesis，并停止这一阶段的循环研究。
