# 从去一个地方上网到把终端带在身上：共享终端、网吧与终端独立，中国 1996—2026

## 本轮问题

仓库已经分别研究过寻呼、公用信息入口、旧 Web 平台、远程教育、在线求职、迁移、QQ/同学录、宽带时代和手机时代的一些切片，但还缺一个更基础的生活条件：

> **一个人可以使用 Internet，是否意味着她家里已经有电脑、宽带和一台可以随时占用的终端？**

答案显然是否定的。

在中国大众互联网早期，很多人的 Internet 生活首先发生在网吧、学校机房、单位电脑或其他共享终端，而不是自己的卧室。一个人可以已经拥有 QQ、邮箱、论坛昵称、游戏账号、博客和网络朋友，却没有属于自己的联网电脑。

因此本轮不把“网民数量”直接等同于“家庭联网人口”，而把实际可执行的网络使用拆成：

```text
网络存在
→ 附近有没有可进入的接入场所
→ 付不付得起每小时费用
→ 是否符合年龄 / 证件 / 营业规则
→ 有没有空机器
→ 机器上是否有需要的软件、中文输入法、浏览器、插件
→ 网络是否可用
→ 用户能否登录自己的持久账号
→ 用完后如何退出、保存或带走自己的状态
```

与 `old-web-archaeology` 的交叉研究见：

- <https://github.com/tmzncty/old-web-archaeology/blob/main/research/internet-cafe-shared-terminal-access-authentication-session-and-terminal-context-gaps-1998-2012.md>

## 一、不要把“上过 Internet”偷换成“家里有 Internet”

### `access-without-ownership / 无所有权接入`

HPL 的既有方法已经要求区分：

- 技术存在；
- 商业可得；
- service access；
- 基础设施；
- 可负担性；
- 家庭所有；
- 大众常态；
- 行为整合。

网吧正是这套区分最清楚的历史案例之一。

一个年轻人完全可能：

```text
没有自己的电脑
没有家庭宽带
没有可以长期占用的学校机器

但是：
附近有一家按小时收费的网吧
→ 她仍然可以成为持续使用 Internet 的人
```

这意味着：

> **Internet adoption != household PC ownership**

也意味着用“每百户电脑数”推断“谁能上网”，会系统性漏掉共享终端路径。

## 二、1996—2001：Internet 先成为一个“要去的地方”

关于“中国第一家网吧”存在不同回顾口径，本轮不使用“第一家”作为核心结论。

更稳妥的事实是：北京在 1996 年已经出现面向公众的网络咖啡空间；后来保存的《北京日报》旧报道材料描述，1996 年 11 月开业的一处网络咖啡有 11 台 Pentium 电脑，顾客会发电子邮件、查资料、聊天和玩游戏。

到 1998 年，北京大学附近的飞宇网吧从 25 台电脑起步。2001 年的同时代报道描述，它已经扩张到约 1400 台电脑、2500 平方米，繁忙时仍需排队；用户在里面聊天、下资料、听音乐、下棋打牌。

同期报道还强调：1990 年代中期联网电脑首先更多出现在电信展示设施、酒店、研究/机构环境中，真正快速进入普通人的公共消费生活是随后几年的事情。

来源：

- 《人民日报》2001 年网吧专题（新浪转载）：
  - https://tech.sina.com.cn/i/c/67640.shtml
  - **B：同时代媒体。**
- 2019 年《北京日报》旧报纸回顾，转录 1996/1997 年报道内容：
  - https://media.people.com.cn/n1/2019/1017/c40606-31404334.html
  - **C/B：后来机构性回顾中引用同时代报道；未取得原版扫描。**
- 2006 年关于“第一家网吧”口径不一的回顾：
  - https://news.sina.com.cn/o/2006-11-02/160110397305s.shtml
  - **C：用于提醒首创口径有争议。**

这一阶段适合用一个非常朴素的概念：

## `Internet as destination / Internet 作为目的地`

今天“上网”往往只是拿起手机；当时它可能首先意味着：

```text
出宿舍 / 家门
→ 走路、骑车或坐公交
→ 找到营业中的网吧
→ 等机器
→ 按小时付费
→ 坐到一台临时电脑前
→ 才进入自己的网络世界
```

因此“上网时间”之外还存在：

- 去网吧的交通时间；
- 排队时间；
- 每小时费用；
- 营业时间；
- 座位供给；
- 场所噪声、烟味、隐私和安全环境。

这些都属于 Internet 的真实接入成本。

## 三、身份已经可以随人移动，但终端还不能

网吧时代出现了一个很有意思的不对称：

### `portable identity, nonportable terminal / 身份可携、终端不可携`

一个 QQ 号、邮箱、BBS 账号、游戏账号可以跟着人走。

今天在学校旁的网吧登录；寒假回老家后，可以在县城另一家网吧再次登录同一个身份。

但提供这个身份入口的电脑并不属于本人。

所以普通人的网络连续性来自：

```text
持久账号
+
一次又一次临时借用的机器
```

这和固定电话时代也不同：电话地址更多绑定家庭、单位或场所；网络账号逐渐绑定“这个人”，但早期承载账号的物理终端仍然高度场所化。

这是一种重要的中间状态：

> **数字身份已经个人化，数字终端尚未个人化。**

## 四、网吧并不只是“没电脑的人打游戏的地方”

2008 年《广州日报》的同期报道记录，网吧经营者正在尝试求职、社区资讯和技能培训；文章标题本身就把“学动漫设计、看电影、找工作”列为网吧的新用途。

报道引用的行业调查称，2008 年去网吧主要为了游戏的比例较 2007 年下降，而聊天、看电影、查资料等用途增加。同期两个受访者又提供了不同经验：一名 21 岁仪表技师回顾自己高中阶段长期泡网吧；一名 29 岁白领则把网吧称为玩家线下聚集点，认为这种场所仍有社交意义。

来源：

- 《广州日报》，2008-11-23：
  - https://tech.sina.com.cn/i/2008-11-23/15032597354.shtml
  - **B：同时代媒体 + 行业调查摘要 + 同时代受访者。**

因此本轮不把网吧简化成“娱乐设施”。它至少可以同时承担：

- 临时 Internet 接入；
- QQ / 聊天 / 邮件；
- 搜索资料；
- 下载；
- 求职；
- 影视音乐；
- 游戏；
- 玩家线下社交；
- 某些技能培训或电脑学习。

也就是说，**一小时租来的电脑可能是一小时租来的信息、工作、社交和娱乐入口。**

## 五、2008—2009：共享终端仍然是大规模接入路径，但手机开始越过它

CNNIC 的青少年调查给出了非常清楚的转换点。

截至 2008 年底：

- 中国青少年网民约 1.67 亿；
- 57.5% 的青少年网民过去半年在网吧上过网；
- 农村青少年网民该比例达到 65.4%；
- 接近一半青少年网民已经使用过手机上网。

到 2009 年底：

- 青少年网民约 1.95 亿；
- 74% 使用手机上网；
- 台式机使用比例为 69.7%；
- 网吧使用率从 57.5% 降到 49.4%；
- 学校上网比例从 19.1% 升到 36.3%。

来源：

- CNNIC，《2008-2009 中国青少年上网行为调查报告》：
  - https://www.cnnic.cn/n4/2022/0401/c116-890.html
  - **Measured：官方调查摘要，统计截止 2008-12-31。**
- CNNIC，《2009 年中国青少年上网行为调查报告》：
  - https://www.cnnic.cn/n4/2022/0401/c116-907.html
  - **Measured：官方调查摘要。**

这不是简单的：

```text
网吧消失
→ 手机出现
```

而是多个接入方式重叠：

```text
家里
学校
网吧
单位
手机
```

同一个人可以在半年里使用其中几种。

因此不能把这些比例相加，也不能把“网吧用户”理解成“家里一定没有 Internet 的人”。

### 农村差异尤其重要

CNNIC 对 2008 年农村互联网的调查摘要显示，农村网民的家庭上网比例低于城镇，而网吧使用比例更高；报告估算当时有数千万农村网民使用网吧，其中还有一部分只在网吧上网。

来源：

- CNNIC，2008 年农村互联网发展调查报告入口：
  - https://www2.cnnic.cn/n4/2022/0401/c117-827.html
  - **Measured：官方调查；本轮正文页面抓取不稳定，因此具体数字须在后续全文核验时再次确认。**

这里的机制非常明确：

## `shared access outruns household ownership / 共享接入先于家庭所有`

一项基础设施可以先通过商业共享方式进入生活，再逐步私人化到家庭和个人终端。

## 六、网吧入口不是“打开浏览器”那么简单：证件、计费、座位和机器共同决定可执行性

2004 年南京推行实名刷卡时，同期报道给出了一条很具体的流程：

```text
到前台
→ 出示身份证
→ 办理 / 刷上网卡
→ 系统读取身份
→ 工作人员核对
→ 记录上网时间和机器号
→ 才能进入机器使用网络
```

外地人可以凭身份证使用临时卡，离开时归还。

2006 年合肥的联网实名登记系统进一步把实名卡、临时卡和计费整合起来：实名卡可以储值；临时用户由工作人员核验身份并录入，临时卡一次对应一人次会话。

来源：

- 《扬子晚报》，2004-09-30：
  - https://tech.sina.com.cn/i/2004-09-30/1119434480.shtml
  - **B：同时代操作流程。**
- 新华网稿，2006-11-16（新浪转载）：
  - https://tech.sina.com.cn/i/2006-11-16/16331241190.shtml
  - **B：同时代制度与软件流程。**

因此实际的网吧 access stack 是：

```text
地理接近
+ 营业中的场所
+ 空机器
+ 付费能力
+ 年龄 / 证件 / 实名规则
+ 前台身份与计费系统
+ 本地终端环境
+ 网络链路
+ 用户自己的平台账号
```

其中任何一层失败，都可能使“这个城市有 Internet”无法转化成“这个人今天能完成一次网络动作”。

同时也必须保留反例：制度规定不等于执行完全一致。同期媒体曾记录实名卡被借用、网吧为生意规避规则等现象。

所以：

> **institutional rule != lived enforcement**

## 七、2005—2012 的“扩张型未来”：机会可以先按小时租，而不是先买一整套家庭资本品

这一阶段的扩张不能只理解成“网页越来越多”。

对于没有家庭电脑或家庭宽带的人，一家网吧把昂贵的资本品拆成了按小时购买的服务：

```text
电脑
+ 显示器
+ 网络专线
+ 浏览器 / IM / 游戏 / 输入法
+ 维护
+ 座位
+ 电力
```

用户不需要先一次性购买整台电脑和长期宽带合同，就可以进入：

- 求职网站；
- 招生 /考试信息；
- QQ 与远距离关系；
- 网络游戏；
- BBS / 博客；
- 下载和数字内容。

这是一种 **`capital equipment rental / 资本设备租赁式数字接入`**。

它扩大了可执行的机会菜单，但同时让使用受到场所时间、费用、隐私和机器配置限制。

扩张因此不是“人人都拥有更多东西”，也可以是：

> **越来越多原本必须拥有的设备，被拆成可以买一两个小时的访问权。**

## 八、2015—2019：基础联网越来越个人化，共享场所开始出售别的东西

到 2019 年，讨论共享电脑场所时已经不能继续假定其核心价值只是“家里没有 Internet”。

2019 年《中国青年报》对武汉电竞酒店的现场报道中，一组多年好友平时在不同省份工作，相约来到同一电竞酒店；受访者强调高配置电脑、多人并排、私密性和休息条件。

来源：

- 中国青年报 / 人民网，2019-03-01：
  - https://industry.people.com.cn/n1/2019/0301/c413883-30951533.html
  - **B：同时代现场观察和受访者。**

这说明共享终端场所可以发生功能重组：

```text
过去主要卖：
“你没有联网电脑，我按小时给你一台”

后来还可以卖：
高性能硬件
+ 同一配置的多人组队条件
+ 私密空间
+ 空调、座椅、休息
+ 线下见面场所
```

我把它记作：

## `post-access shared terminal / 基础接入普及后的共享高性能终端`

这很适合修正一种线性技术史：智能手机和家庭宽带普及，并不意味着共享终端场所只能立即消失；它可以从“接入稀缺”转向“性能、空间和社交条件稀缺”。

但这不等于所有网吧都成功转型，也不等于电竞酒店代表所有年轻人。

## 九、2020—2022：“有 Internet”突然不够了，私人终端成为生活连续性基础设施

疫情期间的大规模居家在线教育把过去不明显的区别放大了：

```text
一个地区有 Internet
≠
一个家庭此刻有可用网络
≠
每个孩子此刻都有一台可以独占的设备
```

2020 年一项覆盖约 92.4 万名中小学生的调查显示：

- 84.73% 使用智能手机居家在线学习；
- 19.26% 使用平板；
- 12.22% 使用笔记本；
- 10.57% 使用台式机；
- 1.13% 表示没有任何终端设备；
- 1.88% 无法连接网络。

来源：

- 中国青年报 / 中国教育和科研计算机网，2020-08-24：
  - https://www.edu.cn/xxh/zyyyy/zxjy/202008/t20200824_1764885.shtml
  - **Measured：大规模调查摘要。**

更具体的同期案例显示：河南洛宁一名 14 岁学生因为家里没有网络，需要夜间到村委会附近蹭 Wi-Fi；陕西部分学生则因信号问题到离家数公里的地方上网课。

来源：

- 人民网，2020-03-07：
  - https://gd.people.com.cn/n2/2020/0307/c123932-33857487.html
  - **B：同时代媒体现场材料。**

另有同期案例记录，一个家庭只有一部手机，兄弟姐妹无法同时上网课，教师最终临时借出家中手机。

来源：

- 人民网四川，2020 年相关教育帮扶报道：
  - https://sc.people.com.cn/n2/2020/0908/c345167-34279262.html
  - **B：同时代个案。**

这一阶段出现了一个与早期网吧正相反的问题：

过去可以：

```text
家里没电脑
→ 出门去共享终端
```

而危机状态下：

```text
必须待在家里 / 学校和公共场所不可正常使用
→ 共享接入 fallback 失效
→ 私人设备与家庭网络决定课程是否连续
```

因此本轮加入：

## `private-terminal resilience / 私有终端韧性`

私人终端不是简单的消费升级。在某些制度和危机场景下，它会变成让教育、工作和办事继续运行的连续性基础设施。

## 十、终端“属于家庭”仍然不等于“属于我”：设备争用也是一种数字约束

家庭拥有一部智能手机并不能说明两个孩子可以同时上课。

这要求在传统的 adoption ladder 之外再增加一个日常问题：

## `terminal contention / 终端争用`

应该问：

- 家里有几台可以真正完成任务的设备？
- 谁优先使用？
- 父母上班是否要带走手机？
- 两个孩子是否同时有课？
- 一台低端手机能否运行指定应用？
- 流量、充电、电池、摄像头和麦克风是否正常？

因此：

> **household ownership != individual availability at the needed hour**

这和“一户有一台电视”的统计含义完全不同，因为交互式学习和工作常常要求同时、独占地操作设备。

## 十一、2023—2026：共享终端没有消失，但它已不再等于“没有自己的 Internet”

2025 年一篇行业报道采访/观察到，一些刚毕业年轻人仍选择网咖包夜，理由包括氛围、高刷新率硬件和相对于电竞酒店的价格；报道以重庆解放碑为例，某网咖高刷区域 8 小时包夜团购约 49.8 元/人，而附近电竞酒店价格明显更高。

来源：

- 闻旅 / 36氪，2025-03-03：
  - https://36kr.com/p/3190333863403654
  - **B/C：同期行业媒体的小样本观察与转述，不能代表青年总体。**

这里最安全的结论只有：

> 在个人手机和家庭 Internet 已普及以后，仍然存在把高性能终端、场所和社交环境按小时购买的需求。

不要把这直接写成“防守型未来”。

它可能与：

- 不愿购买昂贵高性能 PC；
- 短期游戏需求；
- 异地朋友聚会；
- 宿舍 / 合租空间限制；
- 对统一硬件性能的需要；
- 夜间休闲；

有关。

要把它和 2023—2026 的“退路、现金缓冲、稳定、少承担固定资产”连起来，还需要更直接的一手材料。

## 十二、海外对照：公共网络接入也早于家庭私有终端普及

这种路径不是中国特有。

1993 年前后 EFF 的《Big Dummy's Guide to the Internet》已经专门介绍美国的 `public-access systems`：有的由商业公司经营，有的由非营利组织经营；有免费、包月/包年，也有按小时收费的系统。

书中列出的 Peoria Free-Net 更明确：

- 在图书馆；
- 政府建筑；
- 老年中心；

设有公共接入终端；取得包括电子邮件在内的完整访问需要提交书面申请，费用为零。

来源：

- Electronic Frontier Foundation / Adam Gaffin, *Big Dummy's Guide to the Internet*, 1993-era text; Project Gutenberg 1994 edition:
  - https://www.gutenberg.org/ebooks/118
  - 文本镜像（本轮用于定位条目）：https://www.lib.ru/INTERMET/bdgtti-1.02.txt_with-big-pictures.html
  - **A：同时代网络指南。**

Cleveland Free-Net 从 1986 年开始运行。Case Western Reserve University 的机构史记录，它让拥有电脑或终端和 modem 的普通人拨号进入，并为注册用户提供免费电子邮件、学校、医疗信息和公共讨论空间。

来源：

- Case Western Reserve University, Cleveland Free-Net institutional history:
  - https://case.edu/news/history-cleveland-free-net-cwru
  - **C/B：后来的机构档案回顾，用于系统身份与功能史。**

跨国共同机制是：

> **网络接入可以先于家庭拥有一整套私人联网终端。**

但组织形式不同。

美国 Free-Net 的公共终端更常与大学、图书馆、社区和非营利公共信息服务连接；中国 1990s 末—2000s 的大规模共享 Internet 接入则更多通过商业网吧、按小时计费，并逐渐叠加实名、计费和场所监管系统。

这不是“谁更先进”的比较，而是说明同一个技术能力可以通过不同制度容器进入普通生活。

## 十三、它改变了我们怎样理解“Internet 普及”

本轮至少需要同时观察四个不同指标：

| 层级 | 问题 |
|---|---|
| 网络覆盖 | 这个地方能否连接 Internet？ |
| 服务接入 | 附近是否有学校、单位、网吧、图书馆等可用终端？ |
| 家庭拥有 | 家里是否有联网电脑 / 手机 / 宽带？ |
| 个体可用 | 我此刻是否有一台可以独占、能完成目标任务的终端？ |

它们越往后越接近一个普通人真正能做什么。

### 一个生活动作的例子

如果 2008 年一个县城青年想在网上找外地工作，问题不只是：

> “招聘网站存在吗？”

还需要问：

```text
附近有网吧吗？
→ 一小时多少钱？
→ 要不要身份证？
→ 今天有没有机器？
→ 机器能否打开网站？
→ 能否输入中文和上传简历？
→ 邮箱密码是否安全？
→ 打印 / 保存简历怎么办？
→ 下次换一台机器还能不能继续？
```

只有这些步骤都能执行，“网上求职”才真正进入这个人的生活菜单。

## 十四、重点矩阵

| 维度 | 本轮新增理解 |
|---|---|
| 教育 | 学校机房/网吧可让没有家庭终端的人接入；2020 又暴露私人终端对居家教育连续性的作用 |
| 就业 | 网吧可以承担查招聘、投信息、学习软件等动作；需要进一步找更强的求职第一人称证据 |
| 住房 | 宿舍、合租、农村家庭的空间/设备条件影响是否需要共享终端；后期电竞酒店又把终端与住宿重新捆绑 |
| 婚姻家庭 | 家庭是否购买电脑、谁能使用设备、兄弟姐妹设备争用会改变数字机会 |
| 迁移 | 持久账号可跨城市继续使用，而接入终端可以每次更换 |
| 照护 | 家庭可通过 QQ/邮件等保持联系，但共享终端具有地点和时间约束 |
| 非正规劳动 | 小网吧、复印店/培训点等可把数字接入嵌入其他小商业空间；仍需更系统证据 |
| 长期中断 | 共享终端可作为家庭设备故障/缺失的 fallback；疫情又显示公共 fallback 可能整体失效 |
| 证件与记录 | 2000s 网吧实名卡把身份证、上机时间、机器号连接成一次可记录的访问 session |
| 通信方式 | 身份随账号移动，终端仍属于场所；之后手机让通信终端逐渐随身 |
| Internet 平台 | 网站用户可能来自完全不同的物理终端环境，平台自身通常看不出这种差异 |
| 信息获取 | “有网站”与“有一台可执行浏览/输入/下载的机器”之间存在共享终端层 |
| 社交关系 | 网吧既承载线上社交，也形成玩家线下聚集；后期电竞空间继续这种功能 |
| 未来预期 | 2005—2012 的扩张可表现为按小时租到此前买不起的数字能力 |
| 线上/线下身份 | QQ/邮箱等持久身份与实名上机卡属于两套不同身份系统 |
| 平台消失与记忆 | 历史网页可能保存下来，但当年的网吧终端软件、计费层、输入法、插件和场所规则往往没有一起保存 |

## 十五、后见之明风险与反例

### 风险 1：把网吧用户等于“没有家庭电脑的人”

不成立。

2008 年受访者已经明确有人单位有良好上网环境，仍因氛围选择去网吧。

### 风险 2：把网吧等于游戏

不成立。

同期证据有聊天、资料、下载、求职、影视和技能培训。

### 风险 3：把实名制度文本等于完全执行

不成立。

2004 年报道自身已经记录借卡、黑网吧和经营者可能放松核验的担忧；后续调查亦有执行不一致。

### 风险 4：把手机普及写成网吧“瞬间死亡”

不成立。

2008—2009 是明显的重叠期；2019、2025 又能看到共享高性能终端和社交空间继续存在。

### 风险 5：把 2020 解释成“Internet 不普及”

错误。

2020 的新问题恰恰是在 Internet 已广泛存在时，某些家庭仍缺少可在正确时间、正确地点完成学校任务的网络和终端。

### 风险 6：把中国早期大众 Internet 从 1994 以前简单回推

本轮没有这样做。

中国 1994 年以前已有科研、邮件、专线和其他数字通信前史，但商业网吧/大众共享 Internet 终端属于正式全功能接入之后的另一阶段；两者不能互相替代。

## 十六、证据分层

### 已知

- 1990s 后期北京已有公众网络咖啡/网吧形态；
- 2001 年大型商业网吧已经可以拥有上千台机器和高客流；
- 2008 年青少年网民使用网吧比例仍很高，农村更高；
- 2009 年手机成为青少年第一位的上网工具，网吧比例下降但仍接近一半；
- 2004—2006 年一些城市把身份证、上网卡、计费和机器号纳入实名上机系统；
- 2019 年共享高性能终端空间仍承担线下聚会和私密休闲；
- 2020 居家在线教育暴露了“家里有无可用终端/网络”和“Internet 已存在”之间的差异。

### 可以合理推断

- 网吧把高额的电脑与网络固定成本拆成按小时购买的数字能力；
- 早期账号个人化快于终端个人化；
- 手机 Internet 的扩张减少了很多必须“去一个地方上网”的动作；
- 私人终端提高了危机期间数字活动的连续性；
- 当基础接入不再稀缺以后，共享终端场所可以转向性能、空间和社交价值。

### 仍不知道

- 不同年份、城市、县城、乡镇的小时价格分布及其占当地青年收入/零花钱的比例；
- 有多少求职、考试报名、租房、恋爱等关键生活动作实际在网吧完成；
- “只通过网吧上网”的群体如何随年份、地区和年龄变化；
- 网吧机器的典型浏览器、输入法、软件安装、USB/软驱/光驱、下载和打印条件；
- 不同实名/计费系统真实执行率；
- 手机第一次真正替代网吧的具体动作分别发生在何时；
- 2023—2026 年年轻人使用网咖的主要动机到底是硬件租赁、社交、空间、价格还是习惯。

## 十七、下一步

最值得继续补的不是再找“某地第一家网吧”，而是三个更生活史的问题：

1. **小时成本**：2000、2005、2008 在不同城市上一小时网，对学生/打工者意味着多少真实预算；
2. **任务证据**：寻找 2007—2010 同时代帖子/博客，直接记录“我去网吧投简历、查成绩、报名、联系家人、找房”；
3. **终端细节**：恢复一台 2003—2008 典型网吧机器真正给用户什么浏览器、输入法、IM、插件、权限、下载/存储方式。

第三项与 OWA 的浏览环境复原直接相连。

## 本轮结论

Internet 普及不是一条从“没有网”到“家里有宽带”再到“每人一部手机”的平滑直线。

中间存在过一个规模很大的历史阶段：

> **一个人的网络身份已经属于自己，但进入这个身份的电脑还只是临时租来的。**

她可以记住自己的 QQ 号、邮箱密码和论坛昵称，穿过城市去另一台陌生电脑上继续同一个网络人生。

后来真正深刻的变化之一，不只是网速更快，而是网络终端从一个必须去的地方，逐渐变成了随身携带的东西。

而 2020 年又提醒我们：当学校、工作和公共服务把“在线”当成连续运行的前提时，**“附近有人能给我一台机器用”与“我在需要的这一小时拥有一台机器”之间，仍然是两种完全不同的生活。**
