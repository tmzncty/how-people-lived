# 从把工资带回家到让账户跟着人走：汇款、银行卡与远程银行，中国 1986—2010

> 类型：ordinary-life infrastructure / 金钱移动 / 迁移家庭 / 数字制度接口研究包  
> 状态：新增机制；不把“银行卡发行”写成“全国随处可取”，不把“网上银行存在”写成“普通人都能独立完成”  
> 交叉仓库：`tmzncty/old-web-archaeology/research/online-banking-card-account-security-token-and-transaction-state-gaps-1997-2010.md`

## 0. 去重：为什么这不是既有“农民工汇款”或“信用史”专题换名字

仓库已有：

- `places/china/migrant-worker-life-horizons-1995-2005.zh-CN.md`，已经指出迁移劳动者身体离开家庭以后，工资仍属于原家庭预算，并提到邮政汇款、邮政绿卡和银行卡；
- `topics/credit-history-borrowing-future-income-and-financial-legibility-china-1985-2026.zh-CN.md`，研究借款、征信和未来收入如何变得可读；
- 若干关于纸—数往返、证明、网吧、电话和 Internet 可及性的研究包。

本文件不重复“为什么迁移”或“银行是否愿意借钱”。它问一个更基础、此前没有独立建模的问题：

> **劳动者已经挣到的钱，怎样从“我身体上带着的现金”变成“一个可以跨城市、跨网点、跨时间被访问和转移的账户状态”？**

研究单位不是某家银行的产品史，而是普通人的几种实际动作：

1. 把工资安全地带回家；
2. 把钱送给远方的父母、配偶或孩子；
3. 离开开户地以后仍能取到自己的钱；
4. 银行关门以后还能查询、转账、缴费；
5. 在家里通过 PC 完成原来必须排队的事务；
6. 为了做到这些，需要什么卡、密码、证件、网点、ATM、浏览器、USB 证书和后台清算网络。

因此本文件研究的是 **money mobility / 资金可移动性**，以及它怎样改变分置家庭、迁移劳动和日常时间预算。

## 1. 先拆开六种完全不同的“钱能跟着人走”

不能把下列状态合并：

```text
银行发行了一张卡
!=
这张卡能在本地另一网点使用
!=
能在同城跨行使用
!=
能异地使用
!=
回到乡镇后附近有受理网点
!=
本人知道并愿意这样用
```

同样：

```text
银行有网站
!=
网站能查账户
!=
能转账
!=
能对外支付
!=
本人已经签约
!=
电脑环境能完成认证
!=
交易最终清算成功
```

这一组区别是本专题最重要的方法约束。

## 2. 1987：ATM 卡已经存在，但账户还没有真正“脱离地方”

中国银行今天保存的银行卡史料写得非常清楚：

- 1987 年，中国银行在珠海发行第一版长城提款卡；
- 这是其所称中国第一张 ATM 提款卡；
- **由于当时电脑通信设备和网络接入不足，只能在珠海当地储蓄所使用**；
- ATM 服务本身已经打破了“取款必须到人工银行柜台”的传统做法。

来源：

- 中国银行，《中国第一张ATM提款卡》：  
  https://www.bankofchina.com/aboutboc/ab5/200811/t20081119_11892.html

证据等级：**B（银行机构后出的历史档案 / 产品实物说明）**。

这条材料特别适合反对“卡一出现，钱就全国可携带”的发明日期陷阱。

更准确的阶段是：

```text
1987：
个人拥有一张机器可读的取款凭证
+
部分人工柜台劳动可以转给 ATM
-
账户可达范围仍被地方网络限制
```

### 新机制一：`account-location coupling / 账户—地点耦合`

如果一张卡只能在珠海本地使用，那么卡跟着人去了别的城市，账户的实际可达性并没有一起走。

所以“银行卡便携”至少有两个层次：

1. **credential portability**：卡本身可以装进口袋；
2. **account portability**：卡背后的账户状态可以在异地系统被识别并执行交易。

第一层可以早于第二层很多年。

## 3. 1986—2001：邮政把“遍布城乡的物理网点”逐渐接成一个金融网络

中国邮政储蓄恢复于 1986 年。后出的邮储机构史记录：

- 1994 年开始建设“绿卡”工程；
- 2001 年实现全国联网；
- 用户凭绿卡或活期存折，可以在联网市县通存通取。

来源：

- 中国邮储相关机构历史材料（北京日报保存）：  
  https://xinwen.bjd.com.cn/content/s63328fcde4b015f9c7a16747.html

证据等级：**B（机构后出的历史回顾）**。

同期地方证据可以把“全国联网”变得更具体。2001-01-17《浙江日报》报道，一名深圳用户在台州通过邮政储蓄成功取款 5 万元；当时浙江已有近 1000 个邮政网点、近 200 台 ATM 接入计算机网络，并公布了异地存取手续费上限。

来源：

- 浙江日报 / 新浪，2001-01-17，《浙江省邮政储蓄实现全国通存通兑》：  
  https://news.sina.com.cn/c/171481.html

证据等级：**B（同期新闻）**。

### 新机制二：`branch decoupling / 网点脱钩`

过去：

```text
钱存在哪里
→ 很大程度决定到哪里能把它取出来
```

联网以后逐渐变成：

```text
账户在后台系统中被识别
+
另一个城市 / 另一个网点加入同一网络
→ 人可以离开原存款地点后继续使用这笔钱
```

这不是“现金消失”。它是**资金所有权和某一个具体柜台的位置开始脱钩**。

对于迁移劳动者，这个变化尤其重要，因为“我在哪里工作”和“我的家庭在哪里花钱”本来就是两个地点。

## 4. 2002：邮政汇兑仍是非常庞大的家庭资金基础设施

《人民日报》2003-10-13 报道的 2002 年邮政数据记录：

- 全国办理邮政汇兑业务的网点约 **4.5 万个**；
- 其中农村网点约 **3.2 万个，占 70%**；
- 全年受理汇款约 **2 亿笔**；
- 其中近 **70% 汇往农村**；
- 全年汇款交易金额近 **2800 亿元**；
- 约一半资金流入农村；
- 流入西部 12 省份约 800 亿元，其中四川约 297 亿元。

来源：

- 《人民日报》2003-10-13，第 16 版，《汇兑服务遍城乡》：  
  https://cn.govopendata.com/renminribao/2003/10/13/16/

证据等级：**B（同时代国家报刊，引用邮政统计）**。

这组数据纠正一种很容易出现的后见之明：

> 2000 年代初“卡和网银已经出现”，不等于远距离家庭汇款已经主要通过网上转账完成。

邮局仍然是一条巨大的资金运输网络，而且农村覆盖正是其核心优势。

### 新机制三：`remote household finance / 远距离家庭财务`

迁移家庭的家庭预算可以在空间上被拆开：

```text
劳动发生在 A 城
工资在 A 城获得
家庭住房 / 孩子 / 医疗支出在 B 地发生
资金通过汇兑 / 账户网络跨距离进入家庭预算
```

这意味着：

**家庭共同经济生活可以早于家庭共同居住。**

一个人住在工地、宿舍或出租屋里，并不妨碍他的工资成为另一个省份家庭的建房、教育或医疗资金。

## 5. 2005：真实农民工仍大量依赖邮政，甚至直接把现金带回家

中国人民银行《中国区域金融运行报告（2005 年）》的“农民工金融需求与农民工银行卡特色服务”专栏给出非常关键的同时代调查：

- 2005 年末转移农村劳动力约 1.8 亿，其中异地转移约 53.5%；
- 常年进城务工约 1.4 亿；
- 30 岁以下青年约占调查对象 76%；
- 年收入集中在 8000—11000 元，人均约 **8520 元**；
- 收入多汇回家乡，用于建房、子女教育、医疗；
- 部分省农民工人均持卡量仅约 **0.32 张**；
- 广东、河南调查中，利用银行卡把钱汇到家的比例约 **11%**；
- 更多人使用邮政汇款与邮政绿卡，两项合计约 **51%**；
- 使用银行卡的农民工中，约 **95%** 主要用于异地存取款，消费、转账相对少；
- 报告还直接指出，由于农村网点和结算条件不足，有较多农民工选择携带现金。

来源：

- 中国人民银行货币政策分析小组，《2005 年中国区域金融运行报告》，2006-05-25，专栏 2：  
  https://www.pbc.gov.cn/eportal/fileDir/history_file/files/att_12732_1.pdf

证据等级：**A（中国人民银行同期正式报告 / 调查汇总）**。

### 这组数据最重要的不是“11%”本身

它证明同时存在至少四条家庭资金路线：

```text
1. 现金随本人返乡
2. 邮政汇款
3. 邮政绿卡 / 异地存取
4. 商业银行卡异地存取 / 汇款
```

不能写成：

```text
银行卡出现
→ 邮政消失
→ 农民工不再带现金
```

真实变化是渠道组合逐渐扩展，而且不同教育、收入、年龄和网点条件的人切换速度不同。

## 6. 2005—2007：“农民工银行卡特色服务”把城市卡网络接到乡镇取款点

2005-12-29，贵州率先试点“农民工银行卡特色服务”。新华社同期报道解释的业务链非常朴素：

```text
打工地
→ 在参与银行把现金存入带“银联”标识的卡
→ 人可以回乡，也可以让家庭使用安排好的卡/账户
→ 家乡县及县以下农村信用社受理
→ 柜台或 ATM 取现
```

试点时每卡每日累计取现不超过 5000 元，手续费按交易额 1% 收取，最低 1 元、最高 50 元。

来源：

- 新华网 / 新浪财经，2005-12-29，《农民工“取款难”得到实质性突破》：  
  https://finance.sina.com.cn/roll/20051229/1911472444.shtml

证据等级：**B（同期新华社报道）**。

2007 年手续费降到 0.8%，最高 20 元；江苏等地仍保留每卡每日累计取现 5000 元的限制。

来源：

- 南京日报 / 搜狐，2007-02-01：  
  https://news.sohu.com/20070201/n247983371.shtml

证据等级：**B（同期媒体）**。

### 新机制四：`value mobility / 资金可移动性`

一个人的工资不再必须以相同的物理钞票跨越铁路和长途汽车：

```text
城市现金
→ 城市账户状态增加
→ 支付/银行卡网络传递账户状态
→ 家乡金融网点确认
→ 家乡现金被取出
```

真正跨省移动的不是那叠钞票本身，而是**可被另一个地点承认的账户状态**。

这改变的不只是方便程度，也改变风险结构：

- 少携带大量现金，降低途中被盗风险；
- 但增加密码、卡、系统、手续费、每日限额、网点可达性等新依赖。

所以“更安全”不是“无风险”，而是**风险从身体携带现金转移到凭证和网络执行**。

## 7. 2007 第一人称：一年的劳动成果为什么会变成“到底怎么带回家”这个问题

2007-02-12 中国新闻网的一组同期报道采访 28 岁的袁丽芳。她三年前从老家出来务工，在昆明一家单位做内勤，月收入约 900 元，准备把攒下的 9000 多元带回家。

她回忆，两年前做工地炊事、月收入约 600 元，一年省下约 7000 元；原本打算翻修房屋、买猪仔、给孩子买衣服。为了防盗，她把钱用塑料袋包好藏在衣服里，但在火车上睡着后仍被偷走。

得知农民工银行卡特色服务以后，她最看重的正是：

- 不再把一年积蓄直接带在身上；
- 回家后可以在乡镇信用社取；
- 手续费可接受。

来源：

- 中国新闻网 / 新浪财经，2007-02-12，《央行推出银行卡特色服务 农民工是心动还是不用》：  
  https://finance.sina.com.cn/roll/20070212/10291213725.shtml

证据等级：**B（同期媒体采访；第一人称经记者编辑呈现，不是私人日记）**。

这条材料比“银行卡更方便”具体得多。

对于她而言，一次金融基础设施变化可以直接改变：

```text
一年劳动所得
→ 是否必须变成随身携带的实物
→ 春运途中睡觉是否意味着高额资产暴露
→ 家里翻房、养殖、孩子衣物的计划是否可能因途中失窃瞬间中断
```

### 反例：知道服务，不等于愿意使用

同期和 2007 年其他报道仍不断出现：

- 有人不知道这一服务；
- 有人嫌手续费；
- 有人受每日取款额度限制；
- 有人原本已经用“自己持卡存、家人持存折/同账户取”的办法解决问题；
- 农村受理网点、服务态度和系统条件仍会改变选择。

因此：

```text
service exists
!= user awareness
!= local acceptance
!= cost acceptable
!= limit fits household need
!= adoption
```

## 8. 2001：为什么“银联”不是一个小 Logo，而是账户可达性的基础设施

中国人民银行 2001-03-13 发布《关于统一启用“银联”标识及其全息防伪标志的通知》，直接说明目标是：

> 建立全国统一的银行卡受理市场，方便商户和持卡人受理与使用银行卡。

通知还要求：

- 新申请发行、需要异地或跨行使用的银行卡应符合统一联网联合业务规范和技术标准；
- 地区性联网通用标识逐步废止；
- 自 2004-01-01 起，ATM、POS 和特约商户统一使用银联标识。

来源：

- 中国人民银行，银发〔2001〕57号：  
  https://www.pbc.gov.cn/chubanwu/114566/114579/114652/2838262/index.html

证据等级：**A（同期监管文件）**。

这说明：

**卡片的物理便携性必须由后台标准化受理网络支撑，才可能变成全国性的资金便携性。**

1999 年《银行卡业务管理办法》则已经把银行卡定义为具有消费信用、转账结算、存取现金等全部或部分功能的信用支付工具。

来源：

- 中国人民银行，银发〔1999〕17号，1999-01-05：  
  https://www.pbc.gov.cn/chubanwu/114566/114579/114658/2899177/index.html

证据等级：**A（同期监管文件）**。

## 9. 2006：银行卡已经非常普遍，但“有卡”仍不等于同样地使用卡

中国人民银行首次发布的《中国支付体系发展报告》披露：

- 2006 年末借记卡发行约 **10.8 亿张**；
- 信用卡接近 **5000 万张**；
- 银行卡消费交易额约 **1.89 万亿元**；
- 剔除批发和房地产后，银行卡消费约占社会消费品零售总额 **17%**；
- 北京、上海、广州、深圳等大城市约达到 30%。

来源：

- 中国人民银行，2007-07-31，《The People’s Bank of China Issued China Payment System Development Report for the First Time》：  
  https://nanjing.pbc.gov.cn/english/130721/2025080815063064391/index.html

证据等级：**A（央行对 2006 支付体系的正式披露）**。

这和 2005 农民工调查放在一起看，最重要的结论不是“谁先进谁落后”，而是：

> **同一年里，银行卡可以已经成为大城市消费基础设施，同时许多迁移家庭仍主要把它当异地存取工具，或者仍依赖邮政和现金。**

“银行卡普及”不是一个单一行为状态。

## 10. 1997—2000：远程银行不是从智能手机开始，甚至不是从“完整网上银行”开始

工商银行机构史记录：

- 1997 年 12 月网站开通；
- 1999 年推出全国统一电话银行 `95588`；
- 2000-02-01 网上银行在北京、天津、上海、广州开通；
- 2000 年 8 月个人网上银行和牡丹信用卡 B2C 在线支付等业务开通。

来源：

- 中国工商银行，《工商银行电子银行引领金融服务走进e时代》：  
  https://www.icbc.com.cn/icbc/%E5%8C%97%E4%BA%AC%E5%88%86%E8%A1%8C/%E5%88%86%E8%A1%8C%E5%8A%A8%E6%80%81/%E5%B7%A5%E5%95%86%E9%93%B6%E8%A1%8C%E7%94%B5%E5%AD%90%E9%93%B6%E8%A1%8C%E5%BC%95%E9%A2%86%E9%87%91%E8%9E%8D%E6%9C%8D%E5%8A%A1%E8%B5%B0%E8%BF%9Be%E6%97%B6%E4%BB%A3.htm

证据等级：**B（银行机构历史回顾）**。

因此更准确的通道演化不是：

```text
柜台
→ Web
→ 手机
```

而是长期重叠：

```text
柜台
+ ATM
+ 电话银行
+ Web
+ 后来的手机
```

### 新机制五：`banking-time decoupling / 银行业务时间脱钩`

柜台有营业时间，也要排队。

ATM、电话银行和网银逐渐把不同动作从“银行开门并且我人在网点”的约束中拆出来：

- 查余额；
- 小额取现；
- 转账；
- 缴费；
- 定活互转；
- 投资交易。

这里改变的是普通人的**一天怎样安排**。

以前：

```text
银行事务
→ 请假 / 午休 / 排队 / 通勤到网点
```

后来一部分事务变成：

```text
晚上回家
→ 打电话 / 打开电脑
→ 几分钟完成
```

## 11. 2003—2007：当钱可以在网页里移动，访问“自己的钱”反而多了一套新物理凭证

工商银行现存旧页面记录，2003 年推出 USBKey 数字证书，后来命名为“U盾”。2007 年银行称：

- 个人网上银行客户约 3066 万；
- U盾客户约 256 万；
- U盾早期价格曾约 138 元，后来降至最低 58 元。

来源：

- 中国工商银行，《工商银行全面下调U盾价格》：  
  https://www.icbc.com.cn/icbc/gxk_1/8724.htm

证据等级：**A-content/B（银行当前服务器保留的历史业务页面；可证明银行现存的历史陈述，不证明页面 DOM 自当年未变）**。

2006 年工行与支付宝合作的旧页面更具体：

- 用户要先到银行网点持有效证件开通个人网上银行并申请 U盾；
- PC 上要安装驱动 / 补丁；
- 证书可柜台代下载，也可自己从个人网银下载到 U盾；
- 失败时仍需回柜台办理；
- 使用支付宝时必须插入 U盾并输入 U盾密码，才能进行充值、提现、账户管理等操作；
- 不插 U盾时只能进行查询类动作。

来源：

- 中国工商银行 2006 年旧页面：  
  https://www.icbc.com.cn/icbc/html/guanggao/2006nian/0523/images/zfb_060522.html

证据等级：**A-content / live-legacy artifact（当前仍可直接读取的银行旧页面；不是已验证的 2006 archive capture）**。

### 新机制六：`credentialized liquidity / 凭证化流动性`

钱从“必须本人拿着现金”变成账户状态以后，自由并不是无条件增加。

访问这笔钱开始依赖：

```text
银行卡 / 存折
+ PIN / 密码
+ 身份证
+ 签约状态
+ 某些交易的 USB 数字证书
+ 兼容电脑 / 驱动 / 浏览器环境
+ 银行后台
+ 清算网络
```

因此：

**资金越脱离身体，越依赖另一套身份与技术凭证把它重新接回本人。**

这和仓库已有的“证件 / 数字接口可执行性”问题直接相连。

## 12. 2009 第一人称：银行从“要去的地方”变成后台服务

中国建设银行 2009-07-02 的同期客户体验报道采访“王睿”：

- 在北京一家大型公司工作；
- 当时工作约四年；
- 从 2006 年开始使用网上银行；
- 除大额取现外，很少再跑银行网点；
- 常用定活互转、汇款；
- 通过网银买基金、做纸黄金；
- 水、电等缴费也在线完成；
- 他描述自己的安全做法为三个不同密码、网银盾和私人电脑。

来源：

- 中国建设银行，2009-07-02，《网银体验：150种服务没有门槛》：  
  https://e.ccb.com/chn/2009-07/02/article_2022110117412612869.shtml

证据等级：**A-content/B（同期银行客户报道；受访者一手话语经银行媒体编辑，不是独立日记）**。

这不是全国青年样本，更不能拿来代表农村、低收入者或所有 2009 年网民。

但作为存在性案例，它非常清楚地展示了 **2005—2012“扩张型未来”** 的一种微观体验：

> 一部分城市青年开始发现，越来越多原本需要专门跑一次机构的生活事务，可以在个人电脑前完成。

2009 年末，建行官方披露个人网银客户超过 3800 万，电子渠道与柜面交易量之比全国达到 77%，北京达到 143%。

来源：

- 中国建设银行，2009-12-29：  
  https://www.ccb.com/chn/2009-12/29/article_2022110414395542753.shtml

证据等级：**A-content（银行同期业务披露；属于该行业务规模，不可外推为全国人口使用率）**。

### 新机制七：`institutional trip compression / 制度性跑腿压缩`

如果一个人可以在晚上完成：

- 查余额；
- 转账；
- 缴水电费；
- 定活互转；

那么变化不是抽象的“金融数字化”，而是：

**一天里少了一次必须在某个营业时间去某个柜台的出门。**

这种节省对工作时间固定、通勤长的人尤其可能有价值。

## 13. 反例：Web 让银行离家更近，也把兼容性、安全和失败处理带进家里

不能把网银写成纯粹“无摩擦”。

2006 工行 U盾页面本身已经显示：

- 要去柜台签约；
- 要安装驱动；
- 可能要安装补丁；
- 证书下载失败要回柜台；
- 某些功能只有插入硬件证书才能执行。

因此家里的 PC 开始承担过去由银行网点统一管理的一部分执行环境。

这可以写成：

### `execution burden transfer / 执行负担转移`

```text
柜员替你操作
→ 你自己操作
```

带来：

- 时间自主性增加；
- 但用户要自己管理密码、驱动、证书、电脑安全和失败排错。

“更自助”不是单纯减少劳动，而是**重新分配劳动**。

## 14. 海外对照：法国 Minitel 证明“远程银行 != Web 银行”

BNP Paribas 历史档案记录：

- 1982 年 BNP 用 Minitel 向 500 名客户测试三项服务；
- `Téléservice B` 可以在家订支票簿、外币、接收网点消息；
- 1984 年交互式服务扩展到专业客户，随后扩展到个人客户；
- 订户从 1984 年约 1.5 万增长到 1989 年底约 22.5 万；
- 转账等日常操作从柜台被转移到 Minitel；
- 1994 年 Panorama 服务又可通过 Minitel 或电话管理账户、查看资产和下证券指令。

来源：

- BNP Paribas Historical Archives, `Customers relationship`：  
  https://histoire.bnpparibas/en/highlights/customers/
- BNP Paribas Historical Archives, `Minitel – the advent of home banking`：  
  https://histoire.bnpparibas/en/minitel-the-advent-of-home-banking/

证据等级：**B（银行历史档案，含历史广告/实物，但文章为后出的机构整理）**。

### 跨国共同机制

中国和法国都出现：

```text
账户后台电子化
→ 客户不再必须每次见柜员
→ 家庭终端 / 电话 / ATM 可以成为银行入口
```

### 不能抹掉的差异

法国的 Minitel 路径说明，**home banking 可以在 WWW 之前大规模存在**。

中国则更明显地看到：

- 邮政城乡物理网点；
- ATM / 银行卡联网；
- 电话银行；
- Web 网银；
- 农村信用社受理；

长期重叠。

因此不应该把“金融现代化”写成统一的 Web 时间线。

## 15. 这改变了我们对“人怎么活着”的哪一点理解

### 15.1 迁移不只需要身体可移动，还需要钱可移动

如果工资只能安全地留在打工城市，或者必须由本人用现金带回，长期分置家庭的执行成本会高得多。

邮政汇兑、异地通存通取和银行卡网络让一种家庭结构更可执行：

```text
一个人在外地工作
+
家人留在原居地
+
收入仍持续进入共同预算
```

### 15.2 “账户属于我”不是自然等于“我随时随地能拿到钱”

它取决于：

- 网络是否连通；
- 网点在哪里；
- 跨行规则；
- 手续费；
- 每日限额；
- 卡 / 密码 / 证件；
- 系统是否在线。

金融所有权和金融可执行性必须分开。

### 15.3 远程银行改变了机构和个人之间的劳动分工

柜员的一部分动作变成用户自己做：

- 找菜单；
- 输入账号；
- 判断收款人；
- 安装安全控件；
- 保管硬件证书；
- 自己确认交易结果。

这与互联网时代更广泛的“self-service institutional labor / 自助式制度劳动”属于同一趋势。

### 15.4 “现金少了”并不代表物质基础消失

真正让账户可移动的仍是大量物质设施：

- 银行机房；
- 通信线路；
- ATM；
- POS；
- 农信社柜台；
- 邮政网点；
- 卡片；
- USBKey；
- PC。

所谓无形资金移动，依赖的是更庞大的有形基础设施。

## 16. 与时代时间感的关系

### 2005—2012：扩张型未来

本轮有较强证据。

银行卡受理面扩大、农民工特色服务、网银客户增长和 2009 城市白领访谈共同显示：

> 越来越多金融动作开始从“去某个地方办”变成“在别处也能办”。

这是一种非常具体的“未来在扩张”：**地理和营业时间少限制了一点。**

但不能把它写成所有人同步进入无现金生活。2005 农民工调查恰恰说明渠道差异仍然巨大。

### 2015—2019 / 2020—2022 / 2023—2026

本轮不强行制造新的时代结论。

后续若重开这一线，优先问题应是：

- 移动支付普及后，现金 / 银行卡 / 手机中的 fallback 是什么；
- 疫情期间，线下银行不可达时数字认证是否变成新的排除机制；
- 2023—2026 年“留现金缓冲 / 多卡多账户 / 备用支付方式”是否真的进入普通人的防守型未来，而不是研究者想象。

这些都需要同时代个人材料，当前包不越证据边界。

## 18. 后见之明风险

### 风险一：把“银行卡”当成天生全国通用

1987 中行 ATM 卡已经直接反驳这一点。

### 风险二：把“网银”写成柜台被淘汰

实际是多渠道共存，而且开户、U盾申请、失败恢复仍可能回到柜台。

### 风险三：把现金携带写成“不会用现代金融”

2005 人民银行报告本身指出农村网点、结算渠道、手续费和产品供给限制。选择现金可能是基础设施约束下的现实判断。

### 风险四：把 2009 北京白领经验投射到全国

必须保留城市、工作单位、收入、PC、银行账户和数字技能等筛选条件。

### 风险五：把法国 Minitel 写成 Web 的“原始版本”

它是另一套专用终端、电信网和服务生态。比较的是远程账户访问机制，而不是把 Minitel 偷换成 Internet。

## 19. 尚未确定

1. 1980s—1990s 普通家庭实际怎样在“现金随身、邮政汇款、银行汇票/转账”之间选择，仍缺更多同时代家庭日记/调查。
2. 邮储绿卡全国联网在不同省县的真实可用时间差仍需细化；“全国联网”不代表同一天覆盖每一基层网点。
3. 1997—2002 早期个人网银的真实普通用户体验材料仍不足，尤其是拨号上网成本、浏览器兼容、首次签约失败和安全焦虑。
4. 2005—2008 农民工银行卡服务的**知道但不用**人群值得继续做第一人称样本，而不只看交易额。
5. 家庭成员共享银行卡/存折/密码的真实实践及风险尚缺可靠材料，不应凭常识推断。
6. ATM 故障、吞卡、跨行失败、节假日现金不足等“失败日常”还没有系统整理。
7. 当前没有证据支持把 2023—2026 年“现金缓冲 / 备用账户”直接纳入防守型未来。

---

## 20. 下一步最值钱的证据

优先级从高到低：

1. **2007–2010 普通人的博客/BBS**：第一次网银转账、U盾安装、异地取款、汇钱回家；
2. 1990s 邮局汇款单、操作规程和用户手册：恢复汇款到底要填什么、等多久、收款人怎样领取；
3. 2000—2006 ATM/异地取款失败与收费争议的同期消费者材料；
4. 一份可核验的 2000s 早期银行 Web 历史 capture，把“银行今天保存旧页面”推进成真正 historical memento；
5. 2018–2019、2020–2022、2023–2026 关于备用支付、现金、冻结/失去手机后的生活 fallback 的同时代材料。

## 21. 本轮饱和判断

这不是一次仅补证据的运行。

本轮新增了此前未独立建模的生活/制度机制：

- `account-location coupling / 账户—地点耦合`；
- `branch decoupling / 网点脱钩`；
- `remote household finance / 远距离家庭财务`；
- `value mobility / 资金可移动性`；
- `banking-time decoupling / 银行业务时间脱钩`；
- `credentialized liquidity / 凭证化流动性`；
- `institutional trip compression / 制度性跑腿压缩`；
- `execution burden transfer / 执行负担转移`。

其中最重要的不是命名，而是它们实质改变了一个问题的答案：

> **一个人离开家乡后，挣到的钱是否还能安全、持续、低成本地进入原家庭生活？**

答案从“本人把现金带回去 / 邮局替他送回去”，逐渐增加到“账户状态本身跨地区可达”，再增加到“本人甚至不必在银行营业时间进入网点”。

因此本轮应重置 no-new-mechanism 饱和计数为 **0/3**。

## 22. 一句可进入后续综合的结论

> **现代迁移不只是让人更容易离开家，也需要让工资不必和人的身体一起旅行。**

当钱逐渐从口袋里的钞票变成一个能够被另一个城市识别的账户状态以后，分居两地的家庭才获得了一种新的执行能力：人可以不回家，钱先回去。
