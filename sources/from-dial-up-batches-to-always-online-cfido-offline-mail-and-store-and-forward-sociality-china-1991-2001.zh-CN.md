# 从拨一次号到持续在线：CFido、离线信包与存储转发式社交，中国 1991—2001

> 性质：`how-people-lived` / `old-web-archaeology` 交叉研究包。  
> 主题：在中国尚未形成大众 Internet 接入以前，普通的计算机爱好者如何通过电话网、调制解调器、拨号 BBS 与 FidoNet 式存储转发网络取得数字通信；这种生活与后来 Web / Internet 的连续和断裂在哪里。  
> 核心限制：本文研究的是一个高度选择性的早期采用者群体，**不能**把 CFido 用户写成 1990 年代中国普通人口的代表，也不能把 CFido 本身写成 Internet。

## 0. 为什么这不是已有专题的同义改写

仓库已经研究过：

- 公共终端 / 网吧与 `access-without-ownership`；
- 离线光盘与 `offline digital access`；
- 邮政、电话、寻呼、电子邮件和移动 Internet 的若干生活执行机制；
- BBS / 论坛后来如何形成兴趣社群与可寻址身份。

但截至本轮仓内检索，`CFido` / `FidoNet` 没有独立条目，也缺少以下机制：

1. **一个数字网络可以在没有持续 Internet 连接的情况下运行；**
2. 用户和站台都可以只短暂拨号，通过批量信包维持跨城交流；
3. 电话线本身是排他资源——一个用户在线阅读，可能意味着别人无法拨入；
4. 因而“离线阅读 / 离线写信”不是便利功能，而是网络规模能够成立的一部分；
5. 1990 年代后半期 CFido 内容又可以同时经拨号网络和 Web 发布，形成旧网络向 Internet 的桥接，而不是瞬间替代。

这组机制会直接改变“中国 1994 年以前有没有数字网络生活”的回答，因此不是单纯补一个平台名。

## 1. 必须先划清的四条边界

### 1.1 1994 年以前不能写成“中国完全没有网络”

中国科学院 / CNNIC 的互联网大事记把 **1994-04-20** 作为中国通过 64K 国际专线实现 Internet 全功能连接的日期；此前已有科研联网、电子邮件等更有限的数字通信形式。

来源：

- CNNIC，《1994年～1996年互联网大事记》  
  https://www3.cnnic.cn/n4/2022/0401/c87-912.html
- 中国科学院计算机网络信息中心，《中国“网”事：穿过羊肠小道，驶入信息高速》  
  https://cnic.cas.cn/jdtw/zxyw/202404/t20240422_7127250.html

因此：

```text
1994-04-20 以前
≠ 没有任何数字网络
≠ 普通家庭已经能上 Internet
```

### 1.2 CFido 不是 Internet

2024 年《Isis》研究把 Chinese FidoNet（CFido）的起点定在 1991 年，并把它描述为中国计算机爱好者的 BBS 网络空间；该研究同时把 dial-up BBS → Internet 的转变视为 CFido 走向终结的重要背景。

来源：

- Wen-Ching Sung, Chen-Pang Yeang, Zhixiang Cheng, “Demarcating a Pure Land: CFido as a Cyberspace for Computer Amateurs in 1990s China,” *Isis* 115(2), 2024, pp.267–291.  
  https://www.journals.uchicago.edu/doi/10.1086/730229

这里应把 CFido 写成：

> 通过公共电话网、调制解调器、独立 BBS 站台、FidoNet 协议和定期信包交换形成的业余数字通信网络。

而不是：

> 1991 年中国普通人已经上互联网。

### 1.3 “能参加”不等于“大众可及”

潭城小站（StarStudio BBS）的遗留页面直接写明，加入 BBS 至少需要：

- 一台电脑；
- 一台调制解调器；
- 一条可以拨打外线的电话；
- 通信软件。

来源：

- StarStudio BBS 遗留页，`https://www.cfido.com/starstudio/star.htm`

所以 CFido 的重要性不是它已经代表大众普及，而是它证明：**在中国大众 Internet 尚未出现时，已有一小群非科研机构内的计算机爱好者把数字网络真正嵌入了自己的日常通信、学习、软件交换和社交。**

### 1.4 今天仍能打开的 `cfido.com` 是 live-legacy artifact，不自动等于“1997 原页原封不动”

`cfido.com` 当前首页自述：

> 网站最后更新时间 2001-10-17；“网站保留了2000年时候的样子，不再美化”。

这使它成为很珍贵的遗留站点，但证据写法应是：

- 可以 A 级证明“今天这个站点当前提供这些 HTML / 文本”；
- 可以作为较强的历史 provenance 线索；
- 但没有独立 hash / 同期 capture 时，不应声称今天的每个字节都和 2000 年完全相同。

来源：

- https://cfido.com/

## 2. 新机制一：`store-and-forward sociality / 存储转发式社交`

今天很容易把“网络交流”默认成：

```text
A 在线
↓
服务器一直在线
↓
B 很快收到
```

1997 年《龙音》第二期里的同期技术文章给出的 CFido / dial-up BBS 图景完全不同。

文章明确说：

- dial-up BBS 的站际信件交流不是实时的；
- 只有两站调制解调器真正拨通以后才能交换信息；
- 全天 24 小时互联在技术上可以，但成本不是一般业余站长能够承担；
- 常见做法是在每天特定时段由 mailer 向上游拨号或等待上游拨号；
- 信包和文件在这段连接中批量交换；
- 交换频率受信息量和站长经济能力影响，文中称一般每天一次。

来源（同时代原文，1997-05-09）：

- 《龙音》第二期，“fts 网络标准与网络运转”  
  https://www.cfido.com/deq.htm

于是一个跨城帖子/信件可能经历：

```text
用户在本地 BBS 写信
→ 本地站保存
→ 到约定时间，本地站拨上游站
→ 批量传输信包
→ 上游再向其他节点传播
→ 另一城市站台下一轮同步
→ 当地用户下次拨入时看到
```

这是一种真正的数字网络社交，但其时间结构接近“批量运输”，而不是今天的持续连接。

### 它改变了什么生活经验

**消息没有消失，但“到达”不再以秒为单位。**

一个人可以和另一个城市从未见过的人讨论软件、音乐、硬件或日常生活，而不要求双方同时在线，甚至不要求两端站台同时长期联网。

它提供了一种介于：

```text
邮政书信
```

和

```text
实时 Internet chat
```

之间的通信时间。

这里可以定义：

> **`synchronization horizon / 同步周期`**：用户对“网络上新消息什么时候会出现”的实际预期，取决于站台之间多久交换一次信包、自己多久拨入一次，而不是只取决于消息发送时间。

## 3. 新机制二：`connection-time scarcity / 连接时间稀缺`

StarStudio 的遗留使用说明把电话线约束写得非常直接：

- 很多业余站台因为成本原因是**单线系统**；
- 也有 3–4 线站；
- 一个用户占用线路时，别人就少一次上站机会；
- 因而用户每天在线时间有限；
- BBS 明确不鼓励在线读信和写信。

更强的是，StarStudio 把使用时间直接写进账号权限：

- 新用户：每天约 10 分钟；
- 正式用户：每天约 20 分钟；
- 更高一级：每天约 30 分钟；
- 正式用户升级条件之一，是会使用 Blue Wave 离线信件工具。

来源：

- https://www.cfido.com/starstudio/star.htm

因此网络访问在这里不是抽象的“账号能否登录”，而是一个**排他的分钟预算**。

可以把实际可及写成：

```text
有电脑
× 有 modem
× 有可拨外线电话
× 电话费可承受
× 站台此刻没有被别人占线
× 账号今天还有分钟额度
× 通信软件可用
= 此刻真的能进入 BBS
```

这和后来“网页存在即可随时访问”的直觉差别很大。

### 普通生活层面的含义

一个用户在屏幕前多停十分钟，并不只是自己多花十分钟：

> 在单线 BBS 上，这十分钟可能同时意味着另一个人不断听到忙音。

所以这里出现了 **`resource-aware etiquette / 资源感知型礼仪`**：

社区规范“不要在线看很久”，不是单纯讲礼貌，而是基础设施稀缺直接塑造出来的文化。

## 4. 新机制三：`offline packetization / 离线信包化`

StarStudio 页面保存了 Blue Wave 的完整生活工作流：

```text
短暂拨入 BBS
→ 下载一整个信包
→ 挂断电话
→ 本地离线阅读
→ 本地离线写回复
→ 软件把回复打成新信包
→ 下一次拨入
→ 上传回复包
→ 站台整理并传播
```

页面自己列出的收益是：

- 节省电话费；
- 节省上站时间；
- 给自己更多读写时间；
- 给其他站友更多上站机会。

来源：

- https://www.cfido.com/starstudio/star.htm

这和仓库已有的“光盘把数据离线搬进电脑”不是同一机制。

光盘解决的是：

> 大文件怎样在低带宽时代进入机器。

Blue Wave 解决的是：

> **交互式社区怎样在连接时间极稀缺时仍然容纳长时间阅读和写作。**

它把：

```text
连接时间
```

和

```text
思考 / 阅读 / 写作时间
```

解耦了。

所以用户可以只占线路几分钟，却在离线状态下花半小时甚至几小时认真看信、写长回复。

## 5. 网络拓扑本身也被电话费塑造

《龙音》1997 年同期技术文把 FidoNet / CFido 的树状路由结构直接和节省电话费联系起来：

```text
node
→ hub
→ host / net coordinator
→ region coordinator
→ zone
```

区域划分往往跟电话区号 / 地理接近有关，因为站际传输要真实发生电话呼叫。

来源：

- https://www.cfido.com/deq.htm

这意味着“网络空间”并没有把地理消灭。

恰恰相反：

> **电话费把地理重新写进了拓扑。**

北京、福建、成都等地的站点之所以以地域网络组织，不只是文化兴趣，也是因为谁给谁打电话、一次通话多少钱，会影响怎样路由最合理。

## 6. 一个非常硬的同时代网络状态物证：1997 nodelist

现代保存仓 `lshw/cfido_nodelist` 保留了原始格式的 CFido nodelist 文件。

`NODELIST.234` 文件头明确写：

- Friday, August 22, 1997；
- Region 65 of Fidonet；
- 中国大陆各 net / hub / node 的机器可读记录。

其中可直接确认：

- 北京、东北、华东、上海、华南、西南、福建等地域 net；
- 福建 Net 657；
- `StarStudio_BBS` 作为 `657/901` 节点存在；
- nodelist 还含 station name、location、sysop、modem capability、phone 字段等。

源文件：

- https://github.com/lshw/cfido_nodelist/blob/master/NODELIST.234

另一个时点 `NODELIST.304`（1997-10-31）仍能看到福建 Net 与 StarStudio，但邻近节点状态已经发生变化，例如某些节点出现 `Hold`、新增 `Pvt` 或 hub 重组。

源文件：

- https://github.com/lshw/cfido_nodelist/blob/master/NODELIST.304

这对生活史的意义不是“列电话簿”，而是证明网络是一套**周期更新的现实基础设施**：站台上线、暂停、迁移、改号、改变角色都会进入下一版状态表。

### 隐私 / 再发布边界

历史 nodelist 含真实电话号码和姓名。号码今天可能已经重新分配，因此本仓：

- 记录字段结构、节点号、站名和历史状态即可；
- 不需要重新复制整份普通个人电话号码清单；
- 若后续做数据集，默认对 phone 字段做红acted / hash / presence-only 处理。

## 7. 1997：旧网络没有瞬间被 Internet 替掉，而是发生“跨传输系统投影”

《龙音》第二期的开头提供了一个非常少见的同期桥接证据。

1997-05-09 的编辑说明写道：

- 1997-05-01 前后，CFido 获得 `cfido.com` 和 Internet 服务器空间；
- 《龙音》的内容基本取材于 CFido 信件；
- 杂志同时以纯文本、HTML 两种版本在 CFido 站台发行，可拨号下载；
- 同时也可以通过 Internet 上的 `cfido.com` 获取。

来源：

- https://www.cfido.com/deq.htm

因此更准确的变化不是：

```text
CFido 关闭
→ Internet 开始
```

而是至少一段时期存在：

```text
同一社群内容
├─ 通过 CFido 信包 / BBS 下载传播
└─ 通过 Internet / Web 页面传播
```

本文把它称为：

> **`transport coexistence / 传输系统共存`**

和：

> **`legacy-to-Web projection / 旧网络向 Web 的内容投影`**。

这能纠正一个很常见的历史叙述错误：把 Web 上线日期当成前一种通信方式突然消失的日期。

## 8. 同时代第一人称：Internet 被体验为“扩张”，但不能外推给所有青年

同一期《龙音》保存了一篇 1997-04-20 写成的个人文章。

作者说：

- 大约 1996 年 8 月朋友送给自己一台 14,400 bps modem；
- 半年多以来使用 Internet 后，觉得眼界、知识和电脑技术快速扩大；
- 他尝试制作中国民族音乐风格 MIDI，希望通过 Internet 让更远地方的人听到；
- 初稿先上传 CFido，几天内收到网友反馈和鼓励。

来源：

- https://www.cfido.com/deq.htm

证据分类：

- **同时期第一人称自述：A / 高相关性**；
- **代表性：低**。

这个人本身有音乐专业训练、电脑兴趣、modem 和 Internet 条件，显然不是 1997 年普通青年的统计代表。

但它可以证明一件窄而重要的事情：

> **对一部分 1990 年代中后期计算机爱好者而言，CFido 和 Internet 并不是互相排斥的世界；一个作品可以先在本地 / 全国 BBS 网络里获得同行反馈，再被想象成向全球 Internet 发布。**

这是一种“远方突然变得更可执行”的同时代未来感，而不是后来的怀旧叙事。

## 9. 海外比较：昂贵电话线塑造 store-and-forward，不是中国特例

FidoNews 的 1989 年同期材料显示，美国 / 国际 FidoNet 同样存在专门的 network mail 时间窗口。

例如 1989 年的 FidoNews 说明某节点只在 `NMH-1` 到 `NMH+1` 时段接收 network mail，其他时间的网络邮件不接收；另一期关于网络设计与成本的讨论直接用长途电话费计算传输成本，并讨论在 mail window 期间让普通 human caller 等待、优先处理站际邮件。

来源：

- FidoNews Vol. 6 No. 1, 1989  
  https://fidonews.site/1989/v06n01/
- FidoNews Vol. 6 No. 22, 1989  
  https://www.fidonews.site/1989/v06n22/

所以这些机制至少有明显的跨国共同性：

```text
电话连接昂贵 / 排他
→ 规定 mail window
→ 批量传递
→ 离线处理
→ 网络时间呈现周期性，而非持续在线
```

中国特有的不是“发明了这种机制”，而是：

- 它进入中国的电话和个人计算机条件；
- 中文编码 / 中文软件 / 国内站群形成自己的内容生态；
- 1994 后又和快速扩张的中国 Internet / Web 发生特殊的叠加与迁移。

## 10. 它改变了我们对“普通人怎么活”的哪一点理解

此前容易有一条过度整齐的线：

```text
没有 Internet
→ 1994 接入 Internet
→ BBS / Web
→ 宽带
→ 手机
```

现在应该改成至少：

```text
电话 / 邮政 / 寻呼等既有系统
↓
科研 / 邮件 / 专线等有限数字联网
↓
业余拨号 BBS 与 FidoNet 式网络：短连接、批量同步、离线阅读
↓                    ↘
1994 全功能 Internet    继续运行的 CFido / 拨号 BBS
↓                    ↗
Web、电子邮件、Internet BBS 与旧网络内容/人员/软件发生桥接
↓
家庭拨号 Internet 大众化
↓
宽带、持续在线、移动 Internet
```

关键不是再多一个“技术名词”，而是意识到：

> **“联网”曾经并不意味着保持连接。**

一个人的数字生活可以由许多很短的电话连接拼起来：

- 几分钟下载信包；
- 挂断；
- 离线读很久；
- 离线写很久；
- 第二天再拨一次；
- 让自己的回复沿着站台树在下一批次继续向外走。

## 11. 重点矩阵映射

| 维度 | 本轮新增理解 |
|---|---|
| 教育 / 技能 | BBS 信区、共享软件与站友互助形成非正规技术学习网络；但样本高度偏技术爱好者 |
| 就业 | 暂不从“未来创业者”反推普通就业路线；2024 研究仅用于说明人群构成与后续分化 |
| 住房 | 家庭架站说明住宅电话线可成为网络节点，但不能推断广泛家庭拥有 |
| 迁移 | 不同城市用户可不迁移身体而参与同一 echomail 讨论 |
| 照护 | 本轮无足够新证据，不扩写 |
| 非正规劳动 | 站长多为业余维护；不自动等于平台劳动 |
| 长期中断 | 节点可 Hold / Down；用户与网络关系可因设备、电话、费用中断 |
| 证件与记录 | BBS 注册资料、账号级别与权限构成平台内身份接口 |
| 通信方式 | **新增：存储转发、批量同步、离线信包、有限连接分钟** |
| Internet 平台 | **新增：中国 1994 前后的“非 Internet 数字网络 / Internet 共存”边界** |
| 信息获取 | 信区和文件区可跨城市传播技术 / 兴趣信息 |
| 社交关系 | 不要求双方同时在线即可形成持续跨地交流 |
| 未来预期 | 1997 个案显示一部分参与者把 Internet 想象为作品向更远世界传播的通路 |
| 线上 / 线下身份 | 节点号、用户 ID、注册资料、权限级别并存 |
| 平台消失与记忆保存 | nodelist、电子杂志、遗留 HTML 比完整互动 session 更容易保存 |

## 12. 证据等级

### A：同时代 / 原始技术与生活材料

## 13. 反例、后见之明风险和仍不知道什么

### 反例 1：不是所有 FidoNet 节点都只能每天同步一次

海外 FidoNews 1990 已有 `Continuous Mail` 节点 24 小时接收 network mail。因此“每天一次”只能写成 1997 CFido 同期文章对典型业余条件的描述，不能定义为协议硬限制。

### 反例 2：不是所有用户都只有单线 BBS

StarStudio 页面自己说也存在 3–4 线站。因此“一个人在线全站就绝对没人能上”只能用于单线站，不应外推所有站台。

### 风险 1：把早期爱好者写成大众网民

CFido 用户必须具备电脑、modem、电话和技术兴趣，这个群体明显选择性极强。

### 风险 2：把 CFido 写成“Internet 的低配版”

它有自己的路由、站号、nodelist、mail window、echomail 和离线工具逻辑。后来的 Internet 不是简单把速度调快。

### 风险 3：把 1994 当成数字通信的“创世日”

1994-04-20 是全功能 Internet 连接的重要制度 / 技术分界，不是中国第一天出现远程数字通信。

### 风险 4：怀旧化“纯净早期网络”

2024 *Isis* 论文讨论参与者如何把它想象成“pure land”，这本身是历史行动者观念，不是研究者应该接受的价值判断。

### 尚不确定

- 1991—1994 CFido 各年真实活跃用户规模；
- 城市 / 职业 / 收入 / 性别构成；
- 用户实际每周拨入次数和电话费负担的分布；
- 普通站友到底有多少同时也使用 1994 后的 Internet；
- 不同城市站际同步实际延迟，而不是文档中的一般说明；
- 1998 以后 CFido 衰退、迁移到 Internet BBS / Web / QQ 的用户级路径。

这些都应继续找同时期站友日记、信区快照、电话费 / 设备价格、BBS 使用统计，而不能靠后来的名人创业史代替。

## 14. 对阶段饱和判断

上一轮 artifact-first checkpoint 记录连续 `1/3` 次没有新机制。

本轮不能继续计入饱和，因为它明确新增了：

- **通信 / Internet 转折机制**：`store-and-forward sociality`；
- **时间机制**：`synchronization horizon`；
- **基础设施约束机制**：`connection-time scarcity`；
- **行为适配机制**：`offline packetization`；
- **中国 Internet 前史边界**：非 Internet 的业余数字网络与 1994 后 Internet 共存、桥接；
- **跨国比较差异**：电话成本 / mail window 是 FidoNet 共性，而中国的中文软件生态和 Internet 转型路径有本地条件。

因此阶段饱和连续计数应重置为：

**`0/3`。**

## 15. 本轮一句话结论

> **早期数字生活并不要求“在线一整晚”。一个人可以只拨号几分钟，把整个社区装进一个信包，挂断电话，在完全离线的电脑前读很久、写很久，再在下一次短暂连接里把自己的话送回网络。**
