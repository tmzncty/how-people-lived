# 同时代切片：农民工求职、混合中介与“数字化但不一定自己上网”的迁移路线，中国 2006–2009

> 状态：研究切片。用于补充 `places/china/migrant-worker-life-horizons-1995-2005.zh-CN.md`，不替代该文件的总体迁移模型。
>
> 核心问题：Internet 进入农民工招聘以后，是否真的意味着工人本人直接在 Web 上搜索、比较、投递？如果不是，数字基础设施究竟改变了迁移路线的哪一层？

## 0. 去重边界

仓库已有材料已经充分说明：

- 1995–2005 的农村劳动力迁移并不是从“临时迁移”线性变成“城市定居”；
- 亲友、老乡、招工点、企业和地方中介长期共同参与迁移；
- Internet 可以在出发前让远方工作变得可搜索；
- 数字公共就业服务也可能先由柜台工作人员替求职者操作。

因此本切片**不再重复**“网上找工作出现了”或“数字后台先于家庭上网”的一般结论。

本轮新增的是更窄的机制：

> **digitally re-engineered intermediation / 数字化重构中介**
>
> Internet 可以先改变企业、培训学校、地方政府、村级联系人和电话坐席之间的信息流，而不要求每一个最终劳动者本人成为 Web 用户。

由此产生一个生命历程上的中间状态：

> **route portability without endpoint autonomy / 路线可移植性增加，但终端自主性未必同步增加**

工人可能比过去更容易被引向另一座城市、另一家工厂或一条培训—就业路径，但并不一定亲自看见全部候选岗位、亲自输入自己的资料，或独立控制信息如何进入平台数据库。

## 1. 2006：平台已经明确把“最后一公里”当成问题

### 1.1 同时代平台报道

2006-11-06，浙江在线《今日早报》经搜狐保存的报道《农民工网站引千万元投资 公益网站上演淘金传奇》称：

- 杭州新农门信息技术有限公司于 2005 年 9 月创办；
- 新农门网站于 2005 年 11 月正式上线；
- 记者当时实际描述首页已有“打工招工、培训、交流、权益、政策、生活服务、活动专区”等栏目；
- “打工招工”里可看见广东、浙江、上海等地企业招聘；
- 技能不足者可继续查看职业学校培训信息；
- 报道同时明确写到：不会上网或没有时间上网的人，可以通过电话或手机短信取得信息；
- 平台与电信、移动合作，计划把 114、短信等纳入服务链。

Source:
- https://news.sohu.com/20061106/n246217039.shtml

证据等级：**B — 同时代媒体现场/采访报道**。其中会员数、数据库规模、成功就业人数、融资与市场规模等数字主要来自企业自报，不能当作独立审计后的总体统计。

### 1.2 一条罕见的普通劳动者同时代自述

Google Groups 目前保存了一份 2006-10-22 的转载，标注来源为《第一财经日报》，并保留原先指向 `bbs.chinaunix.net/viewthread.php?tid=845617` 的链接。文中采访到 24 岁安徽籍农民工王新胜：他“平时喜欢上网”，认为网站里的招聘、培训和维权内容是为他们量身做的。

Source:
- https://groups.google.com/g/jusocn/c/_xob-bzL_js

证据等级：**B/C 边界 — 同时代媒体文本的后续公开转载保存**。

它很有价值，但必须防止两种误读：

1. 王新胜能上网，只能证明**存在**会主动使用 Web 的农民工用户，不代表当时农民工普遍如此；
2. 这不是已经核验的原始《第一财经日报》网页或原 ChinaUnix 帖子 artifact。

同一篇材料反而清楚记录了平台自己所谓的“最后一公里”问题：能上网的农民工仍是少数，因此网站、地方办事处、短信和 114 必须共同构成服务体系。

这使我们可以同时保留两个真实状态：

```text
some migrant workers directly use Web
!=
most migrant workers directly use Web
```

以及：

```text
Internet influences a migration decision
!=
worker personally browsed the Internet
```

## 2. 2006–2007：Web 只是整套招聘拓扑中的一个端点

### 2.1 114 电话不是“旧技术残余”，而是数字平台的接口之一

2006-12-14《杭州日报》经新浪保存的报道记录：新农门与中国电信推出“打电话找工作”平台。用户拨 114，说明求职或招聘后被转到专门热线，由工作人员按要求做劳动力供需匹配并反馈信息。

Source:
- https://finance.sina.com.cn/roll/20061214/05551098410.shtml

2007-01-07《杭州日报》经搜狐保存的进一步报道还把 `www.sinomen.cn`、电话、短信、“打工卡”和人工反馈放在同一个服务体系里。

Source:
- https://news.sohu.com/20070107/n247457743.shtml

这不是“Internet 被电话替代”。更准确的是：

```text
employer / institution Web or database access
          ↓
shared labour-information system
          ↓
Web / SMS / 114 operator / local intermediary
          ↓
worker
```

因此一个没有家庭电脑、不会填写复杂网页表单的劳动者，仍可能进入由 Internet/数据库支撑的招聘链。

### 2.2 2007：平台甚至明确不把农民工 Web 流量当成主要价值流量

2007-07-04《新京报》经新浪保存的报道非常关键。它称新农门的模式从一开始就不是主要依靠农民工本人访问网站，而是让用工企业成为主要 Web 用户：

- 企业会员可以从数据库选择劳动力；
- 平台从职业培训学校定期取得毕业生资料；
- 与各地“阳光工程办公室”联系，把登记劳动力资料收入数据库；
- 又通过短信平台联系上万个自然村村长；
- 有用工需求时，村级联系人可以成为本地招聘中介。

Source:
- https://tech.sina.com.cn/i/2007-07-04/03501596638.shtml

证据等级：**B — 同时代媒体对商业模式的采访/描述**。数据库“上千万”等规模数字来自相关方陈述，不用于总体估计。

这比“机构中介数字化”再多一步：这里并不是单个窗口替一个求职者查询，而是**整个迁移招聘网络被重新布线**。

传统老乡网络可能是：

```text
村里熟人
→ 已经在外务工的亲友
→ 某个具体工厂/工地
```

新农门所描述的混合网络则可能是：

```text
远地企业需求
→ 平台数据库
→ 学校 / 阳光工程办公室 / 村级联系人 / 114 坐席 / SMS
→ 本地劳动者
→ 培训或直接外出
```

信息跨地域移动得更快、更容易复制，但“谁替你筛岗位、谁把你的资料放进去、你到底看见多少选项”仍可能掌握在中介节点手中。

## 3. 新的生命历程机制：迁移路线可以变得更可替换，而不等于个人完全自主

### 3.1 老乡网络的优势不只是信息，而是信任和落地

既有仓库材料已经表明，1990s–2000s 农民工依赖亲友/同乡并不只是“因为没有互联网”。熟人网络还可以提供：

- 哪家厂真的招人；
- 工资是否能拿到；
- 到站后去哪里；
- 初次住宿；
- 工作规则；
- 出事时找谁。

因此 Internet 理论上可以扩展岗位信息范围，却不能自动替代这套信任与落地基础设施。

### 3.2 2007 调查恰好显示“新增路线”和“旧路线”同时存在

2008-01-16《市场报》经搜狐保存的《2007中国农民工（蓝领）报告》摘要称，其联合调查覆盖 40 个城市、两万多名蓝领工人、企业和培训机构。报道给出的求职渠道比例中：

- 朋友介绍：41.9%；
- 老乡介绍：32%；
- “上网找工作”：2006 年 7.9%，2007 年 9.9%。

Source:
- https://business.sohu.com/20080116/n254693642.shtml

这组数字**不能作为全国概率样本**：调查与新农门平台本身有关，具体抽样框、拒访和权重在当前报道中不清楚。

但作为同时代 evidence，它非常适合反驳两种相反的神话：

- 不是“2007 年农民工还根本没有网上求职”；
- 也不是“Web 已经取代老乡与朋友”。

更稳的结论是：

> 新通道已经出现，但旧社会网络仍然占据主要位置；现实是**channel portfolio / 渠道组合**，而不是一个渠道突然消灭另一个渠道。

### 3.3 `route portability without endpoint autonomy`

如果一名劳动者过去只能沿“本村某亲戚 → 某城市某厂”出去，新的平台—学校—村干部—电话链可能使另一座城市、另一家厂更容易抵达。

这可以增加：

- 迁移目的地的可替换性；
- 工厂之间重新分配劳动力的速度；
- “先培训再就业”的路线可见性；
- 一次返乡后重新出发的可能路径。

但它并不自动增加同等程度的：

- 完整岗位比较权；
- 资料录入控制权；
- 对数据库字段的知情；
- 对中介筛选逻辑的可见性；
- 到岗后的议价能力。

因此：

```text
more routable
!=
more autonomous in every dimension
```

## 4. 2009：可搜索、可转介的未来仍然可能被宏观冲击突然关闭

2009-02-10“新华视点”对四川、河南、山东、安徽返乡农民工的蹲点调查，是理解 2005–2012“扩张型未来”不能写成单向扩张的重要反例。

报道援引当时估算：约 2000 万农民工因金融危机失去工作或没有找到工作而返乡。山东菏泽火车站的魏铁旦从大连回来，给出的理由极其直接：城里已经没活，只能回家。另一名返乡劳动者则因最后一个月工资被大幅拖欠/削减，不敢在节后立即再进城找工作。

Sources:
- https://news.sohu.com/20090210/n262156888.shtml
- https://news.sina.com.cn/o/2009-02-11/072815143190s.shtml

证据等级：

- 全国数量：**B/A- — 当时官方调查与官员发布经新华社报道**，仍需保留抽样和推算口径；
- 个案言说：**B — 同时代记者采访**。

这给“扩张型未来”增加一个必要限定：

> 2005–2012 的扩张，不等于每一年、每个人都更容易向前；它也包括一种新经验——路线、城市和岗位看起来越来越多，但一次需求冲击可以同时让大量路线失效。

因此 digital routing 降低的是一部分**信息与协调成本**，不是宏观就业需求风险。

## 5. 2024 的对照：近地就业本身也成为可选路线，而不是只有“出去/不出去”

2024-05-22 人民网安徽报道的天长市劳动者唐来庆提供了一条同期第一人称材料。他回顾此前夫妻长期在上海、苏州、深圳、广州等地务工，老人孩子难以照看；2024 年他利用已有 18 年电镀经验，在本地“春风行动”招聘会上进入家乡工业企业，妻子也在本地园区找到工作。他把“收入”和“能照顾老人、孩子、田地”放在同一个就业判断中。

Source:
- https://ah.people.com.cn/n2/2024/0522/c374164-40853090.html

证据等级：**B — 同时代地方就业报道中的个人采访**。

这不能证明全国农民工普遍转向本地，也不能拿宣传报道估计成功率。

但它适合和 2006–2007 做长线比较：

- 早期混合数字招聘主要帮助“怎样更有效地把人送到需要劳动力的地方”；
- 到 2020s，政策和就业服务还越来越公开地把**返乡、县域、本地园区**作为另一条可执行路线。

因此迁移成为“普通阶段”的一个可能标志，并不一定是人永远离开家乡，而可能是：

> 一个人已经把“出去—换城市—返乡—再就业—就近工作”视为可以反复重组的职业地理，而不是一次决定终身去向的单程票。

本切片仍不足以单独关闭 ROADMAP 中 `When does migration become a normal stage rather than a permanent rupture?`；需要更多 longitudinal life history 才能证明个人层面的重复迁移序列。

## 6. 海外比较：社会网络没有因 Internet 出现就失效

### 6.1 Mexico–United States, 1960s–1980s

Douglas S. Massey 1986 年研究墨西哥—美国迁移时指出，迁移网络把原居地社区与美国特定工作地点连接起来；亲属、朋友和同乡关系随着使用而成熟，最终使迁移能够自我持续。

Source:
- Douglas S. Massey, “The Social Organization of Mexican Migration to the United States,” *The ANNALS*, 1986.
- https://doi.org/10.1177/0002716286487001006

这说明：

> “一个已经出去的人把下一批人接出去”并不是中国农民工或 Internet 时代特有现象，而是劳动力迁移的一种更一般的社会基础设施。

### 6.2 Early online job search in the United States

Niles & Hanson 2003 对美国 Massachusetts Worcester 的研究原本就提出：Internet 有潜力把求职信息带到个人原有地理/社会网络之外，但实际招聘中既有社会关系与既有地理并没有因此消失。

Source:
- Sarah Niles & Susan Hanson, “The Geographies of Online Job Search,” *Environment and Planning A* 35(7), 2003.
- https://doi.org/10.1068/a35253

它与中国 2006–2007 的材料形成一个很好的共同点：

> Internet 更常见的早期作用不是“杀死中介”，而是改变哪些中介能看见更远的信息、以多快速度把它重新传给人。

中国案例比较特殊的地方，在于新农门明确把**职业学校、政府培训项目、村级联系人、114、电信短信和 Web 数据库**组装在同一条服务链里，并把“不上网的人”本身当作目标用户。

## 8. 后见之明风险

### 风险 A：把“平台有 Web”写成“劳动者本人已网络化”

错误：

> 2006 年农民工开始普遍在网上自主选择工作。

更稳：

> 2006–2007 年已经存在直接 Web 求职的农民工，但平台同时专门设计了电话、SMS、学校、政府办公室和村级中介来触达大量不上网的人。

### 风险 B：把“数字化”写成“去中介化”

实际材料恰恰显示中介没有消失，而是出现：

```text
human intermediary
+
digital database
+
telecom endpoint
```

的新组合。

### 风险 C：把“登记入数据库”当成“个人亲手建立档案”

企业、学校、政府项目和村级节点都可能参与资料进入系统。现阶段不能对个别劳动者推断：

- 他是否亲自提交；
- 是否亲自看过 Web profile；
- 是否知道全部字段；
- 是否拥有修改权。

### 风险 D：把 2005–2012 写成持续乐观的线性扩张

2009 金融危机材料提醒：未来菜单可以在扩张期内部突然收缩。

2. `www.sinomen.cn` 的 2006–2008 历史首页、职位列表、职位详情、用户入口是否能打开满足 old-Web METHOD 的 archive capture？
3. 职业学校、阳光工程办公室、村级联系人分别通过什么软件/表格/协议向数据库提交资料？
4. 劳动者通过 114 得到的是口头岗位列表、短信、回拨，还是多种模式？不同地区是否不同？
5. “打工卡”究竟承担身份、优惠、联系信息还是数据库索引功能？当前媒体描述不足以复原其状态机。
6. 2007 调查的完整问卷、抽样框、城市选择、权重和原始报告是否公开可得？
7. 这种混合网络究竟改变了多少人的**实际迁移目的地**，而不仅是信息触达？需要劳动者级 longitudinal 数据。

## 10. 这一切改变了我们对“人怎么活”的哪一点理解

一个普通人进入 Internet 时代，并不一定发生在他第一次自己打开浏览器时。

对 2006 年的一部分农民工来说，Internet 可能首先出现在**别人那一端**：

- 企业的人事员打开数据库；
- 培训学校把毕业生资料送进系统；
- 县里的项目办公室登记劳动力；
- 村里的联系人收到短信；
- 114 坐席在后台匹配岗位；
- 最后工人才接到一个电话，知道“某地现在要人”。

于是数字化最早改变的，可能不是“我会不会上网”，而是：

> **我这一趟人生可以被哪些远方需求找到，又可以沿哪些中介节点被重新路由。**

这比“Internet 取代老乡介绍”更接近实际历史：老乡没有消失，村干部、培训学校和人工坐席也没有消失；它们被接进了一张新的信息网络里。
