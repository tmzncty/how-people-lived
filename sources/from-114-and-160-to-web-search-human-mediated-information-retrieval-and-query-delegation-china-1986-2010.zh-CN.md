# 从 114、160 到 Web 搜索：人工中介检索、查询委托与自助信息获取，中国 1986—2010

> 研究包 / evidence package。初稿由 AI 辅助整理，所有结论按来源等级与不确定性显式标注。

## 为什么补这一层

今天谈“互联网改变信息获取”时，很容易默认互联网以前普通人只能依赖报纸、熟人或纸质目录，而 Web 出现以后才第一次能够“搜索”。这会漏掉一类非常重要的中间基础设施：**普通人把问题交给一个远程的人或电话信息系统，由对方替自己查数据库。**

114 查号台、160/168 声讯或人工信息台、纸质电话号簿，以及 1990 年代末开始出现的网上 114，并不是互相排斥的几代产品。它们更像同一类“把城市变得可查询”的能力，在不同终端、不同收费方式和不同劳动分工之间投影。

这一研究包因此不问“搜索引擎是哪一年发明的”，而问：

> **一个普通人不知道某个单位的号码、火车信息、考试结果、餐馆或服务位置时，实际怎样把一个模糊问题变成可行动的信息？这个检索劳动由谁完成？**

它补充的不是一个新网站清单，而是一个此前仓库没有单独建模的执行机制：`query delegation / 查询委托`。

## 1. 先区分五种不同的信息检索状态

为了避免把纸、电话、数据库和 Web 混成同一个“信息时代”，本包先区分：

1. **纸质目录检索**：用户自己翻分类或按名称找条目；
2. **人工电话检索**：用户把自然语言需求告诉接线员，由接线员查询内部目录/数据库；
3. **自动语音/声讯服务**：用户按菜单、号码、准考证号等结构化输入取得结果；
4. **Web 自助目录检索**：用户直接操作数据库在 Web 上的公开投影；
5. **通用 Web 搜索**：检索对象从受控目录扩展到更广泛网页和内容。

这五种状态可以长期共存。一个城市居民完全可能在同一天：

- 翻一本纸质黄页找企业类别；
- 打 114 问一个记不清全名的单位；
- 打 160 查考试结果；
- 上 `114china.com` 自己查电话号码；
- 再去门户或搜索引擎找更详细的网页。

因此不能写成简单的“纸 → 电话 → Internet”替代史。

## 2. Internet 以前，电话号簿已经把城市的一部分社会关系做成了可检索目录

日本国立国会图书馆与 CiNii 的书目记录表明，中国电话号簿公司至少从 1986 年起已有《中国电话号簿》系列；现存馆藏记录包括 1986 年的“工商企业”“机关事业”等卷册。另一条馆藏记录显示《中国大黄页 = China Big Yellow Pages》以纸质册形式从 1996 年起出版，并保存有 1996/1997、2003/2004 等卷次。

**证据等级：A/B 边界。** 这些是图书馆书目与馆藏记录，可可靠证明出版物的存在、载体和年份；它们不能单独证明一本目录在某个家庭中的实际拥有率，也不能证明普通用户如何具体使用它。

来源：

- National Diet Library, *中国电话号簿 (中国大黄页 = China Big Yellow Pages)*: https://ndlsearch.ndl.go.jp/books/R100000002-Ia0000038428
- CiNii Books, *中国电话号簿*: https://ci.nii.ac.jp/ncid/BA7649628X

### 对普通生活意味着什么

纸质黄页已经实现了一种很重要的变化：

> **“我认识谁”不再是找到一个机构的唯一入口。**

但纸目录的检索劳动仍主要由用户自己承担。你需要知道大概该翻什么分类，能够识字、理解机构名称，并且目录本身必须足够新。目录一旦印刷，城市中新开、改名、迁址、换号的机构不会自动跟着更新。

这一状态可以称为：

### `portable directory, frozen snapshot / 可携带目录、冻结快照`

它和后来 Web 的一个差别，不只是纸与屏幕，而是**更新时间和检索劳动的分配方式**。

## 3. 114 的关键能力不是“一个号码”，而是把搜索劳动交给了接线员

传统 114 查号服务提供了一种和纸目录不同的生活能力：用户不一定需要自己精确知道条目名称，也不需要自己翻完整目录；可以先把问题交给一个人工中介。

本包把这种结构定义为：

### `query delegation / 查询委托`

用户提供的是不完整的意图：

> “我想找某某单位。”

而真正完成下面这些步骤的人，可能是接线员：

- 判断用户说的是哪个单位；
- 处理简称、同音、旧名、新名；
- 选择目录字段；
- 查询数据库；
- 必要时追问澄清；
- 把结果读回给用户。

这是一种**人工中介搜索（human-mediated search）**。

它和现代搜索框最大的区别不是“有没有计算机”。后台完全可能已经是数据库和联网系统；差别在于，谁负责把人的模糊问题翻译成机器可执行查询。

## 4. 1990 年代的 160/168 证明：电话网络已经可以承载大规模“数据库式信息服务”

1999 年通信业统计公报摘要称，全国 160、168 等电话信息服务台接近 1200 个，用于满足多样化的信息需求。

来源：

- 《一九九九年通信业发展统计公报（摘要）》：https://tech.sina.com.cn/it/2000-06-14/28154.shtml

**证据等级：A/B。** 公报本身是当时行业统计；当前访问的是新浪转录页，适合证明当时公开发布的统计口径，但若将来找到信息产业部原版，应升级 provenance。

1999 年 9 月 29 日《人民日报》还报道，全国范围的电话信息服务联网工程启动，通过专线把各城市信息台接到北京电报局平台，支持 160、168、169 服务；当时北京中心平台已经与 100 多家 168 信息台实时联网，并计划年底连接 200 个城市。

来源：

- 《电话信息服务迈向网络化》，《人民日报》1999-09-29，第 5 版；现可检索的历史报纸镜像：https://www.rmrb.zhouenlai.info/人民日报（1946-2003）/1999/09/1999-09-29.htm

**证据等级：A（文本内容）/ B（当前承载镜像）。** 文章是同时代报纸文本，但当前访问入口不是人民日报官方数字档案，后续若可取得正式馆藏扫描应替换。

### 这一点为什么重要

这说明 1994 之后的中国数字信息基础设施不能只画成：

`Internet 用户越来越多`

还必须同时画一条：

`电话网 → 信息台 → 数据库/联网平台 → 普通电话用户`

一个没有电脑、不会浏览 Web、甚至从未拨号上网的人，也可能正在使用数据库化的信息服务。

因此：

### `digital information access != Internet access`

数字化的信息检索可以先通过普通电话进入生活。

## 5. 1999 年的“网上 114”是数据库换界面，而不是数据库第一次出现

1999 年 9 月 15 日《北京晨报》经新浪转载报道，北京“网上 114”开始试运行，用户可以登录：

`www.114china.com`

查询电话号码、通过号码反查单位、查区号、旧号/旧名对应的新号/新名、常用电话等。报道最关键的一句话不是“114 上网”，而是：**网上 114 建立在查号台原有数据库基础上。**

报道还说：

- 114 查号台当时共有 230 多万个号码资源；
- Web 用户可按单位全名、名称拼音首字母或行业类别查询；
- 企业可以补充信息并查看访问量；
- 为保护隐私，Web 上基本不提供私宅电话。

来源：

- 《北京114查号台提供网上查询服务》，北京晨报 / 新浪，1999-09-15：https://news.sina.com.cn/society/1999-9-15/14567.html

**证据等级：B，confidence: high。** 同时代媒体对明确服务、URL、功能与数据来源的报道；但未取得可直接核验的 1999 Web capture，因此不能把报道里的页面描述升级成 archived-page A 级证据。

### 这里出现了一个新的机制

### `database–interface separation / 数据库—界面分离`

同一套或相互关联的号码数据，可以依次或同时通过：

- 接线员；
- 自动语音；
- Web 表单；
- 后来的电话“语音搜索”；

向普通人开放。

因此“Internet 到来”在这一案例里并不是第一次创造信息，而是：

> **把原先需要通过一个人或电话菜单取得的数据库查询权，部分移交给用户自己。**

## 6. Web 自助查询带来的是自由，也带来搜索劳动的转移

1999 年报道强调，网上 114 的查询次数和时间“不受限制”。这与人工查号或按时长收费的信息服务相比，确实改变了用户能做什么。

一个人可以：

- 重复尝试不同关键词；
- 一次浏览多个同类单位；
- 自己比较结果；
- 在深夜查询，不依赖一个接线员当下的处理速度；
- 把结果复制进其他数字工作流。

但这里也发生了劳动转移。

### `self-service search-labor transfer / 自助搜索劳动转移`

过去：

`用户讲需求 → 接线员理解 → 接线员查 → 返回结果`

Web：

`用户自己决定关键词/拼写/分类 → 系统匹配 → 用户自己判断哪个结果对`

这不是简单的“效率更高”。它意味着检索能力的一部分从专业中介移到普通人身上。

一个人必须逐渐学会：

- 用什么词描述需求；
- 一个机构的正式名称是什么；
- 搜不到时怎样换关键词；
- 列表里哪些结果可信；
- 信息太旧时怎样交叉确认。

因此“会用搜索”本身是一种新的生活技能。

## 7. Web 投影并不等于把电话数据库原样公开：隐私和权限改变了可见世界

1999 年网上 114 报道明确说，为保护隐私，绝大多数私宅电话并没有随号码库一起上 Web。

这很重要，因为它说明：

### `same database family != same visible world`

人工 114、内部数据库、纸质号簿、Web 查询页之间，可能存在不同的：

- 字段范围；
- 条目数量；
- 隐私过滤；
- 反查权限；
- 商业信息层；
- 更新时间。

所以不能因为 Web 服务“基于原有数据库”，就假定一个 1999 年网页用户能看到接线员能看到的所有东西。

这也是后续 OWA 需要特别记录的 `interface-projection state`。

## 8. 2002 年：查高考信息展示了“按时间购买信息”的现实成本

2002 年 8 月 16 日一场关于高考信息收费的公开讨论里，考生家长明确表示，高考信息查询电话每分钟 3 元，家庭因为想尽快知道成绩和录取信息会反复拨打。参与讨论的 160 信息台工作人员则解释了收费和限时机制。

同年北京高招信息也明确给出自动声讯和人工辅助查询电话，并说明输入 9 位准考证号后可查分，每分钟收费 3 元。

来源：

- 《收取“信息费”、“邮寄费”合理吗》，中国教育/CERNET 存档，标注 2002-08-16：https://www.cernet.edu.cn/edu/ji_chu/ji_jiao_news/200603/t20060323_58097.shtml
- 《北京：高考录取8月5日开始》，2002-07-22：https://gaokao.eol.cn/news/200603/t20060323_56370.shtml

**证据等级：B；其中家长发言是同期媒体记录的第一人称材料。** 当前网页是后来的站内迁移/归档页面，应保留原文日期与当前 URL 分离。

这补出另一种生活机制：

### `information-as-metered-service / 信息作为计时收费服务`

一个家庭面对的不只是“有没有信息”，还有：

> **为了更早知道信息，愿不愿意、付不付得起每分钟几元的查询费？**

这种费用结构会直接改变行为：

- 等学校公布，成本低但慢；
- 打信息台，快但收费；
- 让亲戚代查；
- 以后改用 Web，自助查询的边际查询成本下降。

信息时间差本身因此可以被货币化。

## 9. 2002/2007 的一份“北大生存手册”说明：电话与 Web 是并列的城市生活工具

Google Groups 今天仍能访问一份 2007 年 4 月 2 日的转帖。发帖者说明，其中“北大生存手册”原来是北大学生 2002 年在未名 BBS 给暑期来北大备考者写的帖子，因此它应标为：

- 2007 年可核验的转帖 artifact；
- 内容声称来自 2002 年未名帖子；
- **不是已经验证的 2002 原始 BBS capture。**

这份材料非常有价值，因为它把不同信息渠道放在同一页实际生活指南里：

- 北京站行包查询：普通固定电话 + `1608160`；
- 订票：普通电话 + `1605266`；
- `114` 查号台；
- `121` 天气预报；
- `2580` 民航咨询；
- `2585/2586` 铁路信息；
- `1600148` 法律服务热线；
- 同时又列 `www.114china.com`、票务网站、北京公交网等“常用信息查询网站”。

来源：

- Google Groups, 《共享：我所收集到的北大社会学考研信息及资料（转）》, 2007-04-02：https://groups.google.com/g/forcode/c/mQzaCEkX51A

**证据等级：A（2007 转帖 artifact）+ C/B 混合（其中声称转自 2002 未名帖的内容 provenance 尚未独立验证）。**

### 它改变了怎样的历史图景

对于一个从外地来北京备考的人，实际的信息系统不是“互联网替代电话”，而是：

### `channel portfolio / 渠道组合`

她可能随身记着一串电话号码，也记着几个 URL；哪些问题用电话、哪些用 Web、哪些仍看校园张贴、哪些直接问人，取决于：

- 当下有没有联网电脑；
- 电话是否就在手边；
- 信息是否需要即时确认；
- 是否愿意支付信息费；
- 网站数据是否足够新；
- 自己是否知道正确关键词。

**普通人的“信息化”往往首先表现为渠道增加，而不是旧渠道消失。**

## 10. 2006 年的“号码百事通”说明人工搜索并没有因为 Web 普及立刻失去价值

2006 年多家同期媒体把升级后的 114 称作“语音 Google”或电话搜索。报道描述的服务已经不只是返回电话号码，而是餐饮、订票、家政、购物、交通、订房、汽车维修等生活服务信息，并可直接转接相关电话。

来源：

- 《114：从查号台变为“百事通”》，新华社/新浪，2006-03-07：https://news.sina.com.cn/c/2006-03-07/08538379589s.shtml
- 《深圳114查号台变身“电话Google”》，晶报/搜狐，2006-02-22：https://news.sohu.com/20060222/n241950752.shtml
- 《114查号台升级为“号码百事通”》，深圳特区报，2006-02-22：https://finance.sina.cn/sa/2006-02-22/detail-ikkntiak9949842.d.html

**证据等级：B。** 它们可证明运营商和媒体当时确实把电话服务重新定义为生活信息“搜索/导航”；不应把营销措辞直接当成使用效果测量。

其中一篇报道特别强调，电话用户规模远高于网民规模；另一篇深圳报道把不会上网的老年人也作为“语音搜索”可能服务的对象。

这给 2005—2012 “扩张型未来”增加了一个重要修正：

> **Internet 扩张并不意味着所有生活能力都必须先经过 PC 浏览器。**

一部分“搜索能力”继续通过普通电话向未上网、不会上网或不方便上网的人扩散。

## 11. 跨国对照：法国 Minitel 证明“电子自助目录”也不是 Web 发明的

Orange 的官方历史把 Minitel 的商业推广起点放在 1982 年。它依托此前建设的 Transpac 网络，早期试验就包括圣马洛的电子电话簿；1984 年 3615 服务开启后快速扩张，到 1990 年代初约有 650 万户家庭配备终端。Orange 还指出，Minitel 在 2010 年仍有约 200 万用户。

来源：

- Orange, *Our history*: https://www.orange.com/en/our-groupe/our-history

**证据等级：B/A 边界。** 这是制度继承者的官方企业史，可可靠证明其自身服务历史的大框架，但仍属于后出的机构叙述。

### 比较意义

法国材料提醒我们：

### `electronic self-service search != Web search`

普通家庭通过电话线路和专用终端自己查电子目录，在大众 Web 之前已经可以实现。

因此跨国共同变化更像：

`纸目录 / 人工查询`

`→ 数据库化`

`→ 人工或专用终端访问数据库`

`→ PC Web 自助查询`

`→ 通用搜索 / 手机定位 / 平台化本地搜索`

但不同国家走过这些状态的具体组合不同。法国 Minitel 的专用终端自助检索形成了大规模家庭基础设施；中国 1990 年代更值得强调的则是**普通电话 + 人工/声讯信息台 + 后台数据库/联网 + 1990 年代末 Web 投影**之间的重叠。

这是一条真正的跨国差异，而不是笼统的“谁更早上网”。

## 12. 这条线怎样进入“普通人到底有多少种活法”

一个机会要变成现实行动，往往先要被找到。

### 教育

- 查学校和招生办电话；
- 查考试成绩与录取状态；
- 外地考生利用电话和 Web 组合规划赴京备考。

### 就业

- 找一个公司的电话号码和地址；
- 知道行业里有哪些同类单位；
- 在没有互联网终端时仍可通过电话完成初步信息搜索。

### 住房与迁移

- 新到一个城市的人可以查旅馆、交通、单位、公共服务；
- 信息可达性降低了“必须先认识本地人”这一门槛的一部分，但没有消除它。

### 照护

- 家庭成员可以远程替另一个人查号码、查成绩、查交通；
- 老年人或不会上网者可以继续借助语音中介获取信息。

### 非正规劳动与小商户

- 被收录进电话号簿、114 数据库、网上 114 或后来的“号码百事通”，会改变小商户能否被陌生客户找到；
- 但被收录不等于排名公平，也不等于生意一定增加。

### 通信方式与信息获取

- 人工接线员、自动语音、Web 表单、搜索引擎不是纯粹替代关系；
- 普通人常把它们组合使用。

### 线上 / 线下身份

- 一个单位在电话数据库里的正式名称、用户口中的简称和 Web 可搜索关键词可能不同；
- “搜不到”有时并非对象不存在，而是名称没有成功映射。

### 历史可见性

- Web archive 更容易留下 Web 查询页；
- 电话接线员与用户之间的大量澄清、失败查询和口语表达通常没有可见档案；
- 因而后世可能系统性高估“自助 Web 查询”在信息生活中的份额。

## 13. 四段未来框架：这一机制能支持什么，不能支持什么

### 2005—2012：扩张型未来

本轮能支持的窄结论是：

- 可查询的信息渠道快速增加；
- Web 自助、电话人工搜索、自动声讯和手机通信共存；
- “我能不能找到这个机构/服务”越来越少完全依赖熟人网络；
- 对不会上网或没有 PC 的人，电话检索仍是现实 fallback。

这与“扩张型未来”相容，因为一个人的可行动菜单在变宽：陌生城市、陌生单位、陌生服务变得更容易进入视野。

但本轮**没有**取得足够的 2008 年青年第一人称“我如何想象五年后”的材料，因此不把这种基础设施扩张直接偷换成主观乐观。

### 2015—2019：拥堵型未来

本轮没有取得新的、足够强的一手证据来说明这一时期的检索基础设施如何直接产生“拥堵型未来”。现代本地搜索与平台推荐当然可能带来结果过载、竞价与排序问题，但这已经是另一个专题，不在本轮扩写。

### 2020—2022：偶发型未来

本轮没有新增可改变既有结论的证据。

### 2023—2026：防守型未来

本轮没有新增可改变既有结论的证据。

**方法提醒：** 不为了填满四格而给每一时期硬找一个例子。

## 14. 反例与边界

### 反例 1：人工中介并不总比自助搜索“更低级”

一个熟练接线员能够处理：

- 听错/说错一个字；
- 只记得简称；
- 不知道正式行业分类；
- 老年人不熟悉键盘；
- 需要澄清“你找的是哪一家”。

因此 Web 自助不是单向“更先进”，而是把灵活的人类解释换成规模、并发和自主性。

### 反例 2：Web 上线不等于普通电话信息服务立即退出

2006 年 114 反而继续被重新包装成“语音搜索”。渠道重叠持续多年。

### 反例 3：后台数字化不等于普通人自己直接操作数字系统

160/168 和 114 可以高度数据库化，用户表面上却仍只是拿起普通电话说一句话或按几个键。

### 反例 4：一个 URL 能查询不等于数据库全部公开

1999 网上 114 已明确存在私宅号码隐私过滤。

## 15. 后见之明风险

1. **不要把 114 描述成“落后的搜索引擎”。** 对当时很多人，它可能是最易获得、最熟悉、最少要求数字技能的实时检索界面。
2. **不要把 160/168 等同于 Internet。** 它们可以使用数字数据库和联网平台，但普通用户入口仍是电话网。
3. **不要把 1999 的 Web 114 写成大众家庭已经普遍上网。** 功能存在、能访问与大众常态是不同阶段。
4. **不要把 Web 自助当成纯粹减少劳动。** 它把一部分接线员的解释与查询劳动转移给用户。
5. **不要把 2006 的“语音 Google”当成技术等同性。** 这是当时运营商/媒体的比喻和商业定位。
6. **不要把今天搜索引擎的成功投射成 1999 年唯一明显的未来。** 电话搜索、专用电子目录和 Web 查询都曾是现实存在的路线。

## 17. 我们知道什么

- 中国至少在 1980s 已有纸质电话号簿这一制度化目录形态；
- 1990s 160/168 等电话信息服务已形成大规模网络化基础设施；
- 1999 北京网上 114 明确是在原有查号数据库基础上建立 Web 自助接口；
- Web 公开的数据范围与后台/电话服务范围并不完全相同；
- 2002 高考查询展示了电话信息可以按分钟付费，并对家庭造成真实成本；
- 至少在 2002/2007 的城市生活指南中，电话查询号码和 Web URL 被并列作为普通人的信息工具；
- 2006 以后 114 仍继续扩展为生活信息“语音搜索”，说明 Web 并未立即淘汰人工/电话查询；
- 法国 Minitel 证明电子自助目录本身早于 Web，可以通过非 Internet 网络进入普通家庭。

## 18. 可以合理推断什么

### 推断 A：搜索劳动经历了“中介化 → 部分自助化”

证据支持把 114 → 网上 114 理解为：同类数据库的查询劳动从专业接线员向用户部分转移，而不是信息检索从无到有。

**Confidence: high。**

### 推断 B：普通人的数字生活可能早于个人 Internet 使用

一个人通过 160/168/114 使用后台数字数据库，即使本人从未直接操作 Internet，也已经在依赖数字信息基础设施。

**Confidence: high。**

### 推断 C：渠道增加比渠道替代更符合 2000s 初的生活事实

2002/2007 指南同时列电话和网站，2006 电话搜索继续扩展，支持“渠道组合”而非瞬时替代。

**Confidence: high。**

### 推断 D：Web archive 会系统性漏掉人工解释层

历史档案能保存表单或网页，却难保存接线员如何理解口语需求、追问、纠错和选择数据库条目的过程。

**Confidence: high，属于保存机制推断。**

## 19. 仍然不知道什么

1. 1999 年 `114china.com` 的真实页面 DOM、字符集、表单字段、浏览器兼容性和结果页结构；
2. 北京网上 114 的试运行、正式开放时间是否存在媒体口径差异；
3. 报道中的“230 多万个号码资源”与另一时期媒体所述 Web 信息记录数量如何对应；
4. 人工 114 在 1999 年对私宅号码、反查和模糊查询的具体权限；
5. 160/168 各地收费、服务目录和使用频率的地区差异；
6. 普通用户在什么时候开始觉得 Web 查询比打电话“更自然”；
7. 接线员培训手册、查询终端界面与日常工作流程；
8. 2007—2010 年普通年轻人的同期第一人称材料：何时会先百度、何时仍先打 114/12580/号码百事通；
9. 纸质黄页的实际家庭、单位和公用电话场所分布。

## 20. 下一步高价值证据

优先级不是继续发明新概念，而是补真正能改变证据等级的 artifact：

## 21. 它改变了我们对“人怎么活着”的哪一点理解

过去的叙事很容易把信息获取写成：

`没有 Internet → 有 Internet → 会搜索`

本轮证据支持一个更复杂也更符合普通生活的链条：

`纸目录自己找`

`→ 打电话，把问题交给接线员`

`→ 按电话菜单/编号访问数据库`

`→ 同一个数据库的一部分投影到 Web，自助查询`

`→ 电话搜索和 Web 搜索长期并存`

真正改变生活的并不只是“数据库上线”，而是：

> **一个人为了找到陌生世界里的机构和服务，需要亲自掌握多少检索劳动，又有多少可以委托给一个远程的人或系统。**

当用户第一次在 Web 表单里自己敲下名称并按下“查询”时，消失的并不只是一次电话通话。原来坐在另一端、替你听懂一句模糊问题再把它变成数据库查询的那部分劳动，也开始转移到了你自己手里。
