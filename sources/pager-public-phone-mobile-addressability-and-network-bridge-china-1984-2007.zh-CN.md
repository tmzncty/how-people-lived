# 从“有事呼我”到移动 OICQ：寻呼机、公用电话、网上寻呼与移动可寻址性，中国 1984–2007

> 类型：communication infrastructure / internet prehistory / life-course research package。  
> 交叉对象：`tmzncty/old-web-archaeology/research/online-paging-oicq-email-to-pager-gateway-and-terminology-collision-1999-2001.md`。  
> 本文不是“怀旧 BP 机史”，也不是 QQ 产品史。核心问题是：**在普通人还不能随身携带一台廉价双向语音/数据终端的时候，人怎样先获得“离开固定电话以后仍然能被找到”的能力；Internet 到来以后，这套寻呼基础设施又怎样与 Web、电子邮件、OICQ 和 GSM 短信短暂叠在一起？**

---

## 0. 去重与本轮缺口

仓库已经有：

- 1991–1999 CFido / BBS 的 store-and-forward 通信；
- 1997–2003 家庭拨号上网、电话线占用与时间费用；
- 网吧 / 公共终端的共享机器接入；
- 同学录、QQ 等关系重新寻址问题；
- 长距离家庭通信、迁移、汇款、远距离生活成本；
- 互联网大众化以后从 PC 到手机的多种生活路径。

但这些材料很容易把 1990s 的个人通信写成两端：

```text
固定电话 / 公用电话
→
手机 / Internet 即时通信
```

中间缺少一个当时规模非常大的过渡状态：

```text
我本人已经可以移动
+
别人随时可以“叫到我”
+
但我仍不能从随身设备上直接完成双向交谈
```

本轮把这一层称为：

**`mobile addressability before conversational mobility / 双向移动通信之前的移动可寻址性`**。

寻呼机最关键的生活史作用不是“能收到几个数字”，而是第一次让很多普通人的**通信地址跟着身体移动**；但回复仍然依赖固定电话、公用电话、单位电话或其他人的电话。

## 1. 严格区分四件事：固定电话、无线寻呼、移动电话、Internet 并不是一条直线

### 1.1 1998：寻呼已经是大规模通信基础设施，Internet 仍是另一层系统

国家统计局保存的 1999 年通信业回顾材料记载，截至 1998 年底：

- 全国公用电话网电话用户近 9000 万户；
- 移动电话用户 2386 万户；
- **无线寻呼用户 3908 万户**；
- 各类数据通信用户 156 万户。

这些口径并不完全可互换，也不能简单相加，但它们足以说明：在大众 Internet 尚未普及时，无线寻呼已经不是一个边缘玩具。

### 证据

- **A（国家统计局保存的同期统计回顾）**：《之十一：邮电通信业突飞猛进》，原系列写于 1999 年。  
  https://www.stats.gov.cn/zt_18555/ztfx/xzg50nxlfxbg/202303/t20230301_1920449.html

### 1.2 不要把“1994 以后中国已经全功能接入 Internet”写成“普通人已经用 Internet 通信”

CNNIC 第五次调查显示，1999 年底中国 Internet 用户约 890 万。这个数字本身已经远小于当时寻呼用户的数量级；而且 Internet 用户仍高度集中于能够获得电脑、拨号线路、单位或网吧接入的人群。

因此 1990s 末一个普通人的通信栈可能同时是：

```text
家里 / 单位：固定电话
在外：BP 机
需要回话：找公用电话
偶尔：网吧 / 单位电脑上 Internet
少数人：已经拥有手机
```

这些不是互相替代后才出现的整齐阶段，而是长期叠加。

### 证据

- **A（CNNIC 第五次调查）**：2000-01-18 报告，用户规模与使用结构。  
  https://www3.cnnic.cn/n4/2022/0401/c88-823.html
- **B+/同期全文转载**：新浪保存的第五次报告。  
  https://tech.sina.com.cn/news/internet/2000-01-18/15795.shtml

## 2. 寻呼机真正改变的是“别人怎样找到正在移动的我”

固定电话时代的一个基本限制是：

> 电话号码属于一个地点，不一定属于一个正在移动的人。

当一个人离开家、宿舍、办公室以后，打电话的人首先得猜：

- 他现在在哪？
- 那里有没有电话？
- 有谁能替我传话？

寻呼机把这一点改成：

```text
打固定电话 / 寻呼台
→ 寻呼网络广播
→ 某一个人腰间的接收机响
```

这样，通信地址第一次比较稳定地绑定到**人**，而不是绑定到房间、单位或电话亭。

但它只解决了第一半。

## 3. `pager + public phone` 是一个组合系统，而不是两种竞争产品

一台典型的单向数字 / 中文寻呼机不能自己拨号。

于是实际生活动作是：

```text
有人找我
→ 呼机响
→ 看号码 / 留言
→ 判断要不要回复
→ 找最近的固定电话 / 公用电话
→ 回拨
```

这意味着寻呼机和公用电话是**互补基础设施**。

### 3.1 2007 年重庆的“退场时刻”仍然保留了这套动作

重庆晚报 2007 年在联通准备关闭全国无线寻呼服务时回顾当地使用方式，直接写到熟悉的城市画面：呼机响以后，人会去最近的公用电话回话。报道同时记载，重庆 1998 年高峰期有约 50 家寻呼台、150 万寻呼用户；到 2006 年底仍有 7000 余户，但已经主要转向单位内部等专用场景。

这份材料已经处于寻呼退场阶段，不能拿来证明 1990s 每个人都这样使用，但它保存了当时人们仍能共同识别的一套动作语法。

### 证据

- **B（2007 同期退网报道 + 行业回顾）**：重庆晚报经搜狐保存，《重庆尚存7000台呼机使用寻呼业务 归单位专用》，2007-03-06。  
  https://news.sohu.com/20070306/n248531044.shtml

### 3.2 一个 1998 年异地恋个案：身体移动以后，关系可以继续被“叫到”

2008 年的一篇回顾性报道采访到一名 1998 年从江苏到北京上大学的学生。受访者称，他靠 BP 机和仍在老家读书的女友保持联系；每次收到寻呼以后，会跑到外面的公用电话亭回拨，直到后来有了第一部手机。

这是一条 **C 级回顾性个案**，不能被写成 1998 年大学生的总体代表。但它清楚展示了：

```text
异地迁移
+
个人寻呼号码
+
城市公共电话
=
离开原居地以后，仍能保持一种低成本、非同时双向的关系
```

### 证据

- **C/B（2008 媒体采访中的十年前个人回忆）**：《记忆中的BP机时代》，2008-12-03。  
  https://news.sina.com.cn/c/2008-12-03/113316775726.shtml

## 4. “被找到”与“被迫马上说话”并不是同一种可达性

寻呼机的单向性通常被写成技术缺陷，但从生活角度看，它也创造了一种后来手机语音不完全相同的节奏：

```text
别人能通知我
→ 我先看到是谁 / 什么事
→ 我可以决定什么时候找电话回复
```

2017 年一名深圳老用户回忆，他后来即使已经有手机，仍偏爱寻呼机，因为成本低，而且可以降低电话直接打进来的打扰；必要时他甚至会关掉手机，只保留寻呼。

这是很晚的回忆材料，只能用来说明一种曾存在的主观使用逻辑，不能反推所有 1990s 用户都追求“可控可达”。但它提醒我们：

**双向实时通信能力增强，不必然等于所有人都希望对方拥有即时占用自己注意力的权利。**

### 证据

- **C（2017 回顾性地方口述）**：深圳晚报/新浪整理，《“有事CALL我！”那些年……》，2017-11-13。  
  https://news.sina.cn/2017-11-13/detail-ifynrsrf4458004.d.html

## 5. 1999：Internet 没有先“替代”寻呼，而是开始接到寻呼网上

这是本轮最重要的前史修正。

信息产业部综合规划司《通信统计资料汇编（1999）》记载：国信寻呼的用户网络当时覆盖全国 335 个地市、2022 个县市；截至 1999 年底，**“网上寻呼”已经开通 198、199 全国寻呼网、27 个省及部分市县寻呼网，电子邮件业务开通 22 个省市。**

这说明 Internet 早期进入普通通信生活的一条路径不是：

```text
每个人先买电脑
→ 每个人都直接成为网民
→ 寻呼消失
```

而可以是：

```text
Internet / Web / email
→ 电信网关
→ 寻呼网络
→ 一台没有 Internet 接入能力的 BP 机
```

也就是说，**一个人可以先收到来自 Internet 的信息，而不必自己拥有一台联网电脑。**

这可以叫：

**`network benefit without direct network access / 不直接接入网络也能获得网络外溢收益`**。

但注意：这不是说 1999 年大多数寻呼用户都在使用网上寻呼，也不是说普通 BP 机突然变成了 Internet 终端。它只证明跨网服务已经存在并覆盖到相当大的寻呼网络。

### 证据

- **A（信息产业部综合规划司 1999 年统计汇编扫描件）**：《通信统计资料汇编（1999）》。  
  扫描件： https://upload.wikimedia.org/wikipedia/commons/a/a2/SSID-12873460_%E9%80%9A%E4%BF%A1%E7%B5%B1%E8%A8%88%E8%B3%87%E6%96%99%E5%8C%AF%E7%B7%A8_1999.pdf

## 6. 1999 腾讯的一套邮件系统把这个跨网动作写得更具体

腾讯官网当前保存一篇内部日期为 **1999-07-11** 的公司新闻：腾讯与 SINET 合作，把电子邮件增值系统放到深圳电信网络试运行。

系统逻辑是：

```text
邮件到达
→ 提取发件人 / 主题 / 正文
→ 按用户设定规则过滤
→ 发送到寻呼台或 GSM SMS 系统
→ 用户在寻呼机 / 手机上收到内容
```

用户还能在通过用户名、密码验证以后设置：

- 禁呼时段；
- 邮件屏蔽时段；
- 字符串过滤；
- 其他规则。

这条材料特别有价值，因为它证明 Web/Internet 和寻呼并不是两个隔绝世界；**1999 年已经有人在做“把不一定随时在线的 dial-up 用户的 email，投递到随身无线终端”这件事。**

### 证据

- **A-/B+（腾讯当前官网保存的历史公司新闻；内容属于第一方历史陈述，但本轮未验证 1999 年网页原始 capture / DOM）**：Tencent, “Tencent launched email value-added service system in cooperation with SINET”, dated 1999-07-11.  
  https://www.tencent.com/en-us/articles/80260.html

### 不能过推

这条来源能证明腾讯当时宣称该系统试运行、描述了其架构和功能；不能单独证明：

- 用户规模；
- 实际投递成功率；
- 普通用户能否负担；
- 1999 年所有寻呼网络都支持同样能力。

## 7. 一个必须纠正的历史术语陷阱：“网上寻呼”不一定是 BP 机

1999–2001 年左右，“网上寻呼 / 网上寻呼机 / 网络寻呼机”至少存在两种相邻但不同的意思。

### A. 物理无线寻呼网络的 Internet 网关

例如：

```text
Web / email
→ 寻呼台
→ 198 / 199 等无线寻呼网
→ BP 机
```

信息产业部 1999 统计汇编、腾讯 email-to-pager 系统属于这一类。

### B. 用“寻呼”隐喻来命名 Internet 即时通信

例如 OICQ / ICQ。

2000 年 7 月 26 日，《长江日报》一篇网吧现场报道明确把 OICQ 称为**“时下流行的网上寻呼”**。17 岁学生在武汉网吧点击“小企鹅”，同时与多个网友聊天；同一班里有男生会把自己的**真实呼机号**交给刚在网上认识的人，再在课堂上收到物理传呼。

这条现场材料非常罕见，因为两套“寻呼”就在同一个人的通信世界里同时出现：

```text
OICQ：Internet 上的“网上寻呼”
+
BP 机号：离开网吧以后仍能找到这个人
```

### 证据

- **B+（2000 同期网吧现场报道 + 学生直接引语）**：《长江日报》经新浪保存，2000-07-26。  
  https://edu.sina.com.cn/edu/2000-07-26/8748.shtml

## 8. 因此不能把 CNNIC 的“网上寻呼机 21%”直接解释成“21% 网民把 Web 消息发到 BP 机”

CNNIC 1999 年 7 月调查把“网上寻呼机”列为常用网络服务之一，占网上调查用户的约 14.8%；2000 年 7 月的比较表则写成：

- 1999.7：15%
- 2000.7：21%

但同一时期的媒体语汇已经明确把 OICQ 称作“网上寻呼”，后来的中国电信互联网十年回顾也把这一统计项目解释为 **OICQ、ICQ 等**。

因此最安全的研究写法是：

> CNNIC 的“网上寻呼机”说明“network paging / IM-like service”在网民中的使用上升；**不能在没有原始问卷选项说明的情况下，把这个 21% 当成 physical pager gateway adoption。**

这是一条很重要的统计解释纠错。

  1999.7： https://tech.sina.com.cn/news/it/1999-12-15/13431.shtml

- **A（CNNIC 当前官方历史报告页）**：第六次报告。

## 9. 1999 年的人并不知道 BP 机会很快消失：同时代未来想象本身就是史料

1999 年 12 月 8 日《光明日报》刊出《寻呼业仍大有可为》。被采访的通信工程专家当时明确对寻呼前景乐观：文章称中国已有约 7000 万寻呼用户，并预测 **2005 年可能达到 1.3 亿**；同时提出“网上寻呼”、股票信息、体育信息等高附加值服务可能成为未来方向。

我们现在知道这个预测没有实现：2000 年以后手机、来电显示、短信、小灵通等快速吸收寻呼功能，寻呼业务迅速收缩。

但正因为预测错了，它对生活史非常有价值。

它证明：

**1999 年的未来并不是“所有人都已经知道 BP 机马上会被手机淘汰”。**

当时至少有专业人士可以合理想象另一条未来：

```text
寻呼继续大众化
+
网上寻呼 / 信息订阅升级
+
手机和寻呼长期并存
```

因此不能用 2007 年的结局回写 1999 年人的选择，嘲笑他们“买了马上过时的东西”。

### 证据

- **B+（1999 同期专家访谈 / 行业未来判断）**：《光明日报》经新浪保存，《寻呼业仍大有可为》，1999-12-08。  
  https://tech.sina.com.cn/news/computer/1999-12-08/12840.shtml

## 10. 从单向寻呼到双向文本：真正的替代不是“Internet 打败 BP 机”，而是功能重新组合

### 10.1 手机先吸收寻呼机的“叫到人”能力

手机普及以后，来电显示让用户看到谁打过电话；用户可以选择先不接，再用便宜的固定电话回拨。2007 年行业回顾把这种使用方式称作一种“自助式寻呼”。

短信又进一步提供：

- 无需同时在线；
- 文本可以直接留在终端；
- 不必先找公用电话才能回复。

于是 BP 机原先的优势逐渐被一个设备内部吸收。

### 证据

- **B/C（2007 行业退出时的近同时代技术回顾）**：《第一代即时通信工具黯然消失 解读BP机发展史》，2007-07-31。  
  https://business.sohu.com/20070731/n251338633.shtml
- **B（2005 同期退潮调查）**：《他们还在使用BP机》，2005-10-15。  
  https://tech.sina.com.cn/t/2005-10-15/1458740584.shtml

### 10.2 Internet 身份也开始跨过 PC，进入短信网络

2001 年 2 月，北京移动开通“移动 OICQ”。同期报道明确说：手机用户**不需要上 Internet、不需要电脑**，可以通过 SMS 指令开通服务，并直接和 Internet 上的 OICQ 用户互发短讯。

服务结构是：

```text
GSM SMS / WAP
↔ 网关
↔ 腾讯 OICQ
↔ PC 网民
```

到 2001 年 1 月，报道引述腾讯数据称全国移动 OICQ 日讯息量已经超过 100 万条；这些属于企业运营数据，应作为平台自报而不是独立人口统计。

这条转折很关键：

> 1999 年是 Internet / email 向 pager / SMS **推送**；2001 年已经可以让手机短信用户与 PC 上的网络身份**双向互通**。

### 证据

- **B+（2001 同期产品/运营报道）**：新浪科技，《北京地区正式开通“移动OICQ”服务》，2001-03-06。  
  https://tech.sina.com.cn/i/c/56518.shtml
- **B+（2001 同期行业报道）**：南方都市报经新浪保存，《撑起移动梦网半壁江山 小QQ赚大钱》，2001-06-24。  
  https://tech.sina.com.cn/i/c/72816.shtml

## 11. 这一变化怎样改变“普通人能怎么活”

### 11.1 离开固定地点，不再等于彻底离开通信范围

寻呼机使得：

```text
上学 / 跑业务 / 外出 / 逛街 / 通勤
```

期间，一个人仍然保留稳定的“被找到”能力。

这不是完整的移动通话，但已经改变：

- 约见面；
- 工作临时调度；
- 家庭找人；
- 异地恋与朋友联系；
- 临时任务；
- 股票 / 天气 / 信息订阅。

### 11.2 沟通开始从“地点寻址”转向“个人寻址”

粗略地说：

```text
家庭电话：找这个地点
寻呼号：找这个人，但通常需要回电
手机：直接找这个人并双向通话
OICQ / QQ：找这个网络身份
移动 OICQ：网络身份和手机号码开始跨网互通
```

这是一条比“通信越来越快”更准确的变化：

**个人在不同基础设施中的地址逐渐变得可携、可持续、可跨网络。**

### 11.3 互联网的生活影响可以先于 Internet household ownership

1999 的 email-to-pager / 网上寻呼告诉我们：

一个普通人未必先经历：

```text
买电脑 → 接网线 → 学浏览器 → 得到 Internet 信息
```

有些网络信息可以通过运营商网关直接到达已有终端。

这和后来：

- 短信新闻；
- 移动 OICQ；
- 手机报；
- 验证码；
- App push

属于同一更长的“网络信息跨终端投递”谱系，但不能把后来的 push notification 机制简单倒投到 1999。

## 13. 海外比较：美国也经历了“可寻址，但回复仍要找电话”的中间状态

1996 年《Washington Post》采访一对美国母女。母亲经常在外跑业务，母女买了 beeper 以后终于能互相通知，但母亲很快发现一个实际问题：高速公路途中并没有足够多的电话亭用来回复寻呼，于是后来又增加了 cellular phone。

这条同期材料和中国 BP 机—公用电话组合高度可比：

```text
pager solves reachability
but
reply still depends on telephone access
```

### 证据

- **B+（1996 同期家庭采访）**：Washington Post, “Keeping in Touch”, 1996-11-07.  
  https://www.washingtonpost.com/archive/lifestyle/1996/11/08/keeping-in-touch/c191c6b0-26b5-4e2d-994a-b87b605737de/

### 13.1 美国两向 pager 又显示同一技术路线的另一种分支

WIRED 1997 年实测 SkyTel 两向 pager：消息可以由 email、Web 页面或 800 电话发送，收件人直接在 pager 上回复，不需要再寻找电话。报道特别把这种体验描述成更接近 email，而不是传统 paging。

这说明“中国 pager → 手机”的路线不是技术上唯一可能的路线；在美国市场，两向寻呼曾经试图直接补掉 callback dependency。

### 证据

- **B+（1997 同期记者长期使用体验）**：WIRED, “Wireless Gets Real”, 1997-10.  
  https://www.wired.com/1997/10/es-wired/

### 13.2 跨国共同点与中国侧差异

共同点：

- pager 先把“人在外仍可被找到”大众化；
- 单向 pager 的基本缺口都是回复依赖另一个电话；
- 1990s 后期都在尝试 email / Web / paging 的融合；
- 手机与双向数据终端最后吸收了大量 pager 功能。

中国侧值得继续研究的差异：

- 1990s 末寻呼用户规模非常大，而家庭 PC / Internet 接入仍明显稀少；
- 公用电话与寻呼形成了非常可见的组合生活基础设施；
- “网上寻呼”一词又同时被用来描述 physical pager gateway 和 OICQ/ICQ 式 IM，容易造成历史统计误读；
- 2000–2001 GSM 短信、移动梦网、OICQ 网关很快把 Internet identity 拉进手机网络。

## 14. 反例：寻呼机没有简单“消失”，某些单位内部用途反而持续更久

2007 年重庆调查中，一名酒店客房部员工已经在 2002 年放弃私人 BP 机，但工作时仍佩戴单位配发的内部中文传呼；酒店约 50 名客房、电脑、工程人员使用内部寻呼系统，理由之一是成本低、内部电话回呼不另产生费用。

所以：

```text
consumer market collapses
!=
all practical uses disappear simultaneously
```

一项技术从“个人潮流品”退出以后，仍可能在：

- 医院；
- 酒店；
- 工厂；
- 应急值守；
- 特定封闭场所

继续活很久。

### 证据

- **B+（2007 同期在用个案）**：重庆晚报资料经 cnBeta 保存，《重庆7000余市民仍在使用寻呼业务》。

## 15. 后见之明风险

### 风险 A：把 1999 写成“BP 机已经注定死亡”

错误。1999 同期专业人士仍提出到 2005 年继续增长的预测，并把 online paging 视为升级方向。

### 风险 B：把“网上寻呼机 21%”当 physical pager Internet gateway adoption

错误 / 至少证据不足。同一时期“网上寻呼”明确也指 OICQ 式 IM。

### 风险 C：把 1994 全功能接入 Internet 等同于 1994 普通家庭互联网生活

错误。寻呼、固定电话、公用电话、网吧、单位电脑长期构成不同层级的实际可及性。

### 风险 D：把 pager 写成“不完整手机”

过度目的论。它当时有不同价格、漫游范围、耗电、骚扰控制和信息订阅结构；在当时约束下可以是合理产品。

### 风险 E：看到 OICQ 名称里的“寻呼”就假设它和无线寻呼网络天然互通

错误。OICQ 的 metaphor / product category 与 physical paging gateway 必须分别验证。

## 16. 仍不知道什么

1. 1999 国信“网上寻呼”的具体用户端 Web UI、URL、登录字段、费用和普通用户实际使用率，本轮未取得合格历史页面 capture。
2. 腾讯 1999 email-to-pager 系统究竟有多少真实付费 / 试用用户，缺独立运营数据。
3. 数字寻呼与中文寻呼在不同城市、收入层、学生 / 务工者 / 商务人员之间的实际分布仍缺全国性微观数据。
4. 公用电话等待时间、单位电话借用规则、回呼费用如何具体影响低收入用户，需要更多同时代日记 / 论坛 / 采访。
5. 1999–2000 CNNIC 问卷里的“网上寻呼机”原始题项说明和示例产品仍值得继续追，以彻底确认统计口径。
6. 1998–2001 物理 pager gateway 与 OICQ/QQ 的产品关系不能靠后来品牌史倒推。

## 17. 它改变了我们对“人怎么活着”的哪一点理解

此前很容易把通信革命写成：

```text
家里有电话
→ 有手机
→ 有 Internet
```

现在更准确的路线之一是：

```text
家 / 单位电话
→ 公用电话扩大临时回话能力
→ pager 让“个人地址”跟着身体移动
→ Web / email 开始跨网投递到 pager / SMS
→ OICQ 把网络身份变成可持续地址
→ SMS 网关让没有电脑的手机用户也能触达 OICQ 身份
→ 手机逐渐把被呼、回话、短信和网络身份收进同一随身终端
```

这条线里最重要的不是某个设备“更先进”，而是一个普通人逐渐获得了几种以前彼此分开的能力：

- **离开固定地点以后仍然可被找到；**
- **不用立即接听也能先知道有人找；**
- **不拥有电脑也能收到来自 Internet 的信息；**
- **网络身份开始跨设备、跨接入地点持续存在；**
- **最终不再需要为了回复一条移动消息而先寻找另一台固定电话。**

因此，移动通信真正改变的并不仅是“说话不需要电话线”。它改变了：**一个人的社会地址究竟属于一栋房子、一个电话号码、一台设备，还是属于这个人自己。**

## 19. 本轮饱和判断

本轮不是对既有“Internet 让联系更方便”的换词重述。

它新增了至少一个真正会改变解释的通信转折：

> **移动可寻址性先于移动双向会话普及。**

并新增了一个必须保留的跨网事实：

> **Internet 的日常影响可以先通过电信网关到达没有 Internet 终端的人。**

同时发现一个足以纠正历史统计解释的术语问题：

> **1999–2000 的“网上寻呼”既可能指 physical pager gateway，也可能指 OICQ/ICQ 式网络即时通信。**

因此本轮不计入“连续无实质新增”。阶段饱和计数维持 **0 / 3**。
