# 从“等单位安排”到自己重做职业：下岗、技能换算与就业信息中介，中国 1998–2024

> 状态：**交叉研究包 / contemporaneous evidence slice**。
>
> 这不是一篇新的“职场空窗期”总论。仓库已有 [`career-gaps-holding-states-reentry-and-discontinuous-life-courses-china-1997-2026.zh-CN.md`](../topics/career-gaps-holding-states-reentry-and-discontinuous-life-courses-china-1997-2026.zh-CN.md)，已经讨论了 holding state、重新进入摩擦、空窗解释劳动与制度日历。本文件只补它没有充分展开的一组问题：
>
> **当一个人的旧工作世界本身缩小或消失时，原有技能、工龄、单位身份、家庭预算与求职信息怎样被重新换算成市场就业；而“就业信息数字化”又是否等于这个普通人已经直接上网找工作？**

---

## 1. 这一轮为什么值得单独保存

现有研究很容易把 1990s 国企职工下岗压成一个抽象节点：

```text
stable job -> layoff -> retraining / job search -> reemployment
```

1998 年同时代访问显示，真实过程更像：

```text
旧行业需求下降 / 企业停工
-> 人仍可能与原企业保留劳动关系
-> 工龄、住房、养老关系与旧单位仍有牵连
-> 家庭先用配偶工资、亲友借款、下岗生活费缓冲
-> 本人等待单位、做零工、摆摊、进私营企业、试着创业或寻找培训
-> 旧技能需要被另一个劳动市场重新理解
-> 新岗位信息可能经街道、职介所、报纸、电视、热线、LED、计算机网络或后来的网站到达本人
-> 最后才可能重新形成一个稳定职业位置
```

因此本轮加入两个工作概念。

### 1.1 skill-world specificity / 技能世界专属性

技能并不是脱离基础设施存在的“人力资本点数”。

一个人可以真的非常熟练，但如果承载这种技能的运输方式、生产线、企业组织或地方产业收缩，技能的**使用世界**会先消失。

于是：

```text
skill still exists in person
!=
local demand still exists
!=
another employer can recognize it
!=
another job pays for it
```

### 1.2 occupational translation burden / 职业换算劳动

从单位内岗位进入外部劳动力市场时，人还要把：

- 十几年工龄；
- 车间经验；
- 班组长 / 车间主任经历；
- 某一厂、某一运输系统内的技术；
- 单位内部福利关系；

重新翻译成另一个雇主愿意购买的能力。

这和“简历空窗解释劳动”相邻，但不是同一件事：

> **这里的问题不是怎样解释没工作的几年，而是原来非常具体、非常真实的一整套工作资历，在新的岗位分类里值多少钱、能不能被识别。**

# 2. 1998：27 年水手经验可以在几条新道路通车以后突然失去岗位世界

1998 年 2 月 16 日《人民日报》“新春走访下岗职工”采访了广东肇庆港航企业集团职工苏洪光。

同期报道给出的生命史很具体：

- 47 岁；
- 在西江当了 27 年水手；
- 随沿江高等级公路建成、铁路通车，西江客货轮减少；
- 他把自己的处境理解为“到了陆地上，水上的功夫没用了”；
- 妻子没有工作，孩子学杂费需要向亲友借；
- 前一年刚搬进约 60 平方米住房，自己交了 1 万多元；
- 集团生活服务公司暂时安排他到另一名下岗职工开的批发零售店，每月约 300–400 元，但他不知道能做多久；
- 他认为以自己的年龄重新培训再选岗位并不现实，也没有做生意的资金。

来源：

- 《人民日报》，1998-02-16，第 2 版，“该做，就大胆去做——新春走访下岗职工（一）”：
  https://cn.govopendata.com/renminribao/1998/2/16/2/

Evidence grade: **B（同时代记者访问；文本由第三方人民日报历史库保存）**。

它不能证明“老水手普遍不能转岗”；但它直接证明一种普通生命历程状态：

> **技术仍在身体里，岗位世界却可以先消失。**

这也是为什么“培训”不能被抽象成万能按钮。重新训练的实际成本会随年龄、家庭现金、照护责任、地方岗位需求与原有技能可迁移性而变化。

# 3. 1998：家庭不是只遭受一次“个人失业”，而可能经历缓冲层逐层失效

同一组 1998 年报道中的卜荣城，38 岁，高中文化，原安徽芜湖一家金属器具厂职工。

报道说，他在 1995 年底工厂关闭后开始寻找各种收入来源。最初，妻子仍在纺织系统工作，他把这份工作称作家里还有的一个“铁饭碗”；几个月后妻子也下岗，家庭缓冲突然再失去一层。

此后两年，他做过许多短期或非正规活动：

- 卖腌鸭；
- 卖甘蔗；
- 卖香烟、活鱼、年历；
- 给乡镇企业和公司跑腿打杂；
- 夫妻在年三十分别卖糖果、气球；
- 1997 年才租下鞋摊，相对稳定一些。

来源：

- 《人民日报》，1998-02-19，第 2 版，“我们的未来不是梦——新春走访下岗职工（四）”：
  https://cn.govopendata.com/renminribao/1998/2/19/2/

Evidence grade: **B（同时代记者访问；第三方报纸历史库保存）**。

这里需要增加一个家庭层面的状态：

## `household shock layering / 家庭冲击叠层`

```text
one spouse loses unit job
-> other spouse's stable wage buffers household
-> second spouse loses job
-> household becomes multi-route income patchwork
```

所以“一个家庭有没有稳定工作”不能只看户主或一个人的就业状态。

同一个家庭里，可以同时存在：

- 一人下岗、一人在岗；
- 两人都下岗；
- 一人摆摊、一人重新上岗；
- 正式劳动关系仍挂在旧企业、日常收入却来自街边经营。

# 4. “什么都愿意做”与“实际上能接受什么工作”之间仍有社会、家庭和性别边界

1998 年 2 月 16 日同篇报道里的王变兰，是太原一家塑料厂下岗数年的女工，约 35 岁。

她的同期自述非常适合防止后来把“再就业失败”解释成单一技能不足：

- 她舍不得接近 20 年的工龄，希望等单位恢复或安排；
- 单位没有搞过培训，再就业机会和信息很少；
- 家庭主要靠丈夫每月约 400–500 元收入；
- 她知道周围女性有人给私人雇主做事、看孩子、清扫机关单位、做家庭服务；
- 她本人对一些工作有明确的体面、环境与安全顾虑；
- 她还有孩子，丈夫也希望有人留在家里。

来源同上：

- https://cn.govopendata.com/renminribao/1998/2/16/2/

Evidence grade: **B**。

因此：

```text
job physically exists
!=
worker knows route into it
!=
household can release worker's time
!=
worker regards it as acceptable / safe / respectable
!=
pay is enough to justify entry
```

这不是为了替任何选择做价值判断，而是说明“有岗位”与“这条生活路径真正可执行”之间仍有多重接口。

# 5. 一个很少见的同时代未来句子：1998 年，她已经把“学电脑”看成另一种生活的入口

王变兰在采访里还留下了一条很强的 future-horizon 证据。她说，电脑越来越普遍，将来想学一学，希望找到一个更“干净、自由、收入比较高”的工作。

这里必须控制结论。

这条自述能证明：

- 至少对这名 35 岁下岗女工而言，**电脑技能在 1998 年已经进入可想象职业未来**；
- 她把它与工作环境、自由度和收入改善连接起来；
- 这种想象出现时，她本人还没有因此获得一份新工作。

它不能证明：

- 她后来真的学了电脑；
- “电脑工作”当时已经普遍高薪；
- 她有家庭 PC 或 Internet；
- 她是通过 Web 招聘得知这个未来；
- 所有下岗工人都把数字技能当主要再就业路线。

这一区分很重要：

## `visible skill future != executable retraining route`

1998 年的“电脑未来”可以先被看见，真正的设备、培训、岗位匹配和招聘渠道则可能远未准备好。

# 6. “下岗”本身是一个很特殊的制度中间态：没有岗位，不等于劳动关系已经结束

1998 年 6 月 9 日的中央通知把进入再就业服务中心的主要对象写得很清楚：因企业生产经营等原因下岗，但**尚未与企业解除劳动关系、且尚未在社会上找到其他工作**的国有企业职工。

再就业服务中心承担的功能包括：

- 基本生活费；
- 代缴养老、医疗、失业等社会保险费；
- 职业指导；
- 再就业培训；
- 帮助实现再就业。

同时，下岗职工一般在中心不超过三年，期满仍未就业者再转向解除劳动关系、失业救济或社会救济。

来源：

- 中共中央、国务院《关于切实做好国有企业下岗职工基本生活保障和再就业工作的通知》，1998-06-09，《人民日报》1998-06-23 第 1 版：
  https://cn.govopendata.com/renminribao/1998/06/23/1/
- 深圳市 1998 年配套实施文件（可见地方服务中心的生活费、社保、培训、指导功能）：
  https://www.sz.gov.cn/zfgb/1998/gb143/content/post_10123116.html

Evidence grade: **A（正式制度文本的同期公开版本 / 政府公报）**。

所以对 1998 的生活史，至少要拆开：

```text
has a job post
has an employment relationship
receives wage
receives basic living allowance
social insurance still being paid
actually earns money elsewhere
is registered unemployed
```

这些状态不能相互替代。

这与现有“holding state”研究一致，但本轮增加的是它的劳动市场后果：

> **一个人一边仍与旧单位保持制度联系，一边已经必须在外部市场重新制造收入和职业身份。**

# 7. 1998–2002：就业信息数字化，并不等于下岗职工已经直接在家用 Web 找工作

这是本轮与 `old-web-archaeology` 最重要的交叉点。

1998 年中央通知要求加强劳动力市场建设，并提出充分利用电视、广播等现代信息渠道发布求职、招聘与职业指导信息；公共职业介绍机构要设置专门窗口，为下岗职工免费服务。

同年以后，劳动保障系统开始建设“劳动力市场信息网”。后来劳动保障部门对这段历史的总结说：

- 1980s 末，就业服务信息化已从职业介绍、待业保险的计算机应用起步；
- 1998 年以后，开始按城市为中心建设劳动力市场信息网络；
- 全国 100 多个地级以上城市陆续依托就业服务、失业保险建设计算机网络；
- 省级监测中心也逐步建立。

来源：

- 青岛市人社局保存的劳动保障部培训就业司 2009 年工作回顾：
  https://hrss.qingdao.gov.cn/zxzx_47/gzdt_47/202206/t20220613_6127566.shtml

Evidence grade: **C/B（后来的官方机构工作回顾；适合重建系统沿革，不替代 1998 原始技术文档）**。

更关键的是，2000 年《关于加强省级劳动力市场信息网监测中心建设的通知》把省级中心明确定义为：

> 联接全省各城市网的**非实时计算机网络系统**管理中心。

来源：

- 劳动和社会保障部培训就业司，劳社培就司发〔2000〕8号，2000-04-13（法规数据库保存）：
  https://www.110.com/fagui/law_154522.html

Evidence grade: **A/B（正式规范文件的第三方法规库文本；原发布机关与文号明确）**。

这证明：

## `劳动力市场信息网 != 自动等同 World Wide Web 公共网站`

行政语境里的“信息网”可能首先是：

- 城市就业服务机构的 LAN/WAN；
- 城市之间、省与城市之间的数据报送网络；
- 供工作人员处理职业介绍、失业保险、供求监测的数据系统。

普通人最终看到的输出可以是：

- 柜台工作人员；
- 职介大厅；
- 纸质 / 屏幕岗位信息；
- 电话；
- 报纸；
- 电视；
- 招聘会；
- 公共终端；
- 后来才越来越多的 Web 页面。

于是出现一个需要长期保留的状态：

## `institutional digitization without end-user internetization / 制度数字化但终端用户尚未互联网化`

```text
job record is digital
!=
worker owns a computer
!=
worker has Internet access
!=
worker directly searches database
!=
worker directly submits application online
```

普通劳动者完全可能**使用到一套数字化劳动市场的结果，却从头到尾没有亲手操作过一台联网电脑**。

# 8. 一个地方切片：窗口、报纸、有线电视、热线、Internet、LED 可以同时属于同一套就业信息基础设施

舟山市地方志对 1997–2000 年劳动力市场建设的记录非常适合说明“新旧渠道不是直线替代”。

记录称：

- 1997 年开始筹建劳动力市场；
- 1998 年职业介绍、失业保险开始窗口式服务；
- 同时通过《舟山晚报》和有线电视推出免费“再就业热线”；
- 1999 年劳动力市场正式开业；
- 就业供求信息发布扩展到报纸、广播、电视、电信、国际互联网等媒介；
- 场内使用 LED 电子大屏幕和电视同步显示；
- 2000 年全市职业介绍信息资源共享，职业介绍服务实现计算机管理。

来源：

- 《舟山市志（1989—2005）》下卷，劳动力市场条目，第 380 页的公开 HTML 转换：
  https://dfz.zj.gov.cn/zlyz/ossfs/h5/ZS-Z-330900-2005-001-0303/files/basic-html/page380.html

Evidence grade: **C/B（后来地方志整理，基于地方行政资料；不是 1998 原始网页）**。

这个例子最重要的不是“舟山很早上网”，而是：

> **同一套就业系统可以同时有人工窗口、广播电视、电话热线、电子大屏和 Internet 出口。**

所以研究普通人的求职渠道时，不应把“线上 / 线下”想成两个互斥世界。

# 9. 到 2001–2002，后台联网规模扩大，但统计口径仍然是“城市系统联网”，不是“劳动者直接在线”

劳动和社会保障部 / 国家统计局的年度统计公报显示：

### 2001 年

- 全国已建立 17 个省级监测中心；
- 100 个“三化”试点城市中，64 个实现市区内实时联网；
- 全国劳动保障部门办职业介绍机构 18,739 所；
- 全年职业介绍成功 1,229 万人次（所有机构口径）。

来源：

- 《2001年度劳动和社会保障事业发展统计公报》：
  https://www.stats.gov.cn/sj/tjgb/qttjgb/qgqttjgb/202302/t20230218_1913248.html

### 2002 年

- 90 个城市实现市区内实时联网；
- 年末各类职业介绍机构 26,158 所；
- 全年职业介绍成功 1,354 万人次；
- 其中劳动保障部门办职业介绍机构 18,010 所，介绍成功 978 万人次。

来源：

- 《2002年度劳动和社会保障事业发展统计公报》：
  https://www.stats.gov.cn/sj/tjgb/qttjgb/qgqttjgb/202302/t20230218_1913251.html

Evidence grade: **A（机构年度统计公报）**。

这些数据能证明公共就业服务的信息化和机构服务规模；不能直接推出：

- 多少求职者亲自操作 Web；
- 多少介绍成功来自“网络自动匹配”；
- 一个下岗工人是否有电脑；
- 一个城市“实时联网”以后所有街道 / 社区都接入；
- 公共服务系统里的每条岗位信息都同时出现在公开 Internet。

# 10. 海外对照：法国 Minitel/ANPE 更早出现了“劳动者直接操作的远程职位数据库”

法国提供了一个很有用的非 Web 对照。

1996 年法国参议院答复记录，La Poste、France Télécom 和 ANPE 在 1995 年签约，在默尔特-摩泽尔省 6 个邮局放置 Minitel，让求职者可以免费查询 ANPE 岗位。

来源：

- Sénat, question écrite et réponse, 1996：
  https://www.senat.fr/questions/base/1996/qSEQ960314377.html

到 1999 年，法国就业部对参议院的正式答复说明：

- `3614 ANPE` 自 1997 年 2 月起在全国推广；
- 可以 24 小时访问；
- 可查本地岗位、培训、服务；
- 可以通过 Minitel 提交岗位申请；
- ANPE 地方机构内可免费使用；
- 当时每月发布/处理超过 10 万份岗位，月连接超过 100 万次；
- 已有 53.5 万份申请经 Minitel 提交。

来源：

- Sénat, *Difficultés dans la recherche d'emplois*, question publiée 1998-07-16, réponse publiée 1999-03-25：
  https://www.senat.fr/questions/base/1998/qSEQ980709643.html

Evidence grade: **A（同期议会问答 / 政府正式答复）**。

这个对照不能用来简单得出“法国先进、中国落后”。更有价值的比较是**数字化发生在哪一个端点**：

### 法国 ANPE / Minitel

```text
central job data
-> household/public Minitel terminal
-> job seeker directly searches / applies
```

### 中国 1998–2002 的很多公共就业网络

```text
city/provincial employment-service computer network
-> employment office / street service / public display / media outlet
-> worker receives information, sometimes through a human intermediary
```

两边都可以叫“数字化就业服务”，但 ordinary-life experience 完全不同。

这提示一个跨国比较变量：

## `digitization locus / 数字化落点`

问的不只是“数据库有没有计算机化”，而是：

> **谁实际坐在终端前面？劳动者本人、职介员、街道工作人员，还是后来的网站用户？**

# 11. 2019：同样是“35 岁”，但技能转换已经更明显变成个人主动维护的职业项目

为了不把 1998 的年龄 / 技能困难当成一次性历史，本轮检查了 2019 同期材料。

《工人日报》2019 年采访中，34 岁的“老胡”准备跳槽，却在招聘信息中反复看到“35 周岁以下”；另一名受访者高洁认为自己已碰到职业天花板，于当年脱产培训，准备临床执业医师证。

来源：

- 《工人日报》 / 新华网，2019-12-03，“应对‘35岁危机’，学习才是硬道理”：
  https://www.xinhuanet.com/politics/2019-12/03/c_1125301660.htm

Evidence grade: **B（同时代媒体采访）**。

这和 1998 不是同一人口、行业或制度，不能做简单纵向比较。

但它揭示了一个很重要的变化：

1998 年王变兰仍然主要在“等单位 / 学点电脑 / 看有没有更好岗位”的空间里想象未来；2019 年的中年职业转换已经更明确地表现为：

- 自己浏览招聘条件；
- 自己发现年龄门槛；
- 自己决定脱产学习；
- 用证书 / 新专业重做可雇佣性。

因此：

## `reskilling burden individualization / 再技能化负担个体化`

并不是说企业、政府培训消失了，而是劳动者越来越需要把“不断证明自己仍适合下一份工作”当成自己的长期项目。

这给“2015–2019 拥堵型未来”增加一个具体机制：

> **路线仍然存在，但转换路线需要先支付学习时间、证书、收入中断与年龄风险。**

---

# 12. 2024：职业转换开始被主动设计成“找一门能做得更久的工作”

2024 年一组对 35 岁以上转行者的同期采访记录了多种路线：

- 38 岁受访者多次考研后转向心理咨询；
- 有人从教培创业转会计审计，再通过 MBA 转入金融投资；
- 36 岁受访者考研未成后通过法考进入律师路线；
- 有人在结婚生子后离开景气下行的建筑行业，转做保险经纪。

受访者反复使用的目标不是单纯“工资最高”，而是“能持续做下去”“主动权更多”。

来源：

- 一条 / 澎湃新闻，2024-03-27，“35岁时我决定转行：找一门越老越吃香的职业”：
  https://m.thepaper.cn/newsDetail_forward_26826639

Evidence grade: **B（同期媒体第一人称采访；选择的是已经成功转行或仍在转行的人，存在明显 survivorship / selection bias）**。

它不能证明 2024 的中年劳动者普遍更自由；相反，这组材料的被访者本身就更可能拥有教育、时间、配偶 / 家庭支持或重新投资自己的资源。

但它能证明“防守型未来”的一个不同维度：

> **防守不只等于守住当前职位，也可以等于重新设计一个不那么容易在下一轮年龄 / 行业变化里失效的职业。**

---

# 13. 把 1998、2019、2024 放在一起，真正变化的不是“人以前不会学习，现在会学习”

更准确的比较是：

| 时点 | 可见问题 | 典型转换接口 | 未来想象中的关键词 |
|---|---|---|---|
| 1998 | 原单位 / 行业岗位消失；工龄与旧技能难外部换算 | 单位、再就业中心、街道、职介、培训、零工 / 摆摊 | “有活干”“等单位”“学电脑”“做生意” |
| 2019 | 市场岗位存在，但年龄 / 技能 / 行业门槛上升 | 招聘平台、职业培训、资格证书、跳槽 | “35岁”“终身学习”“重新规划” |
| 2024 | 既担心行业周期，也担心职业不能长期持续 | 考研、法考、MBA、职业资格、跨行业网络 | “做得更久”“主动权”“可持续职业” |

这里不主张一条线性进步史。

1998 的单位和再就业中心有它自己的保护与限制；2024 的更多路线也伴随更多自费、自我规划和失败风险。

真正值得保留的是：

## `career continuity became a maintenance task / 职业连续性逐渐变成需要维护的任务`

一个人不再只能问：

> “我在哪个单位？”

而越来越要反复问：

> “我的技能在下一个劳动市场还值什么？如果这个行业变了，我下一步怎样让别人重新认识我？”

# 14. 对四阶段未来模型的影响

这份材料不能单独填满 2005–2012、2020–2022 两段，因此本轮**不为了整齐而硬造证据**。

它真正新增的是一个更早的基线和两个后来的对照：

### 1998：市场化职业未来的高摩擦前史

- 旧单位仍然是权利、工龄、保险、身份和期待的锚；
- 外部收入路线已经大量出现；
- 数字技能已经能成为未来想象；
- 但就业信息数字化很大程度仍可能由机构中介。

### 2015–2019：拥堵不只是岗位少，而是“转换成本”变得可见

- 年龄筛选；
- 资格要求；
- 学习时间；
- 自己规划下一条路线。

### 2023–2026：防守可以表现为寻找不易过期的职业

- 不只守现金；
- 也守技能可迁移性；
- 守未来仍能换轨的能力。

下一轮若继续这一线，优先寻找 2007–2010 和 2020–2022 的**同时代普通人转换职业材料**，而不是用后来的“时代回忆”填空。

# 15. 证据等级与反例

## 同时代个人材料

### 强项

1998 两篇《人民日报》访问直接留下：

- 年龄；
- 原职业；
- 家庭成员；
- 收入 / 生活费片段；
- 实际尝试过的工作；
- 对培训、体面、年龄、工龄和未来的当时说法。

这些非常适合重建 life horizon。

### 限制

它们仍由记者选择、编辑并置于“下岗职工在做什么”的公共报道框架中，不是未经中介的日记。

不能由几个个案推出全国概率。

## 制度文本

正式文件能非常准确地证明：

- 什么叫进入再就业服务中心；
- 系统设计想提供什么；
- “信息网”建设的行政目标。

但不能自动证明：

- 每个地方都执行到同样程度；
- 每个工人收到同样服务；
- 培训就带来就业；
- 网络建成就被普通人直接使用。

## 2019 / 2024

都是媒体选择的受访者，尤其 2024 转行成功者存在明显幸存者偏差。

它们只用于证明“这种未来想象和路线确实存在”，不用于估计比例。

# 16. 后见之明风险

### 风险 A：把下岗职工写成“不会适应市场的人”

错误。

卜荣城在两年里试过几十种挣钱方式；真正的问题包括年龄、岗位技能不匹配、信息、社会保险、资本、欺诈风险与家庭约束。

### 风险 B：把“学电脑”写成互联网时代已经到来

错误。

1998 王变兰只证明电脑技能进入她的未来想象；不能推出家庭 PC、Internet 或在线求职。

### 风险 C：看到“劳动力市场信息网”就自动理解成网站

错误。

2000 年正式文件明确存在“非实时计算机网络系统”的省级监测中心；后台数据网络、机构业务网与公开 WWW 必须分开。

### 风险 D：把 informal work 写成浪漫的自由职业

错误。

1998 个案中的摆摊、跑腿、家庭服务等经常来自生计压力，也可能伴随收入波动、欺诈、低保障和身份落差。

### 风险 E：把 2024 的转行故事写成人人都有第二次机会

错误。

教育、储蓄、家庭照护、城市位置、年龄、健康与已有网络决定谁能支付重新开始的成本。

# 17. 它改变了我们对“人怎么活着”的哪一点理解

此前可以说：

> 一个人失去工作以后，需要找下一份工作。

本轮证据把问题改成：

> **有时失去的不是一个岗位，而是原来那套“我的技能、工龄、单位、保障与未来为什么能连在一起”的换算规则。**

这时，人真正要重建的是：

```text
I know how to work
-> what work does this labor market call that?
-> who can tell me where that work exists?
-> can my household survive while I learn / search?
-> will another employer recognize my past?
-> which parts of my old security follow me?
```

而 Internet 进入就业史最容易被误读的一点，也正在这里：

> **数据库先数字化，不代表求职者先互联网化。**

普通人可能先通过一个坐在电脑前的职介员、一个 LED 屏、一通热线、一期报纸或一场招聘会，接触到数字化系统已经整理过的岗位世界。

只有更晚一些，“我自己打开网页、搜索、投递、维护简历”才越来越成为职业生活本身的一部分。

# 18. 下一步最值得查什么

1. 找到 1998–2002 城市劳动力市场信息系统的原始软件 / 业务手册或同期截图，确认 clerk-facing interface 与 public-facing interface。
2. 找 1998–2002 普通下岗职工自己记述“第一次去职介所 / 第一次上机查岗位”的同期材料。
3. 找 2007–2010 中年劳动者换行业的同时代博客 / BBS / 新闻访问，补四阶段模型的早期扩张期。
4. 找 2020–2022 疫情中传统行业劳动者转行、考证、平台就业的即时材料，避免只使用疫情后的回顾。
5. 做性别对照：照护责任如何改变再培训与外出求职的可执行性。
6. 做地区对照：老工业城市、沿海市场化城市与小城市的信息中介拓扑是否不同。
7. 检查就业信息网络的历史 host / URL / archive capture，但不要把后台“信息网”错当成 WWW。

## 本轮结论强度

### 已证实

- 1998 年同时代访问中，存在长期单位职工因行业 / 企业调整而被迫把技能和职业身份重新换算的具体生命史；
- 同一家庭可经历夫妻就业缓冲先后失效；
- 至少一名下岗女工在 1998 年已经把学习电脑与更理想的工作未来连接起来；
- 1998–2002 公共就业服务确实推进了计算机化与城市劳动力市场信息网络；
- 正式材料中的“劳动力市场信息网”至少有一部分是机构间 / 城市内计算机业务网络，不能自动等同公开 Web；
- 法国 ANPE 在 1990s 已有劳动者可直接操作的 Minitel 远程就业服务，可作为不同 endpoint topology 的海外对照。

### 高概率、仍需更多证据

- 对部分 1990s 下岗职工而言，职业转换的主要瓶颈不只是“没有岗位”，而是技能、年龄、信息、家庭、保障和职业体面同时发生换算摩擦；
- 公共就业系统数字化早期，相当一部分普通用户很可能主要通过工作人员 / 公共服务点接触系统输出，而非家庭 Web 端直连。

### 仍不知道

- 王变兰后来是否真的学习电脑、是否重新就业；
- 卜荣城长期经营结果如何；
- 1998–2002 各城市中有多少求职者亲自操作公共终端或 Web；
- 机构后台网络与 `www.lm.gov.cn` 等公共 Web 站点在各地何时、如何具体打通；
- 这一转换模式在不同性别、行业、城市之间的概率分布。
