# 中国家庭拨号上网，1997—2003：把“上网”压进计费时段、电话线和家庭账单

> 研究问题：普通家庭第一次把 Internet 接进家里时，究竟只是“多了一种信息渠道”，还是同时把一种新的时间纪律、家庭资源冲突和账单责任带进了日常生活？当 ADSL 到来以后，真正改变生活的是否只有速度？
>
> 本文件是一个窄的同时代证据包，不是中国互联网普及史。它严格区分：**1994 年国家层面的全功能 Internet 接入、科研/机构网络、商业/消费接入、家庭可及、大规模普及**。本文只讨论 1997—2003 年前后家庭/个人拨号接入和早期 ADSL 的生活结构，不把“已有全国 Internet 连接”写成“普通家庭已经联网”。

与仓库既有研究的分工：

- 不重复“通信降低异地生活成本”的长线；
- 不重复 QQ、BBS、招聘、住房等具体应用专题；
- 本文只补一个更底层的访问问题：**当 Internet 本身还是一次需要拨号、计时、占用家庭电话线并产生可见账单的活动时，普通人怎样安排在线时间？宽带又怎样改变这种家庭资源结构？**

---

## 1. 结论先行

### 1.1 早期家庭 Internet 不是“常驻背景”，而是一个有明确开始和结束的收费时段

1999 年《电脑报》的一篇同期评论留下了非常直接的第一人称体验。作者把自费上网比作堵车中的出租车：没有走多少路，计价器却一直跳；开始上网后，他第一次像关心水表、电表一样关心电信账单，抱怨有限的上网费大量耗在 `wait` 上，而翻番的电话费又招来家人责难。

来源：

- 《电脑报》/新浪科技，1999-10-13，《评论：话说中国电信，一张网住网络的“网”》：https://tech.sina.com.cn/news/review/1999-10-13/8550.shtml

证据等级：**B**（同期报刊评论中的第一人称使用经验；不能推广为所有家庭）。

这支持一个此前未单独建模的时间机制：

> **metered-session temporality（计费会话时间）**：上网不是一直存在的环境，而是一段从“拨通”开始、到“断线”结束、成本随时间累积的会话。

因此早期家用 Internet 的日常问题不仅是：

```text
我想看什么？
```

还包括：

```text
我现在值不值得拨号？
我要先在离线状态准备到什么程度？
这次连接需要几分钟？
页面加载的等待是否值得继续付费？
今天家里还要不要用这根电话线？
这个月账单还能不能承受？
```

### 1.2 页面下载时间本身就是家庭支出的一部分

1999 年国家计委调整电信资费时，中国电信拨号上网网络使用费按月使用时间计费：1—60 小时部分为 4 元/小时，超过 60 小时部分为 8 元/小时；地方执行中还同时存在上网通话费。随后资费继续调整。

来源：

- 国家计委，计价格〔1999〕134号，1999-02-10，《关于调整邮政电信资费的通知》转载：https://law1.110.com/law_28485.html
- 《北京晚报》/新浪，1999-11-30，《上网话费明起减半 优惠只限163》：https://news.sina.com.cn/china/1999-11-30/36695.html

证据等级：**A/B**（国家价格文件转载 + 同期报纸对北京具体执行的报道）。

1999 年 11 月北京的报道尤其说明，拨号家庭面对的不是一个单一“网费”：中国电信 163 用户的上网通话费从每 3 分钟 0.18 元降为 0.09 元，而其他拨号 ISP 当时暂未同步享受这一优惠。

因此：

> **ISP 费用 + 电话网络的通话计费，是可以同时作用于一次上网会话的两个成本时钟。**

网页越慢、等待越长，不只是“体验差”，还可能增加真实支出。

### 1.3 计费方式会反过来塑造浏览行为

2001 年《华东新闻》刊出的“上网冲浪七个好习惯”建议用户：

- 拨号前先想清楚要看哪些网站、下载什么；
- 先启动软件和浏览器窗口，再拨号；
- 关闭图片/多媒体和 Java 以减少下载；
- 利用 Cache；
- 使用 WebZIP 等离线浏览工具；
- **不要在线写邮件**，先写好再连接发送。

来源：

- 人民网-华东新闻/新浪科技，2001-10-10，《上网冲浪需具备的七个好习惯》：https://tech.sina.com.cn/i/c/2001-10-10/87279.shtml

证据等级：**B**（同期大众技术指导；证明当时被公开推荐的行为，不证明所有用户都照做）。

这意味着早期网络生活可以被理解为：

```text
大量离线准备
→ 短时间连线执行
→ 下载/收发
→ 断线
→ 离线阅读、写作、整理
```

而不是今天更熟悉的：

```text
网络始终存在
→ 随时打开页面/聊天/写作/同步
```

本文把前一种状态称为：

> **offline labor around online moments（围绕在线瞬间组织的离线劳动）**。

Internet 已经进入生活，但还没有成为持续背景。

### 1.4 “Internet 账号”不等于“一个人”

《北京日报》2019 年对本报旧版资料的整理，引用 1997-12-08《京城十万网民网上游世界》称：1997 年末北京地区因特网用户超过 10 万户/账号语境，而且“每个因特网的开户账号往往不止一个人使用”。同一篇档案回顾还引用 1997 年 ChinaNet 的多档计时资费和夜间优惠。

来源：

- 《北京日报》/人民网，2019-10-17，《1996年互联网初入北京城 嘶哑拨号声链接“新世界”》：https://media.people.com.cn/n1/2019/1017/c40606-31404334.html

证据等级：**C+ / 后来的报社档案回顾，有明确旧报日期与标题**。

这里不能把 2019 年网页冒充 1997 年原始页面，但它提供了一个重要统计边界：

```text
account != person
```

在家庭、宿舍、单位和熟人共享明显存在的时期，开户账号数不能机械地换算为独立个人用户数。

因此研究普通生活时最好同时区分：

```text
网络账号
设备
家庭/单位
实际使用者
付费者
电话线路所有者
```

它们可以是不同的人或不同层级。

## 2. 不要从“1994 已联网”直接跳到“家庭已上网”

本文采用以下阶段区分：

```text
国家/科研层面的全球 Internet 全功能连接
!= 商业 ISP / 公众拨号入口存在
!= 城市家庭能够负担电脑+电话+Modem+资费
!= 普通家庭普遍接入
!= 家庭进入持续宽带/always-on 状态
```

2001 年 CNNIC 第七次调查的同期报道显示，截至 2000 年底，中国上网用户约 2250 万，其中拨号上网约 1543 万；上网计算机约 892 万台，其中拨号上网计算机 751 万台。

来源：

- 新浪科技，2001-01-17，《截至2000年底中国互联网用户已达2250万》：https://tech.sina.com.cn/i/c/50489.shtml

证据等级：**A/B**（CNNIC 调查数字的同期刊载）。

2001 年 6 月底，CNNIC 报告仍显示拨号上网用户为主力：2650 万网民中拨号用户约 1793 万，拨号上网计算机约 839 万台。

来源：

- 新浪科技，2001-07-17，《CNNIC公布最新互联网状况报告网民有2650万》：https://tech.sina.com.cn/i/c/2001-07-17/76286.shtml

这说明本文研究的“拨号会话”不是极少数技术爱好者的边缘经验；但也不能把这些全国网民数字反过来解释成“多数中国家庭已经联网”。

## 3. 家庭账单使数字行为变成一种可被家人看见的资源消耗

1999 年《电脑报》作者的叙述特别重要，因为他没有只说“贵”，而是说**电话费翻番以后招来家人的白眼责难**。

这使早期家用 Internet 具有一个后来容易被忘掉的家庭结构：

> **bill-visible digital practice（账单可见的数字实践）**。

即使家人不知道你具体看了什么网页，他们也可能从：

- 上网卡余额；
- ISP 月费；
- 电话账单；
- 电话线被占用的时长；
- 电脑使用时段

感知到你的上网行为。

因此“私人上网”并不必然意味着“私人承担全部成本”。

一个青年、学生或其他家庭成员使用 Internet 时，可能实际调用的是：

```text
家庭买的电脑
+ 家庭装的固定电话
+ 家庭承担的市话费
+ 某个共享账号/上网卡
+ 家庭共同失去的电话可用时段
```

这使早期数字生活天然带有家庭谈判。

## 4. 拨号 Internet 与电话不是两套完全独立的基础设施

普通模拟 Modem 通过家庭电话线拨入 ISP。对单线家庭来说，数据会话和普通语音通话会争用同一条接入资源。

中国同期最强的生活结构证据之一，并不是一篇抱怨“电话打不进来”的个人帖，而是 **2001 年北京 ADSL 上线时的卖点和现实装机行为**。

2001-07-27《北京晚报》报道，北京取消电话初装费后二十余天，市区日均电话报装上升，其中不少是**已经有电话的家庭为了上网方便再装一部电话**；报道担心住宅一户一线的规划被新的装机需求挤压。第二天报道家庭 ADSL 时，最醒目的卖点之一就是：

> 上网和打电话可以同时进行。

来源：

- 《北京晚报》/新浪科技，2001-07-27，《北京电信7月27日开通“超级一线通”》：https://tech.sina.com.cn/it/t/2001-07-27/77899.shtml
- 《北京晚报》/新浪科技，2001-07-28，《北京电信开通上网不交电话费的家庭ADSL服务》：https://tech.sina.com.cn/i/c/2001-07-28/77958.shtml

证据等级：**B**（同期新闻报道）。

这支持第二个生活机制：

> **household-line contention（家庭线路争用）**：个人上网不仅占用自己的时间，也可能占用全家的语音通信资源。

所以 ADSL 的生活史意义不能缩减为：

```text
56K → 512K
```

它还包括：

```text
Internet 数据会话与家庭语音通话从同一稀缺时段中部分解耦
```

## 5. ADSL 的第一步不是“无限宽带”，而是先拆掉一部分旧约束

2001-07-28 北京家庭 ADSL 的同期报道写得很清楚：

- 使用现有电话线路；
- 下行 512K；
- 上网时不占用电话线；
- 因此上网本身不再收“上网通话费”；
- 但套餐仍然按 40 小时、100 小时、200 小时等时长分档；
- 月费分别为 99、199、380 元，超出仍按分钟计费；
- 另有设备、工料和安装调测等一次性成本。

来源：

- 《北京晚报》/新浪科技，2001-07-28：https://tech.sina.com.cn/i/c/2001-07-28/77958.shtml

因此必须避免把“宽带到来”写成一个瞬间完成的 `always-on` 革命。

2001 年北京的真实状态更像：

```text
语音线路争用：显著下降
上网电话通话费：取消
速度：明显提高
上网时长计费：仍可能存在
一次性接入成本：仍高
长期在线：技术上更可行，但套餐和价格未必支持所有家庭
```

同年 8 月的报道甚至批评北京 ADSL 的限时套餐与技术可以提供“永远在线”之间存在落差，试运营初期申请并不热烈。

来源：

- 《北京晨报》/新浪科技，2001-08-06，《北京ADSL定位不为普通网民 一问世便遭冷遇》：https://tech.sina.com.cn/i/c/2001-08-06/79011.shtml

所以更准确的过渡是：

> **broadband decoupling precedes universal always-on（资源解耦先于普遍常在线）**。

## 6. 一条很重要的“普通生活史”转换：从安排一次上网，到允许网络留在背景里

拨号时期，连接有明确动作：

```text
准备 → 拨号 → 握手 → 在线 → 计时 → 断线
```

这种结构会自然产生：

- “这次上网要完成什么”的任务清单；
- 上网前先写邮件；
- 先把网页抓下来再离线读；
- 为价格或拥塞选择凌晨/清晨；
- 下载失败意味着不仅浪费时间，也可能浪费已付费会话；
- 家里其他人要打电话时，必须协调。

宽带逐渐普及以后，Internet 才更容易变成：

```text
环境一直存在
→ 想到问题就搜
→ 聊天程序长期在线
→ 网页保持打开
→ 下载、更新、同步可以在背景执行
```

这不是简单“快了十倍”的体验变化，而是**时间组织方式发生变化**。

它也给仓库后来研究 2005—2012 的“扩张型未来”提供了一个隐藏前提：

> 当求职、住房、QQ、博客、论坛、SNS 等越来越多人生事务进入 Web 时，家庭接入正在从“必须压缩到一次付费会话”向“可以长期存在的基础设施”转移。

本文件不因此把 2005—2012 所有人都写成宽带常在线；它只指出，**应用扩张和接入时间结构的变化是两条需要同时看的历史线。**

## 7. 海外比较：电话线争用不是中国特有，但价格与家庭应对可以不同

1998 年 *Washington Post* 一篇同期家庭专栏写到，作者家里的青少年频繁用电脑与朋友在线聊天，以至家庭电话变得难以使用；父亲最终装了第二条电话线，但女儿甚至可能一边用一条线打电话、一边用另一条线在线聊天。

来源：

- Howard Kurtz, *The Washington Post*, 1998-07-12, “A Clique on the Line”: https://www.washingtonpost.com/archive/lifestyle/1998/07/12/a-clique-on-the-line/b17cfdb2-bcd9-4452-8b09-188694d9069c/

证据等级：**B**（同期家庭第一人称专栏；单个家庭，不代表美国所有家庭）。

美国商务部 NTIA 的 2001 年数据又显示，在当时有家庭 Internet 的个人中，约 80% 仍通过普通拨号电话线连接，Cable 约 12.9%，DSL 约 6.6%。

来源：

- U.S. Department of Commerce, NTIA, *A Nation Online*, Chapter 4, 2001: https://www.ntia.gov/sites/default/files/data/dn/html/Chapter4.htm

证据等级：**A**（政府统计）。

因此可以得到一个稳妥的跨国判断：

> **家庭电话线与 Internet 会话争用，是 PSTN 拨号接入本身带来的普遍结构，不是中国特有。**

但不同国家/家庭的应对不同：

- 有的家庭增加第二条线；
- 有的家庭限制在线时段；
- 有的把上网转移到工作单位、学校或网吧；
- 有的尽快升级 ISDN/DSL/Cable；
- 价格结构、固定电话普及、住房布线和家庭收入会改变哪条路线可行。

不能把一个美国中产家庭“再装一条线”的办法直接投射成中国普通家庭的普遍策略。

## 8. 这对“普通人到底怎么活”改变了什么理解

### 8.1 网络进入家庭，不等于网络立即变成个人基础设施

早期家用 Internet 常常是：

```text
共享电脑
+ 共享电话线路
+ 共享/可共享账号
+ 家庭账单
+ 个人使用欲望
```

因此“谁能上网多久”可能和电视、电话、热水、家务空间一样，是家庭资源分配问题。

### 8.2 在线/离线曾经是一个非常物理的边界

今天“离线”常被理解成网络断了；在计时拨号环境中，**主动断线本身就是节约策略**。

这会影响：

- 写信是在离线还是在线完成；
- 一篇长网页是在线读还是先抓取；
- 图片、Java 是否值得加载；
- 聊天能持续多久；
- 大文件是否值得下载；
- 夜间是否成为更便宜的数字时间。

### 8.3 带宽升级同时重写家庭冲突

ADSL 的意义之一，是把“我上网”从“全家此刻不能正常用这根电话线”中部分拆开。

因此技术升级有时不是给个人增加一个新功能，而是**取消了一个家庭成员之间原本必须协商的冲突**。

## 10. 反例与后见之明风险

### 10.1 不要把“拨号家庭”写成所有早期网民

早期用户还可能来自：

- 大学/科研机构专线；
- 公司局域网和专线；
- 网吧；
- 朋友或单位电脑；
- ISDN；
- 后来的小区宽带、Cable、ADSL。

这些人的成本、线路争用和在线时间结构可能完全不同。

### 10.2 不要把高资费写成唯一障碍

电脑价格、固定电话、Modem、数字技能、城市基础设施、ISP 覆盖、内容价值和家庭空间同样重要。

### 10.3 不要把 ADSL 写成一夜之间“无限上网”

北京 2001 年 ADSL 仍有按小时分档套餐和较高一次性接入成本。

宽带的生活结构改变至少分成：

```text
速度提升
线路解耦
通话费解耦
时长计费逐步弱化
常在线逐渐成为可承受状态
```

这些不是同一天发生。

### 10.4 不要把今天的回忆替代同期证据

“拨号声”“偷上网”“半夜上网”已经成为怀旧文化的一部分。本文只在有同时代资费、技术指导或同期第一人称材料时使用这些机制；2019 北京日报文章仅作为带明确旧报出处的档案线索，不把它当 1997 原始 Web artifact。

## 11. 仍然不知道什么

下一步若继续，应优先找更强的一手普通生活材料，而不是再收集技术怀旧：

1. 1997—2002 家庭日记、论坛帖、BBS 或报刊来信中关于“别人要打电话所以必须断网”的同时代第一人称；
2. 同一家庭中父母/子女谁付 ISP 费、谁付电话费、谁掌握账号密码；
3. 多人共享账号的比例、共享方式与统计口径；
4. 夜间优惠到底怎样改变学生、上班族的睡眠和上网时间；
5. 从拨号改 ADSL 的同一家庭前后行为比较；
6. 城市、收入和住房布线差异；
7. 网吧用户与家庭拨号用户在时间纪律上的差异。

## 12. 对核心矩阵的影响

| Matrix item | This slice adds |
|---|---|
| 通信方式 | Internet 最初可能复用家庭电话线，而不是独立设施 |
| 互联网平台 | 平台使用受接入会话、费率和电话线路状态约束 |
| 信息获取 | 用户会为费用关闭图片/Java、使用 Cache/离线浏览 |
| 社交关系 | 家庭成员之间需要协调电话和上网时段；海外同期家庭也可见类似冲突 |
| 未来预期 | 宽带的吸引力不仅是更快，也是希望“不看时间、不想账单”与更接近常在线 |
| 线上/线下身份 | 账号、设备、使用者、付费者并非一一对应 |
| 证件与记录 | 早期账户统计不能机械当个人统计 |
| 历史可见性 | 后来的 Web archive 可保存页面，却很容易抹掉当年访问页面所需的计费会话与家庭线路条件 |

## 13. 本轮最窄但最重要的修正

如果只按网站功能写互联网史，会得到：

```text
1999 年已经能发邮件、聊天、查信息
2001 年已经有大量网站
```

但普通生活史还必须再问：

```text
为了打开这些页面，一个家庭当时要占用什么？
一分钟的等待是谁付钱？
在线期间谁不能打电话？
为什么用户要先离线写完邮件？
为什么“网页变快”会同时改变家庭关系？
```

因此更准确的历史不是：

> Internet 进入家庭以后，人就开始一直在线。

而是：

> **Internet 先作为一段必须被安排、计费、共享和结束的时间进入家庭；宽带后来才逐步把它从“一个事件”变成“一个环境”。**
