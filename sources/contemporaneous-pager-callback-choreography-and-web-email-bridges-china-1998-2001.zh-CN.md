# 被找到的移动性：无线寻呼、回呼编舞与 Web / Email 到 Pager 的桥（中国，1998—2001）

> 研究切片。重点不是写一部 BP 机产品史，而是追问：**在普通人还没有随身双向手机、家庭 Internet 也远未成为默认基础设施时，一个人什么时候开始能够离开固定电话，却仍然保持“别人能找到我”的个人可达性？**
>
> 本轮由 AI 辅助整理。严格区分同期统计、同期媒体、后期地方文史回顾和跨国比较；不把“寻呼网络存在”写成“人人都拥有 BP 机”，也不把 Web / Email 能发寻呼写成寻呼机已经是 Internet 终端。

## 0. 与已有专题的去重

仓库已有 canonical topic：

- [`../topics/communication-and-the-cost-of-living-far-away.md`](../topics/communication-and-the-cost-of-living-far-away.md)

其中已经建立：

```text
terminal ownership != communication-service entitlement
cheap outbound calling != personal inbound reachability
```

并把 `pager adoption` 留在 comparative research agenda 中。

因此本切片不重复“公用电话 / IP 卡使外出者能够便宜打回家”。

新增问题恰好相反：

> **当一个人还不能随身打电话时，是否已经可以随身“被找到”？**

本轮将这一中间状态暂称为：

**addressable one-way mobility / 可寻址的单向移动可达性**。

## 1. 1998 年：寻呼用户规模已经远大于 Internet 用户规模

国家统计局 1999 年发布的“新中国 50 年系列分析报告”记录，至 1998 年底：

- 全国移动电话用户：2386 万户；
- **无线寻呼用户：3908 万户**；
- 280 MHz 高速寻呼网在 22 个省会以上城市联网运行；
- 126、127、198、199 等无线寻呼系统基本形成全国范围无线寻呼服务网络；
- 中国公用计算机互联网已通达所有省会城市。

来源：国家统计局，《之十一：邮电通信业突飞猛进》，1999-09-19。  
<https://www.stats.gov.cn/zt_18555/ztfx/xzg50nxlfxbg/202303/t20230301_1920449.html>

同期的 CNNIC 第三次统计报告则记录，截至 1998 年 12 月 31 日：

- 上网计算机 74.7 万台；
- **上网用户 210 万**。

来源：中国互联网络信息中心，《第三次中国互联网络发展状况调查统计报告》，1999-01-01。  
<https://www3.cnnic.cn/n4/2022/0401/c88-812.html>

### 证据等级

- A：机构同期统计；
- 两者统计单位不同：寻呼为“用户/户”，Internet 为 CNNIC 定义下的“上网用户”；
- 因此不能把 `3908 / 210` 当成严格可比的渗透率倍数；
- 但足以证明：**1998 年无线寻呼已经是千万级大众通信系统，而 Internet 仍处于明显更窄的使用层。**

### 它改变了什么理解

如果只按 Web 普及时间线写 1998 年，会漏掉一个已经非常大的个人通信层：

```text
固定电话 / 公用电话：能双向通话，但人离开终端就可能找不到
寻呼机：人可以离开终端，被个人化地址叫到，但通常不能原机回复
移动电话：个人地址 + 随身双向语音逐渐合并
Internet / IM：又把在线身份、文本消息、文件与更多异步状态叠加进来
```

所以：

**personal reachability did not begin with the mobile phone or the Web.**

个人可达性的一部分，先于个人双向终端出现。

## 2. 寻呼改变的不是“能不能打电话”，而是“离开电话以后还能不能被叫回来”

无线寻呼最关键的生活结构，不是把电话缩小放进腰间。

它更像把一个人的“可联系地址”从固定地点部分剥离出来：

```text
呼叫者找到电话
→ 拨寻呼台 / 自动寻呼号码
→ 输入或口述寻呼号、回电号码、短留言
→ 寻呼网络广播
→ 收件人的 BP 机响 / 显示号码或文字
→ 收件人寻找可用电话
→ 回拨
```

本切片把这条普通动作链叫作：

**callback choreography / 回呼编舞**。

它需要至少两个不同的基础设施层：

1. 随身的一向无线接收端；
2. 某处可获得的固定 / 公用电话，作为真正的回复终端。

因此：

```text
pager ownership != independent two-way communication
```

以及：

```text
alert mobility != reply mobility
```

一个人可以已经“随时被找到”，却仍然必须走到商店、电话亭、单位、宿舍或别人家里才能真正说话。

## 3. 2000 年北京西站：一次寻呼的真实事务里，公用电话仍然不可缺

2000 年 10 月 26 日《北京晚报》的一篇同期调查，本意是曝光北京西站公用电话乱收费，但无意中留下了一个非常好的寻呼生活切片。

记者看到一名刚下火车的外地旅客：

- 先在公用电话处“打了一个传呼”；
- 随后又“接了回电”；
- 摊主向他收了 2 元；
- 电信投诉热线给出的标准则是：一次寻呼 0.3 元，接回电手续费 0.3 元。

来源：《北京西站一公用电话亭真黑 长途电话4分钟开价96元》，《北京晚报》/新浪，2000-10-26。  
<https://news.sina.com.cn/society/2000-10-26/138549.html>

### 证据等级

- B：同期现场媒体报道；
- 不是专门调查寻呼用户，因此不能外推使用比例；
- 但对“寻呼 + 公用电话 + 回电”的真实动作链是强证据。

### 普通生活意义

这条材料说明，BP 机和公用电话不是两个彼此替代的通信阶段。

在一段时间里，它们是**互补技术**：

```text
寻呼机负责把人从流动状态中叫出来
公用电话负责把这个叫唤完成为一次真正的对话
```

因此历史上的“公用电话亭需求”有一部分恰恰可能是被寻呼机放大的，而不是被寻呼机淘汰。

对旅行者、学生、宿舍居民、跑业务的人、没有家庭电话的人尤其如此。

## 4. 回呼把“错过电话”变成“稍后必须处理的通信义务”

在固定电话世界里，如果一个人不在电话旁，常见结果是：

- 电话没人接；
- 由家人、同事、门卫、邻居代接；
- 留口信；
- 以后再打。

寻呼机把这种不确定性部分改变为：

```text
现在不能说话
→ 但我已经知道有人正在找我
→ 我需要决定何时、从哪里回电
```

本切片把这种时间结构称为：

**deferred synchronous obligation / 延迟兑现的同步义务**。

它很像异步消息，却往往以同步电话作为最终结算。

这会产生新的日常问题：

- 看到号码后多久回？
- 谁值得马上去找电话？
- 如果附近没有公用电话怎么办？
- 长途回电太贵怎么办？
- 收到汉字留言以后是否还需要回？
- 工作中能不能离开岗位找电话？
- 在火车、街上、工地、校园里，最近的电话在哪里？

因此寻呼并没有简单“降低通信成本”；它重新分配了通信的等待、移动和响应劳动。

## 5. 地方微观史：同一县可以出现“寻呼先大众化，Internet 仍极稀少”

2025 年玉屏县政府网站刊发的地方文史文章《感受通信工具的变化》，作者依据地方统计与个人经历回顾：

- 1993 年末县邮电局建立无线寻呼基站，126 人工寻呼，当年 39 户；
- 1995 年开通中文寻呼设备和 127 自动寻呼；
- 1997 年全县寻呼用户 3451 户；
- 2000 年末因移动通信增长，寻呼只剩 100 多户；
- 同一地方 1997 年开通 CHINANET，当年计算机 Internet 用户仅 4 户，1998 年 20 户、1999 年 92 户；
- 多数数字 BP 机只显示呼叫者电话号码，用户需要另找电话回拨；汉显机可显示留言，但服务费更高。

来源：杨显政，《感受通信工具的变化》，玉屏网，2025-03-17。  
<https://www.yp.gov.cn/contents/2025/03/17/receive-1764843f-1b66-4998-ac9b-01927ef7a29b.html>

### 证据等级

- C+：后期地方文史 / 机构网站回顾；
- 有明确地方统计数字和作者身份，但不是 1993—2000 当年的原始统计表；
- 不能用来代表全国；
- 适合做“一个具体地方的技术叠层”微观校验。

### 为什么它重要

这组数字说明，在至少一个县级个案里，可以同时成立：

```text
个人无线寻呼已经形成数千用户规模
+
计算机 Internet 仍只有个位到两位数用户
```

因此中国“数字通信史”不能只以 Web 用户数为刻度。

普通人可能先进入：

- 程控电话；
- 自动寻呼；
- 汉显寻呼；
- 移动电话；
- 最后才是家庭 / 单位 Internet；

也可能以不同顺序进入其中若干层。

## 6. 1999：Internet 开始给旧寻呼网络“喂消息”，而不是立刻替代它

信息产业部《一九九九年通信业发展统计公报（摘要）》记录，中国联通国信寻呼公司当时：

- 无线寻呼覆盖全国 335 个地市、2022 个县市；
- 280 MHz 198、199 网覆盖 287 个城市，容量 1700 万户；
- 开通“国信网源”网站；
- 至 1999 年底，**网上寻呼**已开通到 198、199 全国寻呼网、27 个省网和部分本地网；
- **电子邮件到达呼**已开通 22 个省网。

来源：《一九九九年通信业发展统计公报（摘要）(下)》，信息产业部综合规划司资料，经 CCID / 新浪转载，2000-06-14。  
<https://tech.sina.com.cn/it/2000-06-14/28155.shtml>

### 证据等级

- A-/B+：主管部门年度公报的同期转载；
- 强证据证明这些业务在 1999 年底已存在并具有跨省覆盖；
- 当前没有原始“国信网源”网页 capture、业务手册或协议文档，因此不能补猜 URL、表单字段、字符编码、邮件网关协议或递送确认语义。

### 这不是“BP 机变成 Internet 终端”

更准确的拓扑是：

```text
Internet / Web / email sender
              ↓
       paging gateway/backend
              ↓
      radio paging network
              ↓
       one-way pager user
              ↓
   find telephone / call back
              ↓
             PSTN
```

所以：

**Internet participation can affect a non-Internet recipient.**

一个人本人没有电脑、没有 ISP 帐号，甚至不知道“网页”具体是什么，仍可能收到由某个 Web / Email 入口触发的寻呼。

这与仓库此前的“机构中介数字化”有亲缘关系，但不是同一件事：这里中介不是柜台职员，而是**跨协议网关**。

本切片将它称为：

**cross-network reachability bridge / 跨网络可达桥**。

## 7. 2000 CNNIC：“网上寻呼机”已经是被调查网民能识别的一类网络服务

CNNIC 2000 年 7 月统计报告中，在“用户最常使用的网络服务”多选项里列出：

- Email 87.65%；
- BBS 21.17%；
- **网上寻呼机 20.72%**；
- 网上炒股 14.64%；
- 网络电话 9.63%。

同一报告还给出 1999.7 → 2000.7 的比较：

- 网上寻呼机：15% → 21%。

来源：CNNIC，《中国互联网络发展状况统计报告(2000/7)》，新浪保存的全文。  
<https://tech.sina.com.cn/internet/china/2000-07-27/31904.shtml>

### 非常重要的样本边界

报告说明，当次调查同时使用网上联机与抽样调查；联机调查收到 1,629,361 份问卷、处理后有效答卷 573,902 份，另有抽样调查有效答卷 3,679 份。

因此这里**绝不能**写成：

> “2000 年中国有 20.72% 的人使用网上寻呼。”

安全表述只能是：

> 在 CNNIC 当期“网民行为意识调查”结果里，“网上寻呼机”已经是一项明确列出的、相当比例受访网民报告使用过/常用的网络服务类别。

它证明的是**服务类别的历史可见性与 Internet—paging 交叉已经进入公开统计**，不是全国人口渗透率。

## 8. Internet 没有一开始就取代旧通信网络，而是先成为它的一个新的发送入口

很多技术史叙事喜欢画成：

```text
pager → mobile phone → Internet / IM
```

本轮证据更支持一个短暂但重要的叠层：

```text
pager network
   ↑          ↑
telephone    Web / email
   |          |
   +---- gateway ----+
```

也就是说，Internet 最初可能只是改变：

- 谁能发起寻呼；
- 从哪里发起寻呼；
- 什么数字文本能进入寻呼网；

而没有立刻改变收件人的终端。

这也是一种常见的基础设施过渡方式：

**new network first extends the old endpoint before replacing it.**

类似的研究问题今后也可用于：

- Email → 传真；
- Web → 短信；
- 电话 → Web 凭证；
- Internet → 广播/寻呼告警；
- Web 后台 → 人工柜台输出。

## 9. 海外比较：美国 1996—1997 也存在同一“被找到 ≠ 能回复”的断裂

### 9.1 1996：工作中的母亲和女儿用 beeper 保持家庭可达性

《Washington Post》1996 年报道一名经常外出工作的律师母亲 Heather Morcroft 与 14 岁女儿 Sarah。母亲给两人都配了 beeper，以便彼此找到；但她随后发现，自己在公路上收到 page 后，并不容易找到电话亭回复，最后又购买 cellular phone。

来源：Darryl E. Owens, “KEEPING IN TOUCH: CONNECTING WITH PAGERS & PHONES,” *The Washington Post*, 1996-11-07。  
<https://www.washingtonpost.com/archive/lifestyle/1996/11/08/keeping-in-touch/c191c6b0-26b5-4e2d-994a-b87b605737de/>

### 证据等级

- B：同期报刊生活报道；
- 个案，不代表全体美国家庭；
- 极强地显示 `alert mobility != reply mobility` 是技术结构，而非中国特有文化。

### 9.2 1997：双向寻呼明确把“找电话”定义成自己要消除的问题

WIRED 1997 年实测 SkyTel 双向 pager 时，明确把体验描述为：用户可以直接从 pager 回复，而不必再去找电话；别人可通过 Email、SkyTel Web site 或 800 电话向设备发送最多约 500 字符的信息。

来源：Simson Garfinkel, “Wireless Gets Real,” *WIRED*, 1997-10。  
<https://www.wired.com/1997/10/es-wired/>

### 比较结论

美国材料说明，从 one-way pager 到 two-way pager / cellular phone 的关键转折，也可以写成：

```text
personal incoming addressability
→ personal reply capability
```

而不是笼统的：

```text
old device → new device
```

中国的特殊性当前更适合放在：

- 巨大的 1990 年代末公共寻呼规模；
- 126/127/198/199 等网络结构；
- 公共电话、宿舍电话等回呼终端环境；
- 1999 年后 Web / Email 到寻呼的网关叠层；
- 随后 GSM / 短信的快速替代速度。

不能据现有证据声称“这种中间状态只有中国有”。

## 10. 未来时间感：寻呼首先带来的是“别人现在可能立刻找我”

这一切对 ordinary life 的影响，不只是通信更快。

固定地点电话的时间逻辑更接近：

> 我回到家 / 单位以后，才知道有没有人找过我。

寻呼的时间逻辑变成：

> **我走在外面时，就会知道此刻有人要求我的注意力。**

但回复仍然可以被延迟。

因此它第一次大规模制造了一个后来在手机、短信、QQ、微信上越来越强的生活结构：

**portable interruption / 可携带的打断。**

BP 机响起时，用户会立即获得：

- 某人正在找我；
- 这件事可能有紧急程度；
- 我是否现在去找电话；
- 谁值得让我改变当前路线或工作节奏。

这里已经出现后来“永远在线”的一个前身，但绝不能把二者等同。

寻呼机通常：

- 消息短；
- 单向；
- 回复需要另一个终端；
- 接入与资费受寻呼台制约；
- 没有今天智能手机的大量平台并发通知。

因此更准确的历史关系是：

**always-addressable came before always-interactive.**

## 11. 反例与限制

### 11.1 不能把用户数写成人人随身拥有独立设备

统计口径可能存在单位用户、多人共享、停机未销号等问题。

本轮没有取得 1998 全国无线寻呼统计口径的完整定义。

### 11.2 汉显机降低回电需求，但没有消灭回电结构

如果汉字留言已经足以表达完整内容，收件人可能不需要回拨。

所以“所有 page 都必须回电话”是错误的。

正确写法是：

> 对大量数字寻呼和需要对话的场景，寻呼只完成提醒，回复仍依赖电话；汉显寻呼则开始把更多内容本身移动化。

### 11.3 “网上寻呼”不能自动等同 OICQ / QQ

1999 年行业公报证明国信网络已经提供网上寻呼、Email 到达呼；CNNIC 2000 报告也把“网上寻呼机”列为服务类别。

但本轮没有取得足以把 CNNIC 该选项唯一映射到某一个具体产品的原始问卷说明。

因此：

```text
网上寻呼机 category != proven single product
```

OICQ 与 BP 机接口的后期叙述可作为未来线索，但此处不把它当已验证核心证据。

### 11.4 1999 的 Web / Email gateway 不等于收件人“上网”

收件人的最后一跳仍可能是寻呼无线网。

这一点必须保留，否则会把 Internet 的影响范围和 Internet 用户规模混为一谈。

## 12. 对重点矩阵的更新

| 维度 | 本轮新增理解 |
|---|---|
| 通信方式 | 固定/公用电话与寻呼长期互补；寻呼解决“离开电话后被叫到” |
| 互联网前史 | 1998 年无线寻呼规模远大于 Internet；数字/无线个人可达性不能从 Web 才开始计算 |
| 互联网平台 | 1999 年 Web / Email 已可作为旧寻呼网的新发送入口 |
| 信息获取 | 汉显寻呼可直接带来短文本，数字寻呼多只带回拨号码 |
| 社交关系 | 人可以远离家庭/单位固定电话，却继续保持被呼叫状态 |
| 迁移/旅行 | 公用电话 + pager 构成旅行者和无固定终端者的可执行通信栈 |
| 工作 | 随身 pager 把工作请求带出办公室，但回电仍可能要求离岗找电话 |
| 家庭 | “我能找到你”早于“我能随时和你直接说话” |
| 时间感 | 从“回到固定地点再知道”转为“移动途中即时被打断、稍后兑现回复” |
| 线上/线下身份 | pager number / pager account 形成个人可达标识，但不等于 Internet identity |
| 历史可见性 | Web 资料可记录寻呼入口，却很难保存真实无线递送与回呼路径 |

## 13. 后见之明风险

### 风险 A：把 pager 只写成“手机之前的落后玩具”

这会丢掉它真正创造的生活能力：**移动中的个人地址**。

### 风险 B：因为 pager 单向，就把它写成没有改变生活

单向提醒足以显著改变：

- 谁能被及时找到；
- 是否必须守在家里等电话；
- 工作和家庭如何追踪移动中的人；
- 公用电话为什么更有价值。

### 风险 C：用 Web 的最终胜利倒写 1999

1999 更像网络叠层期：Internet 可以给寻呼网发消息，而不是一出现就把寻呼网清空。

### 风险 D：把今天手机上的 notification 体验直接投射回 pager

pager 的打断更稀疏、带宽更低、回复成本更高，社会规范也不同。

## 16. 本轮最小结论

本轮可以高置信度写下：

1. **1998 年中国无线寻呼已是千万级大众通信基础设施，而 Internet 用户仍在更窄数量级。**
2. **寻呼创造的是“个人可以离开固定电话仍被叫到”的能力，而不是完整的随身双向通信。**
3. **现实事务经常是 pager + public/fixed phone 的回呼编舞。**
4. **1999 年 Web / Email 已开始成为旧寻呼网络的发送入口，Internet 可以影响尚未上网的收件人。**
5. **从寻呼到手机的重要转折可以写成：被找到的移动性 → 回复的移动性。**
6. **从寻呼到后来 IM / smartphone 的另一条长线是：always-addressable 先于 always-interactive。**

它改变了我们对“人怎么活着”的一点理解是：

> **普通人并不是等到拥有自己的手机后才第一次把“联系方式”带在身上。更早的时候，他已经可以把一个个人寻呼号和一只单向接收器带着走；别人能在城市里把他叫住，而他接下来要做的，是抬头寻找最近的一部电话。**
