# 从打字复印店、照相馆到手机自拍：格式转换、共享外设与纸—数往返，中国 1992—2026

> **研究问题：一项机会已经“搬到网上”以后，一个普通人是否真的只需要浏览器就能完成它？打印机、扫描仪、照相馆、传真机、单位盖章、A4 纸和后来出现的云打印、手机证照工具，怎样决定数字制度是否真正可执行？**

本研究包补的是一个此前在仓库里没有被单独建模的执行层：**format-conversion infrastructure（格式转换基础设施）**。

它与既有专题有重叠，但不是同义重复：

- `from-paper-credential-to-searchable-proof...` 已经讨论 **proof work（证明劳动）**：保管、复印、盖章、邮寄、核验资格；
- 网吧/共享终端专题讨论 **access-without-ownership（不拥有电脑也能接入 Internet）**；
- 公务员/考试 Web state-gap 研究讨论网上报名、支付、照片、准考证等事务状态；
- 本文问的是这些事务中间还缺的那一层：**当制度要求纸、照片、JPEG、扫描件、传真、打印件、签名、盖章在不同介质之间转换时，谁替普通人完成转换？**

核心结论先写在前面：

> **online opportunity ≠ screen-only opportunity**
>
> **家里没有打印机/扫描仪/传真机 ≠ 不能进入数字制度。**
>
> 很长一段时期，普通人依靠打字复印店、照相馆、单位办公室、学校机房、考试中心和后来出现的云打印，把自己接进“网上办事”。

## 1. 新增概念

### 1.1 paper–digital braid：纸—数编织流程

很多所谓“网上报名”并不是：

```text
打开网页 → 填写 → 提交 → 完成
```

而是：

```text
Web
→ 打印凭条
→ 照相馆生成/上传电子照片
→ 回到 Web 等审核
→ 网上缴费
→ 再打印报名表
→ 单位签字/盖章
→ 保存纸件或带到现场
→ 以后再凭 Web 状态/纸件继续办理
```

纸和数字不是两个历史阶段，而可能在**同一件事里来回切换数次**。

### 1.2 peripheral access without ownership：无需拥有外设的外设可及性

电脑与 Internet 接入只是第一层。

一项制度动作还可能要求：

- 打印机；
- 扫描仪；
- 数码相机；
- 照相馆的灯光、相机与图像处理；
- 传真机；
- A4 纸；
- 复印机；
- 单位公章；
- 后来的手机相机、自动裁切/检测与云打印。

普通人不必把这些设备全部买回家。城市里的文印店、照相馆、学校打印店、单位文印室等，长期充当一种 **public peripheral layer（公共/共享外设层）**。

### 1.3 conversion competence：格式转换能力

知道“网上报名”并不自动等于会：

- 把实体证件变成合格扫描件；
- 把照片裁成规定像素；
- 把 Word 排版保持到另一台机器；
- 把网站结果打印成可现场使用的纸件；
- 判断“300 像素左右”“20KB 以下”“白底”“A4 纸”意味着什么；
- 把需要原件签字的纸再次数字化上传。

一部分数字鸿沟因此不是“会不会上网”，而是**能不能在格式边界之间把材料变成制度接受的样子**。

### 1.4 compliance-ready artifact：合规备用材料

到 2020s，转换能力越来越进入手机，但规则没有消失。

个人反而需要维护：

- 原始版照片；
- 不过度修图的认证版；
- 正确尺寸/像素/背景的文件；
- 可反复提交的电子回执；
- 必要时能重新打印或到线下核验的版本。

“文件在手机里”与“文件能被某个制度接受”仍然不是一回事。

## 2. 1990s：Internet 之外已经存在文件的电子传输与共享办公设备

### 2.1 传真不是 Web，但已经让纸面内容跨电话网移动

国家统计局 1999 年整理的邮电通信历史表显示，全国传真业务量：

- 1995：约 442.3 万份；
- 1996：约 565.0 万份；
- 1997：约 711.8 万份。

来源（A/B+，国家统计局历史统计表）：

- <https://www.stats.gov.cn/yearbook/1999/o38c.htm>

1998 年国家统计局的五十年回顾又明确写到，公用数据通信网可提供：

- 电子信箱；
- **传真存储转发**；
- 数据检索；
- EDI；
- 计算机互联网访问等。

并称 1992 年起大规模建设公用数据通信网，到 1998 年已经覆盖 90% 以上县市。

来源（B+，1999 年国家统计局历史回顾）：

- <https://www.stats.gov.cn/zt_18555/ztfx/xzg50nxlfxbg/202303/t20230301_1920449.html>

这里的边界必须写死：

> **传真/公用数据网存在 ≠ 普通家庭已经上 Internet。**

传真更适合证明：在大众 Web 以前，**“把一个纸面/图像型文件远程送到另一处设备”已经是可运行的制度能力**。

一个人本人可能没有传真机，但学校、单位、政府办公室、宾馆、文印服务点可以代为接收或发送。

### 2.2 打字复印店是信息基础设施，不只是“卖几张复印纸”

2006 年重庆一篇同期报道记录了一个非常具体的乡镇案例：一家 2000—2004 年开在乡政府旁边的打字复印店，因为长期替乡政府打字、复印大量上报材料，累计被欠 28,700 元，最后被迫关门。

来源（B，同期地方媒体）：

- <https://news.sohu.com/20060702/n244049765.shtml>

这个案例当然不能代表全国文印店经营状况，但它能证明一种基础设施关系：

```text
机构自己没有/不愿维护全部文印能力
→ 邻近小店提供打字、复印、输出
→ 文件生产被外包给街边服务节点
```

2003 年关于温州印刷业的同期报道还记录，当地除 2,227 家印刷企业外，有 **1,154 家打字复印店**。

来源（B，同期行业/媒体转载线索；数字应继续寻找原《人民日报》页面复核）：

- <https://paper.com.cn/>

这里不把一家城市的数量外推全国。它只说明：**共享文档设备已经能以高密度商业服务的形式存在。**

## 3. 2005–2012：“网上办”扩大了机会，但常常没有消灭材料转换

这是本轮对“扩张型未来”最实质的补充。

过去我们很容易把这一时期写成：

```text
线下报名 → 网上报名
```

但 2008 年的实际操作链显示，更准确的是：

```text
线下为主
→ Web 成为流程主干
→ 照片、打印、盖章、传真、现场审核成为与 Web 串联的转换节点
```

### 3.1 2008 广州经济师考试：一句“任何地方打开联网计算机”后面，紧跟着一整条线下转换链

广州市人事考试中心 2008 年通知写得异常具体：报名系统 24 小时开放，考生可以在“任何地方（国内外）”打开连接 Internet 的计算机进入网上报名。

但后续流程不是纯 Web：

1. 在线填个人信息；
2. **打印照相凭条**；
3. 去指定照相馆；
4. 照相馆把照片**直接上传**到报名系统；
5. 24 小时后用户再上网查照片；
6. 等网上确认；
7. 网上支付；
8. **打印报名发证登记表**；
9. 交单位审核、盖章并自行保存；
10. 考前再下载并 **A4 打印准考证**。

来源（A-content/B，转载广州市人事考试中心 `穗人考中心函[2008]52号`）：

- <https://www.chinaacc.com/new/15/22/48/2008/4/lu113513204413480024876-0.htm>

照片要求甚至精确到：

- 482×689 像素；
- 350 dpi；
- 24 位 RGB；
- JPEG；
- 通常 20–30KB；
- 白色背景。

因此“能上网”并不足以完成报名。

一个实际可执行的资源栈至少是：

```text
联网电脑
+ 浏览器账号
+ 打印机/文印点
+ 指定照相馆
+ 支付工具
+ 单位盖章
+ 考前再次打印
```

### 3.2 为什么指定照相馆很重要？

它不只是“不会 Photoshop 的人去照相”。

在这个流程里，照相馆是**被制度授权的上传中介**：

```text
个人身体
→ 照相馆
→ 标准化 JPEG
→ 报名系统
```

用户甚至不一定亲手接触那份最终 JPEG。

这和今天“自己手机拍摄 → 本地保存 → 自己上传”的经验完全不同。

新增机制：

## delegated conversion（委托式格式转换）

普通人把“把我变成一份符合数据库规范的图像”这一任务交给专业小店。

### 3.3 2008 江西国考：扫描仪、数码相机、照相馆、传真都可以接进同一网上流程

江西考区 2009 年国家公务员考试（确认发生在 2008 年 11 月）的同期说明规定，电子照片可以通过三种途径取得：

- 自己用扫描仪扫描实体照片；
- 自己用数码相机拍摄；
- 到照相馆拍电子版，请工作人员按要求处理。

而申请减免费用的困难家庭考生，如果无法到现场，还可以把证明材料**复印后传真**给考试中心；工作人员审核后，考生 24 小时后再回到网站查看状态是否变成“确认成功”。

来源（A-content/B，江西人事考试网同期通知转载）：

- <https://edu.sina.com.cn/official/2008-11-03/1618173125.shtml>

于是同一件事里存在：

```text
纸证明
→ 复印件
→ 传真
→ 人工审核
→ Web 状态变化
```

这是一条非常清楚的 **cross-medium fallback（跨介质兜底路径）**。

困难考生没有被简单要求“既然网上报名，就全部网上解决”；制度仍保留传真和现场通道，把另一类通信基础设施接到 Web 后台。

### 3.4 2008 南京自考：网上打印和现场领取同时存在

南京 2008 年 4 月自考通知说，考生可以网上打印考试通知书；但仍允许现场领取。新考生如果未做人像采集，还必须先联系区县自考办完成人像采集、领取准考证，才能使用网上打印。

来源（A-content/B，同期自考办通知转载）：

- <https://edu.sina.com.cn/zikao/2008-03-31/1238131196.shtml>

因此：

> **printable online ≠ printer ownership required**
>
> **online route exists ≠ offline fallback disappears**

这种并存，对判断普通人到底能不能执行一次网上事务比“某网站于某年上线”更重要。

### 3.5 2008 山西国考又补出浏览器环境这一层

山西考区同期网上确认说明要求：

- IE 6.0 以上；
- 调整浏览器安全级别；
- 启用 ActiveX 控件/插件；
- 上传 20KB 以下 JPG。

来源（A-content/B，同期人事考试中心通知转载）：

- <https://edu.sina.com.cn/official/2008-11-03/1522173099.shtml>

所以一项“网上确认”的可执行栈实际上可能同时包括：

```text
正确浏览器/ActiveX
+ 本地电子照片
+ 获取照片的扫描仪/相机/照相馆
+ 支付工具
+ 打印输出
```

旧网和普通生活在这里是同一个问题。

## 4. 这改变了我们对“数字化降低门槛”的哪一点理解？

### 4.1 Web 把地理限制放松，却可能新增格式劳动

2008 广州通知真的允许“国内外任何地方”的联网电脑进入报名系统。

这是实质性的扩张：

- 不必在工作时间跑到报名窗口排队；
- 可以异地填写；
- 可以 24 小时提交。

但它同时把一部分劳动转给个人：

- 找打印；
- 找指定照相馆；
- 查照片是否成功；
- 准备支付工具；
- 再打印；
- 找单位盖章；
- 保管纸件。

因此应该写成：

## queue reduction can coexist with format-work transfer

**窗口排队减少，可以和“格式劳动转移到个人”同时发生。**

### 4.2 “家里没有设备”不等于机会不存在，但会改变机会成本

一个没有打印机的考生仍然可以：

- 去单位打印；
- 去网吧/文印店；
- 找学校机房；
- 去考试中心现场领取；
- 请照相馆代做照片。

机会不是二元的“有/无”。

更好的问题是：

```text
这一步需要走多远？
花多少钱？
在什么营业时间内？
要等多久？
是否必须找到一个懂格式要求的人？
失败后能否重做？
```

这和仓库的方法一致：**service access 与 household ownership 必须分开。**

## 5. 2015–2019：文件已经能随人走，打印机仍然留在地方——于是出现“云打印”

2019 年浙江工商大学一篇同期报道提供了很好的第一人称材料。

学生创业者王作宁回忆，毕业季打印店门口有三四十名学生拿着 U 盘排队；有学生说为了打印毕业论文，在校内排队近一小时，随后又因为店里 Word 版本较低造成排版错误，不得不去校外重打。

创业团队因此把流程改成：

```text
宿舍/教室上传文件
→ App / 小程序 / PC / 微信客服下单
→ 云端进入打印店
→ 到店自取 / 定时配送 / 加急送达
```

报道说团队当时已覆盖 42 所高校、50 家门店。

来源（B+，浙江工商大学宣传部同期稿，2019-08-30；学校页面当前偶发超时，另有原稿转载）：

- <https://news.zjgsu.edu.cn/5/view_18171.html>
- <https://www.sohu.com/a/337589440_178884>

这不是“纸消失”。

恰好相反：**纸仍然是学校制度和学生作业的终端产物，只是 U 盘和排队这两个中间环节被网络替换。**

新增概念：

## file portability / printer locality split（文件可携与打印机在地性的分离）

文件已经可以从宿舍瞬间到打印店；打印机、纸张、装订机和最终成品仍然有地点。

2015–2019 的“拥堵型未来”在这里不是“选择太多”的同一种拥堵，而是很朴素的：

> 当数码文件生产速度远远快于校园共享打印能力时，新的拥堵点会集中到最后一台物理机器前。

云打印做的事情，是把**队伍**从打印机前挪到任务队列和配送系统里。

## 6. 2020–2022：疫情让“少跑现场”加速，但纸—数往返没有立即消失

2020 年湖南省 2021 年研考确认公告说，全省 29 个报考点统一实施网上确认；考生上传身份证、手持身份证照片、学生证/学历材料等，只有系统要求时才转现场。

来源（A-content，2020-10-12 高校转发省级公告）：

- <https://gra.hutb.edu.cn/tzgg/content_68717>

这说明过去“网上填表 → 现场核验”的一部分链条，确实开始被手机拍照/上传替代。

但同一年江苏全国计算机等级考试又给出一个很好的反方向例子：

- 报名在全国统一 Web 系统完成；
- 需要健康码；
- 同时要求考生自行下载、**打印纸质《健康情况声明书》和体温登记表》**，每科一张，考试当天交给考点并留存。

来源（A，江苏省教育考试院，2020-08-10）：

- <https://www.jseea.cn/webfile/ncre_information/2020-08-10/6137.html>

因此疫情时期不是简单的“全部无纸化”。

一项事务甚至可能同时出现：

```text
在线报名
+ 手机健康码
+ 自测体温
+ 打印纸表
+ 现场上交
```

新增时间性理解：

## emergency layer accretion（应急层叠加）

危机时期，旧流程未必先被删除；新数字层和新的纸面证明可能直接叠在原流程上。

这正是 2020–2022“偶发型未来”的一种日常体验：**你不能只知道平时怎么办，还要不断确认今年/这次临时又多了一层什么格式。**

## 7. 2023–2026：外设逐渐进入手机，但“合规”成为新的边界

### 7.1 2024 潍坊：照相馆的一部分功能被手机和后台审核拆走

2024 年潍坊“证照 e 拍”报道中，一名正在政务服务中心等待的李女士现场试用微信小程序，称操作简单，照片提交后一分多钟就收到审核结果。

系统流程是：

```text
手机拍照
→ 自动/后台检查
→ 审核通过
→ 支付检测费
→ 生成电子回执
→ 户籍窗口出示回执
```

用户还可以下载照片重复使用；线下人工拍照和自助机仍被保留为免费路径。

来源（B+，潍坊融媒，2024-01-29）：

- <https://weifang.sdnews.com.cn/wfxw/202401/t20240129_4347121.htm>

这是一条非常清楚的演化：

```text
指定照相馆替你生成并上传
→ 自己手机拍，但系统/人工替你判断是否合规
```

中介没有完全消失，而是从“拥有相机和 Photoshop 的店员”部分变成“手机端规则 + 后台审核”。

### 7.2 2024：漂亮证件照和身份核验照片开始分叉

2024 年考研网上确认期间，辽宁抚顺报考点因身份核验风险明确反对过度修图的“海马体照片”；海马体随后提醒，教育报考/签证类用户应使用其“原生版本”，不要把精致版本拿去做身份验证。

来源（B，同期媒体采访与企业回应）：

- <https://www.nbd.com.cn/articles/2024-11-05/3632242.html>

这说明一张“证件照”已经可能分成不同用途的 artifact：

- 社交/简历展示想要更好看；
- 身份核验要求更接近本人；
- 不同平台又有尺寸、背景、像素和压缩规则。

因此到 2023–2026，“会不会生成电子照片”已经不再是主要困难之一，新的问题是：

> **我是否保留了一份能通过这个特定制度的版本？**

这也是一种很小但真实的“防守型未来”动作：**留原件、留原生版、留可以重新裁切/上传的版本，不把唯一证据做成不可逆的精修成品。**

这里不能扩大成“当代青年普遍悲观”。它只证明：成熟数字制度要求人维护**可回退、可重交、可验证**的材料版本。

## 8. 海外比较：1995 Kinko's 说明“共享信息机器”不是中国特有

1995 年 WIRED 对美国 Kinko's 的同期长篇报道说，当时美国约有 780 家门店，海外还有约 20 家；门店不只有复印机，还提供：

- 电脑；
- 桌面出版；
- 照片处理；
- 视频会议；
- 打印输出。

Kinko's 在 1980s 中期就开始按小时出租电脑；两年内约 200 家店配置 Mac，很多顾客在那里制作并用 LaserWriter 输出简历。

来源（B，同期专题报道，1995-06-01）：

- <https://www.wired.com/1995/06/kinkos/>

这给出一个跨国共同结构：

## expensive office capability can become a service before it becomes a household possession

**昂贵的信息机器常常先以按次/按时服务进入普通人的生活，再逐渐私人化。**

美国 Kinko's 的典型场景偏向学生、自由职业、家庭办公和“虚拟办公室”；中国 2000s 的文印店/照相馆则经常又和考试报名、单位盖章、政府材料这种制度接口强绑定。

共同点不是“都有复印店”，而是：

> **技术能力的社会普及，并不要求每户先拥有设备。商业/公共中介可以把机器能力拆成一次次可购买的动作。**

## 9. 这条机制怎样进入核心生活矩阵？

| 生活领域 | 格式转换怎样成为隐藏接口 |
|---|---|
| 教育 | 报名、准考证、论文打印、成绩/证明扫描 |
| 就业 | 简历输出、证书复印、报名照片、资格材料 |
| 住房 | 租赁/贷款材料复印与后来的电子上传 |
| 婚姻家庭 | 户籍/证件材料、照片、异地材料传送 |
| 迁移 | 异地报名/申请让材料在本人到场前先移动 |
| 照护 | 代理人可替不会操作设备者扫描、打印、传真 |
| 非正规劳动 | 文印店、照相馆本身就是低门槛服务性小生意 |
| 长期中断/重返 | 旧纸证书需要被重新扫描、认证、打印进入新制度 |
| 证件与记录 | 真实经历必须被转换成系统接受的 file/paper state |
| 通信方式 | 传真把纸面内容接进电话/数据网；Web 后又保留 fax fallback |
| Internet 平台 | 浏览器事务经常要求本地文件输入和纸输出 |
| 信息获取 | “网上有表格”之后仍要下载、打开、正确打印 |
| 社交关系 | 可借单位、同学、店员的设备和技能完成手续 |
| 未来预期 | 在线办理扩大异地机会，但个人承担更多自助格式劳动 |
| 线上/线下身份 | 一张照片/证件文件把身体与账号/申请绑定 |
| 平台消失/记忆保存 | 历史页面很难保存用户本地文件、打印件、传真件和盖章后的状态 |

## 10. 证据等级与反例

### A / A-content

- 国家统计局传真/公用数据通信历史统计；
- 江苏省教育考试院 2020 NCRE 公告；
- 2020 湖南研考网上确认公告（高校保存的省级制度文本）。

### B / B+

- 2008 广州人事考试中心通知的同期转载；
- 2008 江西/山西人事考试通知的同期转载；
- 2019 浙江工商大学宣传部关于校园云打印的同期报道；
- 2024 潍坊融媒对证照 e 拍用户与工作人员的采访；
- 1995 WIRED 对 Kinko's 的同期报道。

### 反例与限制

1. **不是所有网上事务都需要打印/扫描。** 很多服务一开始就可以纯文字提交，后来也有越来越多数据库自动核验。
2. **不是所有家庭都缺打印机。** 所以研究必须保留 household ownership 与 service access 的差异。
3. **照相馆不一定只是“帮不会电脑的人”。** 2008 广州是制度直接指定照相馆作为上传节点。
4. **云打印不是纸消失。** 它只是改变文件到达打印机的路线。
5. **手机自拍也不是彻底去中介。** 后台检测、人工审核、电子回执继续发挥中介作用。
6. **传真是早期远程文件基础设施，不应偷换成 Internet。**

## 11. 后见之明风险

### 风险 1：把“网上报名”自动理解成“全流程无纸化”

这是最需要避免的错误。2008 广州流程直接否定了这种写法。

### 风险 2：把街边文印店当成落后时代的残余

文印店实际上可能是普通人接入数字制度的共享外设节点。它的存在不必和数字化相反。

### 风险 3：用今天的手机相机经验回读早期电子照片

2008 年一张合格电子照片可能依赖扫描仪、数码相机、专业照相馆和人工裁切，而不是“随手拍一张上传”。

### 风险 4：把“无纸化”当成单向终点

2020 疫情期间，数字健康码和纸质健康声明可以同时增加；制度会按风险临时重新物化材料。

### 风险 5：把 2024 的反过度修图要求写成文化道德判断

目前证据支持的是狭义的**身份核验兼容性**问题，不应扩大成关于审美、年轻人或社会风气的泛论。

## 12. 已知 / 可合理推断 / 未知

### 已知

- 1990s 中国传真和传真存储转发已经真实运行，且与 Internet 是并存而非同义的通信能力；
- 2008 年多类考试已经形成“Web → 打印/照片/传真/盖章 → Web/现场”的混合流程；
- 一些流程显式允许扫描仪、数码相机、照相馆等多种本地生成方式；
- 2019 校园打印仍是高频物理需求，网络化主要改变文件传输和排队；
- 2020 疫情时期网上确认和纸质健康材料可以同时存在；
- 2024 手机自拍可以替代一部分照相馆动作，但合规审核仍然存在。

### 可合理推断

- 文印店、照相馆、单位办公室和学校机房长期承担了“没有家用外设也能完成数字事务”的社会缓冲层；
- 许多早期网上政务/考试的真实数字鸿沟，不能只用“是否上网”解释，还包括本地格式转换能力；
- 当数据库自动核验、手机相机和电子签名成熟后，一部分转换劳动会从街边店转进平台后台，但不会完全消失。

### 仍不知道

- 2005–2012 不同城市普通人完成一次报名时，去文印店/照相馆的真实比例；
- 打印、扫描、传真、证件照的典型单价与相对工资负担；
- 家庭打印机/扫描仪拥有率的可靠长序列；
- 文印店在农村县城、大学城、单位区的密度差异；
- “格式不合格”导致报名失败的实际比例；
- 2008 年左右足够可靠的普通考生第一人称日记/博客样本，能否把制度说明转换成具体时间成本。

最后一条尤其重要：**本轮找到的是很强的同时代制度工作流，但没有把制度说明冒充个人体验。** 2019 和 2024 有具体受访者，2008 的普通考生第一人称材料仍需继续找。

## 13. 它改变了我们对“人怎么活着”的哪一点理解？

过去我们容易把数字化理解成“越来越多事情进入屏幕”。

这一轮更准确的模型是：

```text
现实身体 / 纸证件
↕
照相馆、扫描仪、复印机、传真机、打印店
↕
Web 表单 / 数据库
↕
打印表 / 准考证 / 签字 / 盖章
↕
现场制度
```

现代生活真正变化的，不只是“网页多了”。

而是越来越多普通人学会、或者花几块钱请别人帮忙，把自己的身体、证件、经历和申请在**纸、图像、文件、数据库、打印件**之间反复转换。

很多时候，一条人生路径能不能走通，取决于的不是“网上有没有这个机会”，而是：

> **你能不能把手里那张纸，变成系统愿意接受的那个文件；再把系统里的那个状态，变回门口工作人员愿意接过的那张纸。**
