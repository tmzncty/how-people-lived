# 电话可查询的制度状态：168 声讯、考试查分与大众 Web 之前后的交互信息生活（中国，1998—2015）

> 研究切片。重点不是写一部“168 声讯台史”，而是追问：普通人什么时候开始能够**主动查询一条远方数据库里的、与自己人生直接相关的信息**，而不必先拥有电脑或 Internet 接入？
>
> 本轮由 AI 辅助整理；关键事实按来源类型与时间性分别标注，不把媒体转述、平台宣传和研究者推断混为一谈。

## 一、为什么值得单独研究

如果把中国信息生活写成：

> 报纸 / 广播 / 电视 → 1994 接入 Internet → 家庭上网 → Web 查询

会漏掉一层非常重要的中间基础设施：**电话网上的自动信息服务与人工信息服务**。

它们与广播不同，因为用户可以主动拨号、按键、输入准考证号或其他标识，查询自己要的信息；它们与 Web 又不同，因为终端可以只是一部普通双音频电话，界面是语音提示与按键，不要求电脑、浏览器、域名知识或家庭 Internet。

本切片暂时把它概括为：

**telephone-queryable institutional state / 电话可查询的制度状态**

也就是：

> 一个制度过程已经把某人的考试成绩、录取状态或其他记录变成可远程查询的数据，但查询入口仍然可以是 PSTN 电话 + IVR/自动声讯，而不是网页。

这不是说 168 是“中国版 Internet”，也不是说所有 168 服务都属于同一技术平台；它只是提醒我们，**交互式数字信息生活早于、并长期平行于普通家庭 Web 使用**。

## 二、基础设施边界：1998 年 168 已经全国地市联网，但家庭 Internet 仍不是大众默认

国家统计局对 1998 年邮电通信业的同期总结记录：

- 1998 年全国公用电话达到 259 万部；
- 67.1% 的行政村通电话；
- 公用数据通信网覆盖地市以上城市、90% 以上县市和部分乡镇；
- 中国公用计算机互联网已经通达所有省会城市，联网省市超过 20 个；
- **168 信息服务台实现全国地市以上城市联网**。

来源：国家统计局，《之十一：邮电通信业突飞猛进》。  
<https://www.stats.gov.cn/zt_18555/ztfx/xzg50nxlfxbg/202303/t20230301_1920449.html>

### 证据等级

- A / 机构同期统计总结；
- 高置信度用于证明 1998 年基础设施覆盖；
- 不用于证明“每个家庭都能使用 168”或“168 的所有地方实现完全相同”。

### 它改变了什么理解

1998 年有三个状态可以同时成立：

1. 国家级 / 城市级 Internet 与公用数据通信网已经存在；
2. 168 自动信息服务已经形成全国地市级网络；
3. 相当一部分乡村仍然没有电话，家庭 Internet 更远未成为普通生活默认。

因此不能用一个“联网 / 未联网”二值变量描述普通人的信息世界。

更接近实际的是：

```text
广播/报刊可见
→ 电话可获得
→ 电话可主动查询
→ 短信可主动/订阅查询
→ Web 可主动查询
→ 多渠道并存
```

这些阶段重叠，而不是一夜替代。

## 三、2000 年南京中考：数据库里的成绩可以比纸面成绩单更早到达家庭

2000 年 6 月 27 日《扬子晚报》报道，南京市招办从 6 月 28 日零点起开放中考文化成绩查询：

- 自动台：`16896967`；
- 人工台：`1680`；
- 考生接通后输入本人考试座位号即可查询；
- 纸面成绩通知单则在 6 月 29 日到毕业学校领取。

同期转载：新浪教育，《南京中考成绩明日公布》，2000-06-27。  
<https://edu.sina.com.cn/job/2000-06-27/5390.shtml>

### 证据等级

- B / 同期媒体报道；
- 高置信度证明当时的操作路径与时间差；
- 尚未取得 2000 年南京 168 系统本身的原始 IVR 手册、录音、数据库接口文档。

### 生活史意义

这是一个很小、但非常具体的时间变化：

```text
过去：等学校公布 / 去学校领取
现在：零点后在电话上输入座位号
然后：第二天仍领取正式纸面通知
```

因此：

**remote query != replacement of official paper**

电话查询改变的是“我什么时候知道”，不一定改变“什么才是正式凭据”。

本切片把这种变化称为：

**institutional-information latency compression / 制度信息延迟压缩**

对考生家庭而言，一天不是抽象的数据延迟。它可能意味着：

- 少等一个晚上；
- 更早开始讨论志愿或下一步；
- 亲属不必第二天陪同去学校才知道结果；
- 但也可能把焦虑集中到查询开放的几分钟和线路拥塞上。

## 四、电话查询的“资格”：不是有号码就一定可执行

2004 年江苏高考查分报道提供了比“有一个 168 号码”更完整的事务条件：

- 查询号码为 `16887799`；
- 高峰地区扩容，例如南京可同时容纳约 2000 名用户查询；
- 为保护成绩私密性，需要同时输入准考证号和考试证号；
- 电话必须处于双音频 / `T` 状态；
- 各地查询电话只提供本地考生成绩；
- 系统开放还取决于考试数据输入、核对完成。

同期转载：新浪教育，《江苏省2004年高考查分电话26日晚开通》，2004-06-27。  
<https://edu.sina.com.cn/l/2004-06-27/74104.html>

### 这意味着什么

“电话普及”仍不足以推出“可以自己查成绩”。真正可执行的条件更接近：

```text
可用电话终端
+ 本地接入资格
+ DTMF/双音频能力
+ 正确的个人标识
+ 后端数据已装载
+ 线路容量尚可
+ 能承担资费
→ 才能获得结果
```

所以应继续沿用本仓的技术采用阶梯：

**存在 → 服务可及 → 经济可及 → 实际可执行 → 行为常态化**。

## 五、2003 年江苏：查询速度开始成为可以买卖的稀缺资源

2003 年江苏高考查分出现了一次非常有价值的公共争议。

同期报道记录：

- 2001 年以前，江苏高考较早查询主要由电信 168 提供；
- 2001 年移动进入短信查分；
- 2002 年联通也进入；
- 短信因为可储存、可转发、可预订，并且增加了信息来源，受到考生和家长欢迎；
- 2003 年，高招办通过竞标让江苏电信获得主要查分发布权，电信出价 120 万元；
- 部分家长反映 168 高峰时必须反复拨打，幸运时一两分钟接通，忙时一两个小时也未必打通；
- 一次查询约需两三分钟，不少家庭会重复查询。

来源之一：新浪新闻，《江苏省高招办委托电信独家承担高考查分引争议》，2003-07-01。  
<https://news.sina.com.cn/c/2003-07-01/1352300325s.shtml>

新华社后续报道亦讨论“高考分数发布权”与收费争议：  
<https://news.sina.com.cn/c/2003-07-08/0154336684s.shtml>

### 证据等级

- B / 多篇同期新闻；
- 关键数字和家长反应来自媒体采访；
- 多个转载 URL 不能机械计为多个独立调查。

### 新机制 1：channel-dependent cost of uncertainty

**同一个制度结果，因为查询渠道不同，会产生不同的等待成本、金钱成本和失败概率。**

在这里，真正售卖的不只是“一个分数”，还包括：

- 更早知道；
- 不用去学校；
- 在家就能反复确认；
- 但高峰拥堵、计时收费可能把焦虑本身转化成额外成本。

因此可以写成：

```text
结果已经存在
≠ 我已经知道结果
≠ 我可以免费知道
≠ 我可以在第一时间稳定知道
```

### 新机制 2：渠道竞争不是简单的技术升级

短信相对电话的优势不只是“更先进”，而是：

- 结果可保存；
- 可转发给家人；
- 不需要一直占着电话听完；
- 可以预订后等待系统主动发送；
- 在高峰时不必由一个人抱着电话连续重拨。

这是一种**工作流改变**，而不仅是媒介名称改变。

## 六、2007 年南京：一个人的查分变成了全家的并行拨号劳动

2007 年《中国青年报》报道了一名南京考生计璐的具体经历：

- 她为了查询高考成绩连续拨打 168 三次；
- 前两次已经进入系统并开始计费，但未获得结果；
- 第三次才查到；
- 当时资费为每分钟 1 元，记者估算她约花五六元；
- 高峰时因为线路忙，一些家庭会让亲戚朋友同时帮忙拨打；
- 江苏当年声讯台先开放，24 小时后考生也可在学校或当地招办获得成绩。

来源：中国青年报，2007-08-20；学信网转载：  
<https://gaokao.chsi.com.cn/gkxx/js/200708/20070820/1055474.html>

新浪同期转载：  
<https://news.sina.com.cn/c/2007-08-20/034913698832.shtml>

### 证据等级

- B / 同期记者采访；
- 这是一个具体个案，不代表江苏每个家庭；
- 可用于重建流程与感受，不能直接外推平均查分费用。

### 新机制 3：family parallelization under queue congestion

当一个热线成为高风险、高峰值的制度入口时，家庭会把排队问题转化成人力并行问题：

```text
一个考生的结果
→ 多个家庭成员 / 亲友同时尝试
→ 谁先接通谁报告
```

所以“数字化”不必然减少家庭劳动。

有时它只是把：

> 去学校排队

变成：

> 在多个电话终端上重复拨号。

### 新机制 4：earlier access as a paid option

如果学校在 24 小时后免费提供结果，那么 168 的一部分价值实际上可以被理解为：

**为提前一天消除不确定性付费。**

这并不意味着每个家庭都愿意付，也不意味着收费合理；它只是说明“时间”本身已经进入信息服务的价格结构。

## 七、从收费声讯到免费 Web：不是一次全国统一切换

2005—2008 的材料很清楚地反对“电话查分被 Web 在某一年全国替代”的线性叙事。

### 2005 江苏：是否免费仍在争论

学信网转载《扬子晚报》报道：上海、广州、浙江等地已开始停止或减少高考有偿查分，而江苏考生仍关注 168 是否收费。  
<https://gaokao.chsi.com.cn/gkxx/js/200506/20050620/49117.html>

### 2006 安徽：168 与网站同时存在

安徽考生可以在指定时间以后拨打不同的 168 号码查询文理科分数、志愿或录取，也可以通过高考网站查询。  
<https://gaokao.eol.cn/an_hui/200606/t20060624_185451.shtml>

### 2008 广西：电话、短信与号码服务并存

中国教育在线整理的 2008 年查分方式中，广西同时存在：

- 168 声讯；
- 小灵通短信；
- 118114 号码百事通。

同一张全国列表还可看到其他省份采用网站、电话、短信、招办现场等不同组合。  
<https://zsb.jxvct.edu.cn/news/2011/03/0321G2011.html>

### 2015 甘肃：Web 普及以后 168 仍没有立刻消失

2015 年甘肃普通高考成绩查询仍同时提供：

- 省招办网站；
- 电信 168 声讯台；
- 移动 12580；
- 联通 1161148；
- 县区招办线下查询。

来源：中国教育在线，依据甘肃省高等学校招生办公室信息。  
<https://gaokao.eol.cn/gan_su/dongtai/201506/t20150621_1277776.shtml>

### 结论

更准确的过程是：

**single-channel transition → multi-channel redundancy → channel-specific survival**

也就是：

- 电话没有在 Web 出现时马上消失；
- Web 也不是所有地方同时成为第一入口；
- 不同设备、资费、网络条件和用户习惯使渠道长期重叠。

这对研究 2005—2012 的“扩张型未来”很重要：

> 扩张不仅是“更多信息上网”，也是**同一件人生大事可以从越来越多入口获得状态**。

## 八、168 不只是“旧电话服务”：它还能成为 Web 服务的支付 / 凭证桥

2002 年腾讯推出通过 168 声讯获取“Q币”的方式，是一个非常有价值的跨基础设施案例。

同期新浪科技报道：

- 用户拨打 `16896366`；
- 系统通过语音给出一个 12 位数字串；
- 报道甚至提醒用户提前准备纸笔记录；
- 没听清可按 `1` 重听；
- 当时声讯费为 1 元/分钟；
- 积累到一定数量后，用户再到腾讯网站会员服务中输入 / 使用这些 Q 币完成会员注册或续费。

来源：新浪科技，《腾讯推出168申请“Q币”》，2002-04-30。  
<https://tech.sina.com.cn/it2/2002-04-30/113827.shtml>

另一篇同期教程亦记录北京及其他城市通过声讯台取得 12 位数字串后，再到腾讯网站开通会员：  
<https://tech.sina.com.cn/it/t/2002-03-21/107815.shtml>

### 证据等级

- B / 同期技术媒体与操作说明；
- 可证明当时被公开提供 / 教授的支付路径；
- 暂未取得 168 语音树、结算数据库、腾讯后台接口的原始技术文档。

### 为什么它重要

这里没有“电话时代”和“互联网时代”的干净边界。

真实事务是：

```text
电话线路
→ 168 声讯计费
→ 系统念出数字串
→ 用户用纸笔记录
→ 人工重新输入网页
→ Web 会员状态改变
```

**人本身就是两个网络之间的复制粘贴层。**

纸笔不是“落后残余”，而是一个真实的跨协议接口。

因此：

`Web service exists != payment occurs on Web`

甚至：

`Internet membership can be executable for someone without a bank card or online payment account, if a telephone-billing route exists.`

这和后来的全在线支付非常不同。

## 九、海外比较：法国 Minitel 与语音 / SMS / Web 查分的长期共存

这一现象不是中国特有。

### 1999 法国：Minitel 与移动电话已经改变“守在学校榜前”的查分仪式

法国《La Dépêche》1999 年 7 月 6 日的现场报道说，Minitel 和移动电话已经在一定程度上替代学生守在学校公告板前等待结果。  
<https://www.ladepeche.fr/article/1999/07/06/204049-la-ruee-vers-demain.html>

同日报导另一地考试结果系统故障时，也记录学生因无法连上 Minitel 而继续焦急等待。  
<https://www.ladepeche.fr/article/1999/07/06/240113-copie-blanche-pour-le-bac.html>

### 2005 法国：Minitel、Web、语音电话、SMS 同时存在

01net 2005 年采访 France-Examen 负责人时记录，在 bac 成绩发布周期中：

- Web 出现 46,000 个同时会话峰值；
- 语音服务峰值面对约 300,000 个同时呼叫；
- 预计整个期间约 120 万次 Minitel 呼叫；
- 约 80 万次语音呼叫；
- 约 50 万条 SMS。

来源：01net，2005-07-13。  
<https://www.01net.com/actualites/loic-jauson-france-examen-nous-diffusons-plus-de-2-25-millions-de-resultats-scolaires-284467.html>

### 可比与不可比

可比之处：

- 高风险考试结果推动“尽早查询”需求；
- 公共结果数据可以被多种商业 / 公共渠道重新发布；
- 付费查询、免费官方渠道和更早获取之间都会产生争议；
- 新渠道通常先与旧渠道共存，而不是立刻替代。

不可简单类比之处：

- Minitel 是屏幕式双向远程信息系统，终端生态和法国电信制度与中国 168 完全不同；
- 中国 168 可以利用普通固定电话 / 公用电话这种更低门槛的终端；
- 本轮没有可比的全国渗透率数据证明 168 在家庭中的使用密度等同于 Minitel。

因此不能写“168 就是中国的 Minitel”。

更稳妥的比较问题是：

> **在家庭 Web 成为默认入口以前，不同国家用什么已经存在的终端，把数据库查询能力送到普通人手里？**

## 十、对“互联网前史 / 大众化 / 平台化”的阶段修正

### 1. “尚未大众上网”不等于“没有交互式数字信息”

电话自动查询说明，普通人能够主动向一个远程信息系统请求个体化结果，并不以 PC + Web 为前提。

### 2. 1994 全功能接入不是家庭信息生活的单一分界线

国家网络接入、运营商数据网、168 自动信息服务、家庭固定电话、PC、拨号 Internet 和后来宽带普及，是多条不同时钟。

### 3. Internet 的重要变化之一，是把原本分散在电话、短信、银行、纸笔和人工服务里的查询 / 支付 / 提交逐渐汇聚到通用终端

但汇聚过程很慢，而且并不彻底。

2015 年仍存在 Web + 168 + 移动热线 + 联通热线 + 招办现场共存，就是很清楚的反例。

## 十一、矩阵更新

| 维度 | 本轮新增 |
|---|---|
| 教育 | 中考 / 高考成绩、录取状态可通过电话数据库主动查询 |
| 就业 | 本轮无新增，不强行扩写 |
| 住房 | 本轮无新增 |
| 婚姻家庭 | 高峰查分可转化为亲属共同拨号劳动；家庭是并行查询资源 |
| 迁移 | 电话入口理论上不要求人在学校现场，但本轮缺直接迁移案例 |
| 照护 | 无新增 |
| 非正规劳动 | 无新增 |
| 长期中断 | 无新增 |
| 证件与记录 | 准考证号 / 考试证号成为远程查询身份键；正式纸面通知仍可能保留 |
| 通信方式 | PSTN + IVR/自动声讯成为交互式数据入口 |
| Internet 平台 | 168 可作为 QQ / Web 服务的付费凭证桥 |
| 信息获取 | 从广播式接收转为按需查询，再进入短信 / Web 多渠道并存 |
| 社交关系 | 亲友可共同并行拨号，结果也可经短信保存 / 转发 |
| 未来预期 | 更早获得考试结果压缩不确定性，但也制造“第一时间知道”的时间溢价 |
| 线上 / 线下身份 | 电话中的准考证号与网页账号属于不同认证世界；人可在两者间手工搬运凭证 |
| 平台消失与记忆保存 | 本轮 HPL 只记录生活意义；具体 IVR 保存缺口交叉链接 OWA |

## 十二、证据边界与后见之明风险

### 不要把“168 全国地市联网”写成“全国普通人都在用”

联网是服务基础设施状态，不是家庭使用率。

### 不要把电话查询自动写成“互联网”

168 运行在电信服务体系上。它可以由计算机数据库、语音平台和电信网共同实现，但这不等于终端用户在使用 Internet。

### 不要把媒体保存下来的查询号码当成完整系统复原

我们目前能证明的是操作说明、收费、部分容量与用户经历；尚不知道很多地区实际使用的交换 / IVR 平台、后端同步机制、语音树版本和数据库装载流程。

### 不要把“收费争议”简化成技术落后

真正的问题同时涉及：

- 谁掌握结果数据；
- 谁能第一时间发布；
- 免费渠道何时开放；
- 电话 / 短信 / Web 的成本结构；
- 用户对早知道一天的价值判断。

### 不要把 Web 出现写成 168 立即消失

2006、2008、2015 的多渠道证据直接反对这种线性替代模型。

## 十三、我们知道什么 / 可以推断什么 / 仍不知道什么

### 我们知道什么

1. 到 1998 年，168 信息服务台已实现全国地市以上城市联网；
2. 2000 年南京中考已经可以通过自动 / 人工声讯输入座位号查询成绩，并早于次日纸面成绩单；
3. 2003—2007 江苏高考查分证明线路拥塞、按分钟收费、重复拨号和家庭并行查询是真实体验；
4. 电话、短信、Web、学校 / 招办现场长期并存，而不是一次性替代；
5. 2002 年腾讯曾公开提供“电话获得数字串 → 到 Web 使用”的跨协议会员付费路径；
6. 到 2015 年，部分地区高考查询仍保留 168 与 Web、移动 / 联通热线并行。

### 我们可以合理推断什么

1. 在家庭 Internet 普及之前，电话网络已经让部分普通人接触到“按需查询远方数据库”的交互模式；
2. 高考 / 中考等强时间敏感制度状态，推动了大众学习 IVR / DTMF 查询流程；
3. “知道结果的延迟”本身可以形成可收费的服务价值；
4. 渠道拥塞会把技术等待重新转化为家庭时间与协作劳动；
5. Web 普及初期的服务执行经常跨越电话计费、纸笔抄码和浏览器输入，不应假设事务从一开始就在 Web 内闭环。

### 我们仍不知道什么

1. 168 在各省 / 城市的精确开通日期与平台谱系；
2. 1990 年代典型 168 系统的厂商、交换 / IVR 软件、存储与数据库架构；
3. 不同地区实际使用人数、家庭渗透率与城乡差异；
4. 公用电话、宿舍电话、家庭电话各自在 168 使用中的比例；
5. 高峰时真实呼叫失败率、平均重拨次数、平均费用；
6. 各地 160 人工台与 168 自动台之间的后台关系是否一致；
7. 168 与教育部门成绩数据库之间的数据传输、加密、同步和审核流程；
8. 2002 年腾讯声讯 Q 币的具体运营商结算和后台核销协议。

## 十五、本轮结论

这条材料改变的并不是“电话比 Internet 早”这样简单的年代顺序。

更重要的是：

> **普通人第一次能够远程、主动查询一条与自己有关的制度状态，并不需要等到家里先有电脑和 Web。**

一部电话、一个准考证号、双音频按键和一个自动语音系统，就已经足以让“远方数据库里的我”变得可查询。

后来 Internet 真正扩张的，不只是把这些信息搬到网页上；它逐渐把查询、保存、转发、支付和后续行动汇集到同一台通用终端里。

而在这之前，相当长一段普通生活里，人们是在**电话、纸笔、短信、网页和学校柜台之间来回搬运自己的未来状态**。
