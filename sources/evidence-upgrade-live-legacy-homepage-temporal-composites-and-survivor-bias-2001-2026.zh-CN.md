# 证据升级：长期存活个人主页、时间复合与历史可见性偏差（2001—2026）

> 性质：artifact-first 证据补强。  
> 本文件**不新增生活机制专题**，而是给既有 `topics/personal-homepages-self-publishing-and-platformed-public-identity-china-1980-2026.zh-CN.md` 补一组可直接核验的存活页面证据，并记录本轮研究饱和判断。

## 1. 为什么这一轮不再新开“个人主页机制”

现有专题已经覆盖：

- 编辑门控的公开自我；
- 公开自我可寻址性；
- 早期主页的发布栈劳动；
- 计数器 / 留言带来的受众反馈仪表化；
- 平台化身份；
- 页面、账号、托管平台和历史记忆并不等价。

`old-web-archaeology` 也已经明确提出：

```text
visible Last updated
!= actual edit time
```

所以本轮若再创造“长期主页 / 时间戳错位”新概念，只会重复已有结构。真正有价值的是：找到可以直接核验的 artifact，看这种方法风险是否真的发生。

---

## 2. 中国对象：南京大学李宣东个人主页是一份明显的时间复合页面

当前可访问：

- https://cs.nju.edu.cn/lixuandong/

本轮直接核验时，页面内部同时存在：

- `Formal Languages and Automata, Fall 2019`；
- 2016—2019、2017—2021 等研究项目时间；
- 页脚 `Last updated: Nov. 10, 2001`。

因此可以直接确认：

```text
2026 年当前可见 representation
包含至少到 2021 的内部时间信息
但可见 footer 仍写 2001
```

证据类型：**平台/页面可观察事实**。  
不是第一人称生活史，也不是 2001 年历史 capture。

这件事本身不创造新的生活路径，但会改变我们如何使用“幸存个人主页”作为生活史材料：

> 一个今天仍能打开、看起来很“旧”的个人主页，并不自动是一张冻结在旧时代的自我肖像；它可能把二十多年不同时间层压在同一 URL 下。

---

## 3. 海外对照：Berkeley 也出现同样的时间层叠

UC Berkeley 数学系 John R. Steel 个人主页：

- https://math.berkeley.edu/~steel/

当前可见信息包含 `Spring Semester 2020` 的 office-hours 内容，同时页面底部仍显示：

- `Last modified: Mon Jan 5 10:58:16 PDT 2001`

因此，“旧 footer + 新正文”的时间复合并不是中国高校网页独有现象。

这里更稳妥的共同机制不是“大学网站都不更新日期”，而是：

> **长期机构托管可以让个人公开地址非常耐久；但耐久 URL 不保证整份内容属于同一个历史时点。**

这是一种跨国的历史可见性问题，而不是中国特有的 Internet 文化。

---

## 4. 它怎样影响“普通人有多少种活法”的研究

### 4.1 幸存者不是随机样本

能从 1990s / 2000s 一直活到今天的个人主页，往往更可能依附于：

- 大学；
- 研究机构；
- 长寿组织域名；
- 技术人员自己维护的 namespace。

普通人的免费主页、短期 ISP 空间、个人小站反而更容易整体消失。

所以今天最容易看到的旧个人 Web，很可能系统性高估：

- 高校人员；
- 技术人员；
- 有稳定机构 affiliation 的人；
- 长期职业连续性较强的人。

这不意味着这些群体“不普通”，而是提醒：

```text
what survives visibly today
!= distribution of who had a homepage then
```

已有 CNNIC、同时代报刊和个人回顾仍然必须和存活 artifact 一起使用。

### 4.2 URL 连续不等于人生叙述连续

同一个个人 URL 可以经历：

- 工作阶段变化；
- 项目和课程变化；
- 主页局部更新；
- 模板不更新；
- 机构服务器迁移；
- 作者长期不维护后又局部恢复。

因此研究“线上身份是否连续”时，至少要分开：

```text
person continuity
institution continuity
URL continuity
content continuity
visible timestamp continuity
```

这些不能压成一个“这个主页从 2001 年保存至今”的句子。

---

## 5. 对历史可见性的一个更具体警告

如果研究者今天只收集“还活着的旧主页”，可能得到一个很诱人的结论：

> 早期个人 Web 很稳定，很多人的公开自我可以持续二十多年。

但这里混进了两个偏差：

1. **survivorship bias**：死掉的免费主页最难进入样本；
2. **temporal compositing**：活着的 URL 又可能把多个年份的内容压成一个当前页面。

因此以后个人主页生活史的最小证据组合应尽量是：

```text
current survivor
+ contemporaneous report / directory / citation
+ actual historical capture when available
+ second historical timepoint when available
```

而不是只看今天网页底部写了哪一年。

## 6. 反例、边界与未知项

本轮不能推出：

- 所有高校个人主页都会出现错误时间戳；
- 2001 年以后这两个页面每年都持续维护；
- 当前网页的所有区块都来自同一个文件；
- 页脚一定是“作者忘记更新”，而不是模板/include/迁移造成；
- 这种 artifact 能代表 2001 年普通网民的主页使用方式。

仍待补：

- 南京大学该 URL 的真实历史 capture；
- 至少第二个历史时点；
- 页面原始 HTML / 响应头 / 资源层面的时间信息；
- 与早期目录或外链记录的 URL continuity 交叉确认。

---

## 7. 对核心矩阵的贡献

本轮主要补强：

- **线上/线下身份**：URL 可以长期连续，但公开自我内容并非单一时点；
- **平台消失与记忆保存**：机构托管提高存活概率，同时制造样本偏差；
- **历史可见性**：当前幸存物不能直接当过去总体；
- **时代时间感研究的方法**：页面 footer 日期不能代替材料当时性判定。

它没有新增教育、就业、住房、婚姻、迁移等生活路径类别。

---

## 8. 本轮饱和判断

前几轮 CFido、寻呼和纸—数往返分别新增了真实的通信 / 制度执行机制，因此此前的 no-new-mechanism 计数已经被重置。

本轮：

- 没有新增生活路径类别；
- 没有新增制度接口；
- 没有新增时代时间感机制；
- 没有新增通信 / Internet 转折机制；
- 海外 Berkeley 对照主要确认已有 archive / temporal-composite 判断；
- 但取得了可直接核验的中外 live-legacy artifact，实质提升了证据质量。

因此本轮应记为：

**阶段饱和连续计数：`1/3`。**

尚未达到 closure 条件，不停止研究。

---

## 9. 下一轮优先级

1. 继续 artifact-first，而不是从主题表里继续发明新名词；
2. 优先为已有精确 locator 取得真正 historical capture；
3. 对南京大学这类 live-legacy URL 尝试取得第一、第二历史时点；
4. 继续补 2007—2010、2018—2019、2023—2026 的同时代第一人称材料，尤其是能真正改变现有 future-horizon 判断的材料；
5. 只有出现新的生活机制 / 制度接口 / 跨国差异或实质改写结论的一手证据，才再次把饱和计数清零。
