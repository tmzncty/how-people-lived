# 个体经营、摆摊、网店与平台化微型生意：中国普通人的自雇路线，1980–2025

> 类型：跨时期 life-path / work-infrastructure 研究包  
> 核心问题：一个普通人除了“进单位 / 找公司 / 换工作”，还能怎样靠自己组织商品、客户、信用、支付、库存和时间来维持生活？  
> 时间范围：1980–2025  
> 与 `old-web-archaeology` 交叉：淘宝 2003 年历史页面、卖家开户/发布商品/信用/排序与登录态的保存问题。  
> 证据纪律：不把“创业成功者”当作典型，不把平台公布的卖家数当作人口普查，不把“开店容易”写成“赚钱容易”。

## 0. 去重：这不是再写一次“互联网让人更容易找工作”

仓库已有中国城市青年约 2005 的求职画像，已经明确写过：校园招聘会、社会招聘会、报纸、招聘网站、公司网站、学长推荐等渠道并存；Web 扩大的是职位可搜索性和远程投递能力。

本文件研究另一条此前没有独立建模的路线：

```text
不是找到一个雇主
而是自己成为一个微型经营主体
```

其历史形式可以是：

```text
街边小摊
→ 个体工商户 / 小店
→ 兼职网店
→ 全职网店
→ 平台店铺 / 内容带货 / 平台服务
→ 工资工作 + 副业 + 摆摊 / 网店的组合生计
```

关键不是把这些状态浪漫化为“自由创业”，而是问：

1. 谁承担库存、租金、平台规则、退货和现金流风险？
2. 店铺“存在”以后，顾客怎样真正看见它？
3. 家庭住房、父母时间、婚姻收入和物流是否在背后补贴这条路线？
4. 一个人是在主动追求经营，还是在失业、债务或收入不足时把它当作缓冲？
5. 当平台成为市场入口以后，经营资格又增加了哪些数字状态？

## 1. Internet 之前：自雇路线先存在，Web 后来改变的是市场半径和接口

### 1.1 1980 年前后的个体经营：先有“自己卖东西”，再有在线店铺

今天回顾个体经济时，经常以温州章华妹为象征案例。国家市场监管系统和多家机构的后来的回顾材料记载：1980 年她获得个体工商户营业执照；此前已经以小摊形式售卖纽扣、表带等小商品。

可用来源：

- 国家市场监督管理总局，2022-02-28，《我国个体工商户突破1亿户》：  
  https://www.samr.gov.cn/xw/zj/art/2023/art_50ae76de7063472991b6bce7b75d6f09.html
- 中国新闻网 / 人民网等对章华妹的后期访谈与回顾，2018。

**证据等级：A-（规模）/ C（个人回忆）。**

市场监管总局材料给出的长时段基线是：1980 年全国个体工商户不到 1 万户；到 2021 年底登记个体工商户已超过 1 亿户。这个数字不能告诉我们个体户是否盈利，也不能把四十年的制度变化压成一条线，但足以提醒：

> **“不成为工资劳动者，而自己做一门小生意”远早于大众互联网。**

1991 年国家统计局公报也记录，“七五”期间城镇个体劳动者增加约 250 万人。

来源：

- 国家统计局，1991 年统计公报：  
  https://www.stats.gov.cn/sj/tjgb/ndtjgb/qgndtjgb/202302/t20230206_1901994.html

**证据等级：A。**

因此不能使用：

```text
淘宝出现 → 中国人才第一次可以自己做生意
```

更合理的问题是：

```text
已有个体经营路线
+ 家庭 PC / 网吧 / 宽带
+ 可搜索市场
+ 数字支付 / 物流
+ 平台信用
→ 哪些原本要租门面、靠本地客流的经营环节被重新组合？
```

## 2. 2003：店铺开始成为一种“账号状态”

本轮与 OWA 共同核验了淘宝 2003 年的多个 Internet Archive capture。

### 2.1 2003-07-30 首页：普通用户已经能“搜索店铺”和“创建网上店铺”

历史 capture：

- Original URL: `http://www.taobao.com/`
- Memento datetime: **2003-07-30 01:30:07**
- Internet Archive：  
  https://web.archive.org/web/20030730013007/http://www.taobao.com/

页面可直接观察到：

- “搜索宝贝 / 搜索店铺”；
- 登录与“免费开户”；
- “创建网上店铺”；
- “我要买 / 我要卖 / 我的淘宝”；
- 拍卖、一口价、讨价还价、贴张海报等交易模式；
- 北京、上海、广州、杭州等“同城交易”；
- 实际商品条目和价格。

**证据等级：A（核验过的历史 capture）。**

这里出现了一个很重要的生活变化：

> **店铺不再首先等于一间需要被路人经过的物理空间，它可以首先是一种账号、商品列表和搜索结果中的存在。**

我把它称为：

**`storefront-as-account-state / 店铺作为账号状态`**。

它降低了“必须先租下一间门面才能开始试卖”的固定成本，但并没有消除货源、库存、包装、电脑、上网、物流、售后和时间成本。

### 2.2 2003-08-02 卖家入口：早期电子商务仍然允许“线上发现、线下面谈”

历史 capture：

- Original URL: `http://aucpost.taobao.com/sellstart.php`
- Memento datetime: **2003-08-02 06:15:25**
- Internet Archive：  
  https://web.archive.org/web/20030802061525/http://aucpost.taobao.com/sellstart.php

页面告诉卖家：家里的闲置书籍、手机、VCD 等都可以拿来卖；同时列出四种发布方式。

尤其值得注意的是“贴张海报”一类：平台可以公开联系方式，再由双方约时间面谈。

因此早期 C2C 不是一个纯粹的：

```text
网页 → 在线支付 → 快递 → 完成
```

它还可能是：

```text
线上让陌生买家发现商品
→ 看联系方式
→ 约时间
→ 线下面谈 / 当面交易
```

这与旧的分类广告有连续性，也与后来高度平台内闭环的电商不同。

### 2.3 “免费开户”不等于无条件经营

2003-08-01 的历史注册页保存了当时淘宝服务条款。它明确写到：

- 用户注册需要填写信息并确认协议；
- 用户应提供有效电子邮件、联系电话、联系地址、邮编等资料；
- 用户可以发布交易信息、竞买、签订交易、评价其他用户信用；
- 平台把自己定义为提供交易地点，而不是每笔买卖中的买方或卖方。

历史 capture：

- Original URL: `http://member.taobao.com/register.php`
- Memento datetime: **2003-08-01 08:01:24**
- https://web.archive.org/web/20030801080124/http://member.taobao.com/register.php

**证据等级：A。**

所以：

```text
低门槛 ≠ 无门槛
```

一个人仍然需要进入账号体系、承担规则责任，并且把可联系性、用户名和后来的信用状态变成经营基础设施的一部分。

## 3. 2005–2012：扩张型未来的一种具体形式——“工资工作之外还可以长出一门自己的生意”

### 3.1 2009 年张浩学：从大学副业到辞掉工资工作

2009 年中新网转载《联合早报》的一篇同期采访记录，26 岁的张浩学在大学二年级时开始在淘宝转卖自己淘来的衣服，毕业后到成都一家房地产公司做秘书，同时继续经营网店；两年后网店收入远高于工资，2009 年 4 月辞职全职开店。

来源：

- 中国新闻网 / 新浪，2009-09-01，《联合早报：网购热传染成中国80后生活方式》：  
  https://news.sina.com.cn/o/2009-09-01/164716222022s.shtml

**证据等级：B+（同期第一人称采访，成功者个案）。**

这条材料尤其重要，因为它恢复了一条渐进路线：

```text
学生
→ 网上转卖赚零用钱
→ 毕业进入公司
→ 工资工作 + 网店并行
→ 网店收入超过工资
→ 辞职全职经营
```

它不是“一毕业就创业”的英雄叙事，而是**两个收入系统先重叠，再决定是否退出工资工作**。

我把这种结构写成：

**`dual-track livelihood / 双轨生计`**。

普通人可以先让副业在工资收入旁边小规模运行，而不是一开始就把全部未来压在一条路线里。

### 3.2 家庭住宅并没有消失，反而进入商业栈

张浩学说，所有拍照、制图、装修店铺等工作都由她自己完成；母亲家里成了库房，婚后搬出去以后，原来的房间继续做仓储。她每天从早上 9 点工作到午夜，旺季处理全国各地买家的询问和交易。

这说明“网上店铺”并不是去物质化：

```text
网页店铺
+ 家庭房间当仓库
+ 相机 / Photoshop / 电脑
+ 进货
+ 包装
+ 快递
+ 家庭成员可能协助
```

才组成真实生意。

因此新增：

**`household-commercial overlap / 家庭—商业空间重叠`**。

低门面成本的一部分，可能只是被转移进家庭住房、家庭时间和库存风险。

### 3.3 另一条同期个案：有全职工作的人把父母时间也接进网店

同一篇 2009 年报道中的邓力珂有全职工作，只能在下班后和周末管理网店，并考虑让父母帮忙拿货、邮寄。

所以平台化微型生意并不必然等于“一个人完全独立”。它可能是一种家庭劳动组合：

```text
一人的账号
+ 一人的工资工作
+ 父母拿货 / 发货
+ 家里库存空间
```

## 4. “开店”与“有人看见”是两件事

### 4.1 2009 年肖肖：两万元进货，近一年只卖出 11 件

《南都周刊》2009 年同期采访一名杭州大学生肖肖：她在 2008 年 8 月注册淘宝店，用家里给的 2 万元到四季青批发市场进货，但直到 2009 年 6 月，店铺日流量长期只有约 2 人，近一年只卖出 11 件衣服。后来她在淘宝社区发帖获得大量关注，店铺访问才从个位数上升到三位数。

来源：

- 南都周刊 / 新浪，2009-06-23，《网店小红人：不为钱只为名》：  
  https://news.sina.com.cn/s/2009-06-23/144618077473_6.shtml

**证据等级：B+。**

因此：

```text
店铺创建成功
!= 商品被看到
!= 有询问
!= 有成交
!= 足以谋生
```

这一轮把它称为：

**`entry-cost compression / 进入成本压缩`** 与 **`visibility-cost rebound / 可见性成本回弹`**。

平台可以把“拥有一个店铺”的成本压得很低，却不能无限制造买家的注意力。卖家增加以后，真正稀缺的资源从“有没有门面”逐渐变成“搜索、推荐、社区和内容里能不能被看见”。

### 4.2 2006 年“招财进宝”：可见性甚至一度直接被做成竞价状态

2006 年淘宝推出“招财进宝”，卖家可为关键词和推荐位付费，付费金额会影响排序。东方早报同期报道中，一名没有参加该服务的卖家说自己的商品排名明显下降，并担心库存难以卖出；大量卖家抗议，服务最终在一个月左右后经投票取消。

来源：

- 东方早报 / 新浪，2006-05-30，《卖家扬言集体下架 淘宝大幅降“推荐费”》：  
  https://news.sina.com.cn/c/2006-05-30/02459061654s.shtml
- 上海青年报 / 新浪，2006-06-12，《淘宝网公投关了“招财进宝”》：  
  https://tech.sina.com.cn/i/2006-06-12/1032985201.shtml

**证据等级：B（同期媒体，参与人数与影响需视为报道口径）。**

这里出现一个以后平台经济反复出现的结构：

**`free listing != free visibility`**。

进入市场可以免费，但让自己持续出现在买家面前，可能重新成为要付钱、做内容、积累信用或研究规则的工作。

## 5. 信用不是“附加评价”，而会变成经营资产

2003 年注册条款已经明确允许用户评价其他用户的信用，并禁止通过不正当方式提高自身信用。

到 2006 年，淘宝调整评价体系，把原本某些合并计算方式改成更细的买卖双方信用区分。同期报道记录，卖家发现自己的显示等级因此下降，并担心生意受影响。

来源：

- 钱江晚报等 / 新浪，2006-01-23，《评价变动橇动“淘友”神经》：  
  https://news.sina.com.cn/o/2006-01-23/08358056859s.shtml

这表明：

**`platform reputation / 平台信用` 已经是一种经营资本。**

它有三个特点：

1. 需要跨很多交易逐步累积；
2. 会影响陌生买家愿不愿意交易；
3. 平台改变计算规则时，过去累积的同一批交易可以被重新估值。

因此个人经营的“资产”不仅有库存和现金，还会出现：

```text
账号年龄
+ 评价数量
+ 信用等级
+ 搜索权重
+ 店铺访问量
```

这些平台状态不能像货架一样搬走。

## 6. 2015–2019：拥堵型未来——路线仍然存在，但“一个人开店”越来越不像轻量旁路

### 6.1 2018 年两个店主的回看：同一个人已经感觉到生态改变

澎湃新闻 2018 年采访“浪里小白龙”和“镜子”。两人在约 2011 年都做过淘宝副业；其中一人后来 2017 年辞掉 UI 设计工作再次开店，尝试自己设计服装，但最终亏损几千元后重新找工作。

她们共同描述的变化包括：

- 早期个人店铺不必做太多宣传也有机会积累；
- 2017–2018 经营越来越依赖流量、运营、专业美工、设计、选款和团队分工；
- “没有顾客”和“宣传运营”成为突出困难；
- 商品不错并不保证被发现。

来源：

- 澎湃新闻，2018-01-25，《开个淘宝店：兴趣、梦想还是生意？》：  
  https://www.thepaper.cn/newsDetail_forward_1916345

**证据等级：B+（同期采访，同时带有对约 2011 年经历的回顾）。**

这说明“拥堵型未来”并不是这条路消失，而是：

```text
可进入者增加
→ 店铺数量增加
→ 注意力更稀缺
→ 运营专业化
→ 单人店铺要承担更多看不见的工作
```

### 6.2 这也校正了“自由职业 = 更少工作”

2009 年张浩学全职开网店以后每天约 9:00 工作到 24:00；2018 年店主又把设计、跑面料市场、打版、拍摄、修图、文案、上新、营销分开描述。

所以：

**退出工资雇佣，并不自动等于退出高强度劳动。**

变化更像是劳动控制权、风险、收入波动和任务组合重新分配到个人身上。

## 7. 2020–2022：偶发型未来——“开网店”同时成为就业统计项和冲击期试路

2020 年就业形势变化时，教育部门把“开网店”等纳入高校毕业生相关就业统计口径。国家大学生就业服务平台转载新华社报道称，大学生胡为在临近大四时因为当年就业困难，决定先“开淘宝创个业试一试”；淘宝同时公布了大量新增店主数据。

来源：

- 国家大学生就业服务平台 / 新华网，2020-08-06，《淘宝：今年以来20万大学生涌入平台开店创业》：  
  https://www.ncss.cn/ncss/jydt/cy/202008/20200806/2101835206.html
- 广州日报 / 人民网，2020-08-18，《造战车、绣汉服……大学生在淘宝上“玩”出大生意》：  
  https://sc.people.com.cn/n2/2020/0818/c345167-34233981.html

**证据等级：A-/B。** “把开网店纳入统计口径”是制度接口；店主数量为平台口径，不能当作独立人口调查。

最重要的变化不是“疫情让所有人创业”，而是：

> **当标准招聘路线本身变得不确定时，自雇平台可以被一部分人当作一条可先试运行的旁路。**

这和 2009 年“副业跑起来以后再辞职”恰好形成另一种方向：

```text
2009：工资工作稳定存在 → 副业成长 → 决定退出工资工作
2020：标准就业路径本身受冲击 → 先把网店作为可执行选项试起来
```

## 8. 2023–2025：防守型未来——不是“我要当老板”，而是“我不能只有一个收入入口”

### 8.1 2023 年乐乐：工资工作 + 夜摊 + 自媒体 + 供货

中新网 2023 年采访的“乐乐”在 2020 年餐饮创业失败、负债后重新上班。2021 年她拿 3500 元作为启动资金，下班以后摆摊卖玩具；同时做自媒体，因为成本低，而且她明确把摆摊看成“即使自媒体做不起来，也还有一份收入”的后备。

来源：

- 中国新闻网 / 澎湃，2023-03-25，《“我兼职摆摊两年，3500元起家，年入200万”》：  
  https://www.thepaper.cn/newsDetail_forward_22452266

**证据等级：B+（同期采访，但标题和成功收益有强烈新闻选择效应）。**

真正值得保留的不是她后来的高收入数字，而是 2021 年起点的决策结构：

```text
已有工资工作
+ 债务压力
+ 缺少大额本金
→ 选择低资本摊位
→ 同时试低成本内容渠道
→ 保留至少一个能产生现金流的后备
```

这可以称为：

**`defensive income-stack / 防守型收入栈`**。

它和 2005–2012 扩张型未来很不一样。早期常见叙事是“我还可以把爱好做成自己的事业”；防守型版本更接近：

> **我最好不要让自己的生计只依赖一个雇主、一个店铺或一个平台。**

### 8.2 低进入成本同时制造“卖创业给创业者”的二级市场

同一篇报道也发现，围绕摆摊出现了短视频教程、货源推荐、收费收徒等生意；失败者甚至认为真正稳定赚钱的可能是“教别人摆摊”的营销账号。

因此每当某种低门槛经营路线进入流行想象，都必须追问：

```text
谁在卖货？
谁在卖工具？
谁在卖流量？
谁在卖课程？
谁向谁收取进入费用？
```

不能把“很多人讨论一种副业”直接当成“很多人靠这种副业稳定谋生”。

## 9. 海外对照：eBay 说明这些机制并非中国特有

### 9.1 1999：地方小摊的商品突然获得全球买家

TIME 1999 年报道古董商 Sharon Balkowitsch：她原本在北达科他州 Bismarck 的古董摊卖货，本地需求限制销量；进入 eBay 后，买家可以来自冰岛、埃及、中国等地。她用非常直观的方式比较过：实体摊位最好的月份只卖约 15 件，而在 eBay 高峰时可以在一小时内卖出类似数量。

来源：

- TIME, 1999, “Inside eBay.com: The Attic of e”:  
  https://time.com/archive/6737323/inside-ebay-com-the-attic-of-e/

**证据等级：B+。**

这说明在线市场最基础、也最容易被“创业神话”遮住的变化其实是：

**`market-radius expansion / 市场半径扩张`**。

它让本地没有足够买家的小众商品，可能找到远方需求。

### 9.2 2000：扩张也会迅速变成拥堵

Salon 2000 年的一篇第一人称文章中，一名卖家回忆自己约 1997 年辞掉日常工作，全职靠 eBay 卖收藏品，初期收入明显高于传统工作；几年后，随着卖家大量涌入，她即使已经积累了约 850 条正面反馈，生意仍明显下滑。

来源：

- Salon, 2000-10-27, “Doomed by eBay”:  
  https://www.salon.com/2000/10/27/doomed_by_ebay/

**证据等级：B+（同期第一人称）。**

这与中国从 2009 到 2018 的变化高度可比：

```text
新市场出现
→ 早期卖家发现巨大新增需求
→ 更多卖家进入
→ 供给与注意力拥堵
→ 信誉、运营、广告和专业化变重要
```

因此“红利期结束”并不是中国平台经济独有心理，而是双边市场成熟过程中很常见的结构。

## 10. 到 2013：开店已经是一个更完整的数字资格栈

阿里巴巴 2014 年向美国 SEC 提交的 F-1 对 2013 年淘宝卖家结构有很清楚的第一方说明：卖家主要是个人和小企业；卖家需要身份验证、通过淘宝规则在线考试并签署诚信承诺；店铺和商品发布本身免费，但平台收入的一部分来自卖家购买流量导向相关的营销服务和店铺软件。

来源：

- Alibaba Group Holding Limited, Form F-1, 2014，Taobao Marketplace 段落：  
  https://www.sec.gov/Archives/edgar/data/1577552/000119312514184994/d709111df1.htm

**证据等级：A-（第一方监管披露；证明平台制度，不证明卖家主观体验）。**

这让“开网店”可以拆成：

```text
具备设备与网络
→ 建立账号
→ 身份验证
→ 学习并通过平台规则
→ 创建店铺
→ 创建商品
→ 获取流量
→ 与买家沟通
→ 支付 / 发货 / 售后
→ 累积信用
→ 维持规则合规
```

所以：

**`platform access != market success`**。

## 11. 重点矩阵

| 维度 | 本轮新增理解 |
|---|---|
| 教育 | 学生可以把网店作为在校期间的试经营；学历路线与经营路线可并行，不必互斥。 |
| 就业 | 工资工作之外存在自雇、兼职店铺、摊位和平台服务；可先并行再决定是否退出雇佣。 |
| 住房 | 家庭住房可被改造成仓库、打包点和工作室，低门面成本可能转移为家庭空间成本。 |
| 婚姻家庭 | 配偶工资可以缓冲经营风险，父母可以参与拿货、发货、仓储；“个人店”可能是家庭劳动项目。 |
| 迁移 | 在线市场扩大买家半径，后来物流和平台又允许经营者从非一线城市接全国订单。 |
| 照护 | 海外材料显示照护责任可以推动居家在线经营；中国材料仍需要更多直接照护型卖家一手证据。 |
| 非正规劳动 | 摆摊、兼职网店、内容副业等可以与正式工资工作重叠，而不是简单二分。 |
| 长期中断 | 店铺可暂停、重开，经营身份可能在工作间隙反复进入；但账号信用是否能跨中断保留非常关键。 |
| 证件与记录 | 线下个体经营有营业执照，平台经营又增加账号、身份、规则考试、信用和支付状态。 |
| 通信方式 | 咨询、议价、售后从面对面 / 电话进一步转成即时消息和平台内通信。 |
| Internet 平台 | 平台同时是门面、市场、信用系统、搜索引擎、支付入口和治理机构。 |
| 信息获取 | 卖家不仅找客户，还要找货源、研究规则、学习图片/运营技能。 |
| 社交关系 | 社区帖子、内容和“人设”可以直接变成商业可见性。 |
| 未来预期 | 扩张期更常见“副业可能长成事业”；防守期更常见“多保留一个现金流入口”。 |
| 线上/线下身份 | 一个实体人可能同时是员工、学生、卖家、摊主、内容账号；平台身份并不等于线下职业身份。 |
| 平台消失与记忆 | 店铺 HTML 能保存，不等于订单、买家群、评价图谱、余额和流量状态仍可恢复。 |

## 12. 反例与后见之明风险

### 反例 1：低成本进入并不保证生意成立

肖肖投入 2 万元、近一年只卖出 11 件，是对“开网店门槛低 = 容易赚钱”的直接反例。

### 反例 2：成功卖家有严重的媒体选择偏差

2009、2020、2023 的报道都倾向选择故事完整、商品有特色或后来做大的卖家。它们可以证明**这种生命路线真实存在**，不能估计成功概率。

### 反例 3：平台让全国买家可达，同时制造新的依赖

搜索排名、信用算法、营销服务和平台规则会重新决定谁可见。卖家省掉了某些物理门面成本，却把部分生意命运交给平台状态。

### 风险 1：不要把“个体户”与“互联网创业者”连成单线进步史

1980 年街边摊、1990s 小店、2000s 网店、2020s 副业平台之间有连续性，也有制度和技术断裂。它们都属于非工资劳动，但经营资产和风险并不相同。

### 风险 2：不要把“平台自由”写成没有老板

没有直接雇主，不代表没有规则制定者。平台可以改变信用、排序、收费、身份要求和交易可见性。

### 风险 3：不要把副业自动解释成热爱工作

同一形式既可以来自爱好与表达，也可以来自债务、就业困难、工资不足或担心单一收入中断。

## 13. 本轮新增的最小结论

这轮不是得出“互联网让人人都能创业”。更窄、也更可靠的结论是：

> **中国普通人的经营型人生路线早于 Internet；Web 平台后来把市场门面压缩成账号和商品状态，扩大潜在买家半径，并让一个人可以先在工资工作旁边试运行一门微型生意。随着卖家增加，门面成本下降并没有消灭竞争，而是把稀缺资源逐步推向搜索可见性、平台信用、运营技能和流量。**

因此 2005–2012 的扩张型未来、2015–2019 的拥堵型未来、2020–2022 的偶发型未来和 2023–2025 的防守型未来，在同一条经营路线里可以连续观察：

```text
扩张：我可以在工作以外开一个店，甚至让它长成主业
→ 拥堵：店还可以开，但“有人看见”越来越需要专业运营
→ 偶发：标准就业中断时，开店可以被当作一条可先运行的替代入口
→ 防守：我不一定要辞职，但最好保留第二个收入入口
```

最重要的变化，不是“所有人都变成老板”，而是：

**普通人能够在“找一个雇主”和“完全没有工作”之间，组装出更多介于二者之间的生计状态。**

## 14. 尚未确定与下一步

1. 需要补一批 1980s–1990s 个体户的同时代报刊、工商登记、市场摊位与家庭账本材料，避免早期部分过度依赖后来回顾。
2. 需要继续找 2003–2006 淘宝卖家的原始论坛帖、帮助页、店铺规则和历史 capture，尤其是信用、支付宝与物流的实际用户流程。
3. 2019 年需要更多普通、没有做大的店主第一人称材料，尤其是退出平台、重新上班、店铺闲置者。
4. 2020–2022 需要区分“统计上被算作就业”与“实际能持续覆盖生活费”。
5. 2023–2026 的副业材料需要进一步区分主动兴趣、多元收入防守、失业后的临时缓冲、债务后的恢复路线。
6. 需要专门比较女性、照护者、残障人士、县域经营者使用居家/平台经营的不同可执行性。

### 饱和判断

本轮发现新的生活路径机制（工资劳动与自雇之间的双轨生计）、新的时代机制（进入成本压缩后出现可见性成本回弹）以及新的平台状态依赖（信用、排序、登录与市场状态）。因此本轮**不计入连续无新增**。
