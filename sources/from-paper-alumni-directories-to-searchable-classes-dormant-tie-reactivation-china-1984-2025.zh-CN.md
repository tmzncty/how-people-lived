# 从纸质校友通讯录到可搜索班级：失联、休眠关系与同学关系的重新寻址，中国 1984–2025

> 类型：life-path / communication-infrastructure research package。  
> 交叉对象：`tmzncty/old-web-archaeology/research/alumni-directory-class-page-credential-afterlife-and-cross-platform-operational-fossils-2004-2008.md`。  
> 本文研究的不是“社交网站发展史”本身，而是一个更普通的问题：**一个人毕业、搬家、换工作、改电话号码甚至多年不联系以后，过去认识的人还有没有一条现实可执行的路重新找到她？**

---

## 0. 去重：为什么这不是已有“远距离通信”专题的重复

仓库已经有：

- `communication-and-the-cost-of-living-far-away`：讨论远距离联系成本；
- 分址家庭、迁移、汇款：讨论家庭成员分散以后怎样继续维持生活；
- 个人主页、BBS、SNS、公共终端：讨论个人如何进入网络公共空间；
- 婚恋平台：讨论陌生人怎样在资料库中变得可搜索。

但它们没有单独回答：

> **已经认识、却多年没有当前联系方式的人，怎样重新变得可寻址？**

这是一个不同的生活状态。两个人之间可能并没有决裂，也没有持续通信，只是：

```text
毕业 / 搬家 / 换单位 / 电话变更 / 邮址失效
→ 原联系坐标失效
→ 关系进入休眠
→ 某一天又想寻找对方
```

本轮把这条路线称为：

**`dormant-tie reactivation / 休眠关系再激活`**。

这里的“休眠”不是心理学判断，也不是说关系一定还亲密，只表示：**过去存在可识别关系，但当前日常通信已经停止或显著减弱。**

## 1. Internet 以前：校友身份已经可以成为一种寻找索引

Web 并没有发明“按学校、届次和班级组织旧关系”。

书目记录可以确认，北京师范大学校友联络处在 **1984 年**编印过《北京师范大学校友通讯录》；1990 年又有《武汉大学校友通讯录》，后者书目记录为 188 页。

这些书目记录只能证明纸质校友目录这种物件存在，**不能证明每名毕业生都能获得一本、信息始终准确、也不能证明它被怎样实际使用**。但它足以说明，在大众 Internet 到来之前，学校/校友会已经可以把人按共同机构历史重新编成一个地址簿。

### 证据

- **A-/B+（图书馆书目元数据；证明出版物存在，不证明实际使用率）**：CiNii Books，《北京师范大学校友通讯录》，北京师范大学校友联络处编，1984.9。  
  https://ci.nii.ac.jp/ncid/BB23789163
- **A-/B+（Google Books 书目元数据）**：《武汉大学校友通讯录》，武汉大学校友通讯录编委会，1990，188 页。  
  https://books.google.com/books/about/%E6%AD%A6%E6%B1%89%E5%A4%A7%E5%AD%A6%E6%A0%A1%E5%8F%8B%E9%80%9A%E8%AE%AF%E5%BD%95.html?id=uQrOxQEACAAJ

### 一个重要边界

纸质通讯录更接近：

```text
机构知道一批人的某次联系资料
→ 定期收集 / 编印
→ 持有目录的人按姓名、届次等人工查找
```

而不是今天的：

```text
任何时候在线检索
→ 对方更新资料后数据库马上变化
```

所以 Internet 后来的变化不是第一次有“校友索引”，而是把**更新、搜索、留言、群体空间和跨地域访问**逐渐放到同一套在线系统里。

## 2. 联系坐标检索 vs 身份属性检索

为了描述这次变化，可以区分两种寻找方式。

### 2.1 联系坐标检索

你已经知道对方的：

- 地址；
- 电话；
- 单位；
- 邮箱；
- 某个中间人的联系方式。

问题是：这些坐标非常容易随着迁移、换工作、换号而失效。

### 2.2 身份属性检索

你只记得：

- 哪所学校；
- 哪一年入学 / 毕业；
- 哪个班；
- 姓名或旧昵称。

如果平台已经把这些字段组织成索引，就有可能从“过去共同经历”反推出一个新的联系入口。

本轮把这个变化称为：

**`identity-attribute lookup / 身份属性检索`**。

它尤其适合处理一个典型问题：**我不知道你现在住哪里，但我记得我们在哪里一起生活过。**

## 3. 2004：网上同学录已经把“学校—班级—账号”做成普通用户可操作的检索结构

2004 年 6 月 23 日 PChome 的同期教程《百花争艳网上同学录》非常适合恢复普通用户的实际动作。

文章记录，当时 ChinaRen 校友录允许注册后按“我的大学 / 我的中学 / 我的小学”搜索或创建班级；QQ 校友录则以 QQ 号进入，可以创建班级、加入班级，甚至把已有的“同学”QQ群转成校友录并指定入学年份。

5460 的 Windows 客户端进一步显示：用户第一次登录后从服务器下载自己的数据和班级数据；“我的班级”显示成员列表、班级留言和相册，“我的通讯录”分为班级同学、教师和附加通讯录；还可以按数字 ID、用户名、昵称或姓名搜索好友并实时聊天。

### 证据

- **B+（2004 年同期软件/网络使用教程；可以证明作者当时观察到的操作路径，不能证明所有用户都这样用）**：PChome，2004-06-23，《百花争艳网上同学录》。  
  https://m.pchome.net/article/content-17875-all.html

### 生活史意义

这里出现的不是抽象的“社交网络”，而是一条可执行路线：

```text
只记得学校 / 班级 / 入学年 / 姓名
→ 在平台搜索学校或班级
→ 找到公共班级空间或具体账号
→ 留言 / 加好友 / 即时聊天
```

与纸质校友录相比，最大的变化之一是：**同一个索引不仅告诉你“这个人曾经属于这里”，还可能直接变成重新联系的入口。**

## 4. 2005：网上班级把毕业后的分散关系变成一个持续存在的“共同地址”

2005 年 3 月 18 日《解放日报》经新浪保存的同期报道《“我的大学”虚拟化》提供了非常具体的日常材料。

报道中的复旦大学新闻学院 2002 级硕士班，因为同学到全国各地媒体实习，在 ChinaRen 建立网上同学录，班级通知、留言和偶遇式即时聊天转移到线上。另一个案例中，武汉大学 1996 级广电班毕业后散居各地，一名去了甘肃酒泉的毕业生说，五年来网上同学录让自己继续和全国各地同学保持联系。

记者同时观察到：5460 上复旦、同济等学校已经出现大量网上班级；ChinaRen 上上海交通大学也有大量班级。这里的平台数字来自记者当时看到的页面，**不应进一步推成全国学生使用比例**。

### 证据

- **B+（2005 年同期报刊采访，经新浪 current-live legacy 页面保存）**：《解放日报》，2005-03-18，《“我的大学”虚拟化》。  
  https://news.sina.com.cn/s/2005-03-18/09105394097s.shtml

### 新的解释：`group address persistence / 群体公共地址持续性`

过去毕业以后，每个人的地址都可能变；网上班级则提供一个相对稳定的**共同地址**：

```text
A 去北京
B 去上海
C 去酒泉
D 换了手机号
↓
只要大家还知道同一个班级页面 / 平台账号
↓
班级本身继续成为集合点
```

这并不要求每对同学都持续一对一通信。

它降低的是：**关系重新启动时，先找“人在哪里”的成本。**

## 5. 反例：有一个班级页面，不等于形成一个活跃班级

同一时期的材料也提醒，不应把“班级被创建”直接写成“关系被维持”。

2005 年报道里，同济的一名博士生就认为，过度依赖网络甚至可能让仍住在附近的同学减少线下集体生活；线上说“有兴趣”的活动，也可能到了真正安排时间地点时无人参加。

这意味着：

```text
class page exists
!=
members regularly visit
!=
relationships remain close
!=
offline collective action succeeds
```

所以网上班级是一种**关系基础设施**，不是友情强度计。

## 6. 2008：班级并不会自己“长出来”——有人要做行政劳动

2008 年 7 月，一个今天仍可在 Google Groups 看到的同期班级邮件串，为 5460 留下了非常细的操作证据。

出于隐私与安全考虑，本研究**不重新复制邮件中的普通个人姓名、邮箱、用户名或历史明文初始口令**；这里只保留支持研究结论所需的动作结构。

这组邮件显示：

1. 一名班级成员看到邻班已经使用 5460，于是为自己的班建了“虚拟教室”；
2. 管理者为全班预先建立账号，再通过邮件把班级入口和登录说明发给成员；
3. 成员也可以从 5460 首页按学校并指定入学年份找到班级；
4. 创建后的两天内，24 名成员中有 16 名完成过登录；
5. 几个月后，邮件又提到部分成员很久没登录，可能已经忘记账号。

### 证据

- **A-/B+（2008 年同期普通用户邮件/Google Groups archive；时间、操作内容和历史 URL 可观察，但作者现实身份不做额外核验；包含敏感旧凭证信息，研究引用实行最小化）**：《5460同学录——多一条思念通道》，2008-07 起。  
  https://groups.google.com/g/class-1-in-sisu-2007/c/r8zeyNgOUkI

### 新增生活劳动：`relationship infrastructure maintenance / 关系基础设施维护`

互联网没有让社会关系自动持久。

有人仍然要：

```text
创建班级
→ 整理成员
→ 建账号 / 邀请
→ 发入口
→ 解释登录
→ 催促签到
→ 处理忘记账号
→ 继续更新内容
```

这是一种很容易被平台界面隐藏的组织劳动。

因此：

> **social graph availability != social graph self-maintenance**

## 7. 对 2005–2012“扩张型未来”的修正：扩张的不只是陌生人世界，还有“过去不必彻底失去”

互联网扩张通常被写成“可以认识更多人、看到更远的世界”。

同学录材料增加了另一面：**一个人的未来变大以后，过去也更容易被带着走。**

一个普通青年离开学校以后可以同时：

- 去另一个城市工作；
- 换电话号码；
- 几年不主动联系某个同学；
- 但仍保留一个按学校 / 班级可回到的公共入口。

这让人生中的迁移不再必然等于一次彻底的关系切断。

可以把它写成：

```text
mobility increases
+
identity-indexed communication infrastructure
→
old ties can remain dormant instead of becoming permanently unfindable
```

这里的关键词不是“永远在线”，而是**可恢复**。

## 8. 2019：数据还在，关系却可能只剩“熟悉的陌生人”

2019 年 10 月，人人网重新上线测试时，《扬子晚报》经人民网报道，老用户可以尝试用原账号密码进入；记者把登录后的感受概括成“满眼熟悉的陌生人”。同年 12 月新版人人 App 正式公测时，运营方把“找回旧账号密码”和恢复校园主页、聊天等作为重要功能。

这里必须严格区分平台自己的规模声明与记者可观察事实。运营方关于累计用户、历史图片和状态数量的数字只能证明**平台当时这样宣称**，不能作为独立审计后的真实规模。

### 证据

- **B+（2019 年同期媒体现场/用户采访）**：人民网转载《扬子晚报》，2019-10-28，《人人网归来，你找回旧密码没？》。  
  https://media.people.com.cn/n1/2019/1028/c14677-31424126.html
- **B（同期媒体报道，包含运营方声明）**：北京日报/人民网，2019-12-31，《人人网推新APP回归社交市场》。  
  https://media.people.com.cn/n1/2019/1231/c40606-31529296.html

### 2015–2019“拥堵型未来”中的关系状态

这里出现了一个很重要的不等式：

**`data persistence != relationship persistence`**

平台可以保存：

- 名字；
- 好友关系；
- 老照片；
- 旧状态；
- 账号。

但它不能自动保存：

- 现在是否还亲密；
- 是否仍有共同生活；
- 是否还愿意重新联系；
- 是否觉得过去内容应该继续可见。

一个历史社交图可以完整得惊人，而现实社会关系已经静止多年。

这也说明所谓“可恢复的人生过去”有两面：

- 它可以帮助找回关系；
- 也可能把已经想遗忘的“黑历史”重新推回面前。

## 9. 2020–2022：实体聚会被打断以后，班级身份成为“云端重新集合”的索引

2020 年，北京大学 86 级毕业三十周年聚会因新冠疫情转到线上。校友为此在七天内搭建“86云家园”，官方校友网记录有 1106 位同学注册，不少于 2165 人观看直播，并设置云主场、分桌和若干线下分会场。

2022 年，中国科大 6523 班的材料更加适合观察老年同学群体。该班 1965 年入学，成员在 2022 年平均年龄约 75 岁；原计划 2020 年在扬州线下聚会，疫情使计划无法实现，2021、2022 年改成网络视频联谊。活动前通过**微信群、电话、邮件**等多渠道逐一通知老师和同学。

### 证据

- **A/B+（高校校友机构同期活动记录）**：北京大学校友网，2020-08-09，《千人云端聚｜86级毕业三十周年云聚会》。  
  https://www.pku.org.cn/info/1011/11376.htm
- **A/B+（高校校友机构同期班级记录）**：中国科学技术大学校友总会，《中国科大6523班2022年元宵节网络联谊会》。  
  https://aga.ustc.edu.cn/info/1199/26202.htm

### “偶发型未来”中的意义

这里的替代不是：

```text
有视频会议
→ 聚会自然发生
```

而是：

```text
线下年度/周年节点被疫情打断
+
班级身份仍然可辨认
+
微信群 / 电话 / 邮件能够重新寻址成员
+
视频会议成为临时共同空间
→
一次原本会消失的聚会可以换通道继续
```

尤其值得注意的是，2022 年案例并不是只靠一个新平台；它依赖的是**多通道冗余**。有的人从微信收到通知，有的人靠电话，有的人靠邮件。

因此旧关系的可恢复性往往来自：

**`one social identity + several communication channels`**，而不是某一个 App 单独完成全部工作。

## 10. 2023–2025：通用社交网络已经普及，“按校友/班级重新寻找”仍然没有完全消失

2025 年 3 月，一个新的 iOS 应用“校友录ALUMNI”上线。App Store 上开发者将产品直接描述为“专为找寻校友”的互动平台，并继续提供班级、留言、照片等结构。

这只能证明：**到 2025 年仍然有人把“按校友/班级重新组织旧关系”当作一个值得开发的产品需求。**

它不能证明：

- 大量用户真的成功找回了旧同学；
- 这种专门平台重新成为主流；
- 微信、QQ、短视频和一般 SNS 无法完成类似任务。

### 证据

- **A-/B（当前 App Store 产品页；证明产品定位、上线日期与功能声明，不证明用户效果）**：`校友录ALUMNI`，版本 1.0 于 2025-03-06 上线。  
  https://apps.apple.com/us/app/%E6%A0%A1%E5%8F%8B%E5%BD%95alumni/id6742598597

### 对“防守型未来”的谨慎解释

这条证据暂时不足以证明 2023–2026 的年轻人因为未来更防守，所以更想找旧同学。

更安全的结论只有：

> 即使在“几乎人人已有通用社交账号”的时代，**旧关系的可寻址性仍然不是自动问题**；学校、届次、班级这种旧式制度身份，仍可以被重新拿出来当搜索键。

这一点应等待更多 2023–2026 同期第一人称材料后再解释为时间感变化。

## 11. 海外对照：Classmates.com 说明这不是中国特有现象

美国 Classmates.com 在 1995 年创建。2003 年 CBS 的同期专题里，创始人把平台最初目标描述为让人重新连接青年时期的人；报道记录了利用学校索引和旧同学网络寻找多年失联者的具体案例。

其中一个重要设计细节是：为了提高女性婚后改姓之后的可找性，平台会保留/使用旧姓作为检索线索。这个细节非常适合说明：

**身份属性检索的价值，正是在于现实联系坐标和部分身份字段会变化。**

### 证据

- **B+（2003 年同期 CBS 报道；包含平台方陈述和使用者案例）**：CBS News, 2003-08-19, “In Search Of The Past”.  
  https://www.cbsnews.com/news/in-search-of-the-past-19-08-2003/

### 可比与不可比

共同机制：

```text
school / cohort memory
→ searchable institutional index
→ new contact route
→ dormant relationship may reactivate
```

中国 2000s 的材料更突出：

- “班级”不只是索引，也是持续留言、相册和通知的共同空间；
- QQ 等即时通信账号可以和校友录相互转换/联动；
- 大学校园和中文门户竞争共同推动了大量“网上班级”。

不能据此说中国用户更“集体主义”或美国用户更“个人主义”；现有证据只支持平台结构和使用案例不同。

## 12. Internet 到底改变了什么？

把 1980s 纸质通讯录、2000s 网上同学录、2019 老 SNS 数据恢复、2020s 云聚会放在一起，可以把变化拆得更清楚。

### 12.1 Internet 没有发明校友身份

学校、届次、班级早已是社会组织和纸质通讯录中的分类方式。

### 12.2 Internet 把身份索引变成了更频繁的可执行入口

过去：

```text
找到纸本 / 找校友会 / 找旧同学中介
→ 得到一个可能已经过期的地址或电话
→ 再联系
```

后来：

```text
搜索学校 + 年级 + 班级
→ 进入持续存在的班级空间
→ 直接留言 / 加好友 / 发消息
```

### 12.3 Internet 让“关系可恢复”与“关系持续亲密”分离得更明显

一个人可能十年没和某同学说过话，但数据库仍然知道两人曾在同一班。

所以：

**`relationship addressability != relationship intimacy`**。

### 12.4 平台化又增加了新的失联方式

过去失联常常是：

- 地址变了；
- 电话停了；
- 单位换了。

平台时代还可以是：

- 忘记账号；
- 忘记密码；
- 平台关闭；
- 旧手机号无法验证；
- 数据迁移失败；
- 对方不再登录。

因此“数字化以后永不失联”同样是后见之明神话。

## 13. 证据类型与个人材料分级

本专题特别容易把“平台上能看到”误写成“关系真的存在”，因此每条材料至少区分：

1. **平台可观察事实**：平台提供学校、班级、姓名等检索；
2. **同时性自述**：某用户说自己用它联系同学；
3. **回顾性自述**：多年后说当年如何使用；
4. **交叉确认**：另一来源独立证明班级/事件存在；
5. **平台/媒体二次重构**：运营方以怀旧营销解释过去。

2008 Google Groups 邮件属于非常强的同时性操作痕迹，但仍然只能证明这个班级的做法，不能推广为所有 5460 用户。

2019 人人回归时的平台历史数据声明属于平台自述，不能和独立统计混为一谈。

## 14. 后见之明风险

### 风险 A：把网上同学录写成 Facebook/微信群的“不成熟前身”

不应该。它解决的是当时非常具体的学校身份、班级页面、留言、相册和通讯录问题。

### 风险 B：把“找到”写成“恢复关系”

搜索结果只提供入口。对方可能不回、账号可能废弃、现实关系可能已经结束。

### 风险 C：把一个幸存班级当作代表性样本

能在 2026 年仍看到完整邮件串，本身就是保存选择偏差。

### 风险 D：把今天对人人网/同学录的怀旧投射回 2004

2004 用户可能只是因为当时它最方便，而不是因为他们自觉地“保存青春记忆”。

### 风险 E：忽略隐私

同学录把过去的制度身份变成搜索键，同时也提高了旧关系和旧资料被陌生人重新找到的可能。本专题不应为了“复原完整班级”而批量复制普通个人的姓名、邮箱、账号或历史凭证。

## 15. 反例与尚未确定

### 已证实

- 1980s–1990s 中国已有纸质大学校友通讯录；
- 2004 年 ChinaRen、QQ、5460 等已经提供学校/班级检索、班级空间和账号通讯功能；
- 2005 年有毕业后分散同学借网上班级持续联系的同期采访；
- 2008 年有班级管理员用邮件创建、分发、维护 5460 班级账号的同期操作痕迹；
- 2019 年人人恢复时，旧账号/旧社交图的“找回”已成为产品和媒体叙事的一部分；
- 2020–2022 疫情期间，至少有高校班级把周年/节日聚会转移到线上，并用微信、电话、邮件等多渠道重新集合成员；
- 2025 年仍有新产品按“找校友 / 班级”定位。

### 可以合理推断

- 网上同学录降低了“毕业后只剩学校记忆、没有当前地址”时重新找人的成本；
- 班级公共页面能在个人联系坐标变化时充当较稳定的集合点；
- 维护班级空间需要实际组织劳动，活跃度不会由技术自动生成。

### 尚不知道

- ChinaRen、5460 等各时期真实的去重活跃人数和班级活跃率；
- 一次成功搜索转化为持续现实关系的概率；
- 纸质校友通讯录普通毕业生的实际持有率与使用频率；
- 2023–2026 专门“找同学”产品的真实使用规模；
- 不同阶层、城乡和年龄群在“失联以后还能否重新找到”上的分布差异；
- 多少旧关系因为平台关闭、账号回收或验证方式改变而发生了第二次数字失联。

## 16. 它改变了我们对“人怎么活着”的哪一点理解？

过去对现代迁移生活的描述很容易只有两种状态：

```text
一直联系
or
失去联系
```

这一轮增加了第三种长期状态：

```text
曾经认识
→ 多年不联系
→ 关系休眠
→ 过去共同身份仍可检索
→ 某个事件 / 聚会 / 需要帮助 / 偶然想起
→ 再次建立联系
```

也就是说，现代通信基础设施不仅改变“现在能多快说一句话”，还改变了：

> **一个已经从日常生活中消失的人，十年以后还有没有机会重新被找到。**

这是一种真实的生命历程可逆性。

它也解释了为什么旧平台消失不仅是“网页没了”：一起消失的可能还有一整套**把过去的人重新寻址到现在**的社会索引。

## 17. 与矩阵的对应

| 矩阵项 | 本轮新增 |
|---|---|
| 迁移 | 地理分散不再必然导致旧同学永久失联 |
| 通信方式 | 纸质通讯录 → Web 班级 → SNS/多通道群体通知 |
| 互联网平台 | 学校/届次/班级成为可搜索身份键 |
| 信息获取 | 从查“现在电话号码”转为查“过去共同机构身份” |
| 社交关系 | 新增“休眠后再激活”这一长期状态 |
| 线上/线下身份 | 班级、届次把线下过去映射成线上索引 |
| 平台消失与记忆保存 | 数据可存而关系可休眠；平台死后重新寻址能力也可能丢失 |
| 时代时间感 | 2005–2012 的扩张也包括“离开并不等于永远失去过去”；2020–22 冲击中旧关系网络成为可快速重新集合的资源 |
