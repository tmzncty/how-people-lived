# 从报纸征婚到可搜索的择偶池：婚恋基础设施、条件化可见性与关系形成，中国 1981—2025

## 本轮问题

仓库已有婚姻年龄、住房门槛、家庭形成、亲职选择、独居、迁移与成年顺序等专题，但还缺一个更靠前的问题：

> **一个准备寻找伴侣的人，实际能够“遇见谁”？**

婚姻是否发生，不能只用价值观、房价或平均初婚年龄解释。一个普通人首先需要一套把潜在伴侣带进可见范围的社会与信息基础设施。

这个基础设施可以是：

- 亲友介绍；
- 单位 / 学校联谊；
- 婚姻介绍所；
- 报纸征婚；
- 公园相亲角；
- 婚恋网站；
- 婚恋平台的线下活动；
- 微信群 / 社群；
- 直播间；
- 政务或公益婚恋服务。

本轮研究的核心不是“爱情观变了”，而是：

1. 陌生人怎样进入彼此的候选范围；
2. 哪些人生条件被做成公开、可比较、可筛选的字段；
3. Internet 到来后究竟改变了候选池、搜索、验证和联系中的哪一层；
4. 父母、红娘、线下见面为什么没有因为 Web 出现就消失；
5. 候选更多为什么不等于关系一定更容易形成。

- <https://github.com/tmzncty/old-web-archaeology/blob/main/research/love21cn-jiayuan-profile-search-verification-contact-relay-and-relationship-state-gaps-2003-2011.md>

## 一、Internet 以前，媒体已经能把“择偶半径”推出熟人网络

1981 年 1 月 8 日，《市场报》刊登丁乃钧的征婚启事。后来的多次采访和报刊回顾保存了这件事的基本结构：征婚人把年龄、婚姻状态、身高、职业、收入等个人信息压缩成一小块公开文字，并要求有意者通过邮政来函、附照片联系。

后来的亲历者采访称，他收到了数百封来信。

本轮不把“第一则”本身当成最重要的结论。更重要的是它展示了一种前 Internet 的社会技术：

```text
一个人的婚配候选
不再只能来自亲友 / 单位 / 邻里 / 当地介绍人
→ 个人资料被公开复制到大范围发行的报纸
→ 陌生读者通过邮政回应
→ 候选范围被发行网络扩大
```

我把这记作：

## `marriage-market reach / 择偶可达半径`

报纸和邮政已经能够扩大这个半径。

所以后来 Web 的历史新意不能写成：

> “Internet 第一次让陌生人能够找对象。”

更准确的比较应该是：

> Internet 让陌生候选的资料变得更大规模、更快更新、更容易搜索和筛选，并逐渐把回复、验证和联系也放进同一套信息系统。

### 证据

- 2008 年《重庆晨报》采访丁乃钧及当年编辑、同事，对 1981 年征婚经过作回顾：
  - https://news.sina.com.cn/o/2008-12-01/060614810050s.shtml
  - **C/B：多年后的亲历者回顾，不是 1981 年原版报纸。**
- 2009 年《环球人物》对丁乃钧的回顾性采访：
  - https://style.sina.com.cn/news/2009-10-10/101649707_2.shtml
  - **C：回顾性自述。**
- 2023 年《长沙晚报》文章转录了广告中的年龄、身高、职业、月薪、来函和照片要求：
  - https://www.icswb.com/h/106003/20230707/821669.html
  - **C：后来报刊整理。**

### 尚未取得

本轮没有取得可直接逐版核验的 1981-01-08 《市场报》第七版原始数字扫描，因此具体字数、排版和“全国第一”等标签不作为 A 级原始证据使用。

## 二、从“别人介绍一个人”到“先筛一批人”：候选开始结构化

无论是纸面征婚还是后来婚恋网站，都有一个共同动作：把一个复杂的人压缩成若干可以快速识别的字段。

1981 年的广告已经包含：

- 性别；
- 婚姻状态；
- 年龄；
- 身高；
- 工作；
- 收入；
- 联系方式 / 回应方法。

到 2000 年代婚恋网站，这套结构被数据库化。

2006 年世纪佳缘创办人龚海燕在新浪在线访谈中称，网站创办于 2003-10-08，历史域名为 `www.love21cn.com`；其“严肃婚恋”定位强调身份证明、学历证明等资料。

这使择偶出现一种新的普通动作：

```text
不是：
有人给我介绍 A → 我决定见不见

而是：
我先给出所在地 / 年龄 / 学历 / 婚姻状态等条件
→ 系统返回一批候选
→ 我再决定联系谁
```

我把它记作：

## `profiled eligibility / 条件化可见性`

一个人在成为“我可能认识的人”以前，先成为一条可以按条件进入或退出结果集的 profile。

这不代表这些条件是“真正的爱情本质”。它只说明技术系统把某些社会评价标准做成了机器可处理字段。

### 证据

- 新浪科技，2006-01-23，世纪佳缘创办人在线访谈：
  - https://tech.sina.com.cn/it/2006-01-23/1115827191.shtml
  - **A/B：同时代平台创办人陈述，可证明平台当时如何描述自身，不自动证明认证有效率或用户总体特征。**

## 三、2007 地坛案例：Web profile 可以变成纸牌、信封和现场见面

2007 年地坛庙会“相亲大会”留下了一条特别完整的跨媒介流程。

《京华时报》同期报道给出了历史 URL：

`http://www.love21cn.com/xiangqin/index.html`

用户可以先在 Web 填个人信息；资料随后在网页上显示。活动举办时，工作人员又把这些资料**打印 / 悬挂到现场**，并在资料下面放置小信封。感兴趣的人把自己的纸条投入信封，再由工作人员交给征友人。

现场还被分成：

- 硕博专场；
- “北漂”专场；
- 8 分钟交友；
- 中老年专区；
- 家长代子女参加的“老爸老妈相亲会”。

提前报名者还可以取得一个“佳缘通”号码，让别人能够联系她 / 他，而不必先知道平常使用的真实联系方式。

这说明 Internet 并没有把相亲变成纯线上关系。

真实动作可以是：

```text
Web 填资料
→ Web 浏览
→ 平台打印
→ 线下张贴
→ 纸条投递
→ 工作人员转交
→ 匿名 / 中继号码联系
→ 面对面见面
```

因此需要一个更准确的概念：

## `hybrid matchmaking infrastructure / 混合婚恋基础设施`

Web 的价值可以只是扩大报名、搜索和预筛选；真正的接触仍然经过纸、工作人员、电话和线下空间。

### 证据

- 《京华时报》，2007-02-13：
  - https://news.sina.com.cn/c/2007-02-13/035311227831s.shtml
  - **B：同时代媒体对具体操作流程、URL、票价、现场分区和“佳缘通”的报道。**
- 《京华时报》，2007-02-20，活动现场“8 分钟速配”与联系方式交换：
  - https://news.sina.com.cn/s/2007-02-20/011912348522.shtml
  - **B：同时代现场报道。**

## 四、父母和红娘没有被 Internet 淘汰：中介只是重新接入

2007 地坛活动已经专门为父母设置专区。

2019 年《中国青年报》对 1972 名单身青年的调查和采访更加清楚地显示，年轻人常常不是在“线上”和“线下”中二选一，而是在使用**渠道组合**。

一名 27 岁受访者说，自己半个月最密集时见了 6 个相亲对象，来源包括：

- 家人 / 亲戚；
- 单位同事；
- 家人在公园相亲角寻找的对象。

另一名北京事业单位 90 后受访者同时尝试：

- 家庭安排；
- 校友联谊；
- 婚恋平台；
- 平台组织的线下相亲活动。

这说明一种现代化误区必须避免：

```text
亲友 / 父母 / 红娘
    并没有简单被
平台 / 算法
    取代
```

而更像：

## `proxy-preserving modernization / 保留中介的现代化`

新的平台把更多人放进可见范围，但父母、朋友、同事、线下红娘仍继续承担：

- 初步推荐；
- 信任背书；
- 条件判断；
- 线下组织；
- 关系推进。

### 证据

- 中国青年报 / 人民网，2019-09-19：
  - https://health.people.com.cn/n1/2019/0919/c14739-31361085.html
  - 样本 1972 名单身青年；78.8% 表示注册过婚恋交友平台；同时“别人介绍对象”、社群、单位联谊、相亲角等渠道继续存在。
  - **B：同时代调查与受访者自述；不是全国概率样本。**
- 人民网，2019-10-24，对公园相亲角、父母代理、微信群和线下活动混合使用的报道：
  - https://politics.people.com.cn/n1/2019/1024/c429373-31417696.html
  - **B：同时代媒体观察。**

## 五、2005—2012 的“扩张型未来”：候选池扩大，但不是自动获得伴侣

如果把这一时期只写成“网上恋爱兴起”，会漏掉真正改变普通人行动的问题：

> **工作、学校、亲友圈以外的人，开始更容易进入自己的可执行候选范围。**

一个在大城市工作、社交圈窄、空闲时间有限的人，可以：

- 晚上浏览候选；
- 先筛年龄、城市等基本条件；
- 异步发消息；
- 再决定是否打电话 / 见面；
- 跨城市认识过去几乎没有交集的人。

这是一种 `candidate-pool expansion / 候选池扩张`。

但需要同时保留反例：

```text
候选更多 != 关系更容易形成
资料更多 != 资料一定真实
筛选更快 != 见面以后更合适
```

婚恋平台从很早开始就把“真实性”作为产品问题，恰好说明陌生候选扩张同时制造了新的信任成本。

2011 年百合网进一步把这一问题制度化为“前台匿名、后台实名”：新用户必须实名验证，旧用户有过渡期；只有验证后才能继续完整使用服务，但前台仍可保持匿名，交换认证信息需要双方授权。

这让普通人的“可见身份”第一次明显分成两层：

```text
平台后台知道我是谁
!=
陌生候选立即知道我是谁
```

### 证据

- 中国广播网，2011-12-15：
  - https://finance.cnr.cn/gs/201112/t20111215_508933705.shtml
  - **B：同时代报道。**
- 财新网，2011-12-15：
  - https://companies.caixin.com/2011-12-15/100338598.html
  - 记录身份数据与全国公民身份信息系统比对、验证结果返回手机，平台称不保留身份证号码。
  - **B：同时代财经媒体。**

## 六、2015—2019 的“拥堵型未来”：候选太少的问题开始和筛选太多并存

2019 年的受访者已经很能说明时间结构的变化。

一名天津科研工作者因为工作忙，在婚恋网站空余时间浏览，按所在地、年龄筛选候选，并明确说这样“节省了不少时间”。

另一名受访者则因为面对陌生人容易害羞，认为在线主动联系即使没有回复，也比线下被拒绝更少有面子压力。

这意味着婚恋平台处理的不只是空间距离，还有：

- 搜索时间；
- 拒绝成本；
- 第一次开口的社交压力；
- 候选排序与比较。

我把这一层写成：

## `compatibility triage / 匹配预分诊`

它不是系统替你决定“谁适合结婚”，而是让人先用少量字段和低成本接触，决定是否值得投入一次电话、一次约会或更多时间。

但与此同时，2019 年同一组调查里：

- 73.0% 受访者担心平台泄露用户信息；
- 66.7% 担心用户资料不实。

所以信息更多也产生了 `trust congestion / 信任拥堵`：人必须判断资料、照片、认证标记和对方动机是否可信。

### 证据

- 中国青年报 / 人民网，2019-09-19，渠道和筛选：
  - https://health.people.com.cn/n1/2019/0919/c14739-31361085.html
- 中国青年报 / 人民网，2019-09-19，隐私与真实性担忧：
  - https://health.people.com.cn/n1/2019/0919/c14739-31361090.html
  - **B：同时代调查与采访。**

## 七、2024：直播间把“预筛选”压缩到几分钟

2024 年《中国青年报》对婚恋直播间的现场观察显示，一名红娘可以同时让 8 名嘉宾处于同一九宫格中，反复介绍：

- 年龄；
- 籍贯；
- 工作；
- 房 / 车等条件。

规则甚至可以是：三分钟内有兴趣就进入群聊，再取得联系方式进入一对一交流；无人响应则马上换下一批。

32 岁受访者刘欣媛此前一年已经线下见过 3 名男性，后来又同时浏览多个同城相亲直播间。她描述的实际动作是：看外貌、听基本资料、感兴趣就继续聊，不感兴趣就切换另一个直播间；信息更新很快，一次判断常被压到“三五分钟”。

这不是“相亲彻底变肤浅”的证据。

它更准确地证明：

## `high-throughput candidate triage / 高吞吐候选预筛选`

候选进入 / 退出注意力的速度显著上升。

而传统红娘没有消失，反而以主播的形式重新成为界面的一部分。

### 证据

- 中国青年报 / 澎湃新闻，2024-01-30：
  - https://www.thepaper.cn/newsDetail_forward_26193207
  - **B：同期现场报道和第一人称采访。**
- 中国青年报 / 澎湃新闻，2024-01-23，对“红娘主播”及房、工作等现实条件提问：
  - https://www.thepaper.cn/newsDetail_forward_26108117
  - **B：同期报道。**

### 对“防守型未来”的谨慎解释

这组证据足以说明：2020 年代部分人的择偶动作可以更强调快速排除、条件兼容与有限时间的使用效率。

但它**不足以单独证明**“2023—2026 所有人都更悲观 / 更防守”。

本轮因此只把它作为微观时间机制：

> **当工作、住房、城市和家庭计划已经是多个并行项目时，人会使用更高吞吐的工具减少一次不合适见面的时间成本。**

宏观“防守型未来”仍需收入、住房、职业和家庭规划的一手材料共同支持。

## 八、海外对照：远程陌生人配对并非中国特有，也不始于 Web

### 法国 Minitel：1980 年代已经出现匿名远程陌生人交流

1986 年《Le Monde》报道 Minitel 的快速扩张时，明确提到 1985 年服务目录中已有约三十个“messageries”，用户可以匿名和其他使用者对话，并用于结识陌生人。

这说明：

```text
终端 + 电信网络 + 匿名账号 + 文本交互
```

在 Web 以前已经能够形成陌生人社交与约会基础设施。

来源：

- Le Monde, 1986-04-12：
  - https://www.lemonde.fr/archives/article/1986/04/12/le-phenomene-minitel-en-1985-ce-n-etait-qu-un-pari-risque-en-1986-c-est-un-succes-industriel-et-commercial_3115720_1819218.html
  - **A/B：同时代报刊。**

注意：Minitel “messageries”中包含广泛社交、成人 / 情色聊天等多种用途，不能把它们直接等同于中国 2000 年代“严肃婚恋网站”。跨国比较只比较**匿名远程陌生人接触机制**。

### 美国 Match.com：报纸 personals 被搬进可搜索 Web

1998 年《San Francisco Chronicle》对 Match.com 创办人 Gary Kremen 的采访称，他原本就常刊登报纸 personals；1994 年创办 Electric Classifieds 时，把 personal ads 当作在线分类广告概念的试验对象，Match.com 在 1995-04-21 上线。他特别强调先匿名交谈、再决定是否线下见面。

来源：

- San Francisco Chronicle, 1998-02-12：
  - https://www.sfgate.com/business/article/love-s-labor-lost-online-matchmaker-still-seeks-3013097.php
  - **B：接近创办期的创办人采访。**

这说明跨国共同变化更接近：

```text
纸质 personals / 人工介绍
→ 数字个人资料
→ 可检索候选池
→ 匿名 / 半匿名通信
→ 线下见面
```

中国的具体差异则需要单独研究，例如：

- “严肃婚恋”定位；
- 学历、婚姻状态、住房等字段的权重；
- 父母作为代理搜索者；
- 平台线下大型相亲活动；
- 身份 / 学历等认证层。

这些差异不能简单归因于“文化”。需要继续看城市、教育、住房和家庭责任的制度背景。

## 九、一个关系不是一个页面：需要记录完整状态链

婚恋基础设施最容易造成的一种统计误读是把平台注册量当成“形成关系”的数量。

更好的状态链是：

```text
profile visible
→ appears in someone’s candidate set
→ first contact
→ continued exchange
→ phone / private-channel contact
→ offline meeting
→ repeated meetings
→ relationship
→ co-residence / marriage / breakup / no further contact
```

每一段都可以中断。

2006 年同期报道曾提到世纪佳缘用户把状态改成“已找到中意人选”。这个字段最多证明：

> 用户 / 平台在某个时刻记录了“已找到中意人选”的状态。

它**不能自动换算成结婚成功率**。

这条区别对 ordinary life 很重要：

> **能找到很多人，是一种基础设施能力；能建立一段持续关系，是另一件事。**

## 十、成功反而可能让数字痕迹消失：`termination success paradox`

婚恋平台还有一个和普通 SNS 不太一样的保存偏差。

如果一个人的目标是寻找长期伴侣，那么“成功”常常意味着：

- 不再搜索；
- 不再登录；
- 隐藏 profile；
- 删除账号；
- 把交流迁到电话 / QQ / 微信；
- 最终平台失去后续关系信息。

因此可以定义：

## `termination success paradox / 退出即可能是成功`

一个历史数据库里长期保持活跃、反复更新的 profile，并不天然更能代表“成功的婚恋路径”。

反而，真正形成关系的人可能更早退出可观察系统。

这意味着以后研究婚恋平台时必须防止：

```text
存留下来的 active profiles
→ 被误当成当时所有使用者
```

平台 archive 很可能结构性高估：

- 尚未匹配者；
- 长期使用者；
- 愿意持续公开资料的人。

而低估：

- 快速退出者；
- 成功后删号者；
- 转入线下 / 私聊者；
- 因隐私顾虑从未公开注册的人。

---

## 十一、它改变了我们对“人怎么活着”的哪一点理解

以前的成年路线经常只写：

```text
工作 / 房子 / 年龄达到某状态
→ 结婚
```

现在需要在中间补一个实际执行层：

```text
我是否想找伴侣
→ 我能接触到哪些候选人
→ 谁替我介绍 / 搜索
→ 哪些条件先被公开和筛掉
→ 我如何判断资料是否可信
→ 怎样进入第一次私下接触
→ 是否愿意线下见面
→ 才可能形成关系
```

因此婚姻和家庭形成不仅有“准备条件”，还有**匹配基础设施**。

它会改变：

- 一个陌生城市里的人是否只能依赖单位 / 亲友圈；
- 异地、跨职业、跨学校的人能否互相看见；
- 父母能否替成年子女继续搜索；
- 一个内向、工作忙、社交圈小的人怎样使用零碎时间寻找候选；
- 人在见面以前要暴露多少身份、学历、住房和职业信息；
- 候选稀缺什么时候变成筛选和信任负担。

## 十二、与四种“未来时间感”的关系

### 2005—2012：扩张型未来

证据较强的是：

- 候选池跨出熟人网络和城市；
- 可以主动筛选；
- 平台与大型线下活动把陌生候选转化为可执行见面。

这与“人生菜单扩大”一致，但不意味着所有人都更乐观或婚姻更容易。

### 2015—2019：拥堵型未来

证据较强的是：

- 多渠道并行；
- 平台用于节省筛选时间；
- 真实度、诈骗和隐私成为额外判断负担；
- “候选太少”与“候选太多但难判断”并存。

### 2020—2022：偶发型未来

本轮没有找到足够强、且不与既有疫情专题重复的第一人称材料来证明疫情如何系统性改变婚恋匹配链。

**不为了填时间轴而补故事。**

后续可继续寻找：封控期间取消见面、视频相亲、异地关系暂停 / 重启等同期材料。

### 2023—2026：防守型未来

本轮能确认的是高吞吐筛选、公开条件、直播间快速切换等微观机制。

能否进一步上升为“稳定、退路、住房、现金缓冲进入择偶标准的防守化”，需要更直接的一手访谈和调查，暂不下结论。

## 十四、反例与后见之明风险

### 反例 1：更多候选可能只是更多无效候选

平台降低搜索成本，不代表降低关系建立成本。

### 反例 2：认证标记不等于信息完全真实

身份证只能验证某些身份字段，不能自动验证收入、人格、关系意图或所有生活叙述。

### 反例 3：父母介入不是“前现代残余”那么简单

2019 年互联网高度普及以后，父母代理、平台、微信群和线下相亲仍然可以组合使用。

### 反例 4：相亲直播并不证明所有关系都被“商品化”

它只证明存在一种快速、字段化、公开筛选的场景。

### 后见风险 1：不要把 1981 报纸征婚写成“原始版 Tinder”

报纸没有动态搜索、实时反馈、账号体系、过滤器或可更新 profile。

### 后见风险 2：不要把 Minitel / Match.com / 世纪佳缘当成同一个产品

可比较的是信息机制，不是社会意义完全相同。

### 后见风险 3：不要从网站存在推断普通人普遍使用

每个时期都要继续区分：注册、活跃、付费、实际联系、见面、形成关系。

## 结论

婚恋基础设施改变的，不是一个抽象的“爱情自由度”，而是一组非常实际的动作：

```text
谁能被我看见
→ 我先知道对方什么
→ 谁替我筛
→ 我怎样证明自己
→ 我怎样联系而不立刻暴露全部联系方式
→ 我愿不愿意花一次见面的时间
```

1981 年，一张报纸已经能把一个人的择偶半径推出熟人圈；2007 年，一个 Web profile 可以被打印成庙会现场的资料牌，再通过纸条和中继号码重新回到线下；2019 年，年轻人把亲友、相亲角、婚恋网站和线下活动放进同一个渠道组合；2024 年，同样的第一次筛选可以被压进直播间的三五分钟。

所以 Internet 没有发明“陌生人可以相爱”。

它更深的改变之一，是把**陌生人的可见、可筛、可验证和可联系**做成了一套日常基础设施。

而关系本身仍然要在这个基础设施之外继续发生。
