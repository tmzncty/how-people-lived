# 从配套光盘到宽带下载：离线数字媒介、带宽替代与本地可检索信息，中国 1995—2014

## 本轮问题

普通人接触数字信息，不应被写成“纸张时代 → Internet 时代”的二段论。

1990 年代中后期到 2000 年代，中国存在一个规模不小、持续时间也不短的中间层：**数字内容已经进入普通 PC，但内容本身仍通过报刊发行网、书店、光盘复制厂和邮路移动，而不是通过用户自己的网络连接传输。**

这一层包括：

- CD-ROM / DVD-ROM 电子出版物；
- 电脑杂志和报纸的配套光盘；
- 软件、浏览器、补丁、共享软件和游戏 demo 的光盘分发；
- 光盘版工具书、全文数据库和多媒体教程；
- 后来出现的“光盘版 + 网络版”并行产品。

它直接关系到两个核心问题：

1. **一个没有宽带、甚至暂时不上网的人，能不能先取得数字化内容和 Internet 软件能力？**
2. **Internet 到来以后，哪些行为真的被网络传输替代，哪些离线数字路径仍长期共存？**

这不是“怀旧光盘史”。它研究的是普通人的**信息可达性、软件可达性和数字能力取得路径**。

## 一、不要把“电子出版物”自动理解成“网络出版”

1996 年新闻出版署《电子出版物管理暂行规定》已经把软磁盘、CD-ROM、CD-I、Photo-CD、IC Card 等定义为电子出版物载体；1997 年底的新规又加入 DVD-ROM。

这说明在当时的制度语言里：

```text
电子出版物 != 网络出版物
数字内容 != 在线传输
```

电子出版物可以完全依靠物理复制和发行完成传播。

这条边界很重要，因为今天很容易把“数字化”后见式等同于“Internet 化”。

### 证据

- 新闻出版署《电子出版物管理暂行规定》，1996-03-14。
  - https://falvdb.com/law/codex/acts/364962-%E7%94%B5%E5%AD%90%E5%87%BA%E7%89%88%E7%89%A9%E7%AE%A1%E7%90%86%E6%9A%82%E8%A1%8C%E8%A7%84%E5%AE%9A
  - **A：同期制度文本。**
- 新闻出版署《电子出版物管理规定》，1997-12-30。
  - https://www.cecc.gov/resources/legal-provisions/provisions-on-the-administration-of-electronic-publications-cecc-partial
  - **A：同期制度文本的保存文本。**

## 二、1994—1997：光盘出版增长发生在大众 Internet 仍很早的阶段

1998 年 7 月《人民日报》回顾中国电子出版业时给出了一组很有用的同期统计：

- 1994 年底以前，国内正式出版的只读光盘只有约 12 种；
- 1995 年约 100 种；
- 1996 年约 300 种；
- 1997 年达到 1025 种；
- 1997 年只读光盘复制总量约 753 万张。

报道列举的产品并不只是娱乐软件，而包括：

- 多媒体百科 / 教育产品；
- 《人民日报》五十年合订本；
- 《中国学术期刊（光盘版）》；
- 图片数据库和文化类产品。

这发生在中国正式全功能接入 Internet 只有几年、家庭 Internet 尚远未普及的时候。

所以这里存在一种明确的历史状态：

```text
内容已数字化
+ 家庭 / 单位已有 PC 和光驱
+ 大容量数据通过实体介质进入机器
+ Internet 连接仍稀少、昂贵或缓慢
```

我把它记作：

## `offline digital access / 离线数字访问`

普通人可以进入数字信息世界，却不必在“读取这份内容”的同时连接任何网络。

### 证据

- 《人民日报》1998-07-29，关于我国电子出版物发展的报道。
  - https://rmrb.zhouenlai.info/%E4%BA%BA%E6%B0%91%E6%97%A5%E6%8A%A5%EF%BC%881946-2003%EF%BC%89/1998/07/1998-07-29.htm
  - **A/B：同期中央报刊；统计来源为行业主管体系，但原始统计表尚未单独取得。**

## 三、配套光盘不是“杂志附件”：它可以直接替代一次大规模下载

现在保存下来的一批 1998—2000 年电脑杂志配套光盘目录，让这一点变得非常具体。

1998 年 8 月《大众软件》配套光盘约 629 MB，里面不仅有文章和游戏内容，还有：

- Winamp 1.92；
- WebTwin 1.1a；
- 网络工具；
- 关于“因特网上的虚拟现实”的文章；
- 其他共享软件和演示程序。

其中 WebTwin 的同期说明尤其有意义：它可以把 Web HTML 转成 Windows Help 文件，也可以做类似离线浏览器的工作。

这意味着一本实体杂志可以把：

```text
网上内容的阅读方法
+ 离线网页工具
+ 网络客户端
+ 多媒体文件
+ 软件本体
```

一次性带进用户电脑。

1999 年 5 月《电脑报配套光盘》目录更直接：其中收录中文 IE 5.0、Netscape 4.51、Acrobat Reader 4.0、ICQ 99a Beta、DirectX、多个 Service Pack / 升级补丁等。

因此，一个人取得“上网能力”的动作并不一定是：

```text
已经上网 → 下载浏览器 / 客户端 → 才能更好地上网
```

也可以是：

```text
在报刊亭 / 书店买实体介质
→ 从光盘安装浏览器 / ICQ / Reader / 补丁
→ 再拨号连接 Internet
```

我把这一层写成：

## `offline acquisition of online capability / 在线能力的离线取得`

这是互联网大众化中一个很容易被 Web 中心史观漏掉的中间步骤。

### 证据

- 《大众软件》配套光盘 1998.08 的现存目录 / 镜像记录。
  - https://www.shopmsdn.com/detail-%E5%A4%A7%E4%BC%97%E8%BD%AF%E4%BB%B6%28%E9%85%8D%E5%A5%97%E5%85%89%E7%9B%98%29%281998.08%29%28%E6%80%BB%E7%AC%AC14%E6%9C%9F%29-3238.html
  - 当前页面列出 ISO 大小、SHA1 与目录。
  - **C：现代数字保存 / 目录材料；尚未取得出版方原始母盘或独立馆藏 hash 交叉确认。**
- 《电脑报配套光盘》99 年第一期要目，页面日期 1999-05-24。
  - https://software-archive.tifan.la/%E7%94%B5%E8%84%91%E6%8A%A5/1999/20/99201501.html
  - **B/C：保存的同期目录文本；站点为后来的软件档案，不等同于原始物理盘 provenance。**

### 后见风险

不能从“光盘里有 IE / ICQ”直接推出某个购买者随后一定上网。

能确认的是：**实体发行体系能够把 Internet 所需客户端和软件版本带给尚未完成在线下载的人。**

## 四、低价正版：实体介质也在改变软件取得的经济路径

1999 年 10 月中关村在线 / 《人民日报》背景的一篇同期报道讨论“红色正版风暴”，称 1998 年《电脑报配套光盘》引发的“28 元现象”影响很大；1999 年《金山词霸 2000》《金山快译 2000》等也以 28 元价格推出。

这一材料不能证明所有普通用户因此停止盗版，但它至少说明：

- 当软件主要依靠实体介质传播时，复制成本、零售价格和报刊发行渠道会直接影响“正版能否进入普通人的生活”；
- Internet 下载并不是当时唯一、甚至未必是最现实的软件获取方式；
- “信息可得”不仅取决于有没有 PC，也取决于附近能不能买到介质、机器有没有光驱、软件价格是否可承受。

因此 adoption ladder 应再细分：

```text
软件存在
→ 有实体发行
→ 本地能买到 / 借到
→ 价格可承受
→ 有兼容光驱与 OS
→ 能安装
→ 才可能进入日常使用
```

### 证据

- 中关村在线，1999-10-26，《红色正版风暴》。
  - https://news.zol.com.cn/1999/1026/671.shtml
  - **B：同期行业媒体报道。**

## 五、`bounded local corpus / 有边界的本地数字语料库`

光盘还有一个和 Web 完全不同的时间结构。

Web 的基本想象是：

```text
需要什么 → 去远端服务器查询 / 下载最新状态
```

光盘则是：

```text
先取得一份固定版本 → 内容整体留在本地 → 反复检索直到换新盘
```

1996 年底创刊的《中国学术期刊（光盘版）》是非常清楚的例子。1998 年北京师范大学图书馆工作人员已经发表文章讨论其全文检索功能和实际使用；1999 年《人民日报》又报道，其全文数据库网上检索系统已经通过教育科研网发布。

这意味着从光盘版到网络版并不是“模拟资料第一次数字化”，而是：

**同一类已经数字化、可全文检索的 corpus，从周期性实体更新转向远程网络查询。**

变化的关键之一因此是 `update latency / 更新延迟`：

- 光盘版：内容可以本地快速检索，但版本在下一批介质到达前基本冻结；
- 网络版：远程依赖更强，却可以提高更新频率并减少物理配送。

### 证据

- 贾西兰，《中国学术期刊（光盘版）的使用》，《现代图书情报技术》1998(6)。
  - https://manu44.magtech.com.cn/Jwk_infotech_wk3/CN/10.11925/infotech.1003-3513.1998.06.13
  - **A/B：同期专业实践文章。**
- 《人民日报》1999-02-27，《台学者盛赞〈中国学术期刊〉光盘版》。
  - https://cn.govopendata.com/renminribao/1999/02/27/7/
  - **B：同期报刊。**

## 六、网络起来以后，光盘没有立即消失

不能写成：

```text
拨号时代 = 光盘
宽带时代 = 下载
```

2007 年仍有面向初 / 中级普通用户和培训班的《开天辟地学电脑》Windows XP 配套光盘，教程覆盖 IE6、MSN / Messenger、拨号上网、防火墙、家庭网络等 Internet 应用。

2009 年《电脑爱好者》合订本配套介质已经升级为两张 DVD，每张约 4 GB，内容包括 2008—2009 年杂志全文检索、电子图书和教程。

与此同时，2008 年北京网通推出 8 Mbps 家庭 ADSL 时，宣传报道已经用“约十分钟可下载一张 650 MB 光盘内容”来说明速度，但该套餐月费 498 元；同一报道还提到 4 Mbps、2 Mbps、1 Mbps、512 Kbps 等不同层级以及不同开户条件。

这组材料说明更合理的转换模型是：

## `bandwidth substitution threshold / 带宽替代阈值`

只有当：

```text
接入可得
× 速度够快
× 费用可承受
× 服务器可访问
× 下载管理足够可靠
```

都逐渐成立以后，实体光盘“替用户搬运大量比特”的价值才明显下降。

而这一阈值对不同城市、家庭、学校和单位并不同时到达。

  - https://www.shopmsdn.com/detail-%E6%B4%AA%E6%81%A9-%E5%BC%80%E5%A4%A9%E8%BE%9F%E5%9C%B0%E5%AD%A6%E7%94%B5%E8%84%91-%E6%96%B0%E7%BC%96%E5%85%A8%E9%9D%A2%E6%8E%8C%E6%8F%A1WindowsXP%28%E9%85%8D%E5%A5%97%E5%85%89%E7%9B%98%29%282007%29-4343.html

## 七、这怎样修正 2005—2012 的“扩张型未来”

过去我们容易把 2005—2012 的扩张理解为：

> 网络越来越快，所以生活越来越在线。

本轮材料要求加一个限定：

**扩张期很长一段时间是“在线网络 + 离线数字介质”共同扩张。**

一个 2007—2009 年的普通 PC 用户可以同时：

- 用 ADSL / 校园网 / 网吧访问 Web；
- 从实体 DVD 学 Windows、IE 和网络应用；
- 买光盘版软件；
- 用 DVD / CD 保存巨量本地内容；
- 再把从网上取得的 ISO 挂进虚拟光驱。

也就是说，介质没有立刻消失，反而出现了一段 **physical-disc 与 network-file 两套物流互相转换** 的时期。

2009 年 DAEMON Tools 等虚拟光驱软件的同期普及材料进一步说明：

```text
physical disc → ISO image → network download → virtual disc
```

“光盘”甚至可以在实体介质衰退之后继续作为文件格式和软件分发逻辑存在。

因此不要把网络化理解为“物理格式瞬间被删除”。

## 八、海外对照：美国 1995 年，CD-ROM 对家庭电脑用户甚至比 online service 更日常

Pew / Times Mirror Center 在 1995 年对 4005 名美国受访者的调查提供了非常好的同期对照：

- 当时 online service 订户约从 500 万增长到近 1200 万；
- 约 200 万人直接连接 Internet；
- 调查中的家庭电脑用户约 48% 已有 CD-ROM drive；
- 52% 的 CD-ROM 用户至少每周使用一次；
- 受访者对 CD-ROM 的依赖评价甚至高于 online services。

这说明“数字信息先大量以本地光盘形态进入家庭，然后网络服务才逐渐接管更新和传输”并不是中国特有。

中国较值得比较的地方在于：

- 大众家庭 Internet 接入较晚且地区差异大；
- 电脑报刊与实体软件市场形成了很强的光盘分发层；
- 光盘又和盗版 / 低价正版、网吧、电脑城等本地生态缠在一起。

### 海外来源

- Pew Research Center / Times Mirror Center, *Americans Going Online…Explosive Growth, Uncertain Destinations*, 1995-10-16.
  - https://www.pewresearch.org/politics/1995/10/16/americans-going-online-explosive-growth-uncertain-destinations/
  - **A/B：同期全国性调查报告。**

## 九、这改变了“普通人怎么活着”的哪一点理解

### 1. “数字生活”并不等于“在线生活”

一个家庭可以有：

- PC；
- 光驱；
- 数字百科 / 词典；
- 软件和游戏；
- 本地全文检索；

却仍然没有持续 Internet 连接。

因此：

```text
computer ownership
!= Internet access
!= broadband access
!= digital-content access
```

最后一项可以通过完全不同的物流获得。

### 2. 网络接入不足时，物理交通可以替代通信带宽

配套光盘本质上是在做一件朴素的事情：

> 用卡车、火车、报刊发行系统和人的步行，把几百 MB 数据搬到用户家里。

从普通生活角度看，这是一种 **`physical transport as bandwidth / 物理运输充当带宽`**。

### 3. 软件环境也是一种生活基础设施

如果浏览器、Reader、DirectX、杀毒软件、聊天客户端难以从网上取得，那么“有电话线 / ISP 账号”仍不等于 Web 可执行。

报刊配套盘把软件栈带到本地，是大众 Internet 的隐形辅助基础设施。

### 4. 本地语料库改变了“找资料”的动作

纸书时代：翻目录 / 索引；

光盘时代：本地全文搜索固定版本；

网络时代：远程搜索不断变化的 corpus。

这三者的“信息新鲜度、稳定性、可搜索性、离线可用性、依赖基础设施”完全不同。

## 十、历史可见性与材料等级

本轮必须把几种材料严格分开。

### 已确认

- 1996 / 1997 制度文本明确承认 CD-ROM 等电子出版物；
- 1997 年电子出版物品种与复制量已有同期统计报道；
- 1998—1999 年电脑报刊配套盘明确包含网络软件、浏览器、ICQ、补丁、离线 Web 工具等；
- 2007—2009 年配套光盘 / DVD 仍存在；
- 2008 年家庭宽带已达到能较快传输 CD 等量数据的高端档位，但价格 / 接入层级仍有明显差异；
- 美国 1995 年家庭 PC 用户中 CD-ROM 已是高度日常的数字媒介。

### 强推断

- 对一部分用户，配套光盘显著降低了拨号下载大型客户端 / 补丁的必要性；
- 实体发行可以把 Internet 软件能力带给尚未拥有高质量网络连接的人；
- 宽带可承担大文件传输后，光盘的“带宽替代”价值逐渐下降。

### 尚未知

- 1998—2001 年中国普通 PC 家庭中，有多少人主要通过配套光盘而不是网络下载取得软件；
- 城市、县城、校园和家庭之间光驱 / 光盘购买的实际分布；
- 当前网上 ISO 收藏中的每一张镜像是否能与原始零售盘建立严格 provenance；
- 哪些旧 Web 页面、插件或客户端只在配套光盘中幸存，而 Web archive 已完全缺失。

## 十一、后续可检验问题

1. 找到 1998—2003 年电脑报刊关于“为什么把某软件放进配套盘”的编辑说明或读者来信。
2. 对一张 provenance 较强的 1998 / 1999 配套盘做文件级清单：浏览器、插件、网络客户端、HTML / HLP、URL、版本、时间戳。
3. 比较盘中保存的软件主页 URL 与现有 Web archive coverage，测试“光盘是否保存了 Web archive 没保存的软件生态”。
4. 找同时代县城 / 校园 / 家庭用户日记或论坛，确认“买盘代替下载”的真实执行频率。
5. 与美国 magazine cover disc / AOL CD、英国 PC magazine cover CD 做进一步比较，不把中国经验孤立化。

## 本轮结论

本轮新增的不是“又一种旧媒介”，而是一个会改变 Internet 大众化叙事的机制：

> **网络能力和数字内容可以通过离线物流先进入普通人的机器。**

因此，中国 1990 年代后半到 2000 年代的数字生活不能只用“联网 / 未联网”二分。

更真实的状态可能是：

```text
家里有电脑和光驱
+ 软件、百科和浏览器从报刊亭买回来
+ 偶尔拨号 / 去网吧 / 用单位网络
+ 大文件继续靠实体光盘
+ 小而新的信息开始靠 Internet
```

Internet 后来真正取代的，不只是“纸”。

它还逐步接管了一个此前由**光盘复制厂、出版社、报刊发行网、电脑城和用户书包**共同承担的数据传输层。
