# 从“没接到电话”到“声音可以等你回来”：答录、语音信箱与统一消息，中国 1991—2005

> 类型：通信前史 / ordinary-life infrastructure 研究包  
> 状态：新增机制，不把“服务存在”写成“大众普及”  
> 交叉仓库：`tmzncty/old-web-archaeology/research/voicemail-unified-messaging-webmail-audio-payload-and-cross-channel-mailbox-state-gaps-2001-2005.md`

## 0. 为什么这不是“寻呼机专题换一个名字”

仓库已经有寻呼、CFido、电话信息台、网吧、传真/打印与 Internet 接入等专题。寻呼解决的是“人离开固定电话后，怎样仍然让别人找到她”；CFido/电子邮件解决的是“文字消息怎样存储转发”；本文件问的是另一个此前没有独立建模的问题：

> **如果电话仍然以声音为主，但接听者当时不在，声音本身能不能留下来，等她以后再听？**

这会把电话从严格同步媒介，变成部分异步媒介。

所以本文件的分析单位不是“语音信箱这个产品”，而是：

- 来电发生时接听者是否必须在场；
- 声音内容存在哪里；
- 谁负责提醒“有消息”；
- 收件人在哪里、用什么终端取回；
- 留言和取回分别怎样计费；
- 本地机器、运营商网络、WebMail、短信通知怎样叠在同一通信链条上。

## 1. 先拆时间线：技术存在、服务存在、用户知道、用户会用、用户愿意用不是一回事

### 1.1 1990—1991：中国已经存在“电话自动记录留言”的技术方案，但这不能证明家庭普及

中国专利 `CN2085118U`，申请日 1990-12-23，公开日 1991-09-18，题为《一种电话自动记录留言装置》。它至少能证明：自动应答、记录来电留言这一技术对象在中国 1990 年代初已经进入可公开检索的技术文献。

来源：

- Google Patents / CN2085118U：
  https://patents.google.com/patent/CN2085118U/zh

**证据等级：A（专利元数据 / 技术存在）。**

它不能证明：

- 1991 年普通家庭可以买到或买得起；
- 城市家庭普遍安装；
- 用户形成了“有事请留言”的生活习惯；
- 运营商已经提供网络托管式 voicemail。

这里必须保持：

```text
technology exists
!= product widely sold
!= service accessible
!= household adoption
!= behavioral integration
```

### 1.2 1999—2000：移动通信资费体系已经把“语音信箱”当作可收费的新业务之一

2000-08-21《光明日报》经新浪科技刊载的通信资费报道，在介绍当时移动电话收费构成时，把“语音信箱、短消息、呼叫转移”等列为新业务收费。

来源：

- 新浪科技 / 《光明日报》，2000-08-21：
  https://tech.sina.com.cn/it/t/32975.shtml

**证据等级：B（同期媒体对运营商业务/资费的报道）。**

这里安全的结论只有：

> 到 1999—2000 前后，语音信箱已经进入移动运营商可以向普通移动电话用户提供/计费的业务菜单。

不能由此推成“手机用户普遍使用语音信箱”。

### 1.3 2002：固定电话语音信箱也已经进入普通电信资费监管范围

重庆市发展改革委今天仍保存一篇标注 2002-11-21 的同期报道，转述四川放开部分电信资费市场调节价。其中明确列出：

- 座机语音信箱业务开户费、月租费；
- 移动电话语音信箱等增值业务费用。

来源：

- 重庆市发展改革委存档《四川省开始放开34类100余种电信资费》，2002-11-21：
  https://fzggw.cq.gov.cn/zwxx/xwbd/202003/t20200319_5775331.html

**证据等级：A-content/B（政府网站保存的同期新闻报道，直接反映当年资费项目）。**

它很重要，因为它说明语音信箱不是只能装在一台家庭答录机里的功能；运营商网络已经可以把固定电话号码本身变成一个“离线也能接收内容”的邮箱地址。

## 2. 新机制一：time-shifted voice / 通话错时化

传统电话的基本约束是：

```text
A 打来
+ B 此刻在电话旁
+ B 此刻能接
= 通话成立
```

答录机或网络语音信箱插入以后，链条变成：

```text
A 打来
→ B 不在 / 没接
→ 系统播放问候语
→ A 留下完整声音
→ 系统保存
→ B 以后再取回
```

因此声音通信第一次不必严格要求双方同时在线。

本文件把它叫：

### `time-shifted voice / 通话错时化`

它和“未接来电”不同。未接来电只保存“有人来过”；语音留言可以保存**内容本身**。

它也和寻呼不同。数字寻呼常常把“请回电”交给接收者，完整交流仍然要回到同步电话；语音信箱则允许一部分消息在不回拨原呼叫者的情况下直接被理解。

---

## 3. 新机制二：message-bearing absence / 人不在，号码仍然可以收内容

对普通生活而言，一个固定电话号码原本高度依赖“家里有没有人”。

网络语音信箱改变了一件很细小但很重要的事：

> **人可以缺席，通信地址仍然保持收件能力。**

这可以称为：

### `message-bearing absence / 缺席仍可收信`

它把“电话号码”从一个只负责实时振铃的入口，逐渐变成：

```text
可被呼叫的地址
+
在本人缺席时暂存内容的地址
```

这和后来 email / IM 的“给一个不在线的人发消息”在生活逻辑上有亲缘关系，但基础设施完全不同，不能倒写成“电话早就等于 Internet”。

## 4. 2003：为什么“技术可用”仍然可能没有真正进入日常

2003-07-01，北京现代商报经新浪报道中国联通全国开通 `10158 短信听`：

- 发送者拨 10158；
- 在 30 秒内留下语音；
- 输入接收者手机号码；
- 接收者先收到一条文本短信，提示存在语音留言；
- 再拨 10158 免费收听原声；
- 发送一次按 0.1 元/条收费，接收通知与收听免费。

同一报道明确说：此前中移动和联通都曾开通过语音信箱等留言业务，但因为**发送方和接收方都收费，并按留言时间按分钟收费**，市场反应平平。

来源：

- 北京现代商报 / 新浪科技，2003-07-01，《联通开通“语音短信” 语音服务瞄准手机终端》：
  https://tech.sina.com.cn/it/t/2003-07-01/1322204317.shtml

**证据等级：B（同期行业/消费报道）。**

这条材料非常重要，因为它直接反驳：

```text
feature exists
→ users naturally adopt it
```

更准确的是：

```text
technical capability
× notification friction
× sender cost
× recipient cost
× retrieval steps
× user habit
→ behavioral integration
```

### 新机制三：cost topology / 费用拓扑

同样是一段 30 秒声音，谁付费、什么时候开始计费、收听是否再收费，会决定它在生活中是什么东西。

旧语音信箱若让双方都付费，用户可能宁可：

- 重新拨电话；
- 发短信；
- 用寻呼或秘书台；
- 什么都不留。

`10158` 的设计则尝试把成本压到发送方一次性 0.1 元，并用免费短信提醒接收方。

因此“资费”不是技术史旁边的一张价格表，而是通信行为本身的一部分。

## 5. 新机制四：notification–retrieval split / 通知和取回是两套动作

语音信箱有一个容易被今天智能手机经验遮住的问题：

> 系统把声音保存下来以后，收件人怎么知道自己应该去听？

2003 年 `10158` 把这件事显式拆成：

```text
语音内容：存放在语音系统

通知：通过短信到手机

取回：用户再拨 10158
```

所以一次“收到语音”实际可能跨越三种通信状态。

这可以称为：

### `notification–retrieval split / 通知—取回分离`

它也是理解后来 email 新邮件提醒、短信验证码、App push、未读红点等机制的一个前史：

**内容所在的系统，未必也是告诉你“有内容”的系统。**

## 6. 2004 西安：服务可以已经“在你号码上”，但用户甚至不知道

2004-04-28《北京青年报》报道，西安电信在大量家用固定电话和小灵通上开通“免费”语音信箱后，引发消费者不满。

报道记录：

- 一些市民发现来电振铃数次后被转入语音提示；
- 记者咨询后才知道可拨 `96809` 查询留言；
- 记者实测发现一天已有 9 个未接来电留下号码；
- 多名市民争议的焦点包括未充分告知、不会使用、主叫端可能产生费用；
- 电信方面解释，系统升级后的初衷是避免用户因未接电话漏掉重要信息。

来源：

- 《北京青年报》/ 新浪新闻，2004-04-28，《“免费”语音信箱 暗设收费陷阱》：
  https://news.sina.com.cn/c/2004-04-28/06502419649s.shtml

**证据等级：B（同期消费报道；含记者实测、运营方回应与普通用户意见）。**

这条材料新增一个非常重要的区分：

```text
service provisioned
!= user informed
!= user understands retrieval
!= user intends to use
!= user values the service
```

### `provisioned-but-unowned practice / 已配置但未成为“我的用法”`

技术系统可以把一个功能自动挂在号码上，但它并不会因此自动成为用户生活中的习惯。

这比“有没有覆盖”更接近真实生活史。

## 7. 2001：电话、电子邮件、传真和 Web 开始共享同一个消息后台

2005 年 DOIT 保存的一份中国电信 IDC 项目案例称：项目签订时间为 **2001 年 5 月**，在北京、上海、广州、西安部署 UMS（Unified Message Service，统一消息服务）系统。

案例描述的系统在大容量邮件基础上增加：

- 邮件管理；
- 语音邮件；
- 传真邮件；
- 邮件通知。

其中语音邮件可通过：

- 电话；
- WebMail；
- POP/IMAP 邮件客户端；
- TTS（文本转语音）

进行存取；系统还支持邮件转传真、传真转邮件。

来源：

- DOIT，2005-04-05，《中国电信IDC项目UMS统一消息服务系统案例分析》：
  https://www.doit.com.cn/p/17152.html

**证据等级：B/C 边界（2005 厂商/项目案例回述 2001 项目；强于纯回忆，但不是 2001 用户现场记录，也不能证明大众使用规模）。**

这给出了一条非常重要、也最适合和 old-web-archaeology 交叉的历史状态：

```text
同一“消息”后台
← 电话
← WebMail
← POP/IMAP
← 传真
← 文本转语音
```

### 新机制五：cross-channel mailbox / 跨渠道邮箱

Internet 并不是在这里“把电话替换掉”。

相反，一段时间内技术演化方向是：

> **让电话、Web、电子邮件和传真都成为同一个 mailbox 的不同入口。**

用户可以在一种媒介上产生消息，在另一种媒介上取回。

这比“电话时代 → Internet 时代”的两段论更准确。

## 8. 海外对照：本地答录机先把异步语音做成一个家庭物件

### 8.1 美国，1980：留言先存在家里的机器里

Smithsonian National Museum of American History 保存一台 1980 年的 `AutoMatic TelePhone`：

- 电话与 answering machine 合一；
- 可保存约 20 分钟录音；
- 更高级型号支持用户从任意电话用音调发生器远程激活并取回留言。

来源：

- Smithsonian NMAH, Telephone Answering Machine, 1980：
  https://americanhistory.si.edu/collections/object/nmah_1299450

**证据等级：A（博物馆实物）。**

这给出了一条和运营商语音信箱不同的基础设施路径：

```text
电话线
→ 家庭自己的机器
→ 本地磁带保存
→ 用户回家听 / 远程拨回机器听
```

### 8.2 1981：普通人的真实留言也留下了档案

Smithsonian Archives of American Art 保存 Jan Butterfield 约 1981 年的 telephone answering machine messages：

- 1 盘模拟录音带；
- 约 1 小时 20 分；
- 内容包括不同熟人留下的电话留言和通话。

来源：

- Archives of American Art, `Telephone answering machine messages, circa 1981`：
  https://www.aaa.si.edu/collections/items/detail/telephone-answering-machine-messages-14295

**证据等级：A（真实历史消息 artifact）。**

这比产品广告更强：它证明机器不只是能工作，而确实被人用来把“我现在不在”转化成可延迟处理的社交消息。

### 8.3 1982：行为习惯并没有自动跟上机器

Smithsonian 另一台约 1982 年的 Code-a-Phone 1100 说明写得非常直接：有些来电者不喜欢“对着机器说话”，听到自动问候语就挂断；厂商甚至销售幽默提示语手册，希望降低这种抵触。

来源：

- Smithsonian NMAH, Code-a-Phone 1100, ca. 1982：
  https://americanhistory.si.edu/collections/object/nmah_1299447

**证据等级：A/B（博物馆实物说明所保存的产品/使用史）。**

因此海外对照也支持：

> 技术让异步语音成为可能，不意味着人会立刻觉得“给机器留言”自然。

## 9. 中国与海外：当前证据能比较什么，不能比较什么

### 能比较的共同机制

1. **同步电话可以被改造成异步消息媒介。**
2. **消息保存位置可以从本地机器迁到网络后台。**
3. **远程取回让“家里的电话”不再要求人真的回家。**
4. **用户习惯、费用和通知方式会决定服务是否真正进入生活。**

### 当前不能安全下的结论

本轮海外一手 artifact 很容易找到，而中国 1980s–1990s 家庭答录机的同时代个人材料很弱；中国这轮最硬的证据反而集中在运营商网络语音信箱、资费和 2000s 用户投诉。

因此只能说：

> **本轮可见的中国证据更偏运营商托管路径，美国可见 artifact 更清楚地展示家庭设备路径。**

不能由“搜索到什么”直接推成：

- 中国家庭答录机一定很少；
- 美国人普遍比中国人更早使用 voicemail；
- 中国只存在网络托管、没有家庭设备。

这正是历史可见性偏差的一部分。

## 10. 它改变了我们怎样理解“人怎么活着”

### 10.1 通信时间不再只有“现在接不接”

有了留言以后：

```text
来电时刻
!= 获得内容时刻
!= 回复时刻
```

一个人可以：

- 白天不在家；
- 晚上回来集中听留言；
- 再决定哪些需要回拨。

这是一种非常早的“消息队列化”的日常生活。

### 10.2 “可联系”开始不等于“随时能实时说话”

寻呼已经让人移动中可被找到；语音信箱又进一步让：

```text
暂时不可实时接通
!= 通信内容完全丢失
```

因此“可达性”应该拆成：

- 此刻能否振铃到；
- 此刻能否实时通话；
- 对方能否留下完整内容；
- 本人何时知道有内容；
- 本人何时能取回；
- 本人何时能回复。

### 10.3 异步通信并不是 Internet 独有

1994 年以前、或者一个普通人尚未上网时，社会已经存在多种异步机制：

- 邮政；
- 电报；
- 传真；
- 寻呼留言；
- 答录机；
- 运营商语音信箱；
- BBS/Fido 存储转发。

Internet 的到来改变的是这些机制的成本、可搜索性、可复制性、跨媒体整合和规模，不应把“异步”本身误写成 Web 发明。

## 11. 和 2005–2012“扩张型未来”的关系：不要倒写成必然胜出的技术树

2001—2004 的材料显示，当时技术公司和运营商仍认真投资：

- voicemail；
- voice SMS；
- unified messaging；
- faxmail；
- TTS；
- WebMail / POP / IMAP；
- 手机短信通知。

今天看，这些功能后来大量被短信、即时通信、智能手机 App、可视化语音信箱或云通信吸收，很容易产生一种后见之明：

> “那些不过是智能手机出现前的临时过渡。”

本文件不采用这种写法。

2001 年的人看到的是多条仍在竞争的未来：

```text
电话继续增强
vs
邮件统一消息
vs
短信
vs
移动数据
vs
Web
```

谁会成为主界面，当时并没有今天这么明显。

## 12. 重点矩阵影响

| 矩阵维度 | 本轮新增 |
|---|---|
| 通信方式 | 同步电话 → 本地答录 / 网络语音信箱 → 短信通知取回 → 统一消息 |
| 信息获取 | 收件不再要求本人实时在场；内容与通知可分离 |
| 社交关系 | 可以给“缺席的人”留下完整声音，而不是只能等待/重拨 |
| 工作与照护 | 联系窗口可以跨越临时离岗，但是否可靠取决于提醒/取回习惯 |
| 制度接口 | 运营商 provisioning、资费、默认开通与取消流程进入日常 |
| 线上/线下身份 | 电话号码逐渐兼具实时地址与 mailbox 地址 |
| 历史可见性 | 留言内容高度私人且易消失；资费/产品说明比真实收听行为更容易留下 |
| 平台消失与记忆保存 | 本地磁带偶尔能留下真实声音；网络 mailbox 状态通常不会被 Web 档案保存 |
| 未来预期 | 2001 前后“统一所有消息渠道”是一个真实技术未来，不应被后来的 App 结果倒写 |

## 13. 证据纪律：本轮明确区分的层级

### A：原始/直接 artifact

- 1990/1991 中国自动记录留言装置专利；
- Smithsonian 1980 / 1982 answering-machine 实物；
- Smithsonian 1981 真实留言磁带。

### B：同时代制度 / 媒体 / 用户材料

- 2000 前后移动语音信箱资费报道；
- 2002 电信资费放开材料；
- 2003 `10158` 语音短信及对旧 voicemail 市场反应的同期报道；

## 14. 后见之明风险

1. **不要把 voicemail 写成“必然通向微信语音”。** 这是完全不同的网络、终端和社会习惯。
2. **不要把运营商开通写成用户主动采用。** 2004 西安正好证明两者可能相反。
3. **不要把“收费平平”扩大成“没人使用”。** 同期报道只支持市场反应弱，不给出全国 penetration。
4. **不要把 UMS 项目部署写成家庭大众服务。** 它证明架构和运营商投资，不证明普通用户规模。
5. **不要因为美国实物更好找，就推断中国没有家庭答录机。** 搜索可见性本身有偏差。
6. **不要把异步消息归功于 Internet。** 邮政、寻呼、答录和网络 voicemail 都提供了不同形式的时间解耦。

## 15. 仍未解决的问题

- 1990s 中国家庭/办公室答录机到底有多普及？目前缺同期销售量和家庭调查。
- 哪些城市/运营商最早提供固定电话网络语音信箱？
- 早期移动 voicemail 的具体号码、保留时长、取回费用如何随地区变化？
- 有无 1998–2004 普通用户在 BBS/博客里讨论“懒得听语音信箱”“漏听留言”“习惯留言”的第一人称材料？
- 中国电信 2001 UMS 是否存在可恢复的公众 WebMail 前端、帮助页、用户手册或历史域名？
- 网络语音留言的 retention / 自动删除规则是否留下同期操作手册？

下一轮如果继续这条线，应优先补**普通用户同时性自述**和**可核验历史 Web artifact**，而不是再造一个“统一通信改变生活”的同义专题。

## 16. 本轮阶段饱和判断

本轮新增的是此前仓库没有独立覆盖的通信转折机制：

- `time-shifted voice / 通话错时化`；
- `message-bearing absence / 缺席仍可收信`；
- `cost topology / 费用拓扑`；
- `notification–retrieval split / 通知—取回分离`；
- `cross-channel mailbox / 跨渠道邮箱`。

它们会改变对“Internet 以前普通人是否只能同步通信”和“电话 → Internet 是否线性替代”的理解。

因此本轮**不计入连续无新增运行**；阶段饱和计数保持 / 重置为 **0/3**。
