# 从 114 查号到本地平台搜索：服务可寻址性、可发现性与排序，中国 1982–2025

> 状态：研究包 / source note
>
> 主题：信息获取、日常服务、电话目录、114、电子黄页、本地搜索、平台排序、疫情中的实时可用性、AI 推荐
>
> 核心问题：一个普通人需要搬家、开锁、找餐馆、订票、找商家或联系某个机构时，怎样从“这个服务存在”走到“我知道该联系谁，而且现在真的能联系到”？
>
> 本条目不研究某一家搜索公司的商业史本身，而研究**服务发现怎样成为普通生活可执行性的基础设施**。

---

## 0. 为什么这是一个独立问题

仓库已经有远距离通信、寻呼、公用电话、分类信息、二手交易、就医预约、交通预订等专题，但它们往往从“已经知道要联系谁/去哪里”开始。

现实生活里还存在更前面的一步：

```text
我需要一项服务
→ 哪些提供者存在？
→ 我怎样找到它们？
→ 我怎样判断哪个可以用？
→ 我怎样取得联系方式/地址？
→ 我怎样实际联系并获得服务？
```

因此本条目区分至少五层：

1. **service existence**：某家店、某个机构、某项服务实际存在；
2. **addressability**：这个实体是否有公开地址/电话号码等可联系坐标；
3. **directory visibility**：它是否进入普通人能查询的目录/数据库；
4. **discoverability**：一个不知道具体名称、只知道需求的人，能否找到候选者；
5. **operational availability**：找到以后，它此刻是否营业、能否送达、能否真正完成服务。

最重要的不等式是：

**`service existence != service discoverability`**

一家店可以真实存在，也可以有电话，却仍然对一个普通人“不可见”。

## 1. Internet 以前：查号已经是一种远程信息检索

### 1.1 1982 的 114：先知道名字，再找号码

中国电信 114 四十周年相关回顾材料称，1982 年邮电部正式要求市话查号台 114 面向社会公众和企业提供查号服务；1990 年代以后又逐步增加搬场、开锁、家政等延伸信息。

来源：

- 金羊网，2022-05-17，《数字化、适老化升级 中国电信114借科技力量打造综合信息平台》：https://3c.ycwb.com/2022-05/17/content_40780624.htm

证据等级：**C/B，谨慎使用**。

理由：这是四十周年回顾而非 1982 原始文件。本轮没有取得邮电部 1982 通知原件，因此只用来建立 chronology lead，不把其中所有细节升级为 A 级。

查号台解决的原始问题通常是：

```text
我知道单位/商家叫什么
→ 但不知道电话号码
→ 话务员替我查目录
→ 我得到一个可以继续行动的号码
```

本条目把这种能力称为：

**`service addressability / 服务可寻址性`**。

它已经是一种远程信息服务，而且不要求 Internet，也不要求个人计算机。

更重要的是，它也不严格要求**家庭拥有电话**：理论上，一个没有住宅电话的人只要能够使用单位电话、邻居电话、公用电话或其他可拨 114 的电话，就可能使用查号服务。

但本轮没有找到足够好的分时期资料去量化“没有家庭电话但实际通过公共/单位电话使用 114”的比例，因此只能把它写成可执行路径，不能写成人群频率。

## 2. 纸黄页：已经可以按“行业”找，而不只是按名字找

### 2.1 上海 1987：纸质黄页把商家按类别组织起来

2001 年《21世纪经济报道》同期采访称，上海市电话号簿公司从 **1987 年底**开始出版黄页号簿。2001 年，该公司甚至向上海 28 所大学宿舍免费赠送 5 万多本《上海黄页》，试图培养大学生使用黄页的习惯。

同一篇报道也给出了非常重要的采用反例：公司承认，调查中超过 30% 的受访者平常根本不用黄页；报道转述的调查称，上海人平均大约每月使用一次。

来源：

- 《21世纪经济报道》，2001-06-06（新浪保存）：https://tech.sina.com.cn/it/t/69995.shtml

证据等级：**B，高置信**（同期行业采访）。

这说明：

**`directory availability != routine directory use`**

一本电话簿已经被送进宿舍，并不等于它已经进入每个人的日常信息习惯。

### 2.2 从“查一个已知名字”到“按需求浏览候选者”

黄页按行业/产品分类的意义在于，它不再要求用户事先知道商家的准确名字。

用户可以从：

```text
“上海某某搬家公司电话号码是多少？”
```

变成：

```text
“我需要搬家公司，附近有哪些？”
```

这是一种比 addressability 更强的能力：

**`service discoverability / 服务可发现性`**。

普通生活中，“知道一个实体的联系方式”和“从一个需求找到可能的实体”是两个不同的信息问题。

## 3. 1996–1998：企业可以在 Web 上“可见”，却不需要自己拥有网站

### 3.1 ChinaBIG 的关键意义不是“很多企业开始建网站”

1997 年《South China Morning Post》同期报道，中国大黄页 ChinaBIG 已经作为 Internet-based directory 提供约 200 万企业的电话、地址等信息；报道直接给出历史 URL：

- `www.chinabig.com`

1998 年 WIRED 的同期报道同样称 ChinaBIG 有约 200 万 business listings，并指出当时中国活跃 Web sites 仍然少得多。

来源：

- South China Morning Post, 1997-10-28, *Mainland guide lists two million phone numbers, addresses and e-mails*：https://www.scmp.com/article/216823/mainland-guide-lists-two-million-phone-numbers-addresses-and-e-mails
- WIRED, 1998-03-01, *China, Big Time*：https://www.wired.com/1998/03/neweconomy-9/

证据等级：**B，高置信**（两组独立同期媒体）。

因此必须严格区分：

**`business visible on the Web != business itself using the Web`**

一个没有自己网站、甚至内部没有 Internet 接入的企业，也可能因为电话数据库、工商数据、销售人员采集或第三方目录发布，而出现在 Web 搜索页面里。

这给早期 Internet 普及史增加了一条非常重要的中间状态：

> 普通人可能先通过 Internet 获得**关于未联网实体的信息**，而不是只和“已经上网的人/企业”发生联系。

### 3.2 目录数据本身也有生产劳动

2001 年《经济观察报》对联通黄页的同期报道回顾称，中华大黄页的电子项目始于 1996–1997；在大陆获取号码资源并不顺利，早期一部分信息甚至要由销售人员“扫街”采集。

来源：

- 《经济观察报》，2001-06-19（新浪保存）：https://tech.sina.com.cn/it/t/72064.shtml

证据等级：**B，中高置信**。

这提醒我们：电子目录不是“网络自己知道了所有商家”。它背后仍然可能有：

- 电信用户数据；
- 工商/机构数据；
- 企业主动登记；
- 广告销售；
- 人工核对；
- 销售人员实地收集。

因此数据库覆盖范围本身就是一种基础设施能力。

## 4. 2001–2004：不是“纸黄页被网站替代”，而是同一目录变成多入口

2001 年上海黄页同期材料称，它已经建立：

- 网上黄页；
- WAP 黄页；
- 呼叫中心；
- 纸质黄页。

来源：

- 《21世纪经济报道》，2001-06-06（新浪保存）：https://tech.sina.com.cn/it/t/69995.shtml

2004 年，中国电信又推出“短信版黄页”：手机用户把查询请求发送到特定代码，就可以查询上海、北京等 10 个城市的公司地址和电话号码，也可以由电话号码反查公司名称；报道说该服务依托中国电信黄页号码资源数据库。

来源：

- 《北京现代商报》，2004-07-01（新浪保存）：https://tech.sina.com.cn/it/t/2004-07-01/1514382127.shtml

证据等级：**B，高置信**。

因此历史真实更接近：

```text
同一类 directory corpus
→ 纸质书
→ 电话话务员
→ Web
→ WAP
→ SMS
```

而不是一条简单的：

```text
纸黄页 → Web（旧媒介消失）
```

这也意味着**服务可及性和家庭设备拥有必须继续分开**。

一个没有 PC 的人仍可能通过电话或短信使用数字数据库；一个已经上网的人也可能因为打电话更方便而继续使用 114。

## 5. 2006：真正的转折是 `lookup → discovery`

2006 年同期报道中，中国电信工作人员用一个非常生活化的例子解释“号码百事通”：

> 想吃饭，只知道想吃什么，却不知道餐厅名字。

于是 114 不再只做精确报号，而开始做“模糊查询”。广州从 1998 年起已经给企业录入包含地址、业务、联系方式甚至网址的“语音名片”；成都从 2004 年起又把餐馆按口味、价位等整理，能告诉用户怎样到达。

来源：

- 《今日早报》，2006-05-17（新浪保存）：https://news.sina.cn/sa/2006-05-17/detail-ikkntiam7065191.d.html
- 新华社，2006-03-06（新浪保存）：https://news.sina.com.cn/c/2006-03-07/08538379589s.shtml

证据等级：**B，高置信**。

这次真正改变普通生活的，不是把一个电话号码“数字化”，而是把问题从：

```text
我知道商家是谁，只差号码
```

变成：

```text
我只有需求，不知道商家是谁
```

本条目把这一变化写成：

**`lookup → discovery / 从查找已知对象到发现未知候选`**。

### 5.1 人类话务员是早期的“自然语言查询接口”

这一阶段，用户不需要学关键词语法，也不需要操作浏览器。

用户说：

- “附近有什么川菜？”
- “我要找搬家公司。”
- “这附近有没有便宜一点的饭店？”
- “从这里怎么去？”

话务员把口语需求转换成数据库类别、地点、价格等条件，再读出结果、转接电话或把结果发成短信。

因此可以把这种劳动称为：

**`operator-mediated search / 话务员中介搜索`**。

Internet 搜索引擎并不是普通人第一次把自然语言需求交给某种远程信息系统；电话时代已经有一层人类“query compiler”。

## 6. 目录不是世界本身：2005–2006 的运营商分裂让“存在的店”在 114 里消失

2006 年《齐鲁晚报》报道，山东固定电话市场有网通、铁通、电信等不同网络后，网通掌握的 114 无法直接提供部分铁通、电信号码；一些真实营业的酒楼、公司因此在 114 中“查无此单位”。当地甚至出现三个不同查号台。

来源：

- 《齐鲁晚报》，2006-03-20（新浪保存）：https://news.sina.com.cn/c/2006-03-20/07538480130s.shtml
- 《信息时报》，2005-08-30（新浪保存，广东跨运营商登记争议）：https://tech.sina.com.cn/t/2005-08-30/0717706378.shtml

证据等级：**B，高置信**。

这里可以得到一个非常重要的不等式：

**`phone number exists != number visible in the directory you use`**

对普通人而言，信息基础设施的数据库边界可以直接改变城市生活的“可见地图”。

商家没有搬走，电话号码也没有消失，但如果它从最常用的查询系统里掉出去，它的**实际可发现性**就会下降。

## 7. 2007：当发现机制可以收费，“哪个答案先出现”成为生活问题

2007 年《南方周末》的同期调查提供了一条非常重要的第一人称材料。

一名上海白领替公司订机票时，先拨 114 查询平常使用的售票处；话务员称没有找到，并把她转到“号码百事通机票订购中心”。她订到的机票每张约 1967 元，后来发现邻座旅客约 1200 元；进一步追查才发现，被优先转接的并不是中国电信直属售票机构，而是购买了“优先报号”服务的代理商。

同一报道记录，各地已经拍卖或出售“优先报号权”：当用户只说“找一家开锁公司”“找机票代理”等模糊需求时，付费商家可能首先被报出。

来源：

- 《南方周末》，2007-11-22（搜狐保存）：https://business.sohu.com/20071122/n253422378.shtml

证据等级：**B，第一人称同期媒体转述；高置信于“该案例被当时媒体如此记录”，不能外推所有 114 查询。**

为了隐私最小化，本研究包不重复普通受访者姓名。

这一材料说明，服务发现基础设施从来不只是“中立地告诉你城市里有什么”。

它还会决定：

**`which candidate is surfaced first / 哪个候选最先被看见`**。

于是历史上很早就出现：

```text
可发现性
→ 排序
→ 商业化优先级
→ 用户信任
→ 实际消费选择
```

这和后来搜索广告、平台榜单、推荐算法的问题存在结构连续性，但不能后见式说“114 就是现代算法推荐”。

区别很重要：2007 的关键中介仍是电话、人工话务员和电信数据库。

## 8. 对 2005–2012“扩张型未来”的修正：城市变大以后，信息系统让陌生城市更可执行

2005–2012 的扩张不只意味着：

- 更多人跨城工作；
- 服务业更多；
- 手机上网和宽带增加。

还意味着一个人在陌生城区遇到需求时，不必事先拥有完整的本地熟人网络。

```text
不知道饭店名字
不知道搬家公司名字
不知道订票点
不知道具体路线
```

不再必然等于“只能问身边熟人或碰运气”。

电话 114、黄页、Web、WAP、SMS 和后来的地图/点评平台共同降低了**陌生地方的信息进入成本**。

因此，本地信息检索也是迁移和城市流动的隐性基础设施。

## 9. 2015–2019：从“谁存在”进入“大家觉得谁好”与“朋友去过哪里”

2019 年微信在广州测试“附近的餐厅”时，早先的“附近小程序—美食”入口主要展示地址、营业时间、商家电话、门店图片；新入口则进一步加入附近餐厅列表、朋友“想去/去过”、印象、推荐等社会信息。

来源：

- 36氪，2019-01-04（搜狐保存）：https://www.sohu.com/a/286602321_114778
- IT之家，2019-01-07（转述微信官方发布）：https://www.ithome.com/0/404/296.htm

证据等级：**B，中高置信**。

这对应一个新的 discovery stack：

```text
商家存在
→ 有地址/电话
→ 可按距离找到
→ 有用户评价/照片
→ 有朋友社会证明
→ 有排序/榜单
```

所以到“拥堵型未来”阶段，普通人的问题越来越不是“完全找不到候选”，而是：

**候选太多，我应该信哪个排序、哪个评分、哪个朋友、哪个平台？**

## 10. 2020–2022：危机把问题从 `discoverability` 推到 `operational availability`

2022 年上海封控中的社区团购材料非常适合说明这一点。

《每日经济新闻》采访的一名社区团长说，她加入了二十多个供货群，需要筛选能够提供合规证明、满足居民需求、实际可以供货和配送的供应商；人民网的“团长”采访同样记录了居民通过公众号、街道、团长群和朋友渠道寻找货源，再继续确认价格、运输、通行证明和交付。

来源：

- 每日经济新闻，2022-04-14：https://www.nbd.com.cn/articles/2022-04-14/2218833.html
- 人民网上海频道，2022-04-15：http://sh.people.com.cn/n2/2022/0415/c134768-35224743.html

证据等级：**B，同时代第一人称/现场采访；不能外推整个上海或全部疫情生活。**

危机中的信息问题已经不是：

```text
这家超市/供应商存在吗？
```

而是：

```text
它今天还能不能出货？
它能不能进入这个小区？
它有没有通行和防疫条件？
最低起订量是多少？
什么时候能送到？
```

因此本条目增加第三层：

**`operational availability / 实时运行可用性`**。

2020–2022 的“偶发型未来”在这里表现为：**过去稳定的目录信息突然不足以支持计划，普通人需要不断确认“这个服务现在还运行吗”。**

## 11. 2023–2025：从信息稀缺走向“选择压缩”

2024 年 36氪采访一名在杭州工作的年轻消费者。她说，和家人朋友约饭时，即使有大量高分餐厅和各种推荐，仍然觉得推荐千篇一律，不知道到哪里寻找更多合适选择。

来源：

- 36氪，2024-10-23（新浪保存）：https://finance.sina.com.cn/tech/roll/2024-10-23/doc-inctpzxs0549095.shtml

2025 年《中国经营报》采访一名美食爱好者体验 AI 餐饮推荐后，她把变化概括为“不用再翻三小时点评”，说明对部分用户而言，新的信息成本已经不是“有没有目录”，而是需要在海量评价中做筛选。

来源：

- 中国经营报，2025-07-05（东方财富保存）：https://finance.eastmoney.com/a/202507053448896346.html

证据等级：**B，存在性个案，不外推青年总体。**

这可以暂时称为：

**`decision compression / 决策压缩`**。

历史问题从：

```text
我不知道任何一家
```

逐渐移动到：

```text
我知道几十家，但没有精力逐个判断
```

这和 2023–2026 的“防守型未来”存在一个值得继续检验的连接：当时间、现金和试错预算都需要保留时，人会更重视“尽快得到一个足够可靠的答案”。

但目前证据只能证明这种逻辑存在，**不能把它直接概括成这一代人的总体心理**。

## 12. 海外对照：法国 Minitel 说明“数字本地检索”远早于 Web

法国是非常好的对照，因为它把电话目录直接做成了大众数据网络的起点。

1987 年 Jean-Marie Charon 对法国 videotex 的同期研究指出，Ille-et-Vilaine 的主要 Minitel 试点最初只提供 **Electronic Telephone Directory**；Minitel 是接普通电话插口的终端。

1995 年关于 Teletel 的学术研究又记录，当时法国已有约 650 万台 Minitel，约 20% 家庭和约 80% 企业至少有一台，电子电话簿与约 25,000 种其他信息/通信/商业服务共同存在。

来源：

- Jean-Marie Charon, 1987, *Videotex: from interaction to communication*, Media, Culture & Society：https://journals.sagepub.com/doi/10.1177/016344387009003004
- Charles Steinfield et al., 1995, *The Impact Of Interorganizational Networks On Buyer-Seller Relationships*, Journal of Computer-Mediated Communication：https://onlinelibrary.wiley.com/doi/full/10.1111/j.1083-6101.1995.tb00168.x
- Washington Post, 1987-05-31, *Communication With a French Twist*：https://www.washingtonpost.com/archive/lifestyle/magazine/1987/05/31/communication-with-a-french-twist/22716faa-5335-4fcf-81cf-d8ba31a0f0db/

证据等级：**B/A-（同期学术研究与同期媒体）**。

跨国共同机制是：

> 把电话目录数字化、远程可查询，本身就可以成为大众网络服务的重要入口，不需要先等 World Wide Web 普及。

但中国与法国的用户接口并不相同：

- 法国大量家庭/企业得到专用 Minitel 终端，用户自己在屏幕上查询；
- 中国 114 很长时间保留人工话务员这一层，让只会打电话的人也能把口语需求提交给数据库；
- 中国 1990s–2000s 又把同类目录数据逐步暴露给 Web、WAP、SMS。

因此“数字搜索”不应该被写成一个只属于浏览器和搜索引擎的故事。

## 13. 新的生活史模型

这次材料允许把“找服务”拆成五次历史变化：

```text
熟人询问 / 纸面广告
↓
已知名字 → 查号码（addressability）
↓
按行业/需求 → 找候选（discoverability）
↓
评价/排名/付费优先 → 选择候选（selection）
↓
实时营业/库存/配送 → 判断现在是否可用（operational availability）
↓
AI/榜单/朋友图谱 → 压缩过量选择（decision compression）
```

这些阶段不是整齐替代关系；纸黄页、电话、Web、短信、地图、点评和人工客服可以长期共存。

## 14. 它改变了我们对“普通人怎么活着”的哪一点理解

以前很容易把城市现代化理解成“店更多、交通更好、网络更快”。

这批证据增加了另一层：

**城市机会只有在普通人能够发现、识别并联系它时，才真正进入她的生活菜单。**

这对以下生活路径都重要：

- 初到陌生城市的迁移者；
- 没有本地熟人网络的人；
- 临时需要维修、搬家、订票、就医、餐饮的人；
- 在危机中需要找到“现在仍可运行”供应商的人；
- 面对过量评价、榜单和推荐，希望减少决策成本的人。

因此“信息获取”不是消费史的附属问题，而是普通生活的**执行层基础设施**。

## 15. 反例、后见风险与边界

### 15.1 不要把 114 浪漫化成中立公共搜索引擎

2005–2007 的跨运营商号码缺失和付费优先报号都说明，目录覆盖、排序和商业利益会改变答案。

### 15.2 不要把“Web 上有 200 万企业记录”写成“200 万企业已经上网”

第三方目录可以把完全没有网站的实体做成 Web-visible record。

### 15.3 不要把法国 Minitel 等同于 Internet

Minitel/Teletel 是自己的终端和网络体系；它能证明大众电子检索和在线服务可以早于 Web，而不是证明 1980s 法国家庭已经在使用今天意义上的 Internet。

### 15.4 不要从一个 2025 AI 使用者外推“所有年轻人都厌倦搜索”

它只证明 decision-overload/decision-compression 作为一种体验真实存在。

### 15.5 平台上的高排名不等于服务质量更高

2007 的“优先报号”正好是反例。排序是信息制度的一部分，而不是现实质量的透明镜子。

## 16. 证据等级小结

- **A**：本轮没有取得 1980s 114 原始业务文件；纸质《中国电话号簿》1996 起的馆藏书目可由日本国立国会图书馆确认，但不直接证明普通人使用频率。
- **B**：1997 SCMP、1998 WIRED、2001 黄页行业采访、2004 短信黄页、2005–2007 114 同期报道、2019 平台功能报道、2022/2024/2025 同期人物采访。
- **C**：2022 的 114 四十周年回顾用于 1982/1992 等 chronology lead。
- **D**：`service addressability`、`lookup → discovery`、`operator-mediated search`、`operational availability`、`decision compression` 是本研究包依据证据提出的分析概念，不是历史行动者术语。
