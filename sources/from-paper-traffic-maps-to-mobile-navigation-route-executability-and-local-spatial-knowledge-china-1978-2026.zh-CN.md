# 从纸质交通图到手机导航：路径可执行性、陌生城市与地方空间知识，中国 1978—2026

## 本轮问题

仓库已经研究过迁移、订票、服务可发现性、快递、网吧、住房与陌生城市生活，但还缺一层极其普通的执行条件：

> **我知道一个地方存在，也决定要去，是否意味着我真的知道怎样到达？**

一个人在陌生城市里能不能找到学校、招聘单位、医院、出租屋、餐馆、车站或客户，不只取决于交通工具存在，还取决于她能否把“目的地”转换成一条可执行路线。

因此本轮把普通人的移动拆成：

```text
知道目的地
→ 能否把名称转换成位置
→ 能否知道从当前位置到目的地的路线
→ 能否理解换乘 / 转弯 / 出入口
→ 行进过程中能否发现自己走错
→ 走错后能否重算
→ 到达街区后能否找到门、楼栋、入口和真正可进入的路径
```

与 `old-web-archaeology` 的交叉研究见：

- <https://github.com/tmzncty/old-web-archaeology/blob/main/research/online-maps-route-planning-map-tiles-geocoding-and-routing-state-gaps-1999-2015.md>

## 一、概念：`route executability / 路径可执行性`

地图上两点之间有道路，不等于一个普通人能顺利完成这次移动。

本轮把路径可执行性定义为：

> **一个人能否凭自己当时实际可获得的信息、设备、交通方式和地方规则，把目的地转换成可执行移动。**

它至少包含：

- `place identification`：知道目的地到底在哪里；
- `route acquisition`：获得一条路线；
- `route interpretation`：读懂路线、站名和方向；
- `error detection`：发现自己走错；
- `re-routing`：走错以后产生新路线；
- `last-hundred-meter access`：进入小区、园区、楼栋、地下通道、正确门口；
- `temporal validity`：路线信息此刻仍然有效。

所以：

> **transport network availability != route executability**

这与铁路票研究中的“有铁路 != 某天能取得座位”、114 研究中的“城市里有服务 != 陌生人能找到它”是同一类生活史问题的下一层。

## 二、Internet 以前：纸质交通图已经是一种可携带的城市接口

### 1978 年北京交通图：城市知识可以被折起来带走

2018 年《北京青年报》经央广网保存的一篇地图收藏报道，详细记录了一件 1978 年实物：

- 《北京市区交通图》由地图出版社 1978 年 1 月编制出版；
- 新华书店北京发行所发行；
- 售价 0.25 元；
- 正面不仅有市区交通图，还有郊区汽车路线图和长途汽车路线图；
- 背面有故宫、天坛、颐和园等景区图。

来源：

- 央广网 / 北京青年报，2018-12-17：
  - https://www.cnr.cn/bj/tpxw/20181217/t20181217_524452207.html
  - **C + artifact description：后来报道，但对具体实物的出版时间、发行方、售价和版面做了可核查描述。**

这不是同时代使用调查，不能由此证明“北京普通居民都靠地图出门”。

但它能证明至少一种现实能力已经商品化：

```text
陌生城市 / 陌生城区
→ 购买一张低价交通图
→ 将道路、公交和景点的空间关系带在身上
```

我把它记作：

## `portable spatial legibility / 可携带的空间可读性`

城市本地知识第一次不必完全存在于：

- 出租车司机脑中；
- 售票员脑中；
- 本地亲友脑中；
- 路人的口头指路中。

它也可以被印刷、折叠、出售，并由陌生人随身携带。

## 三、纸地图并不是实时城市：`map lag / 地图滞后`

同一件 2018 年实物报道还提醒：地图内容可能落后于现实。

收藏者指出，1980 年交通图上首次出现一个很小的地铁示意图，但地铁实际通车时间更早；快速变化的城市道路和轨道网络也不断迫使地图改版。

来源同上：

- https://www.cnr.cn/bj/tpxw/20181217/t20181217_524452207.html

这提示一个贯穿纸地图、Web 地图和手机导航的共同问题：

> **a map is a dated representation, not the city itself**

一张图可以：

- 准确显示昨天的道路；
- 却错过今天刚封闭的门；
- 仍保留已经改名的站；
- 没有新建小区；
- 或者把规划线路画得比实际可用时间更早/更晚。

因此以后不能只问“有没有地图”，还要问：

- 哪一版？
- 何时编制？
- 数据更新到哪一天？
- 对哪个交通方式有效？

## 四、地方空间知识长期是一种劳动技能

纸地图并没有消灭熟路人的价值。

上海市交通行业的后来机构性回顾记录，出租汽车调度体系曾留下 1970s—1990s 的手写道路、地名和地标笔记。老从业者的道路知识大量来自长期跑车和现场经验。

来源：

- 上海市交通相关历史回顾，2019（本轮作为 C 级线索，不以具体数量做总体推断）。

这一点的意义不是怀旧，而是说明城市空间从来有两套知识：

```text
formal map knowledge
道路、站点、门牌、行政地名

+

operational local knowledge
哪个门能进
哪条小路更快
哪里掉头困难
哪个站实际换乘更省力
哪栋楼的入口不在门牌所指方向
```

后面会看到，手机导航普及以后第二套知识并没有消失。

## 五、1999—2005：Web 地图首先把“查地点”搬到联网电脑上

### Go2Map：在线地图不是从 Google Maps 才开始

2005 年搜狐向美国 SEC 提交并公开的收购公告明确写道：

- Go2Map 是中国在线地图服务提供商；
- 官方历史 URL 为 `http://www.go2map.com`；
- 平台可通过 Internet / Intranet、手机、呼叫中心、PDA 提供地图服务；
- 数据库当时覆盖全国约 200 个城市的 POI；
- 其中 14 个城市向 Web 用户提供免费在线地图查询。

来源：

- SOHU / SEC，2005-04-12：
  - https://www.sec.gov/Archives/edgar/data/1104188/000119312505075385/dex991.htm
  - **A：当时公司正式披露。能证明产品定位与公司宣称的覆盖，不能自动证明实际准确率或用户普及率。**

同期和近同期产业报道把 Go2Map 的公开服务起点追溯到 1999 年 5 月。

- 《经济观察报》2007 年行业回顾：
  - https://www.eeo.com.cn/2007/0604/67899.shtml
  - **B/C：2007 年对 1999—2007 行业史的近时回顾。**

因此中文大众 Web 上的在线地图不能从 2005 Google Maps / 百度地图才开始叙述。

## 六、在线地图第一次改变的是“出发以前”

早期 Web 地图最明显的能力不是行进中语音导航，而是：

```text
人在电脑前
→ 搜地点
→ 看地图
→ 查公交 / 驾车路线
→ 记下来 / 抄下来 / 打印
→ 离开电脑
→ 按结果去走
```

我把它记作：

## `pre-trip route compilation / 出发前路径编译`

这和纸地图不同。

纸地图把空间数据交给用户自己推理；Web 路线服务开始替用户执行一部分计算：

- 起点在哪里；
- 终点在哪里；
- 哪几条公交可能换乘；
- 驾车应经过哪些道路；
- 哪条方案少换乘或更快。

但计算仍然主要发生在**出发前**。

一旦离开联网 PC，路线通常会冻结成：

- 记忆；
- 手抄地址；
- 一张打印纸；
- 一条短信；
- 或事先记下的站名。

## 七、2005—2006：地图开始从“看街道”变成生活搜索入口

2005 年搜狐收购 Go2Map 后，搜狗很快上线地图搜索测试版。同期报道说，服务整合位置、交通和关键词搜索，覆盖城市道路、公交等空间信息。

来源：

- ChinaTechNews，2005-06-01：
  - https://www.chinatechnews.com/2005/06/01/2664-sohu-maps-the-future-with-new-acquisition
  - **B：同期行业报道。**

2006 年 Mapbar 改版的同期报道则已经把首页划成：

- 本地搜索；
- 地图查询；
- 公交驾车；
- 房屋租售；
- 票务查询。

并提供公交线路、站点搜索，以及用户“问路”等社区功能。

来源：

- ChinaByte / 新浪科技，2006-09-15：
  - https://tech.sina.com.cn/roll/2006-09-15/1123100442.shtml
  - **B：同期产品报道。**

这说明在线地图很快超出了“电子版折叠地图”的范畴。

它开始把：

```text
我在哪里？
某个地方在哪里？
我怎样去？
附近有什么？
哪个公交经过这里？
```

放进同一套查询系统。

因此，上一轮研究过的 `service discoverability / 服务可发现性` 与本轮的 `route executability / 路径可执行性` 在这里开始合流。

## 八、2006：手机导航已经存在，但不能把存在偷换成普及

2006 年《新经济导刊》留下了一份非常有价值的同时代第一人称材料。

报道中的张涛：

- 30 岁；
- 市场经理；
- 春节后刚从外地到北京工作；
- 要去一家此前没去过的餐馆；
- 公司为他的手机开通了中国联通 CDMA 语音导航业务。

他描述，输入目的地后可以看到地点；如果开车，同时输入起点和终点，还会得到路线图和语音导航。

来源：

- 《新经济导刊》/ 新浪科技，2006-03-14：
  - https://tech.sina.com.cn/t/2006-03-14/1547867045.shtml
  - **B + contemporaneous first-person：同期媒体中的同时性自述。**

这是非常好的“新到城市的人怎样减少地方知识缺口”证据。

但同一篇报道马上提供了反例：

- 中国联通相关定位业务用户当时约 20 万；
- 中国移动试点“手机地图”用户只有约 1 万；
- 报道将业务描述为仍处市场导入阶段；
- 终端价格、体验成本、地图与公交数据更新都被列为瓶颈。

因此必须同时写：

> **mobile navigation existed in 2006 != mobile navigation was normal in 2006**

这正是 HPL 方法中“商业存在 / service access / mass normality”区分的典型案例。

## 九、2008：扩张型未来中的“陌生城市可执行性”

2008 年有两份非常直接的同时代证据。

### 第一份：路线计算的覆盖扩大

Google 中国官方博客 2008 年 9 月宣布：

- 公交查询覆盖全国 81 个城市；
- 产品宣称包含约 38,000 条交通路线；
- 北京站到奥林匹克公园的例子可给出公交、地铁、站点、路程与路线；
- 用户可以选择“较快捷”或“少换乘”；
- 驾车可以查询跨省路线。

来源：

- Google 中国官方博客，2008-09-01：
  - https://china.googleblog.com/2008/09/blog-post_1940.html
  - **A：同时代官方产品说明；证明平台宣称的功能和覆盖，不证明每条数据均准确。**

路线不再只是“怎么走”，而开始成为一个可以优化的问题：

```text
最快
少换乘
开车
公交
跨城
```

### 第二份：路线从 PC 离开桌面

同月，Google 中国一名刚大学毕业、在北京生活四年多的软件工程师在官方博客写道，以前为了出行会问路，却仍可能坐错公交或让出租车绕远；后来可以在 PC 上事先规划路线，但前提是身边有能上网的电脑。手机地图的新意义，在他的描述里正是把路线规划从固定 PC 带到“任何时间、任何地点”。

来源：

- Google 中国官方博客，2008-09-24：
  - https://china.googleblog.com/2008/09/22_2361.html
  - **A-source / contemporaneous self-report：同期官方博客中的员工第一人称；存在产品宣传选择偏差，不能当人口调查。**

这给 2005—2012“扩张型未来”增加了一个具体机制：

## `route knowledge decoupling / 路线知识与本地熟人脱钩`

一个年轻人去陌生城区、面试、看房、见朋友或第一次去新单位，越来越不必预先认识一个“熟路的人”。

城市里的潜在地点因此更容易变成**可执行的地点**。

这不会自动增加工资、住房或工作岗位，但它降低了尝试一条新路线所需的地方知识门槛。

## 十、出发前规划 → 行进中重算

早期 Web 地图的核心时间结构是：

```text
出发前知道路线
→ 出发后尽量别走错
```

移动定位和手机导航逐渐把它改成：

```text
当前位置
→ 当前建议
→ 走错 / 路况变化
→ 再定位
→ 新建议
```

我把这叫：

## `continuous re-routing / 行进中重算`

它改变的不只是方便程度，也改变了人面对陌生空间的风险结构。

过去一次错误转弯可能要求：

- 找路人；
- 找电话；
- 找站牌；
- 重新展开地图；
- 返回已知路口。

后来错误可以由设备持续发现和修正。

“我必须先把路记住”逐渐变成“我只需要保持设备还能定位和算路”。

## 十一、不要把导航普及写成地方知识消失

### 2019：骑手仍然是“活地图”

2019 年一组对北京望京外卖骑手的同期影像报道提供了很好的反例。

三名来自甘肃的 90 后骑手长期在望京送餐。他们熟悉：

- 哪些小区；
- 哪些门禁坏了；
- 保安态度；
- 抄近路、小道和夜路。

报道直接形容他们是望京的“活地图”，并说问这些熟练骑手某些近路“比导航还精确”。

来源：

- 2019-10-14 同期影像报道存续页：
  - https://www.sohu.com/a/346792998_120206672
  - **B + contemporaneous observation：同期报道；具体人物可证明一种职业经验，不代表所有骑手。**

这里暴露出数字导航长期很难完整编码的一层：

## `operational micro-geography / 运行中的微观地理`

导航数据库可能知道：

- 一条道路；
- 一个小区；
- 一栋楼的大概坐标。

熟练骑手知道的却可能是：

- 哪个门今天能进；
- 哪个门晚上锁；
- 哪个保安会要求登记；
- 哪条内部路电动车能走；
- 哪个楼号从另一侧入口更快；
- 哪条“地图上不是主路”的小道节省三分钟。

因此：

> **navigation availability != local spatial mastery**

## 十二、2015—2019“拥堵型未来”：导航降低迷路成本，但时间竞争会把地方知识重新变成生产力

导航普及以后，人更容易进入陌生城市和陌生片区。

但对于按单计酬、严格时限的配送工作，路线选择不再只是“能不能找到”，而变成：

```text
哪条路更快
哪个入口少等
哪里能停车
哪部电梯快
哪个门现在开放
```

2019 的骑手材料说明：

- 数字导航提供基础空间可读性；
- 重复劳动产生更细的地方知识；
- 这套知识直接被转换成更多可完成订单和更少时间损失。

所以 2015—2019 的“拥堵型未来”在这里表现为：

> **同一套导航把陌生空间的进入门槛降下来以后，竞争又把更细的空间熟练变成新的优势。**

这不是说外卖平台或导航“导致”拥堵型未来；只是一个能观察到这种时间逻辑的具体劳动场景。

## 十三、2024：到了最后几百米，纸地图又回来了

2024 年北京“骑手友好社区”的材料非常适合防止技术线性叙事。

《北京日报》经人民网发布的报道说，北京已有 20 多个此类社区，通过通行机制、停车区和小区地图等方式改善配送。

在天通苑东三区，一名骑手张明伟到社区门口后，会对照**小区路线图**寻找 63 号楼；报道称整单相比过去快了近 15 分钟。

来源：

- 人民网 / 北京日报，2024-07-03：
  - https://bj.people.com.cn/n2/2024/0703/c82840-40899644.html
  - **B + contemporaneous observation：同期现场报道。**

更早的北京日报客户端材料还说明，社区路线图会标明：

- 出入口；
- 楼门号；
- 充换电柜；
- 停车区；
- 卫生间。

线上平台同时更新社区出入口和便利设施。

来源：

- 北京日报客户端，2024-01-27：
  - https://news.bjd.com.cn/2024/01/26/10687773.shtml
  - **B：同期机构/媒体材料。**

这产生一个看似倒退、实际非常合理的组合：

```text
城市级手机导航
+
小区级纸面路线图
+
物业通行规则
+
骑手自己的熟路经验
```

纸地图不是“被技术淘汰后又复活”。

它只是继续适合一种特定尺度：

- 小区域；
- 稳定入口；
- 无需登录；
- 一眼可见；
- 可以贴在门口给所有临时访问者看。

## 十四、`map coverage != access coverage / 地图覆盖不等于可进入覆盖`

2024 的材料说明，最后几百米的问题往往不属于传统道路网络。

地图平台可能已经准确画出整个小区，但实际移动仍受：

- 门禁；
- 物业规则；
- 骑车能否进入；
- 临时封闭；
- 楼门号是否清楚；
- 电梯权限；
- 地下通道；
- 访客登记；
- 建筑内部路线。

影响。

所以“路由算法找到终点”与“人能到达用户门口”之间仍存在：

## `access-rule layer / 进入规则层`

它对：

- 外卖骑手；
- 快递员；
- 家政人员；
- 上门维修；
- 第一次去医院大楼的人；
- 刚搬来的租客；

都可能决定一次移动是否真正完成。

## 十五、海外比较：美国也经历了“在电脑上算路，再把纸带走”的阶段

这一转折不是中国特有。

### Web 以前：CD-ROM 已经能在家里计算路线

美国 1990s 中期出现过 DeLorme / AAA 等 CD-ROM 旅行和街道地图软件。后来的软件史资料把 AAA Map 'n' Go 的第一版追溯到 1994 年；当时《洛杉矶时报》和《纽约时报》都曾评测在家庭电脑上用 CD-ROM 规划旅行的方式。

本轮尚未取得上述报纸原文的稳定可核验页面，因此只将此作为 **C/B lead**，不以软件功能细节做强结论。

### Web 阶段：MapQuest 的路线可以真的变成纸

更强的一份实物证据来自 University of North Texas Libraries Special Collections。

馆藏保存了一份：

- 2004-04-15 产生；
- 从 Dallas 到 Austin；
- 共 9 页；
- 明确描述为 “Printed driving directions from MapQuest”。

来源：

- UNT Digital Library：
  - https://digital.library.unt.edu/ark:/67531/metadc980091/
  - **A：实际保存的同时代打印路线 artifact。**

它把 `pre-trip route compilation` 变成一个可以摸到的历史物：

```text
Web server 计算路线
→ 家庭 / 办公电脑显示
→ 打印机输出
→ 纸张进入汽车
→ 驾驶人在离线状态照纸行驶
```

这也提示 Internet 与纸张并不是简单替代关系。

在很长一个阶段，**Web 恰恰通过打印机进入移动世界。**

## 十六、跨国共同机制与中国特殊层

### 共同机制

美国与中国都能看到：

```text
纸质道路图 / 城市图
→ PC / CD-ROM 或 Web 上的电子地图
→ 起终点路线计算
→ 打印或记下路线
→ 手机中的随身地图
→ 行进中定位与重算
```

共同变化是：

> **路线知识从“必须提前知道”逐渐转成“可以按需计算”。**

### 中国需要单独解释的层

中国大城市的路径执行尤其需要注意：

- 公交换乘的重要性长期很高；
- 2008 年产品已经把“少换乘”单列为优化目标；
- 高密度小区、园区和封闭社区产生大量最后几百米问题；
- 城市道路、轨交和地名在高速建设阶段更新很快；
- 2006 年移动定位已经商业存在，但用户规模和终端门槛意味着它并非大众常态。

不能把美国以驾车 turn-by-turn 为中心的早期 Web 地图体验直接当作中国模板。

## 十七、四段时间感框架：这一机制怎样嵌入现有比较

### 2005—2012：扩张型未来

本轮新增的不是“地图更方便”这样宽泛的结论，而是：

> **陌生地点的试错成本下降，使更大的城市生活菜单更容易被实际执行。**

新工作、新出租屋、新学校、新商圈、新朋友的地址，不再同样依赖本地熟人把你带过去。

这与当期迁移、招聘、住房和移动通信扩张互相配合。

### 2015—2019：拥堵型未来

地图已经成为基础能力，竞争转向：

- 时间；
- 路况；
- 入口；
- 排队；
- 最后几百米；
- 比标准导航更细的熟练。

2019 骑手“活地图”是一个具体劳动证据。

### 2020—2022：偶发型未来

本轮没有找到足够强、且与既有疫情专题不重复的一手材料，证明导航本身形成独立的“偶发型未来”机制。

不能为了填四格强行制造结论。

更值得后续检索的是：

- 临时封路；
- 社区出入口改变；
- 配送范围临时变化；
- 出行线路在短时间内失效；
- 地图数据赶不上现实管控边界。

### 2023—2026：防守型未来

2024 骑手友好社区证明的是**路径执行的 fallback 和微观补丁**，不是直接证明宏观青年未来悲观。

它与“防守型未来”可能相连的地方只是：成熟数字基础设施不再假设一条统一路线足够，而是开始增加：

- 特定人群入口；
- 地图补充；
- 线下标识；
- 人工/物业协商；
- 多路径 fallback。

这条关系目前只应写成研究方向，不应上升为总体时间感判断。

## 十八、历史可见性：熟路经验最容易从档案里消失

道路和地图很容易留下档案。

最难留下的是：

- “从这个门进去快”；
- “那边的门晚上关”；
- “这个站下车其实要走很远”；
- “第一次去这栋楼应该从背面进”；
- “地图说能走，但保安不让”；
- “这里以前可以穿过去，现在围起来了”。

这些知识通常只存在于：

- 司机；
- 快递员；
- 外卖骑手；
- 门卫；
- 本地居民；
- 同事；
- 路人；

的实践记忆里。

因此历史档案天然偏向**formal geography**，而低估 **operational geography**。

这也是为什么生活史不能只保存道路矢量和 Web 页面。

## 十九、重点矩阵更新

本轮改变以下矩阵项：

| 维度 | 新增理解 |
|---|---|
| 教育 | 初到学校 / 培训点的路线也是机会可执行的一部分 |
| 就业 | 面试、上班、配送、上门服务都依赖路径执行；熟路可成为劳动生产力 |
| 住房 | 看房和搬入陌生小区需要地址→入口→楼栋转换 |
| 迁移 | 新城市生活不只要车票和住处，还要快速取得地方空间知识 |
| 照护 | 上门医疗、家政、给亲属送物等均受最后几百米影响 |
| 非正规 / 平台劳动 | 骑手地方知识可直接转成节省时间和更多订单 |
| 通信方式 | 问路、电话指路、Web 查路、短信、手机导航形成连续而非断裂的替代链 |
| 互联网平台 | 地图平台把 POI 搜索、路线计算与本地服务发现结合 |
| 信息获取 | “地点在哪里”与“如何到达”成为可查询信息 |
| 未来预期 | 2005—2012 新机会在空间上更容易被执行；后期竞争转到时间和微观访问规则 |
| 线上 / 线下身份 | 地图中的 POI 与现实可进入地点不是同一状态 |
| 平台消失与记忆保存 | 路由结果、地图版本和最后几百米地方知识尤其难保存 |

## 二十一、反例与后见之明风险

### 风险 1：把“在线地图上线”写成普通人已经不问路

错误。

2006 手机定位用户规模、2008 员工自述、2019 骑手与 2024 小区地图都说明问路、熟路和线下指引长期共存。

### 风险 2：把地图覆盖城市数当作实际可用性

错误。

产品宣称覆盖只证明平台声称有数据，不能证明：

- 每条公交更新及时；
- 每个 POI 坐标准确；
- 每个小区入口可走；
- 每部手机都能运行；
- 每个人付得起流量和业务费。

### 风险 3：把手机地图出现日期当作普及日期

2006 的同期报道已经给出明确反证：业务存在，但规模仍小。

### 风险 4：把导航当作“地方知识终结”

2019 和 2024 材料直接否定这种线性叙事。

### 风险 5：把 2024 配送地图强行解释成青年“防守型未来”

证据不足。本轮只把它作为成熟数字系统中的 fallback / last-mile 执行机制。

## 二十二、What we know / infer / do not know

### What we know

- 至少到 1978 年，北京已有低价公开发行、整合市区道路、公交和景区的交通图实物；
- 1999 后中文 Web 已出现面向大众的在线地图服务；
- 2005—2008 地图服务快速整合 POI、公交、驾车和路线优化；
- 2006 已有商业手机定位/语音导航，但用户规模和终端成本仍限制普及；
- 2008 手机地图已经明确把 PC 上的“出发前查路”带入移动终端；
- 2019 平台劳动仍产生导航未完全编码的微观地方知识；
- 2024 社区地图和通行机制仍可显著改变最后几百米配送时间。

### What we can reasonably infer

- 在线路线规划降低了陌生人进入大城市空间的地方知识门槛；
- 移动导航最大的时间结构变化之一，是把路线计算从“出发前”扩展到“行进中”；
- 共享地图数据越成熟，真正稀缺的空间知识可能越向入口、权限、实时状态和建筑内部移动收缩；
- 对迁移者而言，能够自己导航降低了对本地熟人网络的部分依赖，但没有消灭这种依赖。

### What we do not yet know

- 1980s—1990s 不同城市普通人购买和实际携带交通图的比例；
- 1999—2004 Go2Map 普通用户的真实使用频率、打印习惯与路线查询流程；
- 早期地图站公交 / 驾车算法在不同城市的误差和更新周期；
- “纸地图 → Web → 手机”的转换在农村、县城、低收入用户和不同年龄群体中具体晚了多少年；
- 2007—2010 求职、看房、异地上学等场景中，手机/在线地图到底减少了多少实际问路和误时；
- 疫情期间临时出入口变化是否形成了独立的地图/导航失效机制。

## 二十三、下一步可继续推进

后续若继续这条线，优先级应是：

1. 找 1980s—1990s 同时代报刊中的“第一次到大城市怎样找路 / 买地图 / 问路”个体材料；
2. 找 1999—2004 Go2Map 的已验证 historical capture，而不是只有 locator；
3. 找 2007—2010 普通论坛 / 博客中打印地图、抄公交路线、手机导航失败或成功的同时性自述；
4. 将“路线可执行性”与招聘面试、看房、医院就诊等既有专题做一次跨专题索引；
5. 专门研究建筑、园区、校园、医院内部导航，判断“城市级地图已经成熟以后，迷路问题向哪里转移”。

## 二十四、本轮改变了什么

仓库此前已经可以解释：

- 为什么一个人能去另一座城市；
- 怎样取得车票；
- 怎样找到服务；
- 怎样联系陌生人；
- 怎样让物品跨城移动。

本轮补上了一个介于“知道机会”和“真正抵达机会”之间的执行层：

> **一个地点只有在路线可执行时，才真正进入普通人的生活菜单。**

这意味着现代城市生活的扩张不仅来自道路、地铁和汽车，也来自另一类不那么显眼的基础设施：

> **把陌生空间翻译成“下一步往哪里走”的系统。**
