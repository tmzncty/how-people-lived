# 从“有事呼我”到口袋里的完整通信回路：寻呼机、回呼、公用电话与移动通信，中国 1984—2007

> 性质：`how-people-lived` / `old-web-archaeology` 交叉研究包。  
> 主题：在移动电话尚未普及、Internet 尚未进入多数普通家庭的时期，一个离开固定电话的人怎样仍然“可被找到”；无线寻呼怎样依赖公用/固定电话完成回呼；1999 年前后 Web、电子邮件与寻呼网络怎样短暂形成跨网络混合系统；以及当时人为什么并不能预见寻呼机会如此迅速地消失。  
> 核心限制：无线寻呼的用户统计存在明显统计口径差异；本文保留来源与单位，不把不同序列直接拼成一条精确采用率曲线。

仓库虽然已经研究电话、公用终端、CFido、电子邮件、网吧、移动 Internet 等，但仍缺一个非常基础的问题：

> **人在离开家里或单位的固定电话以后，怎样先变得“可被通知”，再变得“可以在移动中完成双向通信”？**

寻呼机不能简单写成“手机以前的低配手机”。它的关键特征恰恰是：

```text
接收端跟人走
发送 / 回呼端仍然留在电话网络里
```

因此本轮新增的不是一个设备条目，而是一种通信生活结构。

## 1. 先划清历史边界：寻呼不是 Internet，也不是完整移动电话

中国无线寻呼的“第一”日期在后来的官方/行业回顾中存在 1983 与 1984 两种写法。中国电信博物馆采用 1983 年上海开通国内第一套寻呼系统的说法；2008 年的通信史回顾则把上海第一家无线寻呼台写在 1984 年。

来源：

- 中国电信博物馆，《寻呼机》历史回顾：  
  https://museum.chinatelecom.com.cn/yj/txkp/202303/t20230327_73688.html
- 内蒙古晨报 / 新浪，《寻呼台去年“下岗”》，2008-11-25：  
  https://news.sina.com.cn/c/2008-11-25/153016722013.shtml

这里不强行裁定“第一年”。更稳妥的写法是：

> 1980 年代中期，中国城市开始出现面向公众的无线寻呼服务；1990 年代进入大规模采用期。

必须同时区分：

```text
无线寻呼网络
≠ Internet
≠ 移动电话网络
```

寻呼机通常只能接收。数字机最常见的是显示一个要求回拨的电话号码；汉字机可以直接显示短留言，但仍不是一个完整的双向会话终端。

## 2. 新机制一：`reachable-without-callability / 可被找到，但不能直接通话`

数字寻呼的普通工作流可以写成：

```text
A 想找 B
→ A 拨寻呼台 / 自动寻呼号
→ 留下自己的电话号码或数字信息
→ 寻呼网络把信息经无线电发送
→ B 腰间的寻呼机响起
→ B 看见号码
→ B 需要找到另一部电话
→ B 回拨 A
```

这第一次让很多普通用户在离开固定电话以后仍具有一种持续的“个人可达性”。

但它不是今天意义上的“移动通信闭环”。

可以定义：

> **`reachable-without-callability / 可被找到但不能直接通话`**：个人携带一个移动接收端，因此别人能够把“有人找你”的状态送到这个人身上；但这个人无法仅靠同一终端完成回复或通话。

这是一种介于：

```text
只能守在固定电话旁边
```

和

```text
手机可以随时双向通话 / 短信
```

之间的通信状态。

它改变的是“找不到这个人”这一问题，而不是一次性解决全部移动交流。

---

## 3. 新机制二：`split communication loop / 分裂式通信回路`

寻呼生活最重要、也最容易被今天遗忘的地方，是**回呼端经常不属于本人**。

2007 年新浪回访的一名 24 岁受访者回忆自己 1997—1999 年使用 BP 机，最深印象是每次机器响都要“满世界找电话”；他说当时公用电话还不够多，寻找电话本身很麻烦。换成汉字机后，一些事情可以直接看留言，不必每次都回电。

来源（回顾性自述，C 级）：

- 新浪科技，《我们曾经的寻呼生活》，2007-03-21：  
  https://tech.sina.com.cn/t/2007-03-21/17141427256.shtml

2008 年另一篇回顾记录，一名 1998 年从江苏到北京上大学的学生靠 BP 机维持异地恋；收到女友传呼以后，他会跑到宿舍外面的公用电话亭回拨。

来源（回顾性自述，C 级）：

- 新浪新闻，《记忆中的BP机时代》，2008-12-03：  
  https://news.sina.com.cn/c/2008-12-03/113316775726.shtml

所以实际通信系统不是“一个人 + 一部寻呼机”，而是：

```text
个人寻呼机
+ 寻呼台 / 自动寻呼系统
+ 城市固定电话网
+ 路边公用电话 / 商店电话 / 宿舍电话 / 单位电话
```

这里可以定义：

> **`split communication loop / 分裂式通信回路`**：通信的进入方向和返回方向由不同基础设施完成；“移动接收”与“固定地点发送”被拆在两个系统里。

以及：

> **`borrowed return channel / 借用回呼通道`**：一个人虽然已经携带私人通信终端，却仍需临时借用城市里另一部公共、单位、商店或家庭电话才能把通信闭环。

这意味着“有没有自己的寻呼机”和“能不能及时回电话”是两个不同的可及性问题。

## 4. 公用电话不是寻呼机的背景，而是它的组成部分

1999 年通信业统计公报显示，全国公用电话当年净增 41.4 万部，达到约 300.8 万部；无人值守的投币、磁卡、IC 卡公用电话又增加约 27 万部。

来源（信息产业部综合规划司公报摘要，同期统计）：

- 新浪转载《一九九九年通信业发展统计公报（摘要）（下）》，2000-06-14：  
  https://tech.sina.com.cn/it/2000-06-14/28155.shtml

后来的通信史回顾甚至直接把 BP 机普及和 IC 卡电话、公用电话亭扩张联系起来。

来源：

- 内蒙古晨报 / 新浪，《寻呼台去年“下岗”》，2008-11-25：  
  https://news.sina.com.cn/c/2008-11-25/153016722013.shtml

因果关系不能仅凭回顾文章写成“BP 机造成了公话增长”，但至少可以得出一个更窄而重要的结论：

> **对数字寻呼用户而言，城市中是否存在足够密集、价格可承受的回呼电话，直接改变寻呼服务的实际可用性。**

所以“无线寻呼覆盖这个城市”仍然不等于一个人在任何地方都能顺利完成交流。

## 5. 汉字机改变的不是“有没有消息”，而是回呼是否仍然必要

数字机把最主要的信息压缩成：

```text
谁希望你回电话
```

汉字机可以把通信推进到：

```text
对方希望你知道什么
```

玉屏县后出的地方通信史回顾给出了很具体的解释：数字机通常只能显示呼叫号码，需要找地方回电；汉显机可以显示留言，但收费更高。该文还记录当地早期数字机年服务费约 180 元、汉字机约 600 元，后来在竞争中持续下降。

来源（地方政府回顾材料，C/B 级，具体价格应视为玉屏地方个案）：

- 玉屏网，《感受通信工具的变化》，2025-03-17：  
  https://www.yp.gov.cn/contents/2025/03/17/receive-1764843f-1b66-4998-ac9b-01927ef7a29b.html

因此“汉显”不仅是屏幕升级。它降低了某些消息对回呼通道的依赖：

```text
“给我回电话”
```

仍需要找电话，而：

```text
“晚上七点老地方见”
```

可以在寻呼机上直接完成信息交付。

这里可以定义：

> **`callback avoidance / 回呼规避`**：更高信息容量的单向终端，使一部分原本必须通过第二次电话完成的交互，变成一次单向消息即可执行。

它仍然不等于双向手机，但已经改变了生活流程。

## 6. 一个县里的时间错位：大量寻呼用户与几乎没有 Internet 用户可以同时存在

玉屏的地方通信回顾给了一个极有价值的对照：

- 1995-10-06 当地开通中文寻呼设备和 127 自动寻呼；
- 1997 年无线寻呼用户达到 **3451 户**；
- 同年当地才开通 CHINANET，计算机 Internet 用户只有 **4 户**；
- 1998 年 Internet 用户 20 户；
- 1999 年 92 户；
- 到 2000 年，由于移动通信发展，当地寻呼只剩 100 多户。

来源：

- 玉屏网，《感受通信工具的变化》，2025-03-17：  
  https://www.yp.gov.cn/contents/2025/03/17/receive-1764843f-1b66-4998-ac9b-01927ef7a29b.html

这些数字来自多年后的地方史整理，不应替代原始年鉴；但它特别适合说明一种历史结构：

> **一个地方可以已经拥有数千个可移动接收数字信息的人，却几乎还没有普通 Internet 用户。**

因此不能把 1990 年代普通人的“数字通信”全都压缩成 Internet adoption。

这里至少同时存在：

```text
固定电话
+ 公用电话
+ 自动 / 人工寻呼
+ 移动电话
+ 极少量 Internet
```

几个不同速度发展的网络。

## 7. 1999：Web 与寻呼不是互相替代，而是被人真正接在了一起

1999 年通信业公报记录，中国联通国信寻呼覆盖 335 个地市、2022 个县市；198/199 全国网覆盖 287 个城市、容量 1700 万户。更重要的是，该公报说国信开通了“国信网源”网站，截至 1999 年底：

- 网上寻呼已开通到 198/199 全国网；
- 覆盖 27 个省网及一些本地网；
- “电子邮件到达呼”开通 22 个省网。

来源（同期官方统计公报）：

- https://tech.sina.com.cn/it/2000-06-14/28155.shtml

腾讯今天保存的一篇公司新闻标注日期为 **1999-07-11**，描述腾讯与 SINET 在深圳电信网络试运行邮件增值系统。该系统面向拨号 ISP 用户，可以提取邮件发件人、主题和正文，再按用户设定的规则把内容送到寻呼台、GSM 短信系统或传真。

来源（腾讯官方 corporate archive；页面本身是今天的站点，不能冒充 1999 HTML artifact）：

- https://www.tencent.com/en-us/articles/80260.html

这意味着 1999 年真实存在：

```text
Internet email
→ gateway / filter
→ paging station
→ radio paging network
→ pager on a moving person
```

也就是说，一个人不需要随身连 Internet，也可以让 Internet 上的事件追上自己。

这里可以定义：

> **`cross-network notification / 跨网络通知`**：一个网络上的事件，经网关转换后进入另一套终端和传输基础设施，使未持续接入原网络的人仍能收到状态变化。

它是今天手机 push notification 的很早期、但结构不同的前身之一；不应把两者技术上等同。

## 8. 更强的同时代证据：1999 年 Internet 用户真的把“网上寻呼机”当成一种网络服务

CNNIC 2000 年 1 月发布的统计报告，以 1999-12-31 为数据截止日：

- 全国上网用户估计为 890 万；
- 上网计算机 350 万台；
- 在线问卷的“最常使用网络服务（多选）”中，**13.17% 选择“网上寻呼机”**。

来源（CNNIC 报告同期转载）：

- https://tech.sina.com.cn/news/internet/2000-01-18/15795.shtml

这里必须非常谨慎：

- 13.17% 是**网上联机问卷的 Internet 用户样本**，绝不是全国人口比例；
- 也不能由此推出每个使用者都在国信系统上；
- 但它足以证明“网上寻呼”并非只有运营商新闻稿里的概念，而确实进入了 1999 年部分网民的服务菜单。

这进一步说明：

> Internet 早期进入普通生活的一条路线，并不是每个人先拥有一台始终在线的移动终端，而是 Internet 把通知送进当时已经普及得多的其他通信设备。

## 9. 统计口径本身也是历史问题：不要伪造一条光滑 adoption curve

不同官方/准官方来源对 1990 年代末无线寻呼用户数给出过明显不同的数值。

例如：

- 国家统计局的一篇 50 年回顾写 1998 年无线寻呼用户 3908 万；
- 信息产业部 1999 年通信业公报则写，中国联通寻呼用户 4718 万，而“全社会无线寻呼年末用户总数超过 7500 万”；
- 后来的中国电信博物馆回顾使用了 1998 年 6546 万、2000 年约 8400 万的序列。

来源：

- 国家统计局：  
  https://www.stats.gov.cn/zt_18555/ztfx/xzg50nxlfxbg/202303/t20230301_1920449.html
- 1999 年通信业统计公报（上）：  
  https://tech.sina.com.cn/it/2000-06-14/28154.shtml
- 中国电信博物馆：  
  https://museum.chinatelecom.com.cn/yj/txkp/202303/t20230327_73688.html

最合理的处理不是挑一个自己喜欢的数字，而是记录：

> **寻呼统计可能受到运营商范围、社会寻呼台是否纳入、重组前后统计体系等影响；在没有找到每组指标的完整定义前，不把这些数连接成一条精确全国采用曲线。**

本轮只保留一个强结论：1990 年代末无线寻呼已经是**数千万量级**的大众通信基础设施。

## 10. 新时间机制：`branching technical future / 分叉中的技术未来`

今天看寻呼机，很容易把它写成一个“注定会被手机淘汰的过渡产品”。

同时代证据不支持这种必然论。

1999-12-08，《光明日报》刊出的采访《寻呼业仍大有可为》记录，一名南京邮电学院通信工程专家对寻呼业前景表示乐观：当时估计已有约 7000 万寻呼用户，并预测到 **2005 年可能达到 1.3 亿**；文章提出的方向包括农村、学生、专业用户，以及走高科技路线。

来源（同时代媒体，B 级）：

- https://tech.sina.com.cn/news/computer/1999-12-08/12840.shtml

同年行业实际又在做：

- 网上寻呼；
- 电子邮件到达呼；
- 全国联网；
- Internet email → pager gateway。

所以 1999 年的人面对的不是一个已经写好结局的故事，而至少有两条看起来都合理的未来：

```text
A. 手机越来越便宜，最终把寻呼功能吸收进去

B. 寻呼继续变成便宜、低功耗、全国覆盖的信息终端，
   再和 Internet / email / 股票 / 新闻服务融合
```

后来 A 获胜，并不能证明 B 在 1999 年“显然荒谬”。

这里可以定义：

> **`branching technical future / 分叉中的技术未来`**：在一个转型时点，多条基础设施路径同时获得真实用户、投资和产品开发；后来的胜出路径不能倒过来把失败路径写成当时人必然知道的错误答案。

这是“同时代未来想象”研究中一个非常干净的案例。

## 11. 预测失败有多大：2005 年只剩 97.1 万

信息产业部的 2005 年 12 月通信行业统计月报记录：

- 移动电话用户：39342.8 万户；
- 无线寻呼用户：**97.1 万户**；
- 当年无线寻呼净减少 298.1 万户；
- 移动短信业务量：3046.5 亿条。

来源（官方月报）：

- https://www.miit.gov.cn/gxsj/tjfx/txy/art/2020/art_b18e780c481745239acd2fc69364e2a3.html

这和 1999 年“2005 年 1.3 亿寻呼用户”的同期预测形成极强反差。

2007 年，中国联通申请停止除上海外多数地区的 198/199、126/127、128/129 无线寻呼业务。

来源：

- 广州日报 / 搜狐，《中国联通将关闭无线寻呼业务》，2007-03-05：  
  https://business.sohu.com/20070305/n248504668.shtml

所以本专题也补充了一类“未来感”证据：

> **普通人和行业参与者不仅会低估危机，也会高估已经非常成熟的日常基础设施还能持续多久。**

一种技术即使拥有数千万用户、全国网络、成熟运营商和 Internet 网关，也可能在六七年内失去大众日常位置。

## 12. 海外比较：一向寻呼和 Internet gateway 不是中国特有

1994 年 1 月的 RFC 1568、7 月的 RFC 1645 定义了 SNPP（Simple Network Paging Protocol），目标就是从 Internet 侧把数字或字母数字消息送往 radio paging terminals。RFC 1645 还明确说，支持 SNPP 和 SMTP 的网关已经实际用于 nationwide paging / messaging。

来源（同时代协议原件，A 级）：

- RFC 1568：  
  https://www.rfc-editor.org/info/rfc1568/
- RFC 1645：  
  https://www.rfc-editor.org/rfc/rfc1645.html

1995-12-04，《Washington Post》解释美国寻呼的典型生活流程：约 3000 万寻呼机正在使用，最常见用途仍是显示要求回拨的电话号码；调用者拨寻呼服务、输入号码，网络再无线发送到寻呼机。报道同时介绍刚出现的 two-way paging。

来源（同时代媒体，B 级）：

- https://www.washingtonpost.com/archive/business/1995/12/04/how-it-works/8f72080b-8e47-4b43-804e-1c52f4e94c7a/

同年 10 月另一篇报道把 two-way paging 的意义直接说成：用户终于可以发送简单回复，**不再必须寻找电话**。

来源：

- https://www.washingtonpost.com/archive/business/1995/10/02/paging-takes-a-new-direction/777e5512-f023-45fa-8b8e-f3052041dc25/

因此跨国共同点很明确：

1. 一向寻呼先解决“人离开固定电话以后仍可被找到”；
2. 普通数字机把回拨电话作为最常见消息；
3. 公用/固定电话因此是通信闭环的一部分；
4. Internet-to-pager gateway 在大众 Web 早期就已经存在；
5. 双向终端真正重要的一点，是取消“收到消息后必须再找到另一台发送设备”的要求。

中国比较突出的地方，是 1990 年代末极大的用户规模、126/127/198/199 等人工/自动/全国联网服务，以及 Internet 大众化和 GSM/SMS 大扩张几乎同时发生，导致旧系统和新系统有一段很短但很密集的重叠期。

## 13. 它改变了我们对“人怎么活着”的哪一点理解

### 13.1 迁移和外出先变得“可被叫回”，然后才变得“持续在线”

在手机普及前，一个人外出、上大学、跑业务、在城市里移动，可以不再完全从家庭/单位通信网络中消失。

但这种可达性仍然要求：

```text
有人知道你的呼号
× 寻呼网络覆盖
× 寻呼机有电、在身边
× 消息成功发射
× 如果需要回话，附近有一部可用电话
```

所以“移动通信”本身是分阶段形成的。

### 13.2 私人终端不等于私人完整基础设施

一个人拥有自己的 BP 机，却可能使用：

- 饭馆电话；
- 宿舍公话；
- 街边 IC 卡电话；
- 商店电话；
- 单位电话；

完成返回方向。

个人化设备和公共基础设施长期共生，而不是一台私人设备出现以后公共设施立即失去意义。

### 13.3 Internet 的影响可以先通过“不上网的设备”进入生活

1999 年的网上寻呼 / email 到达呼说明：

> 一个人不需要随身接入 Internet，Internet 上的信息也可以进入她的日常移动时间。

这和“家庭是否已经有电脑/宽带”是不同层次的数字化。

### 13.4 技术未来在当时是开放的

1999 年认真建设 pager-Web/email convergence，并不荒谬；2005 年寻呼近乎退出，也同样是真实历史。

研究未来感时，不能只收集最后猜对的人。

## 16. 反例、后见之明风险与未知

### 反例

- 汉字寻呼可以直接给出行动信息，不是每次都需要回电话；
- 专业/内部寻呼在大众市场退出后仍可能继续存在，因此“公共寻呼退场”不等于所有 paging use 同一天消失；
- 一些手机用户在早期因话费高，也会采用“手机收到来电 → 挂断 → 用固定电话回”的方式，因此 split loop 并非 BP 机独占。

### 后见之明风险

不要写：

> “BP 机显然只是手机出现前的过渡产品。”

应写：

> “1999 年仍有运营商、工程师和媒体把 pager + Internet / email / 全国联网视为可继续扩张的技术路线；后来的快速衰退不能倒推为当时已经确定。”

### 仍不知道

1. 1999 年“国信网源”的**精确历史 URL**仍未恢复；
2. 哪些省网的“网上寻呼”是 Web form、客户端、门户入口还是多种方式并存；
3. 1999 年 13.17% CNNIC 样本中的“网上寻呼机”具体分布在哪些服务商；
4. 寻呼收到 → 找电话 → 回拨的平均时间、失败率、空间距离缺乏系统测量；
5. 不同城市公用电话密度是否显著改变 BP 机实际价值，值得用地方年鉴继续检验；
6. 无线寻呼全国用户统计的不同口径需要回到完整统计年鉴/定义表继续厘清。

## 17. 与 OWA 的交叉结论

这一专题直接产生一个 old-Web 考古对象：

```text
Web / email
→ gateway
→ paging backend
→ radio transmitter
→ pager receiver
```

保存了历史 Web form，并不等于保存了：

- 当时的寻呼用户目录；
- gateway routing rule；
- paging station 接收状态；
- 无线发射是否成功；
- pager 是否真的收到；
- 收件人后来是否回电话。
