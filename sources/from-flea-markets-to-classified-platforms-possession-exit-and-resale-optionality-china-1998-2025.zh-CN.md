# 从毕业甩卖到二手平台：物品退出基础设施、搬家与可转售性，中国 1998–2025

> 类型：ordinary-life infrastructure / mobility / household economy / internet transition research package。  
> 交叉对象：`tmzncty/old-web-archaeology/research/classified-ads-sms-to-web-campus-flea-markets-and-listing-lifecycle-2005-2010.md`。  
> 核心问题不是“二手电商什么时候出现”，而是：**一个普通人在毕业、搬家、换城市、消费失误或收入紧张时，怎样把已经占据自己空间的物品重新变成空间、现金或另一个人的使用价值；Internet 到来以后，这件事究竟改变了哪一段动作？**

---

## 0. 去重：已有研究讨论“怎么买”和“怎么搬”，这里研究“东西怎么退出”

仓库已经有：

- 租房、陌生人合租与 household assembly；
- 搬城市作为职业策略；
- 单人家庭怎样维持；
- 网店、自雇与平台微型经营；
- 互联网分类信息、校园 BBS、同学录等信息基础设施的若干侧面；
- 家庭汇款、车票预订等迁移基础设施。

但这些材料仍然容易默认一件事：

> 人要离开一个地方时，只要“把自己搬走”即可。

真实生活不是这样。住过几年以后，人会积累：

- 书；
- 自行车；
- 台灯、电风扇、电饭煲；
- 衣物和鞋；
- 家具；
- 电脑、手机；
- 兴趣物品；
- 一堆“没有坏、丢掉可惜、但带走又不划算”的东西。

因此迁移存在一个常被忽略的前置问题：

```text
我要离开
→ 哪些东西带走
→ 哪些东西卖掉 / 送掉 / 捐掉 / 丢掉
→ 是否来得及找到接手者
→ 才能真正清空房间、宿舍或住所
```

本轮把这层称为：

**`possession exit infrastructure / 物品退出基础设施`**。

它不是“二手市场”的同义词，而是问：**一个人能否低成本地解除自己与一件仍有价值物品之间的占有关系。**

## 1. Internet 之前，旧货流通已经是一套带信息、运输、身份与结算的制度

### 1.1 1998 年《旧货流通管理办法》说明：旧货市场并不只是“摆摊”

1998 年 3 月 9 日公布实施的《旧货流通管理办法（试行）》把“旧货”定义为已经进入生产或生活消费、处于储备/使用/闲置状态、仍保持部分或全部使用价值的物品；把“旧货市场”定义为具有**信息、评估、结算、加工翻新、保管、运输**等配套服务功能的交易场所。

它还规定：

- 旧货企业可以购销、寄售、代购、代销、租赁、易货；
- 市场可以提供鉴定、评估、储存、运输、修理、翻新、信息咨询；
- 经营者可以做电话预约上门收购；
- 对价值超过 100 元的旧货，要记录基本特征、来源和去向；
- 出售、寄卖者的单位名称或个人居民身份证应登记；
- 市场要有结算系统，并在成交后记录品名、数量、单价、供货人、买货人等。

这份规则只说明受其规范的旧货经营体系，不等于 1998 年每次邻里之间的私人转让都经过同样流程。但它足以证明：

**Internet 并没有发明“把闲置物重新匹配给另一个人”这件事，也没有发明围绕旧物形成的信息、信任、鉴定、运输和结算问题。**

### 证据

- **A（现政府法律事务网站保存的正式规章全文）**：《旧货流通管理办法（试行）》，1998-03-09。  
  https://www.hengqin.gov.cn/lab/flfg/bmgz/content/post_3727256.html

### 1.2 一个重要的制度前史：出售旧物早就可能要求“证明你是谁、东西从哪里来”

今天谈二手平台时，身份验证常被解释成平台经济的新要求。但 1998 年规章已经把卖方身份、物品来源与去向登记放进旧货经营制度。

因此更长的历史不能写成：

```text
匿名线下旧货
→
实名互联网平台
```

而应该问：

```text
谁负责核验身份？
旧货市场 / 校园保卫部门 / 平台账号 / 支付账户 / 手机号？

谁保存记录？
纸票 / 市场经营档案 / BBS 申请表 / 网站数据库 / 平台聊天与订单？
```

身份接口在迁移，但“陌生人之间转让有价值物品需要某种可信度”并不是互联网以后才出现。

## 2. 2004：毕业本身就是一次大规模“物品退出事件”

北京交通大学 2004 年 6 月 20 日的毕业生跳蚤市场有 160 多个摊位，商品包括书籍音像、日用百货、文体用品、小家电。学校给出的原因非常直接：2000 级本科生即将离校，**大量物品不便携带、急于处理**；而低年级学生又希望低价得到学习和生活用品。

这不是一个“喜欢淘旧货”的消费故事，而是一种生命周期基础设施：

```text
校园生活积累物品
→
毕业日期固定
→
宿舍必须退出
→
个人运输能力有限
→
在离校前短时间内集中转让
```

### 证据

- **A-/B+（大学当前官网保存的 2004 校内同期报道）**：北京交通大学，《毕业生“手递手”跳蚤市场“供销两旺”》，2004-06-22。  
  https://news.bjtu.edu.cn/info/1044/13458.htm

### 它改变了什么理解

“毕业”通常被写成学历、就业、城市选择的生命节点；这份材料提醒我们，它同时是一场非常物质的 **household disassembly**：四年形成的一套微型宿舍生活，要在几天或几周内拆掉。

## 3. 2005：Web 分类信息没有先替代线下，而是允许信息从别的通道进入 Web

客齐集（Kijiji China）2005 年的一组同期材料特别适合纠正“上网发帖 = 坐在 PC 浏览器里填表”这种后见想象。

### 3.1 小广告 → 志愿者登记 → Web

2005 年 7 月，北京一次“疏引合法小广告”活动中，志愿者一边清理街头小广告，一边把合法广告的**内容和联系方式登记下来**，再通过手机短信告知广告张贴者如何使用客齐集网站。

这是一条过渡链：

```text
电线杆 / 墙面小广告
→ 人工登记
→ Web 分类信息
```

### 证据

- **B（同期科技媒体报道）**：《客齐集北京疏引合法小广告》，2005-07-18。  
  https://tech.sina.com.cn/i/2005-07-18/0954665503.shtml

### 3.2 SMS → 客服补问 → Web listing → 甚至再进入纸媒

2005 年 7 月 27 日，客齐集推出短信发布：用户发送一条 0.1 元短信，就可以把租房、买卖物品、交友等信息交给客服中心发布到对应城市网站；信息不够详细时，客服会再打电话询问。报道还称，平台会选择部分信息发布到平面报纸，并计划通过便利店信息卡把内容送上网。

实际发布栈可以是：

```text
短信
→ 客服人员
→ Web listing
→ 纸报 / 其他线下展示
```

而不是：

```text
PC + browser + website account
→ Web listing
```

### 证据

- **B（同期媒体，含平台业务陈述）**：《客齐集网站开通短信业务》，2005-07-27。  
  https://tech.sina.com.cn/i/2005-07-27/1628675321.shtml

### 生活史意义

这进一步证明：

**`Internet benefit != direct Internet interface use`**。

一个普通人不必先熟练拥有电脑、浏览器和 Web 表单，仍可能让自己的“我要卖 / 我要租 / 我要找”进入在线可搜索的信息空间。

## 4. 2005–2006：分类信息最早扩大的不是“物流”，而是发现对方的半径

客齐集 2005 年仍强调“小社区”“村庄”和邻居对邻居的交易。同期报道把它与淘宝/eBay 区分开：二手手机等交易本来就活跃在专业论坛和本地圈子里，分类信息试图把这些分散的信息聚到同城入口。

58 同城在 2006 年的同期介绍中也把二手商品、租房、招聘、交友等放在一起，个人用户可以免费发布信息；2006 年另一篇同期报道列出其“跳蚤市场”等本地分类。

### 证据

- **B（同期媒体采访）**：《电子商务酝酿造村冲动 客齐集挖掘千亿市场》，2005-09-26。  
  https://tech.sina.com.cn/i/2005-09-26/0716728515.shtml
- **B（同期媒体）**：《58分类信息网获软银亚洲500万美元风险投资》，2006-02-12。  
  https://tech.sina.com.cn/i/2006-02-12/1519838495.shtml
- **B（同期行业报道）**：《58同城：做大分类信息的价值》，2006-10-20。  
  https://news.ouc.edu.cn/2006/1020/c425a102064/page.htm

### 不要误写成“电商闭环已经形成”

分类信息最重要的早期作用之一可能只是：

```text
我有一件东西
→ 在更大的本地人群中被发现
→ 电话 / 短信 / QQ 联系
→ 见面看货
→ 当面成交
```

它首先扩展的是 **matching / discovery**，不必然同时提供支付、鉴定、物流和争议处理。

## 5. 2008–2010：毕业季非常清楚地展示了“资产 → 流动能力”的转换

### 5.1 2008：宿舍不只是住所，也是库存和必须被清空的空间

2008 年广州高校毕业季同期报道描述，学生在离校前集中处理四年积累的物品，从冰箱、空调到水杯；一些依托宿舍做仓库的学生网店也必须在毕业前清货。

这说明“离校”会同时触发：

- 自用品退出；
- 微型经营库存退出；
- 宿舍空间清空；
- 运输 / 留存 / 抛售之间的取舍。

### 证据

- **B（2008 同期新闻）**：《毕业大甩卖成大学生活主旋律 学生网店清货忙》，2008-07-01。  
  https://news.sohu.com/20080701/n257861290.shtml

### 5.2 2009：第一人称直接说“太多、太重、离家远，所以只能卖或送”

南华大学 2009 年校园跳蚤市场上，有毕业生出售专业书、衣鞋、台灯、水壶、电风扇等。一名医学院大四学生说，临近毕业，东西太多、有的又太重，加上离家远，只能低价卖掉，甚至直接送给低年级学生。

这是本轮最直接的 contemporaneous ordinary-life evidence：

```text
物品还有使用价值
+
携带成本过高
+
离校期限逼近
→
转让价格下降，甚至价格降到 0（赠送）
```

### 证据

- **A-/B+（大学官网保存的同期校园报道；含学生同期自述）**：南华大学，《二手物品交易的平台—校园跳蚤市场》，2009-05-16。  
  https://tw.usc.edu.cn/info/1003/1156.htm

### 5.3 可以把它理解成 `asset-to-mobility conversion / 资产向流动能力转换`

这里的“资产”不是金融意义上的高价值资产，而是一个人拥有的、仍然有使用价值的日常物。

毕业生通过低价出售 / 赠送做的事是：

```text
减少体积和重量
+
回收少量现金
+
按时退出宿舍
```

一件旧电风扇可能卖得很便宜，但它不再需要被跨省搬运。本轮因此把“二手转让”纳入迁移基础设施，而不只纳入消费史。

## 6. 2009：校园 Web 不是远距离电商，而是把“摆摊时间”从匹配动作里拆出来

中国地质大学（武汉）2009 年的一份同期报道记录，大二学生张华看到校园里大量摆地摊和墙面求购/甩卖广告后，花 300 元买域名，建了一个只面向本校的跳蚤网站。

网站允许学生发布闲置物；交易可以由卖家自己完成，或委托网站代卖。张华通过寝室楼纸质广告、QQ 签名、好友群和广告衫推广。几天后网站已有 100 多件商品，分类为教材、文具、IT 等。

更关键的是张华自己的解释：学校里有很多“想卖东西但没时间摆地摊”的人，也有“想买东西但不想去地摊”的人；校内交易又**不需要支付宝、不需要快递、不需要邮费**。

### 证据

- **B（《长江商报》同期报道，由中国地质大学新闻网保存；含学生同期第一人称）**：《大二学生“淘宝”高校二手市场》，2009-05-17。  
  https://voice.cug.edu.cn/info/1006/7890.htm

### 它真正改变的是哪一段？

```text
过去：
卖家必须在某个地点、某段时间和货物一起出现
↓
买家也必须同一时间经过

校园网站：
卖家先留下物品信息
↓
买家异步发现
↓
双方仍在校园内完成实际交换
```

所以 Internet 在这里首先减少的是 **co-presence requirement / 同时在场要求**，而不是消灭线下交付。

## 7. 2010：BBS 可以成为线下市场的行政入口，而不是线下的替代品

南京大学 2010 年毕业生跳蚤市场非常适合作为线上/线下混合案例：

- 市场每天有明确开放时段和地点；
- 只允许毕业生出售自己大学期间的学习与生活用品；
- 卖家要填写审批表，写明身份、销售时间地点和物品范围；
- **审批表可以从小百合 BBS 下载**；
- 院系与保卫部门审批登记后，发放登记证明。

### 证据

- **A-/B+（南京大学保卫处当前官网保存的 2010 同期正式通告）**：《关于规范2010年度“毕业生跳蚤市场”活动的通告》，2010-06-18。  
  https://bwc.nju.edu.cn/1b/1c/c577a6940/page.htm

### 为什么这条很重要

Internet 并不是一个独立“线上世界”。在这里它只是嵌进一条线下制度链：

```text
BBS 下载表格
→ 填身份与货品
→ 线下审批
→ 获得登记证明
→ 到固定地点摆摊
→ 当面交易
```

**Web/BBS 可以先数字化信息入口，而实际交易场景、身份审核和物品交付继续留在线下。**

## 8. 2015–2019：二手平台逐渐成为城市迁移者的“常规清空动作”

2019 年一组同期采访特别适合把二手平台重新接回“怎么生活”，而不是行业规模。

其中张维因为在大城市多次搬家，已经养成“不乱买、不囤货”的习惯；即便如此，每次搬家仍会出现搬不走或嫌麻烦而放弃的东西。卖废品觉得可惜，于是把物品“挂”到二手平台已经成为熟悉的常规动作。

同一篇采访中：

- 吴静会把看完、不再利用又占空间的书卖掉；
- 马帅在“双十一”买多以后，把多余物品转卖“回血”。

### 证据

- **B（2019 同期媒体采访；多个普通用户自述，非人口概率样本）**：《两亿用户淘二手，骗子能否毁掉这个市场？》，2019-11-26。  
  https://news.pedaily.cn/201911/448872.shtml

### 对“拥堵型未来”的修正

二手平台不是只有“消费降级”一种含义。它至少可以执行三种不同动作：

1. **空间退出**：搬家前让物品离开；
2. **预算回收**：把误购/闲置变回部分现金；
3. **使用价值再匹配**：让别人接手仍能用的东西。

因此“拥堵”在家庭层面也可以表现为：城市住所空间有限、搬家频繁、消费选择又很多，导致**持有物品本身开始具有持续管理成本**。

## 9. 2020–2022：平台已经很普及，但“处理掉一件东西”仍然需要劳动

2022 年《中国青年报》社会调查中心与问卷网的一项 1185 人调查中，58.1% 受访者表示处理闲置物品有困难。这个在线/社会调查样本不能自动代表全国人口，但它非常适合说明：平台存在并没有消灭退出摩擦。

在北京租房的受访者张明博（化名）说，每次搬家都筋疲力尽，收拾时总会发现很多闲置很久、又舍不得丢的东西。

报告里列出的困难包括：

- 卖不出去；
- 丢掉可惜；
- 捐赠渠道不方便；
- 处理费时费力；
- 对平台规范、透明和社区跳蚤市场仍有需求。

### 证据

- **B（中国青年报 2022 同期调查与采访，人民网转载）**：《卖不出去、扔了可惜 58.1%受访者在处理闲置物品上有困难》，2022-04-07。  
  https://finance.people.com.cn/n1/2022/0407/c1004-32393275.html

### 对 2020–2022“偶发型未来”的边界

这条材料属于 2022 年，但**不能据此说疫情导致了二手交易或搬家处理困难**。本轮只把它作为当期 ordinary-life evidence：

> 即使在线平台已经成为成熟选项，用户仍然要拍照、定价、回复、协商、等待买家、安排交付；没有买家时，物品仍然留在屋里。

因此：

**`marketplace availability != successful possession exit`**。

## 10. 2021–2025：可转售性开始影响“我现在敢不敢买”

2021 年《中国青年报》采访一名 90 后消费者陈豆豆，她说自己“喜新厌旧”，二手包适合她，因为不喜欢时可以比较快转卖，也不会损失太多。报道同时记录二手母婴用品、兴趣服装、3C 产品等多种再流通场景。

2025 年《人民日报》采访 24 岁的胡宇星：她两年前到杭州工作，已经习惯从衣物、箱包、化妆品到家居用品都先看二手；她明确说不是买不起新品，而是二手更具性价比。同期报道也记录，年轻用户会在买家和卖家身份之间切换，把闲置物“赚钱回血”。

### 证据

- **B（中国青年报同期采访）**：《从“买家”到“卖家” 年轻人撑起万亿二手交易市场》，2021-12-07。  
  https://www.dzwww.com/xinwen/guoneixinwen/202112/t20211207_9525506.htm
- **B+（人民日报同期采访）**：《绿色消费成年轻人“心头好”》，2025-02-17。  
  https://finance.people.com.cn/n1/2025/0217/c1004-40419513.html

### `resale optionality / 可转售性带来的选项价值`

一件商品如果未来容易卖掉，购买就不再完全像不可逆的 sunk cost：

```text
现在买
→ 使用一段时间
→ 未来不需要 / 搬家 / 兴趣改变
→ 再转售
→ 回收部分现金与空间
```

这并不意味着二手价格稳定，也不意味着平台保证能卖出；诈骗、假货、等待时间、折价和交易劳动都可能吞掉这种“选项价值”。

但对 2023–2026“防守型未来”而言，它提供了一种值得继续观察的微观策略：

> 与其要求每次购买都“一次买对、永久持有”，一部分人更愿意选择未来还能退出的商品和渠道。

本轮只有个案和媒体材料，不能把这种逻辑外推成全体青年共同的防守性消费心理。

## 11. 跨国对照：二手物品电子匹配早于大众 Web

### 11.1 1985 美国：个人已经会因为技术淘汰担心“现在不卖，以后更不值钱”

TIME 1985 年报道 IBM PCjr 停产影响时，采访一名 1984 年刚买机器的夜班酒店审计员。得知产品停产后，他立即联系 Boston Computer Exchange 挂售，希望赶在更多人知道消息前卖掉；即使降到原标价的约六成，仍没有买家。

这条材料说明 **resale optionality 也可能失败**：产品的未来支持、配件和软件生态一旦崩掉，资产价值会迅速下降。

- **B（1985 同期新闻）**：TIME, “Computers: A Generation of Orphans”, 1985-04-08.  
  https://time.com/archive/6710310/computers-a-generation-of-orphans/

### 11.2 1990–1991：BBS/在线服务可以负责“发现”，电话、物流和托管账户负责后续

1990 年《Washington Post》介绍美国二手电脑市场时明确建议，用户可以用 modem 呼叫本地或全国 BBS；CompuServe、MCI Mail、Delphi 等在线系统可接入 Boston Computer Exchange。1991 年 Inc. 对二手电脑交易所的描述则显示：交易所撮合买卖双方，买方把钱交给交易所进入 escrow，卖方发货，买方检查后再放款。

所以在大众 Web 之前已经存在：

```text
电子列表 / BBS 发现
→ 电话或经纪撮合
→ 托管付款
→ 物流发货
→ 检查
→ 放款
```

- **B（1990 同期消费技术报道）**：Washington Post, “Used-equipment market is haphazard, but bargains can be found”, 1990-09-24.  
  https://www.washingtonpost.com/archive/business/1990/09/24/used-equipment-market-is-haphazard-but-bargains-can-be-found/3749531f-bfe4-4144-a4e1-7e7566a244c4/
- **B（1991 同期商业报道）**：Inc., “The Used-Computer Market”, 1991-05-01.  
  https://www.inc.com/magazine/19910501/4613.html

### 11.3 1995–2004 Craigslist：从 email list 到本地分类信息，是同一种“发现基础设施”继续扩大

Craigslist 自己的历史页称，1995 年从旧金山本地事件 email list 开始，后来用户开始发布工作、出售物品、公寓等内容，系统把 email 投稿自动加到网站；2004 年 BusinessWeek 的同期访谈里，CEO Jim Buckmaster 回忆自己 1990s 末就曾在 list 上卖 futon、找公寓、贴简历。

- **C/B（平台后来的第一方历史说明）**：Craigslist, “mission and history”.  
  https://www.craigslist.org/about/mission_and_history
- **B（2004 BusinessWeek 访谈，由 Craigslist 保存）**：“A Talk with craigslist's Keeper”, 2004-09-08.  
  https://www.craigslist.org/about/press/craigslist.keeper

### 跨国判断

共同变化不是“中国从摆摊进化到 App”或“美国先发明网上二手”。更一般的过程是：

```text
本地旧货 / 纸广告 / 校园告示
→ 电话 / BBS / email / Web 把供需异步化
→ 搜索和分类扩大可发现范围
→ 支付、身份、物流、评价再逐渐接入
```

而对于便宜、笨重、强本地性的物品，**发现半径扩大以后，实际交付仍可能长期保持线下和近距离。**

## 12. 四个时代的比较：这条基础设施怎样改变“未来”

### 2005–2012：扩张型未来

关键变化不是“人人靠卖二手赚钱”，而是一个学生、租客或普通城市居民可以更容易试着把手中的东西送到更大的潜在接手者集合中。

- 毕业时不一定只能丢掉或跨省背回去；
- 没时间摆摊，也可以先留下 listing；
- 没有 PC，也可能通过 SMS / 便利店信息卡进入 Web 分类页；
- BBS 可以成为线下市场的组织接口。

这使物品和人的未来开始更容易分开：**人去下一座城市，东西留给下一个使用者。**

### 2015–2019：拥堵型未来

城市租住、多次搬家和高频消费让“持有什么”本身变成管理问题。

二手平台的价值不只在“便宜买”，而在：

- 清空间；
- 减少搬家重量；
- 把误购变回部分现金；
- 不让所有东西最后只剩废品价格。

### 2020–2022：偶发型未来

本轮没有找到足以支持“疫情导致二手退出机制发生结构改变”的强一手证据，因此不硬写因果。

2022 材料能确认的是：在线二手已经成熟，但**退出仍然可能失败**；家里仍会积累“卖不掉、扔了可惜、捐不方便”的物品。

### 2023–2026：防守型未来

2025 的个案显示，“二手 = 买不起新品”已经不是唯一使用逻辑；性价比、未来可转售、减少闲置，都可以成为主动策略。

更值得后续追的是：

> 当人更重视现金缓冲、迁移弹性和避免 sunk cost 时，**“以后还能卖掉”是否开始进入购买决策本身？**

目前证据能证明这种逻辑存在，不能证明它已经成为普遍青年价值观。

## 13. 反例与边界

### 13.1 能发布不等于能卖掉

2022 调查正是反证。平台入口存在，仍有大量人感觉闲置物难处理。

### 13.2 转卖不是无摩擦金融资产

二手商品会：

- 折价；
- 被技术淘汰；
- 找不到买家；
- 产生鉴定和信任成本；
- 需要拍照、描述、聊天、议价、寄送或见面；
- 遇到诈骗、假货与纠纷。

因此不能把“可转售性”浪漫化为完全流动的资产。

### 13.3 赠送也是一种退出机制

2009 毕业材料提醒我们：当截止日期逼近、运输成本过高时，最优价格可能不是“卖最高”，而是**快速找到接手者**。赠送、捐书、送学弟学妹同样属于 possession exit infrastructure。

### 13.4 旧货经营制度与私人偶发转让不要混淆

1998 规章提供的是正式旧货市场/经营者制度证据，不能机械套到每一个学生之间的私下交易，也不能据此推断后来每个互联网平台承担完全相同的法定义务。

## 15. 后见之明风险

### 风险 A：把二手平台写成“循环经济意识觉醒”

毕业甩卖和搬家处理可能首先是重量、空间、现金和截止日期问题；环保意义可以存在，但不能覆盖所有人的第一动机。

### 风险 B：把 2005 分类信息写成今天的 App 电商

当时 Web listing 很可能只是一个 rendezvous point。交易可以继续依赖电话、短信、QQ 和当面交付。

### 风险 C：把线下市场写成“低效前现代遗留”

2009 校园案例反而说明：对一个学校内部的便宜大件物品，**不需要支付宝、不需要快递、不需要邮费**正是本地线下交付的优势。

### 风险 D：把“回血”自动解释成经济悲观

它既可以来自预算压力，也可能来自高频消费、兴趣变化、搬家、空间管理和主动追求性价比。必须保留动机分布。

## 16. 它改变了我们对“人怎么活着”的哪一点理解

以前的迁移模型很容易只写：

```text
找到工作
→ 找到房子
→ 买到车票
→ 搬去新城市
```

现在至少要加一段：

```text
旧住所里已经有一套物质生活
→ 决定什么跟着人走
→ 什么变成现金
→ 什么送给别人
→ 什么最终只能丢掉
→ 清空旧空间
→ 人才真正能离开
```

**普通人的流动性，不只由交通、户籍、住房和工作决定，也由她能不能从自己已经拥有的东西里退出。**

而二手网络真正改变的，不只是“淘便宜货”——它让一个人在购买以后，多了一条可能的未来路径：

> **这件东西今天属于我，但它不一定必须一直跟着我。**

## 17. What we know / infer / do not know

### What we know

- 1998 年正式旧货市场已被制度化为包含信息、评估、结算、运输、身份记录的服务体系；
- 2004–2010 多所高校的同期材料明确把毕业离校和物品“不便携带 / 太多太重”联系起来；
- 2005 年中国分类信息平台实际试过 SMS、人工登记、便利店信息卡等非 Web 输入通道；
- 2009 年校园网站可以把“必须摆摊才能被看见”改成异步发布和发现，同时保留校内面对面交付；
- 2019、2022 的 contemporaneous evidence 直接把搬家、占空间、闲置处理和二手平台联系起来；
- 2021–2025 已有第一人称把“以后能转卖 / 更具性价比”作为购买逻辑的一部分。

### What we can reasonably infer

- 二手流通是迁移基础设施的一部分，因为它能把难运输的物品转换成现金、赠与或本地接手；
- Internet 对这一生活动作最早的改变之一，是降低供需双方必须同时出现在同一地点的要求；
- 对便宜/笨重物品，本地匹配和线下交付可以长期比“全国物流式电商”更合理；
- 当转售渠道稳定存在时，一部分消费者可能把 resale value 当作购买可逆性的一部分。

### What we do not yet know

- 1990s 普通家庭处理家具、家电、书籍的实际渠道占比；
- 旧货商店、废品回收、亲友转赠、跳蚤市场和互联网平台各自承担多少流量；
- 2005–2010 分类信息网站上二手 listing 的成交率、平均存活时间和线下见面比例；
- 早期校园 BBS/分类信息中有多少“卖掉”状态会被更新或删除；
- 搬家频率与二手平台使用之间有没有可靠微观调查；
- 2023–2026 的“现金缓冲 / 退路 / 可转售性”是否已经能在高质量调查中与宏观不确定感建立明确关系。

## 18. 下一步

高价值后续不是再找十篇“年轻人喜欢二手”的报道，而是：

1. 找 1990s 城市旧货市场的同期价目、广告、电话预约上门记录或消费者口述；
2. 找 2005–2010 可实际打开的客齐集 / 58 / 校园二手版历史 capture，恢复 listing 字段、联系方式、发布时间、城市粒度和删除/过期语义；
3. 找 2007–2010 普通用户而非创业者的 Web/BBS 二手发布原文，按隐私最小化处理；
4. 找 2018–2019 “因为搬家 / 换城市 / 租房而出售”的 contemporaneous forum/blog 样本；
5. 找 2023–2026 对 resale value、现金缓冲和购买决策的调查数据，判断“可转售性”到底是个案策略还是更广泛的时间感变化。
