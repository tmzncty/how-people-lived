# 可携带的长途通话权：IP 电话卡、公用话吧与离家生活的通信成本，中国 1999–2008

> 研究问题：在个人手机尚未成为默认终端、家庭固定电话又并非人人拥有或人人能自由使用时，学生、流动劳动者和普通家庭怎样获得便宜的长途通信？Internet/IP 基础设施是否可能在一个人并不“上网”的情况下改变其生活？
>
> 本条目与 `topics/communication-and-the-cost-of-living-far-away.md` 直接相连。它补的是该文件研究议程里尚未单独展开的 **public telephone shops / long-distance calling prices**，不是再写一篇泛泛的“电话让迁移更容易”。

## 0. 本轮新增结论

这一组材料提示，1999–2000 年代初中国长途通信的关键变化，不只是“更多家庭装了电话”或“手机开始普及”。还出现了一种介于家庭固定电话和个人手机之间的基础设施形态：

```text
共享 / 借用 / 公共电话终端
+
个人持有的卡号、密码或预付费余额
+
运营商的 IP 长途网络
=
不拥有电话线路的人也可以购买一段可携带的长途通话能力
```

因此本轮使用两个工作概念：

- **portable service entitlement / 可携带的服务权**：长途通话资格部分从某一条家庭线路上剥离，变成用户可以随身携带的卡、账号、PIN 或预付费余额；
- **terminal–service decoupling / 终端—服务解耦**：终端可以属于宿舍、学校、商店、工地、公用电话亭或其他人，而长途服务的付费身份属于实际呼叫者。

这使“有没有电话”不再只有 `家里装没装固定电话` 这一种答案。

同时必须保留另一条不对称：

> **cheap outbound calling != personal inbound reachability**
>
> 便宜地从一个公用终端给家里打出去，并不自动意味着家人也拥有一个稳定、个人化、随时可回拨的号码找到你。

这类基础设施首先降低的是**主动联系远方**的成本，和后来“每个人都有一个随身号码、可以被随时找到”的移动通信生活并不相同。

## 1. 1999：IP 长途先成为一种电话业务，而不是一种 Web 用户行为

1999 年 4 月 27 日，信息产业部批准中国电信、中国联通、吉通开展 IP 电话业务试验。次日《人民日报》报道：

- 中国电信试验接入号 `17900`；
- 中国联通 `17910`；
- 吉通 `17920`；
- 试验期国内长途暂定 **0.30 元/分钟**；
- IP 电话资费之外，用户仍需支付本地电话接入费用。

来源：

- 《人民日报》，1999-04-28，《IP电话试验正式获准　试验期间国内长途每分钟仅0.3元》：https://cn.govopendata.com/renminribao/1999/04/28/2/

**证据强度：B（同时代全国报纸对主管部门公告的报道）。**

这里最需要避免的后见之明，是把“IP 电话”自动理解成“用户打开电脑上的 Internet 软件打电话”。同期联通使用说明明确展示了另一条普通路径：固定电话用户购买 IP 电话卡，在双音频电话机上拨 `17910`，再按语音提示输入卡号、密码和对方号码。

来源：

- 中关村在线 / 北京青年报，2000-06-12，《联通IP又开通哪些城市》：https://news.zol.com.cn/2000/0612/5333.shtml

因此：

```text
voice call transported by an IP network
!=
caller operating a Web browser
!=
caller owning an Internet-connected computer
```

一个人可以已经在使用 IP 网络降低远距离联系成本，却完全不把自己理解为“正在上网”。

## 2. 预付费卡把“长途账户”从家庭电话线上拆了下来

2000 年深圳的同期报道已经把 IP 卡描述成普通市民熟悉的省钱工具：在固定电话上使用 IP 卡，国内长途约 0.30 元/分钟，而传统固定长途更贵；报道还列出联通、吉通、网通和中国电信等多种卡。

来源：

- 《深圳商报》2000-12-08，新浪保存页：https://finance.sina.cn/sa/2000-12-08/detail-ikftpnnx6095431.d.html

到 2001–2002 年，卡本身又形成高折扣零售市场。南京 2001 年报道明确说当地高校、驻军、打工人员多，电话卡销量大，一张面值 100 元的 IP 卡可以按约 40 元成交；2002 年北京市场报道也列出多运营商、多面值卡以及不同折扣。

来源：

- 人民网 / 新浪，2001-10-29，《疯狂打折透出降价空间 南京IP电话卡四折起售》：https://tech.sina.com.cn/it/t/2001-10-29/89668.shtml
- 中关村在线，2002-03-22，《种类繁多打折疯狂 IP卡你选哪一种》：https://news.zol.com.cn/2002/0322/37934.shtml

**证据强度：B。**

这里的生活史意义不是“电话卡便宜”本身，而是账户和终端发生了部分分离：

```text
I own a home telephone line
```

不再是获得低价长途的唯一入口。更接近的是：

```text
I can obtain a phone terminal long enough to dial
+
I carry my own card / account / PIN / balance
```

于是宿舍电话、公用电话、单位电话、亲友电话和话吧终端，都可能成为同一个人的临时通信终端。

这是一种在智能手机账户体系之前就存在的**服务可携带性**。

## 3. 2003：大学生把两套卡叠在一起，主动优化通信成本

2003 年 7 月，北京通信关闭 201 卡套拨其他 IP 长途卡的功能后，《京华时报》记录了很具体的学生行为。

报道说，一些大学生表示，大部分学生会使用 **201 卡套拨 IP 卡**：先拨 201 卡，再继续输入 IP 卡号；这样可以只付每分钟 0.30 元的 IP 长话费，绕开普通 IP 卡使用固定电话时额外的本地通话费。功能关闭后，北京通信客服投诉量明显增加。

来源：

- 《京华时报》2003-07-23，新浪保存页，《不准用201卡套拨IP电话》：https://news.sina.cn/sa/2003-07-23/detail-ikkntiak7674806.d.html

**证据强度：B；同时代用户群体自述由记者转述。**

这一材料增加了一个不能被“电话越来越普及”概括掉的机制：

### tariff-stack arbitrage / 资费栈套利

普通用户不是被动接受单一价格表，而会把：

- 宿舍 / 校园 201 终端；
- 201 卡的接入能力；
- 另一家运营商的 IP 长途卡；
- 本地通话费和长途费的结算边界；

组合起来，寻找更便宜的通信路径。

也就是说，2000 年代初的一部分学生已经在做一种很日常的“通信路由优化”，只是他们优化的对象不是 VPN 或数据流量，而是**一分钟给家里打电话到底走哪一层资费**。

这也提醒研究者：

```text
listed tariff
!=
effective household/student calling cost
```

因为实际成本还取决于折扣购卡、套拨、共享终端和运营商互联策略。

## 4. 公用话吧把共享电话变成流动人口的通信前台

2003 年南京的同期报道把 IP 话吧与流动人口直接连在一起。

江苏联通有关人士称，联通从 2001 年就在省内铺设长途话吧；城市边缘、流动人口密集区和建筑工地是重要布点区域。报道解释：工地和暂住地即使有电话，也无法满足每个人的需要，手机又不是人人都有且通话较贵；话吧使农民工能够“想打就打”，坐在室内给家里打电话。

来源：

- 《扬子晚报》2003-07-11，新浪保存页，《城市话吧上演“三国大战”》：https://news.sina.com.cn/s/2003-07-11/0811360267s.shtml

同年对全国移动“话吧”的调查又说，这些运营商委托个体商户经营的设施大量布置在居民区、打工流动人口和学生聚集区，并把其现实作用概括成缓解“打电话难”“打长途贵”。

来源：

- ChinaByte / 新浪，2003-12-02，《移动“话吧”调查：低价长途背后的灰色陷阱》：https://tech.sina.com.cn/it/t/2003-12-02/1526262920.shtml

**证据强度：B。**

这里出现了一种介于“我家电话”和“我自己的手机”之间的通信生活：

```text
shared commercial terminal
+
walk-in access
+
per-call / metered payment
+
cheap long distance
```

它特别适合：

- 在城里没有自己固定电话的流动劳动者；
- 集体住宿者；
- 手机尚贵的学生；
- 临时旅行者；
- 需要偶尔打长途、但没有理由为此建立完整家庭通信账户的人。

因此“服务可及”必须和“家庭拥有”分开。一个人没有电话，并不等于他完全没有实时远程通信；相反，他的通信可能依赖**步行到某个地点、排队、付费、在半公共空间完成一次通话**。

## 5. 这类基础设施降低分离成本，但没有制造今天式的持续在线

IP 卡和话吧确实能降低远距离家庭联系成本，但不能把它浪漫化为“手机时代已经提前到来”。

至少存在以下差异：

1. **个人终端不持续在身边**：需要找到宿舍电话、话吧、公话或可借用电话；
2. **入站可达性可能仍弱**：共享终端改善的是主动拨出，不必然给每个人一个稳定回拨号码；
3. **隐私有限**：话吧、宿舍和公用电话通常不是私人空间；
4. **卡和线路会失败**：卡余额、接入号、互联、线路拥塞和运营商政策都可能阻断一次通话；
5. **使用仍需程序知识**：接入号、卡号、密码、区号、长串按键都构成微小但真实的操作成本。

2004 年宁波一名老人就因为一张吉通 IP 卡只使用一部分后突然无法继续拨打，向媒体投诉；报道显示公司合并、卡停止发行与客服解释之间存在明显断裂。

来源：

- 宁波晚报 / 新浪，2004-11-26，《50元话卡为啥打了20元就“卡壳”》：https://news.sina.com.cn/s/2004-11-26/13414355820s.shtml

**证据强度：B；同期个人投诉。**

因此：

```text
portable prepaid entitlement
!=
guaranteed service continuity
```

账号变得可携带的同时，普通人也第一次需要自己承担卡是否有效、运营商是否还存在、余额如何解释、接入码是否互通等服务连续性问题。

## 6. 2008：手机并没有让所有公共电话形态在同一天消失

2008 年广州记者调查记录到两个并存的现象：

- IC 卡电话亭已经明显冷落；一位居民回忆早期电话亭曾经需要排队；
- 但附近公用话吧仍有顾客，店主解释，一些人忘带手机、需要便宜打长途或临时应急时仍会使用；
- 报道同时回顾，2003 年后广州的 IP 话吧 / 公话超市在学校、网吧和街头快速出现，并以电脑计费和直接拨号减少了过去连输卡号、密码的步骤。

来源：

- 《信息时报》2008-10-16，新浪保存页，《过气电话亭成了都市“鸡肋”》：https://news.sina.com.cn/o/2008-10-16/040714580738s.shtml

**证据强度：B；其中“早年排队”的部分属于同时代采访中的回顾性自述，应单独视作 C。**

这说明技术替代不是：

```text
public telephone -> mobile phone
```

在某一天整齐切换。

更接近：

```text
IC booth declines
+
phone bar retains price / shelter / backup advantages
+
mobile becomes increasingly personal and ubiquitous
```

不同通信形态会因为价格、场所、隐私、可回拨性和便利性，在一段时间里重叠存在。

## 7. 一个回顾性学生切片：从排队，到宿舍卡号，再到网线

2012 年《北京晨报》回顾高校迎新生活时，保存了两条不同年代的个人记忆：

- 一名 1992 年入学者回忆，当时往家里打电话要排长队，有专人掐表计时，打久了后面的人会不满；宿舍楼接听电话也可能只有楼管处一条线，由楼管上楼叫人；
- 一名 2002 年入学者回忆，宿舍已安装 201 电话，需要自己购买卡、输入卡号和密码；2003 年又开始出现宿舍网线端口。

来源：

- 北京晨报 / 大众网，2012-09-06，《时代变迁：开学，迎新路上二十年》：https://edu.dzwww.com/kszx/gk/gkkd/201209/t20120906_7406821_4.html

**证据强度：C（多年后的回顾性第一人称），不能用来单独钉死全国时间点。**

但它很好地展示了一种生活流程变化：

```text
shared scarce telephone + human queue
->
shared/dorm terminal + personal card/account
->
personal mobile / networked devices
```

这不是简单的“越来越先进”，而是**个人对通信资源的控制权逐步从排队和管理员，移动到自己携带的凭证，再移动到自己携带的终端。**

## 8. 海外比较：美国预付费电话卡也把服务从固定订户线上拆下来

这个机制并非中国特有。

美国 FTC 在 1997 年处理预付费电话卡欺诈案时，已经把这种产品描述为许多无家庭电话的住户、学生、旅行者以及没有长途服务的人获得电话服务的重要方式。涉案公司特别面向印度裔美国人销售可低价拨打印度等地的电话卡，并通过少数族裔报纸、零售点和 Web 页面营销。

来源：

- U.S. Federal Trade Commission, 1997-08, “FTC Charges Seller of Prepaid Phone Cards with Deception…”：https://search.ftc.gov/news-events/news/press-releases/1997/08/ftc-charges-seller-prepaid-phone-cards-deception-causing-substantial-losses-consumer

**证据强度：A/B（同时代监管文件；对市场行为的指控需保留“alleged”性质）。**

2001 年《Washington Post》又在华盛顿都会区的公共电话旁直接观察到移民购买电话卡后给原籍国亲友打电话。一名斯里兰卡移民说，他一直无法接通妻子和孩子，但每次失败呼叫仍被扣费。

来源：

- *The Washington Post*, 2001-09-02, “Hearing the Call”：https://www.washingtonpost.com/archive/lifestyle/magazine/2001/09/02/hearing-the-call/ee726499-68f7-4fb3-a3f0-6e29811ea3d9/

**证据强度：B；同期现场观察与第一人称。**

跨国共同机制是：

```text
subscriber line ownership
```

开始不再决定一个人是否能购买长途通信。预付费账号 / PIN 让通信能力可以附着到公用电话、借来的电话或临时终端。

中国材料目前显示的一个较鲜明差异，是这种可携带账户又与：

- 运营商 IP 长途接入码；
- 校园 201 系统；
- 高折扣卡市场；
- 城市边缘的运营商 / 个体话吧；

组合成了非常复杂的资费栈。

但当前证据不足以声称这种组合“中国独有”。

## 9. 它改变了我们对“人怎么活着”的哪一点理解

过去的通信史很容易被写成设备拥有史：

```text
没有电话 -> 家里装固定电话 -> 买手机 -> 上网
```

这组材料说明，中间其实存在一个很大的生活世界：

> **终端不属于我，但一段通信能力可以属于我。**

对于在外求学、进城务工、住集体宿舍、短期旅行或刚到陌生城市的人，这很重要。一个人不必先建立自己的家庭固定电话，也不必先买得起手机，就能用一张卡和一个临时终端把远方家庭重新接进日常。

因此“远离家乡的通信成本”至少要拆成：

- 找到终端的成本；
- 本地接入成本；
- 长途分钟成本；
- 购买 / 保存个人账户或卡的成本；
- 排队与场所成本；
- 隐私成本；
- 被家人反向找到的成本。

最后一项尤其重要：

> **能便宜打回家，是迁移生活的一次重要改善；能让家人随时找到自己，则是另一轮改善。**

两者不应被同一个“电话普及”指标吞掉。

## 10. 反例、边界与后见之明风险

### 不能从这些材料推出

- 1999 年普通人已经普遍使用 IP 电话；
- 所有农民工都依赖话吧；
- 有 IP 电话卡就等于本人会使用 Internet / Web；
- 卡面值等于实际购买成本；
- 折扣越大就一定意味着真实分钟成本越低；
- 一次便宜拨出就意味着双向、持续、私人可达；
- 手机出现后公用电话立即消失。

### 样本偏差

- 城市新闻对价格战和“新鲜通信方式”有报道偏好；
- 学生和流动人口更容易在“话费高 / 话吧竞争”报道中出现；
- 2003 北京大学生的“多数学生”说法来自媒体采访，不是抽样调查；
- 2008 广州调查是地方切片；
- 2012 高校材料是回顾性记忆。

### 尚未确定

- 1999–2003 各地区 IP 卡、201 卡和话吧的真实人口覆盖率；
- 学生 / 流动劳动者平均每周实际打几次长途、每次多久；
- 公共终端的入站回拨安排究竟有多常见；
- 不同运营商卡的失败率、到期规则和真实折扣后的分钟成本；
- 公用话吧是否显著改变返乡频率、家庭冲突或汇款决策；
- 何时个人手机真正让这套 `shared terminal + portable account` 模型退出多数人的日常。

## 11. 后续最值得找的材料

1. 1999–2003 真实 IP 电话卡正反面扫描、卡套和使用说明；
2. 高校 201 电话用户手册、宿舍公告、学生同期 BBS 讨论；
3. 工地 / 城郊话吧的同时代使用者第一人称；
4. 公话 / 话吧价格与当地工资的同年比较；
5. 有稳定个人手机号前后，同一流动家庭联系频率的生命史；
6. 公共电话 / 话吧是否允许回拨、留言或转接，以及用户如何安排“几点钟打来”。

这些材料可以进一步回答一个比“手机什么时候普及”更细的问题：

> **一个离家的人什么时候不再需要先找到一台电话，才有资格进入家庭的实时生活？**
