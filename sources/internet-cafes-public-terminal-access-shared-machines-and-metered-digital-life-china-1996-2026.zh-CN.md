# 网吧、公共终端与“租一小时电脑”：中国普通人的公共互联网入口，1996–2026

> 类型：跨时期 communication / information-access / work-and-family life-path 研究包  
> 核心问题：在家庭尚未拥有电脑、电话线、宽带或合适硬件时，一个普通人怎样实际进入互联网？当“上网”发生在别人的机器、按小时计费、受营业时间和身份登记约束的公共空间里时，网络生活是什么样？  
> 时间范围：1996–2026  
> 与 `old-web-archaeology` 交叉：公共终端的操作系统、浏览器、网管/计费壳、实名登记、还原软件和临时 session 往往不在网页档案里，却直接决定旧网页当时能否被普通人使用。  
> 证据纪律：不把“城市已有网吧”写成“普通家庭已经上网”；不把早期昂贵网络咖啡屋、2000s 大众网吧和今天电竞馆视为同一种消费；不把 CNNIC 网上问卷比例当成人口普查；不把“网吧使用率下降”写成公共共享算力完全消失。

## 0. 去重：这不是再写一次“拨号上网很贵”或“互联网进入家庭”

仓库已经有：

- 拨号家庭的电话线占用、计时资费和离线读写；
- CFido 的离线优先社交；
- 招聘网站、电子邮件、BBS、网店等具体 Web 路线；
- 迁移、异地家庭和远程沟通。

本文件补的是一个此前没有独立建模的中间状态：

> **互联网已经可以被普通人使用，但使用者不一定拥有一台自己的联网电脑，也不一定从家里上网。**

需要严格拆开：

```text
互联网在本地存在
!= 某单位/学校已经接入
!= 城市里有商业网吧
!= 一个人付得起一小时上机费
!= 一个人家里有电脑
!= 家里有可用线路/宽带
!= 可以随时、私密、持续地上网
!= 已经把网络嵌入日常生活
```

这正对应 `METHODOLOGY.md` 的 adoption ladder：**service access 可以先于 household ownership**。

本轮新增的核心概念是：

## **`public-terminal internet / 公共终端互联网`**

以及它对应的一种生活状态：

## **`metered digital life / 按时计费的数字生活`**

一个人的邮箱、QQ、论坛身份或求职账号可以属于自己，但进入这些身份所用的电脑、桌面、硬盘、浏览器和网络时间都可能只是按小时租来的。

## 1. 1996–1997：正式 Internet 已经进入城市，但家庭所有权并不是唯一入口

2019 年《北京日报》历史栏目根据本报 1996–1997 年同期报道回溯：1996 年 11 月，北京“实华开网络咖啡屋”开门；1997 年 1 月记者探访时，店内有 11 台奔腾电脑。现场顾客包括发电子邮件的大学生、查资料的公司职员、网上聊天的年轻人和玩联网游戏的外国人。

来源：

- 人民网转载《北京日报》，2019-10-17，《1996年互联网初入北京城 嘶哑拨号声链接“新世界”》：  
  https://media.people.com.cn/n1/2019/1017/c40606-31404334.html

**证据等级：B/C 混合。** 当前页面是 2019 年回顾，但明确引述 1996-11-23、1997-01-24 的《北京日报》同期报道，可用于恢复当时观察到的用途；在没有直接取得原报版影像前，不把它升级成 A。

同一回顾材料称，1996 年北京网吧上机价格约 **30 元/小时**，而高上网成本仍限制家庭接入。

这里最重要的不是争论“全国第一家网吧”究竟在哪里、哪天开业——这一点在后来的报道里本身就存在口径冲突——而是确认一种新入口已经出现：

```text
我没有家庭联网电脑
→ 我可以去一个物理场所
→ 租用一台已经联网的终端
→ 在有限时间里发邮件 / 查资料 / 聊天
→ 结账离开
```

这不是家庭 Internet 的缩小版。它把固定资产门槛改写成了**按次/按时购买访问权**。

因此本轮增加：

## **`fixed-cost → time-rent conversion / 固定成本转化为时间租金`**

买电脑、装电话、开户这些较大的前置成本，可以部分被“今天先买一小时”替代。

但它并不意味着更便宜到人人可及。1996 年约 30 元/小时本身就是很高的选择门槛，早期网络咖啡屋首先仍偏向学生、白领、外国人和对新技术有强需求的人。

## 2. 1999–2002：成为“网民”不再等于“家里有一台联网电脑”

CNNIC 1999 年 7 月第四次调查把“上网的主要地点”列为：

- 家中 44%；
- 单位 47%；
- 网吧 4%；
- 其他 5%。

来源：

- CNNIC，《中国互联网络发展状况统计报告（1999/7）》：  
  https://www.cnnic.cn/NMediaFile/old_attach/P020120612485127164902.pdf

报告同时说明，这是通过网上联机问卷得到的用户调查，1999-06-15 至 06-30 共获得 52,549 份有效答卷。因此它是**当时网民样本的使用地点分布，不是全国人口的上网概率**。

**证据等级：A（官方同期统计报告）。**

到 2000 年 7 月，CNNIC 报告改为多选题，结果为：

- 家中 58.84%；
- 单位 42.96%；
- 网吧 20.89%；
- 其他 8.82%。

同时 56.37% 的答题者称上网费用主要自费，平均每周上网 16.54 小时。

来源：

- CNNIC 报告同期转载，新浪科技，2000-07-27：  
  https://tech.sina.com.cn/internet/china/2000-07-27/31904.shtml

**证据等级：A-/B+。** 数据来自 CNNIC 同期报告，当前载体为同期新浪转载。

不能把 4% → 20.89% 直接写成精确增长 5 倍，因为 1999 的题目写作“主要地点”，2000 明确是“多选结果”，调查方法和分母表达不同。能够较稳妥地说的是：

> **到 2000 年前后，网吧已经是一个不可忽略的上网入口，并且和家庭、单位入口并存。**

2002 年对某工科院校一个完整专业数百名大学生的调查又给出一个局部但很具体的日常截面：84% 的学生上网；报告为在家 11%、校内 38%、网吧 71%、其他 2%，而 **53% 的受访上网学生主要在网吧上网**。

来源：

- 中国教育和科研计算机网，2002-01-25，《大学生上网情况调查报告(上)》：  
  https://www.edu.cn/yuan_cheng_jiao_yu_161/20060323/t20060323_23591.shtml

**证据等级：B+。** 近同时代调查，样本明确局限于一所工科院校的一个专业，不能外推全国大学生。

这条材料很重要，因为大学本身已经有校园网络，但网吧仍可能成为主要入口。由此可见：

```text
学校有网络
!= 宿舍/个人随时可用
!= 网吧只服务“家里完全没网的人”
```

公共终端也可以提供不同的开放时间、机器性能、同伴环境、游戏/聊天软件和地点便利。

## 3. 一个在线身份，可以在很多不是自己的电脑上生活

这一阶段出现一种今天容易被家庭 PC / 手机经验遮蔽的结构：

```text
QQ号 / 邮箱 / BBS账号 / 游戏账号属于我
但电脑不属于我
```

我把它称为：

## **`portable account, non-portable machine / 可携账号、不可携机器`**

这使“个人计算”出现一种奇怪但真实的分离：

- 身份是个人的；
- 设备是公共的；
- 本地文件可能是临时的；
- 浏览器历史和 cookie 可能被别人看到，也可能重启即消失；
- 下载一个程序并不保证下次来还能存在；
- 联系人和聊天记录是否跟着人走，取决于客户端/服务器当时怎样保存；
- 使用时间由网吧计费系统而不是个人作息完全决定。

因此真正的日常动作可能是：

```text
到店
→ 找空机
→ 登记 / 付押金或充值
→ 登录自己的网络账号
→ 在公共机器上处理私人的通信、游戏或求职
→ 注意剩余上机时间
→ 退出账号 / 结账
→ 下一次可能换另一台机器重新开始
```

这是一种 **`shared-machine personal life / 共享机器上的私人生活`**。

## 4. 2002–2006：公共入口不仅有网费，还有“场所身份层”

2002 年 11 月 15 日起施行的《互联网上网服务营业场所管理条例》要求网吧等营业场所核对、登记消费者的有效身份证件，并记录有关上网信息；当时规定每日营业时间为 8:00–24:00，并禁止接纳未成年人。

来源：

- 中国新闻网同期报道，新浪转载，2002-11-14：  
  https://news.sina.com.cn/c/2002-11-14/1655456s.html
- 深圳市政府保存的 2002 年重新审核登记实施方案：  
  https://www.sz.gov.cn/zfgb/2003/gb317/content/post_5020634.html

**证据等级：A-/B+。** 政府文件可证明制度要求；同期新闻可证明它在当时作为实际营业规则被宣布。

到 2006 年，一些城市又把纸面登记计算机化。长沙的“网络110”要求新版管理软件与网吧计费系统对接，可通过键盘录入实名信息或身份证读卡器验证；合肥则把纸质登记换成统一的实名管理系统，并提供可跨全市网吧使用、带储值功能的实名登记卡以及临时卡。

来源：

- 红网 / 潇湘晨报同期报道，新浪，2006-06-17：  
  https://news.sina.com.cn/o/2006-06-17/03439224242s.shtml
- 中国广播网同期报道，新浪，2006-11-17：  
  https://news.sina.com.cn/c/2006-11-17/161110529923s.shtml

**证据等级：B+。** 同期报道，且直接描述系统操作。

这形成一个很重要、而且不能被“互联网实名制”四个字粗暴压平的身份分层：

## **`platform identity != access-point identity / 平台身份不等于接入场所身份`**

一个人完全可能：

- 用真实身份证进入网吧 session；
- 进入 QQ、论坛或聊天室后继续使用昵称；
- 某网站本身并不知道身份证姓名；
- 但接入场所却把“这个时间段哪张机器由谁使用”记录下来。

因此：

```text
论坛匿名/昵称制
!= 整条网络访问链匿名
```

这与仓库已有“心理论坛的互动匿名 ≠ 档案匿名”是不同层级：这里是**接入层和应用层之间的身份错位**。

## 5. 网吧的时间不是抽象“在线时长”，而是可以买、会用完、会排队的座位时间

公共终端把网络时间变成一种带空间容量的资源。

如果家里有自己的机器，今天多写十分钟邮件通常不会让陌生人失去电脑；但在一个 40 台、100 台甚至只有 4 台机器的公共场所里：

```text
一个人占用一台终端
= 同一时间少一个别人可以使用的座位
```

因此可以把这一机制称为：

## **`seat-constrained connectivity / 座位约束的连接`**

它和 CFido 的“共享线路时间公地”类似，但资源不是一条电话线，而是**可用终端席位 + 营业时段**。

上网费又把这一资源变成：

## **`metered attention / 计费中的注意力`**

读一封长邮件、慢慢找工作、等待网页打开、下载文件、在聊天室里发呆，都不只是消耗人的时间，还可能继续跳表计费。

## 6. 2007–2008：对迁移劳动者，公共终端能进入找工作和异地家庭通信

2008 年发布的《2007 中国农民工（蓝领）报告》相关报道，调查覆盖 40 个城市、两万多名蓝领工人等样本。报道说，亲友和老乡介绍仍是最主要的就业渠道之一；但“上网找工作”的比例从 2006 年的 7.9% 上升到 2007 年的 9.9%。

来源：

- 人民网《市场报》同期报道，搜狐转载，2008-01-16：  
  https://business.sohu.com/20080116/n254693642.shtml

**证据等级：B+。** 报道给出调查机构、样本范围和指标；仍需找到完整原始报告才能进一步核对抽样与题目措辞。

这里最重要的是反例：网络没有立刻替代熟人就业网络。正确模型是：

```text
老乡 / 亲友介绍仍占主导
+ 招工市场 / 中介
+ 报刊
+ 开始出现网络求职
```

即 **`hybrid intermediation / 混合中介`**。

同年沈阳出现更直接的公共接入生活材料。新华社 2008-12 报道，沈阳市总工会在 10 个建筑工地建立免费“农民工网吧”，每个点只有 **4–6 台电脑**，每天 **18:00–22:00** 开放。受访农民工说，他们会看新闻、看小说，也通过网络和家人朋友联系；报道同时明确说机器少、供不应求。

来源：

- 新华社，搜狐转载，2008-12-03：《沈阳：“农民工网吧”走进建筑工地》：  
  https://news.sohu.com/20081203/n260986154.shtml

**证据等级：B+，其中用途含同期近第一人称。**

这条材料把“数字鸿沟”从抽象所有权变成了可执行的日程：

```text
白天施工
→ 18:00 后才有可用公共电脑
→ 4–6 个座位面对一个工地的人
→ 排队后才能看新闻 / 联系家人
→ 22:00 关闭
```

所以：

> **Internet 已经能跨越城市把家庭重新连起来，不等于这个人拥有随时打开网络的能力。**

互联网的存在、工地有接入、本人能排到机器，是三个不同层级。

## 7. 2005–2012 的“扩张型未来”：公共座位让部分路线先跑起来

在这一阶段，公共终端最值得放进“扩张型未来”的地方，不是“大家觉得未来光明”，而是它把一些原本需要家庭固定资产的动作拆成了按需服务：

- 先上网查一个招聘信息；
- 先注册一个邮箱；
- 先和异地家人聊一会；
- 先玩一个网络游戏；
- 先在论坛里认识陌生人；
- 先试着做一件网络事务；

而不必先完成：

```text
买 PC + 家庭电话/宽带 + 配软件 + 自己维护机器
```

这可以称为：

## **`option-before-ownership / 所有权之前的选项`**

它让“我还没有条件把 Internet 搬回家”不再完全等于“我不能参与 Internet”。

但这种扩张仍然受到钱、座位、地点、营业时间、身份证、性别/年龄规范、机器环境和数字技能约束。

## 8. 2011–2019：家庭宽带、笔记本和手机普及后，网吧没有简单“消失”，而是换了存在理由

2018 年《潇湘晨报》经人民网传媒频道发布的行业回顾指出，随着微博可在手机使用、2011 年后微信兴起，过去专门去网吧聊天的场景明显衰退；2013 年以后，多地网吧开始向“网咖”、电竞馆和综合休闲场所转型，加入餐饮、咖啡、棋牌、桌球等服务。

来源：

- 人民网传媒频道 / 潇湘晨报，2018-10-23：《网吧行业主动转型升级 发展背后是网络社交变迁史》：  
  https://media.people.com.cn/n1/2018/1023/c40606-30356433.html

**证据等级：B/C。** 2018 年行业回顾包含经营者回忆和当期观察；适合说明业态转型，不适合精确复原 2000 年每个普通用户的体验。

2019 年中国青年报对武汉电竞酒店的同期走访，则看到另一种新的公共计算空间：2–5 台高配电脑和床铺同处一间客房，受访年轻人把它用于多人组队、异地朋友聚会和连续数日休闲；相较普通网吧，受访者强调私密、可休息和多人共处。

来源：

- 中国青年报，人民网转载，2019-03-01：《城市电竞酒店热潮涌动 部分年轻人的“异度空间”？》：  
  https://industry.people.com.cn/n1/2019/0301/c413883-30951533.html

**证据等级：B+。** 同期记者走访与近第一人称。

因此 2015–2019 的变化更适合写成：

```text
“我需要一台能上互联网的电脑”
逐渐弱化

“我需要一台比自己的设备更强的机器 / 和朋友并排的机器 / 一个可长时间占用的游戏空间”
变得重要
```

也就是：

## **`access scarcity → hardware/social scarcity / 接入稀缺转向硬件与社交空间稀缺`**

网吧的历史不能只写成“家庭 Internet 普及以后死亡”。它可以从网络入口，转化成高性能设备租赁与共同娱乐空间。

## 9. 2020–2022：公共互联网空间的弱点是它必须让身体到场

2020 年 1 月，黑龙江等地的疫情防控公告明确要求网吧等公共娱乐场所暂停营业。

来源：

- 新华社，2020-01-29：《黑龙江省暂停公共休闲娱乐场所营业》：  
  https://www.xinhuanet.com/politics/2020-01/29/c_1125511327.htm

**证据等级：A-/B+。** 新华社同期报道官方公告。

这条材料不能证明“所有依赖网吧的人因此失去 Internet”，因为到 2020 年智能手机和家庭网络已经广泛普及；但它揭示公共终端路线和家庭/手机路线的结构差异：

> **公共接入是一种 place-bound digital infrastructure——必须让身体进入一个营业中的空间。**

因此当线下场所本身停摆时，网页和网络服务即使还在线，公共座位这层入口也会消失。

这正是 2020–2022“偶发型未来”的一种基础设施断裂：

```text
Internet 服务继续存在
!= 我习惯使用的接入地点继续开放
```

## 10. 2023–2026：网吧重新增长时，“上网”已经不再是最准确的需求描述

中国青年报 2025 年报道中国互联网上网服务行业协会监测数据称，网吧、网咖、电竞馆、电竞酒店等上网服务场所约 10.36 万家，营收约 900 亿元，从业约 65.6 万人；行业方把当代场所描述为游戏、视频、社交、休闲等复合体验空间。

来源：

- 中国青年报，新浪财经转载，2025-01-19：  
  https://finance.sina.com.cn/jjxw/2025-01-19/doc-inefpcsw1182963.shtml

**证据等级：B（行业协会监测数据经媒体报道）。** 这是行业经营口径，不是网民使用率。

2026 年 2 月《21世纪经济报道》刊载的行业观察中，一名常去网吧的受访者给出的理由已经完全不是“家里没有 Internet”：他认为买八九千元的游戏电脑昂贵且不保值，而网吧能按次使用同档高配置，更有性价比。报道还记录返乡朋友把网吧当成共同游戏和见面的廉价娱乐场所。

来源：

- 21经济网 / 豹变，2026-02-25：《春节假期县城网吧人气旺，网吧又是一门好生意了？》：  
  https://www.21jingji.com/article/20260225/herald/d0a28de5c516bad31c2537a45448b996.html

**证据等级：B，含同期近第一人称。**

于是到“防守型未来”阶段，公共终端又可以被重新理解为：

## **`expensive-capability rental / 昂贵能力的按时租用`**

当普通网页和通信已经可以在手机上完成，仍有人不愿为低频需求买高端 GPU、显示器和整套游戏硬件，而选择把固定资产再次转回使用时间。

这和 1996 年有一个惊人的形式相似：

```text
我不买这台机器
我买一段使用它的时间
```

但稀缺对象已经不同：

- 1996：稀缺的是 **进入 Internet 的终端和线路**；
- 2026：对不少用户，稀缺的是 **高性能算力、外设、多人共同空间**。

不能因为两者都叫“网吧”，就把它们当成同一种生活基础设施。

## 11. 海外比较：公共 Internet 不只是“落后地区等家庭接入的过渡物”

Sarah Lee 1999 年发表在 *New Media & Society* 的实证研究，以英格兰东南部一家 Internet café 的用户访谈为基础，专门比较家庭和公共空间中的互联网使用。文章的核心结论之一就是：公共互联网使用**不应被理解为家庭接入普及之前的单纯过渡阶段**；该咖啡馆形成了一个独立、专门的使用空间，并和用户的工作、家庭日常发生联系。

来源：

- Sarah Lee, “Private Uses in Public Spaces: A Study of an Internet Café,” *New Media & Society* 1(3), December 1999: 331–350.  
  https://journals.sagepub.com/doi/10.1177/14614449922225618

**证据等级：A-/academic contemporary.** 同期经验研究；地理范围是一家英国 Internet café，不能代表全球。

2000 年一则关于沙特女性网络咖啡馆的同期报道则给出更具体的跨国反例：一名女大学生称自己没有家庭网络接入，因此依靠女性可进入的上网茶座和在美国的亲属通信；场所被关闭后，她必须寻找另一个符合当地性别规范的入口。

来源：

- 中新社综合报道，新浪，2000-04-17：  
  https://news.sina.com.cn/society/2000-4-17/82274.html

**证据等级：B，含同期近第一人称。**

这说明公共 Internet 的共同机制是全球性的：

```text
网络存在
+ 家庭接入不足或不适合
→ 公共场所成为可执行入口
```

但公共入口又被不同社会的价格、性别规范、营业许可、身份制度和城市空间重新塑形。

中国不是唯一出现 Internet café 的社会；中国更值得单独研究的是：2000s 大规模商业网吧、实名登记、QQ/网络游戏、农民工迁移和后来手机普及如何叠在一起。

## 12. 这条路线改变了哪些“普通人怎么活”的理解

### 12.1 信息获取

以前的模型容易写成：

```text
家里没 Internet → 没法上网
```

现在应改成至少四态：

```text
完全没有可用入口
公共/单位/学校偶发入口
公共终端成为日常入口
家庭/个人设备入口
多设备随身入口
```

### 12.2 就业

网络招聘的存在，不等于求职者需要先拥有私人电脑。公共终端可以把“网上找工作”提前变成可执行动作；但 2007 年农民工材料同时证明熟人介绍仍然重要，不能写成 Web 一夜替代旧中介。

### 12.3 迁移和家庭

工地免费网吧证明：公共终端可以同时承担新闻、休闲和异地亲友通信。它不是纯“娱乐消费”。但公共入口的座位和时段会限制家庭联系的频率与自主性。

### 12.4 线上/线下身份

一个网络昵称可以跨机器移动，而接入 session 又可能需要身份证实名登记。研究在线身份时必须保存至少：

```text
real-world person
access-point session
platform account
public nickname
local workstation state
```

不能把它们视为一个身份。

### 12.5 历史可见性

普通用户说“我 2003 年上 17173 / QQ / BBS”，不自动告诉我们：

- 他用 Windows 98 还是 XP；
- IE 几；
- 哪个 QQ 客户端已经预装；
- 网管软件限制了哪些程序；
- 本地下载能否跨重启保存；
- 一小时多少钱；
- 是否需要身份证/上网卡；
- 是否有空座；
- 带宽和下载速度是多少。

也就是说，网页档案没有保存完整的**access environment**。

## 14. 反例与后见之明风险

### 反例 A：网吧不是“穷人的 Internet”一个标签就能解释

1997 北京早期顾客包括学生、公司职员和外国人；2019 电竞酒店和 2026 高配网咖又服务愿意为性能和共同空间付费的人。

所以：

```text
public access != low-income-only access
```

### 反例 B：家里有网，也可能继续去网吧

英国 1999 研究已经反驳“公共接入只在家庭接入前存在”的单线模型；中国后来网咖/电竞馆转型也是同一提醒。

### 风险 C：不能把“网吧比例下降”写成“公共数字空间消失”

功能可能转移成：

- 电竞馆；
- 电竞酒店；
- 图书馆/学校公共电脑；
- 工作共享空间；
- 手机 + 公共 Wi-Fi；
- 高性能算力按时租用。

### 风险 D：2000s 青少年网吧道德恐慌会造成史料偏向

大量同期报道关注未成年人、游戏、治安、消防和监管。这些材料真实反映制度争议，却容易遮蔽同一场所也被用于邮件、查资料、求职和异地家庭联系。

对应研究 note：

`tmzncty/old-web-archaeology/research/internet-cafe-shared-terminal-access-environment-billing-shell-real-name-and-session-state-gaps-1998-2012.md`

交叉研究的核心提醒是：

> **旧 Web 的普通用户体验 = 页面/网站 + 账号 + 浏览器/OS + 公共终端策略 + 网管/计费壳 + 身份登记 + 本地状态是否持久 + 座位/时间/价格。**

```text

```

## 17. 饱和判断

本轮**不进入“连续无新增”计数**。

新增了至少四个此前未独立建模的机制：

1. `public-terminal internet`：家庭所有权之前/之外的公共互联网入口；
2. `metered digital life`：私人网络生活发生在按时租用的公共机器上；
3. `platform identity != access-point identity`：应用昵称与场所实名可以同时存在；
4. `access scarcity → hardware/social scarcity`：网吧从“接入 Internet”转向“租高性能算力与共同空间”。

并取得 2008 农民工公共终端的同期近第一人称、1999 英国 Internet café 同期学术对照，以及 2026 “不买高配 PC、按次租性能”的同期用户材料。

因此阶段研究饱和计数仍为 **0/3**。
