# 从邮包到可追踪快件：物品可寻址性、远程占有与“它现在到哪了”，中国 1994–2025

> 状态：研究包 / cross-repo bridge
>
> 研究对象：普通人如何把物品送往另一个地方、如何在物品离开自己以后继续知道它的状态，以及这种“可追踪的物品未来”怎样改变迁移、家庭照护、网购、毕业离校和日常收件。
>
> 与 `tmzncty/old-web-archaeology` 的交叉对象：EMS/邮政的内部跟踪网、185/11185 电话、183/EMS Web 查询、短信查询、第三方电商物流页，以及历史 tracking UI 与真实运输事件之间的保存缺口。

## 0. 去重与研究边界

本题不是：

- 再做一次“汇款如何回到家里”：钱的价值传输已由既有 remittance 专题处理；
- 再做一次“毕业东西卖掉还是带走”：物品退出基础设施已由 possession-exit 专题处理；
- 再写一般意义上的淘宝/电商史；
- 把所有快递增长都解释成 Internet 的结果。

本题补的是此前两个专题之间缺失的一层：

> **当人和物分开以后，普通人怎样继续管理那个正在远方移动的物？**

核心区分：

1. **transport availability**：有没有邮政/快递把东西运走；
2. **object identity**：有没有一个稳定的邮件号/运单号，让同一件物在网络中被识别；
3. **status capture**：处理节点有没有把“收寄、转运、投递”等事件写入信息系统；
4. **remote query access**：寄件人/收件人能否在不去邮局的情况下查询；
5. **last-mile possession**：系统显示到达/签收后，收件人是否真的把物拿到手。

因此：

`a parcel can travel != a parcel can be remotely observed != the recipient possesses it`

## 1. 新增机制：object addressability / 物品可寻址性

电话、寻呼、OICQ 的历史让“人”逐渐获得随身体移动的地址；快递跟踪史说明，另一种东西也在同期获得稳定地址：**物品本身**。

一张运单上的号码把一个纸箱从“王大姐寄给儿子的羽绒服”转换成物流系统中可以被重复识别的对象。只要各处理节点继续把事件写回同一个标识符，一个不在任何一方视野里的实物就会产生一条信息影子：

`实物包裹 P`  ↔  `运单号 ID(P)`  ↔  `事件序列 E1, E2, E3 ...`

这不是“实时 GPS 位置”。早期以及大量今天的 tracking，本质上都是**离散处理事件的累积**。物已经离开上一个扫描点，并不意味着页面知道它此刻在公路哪一公里。

建议在仓库中固定术语：

### `object addressability / 物品可寻址性`

一个正在跨空间移动的普通物件，拥有可供制度、承运商和用户反复引用的稳定机器标识。

### `informational shadow / 物品的信息影子`

运输对象在信息系统中留下的离散事件记录。它与实物相关，但绝不等于实物本身。

## 2. 1994：一定要把“跟踪查询网”与公众 Internet 分开

中国邮政速递物流的后出历史材料普遍把 **1994 年 1 月 18 日**列为“开通邮政特快专递跟踪查询网，实现快件网上跟踪查询”的节点。

但这里最重要的不是把它写成“中国人在 1994 年 1 月已经上 Web 查 EMS”。恰恰相反，这个日期早于中国正式全功能接入国际互联网（1994 年 4 月）这一通常采用的界线，因此“网上”首先必须按 1990s 的通信/计算机语义理解为**联网的信息处理/查询网络**，不能未经证据直接等同于 public Internet / WWW。

当前证据能支持的窄结论是：

- EMS 在 1994 年初已经把跟踪查询做成联网信息系统；
- 邮件的处理状态不再只存在于某个局所的纸面知识中；
- 后续公众电话和 Internet 查询可以建立在这个后台状态层之上。

当前证据**不能**支持：

- 1994-01-18 普通家庭已经通过浏览器访问 EMS tracking；
- 当时存在与 2000s `ems.com.cn` 等价的公众 Web 产品；
- “网上跟踪”就是“互联网跟踪”。

这条边界对整个项目非常重要：

> **backend networkization can precede household Internet access by many years.**

来源线索（后出公司史，证据等级 B/C；需继续追官方年鉴或同期技术文献）：

- 中国邮政速递物流发展沿革的公开汇编记录 1994-01-18 “邮政特快专递跟踪查询网”节点：<https://wapbaike.baidu.com/item/%E4%B8%AD%E5%9B%BD%E9%82%AE%E6%94%BF%E9%80%9F%E9%80%92%E7%89%A9%E6%B5%81%E8%82%A1%E4%BB%BD%E6%9C%89%E9%99%90%E5%85%AC%E5%8F%B8/6597081>

**后见之明风险**：今天的“网上查询”几乎自动让人想到 Web；1994 年材料不能这样倒读。

## 3. 1996–2004：后台状态变成普通人可以远程询问的公共接口

### 3.1 185：先是“打电话问我的东西在哪”

1996 年 9 月，邮电部发文设立全国邮政特快专递业务 `185` 电话特服专号。文件甚至专门要求电信部门保障中继线，说明这不是一个宣传号码，而是一项需要通信线路和客服基础设施支撑的公共接口。

- 《邮电部关于设立全国邮政特快专递业务“185”电话特服专号的通知》，1996-09-25（法规文本转录）：<https://zh.wikisource.org/zh-hans/%E9%82%AE%E7%94%B5%E9%83%A8%E5%85%B3%E4%BA%8E%E8%AE%BE%E7%AB%8B%E5%85%A8%E5%9B%BD%E9%82%AE%E6%94%BF%E7%89%B9%E5%BF%AB%E4%B8%93%E9%80%92%E4%B8%9A%E5%8A%A1%E2%80%9C185%E2%80%9D%E7%94%B5%E8%AF%9D%E7%89%B9%E6%9C%8D%E4%B8%93%E5%8F%B7%E7%9A%84%E9%80%9A%E7%9F%A5>

到 2001 年，内蒙古 12 个盟市的 185 客服中心全部开通，地方志记载其业务包括“特快邮件查询、业务咨询、特快揽收”等；系统有语音导航、语音播报、电话转接、夜间录音等功能，赤峰日均业务量达约 2000 笔，其他盟市也有稳定使用量。

- 《内蒙古年鉴》相关邮政条目（2001 年 185 与 183）：<https://nmgqq.com.cn/shuzishizhi/nianjian/neimengguniajian/nianjianerlinger/jingji/2011-4-14/1702.html>

这说明公众 tracking 的一条重要路线不是：

`paper → Web`

而是：

`后台联网状态 → 人工/IVR 电话查询 → Web/SMS 自助查询`

### 3.2 183 / EMS Web：Internet 成为另一扇窗，不是后台系统的起点

同一份内蒙古地方志记载，`183` 电子邮政网站于 2000 年 11 月启动、12 月开通，后台采用 Windows 2000 Server + Oracle，各盟市可以拨号远程维护内容。

这里仍要分开：地方 183 电子邮政网站的“业务受理”和 EMS tracking 的具体数据库是否同构，当前材料不足；但它证明中国邮政的公众 Internet 门户在 2000 前后已经与电话中心并行。

2004 年新华社报道，邮政客服 `185 → 11185` 升位，同时原邮政计算机互联网接入码 `183 → 11183`。11185 继承查询、受理、投诉等功能，在全国 200 多城市提供服务。

- 新华社，2004-06-29，《中国邮政客户服务电话号码升位为11185》：<https://news.sina.cn/sa/2004-06-29/detail-ikkntiam0305616.d.html>

2004 年 8 月 EMS “全夜航”开通时，同期《中国青年报》报道已经非常明确地给出三种公众跟踪方式：

- 手机用户把邮件号发到 `5185` 查询；
- Internet 用户登陆 `www.ems.com.cn`；
- 也可访问 `www.183.com.cn`。

- 中国青年报，2004-08-11，《中国邮政EMS开通“全夜航”》：<https://finance.sina.com.cn/b/20040811/0741939950.shtml>

这形成一个典型的 **multi-channel status access / 多通道状态访问**：

`同一件物 → 同一后台状态 → 电话 / SMS / Web 多种用户入口`

Internet 的意义不是第一次让包裹“有状态”，而是把原本必须由话务员代查的一部分状态改成用户自己检索。

## 4. 从“它到哪了”到“它什么时候应该到”：可追踪性改变未来时间

2005 年 EMS 与多地邮政推出时限承诺。同期《北京晨报》报道，用户可以通过 11185 或 EMS 网站输入两地邮编查询承诺时限，并查询邮件传递中的具体信息；如果因邮政原因超过承诺时限，可以退邮资。

- 北京晨报，2005-07-26，《投递超时EMS邮资可退》：<https://news.sina.com.cn/o/2005-07-26/03306526163s.shtml>

这里发生的不只是“信息更多”。普通人的未来开始从：

`我把东西交出去 → 过几天大概会到`

变成：

`系统给出承诺窗口 → 我可以检查实际进度 → 超时可以形成责任`

建议术语：

### `transport uncertainty compression / 运输不确定性压缩`

追踪系统不会让物理运输瞬间变快，但它可以缩小用户对“它是否丢了、现在到了哪一段、是否已经超时”的不确定区间。

### `accountable delivery future / 可问责的递送未来`

当承诺时限、状态事件和赔付规则绑定以后，“明天/后天应该到”不再只是经验猜测，而成为可验证、可投诉的服务承诺。

## 5. 2007–2010：扩张型未来里的“把物和人分开移动”

### 5.1 毕业离校：人走一条路线，行李可以走另一条

2007 年中国人民大学毕业生离校安排里，双榆树邮局、中铁快运、宅急送同时进校办理行李邮寄和托运。通知特别要求包裹外包装写清收寄件地址和联系电话，并说明邮政包裹会寄到最近邮局，再由邮局投送取包通知。

- 中国人民大学，2007-06-26，《2007年暑期毕业生离校工作安排》：<https://www.sard.ruc.edu.cn/xysy/tzgg/f2c83de1a37c4e9bb1c9e62d2375ab9b.htm>

浙江大学 2007 年两天内为毕业生托运 3200 多件行李，目的地从新疆、海南到山东、黑龙江。

- 浙江大学后勤集团，2007-07-05，《商贸中心圆满完成毕业生行李托运任务》：<https://zulg.zju.edu.cn/info/1020/1423.htm>

2009 年北航甚至要求毕业研究生提前在线录入个人邮寄信息，再由邮局入校现场收寄。

- 北京航空航天大学，2009-03-09，《关于2009年3月毕业研究生离校托运行李的通知》：<https://www.ee.buaa.edu.cn/info/1193/15175.htm>

这补出了 migration 研究中一个具体机制：

### `split mobility / 人—物分路迁移`

毕业、迁城时，人无需再把所有生活物品与自己的身体放在同一趟火车上。行李可以进入独立运输网络，人的路线与物的路线解耦。

与 possession-exit 专题的关系：

- possession exit 研究的是“不带走的东西如何退出”；
- 本题研究的是“决定保留的东西如何在本人不携带的情况下继续跟着人生移动”。

### 5.2 2009 年的母亲与羽绒服：包裹也是跨地照护

2009 年 11 月北方大雪造成物流拥堵时，《今日早报》的同期报道记录：宁波一位母亲从家里给在杭州下沙读书的儿子快递羽绒服，使用圆通。

- 今日早报，2009-11-23，关于电商/快递拥堵的报道（新浪转载）：<https://news.sina.com.cn/c/2009-11-23/052516650994s.shtml>

这条材料很小，却能防止我们把快递史只写成“网购商品配送”。包裹网络也使家庭照护可以跨地点物质化：

`家里发现降温 → 找出衣服 → 交给快递 → 异地学生收到`

它和电话/QQ解决的是不同问题：通信可以说“多穿一点”，快递可以真的把那件衣服送过去。

建议术语：

### `remote material care / 跨地物质照护`

家庭成员不共居时，通过包裹把衣物、食品、药品、文件等实物输送到另一地点的照护方式。

这条路径早于电商，也不会被电商完全取代。

## 6. 电商时代：运单号把“购买”与现实运输接起来

2008 年的一份普通网络工具清单已经把 `http://www.ems.com.cn/ems/index.jsp` 列为“EMS全球快递邮件号查询”，说明“拿一串号码自己上网查货”已进入普通网民工具箱。

- CSDN 历史博客，2008-03-23，《最全的在线查询》：<https://blog.csdn.net/weixin_34101784/article/details/85400363>

2009 年淘宝卖家与快递企业冲突的同期报道中，论坛用户已经在抱怨“下的单子还没有人来取”“13日发的货到现在没有看到影子”，说明电商交易完成后，运输进度已经成为交易关系中的独立焦虑对象。

- 今日早报，2009-11-23，《传申通快递封杀淘宝：物流公司酝酿集体涨价》（新浪转载）：<https://tech.sina.com.cn/i/2009-11-23/09093615033.shtml>

另一篇 2009 报道中的淘宝鞋店卖家提到：客人五天没收到鞋，打电话来问，查询后才发现货物途中丢失，卖家先补发再向快递公司索赔。

- 2009-03-30，关于快递格式条款的同期报道转载：<https://www.taokshop.com/taobao/tao1142.htm>

这里形成一种新的责任三角：

`buyer ↔ seller ↔ carrier`

货物信息不再只是寄件人与邮局之间的内部事务；它被嵌入买卖合同、售后、赔付和信誉体系。

## 7. 2015–2019：东西越来越可追踪，最后一百米却重新制造“状态歧义”

2019 年全国快递业务量达到 635.2 亿件，其中异地件 510.5 亿件。巨大的规模使末端配送越来越依赖驿站和智能快件箱。

- 国家邮政局 2019 年行业数据（中国政府/人民网转载）：<https://politics.people.com.cn/n1/2020/0519/c1001-31715373.html>

同年国家邮政局第二季度满意度调查（16692 份有效样本）显示：

- 25.3% 受访用户当年使用过智能快件箱；
- 82.5% 有过快递代收点收件经历；
- 只有 71.1% 的相关快递员会在使用智能快件箱前征得用户同意；
- 全程平均时限约 58.39 小时。

- 国家邮政局，2019-08-05：<https://www.gov.cn/xinwen/2019-08/05/content_5418702.htm>

同期一位北京消费者抱怨：网购图书未经电话联系就被放入快递柜，她发现时已经过了几天并产生超时费用。

- 北京商报相关报道，2019-08：<https://www.jiemian.com/article/3373631.html>

于是 tracking 史里必须再固定一个区分：

### `delivery status != possession state`

`系统：已投递/已签收`

不必然等于：

`收件人：物已在我手上`

物可能在门卫、柜子、驿站、一楼门厅、邻居处，甚至只是在系统里被提前确认。

这不是信息化失败的简单故事。恰恰是因为件量极高、事件记录极密，**“最后几十米由谁完成”**反而成为新的生活劳动。

对于 2015–2019 的“拥堵型未来”，可以增加：

> 未来并非不可见，而是被分割成大量可见状态；用户知道包裹已经到小区，却仍需要从自己的工作时间里挤出一个取件窗口。

## 8. 2020–2022：偶发型未来里，物流替代了本人回到现场

2022 年北京高校毕业季，一部分学生因疫情不能返校或匆忙离校。中国传媒大学等学校让志愿者通过视频与不在场毕业生逐件确认，完成“云打包”，随后由快递统一邮走。受访毕业生徐杨说，一个视频解决了行李邮寄的燃眉之急，她随后在异地等待行李“回家”。

- 北京日报，2022-06-20，《收得进，寄得出！首都高校为毕业生打造贴心“毕业寄”》：<https://wap.bjd.com.cn/news/2022/06/20/10105724.shtml>

这是一个很强的新路径证据：

`人无法进入原空间 → 远程视频代理确认 → 他人打包 → 物流移动物 → 物回到本人`

也就是说，包裹网络不仅替代“我亲手带东西回家”，在偶发中断时期甚至可以部分替代“我先回宿舍拿东西”本身。

建议术语：

### `proxy-mediated possession recovery / 代理式占有恢复`

本人无法抵达旧空间时，由代理人通过通信确认物品，再借寄递网络把物重新送回本人。

它连接了照护、长期中断、迁移与通信基础设施几个矩阵格。

## 9. 2023–2025：防守型未来中的问题不是“有没有物流”，而是“我能不能控制最后一步”

2023 年全国快递业务量达到 **1320.7 亿件**，其中异地快递 1153.6 亿件。此时寄递已经不是稀罕服务，而接近高频日常基础设施。

- 国家邮政局，2024-01-22 公布 2023 年数据：<https://www.spb.gov.cn/gjyzj/c100015/c100016/202401/59eeb6e8b0e7404f8127aa2c7aebded6.shtml>

2024 年 3 月新《快递市场管理办法》实施后，未经用户同意不得擅自把快件投到智能柜或服务站。人民日报同年调查保留了几种非常具体的同期第一人称：

- 武汉一名消费者经常给住在 6 楼、腿脚不便的父母买日用品；包裹被放快递柜以后，老人只能把纸箱一点点挪上楼；
- 泰州一名消费者说物流详情甚至会显示“已送达”，本人却不知道送到哪里；
- 快递员一上午面对约 380 单任务，真正标注要求上门的只有二十多单，电话联系本身就会改变路线和工时。

- 人民日报，2024-06-24，《怎样让快递送上门更好实现》：<https://paper.people.com.cn/rmrb/html/2024-06/24/nw.D110000renmrb_20240624_1-11.htm>

这给 2023–2026 的“防守型未来”提供一个很朴素但重要的版本：

> 当物流已经无处不在以后，用户争取的不再是“有没有渠道把东西送来”，而是**服务是否按自己可承受的方式兑现**。

对于照护者，真正需要的是：

`我远程买给父母的重物 → 真的送到父母能拿到的位置`

而不只是：

`tracking page 出现绿色“已签收”`

所以新机制可写成：

### `delivery-control claim / 末端交付控制权`

在成熟物流社会，收件人对“上门 / 驿站 / 柜 / 门卫 / 指定代收人”的选择本身变成制度化权益。

## 10. 海外对照：FedEx 说明“数字跟踪”同样早于 Web

美国 FedEx 是一个非常好的对照，因为它能防止把 package tracking 写成 Web 的发明。

FedEx 官方历史材料记录：

- 1979：上线 COSMOS 中央计算系统，用于管理人员、包裹、车辆与运行情境；
- 1986：推出 SuperTracker 手持条码扫描系统，把包裹节点信息数字化采集；
- 1994：`fedex.com` 上线，成为其所称首个提供在线包裹状态跟踪的运输网站。

- FedEx 40 周年公司史：<https://newsroom.fedex.com/newsroom/global-english/fedex-marks-40th-anniversary-with-community-service-eye-to-the-future>
- FedEx 官方历史：<https://www.fedex.com/en-us/about/history.html>

FedEx 后来的公司材料还给出一个非常能说明大众化速度的数字：1995 年 `fedex.com` 日均约 9000 次 tracking 请求；到 2008 年 12 月 23 日单日 tracking 请求达到约 980 万次。

- FedEx, 2009, `FedEx Refreshes Web Tracking Tools`: <https://newsroom.fedex.com/newsroom/united-states-english/fedex-refreshes-web-tracking-tools>

跨国共同结构因此是：

`内部计算机化 → 条码/节点事件 → 电话客服可查询 → public Web self-service → push notification / mobile`

中国不是“没有互联网就没有数字物流”，美国也不是。

共同变化是：**后台先能看见物，然后普通用户逐渐获得看见后台状态的窗口。**

## 11. 四个未来时间感框架的修订

### 2005–2012：扩张型未来

新增的不是“大家相信快递会越来越快”，而是：

- 人可以去更远的城市，保留物品可以独立寄走；
- 家庭可以把衣服、文件等物质照护跨城送达；
- Internet 订单与实物运输开始通过运单号连接；
- 一个物件的未来路径越来越可查询。

扩张的一部分是 **remote possession can follow a mobile life**。

### 2015–2019：拥堵型未来

件量爆炸以后，未来被细分成越来越多 status events，但用户的时间又被驿站、柜子、取件码、派件时间重新占用。

关键不是“更慢”，而是：

`high observability + last-mile congestion`

### 2020–2022：偶发型未来

人在制度上/物理上无法返回现场时，视频 + 代理人 + 快递可以拼成临时的 possession recovery system。

### 2023–2026：防守型未来

当前材料支持的更谨慎命题是：

- 寄递已成为基础设施；
- 普通人更关心可预期、不会丢、按约上门、失败后可追责；
- 对老人、残障者和跨城照护者，最后几十米直接决定远程购买有没有真正完成照护。

不要把它扩大成“大家因为悲观所以要快递送上门”。这是成熟基础设施中的**可靠性与控制权**问题。

## 13. 反例与限制

1. **可追踪不等于可靠。** 状态更新本身可能延迟、缺扫、误扫、提前签收。
2. **有运单号不等于普通人能自助查。** 后台 tracking 早于 public Web；电话客服也有占线、地区覆盖等门槛。
3. **已签收不等于已占有。** 柜、驿站、门卫和代收人使“系统完成”与“生活完成”分离。
4. **快递不等于电商。** 毕业行李、家庭衣物、文件、礼品和维修件等都可独立于网购存在。
5. **追踪不是实时位置。** 很多历史 tracking 是事件日志，不是连续空间定位。
6. **大量件量不能直接推断主观未来感。** 业务量用于说明基础设施密度，不用于替代个人材料。

## 14. 对“普通人到底有多少种活法”的增量

这轮增加的并不是一个消费习惯，而是几条真正不同的生活执行路径：

- **人去异地，物随后寄到**：迁移不必把全部家当随身携带；
- **人留在异地，家人寄物照护**：家庭可以在不共居时继续输送物质照护；
- **人无法回旧空间，由代理人打包寄回**：偶发中断中恢复个人占有；
- **照护者远程买重物给老人，要求最后送到门**：电商—快递成为跨地照护链；
- **卖家通过 tracking 管理售后与补发**：实物移动成为网络劳动的一部分。

真正的新结论可以压成一句：

> **现代流动生活不只要求“人可以远走”，还要求“属于人的物可以在他不在场时继续被识别、移动、查询并重新交到他手里”。**

## 16. 下一轮可继续追的一手证据

优先级高：

1. 1994 年“邮政特快专递跟踪查询网”的同期邮电技术文献/年鉴，确认网络架构与查询主体，彻底解决“网上 ≠ Internet”的语义；

4. 淘宝 2005–2010 “查看物流”早期帮助文档，确认电商平台何时开始直接聚合承运商轨迹；
5. EMS/民营快递旧运单、状态码、条码/扫描设备手册；
6. 2007–2010 同时代个人博客中“等快递/查单号”的第一人称材料。

这些证据一旦取得，将主要升级来源强度，而不是再扩张新的概念词表。

## 17. 阶段饱和判断

本轮不是“连续无实质新增”：它增加了 **物品可寻址性、物的信息影子、人—物分路迁移、跨地物质照护、代理式占有恢复、末端交付控制权**，并且第一次把 1994 EMS 跟踪网严格放在“中国正式全功能 Internet 接入之前的后台数字通信”框架里。

因此本阶段连续无新增计数：**0 / 3**。
