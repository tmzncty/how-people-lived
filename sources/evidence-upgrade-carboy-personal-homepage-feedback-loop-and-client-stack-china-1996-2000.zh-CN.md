## 0. 为什么这一轮不再另开“个人主页改变人生”的新题

仓库已经充分建立了这些机制：

- `public-self addressability`：普通人获得可反复访问的公开 URL；
- `publishing-stack labor`：早期个人出版需要自己处理 HTML、上传、链接和资源；
- `audience-feedback instrumentation`：计数器、留言本等把“有没有人看我”部分仪表化；
- 平台托管降低发布门槛，却也使个人公开身份依赖宿主；
- 搜索、平台迁移与停服会改变旧内容的长期可见性。

因此本轮的有效增量不是再命名一个近义机制，而是把一个 1996—2000 的具体人物序列做得更扎实，并继续尝试 old-Web artifact verification。

# 一、先把 1990s 中国的“联网”分层：视聆通并不等于完整 Internet

2000 年 11 月 6 日，刘韧在《计算机世界》刊出的《杨震霆广州网事》是一份很有价值的近同时代人物侧写。文章回顾杨震霆第一次接触“视聆通”时明确记录：

- 他买了 14400 bps modem；
- 自己已使用 Windows 95，但视聆通提供的客户端只能运行在 Windows 3.1，因此又装回 Windows 3.1；
- 真正连上以后，他发现所进入的并不是可以自由访问全球 Internet 的连接，而是只能访问广东省内一两个站点的省内网络；
- 后来他又另行向广州数据局申请 Internet 账号，并拿到写有 DNS 与邮件服务器地址的配置纸条。

来源：

- 刘韧，《杨震霆广州网事》，《计算机世界》/ 新浪科技，2000-11-06：<https://tech.sina.com.cn/path/2000-11-06/491.shtml>

证据等级：**B：近同时代人物侧写，包含大量当事人口述；适合恢复动作链与当时的基础设施区分，不单独据此确认所有精确“第一”或普及率。**

这条材料对本仓最重要的不是怀旧细节，而是再次证明：中国 1994 以后也不能把所有“上网”体验压成同一种连接。

更准确的用户路径是：

```text
本地/省内数字网络可用
→ 聊天、BBS、身份昵称已经形成
→ 但不能自由访问全球 Internet
→ 再申请 Internet 账号
→ 学习 DNS / 邮件服务器 / 拨号配置
→ 才获得另一层网络可达性
```

因此：

```text
networked communication experience
!=
full global-Internet access
```

这不是新机制，而是对仓库既有“中国前互联网 / 早期联网阶段必须细分”的一条高质量人物证据升级。

# 二、个人主页内容不是一次性“表达自我”，而会被陌生受众反过来塑形

同一篇 2000 年侧写记录：杨震霆最初把自己的页面命名为“carboy 的个人主页”，因为自己熟悉汽车，所以主页最初主打汽车内容。

但实际访问反馈完全不是他预想的方向：

- 汽车内容没有得到太多回应；
- 作为辅助内容写下的 Windows 95 拨号上网心得却明显更受欢迎；
- 网友不断继续提出新的上网问题；
- 他因此一边自己试，一边把解决办法继续写回页面；
- 页面逐渐从汽车兴趣页延伸成“完全上网手册”。

来源同上。

这使既有的 `audience-feedback instrumentation` 可以被更具体地写成一条生命史动作链：

```text
我先按自己的兴趣定义公开身份
→ 陌生访问者实际只对其中一部分内容持续回应
→ 问题与反馈改变我的更新方向
→ 页面主题发生偏移
→ 我公开呈现出来的“我是谁”也随之改变
```

这里值得保留的不是一个新术语，而是一个很具体的修正：

> **早期个人主页不是“把一个已经完成的自我放到网上”。公开身份也可能在发布以后，经过陌生人的提问、链接和访问反馈才逐渐成形。**

这与今天算法推荐塑造创作者内容方向有远亲关系，但不能把 2020s 的算法逻辑倒投给 1996。现有证据只足以说明：**受众回应在当时已经能够改变一个主页作者继续投入什么内容。**

# 三、公开主页可以进入职业世界，但不要把因果写得过头

刘韧的 2000 年侧写还描述了杨震霆随后进入广州 Internet 产业网络，并记录他在 1999 年收到北京 `.com` 的工作机会等经历。

这里需要严格避免一个很诱人的后见式结论：

```text
个人主页有名
→ 所以一定获得工作机会
```

现有材料只能确认：

- 主页、BBS 活动、网络圈关系和他的专业声誉在同一个早期广州 Internet 社群中叠加；
- 到 1999—2000 年，他已经处于可以被其他 Internet 公司挖人的职业位置。

因此更稳妥的结论仍然是仓库已有的：

> **个人公开页面可以成为可被陌生人和职业圈持续看到的声誉表面，但单个岗位变化通常不能仅凭一篇人物报道归因给某个主页。**

# 四、1998：免费个人主页申请量说明“想拥有页面”已经形成明显需求，但分母不能偷换

1998 年 5 月 16 日，中文 Usenet/Google Groups 保存的一份“网络新闻(转)”写道：网易重新开放个人主页申请服务后，“首天申请人次突破 3000”。同一转帖还报道 `163.net` 免费邮箱开放约 60 天后注册超过 11 万。

来源：

- `cn.bbs.comp.software`，1998-05-16，“网络新闻(转)”：<https://groups.google.com/g/cn.bbs.comp.software/c/N-CnYVj4n8M>

证据等级：**B/C：同时代网络转帖，日期和当时流通文本可核；原始新闻出处在本轮未继续确认，因此不能把其中的运营数字升格为独立审计过的公司统计。**

它适合支持：

> **到 1998 年，在当时已经进入网络空间的一部分用户中，“申请一个自己的主页空间”已足以形成数千人级的即时需求。**

它不适合支持：

- 1998 年中国普通人口的主页拥有率；
- 所有网民的概率分布；
- “3000 人都成功长期维护了主页”。

# 五、一个很有价值的“消失以后仍被搜到”证据，但它强化的是已有机制

刘韧 2000 年文章还有一处值得 old-Web / life-history 交叉线保留：文章说，原来的“完全上网手册”消失/迁移后，在 Yahoo! 中仍然可以按这个名字搜到一个结果，但指向的内容已经与杨震霆原来的手册无关。

来源：同《杨震霆广州网事》。

这里可以确认的是一个当时人已经观察到的错位：

```text
search identity / old name remains discoverable
!=
original content identity still intact
```

这对“历史可见性”和“搜索中的过去”很重要，但仓库已经有大量 searchable-past、平台迁移与页面身份漂移专题，因此本轮**不把它另命名为新机制**。

它应被当作：

- 2000 年中国语境下的同期补强证据；
- old-Web artifact identity / URL identity 不稳定性的 locator；
- 未来若取得历史 Yahoo / 页面 capture 时的验证线索。

# 六、海外比较：GeoCities 同样降低个人出版门槛；中国材料的特殊处不在“会做个人主页”

1999 年 1 月 Yahoo 宣布收购 GeoCities 时，公司公告称 GeoCities 已托管超过 350 万个用户创作站点，并把其价值直接表述为让非技术用户可以创建、发布和更新 Web 内容。

来源：

- Yahoo!, `Yahoo! To Acquire Geocities`, 1999-01-28（现由 NewMediaWire 保存）：<https://www.newmediawire.com/news/yahoo-to-acquire-geocities-3064119>
- 同期 WIRED 对交易的报道，1999-01-28：<https://www.wired.com/1999/01/yahoo-gobbles-up-geocities-2/>

证据等级：

- Yahoo 公告：**B：同期企业自述，适合证明平台当时怎样描述自己的规模与功能；规模数字保留企业来源属性。**
- WIRED：**B：同期媒体。**

这说明“托管平台把网页发布能力交给普通用户”不是中国特有现象。

中国这一例更值得比较的地方是：

- 个人主页实践与本地/省内数字网络、全球 Internet 账号可能并不同步；
- 客户端软件甚至可能迫使 Windows 95 用户重新安装 Windows 3.1；
- 用户需要自己理解 DNS、邮件服务器、拨号配置；
- 即使公开 URL 已经成为可能，真正获得全球网络可达性仍可能是另一道门槛。

因此全球共同变化是 **personal publishing threshold下降**；中国 1990s 具体材料更清楚地暴露了**接入层、客户端栈与发布层并不总是同步升级**。

# 八、后见之明风险

1. **不要把视聆通直接写成全球 Internet。** 本轮最重要的边界就是当事人先有本地/省内联网体验，后又申请真正 Internet 账号。
2. **不要把一个知名早期网民写成“普通中国人”。** 杨震霆是高可见个案，只用来证明路径存在和恢复动作链。
3. **不要把主页声誉与职业机会写成单因果。** BBS、人际网络、行业工作和主页声誉彼此纠缠。
4. **不要把 1998 的 3000 次申请外推成网民普及率。** 这是服务事件数字，而且原始新闻出处尚待进一步校验。
5. **不要用今天能搜到的新浪转载，冒充 1996 年页面本身。** 本轮仍未取得经过核验的 `carboy` 历史主页 capture。
6. **不要把 1990s 的访客反馈直接等同于今天的推荐算法。** 可比的是“受众会反过来塑造内容”，不是技术机制相同。

# 十、本轮如何改变了我们对“人怎么活着”的理解

这轮**没有**发现新的生活路径类别，也没有发现一个此前未建模的制度接口或时间机制。

它把一个既有结论做得更具体：

> 1990s 的个人主页不只是“我终于可以公开说话”。一个人可以先在本地数字网络里形成昵称和社交关系，再艰难跨过客户端与 Internet 配置门槛；第一次做页面时也可能并不知道自己最后会以什么身份被记住——访问者不断提问以后，原来写汽车的人，逐渐变成了教别人上网的人。

这是一条**证据升级**，不是新机制。

按交叉研究的饱和规则，并考虑此前 Internet café 运行已产生实质新机制、将连续计数重置，本轮应记录为：

**连续无实质新增：1 / 3。**

不触发 closure；下一轮仍应优先尝试可核验 historical artifact，或者寻找真正能改变既有结论的同时代第一人称序列。
