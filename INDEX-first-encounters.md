# Technology First-Encounter Index

This index collects a specific kind of ordinary-life evidence:

> **When did a person first encounter a technology closely enough for it to become part of daily life?**

National invention or adoption dates are not enough.

A person can live for years in a country where a technology exists without personally using it.

The first encounter can therefore reveal:

- region;
- class;
- household resources;
- school/work access;
- urban/rural timing;
- age at adoption;
- which older system was replaced.

## Why first encounters matter

Consider three questions:

> When did China have home computers?

> When did your town commonly have home computers?

> When did **your household** first have a computer you could use without going somewhere else?

These are three different historical facts.

The third is especially valuable for life history.

## Technologies to collect

### Household infrastructure

- first electric light remembered;
- first piped water;
- first indoor toilet;
- first shower / water heater;
- first refrigerator;
- first washing machine;
- first air conditioner.

### Information and communication

- first household telephone;
- first pager;
- first mobile phone in the family;
- first personal mobile phone;
- first computer used;
- first household computer;
- first Internet connection;
- first Internet café visit;
- first QQ account;
- first smartphone;
- first mobile payment;
- first video call;
- first remote class or remote workday;
- first generative-AI conversation.

### Transport

- first bicycle personally owned;
- first motorcycle in household;
- first private car;
- first train trip;
- first high-speed rail trip;
- first flight;
- first navigation-app trip where no paper directions were needed.

### Media

- first black-and-white TV;
- first color TV;
- first VCR/VCD/DVD;
- first cassette player;
- first MP3 player;
- first downloaded music file;
- first streaming subscription.

## Do not record only the date

For each first encounter, ask:

- How old were you?
- Where were you?
- Was it yours, your family's, your school's or your workplace's?
- Did you use it once or regularly?
- Was it expensive or ordinary by then?
- What did you do before it existed in your life?
- Which task changed first?
- Did older household members use it differently?
- Did it make something newly possible?
- Did it remove waiting, labor or distance?
- Was the first encounter memorable because it was rare, or because it immediately became normal?

## Example: computer and mobile-phone timing

National household statistics show why personal memory matters.

Per 100 households:

### 2000

- urban computers: **9.70**;
- rural computers: **0.47**;
- urban mobile phones: **19.50**;
- rural mobile phones: **4.32**.

### 2005

- urban computers: **41.52**;
- rural computers: **2.10**;
- urban mobile phones: **137.00**;
- rural mobile phones: **50.24**.

### 2010

- urban computers: **71.16**;
- rural computers: **10.37**;
- urban mobile phones: **188.86**;
- rural mobile phones: **136.54**.

Sources:

- urban: https://www.stats.gov.cn/sj/ndsj/2012/html/J1010e.htm
- rural: https://www.stats.gov.cn/sj/ndsj/2012/html/J1030e.htm

Dataset:

- [`data/china-household-communication-devices-2000-2010.csv`](data/china-household-communication-devices-2000-2010.csv)

This means two people born in the same year can remember very different technological childhoods.

## Cohort questions

### Born c.1955

What technology arrived after adulthood was already established?

Possible memories:

- first refrigerator;
- first color TV;
- first household telephone;
- first computer at work;
- first mobile phone late in career.

### Born c.1975

What did the person learn as an adult rather than as a child?

Possible memories:

- first home computer;
- first Internet café;
- first mobile phone;
- first online shopping;
- first smartphone after career formation.

### Born c.1985–1995

Which transitions happened during adolescence or young adulthood?

- home Internet;
- QQ;
- MP3;
- mobile phone;
- smartphone;
- mobile payment.

### Born c.2005

Which technologies were already background infrastructure?

The important memory may no longer be:

> “When did I first use the Internet?”

but:

> “When did I first use AI to help me think?”

## Evidence types

Useful evidence includes:

- family photographs;
- receipts;
- warranties;
- old device boxes;
- school computer-room photos;
- Internet-café cards;
- phone bills;
- SMS records;
- screenshots;
- old hard drives;
- software installers;
- AI conversation exports;
- diaries and retrospective oral histories.

Retrospective memory should be labeled as retrospective.

## Core historical insight

Technology history usually asks:

> **When did the technology arrive?**

Ordinary-life history should also ask:

> **When did it arrive in this person's life — and what did they stop doing afterward?**
