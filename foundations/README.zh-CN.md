# 基础框架：普通生活的物质底座

日常生活建立在生产、基础设施、收入和时间之上。

这个目录收集可以反复使用的背景框架，用来解释：为什么生活在同一个大时代中的两个家庭，能做的事情却完全不同。

## 一条常用的基础链

可以先从下面这条链开始：

**生产 → 分配 → 基础设施 → 价格 → 家庭可及 → 日常流程 → 期待**

例如，一台洗衣机要真正改变家庭生活，需要的不只是“已经被发明”：

1. 工厂能大规模生产；
2. 商店或经销网络能触达家庭；
3. 家里有稳定电力；
4. 自来水和排水足够方便；
5. 价格能够进入家庭预算或信贷范围；
6. 有维修与备件；
7. 足够多家庭使用以后，习惯和社会期待也随之变化。

只有这样，“洗衣服”才可能从一种高度依赖体力和时间的家务，变成另一种完全不同的日常活动。

## 写一个 life slice 之前应该先重建什么

### 生产

- 当地生产什么？
- 什么依赖进口或外地运输？
- 什么长期短缺？
- 哪些产业已经成熟？
- 哪些产品强烈受季节影响？

### 收入

- 现金工资；
- 实物收入；
- 家庭中有几个挣钱的人；
- 储蓄；
- 债务与信贷。

### 价格

把生活必需品和大型耐用品分开记录：

- 主食；
- 房租；
- 燃料；
- 衣物；
- 交通；
- 通信；
- 大型家电。

一个孤立的名义价格通常没有意义，最好和工资、家庭预算一起比较。

### 基础设施

- 电力；
- 自来水；
- 下水道与厕所；
- 燃气；
- 道路质量；
- 铁路可及；
- 港口；
- 邮政；
- 电话；
- 广播电视接收。

### 分配与公共服务

- 商店；
- 市场；
- 邮购；
- 配送；
- 维修；
- 公共洗衣房；
- 送冰服务；
- 食堂；
- 公共浴室；
- 公用电话。

拥有并不是获得服务的唯一方式。

### 住房

某件家电即使买得起，也可能因为住房条件而很难使用：

- 面积不足；
- 线路不够；
- 没有上下水；
- 排水困难；
- 通风不足；
- 没有安全储物空间。

### 时间

时间本身也是一种物质资源。

问一问每天或每周有多少时间被这些事情占走：

- 通勤；
- 做饭；
- 打水或取燃料；
- 洗衣；
- 照顾孩子；
- 排队；
- 采购；
- 维修；
- 无偿家庭生产。

家庭技术的重要性，很大一部分就在于它改变了时间预算。

## 为什么平均数很危险

一个全国平均值可以掩盖完全不同的世界。

同一个国家、同一个年代里可能同时存在：

- 已经高度电气化的城市与供电很差的村庄；
- 有冰箱的家庭与每天买菜、无法长期储存食物的家庭；
- 汽车拥有者与主要依赖步行、自行车的人；
- 家里有电话的人与必须走很远才能打一次电话的人。

只要证据允许，就尽量保留最小的地理单位和社会群体差异。

## 为什么“旧”和“新”总是长期共存

技术史通常不是线性替代，而是层层叠加。

一个家庭完全可能：

- 有电视但没有冰箱；
- 有洗衣机但没有方便的热水；
- 附近有电话但家里没有电话；
- 有摩托车，但短途仍然主要骑自行车。

不要把历史写成“新技术一出现，旧系统立刻消失”。

真正有意思的往往就是过渡期本身。
