# 从“去图书馆才知道有没有”到“先查、先约、就近取”：公共图书馆、知识可寻址性与学习空间（中国，1980—2026）

Status: research note / cross-repo topic  
Companion: `tmzncty/old-web-archaeology/PUBLIC_LIBRARY_OPAC_READER_ACCOUNT_RENEWAL_RESERVATION_AND_DIGITAL_RESOURCE_STATE_GAPS_1999_2015.md`  
Last research pass: 2026-09-10

## 0. 研究问题

互联网史很容易把“信息获取”写成浏览器、搜索框与手机的历史，但普通人的信息生活从来不只发生在个人设备上。

在大众互联网以前，一个人如果想找一本书、一篇文章、某种职业或考试资料，常常需要先知道：

- 哪一家图书馆可能有；
- 自己能不能进去；
- 是否需要读者证；
- 开馆时间是否和工作、上学冲突；
- 卡片目录或索引该怎么查；
- 找到书目以后，书究竟在哪个馆、哪个阅览室、哪个索书号；
- 找到以后能不能借走，还是只能现场看。

互联网到来以后，这些问题没有一起消失。它们被拆成更多可远程处理、也更容易彼此错位的状态：

```text
知道一本书存在
→ 在目录里检索到书目
→ 知道哪个馆有复本
→ 复本当前可借
→ 自己拥有有效借阅资格
→ 成功预约/委托
→ 书被分配给自己
→ 书被送到约定取书点
→ 在截止日期前到馆
→ 真正取到书
→ 阅读、复制或把信息用于现实行动
```

因此，本专题研究的不是“图书馆发展史”，而是公共图书馆怎样成为普通人的 **knowledge-access infrastructure——知识获取基础设施**，以及数字网络怎样改变：

1. 知识能否被定位；
2. 图书馆资源能否跨馆、跨时间、跨距离调度；
3. 普通人是否必须拥有私人设备、私人订阅和私人学习空间，才能继续学习；
4. 一个成年人离开学校以后，是否仍有低成本的学习入口；
5. 图书馆作为公共空间、设备、网络和人工服务的角色，为什么没有随着 Web 搜索而消失。

核心边界：

> **bibliographic existence ≠ holdings existence ≠ current availability ≠ reader eligibility ≠ successful reservation ≠ pickup ≠ reading ≠ life outcome**

以及：

> **information access ≠ information ownership；online access ≠ household Internet access；digital service ≠ home-only service。**

## 1. 与已有专题的边界

本专题与已有《从“知道去哪里找”到“输入一个问题”：分类目录、搜索引擎与检索劳动》互补，而不重复。

已有专题研究的是 **retrieval labor**：目录、搜索引擎、关键词、排名和核验怎样改变“找到信息”的成本。

本专题研究的是另一个状态机：

```text
检索结果
→ 馆藏复本
→ 公共机构成员资格
→ 物理/数字访问
→ 借阅、续借、预约、调拨
→ 学习空间与设备
```

因此，即使搜索引擎已经告诉一个人某本书叫什么，他仍可能因为没有购买预算、离图书馆太远、没有空座、开馆时间和工作冲突、复本被借走、数据库只允许持证读者登录，而无法真正使用它。

它也和成人继续教育专题不同：成人教育专题研究“重新进入教育”的制度路径；本专题研究一个人即使不正式入学，仍能否获得 **书、数据库、网络、桌椅、安静时间和参考服务**。

## 2. 方法与证据规则

遵循仓库 `METHODOLOGY.md`：

- 不把“某馆建立自动化系统”写成普通家庭已经能远程使用；
- 不把“OPAC 有书目记录”写成架上一定有可借复本；
- 不把“一个城市建立一馆通”写成所有居民都实际办证或使用；
- 不把数字资源采购量写成实际阅读量；
- 不把网页访问量写成独立人数；
- 不把线上服务存在写成线下场馆已经不重要；
- 不把 1994 年中国全功能接入 Internet 写成普通家庭 1994 年已普遍联网；
- 个人材料用于恢复当时的操作、摩擦和时间感，不默认代表全国。

个人材料继续区分：

- **platform-observable fact**：页面、接口、栏目或规则确实存在；
- **contemporaneous self-report**：当时用户描述自己的使用；
- **retrospective self-report**：多年后回忆；
- **cross-confirmed**：有制度、技术或统计材料交叉确认；
- **media reconstruction**：记者或平台对用户行为的二次整理。

## 3. Internet 以前：公共知识本来就是“地点 + 时间 + 凭证”的基础设施

### 3.1 图书馆降低了购买门槛，却没有消除空间门槛

在纸质目录时代，公共图书馆的优势不是让信息“无处不在”，而是让一个普通家庭不必购买每一本书、每一期报刊或每一种参考资料。

代价是访问与机构地点绑定：

```text
知道图书馆在哪里
→ 在开放时间到达
→ 获得阅览/借阅资格
→ 使用目录或人工咨询
→ 找到馆藏位置
→ 在馆内阅读或借回家
```

这可以称为：

## **reading-place dependency——阅读地点依赖**

信息可以是公共的，但使用它的人仍必须把自己的身体搬到正确地点。

开馆时间也构成 **library time window——图书馆时间窗**。对白天上班、照护孩子、通勤很长或只能晚上学习的人来说，馆藏多少与“我今天能不能用”之间并不等价。

### 3.2 数字目录早于 Web，也早于家庭 Internet

海外前史可以帮助避免“Web 创造了数字图书馆”这种后见之明。

美国 Evanston Public Library 的机构历史记录：1979 年决定采购 online public access catalog，1980 年 10 月普通读者开始使用 CLSI 触摸屏目录终端。

Source:
- Evanston Public Library, `Evanston Public Library History`:
  https://epl.org/evanston-public-library-history/

Evidence:
- B+/C+：当代机构保存的历史时间线，可确认机构自身所记录的技术部署；不是本轮取得的 1980 年原始系统日志。

Arizona Memory Project 保存了一张日期标为 1985 年的 Glendale Community College OPAC 原始照片及说明：学生在 Web 普及以前就可以用字符界面按作者、题名、主题等检索；记录页还显示持有馆、索书号，以及当时是否借出。

Sources:
- Arizona Memory Project, GCC Library OPAC, 1985:
  https://azmemory.azlibrary.gov/nodes/view/210418
  https://azmemory.azlibrary.gov/nodes/view/210419

Evidence:
- A-/B+：有明确原始日期、机构与数字档案 provenance 的历史图像/说明。

这里最重要的不是“美国更早”，而是技术层级：

> **馆内终端已经数字化 ≠ 普通家庭已经联网。**

同样的边界以后必须用于中国材料。

## 4. 1990s 海外比较：目录第一次跟着电话线回家，图书馆也成为早期公共联网入口

### 4.1 1991：家庭拨号先接入“图书馆数据库”，不必先进入开放 Web

Westerville Public Library 的机构历史记录，1991 年启动 dial-up access，使读者可以在家或办公室用电脑和调制解调器搜索图书馆数据库。

Source:
- Westerville Public Library, `History of the Westerville Public Library`:
  https://westervillelibrary.org/library-history/

Evidence:
- B+/C+：机构历史回顾。

这说明普通人的远程知识访问可以有一条与后来 Web 不同的路径：

```text
家用 PC + modem
→ 拨号进入单一机构数据库
→ 搜索馆藏
```

而不是：

```text
先拥有开放 Internet
→ 再访问网站
```

### 4.2 图书馆还可以是 Internet 的“公共前门”

Internet Hall of Fame 对 Jean Armour Polly 的回顾记录：1990s 初，纽约州 Liverpool Public Library 在公共馆内提供电脑，并运行夜间 BBS；图书馆闭馆后把电话线交给 BBS，远程用户可以留言、提参考问题和获得荐书服务，次年达到每月约 1000 次来电。

Sources:
- Internet Hall of Fame, `The Librarian Who Hated to Type Catalog Cards`:
  https://www.internethalloffame.org/2020/04/02/librarian-who-hated-type-catalog-cards/
- Internet Hall of Fame, `The Origins of the Ubiquitous “Surfing the Internet”`:
  https://www.internethalloffame.org/2019/10/10/origins-ubiquitous-surfing-internet/

Evidence:
- C+/B：多年后的机构人物史；适合证明一条被交叉记录的技术/服务谱系，不用于外推美国公共图书馆普及率。

它提供了本专题第一个跨国共同机制：

## **institutional bandwidth——公共机构带宽**

普通家庭无法独自承担昂贵设备、线路、数据库或技能成本时，公共机构可以先拥有它，再让多人共享。

所以 Internet 的大众化从来不只有“设备越来越便宜 → 每家自己买”这一条路，还包括：

```text
私人不可及
→ 学校/单位/图书馆先可及
→ 公共终端与共享账户降低进入门槛
→ 家庭接入再逐步扩张
```

## 5. 中国边界：1994 以前不是“完全没网络”，1994 以后也不是“家庭立刻全联网”

本专题继续沿用仓库既有网络史边界：

```text
科研邮件 / 专线 / X.25 等前互联网数字通信
≠ 1994 全功能 Internet 接入
≠ 公众商业 Internet 出现
≠ 普通家庭可及
≠ 大规模日常使用
```

公共图书馆尤其适合观察中间层，因为数字资源完全可能先通过**机构节点**进入普通生活，而不是直接进入家庭。

2002 年启动的全国文化信息资源共享工程就是例子。文化部、教育部 2006 年文件明确说明：工程把文化信息资源数字化后，通过 **互联网和卫星**传到基层服务网点；并与农村中小学现代远程教育工程结合，通过中国教育卫星宽带网把资源送到农村中小学，服务学生和农民群众。

Source:
- 教育部、文化部《关于在农村中小学实施全国文化信息资源共享工程的通知》，2006-03-30：
  https://zwgk.mct.gov.cn/zfxxgkml/ggfw/202012/t20201205_916509.html

Evidence:
- A：政府同期文件。

2008 年文化部材料又记录，上海截至 2007 年底已有 1106 个文化共享工程中心/服务点，包括街镇图书馆、行政村、社区信息苑、学校、企业等。

Source:
- 文化部《实现文化信息资源共享工程网点全覆盖》，2008-08-18：
  https://www.mct.gov.cn/whzx/bnsj/cws/201111/t20111128_827692.html

Evidence:
- A-/B+：政府同期项目材料；可以证明项目报告的建设状态，不能单独证明每个网点真实使用强度。

因此应该写成：

> **数字资源进入基层服务点 ≠ 每个家庭都拥有宽带。**

一个村民可以在本地学校、文化站或信息苑接触数字内容，而家里仍没有 Internet。这种 **institution-mediated digital access——机构中介的数字接入** 是中国大众互联网史中不应被“家庭上网率”抹掉的一层。

## 6. 2001—2012：扩张型未来——“我不必先去总馆，才知道总馆有什么”

### 6.1 上海中心图书馆：先把分散馆藏变成一个可查询、可调度的城市网络

上海 2001 年启动中心图书馆首批分馆建设。2005 年同期报道已经把市、区、街道之间的一卡通与联网目录写进普通使用场景：持卡读者可以通过计算机了解其他成员馆是否有某本书，并在网络内通借通还。

Source:
- 《新民晚报》/新浪，`市民有了“身边的图书馆”`及相关 2005—2010 中心图书馆报道。
- 2010 年解放日报总结：
  https://news.sina.com.cn/o/2010-12-29/065421724900.shtml

Evidence:
- B+：同期媒体；城市体系建设可由后续政府材料交叉确认。

2010 年上海中心图书馆实现所有 212 个街道/乡镇图书馆加入“一卡通”服务体系，同期报道还列出“网上预约、就近取书”和手机图书馆等服务；2007-09-25 试运行的 `e卡通` 则允许持证读者远程访问获得授权的电子资源。

Sources:
- 东方网/新浪，2010-12-28：
  https://news.sina.cn/sa/2010-12-28/detail-ikftssap3471407.d.html
- 文化部，2012-02-24：
  https://www.mct.gov.cn/preview/special/3461/3469/201202/t20120224_230995.html

Evidence:
- B+/A-：同期媒体与政府公共文化材料。

这一步产生了本专题的核心概念：

## **holdings addressability——馆藏可寻址性**

过去“这座城市有没有这本书”可能必须逐馆问；联网目录把问题变成：

```text
书目记录
→ 哪个成员馆有复本
→ 当前状态
→ 是否允许预约/委托
→ 能否调拨到近处
```

信息不只是“被数字化”，而是**开始可以被调度**。

### 6.2 2008：真实用户仍会卡在“主页能打开，目录打不开”

百度知道今天仍保留一条时间标记为 2008-12-05 的用户提问。提问者说上海图书馆主页能打开，但点击“书目检索”以后 `http://ipac.library.sh.cn/` 显示页面无法打开，因此询问别人是本机问题还是网站问题；随后回答者称自己能打开。

Source:
- 百度知道保存的 2008 问答：
  https://zhidao.baidu.com/question/78032935.html

Evidence:
- B-/artifact：当前平台仍展示具体 2008 时间戳和当时 URL，可作为同时代用户操作残留；不是本轮取得的 2008 archive capture，也不能据此确定当时服务器故障原因。

它提醒我们：

> **library homepage reachable ≠ OPAC endpoint reachable**  
> **另一个用户能打开 ≠ 这个用户当时就能打开。**

浏览器、线路、DNS、服务器状态、脚本和本机环境都可能成为最后一公里摩擦。

### 6.3 2008 深圳：把“开馆时间”从部分借阅动作里拆出去

2008-04-08 深圳特区报报道城市街区 24 小时自助图书馆样机。系统通过网络连接深圳图书馆中心数据库；用户可以办证、借书、还书，并让预约图书配送到最近的自助点。一名现场试用者把它评价为方便、快捷、像一个现代化小型图书馆。

Source:
- 深圳特区报/新浪，2008-04-08：
  https://news.sina.com.cn/c/2008-04-08/070615310025.shtml

Evidence:
- B+：同期报道；现场用户评价属于 contemporaneous self-report，但单一个案不代表总体体验。

2008 年 7 月首批 10 台进入社区；到当年 10 月底，报道给出的项目运营数为 2478 张新证、处理文献 106735 册次。

Source:
- 广西新闻网，2008-11-15：
  https://news.gxnews.com.cn/staticpages/20081115/newgx491eee9d-1764381.shtml

Evidence:
- B：同期媒体使用项目方统计；可证明当时公开报告的运营规模，不等于独立审计。

这可以称为：

## **opening-hours decoupling——开馆时间脱耦**

过去：

```text
想借书
→ 必须在工作人员在场时到馆
```

现在一部分动作变成：

```text
在线/自助查询与预约
→ 后台分配
→ 物流送至自助点
→ 用户在更长时间窗口取还
```

但这不是“物理图书馆消失”。恰恰相反，机器背后仍需要中心馆藏、编目、物流、补书、设备维修和身份系统。

### 6.4 反例：设备摆在附近，也不等于社区真的采用

2009 年南方都市报对深圳 40 台自助图书馆调查发现，不同社区使用明显分化；某高档小区设备甚至积灰，很多居民不知道具体位置。

Source:
- 南方都市报/新浪，2009-09-02：
  https://news.sina.com.cn/c/2009-09-02/053216224552s.shtml

Evidence:
- B+：同期现场调查。

因此：

> **service deployed ≠ noticed ≠ understood ≠ used。**

这和家庭宽带、公共终端、电子政务的采用逻辑一致：基础设施存在只是可执行性的一个条件。

### 6.5 2009 国家图书馆：Internet 之外，电话也成为远程事务接口

2009-09-07 国家图书馆呼叫中心开通。同期《新京报》报道，固定电话或手机用户可以查询开闭馆、办证信息，也可以自助查询已借图书、查询预约到书、续借，并获得人工服务。

Source:
- 新京报/新浪，2009-09-07：
  https://news.sina.com.cn/c/2009-09-07/040116251610s.shtml

Evidence:
- B+：同期媒体。

这说明“数字化服务”的成熟并不是强迫所有人进入 Web，而可以同时建立：

```text
网页 / OPAC
电话自助
人工坐席
短信/手机
实体柜台
```

这是一种早期的 **multi-channel public service——多通道公共服务**。

## 7. 图书馆网络真正改变的不是“找到书”，而是减少一次失败出行

联网目录、预约和调拨最容易被低估的效果，是改变一个人的计划风险。

传统模式：

```text
坐车去馆
→ 查目录
→ 找书
→ 才发现已借出/不在本馆/不能外借
```

联网后理想模式：

```text
出门前查询
→ 确认复本与借阅类型
→ 预约/委托
→ 等待到书通知
→ 再移动身体
```

因此可以定义：

## **failed-trip avoidance——失败出行避免**

它对时间特别稀缺的人价值更大：上班族、照护者、跨区通勤者、考试备考者。

但必须保留硬边界：

`目录显示“可借” ≠ 那本书此刻一定准确地躺在架上`。

复本可能正在归还上架途中、被错误放置、被另一位读者拿在手里、状态同步延迟，或者业务规则不允许该读者借走。

## 8. 2015—2019：拥堵型未来——信息越来越便宜，安静时间和公共座位反而显得稀缺

### 8.1 2018：工作以后，“到图书馆”本身成为新的时间成本

2018 年中国青年报对 2000 名受访者的在线调查中，武汉青年林溪回忆上大学时经常在学校图书馆坐一天；毕业工作以后，上一年只去了市图书馆两次。北京事业单位员工陈淼则说自己家离最近公共图书馆约 40 分钟，大多直接网上买想看的职场书和小说，因此几乎不去公共馆。

Source:
- 中国青年报，2018-01-30：
  https://zqb.cyol.com/html/2018-01/30/nw.D110000zgqnb_20180130_3-07.htm

Evidence:
- B+：同期媒体中的 contemporaneous self-report。
- 调查为在线问卷样本，不能把“76.3% 一个月内去过图书馆”等比例外推成全国人口发生率。

这一反例非常重要：

> **免费 ≠ 零成本。**

即使借阅免费，40 分钟路程也会把“公共资源”重新变成时间昂贵的资源。

### 8.2 互联网没有消灭专业馆藏的优势

同一报道中，来自太原的大学生张诚会在假期去山西省图书馆，因为自己的工科院校馆藏偏工程技术，省馆有更多文学类图书；另有受访者为了地方戏曲资料使用公共馆，并明确认为部分材料并不是普通网络平台能够替代的。

Evidence:
- 同上。

因此：

`Web 上可搜到相关内容 ≠ 能合法、稳定、完整地获得需要的文献。`

图书馆的意义开始从“唯一信息入口”转成：

- 长尾馆藏；
- 付费数据库的公共/机构授权；
- 参考服务；
- 纸本和特殊载体；
- 可持续保存；
- 一张可以坐下来的桌子。

### 8.3 2019：有人开始为“一张能长期专注的桌子”单独付费

2019 年中国青年报对北京付费自习室的同期报道里：备考法律硕士的刘同学每天学习超过 10 小时；袁翊宸从 5 月起每天坐 40 分钟公交去中关村付费自习室准备北大金融专业研究生；英语老师小姜每天约早 6:40 出门，坐近 1 小时车到自习室，平均每天花费约 33 元。

Source:
- 中国青年报，2019-11-27：
  https://zqb.cyol.com/html/2019-11/27/nw.D110000zgqnb_20191127_1-08.htm

Evidence:
- B+：同期现场报道与个人材料。

另一篇 2019 年报道直接把用户选择付费自习室的原因写成：图书馆难占座、家里学不下去、咖啡店太吵。

Source:
- 北京日报/人民网，2019-10-22：
  https://capital.people.com.cn/n1/2019/1022/c405954-31413167.html

这里新增一个生活史概念：

## **concentration infrastructure——专注基础设施**

现代信息社会的问题不再只是“有没有资料”，还包括：

> **我有没有连续几个小时不被工作、家务、室友、孩子、噪音和消费压力打断的地方。**

对准备考证、考研、转行的人来说，一张桌子和稳定电源可以和教材一样成为再进入未来的基础设施。

## 9. 2020—2022：偶发型未来——场馆关闭后，哪些服务可以远程延续，哪些不能

2020 年疫情期间，公共图书馆大规模面对物理场馆暂停或限流。西藏自治区图书馆 1 月 25 日闭馆后，通过网站、微信等提供数字阅读，并允许读者通过电话和微信办理图书查询、续借；这意味着“闭馆”没有自动让既有借阅关系变成逾期惩罚。

Source:
- 西藏自治区图书馆相关报道，2020-03-05：
  https://rituxian.gov.cn/info/1017/85411.htm

Evidence:
- B+/A-：政府网站转载地方同期报道。

湖南部分高校图书馆在 2020 年又通过在线平台把新购纸书直接寄到师生家中，形成“在线荐购/借阅 + 实体物流”的临时链路。

Source:
- 湖南省教育厅，2020-03-26：
  https://jyt.hunan.gov.cn/sjyt/jyyw/202003/t20200326_1001319.html

Evidence:
- A-/B+：政府教育部门同期材料。

与此同时，恢复开放后的图书馆可能采用网上预约与现场名额并行。湖南图书馆 2020-03-19 起有序开放时，每日既有网上预约名额，也保留现场放行名额，并限制同时在馆人数。

Source:
- 湖南省文化和旅游厅，2020-03-18：
  https://whhlyt.hunan.gov.cn/news/gzdt/202003/t20200318_11815393.html

Evidence:
- A：同期官方开放公告。

这里可以看到“偶发型未来”的典型状态：

```text
物理场馆中断
→ 数字资源继续
→ 已借图书续借/罚则调整
→ 一部分纸本通过物流绕行
→ 恢复后增加预约、容量与时段控制
```

Internet 没有让地点消失，而是给机构增加了 **continuity channels——连续性通道**。

## 10. 2023—2026：防守型未来——成熟数字社会重新发现“一个免费、可坐下、有人在场的地方”

### 10.1 2024：公共学习空间的稀缺重新变得可见

2024 年中国青年报在线调查及采访中，受访者章闻说市图书馆可以自习，但周末、期末座位紧张，晚上关门也偏早；另一位受访者翟子文指出大城市和二三线城市/县城之间公共学习资源差异明显，希望学习资源下沉，支持返乡青年继续成长。

Source:
- 中国青年报，2024-12-26：
  https://zqb.cyol.com/pc/content/202412/26/content_404760.html
  https://m.cyol.com/gb/articles/2024-12/26/content_ZvNz9xC2qe.html

Evidence:
- B+：同期个人材料；问卷为网络样本，不外推全国发生率。

这使“防守型未来”里的一种稳定第一次变得很具体：

## **fallback learning place——学习退路空间**

当家里不适合学习、公司不能久留、学校身份已经结束、咖啡店需要持续消费、付费自习室要花钱时，公共图书馆提供的不是宏大的“知识殿堂”，而是一种低成本退路：

- 桌子；
- 椅子；
- 电源；
- 网络；
- 安静；
- 厕所；
- 可预期的开放时间；
- 不需要不断点单才能留下来的合法停留资格。

### 10.2 2025：图书馆也承担“弱关系社会空间”

2025 年中国青年报采访中，90 后秦越把北京城市图书馆作为周末去处；深圳读者赵茹在宝安区图书馆英语角遇到刚毕业的同龄人和退休老人，并在这里建立新的学习关系。

Source:
- 中国青年报，2025-01-21：
  https://zqb.cyol.com/pc/content/202501/21/content_406228.html

Evidence:
- B+：同期人物报道。

所以图书馆还可以是：

## **low-obligation social infrastructure——低义务社交基础设施**

一个人可以独自进入，不需要先认识任何人，也不必须消费，却仍有机会参加英语角、讲座、夜校、读书会和兴趣活动。

这种空间对迁居、毕业、离职、退休、照护中断等人生节点尤其值得继续研究，因为这些节点常常会让原来的单位/学校社交网络突然变薄。

### 10.3 2026：多通道不是旧时代残余，而是成熟系统的冗余

2026 年国家图书馆节假日开放安排仍允许少年儿童馆预约同时通过微信服务号或电话完成。

Source:
- 北京市政府/北京日报，2026-03-30：
  https://www.beijing.gov.cn/fuwu/bmfw/sy/jrts/202603/t20260330_4569421.html

Evidence:
- A-/B+：当期官方门户转载开放安排。

这很适合“防守型未来”的逻辑：

> 成熟数字服务不必把所有旧入口删掉；电话、人工、网页、App、实体窗口可以构成彼此备用的接口。

“所有人都使用最新 App”不是基础设施成熟的唯一标准；**一个渠道坏了以后还有没有下一条路**，同样重要。

## 11. 四种未来：同一个图书馆，为什么在不同时代代表不同的未来感

### 11.1 2005—2012：扩张型未来

未来感来自资源边界扩大：

- 一张卡可以进入更多分馆；
- 目录可以同时看到更多馆藏；
- 网上预约减少白跑；
- 24 小时自助点延长借还时间；
- e 卡通和数字图书馆让部分数据库不必到馆使用；
- 手机、电话逐渐成为新的入口。

普通人的想象更接近：

> “以后我不必先住在某个大学、某个研究单位附近，才能接触更多资料。”

### 11.2 2015—2019：拥堵型未来

信息数量不再是唯一瓶颈，时间和空间成为更明显的问题：

- 工作以后没时间去馆；
- 图书馆离家太远；
- 安静座位有限；
- 考研、考证和职业升级增加长期自习需求；
- 免费公共座位和付费自习室开始形成替代关系。

未来感转向：

> “我知道自己还要继续学，但一天已经被工作和通勤切得很碎。”

### 11.3 2020—2022：偶发型未来

系统必须回答：场馆突然关闭时，学习与借阅怎样不断线？

- 数字资源；
- 电话/微信续借；
- 延长归还与取消逾期惩罚；
- 纸本物流；
- 分时预约和现场限额。

### 11.4 2023—2026：防守型未来

未来感不是无限扩张，而是保住一种可持续的低成本学习能力：

- 有附近的座位；
- 下班以后仍开放；
- 不必重新获得学生身份；
- 不必持续商业消费；
- 数字和人工入口并存；
- 能在职业变化、备考、失业、返乡、退休时继续进入一个公共学习环境。

## 12. 对“普通人到底有多少种活法”的新理解

本轮增加的不是一种职业或家庭类型，而是一种 **life-course support infrastructure——生命历程支持基础设施**。

标准人生脚本常常默认：

```text
学校阶段负责学习
→ 工作以后负责生产
→ 有问题自己购买信息/课程/设备
```

但现实生命历程更碎：

- 工作几年以后重新考研；
- 转行补知识；
- 失业期间准备资格考试；
- 退休以后系统学习；
- 租住空间太小，没有书桌；
- 家里有孩子，无法连续安静两小时；
- 刚搬到新城市，没有稳定社交圈；
- 经济紧张，买不起大量专业书或数据库。

公共图书馆让“继续学习”不必完全依赖于“重新成为学生”或“持续购买商业服务”。

因此可以提出：

## **knowledge-membership portability——知识成员资格的可携带性**

一个人在学校毕业后失去校园图书馆账号，不代表社会必须让他的系统学习能力一起毕业。公共馆、中心馆网络、跨馆借阅和数字读者证，都是把知识使用资格从单一单位身份中部分拆出来的尝试。

## 13. 新机制词表

### 13.1 `holdings addressability / 馆藏可寻址性`

不仅知道“某书存在”，还知道哪一个地点的哪一个复本当前可被请求。

### 13.2 `reading-place dependency / 阅读地点依赖`

资源虽然公共，却必须到特定建筑、在特定时间使用。

### 13.3 `opening-hours decoupling / 开馆时间脱耦`

自助机、远程续借、数字资源、物流等把部分操作从工作人员在场时间中拆出。

### 13.4 `institutional bandwidth / 公共机构带宽`

机构先承担昂贵线路、终端、数据库、订阅和专业人员成本，让个人共享。

### 13.5 `institution-mediated digital access / 机构中介的数字接入`

普通人使用数字资源，不要求其家庭首先拥有完整 Internet 接入。

### 13.6 `failed-trip avoidance / 失败出行避免`

通过远程查询/预约减少到了现场才发现不可借、无货或不开放的概率。

### 13.7 `concentration infrastructure / 专注基础设施`

让人能连续学习数小时的座位、照明、电源、网络、安静与规则。

### 13.8 `fallback learning place / 学习退路空间`

人在失去校园、办公室或适宜居家空间后，仍能低成本进入的学习地点。

### 13.9 `knowledge-membership portability / 知识成员资格可携带性`

学习资源使用资格不完全被当前学校、单位或雇主身份锁定。

### 13.10 `low-obligation social infrastructure / 低义务社交基础设施`

无需先有熟人、无需持续消费，也可以合法停留并形成弱关系连接的公共空间。

## 14. 反例与后见之明风险

### 14.1 不能写“Internet 让图书馆不再重要”

2018—2025 的材料恰恰显示：专业馆藏、学习空间、公共活动和低成本停留仍有独立价值。

### 14.2 不能写“数字资源等于所有人远程可看”

商业数据库常受读者证、IP、机构许可、并发数和授权范围限制。

### 14.3 不能写“OPAC = 实时真相”

书目记录与复本状态不同，复本状态与架位现实也可能不同。

### 14.4 不能写“自助设备投放 = 普及使用”

2009 深圳的社区分化就是直接反例。

### 14.5 不能写“线上预约 = 线下空间无限”

座位、开馆时长、馆舍面积仍然是物理约束。

### 14.6 不能写“公共馆用户 = 全体居民”

图书馆使用会受教育、距离、职业时间、家庭照护、残障条件和地区资源差异影响。

### 14.7 不能把在线调查外推成全国比例

2018、2024、2025 中国青年报问卷适合恢复受访者诉求和当时的话语，不作为全国人口使用率。

## 15. 与 `old-web-archaeology` 的交叉

中文旧网最值得保存的不是“图书馆官网长什么样”，而是 **public shell 与真实馆藏/读者状态之间的接口**。

重点对象：

```text
公开主页
→ OPAC 检索页
→ 动态查询结果
→ 书目记录
→ 馆藏/复本状态
→ 读者登录
→ 已借记录
→ 续借
→ 预约/委托
→ 到书通知
→ 线下取书
```

另一个链条是：

```text
数字资源目录
→ 读者证/IP/机构认证
→ 商业数据库或自建资源
→ 授权判断
→ 实际全文
```

这些状态具有不同的 archive survivability。

## 17. 当前未知与下一轮可验证点

1. 1980s—1990s 中国公共图书馆卡片目录、自动化目录和读者使用的同期一手材料仍不足；应优先找馆史档案、图书馆学期刊和原始系统手册，而不是靠后来怀旧。
2. 上海 `ipac.library.sh.cn` 2000s 的真实历史 capture 尚未验证；需要得到 capture datetime、HTTP、charset、DOM、query endpoint 和动态结果行为。
3. 国家图书馆 2002 Aleph500 到 2008 `opac.nlc.gov.cn` 的浏览器/编码/会话行为仍需历史页面验证。
4. “网上委托借书”从提交到分馆物流、到书通知之间的真实时间分布尚缺普通用户材料。
5. 公共图书馆数字数据库在 2007—2012 年的家庭远程访问，对不同读者证、ISP、浏览器插件和数据库厂商有何限制，需要逐库验证。
6. 县城/乡镇/农村服务点的真实使用强度、开放时长、维护中断和普通人第一人称材料仍偏薄。
7. 2023—2026 公共学习空间是否真的更多服务于转行、考证、失业间歇和返乡青年，需要更多非问卷式生命史材料。

## 18. 本轮对核心矩阵的改动

本专题直接增加/加厚以下矩阵项：

- **教育**：离校后的继续学习资源；
- **就业**：转行、考证、职业升级需要的资料和学习空间；
- **住房**：家里是否有书桌/安静空间影响公共馆需求；
- **迁移**：搬到陌生城市后能否获得本地公共知识网络；
- **长期中断**：失业、照护、退休后仍可学习；
- **证件与记录**：读者证、借阅资格、已借/逾期/预约状态；
- **通信方式**：电话、Web、短信、App 与实体柜台并行；
- **互联网平台**：OPAC、数字资源门户与授权系统；
- **信息获取**：从书目存在到复本实际可用；
- **社交关系**：英语角、夜校、读书会等低义务弱关系；
- **未来预期**：成年人仍可为考试、转行和长期学习保留低成本退路；
- **线上/线下身份**：网页账号/读者证与现实借阅权并不完全等价；
- **平台消失与记忆保存**：公共目录壳比动态馆藏、读者状态和授权全文更容易保存。

---

## 19. 本轮结论：普通人的“未来”有时只差一张免费桌子

公共图书馆最值得放进生活史的地方，并不是它收藏了多少册书，而是它把几种原本需要私人购买的能力捆在了一起：

```text
书与报刊
+ 目录与专业检索
+ 数据库与网络
+ 一张桌子
+ 电源和照明
+ 安静时间
+ 人工参考服务
+ 不需要持续消费的停留资格
```

Internet 把其中一部分搬出了建筑：目录可以在家查、书可以先预约、部分数据库可以远程登录、电话可以续借、纸书甚至可以通过物流送到近处。

但这没有证明建筑已经过时。相反，2019—2025 的材料显示，数字内容越丰富，**专注空间、公共座位、低成本设备、人与人共处但互不打扰的环境**越可能成为独立稀缺品。

因此，对“普通人到底有多少种活法”的新理解是：

> **一个社会允许多少种非线性人生，不只取决于学校允许几次入学、公司提供多少岗位，也取决于一个已经离开学校、暂时没有单位、家里没有合适学习空间的人，是否还能合法、低成本地坐到一张桌子前，找到资料，然后继续准备下一种生活。**
