# 从“知道去哪里找”到“输入一个问题”：分类目录、搜索引擎与检索劳动（中国，1980–2026）

Status: research note / cross-repo topic  
Companion: `tmzncty/old-web-archaeology/SEARCH_DIRECTORY_QUERY_RANKING_AND_INDEX_STATE_GAPS_1997_2015.md`  
Last research pass: 2026-09-05

## 0. 研究问题

“信息更多了”并不自动等于普通人“知道得更多”。

一个人真正能把信息用于生活，至少要经过：

```text
信息存在
→ 知道应去哪里找
→ 到得了那个来源
→ 能提出可检索的问题
→ 系统返回相关结果
→ 能读懂结果
→ 能判断来源和时效
→ 能把信息转成现实行动
```

本专题研究的不是搜索引擎产品史，而是普通人的 **retrieval labor——检索劳动**：为了找到一个真正可用的答案，人需要付出的目录浏览、关键词选择、改写查询、交叉核验、判断时效、识别广告/平台偏差与继续追到原始来源的工作。

核心区分：

> **possible ≠ discoverable ≠ queryable ≠ returned ≠ trustworthy/current ≠ executable**

社会上真实存在一种工作、一所学校、一套住房、一种生活方式，并不意味着某个具体的人当时知道它；搜索框能返回一条结果，也不意味着结果仍然有效，更不意味着这个人有资源去执行。

因此，搜索基础设施改变普通生活的主要方式不是“凭空增加人生选项”，而是改变：

- 找到候选选项的成本；
- 在多少候选之间比较；
- 信息更新的速度；
- 哪些对象被排名系统优先看见；
- 普通人需要承担多少核验劳动；
- 旧信息、冷门信息和远方信息能否重新进入当前决策。

## 1. 方法边界

遵循仓库 `METHODOLOGY.md`：

1. 不把“数据库/搜索技术存在”写成普通家庭已经可用；
2. 不把“页面被搜索引擎收录”写成所有用户都能找到；
3. 不把“搜索结果排第一”写成最可信、最流行或最相关；
4. 不把“搜索量”写成独立人数；
5. 不把今天的平台搜索习惯倒投回 1990s；
6. 不把 1994 以前中国已有科研网络/email 写成大众 Internet；
7. 不把 1994 全功能接入写成 1994 普通家庭已经普遍上网；
8. 个人帖子只用于恢复实际检索动作与时间感，不默认具有代表性。

每个例子至少记录：

```text
who searched?
where did they search?
what had to be known before searching?
what did the system actually return?
what remained to be verified?
what real action followed, if known?
```

## 2. Internet 以前：信息检索首先是一种“知道去哪里找”的能力

### 2.1 纸质索引本身就是检索基础设施

1980 年创刊的《全国报刊索引（哲学社会科学版）》由上海图书馆等机构编辑，以月刊形式把分散在报刊里的文章重新组织成可查目录。

Source:
- 对外经济贸易大学图书馆 OPAC，《全国报刊索引,哲学社会科学版》书目记录：
  https://opac.uibe.edu.cn/opac/book/61fe81afda7393d14a9f65af37fc4c67

Evidence:
- A-/B+：图书馆书目记录可以确认刊名、起始年份、出版机构与载体；不能单独证明普通读者使用频率。

这类工具提醒我们，在搜索框以前，“查资料”往往要求人先知道：

- 哪个图书馆可能有；
- 应查哪一本目录/索引；
- 主题被编目人员归到哪个类目；
- 找到索引条目后，原报刊又在哪里。

这可以称为：

## **source-location knowledge——来源定位知识**

早期检索劳动的很大部分，不是“如何写关键词”，而是“我应该先去哪个地方、翻哪一本工具”。

### 2.2 中国 1994 年以前不是“完全没有数字网络”，但普通生活仍不能按 Web 时代理解

中国科学院高能物理研究所的机构史记录：

- 1986 年已经借长途电话线与 CERN 传输电子邮件；
- 1988 年改用 X.25，并可与欧洲、北美进行 E-mail 通讯；
- 1990 年通过 CNPAC 与 CERN 通讯；
- 1993 年开通至美国 SLAC 的 64K 专线。

Source:
- 中国科学院高能物理研究所，《网络发展》：
  https://ihep.cas.cn/jg/yjbm/jszx/zxgk/wlfz/

Evidence:
- A：机构官方历史。

CNNIC 的历史材料把 **1994-04-20** 的 64K 国际专线定义为中国与 Internet 的全功能连接；1995 年以后，社会公众互联网接入才开始扩展。

Sources:
- CNNIC，《1994年～1996年互联网大事记》：
  https://www3.cnnic.cn/n4/2022/0401/c87-912.html
- CNNIC/人民邮电报历史综述：
  https://www2.cnnic.cn/n4/2024/0508/c208-10983.html

Evidence:
- A-/B+：CNNIC 官方保存的历史材料。

因此本专题坚持四层边界：

```text
科研/邮件/专线等前互联网数字通信
≠ 1994 全功能 Internet 接入
≠ 公众商业接入出现
≠ 普通家庭可及 / 大规模使用
```

## 3. 海外前史：Minitel 证明“普通生活可电子检索”早于开放 Web

法国 Minitel 的第一个核心服务就是电子电话簿。IEEE Spectrum 的技术史梳理指出，电子目录具有自然语言搜索界面；Minitel 随后又进入行政、注册、银行、新闻等服务，并在家庭、工作地点和公共终端中广泛出现。

Source:
- IEEE Spectrum, “Minitel: The Online World France Built Before the Web”:
  https://spectrum.ieee.org/minitel-the-online-world-france-built-before-the-web

Evidence:
- B+：高质量技术史综合。

1987 年的同行评议论文对 Minitel 早期试点也明确区分电子电话目录、地方行政服务等不同实验区域。

Source:
- Jean-Marie Charon, “Videotex: from interaction to communication” (1987):
  https://journals.sagepub.com/doi/10.1177/016344387009003004

Evidence:
- A-/B+：同期学术研究。

这个海外对照非常重要：

> **电子检索不是 Web 才发明的。**

Internet/Web 的关键变化之一，是可检索语料逐渐从一个中央运营商预先限定的服务目录，扩展到数量巨大、主体分散、持续变化的网页；而到了平台时代，信息又重新分裂进多个彼此不完全可爬取的封闭内容池。

可概括为：

```text
纸质目录 / 人工咨询
→ bounded electronic directory
→ open-web corpus
→ search-ranked web
→ walled-platform corpora
→ multi-source / AI-mediated retrieval
```

这不是线性替代，而是长期共存。

## 4. 1995–2002：从“上哪个站”到“输入什么”

### 4.1 早期中文 Web 的一个核心问题是：先找到网站本身

1998 年前后的搜狐历史页面把自身描述为“大型分类查询搜索引擎”，并留下“出门靠地图，上网找搜狐”的口号。

Source lead:
- 当前可访问的 1997–1998 风格搜狐/爱特信页面镜像：
  https://www.sohuitc.cn/

Evidence:
- C/B locator only：当前镜像/重现页面不是本轮实际验证的 historical memento；只能用于定位历史自我叙述，不能据此复原原 DOM、charset 或查询 endpoint。

这种“分类查询”对应一种和今天不同的检索心智：

```text
先知道门户/目录
→ 进入大类
→ 进入小类
→ 浏览站点标题
→ 才进入目标站点
```

普通人需要学习的是目录 taxonomy，而不是只学习关键词。

本专题称这一转折为：

## **taxonomy-to-query shift——从分类路径到查询表达式**

### 4.2 2001：同一个搜索框背后已经可能是“网页搜索 + 网站目录 + 站内/频道搜索 + 实时信息”不同系统

百度当前保存的一份标记为 2001-01-15 的公司新闻称，其向 263 提供的整套搜索产品同时包括：

- 网页搜索引擎；
- 网站目录系统；
- 特定网站内容/频道检索；
- 实时信息系统。

Source:
- 百度企业历史新闻，2001-01-15：
  https://home.baidu.com/home/index/news_detail/id/16970

Evidence:
- A-/B+：公司当前保存的同期企业新闻，可以证明公司当时如此描述产品；不是本轮验证过的 archive capture，也不独立证明实际效果。

因此 old-Web 与生活史都必须区分：

> **“有一个搜索框”并不告诉我们它到底在搜什么。**

一个搜索框可能只搜：

- 门户自己的栏目；
- 人工目录；
- 部分 Web 抓取语料；
- 新闻数据库；
- 某个垂直站点；
- 当前平台内部内容。

### 4.3 到 2002，搜索已经进入大量网民的日常信息动作，但仍不等于全国普通人口常态

CNNIC 2002 年第十次统计报告记录，截至 2002-06-30，中国上网用户总数为 4580 万。

Source:
- CNNIC，第十次《中国互联网络发展状况统计报告》发布页：
  https://www3.cnnic.cn/n4/2022/0401/c155-4806.html

Evidence:
- A：统计机构官方发布。

同期媒体对 CNNIC 前一轮调查的概括曾把搜索引擎列为网民最常使用的网络服务之一，仅次于电子邮件一类核心应用。

这里的正确写法是：

```text
search became ordinary among many Internet users
≠
search became ordinary for the entire population
```

因为此时“能不能上网”本身仍是分布极不均匀的前置条件。

## 5. 2001 以后：结果排序本身开始成为市场

百度当前保存的 2001-09-20 与 2001-12-17 企业新闻明确描述“竞价排名”：企业购买关键词，并可按出价影响搜索结果中的排序；公司称这一模式在 2001 年进入多个主要中文门户的搜索系统。

Sources:
- 百度，2001-09-20，《百度“搜索”竞价排名浮出水面》：
  https://home.baidu.com/home/index/news_detail/id/16984
- 百度，2001-12-17，《为点击付费》：
  https://home.baidu.com/home/index/news_detail/id/16994

Evidence:
- A-/B+：同期公司材料，可证明其产品规则与市场主张；不能把公司自称覆盖范围当独立市场审计。

这引入一个生活史上非常重要的新变量：

## **ranking-mediated visibility——排名中介的可见性**

当信息量大到必须排序时，“能不能被找到”不再只是页面存在与否的问题，而还取决于：

- 搜索引擎是否抓到；
- 是否解析成功；
- 是否进入索引；
- 查询词如何匹配；
- 排名算法；
- 广告/竞价层；
- 后来的地域、设备、个性化状态。

所以：

> **top result ≠ best evidence ≠ most representative reality**

这不是今天才出现的“算法问题”。

## 6. 2005–2012：扩张型未来——“有问题先搜一下”把远方和冷门选项拉进当前生活

### 6.1 搜索逐渐从“找网站”变成“找答案/找资料”

CNNIC 2008 搜索引擎用户研究的同期报道显示，到 2008 年底中国搜索引擎用户规模已相当大；用户不仅搜索娱乐，也大量搜索专业资料、新闻、生活信息等。

Sources:
- 中国互联网协会转载 CNNIC 研究，2009-03-05：
  https://www.isc.org.cn/article/10314.html
- DOIT 对《2008中国搜索引擎用户行为研究报告》的同期整理：
  https://www.doit.com.cn/p/44466.html

Evidence:
- A-/B+：来自 CNNIC 报告的同期转载/发布信息。

其中一个特别值得保留的数据是：近 2/3 受访搜索用户表示不知道搜索结果的排列规则。也就是说，大规模使用搜索，不等于大规模理解排名机制。

这形成：

## **query literacy / ranking literacy gap——查询素养与排名素养缺口**

### 6.2 2008 第一人称：搜索可以把已经从广播时代表面消失的文化记忆重新拉回来

2008-02-20，一名新浪博客用户写道，自己偶然在网络搜索中找到 1980 年代末新加坡电视剧《窈窕淑女》的视频，继而继续搜索演员刘琦资料；但又发现资料极少，很多作品仍然找不到。

Source:
- 新浪博客，2008-02-20，《新加坡演员刘琦-儿时的记忆》：
  https://blog.sina.com.cn/s/blog_4afaf12c01008mln.html

Evidence:
- A/B：同时代第一人称公开博客；只说明这个人的检索体验，不代表整体网民。

它很好地恢复了搜索的真实双面性：

```text
过去节目离开电视播出时段后几乎不可得
→ 网络搜索使部分旧视频重新可发现
→ 但索引里没有的、没有数字化的、无人上传的仍然“像不存在一样”
```

这里出现：

## **index-visible past——索引可见的过去**

数字化和搜索并不平等地保存历史。被上传、被抓取、被链接、被排名的过去，比没有进入索引的过去更容易成为今天人的“记忆”。

### 6.3 搜索增加候选，不等于降低全部决策成本

扩张型未来里，一个学生可以搜索：

- 学校；
- 专业；
- 新职业；
- 外地岗位；
- 租房；
- 路线；
- 考证；
- “别人这样生活过没有”。

这会扩张 **option horizon——可见选项地平线**。

但随后出现新的劳动：

- 哪些结果是真的；
- 是否过期；
- 是否广告；
- 是否只适合别人；
- 是否遗漏了没有被索引的路径。

因此搜索最重要的历史变化之一可以写成：

> **把“我不知道还有什么”转化成“我知道有很多，但需要筛选”。**

## 7. 2015–2019：拥堵型未来——搜索没有消失，而是被多个平台拆开

CNNIC 2019 年搜索引擎研究与同期分析显示，截至 2019 年 6 月，中国搜索引擎用户仍有巨大规模；但通用搜索的使用率出现缓慢下降，垂直 App、超级 App 和平台站内搜索分流越来越明显。

Sources:
- CNNIC，《2019年中国网民搜索引擎使用情况研究报告》发布页：
  https://www3.cnnic.cn/n4/2022/0401/c122-1110.html
- 2019 年基于 CNNIC 数据的同期整理（81.3% 使用率等）：
  https://cloud.tencent.com/developer/news/433907

Evidence:
- A + B。

这改变了检索的基础问题。

过去可能是：

```text
一个搜索引擎
→ 尽量找整个 Web
```

后来越来越像：

```text
百度搜公开网页
+ 微信搜公众号/聊天/小程序
+ 淘宝搜商品
+ 知乎搜问答
+ 招聘 App 搜岗位
+ 小红书/短视频平台搜经验
```

因此增加：

## **corpus fragmentation——检索语料碎片化**

一个人在 2019 年知道“该搜什么”已经不够，还得知道：

> **这个问题应该在哪个平台搜。**

这使“来源定位知识”在 Web 时代消失以后，又以平台版本重新回来。

同期关于搜索与内容平台的争论也提醒：外部搜索无法完整抓取封闭平台时，`web search no result` 更不能写成 `platform content did not exist`。

## 8. 2020–2022：偶发型未来——“最新”本身成为可执行生活的资格条件

疫情期间，出行规则会在短时间内改变。

2022-09-01 国务院客户端明确提供“出发地 + 目的地”的防疫政策查询，并允许用户订阅变动；政策变化后，系统可以发送提醒。

Source:
- 国务院客户端，2022-09-01：
  https://app.www.gov.cn/govdata/gov/202209/01/489017/article.html

Evidence:
- A：官方服务说明。

这给生活史增加了一个以前搜索研究很少单独处理的变量：

## **freshness horizon——信息新鲜度地平线**

以前一条地图、学校介绍、职业经验即使几个月旧，仍可能有用；疫情出行中，一条昨天正确的规则今天就可能让行程失败。

因此：

```text
search result is relevant
≠
result is current enough to act on
```

而“订阅变动”意味着信息基础设施进一步从：

```text
我主动查一次
```

变成：

```text
系统替我监控这个状态是否变化
```

这和仓库已有的 `from-scheduled-to-ambient-information.md` 相连，但本专题关注的重点不是通知本身，而是：

> **当现实状态变化速度超过一次查询的有效期时，普通人必须把“持续刷新”也交给基础设施。**

## 9. 2023–2026：防守型未来——搜索越来越像“反向背调”和避坑工具

2025 年中国青年报关于应届生入职“避坑”的同期报道中，2026 届毕业生周昊辰在多个 offer 之间比较职业前景、工作强度和社保情况，一边在社交平台发帖请教，一边找学长学姐核实；另一名毕业生在进入小微企业前还查询企业规模、工商信息与纠纷记录。

Source:
- 中国青年报/中新网，2025-12-25，《应届生入职前要注意避开哪些“坑”》：
  https://www.chinanews.com.cn/sh/2025/12-25/10539826.shtml

Evidence:
- A/B：同期媒体第一人称采访。

这和 2008 年的扩张型搜索心态有明显区别。

2008 更容易问：

> “还有哪些我以前不知道的机会？”

2025 的一部分决策则更像：

> “这个机会表面很好，我能不能提前找到它可能出问题的地方？”

本专题把它称为：

## **defensive retrieval——防守型检索**

其目标不是最大化新选项，而是减少：

- 虚假招聘；
- 合同陷阱；
- 社保不缴；
- 公司经营风险；
- 培训/考证诈骗；
- 网红经验把极端个案包装成普遍规律。

### 9.1 UGC 搜索扩大“别人实际体验过什么”，也扩大代表性判断的难度

小红书商业化团队发布的《2024 小红书搜索推广白皮书》声称，70% 月活用户存在搜索行为，88% 搜索为主动发起；相关二次报道把平台描述为生活决策搜索入口。

Sources:
- 福布斯中国对该白皮书的整理：

所以防守型检索本身还需要第二层防守：

## **provenance work——来源谱系劳动**

不只是“搜到什么”，还要问：

- 谁写的；
- 什么时候写的；
- 为什么会写；
- 是亲历、广告、搬运还是情绪内容；
- 平台为什么把它排到我面前；
- 有没有官方/合同/统计资料可以交叉验证。

## 10. 四种未来的同一条检索轴

### 2005–2012：扩张型未来

搜索的主要主观价值是：

- 远方可以先看；
- 冷门职业可以先查；
- 别人的路径可以先发现；
- 旧知识和旧文化可以重新找到；
- 许多未来第一次进入“至少值得查一下”的范围。

关键词：**discoverability expansion**。

### 2015–2019：拥堵型未来

问题从“信息太少”越来越转向：

- 到底去哪一个平台搜；
- 同一问题有太多结果；
- 广告、SEO、平台内容和真正资料混在一起；
- 需要在多个入口维持检索路线。

关键词：**retrieval fragmentation**。

### 2020–2022：偶发型未来

问题进一步变成：

- 信息是不是今天的；
- 本地执行是不是和全国规则一致；
- 一次查询还能有效多久；
- 是否需要订阅变化。

关键词：**freshness as executability**。

### 2023–2026：防守型未来

越来越多检索用于：

- 反向背调；
- 查风险；
- 看“踩坑”经验；
- 查合同/社保/工商/纠纷；
- 判断一个看起来很好的未来有没有隐性成本。

关键词：**defensive due diligence**。

这不是说 2026 的人不再寻找机会，而是：

> **机会搜索与风险搜索越来越同时发生。**

## 11. 对“普通人有多少种活法”的改变

本专题把原来的问题：

> 社会上到底有多少种人生路径？

进一步拆成：

```text
actual path set
→ visible path set
→ queryable path set
→ trusted path set
→ executable path set
```

同一个时代里，不同人的人生菜单差异，可以来自完全不同的原因：

- 信息从未进入其生活圈；
- 没有网络/终端；
- 不知道该用什么词搜；
- 不知道应该去哪一个平台；
- 搜索排序没有把它呈现出来；
- 看见了但不相信；
- 相信了但信息已过期；
- 信息正确但钱、证件、住房、家庭条件使其无法执行。

所以：

## **life-course visibility is infrastructural——人生路径的可见性本身也是基础设施产物。**

## 12. 重点矩阵

| 生活领域 | 检索改变了什么 | 不能偷推的结论 |
|---|---|---|
| 教育 | 学校/专业/考试/课程更可比较 | 搜到课程 ≠ 有资格/钱参加 |
| 就业 | 岗位、行业、公司背景可远程检索 | 有职位页 ≠ vacancy 有效 |
| 住房 | 房源/区域/通勤/口碑可搜索 | 房源页 ≠ 仍可租 |
| 婚姻家庭 | 伴侣/婚姻经验/育儿经验可见 | UGC 经验 ≠ 普遍路径 |
| 迁移 | 城市、路线、工作和生活成本可预查 | 能查 ≠ 能迁移 |
| 照护 | 医疗/养老/政策信息可远程找 | 搜到政策 ≠ 本地执行一致 |
| 非正规劳动 | 零工与小机会更容易被发现 | 平台展示 ≠ 稳定收入 |
| 长期中断 | gap/再教育/转行案例可检索 | 看见案例 ≠ 能复制 |
| 证件与记录 | 验证入口/规则可查询 | 查询页存在 ≠ 记录可匹配 |
| 通信方式 | 从问熟人转向先搜、再问 | 搜索没有消灭熟人网络 |
| 互联网平台 | 每个平台成为自己的语料库 | 外部搜索无结果 ≠ 平台无内容 |
| 信息获取 | 从定位来源转向表达问题+判断结果 | 搜到 ≠ 知道 |
| 社交关系 | 陌生人经验进入决策 | 高互动案例 ≠ 代表性案例 |
| 未来预期 | 可想象未来集合扩大 | 可见未来 ≠ 可执行未来 |
| 线上/线下身份 | 名字/账号/机构记录变得可反查 | 同名/旧记录可能误绑 |
| 平台消失与记忆 | 索引决定哪些过去容易重新被找到 | 索引缺失 ≠ 历史不存在 |

## 13. 反例与后见之明风险

### 13.1 搜索不是“熟人咨询的终结”

2025 求职材料恰恰显示，年轻人会同时：

- 搜平台；
- 查工商/纠纷；
- 发帖；
- 问学长学姐。

搜索改变了咨询顺序与候选池，不等于把熟人经验淘汰。

### 13.2 信息更多也可能增加决策成本

更多结果意味着更多：

- 比较；
- 真假判断；
- 来源追踪；
- 过期检查；
- 焦虑。

所以“降低检索成本”可以同时“增加筛选成本”。

### 13.3 不要把今天的搜索框倒投回 1998

早期：

- 分类目录很重要；
- 不同搜索框可能是完全不同后端；
- 编码与浏览器限制更大；
- Web 总量和收录覆盖更小；
- 用户甚至要先知道门户在哪。

### 13.4 不能把平台商业白皮书当普通人口调查

小红书等平台公布的搜索渗透率，只能说明其自身测量口径下的平台行为，不证明全国所有人都这样搜，也不证明平台内容真实或代表性高。

## 14. 已知 / 可推断 / 尚不知道

### 已知

- 中国 1994 全功能接入 Internet 以前已经存在科研 email、X.25 与专线通信；
- 1990s 末中文 Web 已存在大型分类查询/搜索门户；
- 2001 年中文搜索产品已经明确区分网页搜索、目录、站内/频道检索等后端；
- 2001 年竞价排名已经把结果排序商业化；
- 2008 年搜索已深入多类信息需求，但大量用户并不了解结果排列规则；
- 2019 前后通用搜索与平台/垂直 App 检索开始明显并存；
- 2022 的政策查询出现“订阅变化”，表明信息时效直接成为现实行动条件；
- 2025 求职者会把社交平台、熟人、工商/纠纷信息组合为反向背调。

### 可合理推断

- 搜索降低了陌生城市、陌生职业、旧文化和非本地人生案例的发现成本；
- 随着平台封闭化，检索劳动的一部分从“写什么关键词”转回“到哪里搜”；
- 排名和商业推广使信息可见性越来越不能直接等同于社会重要性。

### 尚不知道

- 1998–2002 普通用户一次完整中文搜索到底会改写多少次关键词；
- 早期网吧/家庭用户如何在目录浏览与全文搜索之间切换；
- 不同社会群体获得“搜索技巧”的渠道；
- 2008、2019、2025 同一人的检索渠道组合如何变化；
- 一条搜索结果究竟有多大概率真正改变工作、迁移、婚姻、住房等行动；
- 未被搜索引擎索引的历史网页和生活路径因此被后人系统性漏掉了多少。

## 15. 下一步最有价值的证据

优先找一条跨时期的 **retrieval ledger**：

```text
1990s：遇到问题先问谁 / 查什么目录 / 去哪里
2000–2005：第一次用目录或搜索引擎解决什么真实问题
2007–2010：最常搜什么，如何判断哪个结果可信
2018–2019：同一问题是否开始分流到微信/知乎/垂直 App
2020–2022：是否因为信息过期导致真实行程/手续失败
2023–2026：是否形成“先搜风险、再决定是否行动”的习惯
```

最关键的不是记“用过百度/小红书”，而是恢复：

- query；
- result；
- verification；
- action；
- failure；
- fallback。

如果能拿到三四代这样的 ledger，我们才能真正测量：

> **普通人的人生菜单究竟是因为社会真的出现了更多路径而变宽，还是因为过去本来存在但看不见的路径，第一次变得可以被问出来。**
