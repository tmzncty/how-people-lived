# 人不是一下子变成“永远在线”的：1983—2002 年寻呼、公用电话与间歇联网的可达性桥

## 研究问题

今天很容易把个人通信史压缩成一条线：

```text
固定电话
→ BP 机
→ 手机
→ 互联网
→ 移动互联网
```

这条线会误导生活史研究，因为真实日常不是一种终端被另一种终端整齐替换，而是多种**不完整的通信能力**长期叠加。

1990 年代的一名普通用户完全可能同时拥有或借用：

- 家庭或单位固定电话；
- 公用电话；
- 寻呼机；
- 移动电话；
- 单位或家中的拨号 Internet；
- 电子邮件；
- 网络寻呼 / 邮件到达寻呼；
- 传真。

这些东西各自解决不同问题。

本文提出四个需要进入生活史矩阵的机制：

1. **split-terminal reachability（分离终端可达性）**：一个终端负责把“有人找你”送到移动中的人，另一个终端负责真正回复；
2. **reachability bridge（可达性桥）**：一个通信网络把通知转交给另一个网络，从而让不在线的人仍能被找到；
3. **intermittent-connectivity life（间歇联网生活）**：早期 Internet 用户经常只在某个地点、某段时间拨号上线，Internet 地址存在并不等于本人持续在线；
4. **contact-stack accumulation（联系栈累积）**：固定电话、寻呼、手机、Email 在一段时期里会同时出现在名片、广告和日常联系流程中，而不是前者出现后者立即消失。

核心问题不是“哪一年中国人开始上网”，而是：

> **在个人还不能随时随地双向联网的时期，一个普通人怎样让消息追上移动中的自己，又怎样把回复送回去？**

这条线同时能帮助澄清中国 1994 年前后的网络史边界：科研网络、电子邮件、公共数据网、正式全功能 Internet 接入、大众拨号接入、家庭可及和真正的持续在线，是不同历史时点，不能压成一个“联网年”。

## 一、先把“可达”拆开：收到通知和完成回复不是一回事

寻呼机最适合暴露现代人已经不容易意识到的一种通信结构。

一个典型的一向寻呼流程更接近：

```text
A 想联系 B
→ A 找到固定电话 / 公用电话
→ 拨寻呼台 / 寻呼号码
→ 留下号码或短消息
→ 寻呼网络把提示送到 B 的移动终端
→ B 看见提示
→ B 再找一部可以使用的电话
→ 回拨 A
```

这里的移动终端只解决了一半问题：

> **B 可以在移动中被找到，但 B 并不因此获得了随处回复的能力。**

因此应该至少拆开：

| 变量 | 问题 |
|---|---|
| notification reachability | 对方能否把“有人找你”送到你身上？ |
| payload capacity | 能收到的是一个号码、短文字，还是完整消息？ |
| reply endpoint | 你在哪里可以真正回复？ |
| reply latency | 从收到提示到找到回复终端需要多久？ |
| mobility | 接收端 / 回复端是否能随身移动？ |
| network dependence | 是否依赖人工寻呼台、固定电话、公话、移动网或 Internet？ |

这比“有 / 没有电话”更接近日常。

### 为什么这对生活史重要

如果一个工人、业务员、医生、司机、摊贩或外出办事的人只带寻呼机，那么：

- 他不必守在办公室等电话；
- 但收到呼叫后仍要寻找可用电话；
- 回电成本会受到公话密度、单位电话规则、排队、资费和所在位置影响；
- 号码提示可以把一次完全失联变成一次延迟联系，但不会自动变成今天式即时聊天。

因此寻呼不能只按“移动电话的落后前身”理解。它是一种独立的**移动通知基础设施**。

## 二、1983 并不等于“大众寻呼”：仍然要使用多重到达时钟

中国电信系统的后来的制度性沿革资料把几个节点列得很清楚：

- 1983 年 9 月，上海开通早期模拟寻呼系统；
- 1984 年广州出现数字寻呼；
- 1980 年代后期至 1990 年代，寻呼网络、用户规模和跨区域服务迅速扩大。

来源：

- 中国通信业发展历史节点整理（中国网络电视台 / 中国电信历史资料，2011）：<https://jingji.cntv.cn/special/history/20111115/109037.shtml>

证据等级：**C/B 边界：后来机构性历史整理**。它适合确定早期系统节点，不足以证明 1983 年普通居民已经能够日常使用。

这里必须继续沿用仓库方法中的 multiple clocks：

```text
技术试用
≠ 城市商业可得
≠ 行业用户采用
≠ 普通劳动者可负担
≠ 全国大规模普及
≠ 日常行为围绕它重组
```

因此本文不写“1983 年中国进入寻呼时代”，只把 1983 作为移动通知系统出现的早期技术边界。

## 三、1990 年代的通信不是一条替代曲线，而是一段重叠期

福建省统计年鉴留下了一组非常适合生活史的同口径省级序列。单位均为万户 / 万用户（依原表）：

| 年份 | 无线寻呼用户 | 移动电话用户 | Internet 用户 |
|---|---:|---:|---:|
| 1995 | 132.96 | 15.50 | — |
| 1996 | 199.59 | 35.65 | — |
| 1997 | 285.58 | 77.82 | — |
| 1998 | 308.00 | 142.20 | 3.85 |
| 1999 | 301.55 | 281.29 | 13.10 |
| 2000 | 317.00 | 441.00 | 70.70 |
| 2001 | 192.27 | 619.97 | 180.37 |
| 2002 | 136.40 | 792.04 | 250.80 |
| 2003 | 82.65 | 965.00 | 295.56 |

来源：

- 福建统计年鉴通信业务主要指标：<https://tjj.fujian.gov.cn/tongjinianjian/dz04/html/1112a.htm>

证据等级：**A：省级统计年鉴**。

这张表至少支持三个窄结论。

### 1. Pager、mobile、Internet 长期共存

1998—2001 年不是“寻呼退出以后手机出现，手机以后互联网出现”。三种网络身份同时增长或维持了几年。

1999 年福建的移动电话用户已经接近寻呼用户，但寻呼并没有立即消失；2000 年寻呼用户仍约 317 万，同时移动电话和 Internet 用户都快速增加。

所以生活史里更合理的模型是：

```text
fixed / public phone
+ pager
+ mobile
+ dial-up Internet
```

而不是单选。

### 2. 新技术的出现不会立即清除旧接口

移动电话确实逐渐把“收到通知”和“回复”合到同一个可移动设备上，但寻呼用户仍会因为价格、既有号码、职业习惯和覆盖等原因继续存在。

### 3. 一省序列不能直接外推全国

福建的城市结构、海外联系、收入和通信产业发展都有自身特征。此表用于证明**重叠结构存在**，不是用来写“全国普通人平均如此”。

### 一个尚未解决的全国统计口径问题

国家统计局 1999 年回顾性统计报告写到 1998 年“无线寻呼用户”3908 万，而后来的通信产业历史资料常出现更高的 6000 多万数量级。不同材料可能涉及统计系统、运营主体、口径和时间点差异。

来源：

- 国家统计局，《之十一：邮电通信业突飞猛进》：<https://www.stats.gov.cn/zt_18555/ztfx/xzg50nxlfxbg/202303/t20230301_1920449.html>

本文不在未解决统计口径前把这些数字硬合并成一个“全国总量”。

这本身也是方法结论：

> **national subscriber total is a claim that requires denominator and operator-scope reconciliation.**

## 四、公用电话是寻呼机那“消失的一半”

国家统计局同一份通信业回顾资料称，到 1998 年全国公用电话达到约 **259 万部**；同期固定电话家庭化和移动电话都在快速增长。

来源：

- 国家统计局：《之十一：邮电通信业突飞猛进》：<https://www.stats.gov.cn/zt_18555/ztfx/xzg50nxlfxbg/202303/t20230301_1920449.html>

证据等级：**A/B：官方历史统计汇总**。

公话数据为什么和寻呼要放在一起？

因为对很多一向寻呼用户来说，真正的移动通信链并不是：

```text
pager → communication complete
```

而是：

```text
pager → find a telephone → callback
```

因此公话密度、单位电话可用性和家庭固定电话拥有率，都参与决定寻呼机的真实使用价值。

### 回顾性第一人称只能作为经验补充

2007 年一篇回忆文章中，一名受访者回忆自己 1997—1999 年使用寻呼机时，每次收到呼叫都要“找公用电话回”；后来中文信息机能直接收到文字后，一部分回拨需求减少。

来源：

- 新浪科技，2007-03-21，《我们曾经的寻呼生活》：<https://tech.sina.com.cn/t/2007-03-21/17141427256.shtml>

证据等级：**C：事后回忆**。

这条材料很符合上述结构，但不能因为回忆生动就把它升级成 1997 年的同期总体证据。

它只说明这种生活经验真实存在过，并提示后续应该继续找同期日记、BBS、工作记录和电话资费材料。

## 五、寻呼的价值不是“像手机但功能少”，而是把失联改造成延迟可联系

如果没有移动通知终端，一个离开固定电话的人可能完全不知道有人正在找自己。

寻呼把这个状态改成：

```text
完全不知道有人找我
→ 我知道有人找我，但需要找到回复工具
```

这是很大的日常变化。

它可能影响：

- 临时工作调度；
- 客户与业务联系；
- 家庭紧急消息；
- 医疗和维修值守；
- 约会和临时碰面；
- 非正规劳动与小生意；
- 外出人员与单位之间的联系。

但它没有消灭：

- 找电话；
- 等待；
- 回拨；
- 电话资费；
- 覆盖盲区；
- 寻呼台 / 运营网络依赖。

因此本文把寻呼时代的一项核心生活变量定义为：

**callback latency（回拨延迟）**。

今天的即时通信常把这一段时间压得近乎不可见；1990 年代它可以是真正需要安排的一段行动。

## 六、Internet 最初进入这套生活时，常常不是替代 pager，而是把消息桥到 pager

这是本轮最重要的新证据链。

### 1999：国信寻呼已经把 Internet 接进物理寻呼网络

信息产业部 / 通信产业同期统计资料在总结 1999 年寻呼业时写到：

- 国信寻呼的 198 / 199 全国寻呼网络已经覆盖大量城市；
- “国信网源”提供网上寻呼；
- Internet 网上寻呼已经与全国 198 / 199 网络及多个省级网络连接；
- 22 个省级网络已经开通“电子邮件到达寻呼”等服务。

来源：

- 1999 年通信业统计公报 / 赛迪整理，新浪科技 2000-06-14：<https://tech.sina.com.cn/it/2000-06-14/28155.shtml>

证据等级：**A/B：同期行业统计与运营业务概述**。

这里发生的不是简单的“Internet 用户不用 pager 了”，而是：

```text
Internet / email
→ gateway
→ paging network
→ physical pager
```

也就是说，Internet 地址已经可以通过传统移动通知网络追上一个当时不坐在电脑旁的人。

这就是本文所谓 **reachability bridge（可达性桥）**。

### 为什么这种桥在拨号时代特别合理

早期个人 Internet 常是 session-based 的：

```text
到家 / 到单位
→ 打开电脑
→ modem 拨号
→ 上线
→ 收信 / 浏览
→ 下线
```

有 Email 地址并不等于“Email 发来时本人就在客户端前”。

于是一个很自然的问题出现：

> 邮件已经到服务器了，但人怎么知道？

寻呼 / 短信网关正好填补这个空隙。

## 七、1999 年腾讯邮件增值系统：Internet 消息主动追上离线的人

腾讯公司保存的一条 **1999 年 7 月 11 日**历史产品记录尤其清楚。

腾讯当时与深圳龙脉公司合作推出电子邮件增值服务系统，面向 ISP 拨号用户。系统可以在新邮件到达时抽取发件人、主题和正文，并按照用户在 Web 上设定的过滤条件和时段，把信息：

- 发往寻呼台；
- 发往 GSM 短消息；
- 或通过传真等方式取得。

来源：

- 腾讯官方历史文章，《腾讯与深圳龙脉公司合作推出电子邮件增值服务系统》，1999-07-11：<https://www.tencent.com/zh-cn/articles/80260.html>

证据等级：**A：公司同期产品 / 历史记录**。它可以证明功能和目标用户设计，不能单独证明实际用户规模。

这条材料特别有价值，因为它把“间歇联网”直接写进产品目的。

完整生活链可能是：

```text
电脑此时没有拨号在线
↓
邮件已经到 ISP 邮箱服务器
↓
后台系统检查规则
↓
摘要跨网络发往 pager / GSM SMS
↓
人在路上收到提示
↓
决定是否稍后找电话、传真机或电脑处理
```

因此这里的技术变化不是简单的：

> Internet 取代旧通信。

而是：

> **Internet 先借旧网络和移动通知网，把自己的“离线时间”补起来。**

## 八、1999 年 CNNIC 调查里的“网上寻呼机”必须谨慎解释

CNNIC 1999 年 7 月《中国 Internet 网络发展状况统计报告》报告，截至 1999 年 6 月底：

- Internet 用户约 400 万；
- 上网计算机约 146 万，其中拨号上网计算机约 121 万。

同一调查的网络服务多选题里，受访者报告的使用项目包括：

- 电子邮件 90.9%；
- 聊天 29.2%；
- BBS 28.0%；
- 个人主页 21.6%；
- 新闻组 21.4%；
- **网上寻呼机 14.8%**；
- Internet 电话 8.4%。

来源：

- CNNIC，第五次以前的 1999 年 7 月调查报告 PDF：<https://www.cnnic.cn/NMediaFile/old_attach/P020120612485127164902.pdf>

证据等级：

- 用户总量与联网计算机：**A：同期行业统计报告**；
- 服务使用比例：**A 级同期调查结果，但样本代表性必须降权解释**。

### 不能把 14.8% 写成“中国网民 14.8% 都使用物理 pager gateway”

这次调查本身说明问卷主要通过多个网站在线征集，共获得 5 万余份有效答卷，因此天然偏向能上这些网站、愿意回答调查的人。

而且“网上寻呼机”这一名称在当时可能覆盖不完全相同的产品形态：

- Web → 物理寻呼网络；
- 桌面在线寻呼 / 即时通信；
- 其他以“寻呼”命名的实时消息产品。

因此这里只能写：

> **“网上寻呼”已经是 1999 年早期中文 Internet 使用者可以辨认的一类服务。**

不能仅凭这个比例推断具体运营商、物理终端或全国人口普及率。

这条词义歧义也会直接进入 `old-web-archaeology` 的证据合同。

## 九、一个村庄的四版名片：联系手段是累积起来的，不是整齐替换

2002 年浙江日报 / 新浪的一篇同期报道保存了一个很罕见的微观序列：浙江青田一个杨梅种植村的农户为了卖果子，几年内不断修改名片上的联系方式。

报道记载：

1. 1999 年，部分收入较好的农户合资安装固定电话；
2. 很多人随后又使用寻呼机，第二版名片开始同时印固定电话和寻呼号码；
3. 2000 年以后移动电话逐渐进入，第三版名片再加手机号码；
4. 到 2002 年，村民会去县城有关农业信息中心上网查询、发布信息，其中一名农户第一次把 Email 地址加到第四版名片上。

来源：

- 浙江日报 / 新浪，2002-07-23，《浙江青田果农名片四部曲》：<https://news.sina.com.cn/s/2002-07-23/1029645564.html>

证据等级：**B：同期媒体现场报道**。

这个案例特别适合反驳“技术世代替换”的想象。

真实联系栈更接近：

```text
固定电话
→ 固定电话 + pager
→ 固定电话 + pager + mobile
→ fixed / pager / mobile + email
```

而不是：

```text
fixed phone disappears
→ pager disappears
→ mobile disappears
→ email
```

### Internet 进入普通生产生活也不是“家里突然联网”

报道里的农户需要去县城农业科技 / 信息服务机构才能查询和发布网络资料。

这意味着 2002 年这里至少要拆成：

- Internet 已存在；
- 农业信息服务已经进入县域；
- 普通农户可以借机构终端使用；
- 但不能由此推出家庭拥有电脑或家庭持续联网。

这正好符合仓库的技术采用阶梯：

```text
infrastructure exists
≠ household ownership
≠ household Internet normality
```

### 这改变了“Email 是什么”的理解

Email 在这里首先可以是一个**被印在纸质名片上的远程地址**。

对方可能从网络上发信，但收信人未必随时在线；于是 Email 地址、手机、寻呼和固定电话可以服务于不同时间尺度。

这就是 **contact-stack accumulation（联系栈累积）**。

## 十、Internet 到来后，真正被压缩的是哪些摩擦？

不能只说“通信更方便”。至少可以拆出四种变化。

### 1. 通知与回复终端逐渐合并

Pager 模式：

```text
移动通知终端
+
另找回复电话
```

Mobile phone 模式：

```text
移动通知
+
移动回复
```

这会直接降低 callback-location dependence（回拨地点依赖）。

### 2. 消息内容变长

数字 / 文字寻呼已经能减少部分“必须回拨才能知道发生什么”的需求；Email 和 Internet messaging 又进一步增加可携带信息量。

### 3. 地址与人的当前位置逐渐脱钩

Email、QQ 类账号和后来的移动网络身份允许消息先到一个持久地址，而不是要求发信人知道“你现在在哪一部电话旁”。

### 4. 但早期 Internet 自身仍有明显在线 / 离线边界

拨号、单位终端和网吧意味着：

- 地址存在；
- 服务器可以收到；
- 本人却可能数小时甚至更久不查看。

因此 Email→pager / SMS 的网关并不是奇怪的过渡玩具，而是非常符合当时生活条件的基础设施。

## 十一、一个新的生活史变量：reachability duty cycle（可达占空比）

“这个人有电话 / 有 Email”太粗。

更好的问题是：

> **在一天 24 小时里，这个人有多少时间处于别人能有效联系到他的状态？**

可以尝试记录：

```yaml
identity_channels:
  fixed_phone: true
  pager: true
  mobile: false
  email: true

reachability:
  fixed_phone_hours: workday_office_only
  pager_receive: most_waking_hours
  reply_phone_access: variable
  internet_session: evenings_or_workplace
  email_to_pager_bridge: unknown
```

这样才能区分：

- “拥有 Email”；
- “每天晚上回家拨号看一次 Email”；
- “工作单位白天可以看 Email”；
- “Email 一到就通过 pager 提醒”；
- “手机本身已经能持续收发信息”。

这也是从大众互联网史走向生活史的一个关键转换。

## 十二、海外对照：美国同样出现“Internet → pager”的可达性桥

这一机制并不是中国特有。

### 1996：AirTouch 把普通 Email 发到 pager

《San Francisco Chronicle》1996 年的同期报道记录，AirTouch 开始向美国约 260 万寻呼用户提供电子邮件到 pager 的服务；普通 Email 程序就可以发信，字母数字寻呼机接收文字。

来源：

- San Francisco Chronicle, 1996-07-30, “E-Mail Reaches Out to Page Someone”: <https://www.sfgate.com/business/article/E-Mail-Reaches-Out-to-Page-Someone-2972200.php>

证据等级：**B：同期主流媒体报道**。

### 1997：有人专门做“别为了查信反复拨号”

WIRED 1997 年报道的 NetNotify 会检查电子邮件并把通知发送到 pager，报道直接把一个使用场景写得很清楚：用户原本可能反复拨号，只为了看看邮箱里有没有新信；pager notification 可以让这个动作延后到真正需要处理时。

来源：

- WIRED, 1997-03-12, “Pager, You’ve Got Email”: <https://www.wired.com/1997/03/pager-youve-got-email/>

证据等级：**B：同期技术媒体**。

这与 1999 年中国面向 ISP 拨号用户的邮件→寻呼 / GSM 网关具有非常接近的结构：

```text
Internet mailbox
→ user is offline
→ background bridge
→ mobile notification endpoint
```

共同机制不是“某国特别爱 pager”，而是：

> **当 Internet 本身还是间歇连接时，跨网络通知桥可以提高人的实际可达占空比。**

### 1997：美国 pager 也依赖公用电话生态

《Washington Post》1997 年报道，美国部分寻呼服务商因公用电话通话补偿费用问题，限制部分免费寻呼号码从 payphone 呼入；受访用户谈到在机场、火车站依靠公话呼 pager 或查询消息会因此受影响。

来源：

- Washington Post, 1997-12-03, “That New Number: 1-800-BLOCKED”: <https://www.washingtonpost.com/archive/business/1997/12/03/that-new-number-1-800-blocked/a921072c-60c3-4e20-8cf5-92bc65f4438e/>

证据等级：**B：同期媒体**。

它给中国案例提供了一个很好的比较边界：

- **共同机制**：一向 pager 的完整生活功能依赖固定 / 公用电话网络；
- **不同制度条件**：美国案例里的公话补偿与运营商计费制度、中国的通信运营体系和资费演进不能互相套用。

## 十三、哪些现象是 Internet 时代共同变化，哪些不是？

### 比较上比较稳的共同机制

1. **移动通知早于移动全双工数据。**
2. **公话 / 固话是 pager 时代回复链的重要部分。**
3. **早期个人 Internet 常是间歇在线。**
4. **Email→pager / SMS 是 Internet 与既有移动通知网之间的桥。**
5. **旧通信方式不会在新方式出现的当天消失。**

### 中国需要单独解释的部分

- 1990 年代寻呼用户规模增长非常快；
- 国信等大型全国 / 省级寻呼网络与公共电信体系的组织方式；
- 1990 年代末移动电话、寻呼和拨号 Internet 在极短时期内高度重叠；
- 大量用户通过单位、网吧、县级信息服务点等非家庭终端进入 Internet。

这些都不能由美国资料替代。

## 十四、反例：不要把 pager 写成“必须回电话”的绝对规则

本文的 split-terminal model 是一种常见结构，不是所有寻呼设备的永恒定义。

必须保留：

- 数字寻呼只能给号码或简短编码；
- 汉字 / 文字寻呼可以直接传递更完整的信息；
- 后期存在双向寻呼设备；
- 部分工作流程收到文字后即可完成，不需要回电；
- 手机普及后，一些人可能 pager 收提示、手机回拨；
- 家里和单位固定电话快速增加，也会改变“必须找公话”的概率。

因此数据库最好记录 `payload_type` 和 `reply_required`，而不是只写 `pager=true`。

## 十五、反例：不要把“1999 年有 Internet”写成“普通人已经永远在线”

CNNIC 1999 年报告显示，当时上网计算机中拨号上网占很大部分；问卷受访者上网地点也包含家庭、单位、网吧等多种环境。

来源：

- CNNIC 1999-07 报告：<https://www.cnnic.cn/NMediaFile/old_attach/P020120612485127164902.pdf>

因此需要至少区分：

```text
Internet full connection exists nationally
→ commercial / public Internet service exists
→ person has an account
→ person can reach a terminal
→ person can afford a session
→ person is online now
→ person can be reached while away from terminal
```

把这些层压成“网民”会丢掉大量日常差异。

## 十七、后见之明风险

### 风险 1：把 pager 写成“失败的手机”

这会看不见它实际解决的是廉价移动通知，而不是完整移动会话。

### 风险 2：把 Internet 写成从电脑直接跃迁到今天手机 Internet

早期 Internet 很多时候是地点固定、拨号、session-based 的。

### 风险 3：把新技术看成旧技术的立即替代

福建序列和青田名片案例都显示长期叠加。

### 风险 4：把网络地址和持续可达混为一谈

`has email address ≠ checking email now`。

### 风险 5：把“网上寻呼”当成一个稳定技术名词

1999 年前后的“网上寻呼”“网络寻呼机”可能指物理 pager gateway，也可能是桌面即时通信隐喻。必须回到具体 delivery endpoint。

### 风险 6：用后来的怀旧代替同期使用证据

Pager 怀旧文章很丰富，但更应优先用当年统计、产品资料、用户页面、广告和业务手册建立基础事实。

## 十九、它改变了我们对“人怎么活着”的哪一点理解？

过去很容易把通信史写成设备史：家里先装电话，后来买 BP 机，再买手机，再上网。

这一轮更接近日常生活的答案是：

> **一个普通人的“可联系性”曾经是被几张网络拼起来的。**

一个人可以移动，却只能收到通知；可以有 Email，却只有晚上拨号时才读取；可以在网上发布生意信息，却需要县城信息中心；可以在名片上同时留下固话、寻呼、手机和 Email，因为每个地址覆盖不同的人、地点与时间窗口。

所以 Internet 到来的第一阶段并不一定是“把旧通信全部替换掉”。它经常先变成旧通信栈里的一个新层，并借 pager、SMS、传真、公话、单位终端把自己的边界补起来。

这说明从前 Internet 到大众 Internet 的真正转折至少有三层：

```text
信息可以进入数字网络
→ 普通人能够在某个地方使用数字网络
→ 数字网络能在普通人离开终端后仍持续追上他
```

第三层发生得比“正式联网”晚，也比今天默认的“永远在线”世界更值得单独研究。
