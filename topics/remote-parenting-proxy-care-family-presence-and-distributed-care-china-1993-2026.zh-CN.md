# 不在家，不等于不参与：远程育儿、代理照护与家庭“在场”的基础设施（中国，1993—2026）

> 研究问题：父母离开家乡工作以后，家庭并不会自动停止运转。谁负责孩子每天吃饭、上学、生病和夜间安全？外出的父母怎样知道家里发生了什么，又能实际改变什么？电话、短信、家校通、QQ 视频、摄像头、儿童主任和跨部门信息台账，分别替代了哪一种距离成本，又有哪些照护劳动始终必须由一个在场的人完成？

本条目研究 **distributed care / 分布式照护** 和 **remote parenting / 远程育儿**，而不是把“留守儿童”当成一种固定人格类型。

它与 [`communication-and-the-cost-of-living-far-away.md`](communication-and-the-cost-of-living-far-away.md) 的分工是：后者问通信怎样降低迁移的社会成本；本条目继续往下拆，问 **信息真的传到以后，照护是否能够被执行**。

一个最小状态机可以写成：

```text
父母离家工作
→ 本地实际照护者明确
→ 孩子与外出父母可互相联系
→ 学校 / 健康 / 安全事件被某人观察
→ 信息传给正确的人
→ 对方理解发生了什么
→ 有人能在当地采取行动
→ 必要的钱、决定或物品能够远程送达
→ 紧急时父母能够回来，或可靠代理人能够顶上
→ 孩子的需要真的被表达出来，而不只是“电话接通”
```

这条链必须把几种“在场”分开：

- **physical presence / 身体在场**：谁与孩子同住、做饭、送医、夜间处理突发情况；
- **informational presence / 信息在场**：谁知道孩子今天有没有到校、考试如何、是否生病；
- **decision presence / 决策在场**：谁可以决定转学、就医、花钱、返乡；
- **emotional presence / 情感在场**：孩子愿不愿把真实烦恼告诉这个人；
- **financial presence / 经济在场**：谁为生活、教育和医疗提供钱；
- **institutional presence / 制度在场**：学校、村居、儿童主任、数据库是否知道这个家庭处于什么状态。

它们可以由不同的人和不同系统承担，不能因为“父母每天打电话”就推出“父母仍然完成了全部育儿”。

## 一、Internet 以前：迁移家庭首先是一套“代理照护 + 慢通信”的家庭结构

农村劳动力跨地区流动扩大以后，父母与儿童长期分居并不是从手机时代才出现的。现有仓库已经讨论过书信、公用电话、村电话怎样降低远距离家庭联系的成本；这里要增加的是：**通信只能移动信息，不能移动照护动作。**

如果父母在外，孩子仍然需要一个本地的人来：

- 做饭、洗衣；
- 看病、买药；
- 处理学校通知；
- 夜里陪伴；
- 应对事故；
- 维持日常纪律；
- 在父母突然无法联系时继续让家庭运行。

因此，远程育儿从一开始就是一种 **care-proxy stack / 照护代理栈**：外出父母、祖父母或亲友、学校、邻里和后来逐渐加入的公共服务共同承担不同状态。

一个很重要的后见之明风险是：不能因为 2000 年代已经有手机，就把 1990 年代想象成“完全失联”；也不能因为某村已有电话，就把它等同于每个家庭都能随时、私密、低成本通话。通信接入、家庭所有权、资费、号码可达性和实际通话频率是几只不同的钟。

## 二、2003—2006：短信和家校平台首先把“学校发生了什么”变成远程可观察状态

2005 年泉州的“家校亲情卡”已经不是单纯的一张电话卡。同期教育信息化报道记录：300 多所学校、约 13 万名学生使用该系统；学校可发停课通知，学生刷卡可触发到校信息，教师可在平台上传通知、成绩和评语，家长也能通过账号获得教育资源。

来源：中国教育和科研计算机网，2005-10-14：
https://cernet.edu.cn/xxh/fei/xin_xi_zi_xun/200603/t20060323_144201.shtml

证据等级：**B，同期行业/教育信息化报道。**

中国移动 2006 年企业社会责任报告又记录，福建“家校通”自 2004 年 1 月正式启用后，短信报平安注册客户达到 20 万，家校互联用户超过 4 万；功能包括签到、报平安、亲情通话、家校互联和小额支付。

来源：中国移动，2006 企业社会责任报告：
https://www.chinamobile.com/aboutus/res/2006cr_cn/P040102.shtml

证据等级：**A，运营商同时代正式材料；只能证明运营商当时公布的产品功能和规模，不能自动证明所有注册家庭都持续使用。**

2005 年 12 月，中山的“家长留言板”又把电话、短信、PC 和校门口电子屏幕接在一起：家长拨 12580 留言，内容显示在学校出入口的电子屏；学校公告则由校方在电脑上录入。

来源：中国教育和科研计算机网，2006-03-29：
https://www.edu.cn/chanpin_xinxi_1709/20060329/t20060329_170194.shtml

证据等级：**B，同期行业报道。**

这些系统第一次大规模创造了一种 **care telemetry / 照护遥测**：父母不必站在校门口，也能获得“到校”“离校”“成绩”“通知”等离散事件。

但必须固定几个状态缺口：

```text
卡已发给学生
≠ 孩子本人完成了所有后续行动

刷卡事件生成
≠ 孩子当天所有时间都处于安全状态

短信已发出
≠ 家长已经读到

家长读到
≠ 家长能亲自赶到学校处理
```

所以 Web / SMS 在这里主要改变的是 **remote observability / 远程可观察性**，而不是把本地照护劳动数字化。

## 三、2008—2009：同时代孩子的未来想象告诉我们，“联系得到”与“想过父母那样的人生”完全是两回事

中国农业大学“中国农村留守儿童研究”课题组从 2006 年 11 月起用两年时间，在安徽、河南、湖南、江西、四川调查 400 名留守儿童及相关群体。2008 年底、2009 年初的同时代成果报道非常适合校正后来怀旧或悲观投射。

调查显示，打电话已经是留守儿童与外出父母维系关系的主要方式，但 95.4% 的外出父母在通话时会询问学习情况，报道同时指出情感交流不足；61.5% 的儿童不愿意把烦恼告诉父母。另一方面，留守女童中 47.2% 经常做家务，53.9% 经常或不时照料祖父母或其他监护人，被研究者称为“逆向监护”。

来源：中国青年报 2009-01-06，央视网存留：
https://news.cctv.com/china/20090106/102098.shtml

补充来源：中国新闻网，2008-12-08：
https://www.chinanews.com.cn/jk/xljk/news/2008/12-08/1478226.shtml

证据等级：**B，同时代媒体对一项有明确样本、地区和调查时段的学术研究的报道。样本不能代表全国所有儿童。**

这里至少出现三个此前矩阵里没有独立命名的机制。

### 1. connected / confiding gap / 接通—倾诉缺口

一个家庭可以技术上“每周都联系”，但如果通话几乎只剩“学习怎么样”“听爷爷奶奶的话”，并不能推出孩子真实的焦虑、冲突和身体状态已经进入父母的决策系统。

**通信频率不是情感信息带宽。**

### 2. child-as-caregiver inversion / 儿童反向照护

标准人生脚本把孩子放在“被照护者”位置，但迁移家庭里，儿童自己也可能承担洗衣、做饭、照顾年老监护人的劳动。因而一个家庭不能只按“父母 → 儿童”一条照护箭头建模。

这不应被浪漫化成“穷人的孩子早当家”。它首先说明：**家庭缺少一个成年人时，原本属于成人的劳动可能向儿童下沉。**

### 3. migration-script rejection / 对父母迁移脚本的拒绝

同一研究显示，90% 以上受访留守儿童的人生理想不涉及体力劳动；他们既不愿留在农村，也不愿像父母一样长期奔波、从事繁重劳动而居无定所。另据所引 2009 年《中国青年报》报道，受访的初中阶段留守孩子中，96% 认为读书有用。

这给 2005—2012 的“扩张型未来”加了一条非常重要的限定：

> 对一些孩子而言，扩张并不是“我要像父母一样去更远的地方挣钱”，而是“我要通过读书进入一种不必重复父母奔波方式的未来”。

不能把 2008 年的希望简单写成今天式悲观，也不能把增长年代写成人人都赞同流动和离乡。

这一时期的第一人称材料尤其需要去猎奇化。课题组自己已经指出，“留守儿童”标签被大量负面事件和极端案例塑造，81.7% 的受访儿童不喜欢这个称呼，79.0% 的外出父母也不希望孩子被这样称呼。

因此本仓使用“留守儿童”时，应首先把它当作一种 **家庭空间结构 / 制度分类**，而不是人格诊断。

## 四、2009—2012：Internet 可能先作为学校和村庄的共享终端进入家庭，而不是先进入每一间卧室

中国移动 2009 年企业社会责任报告称，截至 2009 年 9 月，“校讯通”覆盖 67,097 所各类学校，城镇中小学覆盖率 30.95%，总用户 2,623 万；其技术栈同时包括手机终端、校园信息机、个人电脑、短信、语音和 Internet。

来源：中国移动 2009 企业社会责任报告：
https://www.10086.cn/aboutus/res/2009csr_cn/09/090206.shtml

证据等级：**A，运营商正式材料；规模为运营商口径。**

2010 年重庆则计划在农村学校和主城区农民工公寓建设 2,000 个“亲情视频聊天室”和 5,000 部“亲情电话”，让两端无需自有电脑也可进行视频/语音联系。

来源：新华社 2010-09-22，搜狐存留：
https://news.sohu.com/20100922/n275206482.shtml

证据等级：**B，新华社同期报道；计划数量不自动等于最终全部建成数量。**

2012 年，教育部转载《光明日报》报道贵州修文县村级“绿色网吧”：附近三个村 60 多名留守儿童使用免费微机室，通过 QQ 视频与外出父母联系；报道同时明确说当地家庭计算机普及仍较弱。

来源：教育部，2012-06-25：
https://www.moe.gov.cn/jyb_xwfb/s5148/201206/t20120625_138217.html

证据等级：**B，同期媒体材料由教育部转载。**

这里出现 **shared-terminal parenting / 共享终端式育儿**：

```text
家庭没有 PC
≠ 家庭完全不能使用 Internet 视频
```

孩子可以去学校、村微机室、公益“网吧”；父母也可能在宿舍、公寓或网吧登陆 QQ。Internet 的“家庭采用”因此不能只看 household PC ownership。

更准确的 adoption ladder 是：

```text
服务存在
→ 学校/社区有终端
→ 家庭知道如何预约/使用
→ 两端都有可兼容账号与网络
→ 通话实际接通
→ 音视频质量可用
→ 双方在同一时间在线
→ 对话真的承载了需要表达的事情
```

## 五、2015—2019：智能手机和摄像头把“定期联系”推向持续可见，但身体照护依然高度本地化

2018 年，一名长期在北京务工的四川父亲在老家安装带语音和画面的摄像头，希望更频繁地看到两个孩子和照料他们的祖父母。这一做法当时就引起“陪伴还是监控”的争论。

来源：中国青年报 2018-04-17，人民网存留：
https://gongyi.people.com.cn/n1/2018/0417/c151132-29930199.html

证据等级：**B，同时代媒体个案与评论，不代表所有迁移家庭。**

它代表一种新的 **ambient remote presence / 环境式远程在场**：过去联系要专门打一次电话，后来父母可以更高频率地看到家庭空间发生什么。

但同一时代的行政摸排直接说明，真正的日常照护仍由本地人承担。2018 年 8 月全国农村留守儿童信息系统记录 697 万余名农村留守儿童，其中 96% 由祖父母或外祖父母照料，其余 4% 由其他亲友照料。

来源：新华社，2018-08-31：
https://www.xinhuanet.com/politics/2018-08/31/c_1123362533.htm

证据等级：**A/B，民政部数据的新华社同期报道。定义和统计口径必须与此前更宽的调查口径区分。**

因此有一个不能越过的状态缺口：

> **remote presence / local care labor gap / 远程在场—本地照护劳动缺口。**

摄像头可以让父亲知道孩子在写作业，却不能替祖母做饭、半夜量体温或带孩子去卫生院；手机可以让母亲下决定，却仍需要一个在当地的人完成动作。

2019 年“儿童主任 / 儿童督导员”制度又为这套家庭代理栈加上公共服务层：儿童主任定期走访并协助处理监护、复学、户籍等问题，儿童督导员维护台账、转介服务。

来源：人民日报，2019-06-15：
https://society.people.com.cn/n1/2019/0615/c1008-31153628.html

证据等级：**A/B，同期制度报道和政策执行材料。**

这不是国家“替代父母”，而是新增了 **institutional fallback / 制度兜底节点**：当家庭代理链失效时，多一个人知道“这户现在需要被看见”。

## 六、2020—2022：偶发型未来里，一个更明确的选择出现——不要让下一代重复自己的分居童年

这一轮没有找到足够高质量、可以代表 2020—2022 普通迁移家庭整体经验的第一人称数字育儿样本，因此不把疫情期间大量视频通话的直觉写成已经证明的普遍规律。

但 2022 年有一条同时代个案非常有价值：1995 年出生的占剑飞说，自己曾是留守儿童，因此成为父亲以后明确选择留在老家，“孩子在哪里，我就在哪里”，不希望孩子重复自己的经历。

来源：三湘都市报 / 华声在线，2022-01-26：
https://hunan.voc.com.cn/mobile/news/202201/23680192.html

证据等级：**B，同时代媒体人物个案。不能外推成一代人的统一选择。**

这构成 **intergenerational script correction / 代际人生脚本修正**：

上一代可能把“外出挣钱 → 改善孩子未来”视为必须承担的分离成本；下一代在经历过分离后，可能把“保持身体在场”本身提升为职业选择条件。

Internet 和手机让远程育儿更可执行，并不必然让家庭更愿意长期远程育儿。

## 七、2023—2026：防守型未来的一种具体形式，是把“陪伴半径”和“有人兜底”纳入工作选择

2025 年陕西汉阴县的同期材料记录，多年在新疆、河北务工的李笃琴通过当地“留守儿童家长返乡就业创业”项目进入本地玩具厂。她说从家到工厂只要四五分钟，可以同时挣钱和陪伴孩子。

来源：人民网陕西频道，2025-07-04：
https://sn.people.com.cn/n2/2025/0704/c347857-41281702.html

证据等级：**B，地方政策人物稿中的同期第一人称。不能据此推出返乡就业普遍优于外出就业。**

这里出现 **presence radius / 陪伴半径**：工作不再只比较工资，还比较“从岗位到孩子需要我时，我多久能到”。

这与此前仓库的“防守型未来”可以接上，但不能被写成“年轻人都不想出去”。更准确的是：

> 一些家庭开始把 **可返回性、日常陪伴和紧急照护的执行距离** 当成工作质量的一部分。

与此同时，制度也在试图让照护代理栈更可见。2026 年多部门要求对存在生活、就医、就学困难或监护缺失风险的流动儿童和留守儿童建立“一人一档”并动态更新，通过教育、公安、卫生健康、疾控、残联等数据比对，再由基层逐人核实。

来源：人民日报 / 人民网，2026-06-01：
https://society.people.com.cn/n1/2026/0601/c1008-40731105.html

证据等级：**A/B，正式政策的同期中央媒体报道。**

这产生 **care legibility / 照护可识别性**：家庭的迁移、学籍、健康和监护状态开始更容易被不同制度拼成一个可行动的风险对象。

但必须保留：

```text
一人一档
≠ 一个人的一生

每月联系 / 走访记录完成
≠ 孩子一定愿意表达真实需求

数据库知道“祖母是监护人”
≠ 数据库知道祖母今天是否有能力完成所有照护
```

这就是 **care-record shadow / 照护记录影子**：未来档案最容易保存的是电话号码、监护关系、走访次数、学籍和信息平台日志；最难保存的是沉默、争吵、凌晨发烧时谁起来、一次没有拨出的电话，以及为什么某个父亲最后决定辞掉远方工作回家。

## 八、四种未来时间感：远程家庭不是一条越来越“在线”的直线

### 2005—2012：扩张型未来

- 外出工作可以改善家庭现金收入并扩大孩子受教育期待；
- 电话、短信、家校平台和共享 Internet 终端让“离开以后仍保持家庭关系”越来越可执行；
- 但 2008 年儿童的同时代理想清楚显示，很多人想要的是**脱离父母那种长期奔波的劳动脚本**；
- 扩张因此同时包含“父母去更远处挣钱”和“孩子想通过教育以后不必这样奔波”。

### 2015—2019：拥堵型未来

- 智能手机、QQ/微信、摄像头把工作时间和家庭照护时间压到同一块屏幕；
- 外出的成年人可以在工作间隙询问作业、看监控、处理学校消息；
- 但祖父母和亲友仍承担绝大多数身体照护；
- “更容易联系”也可能意味着外出劳动者同时承担更连续的远程监督与家庭责任。

### 2020—2022：偶发型未来

- 本轮证据不足以给数字育儿本身作强结论；
- 但出现了明确的代际脚本修正个案：经历过留守童年的人，主动把“不让孩子再次留守”列为自己职业地理的约束。

### 2023—2026：防守型未来

- 防守不只是现金缓冲、稳定岗位或少背债；
- 对一些有孩子的人，它也可以是把工作搬回到四五分钟可到家的范围；
- 对仍然必须外出的人，则是确保祖父母、学校、社区和公共服务中至少有一个可靠的 fallback；
- “我出去以后家里仍然有人能处理事情”本身成为一种 **care buffer / 照护缓冲**。

## 九、海外对照：菲律宾说明“移动育儿”不是中国互联网的特例

Madianou 与 Miller 对菲律宾跨国家庭的研究提供了一个很好的前 Web 对照。2011 年关于书信和盒式录音带的研究指出，在廉价国际电话、手机和 Internet 于 1990 年代末大量出现以前，1970 年代起赴英国工作的菲律宾母亲长期主要依靠书信和录音带与家中孩子沟通。

来源：Madianou & Miller, “Crafting Love: Letters and Cassette Tapes in Transnational Filipino Family Communication,” 2011：
https://journals.sagepub.com/doi/10.5367/sear.2011.0043

同年另一篇关于 “mobile phone parenting” 的比较研究发现，移动电话让一些迁移母亲觉得自己可以部分重新构成母亲角色，但孩子对这种远程关系的评价更为复杂。

来源：Madianou & Miller, “Mobile phone parenting: Reconfiguring relationships between Filipina migrant mothers and their left-behind children,” 2011：
https://journals.sagepub.com/doi/10.1177/1461444810393903

证据等级：**A/B，同行评议研究，包含跨国迁移家庭的民族志与回顾性媒介史。早期书信/录音带经验本身包含成年后的回忆，应按回顾性部分使用。**

跨国共同机制是：

> **通信可以降低远距离育儿的信息延迟，却不能消除必须在孩子身边完成的身体照护。**

中国更具地方性的结构则包括：

- 国内城乡迁移而非国际移民为主；
- 大量祖父母隔代照护；
- 学校、电信运营商和地方公共服务较早成为通信中介；
- “校讯通”一类系统把学生到校、成绩和通知直接数据库化；
- 后来又出现全国性儿童信息台账与基层儿童主任体系。

因此不能把菲律宾经验直接套到中国，但它证明“远程母职 / 父职”与“代理照护”是现代大规模劳动力迁移的一类共同问题，而不是某个中文平台制造出来的现象。

## 十、重点矩阵

| 维度 | 本专题新增的生活路径 / 状态 |
|---|---|
| 教育 | 外出父母通过电话、SMS、家校平台远程追踪学习；儿童把教育想象为逃离父母迁移劳动脚本的路线 |
| 就业 | 父母在“远方更高收入”和“本地可陪伴”之间重新计算 |
| 住房 | 父母、儿童、祖父母可长期分居成多个 household node |
| 婚姻家庭 | 家庭成员不必同住才能维持同一预算与决策链，但同住与远程在场不可互换 |
| 迁移 | 外出不只依赖交通和通信，也依赖本地照护代理是否可靠 |
| 照护 | 祖父母、亲友、学校、儿童本人、儿童主任共同组成 care-proxy stack |
| 非正规劳动 | 流动就业的不稳定性会直接改变返乡频率、通信和照护安排 |
| 长期中断 | 一方父母可返乡、停止外出或换成本地工作以重新获得身体在场 |
| 证件与记录 | 监护关系、学籍、走访和风险状态越来越进入儿童信息台账 |
| 通信方式 | 信件 / 固话 / 短信 / 家校系统 / QQ 视频 / 智能手机 / 摄像头并非整齐替代，而是长期叠加 |
| 互联网平台 | Internet 可先通过学校/社区共享终端进入家庭，而不需要 household PC ownership |
| 信息获取 | “到校”“成绩”“通知”被远程可观察化 |
| 社交关系 | 联系频繁不等于孩子愿意倾诉；信息关系与情感关系要分开 |
| 未来预期 | 子女可能把“不再重复父母奔波”当作上学和职业想象；成年后又可能把“不让孩子留守”当成工作约束 |

| 平台消失与记忆保存 | 公共宣传页和统计容易留下，私信、短信、QQ 记录、家庭视频和未说出口的需求最容易消失 |

## 十一、反例与防止过度概括

1. **不能写“手机解决了留守”。** 2008—2009 年材料已经表明，电话可以成为主要联系工具，同时情感交流仍然不足。
2. **不能写“没有家用电脑就没有 Internet 家庭联系”。** 学校、村级“绿色网吧”和农民工公寓可以提供共享视频终端。
3. **不能写“祖父母照护天然失效”。** 96% 只说明隔代照护是主要现实结构，不说明每一户照护质量；应避免年龄主义和污名化。
4. **不能写“返乡一定比外出好”。** 工资、职业机会、医疗教育和住房都可能使外出仍是家庭理性选择。
5. **不能把极端伤害案例当作这个群体的代表。** 2008 年研究本身已经提醒标签化风险。
6. **不能把数据库中的“儿童已走访”“已联系”当作关系质量。** 事务完成和生活结果之间仍有明显缺口。

## 十二、仍不知道什么

- 1990 年代不同农村地区，外出父母实际使用邮政、村电话、公话的频率与价格分布仍需更细的一手材料；
- 2003—2010 家校系统的实际活跃率、退订率、手机运营商限制和家庭承担资费仍需城市级样本；
- 外出父母、祖父母、儿童本人对同一次电话究竟如何理解，现有数据很少能三方配对；
- 2020—2022 需要更多同时代第一人称数字育儿/远程照护材料，不能由后来的疫情叙事代替；
- 视频通话和摄像头是否减少父母返乡频率、或者反而增加返乡意愿，目前本轮没有因果证据；
- 返乡就业是暂时策略还是长期职业重排，需要纵向跟踪；
- 2026 “一人一档”的数据互联能否稳定触发实际服务，仍需后续执行材料。

## 十三、它改变了我们对“人怎么活着”的哪一点理解？

此前可以说：

> 通信让一个人离家以后仍能和家里保持关系。

这轮以后要说得更具体：

> **一个家庭可以被拆到几百上千公里之外继续运行，但前提是照护本身也被拆成很多不同的动作。**

父母在广东挣钱、祖母在村里做饭、老师在学校看见缺课、短信平台把刷卡事件发到手机、孩子自己照顾年老的外公、周末一家人在共享电脑前开一次 QQ 视频——这些动作可以共同构成“这个孩子仍然有人管”。

Internet 最先压缩的是“发生了什么”和“父母什么时候知道”之间的距离。它后来又让成绩、到校、视频和家庭空间越来越可远程观察。但一个孩子发烧时仍需要有人把手放到额头上，一个下午没回家时仍需要有人走出去找。

所以真正变化的不是“父母终于可以隔着屏幕完全养孩子”，而是：

> **身体不在场以后，家庭第一次能把一部分父母角色拆成信息、钱、决定和情感，通过通信网络远程继续执行；而剩下那部分不能穿过网络的照护，则必须重新分配给另一个真实在场的人。**

这也解释了为什么到了下一代，一些人会把“我离孩子只有四五分钟”重新当成一种值得为工作路线付费的未来。
