# 从纸质通讯录到“搜到老同学”：人的可寻址性、关系再激活与平台记忆（中国，1990—2026）

## 研究问题

这篇不写一部泛泛的“中国社交网络史”，而问一个更贴近日常生命历程的问题：

> **一个人离开学校、换城市、换工作、换电话号码以后，过去认识的人什么时候开始不再那么容易“彻底失联”？**

研究单位不是某个平台的用户量，而是一条具体的关系再连接路径：

```text
记得某个人
→ 还记得可用于定位他的线索
→ 在某个目录/平台中能检索这个线索
→ 找到一个候选身份
→ 判断“这真的是我认识的那个人”
→ 获得可用的联系入口
→ 对方仍能收到
→ 对方愿意回应
→ 关系重新进入现实生活
```

这条链上的任何一步都可能失败。

因此本文把一个新变量加入普通生活史：

### `person addressability / 人的可寻址性`

这里的“地址”不只指邮政地址。它包括：

- 家庭住址；
- 固定电话号码；
- 单位/学校地址；
- 纸质班级通讯录；
- 姓名 + 学校 + 年级 + 班级；
- 邮箱；
- QQ / IM 账号；
- 校友录账户；
- 实名 SNS 账户；
- 后来的手机号、微信号或其他平台身份。

一个人可以一直存在，却逐渐变得不可寻址；也可以多年没有联系，却因为一项旧的学校坐标重新变得可寻址。

本文与仓库既有“communication and the cost of living far away”“remote parenting”“matchmaking”等专题的分工是：**这里只研究已经存在过的社会关系，怎样在迁移、毕业、换号和平台迁移之后被重新定位、重新激活，以及这些关系记录后来又怎样被平台托管或丢失。**

Old-Web 对应技术研究见：

- `tmzncty/old-web-archaeology/docs/ALUMNI_DIRECTORY_CLASSMATE_SEARCH_CONTACT_IDENTITY_AND_PLATFORM_MEMORY_STATE_GAPS_1998_2015.md`

## 一、Internet 以前：知道一个人是谁，不等于还知道去哪里找他

### 1. 电话簿解决的是“当前用户可查询”，不是“过去关系可恢复”

2025 年厦门一位居民保存下来的《1990厦门电话号簿》是一个很好的实物边界证据：报道记录该电话簿收录 7600 多名市民号码，个人号码按姓氏笔画排列；同时，当事人回忆当时固定电话仍是稀缺家庭设施。[S1]

这是一份 **C 级后来回忆 + surviving artifact**，不能用它精确代表 1990 年全国电话普及率。但它揭示了前 Web 的一个基本结构：

```text
知道姓名
→ 查纸质电话簿
→ 这个家庭/个人必须本来就有可公开登记的电话
→ 号码仍然有效
→ 对方仍然住在那里
```

纸质电话簿把**当前电话用户**做成可查询对象，却不会自动保存：

- 某人小学读哪个班；
- 大学毕业后去了哪里；
- 是否换城市；
- 是否改了姓名；
- 是否换过单位；
- 过去的朋友通过什么旧身份能重新找到他。

因此可以先定义：

### `known-person / reachable-person gap / 已知其人—仍可联系缺口`

“我记得这个人”与“我还有一种能到达他的地址”是两件不同的事。

在 Internet 大众化以前，这个缺口通常由纸质通讯录、亲友转告、单位/学校、校友会、同学之间的人肉转接、邮政地址和固定电话共同弥补。

这里必须避免一个后见之明陷阱：**不能因为 1990s 已经存在电话、寻呼或少量计算机网络，就推断普通人已经拥有稳定、永久、可搜索的个人数字身份。**

## 二、1998—2005：学校和班级第一次变成普通人的“持久检索坐标”

### 2. 2001：网上校友录已经进入大学生和毕业生的日常 Internet 想象

2001 年 1 月《中华读书报》的一篇同期网络观察，把校友录直接称为“精神家园”。作者记录 ChinaRen 校友录的入口 `www.chinaren.com`，并称专门的“中国同学录”当时使用 `www.5460.com`；文章还注意到 5460 上同一学校常被重复创建很多次，首次访问者可能反而难以找到正确班级。[S2]

这是 **B 级同时代观察**。它支持的不是平台自报规模，而是两件更窄的事情：

1. 到 2001 年，“按学校/班级寻找同学”已经是可见的中文 Web 使用场景；
2. **目录数字化不等于目录已经干净。** 重复学校、重复班级和命名不一致会直接降低“找到旧人”的可执行性。

于是出现新的历史坐标：

### `persistent school-coordinate / 持久学校坐标`

一个住址会变，一个单位会变，一个电话会变，但：

> **“某学校 + 某年级 + 某班”可能在几十年后仍然是两个人共同记得的坐标。**

这正是网上校友录相对于普通电话号码簿更深的生活史变化。

---

### 3. 2004：从毕业十年、联系渐少到筹议同学聚会

2004 年新浪刊载的一封江汉石油学院毕业生集体求助信及湖南卫视《真情》的回复，保存了重聚倡议和寻人求助的过程：毕业十年后，同学平时疏于联系；随着网络普及，他们通过 QQ 和 `www.5460.net` 中国同学录重新增加联系，提出举办十周年聚会，并向节目求助寻找当年的军训教官。节目回复称已找到教官的联系方式，但这份材料没有报告聚会已经举行或教官实际出席。[S3]

这是一份 **B 级同期媒体承载的群体自述及节目回复**，不能推出“2004 年所有毕业生都能靠 Internet 找回同学”。它记录了网上联系增加、聚会倡议和借助电视节目寻找旧人的实践；下面是据此归纳的可能路径，不是来源逐步证实的完整成功链：

```text
毕业十年、平时疏于联系
→ 通过 QQ 和同学录增加联系
→ 筹议十周年线下聚会
→ 希望寻找当年的军训教官
→ 向电视节目求助
→ 节目回复称已找到教官联系方式
```

这里形成本文最重要的机制之一：

### `relationship reactivation option / 关系再激活期权`

一个关系不必持续高频维护，才有未来再次变成活关系的可能。

只要还有足够的身份线索和一个可用索引，十年前的弱连接就可能重新被激活。

这不是说友情因此“永不消失”。更准确地说：**关系的死亡开始不再只取决于今天有没有电话号码，还取决于过去是否留下了可搜索坐标。**

---

### 4. 2004 的操作材料：搜索出来的首先是“候选身份”，不是已经确认的人

PChome 2004 年的同学录教程记录，ChinaRen 当时的校友录入口为 `http://alumni.chinaren.com`；用户可以注册，或直接使用已有 Sohu / ChinaRen 邮箱账户，在“我的大学 / 我的中学 / 我的小学”中搜索或创建班级。[S4]

因此一次“找同学”至少应该拆成：

```text
school exists in directory
→ correct school selected
→ correct class exists
→ candidate user account appears
→ name/profile seems plausible
→ identity is actually the remembered person
→ contact channel works
```

这带来：

### `profile-found / current-person-confirmed gap / 找到资料—确认真人缺口`

同名同姓、重复班级、冒名加入、陈旧资料都可能让“搜索成功”与“找到本人”分离。

## 三、2004—2008：人的过去越来越容易被搜索，也因此越来越容易被冒用

### 5. 可寻址性带来重逢，也带来新的社会工程风险

2004 年武汉一则同期报道记录，一名毕业生接到自称“高中校友”的陌生人电话，对方能说出原高中相关信息，后来借钱行骗；报道还提到某同学录班级管理员提醒有人冒充同学姓名加入班级。[S5]

这类个案不能证明同学录普遍不安全，但它非常重要，因为它阻止我们把“旧关系可搜索”写成纯粹福利。

### `social-legibility / impersonation gap / 社会可识别—冒名风险`

当以下信息被组合到一起：

- 姓名；
- 母校；
- 年级/班级；
- 同学关系；
- 工作城市；
- 留言和共同记忆；

它们既能帮助真正的旧友确认身份，也能帮助陌生人伪造“我们认识”的可信感。

所以**人的可寻址性上升，和身份攻击面的扩大，是同一套基础设施的两面。**

---

### 6. 2005：网上班级不仅“找人”，还开始维持毕业后的持续共同空间

2005 年《解放日报》的一篇同期报道采访武汉大学 1996 级毕业生边志。毕业后他去了甘肃酒泉，报道说五年来网上同学录让他与分散全国的同学继续保持联系，他把网上班级描述为共同的“精神家园”。同一报道也记录，仍在校的一些班级把通知、活动、照片、技术讨论和出游组织搬入 ChinaRen 等网上班级。[S6]

这带来第二个变化：

### `relationship maintenance without co-presence / 无共同在场的关系维护`

过去“毕业”同时意味着：

- 不再共享教室；
- 不再共享宿舍；
- 不再每天经过同一食堂；
- 联系频率很容易突然下降。

网上班级则让“班级”从一个只有共同身体在场时才运行的组织，变成毕业后仍可持续存在的数字容器。

但这份报道也保存了反例：有人认为在校期间过度依赖网上班级，会削弱线下集体生活。[S6]

因此 Internet 不是简单“增加关系”。它也可能改变关系被维护的地点和节奏。

---

### 7. 2005：能搜到，不一定能联系；联系权限可以被身份绑定规则控制

搜狐 2005 年对 ChinaRen 校友录与搜 Q 3.0 整合的同期产品报道指出，Web 校友录的“找同学”当时要求手机绑定用户，而搜 Q 中的相关入口不再要求这一条件；产品还把“找同学 / 找班级”和即时通信放进同一界面。[S7]

因此又出现一个非常 old-Web 的状态缺口：

### `discoverability / communicability gap / 可发现—可通信缺口`

一个平台可以允许你：

- 看见某个名字；
- 看见某个班级；

但仍然因为手机绑定、登录状态、会员权限、隐私设置或失效账号，不能真正向那个人发送可达消息。

---

## 四、2008：从同学录到实名 SNS，“旧人”开始持续出现在日常信息流里

2008 年《中国青年报》/中新网的一篇同期校园采访，为这一变化留下了非常强的第一人称材料。[S8]

受访大学生“小美”说，她一天不上校内网就担心错过老同学出现；另一名受访者“文清”收到高中同学留言后，翻出高中毕业照，对照姓名在校内网搜索，全班 60 多人里半个多小时找到近 30 人。报道还记录，有已经工作的年轻人通过好友列表、日志和圈子继续联系旧友、重新理解过去认识的人，或者找师兄师姐咨询留学。

这不是人口调查，受访者明显属于已经积极使用校园 SNS 的城市高校青年。它真正支持的是一个新机制：

### `searchable social past / 可检索的社会过去`

以前回忆一段高中生活，主要依靠：

- 记忆；
- 毕业照；
- 通讯录；
- 偶尔联系的几个人。

现在，毕业照上的名字可以逐个变成搜索词；某个人又可以通过“好友的好友”暴露出另一个过去关系。

这进一步形成：

### `identity stitching / 身份拼接`

```text
旧照片里的脸
+ 记得的姓名
+ 学校/年级
+ 当前头像/资料
+ 共同好友
→ “大概就是这个人”
```

这是一种普通人以前很难拥有的、低成本的历史身份匹配能力。

## 五、2005–2012 扩张型未来：关系网络也成为一种“未来可选项”

在这一阶段，Internet 对未来感的作用不只表现为招聘、买房和创业机会增加。

对一个刚离校的年轻人，旧同学网络还可能提供：

- 哪个城市正在招人；
- 哪家公司怎样；
- 留学/考试经验；
- 临时住宿；
- 聚会与情感支持；
- 一个多年后仍可重新联系的人。

这不等于“校友网络人人都能变现”。不同学校、家庭背景、职业和地区拥有完全不同的关系资本。

更窄的结论是：

### `social optionality / 关系选择权`

**一个关系即使今天没有被使用，也可能因为仍然可寻址，而成为未来可以重新调用的选项。**

2004 年的聚会倡议与寻人求助、2005 年的异地毕业班和 2008 年的校内网搜索，分别记录了“筹议重聚并借助节目寻找联系入口”“持续班级”和“逐人找回”三种不同路径。[S3]、[S6]、[S8]

## 六、2015–2019 拥堵型未来：关系入口越来越多，旧平台反而开始从“日常场所”变成“记忆仓”

2018 年长春一名受访者欧阳女士回顾自己的校内网/人人网使用：她说最初校内网像“一本智能同学录”，能找到小学、中学乃至更早的旧同学；2009 年毕业后，随着平台用户和功能扩张，她觉得原本清楚的同学关系被游戏、广告和更多内容挤占，登录频率下降，2017 年再次登录时已感到陌生。[S9]

这是 **2018 年产生的 C 级回顾性个人自述**。它不能替代 2006–2010 年校内网／人人网的实时产品证据。另一平台 ChinaRen 的 2007 年产品稿则宣称，将校友录从较单一的班级关系产品扩展成包含社区、校园、博客、相册、动态等 Web 2.0 组件的“年轻人社区”；这可作同类变化的比较，不构成对上述校内／人人用户回忆的独立验证。该产品稿还提到 2006 年首页从 table 转向 DIV+CSS，并大量使用 AJAX。[S10]

这形成一个很重要的结构：

### `relation graph / attention-feed tension / 关系图—注意力流张力`

“我能不能找到旧同学”和“这个平台是不是我每天最愿意打开的地方”不是同一个问题。

一个平台可以仍然保存着关系图，却失去日常注意力。

到 2019 年，人人 App 再次上线时，“旧账号和密码还能登录”“账号密码找回”甚至成为新闻里的核心卖点；用户看到的已是“熟悉的陌生人”。[S11]

这说明平台的角色发生了变化：

```text
实时社交入口
→ 逐渐减少登录
→ 旧资料仍存在
→ 多年后重新找回账号
→ 平台成为一份可进入的个人过去
```

因此新增：

### `platform memory custody / 平台记忆托管`

当照片、日志、留言、班级关系和旧好友只存在于服务商数据库里，用户拥有的是访问能力，而不是完整的数据保管权。

## 七、2020–2022 偶发型未来：不能旅行时，旧关系可以短暂脱离“返乡/返校”才能重聚的日历

2020 年疫情期间，上海交大、清华等高校都留下了“云团聚 / 云校庆 / 云聚会”的同时代机构记录。上海交大生命科学技术学院 2020 年 4 月通过 Zoom 让 200 多名师生和海内外校友在线团聚；清华计算机系 1995 级系友则通过网络会议举行了毕业 20 周年“云聚会”。[S12]、[S13]

这些是 **A 级同时代机构记录**，但不是普通家庭或所有校友的第一人称样本。

它们支持的窄结论是：

### `reunion without trip / 无出行重聚`

在身体移动突然失效的时期，已经建立好的数字关系网络、群聊、邮箱和视频会议可以让“今年见同学”不必完全取消。

但这里不能进一步写成“疫情永久替代线下同学会”。

这一切仍要求：

- 能找到彼此；
- 有当前联系方式；
- 有设备和网络；
- 能处理时差；
- 愿意参与；
- 有人组织。

**视频会议解决的是同处一室，不解决关系本身是否还活着。**

本轮没有找到足够强、足够普通人的 2020–2022 中国第一人称“老同学重连”材料，因此这一段保持较低解释强度，不为了四阶段框架硬补情绪结论。

## 八、2023–2026 防守型未来：从“多找一些人”到“至少别把过去弄丢”

2024 年 12 月，人人网暂停服务。上海《青年报》采访的 85 后吴先生说，他已经很久不用人人网，但发现网站打不开时仍有明显失落；他回忆大学时期加入从幼儿园、小学、中学到大学的班级社区，并认为在手机和微信群尚未成为日常基础设施时，人人网曾让已经失联的老同学重新聚合。面对暂停服务，他最关心的是不要丢掉那本“青春纪念册”。[S14]

这是一份很强的 **B 级同时代个人材料**：采访发生在平台实际暂停服务的当下，而不是十年后怀旧。

同期其他报道也记录，贴吧等处有用户询问如何重新登录，只为把人人网里的照片保存到本地；平台则公开表示数据受到保护、服务正在升级，但没有给出确定重启时间。[S15]

因此“防守型未来”在关系这一格里出现一种此前矩阵没有的操作：

### `memory-preservation as defensive behavior / 记忆保存作为防守行为`

用户未必想恢复 2008 年的日常社交强度。

他可能只是想：

- 把照片下载回来；
- 保住日志；
- 确认旧账号还能进；
- 不让一整段青年时期随平台一起失效。

也就是：

> **过去的关系不再主要被当作“我要每天使用的网络”，而是被当作“最好不要丢失的历史资产”。**

这是一个很不同的时间方向。

2005 年的平台承诺是在帮人“继续联系”；2024 年一部分用户真正焦虑的是“能不能保住已经发生过的东西”。

## 九、一个重要反例：可搜索的社会过去不一定值得永久公开

平台记忆并不天然是正面资产。

2019 年人人网回归时，多篇同期采访都记录老用户对“黑历史”的复杂态度：有人愿意半夜重新登录翻旧内容，也有人希望与过去保持距离。[S11]

2018 年人人网资产出售时，也有人开始导出照片和日志后主动删除，担忧这些旧数据未来落入不确定的商业用途。[S9]

所以不能把“永久保存”写成无条件善：

### `memory availability / desired visibility gap / 记忆可得—愿意公开缺口`

一个人可能同时希望：

- 自己还能看到；
- 老朋友还能找到自己；
- 陌生人不能搜索；
- 平台不能随意商业化；
- 某些年轻时写过的东西可以彻底消失。

普通人的“社会过去”进入数据库以后，**被保存、被发现、被联系、被公开、被平台利用**必须分开讨论。

## 十、跨国比较：Internet 时代真正新的，不只是电子目录，而是“过去身份”也能成为检索键

### 1. 法国 Minitel：Web 以前，家庭已经可以远程查当前电话用户

法国《世界报》1986 年的同期报道记录，Minitel 最初的制度设计核心就是用电子电话簿替代纸质电话簿；到 1986 年 1 月已有 140 万台，其中约 110 万台在私人家庭，电子目录平均每月被使用若干次。[S16]

这是一份很强的 **A/B 级同期基础设施证据**。

它说明：

> **“在家通过数字终端查询另一个人的电话号码”并不是 WWW 发明的。**

但电话目录主要按**当前电信订户身份**组织。

### 2. Classmates.com：学校成为迁移以后仍能使用的历史坐标

美国 CBS 2003 年的同期报道介绍 Classmates.com（创办于 1995 年）如何让用户按学校重新联系旧友。报道中的个案甚至包括：家人因为婚后改姓、迁居、长期失联而无法直接找到某人，最后通过他的旧学校朋友重新建立联系。[S17]

这说明网上校友录相对于电子电话簿的新层次是：

### `historical-coordinate search / 历史坐标检索`

```text
不是“他现在住哪里？”
而是“我们以前共同在哪里？”
```

一个人现在的地址、职业、电话、婚姻状态都可以变化，但“1978 届某高中”“1996 级某大学”仍可能提供定位入口。

### 3. 2008 美国 Facebook：持续更新甚至可能削弱“十年一次重聚”的必要性

2008 年 AP/CBS 的同期报道采访一名准备跳过十周年同学会的美国毕业生，因为她已经通过 Facebook 看到了很多旧同学这些年的职业、婚姻和生活变化；报道把社交网站描述为传统 class reunion 的竞争者。[S18]

这提供一个很好的跨国共同机制：

### `episodic reunion → ambient updating / 周期性重聚 → 环境式更新`

过去可能十年见一次，集中交换“你现在怎么样”；持续社交网络则让这类更新被拆进每天的信息流。

中国的 ChinaRen、校内/人人有自己特殊的实名校园结构和平台史，但“学校身份成为检索键”“异地旧友持续可见”“传统聚会被数字更新部分替代”并不是中国独有。

## 十一、它改变了“普通人到底有多少种活法”的哪一点？

### 1. 离开一个地方不再必然意味着离开那群人

过去，一个人毕业、调动、迁移以后，关系维护很容易依赖少数核心朋友继续转接。

数字校友录以后，班级本身可以跟着人移动。

### 2. 弱关系可以进入“休眠而非死亡”状态

一个关系可以：

```text
多年不联系
→ 仍然可搜索
→ 某次同学会/求职/疾病/迁移/怀旧触发
→ 重新联系
```

所以真实生命历程里多了一种 **dormant-but-recoverable tie / 休眠但可恢复关系**。

### 3. “认识过谁”开始成为机器可读的个人历史

班级成员列表、好友关系、留言和相册把过去关系转换成数据库中的边和节点。

未来历史学家因此可能更容易看见：

- 谁在同一个班；
- 谁加入了哪个社区；
- 谁留下公开留言；

却仍然看不见：

- 两人为什么后来不说话；
- 谁只是注册了一次；
- 谁在线下仍很亲密但平台上从不互动；
- 谁因为换手机号永远找不回账号；
- 谁主动删除了过去。

### 4. 关系记忆越来越依赖第三方持续经营

一张纸质毕业照放在抽屉里，至少它的可读性不要求一家公司二十年后继续维护登录系统。

一个云端“青春纪念册”则要求：

```text
域名仍在
+ 数据库仍在
+ 账号映射仍在
+ 密码/手机号恢复仍在
+ 图片对象存储仍在
+ 权限系统仍在
+ 公司仍愿意提供访问
```

这使数字记忆同时更易复制、更易搜索，也更依赖复杂基础设施。

## 十二、重点矩阵更新

| 维度 | 本轮新增理解 |
|---|---|
| 教育 | 学校不只决定学历，也可能成为几十年后仍可使用的身份坐标 |
| 就业 | 旧同学/师兄师姐网络可以成为咨询、信息和弱关系入口，但不可假定人人获益 |
| 住房/迁移 | 换城市不必同时切断全部旧关系；“地址变了”与“人不可找”逐渐分离 |
| 婚姻家庭 | 旧关系重新激活可能改变伴侣、亲属和同学网络，但不应浪漫化“找回旧爱” |
| 照护 | 弱关系在疾病、事故等情况下可能被重新动员，海外 Classmates 个案提供极端但真实反例 |
| 非正规劳动 | 不作为本篇主轴，但关系网络可以承载机会；需要另证，不能从“好友”直接推“工作” |
| 长期中断 | 关系可进入多年休眠状态，之后再激活 |
| 证件与记录 | 姓名、学校、班级、手机号绑定共同成为数字身份拼接材料 |
| 通信方式 | 纸质电话簿/固定电话 → Web 校友录 + QQ/IM → 实名 SNS → 移动群聊/平台档案 |
| Internet 平台 | 平台从找人工具变成日常 SNS，再变成一部分用户的记忆仓 |
| 信息获取 | “过去认识的人现在怎样”第一次可以成为低成本、持续可查询信息 |
| 社交关系 | 新增 dormant-but-recoverable tie |
| 未来预期 | 扩张期更像“更多人可重新调用”；防守期增加“至少不要把过去丢掉” |
| 线上/线下身份 | profile-found 与 real-person-confirmed 必须分开 |
| 平台消失 | 关系图、照片和日志可能在平台失效时一起进入不可访问状态 |
| 记忆保存 | 用户可能很久不用服务，但仍要求历史内容持续可取回 |

## 十三、证据等级、反例与后见之明风险

### 已经较强地知道

- 1990 左右纸质电话簿仍以当前电话用户为基本可查询对象；
- 2001 年中文 Web 已有明确的 ChinaRen / 5460 校友录使用场景；
- 2004–2005 年，同学录已有帮助筹议十周年聚会、维持异地毕业班联系的记录；2004 年寻找教官联系方式另有电视节目介入；
- 2005 年“找同学”已经存在手机绑定等身份/权限门槛；
- 2008 年同期大学生确实会用毕业照姓名逐个在校内网搜索老同学；
- 同学关系公开化也带来冒名、诈骗和隐私风险；
- 2018–2019 一部分旧用户已把人人网从日常社交入口视为过去记录；
- 2020 年在无法正常返校的条件下，线上周年聚会确实成为替代路线；
- 2024 年人人网暂停服务时，有长期不活跃用户仍强烈要求保住照片、日志和青春记录。

### 不能据此推出

- “2001 年大学生普遍都能上网”；
- “校友录使所有失联同学都能重新找到”；
- “实名制就能确保账户是真人”；
- “好友列表代表真实亲密关系”；
- “网上重聚比线下重聚更好”；
- “人人网的数据一定已经丢失”；
- “用户怀旧就意味着愿意重新成为平台活跃用户”；
- “数字记录越永久越符合用户利益”。

### 选择偏差

成功重聚和“找回失联同学”非常容易被媒体报道。

更常见但更难留下历史证据的也许是：

- 搜不到；
- 找到同名但不确定；
- 发消息没人回；
- 手机号早已失效；
- 忘记密码；
- 对方根本不想重新联系；
- 班级页面创建后没人使用；
- 转去 QQ/微信后旧平台被抛弃；
- 内容后来主动删除。

这些失败路径必须持续主动寻找。

### 隐私边界

这是一个特别容易越界的研究对象。

旧同学录、校友页和个人主页可能暴露：

- 真实姓名；
- 家庭/工作电话；
- 邮箱；
- 住址；
- 班级；
- 家庭成员；
- 照片；
- 留言。

仓库应优先保存：

- URL pattern；
- 公开帮助页；
- 搜索/加入班级的事务结构；
- 同时代新闻和教程；
- 匿名化的状态模型；

而不是重新发布普通人的历史联系方式。

## 十四、尚未确定 / 下一步

1. 1998–2000 5460 / ChinaRen 最早页面的可验证 archive capture、charset、表格/frames 结构仍需实际打开确认；
2. 2001–2005 校友录的普通用户中，家庭 PC、网吧、校园机房各自占多大比例，目前没有足够证据；
3. “找回老同学”的失败率、响应率和关系真正恢复持续多久，缺乏可靠分母；
4. 从 ChinaRen / 5460 向 QQ 群、校内/人人，再向微信班群迁移时，旧关系图怎样被人工重建，需要更细的同代材料；
5. 2020–2022 还需要更普通家庭/普通班级的第一人称“线上重聚”材料，而不是只靠高校机构记录；
6. 2024 人人网暂停服务后，哪些数据最终恢复、哪些只能导出、哪些已经不可访问，需要以后按明确日期重新核验；
7. 平台删除、注销、纪念逝者账户以及死亡用户的关系图如何处理，可能构成下一条独立生命史问题。

## 十五、这改变了我们对“人怎么活着”的哪一点？

过去，毕业是一种很强的空间断裂：大家各自拿着一张写满电话号码和地址的通讯录离开，只要几个人搬家、换单位、换号，那条线就可能越来越细，最后只剩“我以前有个同学”。

网上校友录以后，普通人的过去第一次多出了一种长期坐标：**你现在住在哪里也许没人知道，但只要别人还记得你是哪一届、哪个班，就有可能重新找到你。**

这使一些关系从“断了就是断了”变成“可以休眠很多年以后再叫醒”。

可二十年以后，另一面也出现了：当那一整个班的照片、留言和关系图都被放进同一家公司的服务器，真正让人害怕的已经不只是“找不到老同学”，而是——**那个曾经证明我们认识过彼此的地方，会不会突然也打不开了。**
