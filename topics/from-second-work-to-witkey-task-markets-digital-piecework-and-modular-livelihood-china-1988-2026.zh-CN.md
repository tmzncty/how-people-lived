## 0. 为什么还需要这一条：它不是再写一遍“副业史”

仓库已经有两条很完整的副业/多重工作研究：一条研究一个人怎样同时执行主业、兼职、短工和家庭责任；另一条研究多份收入怎样叠加、怎样受 24 小时与照护约束。

本条目只补一个此前没有被单独拆开的窄机制：

> **当“工作”本身可以被切成一个可发布、可搜索、可竞标、可在线提交、可由平台结算的小型数字对象以后，普通人获得了什么新的生计组合方式，又承担了什么新的未付劳动、竞争和平台依赖？**

这里的关键不是“兼职”两个字，而是工作对象的变化：

```text
传统第二工作：
关系 / 报纸 / 单位 / 电话找到机会
→ 到某个地方
→ 在某个组织或客户现场工作
→ 现金/工资/合同结算

数字任务市场：
客户把需求编码成 task
→ 平台公开或定向分发
→ 陌生人发现 / 投标 / 交稿
→ 客户选择 / 验收
→ 平台释放赏金 / 形成评价
→ 下一次陌生客户再依据历史记录选择
```

这不是说所有威客工作都完全在线，也不是说传统兼职消失了。它只说明：**一部分可数字交付的劳动第一次可以把“找客户—交付—结算—积累声誉”的很大一段放在同一网络事务里完成。**

## 1. 新概念

### 1.1 task-market addressability / 任务市场可寻址化

一项原本需要客户靠熟人、单位、广告公司或本地人才寻找完成者的工作，被编码成公开任务：

- 标题；
- 需求说明；
- 预算/赏金；
- 截止时间；
- 作品/投标入口；
- 选择规则；
- 支付与评价。

于是陌生劳动者可以通过网页任务大厅找到它。

但必须固定：

> **task addressable ≠ task reachable by everyone**

设备、宽带、技能、软件、作品集、账号、支付方式、地区和平台规则仍然构成门槛。

### 1.2 digitally deliverable labor / 可数字交付劳动

2006 年 K68 创办人对媒体明确说，平台任务的前提是“数字化工作”，即能够通过互联网完成和交付。历史上这类工作首先集中于：

- LOGO / 平面设计；
- 网页和程序；
- 文案；
- 命名、策划；
- 翻译；
- 图片处理；
- 后来更广泛的咨询、数据、营销、在线服务。

这与校园 BBS 上“网上看到、线下去商场促销”的兼职是不同拓扑。

### 1.3 speculative labor / 投机性劳动

悬赏/比稿模式的特殊之处是：很多人可以先劳动，再由客户挑一个或少数结果。

```text
N 人投入设计/构思/提交
→ 1 或少数人中标
→ 其余人的时间可能没有工资
```

所以不能只计算“中标者做了几小时”。真正的劳动成本还包括大量未中标工时。

> **submission produced ≠ labor paid**

### 1.4 modular livelihood / 模块化生计

如果一个人的现金流不再只是一份长期工资，而可以由一串离散任务组成：

```text
主业工资
+ 偶尔 LOGO 单
+ 两次翻译
+ 一次程序外包
+ 周末线下兼职
```

那么“生计”获得模块化特征。

它不意味着这些模块可靠。恰恰相反，模块越碎，可能越需要：

- 持续找单；
- 维护账号和作品集；
- 处理客户沟通；
- 承担未中标劳动；
- 管理提现、平台费、税与保障；
- 自己吸收空窗期。

### 1.5 platform-held work history / 平台托管职业历史

在线任务平台不只匹配一次交易，还会把：

- 中标记录；
- 评价；
- 等级；
- 案例；
- 完成金额；
- 认证状态；

逐渐变成未来客户筛选你的依据。

这给没有传统雇主背书的人一种新的“可见履历”，但也把职业声誉的一部分交给平台保管。

### 1.6 income fallback / 收入回退路径

一条已经练熟、已有账号和客户记录的副业路线，在主业收入下降时可能比“从零重新找一份全职”启动更快。

这并不等于它能替代主业。更准确地说，它是一种：

> **income optionality / 收入可选性**。

## 2. 互联网前史：1980 年代已经有“第二职业”，网络没有发明多份工作

### 2.1 1988：广州人的“炒更”已经进入同期公共叙述

1988 年 5 月 8 日《人民日报》关于广州物价与收入的同期报道中，采访到的广州年轻人说“现在挣钱的路子多了”，文章随即明确写到广州业余“炒更”、从事第二职业的人不少。

来源：

- 《人民日报》1988-05-08，第2版，《在羊城街头很少听到对物价波动的非议——广州人物价承受力从何而来？》
- https://cn.govopendata.com/renminribao/1988/05/08/2/
- 等级：A（同期报纸数字化文本）

这条证据只能说明“第二职业/业余挣钱”当时是可理解的城市生活现象，不能据此估算广州参与比例。

### 2.2 前互联网匹配栈

既有仓库研究已经表明，1980s 的第二工作可以通过：

- 单位/技术市场；
- 熟人介绍；
- 报刊；
- 电话；
- 广播；
- 人才交流机构；
- 本人跨城出差/周末到场；

完成匹配。

因此历史分界不能写成：

> “有 Internet 以后，人第一次能够靠技能接零活。”

更准确的是：

> **Internet 把部分原本依赖本地关系、媒体和身体移动的客户发现过程，改造成可搜索、可并行竞标、可跨地域交付的数字任务市场。**

### 2.3 中国 Internet 时间线边界

本条目必须继续坚持：

- 1994 年以前：中国已有科研、邮件、专线等前互联网/联网实践，但不能写成普通家庭已经进入大众 Internet；
- 1994 年全功能国际 Internet 接入：是国家网络基础设施节点，不等于家庭可及；
- 1990s 后期—2000s：商业 Internet、网吧、家庭 PC、宽带逐步扩大；
- 2005–2006 威客平台：属于大众商业 Internet 已明显扩张以后的应用层，而不是中国“第一次有网络”。

这一分层非常重要，因为可数字交付的工作至少需要：

`网络可用 × 电脑可用 × 软件/技能 × 可上传文件 × 可联系客户 × 可收钱`。

## 3. 2005–2006：扩张型未来第一次把“工作本身”想象成可以全球流动

### 3.1 K68 的 Work2.0：非常典型的同期未来想象

2006 年 1 月 2 日《中国电子商务》经新浪保存的报道，记者直接观察 K68，并采访创办人康录发。

报道里的平台结构非常明确：

```text
客户预先付款
→ 发布数字化小任务
→ 多人竞标
→ 按规则确定中标者
→ 中标者获得客户出资的 80%
→ 平台获得 20%
```

记者在 2005 年 12 月 9 日看到的网站数字为：

- 发布任务：669 个；
- 悬赏金额：243042 元；
- 竞标成功：507 人次；
- 发放赏金：191657 元；
- 注册工作人员：20499 名。

来源：

- 《K68让工作全球化》，2006-01-02，《中国电子商务》/新浪
- https://tech.sina.com.cn/i/2006-01-02/1113809253.shtml
- 等级：B（同期专业媒体记者页面观察 + 创办人采访）

这些数字只代表记者看到的 K68 平台状态，不能当全国平台劳动人口。

### 3.2 “也许有一天再也没有上班这一说”

这篇报道最值钱的不只是平台数字，而是一段非常明确的 **2005/06 同时代未来想象**：创办人相信，互联网可能让人每天打开电脑，按特长为全球企业工作，而不再需要传统意义上的“上班”。

这必须标为：

- 同时代；
- 创办人/平台方的愿景；
- 不是普通劳动者已经实现的生活。

它非常适合放入 2005–2012 的“扩张型未来”：

> **未来首先被想象成距离和组织边界不断失效——技能可以越过城市，工作可以被拆成任务，人可以不先加入一个单位再开始工作。**

### 3.3 平台自己也依赖前平台历史：K68 从 BBS 发展而来

同一报道说，康录发先用业余时间开 BBS 聚人，后在 2004 年运行 K68；“76号任务”甚至用平台自己的任务机制寻找数据库开发者，最后把中标者发展成合作者。

这个细节说明早期任务市场并不是凭空长出来：

`论坛社群 → 任务帖 → 支付/规则 → 专门交易平台`

它也正是 `old-web-archaeology` 值得单独保存的中文旧网平台形态转变。

## 4. 2006：扩张叙事里很快出现“很多人劳动，只有少数人拿到钱”

### 4.1 一个任务可以吸收大量未支付方案

2006 年 10 月《中国企业家》记录 K68 上一个婚宴小游戏任务：12 天里有 199 人参与，提供 140 种方案，客户最后从中选择满意结果。

来源：

- 《威客网站当道：创意产品网上换现金》，2006-10-11，《中国企业家》/新浪
- https://tech.sina.com.cn/i/2006-10-11/12131178677.shtml
- 等级：B（同期媒体观察）

这让“任务平台效率”必须从两侧看：

对客户：

`一个需求 → 很多陌生人并行提供方案 → 低搜索成本`

对劳动者：

`很多人投入时间 → 少数结果被选 → 大量投入没有直接支付`

这就是 **speculative labor**。

### 4.2 2006 年的“威客王”也说不能靠它维持生活

《中国新闻周刊》2006 年同期报道给出一个非常重要的反例。报道当时记录 K68 有 44226 名注册用户，其中仅 1505 人/次获得收入，累计收入 531199 元；报道据此强调竞争非常激烈。

更重要的是，被称为“威客王”的陈怡说，平台确实扩大了客户来源，但即使对她这样已经有名气的人，靠平台悬赏维持生活也不现实；后来一些客户会绕过公开悬赏，私下直接找她。

来源：

- 《中国新闻周刊》，2006-10-27，《威客，能赚钱的网络新“游戏”》
- https://www.chinanews.com.cn/other/news/2006/10-27/810922.shtml
- 等级：B（同期媒体采访；平台数字仍按报道口径）

因此必须固定：

> **registered worker ≠ earning worker**
>
> **one winning submission ≠ viable livelihood**
>
> **visible winner ≠ typical participant**

### 4.3 平台可以成为客户关系的“引导层”

2006 年 9 月《都市快报》报道，杭州广告公司设计人员赖明生用业余时间参加十几个悬赏任务，一年多赚一万多元，后来有客户开始直接找他做设计。

来源：

- 《最近流行新职业威客 每天靠上网揭榜赚钱》，2006-09-08，《都市快报》/搜狐
- https://news.sohu.com/20060908/n245227584.shtml
- 等级：B（同期个人材料，明显属于成功者样本）

这产生一个新路径：

```text
陌生平台任务
→ 一次中标
→ 客户看到能力
→ 重复合作
→ 平台外直接客户
```

也就是说，平台的价值有时不只是这一单的赏金，而是 **client bootstrap / 客户启动**。

但这种路径本身也会产生平台治理问题：平台通常不希望交易被绕到站外，因为这会削弱佣金和监管能力。

## 5. 2009：扩张型未来开始被更普通的“主业 + 网上接单”吸收

2009 年 9 月《海峡导报》保存了两名厦门设计人员的同期经历。

25 岁的张金在茶叶包装公司做设计，2008 年注册威客网站后第一次尝试 400 元包装设计就被采用；报道时他称自己投稿 6 次都被采纳，累计得到 7000 多元。

36 岁的林中在传媒公司做设计，2008 年注册猪八戒网，投过两次稿，其中一份北京企业 4000 多元 LOGO 任务中标，得到 3250 元。他明确说这份作品花了自己一周业余时间。

来源：

- 《厦门数万“威客”网上“淘金”》，2009-09-18，《海峡导报》/新浪
- https://news.sina.cn/sa/2009-09-18/detail-ikkntian2022744.d.html
- 等级：B（同期采访）

同一报道也明确提醒“注册的多、赚钱的少”，并引述 K68 管理人员称平台注册很多，但中标者占很小部分；多名受访者也说单个任务通常有很多竞争者。

这组材料特别适合纠正两个误读：

1. **网上接单并不必然替代主业。** 两名主要个案当时都有正式设计工作；
2. **可远程交付不等于时间没有成本。** 林中的一笔中标仍吃掉一周业余劳动。

所以 2005–2012 的扩张型未来更准确的现实版本是：

> **主业还在，但工作边界变薄了；晚上和周末可以把同一技能卖给本单位之外的陌生客户。**

## 6. 2012：平台上的“中标记录”开始向可积累职业资产发展

一品威客今天仍保留一篇内部日期为 2012-11-16 的服务商访谈。受访者“怪猫设计”自称 28 岁、主业为地产设计师，在平台接设计任务；他说 2011 年开始参加威客，第一次中标只有 100 元，后来悬赏任务最高 2000 元，并且曾有客户在一次悬赏合作后直接再发起“直接雇佣”。

来源：

- 一品威客，《努力做好作品回报顾客》，页面内部日期 2012-11-16
- https://m.epwk.com/weike/niu_10576.html
- 等级：A/B 边界材料：平台原生存续页面 + 平台筛选的成功者访谈；可用于证明平台字段和个体路径，不可估计典型收益。

这里发生的是：

`一次任务结果 → 可展示案例/等级 → 下一次陌生客户的信任输入 → 直接雇佣`

因此工作历史不再只存在于传统简历或单位档案里。

但要保留一个关键风险：

> **platform-held work history is portable only as long as the platform/account/history remains accessible.**

如果平台关闭、账号封禁、评分规则变化，劳动者过去几年积累的可见信誉也可能一起贬值。

## 7. 2015–2019：拥堵型未来——任务越来越多样，竞争、收费和无薪工时也变得可测量

### 7.1 2019 不是“人人自由职业”，而是多平台、多任务结构

国际劳工组织 2021 年工作论文研究中国在线数字劳工平台，调查包括时间财富、一品威客、猪八戒等平台。它的调查招募本身来自平台问卷相关区域，因此**不是全国劳动者代表性样本**；作者也明确承认这种抽样限制。

但对于平台内部机制，它提供了非常高价值的工人层数据。

调查中：

- 约三分之一受访者只在一个平台工作；
- 30% 在两个平台；
- 18.9% 在三个平台；
- 常见工作包括设计/图片处理、IT、编辑写作、问卷、微任务等；
- 任务分配包含计件、报名等待甄选、直接竞标、短期雇佣等多种模式。

来源：

- ILO Working Paper 24, *Online digital labour platforms in China: Working conditions, policy issues and prospects*, 2021；中文页面
- https://webapps.ilo.org/static/chinese/intserv/working-papers/wp024/index.html
- 等级：A/B（机构研究；平台工人调查，不具人口代表性）

这说明“威客”到 2019 已经不能只理解成早期一个 LOGO 悬赏网站，而应理解成多种 **task-allocation regimes** 的集合。

### 7.2 把无薪劳动算进去，工资评价会发生变化

ILO 研究特别比较了只算带薪工作时间与把无薪工作时间一起算的时薪。样本中把无薪时间计入后，中位时薪明显降低；作者据此强调寻找、准备、未被采用等时间会实质改变平台工作的经济评价。

这正好验证本条目的核心：

> **contest/task market 的真正成本不能只看中标以后那几个小时。**

无薪时间可能包括：

- 找任务；
- 读需求；
- 写投标；
- 先做方案；
- 修改；
- 被拒；
- 与客户争议；
- 等待结果；
- 提现与账号维护。

### 7.3 “灵活”与“随时在线”可以同时出现

ILO 样本中，部分工人因为平台工作可利用其他活动之间的空闲时间而重视其灵活性；但也有超过十分之一的受访者称，为维护客户关系经常需要在普通工作时间之外服务。

所以：

> **schedule flexibility ≠ low time pressure**

平台允许你在晚上做，不代表晚上不会变成新的工作时间。

### 7.4 2019 的斜杠生活：不仅为钱，也为保持多种人生角色

2019 年半月谈/新华网报道中的薛珍妮明确说自己同时承担：

- 母亲；
- 每周工作 3 天的 HR；
- 兼职旅行领队。

她把主业与兼职时间大致分开，兼职更多连接兴趣和“诗和远方”。报道同时指出，有些公司员工手册并不鼓励兼职，涉及时间冲突与信息泄露。

来源：

- 《斜杠青年：“无边界”更精彩？》，2019-06-27，半月谈/新华网
- https://www.xinhuanet.com/politics/2019-06/27/c_1124678263.htm
- 等级：B（同期个人采访；“8000万”等二手估算不作为人口结论）

所以 2015–2019 的拥堵型未来并不是简单“机会变少”。更像是：

> **一个人可以经营多条收入和身份路线，但每条路线都在争夺同一套时间、注意力、平台信誉和雇主容忍度。**

## 8. 2020–2022：偶发型未来——副业从“可能性”突然变成风险缓冲

### 8.1 2020：“主业 + 副业 = 万无一失”的语言出现

2020 年 4 月《中国青年报》报道疫情期间的“副业慌”。受访者朋友圈里有人直接宣传“副业刚需，主业+副业=万无一失”；另一位少儿英语培训教师因机构数月未发工资，担心房贷，开始寻找兼职。

来源：

- 《警惕一夜暴富心理 疫情让不少年轻人闹起“副业慌”》，2020-04-24，中国青年报/中新网
- https://www.chinanews.com/sh/2020/04-24/9166208.shtml
- 等级：B（同期采访）

这不是证明“2020 年所有年轻人都需要副业”，而是保存了一个非常明确的时代语义变化：

2006 平台方讲的是：

> “也许以后不用上班。”

2020 一部分普通人讲的是：

> “如果主业出事，我最好还有一条线。”

这就是从**扩张 optionality** 向**冲击 fallback** 的权重变化。

### 8.2 回退路径也可能制造新的风险

同一报道里的大二学生沈灿，因为疫情期间空余时间多，支付 398 元加入线上兼职公司。她一开始就担心是否被骗；随后为了做网拍等兼职，工作逐渐侵入网课时间。

这条材料非常适合作为反例：

> **searching for a fallback can itself create financial, fraud, and time risk.**

副业不是天然保险。它有时反而需要先交钱、投入时间、承担平台和中介不透明风险。

### 8.3 偶发型未来的真正机制：已有技能路线比从零再就业启动快

对一个已经有：

- 设计软件；
- 作品集；
- 账号；
- 评价；
- 客户；

的人来说，主业短暂停摆时，线上接单可以在不完成完整招聘/onboarding 的情况下启动一部分现金流。

因此可以把这种能力叫：

**livelihood warm standby / 生计热备**。

它不同于储蓄：储蓄是过去收入留下的钱；热备是过去积累的技能、账号和客户关系，能否快速重新变现。

## 9. 2023–2026：防守型未来——“多一条腿”从潮流身份转向低成本试错与风险分散

### 9.1 2023：副业明确被受访者说成“低成本试错”

2023 年《中国青年报》采访中，王洛宇把副业描述为一种成本较低的试错与体验方式：主业上升期可以通过相关副业理解另一侧业务，如果主业只求稳定，副业又可以用来开拓更多可能性。报道中的研究者也用“两条腿走路”为不确定行业提供多一重保障来概括部分动机。

来源：

- 《搞副业的年轻人，除了“搞钱”另有所图》，2023-03-24，中国青年报/中新网
- https://www.chinanews.com.cn/sh/2023/03-24/9977686.shtml
- 等级：B（同期个人采访 + 专家解释；文中 53.9% 等招聘平台调查不作为全国比例）

这给 2023–2026 的防守型未来补出一个很具体的行为逻辑：

> **不要先辞掉主业再验证另一种人生；先用副业把那条路线跑一小段。**

### 9.2 防守并不等于只有焦虑

同一报道中，徐顺在旅游业不景气时把民宿长期出租、转做陪诊；旅游恢复以后仍保留陪诊，因为它带来另一种价值感。

所以“冲击中的第二路线”可能发生：

`临时替代 → 技能/关系积累 → 主业恢复 → 第二路线仍保留`

这说明人生不一定在危机结束后自动回到原先唯一轨道。

### 9.3 2024：收入组合也可能吞掉恢复时间

2024 年《中国青年报》报道中，29 岁的周建晨白天上班，晚上 8 点后经营乐器教学短视频副业，通常到 10 点多，有时做到凌晨 3 点；周末主业也可能加班。

来源：

- 《闲暇时间闲不下来 77.8%受访青年感觉自己忙》，2024-12-12，中国青年报/人民网
- https://yn.people.com.cn/n2/2024/1212/c378440-41072967.html
- 等级：B（同期个人采访；问卷比例只描述调查样本）

这让“多一条收入线更安全”必须加一个反向变量：

**recovery-time erosion / 恢复时间侵蚀**。

一个人可以获得收入冗余，同时失去睡眠、家庭时间和真正空白的晚上。

因此防守型未来的核心不是“副业越多越安全”，而是：

> **how much redundancy can a person carry without exhausting the body that produces all those income streams?**

## 10. 海外对照：MTurk / Elance 说明这不是中国“威客文化”独有

### 10.1 2005：Mechanical Turk 同期就把劳动切成 HIT

Amazon 2005 年 12 月的官方宣传已经明确写到：企业提交 HIT，Worker 完成，获批准的 HIT 才获得支付。

来源：

- AWS, “Amazon Mechanical Turk Promotion: Build Now, Earn $1,000”, 2005-12-13
- https://aws.amazon.com/about-aws/whats-new/2005/12/13/amazon-mechanical-turk-promotion-build-now-earn-1000/
- 等级：A（平台官方同期材料）

这与 K68 的具体制度不同，但共同点很明显：

`work → discrete web object → remote worker → submit → approve/reject → pay`

因此“把工作切成可被远程陌生人领取的小任务”属于互联网时代的跨国机制。

### 10.2 2010：美国 MTurk 也主要不是“全职替代”

2010 年一项 MTurk 研究中，受访美国 Workers 只有 13.8% 把 MTurk 当主要收入来源，61.4% 表示额外挣钱是重要动机；多数人的收入流较低，常低于每周 20 美元。

来源：

- Paolacci, Chandler & Ipeirotis, “Running experiments on Amazon Mechanical Turk”, *Judgment and Decision Making*, 2010
- https://sjdm.org/~baron/journal/10/10630a/jdm10630a.html
- 等级：A/B（学术调查；代表其样本，不外推美国全部劳动力）

这和 2006 中国“威客王也难以靠平台维持生活”形成很强对照：

> **online labor market can be real while still functioning mainly as supplementary income for many participants.**

### 10.3 Elance：平台历史本身成为职业信号

2014 年 American Sociological Review 对 Elance 的研究指出，平台把自由职业者过去的项目历史标准化展示，雇主据此评价候选人；论文引用的 2012 Elance 调查中，不少 freelancer 同时还有全职或兼职工作。

来源：

- Ming D. Leung, “Dilettante or Renaissance Person? How the Order of Job Experiences Affects Hiring in an External Labor Market”, *American Sociological Review*, 2014
- https://journals.sagepub.com/doi/abs/10.1177/0003122413518638
- 等级：A（学术研究；其中平台调查须保留平台样本偏差）

这验证了 **platform-held career history** 是全球在线劳动力市场的共同机制，而不是中国“威客”等级系统的独有现象。

## 11. 中国特有、互联网时代共同、现代劳动共同：不要混成一个解释

### 11.1 更偏中国具体历史的部分

- “威客”这一命名和 2005–2010 的中文平台话语；
- K68、猪八戒、一品威客等平台规则谱系；
- 2000s 中国宽带/网吧/家庭 PC 扩张的具体速度；
- 单位、本职、兼职限制与中国劳动制度衔接；
- 国内平台主要服务国内客户时的价格结构；
- 后来灵活就业与中国社保制度的接口。

### 11.2 互联网时代跨国共同机制

- 陌生客户与陌生劳动者的远程匹配；
- 工作被切成网页对象；
- 竞标/比稿造成的未支付竞争劳动；
- 平台托管支付和评价；
- 平台声誉作为未来工作入口；
- 多平台工作；
- 任务市场全球/跨地域扩展。

### 11.3 更古老的现代劳动共同机制

- 一个人同时做多份工作；
- 主业之外增加收入；
- 用副业测试职业；
- 在危机中找第二现金流；
- 照护与工作时间冲突；
- 无正式雇佣关系时的保障缺口。

不能把所有这些都归因于“互联网改变了人性”或某个中国平台。

## 12. 社会保障与劳动关系：模块化收入不等于模块化保障

任务市场最容易产生一个制度错位：

```text
收入可以一单一单获得
但养老、医疗、工伤、失业、带薪休假、培训、职业晋升
并不会自动一单一单附着
```

ILO 对中国在线平台劳动的研究明确把经济保障和社会保障列为问题：一部分受访者只做平台工作，另有自由职业者；收入不可靠、拒付、账户关闭、平台规则等都可能影响保障。

特别值得注意的是，ILO 调查中相当一部分受访者经历过“完成工作并提交却没有得到报酬”的情况。由于这是平台问卷样本，不能推全国比例；但它足以证明：

> **digital delivery ≠ payment certainty**。

因此“自由职业/威客给人更多自由”必须和：

- 结算失败；
- 账户封禁；
- 申诉权；
- 社保；
- 工伤；
- 税；
- 客户拒付；

一起研究。

## 13. 历史可见性：平台特别容易保存赢家，抹掉未中标劳动

这一专题给 life-history 方法增加一个很重要的保存偏差：

### winner-survival bias / 中标者保存偏差

公开 Web 更容易留下：

- “优秀威客”；
- 中标案例；
- 高额赏金；
- 成功创业；
- 平台 GMV；
- 榜单；
- 代表作品。

更难留下：

- 看了任务但没投；
- 花两晚做方案后落选；
- 修改三次仍未采用；
- 客户拒付；
- 第一次失败后再也没回来；
- 为了抢任务刷新页面的时间；
- 主业已经很累却继续熬夜接单；
- 没有作品集、从未被算法/客户看见的人。

因此：

> **archive-visible platform labor systematically over-represents completed transactions and visible winners.**

普通人的平台劳动史必须主动寻找失败、未中标和退出。

## 14. 重点矩阵更新

| 维度 | 本轮新增机制 |
|---|---|
| 教育 | 学生可用数字任务做职业探针，但技能/设备门槛强 |
| 就业 | job 可以被拆成 task；正式雇主不再是唯一工作入口 |
| 住房 | 远程数字任务降低部分工作的迁移必要性，但收入不稳会反过来影响住房承诺能力 |
| 婚姻家庭 | 家庭/照护可与线上任务错时组合，但夜间劳动侵蚀照护和恢复 |
| 迁移 | 数字任务弱化“客户在哪我就必须搬去哪”，但不会消除所有地域/制度限制 |
| 照护 | 在家工作可给少数照护者入口；不能浪漫化为自动解决照护冲突 |
| 非正规劳动 | 平台任务是重要新形态；雇佣关系、社保、拒付仍可能模糊 |
| 长期中断 | 已有账号/技能/客户可形成重返收入的 warm standby |
| 证件与记录 | 实名、账号、支付、平台历史逐渐成为工作准入与声誉记录 |
| 通信方式 | 任务页、私信、QQ/电话、站内信共同组成客户沟通栈 |
| 互联网平台 | 从 BBS 任务帖演化为托管支付、评价、竞标的完整交易层 |
| 信息获取 | “找工作”不再只有职位招聘，还包括持续扫描小任务 |
| 社交关系 | 一次中标可转成长期客户；平台又试图阻止站外交易 |
| 未来预期 | 2006“无需上班”的扩张想象 → 2020“副业刚需” → 2023“低成本试错/两条腿” |
| 线上/线下身份 | 平台等级、案例、评价成为并行职业身份 |
| 平台消失与记忆保存 | 平台关闭/账号丢失可能带走工作历史和客户信誉 |

## 15. 证据等级、反例与后见之明风险

### 较强证据

- A：1988 同期报纸明确把“炒更/第二职业”写成可理解现象；
- B：2006 K68 同期记者页面观察保存了任务、赏金、预付、竞标、平台抽成与创办人未来想象；
- B：2006 中国新闻周刊同时保留“赚钱很难”的平台内反证；
- B：2009 两名有主业设计师的实际接单工时/收入自述；
- A/B：2012 一品威客原生存续访谈证明悬赏 → 直接雇佣的客户延续路径；
- A/B：ILO 中国平台工人研究提供多平台、无薪时间、分配模式和支付风险证据；
- B：2019、2020、2023、2024 的同期个人材料保存多重工作、冲击 fallback、低成本试错和恢复时间侵蚀；
- A（海外）：2005 MTurk 官方材料；2010 MTurk 学术调查；2014 Elance 学术研究。

### 不能据此推出

- 不能把威客网站注册人数当真实活跃劳动人口；
- 不能把中标人次当独立劳动者人数；
- 不能把平台 GMV 当工人收入；
- 不能把成功案例当中位数生活；
- 不能把 2006 创办人愿景写成 2006 普通人已经“不用上班”；
- 不能把能远程交付写成“不需要城市/住房/照护”；
- 不能把一笔副业收入写成稳定职业；
- 不能把 ILO 平台问卷样本外推中国全部劳动者；
- 不能把 2020–2026 的副业全部解释成焦虑和贫困；
- 不能把 2019“斜杠”宣传语言倒投给 1980s 第二职业。

### 后见之明风险

今天熟悉 Upwork、自由职业、众包以后，很容易把 2006 的 K68 写成“早期 Upwork”。这是危险的。

2006 K68 的悬赏/比稿、20% 抽成、100% 预付且特定阶段不退款、BBS 社群来源，都属于其具体历史结构；后来平台的雇佣、计件、直接竞标、店铺化、会员化并不是一开始就存在。

同样不能因为今天“副业安全感”常见，就说 2006 用户已经以“防守型未来”理解威客。当时强烈可见的语言反而是全球化、自由、把兴趣技能变现、可能不再上班。

## 16. 仍未知

## 17. 它改变了我们对“人怎么活着”的哪一点理解

以前我们容易把“工作”想成一个很大的容器：一个单位、一栋楼、一份合同、一张工牌、一条长期履历。第二职业当然早就存在，但它仍常常需要熟人、电话、广播、报纸和身体移动才能成立。

数字任务市场改变的是工作可以被切小。

一个 LOGO、一段程序、一篇文案、一次翻译，可以先变成网页上的一个对象。远处的陌生人不用先搬到客户所在城市，也不用先成为那家公司的正式员工，就能试着把自己的几个晚上卖出去。

这确实增加了活法：

```text
我可以只做主业
我可以主业 + 偶尔接单
我可以用接单试另一个职业
我可以暂时靠任务度过主业中断
我可以把平台客户慢慢变成自己的客户
我也可以把一串任务最终长成工作室
```

但它同时制造了一种以前不那么显眼的生活：

> **我今天工作了，却不一定有人为今天付钱。**

因为在比稿、竞标和持续找单里，失败本身也消耗劳动。平台把客户寻找成本分散给了很多竞争者，把职业历史变成账号里的声誉，又把支付、排名和下一次机会系在平台规则上。

所以“普通人有更多种活法”并不自动等于“普通人更自由”。更准确的变化是：

> **一份人生可以被拆成更多小块重新组合了。**

2006 年，人们容易把这种可组合性想成“以后也许不用上班”；2020 年，另一批人开始把它理解成“主业之外要有备份”；到 2023–2026，一些人更明确把副业当作低成本试错和风险分散。

同一种技术能力，从扩张未来的自由想象，逐渐变成拥堵生活里的第二班，再变成不确定时代里的一条热备线路。真正值得继续追踪的，不是“副业火不火”，而是：**一个普通人究竟能同时维护几条劳动路线，而不会让所有路线一起把自己的时间、身体和保障吃完。**
