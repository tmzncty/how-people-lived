# 从“喊楼”到送考：中高考如何被做成一套集体仪式，中国，2010—2026

## 范围

**地点：** 中国大陆，重点使用可核验的学校、政府、主流媒体与教育媒体材料  
**时间：** 2010—2026  
**人口：** 初三、高三毕业年级及其低年级同学、教师、家长和学校组织者  
**问题：** 为什么原本只是一场考试，会在校园里形成“最后一次晚自习—喊楼—合唱—送考—熄灯—上车”的连续仪式？歌曲在这些仪式里究竟做什么？

这篇笔记不是“高考仪式盘点”，也不把所有学校写成同一种校园文化。

它试图重建一条更窄、也更可验证的历史链：

> **学生自发的毕业/喊楼表达，怎样在 2010 年代以后逐步进入中学校园，并被不同学校改造成可重复、可管理、可拍摄、可传承的考试季仪式。**

歌曲在其中不只是背景音乐。它有时是暗号，有时是对答，有时是学校身份的声音，有时是为了让学生暂时停止讨论考试本身。

---

## 核心结论

目前材料支持六个初步判断。

### 1. “喊楼”不应被写成天然属于高考的古老传统

2010 年中新网报道大学毕业生“喊楼”时，已经把它描述成高校毕业季的常见集体表达：宿舍楼之间喊话、泼水、送花、拍 DV，并有人追忆更早年代的类似做法。

来源：

- 中国新闻网，2010-05-22，《离校在即大学毕业生上演集体“喊楼”秀》：https://www.chinanews.com/edu/edu-dxxy/news/2010/05-22/2298514.shtml

到 2012 年，《广州日报》报道广州部分中学高考前“喊楼”时，直接写道：这种做法“起源于大学生毕业时的‘喊楼’，现在已延伸到广州的一些中学校园”。

来源：

- 《广州日报》，2012-06-07（新浪教育转载），《广州高考：师弟师妹“喊楼”送祝福》：https://edu.sina.com.cn/gaokao/2012-06-07/0952341435.shtml

这两条材料不能证明全国所有中学“喊楼”都来自高校，也不能确定唯一发源地。

但它们至少提醒我们：

> **中学高考“喊楼”很可能包含一种仪式迁移过程，而不是自古以来就固定存在的高考习俗。**

更稳妥的研究方法，是逐校记录“这一所学校什么时候开始”“谁先组织”“后来是否制度化”。

### 2. 早期中学“喊楼”常保留明显的学生自发性

2012 年福州一中的报道非常有价值，因为它把场景、时间、参与者和歌曲都保留下来。

当时正值高三“最后一个晚自习”，约 600 名高一、高二学生在教学楼之间为高三喊楼。高三学生唱校歌和《最炫民族风》，现场又合唱《朋友》。活动后，还有低年级学生给高三发短信，确认“你有没有听到我喊”。

来源：

- 中国网络电视台 / 中国经济网，2012-06-05，《福州一中600多学生“喊楼”为高三学长学姐加油》：https://news.cntv.cn/20120605/110849.shtml

这不是一场单向“学校给学生打气”的活动。

它更像是两个年级之间的对答：

```text
低年级喊话
→ 高三回应
→ 双方合唱
→ 晚自习结束
→ 短信延续
```

因此，喊楼的核心不一定是“声音很大”，而可能是**一个学校共同体在毕业年级离开之前，公开确认彼此仍属于同一个群体**。

### 3. 当仪式固定下来以后，歌甚至可以变成“触发协议”

浙大附中玉泉校区的案例尤其清楚。

学校工作人员在 2019 年介绍，该校的高考喊楼始于 2010 年，最初是团委学生干部觉得高三长期紧张备考，于是由低年级学生策划给高三一个惊喜。此后每年延续。

2019 年，组织者故意不公开具体喊楼时间，只告诉各班一个“暗号”：**合唱社开始唱《奔跑》**。

午休铃后，十多名合唱社学生唱起《奔跑》，上千名高一高二学生听到声音后才从教室走到走廊，活动正式启动。

来源：

- 澎湃新闻报道（新浪教育转载），2019-05-28，《杭州一所高中低年级学生每年“喊楼”为高考加油》：https://edu.sina.cn/gaokao/gkrx/2019-05-28/detail-ihvhiqay1821172.d.html

这里的歌曲已经不只是“励志内容”。

它承担了一个非常具体的组织功能：

> **声音 = 事件开始的同步信号。**

没有群消息全校倒计时，也不需要广播宣布“现在开始喊楼”；一首大家认识的歌本身就是协议。

这说明研究考试季声音史时，应新增一个字段：

- `signal_function` — 歌曲是否承担集合、启动、结束或换环节的信号功能。

### 4. 2010 年代中期以后，学校开始主动区分“失控宣泄”和“可管理仪式”

喊楼并不是一直被学校无条件接受。

2016 年，厦门市教育部门针对部分学校高三学生“撕书、吼楼”下发通知，要求学校不要以这类方式简单宣泄压力，强调心理疏导与秩序管理。

来源：

- 中国新闻网 / 中青在线，2016-05-29，《厦门发文禁高三毕业班学生撕书吼楼：造成不良影响》：https://www.chinanews.com/sh/2016/05-29/7886740.shtml

人民网当时转载的评论也指出，争议焦点之一正在于：如果活动是学校刻意组织，而不是学生自然发生，形式感和真正的情绪释放之间可能出现张力。

来源：

- 人民网 / 钱江晚报，2016-05-30，《杜绝撕书，高考宣泄禁不如疏》：https://edu.people.com.cn/n1/2016/0530/c1053-28388897.html

这提供了一个重要历史转折：

```text
学生自发的高声表达 / 撕书 / 抛纸
→ 安全、卫生、秩序和“育人”争议
→ 学校重新设计活动
→ “文明喊楼”、合唱、荧光棒、横幅、快闪、纸飞机、教师祝福
```

所以 2020 年代常见的“文明喊楼”并不只是仪式越来越华丽，也可以理解为学校对学生原有表达方式进行**收编、降风险和重新包装**。

### 5. 中考已经形成自己的喊楼与歌声传统，不是高考的附属版本

现有材料可以明确看到，中考也拥有独立的仪式链。

2020 年成都树德实验中学在中考前安排初一初二学生和老师为初三喊楼。校长明确把活动解释为三件事：鼓舞士气、减压、促进情感交流。

来源：

- 四川在线，2020-07-13，《“壮士出征” 初三学生“喊楼”为中考壮行》：https://sichuan.scol.com.cn/amsc/202007/57851036.html

2021 年海南中学初中部的中考喊楼中，学生在老师带领下齐唱《怒放的生命》《我相信》，同时分班喊口号。报道明确说，这一活动每年举行，用于释放压力、增强信心并给毕业生留下共同记忆。

来源：

- 人民网海南频道，2021-06-18，《海南中学“喊楼”为2021年中考考生加油》：https://hi.people.com.cn/n2/2021/0618/c231190-34783431.html

到 2025—2026 年，一些完全中学直接把初三与高三合并成一次“中高考喊楼”。

晋江紫峰中学 2025 年已经连续第十年举办中高考喊楼；2026 年为第十一年。2026 年活动中出现《起风了》《逆战》《倔强》等歌曲，初三和高三学生共同作为被祝福对象。

来源：

- 晋江市人民政府，2025-05-31，《紫峰中学举行中高考“喊楼” 为考生加油鼓劲》：https://www.jinjiang.gov.cn/xxgk/jjyw/202505/t20250531_3175572.htm
- 晋江市人民政府，2026-05-29，《紫峰中学：举行中高考“喊楼” 为学子加油鼓劲》：https://www.jinjiang.gov.cn/xxgk/jjyw/202605/t20260529_3296012.htm

这类材料说明：

> **同一所学校可以把“考试季”本身做成年度校园节律，而中考、高考只是其中两个不同门槛。**

### 6. 送考歌曲有时承担的是注意力管理，而不是单纯鼓劲

华坪女子高级中学的送考传统给出了非常清楚的解释。

2024 年人民网对张桂梅的报道提到：学校第一次参加高考时，学生会在场次之间讨论上一科，影响后续发挥。后来张桂梅想到用唱歌来减压、转移注意力。报道中，考前全校合唱《万疆》，上车后继续唱歌。

来源：

- 人民网云南频道，2024-06-12，《可敬的张桂梅，其实也有可亲可爱的一面》：https://yn.people.com.cn/BIG5/n2/2024/0612/c378439-40876087.html

2023 年教育部转载报道也记录了张桂梅在送考途中陪学生唱歌；2026 年人民网又记录华坪女高送考前集体演唱《红梅赞》等歌曲。

来源：

- 教育部，2023-06-09，《各方全力以赴护航“平安高考”——倾心传递爱 情暖追梦人》：https://www.moe.gov.cn/jyb_xwfb/s5147/202306/t20230609_1063486.html
- 人民网云南频道，2026-06-10，《“活着就要送考” 张桂梅十六年从未缺席》：https://yn.people.com.cn/BIG5/n2/2026/0610/c378439-41606421.html

这个案例尤其重要，因为它说明歌声可以作为一种**流程性认知管理工具**：

- 阻止上一场考试继续占据注意力；
- 把学生从“讨论答案”切换到“准备下一场”；
- 让大巴车上的时间不被焦虑填满；
- 用熟悉的共同曲目维持群体节奏。

这不是证明“唱歌一定提高考试成绩”。

它只证明：至少有学校明确把歌声设计成考场之间的心理与注意力转换机制。

## 一、从高校毕业喊楼到中学考试喊楼：只能写“迁移线索”，不能写单一起源

### 高校语境里的喊楼

2010 年中新网对广东外语外贸大学毕业喊楼的报道里，喊楼发生在宿舍楼之间，时间接近毕业离校，功能更偏向：

- 男女宿舍之间公开喊话；
- 表达平时不便直接说的话；
- 通过泼水、玫瑰等行为强化“只此一次”的毕业感；
- 拍 DV 上传网络，留下纪念。

这里还没有高考冲刺或低年级给毕业生壮行的结构。

### 中学语境里的改造

到 2012 年广州中学案例，核心关系变成：

```text
低年级学生
↓
为高三送祝福
↓
高三在走廊回应
↓
即将参加高考
```

同一个“对楼喊话”的动作，被重新解释成了**代际交接和考试壮行**。

这非常像一种文化形式的功能迁移：

- 大学里：毕业生之间的告别；
- 中学里：低年级给毕业年级加油；
- 后来：学校把它变成正式考前活动。

但目前证据只能证明“存在这种迁移叙述”，不能断言所有地区都沿同一条路径传播。

## 二、“最后一次晚自习”为什么特别容易和歌绑定

最后一次晚自习具有一个奇怪的时间性质：

- 人还坐在教室里；
- 高中生活形式上还没有完全结束；
- 但大家都知道，这种正常秩序不会再重复很多次。

福州一中 2012 年的材料尤其典型。

低年级学生在晚自习课间开始喊楼，高三走到窗边和走廊回应，随后唱校歌、《最炫民族风》《朋友》。从功能上看，这几类歌并不相同：

- **校歌**：强调“我们属于同一个学校”；
- **当年流行歌**：《最炫民族风》不是高考主题曲，却因为当时高度可识别而能迅速形成共同参与；
- **《朋友》**：被重新解释成离别与同伴关系的语言。

这说明“考试季歌曲”不需要原本就是考试歌。

一首歌真正进入考试季，往往靠的是：

> **它在某一个共同场景里，被足够多的人同时唱过。**

## 三、声音可以组织空间：从窗户、走廊到整座校园

喊楼特别依赖中学校园的建筑结构。

常见空间包括：

- 相对的两栋教学楼；
- 中庭；
- 楼层走廊；
- 操场；
- 教学楼下的广场；
- 校门和送考通道。

这些空间共同提供一种很特殊的传播方式：

```text
不需要每个人站在同一个房间里
但所有人都能听见彼此
```

这也是为什么“喊楼”比普通礼堂活动更容易产生全校参与感。

声音跨过建筑之间的距离，把原本分散在不同班级、不同楼层的人临时组织成一个共同体。

2019 年浙大附中用《奔跑》作为启动暗号，把这种空间组织推到更明显的程度：**歌声先出现，人群随后出现。**

## 四、从“学生自己喊”到“学校策划一整台节目”

2010 年代后期以后，可检索材料里越来越多的是学校策划完整流程的喊楼：

- 主持人；
- 统一口号；
- 荧光棒；
- 横幅；
- 舞蹈；
- 合唱；
- 教师祝福；
- 家长参与；
- 校友参与；
- 官方摄影和视频。

例如 2025 年晋江二中的中高考喊楼，节目依次包括街舞、音乐社、校友演唱《爱拼才会赢》、教师代表演唱《奔跑》，最后全场合唱《年轻的战场》。学校副校长明确把活动解释为缓解高考备考压力、让学生“轻装上阵”。

来源：

- 晋江市人民政府，2025-06-04，《晋江二中激情喊楼 迎战高考》：https://www.jinjiang.gov.cn/xxgk/jjyw/202506/t20250604_3176567.htm

这已经和 2012 年最后晚自习的学生自发喊楼很不一样。

它更接近一场由学校组织的年度仪式。

不能简单说后一种“更假”。

制度化也带来一些新的东西：

- 更安全；
- 初中、高中多个年级都能参与；
- 每届学生都知道自己以后也会经历一次；
- 学校可以把活动纳入校园传统；
- 视频、照片和官方报道会长期保存下来。

但研究时必须继续标记：**谁策划、谁选歌、谁被要求参加、学生能否自己改变流程。**

## 五、“文明喊楼”的出现说明学校在重写仪式边界

海南华侨中学 2023 年的活动直接使用了“高考文明喊楼”这一说法。

学校组织约 1300 名高三学生参加，活动中集体唱《我相信》《奔跑》《追梦赤子心》，并以楼层、班级为单位喊口号。

来源：

- 央广网，2023-06-03，《海南一中学千名考生“喊楼”减压赴考》：https://www.cnr.cn/hn/jrhn/20230603/t20230603_526274754.shtml

“文明”二字本身值得记录。

它暗示喊楼已经不是一个完全中性的动作，而是存在一条被学校接受的边界：

- 可以大声；
- 可以集体；
- 可以激情；
- 但要可控；
- 不能破坏秩序或制造危险；
- 最好能转化成“正向、励志、校园文化”的叙事。

2016 年厦门对撕书吼楼的限制，与 2020 年代“文明喊楼”的流行放在一起看，能看到一种很清楚的治理变化：

> **学校没有消灭仪式，而是重新定义什么样的仪式算合适。**

## 六、中考材料为什么尤其重要

高考的公开报道更多，很容易让研究者误以为“喊楼=高考”。

但中考案例说明，真正稳定的结构其实是：

> **毕业年级即将离开当前学校 / 被下一阶段分流，低年级为其壮行。**

这套结构完全可以发生在初中。

深圳外国语学校初中部的长期传统甚至包括体育中考壮行：初三学生列队经过世界广场时，初一初二学生在楼道和广场喊楼，教师演唱《奔跑》《壮志在我胸》等歌曲。

来源：

- 人民网深圳频道 / 深圳晚报，2021-09-10，《深圳外国语学校初中部教务处主任甘磊：采撷更多的阳光陪学生前行》：https://sz.people.com.cn/n2/2021/0910/c202846-34908545.html

这提醒我们，“考试季仪式”不只围绕文化课笔试。

它还可能围绕：

- 体育中考；
- 艺考；
- 单招；
- 校内选拔；
- 其他具有明确分流后果的考试。

## 七、歌在考试仪式里至少有七种不同作用

### 1. 启动信号

例：2019 浙大附中《奔跑》作为喊楼暗号。

### 2. 年级之间的对答

例：2012 福州一中，低年级喊楼，高三唱歌回应。

### 3. 学校身份确认

例：校歌。

它提醒毕业生：离开以前，你仍是这个学校共同体的一部分。

### 4. 压力释放

例：多个学校官方解释喊楼、合唱用于减压。

这里应记录“学校/学生认为它有减压作用”，而不是把它写成未经验证的医学结论。

### 5. 注意力切换

例：华坪女高用歌声避免学生持续讨论上一场考试。

### 6. 壮行

例：送考前、上车前、走过操场或校门时集体唱歌。

### 7. 记忆封装

多年后听到同一首歌，学生可能首先想起的不是歌曲发行年份，而是：

- 某栋楼；
- 某个晚自习；
- 某一届学弟学妹；
- 那天晚上走廊上的灯；
- 第二天或几天后的考试。

## 八、考试仪式也是“代际交接”

喊楼有一个非常稳定的结构：**今年给别人喊的人，明年或后年会成为被喊的人。**

这使它与普通演出不同。

低年级学生不仅在祝福高三，也是在提前观看自己的未来。

2022 年晋江养正中学对喊楼的官方解释就包括这一层：学校希望高一高二学生在给高三加油的同时，也对高三奋斗状态产生向往。

来源：

- 晋江新闻网，2022-05-21，《“喊楼”送祝福 高考共圆梦》：https://news.ijjnews.com/system/2022/05/21/030096180.shtml

因此，考试仪式具有一种“预演”功能：

```text
现在：我是学弟/学妹
明年或后年：我会站在那栋楼上
```

学校文化通过这种重复实现跨届传递。

## 九、为什么手机和网络改变了喊楼，但没有让它消失

喊楼本质上是一种高度现场化的活动。

但从 2010 年代开始，几乎每篇报道都会同时出现另一个动作：

- 手机拍摄；
- 微博上传；
- DV 纪念；
- 学校官网发布；
- 地方媒体视频；
- 后来进入短视频平台二次传播。

这造成一个反馈回路：

```text
现场仪式
→ 被拍摄
→ 在网上传播
→ 别的学校看见
→ 模仿或改造
→ 新一轮仪式再次被拍摄
```

所以网络并没有把集体校园仪式替换成私人屏幕生活。

相反，它可能帮助一种原本局部的校园传统跨地区传播并逐渐标准化。

但这里仍需谨慎：网络上“看起来很常见”，不等于全国学校都举行。

## 十、一个更精确的事件记录模型

未来记录一条考试季仪式时，建议至少保留以下字段：

| 字段 | 说明 |
|---|---|
| year / date | 哪一年、哪一天 |
| place / school | 哪所学校，不能只写城市 |
| exam_gate | 中考、高考、体育中考等 |
| ritual_stage | 百日誓师、最后晚自习、喊楼、送考、考间转换等 |
| organizer | 学生自发、团委、年级、学校、教师、家长 |
| participants | 谁唱、谁喊、谁被祝福 |
| song | 具体曲目 |
| song_role | 背景、启动暗号、合唱、回应、壮行、注意力切换 |
| space | 走廊、教学楼下、操场、校门、大巴 |
| participation_mode | 自愿、集体安排、表演性、全校参与 |
| media_capture | 是否有照片、DV、微博、短视频、官方视频 |
| source_type | 同时代报道、学校官网、政府、回忆材料 |
| evidence_strength | A/B/C |

尤其要新增两个区别：

1. **谁选的歌？**
2. **歌在流程里做了什么？**

否则“学校播了一首歌”和“全班自己唱了一首歌”会被错误地写成同一种文化事实。

## 十一、后续研究问题

### 1. 真正的传播路径

需要继续查：

- 哪些高校在 1990s—2000s 已有喊楼传统？
- 哪些中学最早明确记录高考喊楼？
- 是否存在不同地区独立产生的类似形式？

### 2. 最后晚自习的独立历史

最后晚自习常常是喊楼、唱歌、熄灯、拥抱、班主任讲话的集中点，值得单独建表。

### 3. 复读生的缺席

很多“最后一次”叙事默认考试之后就离开高三，但复读生实际上会再次进入同样的倒计时。

对复读生而言：

- 去年的毕业歌还是不是毕业歌？
- 再次听见同一首考试季歌曲，会不会从“告别”变成“还没结束”？

这是现有公开材料明显不足的部分。

### 4. 落榜、职教与未被庆祝的分流

公开报道偏爱“壮行—胜利—金榜题名”。

但生活史不能只保存成功仪式。

还应寻找：

- 中考后进入中职的人怎样回忆毕业季；
- 高考后没有进入预期高校的人怎样处理原来的班级告别；
- 复读学校是否有自己的歌曲和仪式；
- 家庭是否会主动回避毕业聚会、谢师宴或公开庆祝。

### 5. 考研、考公等成人考试是否会重新制造类似仪式

成年人通常不再拥有整栋教学楼和低年级学生替自己喊楼。

那么考试仪式会转移到哪里？

可能包括：

- 自习室；
- 培训机构；
- 线上群；
- 考研宿舍；
- 图书馆闭馆广播；
- 考前歌单；
- 社交平台“上岸”视频。

这会是下一阶段很值得接上的研究。

## 十二、为什么这属于 How People Lived

喊楼、唱歌、送考看起来都是“考试外围的小事”。

但它们真正保存的是：

- 学校一天什么时候结束；
- 高三最后几天是否还晚自习；
- 不同年级平时能不能互相接触；
- 学校是否允许学生大声、集体、失控一点；
- 教师如何处理紧张情绪；
- 手机怎样进入校园记忆；
- 一届学生怎样把传统交给下一届；
- 一个人怎样在真正离开以前，确认“这段生活要结束了”。

考试把人分流。

而这些仪式做的，是在分流发生以前，给原来的共同生活安排一个可听见的结尾。

> **不是每个学生都喜欢同一首歌，也不是每所学校都有同一种传统；但当几百、上千个人在同一个时间点一起发出声音时，制度上的“考试日期”就会变成生活里的“这一晚”。**

这正是普通生活史应该保存的东西。

## 证据等级

- **A：** 政府、教育部门、一手制度材料；
- **A/B：** 学校官方、政府地方新闻、主流媒体对当时事件的现场报道；
- **B：** 回忆性采访、校友材料、后续整理；
- **C：** 社交媒体单条内容、平台聚合、无法交叉核验的二手转述。

本文优先使用 A/B 级材料。对“起源”“全国流行”“学生真实心理”均保持保守表述。
