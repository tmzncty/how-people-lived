# 从“银行开门才能取钱”到“现金成为兜底选项”：ATM、跨行网络与支付退路（中国，1987—2026）

> 研究切口：一个人账户里“有钱”，并不等于此刻、此地能把其中一部分变成自己可以拿在手里、交给商店、带回家乡的现金。本文不写银行卡产业通史，也不重复仓库已有汇款专题；它研究 **银行营业时间、网点地理、ATM、自助网络、跨行交换、Web/手机银行与后来移动支付怎样改变“余额→现金→支付”的可执行性**，以及当扫码支付成为常态后，为什么现金又被重新制度化为一种不能轻易消失的退路。

## 一句话结论

**互联网并不是第一次让钱“数字化”。在大众 Web 以前，ATM、银行主机、专线和跨行交换已经把普通人的账户余额变成一种可以跨营业时间、跨网点甚至跨地区调用的网络状态。移动支付后来进一步减少了把余额先转换成纸币的必要；但当数字支付成为默认入口以后，成熟基础设施面对的新问题反而变成：不会用最新界面、手机没电、系统故障或只愿意使用现金的人，是否仍能完成最普通的生活。**

因此这条历史不是简单的：

```text
现金
-> 银行卡
-> ATM
-> 网上银行
-> 手机支付
-> 无现金社会
```

更准确的是：

```text
柜台现金与存折
-> 银行内部电子账本
-> ATM 把部分柜台能力移到非营业时间
-> 跨行网络把现金访问从开户行位置解绑
-> Web/手机银行开始管理 ATM/POS 权限与账户状态
-> 移动支付让许多小额交易不再需要先取现
-> ATM/现金需求下降
-> 社会重新保护“现金仍可获得、仍可支付”这一 fallback
```

本文把“账面余额能否在此时此地稳定变成实际可支配现金”的能力称为：

> **balance-to-cash executability / 余额到现金的可执行性**

把账户资金不再被一个开户柜台、一个营业时段或一个城市锁住的能力称为：

> **cash-access portability / 现金访问可携带性**

把普通人能否在主要数字支付之外仍保有一条可以退出、故障切换或适配自身能力的支付路径称为：

> **payment fallback sovereignty / 支付退路主权**

## 1. 状态链：账户里有钱，不等于今天晚上能拿到现金

```text
账户存在且有余额
  ≠ 银行卡/凭证仍有效
  ≠ 找得到可用 ATM
  ≠ 设备仍实际存在
  ≠ 设备通电并在线
  ≠ 设备接入当前发卡行/跨行网络
  ≠ 身份认证成功
  ≠ 账户允许本次取款
  ≠ 单笔/单日限额允许该金额
  ≠ 机器中有足够且合适面额的现金
  ≠ 吐钞机构动作成功
  ≠ 主机记账与吐钞状态一致
  ≠ 使用者真正拿到钞票
  ≠ 跨行清算/冲正最终完成
```

因此 ATM 不是“墙上的小银行”这么简单。它是一个把 **人、卡、PIN、设备、银行主机、跨行交换、现金库存与物理吐钞机构**接起来的实时事务端点。

最能说明这一点的不是成功取款，而是失败：2007 年苏州一宗案件中，用户操作后屏幕显示交易成功却没有吐钞，随后又因贴在机器上的假“操作须知”遭受诈骗。无论案件责任如何划分，它都固定了一个非常重要的状态边界：

```text
screen says transaction succeeded
!= physical cash received
```

来源：
- 2007-08-06，《法制与新闻》/新浪，《苏州法院首判银行为ATM机诈骗案埋单》：
  https://news.sina.com.cn/c/2007-08-06/120813603687.shtml

证据等级：**A/B（同期司法报道）**。

## 2. 海外前史：ATM 从一开始就是“时间接口”

1967 年 6 月 27 日，伦敦 Enfield 的 Barclays 网点投入早期现金机。Smithsonian 的技术史梳理指出，早期机器的直接问题之一，就是银行关门以后怎样让账户持有人取得现金；1969 年美国 Chemical Bank 推 ATM 时甚至打出“银行九点开门，以后再也不关门”的广告语。

来源：
- Smithsonian Magazine, 2015-01-08, “The ATM is Dead. Long Live the ATM!”
  https://www.smithsonianmag.com/history/atm-dead-long-live-atm-180953838/

证据等级：**B（技术史二手资料，引用同期宣传和研究者访谈）**。

这里最重要的不是争夺“谁发明了第一台 ATM”，而是它改变了一种非常普通的时间约束：

```text
工资/存款已经在账户里
-> 银行柜台下班
-> 我仍然需要吃饭、坐车、购物
```

ATM 最初提供的是一种：

> **cash-time sovereignty / 现金时间主权**

即“银行工作人员此刻是否在岗”不再完全决定我能不能把自己的余额变成现金。

但海外早期经验也提醒我们，采用从来不是自动的。Smithsonian 收集的 1970s 美国材料中，有用户担心机器吞卡、交易中途故障，银行也需要用宣传和奖励鼓励客户尝试自助设备。于是必须区分：

```text
ATM installed
!= customers trust it
!= customers routinely use it
```

## 3. 中国 1987—2002：大众 Web 以前，现金已经开始依赖数字网络

### 3.1 1987：第一批 ATM 的意义首先是“前 Web 银行数字化”

中国新闻网 2008 年回顾银行卡发展时记载，1987 年中国银行珠海分行引进并安装了中国大陆早期 ATM。该材料是后来媒体回顾，而不是 1987 年普通用户日记，因此本文只把它作为“ATM 基础设施已经出现”的历史节点，不据此推断当年普通家庭的采用率。

来源：
- 2008，中国新闻网银行卡史回顾（相关报道保存于中新网/新浪等）：关于 1987 年珠海中行引进 ATM 的节点。

证据等级：**C/B（后来媒体/机构史回顾）**。

真正重要的是：**1987 年的 ATM 不需要公共 Web 才能工作。** 它依赖的是银行后台计算机、终端通信与现金管理。普通用户甚至不知道“网络协议”是什么，仍然可能在日常取款中进入一个数字事务系统。

### 3.2 1993—2002 上海：从同城联网到全国跨行交换

上海市政府保存的 2002—2005 银行卡产业规划回顾：上海 1993 年启动“金卡工程”，1995 年开通 ATM、POS 联网信息系统；到 2002 年 6 月底，全市已有 2,924 台 ATM，ATM 跨行交易额 134.16 亿元。文件同时记录，中国银联于 **2002 年 3 月 26 日**成立，核心任务之一就是全国银行卡联网通用。

来源：
- 上海市人民政府，《关于推进本市银行卡产业发展的若干意见》《上海银行卡产业发展计划（2002年—2005年）》：
  https://www.shanghai.gov.cn/nw6933/20200906/0001-6933_534.html
- 2003-04-14，新浪转载中国银联简介：
  https://finance.sina.cn/sa/2003-04-14/detail-ikknscsi0750501.d.html

证据等级：**A/B（政府规划中的同期历史回顾 + 当时机构简介）**。

这一步改变的不是“有没有纸币”，而是纸币获取背后的权威位置：

```text
以前：我在哪家银行、哪个网点开户很重要
后来：只要卡、终端与跨行网络互认，别家银行的 ATM 也可能成为我账户的现金出口
```

可以称为：

> **branch-dependence decoupling / 柜台依赖解除**

以及：

> **interbank cash portability / 跨行现金可携带性**

但“联网通用”并不意味着免费、同样限额、同样成功率。上海 2002 年规划本身还记录当时同城交易成功率与异地交易成功率存在差异。技术互联只是必要条件，不是体验一致性的证明。

## 4. 2005—2012 扩张型未来：打工地挣钱，家门口再把它变成现金

这一阶段最能把 ATM/银行卡与真实生命历程接起来的，不是都市白领，而是跨地区务工。

### 4.1 “把工资带回家”从携带一捆钞票变成携带一张卡

2007 年河南农民工银行卡特色服务的同期报道中，中牟县一名张姓老人用银行卡取出 2,000 多元打工钱后告诉记者，有了卡以后就不用每天在身上“绑”很多现钱，觉得安全方便。

来源：
- 2007-01-08，《金融时报》/新浪，《河南农民工银行卡：取款通道到农家》：
  https://finance.sina.com.cn/g/20070108/14093225800.shtml

证据等级：**A（同期现场采访）**。

2008 年天津春节前的报道又记录，湖南安化县的张某在天津打工，在工商银行天津分行办“农民工卡”，把日常劳动收入存入卡内；制度目标正是让务工者在工作地存钱、回乡后在农村信用社或邮储等受理网点取出，减少携大量现金返乡的风险。

来源：
- 2008-01-11，《每日新报》/新浪，《回家过年 带张“农民工卡”》：
  https://news.sina.com.cn/c/2008-01-11/113013241603s.shtml
- 2007-09-12，人民网/国际金融报转载，《银联力推农民工银行卡》：
  https://business.sohu.com/20070912/n252093370.shtml
- 2008 Q3 支付体系运行材料（金融时报转载）：
  https://finance.sina.cn/sa/2008-12-31/detail-ikkntiam3569793.d.html

证据等级：**A/B（同期采访 + 行业/监管统计）**。

这对应一条很具体的迁移路径：

```text
人在城市打工
-> 工资在工作地变成银行余额
-> 人本人跨省返乡
-> 账户记录不需要跟着一捆钞票物理运输
-> 回乡后再从本地金融节点取现
```

所以银行卡网络在这里是一种：

> **income-location decoupling / 收入地点与现金使用地点解绑**

它没有消灭城乡金融差距。恰恰因为农村普通受理环境还不充分，才需要“农民工银行卡特色服务”这种制度补丁。2008 年第三季度材料记录，当时特色服务已延伸到大量县及县以下农村金融网点，但这不能被写成“农村家庭已经和大城市拥有一样的 ATM 可达性”。

### 4.2 2007：方便与手续费同时进入日常计算

2007 年郑州张女士自述自己购物时不习惯携现金，刷卡或临时找 ATM 取钱，后来上网查账户明细时才发现跨行 ATM 取款手续费从每笔 2 元变成 4 元，国庆期间累计花了几十元。

来源：
- 2007-10-18，《郑州晚报》/搜狐，《郑州ATM跨行取款手续费涨到4元 多数市民不知情》：
  https://news.sohu.com/20071018/n252722252.shtml

证据等级：**A（同期第一人称采访）**。

这是一个很好的混合数字生活：

```text
线下购物
-> 不带大量现金
-> 临时跨行 ATM 取现
-> 回家上 Web 查交易明细
-> 才意识到新的跨行成本
```

因此“跨行可取”仍要与“跨行取现的价格可承受”分开。

### 4.3 ATM 把排队拿走了一部分，却没有把现金的物理约束拿走

2007 年 ATM 日取款上限提高到 2 万元时，同期记者实测发现很多机器单笔仍只能吐 2,000 元，取满 2 万需要连续操作 10 次、约 8 分钟；银行人士还提到单机钞箱容量有限。

来源：
- 2007-05-23，浙江在线，《部分银行上调ATM机取款上限 取款2万需操作10次》：
  https://zjnews.zjol.com.cn/05zjnews/system/2007/05/23/008451248.shtml
- 2007-05-23，经济观察网，《每台ATM最多容纳20万 日取2万遇难关》：
  https://www.eeo.com.cn/2007/0523/64780.shtml

证据等级：**A/B（同期记者体验 + 银行人士说明）**。

所以：

```text
account authorizes 20,000
!= machine can dispense 20,000 in one operation
```

数字授权与机械吐钞能力从来不是一件事。

## 5. Web 并没有“取代 ATM”，而是开始遥控 ATM 的权限边界

招商银行今天仍能访问的一份旧版更新公告保存了 2008—2012 的连续功能记录。它不是 Wayback capture，而是**当前仍在线的 legacy page**；因此只能证明该站点现存页面声称这些历史更新，不能用于重建当年的 DOM、浏览器或实际页面外观。

其中：

- 2009-07-09：网上银行新增“一卡通 ATM、POS 限额”，大众版可调低每日限额、关闭境外银联 ATM/POS；专业版可调高/调低并开关境外功能；
- 2010-07-28：手机银行 Web 版增加 ATM/POS 限额修改；
- 2011-07-08：手机银行“网点查询”开始提供营业网点排队信息；
- 2011-12-10：网上银行可管理部分他行账户与跨行状态。

来源：
- 招商银行 legacy page，《个人银行专业版更新公告》：
  https://cmbchina.com/cmbpb/v50/gb/pb/PublicMessageMore.htm

证据等级：**A/B 边界（银行官方仍存 legacy 文档，内容含同期日期；非历史 capture）**。

这揭示出一个很有 old-Web 价值的混合系统：

```text
Web/手机页面
-> 改变账户的 ATM/POS 权限参数
-> 用户关闭电脑/手机
-> 几小时后在街边 ATM 插卡
-> ATM 后台读取已经改变的权限
-> 决定是否允许吐钞
```

因此互联网与物理现金不是替代关系。Web 可以成为**物理终端事务的配置界面**。

## 6. 2015—2019 拥堵型未来：最大的变化不是 ATM 更强，而是越来越多交易根本不需要取现

### 6.1 2018：手机开始取代“先找 ATM”这一中间步骤

2018 年《法制日报》采访北京一家面包店员工刘畅：店里电子支付系统出过故障，当天营业额明显下降，因为很多年轻顾客平时只带手机、不带现金；她还遇到顾客手里其实有钱包，却一时没反应过来可以现金支付。

来源：
- 2018-06-08，法制日报/人民网，《移动支付何以让消费者爱恨交织》：
  https://legal.people.com.cn/n1/2018/0608/c42510-30045973.html

证据等级：**A（同期商户观察与用户场景）**。

同年移动支付调查中，80.1% 的该调查用户称每天使用移动支付；49.8% 认为移动支付与现金会共存。它是支付用户调查，不应外推成全国人口行为。

来源：
- 2019-01-03，人民网，《报告：扫码支付成为最常用移动支付方式》：
  https://finance.people.com.cn/forex/n1/2019/0103/c1004-30500810.html

证据等级：**B（行业调查的同期报道）**。

于是日常链条从：

```text
账户里有钱
-> 找 ATM
-> 取 200/500 元
-> 用现金吃饭购物
```

越来越多地变成：

```text
账户/钱包里有数字余额
-> 商户直接收数字支付
```

这不是“ATM 失败”，恰恰是 ATM 所代表的“把银行账本延伸到日常生活”的逻辑被更进一步推进，直到中间那一步纸币转换在许多场景里不再必要。

### 6.2 采用外部性：当大多数人不带现金，数字故障的成本反而上升

面包店案例最值得保留的一点是：**支付方式的采用会改变备用方案的现实可用性。** 如果多数顾客都默认手机，电子支付故障时不是所有人都能立即切回现金。

因此成熟数字支付的风险并不只是“手机支付安不安全”，还包括：

> **fallback availability / 退路是否仍然可执行**。

这已经开始通向 2020s 的防守型未来。

## 7. 2020—2022 偶发型未来：现金从“老办法”重新变成必须维护的物理基础设施

### 7.1 疫情没有创造移动支付，却让现金本身进入卫生与供应链治理

2020 年 2 月，人民银行随州市中心支行的同期材料记录：银行需对营业区域、自助服务区和 ATM 设备消毒，对回笼现金消毒、登记并单独存放；在封城、公共交通中断的条件下，装卸钞人员仍要应急加钞与维护机器，确保取款设备保持现金供应。同时官方鼓励使用网银、手机银行以减少人员流动。

来源：
- 2020-02-07，中共湖北省委金融办转载，《净化货币防疫情 迎难而上保供应》：
  https://jrb.hubei.gov.cn/bmdt/dyyq/lflk/202002/t20200207_2020675.shtml

证据等级：**A/B（同期地方金融管理材料）**。

同一时间里，两条看似矛盾的动作同时成立：

```text
鼓励线上银行/移动支付，减少接触
AND
继续消毒、运钞、加钞、维护 ATM，保证现金仍然可取
```

这说明成熟支付体系需要的不只是“主流渠道效率”，还需要**在突发事件里保留异质渠道**。

### 7.2 ATM 数量开始明显下降，但“用得少”不等于“可以一减了之”

《人民日报》2022 年指出，2018—2021 年全国 ATM 数量从 111.08 万台下降到 94.78 万台，并明确提出不能简单撤机，需要适老化改造；文章同时提到一些地区开始探索 ATM 的数字人民币与纸钞双向兑换。

来源：
- 2022-09-05，人民日报/人民网，《让自动柜员机找回“用武之地”》：
  https://finance.people.com.cn/n1/2022/0905/c1004-32519173.html

证据等级：**A/B（同期主流媒体结合监管统计）**。

于是基础设施进入一个新阶段：

```text
平均使用频率下降
!= 边缘/应急使用价值同比下降
```

如果只按平均交易量优化，最容易被删除的恰恰可能是少数人在关键时候唯一会用的入口。

## 8. 2023—2026 防守型未来：最先进的支付系统开始正式保护“可以不用最新支付系统”

### 8.1 2025：对一部分年轻人，ATM 已经从日常设施变成“古早设备”

2025 年《新黄河》采访中，90 后济南市民秦先生说自己大学时还用 ATM 取现，毕业后基本转向手机；他描述自己的 00 后表弟表妹甚至没有用过 ATM。报道同时引用监管数据：2024 年末全国 ATM 约 80.27 万台，而 2019 年末约 109.77 万台。

来源：
- 2025-06-10，新黄河，《5年减少约30万台，有的日均交易量不足10笔，银行ATM机为何加速“消失”？》：
  https://www.jinantimes.com.cn/news-7-5088551.html

证据等级：**A/B（同期第一人称 + 监管统计转述）**。

这条材料不能证明所有 00 后都不用 ATM，但它很好地固定了一个代际界面变化：**一代人曾把“身上没钱就去 ATM”当作自然动作，另一代人可能先学会扫码和手机转账，直到很晚才第一次需要一台取款机。**

### 8.2 2024—2026：现金被明确重新定义为“兜底”而不是“落后残余”

2024 年人民银行系统公开使用“现金兜底”这一定位，强调老年人、外籍来华人员等群体的现金服务与找零便利。

来源：
- 2024-06-13，中共上海市委金融办转载人民银行工作材料，《坚持以人民为中心的价值取向 持续优化现金使用环境》：
  https://jrj.sh.gov.cn/djfwjyjl/20240613/f56c4930bfaa42a08131842981356b2c.html

到 2025 年 11 月 27 日，中国人民银行会同国家发展改革委、金融监管总局制定《人民币现金收付及服务规定》，自 **2026 年 2 月 1 日**施行。规定要求面对面、线上预约但线下交付且具备当面收款条件的场景支持现金；无人值守和自助设备场景需要显著说明支付方式、现金转换方式及联系电话；银行还需要为突发情况及特殊群体建立现金服务保障机制。

来源：
- 中国政府网公众号转载，2026-01-23，《人民币现金收付新规下月起施行》：
  https://zwfw.gansu.gov.cn/pingliang/zczx/zcjd/art/2026/art_91961b00803646fd86babd22e5a3ebc5.html
- 2026-01-16，江阴市政府，《人民币新规》：
  https://www.jiangyin.gov.cn/doc/2026/01/16/1376599.shtml

证据等级：**A（现行制度文本的政府转载/说明）**。

这意味着“防守型未来”在支付领域不是简单的“大家悲观所以重新用现金”，而是一种更成熟的基础设施逻辑：

```text
主流渠道：手机支付极高效
fallback：现金必须仍能取得、仍能花掉
```

也就是：

> **payment fallback sovereignty / 支付退路主权**。

当一个系统足够成熟以后，真正的自由不再只是“我可以扫码”，而是**我不必因为不会扫码、手机损坏、没电、账号异常或单纯偏好现金，就被普通交易排除出去。**

## 9. 四种未来的证据对照

| 时段 | 关键问题 | 典型生活动作 | 新获得的能力 | 新暴露的风险 |
|---|---|---|---|---|
| 2005–2012 扩张型 | 我的工资能不能跟着我跨地区移动 | 打工地存钱、回乡取现；跨行 ATM；Web 查账 | 收入地点与现金使用地点解绑；营业时间解绑 | 手续费、受理网点不足、限额、设备故障 |
| 2015–2019 拥堵型 | 为什么还要先取现金 | 手机直接付小额消费 | 余额直接进入交易，不必频繁 ATM | 数字系统故障时很多人已经不带现金 |
| 2020–2022 偶发型 | 主流渠道失灵或高接触时，备用渠道还能不能工作 | 线上金融减少接触，同时继续消毒、加钞、维护 ATM | 多渠道连续性 | 物理现金供应、设备维护、数字鸿沟同时暴露 |
| 2023–2026 防守型 | 我能否保留一种不依赖最新界面的支付方式 | 少用 ATM，但制度保护现金收付与现金服务 | 支付方式选择权、现金兜底 | 低使用率导致撤机，备用基础设施可能被平均效率侵蚀 |

这条时间线不能被写成“从现金落后走向手机先进”。更准确的是：

> **每一代技术都把上一代的某种约束拆掉，同时也可能让上一代的退路变得更稀薄。**

## 10. 对“普通人到底有多少种活法”的新增理解

### 10.1 迁移并不只需要交通，也需要钱的地理可携带性

一个人可以坐火车跨省，不代表他的工资也自动跨省。农民工银行卡案例说明：

```text
身体迁移能力
+
收入记录可携带性
+
家乡现金访问节点
```

共同决定“外出挣钱、回乡使用”这条生活路径有多难。

### 10.2 非标准作息需要金融服务脱离柜台时间

夜班、周末、早出晚归的人未必能配合银行柜台营业时间。ATM 的意义因此不仅是“少排队”，而是**标准机构时间不再完全压住个人生活时间**。

### 10.3 数字化既能解除空间约束，也能制造新的排除

当 ATM/卡网成为常态，不会使用银行卡的人可能处于劣势；当手机支付成为常态，不会使用智能手机的人又可能处于劣势。基础设施的“进步”不能只看主流用户操作步数，还要看：

> **旧入口消失以后，谁会从系统里掉出去？**

### 10.4 最终成熟的形态往往不是单一最优接口，而是多轨共存

现金、银行卡、ATM、网上银行、手机支付并不是严格替代。一个家庭或个人可以在不同场景混用：

- 手机支付日常小额；
- ATM 偶尔取现金给老人或小商户；
- 银行卡处理大额/特定商户；
- 现金作为设备故障或账号异常时的退路。

这种“保留多种可执行路径”本身就是一种生活韧性。

### 必须避免的后见之明

1. **1987 有 ATM ≠ 1987 普通家庭可普遍使用 ATM。**
2. **2002 银联成立 ≠ 全国所有地方立即跨行无摩擦。**

4. **账户里有钱 ≠ ATM 此刻有钱可吐。**

6. **移动支付高频 ≠ 现金已经没有社会价值。**
7. **ATM 数量下降 ≠ 每个群体都同样不需要 ATM。**
8. **保护现金 ≠ 社会“倒退”回现金时代。** 它可以是高度数字化社会的 fallback 设计。

## 14. 本轮改变了什么

此前可以把互联网金融史理解为“钱逐渐从纸面和柜台进入屏幕”。这一切口说明，更早而且更普通的变化其实是：

> **钱先从一个地点解绑。**

一个夜班工人不用等银行第二天开门；一个在天津打工的人不用把一年收入缝在衣服里带回湖南；一张银行卡可以在别家银行的机器里召回自己的余额。ATM 是一台极其物质的机器——里面真的装着纸币——却同时也是一台前 Web 的网络终端。

后来二维码让很多人连“先把余额变成现金”这一步都不再需要，ATM 因而从日常必需品逐渐变成低频入口。但这条历史并没有以“现金终于消失”收尾。相反，到了 2020s，政策开始明确维护现金兜底和支付选择权。

因此对“人怎么活着”更重要的不是某一种支付技术赢了，而是：

**一个人的劳动收入能不能跨越城市和时间跟着她走；当主流接口越来越快、越来越省事以后，她是否仍有权在手机没电、系统故障、不会操作或者只想用纸币的时候，找到另一条真正能走通的路。**
