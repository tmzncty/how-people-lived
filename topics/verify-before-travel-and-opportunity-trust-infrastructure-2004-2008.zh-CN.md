# 先核验，再动身：2004—2008 年网络招聘怎样产生“机会可信度基础设施”

## 研究问题

前两条研究已经把早期网络招聘拆成两个变化：

- [先搜索，再动身：1999—2004 年网络招聘怎样改变“机会在哪里”与“谁能找到我”](search-before-travel-and-passive-findability-online-recruitment-1999-2004.zh-CN.md)
- [先筛选，再动身：2003—2006 年网络招聘怎样把一次异地求职拆成多个阶段](screen-before-travel-and-staged-mobility-online-recruitment-2003-2006.zh-CN.md)

它们解释了一个人怎样在买票、请假、搬家之前先看到远方的岗位，并怎样把筛选、笔试乃至一部分面试放到远程完成。

但如果网络让远方机会更容易被看见，就会立刻产生另一个问题：

> **我怎么知道这个机会是真的，值得我真的动身？**

2004—2008 年的同时代材料显示，网络招聘不只是降低了机会搜索成本，也把“机会真实性”变成了一个必须主动处理的日常问题。求职者、学校、招聘平台、人才市场、政府部门和同伴网络开始共同构成一套并不稳定、但越来越可见的 **opportunity trust infrastructure（机会可信度基础设施）**。

这一轮因此在 `search-before-travel` 与 `screen-before-travel` 之间补入第三个动作：

> **verify-before-travel（先核验，再动身）**：在为一个远方机会支付车费、住宿、请假、押金、培训费、证件材料甚至人身移动成本之前，先用平台来源、机构资质、公司联系方式、同伴经验、学校就业部门、政府公开信息等手段判断“这个机会是否值得继续”。

这不是说互联网创造了招聘诈骗。报纸分类广告、街头中介、现场招聘会本来就可能存在欺诈。新的变化是：

1. 机会传播得更远、更快；
2. 求职者可能在从未见过企业和场地的情况下先收到信息；
3. 过去求职者的警告也可以被搜索、转贴和汇总；
4. 招聘平台、学校和政府开始把“审核”“许可”“不良记录”“举报电话”变成信息基础设施的一部分。

因此，互联网同时扩大了**机会可见性**与**验证需求**。

## 一、2005：网络先降低了“去北京看看”的成本，也放大了远程信任问题

2005 年 7 月，光明网一篇关于大学生网上求职的同期报道记录了湖北大学研究生李明的经历。她准备暑假去北京找工作，因为人在武汉、无法参加北京现场招聘会，先在“前程无忧”和“智联招聘”等网站投出十几份简历；一周后有几家单位电话通知面试。她把网络求职的优势概括为：不必盲目到北京参加现场招聘会，节约了不少成本。

来源：

- 光明网 / 新浪财经，2005-07-06，《大学生网上求职需谨慎》：<https://finance.sina.com.cn/roll/20050706/1114181458.shtml>

证据性质：**B — 同时代媒体报道 + 同期第一人称。**

这条材料继续支持 `search-before-travel`：

```text
人在武汉
→ 先看北京岗位
→ 先投简历
→ 有回复以后再决定是否去北京
```

但同一时期的另一条材料恰好说明这种便利为什么会制造新的核验问题。

2005 年 7 月《东南早报》报道，一名应届毕业生在厦门网站看到一条招聘信息。页面只留下接收求职材料的电子邮箱，没有可核验的公司电话和地址；她事后怀疑这类招聘信息的目的可能只是套取求职材料。

来源：

- 东南早报 / 新浪，2005-07-03，《网上求职“求”来恶意骚扰》：<https://news.sina.com.cn/o/2005-07-03/03256333573s.shtml>

证据性质：**B — 同时代新闻 + 同期用户遭遇。**

这两条材料放在一起，比单独讨论“网络招聘方便”更接近日常生活：

> 网络降低了“先去现场再判断”的必要性，却也让求职者更早面对一个此前常由身体到场、熟人介绍、报纸品牌或人才市场场地部分承担的问题：**信息发布者到底是谁？**

因此，网络招聘的历史不能只测量“职位数量”和“投递数量”，还要追踪一个机会从“看见”到“敢行动”之间的可信度判断。

## 二、2006：错误信息可以把低成本网络发现重新变成高成本真实移动

2006 年 3 月，中国教育和科研计算机网报道武汉一场“2006 年春季毕业生供需见面会”。约 6000 名大学生通过网络获得信息后到达武汉某商业广场，其中相当一部分是专程从外地赶来的；现场招聘单位却很少，与宣传中的“6000 余岗位”明显不符，另有近千人买票后甚至无法进入。

事后有关部门调查发现：

- 招聘会未在主管部门登记；
- 未获得相关审批；
- 主办方是一家当年 1 月才成立的小公司。

来源：

- 中国教育和科研计算机网，2006-03-17，《警惕非法招聘诈骗大学生钱财》：<https://www.edu.cn/jiao_yu_ping_lun_1070/20060317/t20060317_167661.shtml>

证据性质：**B — 同时代 institution-hosted 新闻/评论，包含部门调查结果。**

这是 `verify-before-travel` 最清楚的机制证据之一。

网络本来可以让人：

```text
先看信息
→ 再决定是否移动
```

但如果信息本身不可靠，就会变成：

```text
远程看到高吸引力机会
→ 缺少可靠核验
→ 提前相信
→ 买票 / 住宿 / 请假 / 购票入场
→ 到场以后才发现机会并不存在或严重失真
```

也就是说，**搜索成本下降并不会自动让人生试错更便宜。**

如果可信度判断没有一起发展，数字传播甚至可以把一个不真实的机会迅速扩大到更多城市，让更多人支付真实的交通、时间与情绪成本。

因此应新增一个变量：

> **verification-before-commitment（承诺前核验）**：在支付不可逆成本以前，一个人有多少手段确认机会、组织者和联系人是真实的？

## 三、2006：校园 BBS 和“求职黑名单”把上一批求职者的经验变成下一批人的查询资源

2006 年出现了一组很有价值的同时代材料：高校 BBS、独立网站和学生自发整理的“求职黑名单”。

### 3.1 高校 BBS 不只是聊天场所，也开始承担同伴风险查询

2006 年 3 月《当代商报》报道，湖南师大、湖南大学、中南大学等高校 BBS 已经存在求职受骗帖；准备应聘的学生会主动发帖询问某招聘单位的情况。报道还记录一个民间“求职打假黑名单”网站，截至 3 月 10 日已有 75 页，每页约 20 家单位的记录。

来源：

- 当代商报 / 红网 / 新浪，2006-03-20，《公司招聘黑名单惊现网络 长沙四公司榜上有名》：<https://news.sina.com.cn/c/edu/2006-03-20/08498481759s.shtml>

证据性质：**B — 同时代媒体对网站和高校 BBS 的观察。**

同年 12 月《新闻晚报》又报道，一则“上海地区求职黑名单”帖子被多所高校 BBS 转载，原帖已有两万多人次浏览，学生继续补充自己的“遇黑”经历。

来源：

- 新闻晚报 / 新浪科技，2006-12-05，《大学生网上讨伐黑公司》：<https://tech.sina.com.cn/i/2006-12-05/13121272392.shtml>

证据性质：**B — 同时代媒体对 BBS 传播与用户补充的记录。**

另外，新华社“新华视点”2006 年 3 月的报道观察到，复旦大学、交通大学、上海大学等高校 BBS 的求职版存在学生自发维护的公司“黑名单”；部分版主会定期汇总、置顶，并接受更新。

来源：

- 新华社 / 四川在线 / 新浪，2006-03-22，《“实战”暗藏玄机 求职遭遇“忽悠”》：<https://news.sina.com.cn/c/edu/2006-03-22/13338502496s.shtml>

证据性质：**B — 同时代调查报道。**

这些材料证明了一个非常具体的新生活动作：

```text
收到公司邀约
→ 不立即去
→ 先上校园 BBS / 搜索黑名单
→ 看前几届学生或其他求职者经历
→ 发帖询问
→ 再决定是否继续
```

这可以称为：

> **searchable peer warning（可搜索的同伴预警）**。

过去的同学、熟人和学校就业老师本来也会口头提醒“这家公司不靠谱”。BBS 的变化在于：

- 警告可以跨班级、跨年级保存；
- 不认识发帖者的人也能检索；
- 同一单位的多次经历可以被汇总；
- 老帖可以在下一届招聘季被重新顶起或转载。

于是一次求职失败产生的经验，不一定只属于失败者本人；它有可能变成后来者降低试错成本的一种公共品。

这是一种 **distributed trust memory（分布式信任记忆）**。

## 四、但“黑名单可搜索”不等于“黑名单是真的”：网络又制造了第二层核验问题

2006 年的材料同时明确提醒我们：民间黑名单本身也需要核验。

《当代商报》的调查中：

- 一些上榜企业否认网友指控；
- 有企业准备追究网站和发帖者责任；
- 网站创办者承认会做后置审核，但不能保证全部信息真实；
- 法律人士提醒，未经核实的信息可能构成侵权。

同年 2 月《北京娱乐信报》采访一个“求职黑名单”网站时，创办者称网站已有 20 多万人次浏览，但受访法律人士同样指出，网友举报如果不实会带来法律风险；一名学生则把这种名单描述成“可以参考，但最后还得自己判断”。

来源：

- 北京娱乐信报 / 新浪财经，2006-02-22，《“打假”网站揭招聘黑幕 专家：如侵权将负法律责任》：<https://finance.sina.com.cn/roll/20060222/00252421889.shtml>（若原跳转失效，可从新浪移动版检索同题）
- 当代商报 / 红网 / 新浪，2006-03-20，同上。

证据性质：**B。**

因此必须把两件事严格区分：

> **warning exists ≠ allegation is true**

一个 BBS 上有人说“某公司骗人”，可以证明：

- 2006 年某个时间点，平台中存在这条负面声誉信号；
- 后续求职者有可能在行动前看到它；

但不能只凭该帖证明：

- 公司确实实施了帖中所述行为；
- 帖中每项细节准确；
- 同名企业就是同一个主体；
- 后续年份仍然如此。

这对普通生活史也很重要。一个人的行动并不是只受“客观真实”影响，还受**当时能够获得的可信度信号**影响。即使某条警告后来证明有误，它在当时仍可能真实改变一个求职者是否买票、是否去面试。

因此要同时研究：

1. **opportunity reality** — 机会到底真实到什么程度；
2. **perceived credibility** — 当时的人有什么理由相信或怀疑它。

二者不是同一个变量。

## 五、从民间警告到制度化审核：可信度开始被写进就业服务流程

网络同伴警告之外，2004—2008 年还可以看到更制度化的“机会审核”基础设施。

### 5.1 2004：地方人事部门开始建立招聘不良记录

2004 年《扬子晚报》报道，镇江人事部门计划把发布虚假招聘信息、违规收费、出示虚假证明、签假合同等行为记入用人单位招聘高校毕业生的“不良记录”，并以适当方式向求职者警示。

来源：

- 扬子晚报 / 搜狐，2004-06-09，《镇江：违规用人单位将上黑名单》：<https://news.sohu.com/2004/06/09/18/news220441876.shtml>

证据性质：**B — 同时代新闻对地方制度的报道。**

这里的“黑名单”与 BBS 黑名单性质不同：前者试图成为行政/制度化信用记录，后者是求职者自发声誉汇总。二者不能混为一谈。

### 5.2 2007：国家人事部门要求会前审查单位资格和招聘信息

人事部 2007 年《关于规范人才招聘会管理改进人才招聘服务的通知》要求：

- 人才招聘会必须由具备资质的机构举办并经批准；
- 会前严格审查参会单位资格及招聘信息，防止“只招不聘”和“虚假招聘”；
- 对招聘广告和供求信息建立审查制度；
- 及时公布合法中介机构、经审批招聘会、举办单位与举报投诉电话；
- 建立权威人才招聘信息服务平台，强调信息真实可靠。

来源：

- 人事部，国人部发〔2007〕94号，深圳市政府转载：<https://www.sz.gov.cn/cn/xxgk/zfxxgj/tzgg/content/post_1613558.html>

证据性质：**A — 同时代官方规范性文件。**

这说明“可信度”并非只靠个人提高警惕，也开始被设计成一种**组织责任**：

```text
谁有资格举办
→ 谁能发布
→ 发布前审查什么
→ 哪些活动被批准
→ 出问题向哪里投诉
```

于是网络招聘的可信度基础设施逐渐出现多层分工：

```text
求职者自己判断
+
同伴 BBS / 论坛口碑
+
学校就业部门筛选
+
招聘网站内部审核
+
人才中介许可
+
政府审批 / 监管 / 举报
```

### 5.3 2008：高校被要求不要把未经核实的信息直接传给学生

2008 年 1 月，新华社相关报道记录安徽省教育厅要求高校严格筛选招聘信息，未经核实的信息不得随意向毕业生发布。背景案例中，一名毕业生通过其他渠道获得广东某企业招聘信息后单独前往，最终被骗入传销组织。

来源：

- 新华网 / 中广网，2008-01-14，《高校毕业生求职 需谨防虚假招聘》：<https://edu.cnr.cn/jyztc/jyzt/200801/t20080114_504678042.html>

证据性质：**A/B — 官方部门要求由同期媒体转述。**

这条材料特别值得与前几轮的“制度接口”放在一起看：学校不只是发毕业证、就业协议和档案，它也可以临时成为**远方机会的信任代理人**。

## 六、`verify-before-travel` 可以拆成一条实际的核验栈

基于以上材料，一次 2004—2008 年的异地求职至少可能出现以下核验层：

### 1. 来源核验（source provenance）

问题：这条招聘信息最初来自哪里？

```text
企业官网
人才网站
学校就业网
校园 BBS
转载站
短信
Email
报纸
街头广告
```

同一句招聘信息出现在不同渠道，可信度并不相同。

### 2. 组织者核验（organizer authorization）

招聘会是否经过审批？主办机构是否有合法人才中介资质？

2006 年武汉案例说明，**一个网页上写着“招聘会”并不能证明真的存在经过批准的招聘会。**

### 3. 企业主体核验（employer identity）

至少可能包括：

- 公司名称是否完整；
- 地址和电话能否核对；
- 联系邮箱是否只是一只无法归属主体的免费邮箱；
- 招聘地点是否真与公司有关；
- 是否有营业执照、资质或其他可核查记录。

### 4. 行为模式核验（behavioral red flags）

同期报道反复出现的信号包括：

- 条件极低但薪资异常高；
- 几乎不看简历就录用；
- 面试前后要求交押金、报名费、培训费、服装费；
- 先让应聘者购买产品或完成有商业价值的“实战”；
- 公司业务、地址和联系人说法含糊。

这些不是法律意义上的自动定罪标准，只是同时代求职者和就业部门逐渐形成的风险启发式。

### 5. 同伴声誉核验（peer reputation）

```text
搜索公司名
→ 看校园 BBS 旧帖
→ 看前几届学生经历
→ 发帖询问
→ 找同学 / 老乡 / 前同事确认
```

这一层尤其依赖旧网平台。

### 6. 独立通道确认（cross-channel confirmation）

最可靠的核验通常不是“在同一帖子下面再看一条回复”，而是换一个独立渠道：

- 打公开电话；
- 查学校就业中心；
- 查政府批准活动名单；
- 查公司官网；
- 询问已经在那里工作的人；
- 查另一家媒体或平台。

这可以称为：

> **cross-channel trust check（跨渠道信任核验）**。

## 七、可信度基础设施改变的不是“有没有骗局”，而是一次人生行动需要几层确认

把这一轮放回“普通人到底有多少种活法”的核心问题，会得到一个比“互联网信息更多”更具体的结论。

一个远方机会要进入实际生命历程，需要连续跨过：

```text
可见
→ 可理解
→ 看起来适合
→ 看起来真实
→ 值得继续投入
→ 可以行动
```

前三层属于信息和匹配；第四层开始属于信任。

因此：

> **opportunity visibility ≠ opportunity actionability**

一个岗位即使被网页完整保存，如果当时的人无法确认它是真的，它在生活中的“可用性”仍然很低。

这与通信基础设施的早期历史高度相似。电话存在，不代表你能找到那个人；互联网存在，也不代表你能相信那条信息。

## 八、一个新的成本概念：verification friction（核验摩擦）

前两轮已经讨论网络怎样降低：

- 搜索成本；
- 投递成本；
- 早期筛选成本；
- 一部分跨城面试成本。

这一轮补出一个此前容易漏掉的成本：

> **verification friction（核验摩擦）**：为了确认机会、主体、联系人、招聘会或工作条件的真实性，一个人必须投入的搜索、电话、询问、等待、跨平台比对和风险判断成本。

它可能很小：

```text
在校园 BBS 搜公司名 3 分钟
```

也可能很高：

```text
找学长确认
→ 打几个电话
→ 去学校就业中心问
→ 仍然不确定
→ 最后到现场才知道
```

网络不一定把总摩擦降到零；它常常是**把成本从身体移动重新分配到信息判断**。

这也是为什么“会搜索”“知道去哪里查”“认识谁可以问”本身会成为新的不平等来源。

---

## 九、同伴预警也是一种关系资本，但它比普通“人脉”更可扩散

上一条关于迁移的研究提出了 `portable network capital`：老乡、同事和朋友能帮助一个人换厂、换城以后继续找工作。

本轮材料显示，BBS 黑名单增加了一种更松散的关系资源：

> 你不必认识上一届被骗的学生，也可能获得他的经验。

这使关系资本从：

```text
我认识谁
```

部分扩展成：

```text
我能进入哪个信息共同体
```

学校 BBS、行业论坛、招聘论坛因此不只是“社交平台”，也是一种**低强度互助基础设施**。

但它仍然有边界：

- 没有校园账号的人未必能访问；
- 论坛搜索可能很差；
- 帖子可能被删除；
- 同名企业可能被误认；
- 负面经验更容易发帖，普通成功经历未必被记录；
- 强烈指控可能因为法律风险被删改。

因此“网上口碑很多”不能自动写成“求职者拥有充分信息”。

## 十、海外对照：美国大型招聘网站同样很早遭遇“假职位 + 个人信息”问题

这一机制并非中国特有。

2003 年 2 月，Monster.com 向其数以百万计的活跃用户发送安全警告，说明虚假招聘信息可能被用来非法收集求职者个人信息。当时 Monster 自称主站已有 2450 万份简历。Monster、CareerBuilder 和 HotJobs 都已经发布相关风险提示；Monster 还称有专门员工筛查职位合法性。

来源：

- Associated Press / WIRED，2003-02-27，《Monster.com Warns About ID Theft》：<https://www.wired.com/2003/02/monster-com-warns-about-id-theft/>
- InternetNews，2003-02-28，《Job Site Warns of ID Theft Risk》：<https://www.internetnews.com/small-business/job-site-warns-of-id-theft-risk/>

证据性质：**B — 同时代媒体；其中 Monster 的安全警告和平台说法属于平台自身陈述。**

同期 Monster 的安全建议包括：

- 不向潜在雇主提供信用卡和银行账户信息；
- 对要求求职者在雇佣前付款的职位保持警惕；
- 谨慎提供与工作无关的个人信息。

2003 年美国联邦贸易委员会也针对虚假联邦/邮政工作广告开展全国提醒，要求消费者直接向 USPS 等官方渠道核实职位是否存在。

来源：

- U.S. Federal Trade Commission，2003-10-02，《FTC Launches Nationwide Ad Campaign To Protect Consumers from Job Scams》：<https://www.ftc.gov/news-events/news/press-releases/2003/10/ftc-launches-nationwide-ad-campaign-protect-consumers-job-scams>

证据性质：**A — 同时代政府执法/消费者保护材料。**

这个比较带来两个结论。

### 共同机制

网络招聘一旦允许陌生雇主远距离接触求职者，就都会出现：

- 发布者真实性；
- 个人信息暴露；
- 平台审核；
- 官方核验通道；
- “不要预先付款”等风险启发式。

因此 `verify-before-travel` 不是中国特殊现象，而是**陌生人化、远程化劳动市场**中的共同问题。

### 中国的具体形态

中国 2004—2008 年材料的特殊性更多在于：

- 高校就业部门在毕业生求职中承担较强中介角色；
- 人才市场、招聘会审批和中介许可与网络信息并存；
- 校园 BBS 在大学毕业生群体中承担显著的同伴验证作用；
- 户口、档案、三方协议等制度接口使“找到真实职位”和“能完成制度化入职”仍然是不同阶段；
- 网络招聘与现场人才市场长期叠加，而不是后一夜替代前者。

## 十一、反例：互联网没有创造“先核验再行动”

必须主动防止技术决定论。

在网络招聘以前，普通人同样会：

- 问亲友“这家单位靠谱吗”；
- 查报纸品牌；
- 找街道、学校、劳动部门；
- 打电话；
- 到人才市场问；
- 看营业执照；
- 通过老乡确认招工人身份。

因此互联网真正改变的更可能是：

1. **核验对象变得更远**：你可能在武汉判断北京单位；
2. **核验记录更可搜索**：前人的警告可以留下文本；
3. **核验主体更多元**：平台、论坛、学校、政府网站同时参与；
4. **核验本身也需要核验**：匿名黑名单、转载和平台品牌不能自动等于真相。

## 十二、对 2005—2012“扩张型未来”的修正

前几轮提出，2005—2012 的一部分“扩张型未来”可能来自：

- 下一份工作持续可见；
- 换城市、换厂、再尝试仍被认为可行；
- 网络和手机让关系、岗位和机会更容易跨地点保持。

本轮要求再补一个条件：

> **optionality requires trusted options**
>
> 可选择性不仅要求“看到很多选项”，还要求其中足够一部分能被判断为真实、可执行、值得投入。

如果职位列表数量增加，但大量信息无法核验，一个人主观上未必真的获得更多可行动的未来。

因此以后比较“扩张型未来”和“防守型未来”，不只问：

- 看见多少机会？
- 换工作难不难？
- 有多少现金缓冲？

还应该问：

> **一个陌生机会要经过多少核验，才会进入“我真的可以去试”的未来集合？**

## 十三、重点矩阵更新

| 维度 | 本轮新增理解 |
|---|---|
| 教育 | 高校不仅提供学历，也可能作为招聘信息筛选和信任代理人 |
| 就业 | 求职流程在 discovery 与 travel 之间新增 explicit verification stage |
| 住房 | 异地求职信息失真会把住宿成本提前转化为损失；本轮无充分定量材料 |
| 婚姻家庭 | 本轮无直接新证据 |
| 迁移 | 远方职位是否可信直接决定身体是否跨城移动 |
| 照护 | 本轮无直接新证据 |
| 非正规劳动 | 低门槛、高薪、兼职等信息特别容易进入诈骗叙事，但不能据此推断所有非正规劳动更不可信 |
| 长期中断 | 求职受骗可能消耗时间和资金；尚缺纵向生命史材料 |
| 证件与记录 | 中介许可、招聘会审批、营业执照、不良记录开始成为机会核验接口 |
| 通信方式 | 电话、Email、BBS、政府网站被组合用于跨渠道确认 |
| 互联网平台 | 招聘站负责发布/筛选，校园 BBS 和独立黑名单站承担声誉预警 |
| 信息获取 | 从“有没有职位信息”推进到“信息能否被验证” |
| 社交关系 | 同伴经验可通过 BBS 跨弱关系传播，形成 searchable peer warning |
| 未来预期 | “远方有机会”只有在机会可信时才真正进入可行动未来 |
| 线上/线下身份 | 假公司、假联系人、冒名企业使“线上主体 = 线下主体”成为需要证明的命题 |
| 平台消失与记忆保存 | 黑名单、反驳、删除记录和更新状态的保存不对称，会扭曲后来的企业声誉重建 |

## 十五、后见之明风险

### 风险 1：把后来著名的“网络诈骗”概念倒投回 2005 年

当时的求职者可能把风险理解为：

- 黑中介；
- 乱收费；
- 传销；
- 假招聘会；
- 简历泄露；
- “实战”白用劳动；

而不是今天统一的“网络招聘诈骗”分类。应保留当时词汇和场景。

### 风险 2：因为一家单位后来出问题，就把早期所有招聘帖解释成骗局

历史判断必须固定在具体时间点。

### 风险 3：把 BBS 黑名单当事实数据库

它首先是**声誉信号史料**，其次才可能通过外部材料验证具体指控。

### 风险 4：把政府规定存在写成普通人一定知道如何核验

“有批准名单”“有举报电话”与普通求职者是否知道、能找到、愿意使用，仍是不同层级。

### 风险 5：把网络当成诈骗来源，而忘记旧媒介已有同类问题

本轮讨论的是远程传播和可搜索核验怎样改变风险处理，不是网络发明了欺诈。

## 十六、已证实 / 可以合理推断 / 尚不知道

### 已证实

1. 2005—2006 年已有求职者把网络用于跨城岗位发现和投递，以减少盲目到场成本。
2. 同期存在虚假招聘、套取简历、非法招聘会和收费陷阱等风险。
3. 2006 年多个高校 BBS 和独立网站已出现学生自发维护、搜索和转发的招聘“黑名单”或风险帖。
4. 同时代媒体和法律人士明确意识到民间黑名单可能失真并产生侵权风险。
5. 2007 年官方规范要求招聘会主办方在会前审查单位资格和招聘信息，并公开批准/举报等信息。
6. 2008 年至少有省级教育部门要求高校不得把未经核实的招聘信息随意发布给学生。
7. 美国大型网络招聘网站在 2003 年已经公开警告假职位收集个人信息，并称对职位进行合法性筛查。

### 可以合理推断

1. 网络招聘越把初始接触从现场移到远程，求职者越需要在身体移动前建立新的真实性判断习惯。
2. 校园 BBS 把原本依赖强关系的口头提醒部分转化为弱关系可搜索的风险记忆。
3. “平台审核 + 学校筛选 + 政府许可 + 同伴口碑”可以被理解成一套逐步形成、层级重叠的机会可信度基础设施。
4. 这种基础设施如果有效，会进一步降低一次异地人生试错的预期成本；如果无效，则可能让错误信息以更大半径制造真实损失。

### 尚不知道

1. 普通求职者在 2004—2008 年实际有多大比例会主动搜索公司名或 BBS 黑名单。
2. 不同学历、职业和城市群体能否同等访问这些核验资源。
3. 招聘网站对企业资质到底做了什么级别的审核、不同平台差异有多大。
4. 民间黑名单中有多少条后来得到官方投诉、媒体调查或企业回应的交叉确认。
5. 经过核验后“放弃出行”的人生动作极少留下统计记录；目前更多能看到的是受骗或冲突后的可见案例。

## 十七、这一轮改变了我们对“人怎么活着”的哪一点理解

前两轮的模型是：

```text
互联网让远方机会变得可搜索
→ 让部分筛选在移动以前发生
→ 降低一次异地尝试的前置成本
```

这一轮必须补成：

```text
远方机会变得可搜索
→ 信息来源也变得更陌生
→ 必须建立可信度判断
→ 平台 / 学校 / 政府 / 同伴共同提供核验信号
→ 只有足够可信的机会才进入“值得真的去”的未来集合
```

最重要的新结论不是“网上有骗子”，而是：

> **当互联网让普通人更容易想象另一座城市、另一家公司、另一种工作时，它同时迫使人学习一种新的生活技能：在还没有真正走过去以前，判断远方是否值得相信。**

因此，普通人的“选择变多”不能只按职位数衡量。

更精确的单位是：

> **有多少选项同时满足：可见、可理解、可核验、可承担、可行动。**

## 下一步

下一轮如继续这一条链，优先找 2006—2012 年更原始的网络材料，而不是再增加泛泛的“防骗新闻”：

1. 可定位的高校 BBS 原帖或 archive capture，研究学生怎样问“这家公司怎么样”、别人怎样给证据；
2. 早期招聘网站企业发布规则、审核说明、投诉机制和安全帮助页；
3. 企业官网招聘页与转载招聘页之间的交叉核验模式；
4. 具体个案中“看见警告后决定不去面试”的同时代第一人称；
5. 非大学生群体——技校生、工厂工人、跨城务工者——通过什么渠道核验招工人和中介；
6. 继续比较 Monster、Craigslist、职业分类广告和欧洲公共就业服务中的可信度机制。

若找不到“核验成功从而避免移动”的材料，也应记录这一档案偏差：**被骗以后会留下新闻，成功避开一个可疑机会往往不会留下任何文档。**
