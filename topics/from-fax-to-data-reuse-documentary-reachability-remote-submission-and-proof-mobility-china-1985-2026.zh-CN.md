# 从传真到“数据替人跑”：文书可达性、远程提交与证明移动（中国，1985–2026）

## 研究问题

普通人能够离家、跨城求学、找工作、报名考试、办证和签约，不只取决于**人能不能移动、消息能不能移动**，还取决于另一件很容易被忽略的事：

> **一张必须被机构承认的纸，能不能在本人不亲自到场的情况下抵达、被识别、被接进流程，并最终产生有效状态。**

这篇专题追踪的不是“传真机技术史”，而是 **documentary reachability / 文书可达性**：申请表、简历、证明、合同、证件复印件等正式材料跨距离移动的能力，以及这项能力从传真、邮寄、E-mail、Web 表单、扫描上传，进一步转向电子签名、电子证照和后台数据复用以后，怎样改变普通人的可行动范围。

它与仓库既有专题的边界是：

- 邮政专题研究信件和信息延迟，本篇研究**需要进入制度流程的文书**；
- 电子邮件专题研究可携带地址和正式 inbox，本篇研究附件/表单是否真正进入申请、审核和证明链；
- 学历证明专题研究 credential verification，本篇关注更一般的“谁负责搬运证明”；
- 招聘、教育申请、政务服务都只是案例，研究对象是跨领域重复出现的**提交基础设施**。

## 一、先拆状态：文件“发过去了”不是一件事

一份远程材料至少可能经过：

`现实事实/资格`
→ `产生纸质或电子文书`
→ `找到正确接收端点`
→ `发送/上传`
→ `传输成功`
→ `对端实际收到`
→ `内容可读`
→ `能够识别是谁的材料`
→ `和已有申请/案件匹配`
→ `被工作人员或系统受理`
→ `真实性/资格审核`
→ `形成新的制度状态`
→ `需要时再核原件`
→ `最终完成`。

因此以后要坚持：

- `传真机报告发送成功 ≠ 对端材料已进入案件`；
- `E-mail 已投递 ≠ 附件已被打开、可读并匹配到申请人`；
- `Web 表单提交 ≠ 全部报名完成`；
- `扫描件存在 ≠ 原件真实性已核验`；
- `电子证照可调用 ≠ 所有场景都接受`；
- `电子签名具有法律制度基础 ≠ 某一具体业务已经接受电子签名`。

真正改变生活的不是“文件变成电子的”，而是整个链路里**有多少段不再需要本人充当快递员**。

## 二、1980s：传真把“纸的形状”送过电话线，但端点首先属于机构

### 2.1 1985 上海开放用户传真：文件可以直接从单位/家庭终端发出

中国电信博物馆对传真业务史的整理记录：上海市电报局 1984 年开放与东京等城市间的国际公众用户传真电报，1985 年 5 月 1 日开始开放用户传真（FAX）；装有符合要求传真设备的用户可以自行通过通信线路收发真迹传真，不再必须到电报局办理。

来源：中国电信博物馆，《传真技术发展史》相关馆史文章：
https://museum.chinatelecom.com.cn/yj/txkp/202207/t20220729_71073.html

**证据等级：A/B。** 机构博物馆依据行业史料的后期整理；能够确认业务制度和节点，不能证明普通家庭普及。

真正的新能力是：

> **document-image transport / 文书图像运输。**

传真不要求发送方把内容重新编码成电报码，也不要求接收方拥有同一套文字录入环境；表格、签名、手写批注和图形都可以整体扫描成图像，经电话网在远端重新印出。

但这绝不能写成“1985 年普通中国人已经可以在家传真”。

### 2.2 公共端点仍然重要：没有传真机的人也可能获得服务可及

《兰州市电信志》记录，兰州 1989 年 3 月 1 日开办公共传真业务，最初有中心广场电信营业大厅、武都路电信营业处和兰州饭店代办点 3 处；公众可以使用这些设备向国内外安装传真设备的对端发送图表和文字。与此同时当地也开放用户传真，到 1990 年用户传真发展到 215 户。

来源：兰州市地方志《电信志》PDF：
https://www.gsdfszw.org.cn/gssz_58/dyl_69/lzs_224/desejdxz/201707/P020170705346017355463.pdf

**证据等级：A。** 地方志基于邮电系统资料。

这形成了一个很重要的技术采用阶梯：

`技术存在`
→ `邮电机构有设备`
→ `普通人可到公共端点使用`
→ `单位安装`
→ `小企业/家庭办公室安装`
→ `日常流程围绕传真重构`。

它与公用电话、网吧、公共电脑终端有同样的方法论意义：

> **service access ≠ household ownership。**

一个人没有自己的机器，仍然可能通过营业厅、饭店、单位秘书室、复印打印服务等共享端点获得跨距离文书传输能力。

### 2.3 采用增长很快，但使用者结构不能从“用户数”倒推

1993 年《人民日报》同期报道引用邮电部统计：我国用户传真机从 1987 年约 8000 户增长到 1991 年约 5.8 万户。

同期报道存档镜像：
https://cn.govopendata.com/renminribao/1993/6/19/2/

中国电信博物馆的后期史料也记录了传真业务在 1980s 后期快速扩展。

**证据等级：B（同期报刊转录统计）+ B（机构后期整理）。**

这里的“户”不能翻译成家庭拥有率；当时大量终端显然属于机关、企事业单位和商业组织。对普通人的意义经常是**借用一个机构端点**，而不是住宅里拥有一台机器。

新增概念：

### **institutional-endpoint piggybacking / 机构端点搭载**

普通人通过学校、单位、邮电营业厅、旅馆或服务商拥有的通信终端，让自己的私人求职、报名或家庭事务进入远方机构。

## 三、海外前 Web 对照：传真改变的不是“有无通信”，而是完整文书的延迟

1987 年 *Christian Science Monitor* 的同期报道以一名波士顿行政助理为例：老板在纽约急需合同副本，办公室人员把合同送入传真机、拨到老板附近的传真端点，几分钟内对方取得副本。报道同时记录美国传真机销量从 1983 年约 5 万台增至 1987 年预计约 29.5 万台。

来源：
https://www.csmonitor.com/1987/0827/ffax.html

1990 年 *Washington Post* 又报道一家华盛顿律师事务所的传真机从一台增加到四台，并需要专职人员处理大量收发页；文章称美国 1989 年售出约 140 万台传真机、在用量升至约 300 万台。

来源：
https://www.washingtonpost.com/archive/business/1990/05/27/overwhelmed-with-fax-attacks/9e8498ab-ad8e-4c62-b858-af32b5e67618/

Smithsonian 保存的 GammaFax PC fax card 则证明 1985 年已经出现让个人电脑直接向传真机发送文档的商用路线。

来源：
https://americanhistory.si.edu/collections/object/nmah_1346900

**比较结论：**

中国并不特殊地“从纸直接跳到 Internet”。中国和美国都经历过一个相当长的阶段：

`纸/文字处理`
→ `扫描/PC 输出`
→ `电话网传真`
→ `远端重新得到纸`。

传真最重要的共同历史作用，是 **document-latency collapse / 文书延迟坍缩**：邮寄需要天数的纸面内容，可以在分钟尺度抵达。

但美国 1987 的办公室个案也提醒：速度提高并不会自动消灭劳动。传真机旁出现了找号码、拨号、重发、分拣、递送给正确员工的**新文书劳动**。

## 四、2005–2012：扩张型未来不是“全部在线”，而是多种提交路线同时存在

### 4.1 2005：法律开始承认“数据电文可以是书面形式”，但现实流程不会同时无纸化

《中华人民共和国电子签名法》于 2004 年 8 月通过、2005 年 4 月 1 日施行。法律明确规定，能够有形表现内容并可随时调取的数据电文可视为符合法律法规要求的书面形式；符合条件的数据电文可以满足原件形式要求，可靠电子签名在相应条件下具有制度效力。

官方文本：
https://www.cac.gov.cn/2004-08/28/c_126468489.htm

**证据等级：A。**

这提供了一个制度边界：

> 传真把**纸的图像**搬到远端；电子签名/数据电文则开始允许“电子状态本身”成为法律上有意义的文书。

但 `law permits electronic document ≠ every school/employer/government workflow accepts it`。

### 4.2 2007–2008：求职者真正面对的是“信函 / 传真 / E-mail / Web / 现场”并存

郑州大学第三附属医院 2007 年招聘公告明确允许应聘者通过**信函、传真或 E-mail** 报名并附简历，面试时仍需携带身份证、学历学位证、英语证书原件和复印件。

来源：郑州大学官方站：
https://www.zzu.edu.cn/info/1442/60061.htm

**证据等级：A。**

2008 年广东省实验动物监测所的一则校园招聘信息同样写明“将简历传真或发 E-mail”。

来源（应届生招聘档案，原信息注明来自中山大学就业网）：
https://archiver.yingjiesheng.com/job-000-330-498.html

**证据等级：B。**

这表明 2007–2008 的扩张型未来里，远程申请不是一个统一技术栈。应聘者可以根据自己手边拥有的端点选择：

- 邮件附件；
- 传真；
- 纸信；
- 招聘网站；
- 现场递交。

**route portfolio / 提交路线组合** 本身就是可执行性的来源：校园邮箱不好用，可以找传真；没有传真，可以 E-mail；正式证件最后再带到面试。

### 4.3 2008 河海大学：典型的“Web 生成 → 打印 → 传真/邮寄 → Web 查资格 → 线下核验”

河海大学 2008 年播音主持专业招生简章要求考生：

1. 先在学校招生网站网上报名；
2. 下载并打印系统生成的报名信息表；
3. 填写完整；
4. 在截止时间前**寄送、送达或传真**招生办；
5. 几天后再上招生网站查询报考资格；
6. 最终本人到校，携带身份证、照片和通知书参加考试。

官方招生简章：
https://zsw.hhu.edu.cn/zskx/471.html

学校同期新闻也保存了这一流程：
https://www.hhu.edu.cn/_t128/2008/0307/c187a145085/page.htm

**证据等级：A。**

这是非常典型的 **half-digital institutional workflow / 半数字制度流程**：

`Web 产生结构化申请`
→ `打印成纸`
→ `纸上补充/签署`
→ `传真把纸变成远端图像`
→ `工作人员再把它和线上记录匹配`
→ `Web 公布资格`
→ `人带原件到场`。

不能因为有“网上报名”四个字，就把 2008 年的申请经验想象成今天的全流程在线申请。

### 4.4 2008：有时传真甚至被用来降低地理不平等，但仍要求最后到场

广西出入境检验检疫系统 2008 年事业单位招聘的同期公开材料规定：外省考生可下载表格并通过传真报名，广西区内考生现场报名；传真申请者的资格审查结果通过 E-mail 反馈，但通过后仍需在指定日期现场确认、缴费并领取准考证。

同期材料存档：
https://www.job910.com/jobs/zhaopin-146161.html

**证据等级：B。** 当前可访问的是招聘信息二次存档，原主管部门网页仍待补。

这个案例说明传真提供的不是“永远不用旅行”，而是：

> **把第一次筛选推到远程，使只有通过初筛的人再承担长距离旅行。**

因此新增：

### **document-first mobility filtering / 文书先行的移动筛选**

材料先走，人后走。远程文书降低的是“为了知道自己有没有资格而先跑一趟”的成本，而不是把全部身体移动消灭。

## 五、2008 的普通生活侧证据：一个求职通道可以同时包含报纸、电话、短信、QQ、网站与传真

2008 年 2 月《东南快报》“找工专列”的同期报道记录：求职者可以通过记者电话、短信平台、网站留言、专设 QQ 和自动传真联系报社。一名下岗母亲在报道中谈到自己因女儿继续上学需要用钱而急着寻找财会工作。

来源（新浪转载同期报纸）：
https://news.sina.com.cn/c/2008-02-17/002413422317s.shtml

**证据等级：B；其中受访者为同时期第一人称，平台路线为同时期可观察事实。**

这条材料很重要，因为它阻止我们把通信技术史写成：

`传真结束 → Internet 开始`。

现实更像：

`报纸 + 电话 + 短信 + 传真 + QQ + Web`

同时运行。不同人选择的往往不是“最先进”技术，而是**手边最可靠、最熟悉、最容易得到反馈的端点**。

## 六、2015–2019：从“把材料送过去”转向“平台能不能直接复用已有材料”

### 6.1 “网上可办”仍可能意味着上传一堆自己制作的电子复印件

第一阶段的数字化往往只是把：

`复印 → 装档案袋 → 乘车 → 窗口交件`

改成：

`拍照/扫描 → 改文件大小和格式 → 找 portal → 注册登录 → 上传 → 等审核`。

空间成本下降了，但出现了 **document-format labor / 文书格式劳动**：扫描、命名、压缩、转 PDF/JPEG、补传、等待审核。

这篇专题暂不把这一点量化为全国普遍经验；它是从大量具体业务流程中提出的 D 级机制假说，未来需要以用户日志、帮助帖和原始 portal 说明继续验证。

### 6.2 2019 上海“一网通办”：关键变化开始从“上传”变成“数据复用”

2019 年《中国青年报》报道上海“一网通办”：已归集的用户信息可预填，已归集的证照材料可以免交；部分户籍、社保、出入境等证明可以在线申请、自动比对并生成电子证明。

来源：人民网转载《中国青年报》：
https://gongyi.people.com.cn/n1/2019/0522/c151132-31097542.html

同年上海“一网通办”报道中，市民毛翔登录个人主页后直接获得港澳通行证即将到期提醒并在线预约；系统个人主页开始汇聚身份、婚姻、医保、养老金、证照和办事历史等信息。

来源：新民网 / 瞭望：
https://shanghai.xinmin.cn/xmsq/2019/03/02/31494780.html

**证据等级：B（同期报道，个案为同时期自述/观察）。**

这里出现真正不同的结构：

`本人拿一张证明给 B 部门`

逐渐可能变成：

`B 部门在本人授权/制度规则下查询 A 系统已经持有的记录`。

新增概念：

### **document mobility → record mobility / 文书移动 → 记录移动**

这不是简单的“传真升级成 PDF”。责任开始从个人反复搬运证明，部分转移到机构之间的数据交换。

### 6.3 2019 的反例：一个 App 并不自动等于一体化

2019 年人民网讨论“一次不用跑”时也明确提醒，如果每个部门都各做一个 App，反而会让群众在 App 海洋里重新承担寻找入口的劳动；线上服务仍需兼容老年人和残障人士。

来源：
https://politics.people.com.cn/n1/2019/0506/c1001-31066135.html

所以：

`digital submission available ≠ accessible to every person`

`many portals ≠ lower total coordination cost`。

拥堵型未来的一部分麻烦恰恰是：**人不用排一个窗口，却可能要维护多个账户、App、验证码和文件版本。**

## 七、2020–2022：偶发型未来把远程文书从便利设施变成连续性基础设施

2020 年 3 月，教育部在疫情背景下要求高校毕业生就业服务更多转向网上招聘、网上面试和**网上签约**。

来源：教育部：
https://www.moe.gov.cn/jyb_xwfb/xw_zt/moe_357/jyzt_2020n/2020_zt09/jiaoyubu/202003/t20200305_427818.html

同月西安曲江新区的同期报道记录，田先生通过政务服务微信群向工作人员递交资料，完成“不见面审批”，办好的回单再送到小区门口。

来源：人民网陕西：
https://sn.people.com.cn/n2/2020/0311/c380804-33868498.html

宁波 2020 年“公证 E 通”则把申请、身份认证、签名、材料递交、缴费等环节搬到线上，公证书再免费寄送；复杂事项仍保留线下审查。

来源：平安浙江：
https://www.pazjw.gov.cn/wangqunxinxi/ningboshi/202008/t20200814_21255675.shtml

**证据等级：A/B。**

这里的关键变化不是“线上更方便”，而是：

### **documentary continuity infrastructure / 文书连续性基础设施**

当窗口、校园招聘会、跨城旅行本身可能突然停止时，远程提交、电子签署和快递返件开始决定一个制度流程能不能**继续存在**。

偶发型未来的时间感因此增加了一项：不仅要担心“我有没有材料”，还要担心**原本假设可以亲自去完成的环节，明天会不会还开放**。

## 八、2023–2026：防守型未来开始追求“少交原件、少复制、可授权、可追踪”

2024 年浙江临海“免证速办”的同期报道里，市民在未携带实体证件的情况下，通过电子身份核验完成学历信息更正。当地系统在调用身份证电子证照时，会给证件信息加注时间和“仅用于办理某事项”的用途底纹，并记录调取痕迹；企业负责人还可以通过数字授权把特定事项委托给员工办理，而不必把实体身份证直接交给受托人。

来源：人民网 / 台州日报：
https://politics.people.com.cn/n1/2024/1028/c458474-40348461.html

这带来一个此前传真时代不存在的目标：

### **proof minimization / 证明最小化**

不是让个人复制、扫描、上传越来越多证明，而是尽量：

- 少携带原件；
- 少生成永久复印件；
- 只授权当前事项需要的数据；
- 给调用行为留下用途与时间痕迹；
- 让机构直接验证而非让个人反复搬运。

这非常符合“防守型未来”的语法：便利之外，更重视**泄露面、遗失风险、授权边界和以后能不能追责**。

但反例必须保留：系统间并非全部互认，电子身份并非所有高强度认证场景都能替代实体证件，手机故障、账号问题、数据错误仍可能让“免材料”重新退回人工窗口。

## 九、四种未来里的文书观

### 2005–2012：扩张型未来

典型问题：

> “我能不能不先跑到那座城市，就把简历、报名表或申请送进去？”

关键词：

- 传真 / E-mail / Web / 邮寄并行；
- 远程初筛；
- 文书先走、人后走；
- 远方机构变得可申请；
- 但原件、面试、考试仍常需身体到场。

### 2015–2019：拥堵型未来

典型问题：

> “为什么每个部门都让我再注册一次、再传一次同一张证？”

关键词：

- portal 增多；
- 扫描上传；
- 文件格式劳动；
- 多账户协调；
- 从“网上可办”转向“一网通办”和数据复用。

### 2020–2022：偶发型未来

典型问题：

> “如果我根本不能去现场，这件事还能不能继续办？”

关键词：

- 不见面审批；
- 网上面试/签约；
- 线上身份认证；
- 快递返件；
- 远程文书成为系统连续性的组成部分。

### 2023–2026：防守型未来

典型问题：

> “能不能既办成，又少交一份身份证复印件、少暴露一次原始材料，并留下授权痕迹？”

关键词：

- 电子证照；
- 数据共享；
- 用途限定；
- 数字委托；
- proof minimization；
- 数据错误与系统不可用时保留人工退路。

## 十、它改变了我们对“人怎么活着”的哪一点理解

### 10.1 地理自由的一部分其实是“文件先能过去”

一个学生能够报考外地学校，一个求职者能够申请外省岗位，一个流动人口能够异地办证，不只是因为火车更快、电话更便宜、Internet 更普及。

还因为制度逐渐允许：

> **材料先跨过去，本人只有在真正需要的时候再跨过去。**

### 10.2 “无纸化”不是正确的长期主线

更准确的谱系是：

`本人搬纸`
→ `邮政搬纸`
→ `传真搬纸的图像`
→ `E-mail/Web 搬电子文件`
→ `电子签名让电子状态本身成为文书`
→ `机构直接复用数据，连“搬一份文件”本身都部分消失`。

真正下降的是 **document-courier labor / 文书搬运劳动**。

### 10.3 历史上“普通人提交过什么”非常难保存

公开网络最容易留下：

- 招生简章；
- 招聘公告；
- 传真号码；
- 下载表格；
- 上传说明；
- 电子证照帮助页。

最难留下：

- 某人的传真是否真的打印完整；
- 工作人员是否把散页配到了正确档案；
- 某个附件是否损坏；
- 某次上传是否在截止前 commit；
- 某份材料为何被退回；
- 某人因为无法传真/扫描/登录而根本没有申请。

因此历史档案会天然高估“制度设计出来的流程”，低估**现实提交失败率和补材料劳动**。

## 十一、反例与后见之明风险

1. **不要把传真浪漫化成民主化技术。** 早期设备主要集中在机构和商业环境；公共端点存在不等于便宜、近便或人人会用。
2. **不要把“网上报名”倒写成全流程数字化。** 2008 河海大学案例恰好证明 Web、打印、传真/邮寄、现场原件是一个系统。
3. **不要把电子签名法出台等同于实际采用。** 法律可用只是基础，不代表每一业务接受。
4. **不要把电子证照等同于没有身份门槛。** 身份认证仍然存在，只是证明方式改变。
5. **不要把减少材料等同于减少全部劳动。** 登录、验证码、文件转换、数据纠错和隐私管理可以成为新的劳动。
6. **不要拿今天“拍照上传”的习惯倒推 2008。** 当时摄像头、扫描仪、网络速度、浏览器和文件格式环境都不同。

## 十二、尚未确定

下一步最值得找的不是更多“传真机销量”，而是：

- 1988–1998 普通人实际使用邮电公共传真点的一手日记、收费表或操作说明；
- 1995–2005 打字复印店/校园服务点替个人收发传真的价目与第一人称材料；
- 2000s 求职者关于“传真简历是否收到、是否重发”的同时期论坛/博客记录；
- 2005–2012 典型 Web + fax 混合申请系统的真实历史 capture；
- 2010s 从扫描上传转向电子证照复用之前，普通人承担了多少“拍照、压缩、重传”劳动；
- 数据复用以后，错误记录如何纠正，以及没有智能手机/稳定数字身份的人怎样走人工替代路径。

## 十三、一个可复用的 documentary-reachability ledger

以后做个人生命史时，可以按一次真实事务记录：

1. 当事人要向哪一个远方机构证明什么？
2. 原始证据在谁手上、是什么介质？
3. 当时可选路线：亲送 / 邮寄 / 传真 / E-mail / Web / 代理人？
4. 每条路线需要哪些设备、账户、费用和技能？
5. 发送以后有没有回执？
6. 谁负责确认“机构真的收到了”？
7. 是否还要寄/带原件？
8. 哪一步第一次允许本人不用跨城？
9. 哪一步后来从“上传我的证明”变成“系统直接查记录”？
10. 失败时有没有线下/人工 fallback？
11. 最终这项变化让当事人多出哪一种真实可走的人生路线？

这个 ledger 可以直接与就业、教育、迁移、住房、照护和证件专题交叉使用。

## 核心判断

> **一个时代给普通人的远方机会，不只由远方有没有学校、工作和制度入口决定。还要看一张决定资格的纸——以及后来那条记录——能不能在本人尚未到达之前，先替她抵达那里。**
