# 吃饭怎样被外包：送餐、网上订餐、外卖劳动与“厨房可选性”——中国，1993–2025

> 状态：研究笔记；用于 `how-people-lived` 的 food / work / housing / time-use / migration / Internet / life-horizon 交叉研究。
>
> 核心问题：**一个普通人每天怎样获得一顿饭？当买菜、做饭、出门、排队、洗碗中的一部分被转交给食堂、快餐店、电话送餐、网站、即时通信工具或外卖平台以后，独居、加班、搬家、求学、兼职和城市生活的可执行边界发生了什么变化？互联网改变的是“有没有送餐”，还是发现、下单、调度、支付和评价中的某几层？**

---

## 0. 本篇新增的不是“外卖平台发展史”

仓库已经讨论过：

- 家务与照护外部化；
- 就业和兼职路线；
- 合租、独居与住房可逆性；
- 信息发现、同城匹配与平台化；
- 疫情下生活流程的偶发性；
- 通勤、远程工作与时间预算。

但这些专题仍然容易把“吃饭”当成自然发生的背景。

现实中，一顿饭至少可能来自：

```text
自己买菜做饭
家人做饭
学校 / 单位食堂
街边店 / 餐馆堂食
熟人代买
电话叫餐
网站下单 + 电话确认
网站直接下单
QQ / MSN 等即时通信下单
平台 / App 外卖
便利店热餐
平台买菜 + 自己做饭
预制 / 半成品 + 自己加热
若干渠道按当天时间、价格和精力切换
```

所以真正需要研究的是 **meal-provisioning topology（每日供餐拓扑）**：

> 谁负责买、做、送、付钱、等候、清洗，以及这些动作发生在什么地方、耗费谁的时间。

Internet 只是其中一层。

---

## 1. 新变量一：meal-time externalization

这里暂用 **meal-time externalization（用餐时间外部化）** 表示：

> 一个人把原本需要自己投入的采购、烹饪、出门、排队或清洁时间中的一部分，转移给食堂、餐馆、送餐员、便利店或平台组织起来的服务链。

它不等于“更懒”。

对一个具体人，外部供餐可能决定：

```text
午休 45 分钟时能不能吃到热饭
晚下班以后是否还必须买菜做饭
刚搬进出租屋、厨房很差时是否仍能独立生活
备考 / 加班期间能否把一部分家务时间转成学习或休息
一个人住时是否值得为一顿饭完整开火
没有食堂的工作地点是否仍可维持固定就餐
```

所以一顿外卖购买的不只是食物，也可能是 **time bundle（时间包）**。

但必须同时保留：

> `delivery exists ≠ delivery is affordable`  
> `order placed ≠ meal arrives on time`  
> `meal arrives ≠ food is acceptable / safe`

---

## 2. 新变量二：kitchen optionality

现代住房讨论通常默认“一个独立住户需要一个能正常做饭的厨房”。

现实却存在另一种生活路线：

> **厨房仍然存在，但使用频率下降；甚至在部分时间段，完整厨房从“每日刚需”变成“可选能力”。**

这里暂称 **kitchen optionality（厨房可选性）**。

它不是“厨房消失”。

更准确的是：

```text
食堂 / 便利店 / 餐馆 / 电话送餐 / 外卖越稳定
→ 一个人越可以暂时容忍厨房小、厨具少、不会做饭、没有时间做饭
→ 独居 / 合租 / 临时迁移的启动成本下降一部分
```

反方向也成立：

```text
平台失效 / 餐馆关闭 / 配送不可达 / 价格上涨 / 食品安全担忧
→ 自己做饭的能力重新变得重要
```

因此 **kitchen optionality ≠ cooking obsolescence**。

---

## 3. 新变量三：meal latency 与 delivery radius

一顿饭是否“可订”还不够。

普通人实际关心的是：

- 现在下单，多久能吃到；
- 我的楼 / 学校 / 小区是不是在配送范围；
- 午餐高峰是否还能准时；
- 最低起送价是多少；
- 配送费多少；
- 雨雪、交通、门禁是否改变结果；
- 店铺是否还接单；
- 菜单上的菜是否真的有货。

所以至少需要两个变量：

### meal latency

`决定吃什么 → 下单 / 叫餐 → 商家接受 → 制作 → 配送 → 真正吃到`

的总时延。

### delivery radius

不是地图上的理论距离，而是：

> 某个地址在某个时间段是否能被具体商家 / 配送系统真实服务。

因此：

> **menu visibility ≠ delivery reachability**。

# 第一部分：大众 Internet 以前，送餐本来就存在

## 4. 1993：电话、摩托车、自行车已经能构成“无店铺供餐”

2003 年《工人日报》对丽华快餐创始人蒋建平的采访回顾：1993 年他离开粮管所，在常州以几千元起步做快餐，早期自己骑摩托送餐；报道还说企业较早推出“一份起送、随叫随到”。同年另一份采访进一步回忆起步条件为一辆摩托车、两辆自行车。

来源：

- 《创业故事：“丽华”叫板洋快餐》，《工人日报》，2003-10-12：<https://news.sina.com.cn/c/2003-10-12/1019903029s.shtml>
- 《送餐业的领跑者：专访丽华快餐董事长蒋建平》，2003-07-25：<https://finance.sina.com.cn/crz/20030725/1534382256.shtml>

### 证据等级

- 两篇都是 **2003 年同期采访对 1993 年创业过程的回顾**；
- 对 2003 年企业状态属于 B 级同期媒体材料；
- 对 1993 年细节应按 **C/B 混合：十年后的当事人回忆，经同期独立报道交叉** 使用；
- 不能拿创始人口述直接推出 1993 年普通城市居民已经普遍叫外卖。

### 4.1 对 Internet 史的边界意义

这条证据足以排除一种错误叙述：

> “有了网站 / App 才有送餐。”

1990 年代初，一套基本送餐系统已经可以由：

```text
公开电话号码
+ 电话接单
+ 厨房
+ 人工调度
+ 摩托车 / 自行车
+ 地址识别
```

组成。

Web 后来改变的是其中的发现、菜单浏览、下单、排队、匹配、记录与支付，而不是发明最后一公里本身。

---

## 5. 2003 SARS：送餐也可以成为“生活连续性”基础设施

2005 年回顾丽华的报道说，2003 年 SARS 期间，北京部分定点医疗机构由其供餐，同时普通居民和单位的订餐也增加。该材料由企业采访与媒体重构组成，不能据此精确估算全市居民行为，但它至少说明：

> 在堂食、出行或机构后勤受到扰动时，已经存在的专业送餐网络可以临时承担 continuity function。

来源：

- 《今天，你“丽华”了吗？》，2005-07-27：<https://news.sohu.com/20050727/n226465975.shtml>

这为 2020 年以后的平台配送提供了前史：

**危机使配送重要，不等于危机发明配送。**

# 第二部分：2004–2008，Web 开始改写“怎么叫到饭”

## 6. 2004：公开菜单 + Web 下单进入既有送餐链

2004 年 8 月《新京报》报道丽华在北京推出网上订餐。记者实际查看订购网站，看到 6–20 元不同档次菜单；报道给出的承诺是半小时内送达，并称还可以替异地亲友下单。

来源：

- 《中外快餐连锁争抢京城市场》，《新京报》，2004-08-05：<https://news.sina.com.cn/o/2004-08-05/09023299815s.shtml>

### 证据等级

**B：同期记者页面观察 + 企业说法。**

本轮没有取得 2004 年该订餐页的可验证 archive capture，所以：

- 可以证明记者当时观察到网上菜单与订餐功能；
- 不应声称已经恢复 2004 年原始 HTML、字符集、浏览器兼容性或真实订单数据库。

### 6.1 Internet 插入的位置

更准确的链条是：

```text
旧：电话 → 接线 / 记录 → 厨房 → 配送
新：Web 菜单 / 表单 → 后台 / 人工接单 → 厨房 → 配送
```

最后一公里依旧完全物理。

因此：

> **online order ≠ dematerialized meal**。

---

## 7. 2006：真正重要的变化是“先按地点筛可送餐商家”

2006 年《每日经济新闻》报道“3797想吃就吃”时，给出了非常具体的用户流程：

1. 登录网站；
2. 输入写字楼或小区名称；
3. 得到外卖店列表；
4. 进入某店；
5. 看带价格的菜单；
6. 点击加入购物车；
7. 输入具体地址；
8. 等待送达。

来源：

- 《网上订餐市场瓶颈渐现》，《每日经济新闻》，2006-08-15：<https://tech.sina.com.cn/i/2006-08-15/09581086122.shtml>

### 7.1 新增的是 service-area addressability

电话时代也能送餐，但用户通常要先知道“哪家店可能送到我这里”。

按写字楼 / 小区检索的 Web，把问题改成：

> **“我在这里，现在有哪些饭能送到？”**

这是一种 **service-area addressability（服务区域可寻址性）**。

它把商家发现与地理可达性第一次明显绑在同一查询动作里。

### 7.2 当时的瓶颈已经不是单纯“有没有网站”

同篇报道同时指出物流、信用和技术丢单问题。

这提醒我们：

```text
页面可打开
≠ 订单会进入商家
≠ 商家会确认
≠ 配送人员会准时找到地址
```

网站越成熟，物理执行层反而越值得单独研究。

---

## 8. 2006–2007：Web、电话、MSN 并存，而不是整齐替代

2007 年《北京晚报》记者亲自体验丽华的“MSN 订餐机器人”：添加账号后，对话框中弹出菜单，可以在即时通信工具里完成选餐。报道同时判断，网上订餐当时还没有被白领普遍接受。

来源：

- 《网络企业争食白领午餐市场 网上订餐画饼难充饥》，《北京晚报》，2007-08-29：<https://www.chinanews.com.cn/cj/xfsh/news/2007/08-29/1013780.shtml>

这里出现的是：

```text
电话
Web
MSN
线下门店 / 食堂
```

长期重叠。

所以旧网史不能写成：

> `telephone → website → app`

更接近：

> **不同入口不断叠加，而厨房和配送仍是同一个物理瓶颈。**

## 9. 2008：网上送餐本身也成为一条毕业后的创业路线

2008 年报道记录中国人民大学毕业生叶路春：他毕业后没有继续一份培训主管工作，而是与同学继续做大学期间用 2000 元搭起来的订餐网站；他们白天给附近写字楼送盒饭，晚上做大学生夜宵，报道现场描述二百多份盒饭通过三轮车配送。

来源：

- 《名牌大学毕业生网上揽顾客卖盒饭》，2008-03-04：<https://language.chinadaily.com.cn/campus/2008-03/04/content_6506743.htm>

### 证据等级

**B：同期媒体报道，内含同时性第一人称。**

不能从一个创业个案推出 2008 年毕业生普遍把互联网创业当作可行路线。

### 9.1 对“扩张型未来”的意义

这条材料同时连接两端：

消费者端：

> 网站降低附近学生 / 白领发现服务的成本。

劳动与创业端：

> 一个毕业生可以用很低的网站启动成本 + 非正式物流，把“提供午饭 / 夜宵”做成工作路线。

但真正的规模瓶颈仍然是：

- 厨房；
- 保温；
- 三轮车；
- 午餐峰值；
- 人工配送。

因此 2005–2012 的扩张不是“互联网让一切虚拟化”，而是：

> **数字入口让本地小型服务更容易被发现和组织，物理劳动则继续决定能扩张到哪里。**

# 第三部分：2015–2019，选择很多以后，稀缺的是时间、注意力和可执行性

## 10. 2018：即使在白领样本里，外卖也没有替代食堂和家庭厨房

一份 2018 年白领膳食相关报道援引《中国白领膳食健康白皮书》：午餐主要在单位食堂解决的比例明显高于外卖，外卖只是其中一种渠道；早餐和晚餐仍有大量人在家完成。

这类行业 / 协会调查的抽样与定义需要回查原报告，所以本篇不把百分比外推为全国白领人口参数。

它的价值主要是反例：

> **platform maturity ≠ single provisioning regime**。

即使 App 已经成熟，一个人的一周也可能是：

```text
工作日午餐食堂
+ 加班夜晚外卖
+ 周末自己做饭
+ 早餐便利店
```

供餐拓扑变得更复杂，而不是只剩一个入口。

参考：

- 《中国城市白领膳食健康白皮书》相关同期报道，2018：<https://www.21jingji.com/article/20180517/herald/>

（本轮未取得该页面稳定抓取；此条只作为待加强的结构性反例，不承担关键数字。）

## 11. 2019：独居 / 白领生活里，“不做饭”可以是一种时间预算结果

2019 年关于“空巢青年”的同期报道描述：一些独居年轻白领早餐在便利店解决，午餐、晚餐在便利店热餐与外卖之间切换；报道援引的样本还显示，部分年轻受访者在家做饭频率较低。

来源：

- 《餐饮消费趋势研究：“空巢青年”不愿做饭 便利店成“城市厨房”》，2019-05-19：<https://www.nbd.com.cn/articles/2019-05-19/1333110.html>

### 证据等级

**B：同期媒体 + 行业调研重述。**

限制：

- “空巢青年”是媒体分类，不是稳定人口学类别；
- 样本不能外推为所有 90 后；
- “不愿做饭”不能自动解释成懒惰。

### 11.1 新变量：meal-energy budget

做饭需要的不只有分钟数，还包括：

- 下班后决定吃什么；
- 买菜；
- 处理食材；
- 清洁；
- 剩余食材管理；
- 冰箱与厨具；
- 一个人做一份饭的规模不经济。

所以“拥堵型未来”里的晚餐问题可以写成：

> **钱、时间、精力和健康之间的日常微型配置。**

外卖让一个人可以用钱买回部分时间，但不会消灭食品安全、价格与营养问题。

## 12. 2019：外卖平台同时创造了一条“进入陌生城市的短期工作路线”

2019 年饿了么发布的大学生骑手报告，由多家同期媒体转述。报告称当年暑期有 9896 名大学生新加入平台兼职骑手；其中一些去陌生城市边送单边熟悉城市。

一名来自武汉、即将到上海读研的学生说，他提前到上海做骑手，希望先熟悉这座未来至少生活三年的城市，同时赚生活费。

来源：

- 每日经济新闻，2019-08-28：<https://www.nbd.com.cn/articles/2019-08-28/1366866.html>
- 《中国城市报》，2019-09-02：<http://paper.people.com.cn/zgcsb/html/2019-09/02/content_1944406.htm>

### 证据等级

- 平台报告：**B，但有企业样本与宣传选择偏差**；
- 媒体中的学生话语：**同时性第一人称嵌入 B 级材料**；
- 多家报道大体来自同一平台报告，不能当作多个独立 evidence family。

### 12.1 新的生活路线：delivery-mediated city entry

这名学生的路线不是：

```text
来到城市 → 先找到正式长期工作 → 才开始生活
```

而是：

```text
研究生入学前
→ 提前进入陌生城市
→ 用即时配送做短期收入
→ 骑行过程中熟悉道路与城市
→ 再进入正式学生身份
```

这是一种 **delivery-mediated city entry（通过配送劳动进入城市）**。

它不意味着骑手工作普遍轻松，也不能用大学生暑期样本代表长期职业骑手；但它确实新增了一种“临时劳动 + 城市学习 + 迁移过渡”的组合路线。

# 第四部分：2020–2022，供餐系统变成生活连续性的显性问题

## 13. 2020：餐馆关门以后，平台可能不是送“成品饭”，而是送“做饭能力”

2020 年 3 月《中国青年报》一项 3004 人问卷及采访记录了疫情初期的“云买菜”。

一名北京受访者说，疫情最严重时，她和丈夫减少去超市，每晚在电商平台下单食材，第二天早晨送到；有一次想吃火锅而餐馆没开，就把锅底与生鲜一起在线购齐，第二天在家吃。

另一名 23 岁、刚工作的受访者独自在家做饭，同时通过视频与朋友“云做饭”“云聚会”。

来源：

- 中国青年报 / 央视网转载，2020-03-26：<https://news.cctv.com/2020/03/26/ARTINJjUFFoQgLzsTTl21zPs200326.shtml>
- 新华网转载：<https://www.xinhuanet.com/politics/2020-03/26/c_1125768559.htm>

### 证据等级

**B：同期调查与第一人称采访。**

### 13.1 “偶发型未来”的新机制：provisioning-mode switching

疫情并没有只让“外卖更多”。

它还让一些家庭发生：

```text
堂食 / 菜市场
→ 平台买原料
→ 家里烹饪
```

也就是说，数字基础设施可以保留的是 **采购能力**，而不是固定保留一种就餐形式。

这里应该区分：

- cooked-meal delivery；
- grocery delivery；
- home cooking；
- social eating / remote companionship。

真正的 resilience 来自 **mode switching（模式切换）**，不是单个平台。

---

# 第五部分：2023–2026，“防守型未来”不是不点外卖，而是更频繁地算账与核验

## 14. 2025：高频外卖可以与卫生担忧、筛商家、优惠计算同时存在

2025 年《中国青年报》对 1335 名受访者的调查中，74.1% 表示每周至少点一次外卖，70.6% 表示最关心卫生安全。该调查由中国青年报社社会调查中心与问卷网合作，不能直接外推为全国青年人口比例。

真正有生活史价值的是同期第一人称：

- 一名 90 后每周约五天点外卖，有时只是因为不想做饭，同时会避开自己怀疑为预制的菜；
- 另一名 90 后工作忙时两三天点一次，遇过展示与实物不符后开始更认真筛选商家信息；
- 一名 00 后酒店厨师因为工作中已经长时间做饭，回家后每天仍会点一两顿外卖，并特别在意后厨卫生；
- 另一名 00 后几乎每天点，但会计算满减、优惠券和配送费。

来源：

- 《超七成受访者点外卖最关心卫生安全》，《中国青年报》，2025-12-04：<https://zqb.cyol.com/pc/content/202512/04/content_419531.html>
- 中国青年报客户端，2025-11-18：<https://m.cyol.com/gb/articles/2025-11/18/content_YOMJj4umpZ.html>

### 证据等级

**B：同期媒体调查 + 同时性第一人称。**

### 14.1 防守型不是“缩回家做饭”

同一个人完全可能同时做三件事：

```text
继续高频使用外卖
+ 更关注卫生 / 商家真实性
+ 更认真计算优惠与配送成本
```

所以本篇只提出一个较窄的候选机制：

> **meal-cost / trust hedging（吃饭成本与信任对冲）**。

未来不确定感增加时，普通人未必放弃便利，而是更频繁地在：

- 自己做；
- 食堂；
- 便利店；
- 低价外卖；
- 更可信但更贵的店；
- 优惠券与满减；

之间切换。

这比“消费降级”更接近实际动作。

---

## 15. 当前边界：外卖已经是大规模基础设施，但仍不能把网民比例当成每个人的日常频率

CNNIC 2025 年发布的第 55 次《中国互联网络发展状况统计报告》显示，2024 年底中国网民规模为 11.08 亿、互联网普及率 78.6%；同期公开报道援引该报告称，网络外卖用户约 5.92 亿，占网民 53.4%。

来源：

- CNNIC 官方发布页，2025-01-17：<https://www3.cnnic.cn/n4/2025/0117/c88-11229.html>

本篇只把这一数字用来判断 **mass-scale availability / use**，不把它写成：

> “53.4% 中国人每天靠外卖吃饭。”

原因包括：

- denominator 是网民，不是全国人口；
- “网络外卖用户”是统计期内使用者，不等于高频用户；
- 地区、年龄、收入和工作场景差异仍然很大。

# 第六部分：海外对照——Web 不是第一次把“食品采购”接进网络

## 16. 法国 Minitel：1980 年代已经出现网络化同日送货

IEEE Spectrum 对 Minitel 史的高质量回顾指出：1983 年已有 `3615 TMK / Tele-Market`，巴黎用户可通过 Minitel 订购杂货并同日送达。

来源：

- Julien Mailland / Kevin Driscoll, “Minitel: The Online World France Built Before the Web,” IEEE Spectrum, 2017：<https://spectrum.ieee.org/minitel-the-online-world-france-built-before-the-web>

这不是同时代来源，所以此项功能按 **C/B：后来的高质量技术史研究** 使用。

为了判断它是不是“少数极客玩具”，还需看同时代覆盖。1988 年《世界报》援引法国电信年度数据：1987 年新装约 113.6 万台 Minitel，总量达到约 337.3 万台，相当于电话订户的 14%；在家或工作场所可接触到 Minitel 的范围更广，但仍绝不是所有法国人都在使用。

来源：

- *Le Monde*, 1988-04-21：<https://www.lemonde.fr/archives/article/1988/04/21/reflux-des-messageries-hausse-des-services-professionnels-le-deuxieme-souffle-du-minitel_4102726_1819218.html>

### 16.1 可比较之处

中国 2000 年代网上订餐与法国 1980 年代 Minitel 共同说明：

> **networked food provisioning predates the modern smartphone platform.**

共同问题一直是：

- 菜 / 商品目录怎样展示；
- 地址能否服务；
- 谁把请求变成真实拣货 / 做饭；
- 最后一公里由谁完成；
- 订单结果如何确认。

### 16.2 不可混同之处

不能因此说“中国网上订餐只是复制 Minitel”。

两边在：

- 终端拥有模式；
- 电信计费；
- 城市密度；
- 餐饮结构；
- 自行车 / 摩托车 / 电动车配送；
- 即时通信与移动支付；
- 平台劳动组织；

上都不同。

比较的价值是把 **Web/App 特有现象** 与 **网络化本地服务的一般机制** 分开。

# 第七部分：把四种“未来”放回一张表

| 时期 | 同期证据中的主要动作 | 本篇新增机制 | 不能写成 |
|---|---|---|---|
| 2005–2012 扩张型未来 | 建小网站、给校园/写字楼送餐；Web、电话、MSN 叠加 | 本地服务 discovery 扩张；低成本创业入口；service-area addressability | “当时人人已经网上点餐” |
| 2015–2019 拥堵型未来 | 食堂、便利店、外卖、自己做饭并存；大学生做兼职骑手进入陌生城市 | meal-energy budget；delivery-mediated city entry | “年轻人都不做饭 / 都去送外卖” |
| 2020–2022 偶发型未来 | 堂食受阻时改为平台买菜、家中做饭、远程一起吃 | provisioning-mode switching | “疫情只推动成品外卖” |
| 2023–2026 防守型未来 | 高频点餐与卫生筛选、价格/优惠计算并存 | meal-cost / trust hedging | “现在大家只是消费降级 / 全部回家做饭” |

四个阶段并不是四种人格。

它们描述的是：

> **同一个人安排下一顿饭时，面对的基础设施、时间约束、风险与可替代路径发生了变化。**

# 第九部分：反例与停止过度解释

## 17. Internet 并没有自动缩短全部吃饭时间

如果发生：

- 午餐高峰拥堵；
- 商家爆单；
- 配送地址难找；
- 小区 / 校园门禁；
- 菜品售罄；
- 天气恶劣；
- 退款 / 重送；

那么数字下单更快，不代表 **meal latency** 更短。

## 18. 点外卖不一定比做饭贵，也不一定更便宜

必须按具体：

- 食材量；
- 一人 / 多人；
- 厨房条件；
- 买菜路程；
- 剩余食材浪费；
- 配送费 / 满减；
- 时间机会成本；

判断。

本篇不设一个跨时期统一结论。

## 19. “不会做饭”与“选择不做”不同

一个人可能：

- 会做，但下班没精力；
- 会做，但一人份不划算；
- 不会做；
- 厨房条件差；
- 工作包餐；
- 今天点外卖、明天做饭。

历史研究必须保留这些不同路径。

## 20. 平台订单量不能直接等于生活依赖

一个人偶尔点奶茶、每天点两餐、只在加班时点餐，都会进入“外卖用户”统计。

因此：

> `user count ≠ meal share ≠ dependence`。

# 第十部分：后见之明风险

1. **不要把 1993 写成“没有互联网所以没有外卖”。** 电话送餐已经存在。
2. **不要把 2004 一个订餐网站写成普通家庭已经普遍网上点餐。** 当时接入、用户结构与习惯仍有显著限制。
3. **不要把网站菜单写成真实厨房库存。** 历史页面最多先证明公开展示。
4. **不要把 2008 个案写成“大学生创业黄金时代”的代表。** 它只能证明路线存在。
5. **不要把 2019 平台大学生样本写成所有骑手。** 暑期兼职与长期职业劳动不同。
6. **不要把 2020 写成“外卖战胜做饭”。** 同期证据恰恰显示平台买菜 + 自己做饭也很重要。
7. **不要把 2025 对价格与卫生的计算直接命名为全民悲观。** 这只是防守型未来中的一个可检验候选机制。
8. **不要把今天的 App 逻辑倒投给旧 Web。** 早期网上订餐常与电话、MSN、人工接单和线下现金等共同运行。

---

# 第十一部分：已证实 / 可合理推断 / 尚不知道

## 已证实

- 专业送餐在中国大众 Web 以前已存在，电话 + 人工配送足以形成完整服务。
- 2004–2008 中国城市中已有同期媒体观察到 Web 菜单、在线下单、按写字楼 / 小区检索和 MSN 订餐等形式。
- 2008 有毕业生把校园订餐网站继续发展为毕业后的创业路线。
- 2019 平台报告与同期采访保存了大学生用骑手兼职熟悉即将迁入城市的具体路径。
- 2020 同期第一人称显示，疫情中数字采购可以支持“平台买食材 + 家中做饭”，而不只是成品外卖。
- 2025 同期第一人称显示，高频外卖可以与卫生核验、商家筛选和优惠计算同时存在。
- 法国 Minitel 在 Web 以前已经出现网络化食品 / 杂货订购与同日配送服务。

## 可合理推断

- Internet / 平台降低了本地商家发现与菜单浏览成本，并逐步提高服务区域的可查询性。
- 稳定外部供餐会降低部分独居、加班和临时居住场景中“必须天天开火”的要求。
- 成熟配送系统既是消费者时间基础设施，也是新的城市劳动与迁移接口。
- 生活韧性更多来自多种供餐方式之间可切换，而不是依赖单一平台。

## 尚不知道

- 2004–2008 典型用户从点击下单到实际吃到饭的真实延迟分布；
- 早期网站订单有多少最终仍需电话人工确认；
- 2000 年代初家庭、学生、白领分别有多大比例真正使用网上订餐；
- 菜单价格、最低起送、配送费在不同城市的长期可比序列；
- 早期订单后台、地址库、配送调度系统的技术实现；
- 历史平台的失败订单、退款、迟到与用户放弃率；
- 高频外卖是否在具体群体中实质改变住房厨房配置，而不仅仅改变厨房使用频率。

# 第十二部分：它改变了我们对“人怎么活着”的哪一点理解

本篇最重要的新认识不是“外卖越来越方便”。

而是：

> **吃饭本身是一条需要被组织的日常基础设施。**

一个人的一天是否可执行，不只是由“有没有工作、有没有房子、有没有网”决定，还取决于：

```text
在工作 / 学习 / 通勤 / 照护之后
还有没有时间、空间和精力
把食物真正变成一顿能吃的饭。
```

电话送餐已经可以把厨房与食客分离；Web 让菜单、地址和商家更可寻址；即时通信把订餐塞进工作桌面的聊天工具；平台进一步把商家、骑手、路线、支付和评价组织起来。

但数字入口越完整，越不能忘记最后那段物质现实：

> 有人必须买菜、切菜、开火、装盒、骑车、找楼、过门禁，并在饭还没有凉以前把它交给另一个人。

因此，“普通人有多少种活法”还应增加一问：

> **他每天必须亲自维持多少生活后台，又有多少可以用钱、组织和网络临时外接？**
