# 网吧、公共上网与“按小时租来的数字生活”：中国 1994–2025

> 研究问题：在家庭电脑、家庭宽带和智能手机成为日常之前，一个没有自己终端或稳定网络的人，究竟怎样进入互联网？当网络接入从“去一个地方租一小时”变成“随身在线”，普通人的信息、社交、学习、求职和时间感发生了什么变化？

本笔记与 `topics/communication-and-the-cost-of-living-far-away.md`、`topics/from-scheduled-to-ambient-information.md` 互补。前者讨论通信如何降低远离家庭的社会成本；本篇只处理一个更窄的缺口：**Internet service exists 之后，到 household ownership / always-on mobile access 之前，公共、按时计费、共享终端的上网方式如何成为真实的生活基础设施。**

旧网技术与保存问题另见 `tmzncty/old-web-archaeology`：

- `docs/INTERNET_CAFE_PUBLIC_ACCESS_SESSION_ENVIRONMENTS_IDENTITY_AND_CLIENT_STATE_GAPS_1997_2008.md`

## 一、结论先行

### 1. “接入互联网”至少有五层，不应合并成一个日期

中国互联网生活史至少要分开：

1. **科研/学术数字通信与联网前史**：1980 年代已经有学术联网、电子邮件、专线等尝试；
2. **全功能接入国际互联网**：1994 年 4 月 20 日，64K 国际专线开通；
3. **商业/公共接入开始出现**：拨号服务、网络咖啡屋、学校机房等使部分普通人可接触互联网；
4. **家庭接入成为重要地点**：家庭电脑和宽带扩散，但公共网吧仍长期承担补充接入；
5. **移动、常在线接入成为常态**：互联网不再主要是“去某个地点使用的设施”，网吧遂转向高性能终端、游戏、社交、临时空间等功能。

因此：

> `1994 full-function connection ≠ mass household access`
>
> `commercial access exists ≠ affordable repeat use`
>
> `household access rises ≠ public access immediately disappears`

2024 年中央网信办关于中国全功能接入国际互联网 30 周年的历史梳理明确将 1994 年 4 月 20 日与此前的学术联网、`.CN` 注册等前史区分开来。它也指出全功能接入后，全国性骨干网继续建设，普通用户接入是之后展开的过程。

来源：

- 中央网信办，2024-04-20：<https://www.cac.gov.cn/2024-04/20/c_1715291120716362.htm>

证据等级：B（后来的官方历史梳理，用于阶段边界；不当作 1994 年普通人使用状况的一手调查）。

### 2. 网吧提供的不是“电脑”，而是 **access without ownership（无需拥有即可接入）**

家庭上网要求把若干成本同时装进一个家庭：

- 电脑；
- modem / 网卡；
- 电话线或宽带；
- 接入账户与通信费；
- 安装、配置和故障处理能力；
- 可长期摆放电脑的住房空间。

网吧则把这些成本集中到经营者，再按小时切片出售。

因此一个人可能：

- 家里没有电脑，却已经每周收发电子邮件；
- 宿舍没有网络，却已经在 BBS / 聊天室形成稳定关系；
- 没有长期宽带，却能够查招聘、做作业或下载材料；
- 没有高性能电脑，却在后来仍去网吧/电竞馆使用短时高性能算力和高速网络。

这是一条很重要的技术采用规律：

> **行为整合可以早于家庭所有权。**

### 3. 早期公共互联网是一种 **session-based digital life（会话型数字生活）**

当上网按小时收费、必须去固定地点、还要考虑营业时间和空机位时，互联网不是持续背景，而是一段需要安排的“活动”。

可以把一次上网写成：

```text
决定去网吧
→ 到达
→ 排队/找空机
→ 付费或开始计时
→ 登录机器/网络
→ 集中完成邮件、聊天、查资料、下载、游戏等任务
→ 计时压力下决定是否续时
→ 下机
→ 回到离线状态
```

于是价格不只是消费成本，也是**在线时间的上限**。

这和后来手机上的“随时看一眼”是不同的时间结构。

### 4. 网吧后来并非简单“消失”，而是发生 **access-function migration（接入功能迁移）**

当家庭和手机已经解决“能不能上网”后，公共上网场所仍可能提供：

- 比宿舍/家庭更快的网络；
- 更强的电脑；
- 通宵使用条件；
- 多人并排的线下社交；
- 不打扰舍友/家人的独立空间；
- 临时高带宽/高性能的“突发容量”。

因此 2020 年仍有大学生为了抢课或通宵赶作业去网吧；2019 年的电竞酒店甚至把“高性能电脑 + 床 + 私密房间 + 好友聚会”重新捆成一种短期空间。

这不是旧网吧的简单延续，而是公共数字基础设施从 **access necessity** 向 **performance / space / sociality** 转型。

## 二、1994 之前与 1994 之后：不要把“没有大众互联网”写成“没有数字通信”

本仓已有 `before-mass-internet-access-ladder-china-france-1980s-1997.zh-CN.md` 讨论更完整的前史。本篇只固定与网吧直接相关的边界：

- 1980 年代，中国已有学术联网和电子邮件等数字通信尝试；
- 1994-04-20 是**全功能接入国际互联网**的重要基础设施节点；
- 但当时普通家庭并不会因为国家网络接通就自动拥有电脑、电话线、modem、账号和支付能力；
- 1990 年代中后期的拨号、学校机房、单位网络、网络咖啡屋等，是把“国家/机构有网”向“具体普通人能使用”推进的中间层。

正确问题不是：

> “1994 年中国有没有互联网？”

而是：

> **“1994、1996、1998 年，一个具体学生、职员或外来人口若没有家庭电脑，他实际去哪里、花多少钱、通过什么终端才能使用互联网？”**

## 三、1996–1998：公共终端首先解决的是“我根本没有这一套设备”

### 3.1 1996–1997 北京：网络咖啡屋是一种少量、昂贵但真实存在的公共入口

2019 年《北京日报》历史版重新整理并展示了 1996、1997 年本报旧版材料。其保存的同期观察包括：

- 1996-11-19，北京“实华开网络咖啡屋”营业；
- 1997 年 1 月记者探访时，场内有 11 台奔腾电脑与咖啡桌；
- 可观察到的使用者包括发电子邮件的大学生、查资料的公司职员、聊天的年轻人以及玩联网游戏的外国人；
- 1997 年初，北京已出现近 10 家类似场所，集中在海淀/中关村；
- 1996 年网吧上机费约 30 元/小时；家庭拨号同时还需要网络接入费和市话费。

来源：

- 人民网转载《北京日报》历史版，2019-10-17：<https://media.people.com.cn/n1/2019/1017/c40606-31404334.html>
- 北京日报历史版网页：<https://xinwen.bjd.com.cn/content/s5da7a6cce4b037702ff14b36.html>

证据等级：B/C 混合。2019 年文本是后来整理，但明确给出 1996/1997 年《北京日报》原版日期并展示旧版图；本篇只使用其可定位的同期记者观察，不把后来叙述当成独立同时代样本。

这里最重要的不是“第一家”的争论，而是**功能组合**：

```text
公共地点
+ 已安装好的电脑
+ 已配置好的联网线路
+ 按小时付费
+ 一定程度的现场帮助
```

一个没必要/没能力在家部署完整上网系统的人，可以短时进入网络。

### 3.2 价格会直接决定“能不能形成习惯”

2001 年新华社对飞宇网吧创业过程的同期报道记录：1998 年 2 月开业时先免费三天，25 台电脑从早到晚坐满；免费期结束、恢复 20 元/小时收费后，有时一天只剩七八位顾客。

来源：

- 新华社 / 新浪，2001-08-31：<https://tech.sina.com.cn/i/c/2001-08-31/82744.shtml>

证据等级：B（同期媒体对三年前创业过程的当事人叙述）。

这给出一个极干净的生活史边界：

> `curiosity + technical access ≠ affordable repeat access`

一个人免费体验一次 Internet，与每周稳定使用 Internet，是完全不同的社会状态。

## 四、公共接入会让“互联网使用”早于“家庭电脑普及”

将技术采用只按“每百户电脑拥有量”书写，会漏掉大量共享接入。

网吧、学校机房、单位电脑都意味着：

```text
household ownership = 0
```

并不能推出：

```text
internet use = 0
```

这也是为什么需要把技术采用阶梯改成：

```text
网络存在
→ 机构可用
→ 公共付费终端可用
→ 家庭拥有设备
→ 家庭常在线
→ 个人移动常在线
```

这些阶段可以长期重叠。

## 五、公共上网还有一个经常被忽略的变量：**现场支持**

1994 年伦敦 Cyberia 的同期报道很适合做海外比较。英国《独立报》在开业时明确称，场所的目标之一就是让电脑环境对普通人“不那么令人生畏”；缺乏技术经验的人也可以在现场接触数据库和电子邮件。一个月后的现场小品还直接记录工作人员走到终端旁帮助初学者操作浏览器。

来源：

- *The Independent*, 1994-09-12：<https://www.independent.co.uk/life-style/cafe-with-a-mission-to-explain-cyberia-offers-chance-to-check-your-email-and-network-over-coffee-and-croissant-1448226.html>
- *The Independent*, 1994-10-21：<https://www.independent.co.uk/arts-entertainment/overheard-cyberia-1444076.html>
- *The Guardian*, 1994-09-07：<https://www.theguardian.com/technology/1994/sep/08/internet>

证据等级：B（同时代媒体现场报道）。

《卫报》还记录 Cyberia 至少有 6 台终端、Pentium PC、NCSA Mosaic，预计收费约 £2.50/小时。

中国与英国制度、价格和普及率不能直接互推，但这里有一个跨国共同机制：

> **早期公共网络场所售卖的往往不仅是线路和机器，还包括“有人已经替你把复杂系统装好，并且有人可以问”。**

因此“数字技能”也可能通过服务场所被部分外包。

## 六、2003–2006：公共接入逐渐增加一层“身份可执行性”

公共终端与家庭电脑的一个重要差别，是使用者进入一个经营性公共空间，随后越来越多地需要经过身份登记和场所管理系统。

2003 年沈阳同期报道描述的实名上网系统流程包括：

```text
身份证
→ 办上网卡
→ 扫描器确认
→ 管理系统识别
→ 才能打开网页
```

来源：

- 《时代商报》/新浪，2003-07-10：<https://news.sina.com.cn/c/2003-07-10/08441313128.html>

证据等级：B。

2006 年合肥的报道进一步记录：95% 以上网吧已安装实名登记系统；用户可凭规定有效证件办实名卡，临时使用也要由工作人员在管理系统登记，之后才能使用临时卡开机。

来源：

- 央广网 / 新浪，2006-11-14：<https://news.sina.cn/sa/2006-11-14/detail-ikknscsk1272371.d.html>

证据等级：B。

由此必须把普通人的公共互联网接入条件写成：

```text
有钱
+ 有空机
+ 场所开放
+ 符合年龄/身份规则
+ 有被接受的证件
+ 登记系统可工作
+ 终端与网络可工作
```

而不能只写“附近有网吧”。

### 6.1 反例：制度安装并不等于现实执行一致

2006 年新华社记者在天津、南京、兰州等地暗访时发现，多家网吧并不实际要求上网卡；南京同期报道也称一些场所实名系统“名存实亡”。

来源：

- 新华社 / 羊城晚报 / 新浪，2006-05-24：<https://news.sina.com.cn/o/2006-05-24/14509014461s.shtml>
- 人民网-江南时报 / 搜狐，2006-11-11：<https://news.sohu.com/20061111/n246321432.shtml>

证据等级：B。

因此固定：

> `regulation exists ≠ software installed ≠ rule enforced in every venue`

## 七、2008：家庭接入上升，并没有立即把网吧变成边缘设施

CNNIC 第 22 次《中国互联网络发展状况统计报告》给出了非常重要的 denominator。2008 年中：

- 在家上网的网民比例为 74.1%；
- 在网吧上网的比例为 39.2%；
- 半年内在网吧上网的网民规模约 9918 万；
- 网吧使用者明显年轻化，24 岁及以下占网吧网民 70.7%。

来源：

- CNNIC 原报告 PDF：<https://www3.cnnic.cn/NMediaFile/2022/0830/MAIN1661848787213RHRPZ27GU2.pdf>
- 新浪科技同期摘要：<https://tech.sina.com.cn/i/2008-07-24/13372348682.shtml>

证据等级：A（当期机构调查报告；注意“上网地点”允许多选，因此家庭与网吧比例不能相加或视为互斥）。

CNNIC 2008–2009 青少年报告又指出：2008 年青少年网民中过去半年在网吧上网的比例为 57.5%，农村青少年网民为 65.4%。

来源：

- CNNIC，2009-01-16：<https://www.cnnic.cn/n4/2022/0401/c116-890.html>

证据等级：A。

这正好证明：

> **家庭互联网增长与公共互联网高使用可以同时发生。**

网吧在这个阶段不是“没有家庭网的人专用”这么简单，也可能是家庭/学校以外的补充地点。

### 7.1 同时代反例：并不是所有网吧使用都指向“有用信息”

2008 年广州报道已经观察到网吧出现学动漫设计、看电影、找工作等用途，同时又明确说家庭网络与无线网络普及正在压缩传统网吧利润，上网费甚至出现低于 1 元/小时的场所。

来源：

- 《广州日报》/新浪，2008-11-23：<https://tech.sina.com.cn/i/2008-11-23/15032597354.shtml>

证据等级：B。

因此不能把公共接入浪漫化成“知识民主化空间”。同一个物理基础设施可以承载求职、学习、聊天、游戏、影音，也可以形成严重的时间与消费问题。

## 八、2005–2012：扩张型未来里的一个底层条件——“我暂时买不起整套，也可以先进去”

本项目把 2005–2012 暂称为“扩张型未来”，不是说人人乐观，而是许多人的机会地图和工具菜单在扩大。

公共互联网在这里提供一种很特殊的 optionality：

- 不先买电脑，也能接触新服务；
- 不先装家庭网络，也能创建邮箱、QQ、论坛账号；
- 不拥有高性能机器，也能短时使用；
- 刚到一个陌生城市，也可以找到一个相对标准化的联网地点。

这使新数字行为的进入成本可以先从“大额固定投入”改成“小额、按小时投入”。

但它同时带来一种新的时间纪律：

> **在线一分钟也可能正在计费。**

因此早期 Internet 的“未来感”不是今天这种无缝常在线；它常常是一段明确开始、明确结束、看着计时器消耗的活动。

## 九、2015–2019：当“能不能上网”不再稀缺，场所开始卖别的东西

### 9.1 从连接本身转向“性能 + 私密 + 共处”

2019 年《中国青年报》对武汉电竞酒店的同期走访提供了一个很强的生活切口。

几名多年好友平时在不同省份工作，相约到武汉住进同一间电竞酒店，把这里当作碰面的“中转站”；他们过去聚会打游戏会去网吧，现在认为电竞酒店更安静、舒适、私密，而且不用担心其中某个人的网速差。

另一名大三学生周五入住到周日：高性能电脑、床、热水和免受宿舍门禁/舍友干扰被打包成两晚的私人时间块。

来源：

- 《中国青年报》，2019-03-01：<https://zqb.cyol.com/html/2019-03/01/nw.D110000zgqnb_20190301_3-08.htm>

证据等级：B（同期现场报道 + 同时性第一人称）。

这意味着 2015–2019 的“拥堵型未来”里，公共电脑空间的一部分价值已经从：

```text
我没有网络，所以来这里上网
```

变成：

```text
我有网络，但我的宿舍/租房/家庭没有这种设备、隔音、连续夜晚和多人共处条件
```

可以称为 **room-and-compute rebundling（空间与算力再捆绑）**。

## 十、2020–2022：偶发型未来——网络存在，但公共接入地点可能突然不存在

### 10.1 “没去过网吧”的大学生，仍可能在特殊任务时需要网吧

2020 年《中国青年报》采访的 1999 年出生大三学生张宇称自己从未去过网吧；身边去网吧的同学也很少，即便去，往往是为了拼网速选课或通宵赶作业。

来源：

- 《中国青年报》/中国青年网，2020-09-11：<https://news.youth.cn/sh/202009/t20200911_12489694.htm>

证据等级：B（同期第一人称；只证明这名学生及其所述身边经验，不外推为所有大学生）。

这产生一个新的机制：**burst-capacity access（突发容量接入）**。

家庭/手机已经满足 95% 的日常联网，但在以下情况下仍可能需要公共高性能场所：

- 抢课/抢名额；
- 截止日前通宵；
- 家里网络临时故障；
- 需要高性能 PC；
- 与多人同地联机。

因此：

> `nonessential daily infrastructure ≠ useless infrastructure`

### 10.2 疫情第一次让“场所可用性”本身变得不可靠

2022 年杭州日报记录，杭州近 700 家网吧/网咖/电竞馆经历 48 天闭店后才从 4 月 30 日起陆续恢复；恢复后，扫码、测温、口罩、消毒、独立包间等成为实际进入条件的一部分。

来源：

- 杭州日报 / 杭州网，2022-05-31：<https://hznews.hangzhou.com.cn/jingji/content/2022-05/31/content_8268073.htm>

证据等级：B。

这给“偶发型未来”增加了一条非常清楚的基础设施断裂：

> **Internet backbone may work + your account may work + your city may have cafés — yet the public access venue can still be closed.**

公共接入的可靠性天然比“已经在自己房间里的家庭宽带”多一层场所开放条件。

---

## 十一、2023–2025：防守型未来——从“互联网入口”变成需要主动购买的体验与退路

2025 年《中国青年报》报道行业协会监测数据：网吧、网咖、电竞馆、电竞酒店等上网服务场所约 10.36 万家，营收约 900 亿元，从业人员约 65.6 万；行业自己的表述也已经把场所定位到游戏、视频、社交、休闲等综合体验，而不只是“上互联网”。

来源：

- 《中国青年报》，2025-01-19（新浪转载）：<https://finance.sina.com.cn/jjxw/2025-01-19/doc-inefpcsw1182963.shtml>

证据等级：B（行业协会监测数据经同期媒体报道；它描述行业口径，不能直接等同普通人使用率）。

这里的“防守型未来”并不是说青年重新依赖网吧才能上网，而是：

- 个人终端成为默认后，公共场所必须证明自己为什么值得额外付费；
- 价值转向更强电脑、更稳定网络、空间、夜间连续时间与线下同伴；
- 日常基础接入退到背景，**备用容量和体验差异**成为卖点。

---

## 十二、海外对照：公共互联网接入不是中国特有现象

### 12.1 1994 London Cyberia：公共 Internet access 几乎与大众 Web 同期出现

1994 年 9 月《卫报》和《独立报》对伦敦 Cyberia 开业的同时代报道显示：

- 至少数台公共终端；
- NCSA Mosaic 浏览器；
- 按小时收费；
- 现场人员帮助新手；
- 电子邮件、全球数据库、电子公告等用途。

这说明“**没有家庭接入，却通过公共场所进入 Internet**”是早期互联网的一种跨国共同机制，而不是中国特殊路径。

但不能直接比较“1994 英国已经如此，所以 1994 中国普通人也如此”。终端密度、电话资费、家庭 PC、教育程度与地理分布都不同。

### 12.2 2000 New York easyEverything：即使家庭接入增长，公共终端仍服务三类需求

The Register 对纽约 Times Square easyEverything 开业的同期报道记录，该店有 800 台终端、24 小时营业。经营者把欧洲门店的顾客粗分为：

1. 家里负担不起网络的人；
2. 旅行/移动中的人；
3. 把网咖当社交空间的人。

来源：

- The Register, 2000-11-28：<https://www.theregister.com/2000/11/28/stelios_launches_us_cybercaf_empire_in_new_york/>

证据等级：B（同期媒体 + 企业经营者自述；顾客分类不能当严谨人口统计）。

这个三分法与中国后来出现的分化很相似：

> **access poverty / mobility / social-space demand 可以同时支撑同一种场所。**

因此哪些现象是中国特有、哪些是互联网时代共同变化，需要拆开：

- **共同变化**：家庭接入不足时公共终端降低固定成本；家庭接入普及后，场所转向旅行、社交、高性能或专业用途；
- **中国具体接口**：校园周边超高密度网吧、实名登记卡/场所管理系统、特定时期对未成年人进入的强监管、QQ/网游与校园 BBS 等本地应用生态。

## 十三、它怎样改变“普通人到底有多少种活法”

### 13.1 新增一种信息生活：**不拥有终端的联网者**

过去的技术史很容易按物品问：

> “家里有没有电脑？”

现在必须再问：

> “即使没有，附近是否有按小时可用的终端？”

于是会出现此前统计不容易看见的人：

```text
household PC owner = no
regular Internet user = yes
```

### 13.2 新增一种时间生活：**按小时购买在线状态**

早期网络使用可以被安排成：

- 周末两小时；
- 晚饭后一个小时；
- 包夜；
- 去学校机房时顺便完成；
- 到城市后先找一个网吧收邮件。

这与手机时代的碎片化持续在线不同。

### 13.3 新增一种城市基础设施：**陌生地方里的标准数字房间**

网吧像电话亭、邮局、图书馆或后来 coworking space 一样，提供一种城市内可识别的功能节点。

对新到城市的人，它可能意味着：

- 查地图和地址；
- 收邮件/QQ；
- 找工作；
- 查学校/考试信息；
- 与家乡联系；
- 等车时消磨时间。

并不是每个网吧都承担这些功能，但“存在这样的公共节点”本身会改变外出生活的可执行性。

### 13.4 新增一种后期路线：**家里能上网，但仍购买更好的数字环境**

到 2019–2025，去网吧/电竞酒店未必意味着家里“没有网”。

它可能意味着：

- 家里电脑太弱；
- 宿舍会断电/门禁；
- 不能吵到舍友；
- 好友分居不同城市，需要一个聚会地点；
- 需要连续几个小时不受打扰。

因此公共互联网基础设施会从“基本接入”转为“空间与性能 optionality”。

## 十四、历史可见性：网吧恰恰是 Web archive 很难保存的一种互联网

今天能留下来的往往是：

- 网吧主页；
- 新闻报道；
- 价格广告；
- 连锁品牌页面；
- 政策与管理制度；
- 游戏/软件推广页。

真正决定一个普通人那一小时看见什么的，则往往不在公开 Web：

- 那台机器当时装的浏览器版本；
- 默认首页；
- 是否有代理/过滤/加速；
- 本地游戏客户端；
- 计费软件；
- 身份卡系统；
- 终端是否被锁定；
- 下载目录、缓存与临时文件；
- 上一位用户是否退出账号；
- 下机后机器是否自动还原。

这意味着：

> `a café website survived ≠ the café's client environment survived`

而且历史浏览记录、cookie、聊天记录、缓存账号、身份证号等私人残留**不应该**因为“考古完整性”而被重新公开。

因此这一领域的 archive gap 有一部分是合理的 privacy boundary。

详见对应旧网考古笔记。

## 十五、重点矩阵

| 维度 | 本篇新增机制 |
|---|---|
| 教育 | 无家庭终端也可查资料、收邮件；后期变成抢课/赶作业的突发容量 |
| 就业 | 公共终端可承担职位搜索与联系，但并非每位使用者如此 |
| 住房 | 宿舍/租房不提供足够网络、设备或夜间空间时，数字活动外包给公共场所 |
| 婚姻家庭 | 远距关系可以借公共 Internet 维持，但接触具有时间和地点限制 |
| 迁移 | 新城市里的公共联网节点降低“先拥有设备再能获取信息”的门槛 |
| 照护 | 非本篇核心；公共场所不适合作为稳定照护通信的唯一基础设施 |
| 非正规劳动 | 网吧本身产生网管、夜班、设备维护等岗位；亦支持短期求职 |
| 长期中断 | 终端/账号/场所关闭会切断数字连续性；个人内容未必在本地可带走 |
| 证件与记录 | 2000 年代实名卡使证件成为公共上网执行条件之一 |
| 通信方式 | 从“必须去地点登录”向“始终随身在线”变化 |
| 互联网平台 | QQ、邮件、BBS、网游等平台通过公共终端进入无家庭接入者生活 |
| 信息获取 | 行为整合可早于家庭所有权 |
| 社交关系 | 公共终端既支持远程关系，也形成同地点同伴文化 |
| 未来预期 | 2000s：先租用数字能力也能进入新机会；2010s 后：场所更多成为体验/性能 optionality |
| 线上/线下身份 | 一个人的网络账号可跨多台公共机器连续存在；场所身份登记又另有一层 |
| 平台消失与记忆保存 | 公开 Web 很难保存具体终端会话、客户端镜像和私人执行层 |

## 十六、反例与警告

### 反例 1：网吧很多，不等于每个人依赖网吧

2008 CNNIC 同期数据显示家庭已经是更主要的上网地点。公共接入重要，不代表家庭接入不重要。

### 反例 2：网吧不是天然“知识空间”

娱乐、游戏、影音一直占重要位置。不能因为研究者更喜欢“查资料/求职”就把后者写成主要用途。

### 反例 3：实名系统安装，不等于每家店实际执行一致

2006 年的暗访已经提供明确反证。

### 反例 4：今天的电竞馆不是“1998 网吧换了装修”

今天用户通常已有自己的手机、家庭网络甚至电脑，因此同一场所名称背后的社会功能已经改变。

### 反例 5：后来怀旧会系统性高估“青春共同经验”

长期泡网吧的人比从不去的人更容易留下鲜明回忆；网吧史必须与 CNNIC 等 denominator 结合。

---

## 十七、后见之明风险

1. 不把 1994 写成普通中国人突然“上网元年”；
2. 不把少量都市网络咖啡屋写成全国日常；
3. 不把“电脑家庭拥有率”当作互联网实际接触率；
4. 不把“网吧使用”默认等同网络游戏；
5. 不把今日智能手机的常在线时间感投射给 1997 年按小时计费的用户；
6. 不把今天残存的网页界面当作当时网吧客户机真实浏览环境；
7. 不因怀旧材料丰富，就把网吧写成整代人的统一青春。

## 十八、尚未确定 / 下一步

### 仍缺最强的一手纵向链

最值得找的是一个 1997–2010 普通人的多时点材料：

```text
第一次只能去公共机房/网吧收邮件
→ 形成固定 QQ/BBS/求职/学习习惯
→ 后来宿舍或家里买电脑
→ 再后来装宽带
→ 最后不再为“基础上网”去网吧
```

只有拿到这种链，才能准确回答：

> **公共接入到底在哪一年、因为什么条件，对这个人从“必需基础设施”变成了“可选场所”。**

### 还需要更多价格 / 工资比

目前有 1996 约 30 元/小时、1998 飞宇 20 元/小时、2008 部分场所低于 1 元/小时等锚点，但还需要按城市、学生/工人工资、包夜价格建立更系统的 `hourly access cost / hourly wage` 比较。

### 还需要更多农村/县城生活史

CNNIC 能证明农村青年更依赖网吧，但仍缺足够多、可定位到具体年份的同时代第一人称，解释“最近的网吧在哪里、怎么去、一次花多少、用来做什么”。

## 十九、本轮改变了什么理解

此前仓库已经知道：通信可以让一个人离家更远而仍然维持关系。

本轮增加了一个更底层的中间层：

> **一个人甚至不需要先拥有一台联网电脑，才能开始拥有网络生活。**

这会改变对 1990s–2000s 普通互联网史的写法。

互联网进入生活不是：

```text
国家联网 → 家家联网 → 人人上网
```

而更像：

```text
科研/机构网络
→ 商业拨号与公共终端
→ 学校/单位/网吧/家庭多地点并存
→ 家庭宽带成为主要入口
→ 手机把接入带到个人身上
→ 公共场所从“连接本身”转向“性能、空间、社交与备用容量”
```

在这条谱系里，网吧不是一个可以被一句“旧时代娱乐方式”带过的旁枝。

它是一座桥：**把尚未拥有网络基础设施的人，提前接进了已经存在的网络世界。**
