# 从征婚启事到“轻相亲”：择偶基础设施、可搜索配偶与婚姻路线可执行性，中国，1981—2025

> 状态：research note / comparative synthesis  
> 主题：婚姻家庭、标准人生脚本、信息获取、父母代理、证件与身份、互联网平台、隐私、未来预期  
> 交叉旧网：`tmzncty/old-web-archaeology/docs/ONLINE_DATING_PROFILES_VERIFICATION_SEARCH_MESSAGING_AND_OFFLINE_OUTCOME_STATE_GAPS_2003_2012.md`  
> 与既有专题的边界：本条目不再回答“什么时候结婚”或“房子是否成为结婚门槛”本身，而研究**一个普通人如何找到潜在伴侣，以及这种寻找何时从亲友/单位网络变成可公开发布、可搜索、可筛选、可由平台和父母代理执行的一条基础设施路线**。

## 0. 核心问题：想结婚，不等于存在一条能遇见合适对象的路线

人生脚本常把婚姻写成一个里程碑：

```text
读书 / 工作
→ 恋爱
→ 结婚
→ 建立家庭
```

但对真实生活而言，`恋爱` 不是一个自动发生的中间步骤。一个人即使主观上想结婚，也仍然需要：

```text
有可接触的人际网络
→ 能让潜在对象知道“我在找”
→ 能得到关于对方的最低信息
→ 双方愿意继续接触
→ 联系方式可达
→ 身份和基本事实足够可信
→ 可以安排见面
→ 见面后的关系愿意继续
→ 家庭 / 住房 / 地理 / 工作日历等现实条件可以协调
→ 双方才可能进入长期关系或婚姻
```

因此新增一个核心概念：

> **marriage-route executability / 婚姻路线可执行性**：一个人不仅“愿意结婚”，而且能够经过可实际运行的认识、筛选、联系、验证、见面和持续相处过程，把婚姻从社会期待推进成一项现实可能。

硬边界：

- `social expectation to marry ≠ available partner pool`
- `candidate exists ≠ candidate is discoverable`
- `profile visible ≠ profile true`
- `profile true ≠ mutual interest`
- `message sent ≠ message readable`
- `message read ≠ offline contact`
- `offline meeting ≠ relationship`
- `relationship ≠ marriage`
- `parent-operated search ≠ adult child's consent`
- `large candidate pool ≠ easier decision`
- `platform success story ≠ platform success rate`

这个问题直接连接标准人生脚本与信息基础设施：**如果一个时代越来越要求个人自己完成择偶，那么“哪里能遇见人、怎样知道对方是谁、谁替你筛选”就会成为人生基础设施。**

## 1. 互联网以前：媒介首先扩大的是“谁能知道我在找对象”

### 1.1 1981：一则报纸征婚启事把私人寻找变成公开可寻址信息

人民网 2019 年对中国相亲史的整理记录：1981 年 1 月 8 日，人民日报社主办的《市场报》刊登丁乃钧征婚启事，启事包含年龄、身高、职业/收入状态等基本条件，并要求应征者“来函联系和附一张近影”。

来源：

- 人民网，2019-10-24，《中国为什么会有“相亲角”？》：https://politics.people.com.cn/n1/2019/1024/c429373-31417696.html
- 2009 年《环球人物》对丁乃钧本人的回访（新浪转载）：https://style.sina.com.cn/news/2009-10-10/101649707_2.shtml
- 2008 年重庆晨报对本人及旧同事的回访（新浪转载）：https://news.sina.com.cn/o/2008-12-01/060614810050s.shtml

证据等级：C/B。征婚启事日期和文本由多个后来机构/媒体材料相互支持，但本轮没有取得并核验 1981 年《市场报》原版扫描，因此不把排版、字号、准确字数升级为 A 级原件事实。

这个个案的重要性不在于“第一人”的纪念性，而在于通信链：

```text
个人把自己的婚姻需求写成公开信息
→ 全国性纸媒传播
→ 陌生人用邮政回信
→ 照片和文字成为初筛材料
→ 书信往返
→ 再决定是否见面
```

2009 年回访称，这则启事给丁乃钧带来数百封来信，他最后与一位异地来信者建立联系并结婚。具体回信数量在后来材料中存在 270、更多等不同说法，所以本条目不把某个数字当成精确计数。

这里出现了一个以后一直存在的机制：

> **search-space expansion / 择偶搜索空间扩张**：媒介把“我能认识谁”从亲友、邻里、同事和单位附近的人，扩展到一个远得多的陌生人集合。

但扩张马上带来新的劳动：读信、筛选、回信、核验、跨地见面。

所以：

> **more candidates ≠ less search labor**

### 1.2 邮政延迟本身就是恋爱节奏的一部分

报纸征婚并没有取消距离。它只是把陌生人“发现”变得远程化；真正的互动仍受制于：

- 报纸发行周期；
- 邮件寄达时间；
- 对方是否回信；
- 照片和书信中能承载的信息量；
- 长途见面成本；
- 工作单位是否允许请假；
- 最终是否需要一方迁移。

因此互联网前的远程择偶可以写成：

```text
publication latency
+ postal latency
+ reply latency
+ travel latency
```

和后来“平台秒级展示但几周没人回复”相比，技术速度变了，但**等待一个陌生人愿不愿意回应**这一层没有自动消失。

## 2. 1982—1980s：机构化婚介把“找对象”变成可登记的公共服务

人民网同一历史整理记录：1982 年 11 月 15 日，广州市青年婚姻介绍所挂牌；该文引《中国妇女报》资料称，到 1984 年 6 月已经撮合 1400 多对，报道所述成功率为 14.4%。

来源：

- https://politics.people.com.cn/n1/2019/1024/c429373-31417696.html

证据等级：C/B（后来机构性整理，引用早期报刊；本轮未取得原始《中国妇女报》版面）。

这意味着择偶第一次明确出现类似数据库的社会组织逻辑：

```text
登记个人条件
→ 机构持有候选资料
→ 工作人员筛选
→ 介绍双方
→ 双方见面
```

这里的“算法”是人：婚介人员、单位干部、工会/青年组织、亲友。

可以称为：

> **mediated mate search / 中介化择偶**：个人不必直接认识所有潜在人选，而由某个掌握双方资料的中介完成发现和初筛。

这一点非常重要，因为 2000 年代婚恋网站并不是凭空创造一个新行为，而是把“登记条件—匹配—介绍”从纸表、档案柜和红娘劳动进一步软件化。

## 3. 2003—2006：婚恋网站把“一个人”压缩成可搜索资料

### 3.1 网络婚恋真正新增的是 searchable person

世纪佳缘创始业务始于 2003 年。到 2006 年，第一财经日报记录的一场世纪佳缘线下活动中，约 200 名网站会员参加；每人胸前贴有会员编号和年龄，并手持写有联系方式的“纸蝴蝶”。一名以网站注册名参与的中学教师现场自我介绍，希望寻找伴侣。

来源：第一财经日报 2006-02-14（新浪转载）：
https://finance.sina.com.cn/chanjing/b/20060214/01402338668.shtml

证据等级：B（同期报道）。

这段材料特别好，因为它把线上和线下连接在同一场景里：

```text
在线账号 / 会员号
→ 在线资料
→ 平台组织线下活动
→ 身体到场
→ 会员号仍然作为身份索引
→ 纸质联系方式完成进一步联系
```

互联网没有让身体见面消失。它改变的是**见面之前怎样找到彼此**。

### 3.2 profile compression：人的生活被压缩为可比较字段

2009 年《中国青年报》对网络“猎婚”的同期报道写到，婚恋网站大量会员资料会直接展示照片、所在地区、月收入等字段；刚接触网站的小刘不断翻页，他的父母也一起在屏幕前帮他筛选。

来源：中国青年报 2009-12-24，《“剩斗士”催热网络“猎婚”》：
https://zqb.cyol.com/content/2009-12/24/content_2997776.htm

证据等级：B（同期第一人称/家庭场景由记者重构）。

由此新增：

> **profile compression / 人生资料压缩**：原本需要长时间相处才能逐渐知道的信息，被平台压成一组可展示、排序和筛选的字段。

字段往往包括：

- 年龄；
- 地区；
- 身高；
- 学历；
- 职业；
- 收入；
- 婚姻状态；
- 照片；
- 择偶要求。

这并不等于人们“只在乎条件”。它首先说明数字系统需要把一个复杂的人变成机器和陌生人都能快速阅读的结构。

`person ≠ profile`，但 profile 会改变谁先被看见、谁先被排除。

## 4. 2005—2012 的“扩张型未来”：候选人突然变多，父母也进入屏幕

### 4.1 网络把候选集合做大以后，筛选本身变成新的家庭劳动

2009 年《中国青年报》材料中，小刘已经接受过十多次介绍和大型相亲会；母亲转而让他把多个婚恋网站都注册起来。进入世纪佳缘一类网站后，候选数量之多反而让他“眼花缭乱”，父母坐在旁边继续翻页和点评。

这说明早期网络婚恋不是简单的：

```text
传统父母安排
→ 年轻人自己网上自由恋爱
```

更真实的形态可以是：

```text
父母焦虑
→ 父母推动注册
→ 成年子女操作账号
→ 全家一起浏览资料
→ 父母继续承担初筛劳动
```

由此新增：

> **proxy matchmaking labor / 代理择偶劳动**：实际搜索和筛选的人，不一定就是未来进入关系的人。

2009 年另一份婚恋调查报道甚至直接使用“代恋逐渐代替代征”的说法，称一部分父母已经转到网络婚恋网站帮助子女征婚。

来源：中国青年报 2009-12-09：
https://zqb.cyol.com/content/2009-12/09/content_3029736.htm

证据等级：B；调查组织方包括婚恋服务机构，比例与解释应保留来源边界。

### 4.2 expanded option set 也会造成 choice overload

网络婚恋把一个城市甚至全国的候选人放进同一个搜索空间，但这会产生：

- 无限翻页；
- “下一页也许有更好的”；
- 条件比较；
- 回复优先级；
- 多线程聊天；
- 对选择错误的担忧。

所以扩张型未来在婚恋上的一个核心矛盾是：

> **未来的选择集合变宽，同时决定“哪一个未来值得关闭其他选项”变得更难。**

这和仓库已有的 `optionality as a life goal` 可以直接连接。

## 5. 2011：公开网页只是婚恋平台执行链里很薄的一层

世纪佳缘 2011 年向美国 SEC 提交的 F-1/A 招股书是本轮最强的一手系统证据之一。

来源：SEC，Jiayuan.com International Ltd., Form F-1/A, filed 2011-05-11：
https://www.sec.gov/Archives/edgar/data/1511683/000104746911004910/a2203664zf-1a.htm

证据等级：A（同期公司监管披露；用户效果和公司自我评价仍属于公司主张）。

文件显示：

- 注册和基本搜索可以免费进行；
- 发送首条消息本身可以不付费，但为了让首条消息可读，发送者或接收者需要使用价值 2 元的虚拟邮票；
- 首次建立联系后，同一两人的后续站内通信可以免费；
- 平台提供提升搜索排名、消息优先级、图片/资料高级展示、在线聊天等收费服务；
- 用户可以提交年龄、收入、教育等资料证明，提交证明并付费后可以获得更高数据库评级；
- 某些基础字段如身高、薪资和教育一旦填写，之后若要向更有利方向修改，需要验证；
- 2010 年 6 月起部分婚恋功能已经可以通过移动浏览器访问；
- 平台披露自 2008 年起大量举办线下社交活动；
- 截至 2011 年 3 月 31 日，公司披露有 4020 万注册账号，2011 年第一季度平均月活跃账号约 474 万、平均月付费账号约 88 万。这里必须使用“账号”而不是直接写成同样数量的独立个人。

这揭示一条非常重要的执行状态：

```text
profile visible
≠ message readable
≠ trust established
≠ off-platform contact exchanged
≠ date happened
```

而且：

> **search visibility itself was monetizable.**

婚恋平台和网店有一个结构上的共同点：账号存在，不代表在排序中具有同等可见性。

## 6. “证明材料”并没有把数字身份变成真相

2011 年招股书明确描述了资料证明、客服审核、用户举报、黑名单和关键词检查等机制；但公司自己的“proof submitted”只说明用户向平台提交过相应证明，并不意味着研究者今天可以从一个历史资料页推断：

- 该证明当时是否仍有效；
- 该资料是否覆盖全部字段；
- 婚姻状态后来有没有变化；
- 账号当前操作者是否仍是原本人；
- 线下实际身份是否与资料完全一致。

因此增加：

> **verification-state gap / 验证状态缺口**。

到了 2018 年，中国青年报对 1998 名适婚单身青年的调查中，52.7% 称注册过婚恋平台；会员信息不实与审核不严格是主要担忧，69.3% 认为平台有责任严格把关资料真实性。

来源：中国青年报 2018-01-25：
https://zqb.cyol.com/html/2018-01/25/nw.D110000zgqnb_20180125_2-07.htm

这里不能把在线调查比例外推成全国人口比例，但它证明：**平台化十多年以后，“如何知道屏幕上的人是真的”仍然是路线可执行性的核心摩擦。**

## 7. 2008 电影与 2010 电视：当“条件化择偶”进入大众叙事

本仓已经把影视作品定义为 representation/context evidence，而不是人口样本。婚恋尤其适合使用这层证据。

2008 年冯小刚电影《非诚勿扰》直接把公开征婚、连续见陌生候选人作为都市浪漫喜剧的基本机制；2008 年 12 月南方周末对导演的同期采访说明影片围绕葛优与舒淇从相遇、了解走向关系展开。

来源（同期创作者访谈，新浪转载南方周末）：
https://news.sina.com.cn/o/2008-12-25/143214936119s.shtml

F1/F2 证据用途：到 2008 年，**“把自己放进一个公开择偶市场、批量见陌生人”已经足够可理解，可以直接成为大众贺岁片情节，不需要先解释制度是什么。**

2010 年相亲电视节目大规模流行后，身份真实性本身又成为舆论对象。同期报道记录观众对嘉宾职业、动机和身份的质疑；同年海选报道则显示，报名者需要填写基本资料、签署单身/非婚诚信声明并接受编导进一步核查。

来源：

- https://ent.sina.com.cn/v/m/2010-04-06/10112919592.shtml
- https://ent.sina.com.cn/v/m/2010-08-17/07593054134.shtml

这类节目不是现实婚恋的代表样本，但它保存了一条时代默认：**择偶已经可以被设计成公开的资料展示、快速判断、身份核查和媒介表演。**

## 8. 2015—2019 的“拥堵型未来”：算法开始承诺替人做筛选

### 8.1 candidate abundance → filtering delegation

2018 年《中国青年报》调查 1962 名适婚单身青年：70.9% 的样本受访者看好大数据用于婚恋交友，77.9% 有兴趣使用相关平台。报道中的北京程序员余鹏（化名）说，他使用过大数据交友 App，因为系统可以提供可约会对象，省掉逐个聊天、了解和筛选。

来源：中国青年报 2018-04-12：
https://zqb.cyol.com/html/2018-04/12/nw.D110000zgqnb_20180412_2-07.htm

证据等级：B（同期调查与第一人称材料；样本不代表全国单身青年）。

这里出现：

> **filtering delegation / 筛选劳动外包**：候选集合大到个人难以处理后，用户开始希望算法替自己完成部分“谁值得先认识”的劳动。

但同一报道也留下了反例：有人担心算法把感情过程倒转成“先根据参数判断合适，再开始认识”，而且气质、共同阅读经验等很难可靠量化。

这意味着：

`more data ≠ fuller person`

### 8.2 2018：不愿“将就”本身成为一种可表达的时间策略

另一项 2018 年同期调查中，85.0% 的样本受访单身青年表示不愿违背自己心意去“将就”；一名 35 岁的上海互联网公司高级总监说，宁愿晚结婚，也不愿草率结婚后再离婚。

来源：中国青年报 2018-05-24：
https://zqb.cyol.com/html/2018-05/24/nw.D110000zgqnb_20180524_1-07.htm

这为“拥堵型未来”增加一个时间机制：

> **marital optionality / 婚姻可选性保留**：结婚年龄越来越被感知为有压力，但部分人仍把“暂时不关闭其他人生选项”视为比准点完成婚姻脚本更重要。

这不能浪漫化为所有晚婚都出于自主选择。住房、工作、照护、收入、性别结构和可遇见人群仍可能把等待强加给个人。

### 8.3 2019：婚恋平台已成为很多城市样本中的普通候选通道，但信任成本同步上升

2019 年《中国青年报》对 1972 名单身青年样本的调查中，78.8% 称曾注册婚恋交友平台；在注册者中，62.1% 看重大数据匹配，60.4% 希望扩大社交圈。同版另一篇报道中，73.0% 担心平台泄露信息，66.7% 担心用户资料不实。

来源：

- https://zqb.cyol.com/html/2019-09/19/nw.D110000zgqnb_20190919_1-08.htm
- https://zqb.cyol.com/html/2019-09/19/nw.D110000zgqnb_20190919_4-08.htm

这构成典型拥堵结构：

```text
候选更多
+ 筛选更快
+ 数据字段更多
+ 隐私暴露更多
+ 对真实性的验证劳动更多
```

## 9. 父母代理不是互联网的残余，而是可以被互联网重新产品化

### 9.1 相亲角：身体就是“最好的一份简历”

人民网 2019 年在北京中山公园相亲角采访一名 1993 年出生的年轻女性，她说：“我本人站在这就是最好的简历。”现场仍有大量父母替子女寻找对象。

来源：
https://politics.people.com.cn/n1/2019/1024/c429373-31417696.html

这句话特别适合和网页 profile 对照：

> **physical presence can itself function as identity verification.**

但相亲角同样把人压缩成纸张字段，只是资料旁边有父母和偶尔到场的本人。

### 9.2 2025：相亲角的父母操作逻辑直接迁到 App

2025 年北京青年报调查一些面向家长的线上婚恋产品：家长可以替成年子女注册，填写年龄、身高、学历、工作地，以及房产、车辆、工作、婚姻状态等优势或要求；家长先筛选和沟通，再把认为合适的人选交给子女。

来源（人民网转载北京青年报）：
https://sc.people.com.cn/n2/2025/0526/c345167-41239517.html

证据等级：B（同期调查报道）。

由此新增一个必须长期保留的状态：

> **operator-person split / 操作者—婚恋主体分离**：账号是谁操作的，与资料描述的是谁，不一定是同一个人。

所以 old-web / platform history 绝不能默认：

`account holder = profile subject = message author = offline dater`

这在婚恋平台尤其危险。

## 10. 2020—2022 的“偶发型未来”：婚恋路线也会受到普通社会日历停摆的影响

本轮没有找到一个足够强、又与现有疫情专题不重复的 2020—2022 个人纵向婚恋样本，因此不硬造“疫情改变婚恋”的单一结论。

可以保留的边界是：

- 线上搜索和聊天可以继续存在；
- 线下见面、跨城旅行、家庭见面、登记和婚礼仍依赖现实移动与公共服务；
- `digital contact remains available ≠ relationship route remains fully executable`。

这一时期以后若补材料，优先寻找同一个人的原始聊天/日记/论坛叙述：原定见面取消、异地关系怎样维持、推迟结婚是否改变住房或工作决策，而不是只用平台发布的“疫情期间用户活跃度上涨”。

## 11. 2023—2025 的“防守型未来”：从条件盘问到“轻相亲”，人开始防御筛选本身

### 11.1 直播相亲：profile fields 变成实时表演

2023 年《中国青年报》报道山东临沂直播相亲：参与者会在大量观众面前报出身高、体重、工资、房产等个人条件；观看者如果感兴趣，可以直接拨打电话联系。

来源：中国青年报 2023-01-11：
https://zqb.cyol.com/html/2023-01/11/nw.D110000zgqnb_20230111_1-04.htm

证据等级：B（同期现场报道）。

这里产生：

> **profile performance / 资料现场化表演**：网站时代的静态资料字段被搬进高流速直播，个人要在几分钟甚至更短时间内把自己压缩成一个可被陌生人迅速判断的对象。

2024 年《中国青年报》采访近 10 名 25—35 岁单身青年时，一名 32 岁女性说自己的社交圈固化，开始利用相亲直播间寻找可能的人；记者同时观察到直播间里现实条件和价值观被快速陈述和筛选。

来源：中国青年报 2024-01-30：
https://zqb.cyol.com/html/2024-01/30/nw.D110000zgqnb_20240130_2-07.htm

### 11.2 “轻相亲”：对高强度条件化筛选的反作用

2025 年《中国青年报》对 1339 名受访者的调查中，65.0% 表示相亲时担心无话可说、冷场，63.9% 不喜欢目的性过强的“条件盘问”；73.9% 表示身边有人尝试兴趣互动式“轻相亲”。报道中的 27 岁白领姚瑶说，传统流程式相亲一上来介绍姓名、收入、籍贯和家庭情况，让她感觉像“面试”。

来源：

- https://m.cyol.com/gb/articles/2025-03/28/content_ajKG5YTBVx.html
- https://zqb1.cyol.com/pc/content/202503/31/content_409091.html

证据等级：B（同期调查与第一人称材料；样本不外推全国）。

这显示一种新的防守机制：

> **anti-interview matchmaking / 反面试式择偶**：当可搜索条件、平台筛选和婚恋压力已经足够强时，一部分年轻人反而开始争取一个不必立刻把自己变成“年龄 + 收入 + 房车 + 家庭”的接触空间。

因此“防守型未来”不只是经济上的存现金、保工作、留退路，也可以表现为：

- 保护隐私；
- 降低第一次接触的承诺；
- 先以兴趣/活动建立弱连接；
- 不让父母、平台或算法过早替自己关闭候选；
- 拒绝把每次认识新人都立即解释成婚姻绩效考核。

## 12. 海外比较：法国 Minitel 证明“远程陌生人社交”早于 Web，但 denominator 必须保留

1988 年《世界报》报道，法国 1987 年新增约 113.6 万台 Minitel，总量约 337.3 万台，相当于电话订户的 14%；France Télécom 估计，在家庭或工作地点能接触 Minitel 的 15 岁以上人口约占 20%，就业人口约 30%。

来源：Le Monde, 1988-04-21：
https://www.lemonde.fr/archives/article/1988/04/21/reflux-des-messageries-hausse-des-services-professionnels-le-deuxieme-souffle-du-minitel_4102726_1819218.html

证据等级：A/B（同期报纸引用 France Télécom 年度数据）。

法国国民议会 1989 年的一份书面质询又记录，所谓 `Minitel rose` 成人/社交 messagerie 在 1988 年占 3615 大众 télématique 流量很大一部分，质询称约 1400 万小时连接。

来源：Assemblée nationale, Question écrite n°21631, 1989-12-11：
https://questions.assemblee-nationale.fr/dyn/9/questions/QANR5L9QE21631

证据等级：A（同期政府议会记录；它讨论成人 messagerie，不应被等同于正式婚恋服务）。

海外对照的正确结论不是“法国人比中国更早网上相亲”，而是：

> **remote stranger discovery and text-mediated intimacy predate the World Wide Web.**

但不同系统的生活逻辑不同：

```text
中国 1981 报纸征婚：
公开资料 → 邮政回复 → 天/周级延迟 → 异地见面

法国 1980s Minitel messagerie：
终端接入 → 昵称/即时文字互动 → 分钟级连接费 → 可持续在线往返

中国 2000s 婚恋网站：
结构化 profile → 搜索/过滤 → 站内信/付费可读 → 线下移交
```

共同变化是把潜在伴侣从本地熟人网络中抽离出来；差异在**响应速度、身份匿名度、字段结构、费用模型和普通人的终端可及性**。

## 13. 这条历史改变了我们对“标准人生脚本”的哪一点理解？

### 13.1 婚姻脚本包含一段常被历史叙事删掉的“搜索劳动”

当我们写：

```text
毕业 → 工作 → 结婚
```

中间其实可能有几年：

```text
亲友介绍
+ 公园相亲
+ 婚介登记
+ 报纸/网站/APP 注册
+ 晚上下班后刷资料
+ 父母筛选
+ 多次见面失败
+ 异地交通
+ 身份核验
+ 删除账号再重来
```

这段劳动会消耗时间、钱、隐私和情绪，而且男女、城乡、职业、年龄和家庭资源之间分布并不平均。

### 13.2 “婚姻越来越个人化”不能被写成“父母退出”

从 1980s 婚介，到 2009 父母坐在电脑旁帮翻页，再到 2019 相亲角、2025 家长专用 App，证据反而显示：

> **个人自主权可以增加，同时家庭仍承担大量发现、筛选和推动劳动。**

父母没有简单消失，而是不断换接口。

### 13.3 网络降低的是发现成本，不一定降低判断成本

互联网显著降低了：

- 找到更多陌生候选的成本；
- 跨城市浏览资料的成本；
- 初次发起联系的成本。

它可能同时增加：

- 资料真假核验；
- 大量候选比较；
- 回复与多线程聊天；
- 隐私暴露；
- 被算法/排序忽略的风险；
- “是不是还有更好的人”的机会成本。

因此：

> **search friction falls, evaluation friction can rise.**

## 16. 后见之明风险

1. **不要把 1981 写成“从此自由恋爱”。** 报纸渠道只是多了一种发现路线，家庭、单位、地域与社会规范仍存在。
2. **不要把注册人数写成人数。** 婚恋网站披露的是账户，重复账号、休眠账号和实际个人数不能自动等同。
3. **不要把“资料有证明标记”写成身份完全真实。** 验证覆盖范围、时效和操作者状态仍可能变化。
4. **不要把父母参与简单写成传统残余。** 数字平台可以重新放大和产品化父母代理。
5. **不要把晚婚全部解释为自主选择。** “不将就”与住房、工作、照护、性别比例、社交圈收缩等结构压力可以同时存在。
6. **不要把直播相亲当成低俗奇观。** 对参与者而言，它可能是在本地社交网络不足时真正可用的信息基础设施。
7. **不要把影视作品当统计样本。** 《非诚勿扰》等只能作为当时“这种择偶机制已可被大众理解”的叙事证据。

## 17. 隐私边界

婚恋史比一般旧网更容易重新暴露普通人的敏感信息。

本专题不应：

- 汇总仍可检索的历史用户 ID；
- 复制普通人的旧照片、手机号、QQ、邮箱；
- 把婚姻状态、收入、房产、身体信息从旧页面重新集中发布；
- 尝试联系旧账号以验证当年的身份；
- 根据姓名、单位、城市去“人肉”后来婚姻结果。

研究平台结构时优先记录字段、流程和 aggregate evidence，而不是保存可重新识别个人的资料。

## 18. 尚未确定

1. 本轮没有取得 1981 年《市场报》原版扫描，因此最早征婚启事的版式仍保持未验证。
2. 没有取得并实际检查一个 2003–2006 世纪佳缘普通用户 profile 的可公开、安全、合规 historical capture；不能声称恢复了当年 DOM/charset/浏览器体验。
3. 不知道早期平台的“验证”标识在所有年份究竟如何显示，F-1 只能可靠说明 2011 年公司披露的机制。
4. 仍缺同一个普通人 5–10 年的多渠道择偶纵向记录：亲友介绍→网站→App→线下活动→停止寻找/结婚。
5. 2020–2022 仍缺高质量同期第一人称“数字联系还在、现实见面中断”的长链材料。
6. 仍需补农村、流动人口、离婚后再婚、残障者、中老年丧偶者等不同 life route；不能让城市白领成为默认“普通人”。

## 19. 下一步最有价值的研究包

不是再做一个婚恋平台名单，而是恢复一条**同一个普通人的 mate-search ledger**：

```text
谁推动“该找对象了”
→ 第一次介绍来自谁
→ 注册了什么渠道
→ 一周花多少时间浏览/聊天
→ 父母是否参与
→ 见面多少次
→ 哪些人因为地理/住房/工作日历被排除
→ 为什么停用某个平台
→ 是否改用另一个渠道
→ 最后是结婚、继续单身，还是主动停止寻找
```

那样才能真正回答：

> **一个社会规定“应该结婚”以后，到底又要给普通人什么样的信息、时间、身份与空间基础设施，他们才真的有机会遇见一个可以一起生活的人？**
