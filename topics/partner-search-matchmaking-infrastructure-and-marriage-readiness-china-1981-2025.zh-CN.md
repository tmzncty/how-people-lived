# 找得到伴侣吗：择偶搜索半径、婚恋媒介与结婚准备度，中国 1981–2025

> 研究状态：交叉研究包 / 仍可继续补原始报纸与历史网页 capture  
> 核心问题：当“结婚”仍是许多人会认真考虑的人生项目时，一个普通人究竟通过谁、什么媒介、在多大的社会与地理范围里找到可能的伴侣？  
> 交叉仓：`tmzncty/old-web-archaeology`  
> 对应旧网研究：`docs/MARRIAGE_DATING_PROFILES_SEARCH_FILTERS_AND_RELATIONSHIP_OUTCOME_GAPS_2007_2010.md`

## 0. 本专题改变了什么

仓库已有婚姻年龄、家庭形成、住房、父母支持、工作与迁移研究，但如果只问：

- 几岁结婚；
- 有没有房；
- 工作是否稳定；
- 父母是否支持；

仍然会漏掉一层很实际的前置条件：

> **这个人怎样遇到一个可能成为伴侣的人？**

本篇把这个条件称为 **partner-search infrastructure（伴侣搜索基础设施）**。

它包括：

```text
亲友 / 同事 / 邻里介绍
→ 单位或社会组织联谊
→ 报纸征婚
→ 婚姻介绍所
→ 公园相亲角
→ BBS / 网站 / 婚恋数据库
→ QQ / MSN / 短信 / 微信等私下接触
→ App / 小程序 / 算法匹配
→ 兴趣活动与“轻相亲”
```

这些媒介不是简单的“旧的被新的替代”。它们长期叠加，甚至可以由同一个家庭同时使用。

本篇增加五个生活史变量：

1. **partner-search radius（择偶搜索半径）**：一个人理论上能接触多远、多大的候选人池；
2. **profile legibility（个人条件可比较性）**：年龄、学历、职业、收入、户口、住房等如何被压缩为可浏览字段；
3. **search autonomy（搜索自主性）**：本人能在多大程度上自己定义条件、自己搜索，而不是完全依赖熟人或父母；
4. **verification burden（核验负担）**：候选范围扩大以后，身份、意愿、条件与安全由谁核验；
5. **marriage readiness（结婚准备度）**：认识了人以后，住房、工作、户口、迁移、家庭关系和对未来的判断是否允许关系进入婚姻。

最重要的硬边界是：

```text
candidate exists
≠ candidate is discoverable
≠ mutual contact
≠ offline meeting
≠ relationship
≠ marriage
≠ durable household
```

互联网可以大幅改变前半段，却不能自动解决后半段。

## 1. 方法与证据角色

本专题遵守 `METHODOLOGY.md`：先恢复现实约束，再解释选择；不把一个极具故事性的个人经历当成整代人的统计代表。

为与 `old-web-archaeology` 对齐，本篇采用：

- **A**：同时代原始制度材料、原始页面、原始报纸或官方记录；
- **B**：同时代记者观察、同期访谈、当时平台操作记录；
- **C**：多年后的当事人回忆与历史回顾；
- **D**：本文根据多组证据提出的分析模型。

婚恋材料尤其需要再区分：

- **平台可观察事实**：当时页面有哪些字段、搜索或付费功能；
- **同时性自述**：当事人当年如何描述自己的计划；
- **回顾性自述**：多年后如何解释过去；
- **平台 / 媒体二次重构**：报道如何给行为命名；
- **关系结果**：是否真的见面、相恋、结婚，往往不在公共页面中。

研究对象是普通人的生活路径，而不是评价某种婚恋方式“先进”或“落后”。

# 第一部分：互联网以前，陌生人搜索已经存在

## 2. 1981：报纸把择偶从熟人网络部分外置到公共媒介

2019 年人民网的一份历史回顾记录：1981 年 1 月 8 日，《市场报》刊登丁乃钧的征婚启事，公开列出未婚、年龄 / 身高、收入等条件并要求来函附照片；1982 年 11 月，广州市青年婚姻介绍所成立。

来源：

- 《中国为什么会有“相亲角”？》，人民网，2019-10-24：  
  <https://politics.people.com.cn/n1/2019/1024/c429373-31417696.html>

补充回顾：

- 《第246期：婚姻介绍》，新京报，2008-11-19：  
  <https://news.sina.cn/sa/2008-11-19/detail-ikftssap3085412.d.html>

### 证据角色

**C / B 混合。**

本轮没有取得 1981 年《市场报》原页和 1982 年机构原始档案，因此不能把这些精确版面细节标成 A。2008、2019 年材料可以可靠建立“报纸征婚 / 公办婚介在 Web 前已经存在”的边界，但以后仍值得补原始报纸影像。

### 这件事改变的不是“有没有媒人”，而是谁可以成为媒介

传统熟人介绍通常依赖：

```text
我认识的人
→ 他认识的人
→ 候选人
```

报纸则允许：

```text
一个普通人的简短自述
→ 报纸发行网络
→ 大量彼此没有共同熟人的读者
→ 信件回流
```

婚介所则把候选资料、匹配和见面组织进一步制度化。

因此互联网以前已经存在 **search-radius expansion（搜索半径扩张）**。

互联网不是第一次让陌生人互相发现。

## 3. 搜索半径扩大，不等于后续生活摩擦消失

2007–2009 年对丁乃钧的回访资料讲述了征婚后收到大量来信、跨地域接触并最终形成婚姻的经历；这些材料属于多年后回忆，不能单独用来钉住精确数量或每一步时间。

来源示例：

- 《新中国第一条征婚启事主人公娶到吉林姑娘》，2007-08-02：  
  <https://shuangyashan.dbw.cn/system/2007/08/02/050918628.shtml>
- 《新中国公开征婚第一人》，2009 年回顾：  
  <https://style.sina.com.cn/news/2009-10-10/101649707_2.shtml>

这些回忆真正有价值的地方，不是“传奇”，而是提醒我们：

> **找到远方的人，只是把关系带进新的迁移与定居问题。**

一个跨地区伴侣关系还会遇到：

- 谁迁移；
- 到哪个城市生活；
- 工作能否转移；
- 与双方父母距离；
- 住房；
- 通信与见面成本。

所以：

> **wider search radius ≠ wider executable marriage radius**。

# 第二部分：中国网络边界——不能从婚恋网站倒推 1990 年代大众联网

## 4. 1987 / 1994 / 1995 必须分开

中国网信办 2024 年互联网史回顾明确区分：

- 1980 年代已经有国际联网项目与电子邮件前史；
- 1994 年 4 月 20 日，64K 国际专线使中国实现与国际互联网的全功能连接；
- 此后公共骨干网和公众接入继续建设，普通人接触互联网是后续扩散过程。

来源：

- 《中国全功能接入国际互联网30周年述评》，2024-04-20：  
  <https://www.cac.gov.cn/2024-04/20/c_1715291120716362.htm>

因此本篇固定：

```text
科研 / 邮件 / 专线等前互联网数字通信
≠ 全功能接入国际互联网
≠ 商业公众接入
≠ 普通家庭可及
≠ 大规模日常化
```

世纪之交及 2000 年代婚恋网站的出现，不能被倒写成“1994 一联网，普通人就开始在家上网相亲”。

# 第三部分：2005–2012——扩张型未来与“候选池扩张”

## 5. 2008：条件第一次变成用户自己可以即时查询的字段

2008 年《中国青年报》同期报道留下了非常具体的操作行为。一名被报道为“小周”的用户在世纪佳缘搜索栏输入：

- 年龄；
- 学历；
- 月薪；

几秒后页面返回几十名符合条件的人。他把“自主搜索、随时登录、选择更多”作为自己反复使用婚恋网站的原因。

同期保存页：

- 《逾3成网民网上觅姻缘 网恋将成国人主流婚恋方式》，中国新闻网转载《中国青年报》，2008-03-03：  
  <https://www.chinanews.com.cn/sh/news/2008/03-03/1179413.shtml>

### 证据角色

**B：同期记者对用户操作与页面机制的记录。**

文章还引用一项由婚恋网站和行业组织实施、154386 人参与的网络调查。它可以证明“当时行业正在测量这种行为、受访网民中已有大量使用经验”，但不能拿来外推全体中国青年。

### 新机制：profile legibility

熟人介绍里，一个人通常是：

> “我同事的表弟，人挺老实，在某单位。”

数据库搜索里，一个人先变成：

```text
age
education
salary
location
occupation
...
```

这提高了候选人的 **comparability（可比较性）**。

但必须固定：

> **field value ≠ verified reality**。

资料字段是平台允许用户表达 / 填写 / 认证的信息模型，不应自动当作经过独立核验的真实人生。

## 6. 自主搜索增加，不等于“家庭退出婚恋”

网络婚恋常被写成青年“从父母和媒人手里夺回选择权”。这只说对了一部分。

2008 的在线搜索确实提供了新的 search autonomy：

```text
本人定义条件
→ 本人查询
→ 本人浏览候选
```

但是婚姻后续仍会重新进入：

- 父母意见；
- 城市与户口；
- 房屋；
- 双方工作；
- 婚礼与家庭成本；
- 生育与照护预期。

因此需要区分：

> **partner-discovery autonomy ≠ household-formation autonomy**。

一个人可以完全自己找到对象，却仍要依赖父母首付；也可以由父母先找到候选，但最终拒绝见面。

## 7. 2008：“毕业就结婚”证明标准人生脚本已经出现多个可执行版本

同年《中国青年报》关于“毕婚族”的同期采访，是本轮最重要的“未来想象”材料之一。

来源：

- 《“毕婚族”：就算一无所有 但至少拥有爱情》，中国青年报，2008-05-12：  
  <https://zqb.cyol.com/content/2008-05/12/content_2175746.htm>

这里至少出现四种不同脚本。

### 路线 A：没有买房，仍计划毕业结婚

北京师范大学研二学生“小莲”清楚知道双方家庭无法提供很好的经济条件，也预计北京房价高，五年内可能一直租房，但仍计划毕业后进入婚姻。

她想象的五年后不是“先拥有房产再结婚”，而是：

```text
毕业
→ 结婚
→ 租房若干年
→ 两个人一起承担后续不确定性
```

这是非常重要的反例：

> **homeownership can be a future project after marriage, not always a prerequisite before marriage.**

### 路线 B：父母住房支持使婚姻迅速可执行

陈敬恩与耿倩已有工作 offer，双方父母帮助首付，住房因此成为“现在为什么不结婚”的条件之一。

### 路线 C：户口 / 单位住房把结婚日期推到毕业前

王珊珊当时仍未找到合适工作，担心户口转移麻烦，而伴侣单位已有住房，因此两人选择先领证。

这里的婚姻时间不是纯粹感情时间，而是：

```text
感情稳定
× 毕业
× 工作
× 户口
× 单位住房
```

### 路线 D：明确坚持“物质基础先行”

另一名研究生刘晓川认为房子和孩子都需要物质基础，因此不准备毕业即婚。

### 样本边界

文章的在线调查有 1897 人参与，不能视为全国大学毕业生代表性统计。它的最高价值是保存了**同期人如何描述未来顺序**。

## 8. 2008 的反证：“扩张型未来”也包含延迟和拒绝

同年《中国青年报》“恐婚”调查报道保存的第一人称说明，不能把 2005–2012 写成所有青年都乐观进入婚姻。

来源：

- 《调查发现中国离婚率增高造成“恐婚族”》，中国青年报经中国新闻网保存，2008-07-11：  
  <https://www.chinanews.com.cn/sh/news/2008/07-11/1309192.shtml>

文章中的人谈到：

- 跨地区家庭礼俗的麻烦；
- 婚后生育与长期责任；
- 继续学习 / 出国的可能；
- 结婚可能让某些未来“定格”的担忧。

这说明同一个“扩张型未来”里同时存在两种心理：

```text
未来选择更多 → 两个人可以一起闯
```

也可以是：

```text
未来选择更多 → 不愿太早关闭其他路线
```

因此不要把今天的婚恋迟疑倒投回 2008，也不要把 2008 统一浪漫化。

# 第四部分：2015–2019——候选更多以后，为什么反而会“拥堵”

## 9. 2019：公园相亲角仍然是“纸质数据库 + 家长搜索代理”

人民网 2019 年的现场报道记录了北京中山公园相亲角。出生于 1993 年的“小琪”本人到场，她把自己直接站在现场称为最好的“简历”；大量家长则把孩子的：

- 年龄；
- 学历；
- 户口；
- 收入；
- 工作；

写在纸上交换和比较。

来源：

- 《中国为什么会有“相亲角”？》，人民网，2019-10-24：  
  <https://politics.people.com.cn/n1/2019/1024/c429373-31417696.html>

### 关键比较

2008 婚恋网站：

```text
profile fields
→ database query
→ results
```

2019 相亲角：

```text
profile fields
→ paper card / person
→ parents scan & ask
```

两者在技术上很不一样，却共享同一种社会操作：

> **把复杂的人生先压缩成若干可比较条件，再决定是否投入进一步了解的时间。**

因此“平台化”并不只发生在手机屏幕上。

## 10. 父母可以成为 search agent，而不是单纯“传统残余”

2019 年《中国青年报》采访 29 岁陈铭时，记录他的母亲两年内从义务红娘处拿走过七八名女孩的信息；当红娘询问他想找什么样的人时，他又直接让母亲回答。

来源：

- 《我的婚姻谁做主？晚婚时代两代人的婚姻观分歧加大》，中国青年报经中新网保存，2019-09-06：  
  <https://www.chinanews.com/gn/2019/09-06/8948850.shtml>

这个个案不能代表所有青年，但它证明一种长期存在却很容易被“互联网个人主义”叙事抹掉的路线：

```text
adult child
→ delegates part of search to parent
→ parent filters candidates
→ adult child may or may not execute the contact
```

我把它称为 **intergenerational co-search（代际共同搜索）**。

它可以是：

- 本人主动授权；
- 勉强配合；
- 父母先做、本人后来才知道；
- 父母和本人并行搜索。

这些状态必须分开。

## 11. “拥堵”不是没有候选，而是匹配条件、注意力和意愿无法自动对齐

2019 年已经同时存在：

- 婚恋网站；
- 社交 App；
- 微信群；
- 微信公众号；
- 公园相亲角；
- 红娘与线下活动。

《中国青年报》一份 1972 名单身青年的网络调查中，大量受访者表示注册过婚恋平台并看重大数据匹配或扩展社交圈。

来源：

- 《78.8%受访单身青年在婚恋交友平台注册过》，中国青年报经人民网保存，2019-09-19：  
  <https://media.people.com.cn/n1/2019/0919/c40606-31361024.html>

这仍是网络调查，绝不能外推为全国单身人口比例。

但它和同期个人材料放在一起可以支持一个机制：

### matching congestion（匹配拥堵）

候选越多以后，新的稀缺资源变成：

- 谁真的单身；
- 谁真的愿意见面；
- 条件是否真实；
- 谁值得花一个晚上聊天；
- 双方父母是否接受；
- 城市、住房、工作未来是否兼容；
- 对婚姻质量的期待是否相容。

因此：

> **candidate abundance ≠ relationship abundance**。

# 第五部分：2020–2022——偶发性如何进入亲密关系的计划

## 12. 本轮不强行新增疫情婚恋结论

仓库已有疫情专题，2020–2022 的出行、封控、就业和不确定性已经有较强覆盖。

本轮没有找到一组比现有材料明显更强、同时又能直接改变“伴侣搜索基础设施”模型的一手材料，因此不为了填满四格而硬凑。

这一时期本专题只保留一个待验证命题：

> 当见面、跨城移动和线下活动具有偶发中断风险时，线上联系可以继续，但 **contact continuity ≠ embodied courtship continuity**。

后续若找到同一普通账号在 2019 / 2020 / 2021 的连续婚恋日记，再单独补强。

# 第六部分：2023–2026——婚姻从默认节点转向更审慎的“可选项目”

## 13. 2024：单身生活可以满意，同时仍对亲密关系开放

2024 年《中国青年报》同期采访记录 34 岁北京单身青年“周亚玲”的生活：她满意自己决定消费、饮食、娱乐、健身和兴趣的节奏，也承认有时会孤独；她并不排斥恋爱结婚，只是主动寻找动力不足，并用“不急不躁，宁缺毋滥”描述未来伴侣标准。

同文中的 28 岁“张钰”一方面会因负面婚姻叙事和家庭经历觉得“一个人也能过”，另一方面又明确表示现在希望遇到能相互信任、扶持的人。

来源：

- 《年轻人婚恋更看重情感质量》，中国青年报经中新网保存，2024-05-30：  
  <https://www.chinanews.com.cn/life/2024/05-30/10225531.shtml>

### 新机制：single-life optionality（单身生活可持续性）

这不是“拒婚”。

更准确的状态是：

```text
单身生活本身可执行
+ 亲密关系仍有吸引力
+ 进入关系需要更高质量阈值
```

因此今天的防守型未来不能简单写成“悲观所以不结婚”。

它也可以是：

> 当前生活不至于因为没有伴侣而立即失去可执行性，所以关系必须提供足够真实的增量价值，才值得改变现有生活结构。

---

## 14. 2025：“轻相亲”把条件过滤和真实互动重新排序

2025 年《中国青年报》报道一组兴趣互动式“轻相亲”。

27 岁石家庄白领“姚瑶”说身边男性少，又觉得纯网恋风险高；她愿意参加周末派对、桌游、聊天等活动，把“认识人”和“必须立即确定婚恋结果”暂时分开。

北京理工大学硕士生“陈熙”则参加公众号组织的“一周 CP”：先填基本资料和匹配要求，系统一对一匹配，随后加微信，用七天任务推进从自我介绍、共同游戏、听音乐、打电话到线下见面。

来源：

- 《青年青睐“轻相亲” 73.9%受访者表示周围有人尝试过》，中国青年报，2025-03-31：  
  <https://zqb.cyol.com/pc/content/202503/31/content_409091.html>

### 不是“条件消失”，而是条件与互动次序改变

旧式条件优先模式可以写成：

```text
先看年龄 / 学历 / 收入 / 户口 / 房
→ 再决定是否聊
```

部分“轻相亲”尝试则更接近：

```text
少量基本条件预筛
→ 一段低压力共同活动
→ 再判断是否愿意进入关系
```

因此更准确的概念是 **interaction-first matching（互动优先匹配）**，而不是“年轻人不看现实条件了”。

调查同样来自问卷网的 1339 人样本，只能作为同期受访者分布，不能外推全国青年。

## 15. 2025：父母也进入 App——相亲角不是消失，而是被数字化扩半径

2025 年《中国青年报》记录 29 岁“赵敏敏”发现母亲已经在相亲软件替她搜索；界面显示有大量父母查看其信息与“潜在亲家”。她本人期待亲密关系，却不希望父母过度介入。

另一名“刘欣”则采用明确协作：自己在一个 App 匹配，同时让父亲在另一个相亲渠道先筛选候选，再由她见面，称之为提高效率。

同文还记录部分父母端界面的大字号、每日推荐、会员付费、父母交换子女联系方式等产品形态。

来源：

- 《“爸妈替我在线相亲”：助力还是越界》，中国青年报，2025-05-03：  
  <https://zqb.cyol.com/pc/content/202505/03/content_410532.html>

### 这改变了什么

2004–2019 的公园相亲角受城市地理约束：

```text
父母必须到某个公园
→ 浏览当地出现的卡片和人
```

父母端 App 则可能变成：

```text
父母在家
→ 搜索更大地理范围的资料
→ 父母先沟通
→ 子女再决定是否接触
```

所以新的不是“父母重新掌权”，而是 **intergenerational search itself becomes networked**。

而且存在两种相反路线：

- 子女主动授权父母协助；
- 子女不知情 / 不愿意，父母先建立候选池。

必须分别编码。

# 第七部分：海外对照——网络化陌生人交流远早于 Web

## 16. 法国 Minitel，1987：文字网络已经进入陌生人夜间社交

1987 年《世界报》同期报道一名 28 岁、使用化名 “Hitchcock” 的 Stéphane。他在 Minitel messagerie 网络上长期交流，有时每天使用数小时，特别强调夜间网络谈话和遇见各种陌生人的吸引力。

来源：

- Le Monde, “Hitchcock sur la ligne…”, 1987-01-11：  
  <https://www.lemonde.fr/archives/article/1987/01/11/hitchcock-sur-la-ligne-au-coeur-de-la-nuit_4022989_1819218.html>

### 样本边界

这个人是高收入公司职员，且电话费用由公司承担，明显不是“普通法国人”的代表样本。

它能证明的是：

> **在 WWW 以前，家庭 / 办公终端上的文字网络已经可以承载匿名或半匿名陌生人社交。**

而不是“1987 年法国人都网上约会”。

---

## 17. 1988：Minitel 已有相当规模，但使用仍然有成本与高度不均

1988 年《世界报》根据 France Télécom 年度数据报道：1987 年末法国安装的 Minitel 达约 337.3 万台，相当于电话订户的 14%；France Télécom 估计，在家庭或工作地点能接触终端的人占 15 岁以上人口约 20%、就业人口约 30%。

来源：

- Le Monde, “Le deuxième souffle du minitel”, 1988-04-21：  
  <https://www.lemonde.fr/archives/article/1988/04/21/reflux-des-messageries-hausse-des-services-professionnels-le-deuxieme-souffle-du-minitel_4102726_1819218.html>

文章同时记录连接费用仍被很多用户认为昂贵、重度用户占流量很大。

这正好避免另一个常见错误：

```text
networked social service exists
≠ everyone owns terminal
≠ everyone can afford long sessions
≠ everyone uses it for courtship
```

### 中法共同点与差异

共同机制：

- 异步 / 文字化交流扩大陌生人接触；
- 化名与身份不确定性随之出现；
- 网络费用、终端位置与接入条件影响谁能长时间使用。

中国更需要单独解释的，是：

- 2000 年代公众互联网的扩散时点；
- 婚恋网站把学历、收入、户口、住房等显著生活条件字段化；
- 父母搜索代理长期存在，并可从公园转入 App；
- 住房、城市迁移、户口和工作与结婚准备度高度耦合。

不能把中国写成 Minitel / Match.com 的延迟复制。

# 第八部分：四种未来时间感的比较

## 18. 2005–2012：扩张型未来

本专题新增的机制不是“大家更想结婚”，而是：

### 候选池扩张 + 人生脚本仍有较大试错想象

2008 年材料同时存在：

- 网上自己搜更多候选；
- 毕业即婚；
- 预计五年内租房、两个人一起承担；
- 因住房和户口提前结婚；
- 因未来留学 / 职业 / 责任而推迟婚姻。

因此扩张感的核心是：

> **未来似乎有很多可以继续解决的问题，婚姻既可能是共同闯未来的起点，也可能是过早关闭其他未来的风险。**

---

## 19. 2015–2019：拥堵型未来

到了 2019，认识人的渠道更多，但：

- 平台候选多；
- 公园卡片多；
- 父母和本人可能同时筛；
- 对住房、城市、职业、价值观、婚姻质量的要求叠在一起。

因此出现：

> **more searchable candidates + more comparison dimensions + more family negotiation = not necessarily faster matching**。

“拥堵”可以发生在关系形成之前，而不只是买房 / 找工作之后。

---

## 20. 2020–2022：偶发型未来

本轮没有用弱证据硬填。

保留待验证命题：

- 线上联系可保持；
- 线下见面和跨城关系更容易被突发规则打断；
- 关系时间表可能因此变成可延期、可暂停的项目。

需要连续个人材料才能写得更强。

---

## 21. 2023–2026：防守型未来

2024–2025 的同期材料显示的不是统一的“婚姻悲观”，而是：

- 单身生活本身可以维持；
- 仍有人渴望可靠亲密关系；
- 更强调关系质量、相互扶持与风险判断；
- 传统高压力相亲可被重新包装成低压力社交；
- 父母继续参与，但其参与是否被授权成为新的边界。

可以暂时称为：

### relationship-risk gating（关系风险门控）

即：

> **不是完全退出关系市场，而是在进入下一阶段以前增加核验、互动和主观质量阈值。**

这个命题仍需更多 2023–2026 第一人称材料交叉验证。

# 第十部分：重要反例与后见之明风险

## 22. 不能写“互联网让婚恋从包办走向自主”

原因：

- Web 前已有个人主动报纸征婚；
- Web 后父母仍可能承担大部分搜索；
- 同一个人还可以主动授权父母协助。

更准确：

> **媒介改变搜索分工，不保证代际权力按单一方向变化。**

---

## 23. 不能写“网上条件化导致婚恋功利化”

收入、职业、年龄、地域等条件在 Web 前就存在于征婚、婚介和家庭判断中。

互联网更明确改变的是：

- 字段化；
- 查询速度；
- 候选规模；
- 排序 / 筛选方式；
- 联系成本。

价值观变化与平台字段之间的因果关系需要另证。

---

## 24. 不能把诈骗与身份虚假写成互联网独有

报纸征婚与传统婚介时代同样存在身份与欺骗问题。

互联网扩大陌生人接触以后，验证问题会改变规模和技术形态，但不是凭空出现。

---

## 25. 不能把“注册用户”写成“真实可约会人口”

一个账号可能：

- 已经离开；
- 已婚但未删除；
- 长期不登录；
- 资料过期；
- 不回复；
- 由父母维护；
- 只是浏览；
- 重复账号。

所以：

> **registered profile count ≠ active candidate pool**。

---

## 26. 不能从成功故事推平台成功率

平台和媒体更容易报道：

- 成功结婚；
- 戏剧性骗局；
- 典型冲突。

最普通的状态——聊两天、没感觉、停止联系——反而很少被保存。

这会产生强烈的 **outcome visibility bias（结果可见性偏差）**。

# 第十一部分：已知、合理推断与未知

## 27. 已知

- 中国 Web 前已经存在报纸征婚、婚介所和其他扩大陌生人接触的媒介；
- 1994 全功能接入国际互联网不能等同于普通家庭立即普及；
- 2008 同期材料直接观察到婚恋网站按年龄、学历、月薪等字段搜索候选；
- 2008 同期第一人称呈现了“毕业即婚 / 继续租房 / 住房父母支持 / 户口接口 / 先立业再成家”等多个真实并存脚本；
- 2019 相亲角与网络平台并存，父母仍可充当搜索代理；
- 2024–2025 第一人称材料显示“满意单身但仍开放亲密关系”“互动式轻相亲”“父母在线协助”等路径；
- 1980 年代法国 Minitel 已能承载大规模文字网络与陌生人社交，说明这一机制早于 Web。

## 28. 合理推断

- 网络婚恋最大的历史变化之一是把候选池从熟人关系网扩展成可查询数据库；
- 候选扩张以后，验证、注意力和条件协调成为更突出成本；
- 婚姻搜索自主性与婚后经济独立不是同一变量；
- 当单身生活越来越可持续时，关系进入的质量阈值可能提高。

这些都是 D 级机制，不应写成已经证明的全国因果结论。

## 29. 尚不知道

- 2007–2010 普通婚恋网站用户从第一次搜索到第一次线下见面的真实中位耗时；
- 大量“符合条件”的搜索结果里，有多少账户当时真实活跃；
- 2008 搜索页面在 IE / Firefox、不同字符集和屏幕宽度下的真实历史呈现；
- 一个用户修改收入 / 城市 / 婚姻意愿后，旧值是否有任何公共历史保存；
- 站内信到 QQ / 手机 / MSN 的真实 handoff 比例；
- 大量没有结果、悄悄结束的联系如何系统性进入历史记录；
- 2020–2022 同一普通人的关系形成过程究竟被偶发中断改变多少。

---

# 第十二部分：下一步高价值证据

最高价值目标不是再找平台“多少会员”，而是找到一条 **2007–2010 同一普通用户的多时点原生关系链**：

```text
注册 / 建 profile
→ 第一次查询
→ 收到 / 发送站内信
→ 是否付费解锁
→ 转 QQ / MSN / 手机
→ 线下见面
→ 再次联系或停止
→ 数月后 profile 更新 / 删除 / 继续寻找
```

如果能拿到两个以上历史时点，并且不重新公开敏感个人信息，就能第一次真正观察：

> **一个数据库里“符合条件的人”，到底怎样——或者为什么始终没能——变成现实生活里的伴侣。**
