# 从“选一条路”到“同时保留几条路”：申请组合、资格窗口与制度化未来，中国 2003–2025

## 研究问题

一个年轻人毕业时“有多少种活法”，不能只按最终去向计数。

如果只看最后结果，一个人可能最终只成为：

- 研究生；
- 公务员；
- 事业单位职工；
- 企业职工；
- 或继续待业。

但在真正作决定的几个月里，他/她完全可能同时维护多条尚未关闭的路线：

```text
秋招投递
+ 研究生考试
+ 国家/地方公务员考试
+ 选调/事业单位考试
+ 职业资格考试
+ 其他城市或单位的招聘
```

本笔记把这种状态称为 **application portfolio（申请组合）**，把同时或连续维持多条制度化路线称为 **route multiplexing（路径复用 / 多路并行）**。

它和仓库已有的 optionality 不完全相同。optionality 是“保留未来选择”的一般目标；application portfolio 则是它的一种可观察实现：一个人已经实际填写表格、报名、备考、投递、面试或等待资格审查，使若干未来仍保持为“活的候选项”。

核心结论有三点：

1. **这种多路线策略不是 2020 年代才出现。** 2008 年的同时代材料已经记录毕业生半年参加六类大型考试，把每一次报考都理解为增加一个机会。
2. **互联网没有发明多路线人生，但降低了部分路线的申请、查询和状态维护摩擦。** 2003–2005 年研究生、公务员招考逐步把报名、资格审查、确认、准考证等环节迁到网络，使“申请一个未来”越来越像维护一条带状态的制度流程。
3. **不同时期变化的，未必是“有没有多条路”，而是为什么要保留它们、保留多久、以及哪些资格会过期。** 2008 年可以是扩大机会；2019 年可以是避免过早定型；2023 年以后则常能看到把稳定岗位作为风险对冲，同时仍保留市场岗位的组合。

## 一、2003–2005：制度路线开始变成可以远程提交和查询状态的对象

### 1. 研究生报名：网络化和“单位盖章”退出几乎同时发生

2003 年教育部说明 2004 年硕士招生改革时，列出两个彼此不同、但对普通报考者都很具体的变化：

- 报考时不再要求所在单位出具同意证明，报名登记表也不再要求所在单位签署意见并盖章；
- 部分招生单位试点网上报名，网上试点报名入口为 `chinayz.com.cn`。

这两项变化不能混成一个“互联网带来报考自由”的因果故事。前者是制度授权接口变化，后者是技术/操作接口变化；它们只是恰好共同减少了报考者需要穿过的若干门槛。

到 2005 年硕士招生，教育部规定考生一律网上报名；但 2004 年 11 月的同期提醒又明确说，网上提交后仍必须在指定报考点现场确认、缴费、照相，否则报名无效。

所以当时的真实流程更接近：

```text
制度上获得报考资格
→ 网上填写申请
→ 在报名窗口内修改/校正
→ 现场确认
→ 缴费/照相
→ 报名真正生效
→ 考试
```

这和“纸表换成网页”不同。它开始把一个人生选择拆成一系列可查询、可修改、会失效的状态。

### 证据

- **A（官方同期政策说明）**：教育部，2003-08-09，《教育部负责人详解研究生招生政策新变化》；取消所在单位同意/盖章要求，并在部分招生单位试点网上报名。  
  <https://www.moe.gov.cn/moe_879/moe_329/moe_296/tnull_2998.html>
- **A（官方同期招生通知）**：教育部，2004-08-25，《关于做好2005年招收攻读硕士学位研究生工作的通知》；2005 年硕士考生一律网上报名，报名期内可修改信息。  
  <https://www.moe.gov.cn/srcsite/A15/moe_778/s3113/200408/t20040825_79970.html>
- **A（官方同期提醒）**：教育部，2004-11-04；全国网上报名后仍须 11 月 10–14 日到报考点确认、缴费、照相，否则网报无效。  
  <https://www.moe.gov.cn/jyb_xwfb/gzdt_gzdt/moe_1485/tnull_4354.html>

### 研究边界

**online application ≠ completed application**。

而且：

**technical simplification ≠ institutional simplification**。

一个制度可以同时发生“取消单位盖章”和“改为网络报名”；研究时必须分别寻找各自的法律/政策与技术证据，不能自动把前者归因给后者。

## 二、2003–2006：公务员报考形成“提交—审查—确认—准考证”的数字状态链

2003 年中央、国家机关招考已有 360,240 人通过互联网报名，其中 181,488 人通过招考部门审核。这里最值得注意的不是人数本身，而是“网上报名人数”和“审核通过人数”已经被制度明确区分：**提交申请**和**获得资格**是两个状态。

2005 年发布的 2006 年中央、国家机关招考公告又把流程进一步拆开：网络报名、不设现场报名；资格审查通过者还要完成报名确认；部分省市可网上上传照片并缴费，其他地区仍现场确认；最后再自行下载打印准考证。

同一时期的地方招考也能看到类似状态机。青岛 2006 年公安人民警察招考规定，报考者网上提交资料，用人单位网上进行资格初审；申请者可在提交 24 小时后查询初审结果，通过后再打印报名登记表、诚信承诺书和准考证主证，并到指定地点现场认定。

从普通人的角度，一项“报考公务员”的人生动作已经不是一次性递交材料，而越来越像：

```text
找到职位
→ 比对资格条件
→ 网上提交
→ 等待资格审查
→ 查询审查结果
→ 确认/缴费/上传照片
→ 取得报名序号或准考证
→ 参加考试
→ 等待后续结果
```

每一层都可能让一条未来继续存活，也可能让它关闭。

### 证据

- **B（同期媒体转述人事部门统计）**：中新网，2003-11-02；2004 年中央、国家机关公务员招考 360,240 人经互联网报名，181,488 人通过审核。  
  <https://www.chinanews.com.cn/n/2003-11-02/26/363811.html>
- **B/A-near-primary（同期公告转载，来源标注为官方）**：搜狐，2005-10-12，《中央国家机关2006年考试录用公务员公告》；报名、确认、照片、缴费、准考证等流程。  
  <https://business.sohu.com/20051012/n240528095.shtml>
- **A（政府站保留的同期招考简章）**：青岛市相关人社/政务页面，2006 年招考公安人民警察简章；网上报名、资格初审查询、打印材料与现场认定。  
  <https://hrss.qingdao.gov.cn/zxzx_47/gzdt_47/202206/t20220613_6129786.shtml>

## 三、互联网减少的是“维护一条申请”的部分摩擦，不是多路线策略本身的起点

这里最需要防止技术决定论。

纸质时代的人当然也可以同时报名多所学校、参加多个招聘、托熟人寻找不同岗位。互联网没有创造“多投几个试试”的行为。

它更可能改变的是几类 **application friction（申请摩擦）**：

- 获取公告和职位表；
- 重复填写标准化信息；
- 在截止日前修改信息；
- 查询资格审查状态；
- 获取准考证/结果；
- 远距离完成本来需要专程前往的某些步骤。

与此同时，网络化也会增加新的依赖：

- 设备和网络接入；
- 身份信息格式；
- 照片规格；
- 在线支付；
- 浏览器兼容；
- 截止时间；
- 账号、报名号和密码管理。

所以更准确的命题是：

> **digital application can lower some marginal costs of keeping another route alive, without making the portfolio costless.**

数字申请可能降低“再多维护一条路线”的边际操作成本，但不会消除备考、交通、住宿、时间和机会成本。

这与仓库已有的 `document-gated connectivity`、`transaction stack` 可以直接相连，但研究对象不同：这里关心的不是“能否上网”或“能否完成支付”，而是**多少个制度化未来能在同一段时间里保持为有效候选项**。

## 四、2008：同时代第一人称已经出现明确的“多考一场，多一个机会”逻辑

2008 年 3 月的一篇同期报道记录烟台一名大四学生“房甲”的学年计划：从前一年 11 月到次年 5 月，依次准备国家公务员、研究生、选调生、地方公务员、企事业单位、职业资格等六类考试。

报道中的关键不是把他当成“2008 年大学生平均值”，而是这份个案清楚证明：

- 多路线申请在当时已经是一种可以被本人明确表述的毕业策略；
- 各类考试时间相对错开，使同一个人能够一路参加；
- 这种 optionality 很昂贵，需要复习材料、报名、交通、住宿乃至培训；
- 个案本人把“再参加一场”理解为增加一次前途机会。

这说明所谓 2005–2012 的“扩张型未来”不能理解成“年轻人只需要选一个高速增长行业就行”。另一种非常普通的扩张方式恰恰是：**相信多试几条制度路线，总有一条可能打开。**

### 证据

- **B（同期采访/生活材料）**：中国教育和科研计算机网转载同期报道，2008-03-28，《考“公”考研考选调 透视毕业生“赶考”热》。  
  <https://www.edu.cn/edu/jiao_yu_yan_jiu/200803/t20080328_288080.shtml>

### 反例：2008 年的“稳定”不能被今天倒灌成唯一动机

同年金融危机后的中国青年报调查显示，2009 届受访者中希望去政府、国企的比例相对前一届调查有所提高，但“自主创业”也大幅增加；而且两轮调查使用的平台并不完全相同，不能直接当严格纵向面板。

这组材料恰好提醒：冲击后的路线重排不等于所有人同时只想“求稳”。在同一个时点，**政府岗位、国企、外企、创业可以同时被重新估值**。

- **B（同期调查报道）**：中国青年报，2008-12-11，《金融危机下大学生首要职业目标悄然转向》。  
  <https://zqb.cyol.com/content/2008-12/11/content_2466836.htm>

因此对 2008 年更稳妥的说法是：

> **shock can reweight an application portfolio without collapsing it into one route.**

冲击会改变申请组合中各条路线的权重，不一定把组合本身消灭。

## 五、2019：“慢求职”不是没有路线，而可能是暂时拒绝过早锁定

2019 年 11 月江苏一次大型高校毕业生招聘会的同期现场报道提供了很有价值的第一人称材料。

受访毕业生张雨婷在招聘会只投了三四份简历，表示自己尚未想好未来，不愿太快把自己“定型”；同场其他学生所在宿舍或班级里，同时存在考研、考公务员、考银行、考教师资格证和求职等安排。

报道还指出，二次考研、二次公考等会延长毕业后的求职周期。

这里出现了和 2008 年不同的时间机制：

### 2008 的组合

```text
多报一些
→ 多获得几次机会
→ 尽快让某条路线成功
```

### 2019 的组合（至少对部分人）

```text
先让多条路线保持开放
→ 观察结果/继续备考
→ 不急于用第一个可得工作把自己锁定
```

我把后一种机制称为 **deferred lock-in（延迟锁定）**。

它并不意味着所有“慢就业”都来自主动选择：家庭支持、经济压力、岗位质量、考试失败、情绪状态等都可能改变一个人能拖多久。这里只能证明 2019 年同期已经存在“我不想太快定型”这种明确自述。

### 证据

- **B（同期招聘会现场采访）**：中国江苏网，2019-11-17，《江苏高校毕业生“招聘大集”开锣 大学生进场“慢求职”》。  
  <https://jsnews.jschina.com.cn/jsyw/201911/t20191117_2425831.shtml>
- **B（同期同场采访，另一媒体）**：荔枝网/江苏新闻广播，2019-11-16；记录考研、公考、银行、教师资格证与招聘会并存，以及部分学生“不想马上上班”的表达。  
  <https://news.jstv.com/a/20191116/cec9ee564d6b4b36a9b22d31852d6ce7.shtml>

两篇都来自同一场招聘活动，不能完全当成互相独立的社会样本，但采访对象和报道组织不同，可以用于交叉理解当天的 route portfolio。

## 六、2023：防守型未来不是“没有别的 offer”，而可能是把稳定路线放在组合顶端

2023 年出现了一个很强的反例，能纠正“考公=市场上无路可走”的简单叙事。

界面新闻同期访谈的一名 25 岁研究生刘晓豪：

- 累计报名 13 场公务员考试，实际参加 7 场，跨江苏、广东、上海、河南、湖北等地；
- 同时向国企、央企等投递 100 多至近 200 份简历；
- 已拿到十多个 offer，仍继续巡考；
- 最多出现四场考试同日冲突，需要主动放弃其中若干场；
- 他明确把公务员置于首选，但又表示如果不能上岸，会去国企/央企入职。

这个个案当然不能代表所有考公者，却直接证明了一种 **defensive portfolio（防守型申请组合）**：

> 一个人不是因为“没有任何工作”，才保留稳定路线；他也可能在已经拥有多项市场/国企选择时，继续把更稳定或更符合长期偏好的制度岗位保留到最后。

更重要的是，组合越大，摩擦并没有趋近于零。考试日期会撞车，城市之间要移动，报名费、交通、住宿和备考时间都会累积。所谓“多投几条路”最终受到人的 24 小时和身体位置约束。

另一篇 2023 年中国青年报报道中，吴江半年报考 26 个事业编岗位、在湖南多地巡考后才录用；22 岁的小春则在毕业后全职准备考公考编。这说明“巡考”已经形成一个当时人自己使用的行为类别，但仍不能把它推广为整个毕业生群体的主流路径。

### 证据

- **B（同期深度访谈）**：界面新闻，2023-04-04，《手握十多个offer，我为什么还要加入公务员巡考大军？》。  
  <https://www.jiemian.com/article/9180324.html>
- **B（同期采访）**：中国青年报，2023-04-11/12，《巡考大军：为“上岸”放手一搏是否值得》。  
  <https://dxs.moe.gov.cn/zx/a/jj/230412/1835841.shtml>

## 七、2024–2025：路线不仅有成本，还有“资格保质期”

一个申请选项是否还活着，不只取决于本人愿不愿意继续。

年龄、毕业年份、工作经历、是否仍属于某种“应届”口径、档案/就业状态，都可能决定某条制度路线还能否报名。

这可以定义为：

## eligibility horizon（资格视野）

> 一个制度选项在人的生命历程中，还能合法/制度性保持开放多长时间？

2025 年江苏事业单位招聘提供了一个很清楚的例子：部分面向 2025 届毕业生的岗位，也允许符合条件、仍未落实工作单位且相关关系保留在规定机构的 2023、2024 届毕业生报考。官方报道还明确把这一变化描述为对应届毕业生身份认定的进一步放宽。

这里不能推广成全国所有事业单位统一规则，但它证明：**“应届身份”不是纯自然年龄标签，而是一种可以被政策定义、延长或缩短的制度资格窗口。**

同一平台又把这种资格变成可查询的状态：提交信息和照片后，申请者等待资格初审，再回到系统查看结果；有些岗位还保留陈述申辩和异议处理窗口。

2024 年的另一条同时代材料则显示，已经在知名互联网企业工作的张璐仍第二次参加国考，并把家庭对“安稳工作”的期待作为自己的报考背景之一。它不能代表所有在职考公者，但说明防守型路线也可以在“已有工作”之后继续存活。

### 证据

- **A/B（江苏省政府门户转载官方招聘信息）**：2025-03-20，江苏事业单位联考 6200 余岗位，并说明应届毕业生身份认定进一步放宽。  
  <https://www.jiangsu.gov.cn/art/2025/3/20/art_90848_11520906.html>
- **A（江苏省人社厅招聘公告）**：2025 年具体公告示例；2023、2024 届在满足未落实工作单位等条件时可应聘面向 2025 届岗位；报名、照片、资格初审、结果查询均在线。  
  <https://jshrss.jiangsu.gov.cn/art/2025/3/10/art_78506_11512525.html>
- **B（同期考试现场采访 + 官方人数）**：中国青年报客户端，2024-12-01；在互联网企业工作的张璐第二次参加 2025 年度国考。  
  <https://news.cyol.com/gb/articles/2024-12/01/content_xaGjlycVxO.html>

## 八、学历记录也在变：从“拿着证书”到“数据库中可查询的资格事实”

application portfolio 还有一个更底层的支撑：有些人生记录开始从纸质凭证变成制度数据库中的可查询记录。

学信网 2009 年发布的官方沿革说明：

- 2001 年起实行高等教育学历证书电子注册制度；
- 2002 年回登 1991–2000 年学历证书信息；
- 2005 年学信网被指定为高等教育学历证书查询网站。

这可以称作 **credential queryability（资格记录可查询化）**。

但这里必须特别克制：

> **credential database exists ≠ every recruitment portal automatically queried it**。

数据库存在，只证明某类学历事实可以被制度化查询；除非有接口、操作手册或具体系统证据，不能推断某次 2005 年公务员/研究生报名已经自动联网验证学信网记录。

### 证据

- **A（官方平台沿革/制度说明）**：学信网，2009-02-09，《关于我们》。  
  <https://www.chsi.com.cn/about/200902/20090209/17223140.html>

## 九、海外对照：美国大学申请也出现“数字化 → 更大的申请组合”，但制度对象不同

1998 年《华盛顿邮报》记录一名 17 岁高中生 Reshma Shetty 申请 10 所大学：

- 一份申请完全在线提交；
- 一部分使用电子下载的 Common Application 填写后打印、发送给多校；
- 一部分使用 CD-ROM 软件复用基础信息；
- 还有一所仍用传统纸质方式。

这个案例很适合与中国早期网络报名比较，因为它显示数字化通常不是“一夜之间全部在线”，而是多渠道叠加。

到 2008 年，NACAC 数据经 *Inside Higher Ed* 报道：19% 的学生申请 7 所或更多大学，71% 申请 3 所或更多；高校收到的申请平均 68% 已经在线，较前一年提高。

这支持一个跨国共同机制：**当重复填写、投递和状态维护的操作成本下降时，较大的申请组合更容易成为现实。**

但不能从并行趋势直接推出“网络申请导致多投”。美国大学升学和中国毕业后的考研/公考/就业不是同一制度，竞争结构、费用、资格限制和人生后果都不同。

### 证据

- **B（同期第一人称/家庭技术条件）**：*The Washington Post*, 1998-04-05, “The Application Superhighway.”  
  <https://www.washingtonpost.com/archive/1998/04/05/the-application-superhighway/5f352121-31d4-41a3-b02e-233f3d622216/>
- **B（同期招生行业统计报道）**：*Inside Higher Ed*, 2008-09-23；NACAC 关于多校申请与在线申请比例。  
  <https://www.insidehighered.com/news/2008/09/23/mixed-messages-early-decision>

### 可比与不可比

可比的是：

- 标准化表格；
- 远程提交；
- 多个候选目的地同时保持开放；
- 截止日、确认和结果状态；
- 数字化降低部分边际申请成本。

不可直接类比的是：

- 美国本科多校申请主要在同一教育层级内竞争；
- 中国毕业生的 portfolio 往往跨越教育、公共部门、事业单位和企业就业等不同制度体系；
- “应届身份”、岗位资格、考试日冲突、跨城巡考等成本结构不同。

因此，这更像一个 **现代制度化生命历程的共同变化**，而不是某一个国家独有的互联网文化。

## 十、一个可复用的“申请组合”记录模型

以后研究 2000 年以后毕业生时，不应只记录 `final_outcome`。

建议至少记录：

```yaml
observation_date:
person_status:
  student_or_worker:
  graduation_year:
  city:
portfolio:
  - route_type: graduate_school | civil_service | public_institution | private_job | state_owned_job | certificate | other
    filed_or_only_considered:
    application_date:
    eligibility_deadline:
    status: considered | filed | screened_in | screened_out | exam_taken | interview | offer | withdrawn | expired
    city_or_region:
    monetary_cost:
    travel_required:
    preparation_time:
    reason_for_keeping_open:
portfolio_constraints:
  exam_collision:
  financial_limit:
  family_expectation:
  graduation_status_rule:
  age_rule:
  work_status_rule:
  physical_mobility:
final_choice:
choice_date:
retrospective_or_contemporary:
```

这个模型尤其可以把几个容易混淆的问题拆开：

- “想过考研” ≠ 已报名；
- 已报名 ≠ 参加考试；
- 进面 ≠ 一定愿意去；
- 有 offer ≠ 已锁定；
- 最终去了国企 ≠ 当时没有考公；
- 最终考公成功 ≠ 当时没有市场 offer；
- “应届生” ≠ 仅由毕业日自然决定；
- 多路线 ≠ 每条路线权重相同。

## 十一、它怎样改变四段“未来时间感”的比较

### 2005–2012：扩张型未来

新增理解不是“大家都乐观”，而是：

> **机会可以通过多报、多考、多投来累积。**

2008 年“六个月六场考试”说明，即使竞争激烈，一个人仍可能相信扩大申请面能够增加未来出口。

### 2015–2019：拥堵型未来

新增理解是：

> **路线仍多，但把哪一条变成正式人生越来越需要延迟锁定和反复比较。**

2019 年“不要太快定型”的同期表达，与二次考研/公考、秋招并行，使 coordination congestion 进入毕业季本身。

### 2020–2022：偶发型未来

本轮没有把这一阶段写成主要证据段，但 2023 巡考者回忆到考试延期、日期集中、跨城核酸与移动安排，提示需要把已有的 `reservation-horizon compression` 延伸到考试日历：

> **报名成功 ≠ 考试日期稳定；一条未来可能仍在系统里，却暂时不知道什么时候兑现。**

这仍需要更多 2020–2022 当时产生的第一人称原始材料，不能只靠 2023 回忆补写。

### 2023–2026：防守型未来

新增理解不是“人只剩考公”，而是：

> **一些人会把稳定路线作为 portfolio 中优先级更高的 hedge，同时继续保留企业、国企、地域和其他制度选项。**

2023 年“十多个 offer + 继续巡考”正是一个重要反例。

## 十二、反例与后见之明风险

### 1. 不要把 2008 写成“大家还没有稳定焦虑”

当时公务员竞争已经很高，且金融危机冲击会重新分配职业偏好。

### 2. 不要把 2008 写成今天的“考公时代”

同期数据同时显示创业、外企、国企、政府等多种目标；多路线的意义可能是扩大机会，而不是单纯躲避风险。

### 3. 不要把 2019 的“慢”全部浪漫化成主动探索

延迟可能来自考试失败、经济支持、岗位不匹配，也可能是被动停滞。第一人称只能证明某些人明确不愿过早定型。

### 4. 不要把 2023 的巡考个案当总体人口

能跨省巡考的人需要时间、交通费、住宿费、备考能力和信息获取条件，本身存在明显选择效应。

### 5. 不要把“网上报名”写成低成本

网页减少一部分文书/路程，不会替人学习，也不会解决考试撞期、跨城面试和等待周期。

### 6. 不要从最终结果倒推当时只有一条路

历史档案最容易留下录取、聘用、毕业、任职等结果；**被放弃的申请组合**通常比成功路线更难进入档案。

## 十三、重点矩阵影响

| 维度 | 本轮新增理解 |
|---|---|
| 教育 | 考研可以与求职、公考等并行，而非天然是单一路径 |
| 就业 | 最终职业不能代表当时全部申请组合 |
| 住房 | 本轮未直接建立新住房机制；工作城市选择会间接改变后续住房路径 |
| 婚姻家庭 | 家庭期待会影响 portfolio 权重，但不应自动等同于最终选择 |
| 迁移 | 跨地域考试/招聘把“城市选择”前移到报名阶段 |
| 照护 | 尚缺直接材料；值得追踪因照护限制而不能巡考/迁移的人 |
| 非正规劳动 | 本轮覆盖不足 |
| 长期中断 | 二次考研、公考可把毕业到正式就业之间拉成长周期 |
| 证件与记录 | 学历电子注册、应届身份、年龄/经历条件决定路线是否仍有效 |
| 通信方式 | 网络把公告、提交、资格审查、结果查询接进同一申请链 |
| 互联网平台 | 公共招考/招生站点成为制度入口，而不仅是信息发布页 |
| 信息获取 | “知道有一条路”逐渐与“能在线实际申请并查询状态”分开 |

| 未来预期 | 未来可以被维护成若干并行候选项，而不是先选一条再承担全部风险 |
| 线上/线下身份 | 网上提交的个人记录进入资格审查，部分流程仍需线下确认 |
| 平台消失与记忆保存 | 公开公告容易保存，个人失败/放弃的申请状态极易消失 |

## 十四、我们知道什么 / 可以推断什么 / 还不知道什么

### 我们知道

- 2003–2005 年研究生和公务员招考已经快速采用网上报名、资格查询等机制，同时保留若干线下确认环节。
- 2008 年至少有同时代受访毕业生明确同时安排多类考试，以增加机会。
- 2019 年同期招聘会材料中可以看到考研、公考、证书、求职并存，以及“不急于定型”的第一人称表达。
- 2023 年存在跨省多次巡考并同时保留大量其他工作申请/offer 的具体个案。
- 2025 年至少在江苏某些事业单位招聘规则中，“应届毕业生”资格窗口可以覆盖符合条件的前两届未落实工作单位毕业生。

### 可以合理推断

- 网络化使“再维护一个申请”的部分边际操作成本下降，并提高了制度状态可查询性。
- 申请组合是 optionality 的一种可观察形式；不同历史阶段的差异可能主要在组合的目标函数，而不只是选项数量。
- “防守型未来”可以表现为对稳定路线赋予更高优先级，而不是完全退出其他劳动力市场。
- 某些制度资格具有明确 shelf life；人的主观未来会受到资格何时失效的约束。

### 仍不知道

- 普通毕业生在 2008、2019、2024 平均同时维护多少条真实申请，而不是口头考虑多少条。
- 互联网报名究竟把单次申请的时间/金钱成本降低了多少。
- 不同家庭收入对“可以巡考多少次、可以晚多久就业”的影响有多大。
- 农村、县城、专科、高职、已经承担照护责任的人，在 route multiplexing 上与大城市本科/研究生有多大差异。
- 2020–2022 考试延期和取消怎样改变当时人的 portfolio；这一段还需要真正同期的第一人称材料。
- 数字档案能否找到匿名化、可研究的失败/撤回申请痕迹，而不触及个人隐私。

## 十五、这一轮改变了“人怎么活着”的哪一点理解

以前我们容易把人生路线画成一棵树：

```text
毕业
├── 考研
├── 考公
└── 找工作
```

这会误导，因为树图暗示一个人先选择一条分支，然后才继续生活。

更接近真实生活的图可能是一组同时变化的状态：

```text
考研：      已报名 → 已考试 → 等成绩 → 放弃/复试
国考：      已报名 → 资格通过 → 已考试 → 等面试
地方公考：  搜索中 → 已报名 → 撞期 → 放弃
秋招 A：    已投递 → 面试 → offer → 暂缓签约
秋招 B：    已投递 → 无回复
资格证：    已报名 → 等考试
```

普通人的未来不是只存在于“最后去了哪里”，也存在于这些**同时还没有关闭的路线**里。

所以接下来研究“扩张、拥堵、偶发、防守”四种未来时，可以增加一个很具体的量：

> **在某个日期，一个人到底有多少条已经付出行动成本、且制度上仍然有效的未来路线？**

以及：

> **他/她保留这些路线，是为了扩大机会、避免过早定型、等待环境恢复，还是给现有工作买一个更稳定的退路？**

这比单纯统计最终就业去向，更接近“普通人到底有多少种活法”。
