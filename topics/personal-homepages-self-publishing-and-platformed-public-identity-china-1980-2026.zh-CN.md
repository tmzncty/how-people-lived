# 从“给编辑写信”到“每个人都有主页”：个人出版、公开自我与平台化身份（中国，1980—2026）

## 研究问题

这份笔记追问的不是“博客什么时候出现”，而是一个更接近日常生活史的问题：

> **普通人从什么时候开始，可以不先成为记者、作家、单位宣传员或被编辑选中的来稿者，就获得一个能被陌生人反复访问的公开页面；而这个公开自我后来又怎样从“我的主页”变成职业资产、平台账号和需要主动分隔的数字身份？**

它与本仓已有研究相邻，但不是重复：

- `stranger-life-scripts-forums-peer-advice-and-alternative-life-course-visibility...` 研究一个人**看见别人的生活脚本**；
- `owned-media-vs-platform-access.md` 研究文化对象和文件的“拥有”关系；
- `electronic-mail-portable-address...` 研究私人/制度通信地址；
- 本文研究的是：**一个普通人怎样获得公开可寻址的自我表达表面，以及维护这个表面所需的劳动、风险和人生用途。**

对应 `old-web-archaeology` 的交叉笔记：

- `docs/PERSONAL_HOMEPAGE_PUBLIC_SELF_METRICS_AND_PLATFORM_MORTALITY_1996_2015.md`

---

## 先给出结论

个人主页史不能写成：

```text
没有声音
→ 有个人主页
→ 有博客
→ 有 SNS
→ 人人成为自媒体
```

更准确的变化是：

```text
公开表达需要编辑/组织中介
→ 普通用户获得可公开访问的个人 URL
→ 托管平台降低技术门槛并加入留言、计数器、相册、日志
→ SNS 把个人主页变成关系图中的节点，并把“谁看过我”仪表化
→ 自媒体平台把公开自我进一步变成可积累、可变现、可职业化的受众资产
→ 多重现实角色碰撞后，用户又开始拆分账号、隐藏旧内容、迁移公开身份
```

因此长期趋势不是单纯“越来越公开”，而是：

> **发布权下沉以后，普通人获得了前所未有的公开可见性；可见性一旦进入工作、关系和算法评价，它又反过来制造了新的边界管理劳动。**

# 一、互联网以前：普通人已经可以公开发言，但“进入公共空间”需要中介

## 1. 1980 年的青年人生讨论是一种高延迟、强编辑门控的“公众自述网络”

1980 年 9 月 7 日《人民日报》报道，《中国青年报》从当年 7 月初持续开展“怎样认识人生意义，怎样找到前进路标”的讨论：

- 每周见报两次；
- 两个月已发表 70 多篇文章；
- 编辑部收到来信来稿 36,000 多件；
- 讨论直接涉及青年在工作、学习、生活中遇到的困难和人生道路。

来源：

- 《人民日报》，1980-09-07，第 3 版：<https://cn.govopendata.com/renminribao/1980/9/7/3/>

证据等级：**B：同时代报纸对另一家报纸讨论的报道。**

### 这说明什么

互联网没有发明：

- 第一人称人生叙述；
- 陌生人之间围绕人生选择争论；
- 普通读者把自己的经历发送给公共媒介；
- 读者通过别人的经历重新理解自己。

但当时的公开链路大致是：

```text
个人经历/观点
→ 写信或投稿
→ 邮政传递
→ 编辑部收到
→ 编辑筛选
→ 排版印刷
→ 报刊发行
→ 别的读者看到
→ 再写信
```

真正稀缺的不是“会不会写”，而是：

> **能否通过编辑门槛进入一个规模化公共表面。**

本文称之为：

**editor-gated public self — 编辑门控的公开自我。**

这仍然可以形成全国性的讨论，但延迟高、版面有限，而且绝大多数来信不会成为可反复访问的个人档案。

# 二、1990s：网页让“我自己的一块公开地址”成为真实可能

## 2. 个人主页最重要的变化不是炫技，而是“公开自我可寻址”

早期个人主页的关键属性不是动画 GIF、滚动字幕或 HTML 技巧本身，而是：

```text
一个普通人
→ 获得一个 URL / 路径
→ 可以把自己选择的文字、图片、链接放进去
→ 别人以后可以再次访问同一地址
```

这产生一个新的生活条件：

**public-self addressability — 公开自我可寻址性。**

在报纸来信系统里，普通人的观点通常附着在一期报纸、一篇稿件或编辑栏目中；在个人主页体系里，至少部分用户开始拥有一个长期指向“这个人自己编辑的公开空间”的网络地址。

这并不等于真正拥有服务器、域名或基础设施。很多“我的主页”实际寄居在：

- ISP；
- 门户网站；
- 免费主页空间；
- 学校/单位服务器；
- 海外托管服务。

所以：

```text
page feels personal
≠ infrastructure is personally owned
```

---

## 3. 1996—2000 的第一人称回顾显示：早期中国个人主页是一项真实的“制作劳动”

2000 年 12 月，杨震霆回顾自己 1996 年前后的个人主页经历时记录：

- 早期曾使用 GeoCities；
- 广东“视聆通”等 ISP 向用户提供个人主页空间；
- 飞捷、湛江等地服务也提供主页托管；
- 有的空间允许 FTP 自行维护；
- 计数器、留言板、空间容量和 URL 长短都直接影响使用体验；
- 主页会因为服务商转移、停止服务、工作变化而停止更新或消失。

来源：

- 杨震霆，《中国最早的“十佳个人主页”流落何处》，新浪科技，2000-12-14：<https://tech.sina.com.cn/r/m/46310.shtml>

证据等级：**B/C 混合：2000 年的近同时代第一人称回顾，用于恢复使用流程与当事人记忆；不单独用它确定“全国第一”或精确普及日期。**

### 主页不是一个按钮，而是一条生产链

早期公开自我可能需要：

```text
学 HTML / 网页编辑器
→ 准备图片和文件
→ 获得托管空间
→ 记住路径/URL
→ FTP 或其他方式上传
→ 检查链接
→ 控制文件大小
→ 更新页面
→ 处理留言/邮件
→ 修复失效资源
```

本文称为：

**publishing-stack labor — 发布栈劳动。**

今天在手机 App 里点“发布”的动作，掩盖了早期个人网页作者必须自己承担的很多基础设施工作。

## 4. 网易的同期材料确认：计数器、留言本和免费托管不是后来怀旧者虚构出来的

丁磊在 1999 年《生活时报》的第一人称文章中回顾网易初创时期，明确说自己写过个人主页服务系统，其中包括计数器和留言本；当时又通过多个国内站点投广告推广免费个人主页空间。

来源：

- 丁磊，《我与网易（下）》，《生活时报》，1999-02-21：<https://www.gmw.cn/01shsb/1999-02/21/GB/896%5ESH3-2125.htm>

证据等级：**B：近同时代创办者第一人称回顾。**

同年 1 月《生活时报》对 CNNIC “十佳网站”的报道也把网易当时服务描述为包括：

- 免费个人主页空间；
- 免费流量统计；
- 免费邮件；
- 虚拟社区；
- 搜索等。

来源：

- 《十佳网站评出》，《生活时报》，1999-01-22：<https://www.gmw.cn/01shsb/1999-01/22/GB/867%5ESH14-211.htm>

证据等级：**B：同时代媒体。**

这至少能确认：

> **“写一个页面”很早就和“看有没有人来过”“别人给我留下什么”一起进入普通站长的体验。**

# 三、1999：个人主页不是全体人口的普通状态，但在当时上网人群中已经不是极罕见边缘行为

## 5. CNNIC 1999 年调查必须读出两层含义，而不是只抄一个百分比

CNNIC 1999 年 7 月报告通过网上联机问卷得到 52,549 份有效答卷。报告记录：

- “免费个人主页空间”是 21.6% 受访者常用的网络服务之一；
- 24% 的受访者表示拥有个人主页；
- 在有主页者中，88% 把主页放在国内网站，12% 放在国外网站。

来源：

- CNNIC，《中国互联网络发展状况统计报告（1999/7）》：<https://www.cnnic.cn/NMediaFile/old_attach/P020120612485127164902.pdf>

证据等级：**A：同期机构调查。**

### 但这个 24% 绝不能写成“1999 年 24% 的中国人有个人主页”

该调查是：

- 在线问卷；
- 由约 30 家国内站点在主页放置链接；
- 受访者本身已经是当时 Internet 用户，并且愿意点击完成调查。

因此它非常适合说明：

> **在这批主动参与 CNNIC 在线调查的早期网民中，个人主页已经形成可测量的使用实践。**

它不适合直接外推：

- 中国总人口；
- 所有青年；
- 所有互联网用户的真实概率抽样比例。

同一报告还记录当时上网地点以单位（47%）和家庭（44%）为主，网吧为 4%；这再次提醒：

> **拥有一个个人 URL，并不必然意味着拥有一台专属联网电脑。**

公开身份的可携带性，可以早于个人终端的完全独占。

# 四、个人主页把“谁在看我”变成仪表盘

## 6. 从留言本到点击率：注意力第一次变成普通用户日常可以观察的数字

个人主页的计数器有一个容易被技术史忽略的生活后果。

在编辑门控报刊时代，一个普通作者常常很难知道：

- 有多少人读过；
- 谁读过；
- 读者是否回来；
- 陌生人怎么看。

主页和后来 SNS 逐渐提供：

- 点击率；
- 访客；
- 留言；
- 评论；
- 好友请求；
- 转发/点赞/收藏；
- 粉丝。

本文称为：

**audience-feedback instrumentation — 受众反馈仪表化。**

它让“我是否被别人注意”从一种模糊感觉，部分变成可刷新、可比较的界面状态。

这也开始制造新的劳动：

- 回留言；
- 看访问量；
- 更新以维持流量；
- 到别人主页留下访问痕迹；
- 学习什么内容更容易被看见。

# 五、2001—2008：从“我做了一个网站”到“平台里的我”

## 7. 2001 年“个人家园”已经把主页、邮箱、相册和生活管理绑定在一起

2001 年新浪“个人家园”的同时代报道把收费邮箱、个人主页、电子相册、名片/日程等整合成一套个人服务。报道甚至把两地分居夫妻共享相册、海外居住者用个人主页让父母了解近况作为使用场景。

来源：

- 《汪延：个人家园是新浪的重要战略步骤》，《京华时报》/新浪科技，2001-08-19：<https://tech.sina.com.cn/i/c/2001-08-19/81089.shtml>

证据等级：**B：同时代媒体转述平台产品与场景宣称。**

这些场景是厂商举例，不能证明实际普及率；但它证明平台当时已经把个人主页想象成：

> **不只是“介绍我是谁”，还可以持续向远方亲友展示“我最近怎么样”。**

个人公开页面开始和远距离家庭生活、照片、日程、联系方式重叠。

---

## 8. Blog 降低技术门槛，却没有让“公开私人生活”变得没有代价

2005 年《中国新闻周刊》把 Blog 比喻为相对于 BBS “开放广场”的“开放私人房间”，并讨论网络日志把个人性和公共性结合起来时引起的社会争议。

来源：

- 《博客：开放着的私人房间》，《中国新闻周刊》，2005-03-03：<https://www.chinanews.com.cn/news/2005/2005-03-03/26/546057.shtml>

证据等级：**B：同时代媒体解释。**

Blog 的重要变化并不是“人第一次写日记”，而是：

```text
写日记
+ 公开 URL
+ 更新序列
+ 评论/链接
+ 搜索/推荐入口
```

这让私人叙述第一次大量进入一个“默认可能被陌生人读到”的技术结构。

# 六、2008：个人主页从手工建筑变成社会关系图里的“我”

## 9. 一条非常清楚的同期第一人称：上线第一件事先看“我的个人主页”和点击率

2008 年《中国青年报》关于校内网的报道记录大四学生“艾丽”的同期日记和采访：

- 每次上网，第一个打开校内网；
- 登录后先进入“我的个人主页”；
- 看点击率；
- 看谁访问过；
- 看留言、招呼和日志评论；
- 点击率上涨会带来满足感。

同篇报道还记录其他学生：

- 用日志表达不适合当面说的话；
- 通过好友关系寻找旧同学；
- 通过个人主页了解同学的思想和生活；
- 毕业工作后仍持续使用校园 SNS。

来源：

- 《虚拟网络交友成为过去 实名制网站火爆大学校园》，中国新闻网转载《中国青年报》，2008-10-13：<https://www.chinanews.com.cn/edu/dxxy/news/2008/10-13/1409431.shtml>

证据等级：**B + 同期第一人称自述。**

### 这一例不能被写成“所有大学生都这样”

它是若干受访者和平台相关报道，不是全国随机样本。

但它非常适合证明一种新日常已经真实存在：

> **个人主页不再只是“我自己搭的站”，而成为默认登录后出现的个人节点；维护自我、看别人和维持关系发生在同一套页面结构中。**

本文称为：

**profile-platform convergence — 个人主页的平台化汇合。**

---

## 10. 主页平台化以后，在线身份开始具有新的“人生尾巴”

学生注册的校园 SNS 账号可以在毕业后继续存在。

因此要分开：

```text
life stage ends
≠ profile disappears
≠ audience disappears
≠ old content disappears
```

一个人已经工作，但平台上的旧班级、旧照片、旧日志、旧好友关系仍可能继续跟随她。

这会逐步产生：

**life-stage residue — 人生阶段残留。**

公开数字身份第一次可以系统地跨过毕业、换工作、迁城等现实节点。

# 七、2005—2012 的“扩张型未来”：先是“我也能在网上有一个我”

把 1999—2008 的材料放在一起，可以看到一种与今天不同的扩张感。

早期主页与博客的未来想象经常隐含：

- 我可以学会网页制作；
- 我可以把爱好做成一个站；
- 我可以认识远方的人；
- 我可以被陌生人看到；
- 我可以把自己做的东西公开给整个网络；
- 我甚至可能因为这个主页进入一个新的职业圈。

2000 年那篇“十佳个人主页”回顾中，不少早期站长后来进入互联网公司或把个人站点扩展成更大的项目。

但这里必须警惕明显的 **survivor-success bias — 成功幸存偏差**：

被 2000 年媒体重新追踪的“十佳主页”本来就是异常可见、异常成功的一小群人。

他们可以证明“这种路径存在”，不能证明“做主页通常会变成互联网职业”。

---

# 八、2015—2019 的“拥堵型未来”：公开自我从表达空间变成需要运营的职业选项

## 11. 2019 年同期材料：个人发布已经可以被规划成第二职业

2019 年《中国青年报》对 1,870 名 18—35 岁青年进行在线调查，并采访具体从业者。报道中：

- 52.8% 的受访者表示对利用自媒体平台发展职业有具体目标或规划；
- 32.8% 的受访者同时认为自媒体平台不够稳定、缺乏保障，不能作为长期职业；
- 研一学生“曲佳”一边运营考研类公众号，一边拥有个人公众号，从写作和排版获得收入；
- “毛毛”几乎在所有自媒体平台维持账号，各账号已有自己的受众。

来源：

- 《把自媒体当职业，靠谱吗》，《中国青年报》，2019-11-07：<https://zqb.cyol.com/html/2019-11/07/nw.D110000zgqnb_20191107_1-08.htm>

证据等级：**B + 同期第一人称。**

### 样本边界

这不是全国青年概率抽样：

- 调查通过问卷网完成；
- 一二线城市受访者占很大比例；
- 农村受访者极少。

因此不能把 52.8% 写成“全国一半青年都计划做自媒体”。

但它非常适合保存 2019 年的**同时代职业想象**：

> **“自己公开发布内容”已经可以被明确想象成副业、第二职业甚至长期职业路线，同时稳定性焦虑也已经出现。**

本文称为：

**audience as optionality — 受众作为职业可选性。**

---

## 12. 从主页维护到多平台运营：发布劳动没有消失，只是换了形状

早期个人主页的劳动是：

- HTML；
- FTP；
- 图片压缩；
- 链接维护；
- 服务器空间；
- 计数器/留言本。

2019 年的劳动更像：

- 写作；
- 排版；
- 拍摄；
- 剪辑；
- 修图；
- 看热点；
- 研究流量；
- 回复评论；
- 同时维护多个平台。

所以“平台降低发布门槛”并不意味着：

```text
publishing labor → 0
```

而更像：

```text
technical hosting labor ↓
content/attention/algorithm labor ↑
```

本文称为：

**publishing-labor migration — 发布劳动迁移。**

---

# 九、2020—2022 的“偶发型未来”：账号可能突然从兴趣档案变成收入入口

## 13. 2022 年第一人称个案：兴趣账号成为灵活就业的一部分

2022 年《中国青年报》记录“95 后”季卿卿经营个人社交平台账号不到一年，累计得到 21.4 万点赞与收藏，并把“校园博主”作为灵活就业方式；她本人说最初来自兴趣，后来意外帮助自己实现经济独立。

来源：

- 《就业新选择 新赛道上的年轻人》，《中国青年报》，2022-06-07：<https://zqb.cyol.com/html/2022-06/07/nw.D110000zgqnb_20220607_3-03.htm>

证据等级：**B + 同期第一人称个案。**

这不证明“大多数学生都能靠账号赚钱”。

它证明的是一种新的路径类别已经可执行：

```text
兴趣表达
→ 持续发布
→ 受众/互动积累
→ 平台可见性
→ 商业或劳动机会
→ 部分收入
```

在一个正常招聘、校园生活和城市流动都可能被外部事件打断的时期，已有的公开账号有时会变成一种临时替代入口。

但：

```text
visible account
≠ stable income
≠ social insurance
≠ durable career
```

# 十、2023—2026 的“防守型未来”：问题不再只是“怎样被看见”，而是“谁应该看见哪个我”

## 14. 2025 年非常清楚的第一人称：为了职业形象而“电子搬家”

2025 年 10 月 27 日《中国青年报》一篇第一人称文章记录作者自己的“电子搬家”：

- 把某社交平台个人主页分类清空；
- 隐藏/收纳大部分公开内容；
- 原因是该平台同时用于工作沟通；
- 新爱好内容与她想维持的职业形象发生冲突；
- 最终考虑把这些内容迁到一个更不为人知的小号。

文章还记录另一名受访者把不同平台分配给不同关系圈和身份用途。

来源：

- 蒋继璇，《“电子搬家”：在社交平台上迁徙的年轻人》，《中国青年报》，2025-10-27：<https://zqb.cyol.com/pc/content/202510/27/content_417880.html>

证据等级：**A（作者自身行为的同时代第一人称）+ B（对他人的采访）。**

### 这标志着一个重要翻转

1990s 的难题是：

> **我怎样才能拥有一个会被别人看到的主页？**

2020s 的难题可能变成：

> **我怎样阻止工作的人看到兴趣圈里的我，同时又不必彻底放弃任何一个身份？**

本文称为：

**audience-collision management — 受众碰撞管理。**

以及：

**defensive identity compartmentalization — 防守型身份分舱。**

一个人的在线生活不是越来越统一，而可能反向拆成：

- 工作号；
- 熟人号；
- 兴趣号；
- 小号；
- 匿名账号；
- 面向职业的公开作品集。

这和本仓“防守型未来”的其他机制很相似：

> 不是承诺一个永久、完整、统一的身份，而是尽量保留退出、隐藏、迁移和重新出现的权利。

# 十一、跨时期比较：公开自我的主要约束改变了什么

| 时期 | 获得公共可见性的主要入口 | 主要劳动 | 主要风险 | 典型未来感 |
|---|---|---|---|---|
| 1980s | 报刊来信、编辑栏目、单位/学校媒介 | 写信、邮寄、等待、被编辑选中 | 不被刊出、延迟、版面稀缺 | 被公共讨论接纳 |
| 1996–2001 | ISP/门户免费个人主页 | HTML、FTP、空间、链接、图片、更新 | 托管消失、URL 变动、资源失效 | 我也能在 Web 上有一个“家” |
| 2002–2008 | Blog、个人空间、校园 SNS | 日志、相册、评论、好友、访问量 | 过度暴露、注意力依赖、旧身份残留 | 被看到、被联系、找到同类 |
| 2015–2019 | 公众号/自媒体/视频平台 | 内容生产、热点、算法、跨平台运营 | 不稳定、流量压力、商业化 | 公开表达也许能成为第二职业 |
| 2020–2022 | 社交/短视频/创作账号 | 持续产出、受众维护、变现 | 收入波动、平台依赖 | 账号可能成为偶发替代生计 |
| 2023–2026 | 多平台、多账号、职业/兴趣分区 | 身份分舱、隐私清理、迁移、可见性管理 | audience collapse、旧内容反噬、平台风险 | 保留多个自己，同时保留撤回权 |

# 十二、海外对照：GeoCities 说明“个人主页平台化”并不是中国特有

## 15. 1998 年 FTC 文件证明：个人主页从很早开始就同时是自我表达和平台数据结构

美国联邦贸易委员会 1998 年针对 GeoCities 的投诉文件，把 GeoCities 描述为：

- 由消费者个人主页组成的 Web 虚拟社区；
- 主页被组织在约 40 个主题 neighborhood 中；
- 平台提供免费和付费个人主页、免费邮件；
- 成为成员要填写注册资料；
- 平台利用人口统计、兴趣和 neighborhood 信息做广告定向。

来源：

- U.S. Federal Trade Commission, *In the Matter of GeoCities — Complaint* (1998): <https://www.ftc.gov/sites/default/files/documents/cases/1998/08/geo-cmpl.htm>

证据等级：**A：同时代监管文件。**

这说明一个重要跨国共同机制：

> **“每个人都有一块自己的网页”从一开始就不只是去中心化个人自由；在托管平台上，它也会同时产生注册、分类、广告和平台治理关系。**

也就是说：

```text
personal page
≠ personal infrastructure
```

这个关系后来在博客、SNS 和内容平台上只会更强。

---

## 16. GeoCities 的消失又揭示“平台死亡会一次性抹去一代人的公开自我”

Computer History Museum 对 GeoCities “Deleted City”项目的介绍指出，GeoCities 在 1990s 让大量用户建设按主题社区组织的个人页面；后来社区主站关闭后，志愿者保存下来的数百 GB 数据才成为今天重新观察这些网页的重要入口。

来源：

- Computer History Museum, *Deleted City*: <https://computerhistory.org/exhibits/deleted-city/>

证据等级：**C/B：后来的高质量机构性数字史整理。**

跨国共同结论是：

**hosted-public-self mortality — 托管公开自我的平台死亡风险。**

一个人的纸质日记可能因为私人保存而幸存；一个人的公共主页看起来“更公开”，却可能因为一个平台停止服务而和几百万人的页面同时消失。

# 十三、这改变了我们对“普通人有多少种活法”的哪一点理解

## 17. “人生菜单”不仅由别人怎么活组成，也由一个人是否能把自己公开成一种可被别人看见的案例组成

论坛研究强调：

> 我能看到多少陌生人的生活路径。

本研究增加另一半：

> **谁有机会把自己的生活变成别人能看到的路径样本。**

因此互联网扩大“人生脚本”的机制至少是双向的：

```text
更多人能读陌生人的生活
+
更多普通人能把自己的生活公开给陌生人
```

一个辞职、学乐器、移居、做独立开发、养孩子、单身生活、跨城工作的人，不再必须先被记者采访才可能成为别人人生想象的一部分。

但平台排序、受众规模和公开意愿又会重新筛选哪些人生更容易被看见。

---

## 18. 数字史会系统性高估“愿意公开的人”的人生

个人主页、博客和 SNS 会制造一种新的历史可见性偏差：

**public-self survival bias — 公开自我幸存偏差。**

未来研究者更容易找到：

- 会做主页的人；
- 爱写博客的人；
- 发很多照片的人；
- 公开讲人生的人；
- 做过内容创作的人。

更难找到：

- 只浏览不发言的人；
- 从不注册的人；
- 只在私聊里说的人；
- 主动删掉旧账号的人；
- 页面随服务商消失的人；
- 现实生活很丰富但不公开记录的人。

所以“旧网上留下来的人生”不能当作“当时最常见的人生”。

---

## 19. 公开页面也不是完整的人

一页个人主页、博客或账号最多证明：

> 某人在某一时点选择公开呈现这些内容。

它不自动证明：

- 现实生活只有这些部分；
- 页面里的自我描述全部准确；
- 页面当时仍由原作者控制；
- 作者现实身份可以从昵称直接确定；
- 页面点击率等于真实独立读者；
- 粉丝数等于关系强度；
- 旧文章今天仍代表作者的观点。

本文称为：

**performed-life / lived-life gap — 展演人生 / 实际人生缺口。**

# 十四、核心矩阵

| 生活维度 | 本研究新增机制 |
|---|---|
| 教育 | 学生可通过主页/SNS展示技能、作品、学习轨迹，也可能把学生身份残留到毕业后 |
| 就业 | 个人主页可成为作品展示；后来自媒体/创作者账号可成为副业和职业资产 |
| 住房/迁移 | 远离家乡后，主页/相册可承担“我最近怎样”的低频展示；平台身份又可以跨城市继续存在 |
| 婚姻家庭 | 远距离伴侣/家人可通过主页、相册、动态持续观察近况，但公开程度因平台和关系而异 |
| 非正规劳动 | 内容创作、账号运营、兼职自媒体进入收入路径 |
| 长期中断 | 页面可因工作、毕业、平台关闭、账号遗失停止更新，但仍可能留下历史残片 |
| 证件与记录 | 平台资料可以表现身份，但不能替代现实学籍/职业/证件证明 |
| 通信方式 | 从编辑回信到留言本/评论/私信，公开表达和反馈周期大幅缩短 |
| 互联网平台 | URL 托管、账号、推荐、算法、粉丝、平台迁移共同决定公开自我是否可见 |
| 信息获取 | 个人作者成为信息源；读者需要额外判断自述、经验和代表性 |
| 社交关系 | 主页从“网站”逐渐变成关系图中的个人节点 |
| 未来预期 | 从“我也能上网有个家”到“我也许能靠内容获得职业选项”，再到“我要保留隐藏和迁移的能力” |
| 线上/线下身份 | 线上身份可跨越现实人生节点，也可能与职业/熟人/兴趣角色发生碰撞 |
| 平台消失与记忆 | 托管公开自我可能随服务商、域名、CDN、后台数据库一起大规模消失 |

# 十六、反例与后见之明风险

## 反例 1：个人主页存在，不代表普通家庭普遍拥有电脑或 Internet

1999 的页面实践属于早期网民生态，不能倒推全民。

## 反例 2：公开表达门槛降低，不代表每个人都愿意公开

24% 的 CNNIC 受访者自报拥有主页，也意味着同一调查里 76% 没有。

## 反例 3：有主页不代表有受众

页面存在与被发现、被访问、被记住、产生现实关系是不同状态。

## 反例 4：粉丝和点击并不等于稳定职业

2019 的同期调查里就已有相当部分受访者认为自媒体不稳定、保障不足。

## 反例 5：更多公开空间也会制造更多自我审查和边界劳动

2025 的“电子搬家”说明，公开身份达到一定密度以后，人可能主动减少可见性，而不是继续增加。

# 十七、尚未确定

1. 1996—2000 中文免费个人主页的实际创建/活跃/死亡率，目前仍缺稳定、可比、按平台统计的数据。
2. 早期主页作者中学生、技术人员、普通办公室职员、女性、不同地区用户的分布仍很不清楚。
3. “主页促进职业转换”的真实基准率未知；媒体更容易追踪成功站长。
4. 早期访客计数器的实现、重置、缓存、机器人和多次访问含义需要逐平台考古。
5. 从个人主页迁移到 Blog/SNS 时，哪些内容真正被用户搬走、哪些永久丢失，缺系统样本。
6. 2020s 多账号分舱究竟多普遍，需要比个人新闻特写更稳健的调查证据。
7. 我们仍缺一份能跨 1990s→2000s→2010s→2020s 跟踪同一个普通人的 **public-self ledger**。

# 十八、下一步最值钱的证据：public-self ledger

理想的生命史访谈/数字档案不要只问“你什么时候开始上网”，而应追问：

```text
第一次给报刊/论坛投稿是什么时候？
第一次拥有自己的公开 URL 在哪里？
网页是谁教会你做的？
在哪台机器上更新？
需要 FTP 吗？
第一次看到计数器上涨是什么感受？
谁会给你留言？
主页什么时候不更新了？为什么？
后来有没有搬到博客、QQ 空间、校内/人人、微博、公众号或短视频？
哪些旧内容一起搬过去？哪些丢了？
第一次因为公开内容认识现实中的人是什么时候？
第一次因为公开内容获得工作/收入机会是什么时候？
第一次因为同事、家人或雇主可能看到而删帖/隐藏/开小号是什么时候？
今天如果原平台关闭，你最想保存哪一部分？
```

这样的 ledger 才能把“旧网产品史”变成真正的生活史。

# 核心洞见

从 1980 年的 36,000 多封青年读者来信，到 1990s 的个人主页，再到 2008 年每天刷新“我的个人主页”，再到 2019 年把公开账号当成第二职业，再到 2025 年为了工作与兴趣边界而“电子搬家”，变化的并不只是媒介形式。

真正变的是：

> **一个普通人逐渐获得了把自己做成公共信息的能力。**

而当这种能力足够普遍以后，新的问题又出现了：

> **不是“我怎样才能被世界看见”，而是“世界已经可能看见我太多部分，我怎样决定哪个我留在哪个地方”。**

这说明“普通人有多少种活法”还取决于另一件常被忽略的事情：

> **有多少普通人的生活能够被他们自己公开、被别人找到、被平台保存，又有多少人在后来仍有权把那个公开版本撤回。**
