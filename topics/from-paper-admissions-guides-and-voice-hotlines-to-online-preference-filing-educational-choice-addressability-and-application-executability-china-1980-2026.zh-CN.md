# 从纸质招生信息、声讯电话到网上志愿：教育选择可寻址性、信息中介与大学路径可执行性（中国，1980–2026）

> 研究问题：大学成为“普通人生选项”之后，还有一个经常被忽略的第二道门槛——一个考生究竟怎样知道有哪些学校和专业、怎样判断自己可能去哪里、怎样把一个人生选择正确地写进招生系统，并确认它真正生效？互联网改变的是大学本身，还是把原来分散在老师、报纸、招生目录、电话、学校机房与家庭经验里的“选择基础设施”重新组织起来？

## 0. 与既有专题的区别

本仓已有 `when-did-university-become-an-ordinary-life-option.md`，讨论高等教育何时从少数人的特殊路径变成普通家庭会认真规划的下一阶段。本专题不重复规模扩张史，而研究从“大学对我而言可想象”到“我能完成一次有效的学校/专业选择”之间的事务链。

它也推进 ROADMAP 中尚未完成的 `first-generation university student, c. 2000–2005` 缺口，但**不能视为已经完成那个窄人物画像**：本轮得到的是选择与申请基础设施史，第一代大学生仍需要更集中、更多 c.2000–2005 同时代生命史材料。

本文使用几个工作概念：

- **educational-choice addressability / 教育选择可寻址性**：考生能否知道哪些学校、专业、城市、费用、奖助与录取规则对自己存在；
- **application executability / 申请可执行性**：知道一个志愿之后，能否在正确时间、正确入口、正确身份状态下把它提交并最终生效；
- **information brokerage / 信息中介**：老师、父母、亲友、同学、报刊、咨询会、热线、网吧/机房、网站与后来商业规划师如何替考生解释复杂规则；
- **first-generation navigation load / 第一代大学生导航负担**：家庭中缺少经历过高校招生的人时，规则解释、城市/专业想象、成本判断与风险估计更依赖校内和公共信息基础设施；
- **decision-timing exposure / 决策时点暴露**：考前填、估分填、知分填会让同一考生面对不同程度的不确定性；
- **submission finality / 提交终局性**：草稿、保存、提交、确认提交、纸面签字与最终生效不是同一状态；
- **information abundance without decision competence / 信息丰富但决策能力不足**：网页越多并不自动意味着普通人更懂专业、规则和职业后果；
- **public decision infrastructure / 公共决策基础设施**：当招生计划、规则、往年录取、专业、就业等逐渐被公共平台整理，家庭不必完全依赖私人关系或付费中介。

核心判断：

> **互联网没有创造“填高考志愿”这件事。它先把分散的招生资料和高校咨询做成可搜索、可问答的信息层，再把部分省份的正式志愿提交做成有账号、密码、确认、短信和截止时间的事务系统。真正改变人生选择可执行性的，不只是网页存在，而是信息、身份、提交状态、学校协助和线下确认能否接成一条不断裂的链。**

## 1. 永久保留的状态链

不要把“报大学”压成一个按钮：

```text
knows university exists
!= knows a specific institution / major exists
!= understands what the major means
!= knows tuition / city / aid / career implications
!= academically eligible
!= has a realistic score / rank range
!= knows current-year quota and rules
!= has an intended preference list
!= has access to the filing channel
!= authenticates successfully
!= form fields are valid
!= draft saved
!= preference submitted
!= final confirmation submitted
!= required offline signature / school confirmation completed
!= preference becomes legally/administratively effective
!= file is actually投档
!= institution admits
!= admission result becomes queryable
!= admission notice reaches the household
!= student actually enrolls
!= student remains enrolled
```

长期保持以下差异：

- `高校信息可见 != 对该省该科类当年有招生计划`
- `招生计划存在 != 本人分数/位次可达`
- `专业名称看懂 != 理解真实学习内容和职业路径`
- `网上填完 != 已确认提交`
- `已确认提交 != 已正式投档`
- `投档 != 录取`
- `网页显示录取 != 录取通知书已经送达 != 最终报到`
- `全省网上填报 != 每个考生家里有电脑/宽带`
- `本人账号提交 != 全部信息判断由本人独立完成`
- `信息更多 != 信息差消失`

## 2. 1980s–1990s：没有大众 Internet，不等于没有招生信息系统

1980 年《人民日报》已经刊登了一个家庭如何讨论高考志愿的同时代故事：北京中学生曾筝把四川医学院列为第一志愿，家庭讨论里同时出现“外地大学”“师范院校”“国家需要”“如果考不上怎么办”等未来判断。它不能代表普通家庭，也不是信息渠道调查；但它说明志愿本来就是把专业、城市、家庭意见和未来工作压进一张选择表的生命历程接口。

- **A / contemporaneous newspaper**：《人民日报》1980-06-19，《填报高考志愿的故事》  
  https://cn.govopendata.com/renminribao/1980/6/19/3/

前互联网和早期互联网时期，招生信息依赖一个混合栈：

- 中学教师、班主任和学校教务；
- 省级招生计划、招生简章、纸质院校/专业代码册；
- 报纸的分数线、上线名单、招生政策；
- 现场咨询与高校宣传；
- 邮政录取通知；
- 后来出现的声讯电话查分/查录取。

1995 年浙江的一个后来回忆特别适合作为“报纸是事务接口”的 C 级材料：当年的《钱江晚报》曾以大量版面刊登上线考生名单。2025 年回访中，有考生回忆自己正在农忙田间，是姑姑把报纸带来，他才从密密麻麻的名字里找到自己。这只能证明该人的回忆与报纸实物相互呼应，不能把 2025 年怀旧叙述当成 1995 年全国通用流程。

- **C + surviving newspaper artifact**：钱江晚报/潮新闻 2025 对 1995 报纸与考生回忆的整理  
  https://www.sohu.com/a/887113073_121627717

到 2002 年，安徽考生已经可以打 168 声讯台查询高考分数，录取后另有声讯号码查询结果。这时中国当然已经有 Internet，但电话仍然是普通家庭获取关键状态的一条独立通道。

- **B / contemporaneous local report**：2002-07-24 安徽 168 声讯查分/查录取  
  https://edu.sina.com.cn/l/2002-07-24/28867.html

因此必须避免一个常见技术史错觉：

> **Web 出现以后，报纸、电话、学校和邮政并没有同一天失效。招生信息系统长期是多渠道叠加，而不是纸 → Web 的整齐替代。**

## 3. 海外前 Web 对照：法国 Minitel 已经把升学意愿做成远程结构化输入

1987 年《Le Monde》关于巴黎大学注册的同期报道记录，高三学生在 5 月通过 **Minitel** 提交自己希望就读的十个高等教育专业/机构；约 8 万名会考考生中，约 5.2 万人使用了该系统。报道同时提醒，这并不意味着系统覆盖了所有考生，也不意味着意愿本身等于最终入学。

- **A/B / contemporaneous press on official allocation process**：Le Monde, 1987-07-04  
  https://www.lemonde.fr/archives/article/1987/07/04/les-inscriptions-dans-les-universites-parisiennes-tous-les-bacheliers-devraient-etre-accueillis-mais-ils-ne-seront-pas-loges-a-la-meme-enseigne_4044658_1819218.html

这个案例很重要，因为它说明：

1. “远程电子填报升学意愿”早于 WWW；
2. 家庭终端可以直接进入教育分配流程，但采用仍然不完整；
3. 电子表单没有创造高校容量，只改变意愿收集与匹配的速度和结构。

美国 Common Application 也提供另一条谱系：1975 年先用统一纸表减少重复填写，1994 年有软盘版，1998 年才上线 Web。1998 年《Washington Post》同时代报道中的 17 岁申请者已经混合使用在线申请、电子下载后打印、CD-ROM 套件和传统纸申请；她家甚至没有打字机，因此某份传统申请仍需在学校完成。

- **B / institutional history**：Common App 50th timeline  
  https://www.commonapp50.org/
- **B / contemporaneous first-person application example**：Washington Post, 1998-04-05  
  https://www.washingtonpost.com/archive/1998/04/05/the-application-superhighway/5f352121-31d4-41a3-b02e-233f3d622216/

跨国共同点不是“大家都把纸表搬上网”，而是：**正式教育选择越来越早进入机器可处理的结构化记录，同时家庭设备、学校设备、纸面和人工辅导长期共存。**

## 4. 2003–2006：先数字化“知道和询问”，再数字化正式志愿

学信网自己的机构史记录，2003 年非典期间曾举办全国大型网上高考咨询周；2004 年三个阶段累计有大量访问、提问和答复。这里平台自己的回顾适合证明服务谱系，不适合单独推断每类考生的真实采用率。

- **B / official institutional retrospective**：学信网“关于我们”  
  https://www.chsi.com.cn/about/ct15.shtml

2005 年 5 月 10 日，教育部正式开通“阳光高考”信息平台 `http://gaokao.chsi.com.cn`，集中提供分省分专业招生计划、招生政策、招生资格、高校院系、录取规则、往年录取、学费、奖贷学金、食宿条件等，并开放在线咨询。

- **A / contemporaneous official announcement**：教育部，2005-05-09  
  https://www.moe.gov.cn/jyb_xwfb/gzdt_gzdt/moe_1485/tnull_5675.html
- **A / contemporaneous official consultation-week notice**：2005-05-30  
  https://gaokao.chsi.com.cn/gkxx/file/200505/20050530/28062.html

2006 年的同时代说明进一步把状态拆开：未注册用户可以浏览、搜索已有问题，注册用户才能提交问题；而且问题需要被回答后才显示。也就是说：

```text
page reachable
!= registered user
!= question submitted
!= question accepted / queued
!= answer produced
!= Q&A publicly visible
!= candidate's decision changed
```

- **B / contemporaneous report**：2006-05-12  
  https://news.sina.com.cn/c/2006-05-12/09268905275s.shtml

这一阶段 Web 的关键贡献首先是 **educational-choice addressability**：一个不在北京、上海或高校集中的城市里的家庭，可以从统一入口看到过去需要靠纸质目录、学校经验或远途咨询才能拼出的部分信息。

但这仍不等于正式志愿已经全国统一网上提交。不同省份的志愿时点、填报介质和确认流程长期不同。

## 5. 2007–2010 的扩张型未来：网上志愿把人生选择变成一个有状态的事务系统

2008 年陕西首次实行网上填报志愿；当时报道仍明确要求考生结合纸质《招生考试特刊》里的学校/专业名称和代码，以及网上招生章程完成选择。纸与网不是替代，而是同一事务的两层材料。

- **B / contemporaneous report**：陕西 2008 首次网上填报  
  https://news.sina.com.cn/o/2008-05-05/053713830335s.shtml

同年内蒙古实时在线填报留下了很有价值的 T1 使用场景。和林县一中的考生李娜是在**学校电脑机房**登录系统，看实时排名和招生数据后提交；另一名呼和浩特学生则和父母在家完成。二者同属“网上填志愿”，家庭设备条件和现场支持却完全不同。

- **T1/B / contemporaneous media observation**：2008-07-23  
  https://news.sina.com.cn/c/2008-07-23/013514202466s.shtml

2009 年陕西官方说明已经形成很清楚的事务状态机：报名号+密码登录；先“提交”，再“确认提交”；确认前可修改，确认后不能；成功后短信提示；之后中学/报名点打印确认表，由考生纸面签字，再由报名点上报，志愿才最终生效。

- **A / contemporaneous provincial examination authority**：陕西省教育考试院，2009-06-01  
  https://www.sneea.cn/info/1027/2044.htm

因此必须永久保留：

```text
draft != submit
submit != final-confirm submit
SMS success != school-side final reporting
online final-confirm != paper signature
paper signature != admission
```

这也是 old-Web 与生活史真正交叉的地方：**界面上的一个“确认”按钮可以改变一个十八岁人的未来选项，但只有它与学校、短信、后台和招生录取系统共同工作时才有现实效力。**

### 纸仍然是重要的信息中介

2009 年陕西在线填报已经运行，《华商报》却仍专门制作 48 版高考填报手册，并在西安以外地区增印。网页成为正式事务入口，不代表家庭立即放弃可以摊在桌上比较的纸质说明。

- **B / contemporaneous newspaper**：2009-06-09  
  https://news.sina.com.cn/c/2009-06-09/022615756150s.shtml

### 第一代大学生/弱家庭教育资本的信息负担并没有自动消失

2010 年新浪—麦可思针对当届考生和家长的跟踪调查称，在其样本中，农民与农民工家庭考生到 4 月仍“无志愿填报计划”的比例最高（58%），并据其更早毕业生研究把信息不对称列为可能原因。该网络调查的抽样与分类不能代表全国农村考生，也不能把相关性写成因果；它的价值在于证明：**当正式填报已经越来越网络化时，家庭是否有上一代经验和解释能力仍然会影响准备状态。**

- **B / contemporaneous survey report, sampling limits required**：2010-04-14  
  https://edu.sina.com.cn/gaokao/2010-04-14/1451242938.shtml

这正是第一代大学生研究需要继续追的机制：缺少的未必是一台电脑，而可能是一个能解释“这个专业以后做什么、这个城市生活费多少、这个位次应该怎么理解”的人。

## 6. 决策时点本身也是基础设施：考前、估分与知分不是同一种未来

2008 年全国仍并存考前“猜分”、考后估分、知分后填报等多种制度。广东 2008 年重新改为公布分数和分数线后再填志愿；陕西 2009 的前两批仍存在考后估分填报，家长甚至把这种决策形容成像“赌命”。这些说法是同期主观表达，不应升级成所有家庭共同感受。

- **B / contemporaneous national comparison**：2008 志愿时点概览  
  https://edu.sina.com.cn/gaokao/2008-03-20/1214129295.shtml
- **B / contemporaneous Guangdong policy report**：2007-11-09  
  https://news.sina.com.cn/c/edu/2007-11-09/012014265697.shtml
- **T1/B / contemporaneous parent reaction, Shaanxi 2009**  
  https://news.sina.com.cn/c/2009-06-09/022615756150s.shtml

所以“数字化”不是唯一重要变量。一个系统即使完全在线，如果要求人在不知道成绩/位次时锁定选择，它仍然暴露于更强的不确定性。

本文将其称为 **decision-timing exposure**。

## 7. 2015–2019 的拥堵型未来：信息短缺转成信息过量与解释竞争

2019 年中国青年报对 1975 名参加过高考者的网络调查显示，受访者最常参考志愿指南/手册、高校官网、招生宣讲等；59.6% 坦言当时不了解专业的具体含义和学习内容。受访者朱婷说自己用两整天研究志愿，并感到网上信息庞杂、不够系统。

- **T1/B / contemporaneous survey + interviews**：中国青年报/人民网，2019-07-11  
  https://edu.people.com.cn/n1/2019/0711/c1053-31227081.html

这标志着瓶颈改变：

```text
1980s/1990s: 我能不能拿到招生信息？
2000s: 我能不能在网上找到并提交？
late 2010s: 我面对这么多学校、专业、往年线、排名与解释，到底相信什么？
```

**可寻址性扩大以后，导航能力本身成为新的不平等来源。** 家长、老师、商业志愿咨询和平台算法开始竞争“解释未来”的位置。

## 8. 2020–2022 的偶发型未来：日历可以断裂，线上咨询成为连续性 fallback

2020 年 3 月 31 日，教育部宣布全国高考整体延期一个月到 7 月 7–8 日。郑州高三学生马博在同期采访中说，居家网课环境下提问和获得教师充分解释更困难，也更容易烦躁焦虑。

- **A / contemporaneous official schedule change**：教育部，2020-03-31  
  https://www.moe.gov.cn/jyb_xwfb/s271/202003/t20200331_436696.html
- **T1/B / contemporaneous student interview**：光明日报/教育部，2020-04-01  
  https://www.moe.gov.cn/jyb_xwfb/s5147/202004/t20200401_437118.html

同年高考网上咨询周被推迟到 7 月 22–28 日，教育部特别要求高校根据疫情防控要求加强线上招生宣传与咨询；考生可通过网页和微信公众号参与。

- **A / official**：教育部，2020-07-13  
  https://www.moe.gov.cn/jyb_xwfb/xw_zt/moe_357/jyzt_2020n/2020_zt12/dongtai/yaowen/202007/t20200710_471287.html

这里新增的是 **calendar resilience / 日历韧性**：大学申请基础设施不仅要能“平时工作”，还要在考试、出分、咨询、填报整体后移时继续把信息和状态接下去。

它同时提醒我们：线上渠道可以替代一部分现场宣讲，却不能替代家庭安静空间、教师即时反馈和考试本身。

## 9. 2023–2026 的防守型未来：从“知道更多”转向“不要在一次选择里把未来锁死”

2023 年中国青年报调查的 1334 名受访者中，66.2% 表示选择专业时侧重就业前景；具体采访也显示，考生和家长常把兴趣、学校名气、分数可达性与未来实用性一起计算。该样本不能代表全国考生，但它说明“专业 = 四年学习”越来越同时被当成“毕业后风险暴露”的决定。

- **T1/B / contemporaneous survey + interview**：2023-06-30  
  https://t.m.youth.cn/transfer/index/url/news.youth.cn/qdc/djdc/202306/t20230630_14618528.htm

2024 年教育部在“阳光高考”平台免费开放“阳光志愿”信息服务系统，把院校、专业、就业前景、心理测评和基于往年录取情况的“冲稳保”推荐放进同一公共服务。到 2026 年系统进一步提供 31 个省份普通批次筛选、专业/职业前景、毕业生评价等功能。

- **A / official**：教育部，2024-06-17  
  https://www.moe.gov.cn/jyb_xwfb/gzdt_gzdt/s5987/202406/t20240617_1136235.html
- **A / official**：教育部，2026-06-17  
  https://www.moe.gov.cn/jyb_xwfb/s5147/202606/t20260617_1440970.html

这可以理解为公共部门对“信息拥堵”的一次再中介化：不是继续扔给家庭更多网页，而是帮助缩小选择集。

### 但“防守型未来”不能写成所有人只追求稳定

2025 年中国青年报调查里，就业率与薪资前景确实是受访者最常选择的考虑因素之一，但兴趣爱好、院校排名、专业实力和职业潜力同时存在；一名河南考生面对 48 个平行志愿和大量专业时仍强调“就业要考虑，但适合最重要”。该调查农村受访者极少，更不能拿它代表农村家庭。

- **T1/B**：中国青年报，2025-07-11  
  https://news.youth.cn/gn/202507/t20250711_16110585.htm

2026 年《光明日报》的同期志愿观察又提供了反例：有乡村长大的考生主动选择优师计划，接受毕业后到中西部县乡学校服务至少六年的约束，理由来自自己曾经遇到返乡任教大学生的经验；另有学生选择核技术专业。它说明就业安全只是一个轴，地域承诺、公共服务、兴趣和价值仍能成为未来选择。

- **T1/B / contemporaneous interviews**：光明日报/人民网，2026-07-08  
  https://edu.people.com.cn/n1/2026/0708/c1006-40755771.html

因此更准确的“防守”是：**家庭越来越想知道一项选择未来有哪些出口、能否转向、成本多高，而不是简单把所有人写成只想要铁饭碗。**

## 10. 互联网到底改变了什么？

### 改变 1：从“找到一本资料”到可搜索的全国信息层

2005 年以后，招生计划、章程、往年录取、院校与专业信息可以从统一公共入口被主动查询。

### 改变 2：从咨询到事务提交

一旦省级志愿系统上线，Web 不只是“了解大学”，而是进入正式录取状态机。

### 改变 3：把确认、修改与截止时间机器化

纸表时代也有确认，但数字系统把“还能改 / 已锁定 / 超时无效”等状态直接做成界面和后台规则。

### 改变 4：扩大信息后又制造解释压力

当几千个专业、历年分数、位次、就业信息都可查时，稀缺的不再只是资料，而是**把资料转换成适合自己的决定的能力**。

### 改变 5：公共系统开始承担“导航”而不只是“发布”

2024 以后免费公共志愿系统的意义，是试图降低家庭必须购买私人解释才能处理数据洪流的压力；实际效果仍需独立评估，不能从“上线”直接推断“消除了信息差”。

## 11. 对第一代大学生特别重要的机制

第一代大学生的困难不应浪漫化成“靠自己闯出去”，也不应简化为“不会上网”。更具体的缺口可能是：

1. 家庭里没人知道一本到二本、专业代码、调剂、征集志愿分别意味着什么；
2. 父母难以用亲身职业经验解释大学专业；
3. 城市、住宿、学费与奖助信息需要第一次自行估算；
4. 家庭更难判断“这个分数值得复读还是现在走”；
5. 正式系统出错或错过截止时，家中没有上一代经验提供 fallback；
6. 即使家里没有电脑，学校机房和老师可以让“网上填报”仍然可执行，但这会提高对学校组织能力的依赖。

2010 农民/农民工家庭调查只提供一个信号，不足以完成人物画像。下一轮若专门补 ROADMAP 的 first-generation profile，应优先找：

- c.2000–2005 农村/县城学生的同期日记、报道、访谈；
- 家庭中第一个大学生如何选学校/专业；
- 学费、助学贷款与迁移城市如何进入家庭讨论；
- 老师/亲属/报刊/电话/网吧分别承担什么信息角色；
- 入学后第一次处理宿舍、银行卡、校园网、学籍与城市生活的经验。

## 12. 重点矩阵更新

| 维度 | 本轮新增认识 |
|---|---|
| 教育 | “能考大学”与“能做出有效院校/专业选择”是两层能力 |
| 就业 | 专业选择越来越提前吸收对毕业就业的判断 |
| 迁移 | 填志愿同时决定未来四年的城市与离家距离 |
| 家庭 | 父母既是资金提供者也是信息中介；第一代大学生家庭经验更薄 |
| 证件与记录 | 报名号、密码、考生身份、成绩/位次与志愿记录形成资格链 |
| 通信 | 报纸、声讯电话、短信、Web、微信长期叠加，而非整齐替代 |
| 互联网平台 | 从信息发布/问答进入正式志愿事务，再进入个性化筛选 |
| 信息获取 | 瓶颈从资料稀缺转为信息过量与解释竞争 |

## 13. 反例与后见之明风险

1. **不要把 2005 阳光高考上线写成中国考生从此都用 Web。** 电话、纸质手册、学校和现场咨询继续存在。
2. **不要把“网上填报”写成“家庭有电脑”。** 学校机房、报名点和他人协助可能承担终端角色。
3. **不要把信息不对称自动归因于农村身份。** 地区、学校资源、父母教育、成绩层次和个人兴趣都可能作用；现有调查只是有限样本。
4. **不要把填报工具推荐当录取承诺。** “冲稳保”、历史位次或算法建议都不能决定未来竞争者的实际志愿和当年投档状态。
5. **不要把后来就业结果倒推成当年志愿“选错”。** 当时能知道的信息、产业结构和个人目标可能不同。
6. **不要把今天的考公/稳定话语投射回 2008。** 2008–2010 的同期材料同时存在“大学扩张仍值得追求”“就业担忧”“弃考/提前工作”“留学”等不同未来。
7. **不要把 2023–2026 的就业谨慎写成兴趣消失。** 同期材料仍有价值、地域、专业兴趣和公共服务动机。

## 14. 尚未确定

- 各省第一次全面网上填报志愿的精确年份需要逐省建表，不能用陕西/湖北代表全国；
- 1990s 各地声讯查分、电话填报、报纸公布名单的覆盖范围仍缺系统比较；
- c.2000–2005 第一代大学生的同期第一人称材料仍不足；
- 学校机房、网吧、家庭电脑三种终端在不同地区的比例尚无可靠全国数据；
- 志愿商业咨询从何时开始成为规模行业，以及各阶层采用差异，仍需独立研究；
- 2024–2026 公共志愿推荐系统是否真正降低家庭信息差，需要后续采用与结果证据，而不能从产品功能推断。

## 15. 它改变了我们对“人怎么活着”的哪一点理解

高等教育扩张以后，“能上大学”看起来像一条越来越普通的路线。但一条路线真正进入普通生活，需要的不只是座位和考试。

一个十八岁的人还必须把非常模糊的未来翻译成一串机器和制度能够理解的字段：

```text
城市
学校
专业
批次
顺序
是否服从调剂
```

这些字段又隐含了更大的问题：离不离家、学什么、花多少钱、四年后做什么、如果没录上怎么办。

纸质招生目录时代，知道这些往往依赖老师和家庭经验；声讯电话缩短了等待结果的时间；Web 让全国院校更容易被搜索，也让志愿变成可以保存、修改、锁定和校验的数字状态；后来数据太多，公共系统又开始替家庭做筛选。

因此这一轮真正新增的不是“高考也上网了”，而是：

> **一种人生机会只有在普通人能够看见、理解、选择、正确提交并确认它时，才真正进入她的生活菜单。大学扩张扩大了门，招生信息与志愿基础设施则决定一个第一次走到门口的人，能不能知道该推哪一扇。**
