# 《寻遍星空》（2013）：从年少星空到城市独居，中文 VOCALOID 如何保存青年未来想象

## 范围

**地点：** 中国大陆中文互联网 / bilibili 中文 VOCALOID 文化语境  
**时间：** 2013—2019 为主，并追踪至 2025—2026 的再创作  
**材料：** 公兔《寻遍星空》（洛天依演唱）及其续作《化作繁星》  
**问题：** 一首早期中文 VOCALOID 原创，怎样把“长大以后会怎样”写成可被一代年轻听众反复进入的情绪空间？六年后，同一创作者又怎样从“寻找未来”转向“回望昨日与明天”？

这是 [《当一首歌变成时代档案》](songs-as-everyday-life-archives-china-2010-2020.zh-CN.md) 的后续 case note，也与 [《从拨号 BBS 到洛天依：中文世界普通人在线做歌的基础设施史》](from-dialup-bbs-to-vocaloid-grassroots-online-music-making-chinese-world-1993-2018.zh-CN.md) 互相补充。

这里不把《寻遍星空》当作“2013 年中国青年的平均心态”。歌曲能证明的，是某种生活经验与未来想象已经具有足够强的**文化可识别性**：年少记忆、城市楼宇、独自生活、重复奔波、孤独、仍不愿放弃的愿望，可以被组织成一首面向中文互联网青年听众的作品。

---

## 核心结论

《寻遍星空》值得进入 How People Lived，不只是因为它“好听”或“古早”。

它保存了一种很具体的青年时间结构：

```text
年少时对世界仍有明亮想象
→ 长大
→ 进入楼宇、独居、重复的日常节奏
→ 发现现实并不像少年时期想象的那样展开
→ 仍试图从旧日记忆中找回能够继续前进的东西
```

这和单纯的“怀旧”不同。

作品里的过去不是终点，而是**未来行动的资源**：回望年少，并不是为了永久停在那里，而是因为成年后的生活已经出现了疲惫、孤独与重复，需要从曾经相信过的东西里重新建立方向。

因此，它正好可以放在仓库已有的两种时间经验之间：

```text
2010《北京东路的日子》
未来突然打开：我们即将离开共同校园，各自走向不同道路

2013《寻遍星空》
未来已经开始兑现：长大、独自生活、城市奔波，但仍想守住少年时的方向

2020《过去的歌》
过去开始堆积：媒介、偶像、设备、青春本身都已经被体验成历史
```

这三者不能代表所有青年，却可以组成一条很有价值的文化史问题链：

> **一代年轻人什么时候在想象未来，什么时候开始实际生活于那个未来，又什么时候意识到自己的“现在”也正在成为过去？**

## 一、版本沿革：一首 2013 年作品怎样逐步获得完整形态

VCPedia 与萌娘百科的作品资料均记录：

- **2013-11-09：** 公兔投稿《寻遍星空》原版，洛天依演唱；
- **2013-11-10：** 隔日投稿重新调教、提高音质的版本；
- **2014-04-04：** 再次投稿合作制作的 PV 版；
- 资料页将词、曲、编等主要创作归于公兔；VCPedia 的创作者条目还记录其后改用“鸽稀拉”名义。

来源：

- VCPedia，鸽稀拉（公兔）：  
  https://vcpedia.cn/zh-hans/%E9%B8%BD%E7%A8%80%E6%8B%89
- 萌娘百科，《寻遍星空》：  
  https://moegirl.uk/%E5%AF%BB%E9%81%8D%E6%98%9F%E7%A9%BA

**证据等级：B。** 两者都是中文歌声合成社区整理资料，适合确认投稿日期、版本和社区内部作品谱系；若以后能找到原始投稿页面的完整历史快照、作者本人旧动态或 Web Archive，应进一步提升版本 provenance。

这个版本序列本身很有意义：

```text
先把歌做出来并投稿
→ 很快重调
→ 数月后补成更完整的 PV 作品
```

它不是传统唱片工业中“制作全部完成后再一次性发行”的唯一模式，而更像网络原生创作：**作品可以先进入公共空间，再被继续修订、协作和视觉化。**

## 二、它写的不是抽象“梦想”，而是“未来兑现以后”的生活落差

现存作品资料保存的歌词文本中，可以辨认出两组非常不同的生活场景。

### 少年时期

- 星空；
- 烟花与流萤；
- 欢笑；
- 对未来仍然朦胧但明亮的感受。

### “如今”的成年 / 青年生活

- 楼宇构成的城市空间；
- 独自生活；
- 日复一日的节奏；
- 奔波、退缩与沉默；
- 一个人继续行走和坚持。

来源：

- 萌娘百科，《寻遍星空》歌词与作品说明：  
  https://moegirl.uk/%E5%AF%BB%E9%81%8D%E6%98%9F%E7%A9%BA

这里尤其值得注意的是：歌曲并没有把“长大”写成单一的成功叙事。

从学校、家庭保护或少年共同体进入成年世界以后，生活可能首先表现为：

```text
空间更大
+ 选择更多
+ 行动更自由

但同时也可能：

共同时间减少
+ 独居或独自行动增加
+ 工作 / 学习 / 通勤节奏重复
+ 维持方向需要更多自我驱动
```

歌曲不能证明 2013 年有多少青年真的独居，也不能据此推出全国城市青年都处在相同状态。但它能够说明：**“从少年理想进入城市中的独自奔波”已经是一套创作者预计听众能够迅速理解的叙事。**

这正是文化史料与统计史料的分工。

## 三、“星空”为什么重要：它是一种跨越少年与成年时间的坐标

《寻遍星空》的关键并不是天文学意义上的星空，而是一个能够把两个时期接起来的稳定意象。

少年时期看见它时，它与天真、想象和还没有被兑现的未来绑定；成年以后再次抬头，它变成一种证明：**过去那个相信未来的人曾经存在，而且仍可以被现在的自己重新调用。**

因此，歌曲的时间方向不是简单的：

```text
过去 ← 怀旧
```

而更接近：

```text
过去的自己
   ↓
保存一套价值 / 愿望 / 感受
   ↓
现在疲惫的自己重新读取
   ↓
继续面对尚未确定的未来
```

这对 How People Lived 很重要，因为“未来”不是只有收入、住房、职业和教育路径这些可量化项目。

普通人还需要回答：

- 我为什么要继续这样生活？
- 现在的生活还是不是我小时候认为的“长大”？
- 当现实与早期想象不一致时，我怎样重新解释自己的方向？
- 哪些旧记忆会成为继续行动的资源，而不只是怀旧消费？

歌曲正适合保存这种统计材料很难直接记录的**未来感与时间感**。

## 四、2013：洛天依出现一年多以后，虚拟歌手已经可以承载这种私人而普通的叙事

洛天依的中文 VOCALOID 声库于 2012 年发布。到《寻遍星空》投稿时，中文虚拟歌手文化仍处在很早的阶段，但创作者已经可以用一个合成声音表达相当私人化的青年生活经验。

这里值得避免一种误读：

> 虚拟歌手并不意味着内容脱离现实生活。

恰恰相反，《寻遍星空》的文本把虚拟歌手的声音用于非常普通的现实经验：少年记忆、城市楼宇、独自生活、重复节奏、失落与继续前进。

这和仓库已有的网络音乐基础设施研究能够接起来：

```text
家用电脑 / 音乐制作软件
+ 歌声合成
+ 固定创作者 ID
+ bilibili 投稿
+ 评论、收藏、二创与长期补档
= 一个不必先进入传统唱片工业，也能让私人经验获得公共声音的创作空间
```

参见：

- [从拨号 BBS 到洛天依：中文世界普通人在线做歌的基础设施史（1993—2018）](from-dialup-bbs-to-vocaloid-grassroots-online-music-making-chinese-world-1993-2018.zh-CN.md)
- [当创作者和听众离得很近：2016—2018 年中文 VOCALOID 民间创作](grassroots-vocaloid-creation-and-short-social-distance-china-2016-2018.zh-CN.md)

## 五、2013 → 2019：同一个创作者从“寻遍星空”写到“化作繁星”

2019 年 12 月 6 日，公兔投稿《化作繁星》，仍由洛天依演唱。作品资料明确把它称为《寻遍星空》的续作，并说明其意图是写给“昨天与明天”；作品还在音乐与视觉上主动回接前作。

来源：

- 萌娘百科，《化作繁星》：  
  https://mzh.moegirl.org.cn/zh/%E5%8C%96%E4%BD%9C%E7%B9%81%E6%98%9F
- VCPedia，鸽稀拉（公兔），记录《化作繁星》于 2019-12-06 投稿：  
  https://vcpedia.cn/zh-hans/%E9%B8%BD%E7%A8%80%E6%8B%89

**证据等级：B。** “续作”关系有社区作品资料明确记录；若以后找到作者本人对两作关系的原始投稿说明或访谈，可进一步补为 A/B 交叉证据。

六年的间隔让这组作品比单独一首歌更有研究价值。

可以把二者的差别粗略概括为：

```text
2013《寻遍星空》
少年记忆 → 现实奔波 → 从旧日星空重新取得方向
核心动作：寻找、握住、继续走

2019《化作繁星》
相遇与分离 → 往事褪色 → 把记忆重新组织成陪伴自己的繁星
核心动作：回望、接受消逝、让过去继续发光
```

这里最值得追踪的，不是简单说“作者成熟了”，而是一个更谨慎的问题：

> **为什么同一套“星空”意象，六年前更适合表达对未来的寻找，六年后却更适合表达对相遇、离别与昨日的保存？**

如果以后能取得作者本人同时期自述、听众评论样本和平台传播材料，就可以把这个问题从文本比较推进到真正的创作者 / 受众生活史。

## 六、作品没有停在 2013：再创作让一首歌自己成为“过去仍在场”的证据

《寻遍星空》并没有随着早期中文 VOCALOID 阶段结束而消失。

公开 bilibili 页面显示，2025 年仍有以洛天依不同声库重新演绎该曲的合作投稿；2026 年又出现授权 Remix，并继续明确回指原曲、公兔及早期版本。

来源：

- bilibili，2025-11-03，《寻遍星空》洛天依 V3 / V5 再演绎：  
  https://www.bilibili.com/video/BV1Fu1FBjEAg/
- bilibili，2026-01-16，《寻遍星空 2026 Remix.ver》：  
  https://www.bilibili.com/video/BV1z9rrBQE1G/

这让作品形成另一层时间结构：

```text
2013：作品谈“回看年少、继续寻找未来”
↓
2019：续作再次回看“昨天与明天”
↓
2025—2026：后来创作者又回到这首已经十余岁的作品本身
```

于是，《寻遍星空》不只是在歌词中谈记忆。

**它自己也已经成为后来中文 VOCALOID 创作者重新访问、重调、重编与再解释的文化记忆。**

这和《过去的歌》在 2025—2026 年被重混、重发、重新归档的现象可以并置研究：数字作品不会只是“变老”，还会不断被新的软件、声库、平台账号和创作者关系重新激活。

## 七、和《北京东路的日子》《毕业通知》放在一起：人生转折不是一个瞬间

仓库已有两个毕业相关案例：

- 2010《北京东路的日子》记录共同校园即将结束；
- 2023《毕业通知》记录数字平台时代仍然可识别的校园共同生活与离校经验。

《寻遍星空》补上的恰恰是毕业叙事之后常被跳过的一段：

> **离开学校之后呢？**

毕业歌通常停在“我们要分别了”。

而《寻遍星空》把镜头推到稍后：一个人真的进入新的城市生活、真的开始独自承担时间、真的发现日常可能重复和沉闷以后，少年时期想象过的未来怎样继续存在？

因此，它可以和仓库正在推进的“考试 / 毕业 / 升学 / 工作 / 独立”生命历程研究接成连续链条：

```text
考试与升学
→ 毕业
→ 离开固定共同体
→ 独自安排生活
→ 进入工作 / 学业 / 城市节奏
→ 重新解释少年时期对未来的想象
```

## 我们知道什么

- 《寻遍星空》原版于 2013-11-09 投稿，次日出现重调版，2014-04-04 又有 PV 版；公开社区资料将作品与公兔、洛天依稳定关联。
- 歌曲文本明确把年少时期的星空记忆与“如今”的楼宇、独自生活、重复节奏和奔波并置。
- 《化作繁星》于 2019-12-06 投稿，公开作品资料将其明确记为《寻遍星空》的续作，并以“昨天与明天”描述其主题关系。
- 2025—2026 仍有新的《寻遍星空》再演绎和授权 Remix，说明作品继续存在于中文虚拟歌手社区的活跃记忆中。

## 我们可以合理推断什么

- 对这首歌面向的青年网络文化受众而言，“少年理想—城市独自生活—现实奔波—仍想守住方向”是一套足够可识别的生活叙事。
- 早期中文 VOCALOID 不只是技术展示或角色消费，也已经可以承载普通青年对成长、孤独和未来的私人化表达。
- 《寻遍星空》→《化作繁星》的六年关系为研究“未来感如何转为回忆感”提供了比单首作品更好的纵向入口。
- 后来的重调、翻唱、Remix 与补档，使歌曲本身也成为数字文化如何保存、重访和重写自己过去的材料。

## 我们还不知道什么

- 2013 原始投稿页面当时的完整简介、弹幕、评论和收藏结构，目前需要进一步做 Web / 平台档案追踪。
- 早期听众主要是什么年龄、教育与地域背景，现有社区资料不足以支持人口学结论。
- 2013 年创作者本人写作时的真实生活阶段与具体动机，不能仅凭第一人称歌词反推，需要作者同期自述或访谈。
- 《化作繁星》与前作的关系目前主要依赖作品资料页；仍应寻找 2019 原投稿说明、作者动态或访谈作为更高等级的一手证据。
- 需要进一步采集 2013、2019、2025—2026 不同时期的评论样本，观察听众是在“当下听未来”，还是在多年以后把作品作为自己的青春档案重新进入。

## 方法提醒

不要把“我听这首歌会想起自己的过去”直接升级为“这一代人都这样”。

更稳妥的证据链是：

```text
作品文本与版本史
→ 同期创作者自述
→ 同期评论 / 弹幕 / 社区讨论
→ 平台传播与二创记录
→ 调查、统计和生活史材料
→ 后来的回忆与再解释
```

个人记忆不是无效材料；它只是需要被标明位置。

对于 How People Lived，最重要的问题不是证明某首歌“代表一代人”，而是追问：

> **为什么它能在某个时期被许多人理解，为什么多年以后仍有人回来，而这种反复返回本身又说明了什么？**
