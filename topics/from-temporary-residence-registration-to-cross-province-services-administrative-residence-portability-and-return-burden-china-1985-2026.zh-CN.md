# 从暂住登记到跨省通办：行政居住可携性、返乡办证负担与“人走数据走”（中国，1985–2026）

> 研究问题：一个人已经在另一座城市工作、租房、结婚、照护家人甚至养育孩子，但身份证、户口、居住登记和某些公共服务资格仍然锚定在原籍或旧地址时，这种迁移到底有多“可执行”？Internet 和跨地区数据交换真正改变的，是不是“户籍制度本身”，还是更具体地把一部分原来必须由人的身体往返完成的行政动作，改成由记录、照片、审批状态和电子凭证在机构之间移动？

## 0. 与既有专题的区别

本仓已经讨论：

- 迁移何时成为普通职业策略；
- 长距离通信、汇款、铁路返乡如何降低离家生活成本；
- 社保记录如何跨单位、跨城市延续；
- 教育、求职、住房、照护和家庭形成中的各种数字事务接口。

本专题不重写户籍制度通史，也不把“暂住证 → 居住证 → 户口”写成一条人人都会经历的线性升级路线。它只研究一个较窄的生活能力：**人在异地以后，证明“我是谁、我现在住在哪里、我是否满足某项本地资格”的行政记录能不能跟着人走；如果不能，必须付出多少回原籍、跑窗口、找单位/房东代办和保存纸证的成本。**

本文使用几个工作概念：

- **administrative residence portability / 行政居住可携性**：实际居住地变化后，身份、居住和相关资格是否可以在新地点被识别、更新和继续使用；
- **administrative return burden / 返乡办证负担**：某项事务仍锚定原户籍地时，必须请假、买票、跨省返回才能完成的时间、金钱和机会成本；
- **residence legibility / 居住可读性**：一个城市能否把长期实际居住但未取得本地户口的人识别为持续居住者，而不只视为短暂停留者；
- **record travel replacing body travel / 记录移动替代身体移动**：准迁信息、身份照片、审批结果、户籍数据等在机构网络中传递，从而减少申请人本人往返；
- **credential stack congestion / 凭证栈拥堵**：服务越来越多以后，身份证、户口、居住登记、居住证、社保年限、住房/就业证明等反而需要被组合校验；
- **administrative optionality / 行政选择权**：人在不立刻迁户口、或尚未决定长期定居时，仍能在实际生活地维持证件、教育、医疗、交通、照护等基本事务的能力。

核心判断：

> **迁移不只需要铁路、工作和住房。只要关键身份证明与户政动作仍要求回到原籍，一个人的生活就仍被行政地理拴住。数字化最深的变化之一，是把“你得回去证明自己”逐步改成“两个地方的系统替你核对”。但“能异地办身份证”“有居住证”“能迁户口”“已经取得本地公共服务资格”始终不是同一个状态。**

## 1. 永久保留的状态链

不要把“我住在这里”压成一个状态：

```text
person physically lives in city B
!= city B has residence-registration record
!= registration is current / continuous
!= residence permit application is possible
!= application was submitted
!= materials / identity were verified
!= residence permit was issued
!= permit is currently valid / endorsed
!= holder qualifies for a specific local service
!= resident ID can be renewed in city B
!= household registration (hukou) has moved to city B
!= migration approval was granted
!= origin-side hukou was cancelled / moved out
!= destination-side hukou was entered
!= all linked services immediately recognize the new state
```

长期保持以下差异：

- `actual residence != registered residence`
- `residence registration != residence permit`
- `residence permit != local hukou`
- `resident ID != residence permit != household register`
- `能异地受理身份证 != 原籍审核/签发环节不存在`
- `网上保存 != 上报 != 窗口受理 != 审核通过 != 发证`
- `用人单位代录 != 劳动者本人操作电脑`
- `居住年限连续 != 人从未搬家`
- `电子证照可显示 != 底层资格永久有效`
- `能在一个城市长期生活 != 已决定永久定居`

## 2. 1985：在 Web 以前，“外地人在这里住”首先被做成纸面基层登记

北京市 1985 年发布、1986 年起实施的暂住人口规定，是一个很清楚的前 Internet 状态模型。外地来京人员要向暂住地派出所登记；16 岁以上、拟暂住超过三个月者要申领暂住证。住在单位、工地、旅店等地方的人，往往由留住单位指定人员统一申报；变更暂住地址还要向原、新派出所办理变动手续，离京时则交回暂住证。

- **A / official historical regulation republished by Beijing government**  
  https://www.beijing.gov.cn/zhengce/zfwj/zfwj/szfwj/201905/t20190523_70923.html

这里要注意：今天看到的是政府门户对历史文件的再发布，不是 1985 年网页——当时当然没有这个 Web 页面。

这套制度对普通生活的含义是：

> **身体已经移动，不等于行政身份也完成移动。**

现实中的“住在哪里”需要再次被当地基层机构记录；而且很多人的记录并不是本人独立办理，而是由单位、施工队、户主或旅店承担申报责任。这个“credential subject != paperwork operator”的结构，后来在 Web 时代仍会反复出现。

## 3. 海外前 Web 对照：丹麦 1968 年的 CPR 说明“地址可携性”并不天然属于 Internet

丹麦中央人口登记系统（CPR）建立于 1968 年。官方 CPR 资料说明，系统记录个人号码、姓名以及当前/历史居住信息；地址和迁移等信息由市镇机构持续更新。同行评议综述也把 1968 年以来持续更新的居住地列为这一系统的核心内容。

- **A/B / Danish CPR administration**  
  https://www.cpr.dk/cpr-systemet  
  https://www.cpr.dk/borgere/hvad-staar-der-om-mig-i-cpr-registerindsigt/hvad-og-hvem-er-registreret-i-cpr-og-hvem-opdaterer-oplysninger-om-dig-i-cpr
- **B / peer-reviewed overview**  
  https://journals.sagepub.com/doi/10.1177/1403494810387965

这个对照不能被误写成“丹麦 CPR 等于中国户口”。两者制度目标、福利接口、迁移约束都不同。真正可比的是一个较窄的基础设施问题：

> **一个人的地址和身份事实，能不能成为跨地方机构都能调用、更新的长期记录，而不是每移动一次就重新从零证明。**

因此，`record travel replacing body travel` 并不是 Web 发明的。Web 和手机只是在更晚阶段把原本主要属于机构后台的可携带记录，也逐步变成本人可以发起、查询和验证的事务。

## 4. 2004–2006：二代身份证数字化了证件，但长期外出者仍暴露出“原籍锚定”

2004 年全国第二代居民身份证换发工作正式启动。第二代证采用非接触式 IC 卡技术，可机读；2005 年进入全国集中换发阶段。

- **B / contemporaneous Xinhua report**  
  https://news.sina.com.cn/c/2004-03-29/23072171651s.shtml
- **B / Ministry of Public Security report, contemporaneous**  
  https://news.sina.com.cn/c/2005-04-28/17255777258s.shtml

但“证件变数字”没有自动解决人在异地的问题。2006 年公安部仍专门处理长期外出务工、经商人员回原籍换二代证困难：一代证未到期者可以暂缓，部分地区可组织人员前往流动人口集中地采集人像，也可以由本人提供标准照片、亲属持户口簿在常住户口所在地代办。

- **B / contemporaneous Xinhua report, 2006-10-19**  
  https://news.sina.com.cn/c/2006-10-19/175410276619s.shtml

重庆梁平更进一步尝试“分散采集、集中检测、原籍办证”：在深圳、东莞等地的务工人员拍数码照片，经 Internet 上传检测，家属/原籍机构继续完成其余办证链。

- **B / contemporaneous regional report, 2006-09-27**  
  https://news.sina.com.cn/c/2006-09-27/080010118888s.shtml

这给本项目一个很重要的数字化前史机制：

```text
body remains in work city
→ image travels over network
→ relative / origin office completes part of workflow
→ credential is still legally anchored at origin
```

所以 **online transmission can reduce return burden without yet creating full administrative portability**。

## 5. 2008：深圳把“暂住的人”变成可以被持续管理和服务的“居住者”，但操作主体仍常是单位

深圳 2008 年《居住证暂行办法》规定，非深圳户籍人员在深居住要进行居住登记；制度同时把就业、社保、教育、租赁、交通等公共管理与服务逐步连接到居住证，并要求相关部门通过统一政务信息资源交换平台实现信息互联和共享。

- **A / contemporaneous official regulation**  
  https://www.sz.gov.cn/zfgb/2008/gb604/content/post_4985058.html

同年公安与劳动部门启用“深圳市居住证/劳动就业登记网上申报系统”。关键不是“终于能网上办证”这么简单，而是它留下了一条完整的混合事务链：

```text
单位线下立户 / 领取登录密码与纸表
→ 员工填写纸质申请表
→ 单位登录 Web 系统
→ 录入个人、就业、居住证信息
→ 保存
→ 上报
→ 打印名单/材料
→ 携带相关资料到受理机构
→ 后续审核/制证
```

- **A / contemporaneous official notice, 2008-06-30**  
  https://www.sz.gov.cn/zfgb/2008/gb604/content/post_4985042.html

因此至少要保留：

> **employee is credential subject != employee is keyboard operator**

对于大量工厂员工，所谓“网上申办”可能意味着人事/行政人员替整个单位批量录入，而不是每名劳动者自己拥有 PC、账号和数字能力。

同一时刻，制度变化已经进入普通人的未来想象。2008 年 8 月 1 日，来自湖南、2005 年起在深圳工作的袁先生在同期采访中说，暂住证总提醒他自己是个“外”人；拿到居住证办理回执后，他说自己不再只是“暂住”，准备长期住下去。另一名在深圳工作 6 年的湖南机械维修工向先生，则最直接地把新证与终于可以去香港看看联系起来。

- **T1 / contemporaneous first-person via Xinhua**  
  https://news.sina.com.cn/s/2008-08-01/202114253686s.shtml
- **T1 / contemporaneous first-person via Legal Daily**  
  https://news.sina.com.cn/o/2008-08-04/080414263246s.shtml

这里不能把两名受访者外推成“所有流动人口都产生归属感”。它们能证明的是另一件事：

> **一种证件会改变一个人如何描述自己与城市未来的关系。**

“我在这里工作”开始有机会变成“我也许会长期在这里生活”。

## 6. 2015–2019：从“入口不足”走向“凭证栈拥堵”——资料越来越可查，但资格也越来越可计算

2015 年《深圳经济特区居住证条例》实施后，居住登记和居住证办理进一步重构。官方办理规定允许申报义务人和非深户籍人员通过网络查询相关居住登记/居住证信息；新的制度把连续居住登记、社保等历史状态更明确地带进资格判断。

- **A / contemporaneous official implementation rules, 2015-06-03**  
  https://www.sz.gov.cn/gkmlpt/content/7/7787/post_7787069.html
- **A / contemporaneous Shenzhen ordinance**  
  https://www.sz.gov.cn/zfgb/2014/gb900/content/post_4945836.html

同期中文 Web 已经留下 `https://www.szjzz.gov.cn/` 这一“深圳经济特区居住证服务平台”入口，用户可注册、申报居住登记、办理居住证/签注。

- **B / contemporaneous service guide, 2015-07-08**  
  https://m.bendibao.com/bsy613845.html

但“平台存在”没有消灭流程摩擦。2015 年深圳新闻网对当时舆情的整理保存了一条论坛用户材料：用户注册后提交真实资料，却遇到审核不通过、原因不清楚、短信未收到、咨询电话又难以解决的问题。

- **B/T1 / contemporaneous media reconstruction of forum complaint, 2015-09-22**  
  https://www.sznews.com/zhuanti/content/mb/2015-09/22/content_16895848_13.htm

因此成熟数字接口的新问题是：

```text
page reachable
!= registration succeeds
!= residence record matches reality
!= application passes machine/manual checks
!= user understands rejection
!= support channel resolves the problem
```

2015–2017，全国居民身份证“异地受理”又开始把另一种原籍锚定松开。2017 年 7 月起全国全面实施异地受理等制度。一个长期在郑州工作的天津人魏先生，已经可以直接在郑州补办身份证。

- **T1/B / contemporaneous People’s Daily, 2017-12-14**  
  https://politics.people.com.cn/n1/2017/1214/c1001-29705311.html

这里必须区分：

> **身份证可以异地受理 != 户口已经迁到现居城市。**

到 2018 年，北京第一批积分落户又把“多年稳定就业、住所、教育、社保、年龄等历史”做成一个可计算的长期资格栈。来自山东、已在北京生活 17 年的卢先生说，孩子考试一直是自己的“心病”；进入首批积分落户名单后，他最在意的是孩子以后能在北京参加高考。

- **T1 / contemporaneous China City News / People’s Daily network, 2018-10-22**  
  https://paper.people.com.cn/zgcsb/html/2018-10/22/content_1888259.htm

“拥堵型未来”在这里不只是城市太挤，而是：

> **在城市待得越久，一个人的生活越多层地接入当地系统；但要把这种现实生活转换成正式城市资格，也越需要多年连续记录彼此对得上。**

## 7. 2020–2022：疫情让“必须回原籍一次”从麻烦变成系统性脆弱点

2021 年川渝黔启动户口迁移跨省通办时，原籍贵州、在重庆落户的曹女士已经把旧流程想得很清楚：先向单位请假，回贵州办理迁出，再返回重庆。实际新流程中，她先通过“重庆公安警快办”在线提交购房迁户申请，两地公安系统处理后直接通知领取新户口簿；报道说办理时间由原来的约 25 个工作日压缩至 8 个工作日。

- **T1 / contemporaneous Xinhua, 2021-06-18**  
  https://www.chinanews.com/gn/2021/06-18/9502302.shtml

长三角同年跨省网上迁户案例更直接解释了机制：过去申请人往往要在迁入地、迁出地之间来回办理纸质准迁与迁移手续；升级以后，迁入和迁出公安机关依托人口信息系统在线流转信息，申请人只需在一地等待后续通知。

- **B / contemporaneous Zhejiang Daily / People’s Daily network, 2021-02-20**  
  https://society.people.com.cn/n1/2021/0220/c1008-32032374.html

公安部 2021 年 11 月公布的阶段数据也说明这种“记录替人跑路”已经不是单个演示案例：当年 6 月以来办理户口迁移“跨省通办”14 万余笔、户籍类证明 7 万余笔；另有 4 万余名因疫情无法回国者通过近亲属代办换领居民身份证。

- **A/B / contemporaneous Ministry of Public Security briefing via People’s Daily, 2021-11-25**  
  https://society.people.com.cn/n1/2021/1125/c1008-32292104.html

这里出现一个新生命历程机制：

> **如果一项制度要求“人必须回原籍”，平时它只是时间成本；当跨省、跨境移动突然受阻时，它会变成资格连续性的单点故障。**

疫情没有发明跨省数据交换，却强迫制度暴露“身体往返”到底是不是必要条件。

## 8. 2023–2026：防守型未来里的行政选择权——不必先决定永远留下，也能先让生活在这里继续运行

2023 年公安户政“跨省通办”进一步覆盖首次申领身份证、全类型户口迁移、户籍类证明和部分新生儿入户。人民日报报道中，家住昆明而户口在安徽的张先生，过去需要回户籍地给新生儿落户；新流程由两地公安在线审批流转材料，他在实际生活地就能完成这件家庭事务。2023 年 4–10 月，全国累计办理跨省首次申领身份证 57 万张、户口迁移 93 万笔、户籍类证明 44 万笔。

- **T1/A-B / contemporaneous People’s Daily, 2023-11-24**  
  https://society.people.com.cn/n1/2023/1124/c1008-40124811.html

2025 年郑州推出居住证电子签注：持证人可通过“郑好办”提交、人脸识别，派出所审核通过后系统自动生成电子居住证并延长有效期；实体证签注则可以在之后一年内再安排时间处理。

- **A / Zhengzhou Public Security Bureau, 2025-05-30**  
  https://www.zhengzhou.gov.cn/news4/9357131.jhtml

同期河南商报给出的普通人场景很值得保留：老李因为要经常到郑州帮子女照看孩子而长期居住，过去证件到期需要线下签注；新的电子流程正好作用于这种“为了照护而周期性跨城市生活”的晚年路径。

- **T1/B / contemporaneous service journalism, 2025-06-06**  
  https://www.sohu.com/a/901833171_121434698

到 2026 年，深圳公安居住证专题已经明确：办理渠道覆盖微信、网页、政务服务一体机等，网办率超过 85%；居住证签注成功后，后台自动顺延有效期并重新签发电子证照，不再需要因为“延期”重新制作一张实体卡。

- **A / current Shenzhen Public Security Bureau, 2026**  
  https://ga.sz.gov.cn/ZT/JZZ/  
  https://ga.sz.gov.cn/ZT/JZZ/YWWD/content/post_12764321.html

“防守型未来”在这里不要被理解成“大家只想留在一座城市不动”。更合适的解释是：

> **一个人希望保留移动和照护的余地，同时减少每次移动都要重新证明自己的成本。**

我可以暂时在这里帮孩子带孙辈、在这里换工作、在这里生孩子、在这里续证；是否最终迁户口，可以成为另一个晚一点再决定的问题。

这是一种 **administrative optionality**：并不是所有行政身份都必须一次性永久改变，现实生活也能先继续运行。

## 9. 重点矩阵：这条基础设施改变了哪些普通生活项目

| 生活项目 | 行政居住基础设施怎样介入 | 仍不可偷换的边界 |
|---|---|---|
| 就业 | 单位可代办/申报居住与就业信息；异地身份证减少返乡办证 | 单位录入不等于本人数字自主 |
| 住房 | 地址变更、出租人/房东申报形成持续居住记录 | 实际住址不等于户口地址 |
| 教育 | 居住证、居住年限可能进入随迁子女入学/考试资格 | 有居住证不等于自动获得所有教育资格 |
| 迁移 | 身份证异地受理、户口跨省通办降低行政返乡 | 异地办证不等于已经落户 |
| 家庭形成 | 配偶投靠、新生儿入户可以跨省流转 | 新生儿登记地、父母现居地与户籍地可不同 |
| 照护 | 老人可为了帮助子女长期异地居住并续证 | 数字签注不等于老人一定能独立操作 App |
| 社保/医疗 | 居住、社保历史可进入资格校验；居住证明可接其他服务 | 一个系统显示有效不等于另一部门自动承认 |
| 证件与记录 | 身份照片、准迁信息、审核状态开始在后台跨地区流动 | 数据能移动不等于所有审批都消失 |
| 未来预期 | “只是来打工”可以变成“也许长期住下去” | 个案归属感不可外推成全体流动人口态度 |
| 历史保存 | 公开政策/帮助页易保存，个人居住记录高度私密 | archive 不能恢复真实个人后台状态 |

## 10. 证据等级、反例与后见之明风险

### 我们已经能较强确认

1. **A**：1985 北京暂住登记依赖派出所、单位/户主等基层纸面申报，明显早于 Web；
2. **A**：2008 深圳已经同时存在居住证制度、跨部门信息交换与用人单位 Web 申报流程；
3. **T1/B**：至少有 2008 同期流动劳动者把“居住”而非“暂住”与长期留下、子女/出行未来联系起来；
4. **B/A**：2006–2017 身份证办理由“原籍必须本人返回”的强锚定，逐步发展到照片网络传输、亲属代理和全国异地受理；
5. **T1/A-B**：2021–2023 跨省户口事务已经通过机构间数据流转，实质减少普通人往返原籍；
6. **A**：2025–2026 电子签注/电子证照进一步把“证件有效状态”从实体卡片更新中拆开。

### 反例 / 不应写成线性进步

- 2008 的网上申报仍要线下立户、纸表、打印和窗口材料；
- 2015 的新平台仍有用户遇到信息匹配、审核原因和客服问题；
- 有居住证不等于有当地户口，更不等于每项公共服务资格都相同；
- 异地身份证受理也不意味着所有原籍审核逻辑立即消失；
- 电子证照会降低携带/续签成本，却创造账号、实名、人脸识别、设备和后台数据正确性的新依赖；
- 对老人、低数字技能者、单位集体员工而言，数字事务常由亲属、用人单位或窗口人员共同完成。

### 后见之明风险

- 不把“暂住证”只当成今天看来注定要被淘汰的过渡品；在当时它本身就是管理大规模跨区域流动人口的一套现实接口；
- 不把 2008 的居住证直接解释成今天全国居住证制度的完成形态；
- 不把 2015 的 Web 平台写成“手机政务时代”，当年 PC Web、窗口、电话、单位代办仍高度重要；
- 不把疫情后的“数据多跑路”投射回 2000s；2006 的照片上传仍然只是把流程的一段网络化；
- 不把丹麦 CPR 类比成中国户籍制度，只比较“跨地点持续身份/地址记录”这一基础设施问题。

## 12. 本轮改变了我们对“人怎么活着”的哪一点理解

迁移不是一个人在地图上从 A 点移到 B 点。

一个人可以早已在 B 城市上班、租房、恋爱、生孩子、照顾父母，却仍然需要在关键时刻回 A 城市证明自己是谁、把哪张纸迁出来、更新哪张证。**身体的迁移可以领先行政记录很多年。**

Internet 与跨地区数据交换最深的一项普通生活后果，不是“办事终于有网页了”，而是逐渐改变谁必须移动：

```text
过去：人带纸，在两个地方之间移动
后来：照片、申请、准迁信息、身份记录在两个机构之间移动
```

这会改变一种人生是否值得尝试。如果身份证过期就要请假回老家，如果孩子落户必须跨省往返，如果帮子女照看孙辈每年还要专门跑窗口续证，那么“去另一座城市生活”始终包含很多隐藏返程票。行政居住可携性变强以后，普通人才更可能拥有另一种迁移生活：**先去那里工作、生活、照护和试着留下；至于是否最终把整套身份永久迁过去，可以晚一点再决定。**
