# 1990s–2025：谁和谁可以成为“一户人”——合租、陌生室友与被匹配出来的家庭

> 核心问题：普通人的居住单位并不只有“原生家庭 → 婚后家庭 → 自有住房”这一种。城市迁移、校园离巢、就业地点与租金压力可以让朋友、同学、同事乃至此前完全陌生的人，在一段时间内共同组成一个日常生活单位。
>
> 本专题研究 **roommate search（室友搜索）**、**unrelated co-residence（非亲属共居）** 与 **household-by-match（匹配型住户）**。重点不是把合租浪漫化为“年轻人的自由生活”，也不是把它还原成贫困或住房危机，而是问：一个人什么时候需要和非亲属一起住；他如何找到这个人；价格、通勤、隐私、照护、安全与身份验证怎样共同决定这条路线能否执行；Internet 又在哪一层真正改变了“谁可能成为室友”。
>
> 对 2005–2010 中文旧网中的租房帖子、动态房源、电话/QQ 交接和入住结果缺口，见：
> <https://github.com/tmzncty/old-web-archaeology/blob/main/docs/ROOMMATE_ADS_RENTAL_LISTINGS_PRIVATE_HANDOFF_AND_COHABITATION_OUTCOME_GAPS_2005_2010.md>

## 结论先行

这一轮材料支持九个分析概念。

### 1. household-by-match：家庭之外，还存在“被匹配出来的住户”

历史和统计叙述经常把一个地址里的共同居住者默认理解成家庭、亲属或制度分配的集体生活，例如：

- 父母与子女；
- 夫妻；
- 多代家庭；
- 单位宿舍；
- 学校宿舍；
- 工棚或集体宿舍。

但租赁市场还会制造另一种结构：

```text
住房成本 / 城市进入 / 通勤需求
→ 寻找可分摊的人
→ 朋友、同学、同事或陌生人配对
→ 共同承租或分租
→ 暂时形成一个日常生活单位
```

这里的人并不一定共享亲属关系、爱情关系、长期经济计划或未来家庭目标。

因此本专题把它称为：

> **household-by-match（匹配型住户）**

它提醒我们：

> **same address ≠ family**

> **shared rent ≠ shared future**

> **co-residence ≠ intimacy**

一个社会中“普通人有多少种活法”，不能只数婚姻状态和户籍家庭，还要数这些临时、串行、可退出的共同居住结构。

### 2. roommate-search radius：Internet 没有发明合租，它改变的是“可成为室友的人”来自哪里

前互联网时代，找房和找室友可以依靠：

- 家人、朋友、同乡；
- 单位与学校关系；
- 报纸分类广告；
- 房屋中介；
- 校园、社区和街头信息栏；
- 电话。

Internet 到来以后，新增加的是：

- BBS；
- 房产/地方门户；
- 分类信息网站；
- 论坛和社区；
- 后来的 SNS、小组、App。

因此真正值得观察的不是“哪一年出现网上租房”，而是：

> **roommate-search radius（室友搜索半径）**

一个刚到陌生城市、没有足够熟人网络的人，是否能够把“此前不认识的人”纳入现实可执行的合租候选。

Internet 的关键变化之一是：

> **陌生人从社会上存在的人，变成了可被检索、联系和安排看房的人。**

但这一步同时把过去由熟人链部分承担的信任问题，推给了个人筛选、平台字段和线下核验。

### 3. co-residence optionality：合租可以扩大“能进哪座城市、能住到哪里”的可行集合

对刚毕业、跨城就业或收入较低的人，住房不是就业之后自动解决的背景条件。

如果单独整租超出预算，现实路线可能是：

```text
不去这座城市
vs.
住得很远
vs.
住很差的独立空间
vs.
和别人合租靠近工作地
vs.
床位 / 群租 / 短租
```

因此合租可以提供一种：

> **co-residence optionality（共居可选性）**

它不是“住房自由”的同义词。更准确地说，它可能让一个人以牺牲部分隐私、空间控制权和室友选择成本，换取：

- 更低租金；
- 更靠近工作或学校；
- 更早进入一座城市；
- 在职业尚未稳定时避免高额固定住房承诺。

所以：

> **shared housing can expand city-entry feasibility without creating residential security**

### 4. budget–privacy–commute triangle：很多租房选择不是“喜欢哪种生活”，而是在三个代价之间移动

合租与整租不能简单写成两种审美偏好。

对很多年轻租客，更接近下面这个三角：

```text
低租金
 ↕
隐私 / 独立空间 ←→ 通勤时间 / 地点
```

同样一笔预算，可以换：

- 市区的一张床或一个房间；
- 较远地区的一整套房；
- 更长通勤换取更大私人空间；
- 更少私人空间换取更短通勤。

因此：

> **housing preference must be read together with the feasible budget and transport network**

不能把“选择合租”自动解释为喜欢社交，也不能把“选择远郊整租”自动解释为拒绝城市中心生活。

### 5. trust substitution：陌生人匹配扩大后，职业、学校、性别与生活习惯会变成信任代理变量

2005 年的同期媒体保存了一条网上合租帖。发帖者主动写出：

- 年龄；
- 性别；
- 名校研究生学历；
- 外企工作；
- 不抽烟、不喝酒；
- 希望对方是学生或有“正当职业”的女性；
- 一人一间。

这些字段并不等于真实身份已经被验证。

但它们显示陌生人合租需要一种新的 **trust substitution（信任替代）**：当“这是我同学介绍的人”不再是前提，发帖人会用学历、职业、生活习惯、性别、作息、兴趣等信息，尝试让对方判断“能不能一起住”。

于是：

> **profile legibility ≠ verified identity**

> **compatible self-description ≠ compatible daily life**

这和仓库里已经研究过的招聘简历、婚恋 profile 很像，但结果更具身体性：匹配成功后，两个人不是去面试或见一次面，而是可能每天共享厨房、厕所、门锁、夜间空间和账单。

### 6. co-residence conversion funnel：找到帖子只是最前面一层

一条网上合租信息真正进入生活，至少要经过：

```text
listing/post visible
→ prospective roommate notices it
→ contact
→ phone / QQ / message handoff
→ viewing
→ identity / landlord / room verification
→ price and deposit agreement
→ lease / sublease
→ move-in
→ daily compatibility
→ continued co-residence
→ move-out / renewal / replacement
```

因此必须坚持：

> **listing visible ≠ room available**

> **contact made ≠ viewing completed**

> **viewing ≠ identity verified**

> **move-in ≠ durable co-residence**

这条 funnel 也解释了为什么旧网非常容易高估“住房选择”，却很难告诉我们这些帖子中到底多少真正形成了一个住户。

### 7. household seriality：同一套房可以保持，住户却不断换人

朋友结婚、换城市、换工作、收入增长、情侣同住、房东涨租，都可能使室友退出。

于是现实中的共同居住单位可能是：

```text
A+B+C
→ A+B+D
→ B+D+E
→ D+E
→ 房屋退租
```

这是一种：

> **household seriality（住户串行性）**

对统计横截面来说，每个时点都只是“一套三人合租房”；对生命史来说，却可能是一个人在几年里连续经历四五组不同的室友关系。

### 8. co-residence sovereignty：合租不仅分摊租金，也重新提出“谁有权决定家里怎么过”

陌生或半陌生的人一起住以后，很多家庭内部通常不需要写出来的问题必须显性谈判：

- 谁打扫；
- 食物能不能共用；
- 公共用品谁买；
- 谁可以带客人回家；
- 伴侣能否过夜；
- 什么时候安静；
- 能否抽烟；
- 公共空间怎样使用；
- 水电网费怎样分；
- 谁损坏物品怎样赔；
- 一个室友长期不在家是否仍交同样租金。

因此合租也可以观察：

> **co-residence sovereignty（共居主权）**

一个“家”不再由亲属角色或单一房主自然给出规则，而需要协商、默认、冲突与重新制定边界。

### 9. chosen co-residence：成本型合租与主动型共居可以同时存在

到 2024 年的同期报道里，上海已经出现一些明确把公共空间、共同活动和室友自治当作目标的共居空间。

这些人不只是因为“付不起整租”才住在一起；有人此前独居，却因孤独和缺少日常连接主动加入共居。

但这只能证明一种真实路线存在，不能外推成青年总体。

因此必须同时保留：

- **cost-sharing co-residence**：主要为了分摊房租；
- **location-sharing co-residence**：为了住得离学校/工作更近；
- **transition housing**：实习、刚毕业、换工作时的过渡；
- **friend/co-worker household**：熟人共同租住；
- **stranger-matched household**：通过广告/平台找到陌生室友；
- **intentional co-living**：主动追求共享生活和社群；
- **crowded/bed-space rental**：被价格压缩到床位甚至多人一室的路线。

不能把最后一种浪漫化成“共同体”，也不能把第一种自动写成悲惨。

# 一、前互联网与早期网络边界：先有信息栏、报纸和熟人，后有 BBS

## 1. 找房从来不是纯私人动作，它需要一个信息基础设施

在 Web 大众化以前，房源和室友也需要被发现。

普通人的发现栈可以包括：

```text
熟人 / 同乡 / 同学 / 单位
+ 报纸分类广告
+ 中介
+ 校园和社区信息栏
+ 电话
```

2007 年《南方周末》对北京大学“三角地”信息栏的同期报道提供了一个非常好的边界案例。报道说，到 2000 年代，社团与讲座信息已经主要转向校园 BBS，而实体信息栏仍可见培训、宿舍铺位转让等生活信息；另一个同期报道明确提到信息栏长期贴有租房、求职和讲座信息。

这证明：

> **physical bulletin board was an information interface, not just a wall**

但 2007 年材料只能可靠证明当时的人如何描述三角地以及 2000 年代的媒介迁移；涉及更早年代的感受属于回顾性内容，不能倒写成 1980s/1990s 的直接 capture。

### 证据

- B（同期《南方周末》，2007-11-08/09）：三角地信息栏、BBS 替代与仍存的宿舍铺位等信息。  
  <https://www.edu.cn/yiwujiaoyu_1074/20071109/t20071109_264480_2.shtml>
- B（同期《新京报》经新浪，2007-11-01）：报道明确称三角地信息栏贴有租房、讲座、求职等信息。  
  <https://news.sina.com.cn/c/2007-11-01/020614207298.shtml>

## 2. Internet 的关键变化不是“有广告”，而是广告不再只服务经过那面墙的人

实体信息栏的 reach 受身体位置限制：

- 你要经过那里；
- 或者托人去看；
- 信息覆盖范围与张贴地点高度相关。

BBS / 地方门户 / 分类信息网站把它变成：

```text
知道站点 / 板块
→ 搜索或浏览
→ 远程看到房源/室友信息
→ 先联系
→ 再决定是否跑到现场
```

这降低了 **pre-visit information cost（看房前信息成本）**。

但它不是“住房变成线上商品”。房间、房东、门锁、噪音、室友、合同和社区仍在线下。

因此：

> **remote discovery ≠ remote verification ≠ remote co-residence**

# 二、2005：陌生合租已经可以通过网站、报纸和校园同时进入视野

2005 年《中国新闻网》转载《市场报》的同期专题，保存了一条很有价值的网上合租帖：一名 28 岁男性用学历、外企工作、生活习惯和对未来室友的要求来自我描述；报道同时指出，在北京一些都市报、房产网站和大学校园都能看到类似合租广告。

这条材料最重要的不是“异性合租很时髦”。原报道本身带有很强的“新生活方式/伦理冲击”媒体框架，不能拿标题当社会规模证据。

更扎实的事实是：

1. **多渠道并存**：报纸、校园与网站同时工作；
2. **陌生人可寻址**：候选室友不必先是熟人；
3. **profile screening 已出现**：职业、学历、吸烟饮酒、性别等成为筛选字段；
4. **经济与地点仍是底层约束**：报道中的受访者反复提到减轻租金压力、交通便利与工作地点。

同一篇报道还给出反例：不少合租仍然发生在同学、朋友、同事之间，说明网络陌生人匹配已经存在，不等于熟人合租被替代。

### 证据

- B（同期《市场报》经中新网，2005-03-18）：网站帖子、报纸/房产站/校园的合租广告与多名租客同期采访。  
  <https://www.chinanews.com.cn/news/2005/2005-03-18/26/552059.shtml>

### 不能写成什么

不能写：

> “2005 年中国年轻白领普遍开始与陌生异性合租。”

因为专题报道的取样、城市覆盖和“流行”判断都不足以证明 population prevalence。

可以写：

> 2005 年的同期城市媒体已经能够观察到，网站、都市报和校园广告把陌生人合租变成一种可被公开寻找、讨论和执行的住房路线。

# 三、2006：发现半径扩张以后，身份验证与住房安全成为新的私人劳动

2006 年《新闻晨报》的同期报道记录，一名刚在上海参加工作的女性因一居室房租超过千元、压力较大，在网上发布合租信息；帖子发出后，多名应征者上门看房，她很快接受其中一人入住。一个多月后发生严重刑事案件。

这类材料必须非常克制地使用。它不能用来猎奇，更不能推出“陌生合租危险”。

它真正证明的是一条系统边界：

```text
online post
→ rapid response
→ physical viewing
→ move-in
```

可以跑得很快，但：

> **discoverability expansion can transfer verification work to the renter**

同期报道还称记者浏览上海热线租房栏目时看到大量合租帖，并观察到很多帖子在性别要求上不作限制。这是 B 级同期媒体对平台状态的观察，不等于我们已经取得了上海热线当日房源数据库或原始历史 capture。

因此对旧网考古必须区分：

> **press-observed listings ≠ preserved listing corpus**

### 证据

- B（同期《新闻晨报》经新浪，2006-09-07）：网上发布合租信息、看房、入住与记者对上海热线租房栏目的观察。  
  <https://news.sina.com.cn/s/2006-09-07/02409954170s.shtml>

同年另有上海“群租”讨论：一名刚到上海工作的租客称自己在网上看到低价、地段好的合租信息；当时争议集中在一套住房被进一步切割为多人小间后产生的消防、物业和相邻权风险。

这提醒我们：

> **roommate sharing ≠ subdivided group rental**

虽然日常语言会混称“合租”，但研究时必须把“几个人共同承租完整住宅”和“经营者整租后切成大量房间/床位再分租”拆开。

- B（同期《东方早报》经搜狐，2006-07-19）：群租法律讨论与租客通过网上信息进入低价市中心房源的个案。  
  <https://news.sohu.com/20060719/n244327918.shtml>

# 四、2008：离开学校宿舍，不等于立即进入“独立住房”

2008 年《北京日报》对北京 10 所高校 16 个班级做的小规模随机调查中，572 人有 34 人住到校外，约占样本 6%。这不是全国大学生统计，也不能扩成“北京大学生总体 6%”。

但它很好地揭示了**离开 institution-assigned household（制度分配住户）以后可以出现多少不同路线**。

报道观察到的校外住房从：

- 地下室小隔间；
- 床位；
- 多人一室；
- 单间；
- 一居室；
- 两居室；

同时存在。

中关村附近的同期价格还显示：一个床位、单间、一居室之间有非常大的费用梯度。

于是“搬出宿舍”不能直接编码为“住房独立”。

它更可能是：

```text
学校宿舍
→ 校外床位 / 多人间
→ 合租房间
→ 单独整租
```

不同人的路径可以停在任意一层，也可以来回移动。

### 为什么有人愿意离开更便宜的宿舍？

报道中的一名学生提到宿舍约束、定点断网断电等因素。

这说明住房价值并不只来自面积和价格，还包括：

- 作息自主权；
- 网络连续性；
- 私密性；
- 是否能与伴侣/朋友共同生活；
- 是否离实习/工作更合适。

所以：

> **cheap institutional housing ≠ preferred housing**

### 证据

- B（同期《北京日报》经中新网，2008-04-03）：10 校 16 班 572 人的小规模调查、租金与床位/单间/整套住房梯度。  
  <https://www.chinanews.com.cn/edu/dxxy/news/2008/04-03/1211332.shtml>
- B（《文摘报》转《北京日报》，2008-04-13）：地下室、床位、校外租住与学生对宿舍约束的同期描述。  
  <https://www.gmw.cn/01wzb/2008-04/13/content_760684.htm>

同年《法制晚报》还报道，有经营者先整租住房再按床位或单间向学生分租，说明合租市场中已经存在**intermediation by subdivision（切割型中介）**，室友并不一定自己共同签下整套房。

- B（同期《法制晚报》经搜狐，2008-08-26）：高校周边床位/单间分租。  
  <https://news.sohu.com/20080826/n259214033.shtml>

# 五、2015–2019：拥堵型未来里的住房不是一个终点，而是租金、通勤和隐私的持续优化

## 1. 2016 毕业的小蒙：理想的单身公寓，被收入约束重新计算成合租主卧

2019 年《都市快报》保存了一个非常有用的近同期生命片段。

小蒙 2016 年大学毕业时，本来很介意和别人住，希望有电影式的高品质单身公寓；但月租 2000 元已经约占她当时工资 40%，看房后发现整租不现实，于是选择四室合租中的带独卫主卧。

这条材料说明：

> **stated preference can be real while infeasible**

她不是因为“喜欢合租”才开始合租，而是在预算约束下，把自己最看重的独立卫生间、阳台、新房品质保留下来，把“整套独占”让掉。

这是一种非常典型的 **constraint-preserving compromise（保留核心偏好的约束式妥协）**。

### 证据

- B（同期/近同期《都市快报》，2019-03-06，受访者回顾 2016 起的租房经历）：  
  <https://hznews.hangzhou.com.cn/jingji/content/2019-03/06/content_7156974_0.htm>

报道后半使用某租房平台数据讨论杭州青年合租与地铁距离。平台样本不能当杭州全体租客总体，但它强化一个机制：低预算青年往往同时要求“尽量靠近地铁”。

## 2. 2019 北京：床位 → 多人合住 → 远郊整租

《中国青年报》2019 年的同期人物梁辰提供了一条更漂亮的串行住房路径。

她刚来北京时，先在双井附近一套两居室里租一个床位，整套房摆了 10 张床；后来又在一间卧室里与另外两人同住；生活习惯冲突后，她最终把居住地移动到地铁 S1 线末端石厂，换取宽敞的两室一厅。

她每天通勤约 2 小时 40 分钟，并在途中学英语。

这说明一个人的住房路线可能不是：

```text
合租 → 收入上涨 → 市区整租
```

而是：

```text
近工作地、极低隐私
→ 稍高隐私的合租
→ 更远距离、更多私人空间
```

即：

> **privacy can be bought with commuting time**

同一篇报道还做了一个当时的房源对比：同样约 3000 元，在望京只能租到条件很差的单间，而在地铁末端可以租到两室一厅。

这不是完整市场统计，却非常直观地展示了 **budget–privacy–commute triangle**。

### 证据

- B（同期《中国青年报》，2019-09-10）：梁辰多次换租、床位/多人房/远郊整套住房与 2 小时 40 分通勤。  
  <https://zqb.cyol.com/html/2019-09/10/nw.D110000zgqnb_20190910_2-11.htm>

## 3. 2019 毕业生调查：合租是一条常见路线，但 denominator 必须保留

《2019 大学毕业生租住数据报告》使用线上调查，在北京、上海、湖北、江苏、广东、四川等高校集中地区收回 1725 份问卷。报告中超过八成应届毕业生表示通过租房解决居住问题，超过八成租房者选择合租，九成多人的可接受房租低于 3000 元。

这说明在该样本中，合租已经是非常常见的毕业初期住房路线。

但这份调查由租赁企业等机构参与、使用线上样本、地域集中，不能写成：

> “2019 年中国 80% 大学毕业生都合租。”

更准确是：

> 在这份 1725 人的线上应届生样本中，租住与合租高度集中，且租金预算约束很强。

- B（同期《中国青年报》，2019-07-05）：调查方法、样本量、租金预算与合租比例。  
  <https://zqb.cyol.com/html/2019-07/05/nw.D110000zgqnb_20190705_6-02.htm>

# 六、2020–2022：偶发型未来把“室友是谁”从生活习惯问题变成更明显的共同风险环境

2020 年《中国青年报》对 2000 名 18–35 岁、具有租房需求的年轻人做问卷调查。55.2% 倾向整租，38.1% 倾向两人合租，6.7% 倾向多人合租；报道中的租客在疫情以后把小区与室友卫生条件放到更靠前的位置。

这条材料的价值不在于证明疫情“导致大家都不合租”。事实上样本里仍有很大一部分愿意合租。

真正改变的是：

> **co-resident externality became more salient**

室友的：

- 卫生习惯；
- 出行范围；
- 访客；
- 共同厨房/厕所使用；

不仅影响舒适度，也更明显地被理解为健康与计划风险。

### 证据

- B（同期《中国青年报》，2020-08-13）：2000 人调查、整租/两人合租/多人合租偏好与同期第一人称。  
  <https://zqb.cyol.com/html/2020-08/13/nw.D110000zgqnb_20200813_2-10.htm>

2021 年同报另一项 1546 人调查中，78.0% 称当时租房居住；其中 42.2% 与朋友/同学/伴侣合租，27.6% 自己整租，8.2% 与陌生人合租。同期毕业生还提到虚假房源、满意房源在签约前已被别人租走等摩擦。

这给 roommate matching 增加另一个边界：

> **visible inventory ≠ reservable inventory**

> **online description ≠ inspected room**

- B（同期《中国青年报》，2021-08-12）：1546 人问卷与多名租客同期采访。  
  <https://zqb.cyol.com/html/2021-08/12/nw.D110000zgqnb_20210812_3-10.htm>

2022 年上海又出现“合租换整租”讨论。同期报道主动核验了机构报告，而没有简单接受“趋势”标题；这本身也提醒我们：疫情后的住房变化同时受租金、供给、收入、卫生与个人空间需求影响，不能单因果归给疫情。

- B（同期上观新闻经人民网，2022-07-16）：上海合租/整租变化的同期调查性报道。  
  <https://sh.people.com.cn/n2/2022/0716/c134768-40040845.html>

# 七、2023–2025：防守型未来并不只产生“更便宜的住法”，也产生主动设计关系边界的住房实验

## 1. 2024 上海共居：非亲属住户可以主动追求“家庭感”，但必须自己治理它

2024 年《中国青年报》保存了一组非常罕见的同期共居生活记录。

几名此前互不相识的年轻人合租一套上海公寓，共享客厅、部分食物和活动；住户会一起吃饭、看展、旅行，也会在室友住院时探望。

但最重要的是，它没有把这种生活写成自动和谐。

报道详细记录了：

- 入住要填写线上申请表；
- 有的空间要面试、共同投票；
- 公共基金；
- 垃圾与清洁规则；
- 食物边界；
- 访客/沙发客期限；
- 房租分担争议；
- 室友冲突与退出机制；
- 房间空置后其他人承担的租金风险；
- 恋爱、换工作、去外地导致的高流动。

这使“chosen family”式语言必须被降到恰当位置。

住户可以说“像家人”，但报道中的人自己也提醒：

> **family-like support ≠ kinship equivalence**

这种住户依靠的是持续治理，而不是因为“不血缘”就天然自由。

### 新机制：relationship infrastructure can itself be a housing goal

前几代合租主要被写成“房租分摊”。这批案例中，部分人恰恰曾经独居，却因为孤独、缺少日常互动而主动选择共居。

所以在 2023–2026 的“防守型未来”里，可以把下面几种动作并列，而不是互相替代：

- 降低固定住房成本；
- 保留整租和私人空间；
- 住远一点换空间；
- 合租换地点；
- 共居换日常支持网络。

防守不只等于“花最少的钱”。它也可能意味着：

> **给不确定生活建立一些低门槛、日常可用的社会支持。**

### 证据

- B（同期《中国青年报》经中新网，2024-01-10）：上海共居空间住户、申请、自治、边界、流动与冲突。  
  <https://www.chinanews.com.cn/sh/2024/01-10/10143241.shtml>

### 代表性限制

这是一篇主动寻找“非典型合租”的特写。

它证明：

- 这种生活路线存在；
- 参与者如何理解它；
- 它需要怎样的规则。

它不证明：

- 上海青年普遍转向共居；
- 共居一定比独居幸福；
- 经济压力不是重要原因；
- 这种模式具有长期稳定性。

事实上报道自己记录了高人员流动、空置成本、邻里投诉和内部冲突。

## 2. 2025：平台样本里合租仍占主流，但整租份额同时上升

2025 年上海市青少年研究中心与自如租房联合报告，使用的是**自如 2022–2024 年上海青年租房平台数据**，不是上海全部青年人口调查。

在这个明确限定的样本里，合租约占四分之三，但整租份额上升到约四分之一；应届毕业生的合租比例更高。

它提供了一个重要反例：

> **housing pressure does not produce one-directional collectivization**

即使合租仍然常见，一部分青年对独立空间的需求也可能上升。

因此防守型未来的住房策略更适合写成：

> **成本缓冲、通勤优化、私人空间与社会支持同时竞争。**

- B（同期《中国青年报客户端》，2025-07-10；平台数据来源在报道中明确）：  
  <https://t.m.youth.cn/transfer/index/url/house.youth.cn/dtxw/202507/t20250710_16108834.htm>

# 八、海外对照：美国 1990 年代的 Craigslist 也把“本地陌生人”变成可搜索资源

本轮海外比较选取旧金山，因为它能把网络媒介与住房紧张拆开观察。

## 1. 1995：Craigslist 从邮件列表扩展到本地住房信息

Craigslist 保存的 2000 年《Investor's Business Daily》同期报道说，Craig Newmark 1995 年最初以本地活动与公寓出租信息起步，靠口碑增长；其他保存在 Craigslist press archive 的早期报道也描述了它从电子邮件列表向 Web 分类信息扩展的过程。

这和中国 2000 年代的房产门户/BBS 有一个共同机制：

> **local strangers become addressable through a shared information layer**

并不需要平台先拥有房子，它只需要让：

- 有房的人；
- 找房的人；
- 找室友的人；

在同一个城市 namespace 下发现彼此。

### 证据

- B（2000 年《Investor's Business Daily》，由 Craigslist press archive 保存）：  
  <https://www.craigslist.org/about/press/craigsonlinelistofstuff>
- B（2003/2004 年同期媒体，Craigslist press archive）：邮件列表、Web 与 apartments 分类的扩张。  
  <https://www.craigslist.org/about/press/itlist>

## 2. 2000 旧金山：Internet 提高匹配能力，但没有消灭住房稀缺

WIRED 在 2000 年对旧金山互联网繁荣期住房危机的同期报道中，采访了 Rent Tech——一个帮助居民寻找公寓或室友的服务。当时该服务估计当地空置率低于 1%，两居室平均租金相较 1995 年大幅上涨，许多人因此与室友共享住房。

这个海外对照非常重要，因为它防止技术决定论：

> **better matching infrastructure can coexist with worsening affordability**

Internet 可以降低“找到一个室友”的成本，却不会自动增加城市土地和住房供给。

- B（同期 WIRED，2000-08）：旧金山住房紧张、Rent Tech 的 apartments/roommates 服务与共享住房。  
  <https://www.wired.com/2000/08/dot-commers-go-home/>

### 一个待核验的更早线索：telephone/fax → Web

关于芝加哥《Chicago Reader》的二手史料称，其 1995 年曾用自动电话 `SpaceFinder` 让用户搜索公寓广告并传真返回结果，1996 年再将系统改为 Web 查询。

这条线索非常符合本仓关心的“Web 前数字/电信信息系统”，但本轮未取得可直接核验的同期《Reader》原始材料，官方网站也被当前检索环境 robots 阻断。

因此暂时只登记为：

> **candidate lead, not established evidence**

未来若取得 1995–1996 原始报纸、服务手册或 capture，再升级为正式比较。

# 九、四个未来时期：住房的“未来感”究竟哪里变化了

## 2005–2012：扩张型未来——陌生人匹配降低进入城市的门槛之一

这一阶段的重点不是“大家都喜欢合租”。

更准确的是：

- 城市就业和大学生活把更多年轻人带离原家庭；
- 独立整租并不总可负担；
- 网站/BBS/门户扩大了房源和室友的发现范围；
- 合租可以让人用较低初始住房成本进入城市、靠近学校或工作。

于是：

> **a wider life menu also required a wider temporary-housing menu**

未来选项变多，并不意味着每个选项都自带一套独立住房。

## 2015–2019：拥堵型未来——从“能不能留下”变成“租金、通勤、隐私怎么同时优化”

2016–2019 的同期/近同期材料里，一个人可能明确想要独立空间，却发现：

- 整租太贵；
- 近处只能合租；
- 远处可以整租；
- 地铁把“住远”变成可执行；
- 但时间成本大幅上升。

这就是一种很具体的“拥堵”：

> **options exist, but optimizing one dimension worsens another**

## 2020–2022：偶发型未来——共同居住者成为计划风险的一部分

疫情不是合租的起点，但它强化了：

- 卫生；
- 公共空间；
- 室友活动；
- 隔离时的空间；
- 是否能整租；

这些变量的显著性。

住房从“晚上回去睡觉的地方”，更明显地暴露为一个会影响工作、健康、社交与连续性的基础设施。

## 2023–2026：防守型未来——低成本、独立性与日常支持可以是不同的 hedge

目前证据不支持“青年统一退回合租”，也不支持“大家都追求整租”。

更合理的写法是：

- 有人用合租降低固定成本；
- 有人愿意用长通勤换整套空间；
- 有人把独居当作安全感；
- 有人反过来因为独居孤独而进入共居；
- 有人把共居当作一个小型互助网络。

所以防守型未来不是一个统一的人格，而是：

> **人们开始更明确地为自己选择哪一种风险值得承担。**

# 十、它改变了“普通人到底有多少种活法”的哪一点理解

这一专题加入核心矩阵后，至少新增一类经常被标准人生脚本删除的生活单位：

| 维度 | 新增理解 |
|---|---|
| 教育 | 学生可以离开学校宿舍，却仍处于多人/床位住房，而非直接独居 |
| 就业 | 一份工作能否接受，取决于附近住房是否能通过合租变得可负担 |
| 住房 | household 不只由亲属构成，也可以由市场/平台匹配暂时形成 |
| 婚姻家庭 | 单身不等于独居；与异性共居也不等于情侣或婚姻 |
| 迁移 | 合租降低一部分初次进入城市的住房门槛 |
| 照护 | 室友可提供临时互助，但不能默认等价于家庭照护义务 |
| 非正规劳动 | 二房东/整租后分租把多人共居变成一种经营模式 |
| 长期中断 | 换工作、实习、考研等过渡期可以由短租/合租承接 |
| 证件与记录 | 身份证、合同、房东登记与平台 profile 是不同验证层 |
| 通信方式 | 电话、QQ、站内信等负责从公开 listing 转向私人协调 |
| Internet 平台 | 平台扩大陌生人匹配半径，却把大量执行状态带到私域 |
| 信息获取 | 物理信息栏 → BBS/门户/分类信息 → 平台/App 是发现机制变化 |
| 社交关系 | 室友可以是弱关系、纯经济关系，也可以演变为支持网络 |
| 未来预期 | 租房可作为过渡、长期状态、成本 hedge 或主动生活方式 |
| 线上/线下身份 | 自报职业/习惯帮助筛选，不等于线下身份和安全已验证 |
| 平台消失与记忆 | 最容易保存的是广告；最容易丢失的是谁真正搬进去、住多久、为什么离开 |

# 十二、反例与停止条件

## 反例 1：合租不必来自 Internet

朋友、同学、同事和报纸/实体广告长期可以完成匹配。

Internet 改变的是搜索半径、速度和陌生人匹配能力，而不是发明共同租房。

## 反例 2：Internet 可降低匹配成本，却可能同时增加欺诈和核验劳动

2006、2021 的材料都说明：房源/室友被看见得更容易以后，真假房源、身份、房东权利、实际房况仍需核验。

## 反例 3：合租不总是经济被迫

2024 共居案例有明确的社交与共同生活动机。

## 反例 4：共居不天然更亲密

2019 和 2024 材料都存在生活习惯冲突、公共空间冷漠、室友更替和治理失败。

## 反例 5：共享空间不是越多越现代

2020、2025 材料同时显示相当一部分青年更重视整租、卫生和独立空间。

# 十三、尚不知道什么

1. 1995–2000 中国城市普通租客通过报纸、电话、中介、信息栏分别找到房源/室友的实际占比。
2. 1999–2004 校园 BBS 上“租房/合租”板块的原始页面结构、帖子生命周期与站外联系方式。

# 十四、下一步最值钱的证据

比再找一份“某年合租率”报告更有价值的，是恢复一个 **historical roommate execution chain**：

```text
实体广告 / BBS / 门户 / 分类信息帖
→ 联系方式
→ 看房
→ 身份与房东核验
→ 入住
→ 合住几个月
→ 室友更替 / 退租 / 搬家
```

理想材料是 1999–2010 的同一普通账号两个以上历史时点，且不需要重新公开已删除的私人联系方式。

如果能找到，它会把“平台让陌生人可发现”推进到真正的生活史问题：

> **一次网上匹配，究竟怎样把几个本来互不相干的人，短暂地变成每天共享一把门锁、一间厨房和一笔房租的人。**
