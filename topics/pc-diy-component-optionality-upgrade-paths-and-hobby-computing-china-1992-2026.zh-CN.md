# 从攒机到“海景房”：PC DIY、组件级可选性与兴趣计算生活（中国，1992—2026）

> 研究问题：一个普通人什么时候开始不把“电脑”当成一个只能整机购买的黑盒，而是把 CPU、主板、内存、显卡、硬盘、电源、机箱、散热和软件环境当成可以自己组合、替换、维修、升级和再出售的长期系统？这种实践怎样占用工资、桌面、夜晚、技术注意力与未来预算；报刊、电脑城、论坛、模拟攒机、电商、视频和二手平台又分别改变了哪一层摩擦？
>
> 本题属于 [`../INDEX-hobby-life-worlds.md`](../INDEX-hobby-life-worlds.zh-CN.md) 的兴趣生活世界研究。它不把“家庭拥有电脑”自动写成“DIY 玩家很多”，也不把组装一次电脑的人都称为长期硬件爱好者。
>
> old-Web companion：`tmzncty/old-web-archaeology/docs/PC_DIY_CONFIGURATOR_PRICE_DATABASE_FORUM_AND_PHYSICAL_BUILD_STATE_GAPS_2002_2015.md`

## 1. 先拆状态：有台式机 ≠ 自己攒机 ≠ PC DIY 成为长期爱好

至少区分：

```text
家里/单位可以使用电脑
→ 自己需要一台电脑
→ 知道整机以外还能按零件购买
→ 能看懂 CPU / 主板 / 内存 / 显卡等基本规格
→ 按预算与用途列配置
→ 判断兼容性
→ 获得零件
→ 完成物理装配
→ 第一次点亮 / POST
→ 安装系统、驱动和软件
→ 稳定使用
→ 诊断故障、清灰、换件
→ 局部升级
→ 超频 / 静音 / 小型化 / 灯效 / 改造（可选）
→ 二手出售旧零件
→ 下一轮配置继续使用部分旧组件
```

固定边界：

- `家庭拥有 PC ≠ 用户自己装过机`；
- `看过配置单 ≠ 会独立判断兼容性`；
- `模拟攒机成功 ≠ 真机一定兼容`；
- `零件买齐 ≠ 点亮成功`；
- `首次点亮 ≠ 长期稳定`；
- `跑分高 ≠ 真实工作流更适合`；
- `论坛推荐 ≠ 用户实际购买`；
- `配置单保存 ≠ 真实拥有记录`；
- `价格页面存在 ≠ 当天到店可按该价买到`；
- `自己装过一台电脑 ≠ 长期硬件发烧友`。

本题把从“我想要一台电脑”到“我可以长期重构自己的电脑”称为 **component-level optionality / 组件级可选性**。

## 2. Internet 前基线：DIY 计算并不是 Web 发明，知识入口先是杂志、报纸、市场和社团

中国大众互联网出现以前，微型计算机知识已经通过专业期刊和后来面向爱好者的报刊扩散。现有书目资料可确认《电脑报》1992 年创刊，《电脑爱好者》1993 年创刊；这些入口把原本更偏机构、科研和专业技术人员的微机知识，逐步翻译成面向普通读者的软件、硬件、市场、游戏和操作知识。

可用来源：

- 国家图书馆/期刊书目与后续资料可追《电脑爱好者》1993 年创刊，ISSN 1005-0043；
- 《电脑报》创刊史可继续追原报社档案，本轮只把 1992 作为后续核验 locator，不据此推断当年普通家庭普及度。

这里要保持三只钟：

```text
个人电脑在中国存在
≠
普通家庭买得起
≠
普通用户能从零件层面自己配置
```

前 Web 的信息栈更接近：

```text
报刊 / 合订本 / 技术书
+ 电脑城 / 柜台 / 熟人高手
+ 厂商手册 / 驱动软盘
+ 面对面装机与维修
→ 个人逐渐学会把电脑看成可拆分系统
```

Internet 后来最先改变的是查参数、比价格、找经验和验证兼容性的成本，而不是从零创造“自己组电脑”这件事。

## 3. 1998：一台可升级电脑仍是高额家庭项目，价格波动本身就是知识

1998 年 8 月《生活时报》报道中关村配件价格上涨时，留下了一组非常具体的同期市场价格：32MB 内存约从 200 元涨到 250 元，华硕 BX 主板约 1450 元，Pentium II 233 CPU 从约 1350 元涨到 1700 元，Pentium II 266 涨到约 2100 元。

同期来源：

- 《中关村攒机受重创》，生活时报，1998-08-06：<https://www.gmw.cn/01shsb/1998-08/06/GB/698%5ESH6-620.htm>

国家统计局记录 1998 年全国城镇居民家庭人均可支配收入为 **5425.1 元**，农村居民家庭人均纯收入为 **2162.0 元**。

- 国家统计局《城乡居民家庭人均收入及指数（1999年）》：<https://www.stats.gov.cn/zt_18555/ztsj/hjtjzl/1999/202303/t20230302_1923307.html>

仅以上 CPU + 主板 + 32MB 内存三件，在报道时点就约 3400 元，还不含硬盘、显示器、机箱、电源、键鼠和软件。

这不能直接写成“电脑等于某人一年收入的多少”，因为全国人均可支配收入不是具体买家的工资或家庭总预算；但足以说明：**1998 年的 DIY 可选性建立在很高的资本门槛上，学会自己配零件不等于已经拥有随意试错的预算。**

这也解释为什么当时的“行情”不是今天意义上的娱乐资讯。内存、CPU、硬盘一天或一周的价格波动，可能直接改变一户人家的整机配置。

可称为 **price-timed configuration / 价格时点化配置**：

```text
预算固定
+ 零件价格快速变化
→ 同一张配置单几周后就可能失效
```

## 4. 2002—2003：装机成为可以被普通技术媒体写成“家人/朋友的春节项目”

中关村在线 2003 年 1 月的年度 DIY 总结里，作者回忆 2002 年春节曾为朋友组装一台约 4000 元的机器；到了下一年，文中认为 3000 元左右已经可以进入低价整机，4000—6000 元形成主流 DIY 档位。文章同时讨论 CPU、内存和接口怎样在一年内改变“标准配置”。

同期来源：

- 中关村在线，《2002年ZOL硬件DIY总结--年末装机经验谈》，2003-01-29：<https://news.zol.com.cn/2003/0129/54867.shtml>

这份材料很适合恢复 PC DIY 的日常属性：

```text
春节长假
→ 帮朋友/家人装一台电脑
→ 在有限预算里选 CPU / 内存 / 主板
→ 预留以后升级的可能
```

它不是纯粹的消费：装机者把自己的知识劳动送给亲友，也形成一种非正式的 **household IT support / 家庭技术支持角色**。

一个家庭里“谁懂电脑”常常意味着：以后驱动装不上、系统坏了、硬盘要换、内存要加，仍然会首先找同一个人。

## 5. 2005—2008：中文 Web 把“先在脑中装一台电脑”变成数据库操作

### 5.1 2005：模拟装机第一次把预算、用途、产品库和跑分预测放进同一界面

2005 年 7 月，中关村在线报道搜狐数码天下“智能装机系统”，给出了精确 historical locator：

`http://act.it.sohu.com/jiutian/index.htm`

报道描述该系统用上百个数据库表、标准化配件产品库、评测数据库和性能模拟算法，让初级用户通过“输入预算 + 选择用途”生成推荐配置，高级用户则可指定部件和偏好，并看到 3DMark、SYSMark、PCMark 等预测值。

同期来源：

- 中关村在线，《人人都是DIY高手!搜狐推出智能装机系统》，2005-07-20：<https://news.zol.com.cn/new_news/2005/0720/186845.shtml>

这里出现一个很重要的变化：

```text
过去：先问熟人 / 看杂志 / 到电脑城再拼配置
后来：在去市场之前，网页先生成一台“虚拟电脑”
```

可称为 **pre-purchase virtual assembly / 购买前虚拟装配**。

但必须保留边界：

`database says compatible ≠ retail parts available ≠ physical assembly succeeds`。

### 5.2 2006：配置单本身成为可保存、可点评、可模仿的用户作品

2006 年中关村在线的“网友自助装机专家点评”明确写道，大量用户每天通过 ZOL 模拟攒机系统建立配置，平台再从用户方案库中挑出案例逐项点评。某期还直接指出：选择 IDE 硬盘虽然当时可用，但 SATA 更适合未来升级。

同期来源：

- 中关村在线，《疯狂游戏型 3款AM2速龙网友配置点评》，2006-09-12：<https://diy.zol.com.cn/38/385268_all.html>

这意味着 **future compatibility / 未来兼容性** 开始成为普通消费者能公开讨论的预算变量：

> 今天少花一点，是否会让下一次升级必须连主板、内存和硬盘一起换？

PC DIY 因此特别适合研究一种 **upgrade-path planning / 升级路径规划**。人购买的不是只在今天工作的机器，也是在购买未来几年还能否局部修改的结构。

### 5.3 2008：学生仍是重要 DIY 人群，但笔记本/品牌机已经在挤压这条路线

ZOL 2008 年秋季 DIY 市场分析称，笔记本和品牌台式机整体降价后，传统攒机市场销量与人气都受挤压；但九月开学仍被视为装机旺季，当时 DIY 用户平均预算约在 **4000—5000 元**。

- 中关村在线，《性价比达到最佳 DIY攒机最新攻略大全》，2008-09-11：<https://zdc.zol.com.cn/106/1062657.html>

同月太平洋电脑网的学生装机稿又保留了一句很典型的同期用户话语：学生“小王”希望“不被 JS 坑骗”，又想把钱“花在刀刃上”。

- 太平洋电脑网/新浪，《从七彩虹Intel特惠，谈开学装机五大必知》，2008-09-02：<https://tech.sina.com.cn/h/2008-09-02/1648790663.shtml>

这里的“扩张型未来”不是简单的乐观，而是：

```text
大学开学
→ 电脑被预期同时承担学习 + 娱乐 + 上网
→ 预算有限
→ 自己选件被理解成取得更高性能/性价比的一种能力
```

与此同时，便携笔记本已经提供另一条更省维护劳动的路线。DIY 不再是“买电脑”的同义词，而逐渐成为一种主动选择。

## 6. PC DIY 的特殊资源：兼容性、可维修性和“战未来”

相比摄影和 Hi-Fi，电脑有一个非常强的 **dependency graph / 依赖图**：

- CPU 绑定 socket / 芯片组；
- 内存绑定代际与频率；
- 显卡受电源功率、机箱长度、散热与接口影响；
- 存储受接口和主板槽位影响；
- 散热器受扣具、机箱高度和热设计影响；
- 操作系统和驱动又可能反过来淘汰硬件。

所以 DIY 的核心乐趣之一不是“买零件”，而是维护一个仍有路径可走的系统。

可称为：

- **component granularity / 组件粒度**：坏一个部件时能否只换一个；
- **upgrade-path optionality / 升级路径可选性**：未来能否局部升级；
- **compatibility labor / 兼容性劳动**：为了避免买错而做的研究；
- **maintenance dividend / 维护红利**：懂结构以后，旧机器能否通过换件继续活。

这也是 PC DIY 与标准消费史最不一样的地方：**延长使用寿命本身可能就是 hobby 技能的回报。**

## 7. 2019：信息很多以后，失败并没有消失，反而转成诊断劳动

2019 年 1 月，V2EX 一名用户记录自己组好电脑以后，发现新买的 1250W 电源风扇开机即满速、噪声巨大。用户说自己购买前看过中关村在线大量“噪音小”的好评，真正装好后却遇到相反结果，于是把完整装机单发到论坛求助。

同时代第一人称：

- V2EX，《组了台电脑，电源翻车了》，2019-01-14：<https://www.v2ex.com/t/526723>

这很好地说明 **information abundance ≠ outcome certainty**。

到 2019 年，参数、评测、用户评价和配置工具已经极丰富，但一台真机仍然会因为：

- 单件瑕疵；
- 风扇策略；
- BIOS；
- 兼容性；
- 装配；
- 个体对噪声的敏感度

而进入失败状态。

因此“拥堵型未来”在 PC DIY 里表现成：**你拥有更多信息和更多产品，却必须承担更重的比较、验证和售后判断。**

同年针对大学生的硬件导购仍把 DIY 视为一种可行路线，但文章已经明确说“DIY 电脑水比较深”，说明它不再是默认技能。

- 中关村在线，《马上开学了什么硬件适合大学生？》，2019-08-19：<https://diy.zol.com.cn/724/7245898.html>

## 8. 2020—2022：偶发型未来——电脑变成工作基础设施时，DIY 既是自救也是供应链暴露

### 8.1 2020：为了具体工作流从不可升级笔记本转回台式机

2020 年 3 月，V2EX 一名用户解释自己为什么计划花约 5000 元组台式机：2015 款 MacBook Pro 在浏览器多标签、VS Code、Matlab、PDF 和外接显示器同时运行时已经明显吃力，因此自行按“知乎推荐 + B站视频”拼了一套 Ryzen 3600 + RTX 2060 配置，并把编译、多线程和内存需求逐项写出来。

- V2EX，《5000 左右装机，谢谢大家！》，2020-03-20：<https://www.v2ex.com/t/654455>

这里 DIY 不再主要是“用更少的钱打游戏”，而是 **workload-specific computer building / 按工作流造电脑**：

```text
通用成品设备无法升级
→ 具体软件工作流暴露瓶颈
→ 用户自己决定核心数、内存、SSD 与显卡预算
```

### 8.2 2021：全球芯片与虚拟货币市场可以直接重写普通人的配置单

2021 年显卡短缺/矿潮期间，一名 V2EX 用户想配 6000—7000 元、以编程和双屏为主的台式机，却把显卡预算压到 **500 元二手卡**；同期大量讨论转向核显、“亮机卡”和矿卡风险。

- V2EX，《各位 V 友，准备组个台式机，编程为主，帮忙看下配置》，2021-06-15：<https://www.v2ex.com/t/783577>

同期杭州电脑市场报道也记录，2021 年虚拟货币行情推高显卡后，大容量硬盘又因新的挖矿需求迅速涨价，一名网友描述 18TB 硬盘从自己犹豫购买时的约 2200 元涨到约 5800 元。

- 杭州网/都市快报，《显卡涨完硬盘涨，硬盘涨价源于“炒币挖矿”？》，2021-04-23：<https://xiaofei.hangzhou.com.cn/xfzx/content/2021-04/23/content_9211892.htm>

这增加一个 **global-market intrusion / 全球市场侵入** 机制：

> 一个人已经决定了自己的用途与预算，却可能因为远方的芯片产能、金融投机或挖矿需求，被迫重写整套本地生活计划。

### 8.3 2022：自己装仍然是一种有成就感、也很耗身体和时间的技能实践

2022 年一篇中关村在线第一人称装机记录中，作者作为新手在询问多人、观看视频教程后，花约两天完成一台约 5000 元的台式机；文章直说装完后感觉“全身要散架”，但看到机器工作又有明显成就感。

- 中关村在线，《开学季装机：5000元组装一台性能彪悍的台式机》，2022-08-17：<https://diy.zol.com.cn/799/7995210_all.html>

这提醒我们：DIY 的“省钱”不能只算标价，还应计算 **assembly time / 装配时间**、研究时间和失败风险。

## 9. 2023—2026：防守型未来没有让 DIY 消失，反而出现“功能工具 + 个性物件”双重化

2025 年春节的同期采访里，“90后”建模师江岩计划自行组机，重点是处理器和内存，以提升建模/创作工作效率；“00后”杨晓熙则明确追求双面透明机箱、RGB 显卡和内存，把主机当成具有观赏性的房间物件。

- 中新社/新浪财经，《性能与“颜值”并重 中国年轻人青睐电脑装机DIY》，2025-02-02：<https://finance.sina.com.cn/roll/2025-02-02/doc-ineiaafc9420475.shtml>

2024 年 B 站第一人称装机视频也把“第一次装 PC”完整拍成 40 多分钟的技能学习过程，作者在装完后说此前觉得复杂，真正完成后才建立基础概念；配置本身约万元，并明确将高性能游戏与桌面外观放在一起。

- Bilibili，《如何装机？小白第一次装PC！1W预算主机安装全流程分享！》，2024-06-25：<https://www.bilibili.com/video/BV1RJ4m1u7VL/>

这里出现 **machine-as-room-object / 机器作为房间物件**：

```text
90s：机箱主要是装零件的壳
→ 2000s：散热、静音、侧透开始变成玩家问题
→ 2020s：机箱、灯效、线材、桌搭直接进入审美身份
```

但不要把这写成所有年轻用户都追求 RGB。同期仍有大量“极致性价比”“二手显卡”“小体积 ITX”“低噪声”“生产力优先”等互相冲突的路线。

因此今天的 PC DIY 更像 **plural optimization / 多目标优化**，而不是单一“性能最大化”。

## 10. Internet 到底改变了什么：从“哪里有懂电脑的人”到分层知识栈

可以把中国 PC DIY 的信息链粗略拆成：

```text
1990s：报刊 / 合订本 / 电脑城 / 熟人
→ 2000s：IT门户 / 每日报价 / 产品库 / 硬件论坛 / 模拟攒机
→ 2010s：电商评论 / 垂直社区 / 视频评测 / 跑分数据库 / 二手平台
→ 2020s：视频教程 / 直播装机 / 小红书桌搭 / 配置生成器 / 群聊 / 二手平台
```

Internet 的实质变化至少有：

1. **specification legibility**：规格更容易横向比较；
2. **price visibility**：本地柜台报价不再是唯一价格入口；
3. **compatibility outsourcing**：配置工具与社区帮用户提前检查部分兼容问题；
4. **distributed troubleshooting**：无法点亮、蓝屏、温度、噪声可以带着日志和照片远程问人；
5. **secondhand liquidity**：升级后的旧件更容易找到下家；
6. **benchmark normalization**：跑分变成跨机器比较的共同语言；
7. **attention treadmill**：新品、价格和性能信息更新越来越快，研究硬件本身可能吞掉使用电脑的时间。

这不是纯收益。信息越多以后，用户还要学会判断软文、商家角色、矿卡、返修、参数陷阱、评测条件与实际工作流差异。

## 11. 海外对照：1975 Homebrew 说明“自己造/配电脑”本来就是一种社区化兴趣基础设施

美国 Homebrew Computer Club 1975 年的原始 newsletter 已经明确把 home computing 称为一种 hobby。6 月号写道，个人独自面对机器会遇到大量 bug 和技术障碍，所以通过共享经验与 tips 才能让低成本 home computing 对更多人可行；同一期还记录俱乐部成员共享库账户、购买零件和 MITS Mobile 活动。

- DigiBarn，Homebrew Computer Club Newsletter #4，1975-06-07：<https://www.digibarn.com/collections/newsletters/homebrew/V1_04/index.html>
- Computer History Museum，Homebrew Newsletter artifact：<https://www.computerhistory.org/revolution/artifact/312/1138>

1975 年 11 月 newsletter 又记录约 130 人参加会议、集体购买折扣、计算机商店开始出现。

- DigiBarn，Vol.1 No.9，1975-11-30：<https://digibarn.com/collections/newsletters/homebrew/V1_09/index.html>

到 1997 年，`comp.sys.ibm.pc.hardware.*` 的 FAQ 已经把主板、CPU、价格、购买、二进制文件、故障等常见问题整理成 Usenet 社群的持续知识基础设施。

- PC Hardware FAQ v1.24，1997-06-10：<https://www.computercraft.com/docs/faqind.shtml>

因此跨国共同机制不是“Web 让人开始自己装电脑”，而是：

```text
昂贵、复杂、可拆分的计算设备
+ 爱好者共享知识
+ 零件供应
+ 同行排错
→ 个人能够拥有比成品消费更高的组件控制权
```

中国的特殊时间结构在于，这套 hobby 大规模可见时已经和 1990s 末电脑城、2000s 中文门户以及家庭 Internet 同时扩张，因此实体市场与 Web 数据库长期高度耦合。

## 12. 与普通人生脚本的交叉

PC DIY 不一定决定一个人是否结婚、买房或迁移，却会不断撞上这些变量。

### 教育

2000s 大学开学是典型装机季。电脑同时是课程工具、宿舍娱乐和第一次由本人深度参与配置的大件消费。

### 就业

程序员、设计、建模、剪辑、科研等工作流会把“兴趣配置”重新变成生产资料；同一人也可能把工作需求当成升级预算的正当性来源。

### 住房

ATX 大机箱、多屏、机械键盘、音箱和桌面深度都要求物理空间；合租、宿舍和频繁搬家会推动 ITX、小机箱、笔记本或云端替代。

### 婚姻家庭

高价显卡、占桌面空间、灯效和噪声都需要家庭预算与空间协商；另一方面，“家里懂电脑的人”又可能长期承担免费维修劳动。

### 迁移

大型台式机难搬，零件又相对可拆。跨城生活可能让人卖整机、只带硬盘/显卡，或者在新地点重组。

### 长期中断

2020 年一名 V2EX 卖家写自己 2017 年底组机原本想打游戏，后来“加班到对游戏失去兴趣”，使用率很低而决定出售。

- V2EX，《北京询出组装台式机》，2020-12-14：<https://s.v2ex.com/t/735399>

这是一条很好的反例：**买下一条 hobby 路线，不代表未来真的有时间执行。**

## 13. 历史可见性与后见之明风险

### 13.1 配置单幸存偏差

高端、奇特、超频和翻车配置更容易被讨论；沉默地稳定使用八年的普通主机反而不容易留下历史文本。

### 13.2 产品数据库不是拥有数据库

一个型号有详细页面，只证明它被编辑进数据库，不证明普通用户买过。

### 13.3 论坛“大神”可见度偏差

会超频、会测电压、写长帖的人远比只照着清单装一次的用户更容易留下痕迹。

### 13.4 今日玩家术语不要倒灌

“垃圾佬”“海景房”“战未来”“矿卡”等词必须按各自出现时期使用，不能拿今天的身份语言解释 1998 年所有攒机者。

### 13.5 不能把 DIY 浪漫化成完全自主

用户仍依赖：

- 全球芯片供应链；
- 厂商 socket / BIOS / 驱动支持；
- 商家质保；
- 操作系统兼容；
- 电商与物流；
- 社群知识。

DIY 增加的是组件层控制，不是技术独立。

## 14. 已知 / 可推断 / 未知

### 已知

- 1998 年中关村已经存在高度活跃、价格快速变化的散件与攒机市场；
- 2002—2003 年 DIY 装机已被 IT 门户写成普通假期、亲友购机与预算配置问题；
- 2005—2006 年中文 Web 已出现数据库化模拟装机、用户配置单与专家点评；
- 2008 年学生仍是重要 DIY 人群，同时笔记本/品牌机开始明显挤压市场；
- 2019—2022 同时期第一人称能直接看到翻车、排错、工作流驱动装机和供应链涨价；
- 2024—2025 DIY 同时承担性能、生产力、审美和身份表达。

### 可合理推断

- 中文 IT 门户把部分原本必须去电脑城、问熟人的配置知识前移到了购买前；
- 二手和局部升级提高了昂贵电脑资产的可逆性；
- 随着成品机和笔记本越来越便宜，DIY 从“获得一台电脑的重要渠道”逐渐更多变成“主动选择更高组件控制权”的路线。

### 尚未确定

- 1992—1997 普通城市用户真正自己购买散件并物理装机的规模；
- 不同城市 DIY 市场相对工资的系统比较；
- 女性玩家、非技术职业玩家在 1990s—2000s 公开史料中的实际比例与不可见性；
- 2000s 学生到底有多少是自己装、朋友代装、柜台装好后带回宿舍；
- 模拟攒机平台究竟降低了多少真实兼容性错误；
- “DIY 市场衰退”究竟是人数减少、购买频率减少，还是零件渠道从卖场迁移到电商后统计口径改变。

## 15. 它改变了我们对“人怎么活着”的哪一点理解

PC DIY 补出了一种此前兴趣矩阵里还不够明确的生活能力：

> **普通人可以把一个昂贵耐用品从“买下以后等它坏”改造成一个可持续重写的系统。**

她今天的钱不够，可以先少买一条内存；以后工资高了再加。显卡贵得离谱，可以先靠核显或二手亮机卡过渡。某个零件坏了，不一定整机报废。性能不够时，也不一定一次性重新购买全部设备。

这种生活不是完全自由，因为 socket、驱动、供应链和全球价格仍然会替她关门；但组件化给了普通用户一种特别现代的时间结构：

```text
现在先这样用
→ 以后再换这一块
→ 旧的还能卖
→ 系统不是一次性完成，而是几年里不断长成
```

于是“电脑”不再只是一个物件，也可以是一段持续很多年的个人工程。
