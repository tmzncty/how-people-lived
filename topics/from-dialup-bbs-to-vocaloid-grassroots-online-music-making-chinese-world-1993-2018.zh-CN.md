# 从拨号 BBS 到洛天依：中文世界普通人在线做歌的基础设施史（1993—2018）

## 范围

**地区：** 中文互联网世界，分开观察台湾、中国大陆与香港，不把三地写成一条同步发展的单线  
**时间：** 1993—2018  
**问题：** 一个没有进入唱片工业的普通人，什么时候开始能够把自己的音乐做出来、放到网上、被陌生人听见，并与听众形成持续关系？

本文是 [《当创作者和听众离得很近：2016—2018 年中文 VOCALOID 民间创作》](grassroots-vocaloid-creation-and-short-social-distance-china-2016-2018.zh-CN.md) 的前史。

前一篇从洛天依和 Bilibili 出发，会很容易产生一种错觉：仿佛“听众也能做歌”“投稿者与听众处于同一网络”是虚拟歌手时代才出现的。

向前追二十多年后，情况明显不同。

中文世界至少从 1990 年代开始，就在反复拆解传统音乐工业的若干门槛：

```text
必须找到编辑 / 唱片公司
→ 可以在 BBS / FTP 上建立同好网络
→ 可以把 MP3 放到网页
→ 可以注册音乐社区账号并直接上传
→ 可以拥有持续存在的创作者主页、评论区和圈子
→ 可以跨平台保持一个固定 ID
→ 可以自己完成更多制作环节
→ 可以用歌声合成软件绕过“先找到真人歌手”这一组织门槛
```

这不是一次“民主化革命”，而是一连串不同门槛被重新配置的过程。

---

## 核心结论

### 1. 洛天依不是起点，而是一个已经成熟二十年的网络创作传统的新阶段

1993 年台湾已经出现专业音乐拨号 BBS；1999 年 RockaCola 开始通过网络招募华人音乐创作者；2000 年香港 AsiaMix 让音乐人直接上传作品接触听众；2003 年大陆 163888 与录歌软件 K8 把“录歌—上传—被听见”做成规模化服务；2004 年成立的 5sing 则进一步把原创、翻唱、伴奏、评论、圈子和固定用户身份结合在一起。

到了 2010 年代，洛天依与 Bilibili 接上的不是一片空白，而是一套已经习惯了“网友也可以发歌”的文化基础设施。

### 2. 真正变化的不是“音乐突然变容易”，而是制作与传播链条可以被普通人逐段接管

一个人想让陌生人听到自己的歌，至少要解决：

1. 写作 / 作曲；
2. 演唱或找到演唱者；
3. 录音；
4. 编曲、混音或最低限度的后期；
5. 数字化与编码；
6. 上网；
7. 找到服务器 / 存储空间；
8. 让别人发现文件；
9. 让别人知道“这是谁做的”；
10. 获得反馈并维持一个可再次找到的身份。

不同年代的网络平台并没有同时解决全部问题。

BBS 最先解决的是**找到同好与持续讨论**；MP3 网站解决的是**声音文件传播**；音乐社区解决的是**上传、身份、评论和分类**；Web 2.0 平台解决的是**持续主页、关注与合作**；VOCALOID 又进一步改变了**人声生产**。

### 3. “创作者和听众离得近”有非常具体的技术条件

它依赖的不是抽象的“互联网精神”，而是：

- 可持续使用的用户名；
- 用户主页；
- 评论与留言；
- 圈子、论坛、BBS、群聊；
- 相对小而重复出现的参与者集合；
- 可以自己上传作品，而不是只向编辑投稿；
- 作品与账号之间的稳定链接。

固定 ID 因而不仅是登录凭证，也可能成为一种低成本社会记忆。

### 4. 中文世界不是同时进入这一阶段

台湾 1990 年代的大学网络、BBS、独立乐团与小型演出场景较早接合；香港在 2000 年前后已经有较高的家庭网络接入和面向音乐人的在线社区，但本地原创场景规模与存档条件不同；中国大陆在 1990 年代末互联网用户仍很少，却在 2000—2004 年间快速扩大，并形成极大规模的网络歌曲与翻唱社区。

所以不能写成：

> “1999 年的华人青年已经可以普遍在网上发歌。”

更准确的是：

> **1990 年代末到 2000 年代中期，不同中文地区先后出现了一批让特定网络用户越过传统唱片工业、直接进入公共音乐空间的基础设施。**

# 一、在“上传音乐”之前：先出现的是能持续遇见同好的网络

## 台湾，1993—1997：BBS 先把乐迷、乐手和评论者放进同一个文字空间

《破报》在 1999 年末做“台北乐迷眼中的九○年代”回顾时，留下了一条非常有价值的同时代时间线：

- **1993：** Dial-up BBS 专业音乐网 `Music Link` 成立；
- **1994：** 学术网络 BBS 出现摇滚专板；
- **1995：** Music Link 制作电子音乐刊物 `E-Music`，通过 FTP 开放下载；同年学术网络快速增长，Dial-up BBS 开始蓬勃；
- **1997：** 出现专业乐手 BBS “风之国度”；不同音乐族群开始分化出各自的版面和站点；
- **1999：** “台湾音乐革命军”建立 BBS 讨论组、WWW 站与电子报；同年 RockaCola 出现。

来源：

- 《破报》复刊第 91 号，2000-01，〈台北乐迷眼中的九○年代：五组音乐场景分类流水帐〉：  
  https://s3.us-west-1.wasabisys.com/p-library/books/pots/POTS.091.pdf

这段前史很重要，因为它提醒我们：**创作者—听众关系的缩短，先于大规模音频上传。**

早期 BBS 的优势是文字、小数据量和反复登录。

一个乐手可以在同一个版面反复看到相同 ID；乐迷可以讨论演出、器材、唱片与创作；线下演出的人又回到线上继续说话。

但不能把这一阶段写成今天式的音乐平台。

在低带宽时代，BBS 更擅长承载：

```text
“你在哪里演？”
“这张唱片哪里买？”
“谁会弹这个？”
“谁在组团？”
“昨天那场怎么样？”
```

而不是让每个人随手上传几十 MB 的完整音频。

`E-Music` 要通过 FTP 下载，本身就说明“讨论”和“取得文件”仍然是不同操作。

这是一种**社会网络先于媒体平台成熟**的状态。

# 二、1999：第一次明确出现“通过网络招募华人创作者”的音乐平台想象

## RockaCola：它仍像唱片公司，但入口已经被搬到网上

1999 年 11 月，台湾 iThome 报道滚石正在测试 RockaCola，并计划在 2000 年 1 月正式推出。

最值得注意的不是“在线试听”本身，而是作品来源：

> 网站上的音乐不是主要来自滚石旗下既有歌手，而是通过网络招募艺人。

同年 12 月的后续报道说，RockaCola 已招募来自全球的约 **100 位艺人、700 多首歌曲**；相比滚石实体唱片业务二十年约 50 位旗下艺人的规模，网站希望一年内网罗一万名创作者。

来源：

- iThome，1999-11-10，〈滾石成立「Rockacola」網站，召募網路藝人提供免費音樂下載〉：  
  https://www.ithome.com.tw/news/2515
- iThome，1999-12-27，〈滾石RockaCola網站正式成立，號召百位藝人展開數位音樂銷售〉：  
  https://www.ithome.com.tw/news/2399

RockaCola 是一个很有意思的过渡体。

它并不是后来意义上的完全开放 UGC 社区。报道仍然明确使用“网络唱片公司”的想象：

```text
网上找到创作者
→ 让作品被试听 / 下载
→ 从数据与反馈中发现值得培养的人
→ 安排线下宣传或产业化
```

所以这里被拆掉的是**“必须先在现实世界被唱片公司发现”**这一门槛，而不是唱片公司的角色本身。

后来的回忆材料还留下了一个更贴近日常生活的效果：一些乐团和音乐人不仅在 RockaCola 发布作品，也通过平台认识了合作伙伴、积累第一批听众。

来源：

- BIOS monthly，2022，〈對了，你知道馬大文是誰嗎？〉：  
  https://www.biosmonthly.com/article/11040
- 中央社文化+，2020，〈獨立音樂迎戰串流 逆流而上借力使力〉：  
  https://www.cna.com.tw/culture/article/20200329w002

### 这里已经出现一个以后不断重复的模式

```text
以前：
做歌 → 寄 Demo / 找演出 → 等少数行业入口

开始网络化后：
做歌 → 放到网上 → 先被一些普通听众听见
                     ↓
                 再被行业看见
```

产业并没有消失。

**被产业发现的顺序变了。**

# 三、香港，2000 年前后：在线社区开始同时面向 artists and fans

## AsiaMix：上传不再只是平台方的动作

2000 年 1 月，《南华早报》报道香港的 AsiaMix.com，将其描述为亚洲早期面向艺术家与歌迷的在线音乐社区之一。

报道中的核心功能非常直接：

- 听众可以在线听或下载；
- **音乐人可以上传自己的音乐，以接触更广泛的受众。**

来源：

- South China Morning Post, 2000-01-07, “Bankers hit right notes on Internet”:  
  https://www.scmp.com/article/304872/bankers-hit-right-notes-internet

香港的网络条件与大陆当时并不相同。

香港政府统计处后来的历史序列显示，**2000 年 1—3 月已有 36.4% 的住户家中个人电脑连接互联网**；2005 年相应数字达到 64.6%。

来源：

- 香港特别行政区政府统计处，《主题性住户统计调查第73号报告书：资讯科技使用情况和普及程度》，表 3.5：  
  https://www.censtatd.gov.hk/en/data/stat_report/product/C0000031/att/B11302732021XXXXB0100.pdf

这不能证明每个家庭都在做音乐，却说明 2000 年香港的线上音乐社区面对的是一个已经具有相当家庭接入基础的城市环境。

## Cmidi：小型社区把“作词作曲编曲的人”聚在一起

香港独立媒体 2014 年回顾已经关闭的 Cmidi 时，把它描述为 2000 年代初中期原创音乐爱好者的聚脚地：有人分享作词、作曲、编曲，也有人发表改编歌词；网站在 2013 年关闭。

来源：

- 香港独立媒体，2014-01-10，〈記Cmidi：網上音樂社群的衰落〉：  
  https://www.inmediahk.net/%E7%94%9F%E6%B4%BB/%E8%A8%98cmidi%EF%BC%9A%E7%B6%B2%E4%B8%8A%E9%9F%B3%E6%A8%82%E7%A4%BE%E7%BE%A4%E7%9A%84%E8%A1%B0%E8%90%BD

这类站点的意义并不一定是制造全国级“明星”。

它更像：

> 我有一段曲、一个词、一份编曲，终于有一个地方能给同样会做东西的人看。

这种规模较小的社区反而更容易出现重复 ID 与熟面孔。

# 四、中国大陆的基础条件：1997 年时这仍然只是非常少数人的生活

如果直接从 2004 年“网络歌曲爆发”往回看，很容易高估 1990 年代网络的日常普及。

CNNIC 第一次全国互联网统计显示：

- 截至 **1997-10-31**，中国大陆上网用户约 **62 万**；
- 上网计算机约 **29.9 万台**；
- 大部分用户仍通过拨号接入。

来源：

- CNNIC，《第一次中国互联网络发展状况调查统计报告》：  
  https://www3.cnnic.cn/n4/2022/0401/c88-802.html

三年后，情况已经完全不同。

CNNIC 2000 年 6 月底统计：

- 上网计算机 **650 万台**；
- 上网用户 **1690 万人**；
- 其中约 **1176 万**主要使用拨号上网。

来源：

- CNNIC，《第六次中国互联网络发展状况调查统计报告》：  
  https://www3.cnnic.cn/n4/2022/0401/c88-786.html

因此，大陆早期网络音乐的时间结构大致应写成：

```text
1990年代后半：
非常少量先行用户 / 音乐网站 / 论坛

2000年前后：
用户规模快速扩大 + 网吧 / 家庭拨号 + MP3 / Flash

2003—2005：
专门音乐社区开始把上传、录音和用户身份产品化
```

而不是一句笼统的“互联网出现后大家都可以发歌”。

# 五、2001：Flash 与“网络歌曲”先证明了不经传统发行也能形成公共记忆

2001 年《东北人都是活雷锋》的 Flash 版本在网络传播，经常被后来中国流行音乐史研究当作“网络歌曲”转折点之一。

到 2004 年，《老鼠爱大米》《丁香花》《两只蝴蝶》等作品又形成更大规模的网络传播。

来源：

- 中国文学艺术界联合会，2008，〈中国流行音乐30年的美学变迁〉：  
  https://www.cflac.org.cn/zt/2008-12/18/content_15218569.htm
- 南方周末，2008，〈我想唱歌我就敢唱——中国流行音乐30年回首〉：  
  https://www.infzm.com/contents/21171

这个阶段与后来的“创作者主页”还不完全一样。

Flash、论坛转载、MP3 搜索与网站排行可以让一首歌**脱离唱片发行网络地传播**，却未必能稳定保存作者身份、作品版本和听众关系。

一首歌可能极红，但文件在无数网站之间复制时：

- 谁最早上传？
- 谁唱的这个版本？
- 谁改了歌词？
- 哪个页面是作者自己的？

都可能迅速模糊。

所以“音乐传播门槛下降”和“创作者拥有稳定公共身份”不是同一件事。

# 六、2003：163888 把“在家录一首，再发给网友”做成规模化产品

## 一间很小的创业公司与一群网络熟人

2003 年 6 月，郑立与伙伴建立 163888。

2010 年《南都周刊》对其创业史的回顾保存了很典型的早期互联网细节：郑立先在论坛做版主，把重庆方言歌曲贴到网上；创业伙伴很多通过网络认识；早期团队只有几个人，吃住办公挤在租来的房间里。

随后团队开发了 **K8 录歌软件**，163888 逐渐成为网络歌手聚集地。

来源：

- 新浪转载《南都周刊》，2010-01-15，〈80后创业偶像涉黄被捕 名下公司被指背信弃义〉：  
  https://news.sina.com.cn/c/sd/2010-01-15/120119475815.shtml

这里值得研究的不是创始人的后来命运，而是 K8 这种工具所代表的变化：

```text
以前：
需要自己解决录音软件 + 文件格式 + 网站空间

平台化以后：
录歌工具
→ 音乐社区账号
→ 上传
→ 排行 / 评论 / 传播
```

**制作和发布第一次开始被设计成同一个普通用户流程。**

## 网络歌手不是先成为“歌手”，再来到网上

2005 年关于网络歌手的报道反复强调一个当时很新鲜的事实：一些人没有唱片公司包装和传统媒体宣传，却先在网络上拥有大量听众，然后唱片公司才追过来。

来源：

- 《深圳晚报》/ 新浪娱乐，2005-04-05，〈网络歌手走红内幕大起底〉：  
  https://ent.sina.com.cn/x/2005-04-05/1638694671.html
- 《北京晨报》/ 新浪，2005-01-27，〈网络歌手从虚拟到现实：一夜成名没准备好当偶像〉：  
  https://news.sina.com.cn/s/2005-01-27/02374957515s.shtml

这再次证明：

> **先被网友认识，再被产业认识**，已经成为可执行路径。

## 规模膨胀以后，社区立即出现商业化矛盾

到 2006—2007 年，163888 已经不是单纯爱好者站点。

2006 年的行业报道说，翻唱最初帮助平台获取大量用户，随后原创价值上升，平台会审核上传作品、寻找潜力歌手并签版权协议；盈利包括会员费、版权出售和无线增值业务。

来源：

- 新浪科技，2006-04-07，〈中国新网络力量：26岁的百万美元先生〉：  
  https://tech.sina.com.cn/roll/2006-04-07/1201895036.shtml

2007 年网站更名分贝网时，一篇报道甚至声称平台每天有大规模歌曲持续产生。无论这种宣传数字是否完全可核实，它至少说明当时产业已经把**用户持续上传**视为核心资源。

来源：

- 新浪科技，2007-06-29，〈分贝网域名收购创下行业记录〉：  
  https://tech.sina.com.cn/i/2007-06-29/10501590120.shtml

与此同时，许嵩 2007 年在自己的新浪博客公开批评分贝网未经充分告知使用其作品。

来源：

- 许嵩新浪博客，2007-10-31，〈噪音有一个分贝〉：  
  https://blog.sina.com.cn/s/blog_4a90c0b801000btl.html

这提醒我们：

**创作门槛下降并不自动等于创作者控制权增加。**

平台可以让普通人更容易被听见，也可以因为掌握存储、流量和合同入口而产生新的权力不对称。

# 七、2004：5sing 把“用户名”明确做成音乐世界里的身份证

5sing 官方资料称平台成立于 **2004 年**，以原创音乐为主线，提供创作、发表、展示和交流平台。

来源：

- 5sing，〈关于我们〉：  
  https://5sing.kugou.com/zc/aboutus

但真正值得普通生活史记录的是它的帮助文档。

5sing 对“为什么要注册会员”的解释非常直接：用户需要一个不同于他人的身份，因为这个名字会用于：

- 评论；
- 圈子；
- 上传原创与翻唱；
- 上传伴奏帮助别人；
- 收藏歌曲；
- 编辑自己的专辑；
- 建立圈子；
- 写日志和歌词；
- 与朋友交流。

来源：

- 5sing 帮助中心，〈为什么要注册5SING的会员？〉：  
  https://5sweb.kugou.com/help/detail-202.html
- 5sing 帮助中心，〈如何上传我的歌曲作品〉：  
  https://5sing.kugou.com/help/detail-18.html

这一点非常重要。

平台自己已经把用户名理解成：

> **“让别人记住你，并方便以后交流联络”的身份。**

这就是后来“某个评论区 ID 居然在别的平台又被认出来”这种经验的技术前提之一。

它不是偶然的神秘缘分。

它依赖的是一种新型公共身份结构：

```text
固定昵称
+ 作品页
+ 评论记录
+ 圈子
+ 好友
+ 自己的主页 / 专辑
= 一个可以被反复遇见的人
```

## 这里的“创作”还包括大量二次创作

5sing 把内容分成原创、翻唱、伴奏等区域；其审核规则还专门处理填词、歌曲改编、朗诵等二度创作。

来源：

- 5sing 帮助中心，〈关于5sing歌曲提交审核注意须知〉：  
  https://5sing.kugou.com/help/detail-181.html

因此，网络音乐生态不能只数“原创作曲者”。

很多人的第一步其实是：

```text
听歌
→ 找伴奏
→ 翻唱
→ 重填词
→ 帮别人后期
→ 进入圈子
→ 再开始原创
```

这条技能阶梯后来在古风、同人音乐和 VOCALOID 社群里继续存在。

# 八、2005—2008：Web 2.0 把作品页变成“创作者生活空间”

## StreetVoice：创作平台开始主动追求“让人相遇”

StreetVoice 2006 年 2 月上线。

2008 年的同时代报道记录，当时约有 **2000 名注册音乐人、6000 多首发表作品**。平台不仅放音乐，还同时提供相簿、网志、设计、影像、文字、交友等空间，并明确强调不同创作者之间的串联与合作。

报道甚至直接说：这种社群经营让创作者和网友之间的距离缩短。

来源：

- 《电子商务时报》，2008-11-03，〈打造音樂夢 StreetVoice讓你SHOW個夠〉：  
  https://www.ectimes.org.tw/2008/11/%E6%89%93%E9%80%A0%E9%9F%B3%E6%A8%82%E5%A4%A2-streetvoice%E8%AE%93%E4%BD%A0show%E5%80%8B%E5%A4%A0/
- StreetVoice 官方介绍：  
  https://about.streetvoice.com/

这里与 1999 RockaCola 的差别很值得保存。

RockaCola 更像：

```text
“网络版唱片公司寻找新人”
```

StreetVoice 更像：

```text
“创作者先在这里长期生活、发表、交流，
平台再把其中一部分人与线下演出、发行和产业连接。”
```

创作者的存在方式从“交一首歌”逐渐变成“经营一个持续账号”。

## 豆瓣音乐人：连“一个很小的动机”也可以公开

豆瓣官方博客记录：**2008 年 11 月 20 日，豆瓣音乐人上线。**

发布说明里的措辞非常能说明这一阶段的变化：听众可以关注音乐人，听到最新单曲，“哪怕只是一个小小的动机”，也可以给音乐人留言、鼓励或建议。

来源：

- 豆瓣 Blog，2008-11-20，〈豆瓣音乐人上线〉：  
  https://blog.douban.com/douban/2008/

到 2018 年，豆瓣官方回顾称音乐人社区已有近五万组原创音乐人、累计上传五十多万首作品。

来源：

- 豆瓣 Blog，2018-04-03，〈豆瓣音乐与 V.Fine 完成合并〉：  
  https://blog.douban.com/douban/2018/04/03/3842/

这是另一种门槛变化：

> **以前“作品”往往意味着至少做成一个可发行的完整东西；社区化以后，半成品、demo、一个动机也可以进入公共反馈。**

创作过程本身开始被公开。

# 九、2006 以后：创作者社区不只按音乐类型聚集，而开始跨媒介

上海的 Neocha 由音乐人、视觉艺术家、程序员和创业者在 2006 年共同创办。

来源：

- Neocha, About Neocha：  
  https://neocha.com/magazine/about-neocha/

这类跨媒介社区说明一个后来对 VOCALOID 极重要的条件已经成熟：

一首网络作品越来越不是“一个歌手 + 一首歌”，而是可能需要：

```text
词
曲
编曲
录音 / 调声
混音
插画
摄影
动画 / PV
网页 / 发布
宣传
```

这些角色可以属于不同的人，并通过网络临时组合。

因此，后来中文 VOCALOID 的“词作、曲师、调教师、画师、PV 师”分工，不是凭空发明了一种合作方式。

它继承的是已经逐渐成熟的**网络模块化创作**。

# 十、到了洛天依：真正新增的是哪一层？

前史梳理后，2012 以后中文虚拟歌手文化的新意反而更清楚。

网络早就已经解决或部分解决了：

- 找听众；
- 上传；
- 评论；
- 固定身份；
- 找合作伙伴；
- 建立粉丝；
- 跨平台传播。

VOCALOID / 中文歌声合成进一步改变的是：

> **“谁来唱”不再必然是一个需要在现实中寻找另一个人的问题。**

一个创作者即使没有歌手朋友，也可以通过编辑器与声库产生完整的人声轨。

于是很多原本可能只停留在：

```text
歌词
旋律 demo
伴奏
脑中的想法
```

的东西，有了被做成“完整歌曲”的机会。

而 Bilibili 又把声音与视频、弹幕、评论、收藏、二创连接起来。

详细见：

- [《当创作者和听众离得很近：2016—2018 年中文 VOCALOID 民间创作、弱连接与“谁都可以做一首歌”》](grassroots-vocaloid-creation-and-short-social-distance-china-2016-2018.zh-CN.md)

因此，洛天依时代最准确的位置不是“互联网音乐的开端”，而是：

> **在二十年网络自我发表史基础上，又拆掉了人声制作链中的一个组织门槛。**

# 十一、三地放在一起看：不是谁“更先进”，而是基础设施顺序不同

## 台湾

较早可见的是：

```text
大学 / 学术网络
→ BBS 音乐版与专业音乐站
→ FTP 电子刊物
→ 独立乐团 / Live House 与网络社群互相喂养
→ RockaCola
→ StreetVoice
```

线上与线下独立音乐场景连接得很早。

## 香港

较早可见的是：

```text
较高城市家庭网络接入
→ 在线音乐社区 / 数字下载
→ 小型原创音乐论坛与独立现场并行
```

但很多 2000 年前后的本地小站今天已经很难检索，档案保存本身成为研究问题。

## 中国大陆

较清楚的结构是：

```text
极少量早期网站 / 论坛
→ 1998—2000 用户规模高速扩张
→ Flash / MP3 / 搜索 / 网吧
→ 163888 等录歌上传社区
→ 5sing 等持续身份型音乐社区
→ 豆瓣音乐人 / 虾米 / Neocha 等更分化的创作者生态
→ Bilibili / VOCALOID / 古风 / 同人音乐
```

大陆的特点不是最早，而是进入 2000 年代后规模增长非常快。

# 十二、真正值得写进 How People Lived 的，不是平台名单，而是“普通人的可执行路径”

可以把 1993—2018 压缩成五种普通人的生活模型。

## 模型 A：1994 年的大学音乐爱好者

可能可以：

- 在学校网络或拨号 BBS 找到音乐版；
- 认识同校或其他学校的乐迷；
- 找演出消息、交换观点；
- 通过 FTP 或实体介质交换文件。

但不一定可以：

- 在家轻松录出一首完整作品；
- 上传大音频文件；
- 让全国陌生人立即播放；
- 长期维护一个带完整作品目录的个人页面。

## 模型 B：2000 年会做网页 / 有录音条件的独立乐手

可能可以：

- 自己做主页；
- 压 MP3；
- 把歌放到 RockaCola 等平台；
- 在 BBS 和演出现场积累听众。

但仍受到：

- 宽带；
- 存储；
- 录音硬件；
- 网页制作；
- 数字支付

等条件限制。

## 模型 C：2004 年普通网络翻唱者

路径变成：

```text
一台 PC
+ 声卡 / 麦克风
+ 录歌软件
+ 伴奏
+ 音乐社区账号
→ 可以把自己的声音交给陌生人听
```

这已经非常接近后来的“网络唱见”文化。

## 模型 D：2008 年的小型原创音乐人

可以拥有：

- 创作者主页；
- demo；
- 评论；
- 关注者；
- 博客 / 日志；
- 圈子；
- 跨平台账号；
- 线下演出入口。

此时音乐已经不只是一个文件，而是一种持续公共身份。

## 模型 E：2017 年中文 VOCALOID 创作者

在前述全部基础上，再加入：

- 歌声合成；
- 更成熟的家用 DAW；
- 数字插画；
- 视频制作；
- Bilibili 弹幕与评论；
- QQ 群、微博等跨平台协作。

于是一个人即使不认识真人歌手，也能把非常私人、非常小众、没有产业理由的题材做成一首完整作品。

这才是洛天依时代真正继承并推进的东西。

---

# 十三、一个容易被忽视的反方向：平台越成熟，创作者与听众未必永远越近

早期小社区常有一种特殊尺度：

- 人少；
- ID 重复出现；
- 创作者自己回复；
- 同一个人同时是听众、投稿者、版主或合作伙伴；
- 不同网站、QQ群和论坛之间的参与者重合。

平台成功以后，可能发生相反变化：

```text
参与者增加
→ 推荐算法扩大陌生受众
→ 创作者粉丝规模增大
→ 工作室化 / MCN 化 / 商业化
→ 账号和听众之间重新形成距离
```

因此历史并不是：

> 技术越新 → 创作者与听众越近。

更可能是：

> **小型网络社区先把距离压得很短；成功和规模化又重新制造新的距离。**

这是以后值得继续追的一个轴。

---

# 十四、另一个反方向：更容易发表，也意味着更容易消失

这条历史还有一个明显悖论。

早期互联网让大量原本不可能进入唱片目录的作品得以出现；但它们又常常只存在于：

- 某个个人主页；
- 某个已经关闭的 BBS；
- 某个 Flash 文件；
- 某个失效的 MP3 外链；
- 某个论坛附件；
- 某个停运音乐社区；
- 某个没有迁移完成的用户主页。

RockaCola 已经消失；Cmidi 已关闭；分贝网退出历史；虾米后来关停；大量 BBS 与个人主页也不再可访问。

所以“更多人可以创作”与“这些创作更容易被后世保存”并不是同一个命题。

恰恰相反：

> **中文网络音乐最草根、最私人、最没有商业价值的那一部分，也往往是最容易从历史记录中消失的部分。**

这与 How People Lived 的目标直接相关。

如果只研究后来仍能在 Spotify、Apple Music、QQ 音乐或大型视频网站找到的作品，我们会系统性高估：

- 职业化作品；
- 最成功的作品；
- 被正式发行的作品；
- 有能力迁移账号和版权的人。

而低估真正大量存在过的：

- demo；
- 翻唱；
- 自制伴奏；
- 小圈子原创；
- 同人曲；
- 校园作品；
- 只在一个论坛活过几个月的作者。

# 十五、研究上的“门槛栈”

以后研究任何一代民间音乐创作者，都可以分别问下面这些问题，而不要笼统说“互联网降低门槛”。

| 门槛 | 具体问题 |
|---|---|
| songwriting | 会不会写词、写旋律？ |
| instruments | 是否需要会乐器？能否用 MIDI / 软件替代？ |
| singer | 是否必须认识合适的真人歌手？ |
| recording | 在哪里录？电脑、声卡、麦克风多少钱？ |
| editing | 谁负责剪辑、调音、混音？ |
| encoding | 能否方便地转成 MP3 / WMA / 视频？ |
| bandwidth | 上传一首歌要多久？流量或拨号费用如何？ |
| hosting | 文件放哪里？容量限制多少？链接会不会死？ |
| identity | 有没有稳定账号让别人下次还能找到你？ |
| discovery | 靠首页编辑、排行榜、搜索、论坛还是算法？ |
| feedback | 有无评论、弹幕、站内信、圈子？ |
| collaboration | 能不能找到词、曲、唱、混音、画师、PV？ |
| rights | 上传后版权与授权如何处理？ |
| monetization | 能否获得收入？平台是否会反过来控制作品？ |
| archive | 平台关闭以后，作品和讨论还能不能活下来？ |

只有把这些门槛拆开，才能真正解释：

> 为什么同样是“会上网”，1997、2004、2008 和 2017 年的普通人能够做的事完全不同。

# 我们知道什么

- 台湾至少在 1993 年已有专业音乐 Dial-up BBS；1995 年已有通过 FTP 分发的音乐电子刊物；1999 年 BBS、WWW 与独立音乐线下场景已经形成明显连接。
- RockaCola 在 1999 年末已明确通过网络招募华人音乐创作者，并试图把网络发现与数字发行、线下产业连接。
- 香港 2000 年已有允许音乐人上传作品接触听众的在线音乐社区；同年约 36.4% 住户家中个人电脑连接互联网。
- 中国大陆 1997 年上网用户仍只有约 62 万，到 2000 年中已增长到约 1690 万。
- 163888 在 2003 年出现后，把网络音乐社区与录歌工具结合，并成为网络歌手的重要聚集地。
- 5sing 从 2004 年起把原创、翻唱、伴奏、评论、圈子、日志等放入同一账号体系，并明确把固定昵称理解为让别人“记住你、方便交流联络”的身份。
- StreetVoice 与豆瓣音乐人进一步把创作者主页、长期交流、demo 和线下演出连接起来。
- 到中文 VOCALOID 时代，网络发布与协作基础已经存在多年；真正新增的重要能力之一，是歌声合成降低了寻找真人演唱者的组织门槛。

# 我们可以合理推断什么

- “创作者与听众社会距离较短”不是单一平台文化，而是由固定 ID、小社区重复相遇、直接上传、评论与圈子等功能共同产生的结构。
- 2000 年代中期的大量网络歌曲、翻唱、古风与后来同人音乐 / VOCALOID 文化之间存在基础设施连续性，即使它们的审美、亚文化身份和平台不同。
- 网络并没有简单取消音乐工业，而是改变了进入音乐工业的顺序：一些创作者可以先拥有听众，再与唱片、演出或商业系统接触。
- 越早期、越小型、越没有正式发行的作品，今天越可能因平台关闭与链接失效而在史料中消失。

# 我们还不知道什么

- 1990 年代台湾 Music Link、“风之国度”等 BBS 的完整板面结构、用户规模、当年帖子与文件保存情况，仍需要继续寻找原始备份。
- RockaCola 到底在不同时期开放到什么程度：是任何人直接上传，还是需要站方筛选、签约或审核，应按具体年份继续核对。
- 香港 Cmidi 的准确创站年份、峰值用户数量、版面结构与现存 archive 仍需进一步考证。
- 中国大陆 1997 年前后的早期音乐网站目前大量资料来自后来的回顾，“第一家音乐网站”等称号存在相互矛盾的年份，应避免在没有原始网页或同时代报道前下唯一性结论。
- 163888、5sing 的早期用户页面、评论区、排行榜和圈子如果能通过 Internet Archive、旧截图或用户备份恢复，将非常适合做“一个普通投稿者的一天”式 life slice。
- 还需要专门研究 QQ 群、UC 语音聊天室、YY、贴吧、论坛与音乐站之间怎样互相导流；很多真实的人际关系可能发生在平台外，而不仅是作品页。
- 需要进一步研究台湾、香港与大陆创作者怎样跨区域使用同一个平台，以及繁简体、版权、支付、带宽和线下演出市场如何影响跨区域流动。
- 需要寻找更多普通用户的一手回忆：第一次买麦克风、第一次录歌、第一次收到陌生评论、第一次被固定 ID 认出、第一次与网友合作完成作品。
