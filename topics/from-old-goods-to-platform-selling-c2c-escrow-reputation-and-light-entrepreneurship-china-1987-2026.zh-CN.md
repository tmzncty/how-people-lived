# 从“卖旧货”到“随手挂一件”：C2C、担保交易、平台信誉与轻创业（中国，1987—2026）

## 研究问题

这篇不把“中国电商史”当作公司兴衰史来写，而问一个更窄、也更接近日常生活的问题：

> **一个没有商铺、没有长期商业身份的普通人，什么时候开始能够把一件自己的东西、一个小批量商品，后来甚至一项技能，直接拿到远方陌生人的市场里出售？**

研究单位不是“淘宝改变了中国”，而是一个人实际完成交易所需的路径：

```text
有一件可出售的东西/技能
→ 找到潜在买家
→ 让陌生人相信“人、货、价格”至少足够可信
→ 议价/下单
→ 钱进入一个可确认状态
→ 卖家交付商品或服务
→ 买家确认/提出争议
→ 卖家真正收到钱
→ 评价/信誉留下
→ 下一次交易是否因此更容易
```

这条路径与“正式就业”并不重合。一个人可以同时是学生、公司职员、家庭成员、消费者和卖家；也可以从处理闲置物品开始，逐渐变成副业，再决定是否进入全职经营。

本篇与仓库既有就业、空窗期、住房、汇款、家庭资金和数字身份专题的分工是：**这里只研究普通人进入陌生人市场的固定成本、信任栈、家庭劳动、平台记录与职业可逆性。**

## 一、Internet 以前：普通人当然也能卖东西，但“市场入口”有物理成本

### 1. 1987：旧货流通已经是一套普通生活基础设施

北京市政府 1987 年转发的《关于解决卖旧货问题的请示》是一份很有价值的 A 级制度原件。[S1]

它记录：

- 1985 年北京收售旧自行车 61,015 辆；
- 旧电视机 13,902 台；
- 旧手表 21,529 块；
- 旧录音机 7,602 台；
- 旧货销售额 4,424 万元；
- 政策同时承认当时国营信托企业“渠道单一、网点不足、分布不均”，群众卖旧货不方便。

这说明两件事必须同时保留：

1. **二手流通不是 Internet 发明的。** 家庭耐用品更新以后，把旧物再变成现金已经是现实行为；
2. **出售能力受地点与渠道约束。** “我有一台不用的电视”不等于“我随时有一个全国买家池”。

因此可以定义第一条机制：

### `market-entry fixed cost / 市场进入固定成本`

在旧货商店、寄售、跳蚤市场和走街串巷的世界里，交易常常要求至少一方移动身体、搬运货物、找到特定市场、等候买家或交给中间人。

2025 年《北京日报》基于旧报纸和历史照片的回顾资料，还能把这条前史补得更细：1980 年代北京旧货渠道不足，走街串巷的小商贩和“倒爷”承接了部分流通；1992 年出现“星期日跳蚤市场”，1993 年出现大型旧货市场。[S2]

这属于 **C 级后来的档案整理/回顾**，不能替代当年的现场报道，但足以作为 1990s Web 以前的边界说明。

### 生活史含义

Internet 到来前，人当然可以：

- 卖给信托商店；
- 委托别人寄售；
- 去旧货市场摆摊；
- 卖给走街串巷的收购者；
- 在熟人网络中转让；
- 通过报刊分类广告寻找买家。

Internet 后真正变化的不是“第一次可以出售”，而是：**一个私人个体可以在不先取得实体摊位的情况下，把一件商品变成可被远方陌生人搜索的记录。**

## 二、1999—2005：从“人去市场”到“商品记录进入全国市场”

### 2. 1999—2002：易趣把个人卖家变成平台里的可检索对象

2002 年同期报道记录，易趣 1999 年 8 月在上海创办，当时已提供竞价、一口价和定价等形式，面向个人以及大小商家；报道援引公司数据称其已有 350 万注册用户、累计成交 235 万件商品、累计成交额 7.8 亿元。[S3]

这些规模数字属于**平台提供、同期媒体转述的 B 级证据**，不能当全国人口调查；但它足以证明：到 2002 年，个人把商品放进网络市场已经不是实验室式小规模现象。

2004 年 eBay 易趣负责人又对路透表示，平台创办初期曾鼓励本地交易，估计约 95% 的实际交货需要双方见面；到 2004 年，超过 70% 的交易已经发生在不同城市用户之间。[S4]

这仍是公司管理者的估计，不能当精确普查。不过，它支持一个很重要的机制变化：

### `market-radius expansion / 市场半径扩张`

商品可以先被远方看见，身体和货物只在成交以后再移动。

这和“远距离家庭通信”专题里的变化类似：**网络先让信息脱离身体移动，物流再负责把物体补上。**

---

### 3. 2003—2005：低门槛开店并没有消灭交易摩擦，而是把它拆成平台状态

淘宝 2003 年 5 月上线后，把自己明确定位为免费的个人交易平台；2005 年的同期报道显示，淘宝与易趣的重要竞争之一正是卖家费用：淘宝长期免费，易趣收取刊登和成交费用，后来也主动下调收费。[S5]、[S6]

这里真正与普通生活有关的不是“哪个公司赢了”，而是：

### `listing-cost compression / 上架成本压缩`

如果发布一件商品几乎不需要按件付费，一个学生、职员或家庭成员就可以先试着把东西挂上去，而不必先证明自己“是商人”。

但是，低发布成本没有自动解决陌生人交易的最大问题：

> **我为什么把钱给一个从没见过的人？**

2005 年 2 月 `www.alipay.com` 正式上线时，同期报道对其机制的描述非常清楚：买家付款后，支付宝先替双方保管货款，直到买家确认收到货，资金才进入卖家一侧。[S7]

因此需要把一次看似简单的“网购”拆成：

```text
buyer commits money
→ escrow holds money
→ seller receives a payment-status signal
→ seller ships
→ buyer receives
→ buyer confirms / timeout / disputes
→ seller can receive money
```

这带来第二条关键机制：

### `escrow temporal split / 担保交易的时间分裂`

**“买家已经付钱”与“卖家已经得到钱”不再是同一时刻。**

这不是一个纯技术细节。它使两个陌生人可以把互不信任转移给第三方状态机，从而让“远方陌生人”第一次更大规模地成为普通人的可执行交易对象。

## 三、2005 的一份卖家教程：所谓“零门槛网店”其实是一组新劳动

2005 年《金陵晚报》刊出一篇署名淘宝会员“猪脑子塞了”的卖家教程，是非常有价值的 **B 级同期用户操作材料**。[S8]

它记录的开店路径包括：

- 注册会员名和密码；
- 同时成为支付宝会员；
- 上传身份证进行认证；
- 身份证可以用数码相机、扫描仪或传真提交；
- 等待约 3 个工作日的认证结果；
- 保持至少 10 件“出售中的宝贝”才能开店；
- 自己拍照、修图；
- 写能被搜索到的商品标题和关键词；
- 做商品描述、表格、字体和店铺页面；
- 选择 7 天或 14 天的发布有效期；
- 设计店标、公告、论坛头像和签名；
- 收到支付通知后安排邮寄；
- 继续负责退换货和售后。

所以所谓“开店不需要门面”，并不等于“开店没有成本”。平台把原来集中在实体商铺里的工作拆成了很多家庭/个人任务：

### 新的卖家劳动栈

```text
采购
+ 拍照
+ 图片处理
+ 网页/店铺装修
+ 搜索关键词
+ 在线客服
+ 议价
+ 支付状态监看
+ 包装
+ 物流
+ 售后
+ 信誉维护
+ 流量获取
```

这可以称为：

### `storefront unbundling / 店铺劳动拆包`

**门面租金下降了，但“经营一家店”并没有消失；它被拆进电脑、卧室、家人的时间和快递网络。**

## 四、2005–2012 扩张型未来：消费者可以先成为兼职卖家，再决定要不要换人生路线

### 4. 2008：校园不只是消费 Internet，也开始把 Internet 当作市场入口

2008 年《中国青年报》报道义乌工商职业技术学院时，记录校内已有 200 多家网店，1200 多名学生参加网上创业，快递公司甚至“进驻”校园以便发货。[S9]

这不是全国大学生样本，且报道明显偏向成功案例；但它能证明一种此前少见的生命路径已经存在：

```text
学生
→ 课余经营
→ 订单/客户积累
→ 毕业后继续经营或创办企业
```

过去学生要试做零售，通常至少需要摊位、店面、熟人渠道或长期线下跑货；此时一台联网电脑、可认证身份、货源与快递已经能组成最低限度的“商铺”。

### 5. 2009：张浩学把“买家”身份翻转成“卖家”，再把副业翻转成主业

2009 年同期采访中的张浩学，是这一轮最重要的生命史材料之一。[S10]

她的路径不是“毕业即创业”：

```text
大学二年级网购衣服
→ 买多后在网上转卖赚零用钱
→ 注册网店
→ 毕业后做房地产公司秘书
→ 业余继续经营两年
→ 网店收入超过工资
→ 2009 年辞职全职经营
```

她还把母亲家中原来的卧室变成库存仓库，每天从早 9 点经营到午夜，处理全国各地询问；报道记录其旺季月交易数百件、最高月收入约 1.5 万元。

这些数字只是**单一个案的同期自述**，不能推成“网店普遍比白领工资高”。真正值得保留的是生活路径类别：

### `consumer–seller role reversibility / 买家—卖家身份可逆`

一个平台账户附近，消费、清理闲置、赚零用钱、兼职经营、全职经营可以不是五种完全不同的人，而是同一个人逐步切换的状态。

### `household-space commercialization / 家庭空间商业化`

没有实体仓库不代表没有库存。张浩学的母亲家、她原来的卧室承担了仓储功能。

同一篇报道里的邓力珂还显示，兼职店铺可以调用父母帮忙拿货、邮寄。[S10]

因此平台降低的不是家庭投入，而更像是**把一些商业固定资产改造成可由家庭临时吸收的劳动和空间**。

---

### 6. 扩张型未来必须同时保留失败样本：低上架成本 ≠ 低获客成本

2009 年《南都周刊》采访 19 岁大学生肖肖时，她已经拿家庭给的 2 万元进货、开店近一年，但每天流量一度只有约 2 人，近一年只卖出 11 件衣服；直到她在平台社区发帖获得关注，流量才明显上升。[S11]

这个个案比“学生网店月入数万”的成功故事更能校准扩张型未来：

### `market-entry / attention gap / 进入市场—获得注意缺口`

平台可以让每个人都发布，但**可发布的商品数量增长得越快，注意力本身越可能变成稀缺资源。**

所以 2005–2012 的“扩张”更准确地说是：

> **新的路线变得可尝试，而不是新的路线变得容易成功。**

一个人可以用更低固定成本赌一次自己的商品、审美或手艺是否有人要；失败以后也可能继续读书或回到工作，而不是一次性承担实体店租约。

这也是 `optionality / 可选性` 的一种非常具体的形式。

## 五、平台信誉：陌生人交易把“人品”压缩成了可计算的局部记录

2006 年淘宝调整信用体系，把原先买卖合一的信用拆成买家信用和卖家信用，一些用户立刻发现自己的展示等级发生变化并影响生意。[S12]

同年同期媒体还调查到所谓“信誉提升代办”：通过假装完整走一遍“上架—购买—发货—确认收货—好评”的过程来制造信用。[S13]

这给生活史提供了一个极有用的警告：

### `reputation as platform-local capital / 信誉作为平台局部资本`

好评、心、钻、皇冠并不是人的一般道德人格，也不是收入证明；它只是某个平台按特定规则积累的历史交易信号。

规则改变，信誉展示会变；平台关闭，信誉甚至会消失。

2022 年易趣宣布关闭时，同时关闭商品/商铺交易、用户注册、登录和充值，并提醒用户在关站前查看过去交易记录、退回账户余额。[S14]

这形成：

### `reputation portability gap / 信誉不可携带缺口`

一个人在旧平台上多年积累的“我是可靠卖家”不能自动转成下一家平台上的同等资本。

历史档案也很可能只留下店铺名或部分商品页，留不下那个卖家真正做过的几百次发货、退换和争议。

## 六、制度边界：随手处理自己的旧物，什么时候变成“经营者”？

2008 年北京针对电子商务经营活动的规定，明确把“不以营利为目的出售、置换自用物品”的个人，与持续营利性网上经营区分开；后一类原则上进入工商登记要求。[S15]

这说明平台上的身份至少有四层：

```text
普通消费者
→ 偶尔出售自用物品者
→ 持续营利的个人卖家
→ 已被工商/税务等系统识别的经营主体
```

现实生活中这些边界可以逐渐跨过，并不一定在某一天整齐切换。

因此不能写：

> “有淘宝店 = 已经是一名正式创业者。”

也不能反过来写：

> “没有企业注册 = 这项劳动不是真正的经济活动。”

这正是平台经济的 **administrative legibility gap / 行政可识别缺口**。

## 七、2015–2019 拥堵型未来：开店依然便宜，但“被看见”越来越依赖平台基础设施

2019 年第一财经采访张玉仕，保存了一条从 2010 年开始的长路径。[S16]

他当时即将大专毕业，本来“一心只想从事研发类工作”；为了做机械模型而在淘宝寻找零件，却发现小批量零配件供给不足。供货商虽然要求几千个起买，但总价只有数百元，他于是把剩余零件再放到淘宝出售，第一个月成交 2930 元，后来进一步设计科学玩具，2013 年创办公司。

这个案例的重点不是其后来千万级销售额，而是：

### `search-to-supply inversion / 搜索者转为供给者`

一个人先以买家身份发现“我需要但找不到”，再把这个缺口变成卖家路线。

但 2019 年同一篇报道也显示，小众商家已经越来越依赖定向推广、平台数据分析和流量工具来找到精准用户。[S16]

因此可以把 2015–2019 的拥堵感写得更具体：

### `attention-infrastructure dependency / 注意力基础设施依赖`

2005 年卖家教程还在教“标题里一定要写‘手链’、去论坛签名档宣传”；2019 年的小商家已经需要理解人群标签、推荐系统、数据工具和内容入口。

**市场入口继续便宜，市场注意力却变得更平台化。**

这与“机会越来越多但每个机会都要单独优化”的拥堵型未来是同一种结构。

## 八、2020–2022 偶发型未来：副业从“想试试”变成风险缓冲，但并不自动安全

2020 年疫情冲击期间，《中国青年报》记录年轻人中“副业刚需”“副业慌”等同时代说法：有人把“主业 + 副业”理解成对不确定收入的保险；一名大学生在居家上网课期间尝试网络兼职，却先支付了 398 元入门费。[S17]

同年高校就业信息平台转载报道，教育系统把“开网店”等自主创业纳入更明确的就业统计语境；一名即将大四的学生胡为说，因为“今年就业难”，先开淘宝店试一试；开店刚过三个月，经营结果给了他毕业后继续经营的勇气。[S18]

这里产生一个新机制：

### `side-income as contingency buffer / 副业作为偶发性缓冲`

副业不再只表示“我有创业梦想”，也可能表示：

> **我不确定主业、招聘和收入日历会不会照常运行，所以最好再留一条现金流。**

但同一时期的诈骗、培训费、审核和劳务纠纷案例也提醒：低进入门槛可以同时降低**骗局进入一个人的生活**的门槛。

因此不能把“副业可做”直接写成“副业是安全的风险缓冲”。

## 九、2023–2026 防守型未来：从“卖闲置回血”到“低成本试一次自己能不能靠技能挣钱”

2024 年《经济日报》把年轻人在二手平台出售闲置物品概括为“赚钱回血”，同时明确指出货不对板、假冒伪劣、恶意换货等持续存在。[S19]

这个“回血”比“创业”更接近防守型未来的一种日常操作：

### `household asset liquidity / 家庭物品流动性`

一件已经买下、放在家里的相机、衣服、模型或家具，不再必然只能继续占空间或低价交给附近收购者；它可以被重新变成一小笔现金。

2025 年《人民日报海外版》的现场材料又显示，年轻买家会在二手平台反复看图片、评论并直接与卖家讨价还价，同时在买家和卖家之间切换。[S20]

到 2026 年，平台边界继续从“二手货”向技能和服务延伸。工人日报报道一名广东“00 后”女性最初只是挂闲置衣服，看到需求后开始研究新品销售，累计卖出超过 5 万元；同一报道还记录由 7 名持证心理咨询师组成的兼职团队，其中多人是刚毕业的年轻人。[S21]

财新 2026 年报道的一项平台研究则显示，在 2024-11-01 至 2025-10-31 的一年里，闲鱼“副业”板块有 1962 万名卖家发布服务，超过七成为 35 岁以下；超过四成受访者称副业收入占月收入 30% 以上。[S22]

这些是**闲鱼平台特定板块与特定调查样本**，绝不能改写成“中国 1400 万青年已经靠副业稳定就业”。

它真正支持的是另一条生活路径已经可见：

### `light entrepreneurship / 轻创业`

```text
先卖一件闲置
→ 发现有人愿意付钱
→ 小规模重复
→ 增加货源或技能服务
→ 保留主业继续测试
→ 再决定是否扩大、注册经营或转为主业
```

它的“防守性”在于 **可逆**：

- 不先租店；
- 不先辞职；
- 不先把所有储蓄压进去；
- 可以用一个晚上的时间或一小批货测试需求。

但其另一面是：**人的休息时间也越来越容易变成可出售的剩余容量。**

因此不要浪漫化“斜杠”“轻创业”。对于一些人，它是兴趣变现；对另一些人，它是主业不足以提供安全感后不得不再开第二班。

## 十、跨国比较：陌生人网络交易不是中国特有，差别在于信任和基础设施怎样被编码

### 1. 1994 年 Usenet：Web 商城以前，Internet 已经存在“电子跳蚤市场”

Coalition for Networked Information 1994 年的同期报告把 `misc.forsale` newsgroups 直接比作 Internet 上的 “Penny Shoppers”，并说这些组常按大城市形成，用户主动订阅就是为了知道“有什么在卖”。[S23]

这是一份非常有价值的 **A 级近原始 Internet 同时代材料**。

它证明：

> **商品信息进入陌生人网络市场，早于 WWW 商城成为大众消费基础设施。**

但 Usenet 的帖子本身没有后来 C2C 平台完整的担保支付、物流状态、店铺等级和争议系统。

### 2. 1995–1996 eBay：平台开始把陌生人信任编码成反馈记录

Pierre Omidyar 1996 年 2 月 26 日给 AuctionWeb/eBay 社区的原始信件说明，网站上线约半年后引入 Feedback Forum，他明确希望让人在网上“与陌生人做生意”更容易。[S24]

这与中国 2000s 的淘宝信用、担保支付形成很好的共同机制：

### `stranger-trade trust stack / 陌生人交易信任栈`

```text
persistent account
+ visible transaction history / reputation
+ communication
+ payment mediation
+ delivery evidence
+ dispute handling
```

不同国家和平台组合方式不同，但 Internet 时代的共同变化是：**过去需要熟人、中间商或现场验货承担的一部分信任，被拆成了数据库字段和平台规则。**

### 3. Craigslist：Internet 市场甚至可以先从邮件列表长出来

Craigslist 的同期/近同时期档案材料显示，它 1995 年先是旧金山朋友之间的邮件列表，随后逐渐加入 jobs、stuff for sale、apartment listings，再因为邮件规模过大而写代码转为 Web 页面。[S25]

所以 Internet 对普通生活的影响也不能只从“网站上线日”计算：

**email list → listserv → Web page → searchable local market** 本身就是一条基础设施演化链。

## 十一、它改变了“人怎么活着”的哪一点？

### 1. “商人”不再一定是一种先验身份

过去常见的路径是：

```text
先决定做生意
→ 找摊位/店面/渠道
→ 进货
→ 等顾客
```

平台以后多出一种：

```text
先有一件多余的东西
→ 随手挂上去
→ 第一次成交
→ 再挂第二件
→ 发现需求
→ 才逐渐形成“我也许可以做生意”的自我理解
```

因此职业身份可以由交易反向生成，而不必在第一单之前已经确定。

### 2. 家庭住房可以短暂兼任商业基础设施

卧室可以变仓库，父母可以帮拿货和寄件，配偶的稳定工资可以支撑另一个人试经营。

平台降低实体商业固定成本的同时，也可能把成本“藏”进家庭空间和无偿亲属劳动。

### 3. 一件物品不再只有“消费价值”

它还可能是：

- 未来可变现的余额；
- 搬家前的现金回收；
- 失业/收入中断时的缓冲；
- 第一次测试陌生人市场的商品；
- 进入副业的起点。

### 4. 注意力与信誉成为新的资产，但都由平台托管

商品本身属于你，平台上的曝光顺序、搜索权重、好评记录、粉丝和店铺等级却不完全属于你。

这让现代普通人的“经济资本”增加了一层非常脆弱的数字部分。

## 十二、证据边界、反例与后见之明风险

### 已经较强地知道

- 1980s 北京家庭旧货流通已经有相当规模，且官方承认网点不足；
- 1999–2002 中国已经形成较大规模个人 C2C 平台；
- 2003–2005 免费上架、身份认证、支付担保、信誉和物流已经成为网上卖家的关键事务；
- 2008–2009 学生/年轻职员确实存在“课余开店→副业→主业”的路径；
- 同期也有低流量、长期卖不动的失败/半失败案例；
- 到 2019，低门槛开店仍存在，但流量和数据工具的重要性明显增强；
- 2020 后副业开始更频繁地被表述为不确定收入的缓冲；
- 2024–2026 二手平台进一步承载闲置变现、技能服务和小规模“轻创业”。

### 不能据此推出

- “2008 年大学生普遍靠淘宝赚钱”；
- “网店比普通工作收入高”；
- “疫情导致所有年轻人开始副业”；
- “二手平台用户都是因为经济困难才回血”；
- “1962 万发布服务者 = 1962 万稳定就业者”；
- “平台好评 = 商品一定真实 / 卖家一定可靠”；
- “交易页面存在 = 钱、物流、售后全部执行完成”。

### 选择偏差

成功网店特别容易得到媒体报道；失败者、只卖一两件就停的人、忙了几个月没有成交的人，更容易从历史里消失。

因此 2009 年肖肖“近一年只卖 11 件”的材料非常重要，它防止仓库被“创业神话”反向抽样。

### 平台统计偏差

淘宝、闲鱼、易趣公布的注册人数、成交额、店主年龄和就业人数主要证明“平台当时这样记录/宣称”，不应直接外推到全国劳动市场。

### 历史可见性偏差

最容易留下的是：

- 店铺首页；
- 商品图片；
- 卖家昵称；
- 公开评价；
- 平台新闻稿；
- 成功卖家采访。

最容易消失的是：

- 旺旺/QQ 私聊；
- 支付失败；
- 物流丢件；
- 退款争议；
- 平台风控；
- 家人帮忙打包的时间；
- 只试过一次就放弃的人；
- 被关站带走的历史信用。

所以未来研究者如果只看残存网页，会系统性高估“商品被展示”的重要性，低估“交易真正执行”的劳动。

## 本轮阶段判断

**有实质新增；饱和计数 = 0。**

本轮首次加入了：

- `market-entry fixed cost`；
- `consumer–seller role reversibility`；
- `escrow temporal split`；
- `storefront unbundling`；
- `household-space commercialization`；
- `market-entry / attention gap`；
- `reputation as platform-local capital`；
- `reputation portability gap`；
- `attention-infrastructure dependency`；
- `side-income as contingency buffer`；
- `light entrepreneurship`。

它们都改变了“普通人到底有多少种活法”的既有矩阵，因此还远未满足连续三轮无新增的 closure 条件。
