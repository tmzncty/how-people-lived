# 从劳动服务公司到分类信息与零工市场：本地机会可寻址性、过渡性收入与重新物质化的就业接口（中国，1979—2026）

> 本稿研究的不是“58 同城公司史”或“灵活就业产业史”，而是一个普通生活问题：一个人临时缺一份收入、需要找一间房、搬一次家、请一次保洁、卖一件旧物或在两份正式工作之间找几天活时，**她怎样知道附近究竟有哪些机会，而且怎样判断一条信息是否真的能执行。**
>
> 它同时服务于 `how-people-lived` 与 `old-web-archaeology` 的交叉研究。中文旧网页面的技术、分类、排名、联络方式与存档缺口另见 `tmzncty/old-web-archaeology` 的配套 state-gap note。

## 1. 本轮为什么选这个对象

仓库已经有正式招聘、职业中断与再进入、网约车、租房、二手交易、平台创作等专题；这些材料说明，现代生活里很多机会已被拆成独立项目。

但还有一层没有单独建模：

> **不是“有没有工作”，而是“一个足够小、足够近、足够临时的机会，能不能被此刻需要它的人看见”。**

这类机会特别容易漏出标准人生脚本：

- 一个人可以有主业，同时周末做促销、家教或数据录入；
- 一个人可以在失业与下一份正式工作之间做几天零工；
- 一位照护者可能只能接受离家近、时间可切割的工作；
- 一个新到城市的迁移者可能先靠临时工、合租与本地服务把生活接起来；
- 小商户可能只在节假日或某几天需要额外人手；
- 一次搬家、维修、保洁、转租，本身也会产生短暂的本地劳动需求。

这类行为很难只用“就业人口”“正式职业”“平台用户数”来重建。

## 2. 本轮新增概念

### 2.1 local opportunity addressability / 本地机会可寻址性

机会存在，并不等于普通人知道它存在。

前互联网条件下，机会可能依赖：

- 劳动部门或劳动服务公司；
- 职业介绍所；
- 劳务市场和招聘会；
- 单位、街道、学校；
- 熟人介绍；
- 报纸分类广告；
- 店门、工地、路边或市场里的纸条与口头招工。

Web 分类信息把“城市—区县/街区—类别—价格/工资—时间”等字段变成可检索结构以后，改变的首先是**发现路径**，不是劳动关系本身。

### 2.2 listing-to-life executability / 条目到生活的可执行性

本轮永久保留以下状态差：

```text
现实中存在一项需求
!= 某人把它写成一条信息
!= 信息已经发布
!= 信息当前仍有效
!= 搜索/排序能让需要的人看见
!= 发布者身份真实
!= 联系方式可达
!= 见面主体就是发布主体
!= 条件与页面一致
!= 工作/服务真正发生
!= 报酬/价格按约定执行
!= 发生争议时有可识别的责任主体
```

因此：

> `listing visible != opportunity executable`。

### 2.3 odd-job holding state / 零工过渡态

零工并不一定是一个人的长期职业身份。

它还可能是：

- 正式工作之间的过渡；
- 等待入职、考试、开学或返乡期间的收入；
- 主业之外的补充收入；
- 家庭照护条件下能挤出的短时劳动；
- 生意、行业或季节中断时的临时替代。

因此不能把所有“打零工者”压成一种人格或阶层类型。

### 2.4 ranking-as-market-place / 排名即摊位位置

分类信息网站看起来摆脱了物理市场，但列表顶部本身变成新的稀缺位置。

2013 年 58.com 向美国 SEC 提交的 F-1 显示，付费商户可以购买 priority listing，也可以按“类别 + 地点”竞价次日更显眼的位置；竞价价格还参考历史流量、点击和前一日价格。

这意味着：

> 过去“市场门口的摊位”“报纸分类栏的醒目版位”，在数据库时代重新出现为**排序位置**。

Internet 没有消灭地点竞争，只把一部分地点变成了页面坐标。

### 2.5 contact-channel escape / 联络链逃逸

一条平台信息常常只是交易链的第一步：

```text
平台 listing
→ 电话 / 短信 / 即时通信
→ 后来的 QQ / 微信
→ 线下办公室或工地
→ 纸面/电子协议
→ 付款或结算
```

一旦离开平台，平台页面与真实执行主体就可能逐渐脱钩。

这既是普通生活中的信任问题，也是历史保存问题。

### 2.6 matching/support split / 匹配与保障分裂

Web 和手机很擅长扩大“谁能看见谁”。

但劳动权益、培训、争议调解、等候空间、工资支付确认等支持功能未必随着匹配一起数字化。

2020s 各地重新建设带座椅、电子屏、培训和维权窗口的零工市场，可以理解为：

> **不是从数字化倒退回实体市场，而是把被平台拆开的“匹配”与“保障”重新捆一部分回来。**

## 3. 互联网以前：就业机会本来就通过多层中介流动

### 3.1 1979—1980：从统包统配之外重新打开多条入口

国家统计局后来对改革开放 40 年就业史的回顾记录：1979 年城镇累计待业人员约 1500 万，仅劳动部门登记的城镇失业人员 568 万；1980 年提出劳动部门介绍就业、自愿组织起来就业与自谋职业相结合的“三结合”方针。

同一回顾还指出，1980 年以后以劳动服务公司为代表的就业服务机构开始出现，逐渐向乡镇延伸；1990s 劳动力市场发展，国家就业服务机构与各类社会职业介绍机构并行扩大。

**证据等级：B/C（后来的国家统计机构历史综合）。**

它证明制度入口变化，不能用来重建某个 1980 年青年一天怎样找到具体岗位。

来源：

- 国家统计局，《就业总量持续增长 就业结构调整优化——改革开放40年经济社会发展成就系列报告之十四》  
  https://www.stats.gov.cn/zt_18555/ztfx/ggkf40n/202302/t20230209_1902594.html

### 3.2 一个地方层面的具体量级

台州地方志所载临海县材料显示，1979 年成立县劳动服务公司；到 1985 年底，它曾为机关、企事业单位调配输送约 1500 名城镇劳动力和 700 名农村劳动力。1984 年以后当地各行各业还兴办多种劳动服务公司，并设培训中心。

**证据等级：B/C（地方志后编，但基于地方机构资料）。**

这条材料的重要性不在于代表全国，而在于提醒：

> Web 以前，“临时用工需求 → 一个集中中介 → 具体劳动力”的信息匹配已经存在；数字平台改变的是范围、速度、检索与自助程度，而不是凭空发明中介。

来源：

- 台州史志网，《第三节 安置就业》  
  https://tzsz.zjtz.gov.cn/art/2019/5/29/art_1229208937_54438562.html

## 4. 2005—2012：扩张型未来——把附近的小机会做成可搜索条目

### 4.1 2009：主业之外的兼职已经是一种明确选项

2009 年《新闻晚报》转引智联招聘对约 8000 名白领的调查：在受访者中，一部分人已经做过促销/销售、文字或数据录入、家教、会计等兼职；金融危机背景下，未做过兼职的人中也有相当比例表示打算尝试兼职。

**证据等级：B；同时性 T1，但样本来自招聘网站，不是全国劳动人口代表样本。**

这条材料最适合支持一个窄命题：

> 2009 年城市白领的可说出口工作菜单里，已经可以把“固定工作 + 另一份小工作”当成明确选择，而且动机既可能是经济压力，也可能是积累经验或利用空闲。

不能据此推出“金融危机后中国上班族普遍做兼职”。

来源：

- 《三成上班族兼职收入高过工资 工作清闲是主因》，2009-05-21  
  https://money.sohu.com/20090521/n264097036.shtml

### 4.2 同一个危机里，线下招聘市场仍然非常重要

2009 年广州一场就业活动里，因原公司倒闭失业的谭先生回广州求职；他明确比较了过去 4000 多元工资与此刻“能找到 2000 元就不错”的预期。现场有招聘摊位、政策咨询、创业展示和远程见工区。

**证据等级：B/T1 同期采访。**

它提供一个必要反例：

> 互联网招聘已经存在，并不等于现场招聘会、公共就业机构和地域性劳动力市场突然退出普通人的求职路径。

来源：

- 《失业白领找工忙 岁末此类求职者比例超以往》，2009-01-13  
  https://news.sina.com.cn/c/2009-01-13/004615021520s.shtml

### 4.3 2010：分类信息第一次把很多“小生活问题”塞进同一个搜索入口

2010 年金羊网报道里，孙小姐因为租金上涨，在 58 同城发布“出租两居室客厅一间”的信息；接受记者电话采访时，她明确说这样做是为了减轻住房压力。

**证据等级：B/T1。**

它只是一名租房者，不能代表平台普及率，但它非常具体地显示：

```text
家庭预算压力
→ 把原本不是独立卧室的客厅转成可出租资源
→ 用本地分类信息寻找陌生合住者
```

这正是本研究所说的“本地机会可寻址性”：平台不只是让既有市场效率更高，还能让一个家庭把自己原先未商品化的空间临时转换成收入/成本缓冲。

来源：

- 金羊网/搜狐，《解决生活难题 分类信息网站走入百姓生活》，2010-10-19  
  https://news.sohu.com/20101019/n276017211.shtml

### 4.4 2013 F-1：分类信息并不是“无地点互联网”

58.com 2013 年向 SEC 提交的 F-1 是本轮最强的平台同时代结构证据之一。

文件称：

- 平台当时覆盖约 380 个城市站点；
- 用户通常先选择城市，再可选择具体 neighborhood；
- 分类包括住房、工作、二手、汽车、宠物、票务、黄页和其他本地服务；
- jobs 里包括销售、技能工、餐饮、配送、家政/保洁等；
- 未注册用户可以浏览与搜索，注册后才能发布信息并使用更多通信工具；
- 移动入口同时包括 Android/iOS App、智能手机浏览器适配页面和功能机 WAP；
- 移动端还提供一键拨打 listing 电话、短信或即时通信；
- 付费商户可进行认证、建立 online storefront，并购买优先排序与竞价位置。

**证据等级：A（2013 同期监管申报文件），但它首先证明公司当时如何描述自身产品与业务数据。公司委托/引用的市场份额、用户规模不能不加区分地当作独立统计。**

来源：

- 58.com Inc., Form F-1, filed 2013-09-27  
  https://www.sec.gov/Archives/edgar/data/1525494/000104746913009364/a2216693zf-1.htm

#### 一个关键修正：Internet 没有消灭“本地”

58 的结构恰恰是：

```text
全国品牌
→ 城市
→ neighborhood
→ 类别
→ 子类别
→ 条件过滤
→ 单条 listing
→ 电话/IM/线下
```

因此更准确的历史结论不是“互联网让地理不重要”，而是：

> **地理从“你必须亲自站在那个市场里”变成了数据库里的一个索引字段。**

## 5. 2015—2019：拥堵型未来——机会更多，但验证和收入结构也更复杂

### 5.1 2019 县域零工调查：主业 + 零工必须与“纯零工”分开

2019 年 58 同镇与清华大学社会科学学院县域治理研究中心对 1.6 万余名县域居民的合作调查，经中国经济网/人民网转载，报告称样本中 52.27% 有零工收入，其中 24.72% 同时有主业和零工收入；另有材料称样本中 35.11% 的零工通过互联网渠道获得收入。

**证据等级：B；同期调查，但研究与平台共同发起，抽样框、平台触达方式与代表性需要进一步检查。不得换算成“全国县域人口一半都做零工”。**

来源：

- 人民网/中国经济网，《58同镇联合清华大学发布零工经济报告：互联网成零工集散地》，2019-11-13  
  https://it.people.com.cn/n1/2019/1113/c1009-31453368.html

这条材料真正改变的是分类方式：

> `有正式主业` 与 `做零工` 不是互斥身份。

一个人完全可能同时处在：

```text
主业提供较稳定现金流
+
零工填补消费/家庭支出/闲时
+
未来仍考虑换工作或迁移
```

这比“正式就业 vs 灵活就业”二选一更接近真实生活。

### 5.2 信息越容易发布，真实性验证越成为新的劳动

分类信息把发布门槛压低以后，求职者需要自己承担更多“这条信息究竟是谁发的、是不是真岗位、到现场会不会换条件”的判断劳动。

这不是说纸质广告或线下中介从前没有诈骗，而是说数字平台把**规模化可见性**与**现实责任主体识别**分成了两个问题。

平台自己的 2013 F-1 已经把自动/人工筛查、商户认证、用户举报和 trust score 当成核心产品能力之一。反过来也说明：

> “谁都能发布大量本地条目”的扩张，本身就会制造新的真实性治理需求。

## 6. 2020—2022：偶发型未来——短期工作更像缓冲器，但权利状态仍可能模糊

本轮没有找到一个足够强、可直接代表 2020—2022 全国零工生活的单一第一人称，因此不补一段戏剧性个案。

这里保留一个**研究缺口**：下一轮若继续此线，应优先找疫情期间同时代个人材料，区分：

- 原主业短期停摆后临时找工；
- 平台配送/众包成为主要收入；
- 原来就长期以日结/临时工为主；
- 学生/照护者偶尔补收入；
- 因跨地区流动受限而被迫留在当地找短工。

不能把这些路径都写成“疫情催生灵活就业”。

## 7. 2023—2026：防守型未来——找一份短工，也开始要求“退出有路、出事有人管”

### 7.1 2024：零工可以是两份正式工作之间的 holding state

2024 年《上观新闻》/澎湃新闻调查记录重庆青年谯兵春节后回到上海，正在多个求职平台寻找新工作；在过渡期间，他想先做些兼职零工。

这是一条非常干净的生活路径：

```text
上一阶段工作结束
→ 返回/重新进入城市
→ 正式求职尚未完成
→ 需要短期现金流
→ 零工成为过渡态
```

它提醒我们：**“打零工”有时不是一个人要成为的职业，而是她用来避免生活在两份工作之间彻底断电的桥。**

来源：

- 毛锦伟，《“299元一天”的工作靠谱吗？求职市场打零工走热，监管需跟上了》，2024-04-01  
  https://www.thepaper.cn/newsDetail_forward_26882627

### 7.2 同一案例揭示“联络链逃逸”怎样破坏责任可读性

记者从 58 同城/智联上的兼职 listing 出发，留下联系方式后被引流到微信，再去线下办公室；招工信息发布者、发送面试通知者、收款方、纸面协议签约方先后出现不同公司。之后真正通过朋友圈提供的工作又与页面承诺明显不同。

监管人员向记者说明，平台发布、短信通知、收费和盖章主体彼此分离，会增加固定虚假招聘证据和界定责任的难度。

因此本轮固定：

```text
platform advertiser
!= contact person
!= interview office
!= fee recipient
!= contract signatory
!= downstream labor demander
!= final payor
```

**证据等级：B/T1 调查报道。**

这里不把受骗者作为猎奇材料；它的研究价值在于：

> 数字平台把“机会被看见”做得极其高效，但一次工作最后由谁负责，仍可能沿着跨平台、跨公司的执行链变得更难追踪。

### 7.3 2026：实体零工市场重新出现，但不是互联网的反面

2026 年北京马驹桥零工市场的一场招聘会，62 家企业提供 3108 个岗位，行业包括物流分拣、物业安保、工厂普工、酒店餐饮、家政等；北京市同期推进的零工市场同时提供线上岗位通道、线下争议调解与投诉维权。科技日报还记录“马上有活”数字平台与实体市场结合。

来源：

- 新华社/人民网，《工资能足发 权益有保障——双节期间北京保障零工劳动权益一线观察》，2026-01-12  
  https://society.people.com.cn/n1/2026/0112/c1008-40643366.html
- 科技日报，《北京马驹桥零工市场举办专场招聘会 3108个岗位破解双节用工难题》，2026-01-09  
  https://www.stdaily.com/web/gdxw/2026-01/09/content_459462.html

2026 年《工人日报》又采访 42 岁零工王汝东；他把过去在马路边围车抢活、遇到黑中介和欠薪的经历，与如今在有电子显示屏、洽谈室和调解空间的规范市场找活作比较。

来源：

- 工人日报/人民网，《从“马路边的等待”到“指尖上的订单”》，2026-06-19  
  https://society.people.com.cn/n1/2026/0619/c1008-40743652.html

**证据等级：B/T1。**

这条材料给“防守型未来”增加了一个很具体的机制：

> 成熟阶段的需求不只是“让我更快匹配”，而是“匹配以后工资能不能落袋、主体能不能找到、争议有没有地方去”。

### 7.4 重新物质化：为什么数字时代还要有大厅和驿站

到 2026 年，贵州、新疆等地的官方/媒体材料仍在推广“线上 + 线下”的零工市场、驿站和小程序；线下空间同时承担候工、咨询、培训、劳动维权和生活支持。

这不是简单的技术倒退。

可以把它理解为：

```text
物理劳务市场
→ 网站把 listing 去空间化
→ 手机把 listing 做到随身可查
→ 真实劳动争议仍发生在现实世界
→ 成熟系统重新给数字匹配补一个可找到人的物理责任节点
```

这就是本轮的 `matching/support split` 与重新捆绑。

## 8. 海外对照：电子分类信息也不是 Web 才出现

### 8.1 法国 Minitel：1986 年已经有“petites annonces”与临时工作服务

《Le Monde》1986 年 4 月对 Minitel 的同时代报道，把它描述为已经快速扩张的新媒介，并提到大量新服务持续出现。

同一时期的 Minitel 服务生态包括分类小广告、商业查询及临时工作相关服务。

**证据等级：A/B（1986 同期主流报刊；具体服务名称仍需继续寻找服务目录/终端截图交叉确认）。**

来源：

- Éric Le Boucher, “Le phénomène minitel…”, *Le Monde*, 1986-04-12  
  https://www.lemonde.fr/archives/article/1986/04/12/le-phenomene-minitel-en-1985-ce-n-etait-qu-un-pari-risque-en-1986-c-est-un-succes-industriel-et-commercial_3115720_1819218.html

因此：

> “把附近或日常的机会做成电子条目”并不是 World Wide Web 的独占发明。

### 8.2 Craigslist：甚至先是电子邮件名单，再变成 Web 分类市场

Craig Newmark 2004 年接受 *San Francisco Chronicle* 采访时回忆，自己 1994 年看到 WELL 与 newsgroups 上的人互相帮助，随后做了一个本地活动 CC 邮件名单；到 1995 年，人们开始要求加入工作、出售物品和公寓信息，名单增长后才换成 list server，并逐渐形成 Craigslist。

**证据等级：C/T2（创始人九年后回忆；可用于机制和大致次序，不应单独承担精确页面结构）。**

来源：

- SFGate, “CRAIGSLIST / On the record: Craig Newmark”, 2004-08-15  
  https://www.sfgate.com/business/ontherecord/article/CRAIGSLIST-On-the-record-Craig-Newmark-2733312.php

2003 年一篇被 Craigslist 保存的媒体报道还留下普通用户 Charlene Li 的具体例子：她早上发布免费搬家纸箱，十分钟后收到邮件询问，约二十分钟后对方开车取走。

**证据等级：B/T1（同期媒体中的个人使用案例；由 Craigslist 后来托管副本，来源链仍需注意）。**

来源：

- Craigslist press archive, “Net Idea”, 2003  
  https://www.craigslist.org/about/press/netidea

这与中国后来的分类信息形成共同机制：

```text
附近的人有一个很小的需求
→ 把需求写成机器可传输的条目
→ 陌生人通过地点/类别发现
→ 私下联系
→ 很快在线下完成
```

但中国 2000s–2010s 的 WAP、功能机、城市站/区县层级、商户认证、付费刷新/竞价排序及后来 QQ/微信导流，是需要单独研究的本地技术与商业路径。

## 9. 四种未来：同一个“找活”动作怎样改变含义

| 时段 | 典型时间感 | 本轮观察 |
|---|---|---|
| 2005–2012 扩张型未来 | “附近应该有越来越多机会可以被我找到” | 城市/区县分类、免费浏览搜索、WAP/智能手机入口，让住房、工作、家政、二手等被统一成可寻址条目；兼职可作为主业外增量 |
| 2015–2019 拥堵型未来 | “入口越来越多，我要同时管理多个收入和风险” | 主业 + 零工并存；排名、认证、信息真实性与平台竞争成为新的判断劳动 |
| 2020–2022 偶发型未来 | “主路径可能突然中断，我需要短期桥” | 零工可能充当失业/停业/等待期间的 holding state；本轮仍缺足够好的同期个人样本 |
| 2023–2026 防守型未来 | “有活还不够，我要确认这活是真的、钱能拿到、出事有人管” | 2024 调查暴露跨平台责任碎片；2026 规范零工市场把数字匹配与线下培训、候工、调解、维权重新捆绑 |

这个比较不等于“每个时代只有一种情绪”。同一年里仍然可以存在扩大收入的人、被迫过渡的人、主动组合主副业的人和只想获得一份稳定工作的求职者。

## 10. 对“普通人到底有多少种活法”的修正

这一轮至少增加六种不能被单一“职业”字段很好表示的生活状态：

1. **主业 + 周末/晚上零工**；
2. **两份正式工作之间的临时收入桥**；
3. **照护约束下只接就近、短时工作**；
4. **迁入陌生城市后先靠临时工维持生活，再寻找长期位置**；
5. **家庭把闲置空间、旧物或个人技能临时转换成现金缓冲**；
6. **长期以日结/短单为主要劳动方式，但需要线下权益与公共服务支持**。

这些状态说明：

> 一个人的“职业”与她这个月靠什么把生活接下去，不一定是同一个问题。

## 11. 与重点矩阵的交叉

| 矩阵维度 | 本轮新增观察 |
|---|---|
| 教育 | 学生/毕业生可能在正式就业前用短工填时间；但不能把招聘平台样本代表全体学生 |
| 就业 | 正式职业与零工收入可叠层；零工也可作为 re-entry 前的 holding state |
| 住房 | 2010 孙小姐把客厅变成出租资源，说明分类信息可把家庭空间变成预算缓冲 |
| 婚姻家庭 | 家庭责任可能决定可接受工作的地点与时间；本轮仍缺强第一人称链 |
| 迁移 | 新到城市者可以先通过短工/本地信息接起现金流；同时平台条目仍高度依赖城市与 neighborhood |
| 照护 | 家政/保洁既是家庭服务，也是大量本地劳动需求；未来需做专门照护劳动接口研究 |
| 非正规劳动 | 本轮主轴；必须区分临时劳动、平台零工、主副业叠层、无劳动关系的合作安排 |
| 长期中断 | 2024 个案显示零工可充当两份长期工作之间的桥 |
| 证件与记录 | 商户认证、实名认证、协议主体与真实雇主可能不是同一层 |
| 通信方式 | 路边/熟人/电话 → Web listing → WAP/App → 电话/IM → 微信/线下；不是单向替代 |
| 互联网平台 | 分类、城市索引、排名、刷新、竞价改变谁先被看见 |
| 信息获取 | 信息量扩大以后，真实性、时效和责任主体识别成为额外劳动 |
| 社交关系 | 陌生人匹配扩大；熟人介绍并未消失 |
| 未来预期 | 兼职可被理解为增量、缓冲或退路，而不只是不稳定 |
| 线上/线下身份 | listing 发布者、认证主体、联络人、签约方、支付方可能分离 |
| 平台消失与记忆 | listing 文本可能存活，真实工作是否发生、最终工资与责任链往往消失 |

## 12. 反例与后见之明风险

### 12.1 不要写成“Internet 发明了灵活就业”

劳动服务公司、职业介绍所、劳务市场、熟人和报纸广告早已组织临时劳动与职位信息。

### 12.2 不要写成“线上取代线下”

2009 现场招聘会、2026 零工市场都说明两者可以长期并存；成熟阶段甚至可能重新加强实体支持。

### 12.3 不要把平台合作调查当全国统计

2019 58 同镇合作调查只支持其样本内结论。平台参与、抽样方式和互联网可及性都可能影响样本。

### 12.4 不要把诈骗写成分类信息的本质

线下中介同样可能存在欺诈。2024 案例的真正价值是揭示**跨主体、跨渠道执行链怎样让责任变得难读**。

### 12.5 不要把“自由接单”浪漫化

短工可能意味着灵活，也可能意味着工作不连续、议价弱、社保与劳动关系模糊。需要把“为什么选择”与“还有什么现实替代”一起研究。

## 13. 已知 / 可推 / 不知道

### 已知

- 1980s 中国已经存在劳动服务公司等就业服务机构，临时用工与职业介绍并非数字时代新事物；
- 2009–2010 同期资料可以看到正式工作者考虑兼职、失业者继续依赖线下招聘会，以及普通租客在分类网站把住房空间转成成本缓冲；
- 2013 58.com 同期监管申报可确认城市/街区索引、分类、Web/WAP/App、多种联络方式、认证以及付费排名等平台结构；
- 2019 同期调查至少说明其县域样本中存在明显的“主业 + 零工”收入叠层；
- 2024 调查可确认部分兼职招聘链从平台向微信、线下公司与不同支付/签约主体迁移；
- 2026 公共零工市场正在把线上匹配与线下候工、培训、调解、权益服务组合起来。

### 可以合理推断

- 分类信息最重要的历史变化之一，是把本地机会从“必须在场/必须认识人”变成“可以按地点和类别检索”；
- 排名与竞价把物理市场中的“好位置”转写成数字列表的位置；
- 当匹配成本大幅下降以后，真实性与责任可读性会成为更显眼的瓶颈；
- 成熟期重新建设线下零工服务空间，是对“匹配很快但支持不足”的一种制度性补丁，而不是简单反数字化。

### 仍不知道

- 1990s 中国普通城市劳动者实际怎样在报纸广告、职介所、人才市场、BBS 与早期招聘网站之间组合求职；
- 2005–2008 58/赶集普通用户的原始帖子、站内联络和真实工作完成率；
- 功能机 WAP 对非 PC 用户的实际使用分布；
- 2009 金融危机期间“兼职意愿”有多少转化为真实兼职；
- 2020–2022 疫情中，哪几类人最常把零工当作短期 holding state；
- 数字 listing 与最终工资、工时、劳动关系、社保状态之间的可靠个体级连接数据。

## 14. 下一步若继续此线

优先级从高到低：

1. 找 1990s 城市职业介绍所/劳务市场的同期报刊或个人日记，重建 Web 前一天的求职流程；
2. 找 2005–2008 赶集、58、地方 BBS 的可核验 historical capture，尤其是招聘/家政/搬家分类页；
3. 找 2008–2010 普通求职者的论坛/博客第一人称，比较“网上看到 → 电话 → 面试/上工”完整链；
4. 找 2020–2022 疫情期间的普通零工个人叙事，补足“偶发型未来”；
5. 比较法国 Minitel petites annonces、Craigslist 与中国城市分类站：谁拥有 URL、谁排序、如何联系、是否需要实名/认证、如何处理旧 listing。

## 15. 本轮最重要的生活史结论

以前研究“工作”时，我们很容易只看那份最后写进简历、合同、社保记录和人口统计的职业。

这一轮显示，普通人的生活还由大量**小得不值得进入正式传记的工作与交换**接起来：

- 等正式入职前做三天会展；
- 周末给人补课；
- 下班后做促销；
- 家里租金涨了，把客厅再租给一个陌生人；
- 搬家前把旧物送掉；
- 生意停几周时临时找活。

Web 分类信息真正改变的，不只是“广告从报纸搬到网页”。它把一个城市里原本散落在劳务市场、公告栏、熟人圈和街边的细小机会，做成了可以按地点和类别查询的数据库。

可是当“看见机会”变得越来越容易以后，成熟阶段又把另一个问题暴露出来：

> **一条机会究竟是不是真的，最后是谁付钱，出了问题我要去哪里找一个真正负责的人。**

因此所谓生活选择的扩张，并不是列表里多出一万个岗位就完成了。真正的可选性还要求这条路从搜索结果一直连到现实里的工作、报酬和退出。
