# 在“上传”按钮以前：中文世界普通人怎样让一首歌离开自己身边（1940—1993）

## 范围

**地区：** 中文世界，重点分开观察中国大陆、台湾与香港；不同地区不假定同步发展  
**时间：** 1940—1993，重点落在 1970—1993，并向前追溯纸本歌曲、广播和群众音乐活动的基础设施  
**问题：** 在 BBS、个人主页、MP3 网站和音乐社区出现以前，一个没有唱片公司、没有职业歌手身份、也没有“上传按钮”的普通人，怎样把自己写的一首歌变成别人能够听到、唱到、记住的公共作品？

本文是 [《从拨号 BBS 到洛天依：中文世界普通人在线做歌的基础设施史（1993—2018）》](from-dialup-bbs-to-vocaloid-grassroots-online-music-making-chinese-world-1993-2018.zh-CN.md) 的前史。

1993 并不是“普通人开始创作”的年份。

互联网真正改变的，是一条早已存在几十年的链：

```text
写下一首歌
→ 找到能看懂它的人
→ 找到愿意唱的人
→ 找到可以录音或演出的地方
→ 找到编辑 / 电台 / 比赛 / 唱片公司 / 店铺
→ 被筛选
→ 被复制
→ 被分发
→ 收到反馈
→ 再写下一首
```

网络时代没有发明这条链，而是把其中越来越多的步骤从机构手中移到个人电脑和个人账号上。

因此，要理解 1990 年代以后“网友自己发歌”为什么会如此重要，必须先理解上传按钮以前的世界到底有多麻烦。

---

## 核心结论

### 1. “普通人可以写歌”从来不等于“普通人可以公开一首歌”

一首歌可以在宿舍、家庭、部队、学校、社团或朋友之间存在，却完全没有办法进入公共空间。

在模拟时代，创作者通常至少要跨过几个不同门槛：

```text
创作门槛
↓
记谱 / 保存门槛
↓
演唱者门槛
↓
录音或现场表演门槛
↓
编辑 / 比赛 / 电台 / 唱片公司门槛
↓
复制成本
↓
分销半径
↓
听众反馈回路
```

很多作品并不是“没人想写”，而是写完以后停在其中某一层。

### 2. 互联网以前，中文世界已经出现过多种“半开放投稿系统”

它们的界面不是网页，而可能是：

- 一本歌曲杂志的编辑部地址；
- 一个广播节目；
- 一场校园演唱会；
- 一张报纸上的征歌启事；
- 一个需要寄纸质乐谱的电台排行榜；
- 一个唱片公司办的学生创作比赛；
- 一家愿意寄卖几百盒自制卡带的小唱片店；
- 一个学校或单位内部的文艺汇演。

这些系统都允许“不是已经成名的人”进入公共音乐空间，但进入方式、成本和筛选强度差别非常大。

### 3. 最接近今天“投稿平台”的模拟机制，往往不是唱片公司，而是广播、比赛和小型出版

台湾 1970 年代的民歌广播、金韵奖；香港 1980 年代的自资卡带；大陆 1980 年代广东原创歌曲征集和电台排行榜，都提供了不同版本的“普通人把作品交给陌生听众”的路径。

其中大陆广东电台 1986—1987 年的“健牌”创作歌曲大赛尤其像一个纯模拟时代的平台：创作者寄来的主要不是录音，而是**纸上的歌词和乐谱**；编辑先“读歌”，入选后再安排录音，电台滚动播放，听众通过邮寄投票表格决定榜单。

这是一条几乎可以逐步映射到后来数字平台的链：

```text
寄稿
→ 审核
→ 制作
→ 上线（播出）
→ 曝光
→ 用户反馈（寄信投票）
→ 排名
```

区别在于，每一步都需要人工作业、物理邮递和机构资源。

### 4. 互联网真正带来的核心变化之一，是把“公开资格”与“机构选择”部分拆开

模拟时代的大多数路径仍然是：

> 你先被某个编辑、电台、比赛、商店或制作人接纳，陌生人才可能听见你。

网络时代逐渐变成：

> 你可以先把作品放出去，再看有没有陌生人愿意听。

这看起来只改变了顺序，实际上改变了大量作品是否有机会存在于公共记录中。

### 5. 但模拟时代也有一种网络时代未必保留的“近距离”

校园、小型演出、广播来信、卡带寄卖、地方音乐圈往往规模较小。

创作者和听众未必匿名；一个人可能在电台寄过信、在演出现场见过作者、在唱片小店买到乐队成员亲手送去寄卖的磁带。

所以不能把历史写成简单的：

> 技术越新，人和人就越近。

更准确的是：

> **模拟时代的传播半径小，但局部社会距离可能很短；网络时代传播半径巨大，同时又可能因为平台规模化重新把创作者与听众拉远。**

# 一、在录音以前：一首歌首先必须能被“写下来”

今天谈音乐创作，很容易默认作品首先是一个音频文件。

在大规模廉价录音之前，很多歌曲首先以另一种形式存在：

```text
歌词 + 曲谱
```

这意味着“让别人听见一首歌”往往并不是发送声音，而是发送一套足够让别人**重新把声音做出来**的信息。

创作者需要会记谱，或者至少找到能替自己记谱的人；接收者要能读谱；还要有歌手或群众重新演唱。

这使纸本歌曲产生一种很特殊的传播逻辑：

> 一首歌不是被完整复制，而是被反复重建。

同一张谱可以在不同学校、单位、合唱队、部队或家庭里被重新唱出来。

因此，在模拟时代研究“歌曲传播”，不能只找唱片销量。

还要找：

- 歌曲杂志；
- 歌集；
- 乐谱单页；
- 学校音乐课；
- 广播教唱；
- 群众合唱；
- 文艺汇演；
- 单位或社团演唱队。

# 二、大陆，1940s—1970s：刊物、广播和组织网络先构成“歌曲公共空间”

这里必须谨慎。

这一时期的中国大陆并不存在后来意义上的开放流行音乐市场，创作、传播和演出高度依赖文化机构、工作单位、学校、军队、文艺团体、广播系统和出版系统。

但这并不等于只有少数职业作曲家在写歌。

一个重要入口是**歌曲刊物**。

## 1. 音乐刊物在很早以前就承担“把作品变成可复制公共文本”的功能

中国文联资料对 1940 年代《新音乐》的回顾显示，这类音乐刊物面向青年学生与一般音乐爱好者，发行量一度达到数万份；歌曲、创作讨论和音乐知识通过纸本跨地域传播。

来源：

- 中国文艺网，〈抗战文艺——《新音乐》月刊〉：  
  https://www.cflac.org.cn/wywzt/2015/kangzhanwenyi/wenyizhenying/wyzd/gtq/201508/t20150826_305456.html

1949 年以后，歌曲刊物与广播进一步制度化。

中国音协早期工作回忆记载，1950 年代初已经存在大量以群众歌曲为主要内容的音乐刊物；中央和地方广播电台也会选择歌曲进行广播教唱。1950—1953 年间，包括《歌曲》《人民音乐》及大量地方歌刊在内的音乐出版物构成重要传播网络。

来源：

- 中国文艺网，吕骥：〈为发展和提高人民的音乐文化而努力〉：  
  https://www.cflac.org.cn/wdh/cflac_wdh-2th_Article-05.html
- 中国文艺网，孙慎访谈：〈一位音乐老人的历史记忆〉：  
  https://www.cflac.org.cn/zt/2009-09/10/content_17660819.htm

孙慎的回忆还提到，1949—1953 年间曾举行全国群众歌曲评奖，并出版获奖歌曲集。

这说明一个重要事实：

> **“业余或群众创作 → 编辑/评选 → 纸本出版 → 广播/群众演唱”的链条，在互联网以前几十年已经存在。**

但这里的“开放”不能用今天的平台想象。

它依赖强烈的编辑、组织与制度筛选。

## 2. 一本《歌曲》杂志可以同时是播放器、教程、曲库和投稿目标

对今天的人来说，一本只有纸张、没有音频的歌曲杂志似乎功能残缺。

但在会读谱、会唱歌、学校或单位有人会乐器的环境里，它可以承担很多今天由不同产品分别完成的功能：

```text
Spotify / 音乐平台：告诉你“有什么歌”
教程网站：告诉你“怎样写”
谱库：告诉你“怎样唱 / 奏”
社区声望：告诉你“谁的作品被发表”
投稿平台：提供进入公共传播的入口
```

后来的作者回忆里可以看到这种日常使用方式。

有人把《歌曲》称为自学作曲的“老师”；有人回忆自己作为业余曲作者，第一次在《歌曲》发表作品是一件极大的事情；还有人在偏远单位通过杂志分析调式、结构和旋律写法，自学歌曲创作。

这些回忆属于后见性个人证言，不能直接量化全国情况，但它们能够说明纸本歌曲杂志曾怎样进入普通学习者的创作生活。

参考：

- 《歌曲》创刊于 1952 年；东京艺术大学小泉文夫纪念资料室仍保存 1980 年代《歌曲》《音乐创作》等中国音乐期刊目录：  
  https://koizumi.geidai.ac.jp/collections/magazine/china/
- 关于业余作者与《歌曲》的回忆索引：  
  https://art.alljournals.cn/relate_search.aspx?aid=7F642C06FD0A755DFCC7E840243217A9&ctl=9&etl=0&language=0&pcid=AEE0F63FADC7DCDA

### 一个现代读者容易低估的门槛：你得能把脑子里的旋律变成纸

如果不会记谱，创作就很难离开自己的声音和记忆。

今天一个人可以：

```text
哼出来
→ 手机录音
→ 发给朋友
```

而过去经常需要：

```text
哼出来
→ 自己会简谱 / 五线谱，或找到会记谱的人
→ 把旋律固定下来
→ 交给另一个会读谱的人
→ 对方重新唱出来
```

因此“音乐识字能力”本身就是公共创作的基础设施。

# 三、台湾，1975—1980：广播把“素人寄来的歌”变成可以被陌生人听见的作品

台湾 1970 年代民歌运动特别重要，因为它提供了一条比传统唱片公司更接近“用户投稿”的模拟路径。

## 1. 电台先于唱片公司成为入口

国家文化记忆库关于陶晓清的资料记载，1975 年前后，她在广播节目中鼓励年轻听众和素人音乐人创作，并把作品寄到电台；作品经挑选后，在固定时段播出。

更重要的是，她并不只是“播放投稿”。

相关资料明确提到：

- 有的人会写歌；
- 有的人会唱歌；
- 广播主持人居中把人连接起来；
- 听众的意见又可以被转达给创作者。

来源：

- 国家文化记忆库，〈“民歌40”邀歌迷团聚〉：  
  https://tcmb.culture.tw/zh-tw/detail?id=624061&indexCode=Culture_Object
- 国家文化记忆库，〈陶晓清获第52届广播金钟特别贡献奖〉：  
  https://tcmb.culture.tw/zh-tw/detail?id=624071&indexCode=Culture_Object
- 台湾流行音乐资料库：陶晓清条目：  
  https://pmdb.taipei/xchisvideo/cont?roletpye=&sid=0P139655888635798746&xsmsid=0P077652866224904029

把这条链写成今天熟悉的语言，会很像：

```text
创作者投稿
→ 人工审核
→ 平台帮忙匹配演唱者 / 制作条件
→ 节目播出
→ 听众反馈
→ 创作者获得下一次机会
```

但所有步骤都通过邮政、电话、广播工作者和线下人际网络完成。

### 这里的“平台”其实是一个具体的人

网络平台把中介功能写进软件。

广播时代则可能把同样的功能集中在主持人、编辑或制作人身上。

一个有信誉的主持人可以同时承担：

- 发现作品；
- 筛选作品；
- 解释作品；
- 联系创作者；
- 联系演唱者；
- 向大范围听众播出；
- 收集反馈；
- 把优秀创作者介绍给演出和出版渠道。

因此，模拟时代的“算法”往往是**编辑判断 + 人际信誉 + 节目时段**。

## 2. “唱自己的歌”首先是一种创作资格的主张

1970 年代中期台湾民歌运动常被概括为“唱自己的歌”。

如果只把它理解成音乐风格变化，会漏掉一个普通生活史层面的变化：

> **学生与普通青年开始把“我自己的经验也可以成为一首正式歌曲”当成一件可以公开实践的事情。**

1975 年杨弦的现代民歌演出、1976 年前后的校园民歌事件、广播推动，以及后来的比赛和唱片出版共同扩大了这个空间。

国家文化记忆库对校园民歌的概述明确指出，1970 年代出现“用自己的语言与音乐风格创作属于自己的歌曲”的创作观念。

来源：

- 国家文化记忆库，〈校园民歌〉：  
  https://tcmb.culture.tw/zh-tw/detail?id=128957&indexCode=Culture_Object
- 国家台湾历史博物馆藏《金韵奖纪念专辑》说明：  
  https://tcmb.culture.tw/zh-tw/detail?id=11000037675&indexCode=MOCCOLLECTIONS

# 四、台湾，1977 起：比赛把“投稿—筛选—录音—出版—电视”串成产业入口

广播让素人创作被听见，但还没有解决大规模复制和持续发行。

金韵奖开始把另一套机构接进来。

台湾流行音乐资料库记载，金韵奖 1977 年首次举办，核心目标之一就是鼓励年轻人“自己创作、自己演唱”，参赛对象以大专院校学生为主，原创新作为主要内容。

得奖者可以获得奖金，并可能被唱片公司签下；比赛作品又通过合辑、个人专辑与电视节目继续传播。

来源：

- 台湾流行音乐资料库，金韵奖：  
  https://pmdb.taipei/awards/intro/0p091607311104826321
- 国家文化记忆库，《金韵奖纪念专辑》藏品说明：  
  https://tcmb.culture.tw/zh-tw/detail?id=11000037675&indexCode=MOCCOLLECTIONS

这条链已经非常成熟：

```text
学生写歌
→ 报名比赛
→ 现场 / 评审筛选
→ 专业编曲与制作
→ 唱片
→ 电视节目
→ 广播
→ 歌本 / 简谱
→ 校园继续传唱
```

特别值得注意的是，唱片附赠简谱。

这意味着作品并没有停在“听唱片”这一种消费方式。

听众还可以拿到可以自己弹、自己唱的结构化文本。

所以一首歌同时存在于：

- 唱片；
- 广播；
- 电视；
- 乐谱；
- 校园现场；
- 吉他弹唱；
- 朋友之间的口头传唱。

这是一种典型的**多介质模拟传播**。

# 五、模拟时代的开放不是“任何人都能发”：谁仍然被挡在门外？

台湾民歌路径常让后人觉得很浪漫：学生拿一把吉他，写自己的歌，然后就被时代听见。

但必须拆开实际条件。

一个人至少更容易成功，如果他拥有：

- 大专院校或城市文化资源；
- 乐器；
- 会和弦、会记谱或有人帮忙；
- 能到演唱会 / 比赛现场；
- 能把作品寄到电台；
- 有足够空闲时间排练；
- 有同学、老师或社团网络；
- 风格与节目、比赛接受范围有一定重合。

“学生创作变多”不等于所有青年都具有相同进入机会。

农村、低收入、非学生、缺乏乐器与音乐教育的人，其创作留下公共记录的概率仍然更低。

这正是 How People Lived 需要保留的分布差异。

# 六、香港，1983—1990s 初：当唱片公司不接你，卡带让“自己出版”变成可能

台湾 1970 年代的路径仍然高度依赖广播、比赛和唱片公司。

香港 1980 年代独立音乐则提供另一种重要答案：

> **如果没有机构愿意替你出版，你能不能自己把作品做成商品？**

## 1. 黑胶太贵，卡带成为可承受的小批量介质

乐评人袁智聪对香港 1980 年代独立音乐的回顾指出，当时本地缺乏稳定的独立唱片厂牌，许多乐队若不想等待主流唱片公司的“伯乐”，就选择自资出版。

黑胶需要制作金属母盘、印制成本高；卡带则明显便宜。

于是 1980 年代中后期，香港形成一段可以称为“自资卡带纪元”的历史。

来源：

- 袁智聪，〈香港独立音乐自资卡带纪元：唱自己的歌，制作自己的梦想〉，原刊《阳光时务》，中国数字时代转载：  
  https://chinadigitaltimes.net/chinese/285808.html

1984 年黑鸟乐队自资出版《东方红／给九七代》；1986 年 Beyond 自资出版《再见理想》。后来还有多支地下和独立乐队采用类似方式。

### 卡带降低的不是创作成本，而是“复制一批成品”的最低规模

黑胶时代，一个小乐队可能根本承担不起生产门槛。

卡带则让下面这种流程可执行：

```text
自己写歌
→ 筹钱录音
→ 做母带
→ 找卡带厂复制几百盒
→ 自己设计 / 复印封面
→ 自己送货
→ 在小唱片店、楼上书店寄卖
→ 演出现场卖
```

这已经非常接近后来 DIY 音乐文化的基本精神。

但它仍然有强烈的物理负担：

- 每多一个听众，就真的需要多一盒磁带；
- 需要印刷或复印包装；
- 需要库存；
- 需要拿货和送货；
- 店铺不愿意进货时只能自己找寄卖点；
- 销量只有几百盒时，大型批发体系往往没有兴趣。

因此，“发行”仍然是一种体力劳动。

---

## 2. 独立发行把音乐人的工作向外扩张

在唱片公司体系里，音乐人可以只负责某些创作或演出环节。

自资卡带意味着一个小团队可能同时变成：

```text
乐队
+ 制作人
+ 筹款者
+ 封面设计
+ 复制委托方
+ 库管
+ 批发 / 寄卖联系人
+ 演出组织者
+ 售货员
```

这和后来个人网站时代“一个人同时是作者、站长、运营、客服”非常相似。

技术降低某些门槛时，常常不是消灭劳动，而是把原来由机构完成的劳动转移给个人。

---

## 3. Beyond 的早期路径说明：“先自己发行，再被产业看见”在网络以前就存在

袁智聪的回顾提到，Beyond 在 1985 年自资举办专场演出，之后决定自资录制和出版《再见理想》；这套自制作品后来又成为他们被经纪体系注意并进入更大音乐工业的一部分。

这和 1999 年以后网络音乐平台出现的逻辑非常相似：

```text
不是：
先签约 → 才能有作品

而是：
先自己留下作品和受众 → 再被产业看见
```

所以“先发布，再被选中”并不是互联网发明的。

互联网真正改变的是：让这种路径不再需要先印几百盒实体介质。

---

# 七、大陆，1980—1985：校园、单位、比赛与电视首先提供“表演入口”

中国大陆改革开放初期的音乐公共空间和港台并不相同。

大量表演者仍隶属专业或半专业文艺团体；学校、单位、广播电视机构和大型比赛仍是重要入口。

但 1980 年代出现了越来越多让学生、青年与“业余组”进入公共舞台的渠道。

## 1. 校园演唱活动先让普通学生获得舞台

北京广播学院校史记载，1985 年首届“广院之春”学生歌手大奖赛共有 39 名学生歌手参赛，演唱类型包括校园歌曲、流行歌曲、民歌等，现场有一千余名学生观看；此后活动连续举办。

来源：

- 中国传媒大学档案馆：〈校史撷英（二十二）——广院之春的创办〉：  
  https://archive.cuc.edu.cn/2023/1008/c8243a212351/page.htm

这类校园比赛的重要性不一定在于“产生原创歌曲”，而在于它形成一个低于职业舞台的公开层级：

```text
宿舍 / 班级
→ 校园舞台
→ 校际活动 / 地方电视
→ 更大的音乐系统
```

它让“唱歌”从私人爱好变成一种可以被看见、被评比、被记住的校园身份。

---

## 2. 1984 年青歌赛把“业余组”放进全国电视体系

中央电视台 1984 年创办全国青年歌手电视大奖赛，早期比赛设置专业与业余参与者，并通过电视把青年歌手推向全国受众。

来源：

- CCTV，历届青歌赛回顾：  
  https://sports.cctv.com/specials/music2000/dsbd/dsbd001.html
- CCTV，第一届青歌赛资料：  
  https://www.cctv.com/qgds/qingge/13/03/index.shtml

这仍然主要是**歌手发现系统**，并不是开放歌曲投稿平台。

但它对普通音乐生活史非常重要，因为电视第一次让“地方选拔出来的青年歌手”能够进入全国统一的可见空间。

对一名 1980 年代青年而言，“我唱得好”开始出现一条比加入固定文艺团体更可想象的公开路径。

---

# 八、大陆，1985：广东“红棉杯”把原创流行音乐明确推到公共评选中

1985 年广州举办“红棉杯新歌新风新人大奖赛”。国家版权局和人民网的回顾都把它视为大陆原创流行音乐发展中的重要节点。

来源：

- 国家版权局：〈李海鹰：音乐创作与保护同等重要〉：  
  https://www.ncac.gov.cn/xxfb/yjdt/201901/t20190108_49428.html
- 人民网：〈摸着石头过河闯出流行音乐原创时代〉：  
  https://ip.people.com.cn/n1/2018/1101/c179663-30376105.html

“红棉杯”评选“羊城十大新歌”和歌手，推动一批词曲作者与歌手进入更大的流行音乐体系。

这里的关键不是比赛本身，而是一个新问题获得了正式公共位置：

> **不是“谁唱已有的歌最好”，而是“这座城市今年有什么新的歌”。**

当“新歌”本身成为竞赛对象，创作者的身份开始获得比以往更明确的公开价值。

---

# 九、大陆，1986—1987：一套几乎就是“模拟投稿网站”的电台系统

这一段是整个前互联网史里最值得保留的案例之一。

人民网根据《广东广播报》和音乐人回忆整理的资料显示，广东电台从 1986 年 7 月开始为“健牌”广东创作歌曲大赛向全省征歌：

- 收到 400 多首作品；
- 初审选出 32 首；
- 1987 年元旦开始在广东台滚动播放；
- 听众投票选出最喜欢的作品；
- 后来又扩展成京、沪、粤之间的创作歌曲比赛。

来源：

- 人民网：〈摸着石头过河闯出流行音乐原创时代〉：  
  https://ip.people.com.cn/n1/2018/1101/c179663-30376105.html

最有价值的细节是：

> **最初投稿的往往不是录好的小样，而是写在纸上的歌词与曲谱。**

评委先“读歌”，筛出一部分后，再安排录音。

这意味着一个 1986 年的创作者可能经历：

```text
1. 在纸上写歌词和曲谱
2. 找到征歌信息
3. 邮寄作品
4. 等待编辑部收件
5. 编辑 / 评委读谱
6. 作品入选
7. 平台组织录音
8. 电台播出
9. 听众从报纸或广播得知投票方式
10. 听众寄回纸质票
11. 榜单统计
12. 作品继续获得演出或出版机会
```

如果把它和 2000 年代音乐网站并排，就会发现：

| 1986 广播系统 | 2000s 音乐网站 |
|---|---|
| 邮寄乐谱 | 上传音频 |
| 编辑收件 | 服务器接收 |
| 人工读谱 | 审核 / 分类 |
| 机构安排录音 | 创作者自己录好 |
| 广播时段 | 页面 / 推荐位 |
| 邮寄投票 | 点击、收藏、评论 |
| 季度榜单 | 实时排行榜 |
| 报纸刊投票表 | 网页界面 |

技术变化最大的地方之一，就是**反馈延迟**。

今天一首歌发出几分钟后就可能有评论。

当时一个完整反馈回路可能需要数周甚至一个季度。

---

# 十、前互联网时代，创作者和听众怎么“认识”彼此？

没有用户名、主页和评论区，并不意味着创作者与听众完全无法形成关系。

只是连接对象不同。

## 1. 广播：地址与来信替代用户名

广播节目可以形成一种长期听众共同体。

听众记住的是：

- 主持人名字；
- 节目名称；
- 固定播出时间；
- 通信地址；
- 经常出现的创作者姓名。

如果节目读信、转达意见或安排创作者参与，听众就可能形成持续关系。

这是一种**以节目为中心的社交图谱**，而不是以个人账号为中心。

## 2. 校园：学校和社团替代平台主页

一个校园创作者的身份可能被绑定到：

```text
某大学
+ 某系
+ 某社团
+ 某场演出
+ 某次比赛
```

别人不是通过搜索用户名找到他，而是通过“那个学校唱那首歌的人”来记忆。

## 3. 卡带：实体物和演出现场替代持续在线主页

香港独立乐队把自资卡带送到唱片店、书店或演出现场销售。

作品本身就是联系方式的载体。

一个人可能因为在小店买到一盒磁带、看过一场演出，才进入某个地下音乐圈。

这种关系的传播半径很小，却可能非常具体。

---

# 十一、为什么卡式录音机本身是一个创作基础设施

前互联网时代还有一个容易被忽略的技术变化：**普通人开始能在家里反复录音和复制声音。**

即使没有专业多轨录音，家用卡式录音机也改变了几件事：

- 演唱可以被留下来；
- 可以反复听自己哪里唱错；
- 可以把一段 demo 给朋友听；
- 可以复制一份给另一个人；
- 现场演出可以被非正式记录；
- 一首歌第一次不必依赖记谱才能离开作者本人。

这一步非常接近后来手机“语音备忘录”的意义。

但复制仍然有代价：

```text
复制 1 份 = 再录一次 / 双卡复制
复制 100 份 = 时间 + 空白带 + 设备 + 包装
```

数字文件的真正革命之一，就是复制成本接近零。

---

# 十二、模拟时代为什么会筛掉大量“很小的歌”？

这正好回到我们从洛天依讨论开始的问题。

为什么 2010 年代中文网络音乐会留下那么多：

- 毕业；
- 一场考试；
- 一段没有结果的关系；
- 一个网络梗；
- 极私人情绪；
- 只有圈内几十个人真正懂的东西？

答案之一是：**发表成本下降以后，题材不再需要证明自己“值得占用稀缺公共资源”。**

模拟时代的广播时段、唱片面数、杂志页数、录音棚时间、卡带库存和店铺货架都是真正有限的。

一个编辑面对几十页篇幅，必须删。

一个电台一天只有 24 小时。

一张唱片只能放有限曲目。

一家小店只能摆有限库存。

因此，很多极私人、极局部、极实验的歌曲会在“值不值得花资源复制它”这一层被挡住。

网络时代的意义并不是让所有作品都有人听。

而是：

> **一首作品可以先存在，再证明它有没有听众。**

这与模拟时代经常相反。

---

# 十三、把四种时代放在一起：公共创作资格怎样被逐层拆开

## 阶段 A：纸本歌曲

```text
我写歌
→ 我必须把它记成别人能读的谱
→ 编辑愿意发表
→ 读者自己唱出来
```

主要门槛：

- 记谱；
- 编辑；
- 印刷；
- 发行。

## 阶段 B：广播 / 比赛

```text
我写歌
→ 投稿 / 比赛
→ 机构筛选
→ 找歌手和录音条件
→ 广播 / 电视
→ 听众写信反馈
```

主要门槛：

- 机构入口；
- 节目时段；
- 制作资源；
- 地理位置。

## 阶段 C：自资磁带

```text
我写歌
→ 我自己录
→ 我自己付复制成本
→ 我自己找店寄卖 / 演出销售
```

主要门槛：

- 钱；
- 录音设备；
- 实体复制；
- 库存；
- 分销。

## 阶段 D：网络投稿

```text
我写歌
→ 我自己录 / 合成
→ 上传
→ 作品立即拥有一个公共地址
→ 陌生人可以直接听
```

主要门槛逐渐转向：

- 设备与软件；
- 制作技能；
- 带宽；
- 平台发现机制；
- 注意力竞争。

网络并没有让门槛消失。

它把**复制与分销门槛**大幅降低，同时把新的**可见性门槛**推到前台。

---

# 十四、一个最重要的变化：从“先被选中”到“先留下来”

模拟时代大多数公共路径都是：

```text
创作
→ 被编辑 / 比赛 / 电台 / 唱片公司选中
→ 才留下公共记录
```

网络时代逐渐允许：

```text
创作
→ 先留下公共记录
→ 再决定有没有人看见
```

这对历史研究影响巨大。

过去失败的投稿，往往只存在于编辑部废纸、退稿信、私人抽屉或已经丢失的卡带里。

网络时代失败的投稿，至少有机会留下：

- 一个页面；
- 一个用户名；
- 一个发布时间；
- 几条评论；
- 一个播放量；
- 一段后来还能被搜到的痕迹。

所以网络不仅改变了创作，也改变了**普通失败如何进入历史**。

---

# 十五、但历史又出现第二次消失：数字平台并不等于永久档案

前互联网时代的作品会因为：

- 纸张损坏；
- 磁带消磁；
- 机器坏掉；
- 小店关门；
- 私人收藏丢失；
- 广播母带被覆盖；

而消失。

网络作品则会因为：

- 网站关闭；
- 外链失效；
- 账号删除；
- Flash 失效；
- 音频平台迁移；
- 版权清理；
- 数据库不再维护；

而消失。

因此我们不应该把网络时代想成“终于什么都保存下来了”。

更准确的是：

> **传播门槛下降了，但保存责任从机构档案逐渐分散到平台、个人硬盘、搜索引擎、转载者和偶然的互联网档案。**

# 十六、三个地区的不同路径

## 台湾

比较清楚的链条是：

```text
校园 / 吉他 / 自作曲
→ 广播投稿与主持人中介
→ 演唱会
→ 金韵奖 / 民谣风
→ 唱片与电视
→ 1980s–1990s 音乐产业
→ BBS / Web
```

特点：学生创作、广播人与唱片公司之间较早形成连续入口。

## 香港

比较清楚的链条是：

```text
乐队 / 地下演出
→ 自资演出
→ 自资卡带
→ 小店 / 书店寄卖
→ 被经纪或主流工业看见，或持续地下发行
→ 1990s–2000s Web
```

特点：高商业化主流唱片市场旁边，形成成本很高但自主性强的小规模 DIY 物理发行。

## 中国大陆

比较清楚的链条是：

```text
刊物 / 单位 / 学校 / 文艺团体
→ 地方演出与广播
→ 1980s 学生和青年比赛
→ 原创新歌评选
→ 电台征歌与排行榜
→ 1990s 唱片 / 校园民谣 / 摇滚
→ 1990s 后 BBS / Web
```

特点：早期公共音乐空间更依赖组织与广播体系；1980 年代以后“原创歌曲”和业余表演者逐渐获得更多独立可见性。

这些路径最终在互联网汇合，但它们的前史并不一样。

# 十七、这条历史对 How People Lived 最重要的不是“音乐史”，而是普通人的公共表达史

如果只把这些材料写成音乐风格演变：

```text
民歌
→ 摇滚
→ 校园民谣
→ 网络歌曲
→ VOCALOID
```

会丢掉真正重要的问题。

How People Lived 更应该问：

### 你有一个想法以后，现实世界允许你做什么？

- 家里有没有乐器？
- 会不会记谱？
- 有没有录音机？
- 能不能借到排练室？
- 学校有没有演出？
- 城市有没有广播节目收歌？
- 投稿地址在哪里知道？
- 邮票多少钱？
- 一盒空白带多少钱？
- 录音棚多少钱？
- 最少必须复制多少盒？
- 哪家店愿意寄卖？
- 如果没人选中，作品还剩下什么？

这些问题比“某年出现某种音乐风格”更接近日常生活。

# 十八、一个可复用的“普通创作者可执行性”模型

以后研究任何年代的民间文化创作，都可以拆成下面几层。

## 1. idea executability

我有一个想法，能否把它固定下来？

- 纸；
- 记谱；
- 录音；
- 摄影；
- 打字；
- 数字文件。

## 2. production executability

我能否把半成品做成别人愿意接收的成品？

- 演唱者；
- 乐器；
- 排练空间；
- 录音棚；
- 调音；
- 剪辑；
- 软件。

## 3. publication executability

我能否让作品获得一个公共入口？

- 编辑部；
- 比赛；
- 广播；
- 唱片；
- 小店；
- 网站；
- 平台账号。

## 4. discoverability

陌生人为什么会知道它？

- 节目时段；
- 海报；
- 报纸；
- 店铺货架；
- 榜单；
- 论坛；
- 推荐算法。

## 5. identity persistence

别人听完以后，还能不能找到“这个人”？

- 真名；
- 学校 / 单位；
- 通信地址；
- 唱片署名；
- 固定 ID；
- 用户主页。

## 6. feedback latency

创作者多久能知道别人怎么想？

```text
演出现场：几秒
广播来信：几天到几周
杂志读者信：数周到数月
唱片销量：数月
BBS 回帖：小时到天
视频评论：分钟
实时群聊：秒
```

“创作者和听众离得近不近”，可以被拆成这些具体变量，而不是一句抽象文化判断。

# 十九、我们知道什么

- 1940—1950 年代，中文音乐刊物、歌集、广播和群众音乐活动已经构成跨地域歌曲传播网络；纸本乐谱是重要媒介。
- 1950 年代中国大陆的音乐机构和广播系统大量出版、广播群众歌曲，并举办歌曲评选；业余创作者存在，但公共传播仍高度依赖组织与编辑体系。
- 台湾 1975 年前后，广播节目明确鼓励素人把自己创作的歌曲寄到电台，经选择后播放，并在创作者、演唱者和听众之间进行中介。
- 1977 年起金韵奖等比赛把学生原创歌曲与专业录音、唱片、电视和产业签约连接起来。
- 香港 1980 年代独立乐队因黑胶制作昂贵、独立厂牌不足，大量采用小批量自资卡带出版并亲自寄卖；黑鸟与 Beyond 是标志性案例。
- 中国大陆 1985 年“红棉杯”把原创流行歌曲作为正式公共评选对象；1986—1987 年广东电台创作歌曲排行榜通过纸质词谱征稿、机构录音、广播播放和邮寄投票形成完整反馈链。
- 1984 年后电视歌手比赛和各地校园歌唱活动扩大了青年和业余表演者进入公共舞台的路径。

# 二十、我们可以合理推断什么

- 在模拟时代，限制普通创作者的往往不是“能不能想出一首歌”，而是记谱、演唱、录音、复制、机构选择和实体分销的组合成本。
- 广播主持人、杂志编辑、比赛组织者和唱片小店在前数字时代承担了后来部分由平台软件承担的功能：收稿、审核、推荐、身份确认、反馈和连接合作伙伴。
- 卡带的低成本复制对 1980 年代独立音乐具有类似后来 MP3 的意义，但仍受库存、运输和寄卖限制，复制成本并未接近零。
- 固定网络账号出现以前，创作者身份更常与学校、单位、节目、演出、唱片署名和通信地址绑定。
- 网络时代最重要的变化之一，不只是“传播更快”，而是允许作品在获得机构认可之前先留下公共痕迹。

# 二十一、我们还不知道什么

这篇仍然不是这条历史的真正起点。

需要继续补的前史包括：

- 1920—1940 年代上海、香港等城市的歌刊、广播、唱片和业余词曲投稿，普通人与职业音乐工业之间到底隔着多远；
- 1940—1970 年代大陆地方歌刊和广播节目具体如何接收业余作者作品，退稿、修改、署名与稿酬机制如何；
- 台湾 1950—1960 年代广播、电台歌唱比赛和歌厅体系是否已经存在较稳定的素人创作入口；
- 香港 1960—1970 年代学校乐队、青年乐队和早期本地摇滚怎样获得演出与录音机会；
- 澳门、新加坡、马来西亚等其他中文音乐网络如何与港台唱片、广播和本地创作者连接；
- 家用录音机、空白磁带、吉他、电子琴和录音室价格相对青年收入的实际负担；
- 前互联网时期大量未正式出版 demo、校园录音、广播投稿带如今保存在哪里；
- 失败投稿和没有被选中的作品几乎没有留下记录，这会让历史严重高估成功进入机构的人。

尤其值得警惕的是**幸存者偏差**：

今天最容易查到的，是后来成名的音乐人、得奖作品、正式唱片和机构档案。

最接近普通生活的那一层——没得奖的歌、没签约的人、只复制几十盒的磁带、只在宿舍和社团唱过的作品——反而最容易彻底消失。

## 一句话总结

> **互联网没有让普通人第一次开始写歌。它真正改变的是：过去一首歌必须先找到编辑、电台、比赛、录音棚、卡带厂或唱片店，才有机会进入公共世界；后来，越来越多这些步骤变成了一个人在自己的设备前就能执行的动作。**

而这条变化，正是“普通人何时获得公共创作能力”的一部分生活史。
