# “标准人生”与真实生命历程：主流脚本到底是什么？

> 本文不是要证明“主流人生是假的”，也不是要把非主流生活浪漫化。
>
> 更准确的问题是：**一种社会广泛认可、制度上容易识别的人生脚本，与真实人口中高度分化、可逆、断裂、重叠的生命历程之间，究竟是什么关系？**

## 1. 先区分四件经常被混在一起的东西

研究“标准人生”时，至少要区分：

1. **规范性脚本（normative script）**：一个人“应该”在什么年龄做什么；
2. **制度化路径（institutional pathway）**：学校、劳动市场、婚姻、住房、养老等制度为哪些转变提供了明确接口；
3. **人口中的常见路径（modal pathway）**：真实人口中有多少人按某种顺序经历这些事件；
4. **个人传记（biography）**：某个人实际上怎样生活，其中会有中断、返回、重叠、例外和无法归类的时期。

这四者不能互相替代。

某条路径被社会认为“正常”，不等于多数人完整走过它。

某条路径在人口统计上常见，也不等于每个环节都被个人主动选择。

某项制度为结婚、就业或退休建立了清晰节点，也不等于节点之间的人生就是线性的。

## 2. 中国语境里，确实存在一条非常清楚的线性成年脚本

中国青年研究中甚至有非常直接的表述。

中国青年网转载的青年发展理论文章在介绍传统“过渡理论”时，将经典线性模型概括为：

> 学习 → 就业 → 组建婚姻家庭 → 生儿育女

其特点是阶段之间顺序固定、连续、可预期；文章随后专门指出，现实青年发展已经出现不连续、非线性、可逆和“去标准化”的趋势。

来源：

- 中国青年网，《青年发展研究中的过渡理论：反思与超越》，2017：<https://qnzz.youth.cn/zhuanti/kszt/fzlt13/04/201712/t20171206_11112468.htm>

这条线性模型与日常经验中的“好好读书 → 上大学 → 找稳定工作 → 买房/成家 → 结婚 → 生孩子 → 抚养下一代 → 退休”高度重合。

这里应当注意：“稳定工作”“买房”等并不是所有生命历程理论的必要事件，但在当代中国城市中产叙事里经常与成年资格、婚姻能力和成功想象绑定，因此值得单独研究。

## 3. 政策本身也会把人生分成可治理的阶段

《中长期青年发展规划（2016—2025年）》将青年生活分别组织为教育、就业创业、婚恋、健康、文化、社会融入、权益保护、社会保障等政策领域。

在婚恋部分，文件明确讨论婚恋观、家庭观、婚恋交友和婚育服务；在就业部分，则讨论高校毕业生就业、职业培训、青年农民工、长期失业青年、灵活就业与新就业形态。

来源：

- 中国政府网，《中长期青年发展规划（2016—2025年）》：<https://app.www.gov.cn/govdata/gov/201704/14/402865/article.html>

这个文件很适合说明一个重要区别：

**制度化不等于制度只承认一种人生。**

国家规划确实把教育、工作、婚恋、家庭视为青年发展的核心领域，但同一份文件也明确承认农村未升学青年、长期失业青年、青年农民工、残疾青年、流浪未成年人和灵活就业者等不同位置。

因此，研究时不要把“主流脚本”粗暴写成“官方只允许一种人生”。更准确的说法是：

> 某些节点拥有更强的制度可见性、公共服务、社会评价与家庭期待，因此更容易成为衡量一个人“走到哪一步”的坐标。

## 4. 为什么“上大学”会成为如此强的默认想象？

因为教育扩张确实使较长时间在校学习成为越来越普通的经历。

教育部发布的 2025 年全国教育事业发展统计公报显示：

- 九年义务教育巩固率：96.1%；
- 高中阶段毛入学率：92.0%；
- 高等教育毛入学率：61.3%。

来源：

- 教育部，《2025年全国教育事业发展统计公报》：<https://www.moe.gov.cn/jyb_sjzl/sjzl_fztjgb/202607/t20260706_1442870.html>

但这里必须特别谨慎。

**高等教育毛入学率 61.3% 不等于“61.3% 的这一届年轻人都上了大学”。** 毛入学率使用高等教育在校人数与相应年龄组人口计算，允许年龄错位。

它真正能证明的是：高等教育已经从少数人的特殊道路变成大规模人口制度。

也正因为如此，今天人们更容易把“中学 → 大学 → 毕业就业”当成自然时间表。

可是即使在高度普及化以后，也不能把“高等教育规模很大”偷换成“所有人都沿这条路生活”。

## 5. 学术研究里，“长时间学习 + 稳定就业”也只是多个轨迹中的一个

Wang 与 Zhao 使用 CHARLS 2014 年生命史资料，对 19,002 名出生于 1930—1979 年的人进行多通道序列分析，将 16—30 岁的教育—就业生命历程分成四类：

1. 低教育 + 农业就业；
2. 较长学习 + 农业就业；
3. 较长学习 + 稳定非农就业；
4. 长期未就业。

在整个样本中：

- “低教育 + 农业就业”占 49.37%；
- “较长学习 + 稳定就业”占 26.76%；
- “较长学习 + 农业就业”占 18.83%；
- “未就业”占 5.03%。

到了样本中最年轻的 1970—1979 出生队列，“较长学习 + 稳定就业”增加到 38.97%，而“低教育 + 农业就业”下降到 35.25%。

来源：

- Dianxi Wang & Yufeng Zhao, “A potential new pattern of pathway to adulthood is emerging in China,” *Demographic Research* 44 (2021): <https://www.demographic-research.org/volumes/vol44/42/44-42.pdf>

这份研究不能直接代表 1990 后、2000 后或 2026 年青年；它研究的是更早的历史队列。

但它非常适合说明一个方法问题：

**即使一个后来越来越强势的路径成为“现代主流”，它在真实生命史中仍然只是若干聚类中的一类。**

## 6. 家庭形成的标准顺序也正在松动

同一研究把家庭生命历程分为：

- 早婚、多子女；
- 婚姻 + 两个孩子；
- 婚姻 + 少子女；
- 较长时间保持单身。

“较长时间保持单身”轨迹占总体样本 32.67%，并且在较年轻队列、城市居民等群体中更明显；研究者将其视为成年转变时间推迟和生命事件顺序规范性降低的一部分。

近年的定性研究还进一步发现，不只有“应该几岁结婚”的年龄规范，人们还受到“恋爱多久应该结婚”“结婚多久应该生孩子”这类**持续时间规范**影响。

来源：

- Wang & Zhao 2021，同上。
- Xijia You, “Beyond age norms: Duration as a normative structure in family formation transitions in contemporary urban China,” 2026: <https://journals.sagepub.com/doi/10.1177/0961463X261422527>

这说明主流脚本不仅规定“做什么”，还经常隐含规定：

- 什么时候做；
- 按什么顺序做；
- 在一个阶段停多久才算“正常”。

于是，一个 28 岁未婚者受到的压力，不一定来自法律或经济制度，而可能来自一种时间表：

> “你怎么还停在这里？”

## 7. 主流脚本最容易制造的错觉：把人口分类当成人生本身

统计表为了可计算，必须把人放进离散类别：

- 在校 / 不在校；
- 就业 / 失业；
- 农业 / 非农业；
- 已婚 / 未婚；
- 有子女 / 无子女。

但真实人生经常同时处于多个状态。

比如一个人可以：

- 白天有正式工作，晚上跑外卖；
- 已经大学毕业，又重新回到学校；
- 有工作，却每三个月换一次城市；
- 名义上“失业”，但靠日结和散工维持生活；
- 已婚，但长期与配偶跨城生活；
- 与父母同住，同时经济上完全独立；
- 名义上“退休”，实际上仍持续劳动。

统计分类没有错。

错误发生在研究者把这些分类直接想象成完整生活。

## 8. “稳定就业”也并不意味着统一的朝九晚五生活

2025 年国家统计局数据显示，全国企业就业人员周平均工作时间为 48.6 小时。

来源：

- 国家统计局，2025 年国民经济运行数据：<https://www.stats.gov.cn/sj/xwfbh/fbhwd/202601/t20260119_1962330.html>

同时，人力资源和社会保障系统 2024 年公开资料称，中国灵活就业人员规模已达约 2 亿人；2025 年全国农民工总量为 30,115 万人，其中外出农民工 18,006 万人。

来源：

- 中国就业网 / 人社部，《规范零工市场 优化就业服务》：<https://chinajob.mohrss.gov.cn/c/2024-04-10/402285.shtml>
- 国家统计局，《2025年农民工监测调查报告》：<https://www.stats.gov.cn/sj/zxfb/202604/t20260430_1963472.html>

这些数字不能简单相加，也不能互相排斥，因为“灵活就业”“农民工”“企业就业人员”是不同统计口径且可能交叉。

它们真正告诉我们的是：

**当代中国的劳动世界本身就远比“毕业后进入一个单位，然后一直工作”复杂。**

## 9. 主流脚本为什么仍然如此强？

即使现实已经高度多样化，标准人生仍然有很强的心理和社会力量。

可能的原因包括：

### 9.1 制度节点清楚

学校有毕业证，工作有合同，婚姻有登记，住房有产权，退休有年龄和养老金。

这些节点比“我在三个城市做了五年散工”更容易被制度记录。

### 9.2 家庭容易用节点判断进度

“毕业了吗？”

“工作稳定了吗？”

“买房了吗？”

“结婚了吗？”

“什么时候要孩子？”

这些问题实际上构成了一种民间生命历程检查表。

### 9.3 媒体叙事偏好完整弧线

新闻和人物报道更喜欢：

> 困难 → 奋斗 → 获得稳定位置

而不是：

> 干了半年 → 停了三个月 → 去另一个城市 → 又回来 → 没有最终结论。

因此，那些没有“结局”的人生阶段更容易从公共叙事中消失。

### 9.4 成功者更容易讲述自己的过去

当一个人最终成为企业家、教授、干部、明星或其他可识别身份后，他早年的不稳定经历才可能被重新整理成“成长故事”。

而没有抵达某个可命名终点的人，往往只剩散落的帖子、聊天记录和朋友记忆。

## 10. 这里最值得研究的不是“主流 vs 非主流”，而是脚本与人生之间的距离

以后每一个 life slice 都可以增加一组字段：

| 字段 | 问题 |
|---|---|
| expected_path | 当时社会期望他接下来做什么？ |
| institutional_path | 制度为哪些下一步提供了清晰入口？ |
| actual_path | 他实际上走到了哪里？ |
| divergence | 哪一步开始与预期分开？ |
| return | 后来有没有重新回到标准路径？ |
| overlap | 是否同时处于两个以上角色？ |
| waiting | 有没有大量“等下一步”的时间？ |
| invisible_interval | 哪些时期在正式履历里几乎没有痕迹？ |
| self_evaluation | 本人觉得自己是成功、失败、暂停，还是根本不接受这个评价体系？ |
| external_evaluation | 父母、同龄人、单位、社区怎样评价他？ |

这样，“标准人生”就不再是一个用来批判的稻草人，而会变成一个可以实证研究的变量。

## 11. 一个重要概念：生命历程的标准化与去标准化

生命历程研究把“标准化”理解为：某些人生状态、事件及其顺序在人口中越来越普遍，并集中发生在相似年龄。

“去标准化”则意味着：

- 同一事件发生年龄越来越分散；
- 事件顺序不再固定；
- 某些阶段可以返回；
- 各种状态持续时间差异增大；
- 原来稀有的轨迹成为可见的一部分。

中国社会科学网对相关生命历程理论有中文梳理：

- 《战后日本生命历程的制度化、标准化与弹性化》：<https://www.cssn.cn/dkzgxp/zgxp_gjshkxzzzwb/gjshkxzz202203/202211/t20221114_5563902.shtml>

关于中国新生代农民工，也已有研究用“生平去标准化”描述其生命历程，强调个人能动性与制度条件交织形成的复杂轨迹：

- 西南大学相关研究介绍，《个体化与制度化编织的人生：新生代农民工生命历程研究》：<https://gjzl.swu.edu.cn/info/1006/2239.htm>

## 12. 当前结论

主流人生脚本是真实存在的。

它不只是“宣传”，也不只是某几个长辈的个人偏好。

它来自教育制度、劳动制度、婚姻家庭制度、住房和养老体系、家庭期待、媒体叙事以及人口统计分类之间长期的相互强化。

但这条脚本也不能被误认为所有人的真实生活史。

更准确的图景可能是：

> **社会提供少数几个非常清晰的主干节点，而大量真实人生在这些节点之间形成支路、回路、停顿、叠加和断线。**

有人几乎沿着主干一路走完。

有人走到大学后偏出去。

有人十六岁就进入另一条路，三十岁又重新回到学校。

有人有稳定工作却没有婚姻。

有人结婚生子却从未有过稳定职业。

有人在统计意义上不断换类别，却本人觉得自己一直过着同一种生活。

也有人在履历上二十年没有变化，但那二十年内部已经发生了完整的一生。

所以 *How People Lived* 最终不应该只收藏“非主流人生”。

它应该同时重建：

**社会告诉一个人应该怎样活，现实条件允许他怎样活，而他最终究竟怎样把自己的一辈子活出来。**
