# 从“我是不是只有一个人”到可寻找的另一种人生：同性亲密关系、同伴可发现性、家庭时钟与社区基础设施（中国，1997—2024）

## 研究问题

这份笔记补的是 Life Horizons 里此前明显缺失的一类普通人生路径：

> **当一个人发现自己的亲密关系、伴侣选择或家庭未来并不自动对应“异性恋爱—结婚—生育”的标准脚本时，她/他当时实际上能怎样生活？又需要什么通信、同伴、社区与制度接口，才能把一条非标准人生从“个人感觉”变成可执行的生活？**

这里不把“同性恋者”当成一个跨时代、跨地区、内部无差异的人群，也不从性行为自动推断身份。需要区分：

```text
同性吸引 / 同性性行为
≠ 自我认同为“同性恋 / 同志 / gay / 拉拉”等
≠ 向家庭或同事公开
≠ 有稳定同性伴侣
≠ 伴侣能进入住房、医疗、照护、继承等制度接口
```

本文只使用来源中已经公开自我认同、媒体明确匿名化或研究者以群体层级呈现的材料，不追索普通人的真实姓名、联系方式、旧账号与现居信息。

与仓库已有专题的边界：

- `from-pseudonyms-to-identity-portfolios...` 研究一个现实人物怎样维护多个公开身份；
- `stranger-life-scripts-forums...` 研究陌生人的人生方案怎样被看见；
- 婚恋/婚姻专题研究一般性的择偶、结婚与家庭执行条件；
- **本文研究的是：当主流家庭脚本本身不能直接承载一个人的亲密关系时，怎样通过热线、纸质通信、Web、BBS、线下聚会与后来有限的制度接口，先获得“别人也这样生活”的可见性，再尝试把关系变成日常。**

## 一、核心结论先行：Internet 最早改变的可能不是“公开”，而是“可寻找”

一个很容易被今天倒写的故事是：

```text
过去隐蔽
→ Internet 出现
→ 人们公开身份
```

这条线太整齐。

更接近材料的状态链是：

```text
我意识到自己与标准脚本不完全一致
→ 我是否知道还有别人？
→ 我是否有低暴露成本的方法找到别人？
→ 我能否只对同伴可见，而不同时对家庭/单位/学校可见？
→ 我能否获得关系、健康、生活与未来的信息？
→ 线上关系能否转成稳定线下关系与社区？
→ 这种关系能否进入住房、医疗、照护、财产与老年安排？
```

因此本轮提出两个工作概念。

### 1. peer discoverability without household legibility — 同伴可发现、家庭未必可见

一个人可以变得**对同类可寻找**，却不必因此立刻对父母、单位、学校或所有熟人公开。

这不是简单的“匿名”。它是一种受众分层：

```text
peer-discoverable
+
household-unreadable
+
workplace-unreadable
```

热线、化名、BBS、聊天室和后来不同账号，都可能降低“找到同伴”与“向所有现实关系出柜”之间的绑定程度。

### 2. counter-script infrastructure — 非标准人生脚本基础设施

一个人知道“同性恋”这个词，不等于知道自己以后可以怎样活。

真正改变 life horizon 的，是开始能看到：

- 有人长期和同性伴侣生活；
- 有人没有按家庭预期进入异性婚姻；
- 有人怎样向朋友或部分家人解释；
- 有人怎样找住房、朋友、医疗和社区；
- 有人怎样把伴侣关系维持十年、二十年；
- 有人怎样处理养老、住院签字与照护。

这些可观察的生活实例共同构成一种 **counter-script infrastructure**：它不保证一条路线容易，也不保证制度承认，只是把过去可能连“想象模板”都没有的未来变成可被观察、讨论和模仿的未来。

# 二、Internet 以前并不是“没有网络”：1997—1998 的 BP 机热线、纸质通信与实体“点”

## 1. 1997 年的“BP机同志热线”说明：寻呼本身可以被改造成社区入口

2008 年《南方都市报》/南方新闻网的回顾性调查称，1997 年夏天，北京几名中国和外国男女同性恋者建立“BP机同志热线”；1998 年热线号码在广州《希望》杂志公布后，开始形成跨地域联系人网络。

来源：

- 南方新闻网/凤凰转载，2008-09：<https://news.ifeng.com/society/5/200809/0919_2579_793906_1.shtml>
- China Development Brief 收录版本：<https://www.chinadevelopmentbrief.org.cn/news/detail/11.html>

证据：**C/B-C。** 这是十余年后的调查和参与者回忆，能证明“1997 BP 机热线”已成为后来社群叙事中的明确节点；若要精确复原热线的号码、呼叫流程、值守规则和覆盖人数，仍需同时代材料。

它的历史意义不在“第一”这个容易争论的称号，而在基础设施形态：

```text
纸质杂志印出号码
→ 用户呼 BP 机
→ 值守者回电 / 建立联系
→ 联系人再把线下活动、信息与其他人串起来
```

也就是说，中国大众 Internet 尚未普及时，已经可以用**寻呼 + 固话 + 印刷媒介 + 人工中继**建立一种低带宽的陌生人发现网络。

这和仓库已有的寻呼研究形成一个新的生活用途对照：BP 机不仅让老板、家人或客户找到“某个已知的人”，也可以成为**一个原本互不相识的少数群体的入口地址**。

## 2. 《朋友通信》说明：纸张、邮政与人工分发仍是重要基础设施

2005 年央视《新闻调查》回顾，张北川及志愿者从 1998 年起通过同伴教育、电话咨询和《朋友通信》与各地人群保持联系，材料还记录纸本被放置在特定公共地点供人取得。

来源：

- CCTV《新闻调查：以生命的名义》，新浪文字稿，2005-08-08：<https://news.sina.com.cn/c/2005-08-08/22417444875.shtml>

证据：**B，同期电视调查对已运行多年项目的回顾。**

所以 Internet 到来以前的对照不应写成：

```text
孤立 → 上网 → 社区
```

更准确的是：

```text
实体聚点 / 酒吧 / 公共场所
+ BP 机热线
+ 固话
+ 邮政 / 内部刊物
+ 熟人介绍
→ Web / BBS / chat 再加入这一组合
```

互联网首先改变的，是这些链条的**搜索范围、响应速度和跨城市可见性**，而不是凭空创造“人与人之间的连接”。

# 三、1998—2005：Web 把“同伴存在”从偶遇变成可搜索，但采用高度不均

## 3. 1998 年广州同志：一个后来回忆中的早期 Web 节点

2008 年的调查报道记录，1998 年 8 月，24 岁的英语专业毕业生“诺哲”在广州建立“广州同志” `www.gztz.org`；报道同时记载他此前已经忍受一年多 9.6k 拨号上网，并将网站描述为让跨地域同伴联系更方便的空间。

来源：

- 南方新闻网/凤凰，2008：<https://news.ifeng.com/society/5/200809/0919_2579_793906_2.shtml>

证据：**C，后来回顾与人物采访。** 它适合说明参与者怎样记忆早期联网经验，不宜单独用于复原 1998 年网页结构或精确访问规模。

特别要避免一个后见之明错误：

> **1998 年存在一个同志网站，不等于 1998 年大多数同性恋者能上网。**

早期拨号成本、电脑拥有、学校/单位网络、城市差异与网络技能，都会强烈筛选谁能进入这类空间。

## 4. 2005 年网站运营者的同期报告：个人广告、聊天室、BBS 不只是“内容栏目”，而是生活接口

Hui Jiang 在 2005 年亚洲酷儿研究会议论文中，根据 GayChinese.net 六年运营经验描述当时中国大陆同性恋网站：

- 约 1998 年前后开始出现第一批大陆同志网站；
- 网站常同时提供个人广告、聊天室、BBS、新闻、文学、健康问答等；
- 本地性网站扩展到更多中小城市，并组织运动、郊游、演出及健康活动；
- 作者估计当时大陆约有 300—400 个主要服务 GLBT 人群的网站，但大部分曾存在的网站生命周期只有约一两年，能连续运行六七年的只有约十个；
- 对部分偏远或小城市用户，网站可能是少数能够连接同性恋人群的渠道之一；
- GayChinese.net 1999 年由厦门一对同性伴侣创建，创办者公开讲述自己的伴侣生活，运营者称这种关系后来成为一些用户向往的生活目标。

来源：

- Jiang, Hui. “ICCGL: cultural communication via the internet and GLBT community building in China.” ANU repository, 2005：<https://openresearch-repository.anu.edu.au/items/9aab3336-8840-4a0a-95c8-d7c0df40c72d>

证据：**B，2005 年同期会议论文 + 运营者自述。** 它比多年后的怀旧材料更接近当时，但网站数量、用户体验和运营成效仍主要来自作者自身网络与经验，不能当作全国抽样统计。

### 这改变了什么

个人广告和聊天室最明显的作用当然是“找人”。但从 life-course 角度，更深的一层是：

> **一个人第一次可以在不先进入某个特定酒吧、公园或现实熟人链的情况下，看到大量与自己相似的人正在讨论伴侣、家庭、健康、工作和日常生活。**

这就是 `counter-script infrastructure`。

它让“另一种人生”不再只能靠偶遇来证明存在。

# 四、女性材料是重要反例：不能把早期“同志互联网”自动写成所有人的共同经验

2005 年《中国新闻周刊》关于北京女同性恋社群的同期调查，记录了一个非常不同的基础设施组合：固定时段的女性线下聚会、2005 年成立的“同语”、两条女同志热线，以及医学、健康与同伴支持；报道中一名职业摄影师回忆，四年前她从未想到“有这么多人和自己一样”。

同一报道还明确说，当时女同性恋组织的社会可见度和组织资源明显低于男同性恋群体。

来源：

- 《中国新闻周刊》，新浪转载，2005-09-02：<https://news.sina.com.cn/o/2005-09-02/13566847325s.shtml>
- 同稿另一版本，2005-08-25：<https://news.sina.com.cn/c/2005-08-25/12187592374.shtml>

证据：**B，同期深度报道 + 受访者第一人称回忆。** 同一稿件的两个 URL 只算一个 evidence family。

Jiang 2005 的运营者论文也估计，在约 300 个同性恋网站中，专门服务女同性恋者的网站不到 20 个，并认为技术、资金与组织能力是其中一部分限制。

这要求保留一个分布：

```text
“同志互联网”存在
≠ 男女同性恋用户获得了相同数量的空间
≠ 城市和小城用户拥有相同接入条件
≠ 所有同性爱/同性性行为者都认同“同志”身份
```

因此，热线、酒吧包场、杂志、小组与线下沙龙不是“Web 普及前的落后残余”，而可能长期和 Web **互补**，甚至对某些群体更重要。

# 五、2006 年的同时代第一人称：标准家庭时钟可以和真实亲密关系发生正面冲突

2006 年 8 月，新华社报道北京朝阳区疾控中心网站上的“同志论坛”。公开网址后四天，三个板块已有 128 条帖子，其中“心灵家园”91条。

最重要的不是帖子数，而是报道保存的两条同期第一人称。

一名用户说自己“到了婚嫁的年龄”，家里天天催婚，为了逃避已经三年没有回家。另一名用户说，自己“一直以来以为世界上只有我一个人这样”，第一次看到这个网站后才感到并非如此。

来源：

- 新华社，新浪转载，2006-08-18：<https://news.sina.com.cn/c/2006-08-18/08269782784s.shtml>

证据：**B，但其中嵌有同期论坛第一人称材料。** 原论坛本体和账号历史尚未在本仓完成 archive 级核验，因此这里只证明“新华社在 2006 年这样引用了当时论坛帖子”，不把门户转载冒充原始论坛 artifact。

## 这条材料提供了一个新的 life-course 机制：social-clock divergence — 社会时钟分叉

对标准脚本来说：

```text
到年龄
→ 找异性对象
→ 结婚
→ 成家
```

但这名用户面对的是：

```text
家庭开始按年龄追问婚姻
+
自己可接受的亲密关系并不对应家庭默认脚本
+
缺少可直接替代的家庭/制度接口
→ 回家本身变成高成本行为
```

所以“催婚”不是抽象文化压力；它可以直接改变**返乡频率、亲属联系、居住距离和信息披露策略**。

这也让 2005—2012 的“扩张型未来”获得一个重要修正：

> 对部分人而言，Internet 扩张了“我可以认识谁、我可以看见什么样的伴侣生活”，但**关系的制度可执行性并没有同步扩张**。

可以把它写成：

```text
peer horizon expands faster than institutional horizon
同伴未来扩张速度 > 制度未来扩张速度
```

# 六、2019：关系可以持续十多年，但“谁能为你签字、照护你”仍需要另外拼接口

2019 年 8 月，北京出现一对同性伴侣办理意定监护协议公证和生前预嘱公证的公开案例。公证处当时的公告称，两人已有十多年感情基础，并在国外登记结婚，但对未来养老、医疗和住院签字等问题仍有现实顾虑，因此依据当时《民法总则》第 33 条指定彼此为监护人。

来源：

- 北京国信公证处内容的凤凰转载，2019-08-08：<https://news.ifeng.com/c/7oyZHjOu3P6>
- 中央社同期报道，2019-08-09：<https://www.cna.com.tw/news/firstnews/201908090084.aspx>
- SCMP 同期报道，2019-08-09：<https://www.scmp.com/news/china/society/article/3022181/same-sex-couple-beijing-become-first-take-advantage-new-legal>

证据：**B/A-derived。** 凤凰页面转录了公证处当时公告；中央社同时指出原公告随后已不可见。这里不把意定监护等同于婚姻，也不推断其能覆盖所有财产、亲属或医疗场景。

## 这增加了一个制度接口判断

```text
relationship durable
≠ relationship institutionally complete
```

两个人完全可以已经共同生活十多年，却还需要分别寻找：

- 医疗决定接口；
- 失能监护接口；
- 遗嘱/财产安排；
- 养老照护；
- 对双方原生家庭的说明与协商。

因此 2015—2019 的“拥堵型未来”不只发生在工作、住房和买房上。对不完全符合标准婚姻脚本的人，**还可能需要把原本由“配偶”这个单一制度身份打包的功能拆开，一项项重新组合。**

这和仓库已有的 `assembled adulthood` 形成很强的平行：

> 有些人不仅要“组装成年”，还要**组装亲密关系的制度可执行性**。

# 七、2024：家庭公开本身也越来越像一个分阶段、分对象的组合决策

2024 年《当代青年研究》发表基于 28 位 90 后、00 后同性恋者深度访谈的研究。摘要指出，受访青年并不总把“出柜”理解成一次性向整个家庭公开，而会针对不同家庭成员采取不同策略，并持续衡量家庭关系中的资源与风险。

来源：

- 郑静、乐明：《青年同性恋者的家庭出柜观念与实践》，《当代青年研究》2024年第3期：<https://qing.cbpt.cnki.net/portal/journal/portal/client/paper/354f77be647b9b2fd6e971350b8f7bfb>

证据：**A/B，2024 年同行/学术期刊对同期青年访谈的研究摘要。** 样本只有 28 人，不能外推比例。

它适合补充一个 2023—2026“防守型未来”的非经济版本：

> **保留退路不只意味着现金缓冲、稳定工作或考证，也可能意味着维护家庭支持网络，同时不把所有私人身份一次性暴露给所有家庭成员。**

这并不是“更保守”，也不是所有年轻人都如此。更准确的是：

**family-boundary portfolio — 家庭边界组合**

```text
谁知道？
谁暂时不知道？
谁先知道伴侣？
哪些信息只对兄弟姐妹开放？
父母的住房、照护、情感和经济支持是否会因此改变？
```

公开身份因此本身也是一种 life-course coordination，而不是只有“已出柜 / 未出柜”两个状态。

# 八、海外前 Web 对照：1983 年 Usenet 已经在解决“同伴可发现、外部不必立刻可读”

## 1. net.motss / soc.motss：连群组名字本身都是受众边界设计

1991 年仍可检索的 `soc.motss` FAQ 记录：

- 群组最早于 1983 年 10 月以 `net.motss` 建立；
- 1991 年估计约 40,000 名全球读者，日常流量超过 100 篇；
- FAQ 明确解释为什么没有采用更直白的 `soc.gay`：部分管理员可能不愿传送名称中直接带有 “gay” 的群组；
- 创建者 Steve Dyer 1983 年公告把群组定位为讨论健康、亲职、关系、工作安全等普通生活问题的支持环境。

来源：

- `soc.motss frequently asked questions, release 0`, Google Groups：<https://groups.google.com/g/soc.motss/c/hvqaRx1NEcs/m/aPDDASArBgUJ>

证据：**A，同时代网络文档。**

这与中国 1990s—2000s 材料构成一个非常有用的共同机制：

> **网络空间并不天然要求“越公开越好”。早期使用者反而会主动设计一种 selective legibility：让需要找到的人知道入口，同时降低不相关或可能有风险的受众第一眼就识别入口的概率。**

## 2. GLIB：本地 BBS 把线上联系变成线下社区

Humanities Washington 对 Gay and Lesbian Information Bureau（GLIB）的历史研究记录，GLIB 1986 年建立，在华盛顿地区提供聊天、信息与同伴连接；线上用户后来也组织线下见面。它与 net.motss 一样说明，Web 之前的拨号 BBS/Usenet 已经可以把地理分散、现实环境中难以确认彼此的人连接起来。

来源：

- Humanities Washington, “Love, Acceptance, and Screeching Modems,” 2023：<https://www.humanities.org/spark/love-acceptance-and-screeching-modems/>

证据：**C/B，高质量公共数字史，含早期参与者和档案材料。**

### 跨国比较

共同变化：

- 网络降低同伴发现对特定酒吧、街区或熟人介绍的依赖；
- 线上身份可以先于完整的现实公开；
- 社区空间同时承担关系、健康、工作、亲职和普通聊天；
- 线上关系会转成线下聚会和持续朋友网络。

中国 1997—2005 需要单独解释的，是：

- 大众 Internet 接入时间更晚、区域分布更不均；
- BP 机热线、纸本通信、实体聚点与早期 Web 长期并存；
- 早期网站生态高度依赖少数个人站长、低成本空间与志愿劳动；
- 男女同性恋者的线上组织资源分布很不对称；
- 家庭婚姻时钟与城市迁移/返乡可以直接纠缠在一起。

# 九、历史可见性：最容易活到今天的站点，可能恰好不是当年最典型的网站

Jiang 2005 的一个细节对两个仓都很重要：作者估计当时多数曾存在的同性恋网站生命周期只有一两年，能持续六七年的只有约十个。

这产生一种 **survivor-site bias — 幸存站点偏差**：

```text
今天还能被搜索到 / 仍有域名 / 仍有资料库
→ 更可能是运营更久、组织能力更强、迁移更成功的站点
```

而不一定是：

```text
当年最常见的网站形态
```

尤其容易消失的可能包括：

- 一两人维护的地方站；
- 临时聊天室；
- 免费空间个人页；
- 个人广告和交友板块；
- 小城站点；
- 面向女性、资源较少的小型社区；
- 需要登录才能看的内容；
- 关站后无人迁移的用户自述。

今天 GZTZ/广同的现行站点仍能被搜索引擎索引到带有 2000—2003 “本站发表”日期的新闻、健康和社区自助条目，例如当前索引页仍列出 2000—2001 年记录；但这只能证明**当前 live-origin corpus 正在呈现带历史日期的数据**，不能自动证明现在的 HTML、DOM、字符集、链接结构和服务器程序就是当年的原始页面。

例：

- 当前索引中可见 2000—2001 条目：<https://www.gztz.org/cn/news/index_s22_p8.htm>
- 当前页面承载一条标注 2002-11-22、后于 2007 编辑的记录：<https://gztz.org/cn/news/doc_431399.htm>

这部分的技术证据合同与 archive gap，详见 companion old-web note。

# 十、把这一类人生放回四阶段未来模型

## 2005—2012：扩张型未来

对有接入条件的一部分人，扩张首先表现为：

- 同伴从“偶然遇见”变成可搜索；
- 伴侣和朋友不必只来自本地实体“点”；
- 其他人的生活路线可以成为可观察脚本；
- 身份、健康和关系信息的获取成本下降。

但必须保留不对称：

> **peer horizon 扩张，不等于 institutional horizon 同步扩张。**

## 2015—2019：拥堵型未来

长期伴侣可以存在多年，但医疗、监护、财产与养老仍可能需要单独拼接制度接口。关系越长期，反而越会暴露“日常已经像家庭、制度却不能一次打包”的问题。

## 2020—2022：偶发型未来

本轮没有找到足够好的同期第一人称材料，能够在不重复现有疫情专题的前提下，说明疫情怎样特异改变同性伴侣的生活执行。**暂不补故事。** 未来可检索：跨城伴侣无法会面、医院陪护、共同住房和原生家庭返乡的同期材料。

## 2023—2026：防守型未来

2024 年青年访谈提示，一部分人的“退路管理”可以表现为**分阶段、分家庭成员管理身份公开**。但 28 人样本不足以证明时代总体转向；目前只把它作为一条可观察策略，而不是四阶段模型的群体统计结论。

# 十二、证据等级与反例

## 较强证据

1. **2005 Jiang 会议论文**：同期网站运营者对六年网站生态的描述；B。
2. **2005《中国新闻周刊》女同性恋社区调查**：同期人物、热线与线下聚会；B。
3. **2006 新华社同志论坛报道**：同期论坛规模 + 嵌入的第一人称发言；B，原论坛 artifact 未核验。
4. **2019 公证处内容及同期报道**：具体制度接口案例；A-derived/B。
5. **1991 soc.motss FAQ**：海外同时代原始网络文档；A。

## 较弱但有价值

- 2008 对 1997—1999 社群史的调查：C/B-C，用于恢复参与者记忆，不用于精确网页技术史。
- 2024 的 28 人青年访谈：A/B 学术材料，但样本小，不能作全国概率推断。

## 反例

- Internet 并没有让所有人都公开身份；恰恰可能让**选择性不公开**更可执行。
- Web 不是唯一社区基础设施：女性热线、酒吧聚会、纸本通信和熟人网络长期存在。
- 同性吸引或行为并不保证形成“同志”身份，也不保证参加社区。
- 一个能稳定维持十多年的伴侣关系，仍可能缺失医疗/监护等制度接口。
- 海外 Usenet/BBS 更早出现类似 peer-discovery，并不能说明中国只是“晚几年复制”；不同接入率、家庭结构与本地制度会改变实践。

# 十三、后见之明风险

1. **不能把 1998 年网站存在写成“同性恋者已经普遍上网”。**
2. **不能把今天的 LGBT/queer 分类体系完整倒投到 1990s 行动者。** 来源说“同志”“拉拉”“gay”时尽量保留历史词汇。
3. **不能因为 2006 年有人因催婚三年未回家，就把这种路径外推为同性恋者普遍经验。**
4. **不能把网络社区浪漫化为天然安全空间。** 身份泄露、骚扰、错误健康信息、商业化和平台消失都可能存在。
5. **不能把最耐久的网站当成最具代表性的网站。** 短命小站反而可能更接近日常生态，但最难留档。
6. **不能把 2019 意定监护写成“同性婚姻替代品”。** 它只覆盖特定法律关系的一部分功能。
7. **不能把后来公开自我认同的人反推为其整个生命都使用同一身份词。**

# 十四、仍不知道什么

下一轮若继续，应优先找能改变结论的材料，而不是重复“Internet 帮助找同伴”：

1. 1997 BP 机热线的同时代号码公告、操作说明或值守者记录；
2. 1998—2002 GZTZ / GayChinese 的**可实际打开历史 capture**，至少两个时点；
3. 1999—2005 女同性恋网站/论坛的一手页面与使用者同时代材料；
4. 小城市、农村、工人、农民工与非大学教育背景的同性亲密关系 life history；
5. 2005—2012 同性伴侣真实租房、工作迁移、经济互助和家庭转移支付；
6. 2020—2022 疫情中跨城同性伴侣的同期第一人称，不用后来怀旧替代；
7. 2023—2026 的住房、养老、照护、现金缓冲与“是否离父母太远”的真实规划；
8. 不以公开身份或社区参与为前提的人——也就是最容易从数字档案里消失的那部分生活。

# 十五、这一轮改变了“人怎么活着”的哪一点理解

以前的标准人生研究很容易默认：

```text
一个人先决定自己想怎么活
→ 再去寻找资源执行
```

这批材料提示，有时顺序正好相反：

> **一个人先通过热线、杂志、BBS、聊天室或网站知道“原来还有别人”；等看见别人怎样恋爱、争吵、同居、和家人周旋、一起老去以后，一种原本没有现成名字或脚本的未来才逐渐变得可以想象。**

因此 Internet 进入普通生活的一个深层转折，不只是“信息更多了”。

它让一些人第一次获得一种非常具体的信息：

> **我不是唯一一个，而且别人已经在试着把这种生活过下去。**

这不等于制度问题被解决，也不等于家庭压力消失；但从 life horizon 角度，**“未来里是否存在像我这样的人”本身就是一个基础设施问题。**
