# 从报纸征婚到在线婚恋：浪漫关系可寻址性、婚恋基础设施与伴侣关系选择权（中国，1981–2026）

> 研究问题：当婚姻仍然是强烈的人生预期时，一个普通人究竟通过什么渠道认识一个“可能成为伴侣的人”？通信基础设施扩大候选范围以后，婚恋到底变得更自由、更高效，还是只是把家庭、工作、城市、住房和时间压力重新编码进新的搜索界面？

本专题不把“婚姻率变化”直接解释成态度变化，也不把婚恋网站的注册账户数当作成功婚姻数。它研究的是一个更窄的生活能力：**romantic addressability / 浪漫关系可寻址性**——一个人在现有亲友、单位和地理圈子之外，能否发现、描述、联系、筛选并最终见到潜在伴侣。

相关 old-web 交叉笔记：`../old-web-archaeology/docs/ONLINE_DATING_PROFILE_SEARCH_MESSAGE_VERIFICATION_AND_OFFLINE_MEETING_STATE_GAPS_2003_2015.md`（跨仓链接仅作研究导航）。

## 1. 先拆状态：公开“找对象”不等于建立关系

至少区分：

```text
单身 / 希望认识伴侣
!= 把这一意愿告诉亲友或媒人
!= 征婚信息被公开
!= 平台账号存在
!= profile 完整
!= profile 仍活跃
!= 搜索结果里出现
!= 对方实际看到
!= 第一条消息成功送达
!= 对方愿意回复
!= 双方交换站外联系方式
!= 线下见面
!= 持续约会
!= 建立关系
!= 决定结婚
!= 完成结婚登记
```

因此，“注册用户”“活跃用户”“付费用户”“已改变 relationship status 的用户”和“最终结婚的人”必须保持不同口径。

本专题暂时使用几个工作概念：

- **romantic addressability / 浪漫关系可寻址性**：能否在已有熟人网络之外发现潜在伴侣；
- **matchmaking infrastructure / 婚恋中介基础设施**：亲友、媒人、报刊、电话、电视、网站、App、线下相亲会等帮助陌生人变成可接触对象的系统；
- **profile legibility / 个人资料可读性**：年龄、城市、学历、职业、收入、住房、兴趣等怎样被压缩成可比较字段；
- **search-field formalization / 择偶条件字段化**：原本在聊天和介绍中逐步理解的条件，变成可查询、可排序、可付费提高曝光的字段；
- **contact-pool expansion / 接触池扩张**：技术让候选范围扩大，但不自动提高互相喜欢、信任和现实兼容的概率；
- **relationship optionality / 伴侣关系选择权**：既包括更容易寻找伴侣，也包括可以延迟、拒绝或停止不合适关系，而不把“找到任何人”当作唯一成功状态。

## 2. Internet 以前：报纸已经能把“熟人介绍”扩展成全国陌生人搜索

1981 年 1 月 8 日，《市场报》刊登丁乃钧的公开征婚启事。2007、2009、2010 年对当事人和当年编辑的回访都把这件事视为改革开放初期极少见、并引发广泛讨论的公开征婚案例。丁乃钧当时年近 40，此前依靠周围人介绍多次相亲未果；报纸刊登后收到大量来信，最终通过书信往来认识后来结婚的对象。

这组材料属于 **C（后来回忆）+ B（后来的新闻核访）**，适合证明当事人怎样回忆渠道变化，不宜单独承担精确的全国“第一”断言；如果以后找到 1981 年《市场报》原版扫描或馆藏目录，应升级为 A。

但即使把“第一”暂时放在一边，机制已经足够清楚：

```text
熟人介绍：媒人知道谁单身 → 逐一转述 → 双方见面
报纸征婚：本人写自我描述 → 编辑决定是否公开 → 全国读者看到 → 读者写信 → 邮政把回应送回来
```

报纸没有发明婚姻自主，也没有消灭家庭和媒人；它先改变的是**候选人的可寻址范围**。一个在四川工作的教师，可以被远在其他省份、此前完全不在其社会圈中的人看见。

这里不能用今天“发帖”的低摩擦经验倒推 1981：公开征婚本身可能带来名誉、羞耻和社会评价风险，回应又依赖信件往返。候选池虽然扩大，沟通仍是高延迟的。

来源：

- 四川新闻网/成都商报，2010-02-08，丁乃钧回忆：<https://news.sina.com.cn/c/2010-02-08/040617061784s.shtml>
- 东北网转地方媒体，2007-08-02，对当年编辑的核访：<https://shuangyashan.dbw.cn/system/2007/08/02/050918628.shtml>
- 《环球人物》2009 回访：<https://style.sina.com.cn/news/2009-10-10/101649707_2.shtml>

## 3. 2003–2012：扩张型未来——“认识谁”从熟人网络变成可搜索数据库

世纪佳缘 2003 年出现、百合网 2005 年发布以后，网络婚恋把征婚信息进一步拆成结构化 profile、搜索、站内信、会员等级、验证和线下活动。

### 3.1 2008–2011：平台把“对象”变成一个可以反复检索的数据库

Jiayuan.com 2011 年向美国 SEC 提交的 F-1 是本专题目前最强的一手平台材料之一。它把几种容易被后来的“婚恋网站”三个字掩盖的状态写得很清楚：

- 2011-03-31 有 4020 万 **registered user accounts**；
- 2011 Q1 平均约 474 万 **monthly active user accounts**；
- 平台允许免费注册和搜索数据库；
- 站内初始消息、读取消息、聊天、提高搜索排名、资料突出显示等可以分别收费；
- 用户可以付费提交 profile 信息的证明，让其他用户知道平台已收到相关证明；
- 2010 年平台在 105 个城市举办 864 场线下活动，典型活动约 100–200 人；
- 平台自己的历史数据称，两名用户在站内的平均消息交换约持续 3.5 天，继续交往的人往往交换站外联系方式；
- 从 2010 年 6 月起，部分消息和 profile 功能已可通过手机浏览器访问。

这些都只能证明平台的业务与其自报状态，不应把 `registered account` 写成“4020 万人在认真找对象”，更不能把 profile 状态变更直接写成结婚。

A 级来源：Jiayuan.com International Ltd., F-1, 2011：
<https://www.sec.gov/Archives/edgar/data/1511683/000104746911003874/a2203517zf-1.htm>

百合网自己的历史介绍则把 2005 年的“心理测试/匹配推荐”作为产品核心：用户填写较多个人与心理特征，系统据此推荐潜在对象。这是 **A（平台自述其服务设计）**，不是独立效果评估。

- 百合网历史介绍：<https://news.baihe.com/gybh/438.htm>

### 3.2 在线并没有消灭传统红娘，而是把红娘重新接进平台

Jiayuan 的 F-1 同时记录：平台从 2008 年持续举办大量线下活动，并提供 VIP 人工搜索、背景核查、关系咨询和预筛选候选人。也就是说，Internet 没有沿着“算法取代媒人”的单一路线前进，而是出现：

```text
结构化数据库扩大候选池
→ 用户自己搜索/发消息
→ 对部分用户仍然需要人工顾问和线下活动
→ 平台又把传统红娘劳动商业化、标准化
```

这是一种 **broker rebundling / 中介重新捆绑**。

### 3.3 同时代个人材料：公开字段让小众偏好也变得可广播

2008 年成都一名 37 岁硕士在论坛公开征婚，明确写出自己偏好较胖的女性；报道后来进行了面对面采访。这个案例不能代表主流婚恋，却能证明互联网把过去很难经熟人媒人高效表达的“小众择偶条件”变成了可公开广播的自我描述。

B 级同期来源：<https://news.sohu.com/20081130/n260930770.shtml>

同年还有被证明是戏谑/虚假的“煤老板替女招婿”帖子迅速传播。它是很好的反例：**profile/public post exists != underlying person/intent is authentic**。网络扩大了可见性，也扩大了表演、恶作剧和身份真实性问题。

B 级同期来源：<https://news.ifeng.com/society/2/200810/1022_344_841795.shtml>

### 3.4 2009 的家庭仍然没有退场

2009 年《中国青年报》报道中，一位母亲在给儿子介绍多人、参加大型相亲会都没有结果后，让儿子把多个婚恋网站都注册一遍。材料本身带有“剩男/剩女”时代话语，不能用作人口比例，但能说明线上搜索不是“个人化取代家庭”的简单故事：父母、线下会场和网站可以在同一个人的择偶过程中叠加。

B 级同期来源：<https://tech.sina.com.cn/i/2009-12-24/08273706239.shtml>

因此 2005–2012 的扩张型未来，在婚恋上最像：

> “我不必只在同学、同事、亲戚介绍的几十个人里等；全国有成百万资料可搜索，下一段关系似乎随时可能出现。”

但这只是**接触池扩张**，不是“好关系的无限供给”。

## 4. 2015–2019：拥堵型未来——对象更多了，时间、城市和现实兼容性反而成为瓶颈

2019 年的材料开始出现一种很不一样的婚恋时间感。

浙江一名即将 30 岁、在三线城市工作的女性告诉记者，她过去很享受单身生活，后来开始感到孤单、想找人一起生活，却觉得自己的交际圈太小。这个材料同时保留了两种容易被错误合并的状态：

- 曾经主动享受单身；
- 后来希望进入伴侣关系但现实接触池有限。

它证明 `currently single != wants lifelong singlehood`，也证明 `wants partner != can readily meet compatible person`。

B 级同期第一人称：<https://www.nbd.com.cn/articles/2019-08-21/1364747.html>

上海 2019 年青年婚恋调查又显示，受访未婚青年实际“通过网上结识”的比例并不是压倒性多数，朋友、亲戚和线下组织仍然重要。该调查的样本与组织方式限制其代表性，但足以反驳“2019 年所有年轻人的婚恋都已经平台化”。

B 级同期调查：<https://static.zhoudaosh.com/files/cnews/2019/20190807/E4590582E5FF4461063507884FE1D15FD1AF3335682E4E69B6B97E07B40FFF0C/2.html>

同期香港/杭州等城市相亲活动已经把“学历、年薪、职业、籍贯”等信息做成相亲墙上的资料卡，并用二维码把纸面 profile 接回手机私聊。这是一个很有象征性的混合界面：

```text
线下人群和父母来到同一物理会场
→ 资料被字段化展示
→ 扫二维码进入数字联系
→ 是否见面仍回到现实空间
```

B 级同期报道：<https://ori.hangzhou.com.cn/ornews/content/2019-11/10/content_7301324.htm>

这一阶段的瓶颈因此从“候选人看不见”转向：

- 工作和通勤是否留下持续约会时间；
- 两个人是否能在同一城市生活；
- 租房/买房和家庭经济是否允许共同生活；
- 父母期望是否兼容；
- 平台上的大量候选是否真的转化为现实接触。

这就是 **choice abundance != relationship executability**。

## 5. 2020–2022：偶发型未来——线下见面中断时，关系形成也出现 fallback

2020 年 3 月，中新社采访太原 28 岁未婚女性“闹闹”（化名）。她认为传统相亲更真实可靠但耗费时间，疫情期间线下受限，线上相亲可以先筛选、扩大接触面。

B 级同期第一人称：<https://www.chinanews.com/sh/2020/03-13/9123765.shtml>

这里需要严格拆状态：

```text
视频/语音见面
!= 已建立信任
!= 能检查线下相处感受
!= 已成为稳定关系
```

疫情没有发明在线婚恋，但它把原本“发现对象/初聊”的数字层临时升级成了**线下社交受限时的关系启动 fallback**。这与远程办公、线上问诊等专题有相似机制：便利层在偶发中断时变成连续性基础设施。

## 6. 2023–2026：防守型未来——“能找到人”之后，问题变成是否值得把生活与另一个人绑定

2024–2026 的同时代材料不支持把今天简单写成“不想结婚”。它们更像是**婚姻从默认下一步变成条件化项目**。

2024 年中国青年报的一组青年访问中，有人明确说单身生活拥有时间和经济自主；也有人表示遇到合适的人仍愿意建立关系。这种材料适合证明态度分化，不适合外推全国比例。

B 级同期材料：<https://news.youth.cn/sh/202405/t20240530_15282688.htm>

同年住房调查里，广州一名与男友租房的女性说，双方家庭难以提供太多购房支持，高房价与通勤成为现实压力。这里的重点不是“房价导致不婚”的单因果，而是**partner found != household formation economically executable**。

B 级同期第一人称：<https://news.youth.cn/jsxw/202403/t20240328_15162160.htm>

2025 年北京公园相亲角，一名 35 岁女性告诉记者，她虽然着急也面对春节催婚，但“不想因为年龄而将就”；报道同时记录高强度工作、经济压力与大城市距离带来的约会摩擦。

B 级同期第一人称：<https://paper.people.com.cn/zgcsb/pc/content/202503/03/content_30059920.html>

到 2026 年，中国青年报调查中的 95 后受访者又把“工作忙没精力”“恋爱成本”“买房买车养娃”等作为自己的现实顾虑。该调查不能被写成所有青年共同态度，但可以说明“婚恋风险预算”已经成为公开讨论的一部分。

B 级同期材料：<https://news.youth.cn/jsxw/202603/t20260309_16546748.htm>

所以“防守型未来”在婚恋上不是简单悲观，而更接近：

> 我可以寻找伴侣，但不希望仅为了完成年龄脚本，就把工作、住房、城市、财务和未来照护一起锁进一个无法承受的组合。

这种选择权既包括进入关系，也包括等待、退出和拒绝不合适匹配。

## 7. 海外对照：法国 Minitel 证明“电子陌生人相遇”远早于 WWW

法国 Minitel 在 1980 年代已经形成大量交互式消息服务。1986 年《华盛顿邮报》的同期报道描述，用户以昵称进入消息服务，与陌生人进行持续文字交流；其中一部分商业服务甚至雇佣人员用虚构身份维持对话，用户会尝试索取电话号码或约见。

A/B 边界：这是 **B（同期新闻）**，可证明当时已有大规模匿名/半匿名电子交流及真实性问题；不能把成人消息服务直接等同于今天的严肃婚恋网站。

- Washington Post, 1986-12-25：<https://www.washingtonpost.com/archive/politics/1986/12/25/minitel-is-new-french-revolution/eeaf90f3-90ca-4d60-bb46-fc4808fa2649/>

后来的法国公共媒体和 Minitel 史料也确认，1980 年代中期开始的 Minitel messageries 把匿名昵称、实时文字交流和按连接时长计费做成大众化服务。这里最有比较价值的不是成人内容，而是两个结构：

1. **电子系统可以在 Web 以前就把陌生人变成可即时接触对象；**
2. **一旦身份可以被昵称和文本表演，真实性、代理操作和商业激励会同时进入亲密关系搜索。**

后见之明风险：不能因为 Minitel 与网站都“能聊天”，就抹平其终端、计费、实名程度、图像能力和使用群体差异。

## 8. 这改变了我们对“普通人怎样活着”的哪一点理解

标准生命脚本常被写成：

```text
上学 → 工作 → 恋爱 → 结婚 → 生育
```

但这里真正被历史改变的，不只是“结婚年龄”，而是**“一个人从哪里来”**。

在熟人媒介占主导的环境里，潜在伴侣通常来自亲友、同事、同乡、邻里和单位，候选池与现实社会网络高度重叠。报纸征婚第一次可以让一个陌生人跨省写信；Web 把成千上万陌生人的年龄、学历、城市和职业做成可搜索字段；移动互联网又让这一数据库随身携带。

可候选池无限扩大以后，真正稀缺的并没有消失：

- 对方是不是一个真实的人；
- 双方有没有持续交流时间；
- 是否愿意在同一城市生活；
- 家庭、住房、工作与生育预期能否兼容；
- 是否愿意把两个已经可以独立运行的生活重新绑在一起。

因此更准确的历史变化不是“媒人被算法取代”，而是：

> **伴侣从一个主要由熟人网络递到面前的人，逐渐变成一个可以主动搜索、筛选、联系，但仍必须在现实生活中重新验证的人。**

Internet 扩大了“我可能遇见谁”；它没有替任何人回答“我愿不愿意和这个人一起生活”。

## 10. 反例、后见之明风险与尚未确定之处

### 已证实

- 报刊、线下媒人、Web 数据库、线下活动和移动服务长期叠加，而不是一代渠道瞬间替代上一代；
- 2010–2011 的中国婚恋平台已明确区分注册、活跃、付费和 profile 状态；
- 在线搜索可以扩大潜在接触池，也会把真实性、付费曝光和信息字段化问题带进婚恋；
- 疫情期间线上接触可以承担线下见面暂时中断时的前置沟通功能。

### 可以合理推断

- 婚恋 Internet 化降低了“找到一个陌生候选人”的搜索成本，但没有同步降低现实相处、住房、城市协调和建立信任的成本；
- 当单身生活本身更可执行时，婚姻更容易从年龄脚本变成需要满足若干条件的项目。

### 仍不知道

- 1981《市场报》该版的可核验原件与版面上下文；
- 1995–2003 中文 BBS、聊天室和门户“征友/征婚”中普通人实际怎样从帖子走到线下见面；
- 2007–2010 不同阶层、城市和农村青年对“未来五年结婚/买房/迁移”的同期第一人称样本仍不足；
- 平台搜索字段究竟在何时、以何种顺序把“房/车/收入/户籍”等变成普通用户可检索条件，需要历史页面 capture；
- 账号删除、婚后离站、转向 QQ/手机以后，平台公开数据会如何系统性低估/误读真实关系结果。
