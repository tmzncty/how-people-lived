# 1963–2024：当人离开原来的地址以后——通讯录、同学录与“关系连续性”

> 核心问题：毕业、迁移、换工作、换住处以后，一个普通人怎样继续“被旧关系找到”？纸质通讯录、单位/学校地址、固定电话、寻呼与手机、Email、OICQ/QQ、网上同学录、SNS 分别把什么样的关系从地点中剥离出来，又留下了哪些新的依赖？
>
> 本专题不是“社交媒体史”，也不把“网上还能联系”自动解释成“关系更亲密”。研究单位是 **contact continuity（联系连续性）**：一个既有关系在人的住址、工作单位、学校、终端或平台发生变化以后，能否继续维持可寻址、可更新、可联系的状态。
>
> 中文旧网的专门 evidence contract 见：
> <https://github.com/tmzncty/old-web-archaeology/blob/main/docs/ALUMNI_ROSTERS_MUTABLE_PROFILES_AND_CONTACT_CONTINUITY_GAPS_1999_2006.md>

---

## 结论先行

这一轮材料支持七个新的分析概念。

### 1. contact continuity：联系连续性本身是一种生命历程资源

毕业、迁移、换工作并不只改变“人在哪里”，还会改变别人还能否找到他。

在地点绑定较强的通信环境里，一次迁移可能同时要求更新：

- 邮寄地址；
- 单位/学校地址；
- 固定电话号码；
- 联系人转交关系；
- 纸质通讯录中的记录。

因此：

> **mobility cost includes contact-repair cost**

一个人搬走之后要重新让旧朋友、亲属、同学知道“现在去哪里找我”，这本身也是迁移成本的一部分。

### 2. place-bound addressability → account/cohort addressability：可寻址性逐步从地点松脱

这里不是一次性的“纸质地址 → 网络账号”，而是一条梯度：

```text
住宅 / 单位邮寄地址
→ 固定电话
→ 寻呼 / 手机号码
→ Email 地址
→ OICQ / QQ 等账号
→ 网上班级 / 校友目录
→ SNS 账号 / 好友图谱
```

越往后，联系人越可能先寻找“这个人或这个班级的账号”，而不是先知道此人此刻住在哪。

但：

> **account-based addressability ≠ permanent addressability**

邮箱会离校失效，号码会更换，密码会忘，平台会衰落，账号会被盗，关系图也可能无法迁移。

### 3. cohort addressability：先找到“班级”，再找到“人”

网上同学录带来的变化不只是个人主页。

它把学校、年级、班级变成可搜索的 namespace：

```text
学校
→ 年级 / 专业
→ 班级
→ 成员列表
→ 个人资料 / 留言
→ QQ / Email / 电话 / 线下联系
```

即使不知道某位旧同学现在的住址，只要记得“我们是哪所学校、哪一级、哪个班”，就可能先重新找到班级，再找到人。

这可称为 **cohort addressability（群体/同届可寻址性）**。

### 4. contact-state maintenance：从“重新印一份通讯录”到“维护一个可变状态”

纸质通讯录是一份快照。

当一个人搬家、换单位、换电话以后，旧册不会自动更新。

网络资料页理论上允许用户更新一次，其他人以后看到新的状态，因此联系维护从：

```text
重新通知很多人 / 重印通讯录
```

变成：

```text
更新一个账号或班级资料
```

但这又带来新的历史问题：

> **current profile overwrites past contact states**

如果没有连续 archive capture，我们往往只能看到“最后留下来的资料”，而看不到一个人十年里怎样一次次搬家、换号和换工作。

### 5. ambient awareness：关系可以在很少直接交谈时继续“被看见”

2018 年接受采访的一名早期校内网用户回忆，很多已经不联系的旧同学，她仍会关注其状态；她把能找到旧同学、知道近况视为当年使用校内网的重要原因。

这是一种与电话/书信不同的 **ambient awareness（环境式知晓）**：

- 不一定主动给对方写信；
- 不一定形成长对话；
- 但仍然知道对方大概在哪里、在做什么。

因此：

> **contact continuity ≠ conversational continuity**

更不能推出：

> **visibility ≠ intimacy**

### 6. continuity ≠ intimacy：更容易保持地址，不等于关系更深

2005 年《解放日报》的同期材料既记录了毕业后同学借网上班级继续联系，也记录了反例：仍然住在同一校园、同一楼里的学生如果过分依赖网上联系，现实集体生活反而可能变淡。

因此网络至少可能同时完成两件方向相反的事：

- 让远距离旧关系不至于完全失联；
- 让近距离关系中的部分互动被线上替代。

不能用“联系更多”直接替代“关系更亲密”。

### 7. contact portability has trust, privacy and custody costs

当同学关系被组织成账号、成员表和联系方式数据库以后，会新增三类成本：

1. **identity verification cost**：加入“某班”不等于真是这个人；
2. **audience-control cost**：本来只给同学看的电话、Email、QQ 可能被抓取或二次公开；
3. **memory-custody cost**：平台衰落、出售或关闭以后，旧照片、日志和好友关系由谁保管？

所以：

> **more portable social ties are also more platform-dependent social ties**

# 1. Internet 以前：通讯录本来就是一种“关系基础设施”

## 1.1 1963：一份班级通讯录显示了地点绑定的寻址结构

中国人民大学文学院今天保存并数字化的一份材料，正文明确标注为《中国人民大学文学研究班三年级同学通讯录》，日期为 **1963 年 8 月 5 日**。

当前页面：
<https://wenxueyuan.ruc.edu.cn/xyzj/ljsy/wyjy/6f05df09a2c946768cd7d6d36156b7e4.htm>

其中的联系方式不是“个人账号”，而是多种现实地点：

- 某县某镇某委某组并“转”某人；
- 某大学中文系；
- 某师范大学；
- 某县某公社某村。

### 证据性质

**原始内容的现代机构数字化。**

当前网页不是 1963 年网页，更不能证明当年的册子怎样印刷、发行多少份或每名同学是否实际使用；但它保留了一个明确日期的通讯录文本，可以用来观察当时可寻址性的形态。

### 为什么重要

联系人记录常常依附于：

```text
人
→ 住宅 / 村庄 / 工作单位 / 学校
→ 邮政系统或熟人转交
```

当人迁离原地址时，通讯录会迅速变旧。

这意味着“毕业后还能联系多少同学”不仅是感情问题，也是地址维护问题。

## 1.2 静态目录的关键弱点：address staleness

纸质通讯录解决的是：

> 在印刷时点，大家知道彼此大概在哪里。

它不能自动解决：

> 两年后，此人搬家、调动、换单位以后怎么办？

因此新增一个变量：**address staleness（地址陈旧度）**。

可以把一次关系的可达性粗略拆成：

```text
record exists
→ address still current
→ delivery channel still works
→ recipient still there
→ recipient responds
```

印过通讯录，不等于五年后还能寄到。

# 2. 中国互联网阶段边界：不能把 1994 前后压成一句“从无网到有网”

本专题的时间线必须与中国互联网接入阶段分开。

CNNIC 的互联网大事记记录：

- 1990 年 `.CN` 已完成注册，但服务器因中国当时尚未全功能接入 Internet 而放在德国；
- 1994 年 4 月 20 日，NCFC 通过 64K 国际专线实现与 Internet 的全功能连接；
- 1994 年 5 月已有与 Internet 相连的大陆 BBS 与 Web 服务节点；
- 到 1999 年末，CNNIC 统计中国上网用户约 890 万、上网计算机约 350 万；
- 到 2002 年中，网民约 4580 万，其中拨号用户仍占很大部分；
- 到 2005 年 6 月，网民约 1.03 亿，宽带上网人数首次超过网民一半。

来源：

- CNNIC，1994–1996 互联网大事记：<https://www3.cnnic.cn/n4/2022/0401/c87-912.html>
- CNNIC，2000–2001 互联网大事记：<https://cnnic.cn/n4/2022/0401/c87-914.html>
- CNNIC，第十次互联网统计报告（2002）：<https://www3.cnnic.cn/n4/2022/0401/c88-805.html>
- CNNIC，2005 年发展大事记：<https://www3.cnnic.cn/n4/2022/0401/c44-1426.html>

因此：

> **full Internet connection ≠ ordinary household reachability**

1994 是网络史上的关键节点，但不是“1994 年普通人突然都有 Email 和网上同学录”的日期。

# 3. 2001：账号开始跨过“必须坐在电脑前”的限制

## 3.1 “移动 OICQ”把桌面账号接到手机短信

2001 年 3 月 6 日新浪科技的同期报道记载，北京移动已开通“移动 OICQ”服务；移动用户不必正在上互联网，也不必有电脑，可以通过短信与 Internet 上的 OICQ 用户通信。

来源：
<https://tech.sina.com.cn/i/c/56518.shtml>

### 证据等级

**B：同期科技媒体 / 业务报道。**

它可以证明当时存在并宣传这种跨网业务路径，不能单独证明普通手机用户中的实际普及率。

### 为什么重要

这说明一个网络身份开始出现 **terminal detachment（终端松脱）**：

```text
OICQ account
↙            ↘
Internet PC    mobile SMS
```

于是：

> **account reachability ≠ desktop presence**

前一轮关于 pager 的研究已经显示“通知可以离开固定电话”；这里进一步出现“网络账号可以通过移动电信网追到离线的人”。

但这种可携带性仍依赖：

- 运营商是否开通服务；
- 手机与短信；
- OICQ / QQ 账号；
- 号码与账号绑定关系；
- 服务资费与持续运营。

它不是一种永久身份。

# 4. 2004–2005：网上班级把“同学关系”变成可搜索 namespace

## 4.1 2004：用户教程显示“找学校 / 找班级 / 建班级”已经成为标准操作

PChome 2004 年 6 月 23 日的同期用户教程《百花争艳网上同学录》描述了 ChinaRen 校友录的实际操作：用户注册或使用相关邮箱账号登录后，可以进行“我的大学”“我的中学”“我的小学”的班级搜索或创建。

来源：
<https://m.pchome.net/article/content-17875-all.html>

### 证据等级

**B：同期用户操作教程。**

它适合证明公开界面和使用路径；不应仅凭教程推断平台后端、全部用户体验或活跃规模。

### 新机制：cohort addressability

这种页面不要求先知道旧同学此刻的手机号。

用户可以：

```text
记得学校 / 年级 / 班级
→ 搜索班级
→ 进入共同 namespace
→ 再找具体人
```

这比个人 Email 的意义不同：Email 要先知道地址；同学录可以用共享过去本身作为路由键。

## 4.2 2005：异地实习与毕业迁移以后，班级还能继续工作

2005 年 3 月 18 日《解放日报》经新浪保存的同期报道记录：

- 复旦新闻学院 2002 级硕士班学生分赴全国各地实习后，在 ChinaRen 建网上同学录，用留言与即时聊天继续互通信息；
- 同济一博士班的网上班级同时承载活动通知、照片、技术讨论和春游倡议；
- 武汉大学 1996 级广电班毕业后成员分散，一名学生去了甘肃酒泉，报道中的本人说网上同学录使他仍与全国各地同学保持联系。

来源：
<https://news.sina.com.cn/s/2005-03-18/09105394097s.shtml>

### 证据等级

**B：同期报刊调查，含个人同期自述。**

不能把报道中平台页面上显示的“多少个班级”直接等同于活跃班级或独立真实班级；但具体受访者材料足以证明“毕业/异地实习后仍以网上班级维持联系”这一生活路径真实存在。

### 为什么改变 life-course 模型

标准毕业脚本常被写成：

```text
同学在一起
→ 毕业
→ 各奔东西
```

更准确的 2000s 路径可以是：

```text
同学在一起
→ 毕业 / 实习 / 跨城迁移
→ 身体分散
→ 共同网络 namespace 保留
→ 留言 / 即时通信 / 电话 / 线下聚会继续
```

也就是说：

> **geographic dispersal no longer necessarily implies addressability collapse**

但它仍不等于友情强度不变。

## 4.3 反例：近距离的人也可能把部分互动迁到线上

同一篇 2005 年报道记录了一名仍在校博士生的批评：大家都在校园甚至住在同一楼里，却可能因为依赖网上联系而减少现实中的串门和共同活动。

因此：

> **online continuity can substitute for some face-to-face interaction as well as preserve distant ties**

这防止把网络关系连续性写成纯粹“增益”。

# 5. 可携带关系也产生新的身份与隐私问题

## 5.1 2004：班级成员身份可以被冒充

2004 年 7 月 18 日《楚天都市报》经新浪保存的同期报道记录，一名武汉居民接到自称高中校友者电话，对方知道原学校信息；此后同学录管理员发布提醒，称有人冒充同学姓名加入班级并利用校友情感行骗。

来源：
<https://news.sina.com.cn/s/2004-07-18/06343116632s.shtml>

### 证据等级

**B：同期报纸个案。**

不能从一个诈骗案推断同学录普遍不可信；它证明的是一个结构性边界：

> **class membership ≠ verified offline identity**

共享学校记忆本身会形成信任，因此“能进入班级 namespace”成为需要验证的权限。

## 5.2 2005：只想给同学看的资料可能越出预期受众

2005 年 12 月 27 日《长沙晚报》经新浪保存的同期报道记录，一名用户发现自己曾填在 5460 同学录里的学校、住址、电话、Email、QQ 等信息被另一“搜人”网站展示；本人明确说原资料只针对同学公开。报道又记录 5460 一方称已暂时关闭详细联系方式显示，并限制搜索。

来源：
<https://news.sina.com.cn/c/2005-12-27/11207830273s.shtml>

### 证据等级

**B：同期媒体调查，包含用户和平台方说法。**

报道标题和网站自称的“9000 万人”规模不能直接当作已经核验的全国受害人数。

### 新边界：intended audience ≠ realized audience

网络通讯录把联系状态集中到数据库以后，会产生新的 audience problem：

```text
我以为：只给班里人看
实际：平台搜索 / 抓取 / 二次数据库 / 转载可能扩大受众
```

所以：

> **easier re-contact can be purchased with greater exposure risk**

# 6. 2018：当关系迁走以后，旧平台可能变成“记忆仓库”

2018 年 11 月人人网社交业务出售后，《长春晚报》经新浪财经保存了一组当时用户采访。

来源：
<https://finance.sina.com.cn/chanjing/gsnews/2018-11-19/doc-ihmutuec1446027.shtml>

### 证据等级

需要拆开：

- 对 2018 年“重新登录、导出、删除、担心数据去向”的行为：**B，同期采访**；
- 对 2006–2010 年早期使用习惯的叙述：**C，十余年后的回顾性自述**。

## 6.1 从“找同学”到“关注旧同学状态”

一名 2006 年注册校内网的受访者回忆，最初大家主要靠短信和 QQ；后来校内网流行后，她用它找回高中、初中甚至更早的同学，也会关注那些已经很少直接联系之人的状态。

这里可以提出而不能过度外推的机制：**ambient awareness**。

关系可以处于：

```text
可见
但少交流
仍知道近况
并未完全失联
```

这是书信/电话时代较难低成本维持的一种弱联系状态。

## 6.2 平台衰落不等于关系一起结束

同一报道中，部分受访者说毕业后朋友不再使用人人网，自己也跟着少登录；后来智能手机与新社交软件普及，互动迁往别处。

因此：

> **platform abandonment ≠ relationship termination**

旧关系可能已经交给 QQ、微信、电话或线下生活继续执行。

## 6.3 活跃关系网络与记忆保管可以分离

平台出售后，有人因为担心网站关闭/转型而导出照片与日志；也有人担心数据在所有权变化后被利用，选择删除。

这意味着旧社交平台到生命周期后期可能从：

```text
relationship infrastructure
```

转成：

```text
personal / cohort memory repository
```

两种功能不再一致。

我把这种变化称为 **memory-custody divergence（关系执行与记忆保管分离）**。

# 7. 2024：可联系很多人，仍不能直接推出“不孤独”

人民智库 2024 年 1 月通过互联网和微信公众号开展的青年调查共回收 5458 份问卷。受访者中：

- 45.8% 表示把更多时间用于线上社交；
- 56.6% 认为线上社交能缓解自身社交压力；
- 49.8% 同时认为线上社交有时会让自己感觉孤独。

来源：
<https://paper.people.com.cn/rmlt/html/2024-07/15/content_26080732.htm>

### 证据边界

这是线上招募的问卷，不应外推成“全国青年总体比例”。

它适合作为一个很好的方向性反例：

> **high contact availability and subjective loneliness can coexist**

所以本专题不能把从纸质通讯录到社交平台的历史写成“关系越来越多、越来越好”。

# 8. 海外对照：这种变化不是中国旧网独有

## 8.1 1994 Harvard：Internet 已被用来给旧朋友发 Email，但这是高接入校园

1994 年 4 月 5 日《Harvard Crimson》的同期报道记录，哈佛校方称当时约 78% 本科生拥有学校网络账号；学生用 Internet 给旧朋友发 Email、交作业、看新闻，也有人通过 Email 建立跨校关系。

来源：
<https://www.thecrimson.com/article/1994/4/5/university-moves-onto-infohighway-pdavid-s/>

### 证据边界

这是美国高接入精英大学的局部环境，绝不能当作 1994 年“普通美国人已经这样生活”的代表。

但它证明一个共同机制已经出现：

> **network account can maintain relationships after geography or institution separates people**

## 8.2 2000 Pew：在线美国人普遍报告 Email 增加部分亲友联系频率

Pew Internet 2000 年调查显示，在会给家人发 Email 的在线美国受访者中，59% 说 Email 使自己和某位重要家人的联系更频繁；给朋友发 Email 的人中，60% 对重要朋友给出类似回答。62% 的家庭 Email 使用者还说，Email 使他们可以不用花那么多时间通话也能保持联系。

来源：
<https://www.pewresearch.org/internet/2000/05/10/main-report-29/>

### 证据边界

样本对象是当时的 Internet users / email users，不是全体美国人口。

### 共同机制与中国差异

共同机制：

- 异步电子消息降低维系弱联系的时间成本；
- 网络账号降低距离对联系的限制；
- 数字目录/社交网络帮助找回曾失联的人；
- 联系增加不自动等于亲密增加。

中国需要单独解释：

- 1994 全功能 Internet 接入与普通家庭可及之间的巨大时间差；
- 2000s 大量拨号、网吧、学校/单位接入；
- OICQ/QQ 与移动短信的跨网桥接；
- 5460、ChinaRen 等“班级 namespace”在中文旧网中的独特重要性；
- 后来 QQ/微信等平台接管关系执行，旧同学录/SNS 转为记忆残留。

# 9. 四个“未来时间感”时期怎样与联系连续性相交

这轮证据能补充四时期模型，但只在证据够强的位置落笔。

## 9.1 2005–2012：扩张型未来中的“迁走仍可保持旧关系”

2005 年分赴全国实习的硕士班、毕业去甘肃的武汉大学校友说明：

> 跨城流动不再必然要求切断原来的同学联系。

这可能降低迁移的部分社会成本，并使“去更远的地方工作/实习”更可执行。

但目前证据只能支持：

- 迁移后关系可以继续；
- 人们确实这样使用同学录。

还不能支持：

- 因为有同学录，所以更多人愿意迁移。

后者需要直接因果或同期动机证据。

## 9.2 2015–2019：关系可见性延续，但注意力和平台生命周期成为瓶颈

2018 年的人人网采访显示，一部分早期用户仍然能够回看旧同学和旧数据，却已经把日常社交迁到新平台；旧账号甚至因多年不用而忘记密码。

这一阶段的变化更像：

> **addressability can outlive active attention**

“我还能找到你”与“我仍每天在这里和你说话”分开了。

## 9.3 2020–2022：本轮没有新增足够的一手证据

已有仓库专题已经处理疫情期间远程关系和数字共在。本轮不再用二手材料重复证明。

## 9.4 2023–2026：线上可联系与孤独可以并存，但不能强行解释成“防守型未来”

2024 调查只能说明受访青年对线上社交同时感到便利、低压力和部分孤独。

它不足以证明“防守型未来导致弱联系增多”或“年轻人为了保退路而维持更多联系人”。这些仍需要同期第一人称与行为链。

# 10. 对“普通人到底有多少种活法”的新理解

这一轮增加的不是一种职业或婚姻类型，而是一种**跨阶段维持旧关系的能力**。

同一个人可以走出几种此前容易被历史叙述忽略的生命路径：

### 路径 A：毕业即关系快速衰减

```text
毕业
→ 地址失效
→ 新单位 / 新城市
→ 少数关系靠书信电话维持
→ 多数弱关系逐渐丢失
```

### 路径 B：毕业后保留班级 namespace

```text
毕业 / 迁移
→ 网上班级仍在
→ 更新联系方式
→ 偶尔留言 / QQ / 电话
→ 多年后仍可重新找到
```

### 路径 C：弱关系长期“可见但不常说话”

```text
同学关系
→ SNS 互加
→ 很少直接对话
→ 仍能看到状态
→ 某个生活节点重新联系
```

### 路径 D：关系迁走，旧平台只留下记忆

```text
旧平台建立关系图
→ 日常沟通迁到新平台
→ 旧账号沉寂
→ 多年后回去看照片 / 日志
→ 导出或删除历史数据
```

这些路径说明：

> **“失联”与“仍是朋友”之间存在大量中间状态。**

历史研究如果只看面对面共同生活或明确通信记录，会漏掉大量“可重新激活但平时沉默”的关系。

# 11. 重点矩阵更新

| 维度 | 本轮新增理解 |
|---|---|
| 教育 | 学校/班级不仅是教育单位，也成为毕业后的关系 namespace |
| 就业 | 换城市、实习、就业后仍可通过旧同学网络维持信息与支持 |
| 住房 | 搬家不再必然要求重新分发全部社交地址，但仍可能造成联系方式变化 |
| 婚姻家庭 | 旧同学/弱关系可在多年后重新激活，但本轮不把可见性直接等同于关系形成 |
| 迁移 | migration cost 应包含 contact-repair cost；网络可降低其中一部分 |
| 照护 | 本轮只有间接意义，未新增强证据 |
| 非正规劳动 | 旧同学弱关系可能成为信息渠道，但本轮没有直接案例，不外推 |
| 长期中断 | “多年不联系但还能找到”成为一种可观察中间状态 |
| 证件与记录 | 班级成员身份会产生验证问题；实名/校友身份不能自动互相替代 |
| 通信方式 | 地址、固定电话、手机、Email、QQ、SNS 形成 contact-portability gradient |
| 互联网平台 | 班级 namespace、可变 profile、SNS 状态构成不同关系基础设施 |
| 信息获取 | 弱关系不只用于直接问询，也可通过状态流形成 ambient awareness |
| 社交关系 | contact continuity、conversation continuity、intimacy 必须分开 |
| 未来预期 | 迁走以后不必完全失去旧关系，可能扩大可执行的城市/工作路线，但因果尚未证实 |
| 线上/线下身份 | 班级身份是信任资源，也是冒充与验证风险 |
| 平台消失与记忆 | 活跃关系可以迁走，旧平台转成 memory repository；所有权变化触发导出/删除 |

# 12. 证据等级、反例与后见之明风险

## 已证实

- 1963 年已有以住宅、单位/学校等地点记录为核心的班级通讯录文本；
- 2001 年北京已有把 OICQ 与手机短信桥接的商业服务；
- 2004 年同学录网站允许按学校/班级搜索和创建网上班级；
- 2005 年有异地实习、毕业迁移者同期自述使用网上班级保持同学联系；
- 2004–2005 年已经出现班级成员冒充与半私密联系方式被二次利用的问题；
- 2018 年平台出售时，有旧用户因为担心数据去向而导出或删除历史内容。

## 可以合理推断

- 可搜索班级降低了“我不知道旧同学当前地址”造成的重新寻找成本；
- 可变 profile 降低了静态通讯录的地址陈旧问题；
- SNS 状态流让一部分弱关系进入“少交流但仍可见”的长期状态；
- 平台生命周期会把“关系执行”和“记忆保管”分离。

## 不能据此推出

- 互联网导致人们更愿意跨城迁移；
- 同学录让友情普遍更深；
- 加入同学录的人都长期活跃；
- 平台会员数等于真实个人数或活跃同学数；
- 一个班级页面今天存在，说明当年该班级长期活跃；
- 线上社交让人更孤独，或更不孤独。

## 反例

- 2005 年同一篇报道已经记录：近距离学生可能因为依赖网上联系而减少线下互动；
- 2018 年旧用户可以仍记得平台、仍保存数据，却早已不在该平台执行日常关系；
- 2024 年问卷中，受访者可以同时认为线上社交降低压力，又感到孤独。

## 后见之明风险

1. 不把“QQ / SNS 最终成功”投射回 2001，假定当时用户已知道账号会长期存在；
2. 不把 1994 全功能 Internet 接入写成普通家庭从此联网；
3. 不把今天仍可访问的媒体转载页当作历史原始同学录页面；
4. 不把 2018 年对 2006 年的回忆冒充 2006 同期材料；
5. 不把当前数据库中最后一次 profile 状态当作完整生命史。

# 13. 尚未确定之处

下一步真正有价值的不是再找“某同学录有多少用户”，而是找**同一个普通账号的多时点联系状态**：

```text
在校地址 / 班级
→ 毕业去外地
→ 更新单位 / 手机 / Email
→ 若干年后再换城市
→ 平台迁移到 QQ / SNS / 微信
→ 旧平台沉寂或删除
```

尤其需要：

1. 1999–2006 中文同学录的真实历史 capture，而不是后来媒体截图；
2. 同一 profile 在两个以上年份的版本，用来测量 `contact-state mutation`；
3. 同期用户明确写“搬家/毕业后我怎样通知所有人”的第一人称材料；
4. 一个班级从创建、活跃、毕业后延续到迁移平台的连续链；
5. 普通用户如何处理学校 Email 失效、手机号变化、QQ 盗号/密码遗忘等断裂；
6. 2023–2026 同期第一人称材料，判断人们是否主动把弱关系当作职业、迁移或危机中的 optionality，而不是由研究者事后赋义。

如果能找到这样的序列，研究就可以从“网络让旧关系更容易被找回”进一步推进到：

> **一个人的社会地址，在真实生命历程中究竟怎样被一次次维修、迁移和遗失。**
