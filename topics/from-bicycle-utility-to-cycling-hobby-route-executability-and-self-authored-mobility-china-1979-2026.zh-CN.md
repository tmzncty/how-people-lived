# 从“自行车王国”到周末骑行：工具性移动、路线可执行性与自我编排的移动生活（中国，1979—2026）

> 研究问题：同一辆自行车，为什么在一个时代首先是上班、买菜、接孩子的交通工具，在另一个时代又可以成为周末训练、长途旅行、社交、减脂、亲子活动甚至暂时中断学校/工作的理由？Internet 到来以前，骑行者怎样获得路线、维修、住宿和同伴信息；论坛、GPS、运动 App 到来以后，又真正改变了哪一层？
>

>

## 1. 核心结论：同一个物件可以从“必须移动”变成“主动去移动”

自行车是 Hobby Life Worlds 里一个结构很特殊的对象。

Hi-Fi、摄影、吉他通常需要额外挤出一块兴趣时间；自行车却可能同时存在于：

```text
上班 / 上学 / 买菜 / 接送
+
健身 / 减脂
+
周末休闲
+
长途旅行
+
赛事 / 挑战
+
同好社交
```

因此它最适合研究 **utility-to-hobby decoupling / 工具性移动与兴趣移动的分化**：

> 当一种原本主要承担日常交通的技术，在汽车、公交、地铁等替代交通扩张以后，不一定消失；它可以重新被一部分人定义成“我主动选择的身体活动”。

这不是简单的“自行车衰退 → 骑行复兴”。工具性骑行和兴趣骑行长期共存，而且对道路、时间、车辆、风险和数字服务的需求并不一样。

## 2. 先拆状态：有自行车 ≠ 骑行爱好者

至少区分：

```text
家庭拥有自行车
→ 会骑车
→ 把自行车用于日常出行
→ 偶尔为了休闲多骑一点
→ 主动寻找路线 / 车友 / 装备 / 训练信息
→ 固定把晚间或周末留给骑行
→ 购买更适合特定用途的车辆与装备
→ 参加俱乐部 / 赛事 / 长途骑游
→ 记录速度、距离、爬升、路线
→ 因工作、家庭、伤病、迁移暂停
→ 通勤化 / 小型化 / 亲子化 / 再次重返
```

固定边界：

- `自行车拥有率 ≠ 骑行爱好者比例`；
- `每天骑车上班 ≠ 把骑车当 hobby`；
- `买了公路车 ≠ 稳定训练`；
- `论坛发起骑行 ≠ 活动实际发生`；
- `活动报名 ≠ 到场 ≠ 完赛`；
- `路线帖存在 ≠ 今天仍安全 / 可骑 / 可通行`；
- `GPS 记录存在 ≠ 能完整证明人的身体经验`；
- `骑行热报道 ≠ 所有青年都在骑行`。

本题把从“我想骑到某地”到“我和车真的安全完成这一段”称为 **route executability / 路线可执行性**。

## 3. Internet 前基线：自行车早已普及，但主要作为普通生活基础设施

国家统计局历史资料显示，1979 年城镇居民平均每百户拥有自行车 **113.0 辆**，农村居民为 **36.2 辆**。这说明改革开放初期自行车已经是非常重要的家庭耐用品，尤其在城镇；但这个数字只能证明 household possession，不能证明人们已经形成今天意义上的公路车、山地车、周末训练或骑游文化。

来源：

- 国家统计局，第十届统计开放日历史资料：<https://www.stats.gov.cn/zt_18555/zthd/sjtjr/d10j/70cj/202302/t20230216_1909159.html>

证据等级：**A/B（国家统计机构对历史统计的官方整理）**。

因此前互联网时期必须先保留一个非常清楚的结构：

```text
自行车高度普及
≠
骑行作为独立兴趣已经高度普及
```

但兴趣化并非 2000s 才出现。后来对“杨桂林家庭自行车赛”的整理称，这项民间家庭自行车活动自 1984 年开始；类似材料至少证明，80 年代已经存在把自行车从日常交通抽出来，作为比赛、家庭活动或娱乐的实践。由于目前取得的是后来的行业媒体整理，这一条只作 **C/B 级前史锚点**，不外推其社会规模。

来源：<https://www.biketo.com/racing/14708.html>

另一类前 Web 路线来自报刊刺激。2016 年对老骑友李从明的回顾称，他原是工艺美术系统职工，1989 年在《辽宁青年》看到余纯顺旅行材料后开始自行车远行，当年骑行西南六省，后来又多次跨省旅行。它是多年后的个人回忆，证据等级 **C**；价值不在于精确重建每段路，而在于证明一种前互联网链条实际可行：

```text
杂志人物 / 游记
→ 想象远方
→ 地图、道路、问路、维修等离线知识
→ 现实长途骑行
```

来源：<https://sports.sohu.com/20160521/n450751862.shtml>

Internet 没有发明“骑车去远方”。它后来压缩的是路线发现、同伴联系、装备知识和经验复用的成本。

## 4. 海外前互联网对照：长途骑游本来就需要一整套“路线信息基础设施”

美国 1976 年 Wisconsin 官方 bicycle guide 是非常好的 A 级原始材料。它不仅画路线，还列出 camping area、bike shop、天气（温度、降雨、风）、准备与安全建议，并把路线拆成一天一天可以执行的行程。

来源：

- Wisconsin Historical Society, *Bicentennial Bike Map of Wisconsin* (1976)：<https://www.wisconsinhistory.org/record/map/W014GTN/bicentennial-bike-map-of-wisconsin>
- *Wisconsin Bikeway Map and Guide* (c. 1976)：<https://www.wisconsinhistory.org/record/map/W014GTF/wisconsin-bikeway-map-and-guide>

这说明 Web 前的骑游并不是“有张公路地图就走”。一条长途路线真正可执行，还需要：

```text
道路
+ 每日距离
+ 天气
+ 水 / 食物
+ 住宿 / 露营
+ 修车点
+ 安全知识
+ 时间预算
```

Adventure Cycling Association 的机构史称，Bikecentennial 组织者在 1975 年集中绘制 TransAmerica Trail，1976 年首轮活动有 4,000 余名骑手参加。虽然这是后来机构史，不能替代全部 1976 原件，但与同时代地图、指南可以互相校验：前 Internet 的兴趣旅行已经能够靠纸质路线、组织者、俱乐部和口碑形成规模化网络。

来源：<https://www.adventurecycling.org/about-us/history/>

跨国共同机制因此不是“Internet 让人第一次能长途骑行”，而是：

> **Internet 把一部分原本要靠纸质地图、俱乐部、店铺、邮寄和口耳相传维护的 route infrastructure，变成了更快更新、更容易检索和复制的同行知识。**

## 5. 1995：Usenet 已经把“路线怎么骑”做成陌生人之间的即时问题

1995 年 `ba.bicycles` / `rec.bicycles.rides` 一条同时代帖子里，旧金山一名用户寻找 25—60 英里的训练路线，希望直接从市区骑出去，不必把车装上汽车或 BART；回复者甚至会区分“training ride”和“ride for pleasure”。

来源：<https://groups.google.com/g/ba.bicycles/c/uuvkpTQ0ryA>

证据等级：**A（同时代 Usenet 帖）**。

这里已经出现 **route addressability / 路线可寻址性**：

```text
我有一个非常具体的身体 / 时间 / 交通约束
→ 向陌生人描述
→ 别人按本地经验给出路线
```

而且它早于大众 Web 的常态化。全球互联网前史因此不能从网页开始算：邮件列表、Usenet 等已经在改变兴趣知识的半径。

## 6. 2005—2012：扩张型未来——兴趣旅行甚至可以暂时改写学校与工作日历

### 6.1 2008：三名在校生为了 15,000 公里骑行正式休学

2008 年国际在线/新浪同期报道，华中科技大学“远征协会”成员在 2007 年底筹划雅典到北京骑行；8 人队伍中有 3 名在校生办理休学手续参加，2008 年 3 月 4 日从雅典出发，路线约 15,000 公里，经多国骑回中国。途中也有人因为学校、家庭事务退出或被家人要求返回。

来源：<https://news.sina.com.cn/s/2008-08-01/160214253292s.shtml>

证据等级：**B（同期媒体采访/观察）**。

这比“大学生周末骑车”更强。它证明兴趣活动可以产生 **planned life-course interruption / 计划性生命历程中断**：

```text
正常学业日历
→ 提前数月规划一条长路线
→ 正式休学
→ 长途骑行成为数月主要生活
→ 再回学校 / 转入下一阶段
```

标准人生脚本并不是每一分钟都必须持续推进。至少对少数有资源和意愿的人，兴趣可以合法地暂时占据人生主进程。

这里不能外推“2008 青年普遍敢休学旅行”。这是一个高投入、高筛选、媒体可见度很高的个案。但它是非常强的反例：**非职业兴趣并不总是被挤在“剩余时间”里，它偶尔会要求整个日历让路。**

### 6.2 2008：更多学生型骑行仍然发生在完整的一天和暑假里

同年广州约百名大学生和自行车协会成员绕珠江骑行 40—50 公里，活动从上午持续到傍晚，参与者同时把它描述为认识同好和参加公共活动的方式，组织者还计划暑期广州—北京骑行。

来源：<https://news.sina.com.cn/c/2008-04-14/010213730038s.shtml>

这种实践更接近日常可复制的 **calendar capture / 日历占用**：兴趣不是“每天十分钟”，而是一次占掉整块白天、周末或整个假期。

## 7. 2009—2010：中文垂直 Web 把长途骑行变成可复制的路线文本

BIKETO 当前仍保留 2009—2010 年的大量 legacy pages。必须强调：这些是**今天仍在线、承载历史日期内容的当前页面**，不是本轮验证过的 2009/2010 Wayback capture；当前导航、评论数、样式和后台不能直接当成历史 DOM。

但其中的正文可以用来观察一种已经形成的 Web 知识结构。

2009 年“躺车网址大全”把 CAD、车体图纸、轮组、减震、国际组织和大量站内论坛 URL 放在一页，且历史链接同时出现 `www.biketo.com`、`www2.biketo.com` 以及不同 thread URL pattern。来源：<https://www.biketo.com/racing/70.html>

2010 年 BIKETO 编辑又整理“值得收藏的 101 篇自行车旅行游记”，保留大量精确旧论坛 locator，例如：

- `viewthread.php?tid=65737` — “08 新疆骑情”；
- `viewthread.php?tid=82105` — “2009 单骑新藏线”；
- `viewthread.php?tid=58214` — “08 年 4 月川藏线骑行记”。

来源：<https://www.biketo.com/tour/1528_2.html>

这说明骑行论坛不只在聊天，它逐渐承担 **route memory / 路线记忆**：

```text
一个人实际骑过
→ 写日记、路线、补给、路况和照片
→ 论坛积累
→ 编辑重新索引
→ 后来者把前人的路径当作自己的计划输入
```

Web 使“别人曾经怎么到达那里”变得可搜索，但仍然不能自动保证几年后的道路、住宿、施工和天气条件相同。

因此固定：

> **route text survives ≠ route remains executable**。

## 8. 2015—2019：拥堵型未来——骑行越来越制度化，也开始与城市其他用途争用基础设施

### 8.1 一条自行车道可以同时属于通勤者和运动者

北京首条自行车专用路 2019 年 5 月 31 日开通，全长约 6.5 公里，设计目标之一是服务回龙观—上地区域约 1.16 万通勤人口，限速 15 km/h。开通一周后，新京报报道累计通行 7.8 万余车次，同时出现骑专业车辆、时速三四十公里的运动型骑手。

来源：

- 人民网/中国城市报，2019-06-03：<https://paper.people.com.cn/zgcsb/html/2019-06/03/content_1928415.htm>
- 新京报/人民网，2019-06-07：<https://society.people.com.cn/n1/2019/0607/c1008-31124771.html>

这里出现 **transport–sport overlap / 通勤—运动重叠**：

```text
同一条基础设施
→ 一部分人想稳定、可预测地上班
→ 另一部分人把它当训练路线
→ 速度、超车和空间使用发生冲突
```

因此兴趣生活并不悬浮在城市之外。它会真实进入交通治理、限速、安全和公共空间分配。

### 8.2 兴趣组织也可能产生现实责任

2018 年北京一宗骑行事故后的诉讼，引发车友圈重新讨论群体骑行的组织责任。同期报道显示，一次非正式车友骑行也可能涉及路线安排、领队、参与者风险和事后责任认定。

这提示一个新制度接口：**informal hobby organizer / 非正式兴趣组织者** 可以在事故发生后突然变成法律和责任系统中的可识别角色。

换言之：

`QQ群/论坛里喊一声周末骑车`

并不永远只是“朋友相约”。在高风险活动里，线上协调可能制造现实义务。

## 9. 2020—2022：偶发型未来——远方减少以后，本地半径重新变得有价值

2022 年中新网同期采访中，骑行队长孙洪涛回忆疫情前因为工作忙，最远只骑到北京—草原天路；2020 年春天他组织疫情后第一次小规模短途骑行时，街上人很少，骑行过程中能感觉到积累的压力逐渐释放。之后队伍更多去北京近郊路线。他还观察到年轻人和家庭骑行增加。

来源：<https://www.chinanews.com.cn/sh/2022/07-26/9812048.shtml>

证据等级：**B（同期采访，其中部分内容为受访者对两年前的近时回顾）**。

报道同时明确把疫情期间远距离出行减少，与骑行、露营等城市周边活动上升联系起来。

这可以称为 **local-radius substitution / 本地半径替代**：

```text
跨省 / 长途旅行不稳定
→ 人仍需要离开室内、移动、看见不同空间
→ 自行车把“远方”缩成城市与近郊几十公里
```

它不是“无法旅行所以只好骑车”的单因果模型。骑行本来就存在；冲击只是改变了哪些尺度的移动更容易执行。

## 10. 2023—2026：防守型未来并没有消灭扩张型的兴趣目标

2025 年《中国证券报》同期采访提供了非常具体的当代骑行状态。上海张江一名 31 岁互联网从业者在 33 公里骑行结束后，用码表记录最大速度 39.7 km/h、平均速度 28.7 km/h、总时长约 55 分钟，并把“比上次明显提升”作为评价；另一名骑手从上下班骑行开始，后来在周末和节假日安排 50 公里以上的高强度路线；现场还有家长给幼儿买平衡车，并计划随着年龄增长升级到更专业儿童自行车。

来源：<https://www.ce.cn/cysc/newmain/yc/jsxw/202504/25/t20250425_39349781.shtml>

证据等级：**B（同期媒体采访）**。

这里出现两个新机制。

### 10.1 quantified leisure / 量化休闲

```text
我今天出去骑了一圈
→ 距离 / 速度 / 爬升 / 心率 / 时间进入设备
→ 与昨天、朋友、路线、目标比较
→ 下一次训练按数据重新规划
```

运动码表、GPS 和 App 让兴趣获得持续的数字反馈，使“玩”部分变成可以优化的个人项目。

### 10.2 hobby micro-future / 兴趣微型未来

父母可以计划“孩子以后换更专业的车”，普通上班族可以计划下一次 50 km、100 km 或更快配速。即使宏观生活更强调稳定、现金缓冲和退路，兴趣世界仍可能保留明确的扩张性小目标。

因此不能把“2023—2026 防守型未来”写成每个人在所有生活领域都悲观收缩。

**反例本身很重要：宏观未来感与兴趣微型未来可以同时存在。**

## 11. Internet 到底改变了什么？

骑行提供了一个比纯数字兴趣更清楚的答案。

### Internet 没有创造

- 骑车旅行；
- 自行车比赛；
- 俱乐部；
- 纸质路线与维修知识；
- 骑友之间的经验交换。

### Internet 明显压缩了

- 找路线的时间；
- 找同城车友和俱乐部的成本；
- 异地路况/装备/维修经验的获取摩擦；
- 游记从一次性叙述变成可检索档案的成本；
- 二手器材和零部件的交易半径；
- 活动报名、保险、结果发布等组织成本；
- 个人骑行数据的记录和比较成本。

### 但 Internet 仍无法替代

- 连续三小时、一天或数周的现实时间；
- 身体训练；
- 道路和路权；
- 风、雨、炎热、寒冷；
- 机械故障；
- 吃饭、喝水、住宿；
- 事故风险；
- 家庭和工作是否允许你那天真的出门。

因此骑行是非常典型的 **screen-to-road gap / 屏幕—道路缺口**：

> 网页可以把一条路描述得非常完整，但最后仍然需要一个身体、一辆车和一整块现实时间把它跑通。

## 12. 与标准人生脚本的关系

骑行案例补出了几种过去 Hobby Life Worlds 里还不够突出的生活路径：

### 12.1 兴趣可以暂时覆盖主日历

2008 的休学骑行说明：兴趣有时不是“下班以后”，而是主动让学校或工作阶段暂停。

### 12.2 兴趣和通勤可以共享同一次动作

一个人早上骑车去公司，同时也在完成每日运动。这里“工作时间”和“兴趣时间”并非完全可分。

### 12.3 同一兴趣可以随年龄重写

```text
大学：社团 / 长途梦想
→ 初职场：通勤 / 周末骑
→ 有家庭：亲子骑 / 更短路线
→ 中年：训练 / 赛事 / 长途重新进入
```

这些只是需要继续验证的典型路径，不是统一生命周期。

## 13. 历史可见性偏差

### expedition bias / 远征偏差

15,000 公里休学远征比一个普通人每周骑 20 公里更容易被媒体记录。不能让极端路线代表普通骑行者。

### gear bias / 装备偏差

昂贵公路车和整套装备更容易进入商业报道；大量普通通勤、旧车、二手车和低预算兴趣骑行更难留下“漂亮”史料。

### successful-route bias / 完成路线偏差

完成川藏、新藏、环岛的人会写游记；计划失败、半途撤退、受伤、工作突然加班而没出发的人更难进入路线档案。

### metric bias / 数据偏差

现代平台更容易保存速度、距离和排名，却不一定保存为什么今天骑、和谁一起、途中害怕什么、为什么半年后不骑了。

### platform-survival bias / 平台幸存偏差

BIKETO 等长期在线平台使某类骑行显得历史特别连续；已经消失的地方论坛、QQ群、个人博客和俱乐部主页可能让其他群体在历史里变薄。

## 14. 证据强度、反例与尚未确定

### 已经可以较强支持

1. 1979 年自行车在中国城镇家庭中已是高度普及耐用品，但不能等同于 hobby 普及。
2. 长途/竞技/娱乐型骑行在大众 Web 前已经存在，并依赖纸质路线、社团、报刊和店铺等离线基础设施。
3. 1990s Usenet 已经把本地训练路线和骑行经验变成可向陌生人查询的问题。
4. 2000s 中文垂直 Web 把大量骑行游记、线路、图纸、活动和装备经验积累成可搜索/再索引的知识库。
5. 兴趣骑行既可以占用周末，也可能在少数情况下触发休学/辞职等主日历中断。
6. 2019 后城市慢行基础设施可以同时服务通勤和运动，并产生速度与使用冲突。
7. 2020—2022 的冲击强化了部分城市居民对本地/近郊骑行半径的使用。
8. 2020s 码表、GPS、App 使骑行越来越数据化，但数据化不等同于生活经验完整可见。

### 反例

- 不是“汽车来了，自行车才成为 hobby”：80 年代已经有娱乐/赛事前史。
- 不是“Internet 来了，才有人骑长途”：纸质地图、杂志、俱乐部和组织已经能支持跨地区骑游。
- 不是“骑行热 = 年轻人消费升级”：通勤、减脂、亲子、低预算二手和竞技都是不同路线。
- 不是“防守型未来 = 所有兴趣都收缩”：2025 同期材料仍能看到速度、距离和亲子升级等扩张型微目标。

### 尚未确定

- 1980s—1990s 中国普通业余骑游者的预算、住宿、维修和地图获取，仍缺足够多同时代第一人称材料；
- 山地车/公路车在中国从专业/小众产品进入普通爱好者市场的精确价格与地域扩散时间线仍需补；
- 2002—2008 中国主要自行车 BBS 的历史 DOM、charset、附件和账户状态仍缺 verified capture；
- 女性骑友、县城/农村 hobby cycling、制造业工人/服务业轮班者的时间结构目前明显不足；
- 2026 的同期第一人称材料暂未形成足够强的新结论，不应为了覆盖年份硬补。

## 15. 这一题改变了我们对“人怎么活着”的哪一点理解

此前兴趣生活容易被理解成：

> 正事做完以后，拿剩余时间玩点东西。

自行车说明这不够。

一项兴趣可以和上班共用同一段路，可以一次占掉整个周末，可以成为一年的训练计划，可以让人在大学里休学几个月，也可以在远行突然不可靠的时候，把“我还能去哪”重新缩放到城市周边几十公里。

所以更准确的说法是：

> **兴趣不只是填满剩余时间，它有时会重新划分人的时间和空间。**
>
> 一个人的人生半径，不只由工作地点、房价和交通线路决定，也可能由她愿意用自己的腿，在一个晚上、一个周末或一个暑假里，到底走多远决定。
