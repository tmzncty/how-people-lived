# 从《家庭医生》读者信箱到病友群、医生主页与互联网复诊：疾病信息、病友可寻址性与照护连续性（中国，1983–2026）

> 研究问题：一个普通人发现身体长期“不对劲”以后，怎样知道这可能是什么病、该去哪里看、怎样找到与自己有类似经历的人，又怎样在数月、数年甚至数十年的病程中维持与医生、药物、检查和病友之间的联系？互联网改变的只是“查资料更快”，还是改变了慢性病、罕见病和长期照护本身可以怎样被组织？

本专题与急救、一般医疗可及性、照护劳动等主题相邻，但不重复。急救研究问的是：**人在几分钟内如何被系统找到并得到响应。** 本专题问的是另一种时间尺度：

> **如果疾病不是一次事件，而是十年、二十年甚至终身的生活条件，一个人如何把零散症状、医生、检查、药物、病友经验和制度资格持续接起来？**

本专题尤其关注四个边界：

1. 健康信息可见不等于医学上可靠；
2. 病友经验可贵不等于病友群拥有诊断权威；
3. 在线咨询可进入照护链，但不等于完整线下诊疗；
4. “平台有服务”不等于所有地区、年龄、城乡、疾病类型的人都能实际使用。

---

## 一、核心结论

### 1. 疾病也会形成一种“可寻址性”

前互联网时代，一个人可能只知道“头晕”“关节痛”“孩子发育慢”“这个病医生说很少见”。她能接触到的解释，往往取决于：

- 当地医院和医生；
- 报刊、广播和医学科普书；
- 亲友经验；
- 给杂志或专家写信；
- 是否能去更大的城市；
- 是否知道一个准确的病名。

互联网以后，病名、症状、药名、医院和医生逐渐都变成可查询对象。一个人第一次可以大规模地从：

```text
“我不知道这是怎么回事”
→ 搜索症状/病名
→ 找到疾病页面
→ 找到医生/医院
→ 找到病友论坛或群
→ 继续追问
```

因此，本专题把 **`illness information addressability / 疾病信息可寻址性`** 定义为：

> 一个人能否把模糊的身体经验逐步映射到可以搜索、比较、求证的疾病、药物、医生、医院和患者社群对象。

它不是“网上自我诊断”的同义词。恰恰相反，越能搜索，越需要区分什么只是线索，什么才是诊断。

### 2. 病友可寻址性与医学权威必须分开

互联网还带来了另一种过去成本极高的能力：

> **一个罕见、污名化或长期疾病患者，可以找到另一个并不住在同一城市、甚至从未见过面的患者。**

这可以称为 **`peer-patient addressability / 病友可寻址性`**。

病友之间能够交换：

- 哪里看过病；
- 哪个检查怎么做；
- 药物副作用的日常感受；
- 住院和复诊的实际流程；
- 医保、报销、药物可及信息；
- 工作、恋爱、家庭照护如何调整；
- 对疾病的情绪支持。

这些是医生门诊很难完整提供的生活知识。

但必须保留：

```text
病友有共同症状
!= 病友拥有同一诊断
!= 群体共同相信某种解释
!= 临床证据支持该解释
!= 某种治疗安全有效
```

2009 年“未知病毒”病友群就是极好的反例：成员通过网络聚集，彼此确认相似症状，但多次医学检测并未支持他们坚持的疾病解释。互联网可以帮助人找到支持，也可以稳定一个未经验证的共同诊断框架。

### 3. 标准人生脚本常把“生病”写成短暂插曲，慢性病却会形成另一种生命历程

标准叙事常隐含：

```text
生病
→ 看医生
→ 治好
→ 回到工作/学校/家庭“正常轨道”
```

但慢性病、罕见病、精神疾病、免疫疾病和长期残障常常不是这样。

现实路径可以是：

```text
多年症状不明
→ 多地求医
→ 获得暂定诊断
→ 重新检查
→ 正式确诊
→ 长期用药/康复
→ 因病中断工作或教育
→ 定期异地复诊
→ 调药
→ 等待新药/医保准入
→ 病友互助
→ 自己变成病友组织者
```

因此，本专题引入 **`care continuity / 照护连续性`**：真正重要的不只是某次是否看上医生，而是几年后是否仍能继续获得检查、医生判断、药物、记录和必要的制度资格。

### 4. 数字化最重要的价值之一，是压缩“为了维持照护而移动”的次数

对健康的人来说，“少跑一次医院”可能只是方便。

对需要氧气、行动困难、异地就医、照护孩子、无法请假或每月复查的人来说，它可能意味着：

- 少一次长途交通；
- 少一次家属陪同；
- 少一次请假；
- 少一次挂号和候诊；
- 少一次病情恶化风险；
- 少一次因体力不够而放弃复诊的可能。

这可以称为 **`care-mobility burden compression / 照护移动负担压缩`**。

它解释了为什么在线复诊对慢性病患者的意义不能只按“节省多少分钟”衡量。

### 5. 患者和家属有时会从服务使用者变成疾病基础设施建设者

2023–2026 的材料显示一种此前很少被标准职业分类记录的人生路径：

```text
患者 / 家属
→ 长期积累疾病经验
→ 帮助新患者解释流程
→ 整理药物/医保信息
→ 组织病友
→ 联系医生和科研人员
→ 成为公益项目负责人/患者组织者
```

这可以称为 **`patient/caregiver-to-organizer transition / 患者或照护者向组织者转变`**。

这不是要浪漫化疾病。它首先意味着一个人被迫投入了巨量时间；只是其中一部分经验后来被转化成了社会组织能力。

## 二、证据规则

### 2.1 网络阶段不能压成一个“上线”日期

中国侧至少区分：

1. **1980s：科研、远程登录、电子邮件等前互联网数字通信已经存在；**
2. **1994-04-20：实现与 Internet 的全功能连接；**
3. **1995 起：公用互联网逐渐向社会开放；**
4. **1990s 后半：门户/BBS/个人网页等出现，但用户仍是少数；**
5. **2000s：用户快速增长，城乡、教育、年龄和收入差异仍很大；**
6. **智能手机后：移动入口改变使用频率与使用地点；**
7. **互联网医院阶段：部分咨询、复诊、处方、支付和配送开始进入正式医疗事务链。**

中国科学院档案材料可确认：1986 年高能所已经通过卫星链路远程登录 CERN 并发送电子邮件；1987 年又有更广为人知的“越过长城，走向世界”电子邮件。1994 年 4 月 20 日 64K 专线开通以后，中国才实现全功能接入国际互联网。

来源：

- 中国科学院档案馆，2024，《中国互联网从中国科学院起步——中国接入互联网始末》：
  https://www.acas.ac.cn/byyxc/bydt/202404/t20240422_7174874.html
- 中央网信办，2024，《中国全功能接入国际互联网30周年述评》：
  https://www.cac.gov.cn/2024-04/20/c_1715291120716362.htm

因此不得把“1994 年之前没有互联网”写成“1994 年之前完全没有数字网络通信”；也不得把科研机构能发邮件写成“普通家庭已经可以上网查病”。

### 2.2 个人材料的同时性标签

本专题沿用：

- **T0**：当事人同期自发文字；
- **T1**：同期采访中的当事人叙述；
- **T2**：近时期回顾；
- **T3**：多年后回忆；
- **TX**：时间关系不清。

医疗材料尤其需要防止“后来已知结局”倒灌到当时。

### 2.3 健康材料不做临床建议

本文件研究的是历史上的信息与照护基础设施，不使用旧帖子、病友经验或新闻个案对任何现实个体作医学诊断或治疗建议。

## 三、前互联网：杂志、读者来信与专家信箱已经在连接陌生患者和医学专家

### 1983：《家庭医生》把医学知识带进普通家庭

中山大学资料可确认，《家庭医生》杂志创刊于 1983 年，明确以服务大众求医问药和医学保健知识需求为办刊方向。后来的校方材料记录其长期保持很大的发行规模。

来源：

- 中山大学工会，2013：
  https://zdgh.sysu.edu.cn/article/789
- 中山大学产业集团，2013，《〈中国家庭医生〉杂志举办创刊30周年庆典》：
  https://cyjt.sysu.edu.cn/article/420

**可确认（A/B institutional retrospective）**：大众 Web 以前，大规模医学科普期刊已经把专业医学知识带进家庭。

**不能推出**：每个家庭都订阅，或所有地区、文化程度人群获得信息的机会相同。

### “柯大夫信箱”：纸张和邮政构成早期异步问答系统

《家庭医生》长期设置“柯大夫信箱”等问答型栏目，后来还发展出与之相连的线下门诊和网络问答。其最重要的技术特征其实很朴素：

```text
读者写信
→ 邮政运输
→ 编辑部筛选
→ 专家回答
→ 印刷
→ 下一期杂志送达
```

这是一个低带宽、高延迟的远程健康问答系统。

它已经具备后来网络问答的几个核心要素：

- 陌生人可以提出私人健康问题；
- 专家回答可以被一个提问者以外的大量读者共同看到；
- 同类问题可以沉淀成可重复阅读的知识；
- 编辑承担筛选、匿名化和内容组织功能。

Internet 后来首先压缩的是这条链路的**延迟和检索成本**，而不是凭空创造“远程向专家提问”。

### 前互联网信息系统还有什么

一个普通人在 1980s–1990s 获取健康知识，还可能依赖：

- 医院宣传栏和健康教育；
- 报纸健康版；
- 广播电视医学节目；
- 医药科普书；
- 药店；
- 亲友中的医务人员；
- 单位/学校卫生室；
- 邮寄读者信。

因此后续比较必须问：Internet 到来后究竟改变了哪一环，而不是把此前世界描述成“信息真空”。

## 四、1994–2005：互联网存在，不等于普通患者已经普遍在线

1994 年全功能接入以后，公用互联网基础设施开始发展。到 2005 年末，CNNIC 统计网民为 1.11 亿，普及率约 8.5%；同期新华社报道引用 CNNIC 数据称，乡村网民约 1931.4 万、乡村普及率约 2.6%，城市约 9168.6 万、约占城市人口 16.9%。

来源：

- CNNIC，第十七次中国互联网络发展状况调查统计报告：
  https://www3.cnnic.cn/n4/2022/0401/c88-797.html
- 新华社转载，2006-01-18：
  https://news.sina.cn/sa/2006-01-18/detail-ikkntiam6386071.d.html

这意味着 2005 年的“网络健康门户”不能写成全国普通人的默认入口。

更准确的表述应是：

> 对已经拥有电脑、网络接入和相应数字技能的一部分人，Internet 开始提供新的健康信息路径；但这一能力在城乡、年龄、教育和收入之间仍高度不均衡。

## 五、2000–2004：健康信息从“栏目”进一步变成可搜索的对象

### 2000：39健康网开通

39健康网当前官方发展史把正式开通时间记为 2000 年 3 月 9 日，并记录：

- 2004 年与雅虎中国合作推出健康搜索；
- 2007 年形成疾病、药品、医院、医生等数据库；
- 2008 年推出健康问答；
- 2009 年发展专家健康博客；
- 2010 年 WAP 服务升级。

来源：

- 39健康网官方发展历程：
  https://corp.39.net/info/develop/

证据等级：**A（平台自身历史陈述）**。

边界：它可以证明平台今天如何叙述自身产品发展，不等于每个节点的用户规模、效果或具体技术实现已经得到独立历史 capture 复核。

### 从“读一篇文章”到“按疾病/药物/医生查询”

传统杂志是编辑先决定下一期写什么，读者在固定目录里找。

健康搜索和数据库逐渐改成：

```text
用户先有一个问题
→ 输入症状/病名/药名
→ 搜索系统返回候选内容
→ 再进入文章/药品/医院/医生页面
```

这是 **`health-object addressability / 健康对象可寻址性`** 的重要变化。

但：

```text
搜索命中
!= 医学结论正确
!= 搜索排序等于临床优先级
!= 页面上有某医院/医生
!= 此刻可以挂到号
```

## 六、2005–2012：扩张型未来——“更多知识、更多病友、更多医生以后都应该能在线找到”

### 2007–2009：健康门户开始把文章、数据库、医生和用户社区放到一起

2000s 后半的同期互联网报道已经把健康网站描述成多个层次同时存在：

- 疾病/药品/医院/医生数据库；
- 医生博客；
- 健康论坛；
- 用户问答；
- 医患互动；
- 患者之间交流。

39健康网官方发展史将健康问答上线时间记为 2008 年、专家博客扩展记为 2009 年。

这里的结构性变化是：**知识对象、专业人员和其他患者第一次大量出现在同一个搜索/导航环境里。**

### 2008：54 岁母亲现学打字，建立艾滋感染者 QQ 群

《华西都市报》2008 年同期报道中，54 岁的“何妈妈”为了与 HIV 感染者沟通，现学聊天和打字，与女儿建立 QQ 群。报道强调群体中的安慰、陪伴、治疗与防护知识交换，以及现实社会歧视给感染者带来的压力。

来源：

- 《华西都市报》，2008-11-20：
  https://history.thecover.cn/old/epaper/hxdsb/html/2008-11/20/content_17972.htm

证据：**B + T1**。

这条材料很重要，因为它反驳“早期网络用户=年轻技术爱好者”的简单想象。

数字技能可以在强烈生活需求出现以后被后天学习：

```text
不会打字
→ 身边有一群现实需求极强的人
→ 学会聊天
→ 成为群体组织者
```

而 HIV 又是典型的高污名疾病。线上昵称/群聊在这里不仅压缩地理距离，也降低了第一次进入互助关系时必须暴露现实身份的门槛。

### 2009：病友群也能形成未经验证的共同疾病解释

同年的另一个案例提供必要反证。2009 年大河网/中新网报道，一名网名“求败”的男子在高危性行为后长期坚信自己感染某种“未知病毒”，多次医学检测却不支持这一判断；六年间，他几乎每晚进入 QQ 病友群与他人交流，相似症状和共同担忧在网络里持续聚合。

来源：

- 中新网，2009-10-27：
  https://www.chinanews.com/jk/jk-ysbb/news/2009/10-27/1931974.shtml

证据：**B + T1**。

这里不能把患者痛苦写成“无知笑话”。他们的症状和焦虑对本人是真实生活负担。

但研究必须保留：

```text
多人有相似体验
!= 存在共同的新病原体
```

病友可寻址性带来的不仅是支持，也可能产生 **`peer-confirmation loop / 同伴确认循环`**。

### 2009：医生用“虚拟诊室”重新划定私人电话边界

2009 年 9 月 7 日，好大夫在线医生闵晓珊在自己的页面写道，随着接诊病人增多，越来越多人索要个人电话号码，而休息时间持续被电话打扰；她因此把网站“虚拟诊室”视为一种新的沟通渠道。

来源：

- 好大夫在线，闵晓珊，2009-09-07，《欢迎进入我的虚拟诊室！》：
  https://www.haodf.com/neirong/wenzhang/83957.html

证据：**A/T0（同期医生自发平台文字）**。

这说明在线医疗早期的一个重要问题并不是“能不能联系医生”，而是：

> **怎样让患者在医院以外仍能留下问题，又不等于医生把私人手机号永久开放。**

因此数字平台也在构建 **`care-boundary infrastructure / 照护边界基础设施`**。

### 2012：医生数据库和互动平台已经达到很大规模，但规模数字仍需按公司/媒体口径处理

2012 年同期报道将好大夫在线描述为收录 3000 多家公立医院、近 30 万医生，提供医生推荐、医患互动和预约转诊，并给出约 140 万独立用户的公司/媒体口径。

来源：

- 《理财周报》/新浪，2012-04-09：
  https://finance.sina.cn/sa/2012-04-09/detail-ikftssan7199992.d.html

证据：**B（同期商业媒体 + 平台经营者口径）**。

它可以证明服务模式已经存在并具有相当规模，不能把未经独立审计的平台数字直接转换成全国患者 adoption。

## 七、2015–2019：拥堵型未来——信息和联系方式多了以后，瓶颈变成信任、注意力与医生时间

### “在线轻问诊”不等于线下诊断

2010s 中期开始，越来越多医生明确把网上沟通定位为疾病教育、复诊辅助和轻咨询，而不是替代完整门诊。

这条边界很重要：

```text
医生回复了文字
!= 已完成体格检查
!= 已看到全部检查
!= 已建立正式诊断
!= 任何情况下都能直接处方
```

### 2018：一个医生微信里可能有近 2000 名患者

2018 年《北京青年报》报道，首都医科大学附属北京友谊医院一名医生的微信通讯录中近 2000 人为患者；报道同时记录医生认为微信、QQ 方便随访和沟通，但也占用私人时间，并存在通过网络谈疾病的风险。

来源：

- 人民网转载《北京青年报》，2018-08-19：
  https://politics.people.com.cn/BIG5/n1/2018/0819/c1001-30236823.html

证据：**B + T1**。

这正是“拥堵型未来”的医疗版本：

> 过去的问题是患者够不到医生；后来医生可能随时被几百、几千名患者够到。

可达性提高以后，**attention / 注意力**变成新的稀缺资源。

### 2018：病友群把专业指导和同伴支持混合在一个日常聊天空间里

中国青年报社社会调查中心与问卷网对 2009 名受访者的网络调查中，62.2% 称加入过医患交流群。这个比例不能外推全国人口，但同期采访中的 50 岁王娟提供了有价值的第一人称：她把群中的医生鼓励、专业指导和病友相互支持都视为应对疾病的重要资源。

来源：

- 中国青年报/人民网，2018-12-25：
  https://gongyi.people.com.cn/BIG5/n1/2018/1225/c151132-30485596.html

证据：**B survey（网络样本，有选择偏差） + T1**。

这说明一个微信群可以同时承担过去分散在：

- 复诊；
- 病友会；
- 健康教育；
- 情绪支持；
- 日常提醒

中的部分功能。

但它也使“谁说的话具有何种权威”更难区分。

### 2019：长期疾病把“碎片时间在线咨询”变成连续照护的一部分

2019 年《新快报》采访中，风湿免疫科医生黄建林称自己从 2008 年起持续通过网络回答患者问题；其中一名刚毕业就患系统性红斑狼疮、因病无法工作的年轻患者，需要长期调药，医生在线上持续跟踪并提供用药建议。医生本人则每天用至少约一小时以及通勤、电梯等碎片时间进行在线患者教育和咨询。

来源：

- 《新快报》/新浪，2019-07-17：
  https://news.sina.com.cn/o/2019-07-17/doc-ihytcerm4239210.shtml

证据：**B + T1**。

它把“疾病改变生命历程”表现得很具体：

```text
刚毕业
→ 本应进入工作
→ 疾病发作
→ 在家休养
→ 长期调药
→ 在线关系帮助维持与医生的连续联系
```

标准就业时间表被疾病中断以后，医疗关系本身成为生活中长期存在的基础设施。

## 八、2020–2022：偶发型未来——原本的“便利层”被推到照护连续性的主路径上

### 2020：疫情把在线问诊、复诊和送药从可选便利提升为 fallback

人民网 2020 年健康盘点记录一名 70 岁老人称，从线上问诊到收到药品不到 24 小时；同期全国多地互联网医疗迅速扩张，部分常见病、慢性病患者可以在线复诊、咨询、开药和配送。

来源：

- 人民网，2020-12-29：
  https://health.people.com.cn/n1/2020/1229/c14739-31982599.html

证据：**B + T1**。

疫情没有发明远程问答。它真正改变的是：

> 线下门诊突然变得困难时，一个过去属于“方便一点”的数字渠道，能否接住原本必须持续的慢性病照护。

这可以称为 **`fallback elevation / 备用路径升格`**。

### 2021：对重症慢性病患者，少跑一次医院不是“小便利”

北京协和医院互联网医院 2021 年首批患者采访中，王虹患硬皮病合并肺间质纤维化、肺动脉高压和严重右心衰，一刻也离不开呼吸设备。此前每月为复查调药至少需要去两三趟医院；互联网复诊让其中一部分环节可以在家完成。

来源：

- 《北京日报》/人民网，2021-04-09：
  https://bj.people.com.cn/n2/2021/0409/c233081-34667778.html

证据：**B + T1**。

这里必须保留事实边界：她仍需要线下完成必要检查；互联网医院并不是把身体“传送”给医生。

更准确的是：

```text
检查必须线下
+ 既往病历已在院内
+ 复诊判断可线上完成一部分
= 原来两三次现实移动中的一部分可以被消掉
```

这就是照护移动负担压缩。

### 互联网医院把过去松散的“网上问医生”推进到更正式的事务链

2021 年北京协和互联网医院获批时，官方信息明确包括：

- 在院病历调阅；
- 在线问诊；
- 检查检验；
- 处方开具；
- 部分医保支付。

来源：

- 新华社，2021-03-26：
  https://www.xinhuanet.com/2021-03/26/c_1127260899.htm

这意味着历史上必须把以下阶段分开：

```text
健康文章
→ 匿名问答
→ 医生个人主页咨询
→ 线上复诊
→ 处方/支付/药品配送
```

它们都叫“网上看病”时，会掩盖完全不同的制度权力和法律状态。

## 九、2023–2026：防守型未来——目标从“很快治好”转向维持功能、减少不必要折腾并守住长期治疗条件

### 2023：罕见病患者的未来可以是“维持现在，我还能做好多事情”

中国青年报 2023 年采访的 SMA Ⅲ型患者“波波”从开始求医到第一次听到 SMA 病名用了 11 年；从确诊后无药、药物出现但难以负担，到真正用上药又经历很长时间。他对未来的同期表达不是宏大的“完全康复”，而是：如果能维持当前状态，自己还能做很多事情。

同一报道中的杨毛毛既是多发性硬化患者，也是罕见病公益机构项目负责人，会把新药进入医保目录的信息第一时间分享给病友。

来源：

- 中国青年报/人民网，2023-04-03：
  https://edu.people.com.cn/n1/2023/0403/c1006-32656467.html

证据：**B + T1**。

这里的“防守型未来”不是悲观，而是时间目标发生变化：

```text
不是押注一个遥远的彻底治愈
而是守住：
功能
药物可及
医保资格
医生联系
检查节奏
工作/生活尚能继续的空间
```

这可以称为 **`care continuity reserve / 照护连续性储备`**。

### 2024：每月复查少跑一趟，也是长期生活结构的变化

宁波 2024 年报道中，一名 50 岁乙肝患者需要每月复查肝功能；过去一次复查要先去医院开单，再去一次完成检查。使用互联网医院“复检开单”后，他可以在线申请，直接到院检查，少跑一趟、少一次挂号费用。当地 2023 年此类服务累计近 24 万人次。

来源：

- 宁波晚报/中国宁波网，2024-01-09：
  https://news.cnnb.com.cn/system/2024/01/09/030554573.shtml

证据：**B + T1；服务量为地方官方/媒体口径**。

对于一个需要每月重复十二次的动作，“少跑一次”一年可能变成十二次现实移动的减少。

### 2025：服务存在不等于用户知道它存在

厦门 2025 年已经有 14 家公立医疗机构互联网医院。一名甲亢患者可以在小程序上传复查报告、照片和症状描述，再获得复诊意见和处方；但记者随机采访 50 名年轻人时，只有极少数知道本地这些线上就医渠道。

来源：

- 《厦门日报》，2025-05-08：
  https://news.xmnn.cn/xmxw/202505/t20250508_340037.html

证据：**B + T1；50 人街访不能外推总体知晓率**。

这给方法论提供了一个近乎教科书式的例子：

```text
互联网医院已获批
!= 服务在技术上存在
!= 本地居民知道
!= 居民会使用
!= 适合其疾病
!= 最终完成诊疗
```

### 2025：家属可以从照护者变成跨家庭疾病基础设施建设者

中国青年报 2025 年报道中，天使综合征患儿母亲张雪在女儿确诊后的 13 年里持续组织医生、科学家和患儿家庭交流；最初只是四五个家庭的小型聚会，后来发展成较大规模年会，并主动向基层医生、康复师传播疾病知识。

来源：

- 中国青年报/中国青年网，2025-02-28：
  https://news.youth.cn/jsxw/202502/t20250228_15853531.htm
- 复旦大学附属儿科医院，2025-02-18：
  https://ch.shmu.edu.cn/main/news/content/id/492/pid/19259.html

证据：**B/T1 + A institutional event record**。

这形成一条标准家庭生命史很难描述的路径：

```text
母亲
→ 长期照护者
→ 疾病知识搜集者
→ 患者家庭连接者
→ 医生/科研人员协调者
→ 患者组织建设者
```

她没有因为疾病而“离开家庭身份”，而是在家庭照护之上叠出一个新的公共角色。

## 十、海外比较：病友数字互助并不是 World Wide Web 才出现的

### 1987–1990：美国 HIV/AIDS BBS “SURVIVORS”

First Monday 的历史研究利用一份罕见的完整打印档案，重建了 David Charnow 运营的 `SURVIVORS` BBS：它在 1987–1990 年作为 HIV/AIDS 感染者的“electronic support group”运行。

来源：

- Kathryn Brewster & Bonnie Ruberg, 2020, *SURVIVORS: Archiving the history of bulletin board systems and the AIDS crisis*：
  https://firstmonday.org/ojs/index.php/fm/article/view/10290

证据：**academic reconstruction based on surviving primary artifact**。

这个案例非常重要，因为它证明：

> 在 WWW 出现以前，拨号 BBS 已经可以让地理分散、面临污名和重大疾病的人形成持续的电子互助空间。

### 1996：乳腺癌患者通过家用电脑和 BBS 形成支持小组

1996 年 *Health & Social Work* 一项研究让六名乳腺癌患者在三个月内通过家用电脑进入 BBS 支持组。参与者平均每周约使用一小时，讨论疾病状况、个人担忧并彼此支持。

来源：

- Weinberg et al., 1996, *Online Help: Cancer Patients Participate in a Computer-Mediated Support Group*：
  https://academic.oup.com/hsw/article-pdf/21/1/24/2081927/21-1-24.pdf

这是直接的同期研究材料，不应和后来 Web 社交平台混为一谈。

### 1990s：Usenet 上的抑郁症患者论坛形成“患者知识”

后来的医学史研究重建 `alt.support.depression`：其在 1990s 成为患者讨论抑郁、治疗和自助经验的重要论坛，高峰期研究估计有约 5.7 万读者、每日可达约 500 帖。研究者特别强调用户发展出自己的患者赋权和 lay expertise。

来源：

- Daniel Huang, 2022, *Cyber Solace: Historicizing an Online Forum for Patients with Depression, 1990–1999*：
  https://academic.oup.com/jhmas/article-abstract/77/3/343/6596178

这提示中国案例中的共同机制并非“中文互联网特有”：

- 现代城市和医疗专业化让稀有患者在现实生活中彼此分散；
- 电子网络降低他们找到彼此的成本；
- 患者经验由私人生活片段逐渐汇聚成可共享的 lay knowledge；
- 同时必须重新处理错误信息、权威和隐私。

中国独特之处更多在于：公用互联网较晚进入普通家庭、城乡数字鸿沟、QQ/微信等超级通信平台的高渗透，以及后来互联网医院与医保/实体医院系统的结合。

## 十一、四种未来：这条线真正比较的不是“技术更先进”，而是人如何安排病程时间

| 时段 | 主要未来感 | 医疗/网络机制 | 普通人的时间结构 |
|---|---|---|---|
| 2005–2012 扩张型 | 以后应该能找到更多知识、更多医生、更多和我一样的人 | 搜索、门户、问答、医生主页、QQ群 | 从“等下一期杂志/下次门诊”转向更短反馈循环 |
| 2015–2019 拥堵型 | 信息很多，但可信度、医生注意力和持续关系成为瓶颈 | 微信/QQ 医患群、第三方平台、医生碎片时间 | 患者随时能发问，医生也随时可能被工作追到私人时间 |
| 2020–2022 偶发型 | 线下路径突然可能中断，需要备用通道 | 在线咨询、互联网医院、复诊、处方、配送 | 可选便利被升格为维持慢病连续性的 fallback |
| 2023–2026 防守型 | 重点是守住功能、药物、医保、检查和可持续生活 | 线上复检、患者组织、长期记录、渠道冗余 | 未来从“尽快治好”转向“尽量少失去、让生活还能继续” |

这不是四个互斥年代。扩张、拥堵、偶发和防守会在同一个患者身上同时存在。

## 十二、重点矩阵

| 维度 | 本专题观察 |
|---|---|
| 教育 | 患病可能中断学业；网络患者教育又形成新的非正式学习 |
| 就业 | 慢性病可导致毕业后无法工作、长期请假或职业降载 |
| 住房 | 远程复诊对离大医院远、行动困难者意义更大 |
| 婚姻家庭 | 家属常成为陪诊者、信息中介、长期照护者甚至患者组织者 |
| 迁移 | 异地就医是罕见病和专科患者的重要成本；互联网压缩部分往返 |
| 照护 | 照护从一次门诊扩展为长期检查、调药、康复与情绪支持 |
| 非正规劳动 | 患者互助、家属协调和群管理常是无薪但重要的劳动 |
| 长期中断 | 疾病可以直接打断毕业—就业—成家等标准时序 |
| 证件与记录 | 正式复诊逐渐依赖病历、身份、处方、医保资格与历史检查 |
| 通信方式 | 读者信→电话→BBS/论坛→QQ/微信→医生平台/互联网医院 |
| 互联网平台 | 信息门户、病友群、医生主页和正式互联网医院具有不同权力 |
| 信息获取 | 从编辑预先选择主题转向症状/病名/药名主动查询 |
| 社交关系 | 病友关系把“同病”变成新的社会连接条件 |
| 未来预期 | 从“治好回归正常”扩展到“维持功能、等待药物、守住连续性” |
| 线上/线下身份 | 匿名/昵称可降低污名疾病初次交流门槛，但正式医疗仍需要真实身份 |
| 平台消失与记忆 | 公开问答比真正治疗结果更容易留下；病友私人后续大量消失 |

## 十三、反例与后见之明风险

### 13.1 不要把“网上有健康信息”写成“普通人已能自由获取医疗知识”

2005 年全国互联网普及率仍约 8.5%，城乡差距很大。老年人、农村居民、低数字技能人群尤其不能被平台页面代表。

### 13.2 不要把病友互助浪漫化

病友可以提供极其珍贵的生活知识，也可能共同放大未经验证的疾病解释、偏方或错误治疗信息。

### 13.3 不要把在线问诊等同于诊断

尤其在早期健康网站阶段，很多服务只是健康咨询、科普和就医建议。正式诊断、处方、检查、医保和药品配送属于不同制度事务。

### 13.4 不要把疫情写成互联网医疗的起点

2000s 已有健康问答、医生主页和病友群；疫情把一部分渠道升格为连续照护基础设施，而不是凭空创造它们。

### 13.5 不要把患者组织者写成“疾病带来的礼物”

患者/家属获得组织能力的前提往往是多年照护、求医和制度摩擦。研究可以承认能力转化，不能美化造成它的负担。

## 十四、历史可见性：为什么旧网上“患者说了什么”比“后来发生了什么”更容易保存

数字档案尤其容易保存：

- 一篇健康文章；
- 一个疾病页面；
- 一个医生 profile；
- 一个公开提问；
- 一段病友论坛文字。

却很难保存：

- 医生是否真正看了问题；
- 患者是否按建议去了医院；
- 线下最终诊断是什么；
- 后来是否换药；
- 私人 QQ/微信讨论；
- 病历、检查和处方；
- 病情五年后的结局。

于是会产生 **`public-question / private-outcome asymmetry / 公开问题—私人结果不对称`**：

> 历史研究者最容易看到一个人生病时第一次公开求助，却最难看到她后来究竟怎样活了十年。

这也是为什么旧健康网页不能直接当病例数据库使用。

### 隐私边界

疾病史尤其包含高敏感信息。HIV、精神疾病、生殖健康、罕见病、儿童疾病等材料，即使当年公开，也不意味着今天有必要重新批量索引姓名、联系方式或私人叙述。

研究应优先保存：

- 平台结构；
- 字段；
- 功能；
- 公开制度说明；
- 支撑最小 claim 所需的匿名化个案。

而不是让已经沉寂多年的普通患者重新变得可搜索。

## 十五、仍不知道什么

1. 1980s–1990s 《家庭医生》读者信箱普通来信从寄出到回复/刊登的典型延迟是多少？
2. 2000–2005 中国健康网站访问者的城乡、年龄、疾病结构到底怎样？
3. 早期病友论坛中，多少关系真正迁移到电话、QQ 和线下病友会？
4. 医生主页上的公开回复与实际线下复诊之间有多大转换率？
5. 2010s 大量微信医患群关闭、换群或医生离职后，患者怎样保持连续性？
6. 互联网医院减少了多少异地交通、陪护时间和工作请假？不同疾病差异多大？
7. 平台停运以后，患者最珍贵的长期病程记录是否可迁出？
8. 哪些患者因为数字技能、残障、经济条件或认证流程仍无法使用线上复诊？

---

## 十六、这一专题改变了我们对“人怎么活着”的哪一点理解

疾病不是生命史里的一对括号。

对很多人，它会和工作、婚姻、迁移、照护、收入、住房以及未来想象长期并行。一个人甚至可能在二十岁毕业时生病，此后几十年都要把“下一次检查、下一次调药、药还能不能报销”一起写进人生计划。

前互联网时代，杂志、邮政、医院和亲友已经在帮助普通人获得医学知识。Internet 真正改变的，是这些关系逐渐变得可以主动搜索：

> 我可以找一个病名、一个医生，也可以找另一个和我经历相似的人。

但可搜索并没有消除不确定性。病友越容易相遇，越需要区分经验与证据；医生越容易联系，越需要处理注意力和私人边界；复诊越能在线完成，越需要区分哪些环节仍必须让身体真正到医院。

因此，数字健康基础设施最深的变化不是“网上也能看病”。它是让一种很长、很碎、很容易被标准人生脚本忽略的生活变得更可执行：

> **即使疾病不会立刻结束，我仍然可以一点一点把医生、检查、药物、病友和自己的日常重新接起来，让生活继续往前走。**
