# 从“头像亮着”到“下班后别找我”：在线状态、可联系性与离线时间的重建（中国，1999—2026）

> 研究问题：当人与人的联系从固定电话、BP 机和“上网以后再聊”，逐渐变成手机永远联网、工作群随时可达时，一个普通人怎样表达“我现在能不能被联系”？又是谁开始有权把“没回复”解释成“不在”“没看见”“不愿意”“偷懒”或“失职”？
>
> 本篇补的是仓库里此前没有单独建模的一层：**presence / availability**。`from-scheduled-to-ambient-information.md` 已经说明信息从“定时到达”变成“环境式持续到达”；本篇进一步追问：**当网络不再需要人主动“上线”，普通人怎样重新争取不被看见、不必立即回应的时间？**
>
> old Web 执行层对应：`tmzncty/old-web-archaeology/docs/QQ_WEB_PRESENCE_ONLINE_AWAY_INVISIBLE_WATCHER_BADGE_AND_AVAILABILITY_STATE_GAPS_2000_2015.md`

## 0. 先把“在线”拆开：机器状态不是人的意愿

一个最容易被后见之明抹平的区别是：

```text
account connected
!= user at keyboard
!= user has seen the message
!= user is free to talk
!= user wants to talk
!= user owes an immediate response
```

早期即时通信之所以需要 `Online / Away / Busy / Do Not Disturb / Invisible / Offline`，正是因为“连接着”无法自动回答“这个人现在适不适合被打扰”。

本篇使用以下概念：

- **presence legibility / 在线在场可见性**：别人能否从系统状态判断你是否连接；
- **availability legibility / 可联系性可见性**：别人能否大致判断你现在是否适合被联系；
- **intentional presence / 主动声明在场**：用户主动切换在线、离开、忙碌、勿扰、隐身等状态；
- **presence ambiguity / 在场歧义**：一个状态不能可靠映射到人的注意力和意愿；
- **availability boundary / 可联系性边界**：用户主动制造“不方便联系”“稍后再说”“看不见我”的边界；
- **presence externalization / 在场外置**：由服务器替人保存并向联系人分发当前状态；
- **ambient reachability / 环境式可达**：设备和网络长期在线以后，别人不再先确认“你上线了吗”才发送消息；
- **responsiveness expectation / 回复时限预期**：发送者、组织或关系开始把“技术上可达”解释成“应该尽快回复”；
- **offline-time reconstruction / 离线时间重建**：通过静音、断网、工作群规则、不做已读回执、离线休息权等方式，重新制造不可占用时间；
- **presence petrification / 在线状态石化**：动态在线状态进入网页或档案以后，被保存成一个看似永久的图标，从而诱导后人把瞬时状态误读成人的稳定状态。

核心命题不是：

> 以前有离线，今天没有离线。

而是：

> **过去“在线”首先是一段可见的会话状态；后来网络连接逐渐常驻，社会开始把“可达”当作默认，普通人又不得不用新的制度和界面重新制造“不必回应”的时间。**

# 1. Internet 之前：电话和寻呼解决“找到人”，却没有共享的在线状态

本仓已有电话、BP 机与 contact-stack 专题，不在此重复设备史。

这里仅固定一个比较框架：

```text
固定电话：
号码主要指向地点/家庭/单位
→ 打过去才知道有没有人接

寻呼：
可以把“请联系我”的请求带给移动中的人
→ 但呼叫者通常不知道对方此刻能否回电

早期 Internet IM：
联系人列表在发消息之前就显示一个近实时状态
→ “现在是否适合发起互动”第一次成为界面持续展示的信息
```

因此 presence 并不是“更快的消息”这么简单。

它改变的是**发送消息以前的认知条件**：你不必先打过去、等忙音或无人接听，便能先看到一个由网络服务分发的“在不在 / 忙不忙”的近似信号。

但也正因为这个信号只是近似，后来的很多社会摩擦从这里开始。

# 2. 海外前史：1990s 即时通信已经把“在不在”做成一组用户可操纵状态

## 2.1 1998 ICQ：在线不是二元值，而是一套“打扰协议”

1998 年波兰《CHIP》对 ICQ98 的同期评测列出八种状态：

- Online；
- Away；
- N/A Extended Away；
- Occupied / Urgent Messages；
- Do Not Disturb；
- Free For Chat；
- Privacy / Invisible；
- Offline。

文章还说明状态通过联系人列表图标呈现，并可配合自动回复或自定义说明；同时特别指出，当时拨号用户往往按分钟/电话脉冲付费，因此很多人没有条件长时间保持 `Away`，`Online / Offline` 对他们更现实。

Source:

- CHIP, 1998-07-01, *Sieciowe rendez-vous*: https://www.chip.pl/1998/07/sieciowe-rendez-vous

Evidence grade：**B / contemporaneous technical review**。

这条材料同时证明了两件事：

1. presence 从一开始就不仅是“连接/断开”；
2. presence 的社会形式受接入成本约束。

今天很容易把 1990s 的 `Away` 想成 Slack/Teams 的黄色圆点，但拨号时代的人可能根本不会为了维持一个离开状态持续占线。

所以：

```text
feature exists
!= user can economically remain connected
!= feature becomes ordinary daily practice
```

## 2.2 2000 年 RFC 2778：presence 被正式抽象成“presentity → watcher”

RFC 2778《A Model for Presence and Instant Messaging》把 presence service 明确定义为保存和分发 presence information 的系统，并区分：

- **presentity**：被描述状态的一方；
- **watcher**：观察/订阅状态的一方；
- presence tuple：可含 online/offline/busy/away/do-not-disturb 等状态及通信地址；
- access rules：谁可以看到哪些状态。

Source:

- RFC 2778, 2000-02: https://www.rfc-editor.org/info/rfc2778/

Evidence grade：**A / original Internet standards document**。

这个模型对生活史特别有价值，因为它提醒我们：

> **“我现在是什么状态”与“某个人现在看到我是什么状态”不是天然相同。**

一旦存在隐身、黑名单、可见名单、权限规则，就必须写成：

```text
server connection state
→ user-declared state
→ access rule
→ watcher-specific representation
```

而不能只写：

```text
用户在线 / 用户离线
```

# 3. 中国 1999—2001：QQ 把“在线”变成普通网民可见、可操纵的社会状态

## 3.1 2000 年 QQ2000：隐身与离开留言不是附属功能，而是可联系性边界

腾讯保存的同期产品发布材料显示，2000 年 11 月 QQ2000 正式版本新增或强化：

- 隐身；
- 多种可自定义离开留言；
- 黑名单；
- 从对方好友列表中删除自己；
- 好友备注；
- 移动 QQ（短信）；
- Tencent Browser 的“谁与我同在”。

官方甚至直接把隐身描述为让用户“工作、上网两不误”。

Source:

- 腾讯，2000-11-17，《QQ2000版本正式发布》：https://www.tencent.com/zh-cn/articles/80254.html

Evidence grade：**A / contemporaneous platform announcement**。

这里最重要的不是“QQ 功能很多”，而是用户第一次能把自己的可联系性做成一个主动管理对象：

```text
我确实连着服务器
但我可以让一部分或全部人看起来像没上线
```

这意味着：

> **Invisible 不是“网络失败”，而是一种社会边界。**

因此历史上看到“某账号当时显示离线”，绝不能自动推导：

- 人不在电脑旁；
- QQ 客户端没有运行；
- 他没有和其他人聊天；
- 他当天没有上网。

## 3.2 2001 年移动 OICQ：人可以离开电脑，presence 却开始跨网络延伸

2001 年 3 月新浪报道，北京移动于 2 月 20 日开通“移动 OICQ”。这项服务把 GSM SMS/WAP 与 OICQ 系统通过网关连接，手机用户可以：

- 与 PC 上的 OICQ 用户互发消息；
- 查询不在线时收到的信息；
- 查看好友状态；
- 按昵称、邮箱、OICQ 号码查询用户。

报道还称，2001 年 1 月移动 OICQ 日消息量已超过 100 万条。

Source:

- 新浪科技，2001-03-06，《北京地区正式开通“移动OICQ”服务》：https://tech.sina.com.cn/i/c/56518.shtml

Evidence grade：**B+ / contemporaneous industry report with service details**。

这条证据很重要，因为它打破一个简单阶段论：

> PC 在线状态 → 智能手机常久在线。

中间还存在一个过渡阶段：

```text
人离开 PC
但手机通过 SMS/WAP 网关仍能查询好友状态、收取离线消息
```

也就是说，**身体和 PC 开始解绑得比“完整移动 Internet”更早。**

# 4. 2004—2010：presence 从联系人列表走进网页，成为一种可以公开发布的属性

## 4.1 2004：至少已有用户把 QQ 在线状态代码当成“发布在互联网上”的工具

Google Groups 今天仍可检索到一条标记 2004-11-04 的公开帖子，链接 `is.qq.com/webpresence/`，描述把 QQ/TM 在线状态发布到 Internet、生成状态代码，并允许陌生人点击后发起即时联系。

Source:

- Google Groups surviving post, 2004-11-04: https://groups.google.com/g/cn.fan/c/O7CHPNCx-Vw

Evidence grade：**A-like / surviving contemporaneous public post; archive byte identity not verified**。

它不能单独证明：

- 服务首次上线日期正是 2004-11-04；
- 当天的官方页面长什么样；
- 所有状态语义和后来版本一致。

但它足以把一个新能力钉在 2004 年：

> **个人的即时通信可达性已经可以被嵌进一个普通网页。**

## 4.2 2007 的真实 HTML 代码保存了这条 Web → 本地 QQ 的链

2007 年博客园的一篇技术文章保存了同期网页代码：

- 官方生成器：`http://is.qq.com/webpresence/code.shtml`；
- 状态图片：`http://wpa.qq.com/pa?p=...`；
- 点击链接：`tencent://message/?uin=...`。

Source:

- 博客园，2007-03-09，《QQ、MSN、淘包旺旺、Skype临时对话的链接代码》：https://www.cnblogs.com/finejob/archive/2007/03/09/669238.html

Evidence grade：**B+ / contemporaneous technical user article preserving code**。

从生活层面看，这意味着一个小店、个人博客或论坛账号可以把：

```text
“这是我的网页”
```

进一步变成：

```text
“我现在大概在线，你可以立刻敲我”
```

陌生关系从 `发现页面 → 记下联系方式 → 加好友 → 等通过`，有机会缩短为 `发现页面 → 点击 → 临时会话`。

## 4.3 2008：在线状态已经明确被理解成“是否值得现在打扰”的指引

2008 年一篇同期教程描述 QQ Web Presence：把生成代码嵌入网页或论坛后，按钮可以显示 QQ 是否在线；点击后可以直接发起临时会话，即使双方不是好友。教程也说明，被联系者可以拒绝、设置限制条件、把对方拉入黑名单。

Source:

- 博客园，2008-09-10，《在网页中嵌入QQ》：https://www.cnblogs.com/onlywnan/archive/2008/09/10/1288370.html

Evidence grade：**B / contemporaneous user tutorial**。

所以 presence 不是单向的“提高可达性”。

它从早期就同时包含：

```text
让更多人知道我现在大概能联系
+
让我保留拒绝、隐藏、筛选谁能进入会话的权利
```

这是理解后来“已读回执”“离线权”争论的前史。

## 4.4 2008 同时代第一人称：隐身本身已经是一种日常社会策略

一个今天仍存活的 WordPress 页面中，有一篇内部日期标记为 2008-08-18 的个人文章《状态》。作者说，别人常问为什么看不到自己上 MSN，他表面回答“忙”，实际上是选择隐身；随后回忆 2000—2001 年 QQ 上线后好友头像连续闪动、同时打开多个聊天窗口的经验。

Source:

- surviving personal blog index containing post dated 2008-08-18: https://fanbst.wordpress.com/

Evidence grade：**A-like/C-sensitive：contemporaneous first-person content on a surviving page; historical hosting/byte identity not independently verified**。

隐私处理：本仓只保留支持机制判断所需的最小内容，不做现实身份拼接。

这条材料的价值不在于证明“2008 年大家都隐身”，而在于证明：

> **至少对一部分人来说，隐身不是技术故障，而是处理社交负荷的主动选择。**

它也是很好的反例：

```text
friends do not see user online
!= user is actually offline
```

## 4.5 海外同期研究：Away message 甚至成为一种“日程与身份小窗”

Pew 2005 年美国青少年调查发现，86% 的 teen IM users 曾使用 away message，39% 每天或几乎每天使用；62% 曾写自己正在做什么或为什么不在，28% 曾在 away message 中留下可联系的电话号码。

Source:

- Pew Research Center, 2005-07-27, *Communications Tools and Teens*: https://www.pewresearch.org/internet/2005/07/27/part-4-communications-tools-and-teens/

Evidence grade：**A / primary survey report**。

2006 年 Nastri、Peña 与 Hancock 又研究了 44 名大学生在 2004 年产生的 483 条 away messages，发现其内容主要承担信息和表达功能，用户平均接近每天更换一次。

Source:

- Nastri, Peña & Hancock, 2006, *The Construction of Away Messages: A Speech Act Analysis*: https://onlinelibrary.wiley.com/doi/10.1111/j.1083-6101.2006.00306.x

Evidence grade：**A / contemporaneous academic study using observed messages**。

跨国共同机制因此不是“QQ 特有的隐身文化”，而是：

> **当实时联系人列表出现以后，人们必须发明一种轻量语言，向远方联系人解释自己此刻的可用性、日程和边界。**

# 5. 2005—2012：扩张型未来——“现在就能找到人”本身是一种机会扩张

这一时期 presence 的未来感主要来自：

```text
联系人更多
+
可见谁在线
+
陌生人也可能立刻发起会话
+
离开 PC 后还有手机桥接
```

它对生活路径的影响可以进入很多维度：

### 就业与非正规劳动

小商户、自由职业者、网店卖家可以把即时联系方式直接嵌到页面，不必等待正式客服系统。

### 社交

朋友不用先打电话确认“你在不在”，看到状态就可能直接开聊。

### 迁移

一个离开原城市的人，只要账号继续使用，原关系仍可观察他是否“出现”。

### 兴趣社群

论坛、博客和个人站的陌生访客可以从静态内容直接跳入一对一会话。

### 未来预期

“随时随地”“沟通无限”之类同期产品语言，不应当被当成普及事实，却真实保存了当时人对未来通信的想象：**距离和时机都越来越不应该成为找不到一个人的理由。**

## 5.1 2010：在线状态按钮已经进入小商户的普通业务

2010 年 QQ 在线状态 V3.0 的同期报道描述：用户可以把代码放进网站、邮箱、论坛或博客，允许访客无需加好友就发起临时会话；同时新增黑白名单、安全级别、是否开放文件/语音/视频等设置。

报道中的一名网店经营者称，每天约有 7—8 人通过店铺页面上的 QQ 在线状态咨询业务，他不再需要一直盯着网页等客户。

Source:

- DOIT，2010-09-20，《腾讯QQV3.0推出安全即时沟通等强大功能》：https://www.doit.com.cn/p/68947.html

Evidence grade：**B / contemporaneous product report + contemporaneous user quotation**。

这里出现了一个很具体的新生活能力：

> **网页可以在主人不盯着浏览器时，仍替主人公开“现在能不能来问我”。**

也就是把“守店”从持续看网页，部分转成后台 presence + 客户主动呼叫。

# 6. 2015—2019：拥堵型未来——状态图标消失了，但“你应该一直在”的预设反而变强

智能手机时代并没有简单保留 PC IM 的 `Online / Away / Invisible / Offline` 逻辑。

当消息应用长期驻留、推送通知常开以后，发送者越来越不需要先问：

> “你上线了吗？”

而是直接发送，然后问：

> “为什么还没有回？”

这是一种非常关键的角色反转：

```text
PC IM：
presence state is explicitly visible
→ sender decides whether now is a good time

smartphone messaging：
network reachability is often assumed
→ receiver must explain delayed response
```

## 6.1 2018 同时代职场材料：从“灰头像”到“头像永远是彩色的”

2018 年《中国青年报》、新华社保存的一组同期职场青年采访非常接近本篇核心问题。

一名毕业工作仅一年的年轻人已经保留 481 个微信群，其中 27 个置顶，占聊天界面前四屏；另一名新媒体编辑凌晨 3 点被工作群 @，因为曾经设置免提醒而没有及时回复，随后又被领导再次点名。

报道中的受访者自己把旧 QQ 和微信作了对比：过去 QQ 不在线时头像会变灰，给对方一个“可能不能及时收到”的提示；微信头像长期保持正常显示，于是他感到领导仿佛默认自己永远在线。

Source:

- 新华网 / 中国青年报，2018-11-09，《微信群成“紧箍咒” “隐形加班”带来新负担和焦虑》：https://www.xinhuanet.com/politics/2018-11/09/c_1123686270.htm

Evidence grade：**B+ / contemporaneous reported first-person interviews**。

这里不能得出“微信导致了所有加班”。

可以较强地写的是：

> **当“离线”不再由头像显著表达时，组织可能更容易把技术可达性误读为持续可用性。**

## 6.2 群数量本身开始占据生活时间

同一时期的问题不只是“一条工作消息”。

群组让一个人同时嵌入：

- 部门；
- 项目；
- 客户；
- 家庭；
- 同学；
- 临时活动；
- 学习；
- 票务；
- 社区；
- 各种结束后没有解散的“僵尸群”。

这带来 **availability fan-out / 可联系性扇出**：

> 同一个人不是被一个上级找到，而是被几十甚至几百个半永久群组同时保留为潜在接收者。

因此“手机在线”与早期“一个好友列表里的在线”已经不是同一种社会规模。

## 6.3 2019：制度开始主动重新画边界

2019 年珠海香洲区出台基层减负措施，要求原则上一个单位只建一个工作群，并原则上在非工作时间不发布工作信息；随后全国媒体记录了大量围绕工作群过多、`@所有人`、收到请回复等问题的讨论。

Sources:

- 中国新闻网 / 中国新闻周刊，2019-05-15，《手机里有27个工作群 如何整治“指尖上的形式主义”？》：https://www.chinanews.com.cn/gn/2019/05-15/8836869.shtml
- 央视网 / 中新经纬，2019-05-11，《下班后微信群禁发工作消息！你敢转发这条新规@领导吗？》：https://news.cctv.com/2019/05/11/ARTIm5n1caopV3GLockPCHit190511.shtml

Evidence grade：**B / contemporaneous policy reporting and interviews**。

这表明“防守”并不是疫情后才突然出现。

在拥堵型未来内部，组织已经开始尝试：

```text
减少群数量
+
规定何时不应该发送
+
项目结束后解散临时群
```

也就是把以前由 `Away / Invisible` 个人管理的边界，部分提升到组织规则。

# 7. 2020—2022：偶发型未来——远程办公把“及时回复”临时变成了身体在场的代理指标

2020 年突发的远程办公实验尤其适合观察 presence。

在办公室里，管理者可以看到：

- 人是否坐在工位；
- 是否在开会；
- 是否离开；
- 是否和同事讲话。

居家以后，这些线下 presence cues 突然消失。

于是很多团队自然地试图用数字信号替代：

```text
视频会议出席
群里回复
即时消息响应速度
在线打卡
任务状态
```

## 7.1 同时代第一人称：不敢关提醒，因为“回复晚了老板会担心你不在电脑前”

2020 年《中国新闻周刊》的现场采访中，一家大数据公司的总经办负责人说，远程办公初期自己不敢关闭钉钉提醒，消息一来立刻点开，因为担心回复不及时会让老板怀疑自己不在电脑前工作。高频读取即时消息反过来不断打断工作。

同一篇报道里，一名广告公司策划总监说，居家以后虽然节省约 80 分钟通勤，却常常从上午 11 点一直沟通到午夜，客户也逐渐没有周末概念，他把原来的“995”形容成变成“007”。

Source:

- 中国新闻网 / 中国新闻周刊，2020-03-07，《超过3亿人远程办公，上班族“宅在家”的梦想实现了》：https://www.chinanews.com.cn/sh/2020/03-07/9117326.shtml

Evidence grade：**B+ / contemporaneous multi-person first-person reporting**。

这非常清楚地展示了一种新的制度替代：

> **当管理者看不到身体，回复速度会被诱惑性地当成“人是否在工作”的代理变量。**

但这篇报道本身也提供了重要反例。

该公司后来取消“几分钟内必须回复”，转而按项目和 deadline 评估；负责人认为结果导向反而减少了无意义的即时监控。

因此：

```text
remote work
!= inevitable 24/7 surveillance
```

真正的分叉是管理规则：

```text
presence-based management
vs.
outcome-based management
```

# 8. 2023—2026：防守型未来——成熟通信开始有意保留“没看到 / 不想回 / 稍后回”的模糊空间

## 8.1 2023：微信明确拒绝“已读”——模糊性本身成为产品价值

2023 年 7 月，“如果微信显示已读的话”引发公开讨论。微信团队回应不会增加这项功能；腾讯公关负责人随后解释，团队认为“已读”会增加接收者的心理负担和社交压力，因此长期坚持不显示。

同期用户讨论里，反对者特别把夜间老板发工作消息、已读后不好不回等场景作为理由。

Source:

- 澎湃新闻，2023-07-12，《如果微信显示“已读”的话？微信回应：放心，没有“如果”》：https://m.thepaper.cn/newsDetail_forward_23820450

Evidence grade：**B+ / contemporaneous platform statement + contemporaneous public reactions reported by media**。

这给出了一个很重要的防守型设计原则：

> **系统不一定要把每一个可观察状态都展示出来。**

技术上可以进一步区分：

```text
message submitted
→ delivered
→ notification displayed
→ conversation opened
→ content read
→ human understood
→ human willing/able to respond
```

而社会产品可以选择停在哪一层。

“不显示已读”实际上是在故意保留：

```text
read state uncertainty
```

避免把“我已经看见”自动升级成“我现在欠你一个回应”。

## 8.2 2024：离线休息权从个人习惯变成公开制度语言

2024 年《法治日报》对“隐形加班”的调查采访中，一名金融机构职员描述晚上 10 点工作群仍持续响起，回复不及时会被点名；另一名受访者说非工作时间收到安排越来越频繁，周末手机快没电时会急着找充电宝，因为“手机1分钟都不敢关机”。

同年全国两会期间，也有提案明确使用“离线休息权”概念，主张劳动者在法定或约定工作时间之外有权拒绝通过数字工具处理工作。

Sources:

- 中国新闻网 / 法治日报，2024-12-20，《隐形加班“认定难”，下班后的“离线权”该咋保障？》：https://www.chinanews.com.cn/fz/2024/12-20/10339401.shtml
- 南方都市报，2024-03-05，《下班了还得“在线”！他呼吁“离线权”入法》：https://www.sohu.com/a/761860505_161795

Evidence grade：**B / contemporaneous interviews + policy proposal reporting**。

这里的历史反转已经很完整：

```text
1990s：
怎样让别人知道我在线？

2000s：
怎样让网页访客现在就能找到我？

2010s：
为什么所有群都觉得现在能找到我？

2020s：
怎样让“现在找不到我 / 我不必回”重新成为被承认的状态？
```

## 8.3 2025：有组织开始直接减少群、禁止下班后开会

2025 年美的确认，公司此前发布的“简化工作方式”要求包括：

- 严禁下班时间开会；
- 减少微信群数量；
- 禁止形式主义加班等。

可以写的是：

> **在数字工作高度普及以后，至少有组织开始把“减少通信入口”本身当成减负措施。**

这和早期 IM 不断增加新联系人、新状态、新提醒的扩张逻辑形成非常鲜明的历史反向。

# 9. 四种“未来”的同一条 presence 线

| 阶段 | 当时最重要的能力 | 普通人的典型动作 | 新风险 | 未来感 |
|---|---|---|---|---|
| 2005–2012 扩张型 | 看见谁现在在线；把可达性发布到网页；跨 PC/手机继续联系 | 上线、设离开、隐身、挂 QQ 在线按钮 | 陌生人骚扰、隐身被侦测、在线负荷 | “以后越来越容易找到任何人” |
| 2015–2019 拥堵型 | 群和手机使多人/组织持续可达 | 置顶群、免提醒、小号、夜间断网 | 群爆炸、回复义务、工作进入休息时间 | “每件事都能现在找到我” |
| 2020–2022 偶发型 | 数字 presence 临时替代办公场所的身体 presence | 视频签到、群回复、在线协作 | 响应速度被当作劳动证据、工作时间拉长 | “人不在办公室也必须证明自己在工作” |
| 2023–2026 防守型 | 主动限制可观察性和非工作时段可达 | 不做已读、离线权、减少群、禁下班会议 | 边界规则不统一、紧急联系如何例外 | “未来不能只更可达，还要允许真正下线” |

这张表不是四个完全断裂时代。

同一个 2026 年的人仍然可能：

- 在某个工具里手动 `Busy`；
- 在微信里没有已读回执；
- 在企业工具里被要求回执；
- 把某个群静音；
- 同时为了家人保持电话永远可接。

所以真正的研究对象是**多个 presence regime 在同一个人身上叠加**。

# 10. 它怎样改变“普通人有多少种活法”

## 教育

早期学生可以在宿舍电脑上线、离开时设 away；后来班级群、课程群和手机推送让通知不再只发生在教室或公告栏。

需要继续追问：学生的“课后不可达时间”是否仍存在？

## 就业

presence 从“同事在不在办公室”扩展成“消息多久回复”。远程工作进一步把数字活动状态变成劳动管理数据。

## 住房与迁移

搬家不会让 QQ/微信关系自动中断；但在家也不再天然等于离开工作场所。

## 婚姻家庭

家庭成员可以更容易判断“人现在是否出现”，但工作群和社交消息也能持续进入家庭时间。

## 照护

持续可达对老人、儿童、病人和异地家庭可能非常重要；因此“离线权”也不能简单等同于所有人任何时候都断联。

## 非正规劳动

网店、自雇、兼职和小商户尤其可能把“在线”直接转化为客户机会。越是收入依赖即时询问的人，越难彻底关闭可达性。

## 长期中断

一个人失业、休学、迁移或生病时，账号仍可能保持存在。平台 presence 无法告诉研究者为何这个人不再出现。

## 证件与记录

presence 不是法定身份证明，但在远程办公里它可能被组织误当作“正在履职”的弱证据。

## 通信方式

电话解决“现在打一下看看”；IM presence 把“值不值得打扰”提前到发送以前；智能手机又逐渐把这个预检查取消。

## 互联网平台

平台不仅传递消息，也决定：

- 是否显示在线；
- 是否显示最后活跃；
- 是否显示已读；
- 谁能隐藏；
- 谁能要求回执；
- 谁能在工作时间之外继续 @ 人。

## 信息获取

“在线的人”本身曾经是一种信息来源：看到好友在线，就可能问问题而不是搜索。

## 社交关系

Away、Invisible、免提醒、不回、已读不回都不是单纯技术状态，而会被关系赋予意义。

## 未来预期

扩张期想象的是“任何时候都能找到人”；防守期开始想象“即使技术能找到，我也可以不被要求现在回应”。

## 线上/线下身份

`online` 从来不是现实人格的完整投影。隐身尤其证明：**不可见有时是用户主动生产出来的身份状态。**

## 平台消失与记忆保存

联系人列表和状态历史通常比公开网页更难保存；历史研究会系统性高估公开发言，低估无数只在在线列表、临时会话和 away message 中发生的关系维护。

# 11. 一个新的“标准人生脚本”问题：什么时候社会开始默认你应该可达？

传统标准人生脚本通常写：

```text
上学 → 工作 → 结婚 → 买房 → 退休
```

presence 研究加入另一条不显眼却非常实际的脚本：

```text
拥有固定联系方式
→ 拥有个人手机
→ 拥有长期 IM 账号
→ 加入学校/工作群
→ 手机长期联网
→ 在非工作时间仍技术可达
→ 学会自己管理“什么时候不回应”
```

这个脚本不是所有人同步经历。

特别要问：

- 客服、销售、骑手、自雇者是否更难离线？
- 管理者和普通员工是否拥有同样的“慢回复权”？
- 照护责任重的人是否需要保持某些通道永久开放？
- 夜班、跨时区团队和灵活就业的“下班时间”在哪里？
- 一个 24 小时营业的小店是否把店主本人也变成 24 小时客服？

因此“离线”不是纯粹个人自律问题，而是岗位、权力、收入结构和照护关系共同决定的制度能力。

# 12. 历史可见性：档案最容易保存的是“在线图标”，最难保存的是人在图标背后的真实状态

presence 对旧网考古尤其危险，因为它是**动态、短暂、个性化、关系依赖**的。

一份网页 archive 可能保存：

- QQ 在线状态按钮；
- 一个绿色/灰色图标；
- `tencent://message` 链接；
- “点击这里给我发消息”的 alt 文本。

但它通常不能保存：

- 当时 QQ 客户端是否真的连接；
- 用户是否坐在电脑前；
- 用户是否隐身；
- 特定好友与陌生访客看到的状态是否相同；
- 用户是否看见临时会话；
- 用户是否愿意回复；
- 网页 capture 与动态 badge 是否恰好在同一逻辑时刻取得。

因此：

> **archive-visible presence != lived availability**

并且：

> **captured green icon != biographical proof that a person was “available” at that historical moment**。

这一点在 companion old-Web 文档中进一步建模。

# 14. 反例与限制

## 反例 1：一直在线也可能是真正的自由

对异地家庭、残障者、照护者、远程工作者和跨城市关系来说，持续可达可能显著降低生活成本。

不能把“离线时间”浪漫化成所有人都想回到的旧世界。

## 反例 2：早期 PC IM 也有社交压力

Away message、隐身和回复速度从 2000s 就已经产生关系解释。不能写成“智能手机以前网络毫无压力”。

## 反例 3：没有在线状态不等于压力必然更大

微信不显示传统在线灯，也不显示已读；这同时保留了新的模糊空间。

## 反例 4：工作时间外联系有时确有必要

医疗、交通、应急、跨时区和连续生产场景无法简单用“下班后一律不联系”处理。

## 反例 5：远程办公也可能减少通勤并提高自主性

2020 的同一批采访已经显示，一些人节省通勤、改用 deadline/结果导向后效率并未下降。

因此本篇反对两种简单叙事：

```text
always-on = progress
```

和

```text
always-on = pure deterioration
```

更准确的是：**可达性扩张重新分配了谁承担协调成本。**

# 15. 后见之明风险

1. 不把 2000 年 QQ 隐身写成今天“离线权”的早期版本；当时主要是社交/干扰管理，并非劳动权利话语。
2. 不把产品宣传“随时随地”当成用户已经随时在线。
3. 不把 QQ 灰头像自动解释为真实人不在。
4. 不把智能手机长期联网解释成用户 24 小时查看消息。
5. 不把 2018—2024 的职场压力投射到所有工作、行业与阶层。
6. 不把今天对“已读回执”的反感投射回 2000s；当时用户曾主动大量使用 away/status 信息。
7. 不把 remote work 的疫情异常状态直接当成长期稳定制度。
8. 不把“离线权”政策讨论写成已经普遍落实的法律现实。

6. 海外可继续比较 AIM/ICQ away culture、BlackBerry/always-on email，以及法国/欧盟后来的 right-to-disconnect，但主仓叙事仍以中国普通生活为中心。

# 18. 它改变了我们对“人怎么活着”的哪一点理解

以前，“不在”是一件很容易发生的事。

你离开家里的电话，别人打不通；你离开办公室，同事看不到你；你关掉拨号网络，QQ 头像变灰。早期即时通信反而把这种不确定性变得更精细：你可以说“我在线”“我走开一下”“别打扰”“我其实在线但不想让你看见”。那时的网络生活很大一部分劳动，是**主动告诉别人自己现在处于哪一种状态**。

后来手机和推送把网络连接藏到后台。我们少说“我上线了”，也很少专门设置“离开”；消息可以直接送来。表面上，这是协调成本的大幅下降——远方的人、客户、同事和家人几乎永远有办法找到你。

但成本没有消失，只是换了人承担。

以前发送者要先判断“对方现在在不在”；后来接收者越来越需要解释“为什么现在还没回”。

所以二十多年以后，最值得研究的不是“人终于永远在线”，而是社会开始重新发明那些曾经天然存在的空白：不显示已读、减少工作群、下班后不开会、允许关掉手机、承认一个人即使技术上能被找到，也不等于此刻就属于所有找他的人。

> **现代通信真正成熟的标志，也许不是任何人任何时候都能抵达你，而是所有人都知道：抵达的能力，并不自动产生占用你的权利。**
