# 每天重新找一次工作：日结零工、等待劳动与现金到账速度，中国 1991—2025

> 状态：research note / comparative synthesis  
> 主题：就业、非正规劳动、迁移、长期中断、通信方式、互联网平台、现金缓冲、未来预期  
> 交叉旧网：`tmzncty/old-web-archaeology/docs/DAY_LABOR_TEMP_JOB_LISTINGS_DISPATCH_SHIFT_AND_SETTLEMENT_STATE_GAPS_2009_2011.md`  
> 与既有专题的边界：本篇不重复一般网络招聘，也不重复“主业 + 副业”或个体经营。它研究一种时间结构完全不同的劳动路线：**一个人没有一个持续数月的岗位，而是反复、甚至每天重新进入一次劳动力市场。**

---

## 0. 核心问题：如果今天的工作只存在今天，人生怎样组织？

标准就业脚本通常默认：

```text
找工作
→ 入职
→ 连续工作若干月 / 若干年
→ 按月发薪
→ 离职后再次找工作
```

但日结、短工、马路零工、临时搬运、小时工等可以是另一种结构：

```text
今天需要现金
→ 清晨到劳务聚集点 / 打开群或平台
→ 等雇主出现
→ 询价 / 被挑选
→ 上车或自行到工作地点
→ 干几个小时 / 一天
→ 核算工时和工价
→ 当天或短期内结算
→ 第二天再次找活
```

这里工作的边界不是“职业生命周期”，而可能只有一个班次。

因此新增四个分析变量。

### 0.1 daily labor-market re-entry / 日常重新入市

> **劳动者必须高频率、甚至每天重新完成一次“发现岗位—被选择—到岗”的求职流程。**

一个月做 20 天零工，不等于“有一份工作做了一个月”。

其中可能包含 20 次不同的岗位发现、询价、等待、派工、通勤和结算。

### 0.2 income latency / 收入延迟

> **工资高低之外，从完成劳动到现金真正可用，需要等多久？**

对于现金缓冲很薄的人：

```text
月薪 5000 元、月底到账
```

与

```text
日薪 180 元、今晚拿到
```

不是简单的月收入比较。

后一条路线可能以较低稳定性换取更短的现金到账延迟。

因此固定：

- `quoted wage ≠ cash available now`
- `work completed ≠ wage settled`
- `higher monthly wage ≠ better short-horizon liquidity`

### 0.3 standby labor / 等活时间

在零工市场，“没有干活”的早晨不等于没有为工作付出时间。

劳动者可能必须：

- 凌晨起床；
- 乘车到固定路口；
- 带工具等待；
- 围住临时招工车辆询问；
- 数小时不能离开，否则可能错过下一批招工者；
- 当天没有被选中，收入为零。

可以把它称作 **standby labor / 待派劳动**：没有被计入工资，却是获得零工所必须支付的时间成本。

### 0.4 settlement trust / 结算信任

日结的吸引力有时不只在“灵活”，而在于：

> **今天干、今天结，比承诺一个月后发工资更容易验证。**

如果劳动者过去经历过拖欠、黑中介或包工链条，缩短结算周期本身就是一种风险控制。

但必须反向固定：

> `day labor ≠ guaranteed same-day payment`。

临时工作同样可能发生少算工时、克扣、不给钱或中介失联。

# 第一部分：Internet 以前，“每天找活”已经是一套城市基础设施

## 1. 沈阳鲁园：2004 年报道说这个自发零工市场已经存在 13 年

2004 年 2 月的同期报道记录，沈阳鲁园劳务市场是一个自发形成的零工劳务市场，报道时称其已经存在 **13 年**；2003 年沈阳市外来务工农民工约 30 万，节后大量外地劳动者再次来到鲁园“找活”。

来源：

- 2004-02-11 同期报道《鲁园里 农民工艰难“找活儿”》：  
  <https://news.sina.cn/sa/2004-02-11/detail-ikknscsi2613320.d.html>

证据等级：**B**。报道是 2004 年同期材料；“存在 13 年”属于报道中的历史陈述，本轮没有取得 1991 年市场原始档案，所以不能升级成 1991 年 A 级证据。

如果该陈述成立，鲁园的形成约可回推到 1991 年左右，明显早于中国大众 Internet。

这条边界非常重要：

> **开放式零工匹配不是网络平台发明的。**

一个马路市场本身已经是信息系统：

```text
固定地点
+ 固定清晨时段
+ 长期形成的口碑
+ 雇主知道“这里有人”
+ 劳动者知道“这里可能有活”
```

地点本身就是一个搜索索引。

---

## 2. physical addressability / 物理可寻址性

普通招聘研究往往把地址理解为“公司地址”。

日结市场反过来：

> **劳动者必须让自己的身体出现在一个雇主知道会有工人的地方。**

于是出现一种很具体的基础设施：

```text
城市交通
→ 路口 / 市场
→ 清晨聚集
→ 车辆进入
→ 雇主现场看人
→ 工人上车
```

它和后来手机平台的差别，不是“有没有信息”，而是**信息与身体是否必须处在同一个地点**。

# 第二部分：2005—2012 扩张型未来——机会变多，但“正规市场”未必比马路更好用

## 3. 2008 郑州：政府建了市场，工人却重新跑回二马路

2008 年 8 月 7 日《大河报》的同期报道记录了一个非常干净的反例。

郑州市临时劳务市场刚开业，劳动部门把原本聚集在二马路的人劝进新市场。新市场有：

- 遮阳避雨设施；
- 饮水；
- 免费求职登记；
- 政策咨询；
- 职业指导；
- 职业介绍；
- 维权举报。

但记者在场观察到，市场里几乎没有企业来发布招聘信息。到了中午，大多数劳动者又回到了二马路。

劳动者给出的理由很直接：

> 临时招工的人不知道新市场在哪里，在里面反而不好找活。

报道还记录，原二马路每天约有一千人找工作，劳动者手里或脚边的纸上会直接写“杂工”“炒菜”“护理病人”“保姆”等技能 / 求职信息。

来源：

- 《新劳务市场开业求职农民工不买账》，大河报，2008-08-07，经新浪保存：  
  <https://news.sina.com.cn/c/2008-08-07/073414279363s.shtml>

证据等级：**B+：同期现场报道 + 同期被访者解释。**

### 3.1 two-sided discoverability / 双边可发现性

这件事说明“基础设施更正规”不自动等于“市场更可执行”。

劳动市场同时需要两边知道这里：

```text
劳动者知道去哪里
AND
雇主知道去哪里找人
```

因此：

> **worker discoverability alone ≠ functioning labor market**

> **safe venue ≠ employer traffic**

这和后来互联网平台的 network effect 是同一个更一般的问题：

> **信息市场必须同时让供给和需求聚在一起。**

### 3.2 一张纸也是 profile

2008 年劳动者把“杂工”“护理病人”“保姆”等写在纸上放在脚边。

这是一种非常低技术、但高度可执行的 **physical profile**：

- 我会什么；
- 我现在有空；
- 我人在这里；
- 你可以当场问我价钱。

后来招聘网站把这些东西变成字段和筛选器，但“把自己压缩成雇主一眼能识别的信息”并不是数据库时代才出现。

## 4. 同时期 Web 并没有简单替代马路：真正改变的是搜索距离与随身性

2005 年后，赶集网、58 同城等本地分类信息平台逐渐把招聘、住房、二手交易和本地服务放在城市化的信息页面中。

2010 年的同期行业资料显示：

- 赶集网已在 2009 年推出 WAP 版本；
- 2010 年 9 月又推出面向 iPhone、BlackBerry、Nokia/Symbian 等设备的客户端；
- 58 同城在 2010 年已经把招聘求职列为主要本地生活信息类别之一。

来源：

- Interfax China, 2010-09-06, Ganji launches smartphone application：  
  <https://interfax.com/newsroom/top-stories/63073/>
- 2010 年同期 58 同城发展报道：  
  <https://news.sina.com.cn/o/2010-12-08/112621603044.shtml>

证据等级：**B / company-industry claim**。这些材料证明产品与类别存在，不证明日结工普遍转向线上。

最重要的边界是：

> **online local listings available ≠ street market displaced**。

2008 郑州恰好证明，现实中“知道哪里有雇主”仍可以比拥有更正规空间重要。

# 第三部分：2015—2019 拥堵型未来——“只属于今天的工作”

## 5. 2018 济南：每天凌晨“上市”，找不到活就整天等

2018 年齐鲁晚报的同期报道把零工市场的时间结构记录得极清楚：

- 凌晨 5 点左右，劳动者在路边或街口聚集，称为“上市”；
- 找到活后在 7 点左右散去，称为“下市”；
- 找不到工作的人可能在市场滞留一整天；
- 第二天再重新开始。

来源：

- 《为等活凌晨就上街怕欠薪不敢做长工》，2018-07-16：  
  <https://www.chinanews.com.cn/m/sh/2018/07-16/8568514.shtml>

证据等级：**B：同期现场报道。**

另一篇 2018 年济南报道记录，平时每天有两三千人在一个自发马路劳务市场揽活；很多人约凌晨 4 点起床，约一半能在 6 点左右找到活，工作九小时以上后领取当天报酬；没有找到的人继续等中午或傍晚的下一批招工者。

来源：

- 《零工市场“早起的鸟儿”为何难觅食？》，济南日报，2018-02-26：  
  <https://news.iqilu.com/shandong/shandonggedi/20180226/3845022.shtml>

证据等级：**B**。

### 5.1 employment time is not work time

如果只记“当天干了 9 小时”，会漏掉：

```text
04:00 起床
→ 交通
→ 05:00 等活
→ 06:00 被选中 / 或继续等
→ 到工地
→ 9 小时劳动
→ 回市场 / 回住处
```

因此对零工必须分开：

- paid work time；
- search time；
- standby time；
- transport-to-job time；
- settlement time。

### 5.2 fear of arrears can change preferred contract length

2018 报道标题本身就记录了一种现实选择：**怕欠薪，不敢做长工。**

不能从一个报道外推所有零工，但它足以证明一个机制：

> 有时“日结”不是年轻人的 lifestyle 偏好，而是对较长工资结算周期缺乏信任后的风险管理。

也就是说：

> **short contract can be defensive, not expansive.**

## 6. 2019 马驹桥：临时工可以成为下一份长期工作的桥

2019 年《工人日报》对北京马驹桥马路市场的同期调查写得非常具体：

- 数百名外来务工人员清晨聚集，等待“只属于今天的工作”；
- 不面试、不体检、不缴社保、不签合同的短期招工常由车辆直接拉走；
- 现场手机微信群同时发布各种招工信息；
- 27 岁的张伟此前做过长期工，但长期白班夜班轮换让身体吃不消，于是来到这里，打算“先干临时工，再慢慢找长期工干”。

来源：

- 《非法劳务市场隐患暗藏 整治行动亟待深入》，工人日报，2019-07-18，经中新网保存：  
  <https://www.chinanews.com/sh/2019/07-18/8898589.shtml>

证据等级：**B+：同期现场 + 同期第一人称。**

新京报同年也记录了马驹桥的即时询价过程：雇主车辆停下后，劳动者会立即问工资、件数、是否包饭等条件；有人现场被选中上车离开。

来源：

- 《马驹桥日结工：按天结算的日子》，新京报，2019-06-17：  
  <https://news.sina.com.cn/c/2019-06-17/doc-ihvhiews9529525.shtml>

证据等级：**B**。

### 6.1 bridge employment / 桥接就业

张伟的路径不是：

```text
稳定工作 → 从此选择零工生活
```

而是：

```text
长期倒班不可持续
→ 退出
→ 日结维持现金流
→ 同时寻找下一份长期工作
```

所以日结可以是一层 **bridge employment**：

> 不让“离开一份工作”和“找到下一份工作”之间变成完全无收入的空白。

这直接连接仓库已有的 career interruption / re-entry 研究。

### 6.2 street + WeChat coexistence

2019 年现场同时存在：

```text
路口身体聚集
+ 面包车现场挑人
+ 微信群发招工信息
```

移动互联网不是把旧市场瞬间删除，而是给它增加了一层 dispatch channel。

这也是后面零工驿站“线上 + 线下”结构的前身之一。

# 第四部分：2020—2022 偶发型未来——突然失去原工作以后，临时劳动成为收入桥

## 7. 2020 上海：做了六年酒店经理以后，第一份零工来自平台

新华社 2020 年 6 月的同期报道记录了张诚的经历：

- 他此前在上海一家饭店担任经理约 6 年；
- 疫情中收到公司解职邮件；
- 他通过“独立日”灵活用工平台找到人生第一份零工；
- 同一天可以上午在盒马配送生鲜，下午到星巴克工作。

报道还称，该平台在疫情期间做“共享员工”匹配，为餐饮企业闲置劳动力与生鲜、商超等短期缺工进行对接。平台给出的“9366 人”等数字属于平台/报道口径，不应直接外推整个劳动市场。

来源：

- 新华社，2020-06-17《早上在盒马送生鲜 下午在星巴克冲咖啡 灵活用工兴起》，新浪保存：  
  <https://k.sina.cn/article_2810373291_a782e4ab02001q9ci.html>

证据等级：**B+：同期媒体 + 同期人物经历；平台规模数字保留 vendor/reporting boundary。**

### 7.1 contingent bridge / 偶发桥接

这不是传统“我喜欢自由所以兼职”。

它的顺序是：

```text
连续六年职业身份
→ 外部冲击导致突然失业
→ 平台快速匹配短工
→ 多个短班次拼接现金流
```

因此 2020—2022 的关键不是“零工突然被发明”，而是：

> **既有的短期劳动基础设施第一次在大范围生活中承担 continuity buffer / 连续性缓冲。**

当正式岗位突然中断，它允许劳动者不必等一整套长期招聘流程结束才重新获得收入。

### 7.2 它同样会重新制造制度问题

2020 年同期关于“共享员工”的报道已经讨论：

- 合同怎么签；
- 工资谁付；
- 社保怎么算；
- 工伤责任归谁。

来源：

- 人民网 2020-02-13：  
  <https://society.people.com.cn/n1/2020/0213/c1008-31585232.html>
- 光明日报 2020-02-16：  
  <https://epaper.gmw.cn/gmrb/html/2020-02/16/nw.D110000gmrb_20200216_1-03.htm>

所以：

> **fast rematching ≠ clear employment relationship**。

平台可以缩短空窗，但也可能把原来由单一雇主承担的责任关系变复杂。

# 第五部分：2023—2026 防守型未来——“退路”开始被建成公共基础设施

## 8. 2025 西安：零工市场首先是一个让人不用在风里等的地方

2025 年新华社报道西安半坡立交下的零工“马路市场”，高峰时每天有上千人寻找日结工、短期工。附近新建的零工驿站提供：

- 暖气、热水；
- 岗位信息；
- 就业介绍；
- 法律咨询；
- 培训和权益服务。

来源：

- 新华社 / 人民网，2025-02-20：《从“零工驿站”看“灵活就业”》  
  <https://finance.people.com.cn/n1/2025/0220/c1004-40422241.html>

证据等级：**A/B：同期新华社现场报道；岗位服务数据按机构口径使用。**

这一变化的生活史意义不只是“招聘数字化”。

它是在给以前没人计价的 standby time 补基础设施：

```text
原来：风 / 雨 / 高温下蹲守
现在：室内等待 + 饮水 + 充电 + 岗位屏 + 人工咨询
```

也就是说，公共服务开始承认：

> **等待本身是零工人生的一部分。**

---

## 9. 2025 襄阳：信息、休息、培训、权益被并到同一个“零工接口”

2025 年人民日报采访 50 多岁小货车司机余献忠。他回忆过去“信息少、活儿不好找”，需要在市场里转来转去，寒冬酷暑也没有休息处；当地建立零工驿站以后，他表示接到的活更多，也有了可休息、喝水和纳凉的地方。

来源：

- 人民日报，2025-03-18：  
  <https://finance.people.com.cn/n1/2025/0318/c1004-40440885.html>

证据等级：**B+：同期媒体 + 同期第一人称。**

这形成一种新的 **labor-market fallback infrastructure / 劳动力市场退路基础设施**：

- 不是保证一份终身工作；
- 也不是只给一个招聘网站；
- 而是在人突然缺工作、想短期挣钱、年龄较大或需要重新训练时，提供一个可以再次进入劳动市场的低门槛入口。

2025 年北京零工市场的报道还记录了家庭负担较重的曹大姐通过市场登记、免费培训后进入养老照护零工，并持续服务多位老人。

来源：

- 工人日报 / 中国新闻网，2025-07-25：  
  <https://www.chinanews.com.cn/sh/2025/07-25/10453358.shtml>

这类个案不能代表所有零工，但说明“退路”本身开始被制度化：

> **不必先成为长期员工，也能先取得一点收入、训练和下一步信息。**

# 第六部分：从 2008 到 2025，变的不是“有没有零工”，而是谁承担匹配成本

## 10. 四个阶段可以这样比较

### 2005—2012：expansive future / 扩张型未来

主要变化：

- 城市迁移和用工需求扩大；
- 马路市场、正式劳务市场、职业介绍、电话和 Web 分类信息并存；
- 本地分类网站开始把“附近有没有工作”变成远程可查询信息；
- 但现场 two-sided discoverability 仍决定一个市场好不好用。

生活感受不能写成“大家都觉得未来越来越好”；更窄的结论是：

> **一个人可以尝试的工作入口在增加。**

### 2015—2019：congested future / 拥堵型未来

主要变化：

- 大量人仍每天重新入市；
- 数百甚至数千人在同一地点等活；
- 同一个岗位可能二十多人同时围上去；
- 手机群增加信息入口，却不消除岗位稀缺；
- 日结的即时现金和退出自由，对一些人比长期倒班、月底发薪更可接受。

这里的时间感是：

> **不是看不见工作，而是每天都必须重新竞争今天这一份。**

### 2020—2022：contingent future / 偶发型未来

外部冲击使不少原本连续的职业突然中断。

短工 / 平台临时匹配第一次非常清楚地表现为：

> **income bridge before career recovery**。

### 2023—2026：defensive future / 防守型未来

零工驿站、公共市场、线上群、岗位审核、培训、法律援助和休息空间逐渐被合并。

关键词不是“我要靠零工发财”，而更多是：

- 今天先有收入；
- 没长期岗位时不要完全断现金流；
- 年龄 / 家庭责任变化以后还有入口；
- 被欠薪时有地方问；
- 想从零工转长期工作时有人提供信息。

可以把它理解为：

> **optionality is being infrastructuralized / 可选退路被基础设施化。**

# 第七部分：海外对照——日工不是中国 Internet 时代的特殊产物

## 11. 1999 洛杉矶：street-corner day labor 已经是高度可见的城市劳动系统

UCLA 1999 年发布的 Day Labor Survey 初步结果，基于洛杉矶和橙县 87 个招聘点、481 名日工劳动者的随机调查。材料记录大量拉美移民在：

- 街角；
- 建材 / 家装商店附近；
- 正式 hiring site

等待建筑、园艺、搬运、拆除、油漆等当日工作。

来源：

- UCLA Newsroom, 1999-06-17, *New Study on Southern California Day Laborers Offers First Detailed Look at this Informal Labor Market*：  
  <https://www.newmediawire.com/news/new-study-on-southern-california-day-laborers-offers-first-detailed-look-at-this-informal-labor-market-3064626>
- Abel Valenzuela Jr., UCLA Today, 1999-07-27：  
  <https://www.newmediawire.com/news/misperceptions-beset-day-laborers-3064740>

证据等级：**near-contemporary scholarly / institutional**。

2002 年比较洛杉矶与东京的研究甚至直接把 day labor 定义为：

> 劳动者每天在露天街头市场或路边招聘点寻找临时工作。

来源：

- Abel Valenzuela Jr., Janette A. Kawachi, Matthew D. Marr, 2002, *Seeking Work Daily*：  
  <https://journals.sagepub.com/doi/10.1177/002071520204300205>

### 11.1 共同机制

中国郑州 / 济南 / 马驹桥与洛杉矶、东京在制度和迁移背景上非常不同，不能互相代表。

但它们共享一个比 Internet 更早的劳动市场形态：

```text
固定城市地点
+ 高频劳动需求
+ 没有长期雇佣承诺
+ 劳动者反复到场
+ 雇主当天挑选
```

所以 `daily re-entry` 不是中国特有，也不是平台经济发明的。

### 11.2 差异不能抹掉

洛杉矶材料中的移民法律身份、英语能力和医疗可及性构成非常具体的美国制度约束；中国马路零工的户籍、劳务中介、工资支付、建筑 / 制造用工和社会保险问题则是另一套制度结构。

真正可比较的是 **market form**，而不是把两群劳动者写成同一种人。

# 第八部分：互联网真正改变了什么？

## 12. 从“身体一直在场”到“可远程 dispatch”

可以把找零工的通信谱系写成：

```text
固定马路 / 市场
→ 纸牌 / 熟人 / 包工头
→ 电话 / 寻呼 / 手机
→ 分类信息网页
→ QQ / 短信
→ 微信群
→ 专门兼职 / 灵活用工平台
→ 零工驿站的线上 + 线下系统
```

互联网最明显改变的是：

> **劳动者不一定要一直用身体占据路口，才能保持“我现在可以干活”这个状态的可见性。**

但 2019 的马驹桥证明：

> **digital dispatch can coexist with physical waiting.**

所以不能写“微信群取代了马路市场”。

---

## 13. listing latency matters more for day labor than ordinary jobs

长期岗位发布一周以后可能仍有效。

日结岗位却可能：

```text
05:30 发布：今天需要 8 人
06:05：已招满
07:00：帖子还在
```

因此对零工：

> **posting age is part of job validity.**

这正是交叉旧网专题需要单独研究的地方。

# 第九部分：它改变了“普通人有多少种活法”的哪一点？

## 14. “有工作 / 没工作”并不是二元状态

日结材料至少迫使生活史增加以下中间状态：

```text
有长期工作
短期合同中
今天有活、明天未知
今天正在等活
今天没等到
靠零工维持、同时找长期工
原工作中断、零工作为桥
家庭责任变化后主动只做短工
无法进入正规岗位、被迫依赖日工
```

这些状态不能全部归成“失业”，也不能全部浪漫化成“灵活就业”。

最准确的做法是问：

- 谁控制工作日历；
- 谁承担没有订单的时间；
- 现金多久到账；
- 谁承担工伤 / 欠薪风险；
- 一天结束以后有没有下一天；
- 这条路线是主动选择、暂时桥接，还是被其他路径排除后的剩余选项。

---

## 15. cash buffer 与日结是替代关系之一，但不能机械化

如果家庭有足够储蓄，一个人可以花三周寻找更合适的长期工作。

如果现金只够几天：

> **“月底才发工资”本身都可能成为进入某份工作的成本。**

日结可以暂时承担 cash-buffer substitute 的作用。

但：

- 工价波动；
- 无活日；
- 工伤；
- 交通和住宿；
- 中介抽成；
- 社保缺失

可能让它长期看更不稳定。

因此不要把“到账快”写成“总体更好”。

| 维度 | 本专题新增内容 |
|---|---|
| 教育 | 低学历 / 技能证书可能影响被挑选范围，但不能把零工等同低学历 |

| 平台消失与记忆 | 临时岗位和私聊派工极难进入公共档案 |

# 第十一部分：证据边界、反例与后见之明风险

## 16. 不要把所有短工写成同一种“零工经济”

至少区分：

- 建筑 / 搬运日工；
- 工厂临时工；
- 餐饮 / 零售小时工；
- 家政 / 照护钟点工；
- 大学生兼职；
- 平台配送；
- 专业自由职业；
- 正式企业之间的“共享员工”。

它们的技能、合同、风险和议价完全不同。

## 17. 不要把 2020s “灵活就业”概念倒写回 1990s

1990s 马路日工当然可以被今天分析为一种灵活 / 临时劳动，但历史行动者当时未必用这套词理解自己。

必须保留时代词汇：

- 找活；
- 打短工；
- 临时工；
- 马路劳务市场；
- 趴活 / 等活；
- 日结。

## 18. 不要把“自由”当作默认解释

同样选择日结的人可能因为：

- 不想长期倒班；
- 家庭责任需要可中断时间；
- 年龄或学历难进入正式岗位；
- 怕长期欠薪；
- 手上没钱，需要当天现金；
- 刚失业，用它过渡；
- 只想临时补收入；
- 主动不愿长期绑定一个单位。

必须从具体材料判断，而不是统一解释为“追求自由”。

## 19. 不要把街头市场只当作“落后”

2008 郑州新市场失败的第一天说明：

> 一个更规范、更干净的市场，如果雇主不知道它，也可能暂时比旧路口更难用。

历史分析应该解释旧系统为何仍具有执行优势，同时也记录它的诈骗、欠薪、交通和安全成本。

# 第十二部分：仍不知道什么

1. 尚未恢复一条 1990s 中国普通零工劳动者的连续个人日记 / 工资记录，可以逐日计算“等活—上工—无活—现金”的真实月份。
2. 鲁园“存在 13 年”目前来自 2004 同期报道的历史陈述，仍应寻找 1991–1995 当地报纸、地方志或就业部门材料。
3. 2008 郑州二马路可以看到现场求职和技能纸牌，但尚未恢复同一劳动者后来第一次通过 Web / 手机群找到临工的纵向链。
4. 2018–2019 马路市场材料丰富，但“一个月到底有多少无活日、收入方差多大”仍缺系统样本。
5. 2020 平台“共享员工”提供了过渡机制，但平台宣传数字与真实持续就业结果必须分开。
6. 2025 零工驿站的服务量不能直接等于新增就业；应继续区分 visits / registrations / matches / actual shifts / wage settlement / durable re-employment。

# 下一步

最高价值的下一步不是再找一篇“日结工很辛苦”的报道，而是恢复一条 **同一个普通劳动者至少 30 天的 work ledger**：

```text
日期
→ 去哪里等活
→ 等多久
→ 有没有被选中
→ 做什么
→ 报价
→ 实得
→ 什么时候到账
→ 交通 / 住宿 / 饭钱
→ 第二天是否继续
```

如果能找到 2008–2010 和 2018–2019 各一组，就能第一次把“零工不稳定”从一句形容词还原成真正的生活日历：

> **一个人不是有没有工作，而是这个月有多少个早晨，醒来以后仍然不知道今天有没有工资。**
