# 从“有事呼我”到“为什么不回消息”：寻呼、移动电话、在线状态与可达性边界（中国，1984—2026）

## 研究问题

仓库已有 `communication-and-the-cost-of-living-far-away.md` 讨论电话、移动通信如何降低迁移后的联系成本，也已经研究过校友录如何让旧关系重新可寻址。

本文补的是一个更细、但会直接改变一天怎样被组织的问题：

> **什么时候开始，别人不再只是能联系到“你所在的地方”，而是能在几乎任何地方直接联系到“你这个人”；而这种能力成熟以后，一个普通人又怎样重新争取“不立刻回应”的权利？**

它不是一部中国移动通信行业史，也不把技术变化写成“固定电话 → BP 机 → 手机 → QQ → 微信”的简单替代。

本文区分：

- 能不能留下信息；
- 信息送到一个地点还是一个人；
- 对方是否必须同时在线；
- 对方是否知道自己被联系；
- 联系者能否看见对方的可用状态；
- “在线”是否被理解成“可以打扰”；
- 收到消息以后社会上允许多久不回复；
- 工作、亲友和平台是否允许本人暂时不可达。

这些差别决定了一种很具体的生活能力：**可达性是否可由本人管理。**

---

## 一、先拆状态：`reachable` 不是一个布尔值

### 1. `place-addressability / 地点可寻址性`

家庭电话、公用电话、单位总机首先把一个地点变成地址：

```text
知道某单位 / 家庭号码
→ 电话线路可用
→ 有人在电话旁
→ 有人接听
→ 能把话转给目标本人
→ 本人实际接到电话
```

所以：

`phone installed != target person reachable`。

一个人在单位有电话，不等于下班后仍可联系；家里有电话，也不等于本人此刻在家。

### 2. `person-addressability / 人可寻址性`

寻呼机和移动电话逐渐把联系地址从“你在哪里”移到“你是谁”。

但寻呼机仍然不是双向电话：

```text
呼叫者拨寻呼台
→ 台站把号码 / 文字发给寻呼机
→ 佩戴者注意到提示
→ 理解是谁 / 什么事
→ 找到一部可回拨电话
→ 回拨成功
```

因此：

`pager message delivered != conversation established`。

寻呼机把“请联系我”送到人身上，却仍常常要借另一套电话基础设施完成真正会话。

### 3. `presence visibility / 在线状态可见性`

即时通信又加入新的层：联系者不仅能发送消息，还可能先看到对方状态：

- online；
- away；
- busy / do not disturb；
- invisible；
- offline。

这把“有没有空”第一次部分编码进界面。

但必须保留：

`online != attentive != available != willing to reply`。

### 4. `response-latency norm / 回复时延规范`

技术把消息送到终端的时间压到很短，并不会自动决定人应该多快回答。

真正变化的是社会预期：

```text
信息可能几小时后才被看到
→ 信息已经送达但不知道对方是否在
→ 看见对方“在线”
→ 手机一直随身
→ 工作群 / 私聊随时弹出
→ “为什么还没回”成为一种新的日常追问
```

因此本文把 **`response expectation`** 与 **`transport latency`** 分开。

### 5. `reachability sovereignty / 可达性主权`

本文用这个词表示：

> 一个人能否决定自己何时接受联系、何时只接紧急信息、何时暂时离线，而不会因为技术上可达就自动承担即时回应义务。

它不是“永远关机”，而是控制通信边界的能力。

## 二、1980s—1990s：在大众 Internet 以前，先出现“把召唤送到人身上”

### 6. 1984 起的中国寻呼：不要把 BP 机写成一部小手机

中国电信博物馆的通信史资料把大陆无线寻呼业务的早期节点放在 1984 年上海；1990s 无线寻呼快速扩张，1998 年全国寻呼用户突破 6546 万，2000 年达到约 8400 万的高位。[S1]

这个后来机构史适合做规模锚点，但不能替代当时个人生活材料。

真正重要的是结构：寻呼机是典型的**单向人身可达**设备。

有人要找你时，不必先猜：

- 你今天在单位哪间办公室；
- 你是不是已经回家；
- 你去了哪家饭馆；
- 旅途中住哪家招待所。

但你收到寻呼后，仍可能需要寻找公用电话、单位电话、住宅电话或其他电话回拨。

因此寻呼时代的移动性公式可以写成：

```text
pager = portable notification
telephone = conversational return path
```

两者组合才完成一次普通联系。

### 7. 1995—1996：公用电话是 BP 机“回路”的重要物理层

1996 年《人民日报》回顾，1995 年中国城市公用电话已经发展到 **84.7 万部**，过去“走二里路也找不到公话、还要排队”的状况明显缓解；报道同时显示长途资费、计费器和节假日价格仍是实际使用问题。[S2]

所以不能把“BP 机很普及”理解成佩戴者已经可以直接完成双向移动通信。

一个典型路径仍可能是：

```text
腰间 BP 机响
→ 看见号码 / 文字
→ 找街边公话
→ 排队或付费
→ 回拨
```

**可达性扩大了，但回话仍然有地点。**

### 8. 1996 全国联网寻呼：先让“号码跟着人走”

1996 年 10 月，中国联通公众寻呼网一期实现十城市联网。《人民日报》同期报道明确说，联网用户出差、旅游时无需换机换号；来话还可以在手机关闭时转到同号寻呼机。[S3]

这不是“全国人人都能随身通信”的证据。

但它证明一种新基础设施目标已经非常明确：

> **人的通信地址不应该因为身体跨城市移动就失效。**

可以把它称为 `number portability across movement / 移动中的号码连续性`，但不要和后来法律意义上的“携号转网”混淆。

### 9. 1990s 的分布不能抹平

1998 年 Dataquest 的同时代全球市场材料估计，中国约占 1998 年 1 月全球寻呼订户的 30.4%，已经是世界最大的单一市场之一。[S4]

同年《财富》中文报道援引当时行业统计称全国约有 5380 万寻呼用户，普及率仍只约 4%，同时移动电话用户约 1300 万。[S5]

不同统计时间点、口径和预测值并不完全一致，所以本文不把某一个数字当唯一“真值”。共同能支持的是：

- 寻呼已经是千万级大众通信；
- 它仍远不是全人口普及；
- 手机当时更加昂贵、覆盖和资费也仍有限；
- “BP 机时代”内部仍有巨大城乡、收入和职业差异。

### 10. 海外前 Web 对照：1983 年美国家庭已经在用 beeper 管理“人在外面”

1983 年 `TIME` 的同期报道记录，新泽西一名高中女生晚归时，父母会呼她的 beeper 提醒回家；父母自己进纽约时也会带着 pager，让孩子在重要事情发生时可以“buzz”到他们。[S6]

这是很好的跨国对照，因为它证明：

`portable reachability` 并不是中国 1990s 市场特有现象。

但具体社会意义不同：

- 谁负担设备和服务费；
- 是专业工作者、青少年还是普通家庭先用；
- 公用电话和移动电话的密度；
- 城市覆盖；
- 监管和文化标签；

都会影响这种设备怎样进入日常生活。

## 三、1996—2001：即时通信不只是“网上聊天”，而是把“人在不在”做成可观察状态

### 11. 1998 ICQ：邮件与聊天室之间出现新的时间结构

日本 `INTERNET Watch` 1998 年的同期 ICQ 使用教程非常清楚地描述：

- 对方在线时，消息可以立即到达；
- 对方离线时，服务器会保留消息，下次上线再显示；
- 联系列表会显示 online / away / extended away 等状态；
- 使用者可以主动改变状态。[S7]

另一份 1998 年同期欧洲电脑杂志还列出 Online、Away、N/A、Occupied、DND、Free For Chat、Invisible、Offline 等多种状态，并提醒拨号上网用户按分钟计费，因此并不是所有人都能长时间维持 Away 状态。[S8]

这很重要：

**“在线状态”最早并不是一个无成本、永久存在的背景。**

在按电话脉冲、按分钟付费的拨号环境里：

```text
保持在线
= 占电话线
+ 支付接入时间成本
+ 让别人看见你可以被联系
```

### 12. `presence` 第一次把社交边界编码成协议状态

在电话里，对方往往只知道：

- 打通；
- 占线；
- 没人接。

即时通信却允许一个人表达：

> 我连接着网络，但我不等于现在愿意聊天。

这就是 `presence boundary / 在线状态边界`。

它是后来所有“忙碌”“免打扰”“隐身”的前史。

### 13. 2000—2001：OICQ/QQ 和手机短信开始互相接起来

2001 年 3 月，北京移动正式开通“移动 OICQ”。同期报道说明，GSM SMS/WAP 系统与 OICQ 系统通过网关互通；手机用户可以给 OICQ 用户发消息、查询好友状态，还可以在 OICQ 用户不在线时留下消息。[S9]

报道还说 2001 年 1 月移动 OICQ 每日消息量已经超过 100 万条；这个数量是运营方/媒体当时口径，只能证明业务规模声明，不能直接推出独立用户人数。

更重要的是技术边界发生变化：

```text
PC 上的 OICQ 好友
≠ 必须等我回到电脑前才能联系
```

手机短信开始成为 PC 即时通信的异步外延。

所以早期中国“移动互联网生活”并不等于智能手机装 App；它可以是：

`PC 客户端 + 运营商短信网关 + GSM 手机`。

## 四、2005—2012：扩张型未来——从“等我回电话”到“我一直都可能在线”

### 14. 2006—2007：手机已经是大规模基础设施，但仍不是人人一样可达

2006 年全国通信业统计显示：

- 移动电话用户约 4.61 亿；
- 移动电话普及率 35.3 部/百人；
- 固定电话约 3.68 亿；
- 公用电话约 2982 万部；
- 当年移动短信业务量约 4296.7 亿条。[S10]

到 2007 年末，移动电话约 5.47 亿户，普及率约 41.6 部/百人；固定电话总量开始下降。[S11]

这些是“每百人部数/用户数”，不是“多少个人各自拥有一部手机”的严格同义词。

但它们足够说明：2000s 后期，个人移动号码已经从少数高价设备走向极大规模日常基础设施。

### 15. 2007 中学生：父母买手机首先是为了“随时找到孩子”

新华社 2007 年哈尔滨报道里，多数受访家长给中学生买手机的理由之一是方便接送与紧急联络；报道同时记录学生会频繁短信、反复查看手机，没带手机或没电时感到不安。[S12]

证据等级：**B，同期媒体采访与局部调查。**

不能用它证明所有中国中学生都“手机依赖”。

但它固定了一条很重要的家庭生活变化：

> 一个离开家门去上学的孩子，第一次越来越被期待保持**个人级可达**。

父母不再只能：

- 打学校办公室；
- 给班主任留言；
- 等孩子回家。

### 16. 2008 QQ “隐身”：可达性变多以后，边界争议也已经出现

2008 年山东一则同期采访记录，部分 QQ 用户使用外挂查看好友是否“隐身”。受访者给出了两种非常不同的理解：

- 有人说只是想知道朋友同事是不是在线；
- 另一位受访者则明确把“隐身”理解为“不想被打扰”，认为用户应该拥有不被他人识破的生活边界。[S13]

这是本轮特别重要的一手生活材料，因为它说明到 2008 年，问题已经不再只是：

> “怎样让朋友找到我？”

而是出现了反问题：

> **“我明明在线，但能不能不让所有人知道？”**

这就是 `availability privacy / 可用性隐私`。

### 17. 2009 手机 QQ：在线状态从“电脑旁”脱离

2009 年武汉校园报道保存了一名母亲的困惑：她发现儿子的 QQ 头像几乎一直亮着，原以为孩子逃课，后来才知道学生可以整天用手机“挂 QQ”；报道还采访到从早到晚手机聊 QQ 的大学生。[S14]

同年 CNNIC 数据显示，中国手机网民已经达到约 2.33 亿，占当时网民的 60.8%；即时通信用户约 2.77 亿，手机即时通信用户约 9141 万。[S15][S16]

这意味着 `online` 的语义发生了关键漂移：

```text
1998：Online 很大程度意味着电脑此刻连接着 Internet
2009：Online 可能只是手机客户端常驻
```

所以：

`presence indicator != bodily attention`。

看到头像亮着，越来越不能推出这个人正坐在屏幕前、正在读你的话、或者有空回答。

### 18. 扩张型未来里的新承诺：离开一个地点，不再等于失去联系

对 2005—2012 的年轻人来说，手机 + QQ/SMS 的扩张至少打开了这些现实路径：

- 大学离家后仍可被父母直接找到；
- 求职、租房、临时工作可以把一个个人号码留给陌生机构；
- 出差、旅行和跨城生活不必反复告诉别人“我今晚住哪里才能找到我”；
- 线上朋友可以把留言留到下一次上线；
- PC 端关系图开始延伸到移动终端。

扩张的主观承诺可以概括成：

> **“我走到哪里，关系不必留在原来的电话机旁边。”**

但这还不是“所有人随时在线”。设备、资费、网络覆盖、手机上网能力和年龄差异都必须保留。

## 五、2015—2019：拥堵型未来——“随时可达”从自由变成工作时限模糊

### 19. 2018 工作微信群：联系渠道多到需要人为制造“下班”

2018 年《中国青年报》同期采访的魏丽娜，大学毕业工作一年，微信里有 481 个可统计的群，其中 27 个被置顶；李响工作 4 年后有 246 个群，为了睡觉开始在夜里断网；报道还记录工作指令通过群聊不断延伸到正常工作时间之外。[S17]

另一份 2018 年半月谈调查里，一名大学生村官称自己被加入 120 多个工作微信群，每天的重要工作之一就是翻聊天记录，担心漏掉通知。[S18]

这些材料不是全国劳动者统计样本，但它们非常适合说明一个新状态：

```text
communication infrastructure succeeds too well
→ almost every work relation has a cheap direct channel
→ message delivery cost approaches zero
→ sender can issue requests outside shared work place / work time
→ receiver must create their own filtering boundary
```

### 20. `message delivery` 与 `work obligation` 被错误地贴在一起

移动即时通信最容易产生的一种制度误读是：

`技术上已经送达 ≠ 劳动上必须立刻处理`。

可当手机就在口袋里时，“我没看到”越来越不容易成为可信默认状态。

2018 年《光明日报》甚至明确用“维护职工离线的权利”讨论这种变化。[S19]

这说明拥堵型未来的通信问题不是“没有渠道”，而是**渠道缺乏关闭边界**。

### 21. 2018 的“隐形加班”与 2008 的 QQ 隐身是同一条历史的两端

2008 年用户争的是：

> 我能不能明明登录着 QQ，却不让朋友知道我在线？

2018 年职场用户争的是：

> 我能不能明明拿着手机，却不因此一直处于工作可调用状态？

两者之间的共同问题是：

**presence does not equal permission。**

一个人的终端存在，不等于所有关系都获得同等打扰权。

## 六、2020—2022：偶发型未来——高可达网络成为生活连续性设施，也暴露单点依赖

疫情阶段，大量工作、学校、社区、家庭协调转向手机群聊、视频和即时消息。

本文不再重复仓库已有疫情数字生活专题，而只保留一个与本研究有关的机制：

> 当线下见面突然不可靠时，**原本只是方便的“随时可联系”能力变成维持组织连续性的基础设施。**

此时 `unreachable` 的代价会升高：

- 漏掉工作安排；
- 漏掉学校通知；
- 漏掉社区信息；
- 与异地家人失去实时确认渠道。

但这也意味着通信栈的故障、账号异常、手机没电、不会使用群聊，可能突然把一个人排除在本来默认可以参与的生活之外。

因此成熟通信系统必须同时研究：

`reachability expansion` 与 `fallback paths`。

## 七、2023—2026：防守型未来——从“保证随时找到我”到“我决定什么时候回复”

### 22. 2023：手机已经从通信工具变成持续召唤设备

2023 年《中国青年报》对 2007 名受访者的在线调查中，89.2% 表示自己经常不由自主看手机；同样比例称手机不在身边会不踏实。受访者王凯解释，很多工作都通过手机安排，自己会隔一会儿检查未接电话和未读消息，怕漏掉工作或亲友联系。[S20]

这个样本来自在线调查，不能外推为全体中国人。

但其中的同期第一人称很适合解释一种新的身体习惯：

**设备必须跟着身体，身体还要不断检查设备有没有召唤自己。**

### 23. 2023—2025：防守不是“退出社交”，而是给不同关系设置不同带宽

2023 年中国青年报调查中，受访者常见做法包括：

- 消息免打扰；
- 折叠群聊；
- 不看部分朋友圈；
- 区分工作与生活社交账户；
- 暂时退出微信。[S21]

2025 年有关“低糖社交”的同期采访里，一名青年教师明确把家长微信群限制为请假、课程信息等必要沟通，并给大量联系人设置折叠或免打扰。[S22]

这不是“社交退化”的证据，而是新的 **`relationship-specific availability / 分关系可达性`**：

```text
家人：可以高优先级
工作：工作时段高优先级
兴趣群：想看时再看
弱关系：可折叠
陌生请求：不必立即回应
紧急联系：另留电话 / 特殊入口
```

### 24. 2025 “数字戒断”：真正稀缺的能力是能够暂时不可达

2025 年《中国青年报》记录，娱乐公司策划陈明工作中两分钟不回消息就可能收到同事电话追问；他曾因周末近一天没看工作群被批评。后来他会主动关机、每周安排半天离线。其他受访者则使用集中回复、晚上 10 点后不看消息、定期免打扰等办法。[S23]

这里最值得保留的不是“年轻人手机成瘾”标签，而是一条历史反转：

```text
1990s：担心别人找不到我
2000s：享受随时能联系
2010s：担心漏掉任何消息
2020s：主动制造“暂时找不到我”的空间
```

这就是本文所谓 **`reachability sovereignty`**。

### 25. 防守型未来并不是重新回到固定电话时代

今天主动免打扰与过去“本来就联系不到”有根本不同：

- 通信基础设施仍然存在；
- 消息仍可积累；
- 紧急联系人可另设优先级；
- 本人可以稍后恢复；
- 离线是可逆选择，而不是基础设施缺失。

因此：

**`unreachable by constraint != unavailable by choice`。**

这两个历史状态不能混在一起。

## 八、跨国比较：共同变化不是“某国人特别爱回消息”，而是 person-addressability 的普遍后果

### 26. 美国 1983 pager 与中国 1990s BP 机：先把“人”变成接收端

两地都出现了类似转换：

`我要先找到你在哪` → `我可以先向你随身设备发出召唤`。

但价格、职业结构、公用电话密度和网络覆盖不同，因此不能用美国 1983 年高中生案例替代中国 1990s 用户分布。

### 27. ICQ 1998：在线状态与边界管理从一开始就是同一套系统

ICQ 的 Online、Away、DND、Invisible 说明，全球即时通信从早期就同时面对两个相反需求：

1. **I seek you：我希望知道你在不在。**
2. **Do Not Disturb：我需要告诉你现在不要找我。**

这不是智能手机时代才产生的矛盾。

### 28. 中国的特殊路径之一：寻呼、SMS、OICQ/QQ 与运营商网关高度交叠

2000—2001 的移动 OICQ 是一个很典型的中国技术过渡态：

- 即时通信关系图主要在 PC；
- 移动终端还是 GSM 手机；
- 消息通过 SMS/WAP/运营商网关跨系统；
- 用户可以查询好友状态和接收离线信息。

因此中国早期“在线生活”并不是 Web / PC 与移动网两条互不相干的历史，而是很早就发生了 **cross-network handoff**。

## 九、历史可见性：最容易保存的是“有人发了消息”，最难保存的是“她当时有没有空”

### 29. `message-survival / attention-loss asymmetry`

旧聊天记录、短信备份、论坛教程可能保存：

- 某条消息文本；
- 时间戳；
- 联系人号码 / UIN；
- 当时使用的软件功能。

但真正决定生活体验的状态往往消失：

- 她当时是不是在上课；
- 手机是不是放在包里；
- 是否看见提示；
- 是否故意不回；
- 是否在地铁无信号区；
- 是否已经睡着；
- 为什么后来才回。

因此 `timestamp gap` 必须长期保留：

`message sent at 22:03 != message read at 22:03 != response expected at 22:03`。

### 30. `presence archive illusion / 在线状态档案幻觉`

历史截图可能显示一个好友是绿色、灰色或隐身，但这只能证明界面当时展示某状态。

不能推出：

- 人真的在屏幕前；
- 人同意被打扰；
- status 与服务器权威状态一致；
- 第三方外挂没有修改呈现；
- screenshot 恰好代表日常平均行为。

### 31. `successful infrastructure invisibility`

寻呼时代一次最普通的成功联系可能只留下：

```text
“888888 呼我”
```

随后用户找公话回拨，什么都没有进入公共档案。

同样，QQ / SMS / 电话里最普通的大量关系维持都发生在私人通道，公共 Web 只留下软件教程、下载页、功能评测和极少数用户回忆。

所以旧网页很多，不能意味着它比电话 / 短信更代表普通人的通信量。

## 十、它改变了“普通人到底有多少种活法”的哪一点？

一个人的通信地址从“家里那部电话”变成“腰间 BP 机”，再变成“手机号”和“永远在线的账号”，看起来只是通信效率提高。

但对真实生命历程，它至少改变了四件更深的事情。

第一，**离开原地点的风险降低了。**

上学、出差、求职、迁移、旅行以后，家人和工作不必先知道你当前在哪栋楼，才能把紧急信息送到你身边。

第二，**生活可以更加分散。**

家庭成员可以住在不同城市，工作者可以在路上移动，朋友可以不共享作息，却仍维持高频低成本联系。

第三，**可达性本身开始被制度化。**

手机号可以写进简历、合同、快递、银行、医院、学校和各种账户。于是“能不能收到这一条消息”开始成为进入现代事务的基础条件。

第四，基础设施成功以后，又产生了新的稀缺品：

> **别人已经可以随时找到我，但我是否仍有权决定现在不回应？**

所以这条历史并不是简单的：

`失联 → 永远在线`。

更准确的是：

```text
地点可达
→ 人身可达
→ 异步可达
→ 在线状态可见
→ 移动常驻
→ 社会期待即时回应
→ 重新建立分关系、分时段、可撤销的离线边界
```

普通人的活法因此多出来的不只是“可以离家更远”，还有一种更晚才出现的自由：

**我可以让重要的人找得到我，同时不必把自己的每一分钟都变成公共接线台。**

## 十一、反例与后见之明风险

### 不能写成“BP 机人人都有”

1990s 末寻呼用户规模巨大，但相对总人口仍有限，职业、城市、收入差异显著。

### 不能写成“Internet 发明了异步通信”

信件、寻呼、答录机、语音信箱早已支持不同形式的异步联系。

### 不能写成“QQ 在线 = 用户当时在电脑前”

特别是手机 QQ 和常驻客户端普及后，这一推断越来越错误。

### 不能写成“手机导致隐形加班”而忽略劳动组织

技术降低了工作指令跨时间、跨地点发送的成本，但是否要求立即回复取决于管理方式、职业规范和劳动制度。

### 不能把今天的“数字戒断”投射回 1990s

过去很多人的不可达是设备、资费和网络约束；今天的主动离线是在基础设施已经存在以后进行的边界设计，两者不是同一个状态。

## 十二、我们知道什么 / 可以推断什么 / 还不知道什么

### 我们知道

- 1990s 中国寻呼与公用电话均达到大规模使用；
- 1996 年全国联网寻呼已经明确支持出差、旅行时不换号；
- 1998 ICQ 同期教程清楚显示 online/away/DND/invisible 等 presence 状态；
- 2001 移动 OICQ 已经把 SMS/WAP 与 PC 即时通信接起来；
- 2007—2009 中国手机、手机互联网与移动即时通信快速进入大众生活；
- 2008 年用户已经明确争论“隐身”是否是一种不被打扰的权利；
- 2018 年工作群带来的持续可达压力已有大量同期第一人称；
- 2023—2025 年用户开始主动使用免打扰、折叠、关机和集中回复重新管理可达性。

### 可以合理推断

- 寻呼 + 公话共同降低了移动中的“找人”成本；
- 手机让通信地址从地点进一步转向个人；
- 移动 IM 让“在线”从一次短暂连接逐渐变成背景状态；
- 当技术传输延迟接近零以后，社会冲突会从“能不能联系”转向“多久必须回复”；
- 现代通信自由同时包含“可被找到”与“可暂时不可用”两面。

### 还不知道

- 1990s 不同职业、城乡和收入群体实际多久收到一次寻呼、多久能找到回拨电话；
- 1995—2000 公用电话密度与寻呼机用户密度在城市内部怎样共变；
- 早期 OICQ 各版本的 presence 状态、离线消息与服务器行为精确到版本的变化；
- 2000—2005 “移动 OICQ”真实活跃独立用户数量，而不只是日消息量；
- 2008—2012 手机 QQ 常驻到底怎样改变平均响应时延；
- 不同职业今天对“多久不回消息算失职”的真实规范差异；
- 长期免打扰是否真的减少工作时长，还是只把消息集中到稍后处理。
