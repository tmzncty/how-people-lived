# 当陌生人可以被当作潜在伴侣搜索：征婚启事、婚介、婚恋网站与“可搜索的亲密关系”

> 研究问题：普通人什么时候开始可以不只依赖亲友、单位、邻里和既有熟人圈，而把陌生人纳入择偶范围？报纸征婚、婚介所、电话、互联网档案、婚恋网站、即时通信、微信和“轻相亲”分别改变了什么？
>
> 核心判断：互联网没有发明陌生人婚恋，也没有简单替代亲友介绍。真正的长期变化是：**潜在伴侣从地方熟人网络中的人，逐步变成可以被公开描述、检索、筛选、验证、联系，再重新带回线下关系网络的人。** 这扩大了选择半径，也把择偶变成新的搜索、筛选、验证与注意力劳动。

本笔记不是“中国婚恋网站史”，也不讨论“哪种婚恋方式更好”。它关心普通人的生活路径：工作时间、迁移、城市陌生性、父母介入、证件与资格字段、通信费用、平台设计和风险意识怎样共同决定“我实际上能认识谁”。

---

## 0. 为什么这是生活史问题

标准人生脚本常把“恋爱/结婚”写成自然发生的里程碑：

`读书 → 工作 → 遇到合适的人 → 结婚 → 成家`

但“遇到合适的人”本身需要基础设施。

至少要问：

1. 一个人平常能遇到多少适龄陌生人；
2. 工作、学校、单位、宿舍和城市空间给不给稳定社交机会；
3. 亲友是否愿意且有能力介绍；
4. 跨城迁移以后，旧熟人网络是否仍能工作；
5. 陌生人怎样证明年龄、婚姻状态、学历、收入和身份；
6. 一次联系的时间与金钱成本是多少；
7. 从“看见一个人”到“现实见面”中间有多少状态；
8. 如果失败，退出成本、面子成本和安全风险多大。

所以“单身”有时不仅是一种偏好或结果，也可能是一种**社交基础设施状态**。

## 1. 本轮新增的机制

### 1.1 mediated stranger reach：媒介化的陌生人可达性

报纸、婚介、网站把原本不在个人熟人网络中的陌生人变成可联系对象。

这不是“社交圈无限扩大”，而是把候选池的边界从：

`亲友/邻里/单位/学校`

逐步扩到：

`刊物读者 → 婚介数据库 → 网站用户 → 跨城平台用户 → 兴趣社群/活动参与者`。

### 1.2 life-script serialization：人生脚本字段化

当择偶进入数据库，人的生活状态必须被压成字段：

- 年龄；
- 身高；
- 学历；
- 所在地；
- 月收入；
- 婚姻状态；
- 有无住房/车辆（不同平台和时期字段不同）；
- 性格/测试标签；
- 对另一半的条件。

这是一种很强的历史变化：**“适不适合结婚”的社会判断，部分变成数据库可以排序和过滤的字段。**

它也把学历、收入、所在地、婚姻状态等原本属于教育、就业、住房和民政系统的状态，重新接进亲密关系市场。

### 1.3 searchability is not compatibility：可搜索不等于可相处

`搜索命中 ≠ 看资料满意 ≠ 消息被读 ≠ 回复 ≠ 加入私人联系方式 ≠ 见面 ≠ 继续交往 ≠ 结婚`

互联网最明显地扩大的是前半段，不保证后半段。

### 1.4 stranger-trust stack：陌生人信任栈

熟人介绍的信任可以借用共同关系人。陌生人平台必须另建信任：

`自报资料 → 身份/学历/收入证明 → 平台审核 → 评价/举报/黑名单 → 私聊观察 → 线下见面 → 共同熟人或现实行为再验证`

数字化降低了“发现人”的成本，却可能提高“证明这个人到底是谁”的劳动。

### 1.5 screening labor：筛选劳动

候选人增加并不只意味着选择更多，也意味着：

- 浏览资料；
- 设过滤条件；
- 判断真假；
- 回复消息；
- 淘汰不合适的人；
- 安排见面；
- 在多个渠道维护同一批关系。

因此：

> **更大的选择池可以同时产生更多机会和更多注意力负担。**

### 1.6 relationship-channel portfolio：婚恋渠道组合

现实不是：

`亲友介绍 → 被婚恋网站取代`。

更常见的是同一个人同时使用：

`家人介绍 + 单位/校友活动 + 相亲角 + 婚恋网站 + 微信/QQ + 平台线下活动 + 兴趣社群`。

一个渠道可以发现候选人，另一个渠道承担实际沟通，第三个渠道完成现实核验。

## 2. Web 以前：陌生人择偶已经存在，但通信链很长

### 2.1 1981 年公开征婚：候选人先变成文字对象

多份后来采访和历史回顾把 1981-01-08《市场报》刊登丁乃钧征婚启事作为改革开放后公开报刊征婚的重要早期节点，并有对当年编辑的后续采访。

来源：
- 新浪转载成都商报，2010-02-08：https://news.sina.com.cn/c/2010-02-08/040617061784s.shtml
- 后来的报史整理和当事人/编辑采访可作为交叉线索。

证据等级：**C/B（后来的回顾与采访）**。本轮没有取得并独立核验 1981 年《市场报》该版原始扫描，因此不把精确版式、全文和“绝对第一”提升为 A 级事实。

这里最重要的不是“第一”，而是通信拓扑：

`在报纸刊登自我描述 → 陌生读者看到 → 写信 → 邮递 → 收信 → 选择性回信 → 长期通信 → 才可能见面`

这已经是陌生人搜索，只是搜索由编辑、版面和邮政完成。

### 2.2 报纸征婚说明：互联网不是陌生人婚恋的起点

报纸征婚至少已经解决两件事：

- 让陌生人的存在跨出本地熟人圈；
- 让一个人的婚恋资格可以被压缩成公开文本。

互联网后来改变的主要是：

- 候选池规模；
- 搜索速度；
- 字段结构化；
- 回复延迟；
- 资料更新；
- 图片与即时通信；
- 排名和推荐；
- 身份验证与诈骗治理。

## 3. 2005–2012：扩张型未来——“我可以主动去找”

### 3.1 2008 同时代第一人称：择偶开始像数据库查询

《中国青年报》2008-03-03 的同期报道记录：一名用户“小周”在世纪佳缘输入“年龄、学历、月薪”等条件，页面几秒内返回数十个候选人；他把“自主搜索、随时登录、选择更多”视为吸引力。

来源：
- 中国青年报稿，大众网保存：https://www.dzwww.com/xinwen/guoneixinwen/200803/t20080303_3228860.htm

证据等级：**B — 同时代媒体观察 + 同时代用户表述**。

这提供了一个很强的生活史转折：

> **择偶第一次可以明显地从“等待别人介绍”变成“自己在数据库里检索”。**

### 3.2 工作时间进入择偶基础设施

同一报道中的徐先生平日工作、周末也经常加班，认为传统婚介需要较多时间和精力，而网络让他能主动选择上网时间和见面对象。

这说明网络婚恋的价值不仅是“候选人更多”，还有：

**partner-search time flexibility——择偶搜索时间弹性。**

工作压缩了现实社交时间，网络把一部分搜索劳动搬进：

- 午休；
- 下班后；
- 网吧/家用电脑；
- 能登录的零碎时间。

但这不能推出“互联网解决了忙碌导致的单身”。现实见面仍然需要共同空闲时间。

### 3.3 搜索字段把标准人生脚本变成数据库 schema

该报道观察到的搜索条件包括年龄、性别、身高、信用等级、测试类型等十余项；用户材料又明确出现学历与月薪。

这意味着“一个合适的结婚对象”开始被技术系统拆成多个查询字段。

后见之明风险：不能把平台字段直接当成所有人的真实择偶优先级。字段由平台产品设计决定，用户也可能填假资料、不使用某些过滤器，或者现实见面后完全改变判断。

### 3.4 2011 Jiayuan F-1：平台把搜索、验证、可见性和收费做成一整套状态

世纪佳缘 2011-04-20 向美国 SEC 提交的 F-1 是本轮最重要的平台一手文档之一。

来源：
- SEC F-1：https://www.sec.gov/Archives/edgar/data/1511683/000104746911003874/a2203517zf-1.htm

证据等级：**A — 同时代公司正式申报文件；只能证明公司当时的产品/经营声明和定义，不能自动证明个体体验或成功率。**

文件说明：

- 注册后可以浏览资料和搜索数据库；
- 首条消息发送免费，但需要一方购买虚拟邮票后消息才可被阅读；
- 2008 年 10 月起开始对消息服务收费；
- 增值服务包括更好的搜索排名、消息优先级、在线聊天和更显眼的展示；
- 用户可以付费提交个人资料证明；
- 平台鼓励年龄、收入、学历等资料的证明；
- 还有用户反馈、举报/黑名单与线下活动/VIP 服务。

这让亲密关系第一次很清楚地具有：

**visibility market——可见性市场。**

潜在伴侣并不是只按“匹配程度”被看见，搜索排名和展示本身也可以被购买。

### 3.5 账号数不是人数，状态更新不是婚姻事实

F-1 报告截至 2011-03-31 有 4020 万 registered user accounts，但它也明确说明 registered account 可能出现一个用户拥有多个账号；active account 又有独立登录定义。

因此：

`registered accounts ≠ unique people ≠ active seekers ≠ offline daters ≠ couples ≠ marriages`

同一文件还以“把关系状态改为 currently dating someone / in a relationship”作为平台指标。这只能证明**平台账户状态变化**，不能直接当作已核实恋爱或婚姻结果。

### 3.6 平台天生会把关系送出平台

F-1 说，根据公司历史数据，两名用户在站内平均交流约 3.5 天；公司认为有进一步兴趣的用户会交换私人联系方式，转到站外直接沟通。

这给旧网考古留下关键提醒：

> **婚恋网站最重要的成功路径，往往主动离开它自己。**

Web 档案越完整，越可能只保存“关系发生以前”的那一半。

## 4. 2015–2019：拥堵型未来——选择池扩大以后，筛选与真实性变成成本

### 4.1 2019：普通人使用的是渠道组合，不是单个平台

中国青年报 2019-09-19 的同期调查与访谈中：

- 唐璇最密集时半个月见 6 个相亲对象，来源包括家人亲戚、单位同事、相亲角；
- 张晓同时用家人介绍、校友联谊、婚恋平台和平台线下活动；
- 林鹏工作忙，在空闲时间浏览网站，用所在地和年龄筛选以节约时间。

来源：
- 中国青年报稿，央视网保存：https://news.cctv.com/2019/09/19/ARTIQcf3Z3b8CgW5Ga4UmfT4190919.shtml

证据等级：**B — 同时代媒体 + 同时代个体自述。**

这证明一个重要反例：

**互联网并没有使亲友介绍消失。**

数字平台更像新增一条并行路线。

### 4.2 搜索更容易，真正见面仍然稀疏

同一报道里，唐璇说她真正见面的对象主要仍来自别人介绍；平台认识的人很多只加微信，偶尔聊天。

这恰好说明：

`platform match/contact → WeChat add → occasional chat`

完全可能长期停在中间状态。

因此不能用“平台注册”估算真实伴侣形成。

### 4.3 搜索便利带来 authenticity overhead

2019 同期材料也明确把资料真实性、婚恋诈骗等列为风险。

这不是互联网独有的欺骗，但平台规模放大后，普通人需要额外承担：

- 验证身份；
- 检查职业/学历/收入说法；
- 判断对方是否真的单身；
- 判断其目标是恋爱、婚姻、推销还是诈骗；
- 从线上形象切换到线下行为核验。

所以“认识陌生人更便宜”并不等于“相信陌生人更便宜”。

### 4.4 2019 调查不能当全国比例

该调查共有 1972 名受访单身青年，样本里一二线城市占绝大部分，农村仅 0.3%。

所以“78.8% 注册过婚恋交友平台”等数字只能描述该次问卷样本，不应外推为“中国单身青年总体”。

本仓把个体材料用于恢复机制，把比例保留样本边界。

## 5. 2020–2022：偶发型未来——不能见面时，关系基础设施先保持“候选状态”

### 5.1 疫情没有发明云相亲，但让线下闭环突然断掉

中新网 2020-03-13 的同期报道记录：太原 28 岁的“闹闹”认为传统相亲较真实靠谱但耗时间，线上可以先筛选、更广接触；35 岁高聪原以为疫情让相亲停止，但父母在线上互相了解后，直接把双方拉进同一个微信群视频聊天。

来源：
- 中国新闻网：https://www.chinanews.com/sh/2020/03-13/9123765.shtml

证据等级：**B — 同时代媒体 + 同时代个体自述。**

这提供了两个反例：

1. 线上基础设施并没有消灭父母介入，父母完全可以一起迁到微信/视频；
2. “能在线认识”仍然不等于“能在线完成关系”，现实见面被公共卫生条件独立控制。

### 5.2 relationship continuity without physical closure

疫情阶段可以把链条拆成：

`收到资料 → 文字聊天 → 视频 → 建立初步印象 → 等待现实见面条件恢复`

数字基础设施更像维持一种**未完成关系的连续性**。

这与网课、远程办公一样：信息和交流可远程，身体共同在场仍是另一层状态。

## 6. 2023–2026：防守型未来——从“快速筛条件”转向“降低压力、保护退出权”

### 6.1 2025 的“轻相亲”不是简单的反婚姻

中国青年报 2025-03-31 对 1339 名受访者的调查与访谈记录了一组兴趣互动型“轻相亲”：线上任务、读书/美食/运动社群、主题旅行、线下游戏、直播活动等。

来源：
- 中国青年报：https://zqb.cyol.com/pc/content/202503/31/content_409091.html

证据等级：**B — 同时代媒体 + 同时代个体自述；问卷样本不是全国人口代表样本。**

27 岁姚瑶说自己有恋爱想法但更“随缘”，如果周末活动能放松、交朋友会更愿意参加；她更看重在旅行和共同活动中观察一个人的可靠性，而不是只坐下来短时间交换条件。

这不能写成“年轻人不想结婚了”。更准确的变化是：

**interaction-pressure reduction——交往压力降低。**

一部分人希望把“立即判断是否能结婚”的面试式互动，改造成先作为普通人相处，再决定是否升级关系。

### 6.2 defensive optionality：亲密关系里的防守型可选性

2025 材料中，隐私保护、主办方资质、参与者身份真实性被明确列为关切。

这与 2008 的扩张逻辑形成对照：

- 2008：更多人、更快搜索、随时登录；
- 2025：别一开始暴露太多、降低目的性、先观察行为、保留退出空间。

因此“防守型未来”在婚恋上并不必然表现为拒绝亲密关系，而可能表现为：

> **仍然想认识人，但不愿一次性交出全部身份、未来承诺和家庭谈判。**

## 7. 海外对照：字段化匹配早于 Internet

### 7.1 1965 Operation Match

1965-04-19 的 Harvard Crimson 同期报道记录，Operation Match 为 7800 多名新英格兰大学生处理配对；组织者把 **75 项问卷**输入 IBM 1401，包括安全/声望/权力/金钱偏好、外貌、家庭关系等问题。

来源：
- Harvard Crimson, 1965-04-19：https://www.thecrimson.com/article/1965/4/19/operation-match-draws-32-cliffies-pairings/
- Harvard Crimson, 1965-04-26：https://www.thecrimson.com/article/1965/4/26/have-you-met-your-miss-match/

证据等级：**A/B — 同时代校园报纸对实际项目的报道。**

它证明：

- 用结构化字段表达亲密关系偏好；
- 用机器计算陌生人匹配；
- 把结果寄给参与者；

这些机制都早于 Web，甚至早于个人计算机普及。

### 7.2 共同机制与中国差异

跨国共同机制：

`熟人网络有限 → 中介扩大陌生人池 → 个人被字段化 → 机器/组织筛选 → 结果仍要回到现实互动`

中国材料特别值得继续追的是：

- 单位、亲友和父母介绍与平台长期并存；
- 学历、收入、住房、城市位置等生活脚本字段的强连接；
- QQ/微信等通用通信平台承担婚恋网站的站外闭环；
- 平台线下活动、相亲角、家庭介绍形成多渠道组合；
- 身份验证和“严肃婚恋”平台定位。

## 8. 证件与制度接口：婚恋平台把别的制度记录重新调用一次

一个人在婚恋平台上常被要求描述或证明：

- 年龄/身份证明；
- 婚姻状态；
- 学历；
- 职业与收入；
- 所在城市；
- 住房等经济状态（依时期和平台而异）。

这些不是平台自己创造的身份，而是平台把学校、单位、民政、银行/收入与住宅生活中的状态重新编码成择偶信号。

因此婚恋平台是很典型的 **cross-institution identity interface——跨制度身份接口**。

一个人的“我是谁”同时由：

`本人自述 + 国家证件 + 学校记录 + 工作/收入 + 平台字段 + 他人评价 + 现实见面`

共同构成。

## 9. 历史可见性：最容易保存的是“寻找”，最难保存的是“成为伴侣”

公开 Web 档案可能保存：

- 平台首页；
- 搜索说明；
- 注册流程；
- 公开帮助页；
- 价格；
- 会员等级；
- 某些公开 profile shell；
- 媒体成功故事。

但很难保存：

- 收件箱；
- 谁真正读了消息；
- 私下交换的 QQ/手机号；
- 微信聊天；
- 见面；
- 第二次见面；
- 关系结束；
- 同居；
- 结婚；
- 平台退出原因。

因此婚恋 Web 天生具有 **pre-outcome archive bias——结果前档案偏差**。

平台越成功地把人带出平台，它自己的档案反而越看不到最终结果。

## 10. 四种未来的对照表

| 时段 | 主要时间感 | 婚恋基础设施表现 | 不能过度推论 |
|---|---|---|---|
| 2005–2012 扩张型 | 候选池在扩大，技术能补足社交圈 | 搜索、条件过滤、随时登录、站内消息、线下活动 | 账号增长不等于婚姻增长 |
| 2015–2019 拥堵型 | 渠道很多，但筛选、真假与见面成为成本 | 多平台/家人/活动组合，测试和大数据匹配 | 使用平台不等于主要对象来自平台 |
| 2020–2022 偶发型 | 现实闭环可被突然中断 | 微信/视频维持相亲与家长媒介 | 线上互动不等于现实见面可执行 |
| 2023–2026 防守型 | 想保留关系可能性，同时降低风险和压力 | 兴趣活动、低压力配对、隐私与组织者可信度 | “轻相亲”不等于拒绝恋爱/婚姻 |

## 11. 重点矩阵更新

### 教育
学历从背景变成可搜索字段和验证对象。

### 就业
工作时长和工作圈狭窄直接影响现实认识人的机会；平台提供异步搜索。

### 住房
住房/城市位置可能进入择偶判断，但本轮不把“有房”写成普遍必要条件。

### 婚姻家庭
父母、亲友、单位介绍没有被平台消灭，而是与平台并行甚至迁入微信群。

### 迁移
跨城流动一方面打散熟人网络，一方面使全国平台的地点筛选更有价值。

### 长期中断
疫情证明数字关系链和现实见面链可以分离。

### 证件与记录
年龄、学历、收入等被重新当作陌生人信任证据。

### 通信方式
报纸+邮政 → 网站消息 → QQ/电话 → 微信/视频，关系不断跨媒介迁移。

### 互联网平台
搜索、排序、付费可见性、验证、消息可读性和线下活动共同构成平台。

### 信息获取
“知道有谁”从共同熟人知识变成数据库查询。

### 社交关系
弱关系/陌生关系的发现成本下降，筛选与信任成本上升。

### 未来预期
2008 更强调“更多选择”；2019 更强调筛选；2025 更强调压力、隐私和退出权。

### 线上/线下身份
profile 是一种可编辑的自我描述，不等于现实身份。

### 平台消失与记忆保存
历史平台最易留下 profile/search shell，最难留下关系结果；且私人婚恋档案具有高隐私风险。

## 12. 反例与后见之明风险

1. **不要把 1981 写成中国人第一次和陌生人征婚。** 它只是公开报刊征婚的重要早期节点；更早形式需要单独查证。
2. **不要把婚恋网站写成亲友介绍的替代者。** 2019 同期材料明确显示多渠道并存。
3. **不要把注册账号当成独立个人。** 2011 F-1 已明确 account 口径可能包含一个人多个账号。
4. **不要把平台关系状态当作已核实恋爱/婚姻。** 它首先是用户修改的 account state。
5. **不要用平台/行业问卷外推全国人口。** 2008、2019、2025 的样本都有明确选择偏差。
6. **不要把字段当作真实人生。** 月薪、学历、婚姻状态需要验证，且即使真实也不能预测现实相处。
7. **不要把“轻相亲”解释成普遍的婚姻价值崩塌。** 同期资料里不少人仍明确想建立关系，只是降低互动压力。
8. **不要把站内通信当完整关系史。** 有意义的关系很快可能迁到电话、QQ、微信和现实空间。

## 13. 已知 / 可合理推断 / 尚不知道

### 已知

- 1980s 公开报刊征婚已经能把陌生人的婚恋需求跨地域传播，但本轮早期节点主要依赖后来回顾。
- 2008 同期用户已经把年龄、学历、月薪等输入婚恋网站进行搜索，并强调随时登录、更多选择。
- 2011 Jiayuan 正式文件证明 profile、搜索、付费可读消息、资料证明、搜索排名、线下活动和站外联系方式交换构成同一业务链。
- 2019 同期个体同时使用亲友介绍、线下活动和平台；平台接触并不必然带来见面。
- 2020 父母介绍可以迁移到微信和视频。
- 2025 一部分受访者偏好兴趣化、低压力、强调隐私和身份真实性的交往形式。

### 可合理推断

- 互联网降低了候选人发现成本，但没有同步消灭筛选、真实性核验和共同空闲时间的成本。
- 标准人生脚本的一部分被平台字段化，使教育、职业、收入、城市等制度状态进入亲密关系搜索。
- 婚恋平台扩大关系入口的同时，也创造了新的 attention/verification labor。

### 尚不知道

- 1981《市场报》原始版面、完整传播范围和实际邮政通信链的精确档案；
- 1990s 中国婚介数据库、电话/寻呼与早期联网婚介之间的具体技术桥梁；
- 2003–2006 早期世纪佳缘可验证 archive capture 的 DOM、charset、搜索字段与后台请求；
- 普通用户从站内消息转 QQ/电话以后，平均多久才真正见面；
- 平台筛选究竟改变了长期伴侣的城市距离、教育同质性、年龄差等，需要人口/婚姻调查而不是平台宣传；
- 2023–2026 “轻相亲”是否只是媒体可见的局部形式，还是稳定扩大的普通实践。

## 14. 下一步最值钱的证据

优先寻找一条**partner-search ledger**，而不是再找平台用户规模：

`谁介绍/在哪里看到 → 第一次联系 → 交换多少资料 → 是否验证 → 聊多久 → 是否转 QQ/微信/电话 → 是否见面 → 见几次 → 为什么继续/退出 → 家庭何时介入`

最好能在 2007–2010、2018–2019、2023–2026 各找一条同期材料。

旧网侧优先寻找 2003–2008 的可验证婚恋站点 capture：记录 URL、capture datetime、charset、公开/登录状态、搜索字段、排序、消息提示、付费墙和外链，而不重新公开普通人的敏感征婚资料。

## 15. 本轮对“人怎么活着”的修正

过去的生命历程模型很容易把婚姻写成一个节点：

`未婚 → 结婚`

这一轮把中间过程重新展开成：

`社交半径 → 候选人发现 → 自我字段化 → 对方筛选 → 真实性核验 → 通信 → 迁移到私人渠道 → 现实见面 → 关系磨合 → 家庭/制度介入 → 才可能形成长期关系`

因此更准确的结论是：

> **普通人能不能走进一段关系，不只取决于“想不想结婚”，还取决于这个时代提供了多大的陌生人可达半径、多少可支配社交时间、怎样的身份信任机制，以及从屏幕回到现实的路到底能不能走通。**
