# 从“拿着一张机票去机场”到“数据库里有我这段旅程”：电子客票、自助值机与航空出行可执行性（中国，1979—2026）

> 研究状态：research note / 可直接复用的 life-horizon slice
>
> 核心问题：普通人乘飞机时，什么时候开始不必把“能否出发”系在一张容易丢失的纸票上；而当订座、客票、值机、登机牌和退改都数字化以后，新的脆弱点又转移到了哪里？
>
> 交叉旧网笔记：`tmzncty/old-web-archaeology/AIR_TRAVEL_SEARCH_RESERVATION_ETICKET_CHECKIN_BOARDING_AND_REFUND_STATE_GAPS_1999_2015.md`

## 为什么这是“普通人怎么活”的问题，而不只是航空史

航空出行很容易被写成飞机、机场和航空公司的技术史。但从生活史看，更关键的是：**一个普通人能不能在身体还没到机场以前，就知道某天有没有航班、有没有座、多少钱、自己的预订是否成立，以及如果计划改变能不能撤回。**

这会影响出差、异地求职、探亲、留学、毕业旅行、短期迁移和远距离休闲。航空当然从来不是所有人口同等可及的日常交通，因此本笔记不把“有人网上买机票”外推成“全国普通家庭都经常坐飞机”。2010 年民航全行业旅客运输量达到约 2.68 亿人次，说明航空已经是大规模公共交通，但“人次”不是独立人数，更不是家庭普及率。

本笔记使用几个中性概念：

- `backstage digitization / 后台数字化`：消费者尚未直接联网时，订座代理和航空公司已经依赖联网库存系统；
- `seat addressability / 座位可寻址性`：某一日期、航班、舱位的库存能否被远程查询并操作；
- `ticket dematerialization / 客票去物质化`：运输权利从一张必须携带的票证转为数据库中的电子客票记录；
- `document-stack compression / 凭证栈压缩`：纸票、纸登机牌等部分载体被身份证件、数据库记录、二维码或电子证照替代；
- `pre-airport displacement / 机场前移`：原本必须在机场柜台完成的选座、值机、改期等事务被前移到家、办公室、网吧或手机；
- `boarding executability / 登机可执行性`：从“已经买票”到“本人最终真正登机”的整条状态链能否走通；
- `failure-mode migration / 故障模式迁移`：纸票遗失的风险下降以后，故障转向账户、证件、网络、手机电量、二维码、后台状态和复杂票规；
- `exit-rule legibility / 退出规则可读性`：普通人在买票时能否理解未来退票、改签、价差和时限的真实后果。

核心状态链至少应拆成：

```text
航班计划存在
→ 某舱位在查询时显示可售
→ 预订记录/PNR 建立
→ 支付成功
→ 电子客票实际出票
→ 旅客取得可核验的订单/票号
→ 值机开放且本人符合自助条件
→ 值机成功、座位确定
→ 登机牌/二维码或等效凭证可用
→ 旅行证件核验成功
→ （如有）托运行李被接收
→ 安检/边检等流程通过
→ 航班实际执行
→ 登机口仍接受该旅客
→ 本人真正登机
```

所以：

**reservation != ticketed != checked-in != cleared != boarded**。

同样：

**paperless != infrastructureless**。

## 1. 前 Web 比较：消费者没有“上网”，旅行早已依赖网络化库存

### 1.1 美国 SABRE：后台联网先于消费者直接操作几十年

IBM 对 SABRE 的历史记录显示，航空公司早期依靠各订座点的手工卡片记录航班和旅客信息。SABRE 把分散订座终端通过超过一万英里的电话线路连接到中央处理系统；到 1960 年代中期，系统已可每小时处理约 7,500 个预订，把一次订座处理时间从平均约 90 分钟缩短到数秒。1976 年 American Airlines 又把 SABRE 终端扩展到旅行代理；1985 年 easySabre 才开始让消费者通过 CompuServe 等联机服务直接操作，1996 年又出现 Travelocity。

来源：
- IBM History, “Sabre”: <https://www.ibm.com/history/sabre>

证据等级：**B/A-near-primary（厂商历史，含参与者回忆和系统沿革）**。

这里最重要的不是“美国比谁先进多少年”，而是一条跨国都可能出现的顺序：

```text
后台库存先数字化
→ 柜台/旅行代理先使用网络终端
→ 普通人仍通过电话或面对面提出需求
→ 消费者后来才直接看到查询界面
```

因此：

**consumer did not use Internet != ordinary travel was not already Internet/pre-Internet-network mediated**。

### 1.2 中国：不要把 1994 以前写成“民航没有网络”

中国航信当前官方集团简介把自身起点追溯到 1979 年、前身为中国民航计算机信息中心，并说明其长期形成了订座、离港、分销、结算四大信息系统。

来源：
- 中国航信集团简介：<https://www.infosky.com.cn/travelsky/xxgk/qyjbxx/A069011002Gone1.html>

证据等级：**C/B（机构后来的官方沿革；足以证明前 Web 后台信息化传统，不应用来精确推导每个年代普通旅客的使用率）**。

对本项目最重要的边界是：

- 1979 起步/行业计算机化，不等于普通家庭已经联网；
- 代理人终端能查库存，不等于乘客自己能在家查；
- 民航后台专网存在，也不等于中国已经全功能接入全球 Internet。

这正是“基础设施已经数字化”与“大众互联网已经可及”必须分开的例子。

## 2. 1999—2005：Web 把行业后台的一部分状态暴露给普通消费者

2001 年国泰航空的一份同期企业新闻稿回顾：TravelSky.com 于 **1999 年 12 月**上线，能够对当时中国 25 家商业航空公司及澳门航空提供实时班期、座位可用性、票价信息并处理预订；建立该网站的中国民航计算机信息中心（CACI）同时运营库存控制、计算机订座和机场旅客处理系统，其网络当时连接 300 多个中国内地城市、80 个海外城市和超过 28,000 个终端。

来源：
- Cathay Pacific, 2001-04-19, “Cathay Pacific outlines Travelsky Cooperation”: <https://news.cathaypacific.com/cathay-pacific-outlines-travelsky-cooperation>

证据等级：**A/B（同期公司公告；可证明当时公开宣称的系统能力和网络规模，不能证明普通网民实际使用率）**。

这一步的生活意义不是“1999 年起人人都网上买机票”，而是：**过去只有柜台/代理终端看得到的一部分班期、库存和价格，开始成为消费者自己可查询的对象。**

它建立了一个以后所有 OTA 都依赖的状态差：

**displayed availability != inventory still executable at purchase time**。

航空库存会随其他代理、柜台和后台交易同时变化，因此历史网页里的“有票”从来只是一个时点状态。

### 2.1 电子客票最初不是 Web 的同义词

中国民航报 2005 年文章回顾，南航 2000 年已推出电子客票，国航、东航在 2003 年跟进。电子客票的核心是运输权利和旅客服务记录保存在订座/客票系统中；它可以通过网站销售，但也可以由电话、代理柜台和行业终端完成出票。

来源：
- 中国民航报经新浪科技，2005-07-13，“电子客票勾画明日世界”：<https://tech.sina.com.cn/it/2005-07-13/0911661465.shtml>

证据等级：**B（同期行业媒体/航空公司业务人员署名）**。

所以要永久保留：

**e-ticket != online purchase**。

一个从未自己上网的旅客，也可以通过电话或旅行代理取得电子客票；反过来，一个网页订单也不必然意味着后台已经成功出票。

## 3. 2006—2012：扩张型未来——票不再必须跟着身体走，机场的一部分也搬到了出门以前

### 3.1 2006：最关键的变化是“丢掉纸票，不再等于丢掉运输权利”

2006 年 6 月起，国内民航进一步简化电子客票乘机手续：旅客在值机柜台出示有效身份证明即可领取带 ET 标识的登机牌，电子客票记录保存在电脑系统中。同期民航局信息显示，2005 年电子客票约占全行业客票销售 20%，2006 年推广速度很快；到 2006 年 11 月，行业口径称电子客票销售比例已超过 90%。

来源：
- 中国青年报经新浪，2006-06-02：<https://finance.sina.com.cn/chanjing/b/20060602/07032618565.shtml>
- 新华社经新浪，2006-05-31：<https://finance.sina.com.cn/chanjing/b/20060531/22002613730.shtml>
- 中国民航新闻信息网经新浪，2006-11-28：<https://finance.sina.cn/sa/2006-11-28/detail-ikftpnny2052174.d.html>

证据等级：**A-near-primary/B（民航部门口径、同期报道）**。

电子客票减少的是一个非常具体的故障：

```text
纸票丢失
→ 很可能需要补办/证明/重新处理
```

逐渐变成：

```text
运输权利在后台记录
→ 本人用有效身份证明重新召回这段旅程
```

这可以叫 `mobility-record portability / 流动记录可携带性`：真正决定“你有这张票”的不再只是手里那张纸。

但行程单没有因此失去全部意义。报销、票价证明和部分改退事务仍可能需要它。因此：

**transport entitlement != reimbursement document**。

### 3.2 2006—2008：网站验真又增加了一层“我自己能核对代理到底卖了什么”

电子客票普及后，同期报道也迅速出现假行程单、代理加价等问题。2006 年底，中航信已通过“信天游”网站提供电子客票验真，旅客可以用客票/证件等信息核对出票状态。

来源：
- 北京日报经新浪，2006-12-22：<https://news.sina.com.cn/s/2006-12-22/071210835344s.shtml>

这产生了 `transaction inspectability / 事务可自检性`：消费者不再只能相信代理递过来的一张纸，还可以尝试从权威后台确认“这笔运输记录究竟存在不存在”。

但仍然必须区分：

**itinerary receipt looks valid != e-ticket coupon is valid**。

### 3.3 2008—2010：值机前移到家、办公室、网吧和手机

2008 年国航转入首都机场 T3 首日，官方稿称网上值机旅客已超过一千人、自助设备旅客超过三千人；持电子客票且满足条件的旅客可以提前在线选座、打印登机牌。2009 年山航和东航同期材料更直白：有联网电脑和普通打印机，就可在家、办公室甚至网吧办理值机并打印 A4 登机牌；但有托运行李的人仍需到柜台办理行李交运。

来源：
- 国航，2008-03-27：<https://www.prnasia.com/story/9346-1.shtml>
- 山航/民航资源网经新浪，2009-02-26：<https://travel.sina.com.cn/air/2009-02-26/092565153.shtml>
- 东航/民航资源网经新浪，2009-03-03：<https://travel.sina.com.cn/air/p/2009-03-03/135766484.shtml>

证据等级：**A-near-primary/B（航司公告、同期行业媒体）**。

这就是 `pre-airport displacement`：机场没有消失，只是机场内部的一小段事务被移出机场。

尤其要保留这些边界：

- `web check-in success != baggage accepted`；
- `seat selected != passenger boarded`；
- `A4 boarding pass printed != identity/security check passed`；
- 特殊旅客、国际旅行、行李等常常保留人工/柜台环节。

2008 年民航局发布的“便捷旅行”合作说明本身就把值机、行李、旅行证件核验、改期、登机、行李查询拆成六个不同自助环节，反证“无纸化”不是一个按钮就把全流程同时数字化。

来源：
- 中国民航局，2008-11-14：<https://www.caac.gov.cn/XWZX/HYDT/200811/t20081114_18060.html>

### 3.4 2008：网上提前锁定低价机票，让“远方”成为可预算的计划

2008 年《温州日报》同期报道的一名旅行者“多多”，一家三口前往东南亚时通过网络提前购买亚洲航空低价票；他把“越提前越好、避开周末高价时段”当作省钱经验，并遗憾自己没有抢到更低价的免费票。报道同时描述开心网/旅游论坛里围绕“怎样用最少的钱走最远”的交流。

来源：
- 温州日报经中国侨网，2008-12-08：<https://www.chinaqw.com/lxs/yszx/200812/08/141121.shtml>

证据等级：**B（同期媒体，含个人经验；不能代表全国青年）**。

这是一条很适合“扩张型未来”的材料。网络化库存和动态低价并不只是把既定出差便宜一点，而开始支持一种新的计划技术：

**我可以先在网上把一个很远的地点压缩成一张可承担的价格，再围绕那张票组织假期和路线。**

但廉价票往往也意味着更严格的改退限制，所以低进入价格与低退出成本不能混同。

### 3.5 2010：手机开始取代“出门前必须坐在电脑前”

2010 年东航虹桥 T2 试行手机值机：旅客通过 WAP 页面办理后收到短信和链接，手机显示二维条码登机牌；无托运行李旅客可直接前往指定安检通道，有行李者仍需柜台办理。国航同年推出 3G 手机平台，集机票预订、支付、预选座位、值机和航班动态查询于一体。

来源：
- 中国广播网经新浪，2010-08-16：<https://news.sina.com.cn/c/2010-08-16/110820907195.shtml>
- 国航，2010-08-17：<https://www.prnasia.com/story/35032-1.shtml>

于是又多了一层：

`home/office computer check-in`
→ `mobile check-in while already moving`。

这不是“手机取代机场”，而是**更多事务可以在移动本身已经开始以后继续处理**。

## 4. 2015—2019：拥堵型未来——凭证越来越少，但状态依赖越来越多

### 4.1 2018：无纸化不是“什么都不用带”，而是凭证角色重新分配

2018 年武汉天河机场无纸化流程允许普通、无托运行李、国内始发旅客用手机二维码电子登机牌和身份证完成安检、登机；但婴儿、儿童、病残旅客、国际航班、有托运行李、无人陪伴和其他特殊旅客仍需传统流程。

来源：
- 新华社，2018-06-26：<https://www.xinhuanet.com/politics/2018-06/26/c_1123040149.htm>

所以：

**paperless path != universal passenger path**。

标准化自助路径通常最先服务“单一成人 + 标准证件 + 无特殊服务 + 简单行李”的旅客。偏离标准脚本的人，人工接口反而更重要。

### 4.2 2018：国际无纸化暴露出“旅行证件不能被客票本身吞掉”

2018 年浦东机场国际及港澳台出港无纸化试点中，受访的咨询从业者张廉长期在亚洲、欧洲城市间出差，没有托运行李，习惯提前通过航司官网/App 在线值机；当时新的流程允许他用电子二维码登机牌贯穿多个出港环节。但国际旅客仍必须按目的地持护照、通行证等相应旅行证件。

来源：
- 文汇报，2018-10-29：<https://wenhui.whb.cn/third/yidian/201810/29/220739.html>

证据等级：**B（同期现场，含第一人称使用路径）**。

这说明 `document-stack compression` 不是无限压缩。航空运输权、国家边境身份、入境许可和安检身份是不同权威系统：

**e-ticket != passport != visa/entry permission != boarding authorization**。

### 4.3 2019：“不怕没带证件，就怕手机没电”——故障从纸转移到设备

2019 年长沙机场升级全流程自助服务时，一名从长沙飞成都的王先生现场感叹，新的体验让他“不怕没带证件，就怕手机没电”。这句话不应被当成统计结论，却非常准确地抓到 `failure-mode migration`：当纸质登机牌退居备用，手机电量、屏幕、二维码、App 状态和后台连通性变成新的微型基础设施。

来源：
- 三湘都市报/华声在线，2019-06-04：<https://hunan.voc.com.cn/news/201906/25245287.html>

证据等级：**B/D（同期个人感受，机制例证）**。

因此“更少携带物”与“更少依赖系统”恰好可以同时向相反方向变化。

## 5. 2020—2022：偶发型未来——已经出票的未来，也可以突然失去可执行性

2020 年 1 月民航局因疫情多次扩大免费退票范围。1 月 27 日的官方要求明确：满足时间条件、在起飞前提出退票的旅客，航空公司及销售代理应免费办理；同时航空公司已开始削减部分航班。

来源：
- 中国民航局，2020-01-27：<https://www.caac.gov.cn/XWZX/MHYW/202001/t20200127_200588.html>

这再次证明：

**ticketed != flight operates != passenger can travel**。

与铁路专题相似，航空系统在这一阶段不只承担 `commitment infrastructure / 承诺基础设施`，还承担 `reversibility infrastructure / 撤销基础设施`。但航空票价体系、承运人、代理和联程关系往往更复杂，因此“免费退”本身也必须绑定具体出票日期、旅行日期、航线和票号条件。

偶发型未来最关键的时间变化不是“大家突然不计划”，而是：**一个已经在数据库里成立、甚至已经付钱的未来，也必须不断重新验证它到出发日是否仍然成立。**

## 6. 2023—2026：防守型未来——成熟系统开始竞争“你能不能看懂退出条件”

### 6.1 进入已经很容易，风险越来越集中到票规

当搜索、支付、电子票和手机值机都成熟以后，普通用户新的高成本错误不再主要是“忘带一张纸票”，而可能是：买了哪一种票价产品、通过哪个渠道出票、改签到底是改原票还是退旧出新、什么时候起退票费突然跳档。

2026 年 3 月，国航、东航、南航都推出一定条件下“买贵免费退”安排，核心都围绕出票后约 24 小时和重新购得更低价客票等条件，但三家规则并不完全一致；央视记者同时找到成功退票和因超过时限而失败的用户经验。

来源：
- 央视网，2026-03-23：<https://news.cctv.cn/2026/03/23/ARTIy4YNRXgyCHD3QbxTSeXt260322.shtml>

这可以理解成一种 `price-regret buffer / 价格后悔缓冲`：消费者无需为了担心“明天突然更便宜”而无限推迟购买，但缓冲只存在于清楚定义的时间窗和渠道条件内。

### 6.2 2026：退出规则本身成为需要“强提醒”的基础设施

2026 年 8 月，一张 15,217 元国际机票退票时仅返回 432 元引发争议；报道随后记录平台新增“可退金额低于票款 20%”的强提醒，并进一步解释 OTA、航空公司之间的票款和退款结算链。

来源：
- 每日经济新闻，2026-08-10：<https://www.nbd.com.cn/articles/2026-08-10/4537609.html>

证据等级：**B（同期调查报道，含用户个案、平台和航司解释）**。

这里出现的是 `exit-rule legibility`。现代航空交易的防守性不只是“允许退”，还包括：

- 在购买前看得见不可退/高扣费条件；
- 在退票动作前再次显示实际可退金额；
- 区分平台服务费、航空公司退票费、票价差；
- 区分自愿退改和非自愿退改；
- 不把“页面上有一段条款”自动等同于普通用户已经理解经济后果。

所以：

**rule displayed != rule noticed != rule understood != consequence accepted**。

防守型未来在这里并不是“不再坐飞机”，而是普通人越来越希望未来计划同时拥有一条清楚的退出路径。

## 7. 四种未来放在一起看

| 阶段 | 航空数字基础设施的主要生活承诺 | 新的主要摩擦 |
|---|---|---|
| 2005–2012 扩张型 | 远程查库存、电子客票不怕纸票丢、在家/手机值机、提前锁定低价远方 | 网络/支付/打印机/手机条件；特殊旅客和行李仍回柜台；低价票退出成本高 |
| 2015–2019 拥堵型 | 手机 + 身份证/电子证照压缩纸质凭证，机场等待进一步缩短 | 手机电量、二维码、后台状态；标准旅客路径与特殊旅客路径分化 |
| 2020–2022 偶发型 | 数字系统可批量撤销、改签既有计划 | 已出票航班仍可取消；政策与旅行资格频繁变化 |
| 2023–2026 防守型 | 购买更便捷之后，开始增加后悔期、退改提醒和规则透明度 | 动态票价、渠道和票规复杂；“能退”与“退得起”仍不同 |

这条线不是从“落后”单向走向“方便”。它更像：

```text
柜台/代理替我操作数字后台
→ 我自己在 Web 上看见库存
→ 运输权利从纸票迁入数据库
→ 值机从机场前移到电脑
→ 再前移到手机
→ 纸质凭证越来越少
→ 计划越来越容易建立
→ 也越来越需要明确的撤销和回退路径
```

## 8. 对“普通人有多少种活法”的新增解释

这一轮真正新增的不是“坐飞机”这个生活类别，而是 **`pre-committed long-distance optionality / 可预承诺的远距离选择权`**。

如果买一张机票必须先去售票处、靠代理打电话确认、拿到一张不能丢的纸票，再很早到机场排队，那么“去一个很远的地方”本身需要较高的组织成本。后台联网、Web 查询、电子客票和自助值机把这些成本一层层拆走以后，一个普通人可以在今晚的出租屋里先决定：下个月去另一个城市面试、看朋友、旅行或参加活动。

但真正成熟的流动自由还必须包含另一半：**计划变了以后，能不能不把已经投入的钱和时间一起全部损失。**

因此航空基础设施对生命历程的支持至少有两面：

1. `commitment optionality`：让远方变成今天就能锁定的未来；
2. `exit optionality`：让那个未来不合适时仍可撤销、改写或转向。

这也是为什么 2026 年的关键问题会从“能不能网上买票”变成“这个退改规则到底意味着什么”。

## 9. 与仓库现有专题的边界

### 与铁路 `bookability-travelability-and-reversible-mobility-planning` 的区别

铁路专题已经建立“可预订性 != 可成行性”并研究 12306、实名购票和疫情期间预售视野压缩。本笔记不重复它，而补三个航空特有/更突出的机制：

1. **后台网络早于消费者 Web 数十年**：CRS/GDS 是典型的人介导数字基础设施；
2. **ticket / check-in / boarding 是不同权威状态**：电子客票去纸化后，状态链反而更清楚；
3. **机场前移**：值机、选座、登机牌和部分证件核验逐步从航站楼移到家和手机。

### 与临时住宿专题的区别

住宿专题研究“到陌生城市后今晚有没有床”和住房承诺延迟；这里研究“在身体还没移动以前，远距离运输权利如何被建立、验证和撤销”。两者共同构成短期迁移的可执行栈。

## 11. 反例、后见风险和未确定事项

### 反例

- 航空数字化很快，不代表航空旅行成为所有阶层同频日常；运输“人次”不可当作独立人口普及率。
- 电子客票可以通过电话/代理出售，所以“电子票比例高”不能推出“网上购票比例高”。
- 无纸化通常先覆盖标准成年旅客；儿童、病残、无人陪伴、国际证件和托运行李持续保留人工路径。
- 手机路径更方便，也把故障依赖转向电量、屏幕、App、账号、网络和后台同步。

### 后见风险

- 不把 1960s CRS 叫作今天意义的“互联网订票”。
- 不把 1999 TravelSky 可预订能力写成“大众家庭普遍网上订机票”。
- 不把 2008 A4 登机牌写成今天的手机电子登机牌。
- 不把“电子客票”与“电子登机牌”混同。
- 不把 2020 的免费退票政策泛化为所有时期航空退改都容易。

### 未确定事项

1. 仍需找中国民航 1980s–1990s 计算机订座系统更接近同时代的一手技术文档，精确区分 ICS/CRS/DCS 的上线范围和代理终端覆盖；
2. 仍需找到 1999–2005 `travelsky.com`、早期航司 B2C 订票页的 verified historical capture，核验 charset、表单、session、支付和跨 host 依赖；
3. 需要更系统的 2007–2010 普通用户博客/论坛样本，区分商务旅客、学生、探亲和低价旅行；
4. 需要更好的分母数据来区分“民航人次增长”“互联网购票比例”“自助值机实际使用率”；
5. 2023–2026 可继续比较不同渠道的退改提示方式，避免只从高额纠纷反推平均体验。

## 12. 本轮结论

**航空数字化最深的生活变化，不是“机票从纸变成二维码”，而是把一段未来的远距离移动拆成许多可以远程查询、建立、核验、修改和撤销的状态。**

早期的普通旅客即使从未碰过计算机，旅行代理身后的联网订座系统已经在替他协调座位；后来 Web 让旅客自己看到库存，电子客票把运输权利从纸张搬进数据库，网上和手机值机再把机场的一部分搬到出门以前。

可每减少一张纸，并没有减少一次制度判断。相反，系统越来越依赖“这个人的预订、支付、电子票、证件、值机、安检、登机和航班状态此刻能不能彼此对上”。到了防守型未来，普通人真正关心的也不只是怎样更快把未来锁住，而是：**我今天订下的远方，明天如果不再合适，能不能看得懂代价并安全地把它放掉。**
