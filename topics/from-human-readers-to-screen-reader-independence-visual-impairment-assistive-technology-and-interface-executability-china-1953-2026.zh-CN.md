# 从“请别人念给我听”到自己完成数字事务：视障、辅助技术与接口可执行性（中国，1953–2026）

> 研究问题：一个视障者能否学习、工作、购物、办银行业务和使用公共服务，不能只看这些服务是否存在；还要看信息能否被感知、控件能否被操作、认证能否独立完成，以及整个任务链能否在不把密码、隐私和决定权交给另一个人的情况下走到底。

## 0. 新增变量：interface executability

本仓此前已经研究电话、寻呼、电子邮件、宽带、网上银行、教育平台、购物、求职和数字身份，但经常隐含一个默认用户：网络可达、账号有效以后，用户就能看见并完成页面。

对视障者，这个默认不成立：

```text
网络/终端可用
≠ 辅助技术可用
≠ 页面内容能进入辅助技术
≠ 结构可理解
≠ 控件可操作
≠ 登录/验证码可完成
≠ 支付或提交结果可确认
≠ 整个任务可独立完成
```

因此需要 **interface executability / 接口可执行性**：某个具体的人能否从发现入口一直走到最终现实状态。

还需要 **proxy dependence / 代理依赖**。如果必须请家人、同学、邻居或工作人员替自己念材料、输入密码、拖验证码或确认交易，服务虽然存在，个人仍把一部分隐私、时间自主和决定权交给了另一个人。代理帮助很重要，但 `information exists ≠ independent task completion`。

## 1. Internet 以前：先把内容变成另一种格式

中国盲文出版社 2019 年的机构史把前史追到 1953 年盲文编译/出版组织，1954 年开始出版《盲人月刊》。这是后来的制度史回顾，不冒充 1950s 同期证据。

Source (C/B, later institutional history):  
https://pac.org.cn/hangyedongtai/3606.html

它足以恢复一个前互联网基线：普通印刷文字与视障者真正可读的内容之间，需要盲文、广播、录音、有声材料、专门学校/图书馆或人工朗读等转换链。可称为 **format-mediated access / 格式中介可及性**。

这意味着：

```text
一本书已出版
+ 书店可以买到
≠ 本人有可读版本
```

Internet 并不是从“没有信息”开始，而是逐渐缩短这种额外格式转换的等待和代理劳动。

## 2. 海外前史：1978 Deafnet 说明残障数字通信也早于大众 Internet

SRI 今天保存的机构史记录，1978 年美国 HEW 资助 Deafnet，先在 Gallaudet University 建立演示系统；邮件软件修改自 ARPANET email，1979 年已扩到 Boston 和 SRI 的邮件主机，后来尝试部署到九个都市地区。SRI 自己也承认后续传播不如演示阶段成功。

Source (C/B+, institutional retrospective):  
https://www.sri.com/hoi/deafnet/

所以正确结论不是“1978 年美国聋人已普遍联网”，而是：残障数字通信实验可以在大众家庭 Internet 以前，借用早期网络技术建立。采用仍必须分成：实验存在、机构可用、少量个人可持续使用、普通人可及、大规模日常整合。

这也提醒中国前史不能把 1994 年以前写成“完全没有网络”，更不能把科研/邮件/专线写成普通家庭已生活在 Internet 中。

## 3. 1997–2000：人工朗读瓶颈与读屏转换点

2007 年《羊城晚报》保存了王永德的同时代第一人称生命史。失明后，他曾主要靠广播自学；1997 年借钱买下一台一万多元电脑。编程书没有盲文版，他请亲友和邻居朗读并录成磁带，再反复听。

Source (B+, contemporaneous interview/report):  
https://news.sina.com.cn/c/2007-06-08/170211985722s.shtml

这展示了 **human-reader bottleneck / 人工朗读瓶颈**：电脑已经买到、技术书已经出版，仍不等于本人可以独立读书。

报道记载他在 1999 年末做出读屏软件第一版、2000 年注册，后来持续升级。报道把它称为“国内首个”，本专题不把这个优先权升级成已经独立核验的全国软件史结论。

真正重要的是转换点移动了：

```text
纸书 → 另一个人朗读 → 磁带 → 本人听
```

逐渐变成：

```text
数字文本 → 读屏软件 → 本人实时听取和操作
```

格式转换从“另一个人的日程”部分进入了用户自己的终端。

## 4. 2005–2012 扩张型未来：从读到信息到打开人生路线

2007 年同一报道记录，读屏用户已经用网络聊天、搜索和接受远程教育；其中一名通过远程教育取得相关文凭的受访者说，网络扩大了原本狭窄的信息与交际范围，并带来更多就业可能。

这不能外推为视障者普遍获得高教机会，但证明一条真实的新路线已经出现：

```text
不进入普通校园
+ 读屏访问数字课程/网络信息
+ 维持远程学习关系
→ 某些教育路线开始可执行
```

因此辅助技术不是“附加功能”，而是把一般数字基础设施转换成教育、社交与职业基础设施的桥。

## 5. 2008：责任从“用户要有工具”扩展到“网站也要能配合”

2008 年北京奥运会、残奥会前，中国互联网协会等发起信息无障碍网站行动。4 月 1 日同期通知明确提出推出相关标准，并推动奥组委、中国残联以及部分政府/门户网站进行无障碍改造。

Source (A/B+, contemporaneous association notice):  
https://www.isc.org.cn/article/1521.html

同年 10 月《光明日报》现场报道中国盲人数字图书馆开通，盲人读者使用读屏、键盘与语音提示进入网站并使用电子书、音频、视频和在线讲座。

Source (B+, contemporaneous newspaper report):  
https://www.gmw.cn/01gmrb/2008-10/15/content_848568.htm

这里出现两个重要区分。

第一，**accessibility is a stack**：读屏能力、浏览器/user agent、页面结构、语义、键盘操作和认证必须能接起来。

第二，**special-purpose accessible space ≠ mainstream Web accessibility**。专门盲人数字图书馆可以很好用，不证明同年的招聘、网银、购物、报名页面同样可用。

国际上，W3C 已在 1999-05-05 发布 WCAG 1.0，明确讨论文本替代、导航、不同 user agents 与 assistive technologies。

Source (A, original standard):  
https://www.w3.org/TR/WCAG10/

全国标准信息公共服务平台记录，YD/T 1761-2012 于 2012-12-28 发布、2013-03-01 实施，并替代 YD/T 1761-2008。

Source (A/B+, standards registry):  
https://hbba.sacinfo.org.cn/stdDetail/ccac3842174d800dd0165ba4d77c638b

标准史提醒我们：`页面能渲染 ≠ 信息可感知 ≠ 控件可操作 ≠ 流程可理解 ≠ 与辅助技术可靠兼容`。

## 6. 2009–2010：接口兼容开始扩大可想象职业集合

2010 年《中国青年报》报道，一组视障大学生在求职困难后开淘宝网店，希望把网店做成视障者实训基地，并整理“淘宝盲用操作攻略”和电子手册。报道还保存了队长沈晨娴 2009-07-06 的日记片段；团队明确说不希望把按摩当作唯一职业路线，还曾设想电话营销、英语翻译、心理疏导等以文字、语言和电脑为主的工作。

Source (B+, contemporaneous report with contemporaneous diary excerpt):  
https://news.sohu.com/20100221/n270322328.shtml

这新增 **route expansion through interface compatibility / 接口兼容带来的人生路线扩张**。

但必须保留反例：会读屏不等于淘宝整个交易、客服、支付、退款链无障碍；一个成功网店也不代表整体就业障碍消失。`accessible task route ≠ structural equality`。

## 7. 2015–2019 拥堵型未来：移动互联网扩大独立生活，也会重新制造依赖

2019 年《中国青年报》采访视障钢琴调音师陈燕。她大量依赖网络购物，报道保存了她对实体购物中依赖与尴尬的回忆，并解释手机读屏如何把界面转成语音。

Source (B+, contemporaneous first-person report):  
https://it.people.com.cn/GB/n1/2019/1203/c1009-31486466.html

从 1997 到 2019，可以看到任务层级变化：

```text
1997：请别人把技术书念成磁带
2019：读屏进入通用电商，自己搜索和购买
```

但这不是线性进步。Web → App、复杂脚本、弹窗、图形验证码、触屏组件和平台改版，都可能让昨天可走的路线今天断掉。本专题把它叫作 **accessibility regression / 无障碍回退**。

因此：`newer interface ≠ more accessible interface`。

## 8. 2020–2022 偶发型未来：无障碍成为服务连续性基础设施

工信部 2020-12-25 发布《互联网应用适老化及无障碍改造专项行动方案》，决定从 2021 年 1 月起开展一年专项行动，明确面向老年人、残疾人使用网站和 App 等智能技术时的困难。

Source (A, MIIT policy):  
https://www.miit.gov.cn/jgsj/xgj/wjfb/art/2020/art_18a8b1029f724afc8b31264fcd0f4106.html

这不能证明改造完成后所有应用都真正可用。它说明当购物、金融、医疗、教育和公共服务越来越数字化时，不能使用数字入口已经不只是体验问题，而会成为 **continuity risk / 连续性风险**。

尤其当线下 fallback 临时关闭、限流或变慢：

```text
数字入口不可用
+ 线下后备路线受限
→ 整个任务可能不可执行
```

因此这一阶段需要 **accessibility as continuity infrastructure / 无障碍作为连续性基础设施**。

## 9. 2023–2026 防守型未来：关键不是“有无障碍按钮”，而是关键步骤不能重新把人挡出去

《无障碍环境建设法》2023-06-28 通过、2023-09-01 施行。第三十二条要求财政资金建立的网站、服务平台和移动互联网应用程序逐步符合相关无障碍标准，并鼓励新闻、社交、购物、医疗、金融、教育、交通等领域逐步符合标准；第三十九条又要求涉及医疗、社保、金融、生活缴费的公共服务保留现场指导、人工办理等传统方式。

Source (A, law):  
https://gxca.miit.gov.cn/zwgk/zcwj/flfg/art/2024/art_340a68cb6a8e45ae81c121630dd37346.html

成熟路线因此不是“所有人只用一个 App”，而是：

> **accessible primary route + usable fallback route / 可访问主路线 + 可用后备路线。**

2024 年《人民日报》保存了具体卡点：商磊使用读屏无法完成滑块拼图验证；王洋说自己能用读屏办理多数手机银行业务，但部分银行 App 与读屏不兼容，有的乱序密码键盘还禁用读屏，使他不能独立输入密码；何川谈到开屏广告隐藏的关闭按钮也会造成操作障碍。

Source (B+, contemporaneous first-person reporting):  
https://cpc.people.com.cn/n1/2024/0429/c64387-40226186.html

这新增 **security–accessibility collision / 安全—无障碍冲突**：验证码、防窥视键盘、人脸识别等安全设计如果没有可访问替代路线，可能同时挡住合法用户。

所以安全评价还要问：`合法用户能否独立完成认证？`

## 10. 2025：无障碍升级也有迁移成本

2025 年 5 月中国盲人数字图书馆新版上线。《光明日报》报道新版按 WCAG 2.1 设计，强化全键盘操作、快捷指令和非视觉信息通道，目标是从检索到内容获取的全流程无障碍。

Source (B+, contemporaneous report):  
https://society.people.com.cn/n1/2025/0530/c1008-40490809.html

6 月另一篇同期报道中，低视力读者杜春雷在工作人员帮助下体验新版网站，同时明确说自己对新版还不熟悉。

Source (B+, contemporaneous first-person report):  
https://paper.people.com.cn/rmrbhwb/pad/content/202506/16/content_30079370.html

因此 `standards conformance ≠ zero learning cost`。新导航、快捷键、认证和搜索结构都可能产生 **accessibility migration cost / 无障碍迁移成本**。

## 11. 四种未来的比较

| 时段 | 典型机制 | 同时代语法 |
|---|---|---|
| 2005–2012 扩张型 | 读屏、远程教育、数字图书馆、网店、网站标准 | “以前这条路基本不存在，现在也许可以试。” |
| 2015–2019 拥堵型 | 手机把更多事务带到手上，但每个平台都有自己的兼容障碍 | “互联网让我更独立，但我要维护很多接口。” |
| 2020–2022 偶发型 | 线下替代路线可能突然受限，线上可访问性变成连续性条件 | “如果线上是唯一现实路线，我还能不能完成？” |
| 2023–2026 防守型 | 安全验证、改版和 App 黑箱可能重新关闭路线；法律同时强调数字无障碍与传统 fallback | “主路线要能走，坏了还必须有备用路线。” |

## 12. 重点矩阵改变

- **教育**：课程存在与学习界面可执行必须分开；盲文/广播/录音 → 读屏 → 远程教育。
- **就业**：可操作的通用电脑扩大职业集合，但招聘、办公软件和认证仍能关闭路线。
- **独立居住**：购物、银行、缴费等能否独立完成，会改变离开家庭后需要多少代理劳动。
- **迁移**：购票、导航、通信与远程服务能减少陌生城市中的代理需求，但每个接口都可能有新障碍。
- **非正规劳动**：网店/远程文字工作是新路线，却依赖支付、客服、物流和平台兼容。
- **长期中断**：失明/低视力不应自动编码成人生永久中断；辅助技术可能重新打开教育和职业路线。
- **证件与记录**：验证码、密码键盘、身份核验决定本人能否调用数字记录。
- **通信**：人工朗读/广播/盲文 → 读屏 + Web/App，信息转换从专门格式逐渐接入通用基础设施。
- **互联网平台**：可读页面与可完成任务必须分开；更新可能造成 accessibility regression。
- **社交关系**：网络扩大同伴发现，也能减少必须经亲友中介的信息交流。
- **未来预期**：“这职业我做不了”有时变成“如果接口可用，我可以试”。
- **线上/线下身份**：独立认证是数字自主的一部分。
- **历史保存**：archive 常保存视觉 DOM，却不保存当时的 accessibility tree、焦点顺序、读屏输出和真实任务完成。

## 13. 反例与后见之明风险

1. **不要把 1990s 写成“视障者没有信息”**：盲文、广播、录音、学校、图书馆和人工朗读早已构成基础设施。
2. **不要把王永德这类高技能个案当总体样本**：他的借债买电脑、自学编程和创业经历高度选择性。
3. **不要从“能读页面”跳到“能办成事”**：购物、银行、报名和求职都有认证、提交、支付与反馈链。
4. **不要把专门盲人网站外推为主流 Web 可访问**。
5. **不要把标准/法律发布时间当现实立即改变日**。
6. **不要把视障经验外推所有残障类型**：听障、肢体障碍、认知障碍等需要不同接口模型。
7. **不要写成单向技术进步史**：真实路线可能是 `打开 → 改版后关闭 → workaround → 再打开`。

## 14. 尚未确定

仍缺：

- 1980s–1990s 盲人对盲文书、录音教材、公共图书馆和家人朗读成本的更多同时代第一人称；
- 1997–2002 普通视障用户购买电脑、声卡、读屏软件的价格与收入占比；
- 2000s 不同中文读屏软件的实际使用分布；
- 2005–2010 主流招聘、网银、教育、电商网站在具体 browser/screen-reader 组合上的可用性；
- 可复核的“某网站改版前后同一任务从可完成变成不可完成”版本链；
- 2018–2019 普通用户关于 App 更新造成障碍/修复的连续论坛或博客材料；
- 2020–2022 当线上变成主要现实路线时，医疗、采购、金融、教育的细粒度第一人称 ledger；
- 2023–2026 各公共服务的人工 fallback 是否现实可及，而不只是制度文本存在。

## 16. 它改变了我们对“人怎么活着”的哪一点理解

不能只说 Internet 给普通人更多信息、工作、教育和服务。只有当接口能被这个具体的人感知、理解、操作，并能完成认证、提交和反馈，那些“更多”才真正属于她。

> **一个时代给普通人的生活自由，不只取决于社会上有多少学校、工作、银行、商店、网站和 App；还取决于她能不能在不把自己的密码、隐私、时间和决定权交给另一个人的情况下，亲手把那件事做成。**
