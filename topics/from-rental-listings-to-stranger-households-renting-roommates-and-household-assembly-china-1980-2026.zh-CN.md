# 从“贴条找房”到“陌生人拼成一个家”：租房、合租与临时家庭组装（中国，1980–2026）

Status: research note / cross-repo topic  
Companion: `tmzncty/old-web-archaeology/RENTAL_LISTING_ROOMMATE_AND_OCCUPANCY_STATE_GAPS_1998_2015.md`  
Last research pass: 2026-09-05

## 0. 研究问题

住房史很容易只写成：

```text
单位分房 → 租房 → 买房
```

但对一个刚离开学校、刚到陌生城市、刚换工作、与伴侣分开、暂时失业或不准备买房的人来说，更具体的问题是：

> **今晚、下个月、下一份工作期间，我到底和谁住、住在哪里，又怎样找到这个地方？**

这不是单纯的房地产史，而是普通人如何 **assemble a household——组装一个可运行的住户单元** 的历史。

一个 dwelling 可以早已存在，却仍然不能自动成为某个人的住所。至少还要经过：

```text
住房存在
→ 某种渠道把它变成可发现的房源
→ 房源在需要的日期仍然空着
→ 租金与押金可负担
→ 地点能支撑工作/上学
→ 房东/中介/二房东身份可接受
→ 看房或可信的替代验证
→ 合同/付款成立
→ 若要合租，找到可共同生活的人
→ 实际入住
→ 水电、卫生、隐私、作息和安全可长期运行
→ 退租时能退出合同并取回应得押金
```

因此核心区分是：

> **housing exists ≠ listing exists ≠ vacancy exists ≠ affordable alone ≠ affordable by sharing ≠ compatible roommate exists ≠ contract works ≠ stable home exists**

本专题尤其追踪一个很少被住房统计单独记录的变化：

## **stranger-household assembly——陌生人家庭组装**

当房租高于单人可承受水平时，互联网分类信息、租房平台、论坛、微信群和社交平台不只是“让找房更方便”。它们还可能让原本没有亲属、同学、同事关系的人，在城市里临时组成一个共同承担租金、厨房、卫生间、作息和风险的住户单元。

这并不意味着这种生活必然自由、先进或愉快。它可能同时是：

- 一种降低迁入城市门槛的办法；
- 一种维持职业试错的缓冲；
- 一种把住房成本转化为隐私和协调成本的交换；
- 一种新的陌生人信任劳动；
- 一种因预算不足而被迫接受的生活；
- 一种有人主动偏好的陪伴式居住；
- 一段通往独居、同居、婚姻、买房、返回父母家或下一座城市的临时状态。

研究目的不是浪漫化“合租青春”，也不是把群租苦难做成猎奇，而是恢复这些真实中间状态。

## 1. 方法边界：先区分“房屋制度”“找房接口”和“真实住法”

本专题遵循仓库 `METHODOLOGY.md`，同时与以下既有专题分工：

- `when-did-housing-become-an-adulthood-project.md`：谁负责解决住房，以及住房何时成为独立成年项目；
- `moving-city-as-career-strategy...`：为了工作迁城何时变得可规划、可逆；
- `searchable-city...`：陌生城市何时可以在到达前查询路线、地点和通勤；
- `from-knowing-where-to-look...`：检索劳动怎样变化。

这里专门问：

1. 房源怎样进入一个具体人的可见范围；
2. 单人付不起时，怎样寻找合住者；
3. 一个陌生人住户单元怎样建立、维持和解散；
4. 线上描述、线下住房与实际共同生活之间有哪些状态差；
5. 租房是否让城市/职业选择更可逆，或者反过来制造新的债务和退出成本。

### 1.1 个人材料证据标签

使用个人材料时至少区分：

- **contemporary self-report**：当时本人描述；
- **near-contemporary interview**：记者在当时采访本人；
- **retrospective self-report**：多年后回忆；
- **platform-observable fact**：当时平台界面、规则、listing 结构可观察；
- **platform/company claim**：平台自己声称的规模/效果；
- **cross-confirmed outcome**：入住、搬走、押金纠纷等有第二来源或制度记录确认。

一个人的“我在网上找到了室友”只能证明这种路径存在，不能推出所有青年都这么住。

### 1.2 租房的多个时钟

至少保存：

```text
listing_created_at
listing_updated_at
available_from
viewing_at
contract_signed_at
move_in_at
roommate_joined_at
rent_changed_at
move_out_at
deposit_returned_at
archive_capture_at
```

历史页面保存了某个发布日期，不代表房子在 capture 时仍空着；页面今天仍可访问，也不代表那套住房在历史上长期可租。

## 2. Internet 以前的基线：住房先是家庭/单位问题，私人租住后来才越来越像个人项目

仓库已有住房专题已经记录：城市中国相当长时期内，住房常与单位、家庭和公共住房制度捆绑；一个青年未必首先面对“去市场上搜一套房”的问题，而可能面对“单位何时分房”“能否继续住父母家”“能否住宿舍”。

1998 年国务院《关于进一步深化城镇住房制度改革加快住房建设的通知》（国发〔1998〕23号）明确提出停止住房实物分配、逐步实行货币化，并培育和规范住房交易市场。

Source:
- 北京市政府保存的国发〔1998〕23号全文：
  https://www.beijing.gov.cn/zhengce/zhengcefagui/qtwj/201309/t20130924_776668.html

Evidence:
- **A-**：政府保存的正式制度文本；当前网页发布时间不是 1998 原始网页时间，但文号和正文可核。

这一制度节点并不意味着 1998 年以后所有人都立刻进入统一商品租赁市场。公房、单位宿舍、家庭同住、亲友借住、市场租赁、城中村、集体宿舍和后来各种长租公寓长期并存。

更重要的是，私人租房即使存在，Internet 以前也需要别的信息系统：

- 熟人/亲属/同学；
- 单位和学校内部消息；
- 报刊分类广告；
- 中介门店；
- 校园/街边公告栏；
- 门窗、电线杆、社区附近的纸条；
- 直接问房东和住户。

本轮尚未取得一份足够清晰的 1980s–early-1990s 中国城市“求租/招租”原版报纸样本，因此**不把这些渠道的全国普及时间写死**。但 2000s Internet 已经存在以后，实体公告栏仍然大量使用，至少证明它们不是被 Web 一夜替代。

2007 年一篇高校住宿报道配发的同时代照片说明，北京一所大学校园公告栏上仍贴满房屋出租和求租信息。

Source:
- CCTV / 半岛晨报，2007-07-16：
  https://news.cctv.com/education/20070716/106193.shtml

Evidence:
- **B+**：同期媒体与图片说明，可证明校园实体公告栏仍承担租房信息接口；不能据此推回 1990 年代全国情况。

这里最重要的不是“纸条比网络落后”，而是：

> **信息接口决定候选房源池。**

一张校园公告栏天然偏向校园附近房东、学生和经过那里的人；熟人介绍偏向现有关系网；中介门店偏向其掌握的库存。Web 后来扩大的是“离我当前位置更远、与我没有共同熟人的房子和室友，也可能先进入候选集”。

## 3. 2004–2008：扩张型未来——工作先来了，住房开始成为要自己拼出来的过渡系统

### 3.1 一个 2004 毕业生：合租不是“独立住房”，却能让城市职业路径先运行起来

2008 年《扬子晚报》报道一名 2004 年毕业、来自农村、在南京工作的“小张”。他月工资约 3000 元，最早与同学合租，每月房租 600 元；三年多搬过两次，类似条件下租金涨到 750 元。报道还记录，他周围毕业生有人两人合租一套，也有人六人共同住大套房。

Source:
- 扬子晚报转载于学信网，2008-03-05：
  https://www.chsi.com.cn/lh/jy/200803/20080305/3953780.html

Evidence:
- **B+**：2008 年同期采访，回顾窗口只有约三四年；可恢复个人现金流和合租结构，不能外推所有南京毕业生。

这里增加一个重要概念：

## **housing-cost pooling——住房成本合池**

当一整套住房的租金超出个人预算时，人不是只能选择“搬离城市 / 立刻买房”。合租可以把一个不可执行的 dwelling 转成若干可执行的 room/bed 份额。

这改变了职业迁移的可执行性：

```text
找到工作
→ 先与别人共同承担住房成本
→ 在城市积累收入/经验
→ 之后再决定独居、换城、买房或组成家庭
```

但降低的是钱的门槛，不是全部成本。合租会产生新的：

- 卫生间排队；
- 清洁与水电分摊；
- 睡眠/作息冲突；
- 客人和伴侣边界；
- 私人物品安全；
- 房东是否继续加床/隔间；
- 某个室友突然退出后谁补房租。

### 3.2 2008：Internet 让“室友”从熟人关系逐渐变成可公开检索的需求

2008 年海口一篇同期报道检查当地网站“租屋信息”栏目，记录有人直接在网上公开招募合租者。报道把“异性合租”做成新闻噱头，因此不应把其调查数字外推成常态；但它足以证明一个结构变化：**至少部分租客已经不再只从同学、同事和亲友里找室友，而会把“我需要一个共同住的人”公开发布给陌生人。**

Source:
- 南海网转载于新浪，2008-08-18：
  https://news.sina.com.cn/o/2008-08-18/150914325967s.shtml

Evidence:
- **B**：同期媒体观察；样本小且报道带猎奇选择偏差，只用于证明网上陌生人室友招募存在。

这可以称为：

## **roommate addressability——室友可寻址化**

过去的逻辑可能是：

```text
我认识谁也需要租房？
```

网络分类信息以后可以变成：

```text
谁满足：预算 / 地点 / 入住时间 / 性别偏好 / 工作状态 / 作息 / 卫生 / 宠物 / 租期？
```

也就是把“共同生活的人”部分字段化。

这和婚恋网站相似却不能混同：婚恋字段服务于亲密关系筛选；室友字段首先服务于**共同维持一个住所**。

### 3.3 2008 同时代未来想象：租房常被想成通往买房/婚姻的过渡，而不是永久终点

2008-09-23《中国青年报》对 4807 名两年内将毕业大学生的网络调查显示，57.6% 打算毕业 5 年内买房，愿意“长期租房住”的只有 3.6%。报道中的郭峰磊毕业前原以为“很快经济独立→买房→结婚→组建家庭”，工作后住 10 平方米出租房，才发现住房会打乱原先时间表。

Source:
- 中国青年报 / 中青在线，2008-09-23：
  https://zqb.cyol.com/content/2008-09/23/content_2367571.htm

Evidence:
- **B+**：同期问卷与同期个人采访；网络调查并非全国随机样本，适合研究当时一部分大学生的未来想象，不能当全国青年人口比例。

这对“2005–2012 扩张型未来”的修正很重要：

> 扩张不只是“大家觉得一切都会越来越好”，而是**很多青年相信今天的租住状态只是暂时接口，几年内会升级到稳定住房、婚姻和家庭。**

互联网租房于是既支持职业流动，又常被嵌进一个仍然相当标准的人生脚本：

```text
租房 / 合租（过渡）
→ 收入增长
→ 买房
→ 婚姻 / 家庭
```

不能把后来长期租房的常态感倒投回 2008。

### 3.4 同一时期的反例：合租结构本身可以在签约后被房东改写

2008 年扬子晚报报道大学生吴冉短租合租房：第一次看房时以为三间房只会住少数人，交定金后再去，房东把大房间和客厅继续分割/占用，最后六人共用卫生间。

Source:
- 扬子晚报转载于新浪，2008-08-11：
  https://news.sina.com.cn/c/2008-08-11/035214293436s.shtml

Evidence:
- **B+**：同期第一人称投诉和记者报道。

它提示：

## **occupancy topology can change after viewing——看房后的居住拓扑仍可变化**

“看过真实房屋”仍不等于“入住时是同一个住户结构”。

## 4. 2010：房源数据库已经很大，但 listing 不是现实房屋的镜子

SouFun Holdings 2010 年向美国 SEC 提交的 F-1 提供了一组很强的同时代平台级证据。

截至 2010-06-30，公司称其数据库中约有 **800 万条二手和租赁住宅 listings**，房产内容/搜索/营销/listing 覆盖中国 106 个城市；用户可以按城市、区域、地铁附近、价格、房型、房间数和面积等条件筛选。

Source:
- SouFun Holdings Ltd., Form F-1, filed 2010-09-02, SEC：
  https://www.sec.gov/Archives/edgar/data/1294404/000095012310083390/h04135fv1.htm

Evidence:
- **A**：同期正式监管申报，可证明公司当时对产品、数据库、商业模式和内部风控的陈述；listing 数不是独立住房数，也不是实时空置住房数。

同一文件又明确说明：

- 个人业主可以免费发布；
- 免费 listing 不享有 prime positioning；
- 专业经纪可能冒充个人房东以利用免费服务；
- 平台内部会发现虚假出租/出售信息、虚假价格和重复 listing；
- 平台不能验证所有上传信息，只能通过监控团队和软件定期排查。

这一次材料非常关键，因为它证明：

> **“网络房源很多”与“可执行住房很多”从一开始就不是同一个事实。**

于是必须增加：

## **inventory truth gap——库存真实性缺口**

```text
listing visible
≠ unique dwelling
≠ owner identity true
≠ price true
≠ still vacant
≠ photos/current condition true
≠ viewer can actually rent it
```

以及：

## **visibility market——可见性市场**

房东/经纪的房源并不只是“有没有发布”，还可能因为付费订阅、prime positioning 和排名不同而获得不同曝光。

普通人面对的“市场”从而不是所有现实住房的完整集合，而是：

> **现实库存 × 谁愿意发布 × 平台是否收录 × 谁付费获得曝光 × 排名 × 用户查询条件。**

## 5. 海外对照：陌生人合住早于 Web，Web 改变的是匹配半径和速度

### 5.1 1984：纸质 classified 已经能把陌生室友需求公开化

University of North Texas Digital Library 保存的 1984-06-08 *Dallas Voice* 原版报纸，其 classified 页面明确有 `DWELLINGS & ROOMMATES` 分类，刊登多个寻找合租者/房间的广告。

Source:
- UNT Digital Library, *Dallas Voice*, 1984-06-08, p.19：
  https://digital.library.unt.edu/ark:/67531/metapth615777/m1/19/

Evidence:
- **A**：同期数字化报纸原页。

出于隐私与研究必要最小化，本仓不重新抄录其中普通人的历史电话号码和个人身份描述。

这证明：

> **陌生人共同居住不是 Internet 发明的。**

报纸 classified 已经能把“我有一间房 / 我需要室友”广播给本地陌生读者。

### 5.2 1989：住房成本压力下，roommate matching 已经成为明显的成年生活策略

*Washington Post* 1989 年报道华盛顿地区共享住房，称其抽查年份中 roommate ads 数量比十年前大幅增加，并采访多名二十多岁、三十多岁成年人因住房成本选择共同租住；报道同时强调陌生室友筛选、共同签 lease 和退出责任等风险。

Source:
- *Washington Post*, 1989-08-04/05, “Renters Who Dare to Share”：
  https://www.washingtonpost.com/archive/realestate/1989/08/05/renters-who-dare-to-share/f4e67b16-205c-4941-b687-325333dafe47/

Evidence:
- **A-/B+**：同时代新闻与采访。

所以跨国共同机制更像：

```text
住房贵 / 单人收入不足
→ 需要把 dwelling 拆成多人共同承担的成本
→ 需要一个 roommate-discovery system
```

差异在于系统可能是：

```text
熟人 → 报纸 classified → roommate referral service → BBS/email list → Web classifieds → rental platform → social/group feed
```

### 5.3 1995–2002 Craigslist：住房、工作和社交在同一城市信息基础设施里汇合

Craigslist 当前保存的 2000–2002 同期媒体材料显示：它 1995 年从旧金山本地 mailing list/community bulletin board 起步，很早就出现 apartments/rooms/jobs 等信息；2001 年同期报道已把 rooms for rent 与 jobs、items 作为同一社区 bulletin board 的核心类别。

Sources:
- Investor's Business Daily, 2000-05-25, rehosted by Craigslist：
  https://www.craigslist.org/about/press/craigsonlinelistofstuff
- San Francisco Examiner, 2001-02-08, rehosted by Craigslist：
  https://www.craigslist.org/about/press/dotorgssurviving
- Esquire, 2002, rehosted by Craigslist：
  https://www.craigslist.org/about/press/esquire

Evidence:
- **B+**：近同时代新闻，现由平台重托管；可用于比较产品/生活机制，不是原始 Web capture。

2002 文章中的个人案例尤其值得注意：有人通过同一站点找到 apartment、job、roommate 等不同生活接口。

这说明“同城分类信息 Web”的历史意义不是只把报纸搬到网上，而是把**迁城所需的多个对象**——工作、房间、家具、室友、社交——压进一个可持续刷新、可搜索的城市数据库。

但这一机制并非自动全国化。Craigslist 官方 expansion 列表显示其城市站点是逐步增加的，2000 年才开始向多个美国城市扩展。

Source:
- Craigslist, expansion history：
  https://www.craigslist.org/about/expansion

所以必须继续区分：

```text
platform exists
≠ my city has a section
≠ my city section has enough listings
≠ my social group uses it
```

## 6. 2015–2019：拥堵型未来——房源更可搜索，生活却变成一组要同时优化的约束

2019 年《中国青年报》对 1920 名 18–35 岁租房青年的问卷和采访中，应届硕士曹辛看重家具、热水、地理位置、周边市场/公园和装修；即将入职北京互联网公司的朱睿昱则希望住处距公司不超过 30 分钟、租金每月最多 3000 多元，并希望室友作息规律、爱干净。

Source:
- 中国青年报（央视转载），2019-06-28：
  https://news.cctv.com/2019/06/28/ARTInCmd8pYKTb6YTXRnfivZ190628.shtml

Evidence:
- **B+**：同期调查与第一人称；问卷平台样本不能当全国青年随机样本。

这说明找房已经不再只是：

```text
有房 / 没房
```

而更像一个多目标约束求解：

```text
rent
+ deposit
+ commute
+ metro
+ room size
+ furnishing
+ food/shopping access
+ safety
+ roommate schedule
+ cleanliness
+ privacy
+ lease duration
```

于是新增：

## **household-compatibility work——住户兼容劳动**

一个人能在网上筛房，却还必须筛“共同生活的人”。

这一劳动不能只看 profile 字段，因为真正冲突常发生在入住后：

- 早睡/晚睡；
- 南北饮食；
- 洗澡/卫生间占用；
- 空调温度；
- 清洁频率；
- 是否允许伴侣过夜；
- 谁买公共用品；
- 宠物；
- 谁先搬走。

### 6.1 “近一点但挤”与“远一点但独立”成为可以主动比较的生活结构

2019 年《中国青年报》采访的梁辰，刚到北京时曾在双井附近两室一厅租一个床位，一套房支 10 张床；之后又住过三人一间的合租，遇到作息与生活习惯冲突；后来搬到地铁 S1 线最后一站附近，换取更大空间，但每天通勤约 2 小时 40 分钟。

Source:
- 中国青年报，2019-09-10：
  https://zqb.cyol.com/html/2019-09/10/nw.D110000zgqnb_20190910_2-11.htm

Evidence:
- **B+**：同期第一人称。

这把仓库已有的 commute-time 和 housing 问题真正接起来：

> **共享空间可以购买地理接近，地理远离又可以购买私人空间。**

所以普通人的住房选择不是简单的“房租越低越好”，而是在把：

```text
金钱成本 ↔ 通勤时间 ↔ 私密性 ↔ 室友协调成本
```

互相兑换。

### 6.2 拥堵不只在信息量，也在责任链

2019 年前后租赁市场还出现“押一付一”背后的租金贷等复杂合同结构：租客以为自己只是按月付租，现实上却可能同时签下金融贷款；当中介资金链出问题时，房东未收到租金、租客仍背负贷款。

这个现象在本专题里不展开平台金融史，只保留一个重要概念：

## **rental-stack opacity——租赁栈不透明**

```text
我以为：租客 ↔ 房东
现实可能是：
租客 ↔ 公寓运营商 ↔ 贷款机构 ↔ 房东
```

“租房看起来比买房可逆”只有在退出合同、押金、贷款和转租责任都真的可关闭时才成立。

## 7. 2020–2022：偶发型未来——房子能远程看，但住宅是最难被完全远程验证的对象之一

2020 年疫情使“云租房”从便利功能突然变成大量毕业生实际使用的基础设施。

中国青年报社社会调查中心对 1974 名有租房需求的高校应届毕业生问卷显示，96.8% 的受访者体验过图片、VR 或视频等“云租房”；但同一报道中的楚雯静在线上 VR 里觉得一套开间宽敞，实地看后却觉得实际空间明显更小。

Source:
- 中国青年报，2020-09-03：
  https://zqb.cyol.com/html/2020-09/03/nw.D110000zgqnb_20200903_1-10.htm

Evidence:
- **B+**：同期问卷和第一人称；样本限有租房需求的应届毕业生。

新增：

## **remote-visualization / embodied-dwelling gap——远程可视化 / 身体居住缺口**

VR/视频可以压缩：

- 去多个小区的交通时间；
- 早期筛掉明显不合适房源的成本；
- 异地到达前的盲目性。

但它很难完整传递：

- 实际尺度感；
- 隔音；
- 气味；
- 潮湿；
- 楼道与邻居；
- 夜间噪声；
- 手机信号；
- 真实采光时段；
- 水压和排水；
- 室友实际生活状态。

因此：

> **remote viewing can delay travel, but cannot fully virtualize dwelling.**

### 7.1 住房路径在危机中变得更加组合化

2021 年《中国青年报》采访的李亚先后住过 8 人青年旅舍、合租房、公司双人宿舍，并把公司宿舍当成过渡，仍计划再次进入市场租房。

Source:
- 中国青年报，2021-03-09：
  https://zqb.cyol.com/html/2021-03/09/nw.D110000zgqnb_20210309_2-08.htm

Evidence:
- **B+**：同期第一人称。

这条路径很重要，因为它破坏了“租房只有整租/合租两种”的统计想象：

```text
青年旅舍
→ 陌生/熟人合租
→ 单位宿舍
→ 再租房
```

都是一个职业初期的人可以连续经历的现实住法。

本专题称之为：

## **housing-path composability——住房路径可组合性**

住法不是一次选择，而可以是为了让工作、疫情、现金流和城市试错继续运行而不断切换的临时模块。

### 7.2 共享住房的意义也会因卫生风险而改变

2021 年中国青年报调查的 1546 名受访青年中，42.2% 与朋友/同学/伴侣合租，8.2% 与陌生人合租；同一报道同时记录虚假房源和无法找到房东直租等问题。

Source:
- 中国青年报，2021-08-12：
  https://zqb.cyol.com/html/2021-08/12/nw.D110000zgqnb_20210812_3-10.htm

Evidence:
- **B**：同期问卷；不是总体人口抽样。

这里不能把百分比当全国住房结构，但可以确认：朋友、伴侣、陌生人三种共同居住关系在同一市场中并存，且“室友是谁”已经成为住房风险的一部分。

## 8. 2023–2026：防守型未来——不是不租，而是更强调退出权、可信房东和可控生活边界

### 8.1 2024：经历过押金/驱赶后，“好房子”开始首先意味着可预测

2024 年《中国青年报》采访 30 岁的小梦。她在北京租房 8 年，经历恶意扣押金和暴力驱赶后，宁愿用一半工资租下自己认为的“理想之家”，核心条件是通勤 15 分钟内、房东靠谱、独立卫浴。

Source:
- 中国青年报，2024-03-10：
  https://zqb.cyol.com/html/2024-03/10/nw.D110000zgqnb_20240310_1-07.htm

Evidence:
- **B+**：同期个人采访。

这体现一种和 2008 不完全相同的时间感：

2008 的问题更像：

```text
我现在先租，几年以后能不能买？
```

2024 的问题可以更像：

```text
即使我还要继续租，我能不能让下一年不要突然被打断？
```

本专题称之为：

## **tenure defensibility——租住可防守性**

住房安全不再只等同产权，而包括：

- 合同能执行；
- 房东不任意改变规则；
- 押金可追回；
- 室友边界可控；
- 不必频繁搬家；
- 通勤不会把每天耗尽；
- 房间能够独处。

### 8.2 2025：防守型检索进入租房——先搜“坑”，再决定住哪里

2025 年《中国青年报》报道 23 岁康康的成都租房经历：最初花一两个月筛房，因近单位房租高而暂住 4 公里外老房；后来从同事处获知另一处空房，线下确认后改为合租，用更小面积换取更可信的安保、物业和较短通勤。同一报道还记录互联网从业者整理“租房避坑宝典”。

Source:
- 中国青年报，2025-11-18：
  https://zqb.cyol.com/pc/content/202511/18/content_418758.html

Evidence:
- **B+**：同期第一人称。

这与仓库上一轮的 `defensive retrieval` 直接连接：

> 搜索目标从“哪里有房”增加为“哪里可能骗我、扣我押金、隔断、噪声、物业差、二房东不稳”。

租房信息越丰富，普通人需要做的不是越少，而是把一部分劳动从“到处问房”转成：

## **rental provenance work——房源谱系核验劳动**

```text
谁发布的？
是房东 / 经纪 / 二房东 / 公寓运营商？
照片什么时候拍的？
这个价格是不是引流价？
产权/出租权来自哪里？
合同对象是谁？
押金由谁持有？
房源有没有违规隔断？
真实住户有多少？
```

2025 年另一篇同期报道中，应届毕业生晓文与同学合租一年多，退租时仍因 500 元押金与房东反复交涉；报道同时讨论隔断房、二房东、高收低租等风险。

Source:
- 中国青年报，2025-11-18：
  https://zqb.cyol.com/pc/content/202511/18/content_418756.html

Evidence:
- **B+**：同期个人材料与政策背景。

这提醒：

> **move-in is not the end of a rental transaction; successful exit is part of housing executability.**

因此必须加入：

## **exit-closure labor——退租闭环劳动**

租客真正离开一间房，要同时关闭钥匙、物品、水电、合同、贷款（若有）、押金、室友费用和平台账户等状态。

## 9. 四种未来：同样是“租房”，时间结构已经变了

### 9.1 2005–2012：扩张型未来

主要语法：

> **先在城市站住，再往上走。**

租房/合租经常被理解为：

- 第一份工作的启动成本；
- 离开父母家的过渡；
- 未来买房之前的临时状态；
- 为留在大城市争取几年时间。

2008 年“毕业五年内买房”的调查不能代表所有人，却很好地保存了一部分大学生当时的时间预期：租房不是终身身份，而是未来会被收入增长解决的中间层。

### 9.2 2015–2019：拥堵型未来

主要语法：

> **我要同时把房租、通勤、室友、空间、工作地点和未来买房全部塞进同一份预算。**

信息比以前多，但 constraint 也更多：

- 大城市工作机会；
- 离公司距离；
- 地铁；
- 房租；
- 住房品质；
- 室友；
- 是否还存得下首付；
- 合同是否藏着金融负担。

“选择更多”逐渐变成 optimization burden。

### 9.3 2020–2022：偶发型未来

主要语法：

> **原来连看房、搬家、签约、进小区都可能突然不能按正常流程进行。**

VR、视频和朋友代看把一部分住房搜索远程化，但住房本身仍必须由身体实际进入。公司宿舍、短租、旅舍、借住和市场租房之间的切换成为危机管理的一部分。

### 9.4 2023–2026：防守型未来

主要语法：

> **不一定要立刻拥有，但要尽量住得可预测、退得出来。**

重要性上升的可能不是“最大”“最漂亮”，而是：

- 靠谱房东；
- 合同透明；
- 通勤可承受；
- 独立卫浴/隐私；
- 押金可退；
- 不中断工作；
- 出问题时有替代住所；
- 不因一次租房错误背上长期债务。

这不是简单的“青年更悲观”，而是住房决策越来越明显地围绕 **downside containment——下行风险控制**。

## 10. 重点矩阵：租房如何碰到其他人生系统

| 维度 | 租房/合租怎样改变问题 |
|---|---|
| 教育 | 实习、考研、校外学习需要短租/宿舍/借住；学校宿舍退出是住房转折点 |
| 就业 | offer 可以先出现，但到岗需要一间能立即入住的房；通勤又反过来决定工作是否可持续 |
| 住房 | dwelling 被拆成整租、房间、床位、宿舍、旅舍、短租等多个执行单元 |
| 婚姻家庭 | 与父母同住、独居、同伴合租、伴侣同居不是同一条线性序列；住房仍可能影响婚姻预期 |
| 迁移 | 合租/短租降低首次进城沉没成本；可靠房源不足会提高迁移承诺成本 |
| 照护 | 合租者未必能承担照护；父母来访、伴侣、宠物都会改变空间需求 |
| 非正规劳动 | 服务业、骑手、自由职业可能使用床位/群租/城中村等不同市场 |
| 长期中断 | 失业、疫情、租约终止会迫使人快速切换住房模块 |
| 证件与记录 | 实名租赁、合同、居住证/社区登记、平台账户会把住房与制度身份连接 |
| 通信方式 | 纸条→电话→网页→IM/群→App；联系人可达性决定房源能否成交 |
| Internet 平台 | 搜索/排名扩大库存可见性，同时引入假房源、重复 listing 和商业排序 |
| 信息获取 | 从知道哪个中介/公告栏，到按地铁、价格、房型、通勤时间筛选 |
| 社交关系 | 同学/同事/伴侣/陌生人都可成为共居者；“室友”成为独立社会关系 |
| 未来预期 | 2008 常把租房视为买房前过渡；2020s 可更强调长期租住的可预测性与退出权 |
| 线上/线下身份 | listing profile、电话/IM 联系人与真实房东/经纪/室友可能不一致 |
| 平台消失与记忆 | 历史网页容易保存“有房出租”，很难保存最后谁住进去、住多久、为何搬走 |

## 11. 这一轮改变了什么理解

### 11.1 “独立生活”经常是由相互依赖实现的

一个人离开父母、独自在大城市挣钱，不等于她拥有独立住房。

她可能通过：

```text
和同学分租
→ 与陌生人共享厨房
→ 暂住朋友家
→ 住公司宿舍
→ 用家里给的押金
```

才完成看起来“独立”的城市生活。

因此：

## **residential independence can be financed by residential interdependence——居住独立可以靠居住互依实现。**

### 11.2 Internet 改变的不只是找房效率，而是“谁可以成为一个临时家庭成员”

分类信息、论坛和平台扩大了 roommate discovery radius。

这使一个刚到城市、没有本地熟人的人，有可能仍然拼出一个可负担住所；但陌生人进入家庭内部，也把信任、隐私和安全问题带进每天最私密的空间。

### 11.3 “租房更可逆”只能作为待验证命题

租房通常比买房更少资本锁定，但：

- 押金；
- 长租合同；
- 租金贷；
- 提前退租违约；
- 房东/二房东纠纷；
- 室友共同责任；
- 临时搬家成本

都可能降低真实 reversibility。

所以不能把租房自动写成“自由”。

### 11.4 历史档案最容易保存房子的广告，最难保存住进去的人生

旧网页可以精确留下：

```text
三室一厅
某区某路
月租 1800
联系电话
```

却往往不知道：

- 这是否是假价格；
- 当时是否已经租掉；
- 谁看过；
- 谁付定金；
- 最后住了几个人；
- 室友是否相处；
- 房东是否后来加隔断；
- 是否按时退押金；
- 这间房是否让某个人得以留在那座城市。

所以：

> **housing listing survival is not household-history survival.**

这正是 companion old-Web note 要处理的核心状态缺口。

## 12. 反例与后见之明风险

### 12.1 不要写“Internet 发明合租”

报纸 classified、熟人和 roommate matching 早就能组织陌生/半陌生共同居住。

### 12.2 不要写“1998 后住房完全市场化”

单位宿舍、家庭住房、政策房、市场租赁、城中村和多种非标准住法长期共存。

### 12.3 不要写“合租代表开放/自由的新青年文化”

它可能只是工资不足后的成本合池；也可能是主动社交选择。必须逐个案例判断。

### 12.4 不要用平台 listing 数估计现实住房数

重复、失效、虚假、代理多发、不同时间版本都可能使 listing 远多于独立空置住房。

### 12.5 不要把 2008 的购房未来想象改写成今天的怀旧

当年的同期材料本身显示，相当一部分受访大学生真正在做五年/十年购房规划。今天认为这种想象“天真”是后见之明；研究应保留他们当时所相信的可行时间表。

### 12.6 不要把 2020 云看房写成住房完全数字化

住宅是一种强身体性对象；线上筛选可以显著减少前期移动，但不能自动验证全部居住品质与法律状态。

## 13. 仍不确定 / 下一步证据

1. **1985–1998 中国私人租房信息接口**：需要原版报纸 classified、城市房屋中介手册、街道/高校公告栏照片或同期日记，才能精确回答 Internet 前普通人怎样找市场房源。
2. **1998–2005 中文租房 Web 的 verified capture**：需要真正打开 Wayback/WARC，恢复 original URL、capture datetime、charset、表单、城市/价格字段、联系方式结构与分页，而不是只依赖公司史。
3. **roommate ledger**：最好找到同一个人从“熟人合租→陌生人合租→整租/同居/买房/回家”的连续记录。
4. **deposit/exit ledger**：历史材料大量记录入住，较少记录押金什么时候退、退租耗时、共同租约如何解除。
5. **城乡/阶层分布**：大学毕业生材料太多，仍需补工厂工人、服务业、新就业形态劳动者、家庭带孩迁移者、老年租客等。
6. **性别与安全**：需要高质量研究解释陌生室友筛选怎样受性别、性骚扰风险和照护责任影响，避免从猎奇报道推断。
7. **平台 ranking history**：2010 SouFun 已能证明商业排序存在，但仍缺一个 2000s 历史 SERP/列表 capture 来量化同一 query 下谁真正排在前面。

下一轮最有价值的研究对象不是再统计“有多少青年租房”，而是一条真正的：

## **household-assembly ledger**

至少记录：
