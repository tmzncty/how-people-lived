# 从纸质校友通讯录到校友录、实名 SNS 与公开社交寻人：同学关系的可恢复性（中国，1985–2026）

> 研究问题：一个人毕业、迁移、换工作、换手机号、出国、结婚改名或只是很多年没有联系以后，过去的人际关系究竟会不会自动“消失”？普通人通过什么基础设施，才能再次找到一个已经不知道最新地址和联系方式的旧同学、旧朋友？互联网改变的只是通信速度，还是改变了关系本身的“可恢复性”？

本专题与电话 / 手机号码连续性研究相邻，但不重复。电话连续性问的是：**我已经知道你的号码，这个号码还能不能继续找到你？** 本专题问的是另一件事：

> **我连你现在的号码、地址、账号都不知道了，只记得你是谁、我们在哪所学校或哪个班认识，我还能不能重新定位到你？**

它也不同于一般 SNS 史。这里的研究单位不是“人人网是否流行”，而是一个真实关系从“共同生活过”到“失联”、再到可能“重新可寻址”的状态变化。

---

## 一、核心结论

### 1. 关系的存在与关系的可寻址性不是一回事

两个人曾经是同学，不等于毕业十年后仍有可用联系方式。

必须至少分开：

```text
曾有现实关系
!= 仍记得对方
!= 知道对方现在在哪里
!= 有可用联系方式
!= 某个平台能搜到同名 profile
!= profile 对应正确真人
!= 对方仍登录该账号
!= 对方看见联系请求
!= 对方愿意回复
!= 重新取得联系
!= 关系恢复到过去的亲密程度
```

因此，本专题把 **`relationship recoverability / 关系可恢复性`** 定义为：

> 当原有联系渠道已经中断时，一个人是否仍能利用共同学校、班级、旧照片、校友组织、共同朋友、搜索系统或公开社交网络，重新建立一条到达对方的有效联系路径。

这里的“恢复”首先是 **locator / contact path** 的恢复，不代表友谊本身自动恢复。

### 2. 学校和班级是非常特殊的“关系索引”

人与人的日常关系通常没有统一编号，但学校天然留下：

- 学校名；
- 入学 / 毕业年份；
- 院系；
- 班级；
- 同届同学；
- 教师；
- 集体照；
- 校友组织。

这些信息即使几十年后仍然比较稳定。因此学校经历不仅是教育记录，也可以成为一种长期 **`social locator namespace / 社会定位命名空间`**。

一个人可以换城市、换单位、换电话，但“某校某届某班”常常仍然能把她放回一个有限候选集合。

### 3. 互联网真正增加的是“失联以后还能重建路径”的概率，而不是保证关系永存

纸质通讯录、班主任、校友会本来就能维护关系。Web 以后新增的是：

- 可按学校 / 年级 / 班级搜索；
- 同学可以自己更新 profile；
- 分散到全国的人共享一个持续存在的线上班级；
- 旧同学可以通过共同朋友形成多跳搜索；
- 后来即使专门校友录已经消失，公开社交平台还可以把寻人请求扩散给“可能认识目标的人”。

但这不是“Internet 让同学永远不失联”。平台会关闭，账号会废弃，手机号会更换，用户会迁移，密码会忘记，旧内容甚至可能成为本人希望删除的“黑历史”。

因此更准确的概念是 **`relationship re-bootstrap / 关系重新引导`**：旧关系不是始终在线，而是留下足够的索引、共同节点或历史痕迹，使它在未来有机会重新启动。

### 4. 可恢复性与遗忘权之间存在真实张力

同学录和实名 SNS 的优势恰恰是：过去的人更容易找到你。

这同时意味着：

- 很久没联系的人仍可能重新出现；
- 学校、年龄、旧照片、电话号码可能长期暴露；
- 旧账号、旧动态在多年后重新上线时可能让本人不适；
- 一个普通人未必希望所有旧关系都永久保持“可恢复”。

所以成熟的关系基础设施不能只追求：

> **“任何过去的人都永远找得到你。”**

还必须允许：

> **“我愿意的时候可以被重新找到；我不愿意的时候也能拒绝、隐藏、退出或删除。”**

这可以称为 **`relational exit sovereignty / 关系退出主权`**。

## 二、前互联网：关系已经需要“索引基础设施”

### 1985–1996：纸质校友录 / 通讯录并不是纪念品而已

南开大学档案馆 2019 年的一次捐赠记录提供了很清楚的物质前史：档案馆收到《旅美南开校友录（1990）》和《旅美南开校友通讯录（1996）》；另一批捐赠中还包括 1985–2005 年间旅美南开校友会章程、通讯录和校友录。旅美南开校友会本身则成立于 1946 年。

来源：

- 南开大学档案馆，2019，《校友捐赠 | 南开大学档案馆获捐珍贵历史资料》：<https://archives.nankai.edu.cn/info/1060/1677.htm>

Google Books 书目记录还可确认 1990 年出版过 188 页的《武汉大学校友通讯录》。这只证明这种纸质目录存在，不证明覆盖率，也不证明每个地址和电话一直有效。

- *武汉大学校友通讯录*，武汉大学校友通讯录编委会，1990：<https://books.google.com/books/about/%E6%AD%A6%E6%B1%89%E5%A4%A7%E5%AD%A6%E6%A0%A1%E5%8F%8B%E9%80%9A%E8%AE%AF%E5%BD%95.html?id=uQrOxQEACAAJ>

**可确认（B/C + bibliographic）**：大众 Web 之前，校友组织已经用纸质名录维持分散人口的联系方式。

**不能推出**：普通毕业生普遍拥有一本通讯录，或其中信息在多年后仍然准确。

### 纸质目录的结构性问题：它在印刷当天就开始过期

纸质通讯录的一个地址、单位电话或家庭电话一旦印出，后续迁移不会自动同步。

因此它更像：

```text
一次性 snapshot
+ 学校/班级索引
+ 若干当时有效的联系字段
```

而不是持续更新的社会图谱。

当一个人迁移以后，寻找旧同学可能仍要靠：

1. 找到旧班主任 / 教师；
2. 问仍有联系的同学；
3. 翻旧集体照；
4. 找校友会；
5. 打旧电话或寄信；
6. 再从一个联系人问出另一个联系人。

**Internet 后来最显著地压缩的，是这条多跳人工查询链的时间成本。**

## 三、1999–2005：中文旧网把“班级”直接做成了可持续地址

### 1999–2000：ChinaRen 的历史位置

ChinaRen 创办于 1999 年，2000 年被搜狐收购。搜狐 2000 年收购完成时的公司公告明确把 ChinaRen 称为面向年轻人的社区网站；这里的用户规模属于公司口径，只用于理解企业定位，不外推总体 adoption。

来源：

- SOHU investor release, 2000-10-31：<https://investors.sohu.com/static-files/e5aead3b-87a8-4865-ace5-f570b312b8e7>

这类校友录网站的关键创新，不是“人类第一次可以网上聊天”，而是把学校层级直接做进信息架构：

```text
地区 → 学校 → 入学年份 / 届别 → 班级 → 成员
```

只知道过去共同教育经历，也可能重新进入同一个线上空间。

### 2005：实习和迁移以后，“班级”还可以继续存在

2005 年《解放日报》同期报道提供了一组非常好的日常证据。

复旦大学新闻学院 2002 级硕士班的学生分赴全国各地实习后，在 ChinaRen 建立网上同学录；管理员成为类似“网上班长”的角色，班会通知、留言、聊天继续在线发生。武汉大学 1996 级广播电视班毕业后成员分散全国，一名去了甘肃酒泉的毕业生把网上班级称为共同的“精神家园”。

来源：

- 《解放日报》 / 新浪，2005-03-18，《“我的大学”虚拟化》：<https://news.sina.com.cn/s/2005-03-18/09105394097s.shtml>

这说明 Web 对关系的作用不只是“找到一个失联的人”，还包括 **`separation-delay / 离散延迟`**：

> 毕业、实习、迁移原本会迅速切断日常班级信息流；线上班级让现实共同生活结束以后，班级信息空间仍继续运行。

### 反例：线上班级也可能让“仍在身边的人”更少见面

同一篇 2005 报道明确记录反对意见：一名仍在校的博士生认为同学过分依赖网上沟通以后，即使住在附近也不一定真正组织起线下活动；网上都说愿意踢球，落实时间时仍可能无人有空。

因此：

```text
online class active
!= offline collective life active
```

关系可寻址性提高，不等于共同生活密度提高。

这是本专题的重要反例：**网络可以让远方的人“没那么散”，也可能让附近的人把部分协调留在屏幕上。**

## 四、2005：从“班级页”进一步走向同学搜索、IM 和认证门槛

### ChinaRen + 搜Q：同一个“找同学”动作可以有不同权限路径

2005 年搜狐同期产品文章记录，搜Q 3.0 与 ChinaRen 校友录互通以后，用户可以直接看到自己已有的班级、查找同学和班级、留言、贴照片，并把同学加入 IM 好友进行聊天。另一篇同期文章还指出：直接在 ChinaRen 校友录里查找同学，当时要求手机绑定；从搜Q 的整合入口查找则不需要相同门槛。

来源：

- 搜狐，2005-03-01，《各位ChinaRen校友录用户请注意》：<https://news.sohu.com/20050301/n224481435.shtml>
- 搜狐，2005-03-01，《Chinaren校友录搜Q版 真正意义上实现了IM与校友录的互通》：<https://news.sohu.com/20050301/n224481302.shtml>

这带来一个很重要的旧网状态差：

```text
platform says “find classmates” exists
!= every user through every client has identical search permission
```

同一个身份，在 Web 入口和整合 IM 客户端里可能获得不同能力。

### 班级成员资格本身也是状态

同期操作说明里，找到一个班级以后仍可能需要点击“加入”，等待班级管理员审批。

所以：

```text
school found
!= class found
!= membership approved
!= member list visible
!= ability to contact classmates
```

学校和班级可以作为定位索引，但它们并不天然等于公开电话簿。

### 2005：越容易找到旧同学，越容易暴露旧同学

2005 年《金陵晚报》同期报道已经记录利用网络校友录中的电话号码、账号和班级关系进行骚扰、诈骗和冒名的风险。

来源：

- 《金陵晚报》 / 新浪，2005-05-09，《小心网络校友录出卖个人隐私》：<https://news.sina.com.cn/o/2005-05-09/10135836958s.shtml>

这里不应把个案写成平台普遍风险率，但足以证明：

> **“过去的人更容易找到我”从一开始就同时意味着“陌生人更容易借过去的关系结构接近我”。**

因此 relation recovery 与 privacy 并不是移动互联网时代才出现的冲突。

## 五、2009：即使互联网已经普及，寻找旧同学仍然是混合基础设施

2009 年重庆一名何姓市民希望找到六位失联十余年的小学同学，为 2010 年春节组织同学会。他先从当年的班主任那里取得旧师生合影，然后不是简单“在某 SNS 搜名字”，而是通过报纸的新闻 QQ 和热线公开求助。

来源：

- 《重庆商报》 / 新浪，2009-12-02，《寻6位小学同学春节开同学会》：<https://news.sina.com.cn/c/2009-12-02/083716703837s.shtml>

这是一个非常好的 **T1 同时代第一人称 / 同期采访**，因为它保存了实际 search stack：

```text
班主任保留的旧照片
→ 记忆中的姓名和班级
→ 报纸公开传播
→ 新闻 QQ
→ 电话热线
→ 等待知情者提供线索
```

即使到了 2009 年，互联网也没有把老师、报纸和电话变成无用前史。它们仍然可以叠成一条实际可执行的寻人路线。

### “可恢复”常常依赖中间人，而不是目标本人留下可搜索主页

寻找旧同学最常见的机制之一可能不是：

> A 搜到 B。

而是：

> A 找到 C；C 仍认识 B；C 再把 A 的消息转给 B。

这可以称为 **`bridge-node recovery / 桥接节点恢复`**。

它后来会在公开社交平台时代再次出现。

## 六、2010–2012：扩张型未来——把“真实学校关系”做成持续社会图谱

### 人人网：profile 把学校经历变成长期搜索字段

人人公司 2011 年 F-1 是这一阶段最强的 A 级来源之一。公司向 SEC 描述，用户 profile 可包括姓名、照片、就读学校和大学、就业、当前地点、年龄和兴趣等；平台定位之一就是让用户与朋友、同学、家人和同事保持联系。

来源：

- Renren Inc., F-1/A, 2011：<https://www.sec.gov/Archives/edgar/data/1509223/000119312511099693/df1a.htm>

这些字段意味着学校关系不再只属于一个独立“校友录页面”，而被嵌进持续的个人 profile。

### 2011 的平台公司自己已经意识到：社会图谱有迁移成本

同一份 F-1 里，人人公司明确声称，实名关系有助于 retention，因为用户已经投入时间建立朋友连接、上传照片和内容；如果迁去另一个 SNS，不仅本人要重新建设，朋友也需要迁过去。

这里必须标注：

- **A：公司同期证券文件**，能证明公司当时如何理解产品和风险；
- **不能直接当独立社会科学结论**。

但它非常适合定义 **`social-graph switching cost / 社会图谱迁移成本`**：

> 换一个平台不是只安装另一个软件。你还要重新找到每个人，而每个人又必须在那里。

### 2011 同时代个人材料：平台已经进入日常同学联系

Computerworld 2011 年采访一名 24 岁厦门用户 Kuang Yaqiong，她说自己每天使用人人网与大学同学保持联系，并已有约 500 个站内朋友。

来源：

- Computerworld, 2011-05-04, *China’s Facebook, Renren, faces stiff competition*：<https://www.computerworld.com/article/1446291/china-s-facebook-renren-faces-stiff-competition.html>

这是一个 T1 个人样本，只能证明这种日常使用路径真实存在，不能代表所有 20 多岁城市青年。

### 扩张型未来在关系领域的含义

2005–2012 的“扩张”不只是“以后朋友更多”，而更具体：

> **“毕业以后大家可以各奔东西，但我未必因此永远失去这些人。”**

一个年轻人可以更大胆地：

- 去外地实习；
- 去另一座城市工作；
- 出国；
- 进入新的单位；

因为离开原共同空间不再必然意味着关系索引彻底断裂。

这不是说 Internet 导致迁移，而是通信基础设施降低了迁移的某一部分社会关系成本。

## 七、2014–2019：拥堵型未来——不是“没有旧关系”，而是旧关系分散在太多层里

### 2014：平台自己承认用户向新的消息系统迁移

人人 2014 年年报明确称，自 2013 年末起，白领用户受到竞争影响并向 social messaging services 迁移，公司重新聚焦大学生等年轻人。

来源：

- Renren Inc., 20-F for 2014：<https://www.sec.gov/Archives/edgar/data/1509223/000114420415023129/v403466_20f.htm>

这对关系史比“某个平台衰落”更重要：

```text
old profile remains
!= old platform remains primary contact channel
!= actual relationship disappeared
```

用户可能同时拥有：

- 早年的 ChinaRen / 5460 班级；
- 人人 profile；
- QQ 好友和群；
- 手机通讯录；
- 微信好友和群；
- 微博 / 后来的短视频与内容平台。

**关系没有消失，relationship state 却被拆散到多个互不等价的数据库里。**

### 2017：平台关闭使“社会图谱”暴露出产权边界

2017 年朋友网（前身 QQ 校友）公告停止服务，并明确建议用户提前下载和备份照片、留言板等重要信息。

来源：

- 澎湃新闻，2017-07-15：<https://www.thepaper.cn/newsDetail_forward_1733683>

这里要严格区分：

```text
exported photos
!= exported comments
!= exported class membership
!= exported friend graph
!= exported active contact channels
!= relationship migrated to another platform
```

平台允许保存“内容”并不必然允许完整迁走“关系”。

### 2019：旧图谱重新上线以后，有人想找回，也有人想远离

2019 年新版人人 App 上线时，媒体注意到旧账号密码仍可尝试恢复，旧校园关系和历史内容成为重要宣传点；同期采访也记录一些 85 后、90 后用户对学生时代的“黑历史”保持距离。

来源：

- 《扬子晚报》 / 人民网，2019-10-28，《人人网归来，你找回旧密码没？》：<https://media.people.com.cn/n1/2019/1028/c14677-31424126.html>
- 《北京日报》 / 人民网，2019-12-31，《人人网推新APP回归社交市场》：<https://media.people.com.cn/n1/2019/1231/c40606-31529296.html>

这一阶段的关键机制不是“年轻人变得不念旧”，而是：

**社会图谱的 persistence 开始成为双刃剑。**

过去最让人兴奋的是“毕业后还能找到你”；十几年以后，有些人第一次发现另一种需求：

> **过去的我不应该因为平台重新启动就自动重新公开给所有过去的人。**

### 拥堵型未来在关系领域的含义

候选关系、群、账号和内容都越来越多以后，真正稀缺的不是“联系人数量”，而是：

- 哪些人我仍然在联系？
- 哪些只是通讯录里还留着？
- 哪些只在旧平台里存在？
- 哪些群已经静默？
- 哪些旧关系值得重新激活？
- 哪些过去应当允许保持沉默？

因此 **`relationship abundance != relationship maintenance capacity`**。

## 八、2020–2022：偶发型未来——现实聚会会突然失败，但关系可以通过冗余通道继续运行

### 2020–2022：一群平均 75 岁的同学怎样继续聚会

中国科学技术大学 6523 班 1965 年入学、1970 年毕业。校友会资料记载，原计划 2020 年线下聚会因疫情未能实现；2021 年改用网络视频，2022 年元宵节继续办网络联谊会。活动前二十多天，组织者同时用：

- 微信群；
- 电话；
- 邮件；

通知老师和每一位同学。

来源：

- 中国科学技术大学校友总会，《中国科大6523班2022年元宵节网络联谊会》：<https://aga.ustc.edu.cn/info/1199/26202.htm>

这条材料特别重要，因为它不是年轻“数字原住民”样本。

它证明了一种成熟的 **`relational redundancy / 关系冗余`**：

> 真正可靠的长期关系基础设施，往往不是把所有人押在同一个新 App 上，而是微信、电话、邮件和现实组织者一起工作。

### 疫情没有创造线上同学关系，而是让它从便利层变成 fallback

2005 年线上班级主要解决“分散以后继续交流”；2020–2022 则进一步出现：

```text
线下周年聚会不可执行
→ 线上视频成为主要可执行路径
```

这可以称为 **`fallback elevation / 备用路径升格`**。

“偶发型未来”在关系领域因此表现为：你不能再假设明年周年聚会一定能照常办，但可以提前保留一套不依赖同一城市、同一交通条件的联系栈。

## 九、2023–2026：防守型未来——不再赌某个平台永远存在，而是保留“重新找到彼此”的能力

### 2025：旧关系甚至可以不依赖双方还在同一个平台

2025 年 1 月，美国 21 岁女性 Katharina 在小红书发布视频，希望寻找七年前失去联系的中国交换生朋友 Simon。她当时只保留了过去的关系背景和照片，并不掌握对方当前联系渠道。

22 小时后，关键并不是算法直接识别了 Simon，而是 **Simon 的一名高中朋友看到了寻人视频，把它转给 Simon，同时私信 Katharina**；随后双方才重新联系并交换新的社交账号。

北京青年报的同期采访还记录，Simon 当年回中国后换了电话卡，这正是失联的一部分原因。Katharina 则说自己此前一直没有找到他，把这次公开发帖视为“最后一次机会”，原本并不认为成功概率很高。

来源：

- 《北京青年报》转引页，2025-01-23：<https://finance.sina.com.cn/jjxw/2025-01-23/doc-inefyuyq7651006.shtml>

这是一个非常清楚的 T1 同时代第一人称链：

```text
旧手机号失效
+ 没有直接账号
+ 仍记得共同学校经历 / 照片
→ 公开社交发帖
→ 推荐/转发触达“认识目标的人”
→ 桥接朋友转给目标本人
→ 目标确认
→ 交换新的私域账号
→ 关系重新开始
```

所以 2020s 的 relationship recovery 与 2000s 校友录有一个明显差别：

- 2000s：先进入结构化 school/class database，再找人；
- 2020s：可以先把一段“我在找谁”的叙事公开传播，让社会图谱自己把它路由到合适的桥接节点。

这可以叫 **`social routing / 社会路由`**。

### 防守型未来：保护的不是“所有旧朋友永不丢失”，而是 re-bootstrap capability

如果 2005 年的理想是：

> “同学录一直在，我们永远不散。”

到 2020s 更稳健的目标可能变成：

> “我知道任何一个平台都可能消失；但如果未来真的想找某个人，仍有几条独立的路可以重新找到。”

这几条路可能包括：

- 手机号；
- 微信 / QQ；
- 共同群；
- 学校 / 校友会；
- 邮箱；
- 共同朋友；
- 公开社交搜索；
- 旧照片、姓名、学校和年份。

这不是悲观，而是 **`re-contact optionality / 再联系选择权`**。

同时，成熟的系统也必须保留另一半：不想重新联系的人应有拒绝和隐身能力。

## 十、海外比较：Classmates.com 说明“毕业后失联”不是中国特有问题

美国 Classmates.com 于 1995 年上线。CBS 2003 年的同期报道采访创始人 Randy Conrads 时，他解释高中之所以是平台的重要节点，是因为高中以后人会去大学、工作、参军、旅行，原本密集的关系由此失散。

来源：

- CBS News, 2003-05-05, *In Search Of The Past*：<https://www.cbsnews.com/news/in-search-of-the-past-05-05-2003/>

这说明“学校作为长期关系索引”并非中国特有。

### 一个尤其重要的海外案例：通过同学找到的甚至不一定是同学本人

同一 CBS 报道记录 Russell Kees 与家人失联约半个世纪；家人后来不是直接搜到他，而是通过 Classmates.com 给他的旧校友发邮件，最终重新连接到他。

这与 2025 年小红书案例具有同样的结构：

```text
目标本人不可直接寻址
→ 找到与目标共享过去的人
→ 中间人转发
→ 目标重新出现
```

所以 **bridge-node recovery** 并不是某一平台的独特功能，而是“把过去关系结构做成可查询/可传播对象”以后自然出现的一种跨国机制。

### 什么是中国特有，什么是更普遍的现代变化？

较普遍：

- 教育、工作、迁移把年轻人从共同地点分散出去；
- 电话号码、住址和姓名可能变化；
- 学校/班级因相对稳定而成为长期 locator；
- Internet 把多跳人工寻找压缩成在线查询和多跳转发；
- SNS 成熟以后，social graph 本身产生迁移成本；
- 平台消失又让“永久关系数据库”的想象破裂。

中国更值得单独研究：

- 1990s–2000s 极快的跨城、跨省教育和就业流动与 Internet 普及同时发生；
- ChinaRen、5460、QQ 校友、校内 / 人人等产品长期直接使用“学校—班级”作为核心信息架构；
- QQ、手机、实名 SNS、微信在短时间内连续叠加，使一个人的同学关系同时存在于多个代际平台；
- 旧平台内容和新私域联系方式之间的迁移并不完整。

## 十一、它怎样改变“普通人到底有多少种活法”

### 1. 离开一座城市的社会成本被重新定义

过去“去外地”不只意味着交通和住房成本，也可能意味着：

> **我离开以后，原来的同学和朋友会慢慢彻底失去联系。**

关系可恢复性提高以后，迁移仍会改变友谊，但“离开 = 永久消失”变得没那么必然。

这会给：

- 异地读书；
- 外出就业；
- 出国；
- 长期旅行；
- 职业转换；

增加一层社会选择权。

### 2. 人的一生可以出现“休眠关系”而不是只有“朋友 / 非朋友”二分

数字生活史里应新增一种关系状态：

> **`dormant but recoverable / 休眠但可恢复`**。

两个人可以十年不说话，彼此生活完全分开，却仍因共同班级、共同朋友或旧 profile 保留一条低成本恢复路线。

这和持续亲密关系完全不同，却也不能等同于“关系已经不存在”。

### 3. 旧同学网络可能成为人生 re-entry infrastructure，但不能把它浪漫化成人脉神话

一个旧同学未来可能带来：

- 一条招聘信息；
- 一个城市的落脚建议；
- 一次同学会；
- 一段共同记忆；
- 一次照护或互助；
- 或者什么实际利益都没有，只是重新说一句“你现在过得怎么样”。

因此不能把所有校友关系工具化成“networking capital”。

它首先改变的是：**过去的人不再只能永远留在过去。**

### 4. 标准人生脚本之外，一个人可以多次重新进入旧的人生阶段

毕业并不一定意味着“学生身份世界完全关闭”。

一个 40 岁、60 岁、75 岁的人仍可能：

- 回到班级群；
- 重新找到旧同学；
- 参加线上 / 线下周年聚会；
- 查看旧照片；
- 与几十年前的同学恢复联系。

所以人的社会生命历程并不只有：

```text
上学 → 毕业 → 永久进入工作 / 家庭阶段
```

还可以是：

```text
上学 → 分散 → 失联 / 弱联系
→ 某次人生事件重新激活旧关系
→ 再进入一个旧的社会世界
```

这是一种 **`social re-entry / 社会关系再进入`**。

## 十二、重点矩阵

| 维度 | 本专题新增机制 |
|---|---|
| 教育 | 学校/班级不仅产生学历，也产生长期 social locator namespace |
| 就业 | 跨城就业后旧同学关系可以休眠而非完全消失；不可直接推断为职业收益 |
| 住房 | 搬家不再等于旧关系无法定位本人，但实际地址仍应保持隐私 |
| 婚姻家庭 | 姓名、城市、联系方式和可联系边界会随人生阶段变化；旧关系恢复需要重新征得当下关系意愿 |
| 迁移 | Internet 降低迁移造成的关系断裂成本，但不消除距离本身 |
| 照护 | 老年同学仍能通过多渠道维持群体联系；数字能力分布需要观察 |
| 非正规劳动 | 本轮无直接新增，不应强行套用 |
| 长期中断 | 新增 `dormant but recoverable`：多年不联系仍可能重新建立路径 |
| 证件与记录 | 学校名、届别、班级成为稳定定位字段；不等于身份认证 |
| 通信方式 | 纸质通讯录→电话→校友录→IM/SNS→微信群/公开社交路由，多层叠加而非简单替代 |
| 互联网平台 | 班级页、实名 profile、好友图谱、群聊和内容平台分别保存不同关系状态 |
| 信息获取 | 从“问老师/翻通讯录”转为结构化搜索，再到算法传播和共同朋友桥接 |
| 社交关系 | 新增 relationship recoverability、bridge-node recovery、social re-entry |
| 未来预期 | 从“离开以后会散”到“平台会一直替我们保存”，再到“不赌单个平台、保留 re-bootstrap 能力” |
| 线上/线下身份 | 学校/班级字段把线下过去映射到线上 profile；同名与冒认仍是问题 |
| 平台消失与记忆保存 | 内容备份不等于 friend graph 可迁移；旧图谱恢复也可能违背今天的隐私意愿 |

## 十四、反例与后见之明风险

### 反例 1：Internet 可见不等于关系更亲密

2005 同期报道已出现“同住附近却网上联系更多、现实活动更难组织”的反例。

### 反例 2：找得到 profile 不等于找得到真人

- 重名；
- 假资料；
- 废弃账号；
- 学校字段填错；
- 密码丢失；
- 本人已迁移平台；

都可能让 online find 失败。

### 反例 3：平台消失不等于关系一起消失

朋友网关闭以后，一些关系早已迁到 QQ、微信、电话或现实联系；不能从平台死亡推出社交关系死亡。

### 反例 4：旧图谱恢复不一定是好事

2019 人人回归时的“黑历史”反应提醒：历史可见性和当前自我之间可能发生冲突。

### 后见之明风险 1：不要把 2005 校友录写成“早期微信”

校友录的学校/班级结构、管理员、页面、留言和 IM 都有自身事务状态，不应因为今天熟悉群聊就直接类比。

### 后见之明风险 2：不要把今天所有跨城流动归功于 Internet

就业制度、交通、住房、收入、教育扩张等是更大的迁移条件。Internet 只改变其中的关系维持与重联系成本。

### 后见之明风险 3：不要把“同学”自动写成强关系

同班可以包括：

- 亲密朋友；
- 普通熟人；
- 曾经冲突的人；
- 几乎没说过话的人。

school tie 是索引关系，不代表情感强度。

## 十五、尚未确定

1. 1999–2002 ChinaRen 早期校友录实际页面 schema 的可靠 historical capture 尚未取得；
2. 5460 不同时期班级页、成员页、留言和权限变化缺少两时点 capture；
3. 早期校友录里多少用户会长期更新电话 / 城市，而不是注册一次后弃置，缺少可靠 longitudinal evidence；
4. `校友录 → QQ/人人 → 微信` 的真实 friend graph 迁移比例不可从平台用户总量推出；
5. 老年人与低数字技能人群中，谁承担账号、视频会议、微信群的“数字代理劳动”，需要更多第一人称材料；
6. 公开寻人成功案例具有强烈 selection bias，不能用成功新闻估算普通失联关系的可恢复概率；
7. 还需要更多 2018–2019 普通人材料，区分“旧账号仍存在”“仍偶尔看旧同学”“实际关系已完全迁到微信”等不同状态。

## 十六、这一轮改变了什么理解

过去很容易把通信史写成：

> 信 → 电话 → QQ → 社交网络 → 微信，联系越来越方便。

这条线少了一件更关键的事：

> **如果你已经不知道该联系谁、去哪里找她，“通信更快”本身没有用。**

纸质通讯录先把人放进一个可查找的班级/校友集合；校友录把这个集合做成在线可更新空间；实名 SNS 把学校经历变成个人 profile 的长期检索字段；移动私域又让真正活跃的关系离开公开 Web；到了 2025，一个人甚至可以完全没有目标的新号码和账号，只靠旧照片、学校记忆和公开社交传播，让一个共同朋友把消息重新路由给她。

所以 Internet 对普通人生命历程的影响之一，并不是让所有关系永远保持活跃，而是创造了过去较少存在的一种状态：

> **我可以离开、我们可以多年不联系，这段关系甚至可以沉睡；但如果某一天真的想重新找到彼此，它不一定已经彻底失去返回路径。**

这让“人生阶段”之间的边界也变得更可逆。毕业不必把学生时代所有人永久封存；迁移不必把旧城市所有关系永久切断；一个 75 岁的人仍可以重新进入 20 岁时的班级世界。

但成熟阶段最终还要补上另一半自由：**可重新找到，不等于必须永远可被找到。**
