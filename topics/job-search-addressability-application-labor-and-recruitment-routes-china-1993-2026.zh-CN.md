# 求职可寻址性、申请劳动与招聘路线：中国，1993–2026

> 研究状态：research note / comparative synthesis
>
> 主题：就业、教育、迁移、通信、互联网、证件与记录、未来预期
>
> 初稿日期：2026-09-03

## 为什么单独研究“怎么找到工作”

仓库已经讨论过“什么算好工作”和“什么时候换工作变成正常选择”。这两个问题仍然不足以回答一个更基础的生活史问题：

> **一个职位即使真实存在，对某个普通人来说，它是否可发现、可申请、可联系、可面试并最终可入职？**

在工作分配或强组织中介较强的时期，年轻人可能主要等待分配、学校安排、单位招录或熟人介绍；劳动市场扩大以后，个人获得更多选择，同时也获得了一整套新的工作：

- 找到职位信息；
- 判断自己是否符合条件；
- 准备简历；
- 维护联系方式；
- 投递；
- 等待并解释没有回复的含义；
- 安排电话、邮件或面试；
- 比较多个岗位；
- 处理跨城交通与住房；
- 在录取失败后继续下一轮。

因此，劳动市场不只“提供更多工作”。它也把**管理自己的就业轨迹**变成普通成年生活的一部分。

本条目使用几个工作概念：

- **vacancy addressability / 职位可寻址性**：一个职位是否能被这个具体求职者发现和定位；
- **application labor / 申请劳动**：为了让自己进入招聘流程而付出的搜索、简历、投递、沟通、面试和跟进劳动；
- **application throughput / 申请吞吐量**：一个人在单位时间内能够提交多少次申请；
- **response opacity / 回复不透明性**：没有回复时，求职者无法判断是职位已满、系统未读、筛选失败还是流程尚未开始；
- **representational labor / 表征劳动**：把自己压缩成简历字段、关键词、作品、证书和经历，使雇主或机器能够理解和检索；
- **recruitment calendar coupling / 招聘日历耦合**：学校、毕业、实习、秋招、春招、考试与入职时间互相约束；
- **machine legibility / 机器可读性**：个人不仅要让招聘者“看懂”，还要让搜索、筛选、标签或 AI 系统能够把自己识别成候选人。

这几个变量都强调同一件事：

> **job exists ≠ vacancy is discoverable ≠ application is submitted ≠ recruiter sees it ≠ interview happens ≠ offer arrives ≠ job is accepted ≠ person actually onboards**

## 1. 1993：全功能 Internet 接入以前，人才市场已经把“找工作”做成大型信息与见面基础设施

1993 年 2 月，《人民日报》报道福州举行毕业生供需见面会，三百多家单位进入市青少年宫，毕业生与用人单位直接见面并进行“双向选择”。同年 10 月，北京举行首届全国人才市场人才智力技术交流大会，现场设置 942 个展位，报道描述有数以万计的求职者进入会场。

这些材料很重要，因为它们发生在中国正式全功能接入国际互联网之前。中国互联网官方历史回顾通常把 1994 年 4 月 20 日的 64K 国际专线全功能接入视为关键节点，同时也明确记载此前已经存在学术联网、电子邮件和 .CN 等前史。因此正确的表述不是“1994 年以前完全没有网络”，也不是“1993 年普通人已经在网上求职”，而是：

1. 学术和数字通信前史已经存在；
2. 大众就业匹配仍可以主要通过人才市场、学校、报刊、组织与熟人完成；
3. “信息集中 + 候选人集中 + 雇主集中”并不需要 Web 才能成立。

### 这种求职的一天是什么样的？

对一个参加大型招聘会的毕业生，申请劳动首先是物理劳动：

- 得知道会议在哪里、什么时候举行；
- 带着纸质材料到现场；
- 在有限时间内浏览展位；
- 排队；
- 当面询问；
- 决定把材料交给谁；
- 之后再靠电话、信件、学校或线下通知等继续联系。

这里已经存在“搜索”，只是搜索界面是一座大厅而不是搜索框。

### 证据边界

这两份报道可以证明人才市场和直接见面招聘真实存在，并且规模很大；它们不能证明所有毕业生都通过人才市场就业，也不能把三百家单位或数万参与者外推成全国就业结构。

## 2. 2000：网络招聘首先进入的是“混合渠道栈”，不是一次性替代

2000 年 3 月，《生活时报》报道前程无忧等将网络、报纸和猎头组合成“网络 + 报纸 + 猎头”的招聘体系。更值得生活史注意的是，个人加入求职数据库并不只靠一个网页按钮：报道同时列出信件、电话、传真、电子邮件和直接注册等入口，并提到职位信息订阅。

这说明中国早期网络招聘的真实形态不是：

> 线下求职突然结束 → 人人打开浏览器找工作。

更接近：

> 人才市场 / 学校 / 报纸 / 熟人 / 电话 + Web / email / 数据库订阅同时工作。

这可以称为 **hybrid recruitment stack / 混合招聘栈**。

### Internet 真正新增加了什么？

它至少开始降低两种成本：

1. **重复展示成本**：求职者不必每次都重新把完整信息讲给一个新雇主；
2. **位置更新成本**：新的职位可以通过数据库和订阅远程进入视野。

但是，网页只解决了流程前段的一部分。工资谈判、面试、是否录用、搬家和实际入职仍可能发生在电话、邮件、线下办公室和另一座城市。

- 《生活时报》2000-03-06，同期报道：https://www.gmw.cn/01shsb/2000-03/06/GB/03%5E1274%5E0%5ESH3-631.htm

## 3. 2001：简历从“递出去的一张纸”变成可以被检索和修改的对象

2001 年新浪教育保留的一篇同期求职教程已经把网络简历描述得非常具体：好的求职网站应允许用户用 ID 和密码再次登录修改简历、把简历自动发送给企业，并给出自己的简历 URL。文章甚至建议在填写字段时加入同义词，例如与网页、主页、网站相关的多个词，以增加被检索到的机会。

这意味着一个非常早的 **machine legibility** 问题已经出现：

> 一个真实的人不只需要有技能，还需要把技能写成系统能够检索到的字段和关键词。

同一时期新浪保留的一套 2001 届毕业生求职表单可观察到姓名、学校、专业、意向地区、行业、职位、简历摘要、联系方式等字段，并提供修改或删除信息的入口。它把求职者转换成了一个可以搜索、筛选和更新的数据库对象。

### 新的劳动：representation labor

纸质招聘时代当然也要写简历，但数据库让“怎样表示自己”获得新的技术约束：

- 哪个字段必须填？
- 哪个词能被搜索？
- 意向地区选一个还是多个？
- 职位名称怎样归类？
- 一段经历应该被翻译成什么关键词？
- 什么时候需要更新？

这不是纯粹的文书劳动，而是**让自己的生活经历进入一种机器可比较格式**。

### 重要隐私边界

今天搜索早期求职网页时，仍可能遇到带有普通人姓名、电子邮箱、电话号码等直接识别信息的旧简历页面。本项目不为证明结构性结论而重新记录或传播这些个人字段。

这里应保留的是结构性事实：

- 普通求职者信息可以被网页数据库公开或半公开呈现；
- 这些资料可能在求职结束多年后仍残留；
- **resume survives ≠ consent survives**；
- “历史保存得很好”并不总是值得庆祝，个人资料的消失有时是正确的隐私结果。

## 4. 2003：SARS 把网络招聘变成一次压力测试，但“能大量投递”不等于“更容易得到工作”

2003 年 SARS 期间，网络招聘的重要性明显上升。同期报道提到网上招聘会、在线咨询、一对一交流和职位订阅，但同样留下一个非常重要的反例：**简历数量可以暴涨，面试通知仍然极少。**

一篇同期报道给出了某网上招聘活动连续两天的后台数据：一天收到 26,597 份简历而产生 75 个面试通知，另一天收到 26,682 份简历而产生 257 个面试通知。报道同时指出，主办方自己也无法确切知道最后有多少人真正通过网络招聘找到工作。

这不是可以直接计算“网络招聘成功率”的样本：

- 一份简历不等于一个独立求职者；
- 面试通知不等于录用；
- 报道没有给出完整去重和最终入职数据。

但它非常清楚地证明了一个机制：

> **application throughput 上升，可以和 recruiter attention scarcity 同时发生。**

一个人以前一天只能跑几个展位，网络以后可以投几十个岗位；与此同时，雇主也可能一次收到成千上万份材料。

### 同期反例：互联网没有立刻替代学校、熟人和线下招聘会

同一篇报道追踪一个 23 人班级的就业结果时，已就业者中只有 1 人是通过当次网上招聘会获得工作，更多人通过传统招聘会、学校信息或熟人渠道就业。这个班级极小，绝不能代表全国；它的价值恰恰是反驳“网络出现以后线下渠道马上失效”的线性故事。

当实体人才市场重新开放后，报道中的一些求职者仍更喜欢面对面交流，只把网络当作获取信息的工具。

### 信息可及也不是均等的

当时使用网络找工作需要：

- 能上网；
- 会操作电脑和网页；
- 有可用邮箱或其他联系方式；
- 有时间和地点上网；
- 能支付相应通信与设备成本。

因此：

> **online vacancy exists ≠ every worker can practically access it**

### 一次危机也会改写路线

同年另一批同期采访里，有毕业生大量自荐后仍觉得工作条件或工资不合适，转而和同伴做网站；也有人选择继续读研究生，以推迟进入当时的就业市场并增加未来资格。

这提醒我们：“毕业 → 找工作 → 入职”不是唯一执行路径。就业市场冲击会触发：

- 继续教育；
- 创业；
- 暂缓进入某个城市或行业；
- 重新定义可接受工资和地点。

## 5. 2008：扩张型未来并不是平滑乐观——申请爆炸、现场排队和“先拿一个 offer”同时存在

2008 年底的一组同期毕业生采访把网络投递和线下拥堵放在了同一个人的生活里。

报道中的唐莎莎在 20 天左右向网上投出近 500 份简历。她的日常被电脑、公交、道路、餐馆和招聘会占据，甚至已经很难准确说出自己最想要哪一种工作，更直接的目标变成“先得到一个 offer，让自己和家里放心”。

另一个现场里，黄亮为一次只有约一分钟的面试等待三四个小时；报道描述约两万名学生争夺约四千个岗位。还有毕业生在连续求职后下调工资预期，有人明确把 2009 年就业形势的不确定性放进当前决定中。

### 这给“2005–2012 扩张型未来”增加了一个内部断点

这一时期仍然存在明显的扩张机制：

- 更多城市和企业被远程看见；
- 一个求职者可以在短期内触达大量职位；
- 实习可以提前成为正式招聘的前置阶段；
- 职业选择显得比单次组织分配更开放。

但 2008 年冲击说明，扩张并不意味着每一年都主观乐观。更准确的比较是：

> **选择菜单已经扩大，但在危机年份，人的目标可以从“挑选理想路线”迅速收缩成“先确保进入一条路线”。**

这也说明“海投”不是一个简单的技术结果。投递成本下降以后，求职者与雇主之间可能出现新的拥堵：

- 每个人投更多；
- 每个岗位收到更多；
- 单份申请被认真阅读的概率可能下降；
- 求职者反而更难解释沉默。

### 招聘日历开始向毕业以前延伸

同一报道中的部分工作实际从前一年的实习就开始，后来才转成正式录用。就业因此不再只发生在“毕业那个月”，而会提前进入学生的上一学年甚至更早。

## 6. 2018–2019：拥堵型未来——简历越来越像多年积累的“可竞争档案”

2019 年《中国青年报》关于大学生职业规划的报道保存了几条很有价值的同期路线。

一名受访者在 2018 年放弃原先的考研路线，从会计方向转向摄影；这一转向并非完全突然，她已经有数年的相关学生实践，后来重新改写自己的职业蓝图。另一名学生曾相信多年累积的演讲、竞赛和项目经历能使自己的简历足够有竞争力，最后仍选择了创业路线。

这些个案不能代表同龄人，但它们显示 2019 年求职中的一种结构变化：

> **简历不再只记录“我毕业了”，而越来越像一个从大学早期就开始积累的竞争组合。**

同年基于某招聘平台约 300 万账号数据的报告还观察到招聘季明显拉长：大型企业的秋招可以在前一年 8 月左右启动，一部分毕业生在毕业后仍继续活跃求职。平台账号样本绝不能等同于全国毕业生，但它支持一个机制判断：

**招聘日历越来越早开始，也越来越晚结束。**

于是“拥堵型未来”的压力不只来自职位竞争，也来自履历时间：

- 大一到大三要不要实习？
- 秋招前是否已经来不及补项目？
- 考研和秋招是否冲突？
- 拿到一个 offer 以后还要不要继续投？
- 毕业后继续求职是否意味着失败，还是只是延长搜索？

## 7. 2020：偶发型未来——招聘可以搬进家里，但“家里”必须突然变成面试基础设施

疫情期间，大量招聘流程迁到线上。一名同期受访毕业生青青第一次在陕西家中参加视频面试时，专门找白墙作为背景、提前安排父母和宠物不要打扰；实际面试中又遭遇网络卡顿。

这个片段非常适合提醒我们：

> **online interview available ≠ every home is an interview room**

线上招聘要求家庭临时提供：

- 相对安静的房间；
- 可接受的背景与照明；
- 电脑或手机；
- 摄像头和麦克风；
- 足够稳定的网络；
- 连续供电；
- 与家人共享空间时的时间协调。

因此“招聘数字化”不是无空间化，而是把招聘地点从学校和公司部分转移到家庭。

### 机器可读性进一步强化

同一时期的报道还描述招聘平台把一份简历读成数百个标签，用于匹配和筛选。求职者因此不仅面对人力资源人员，也面对一个先把经历结构化的机器层。

这使 2001 年已经出现的关键词问题获得了新的强度：

- 2001：怎样让数据库检索到我的关键词？
- 2020：怎样让系统正确识别我的技能、经历和标签？

### “未查阅”是一种新型等待经验

同期受访者菲凡投出上百份申请，获得回复很少，平台上还能看到大量“未查阅”等状态。

这比纸质简历时代多了一点可见性，却没有消除不确定性：

- 未查阅是因为雇主忙？
- 岗位暂停？
- 投递太晚？
- 招聘者已经有足够候选？
- 系统排序没有把这份简历推上去？

这就是 **response opacity**：平台可以显示状态，但仍不能完全解释人的下一步。

## 8. 2023–2026：防守型未来——AI 同时进入求职者和招聘者一侧，新的问题变成“怎样让机器读我、我又怎样核验公司”

2026 年的同期报道已经留下两种相互镜像的 AI 使用方式。

一边，求职者董雨琪面对大量不熟悉企业，会用 AI 工具汇总企业业务、经营、负面信息与薪酬讨论，再据此调整简历和面试准备。另一边，招聘人员也开始测试 AI 简历评分和筛选工具。

这使就业市场增加了两种新的劳动：

### 8.1 machine-facing representation

求职者开始主动考虑：

- 系统能否识别我的技能？
- 简历应该怎样写得适合机器解析？
- 是否需要为不同岗位改写不同版本？
- AI 会不会因为字段或表达方式把我排除？

### 8.2 company verification / 公司反向核验

职位越来越容易被发现时，另一个问题变成：

> 我面前出现的这么多企业，到底哪个值得去？

AI 降低了部分背景调查成本，但并没有让企业质量自动透明。求职者仍需区分：

- 企业官方宣传；
- 招聘平台字段；
- 经营信息；
- 员工讨论；
- 岗位实际职责；
- 面试中说的内容；
- 入职后的真实工作。

### 8.3 automation-exposure hedging / 自动化暴露对冲

另一组 2026 年毕业生采访中，有人明确把“这个方向是否更不容易被 AI 替代”纳入职业选择；有人因此向硬件、半导体等方向调整，也有人同时准备多条路线。

同期网络调查中的比例只能代表该调查样本，不能外推成所有毕业生。但这些第一人称足以证明一种真实存在的“防守型未来”机制：

> **职业路线不只在工资和兴趣之间比较，也开始比较未来自动化风险，并保留考试、升学或其他岗位作为退路。**

- 《中国青年报》2026-04-14，AI 与春招求职：https://news.youth.cn/gn/202604/t20260414_16605674.htm
- 《中国青年报》2026-05-14，AI 时代毕业生职业路线调整：https://news.cyol.com/gb/articles/2026-05/14/content_99Eg5gCa3x.html

## 9. 四种未来时间感：招聘基础设施怎样改变“下一步”

| 时段 | 不是一句话概括整个社会，而是本批证据显示的机制 | 求职者面对的典型时间问题 |
|---|---|---|
| 2005–2012 扩张型未来 | 远程职位发现和申请吞吐量扩大，但 2008 冲击显示扩张可突然转成“先占住一个位置” | 我能投多少城市、多少公司？实习是否能提前锁定机会？ |
| 2015–2019 拥堵型未来 | 简历竞争前移到大学多年积累，秋招/春招/考研/实习叠在一起 | 我是不是已经准备得太晚？应不应该再堆一个项目或证书？ |
| 2020–2022 偶发型未来 | 线下流程可以突然失灵，家和网络临时承接招聘 | 明天的面试还能不能按原流程举行？家里的网络和空间够不够？ |
| 2023–2026 防守型未来 | AI 降低信息处理成本，同时制造机器筛选、真假信息与职业替代的新不确定性 | 怎样让机器正确理解我？这个企业值得去吗？这个职业几年后还稳定吗？ |

这四个标签不是人格分类，也不能把同一时期所有人压成一种情绪。它们只是帮助比较：**普通人究竟把什么当作未来风险。**

## 10. 海外对照：美国 1990 年代也经历“报纸分类广告 → 网络数据库”的混合过渡

这一机制不是中国特有。

1998 年美国 CareerPath 的同期行业报道显示，该服务与六十多家报纸合作，把报纸中的招聘分类广告带到网络上，同时提供简历数据库和企业职位。它非常像一个过渡形态：

> print newspaper classifieds + Web search + resume database

而不是“互联网一出现，报纸招聘立刻消失”。

1999 年《San Francisco Examiner》记录一名 30 岁 MBA 求职者使用在线筛选条件，把地区、食品行业和金融职位组合起来，系统通过电子邮件把匹配岗位送给他；他数周内获得了工作。这个个案有强烈的高学历、旧金山湾区和早期采用者偏差，不能代表美国普通劳动者，但它很好地显示了**职位可寻址性**怎样变化：

以前：读整版分类广告、打电话、寄材料。

后来：把自己的条件编码成查询，等待匹配结果进入邮箱。

Pew 2002 年的调查进一步给出 denominator：当时已有数千万美国人使用互联网找工作，但互联网接入和网络求职仍明显偏向年轻、较高学历和较高收入群体；失业者和部分低技能岗位群体的网络接入并非普遍。

因此跨国共同机制是：

> **网络扩大搜索半径和申请吞吐量，但早期收益首先更容易被已有设备、网络、教育和数字技能的人获得。**

来源：

- InternetNews, 1998，CareerPath 与报纸联盟：https://www.internetnews.com/marketing/careerpath-com-adds-new-newspaper-affiliates/
- *San Francisco Examiner* / SFGate, 1999，在线求职个案：https://www.sfgate.com/business/article/Trolling-the-Net-for-jobs-3096205.php
- Pew Internet, 2002，Online Job Hunting：https://www.pewresearch.org/internet/2002/07/17/online-job-hunting/

## 11. 它改变了“普通人到底有多少种活法”的哪一点？

### 11.1 市场化不只增加选择，也增加“搜索人生”的劳动

从等待分配、参加一两场招聘会，到自己维护长期简历、不断比较公司、投递和追踪状态，成年人的劳动里增加了一层看不见的管理工作。

一个人可能并没有“失业躺着”，而是在每天完成：

- 搜索几十个岗位；
- 修改三版简历；
- 填重复表单；
- 做测评；
- 准备面试；
- 查企业；
- 等待消息；
- 继续下一批申请。

这部分时间通常不会出现在正式就业统计里，却会深刻改变一个人的一天。

### 11.2 联系方式可携带性支持了职业移动

当求职联系依赖学校办公室、单位电话、家庭固定电话或特定地点时，换城市和换工作会改变“别人怎样找到我”。

个人邮箱和后来个人手机号的普及使一个人的求职身份可以更容易脱离当前单位继续存在。

因此：

> **portable contact identity can support portable career identity**

这个判断仍需要更多定量史料，但它是下一步值得追的通信—就业交叉变量。

### 11.3 选择更多以后，新的稀缺资源变成“注意力”

网络招聘降低了申请的边际成本，却没有同步增加每位招聘者的阅读时间。

于是：

> more vacancies visible ≠ more offers per person
>
> more applications possible ≠ more applications meaningfully read

这和购物、相亲、租房等平台化生活具有共同结构：**发现成本下降以后，筛选和可信度成本可能上升。**

### 11.4 失败的路径更多，也意味着退路更多

一个普通人的毕业后路线可以是：

`实习 → 留用`

也可以是：

`秋招 → 无 offer → 春招 → 入职`

还可以是：

`投递 → 继续读研`

`投递 → 创业`

`一线城市求职失败 → 回家乡`

`拿到工作 → 因地点/住房/家庭放弃`

`工作几年 → 再求职换行业`

当我们只统计最终雇主时，这些曾经打开又关闭的路线全部消失了。

## 13. 反例与后见之明风险

### 不要写：互联网让找工作从线下变成线上

更准确：线上成为新增入口，并与学校、人才市场、报纸、熟人、电话和线下面试长期叠加。

### 不要写：投得更多就有更多选择

大量投递可能只是因为单次申请成本下降，也可能造成更严重的注意力竞争。

### 不要把 2008 年倒写成整个 2005–2012 的悲观时代

2008 年是扩张结构内部的一次强烈冲击。它证明未来预期可以在短时间内收缩，不证明整个时期所有人都悲观。

### 不要把平台样本当人口样本

2019 年几百万招聘账号说明平台内部行为，不等于全国青年；2026 年的网络调查同样不能代表全部毕业生。

### 不要把 AI 当成所有“防守型未来”的原因

住房、家庭、行业周期、工资、教育竞争和城市选择都可能独立影响职业防守。AI 只是本轮明确找到的一种新增风险语言。

### 不要把“未回复”写成“被拒绝”

在平台化招聘里，沉默可能有很多后台原因。历史研究尤其不应为补齐故事而替雇主推断一次决定。

## 14. 证据等级与材料类型

为了便于和 `old-web-archaeology` 交叉，本条目借用 A/B/C/D 简写，但不改变本仓原有方法：

- **A**：同时代原始报纸、网页、官方文档或可定位原始材料；
- **B**：同期记者对平台、用户、现场的观察与采访；
- **C**：多年后回忆；
- **D**：研究者根据证据提出的机制模型。

本轮核心材料以 A/B 为主：

- 1993《人民日报》人才市场报道：A；
- 2000–2003 网络招聘报道与教程：B / 部分页面 artifact；
- 2008、2019、2020、2026 第一人称采访：B，且只代表受访者；
- 美国 1998–2002 同期媒体和 Pew：B / institutional survey；
- `vacancy addressability`、`application labor` 等术语：D，作为分析工具而非历史行动者原话。

## 15. 目前不知道什么

最缺的仍然不是“平台什么时候成立”，而是**同一个普通人的完整执行链**：

`看到职位 → 创建/修改简历 → 第一次投递 → 是否被读 → 电话/email → 面试 → offer → 是否接受 → 是否搬家 → 三个月后是否仍在岗位`

尤其需要补：

1. 2000–2010 同一普通账号的多个历史时点，而不是媒体压缩后的成功故事；
2. 非大学毕业生、农民工、服务业、工厂工人和低学历劳动者怎样使用或不使用网络招聘；
3. 报纸、人才市场、学校就业办、短信、电话与 Web 的真实份额变化；
4. 个人邮箱和手机号普及怎样改变跨单位、跨城市联系连续性；
5. 一个网络 offer 最终因为住房、交通、户口、家庭或照护原因未执行的个案；
6. 招聘网站内部职位删除、过期、重复发布和雇主回复状态的历史保存情况。

## 16. 本轮改变了什么理解

此前可以说：

> 工作从组织分配逐渐变成个人需要管理的市场选择。

本轮把这句话推进了一步：

> **市场化与网络化共同改变的不只是“有多少工作”，而是普通成年人必须长期维护一个可被发现、可被联系、可被机器和人理解的职业身份，并管理一条充满沉默、失败、重试和退路的申请队列。**

因此，一个时代“普通人有多少种活法”，不能只数职业类别。

还要问：

> **有多少职位实际上能进入他的视野；他要付出多少额外劳动，才能让其中一个职位真正变成下一段生活。**
