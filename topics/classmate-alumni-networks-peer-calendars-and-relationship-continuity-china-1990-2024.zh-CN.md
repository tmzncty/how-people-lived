# 从通讯录到“熟悉的陌生人”：1990–2024 年同学网络、同龄人日历与关系连续性

> 研究问题：毕业、迁移、换工作和成家以后，一个普通人怎样继续找到旧同学；当同龄人的就业、跳槽、恋爱、结婚、生育、住房和消费第一次被持续放在同一个屏幕上时，“别人都走到哪一步了”又怎样进入个人的未来判断？

旧网执行层对应研究：

- `tmzncty/old-web-archaeology/docs/ALUMNI_CLASSMATE_DIRECTORIES_GROUP_MEMBERSHIP_TRUST_AND_MEMORY_STATE_GAPS_1999_2012.md`

本文不是“人人网兴衰史”，也不把同学关系浪漫化成天然可靠的人脉。它研究的是一种更基础的生活基础设施：**离开同一个教室以后，关系还能不能被重新寻址、重新激活，并在数年后继续承载信息、比较、求助或记忆。**

---

## 1. 核心概念：relationship continuity infrastructure

毕业会同时破坏三件过去被学校免费提供的东西：

1. 人每天在同一个地点；
2. 同学名单天然可见；
3. 每个人大致知道别人最近在做什么。

离校后的关系连续性至少需要：

```text
记得这个人
→ 仍知道可用的地址/电话/账号
→ 能确认今天控制该地址的仍是本人
→ 对方愿意回应
→ 双方把关系迁到下一种通信渠道
→ 数月/数年后仍能再次找到
```

本文把支撑这条链的纸质通讯录、校友会、电话、校友录、QQ/微信群、SNS 与学校档案称为 **relationship continuity infrastructure（关系连续性基础设施）**。

几条必须固定的边界：

- `同学关系曾经存在 ≠ 今天仍可联系`
- `平台里仍有账号 ≠ 账号今天仍由本人控制`
- `加入同一班级页面 ≠ 仍有真实关系`
- `看到同龄人的近况 ≠ 看到其完整生活`
- `关系在新渠道延续 ≠ 旧平台里的内容也被保存`

最后一条尤其重要：**social continuity 与 archival continuity 可以朝相反方向发展。** 一群人可以早已迁到 QQ、微信继续联系，而十年前的班级留言、照片和事件顺序却永久丢失。

## 2. Internet 以前：通讯录首先是一张需要反复维护的“关系路由表”

### 2.1 1990：纸质校友通讯录已经把“离校后还能找到”制度化

Google Books 的书目记录显示，《武汉大学校友通讯录》由武汉大学校友通讯录编委会编，1990 年出版，共 188 页。[1]

这条证据只证明该出版物存在，不证明每一名毕业生都拿到、使用或保持其中地址更新。但它足以说明：

> **在大众 Internet 以前，学校/校友组织已经需要专门生产一份跨地点的关系索引。**

纸质通讯录的优势是离线、可长期保存；它的脆弱处则是：

```text
出版时地址正确
→ 人搬家/换单位/出国
→ 纸不会自己更新
→ 下次联系需要电话、书信、熟人转问或重新编录
```

可以把这称为 **contact-state staleness（联系状态陈旧）**。

### 2.2 2005 的一场聚会保存了纸—档案—电话混合路径

南京大学校友网对 81 经管毕业二十年聚会的同期记录说，组织者为了聚会“重修通讯录”，反复联络同学；最后仍有一人毕业后长期失联，组织者通过学校档案馆寻找线索，才重新以电话联系上他。[2]

这是一个很好的桥梁案例：

```text
旧通讯录/熟人线索
→ 仍找不到
→ 学校档案
→ 新线索
→ 电话
→ 关系重新建立
```

Internet 并没有发明“找回失联同学”这个需求。它改变的是搜索范围、更新时间和普通用户能否自行完成查找。

## 3. 1999–2005：在线同学录把“班级”变成可搜索、可更新的远程对象

2004 年《中国电脑教育报》的一篇同期操作文章记录，作者在使用 5460 中国同学录之后继续比较其他服务；ChinaRen 校友录当时允许按大学、中学、小学搜索或创建班级，并提供班级共享、班级宣言等功能；QQ 校友录则能用 QQ 号码进入，并可把既有同学群转换成校友录。[3]

这是一条 **B：同期用户教程/媒体操作记录**，不是平台服务器日志。但它足以证明：到 2004 年，普通网民面对的已经不是“网上有没有校友录”，而是**多个不同班级目录/账号体系之间如何选择**。

这与纸质通讯录相比发生了三个结构变化：

1. **searchable cohort（可搜索同届）**：先找学校、年份、班级，再找人；
2. **mutable directory（可更新目录）**：个人资料和班级内容理论上可继续修改；
3. **shared memory space（共享记忆空间）**：联系表之外还出现留言、文件、照片、班级宣言。

2005 年搜狐同期报道还称，ChinaRen 校友录已经进入手机搜狐 WAP 产品矩阵。[4] 这只证明产品当时被厂商这样提供/宣传，不证明普通学生普遍用手机访问；但它说明**班级关系图开始脱离“只能坐在 PC 前查看”的状态。**

## 4. 2005–2012 的扩张型未来：同龄人的人生第一次变成一张持续更新的“日历”

### 4.1 2008：从“找同学”到让社会身份跟着毕业生继续延伸

2008 年 IT 时报的同期报道记录，校内网开始向刚毕业不久的白领扩展；现场演示中，记者按工作单位和毕业院校筛选，几分钟内找到了大学同班同学。[5]

这里出现的是 **identity continuity after graduation（毕业后的身份连续性）**：

```text
学校身份
→ 毕业
→ 工作单位/城市变化
→ 仍由原来的同学图继续定位
```

网络因此不只是保存“我以前和谁同班”，而开始把学校关系接到毕业后的职业世界。

### 4.2 2009 的同期材料：peer-calendar visibility

2009 年《中国青年报》的一篇同期文章保存了两个非常有价值的班级经验。[6]

第一组人物毕业后走向教师、记者、外企、机关和继续升学等不同道路，但仍通过网上校友录更新近况。文章里的小孙会看到同学分享留学、工资福利、恋爱、婚纱照、生育、跳槽、升职、继续升学、旅行，以及后来住房、汽车等生活节点。

最重要的不是“大家爱晒”，而是报道明确指出：同学年龄相近，因此几乎同时经历就业、跳槽、结婚、生育等阶段。

本文把这种机制称为 **peer-calendar visibility（同龄人日历可见性）**：

> 过去，一个人可能只知道几个亲友何时结婚、买房；班级型网络第一次让几十个年龄接近的人，把生活节点按近实时顺序放在同一个观察面板上。

这会改变“标准人生脚本”的认知来源。

以前的脚本更多来自：

- 父母；
- 亲属；
- 单位/学校；
- 报刊电视；
- 同城熟人。

现在又增加：

```text
我毕业一年
→ 同学工作稳定了
→ 有人开始谈婚论嫁
→ 又有人贴婚纱照
→ 接着出现宝宝、升职、住房、汽车
→ “我们这个年龄是不是该走到这里了？”
```

这里必须避免因果跳跃。该文章是媒体选取的同期个案，不证明“校友录导致一代人攀比”或“所有用户都因此焦虑”。它只证明：**同龄人的里程碑已经可以成为持续可见、可相互比较的生活信息。**

这比“Internet 让社交更方便”更具体。

### 4.3 同一个 2009 年材料也给出了反例：关系平台会衰减

文章第二组人物小杨毕业时，班里特意提出“在网上建个校友录”，希望各奔东西以后仍像在一起；刚毕业时她每天刷新，同为教师的同学会分享第一次公开课、教学成绩、教案和试题。[6]

几年后，登录频率却从每天降到每月甚至更久；现实生活圈重新长出来，过年群发短信反而成了更常见的联系。

这形成 **cohort-platform decay（同届平台衰减）**：

```text
毕业断裂最高
→ 校友录使用最密集
→ 新工作/婚姻/本地生活圈形成
→ 原班级页面更新下降
→ 联系迁往短信/QQ/其他渠道
```

因此不能把 2004 年班级页面的存在外推成“这个班十年后仍在这里生活”。

## 5. 一个很重要的生活机制：同学关系可以从“亲密关系”变成 latent-tie optionality

同学不必仍然是每天聊天的朋友，才具有现实作用。

中国科大北京校友会 2020 年发布的一篇第一人称求职经验，保留了作者 2019 年 9 月的一条精确时间链：他把三个目标公司告诉北京校友会；校友会查找能联系到的校友，通过电话、邮件、微信引介；数日后师兄把简历转给 HR，HR 再加微信协调面试，最终进入后续录用流程。[7]

这是 **C-near：事件后不到一年写成的第一人称回顾**，并且由校友组织托管；不能据此证明所有校友内推都有效。

但它证明了一种新的生活路径：

> **latent-tie optionality（弱/潜在关系的可选性）**。

一个人在大学毕业多年后，不必一直和某位师兄维持亲密友谊，也可能通过学校身份、校友组织和即时通信临时重新激活一条职业路线。

这使“同学网络”不能只按情感强弱研究，还要问：

- 能不能重新找到；
- 谁替你担保身份；
- 旧关系是否足够产生回复；
- 关系能否把你交给下一个制度接口（HR、面试、住房、城市信息等）。

## 6. 2015–2019 的拥堵型未来：熟人更多，真正想重新进入的旧关系却未必更多

2019 年人人 App 测试回归时，同期媒体采访观察到，老用户可以尝试用旧账号/密码重新登录，但不少 85 后、90 后对过去的“黑历史”反而希望保持距离；报道把重新进入旧账号后的感受写成“熟悉的陌生人”。[8]

这提醒我们：

> **recoverable archive ≠ desired relationship revival。**

数字网络可以保存过去的人，却不能保证今天的自己仍愿意进入过去的关系结构。

和 2009 年相比，时间感发生了变化：

- 2009：看同龄人下一步走到哪里；
- 2019：已经经历多轮工作、迁移与平台迁移以后，开始管理哪些旧关系值得保留、哪些旧身份不想重新激活。

所以“人脉更多”不应自动等于“选择更多”。旧关系本身也有维护、验证和情境成本。

## 7. 2020–2022 的偶发型未来：当人不能聚到同一个地方，关系基础设施可以临时接管“重聚”

2020 年 8 月，北京大学 86 级毕业三十周年聚会因疫情转为线上。北京大学校友网同期记录：组织者专门搭建“86 云家园”，七天内有 1106 人注册；活动同时设置线上主场、分桌以及多个城市线下分会场，并跨时区参加。几十名同学用了约 13 周完成方案、网站、网络保障、内容征集和线上培训。[9]

这不是普通同学聚会的代表样本——参与者高度组织化、教育与资源条件也特殊。

但它给“偶发型未来”一个干净机制：

**continuity substitution（连续性替代）**：

```text
原定：共同旅行 → 同一地点 → 聚会
突发：旅行/聚集不可执行
替代：临时网站 + 直播 + 分桌 + 跨时区协作
```

Internet 没有消灭物理重聚的价值，但让“今年这件事不必完全取消”成为另一条可执行路线。

## 8. 2023–2026 的防守型未来：关系可以迁走，记忆却可能被平台扣住

2024 年 12 月，南方都市报在人人网服务升级/无法正常使用的背景下采访老用户和前员工。报道中的 90 后用户说，自己整个大学阶段与同学朋友的互动都记录在人人网；另一名前员工/老用户回忆，大学照片、状态和互动一直延伸到第一份工作、恋爱与成家。与此同时，报道观察到网站登录、密码找回和资料完整性都出现问题。[10]

更重要的反例是：一名前员工说自己至今仍与很多旧同事在微信群保持联系。[10]

于是必须区分：

```text
人际关系迁移成功
≠ 历史内容迁移成功
```

本文把它称为 **memory portability gap（记忆可迁移缺口）**。

一个班可以从 ChinaRen → QQ → 人人 → 微信活下来，但：

- 当年的照片说明；
- 第一次工作/分手/结婚的状态；
- 谁在什么时候回应谁；
- 一段关系从密到疏的过程；

可能只留在已经衰退的平台后台里。

这给“防守型未来”补出一种不只是现金和职业的缓冲思维：**archive insurance（记忆保险）**。真正想保留的关系与资料，不能只假定单一平台永久存在；但这并不意味着应把私人同学资料全部公开备份。正确目标是用户自己可控的导出、备份与隐私最小化，而不是考古者替别人重公开青春档案。

## 9. 海外对照：这些机制并不只属于中国校园 SNS

### 9.1 The WELL：Web 以前的在线共同体已经能延伸到工作、家庭和死亡

The WELL 官方资料称其创立于 1985 年。[11] 2005 年《San Francisco Chronicle》回顾其二十年历史时，采访到长期成员：线上认识的人后来会在线下见面、互相介绍工作，也会分享孩子出生、参加成员葬礼，甚至有人相识后结婚。[12]

这是一个高度选择性的湾区社群，规模和人口结构都不能与中国高校 SNS 直接类比。

但它证明：

> **“线上关系跨越工作、婚姻、育儿和几十年生活阶段”并不是 WWW 或 2000 年代中国 SNS 才出现的结构。**

### 9.2 Classmates.com：按学校和旧姓名寻找失联同学同样是 1990s Web 的早期需求

CBS News 2003 年对 Classmates.com 的报道记录，该服务源于 1995 年的“找回旧同学”需求；报道还讲述有人按旧姓名搜索、发邮件，二十多年后重新见面的个案。[13]

同样不能从网站会员数推成美国普通人普遍如此生活，但它说明“学校/年份/旧姓名作为关系检索键”是跨国的 Web 早期形态。

中国更具特色的部分，不是“人类忽然想找老同学”，而是：

- 班级/年级目录与门户、QQ、WAP/SMS 的具体结合；
- 高校实名 SNS 在大规模高教扩张时期与青年同龄人生活脚本重叠；
- 之后关系迅速迁入 QQ/微信等更强的即时通信渠道。

## 10. 它改变了我们对“人怎么活着”的哪一点理解

过去的生活史很容易把毕业写成一个节点，然后分别研究就业、婚姻、住房。

这条材料显示，毕业以后还多了一条很重要但不显眼的基础设施：**你是否持续看见与你同龄、同校、同班的人正在怎样生活。**

它至少改变五件事：

1. **迁移不再必然等于关系永久断裂**：旧同学可以跨城重新寻址；
2. **标准人生脚本有了实时同龄人样本**：工作、跳槽、婚姻、生育、住房不只由父母和媒体告诉你“应该怎样”；
3. **弱关系可以保存未来路线**：几年不联系的校友仍可能成为职业、城市或信息入口；
4. **关系维持与平台使用不是一回事**：班级可以离开某平台继续活；
5. **生活记忆出现新的基础设施风险**：人际关系保存下来，过程记录却可能随平台消失。

因此，一条更准确的现代生命历程模型应加入：

```text
离校
→ 关系重新寻址
→ 同龄人生活持续可见
→ 比较/信息/求助
→ 关系迁移到新渠道
→ 平台衰退
→ 人际连续性与记忆连续性分叉
```

## 11. 证据等级、反例与后见之明风险

### 较强证据

- 1990 纸质校友通讯录的书目信息：机构/出版物证据；
- 2004 多种在线同学录的同期用户操作记录：B；
- 2008 校内网扩展校友/白领查找的同期媒体报道：B；
- 2009 校友录生活使用：B，同期媒体中的第一人称/人物叙述；
- 2019 人人回归与老用户态度：B，同期报道；
- 2020 北大云聚：A/B，校友组织同期记录；
- 2024 人人网资料可恢复性与老用户回顾：B，当前事件报道 + C 性质的历史回忆。

### 反例

- 2009 小杨的班级页面从每日活跃变成数月不更新：平台存在不等于关系仍在这里发生；
- 2019 老用户能够找回账号，也可能不想重新进入旧关系；
- 2024 一些旧同事仍通过微信群联系：旧平台衰退不等于关系死亡。

### 后见之明风险

不要写：

- “人人网让一代人变得攀比”；
- “有同学录就不会失联”；
- “一个平台关闭就把所有关系一起毁掉”；
- “2009 年照片流里可见的人生节点就是当年所有青年共同的标准脚本”；
- “校友网络天然公平、只要有校友就能获得工作机会”。

## 12. 尚未确定与下一步

1. 仍缺少 1999–2002 普通用户从纸质通讯录/Email/QQ 真正迁入 ChinaRen/5460 的同一个人多时点原生链；
2. 仍需要更强的原始资料确定不同平台的班级创建、加入审核、成员可见范围和数据导出规则版本；
3. 2015–2019 “拥堵型未来”还需要更多**同期**而不是后来回忆的普通用户材料，尤其是看到同龄人买房、结婚、考研/考编时如何调整自己的计划；
4. 2023–2026 还需要研究普通人是否真的形成“主动导出/备份青春资料”的行为，而不能从一次平台故障直接推导普遍 archive awareness；
5. 最有价值的纵向链仍是：同一个班/同一个普通人 `纸通讯录 → 校友录 → QQ/人人 → 微信群 → 某次职业或家庭节点重新激活旧关系`。
