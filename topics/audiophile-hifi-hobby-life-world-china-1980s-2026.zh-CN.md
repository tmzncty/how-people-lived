# 从客厅音箱到个人音频：Hi-Fi、发烧友与兴趣生活世界（中国，1980s—2026）

> 研究问题：一名普通人为什么会把并非生存必需的钱、房间、周末和技术注意力投入“声音更好一点”这件事？这种生活在 Internet 以前怎样获得知识、器材和同好；中文 Web 到来以后又真正改变了什么？
>
> 本题不是高级音响器材史，也不把“发烧友”当成一代人的统计平均。它把深度玩家当作一种高可见度剖面，用来观察 **discretionary life / 可支配生活**：工资剩余、住宅空间、连续时间、维修能力、信息网络和家庭协商如何共同决定一种兴趣能否持续。

## 1. 先拆状态：拥有音响 ≠ “发烧”

至少区分：

```text
家中有收音机 / 录音机 / 组合音响
→ 会主动听音乐
→ 开始比较音质
→ 阅读技术/器材资料
→ 为更好声音专门购买或制作器材
→ 学会搭配、摆位、维护、试听
→ 反复升级 / DIY / 交换 / 购买唱片
→ 进入同好网络
→ 形成稳定听音时间与空间
→ 可能自称 / 被称为“发烧友”
```

固定边界：

- `音响产品销售量 ≠ 发烧友人数`；
- `家庭影院普及 ≠ Hi-Fi hobby 普及`；
- `高端展会观众 ≠ 高端器材拥有者`；
- `论坛注册 ≠ 器材拥有 ≠ 实际长期聆听`；
- `器材价格高 ≠ hobby 对个人更重要`；
- `一位顶级玩家的系统 ≠ 普通工薪烧友预算`；
- `音质话语很多 ≠ 技术结论已经客观一致`。

这条线研究的是 **hobby executability / 爱好可执行性**：一个人是否真的有钱、空间、知识、时间和供应链把“喜欢音乐”转成持续的器材/聆听实践。

## 2. Web 前基线：发烧文化已经有成熟的信息基础设施

### 2.1 不能把音响论坛写成“发烧友圈”的起点

国家图书馆 ISSN 中国国家中心记录《高保真音响》ISSN `1006-0839`；山东大学图书馆的期刊/非书资料系统将该刊出版起点标为 **1994-**，主办/出版关联人民邮电出版社。

来源：

- 国家图书馆 ISSN 中国国家中心：<https://www.nlc.cn/web/yejiefuwu/newtsgj/newissn/cxissn/qkmcx/20101118_11463.shtml>
- 山东大学图书馆非书资料系统：<https://dnlib.wh.sdu.edu.cn/multimedia/DiskShow18562.html>
- ISSN 国际中心：<https://portal.issn.org/resource/ISSN/1006-0839>

证据等级：**A/B（机构连续出版物元数据）**。这些资料能可靠证明刊名、ISSN 与 1994 起的出版记录；不能单独证明发行量、读者结构或普通家庭拥有率。

维普现行期刊资料显示，该刊内容长期覆盖器材原理、选购、搭配、使用和自制，并包含“摩机土炮”“市场消费”等典型 hobby 栏目。

来源：<https://www.cqvip.com/journal/47663/47663/2009>

这至少说明 1990s 中期已经存在一种全国发行的专业知识接口：

```text
厂商 / 海外器材信息
→ 专业编辑与作者
→ 杂志评测、原理、DIY、唱片评论
→ 读者在本地商店 / 家庭中实践
```

Internet 后来改变传播速度和互动性，但不是从零创造“器材知识共同体”。

### 2.2 广州：广播、报纸、商店与展会形成地方发烧生态

2011 年《羊城晚报》回顾广州音响唱片展时称，该展创办于 **1994 年**，其脉络连接到广东电台音乐之声 1991 年开播的“音响世界”节目；报道把节目、器材介绍、发烧录音和后来音响展联系起来。

来源：<https://news.sina.com.cn/o/2011-09-05/145923107995.shtml>

证据等级：**C/B（后来的媒体回顾，含明确机构与时间线）**。它适合建立候选谱系，但下一轮仍应追 1991—1994 同期节目表、报纸版面和首届展会广告。

这个谱系重要之处不是“广州最早”，而是它揭示前 Web hobby 的一套完整空间网络：

```text
周末广播节目
+ 报纸音响版
+ 专门商店 / 试听
+ 本地发烧友口碑
+ 年度展会
→ 一个城市里可持续的兴趣生活世界
```

知识不是随时搜索获得，而是有节目时刻、报刊周期和必须亲自到场的试听地点。

## 3. 1990s 的消费扩张不能直接等同于发烧文化大众化

1999 年《生活时报》转新华社的市场报道估计，当年中国“家庭影院”市场容量约 **260 万台（套）**，并描述当时较常见的组合为大屏幕彩电、VCD 与适当音响设备。

来源：<https://www.gmw.cn/01shsb/1999-01/18/GB/863%5ESH10-105.htm>

证据等级：**B（同期行业/媒体材料）**。

它能说明音视频设备进入家庭的市场正在扩大，却不能据此写：

```text
260 万套家庭影院
= 260 万 Hi-Fi 发烧家庭
```

相反，这里应保留一个关键分层：

```text
大众家庭影音消费
↕
较深度的器材比较、搭配、DIY 和听音实践
↕
极高投入的 Hi-End 系统
```

三者共享供应链，但不是同一个人口。

同年关于 DVD 的报道又指出，高画质/高音质体验并非只需买一台 DVD，往往还要同步升级电视、音箱等配套设备，单高清电视就可能达到万元级。

来源：<https://www.gmw.cn/01shsb/1999-06/06/GB/1001%5ESH6-611.htm>

这很好地说明 **system hobby / 系统型爱好** 的特征：真正的成本不是某一件器材标价，而是多件设备之间的互相牵引。

## 4. Hi-Fi 特别依赖住房：声音爱好会占用真实的房间

与耳机不同，传统双声道系统不是“买回来就完成”。它通常要求：

- 左右声道间距；
- 听音距离；
- 音箱离墙；
- 相对固定的座位；
- 可接受的音量；
- 器材架、唱片架和线材；
- 家人愿意让出一部分共享空间。

因此应增加一个 **acoustic space budget / 声学空间预算**。

这不是纯技术参数，而是住房史变量：

```text
同一对音箱
在独立客厅 / 单身宿舍 / 合租房 / 婚后家庭客厅
具有完全不同的可执行性
```

目前仓库已有 1985—2005 中国住房面积、家庭耐用品与收入数据，可以在后续轮次把音响价格和住房空间放进同一张表，避免只写“器材越来越好”。

## 5. 2001—2005：中文 Web 把“听感、改机与器材”变成持续可搜索的文本

### 5.1 HIFI168：今天仍能看到一批早期历史帖，但要区分 live legacy page 与历史 capture

非常发烧网 / HIFI168 今天仍有论坛页面承载 2003 年日期的旧帖。例如一个现存页面 `showtopic-40621.aspx` 中，用户在 **2003-11-23** 讨论 BOSE，并在正文中回忆十年前在广州实体商店试听，以及近期去广州音响商圈试听 LINN。

当前 legacy page：<https://mail.hifi168.com/bbs/showtopic-40621.aspx>

这个对象对生活史很有价值，因为它同时出现：

```text
线下商店试听记忆
→ Web 论坛公开写听感
→ 品牌比较
→ “中毒”等圈内语言
```

但证据必须精确标注为：

**current live legacy page carrying a post dated 2003 / 今天仍在线、承载 2003 日期内容的遗留页面**。

它不是本轮已验证的 2003 Wayback/WARC capture，因此不能用来确定当年 DOM、CSS、Discuz!/ASP 版本、字符集、头像、签名或页面布局。

### 5.2 从“本地认识一个高手”变成“全国很多陌生人都留下听感”

论坛带来的变化不是简单的“信息更多”，而是经验开始具有持续可检索性：

```text
试听某台机器
→ 写帖子
→ 他人引用/反驳
→ 多年后搜索品牌/型号仍可能找到
```

这使 hobby knowledge 从大量口头、本地、一次性经验，部分转成 **searchable accumulated peer knowledge / 可搜索的累积同好知识**。

同时也产生新的偏差：

- 擅长写长帖的人比沉默玩家更可见；
- 版主精华、热门帖比普通失败经验更容易存活；
- 商家、媒体、玩家身份可能混杂；
- 主观听感会在群体中形成术语，但术语一致不等于测量一致。

## 6. 2004：PC Hi-Fi 说明爱好开始从“大客厅系统”向桌面迁移

2004 年中关村在线转载 Soomal 的年度声卡盘点时，将 DiyEden 描述为音频发烧友组织，并介绍其外置 USB DAC、真空管声卡/耳放等产品；同年的音箱报道则明确讨论“电脑音频发烧友”、300—3000 元价位的中高档 2.0 音箱，以及论坛/媒体围绕器材产生的争论。

同期来源：

- 2004 声卡盘点：<https://sound.zol.com.cn/2004/1224/138651.shtml>
- 2004 2.0 音箱市场：<https://sound.zol.com.cn/2004/1224/138662.shtml>
- DiyEden 真空管 USB 声卡拆解：<https://diy.zol.com.cn/2004/0921/121348.shtml>

证据等级：**B（同期专业科技媒体/转载）**。

这里发生的生活变化比“声卡变好了”更值得记录：

```text
传统客厅 Hi-Fi
需要较大空间和独立音源

PC Hi-Fi
电脑已经是学习/工作/上网设备
+ USB / 声卡 / 桌面音箱 / 耳机
→ 兴趣可以嵌进书桌
```

这可以称为 **hobby-space compression / 兴趣空间压缩**。

它让一些原本难以在宿舍、合租、小房间执行的“发烧”实践，变成桌面级版本。

2008 年“桌面 Hi-Fi”产品报道已经把“近近的听、静静的听”作为明确产品理念，恰好说明听音距离、功率和住宅尺度开始成为产品设计语言。

来源：<https://tech.sina.com.cn/h/2008-04-14/0600631035.shtml>

## 7. 2005—2012：扩张型未来里的 hobby 不是一条消费升级直线

### 7.1 高端系统证明“有人能这样活”，不能证明普通发烧友都这样活

2008 年《常州日报》家访一名外贸公司白领李强。报道将他描述为全国音响论坛中的活跃人物，其家中使用定制音箱、高价线材、黑胶系统等大量高端器材。

来源：<https://news.sina.com.cn/o/2008-05-15/105313879433s.shtml>

证据等级：**B（同期媒体家访 + 第一人称/现场观察）**。

这个个案最重要的用途不是证明“2008 白领很有钱”，而是建立 hobby life world 的上限形态：

- 客厅可以被重构为听音室；
- 器材采购跨越国内外代理；
- 论坛声望与线下器材经验互相增强；
- 个人身份在工作之外形成另一套公开声望。

它属于典型 **enthusiast visibility bias**，必须与工薪级玩家分开。

### 7.2 展会像“临时公共试听室”

2008 广州音响唱片展有 129 家公司、140 多个展厅，展出大量音响和唱片；报道同时突出售价极高的展示器材。

来源：<https://ent.sina.com.cn/x/2008-11-28/14212271362.shtml>

展会的生活意义不只是商品展销：

> 即使一个人不拥有一套顶级系统，她仍然可以用门票和一天时间获得一次短暂的高端试听。

因此应区分：

```text
ownership access
service / event access
```

和博物馆、网吧、公共图书馆类似，某些 hobby 体验可以通过公共/商业场所获得，而不需要家庭拥有。

## 8. 2015—2019：器材仍在，但“能放得下、能安静听多久”越来越重要

2018 年《视听前线》“工薪阶层发烧友”家访明确把高端器材称为大量普通爱好者只能仰望的“理想之梦”，并把真正广泛构成圈子的主体定位为购买入门和中坚产品的工薪阶层。

来源：<https://www.sohu.com/a/274534210_282773>

证据等级：**C/B（行业媒体的同期家访系列）**。它不能给出全国发烧友收入分布，但非常适合纠正“发烧 = 豪宅 + 百万元系统”的媒体可见性偏差。

2019 广州音响唱片展仍然连续举行，说明传统大系统和线下试听文化并没有被手机、流媒体完全替代。

来源：<https://m.zol.com.cn/article/7344572.html>

因此这一时期更适合提出而不是先下结论：

- 城市住房价格和租住生活是否压缩大系统 hobby；
- 桌面、耳机和小型有源音箱是否吸收了一部分原来的需求；
- 论坛衰落、微信群和内容平台兴起后，知识是否从“可公开搜索的长帖”转向更难保存的半私密流；
- 家庭育儿和加班是否使连续听音时间比器材本身更稀缺。

这些问题下一轮需要更多同时代第一人称证据。

## 9. 2020—2022：家庭内 hobby 与场地型 hobby 的疫情效应可能相反

Hi-Fi 是非常适合做疫情反事实的兴趣：

- 器材已经在家的玩家，理论上可能得到更多家庭内聆听时间；
- 但音响展、串门试听、实体店和跨城活动可能中断；
- 新器材仍依赖物流和供应链；
- 家庭成员同时长期在家，又可能让大音量试听更难。

本轮没有找到足够强的 2020—2022 同时代个人样本来判断哪一项更占主导，因此不强行写成“疫情促进宅家 Hi-Fi”。

这作为明确 research gap 保留。

## 10. 2023—2026：个人音频进一步把发烧从“占一个客厅”拆成“占一个头部空间”

2025 年 CanJam Shanghai 官方页面显示，展会聚焦 headphone / personal audio，参展设备价格跨度从约 **50 美元耳塞到 50,000 美元耳机系统**，有 100 多个品牌、2 万平方英尺展区。

官方来源：<https://canjamglobal.com/shows/shanghai2025/>

Head-Fi 的同期活动帖还保留上海展的门票、酒店、志愿者与论坛 badge 等信息，显示在线社区与实体展会仍然紧密连接。

来源：<https://www.head-fi.org/threads/canjam-shanghai-2025-event-impressions-thread-june-14-15-2025.976304/>

这能窄地支持一个长期空间变化：

```text
大客厅双声道系统
→ 书桌 PC Hi-Fi
→ 便携播放器 / DAC / 耳放
→ 高端耳机个人音频系统
```

它不是“耳机取代音箱”的线性故事，而是 **hobby form factor diversification / 兴趣形态尺寸分化**：

- 有房间和预算的人仍可玩大型系统；
- 租房、合住、夜间使用者可以把同样的“比较音质”实践压进耳机；
- 同一个人也可以同时拥有客厅系统与个人系统。

所以技术进步有时不是让 hobby 更便宜，而是让它对不同住宅和日历更兼容。

## 11. 二手市场：升级欲之所以能长期循环，也因为旧器材可以重新流动

Hi-Fi 常被写成“不断买新器材”，但真正的预算模型应该是：

```text
旧器材残值
+ 二手成交速度
+ 新器材追加现金
= 一次升级的实际资金压力
```

因此二手论坛、交易区和后来的闲置平台属于 hobby infrastructure，而不是外围商业。

它影响：

- 入门能否买到停产/旧器材；
- 试错是否可逆；
- 大件搬家前能否快速退出；
- 一件设备是否成为可流动资产，而不是永久沉没成本。

当前仓库已有 secondhand circulation 专题；Hi-Fi 下一轮应专门找 2001—2015 论坛二手区和实际成交/中介规则的历史证据。

## 12. “听感”是知识，也是社群问题

Hi-Fi 比很多 hobby 更容易产生一种特殊知识结构：

```text
可测量参数
+
房间/摆位/搭配
+
个人听觉与音乐偏好
+
同好语言
→ 听感判断
```

Web 以后，同一器材会积累大量看似可比较的第一人称记录，但：

- 房间不同；
- 音源不同；
- 音量不同；
- 搭配不同；
- 购买后的确认偏差可能不同；
- 商业利益可能混入；
- 测量与主观词汇可能长期争论。

因此论坛不是“众包真相数据库”，而是 **peer-evaluation infrastructure / 同行评价基础设施**。

研究时应保存争论本身，而不是替历史参与者裁定谁“听得对”。

## 13. 海外对照：Hi-Fi hobby 早于 Web 很久，而且同样依赖杂志、邮购、DIY 与专门商店

美国 1960 年《HiFi/Stereo Review》原刊扫描中，可以直接看到 Heathkit 家庭立体声套件、唱机、调谐器等广告与价格；套件把“购买成品”之外的 DIY 路线做成大众商品。

原始扫描：<https://www.worldradiohistory.com/Archive-All-Audio/Archive-HiFI-Stereo/60s/HiFi-Stereo-Review-1960-12.pdf>

证据等级：**A（同时代原刊 PDF）**。

1970 年代美国《The Audio Amateur》则围绕自行制作音频设备、晶体管学习、套件厂商等形成完整专业 hobby 媒体。

档案目录：<https://cc-webshop.com/collections/archive-cds-audio-1/products/the-audio-amateur-1970-79>

英国 `What Hi-Fi?` 1976 年创刊时定位就是家庭 Hi-Fi 设备的购买/价格/评测指南，说明面向消费者的器材比较文化同样早于 Web。

来源：<https://www.whathifi.com/features/was-then-first-issue-what-hi-fi>

跨国共同机制因此不是“中国 1990s 才发明发烧友”，而是：

```text
工业化消费电子
+ 家庭电力与住宅
+ 唱片/广播音乐
+ 专业零售
+ 杂志/目录/DIY 知识
→ 可以长期投入的 home audio hobby
```

中国案例的具体差异应继续研究收入、进口/国产器材、广州等市场节点、住房和 1990s 消费电子扩张，而不是用“西方早几十年”代替解释。

## 14. 这条 hobby 改变了我们对“人怎么活着”的哪一点理解

标准生命史通常会写：

```text
毕业 → 工作 → 结婚 → 买房 → 生育 → 退休
```

Hi-Fi 提醒我们，在这些大节点之间还存在另一条不一定进入人口统计表的时间线：

```text
第一次在别人家听到好系统
→ 攒钱买第一对音箱
→ 每月买杂志和唱片
→ 周末跑音响店试听
→ 学会焊线 / 换管 / 摆位
→ 论坛认识一批只聊声音的人
→ 换工作后升级
→ 结婚后重新协商客厅
→ 生孩子后几年很少开大声
→ 换小系统 / 耳机
→ 中年或退休重新搭一套
```

它可能从未成为职业，也不决定婚姻状态，却真实占据了几十年的夜晚、工资和房间。

因此 Hi-Fi 的意义不只在“90 年代流行过一种昂贵电器”，而是证明：

> **当一个社会开始出现越来越多可以长期投入的 hobby，生活的内容也开始从“完成必须事项”向“维护一个自己愿意反复返回的小世界”扩张。**

## 15. old-Web companion：下一步要验证什么

旧网侧不要写音响产业史，只追 2001—2015 中文 Web 怎样承载：

```text
论坛首页 / 版块
→ 器材讨论帖
→ 引用与回复
→ 图片/附件
→ 用户等级与长期昵称
→ 搜索
→ DIY 图纸 / 测量 / 改机
→ 二手帖 / 中介
→ 私信/QQ/电话 handoff
→ 线下试听 / 交易
→ 成交 / 实际拥有
```

候选对象：

- HIFI168 / 非常发烧论坛；
- 耳机大家坛 `erji.net`（公开资料称 2002 年成立）；
- DiyEden / Soomal 早期 PC Hi-Fi 内容；
- 厂商论坛和音频频道；
- 论坛二手交易区。

必须继续区分：

```text
post exists ≠ author owned device
classified exists ≠ deal occurred
reply count ≠ number of distinct listeners
old thread visible today ≠ verified historical DOM
forum account age ≠ uninterrupted participation
```

## 16. Research gaps

### 已知

- 1990s 中期已有全国专业 Hi-Fi 期刊；
- 广州在 1990s 已形成广播/媒体/展会等发烧文化节点；
- 1999 家庭影音市场已经相当大，但不能等同于发烧人口；
- 2003 年日期的 HIFI168 历史内容今天仍有 live legacy page；
- 2004 前后 PC Hi-Fi、USB DAC/声卡和桌面 2.0 已成为明确专业媒体对象；
- 2008 同期媒体能观察到高投入玩家、音响展和桌面 Hi-Fi；
- 2018 仍有专门的工薪发烧友家访；
- 2025 上海个人音频展显示 headphone/personal audio 已形成成熟全球 hobby 市场的一部分。

### 可以合理推断

- Internet 扩大了器材经验、DIY 和二手交易的可搜索半径；
- PC / 桌面 / 耳机降低了传统大系统对家庭空间和噪声条件的依赖；
- 发烧文化的主要稀缺可能从“有没有信息”逐渐转向可信度、时间、空间和预算协调。

### 仍不知道

- 1990s 各收入层发烧友真实支出分布；
- 1990s 广州、北京、上海典型器材价格 / 工资比；
- 女性发烧友、学生、工人、非一线城市玩家的可见度到底多低；
- 结婚、生育和搬家对系统缩小/退出的频率；
- 2020—2022 疫情对家庭 Hi-Fi 实际使用时间的净效应；
- 论坛向微信群/短视频迁移后，知识保存率如何变化；
- 早期论坛二手交易有多少真正成交；
- 当前保存的 2001—2005 页面中哪些能达到 old-Web M1 transaction capture 门槛。

## 17. Evidence / hindsight risks

1. **不要把顶级系统当平均值。** 媒体天然爱拍最夸张的房间和价格。
2. **不要把男性公开论坛当全部兴趣人口。** 公开可见性本身有性别和职业偏差。
3. **不要把“以前的人更专注”浪漫化。** 过去也有工作、家庭、空间和信息限制。
4. **不要把耳机写成音箱的必然终点。** 两者长期共存，并服务不同场景。
5. **不要把论坛热帖当真实拥有率。** 很多人只是围观、梦想、借听或讨论买不起的器材。
6. **不要把 Web 说成知识起点。** 杂志、广播、商店、展会和本地高手早已构成知识网络。
7. **不要把当代“复古黑胶”直接投射回 1990s。** 不同年代的载体、价格、文化含义可能完全不同。
