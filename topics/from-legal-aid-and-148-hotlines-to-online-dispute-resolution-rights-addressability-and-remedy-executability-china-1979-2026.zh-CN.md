# 从减免费法律帮助与 148 热线到在线解纷：权利可寻址性、证据储备与救济可执行性，中国 1979–2026

## 研究问题

普通人“有一种权利”，和普通人**真的能拿这项权利改变自己的生活**，是两件不同的事。

一份劳动合同、一条工伤待遇、一项住房或消费权利可以已经写进法律；但一个真实的人遇到事情以后，仍然要连续回答：

- 这是不是一个法律问题？
- 应该找谁？
- 电话、窗口、网站、仲裁还是法院？
- 我有没有资格申请法律援助？
- 需要保存什么证据？
- 什么时候会过时？
- 线上咨询到底只是意见，还是已经进入正式程序？
- 即使赢了，钱或其他救济最后有没有真正到手？

本专题把这组能力称为 **rights addressability（权利可寻址性）** 与 **remedy executability（救济可执行性）**。

它关心的不是抽象法条史，而是一个生活史问题：

> **当一份工作、一次受伤、一笔工资或一个家庭安排出了问题，一个普通人是否拥有一条现实可走的“退出、索赔、纠正或重新开始”的路？**

这条路可以改变人生选择的可逆性。一个人如果只能吞下损失再离开，和一个人能保存证据、找到援助、仲裁或诉讼、拿回工资以后再换工作，面对的是完全不同的未来菜单。

## 一、先拆状态：有权利 ≠ 能获得救济

本专题使用下面的最小状态链：

```text
损害 / 争议 / 不确定性真实发生
→ 当事人意识到它可能具有法律意义
→ 找到正确的求助入口
→ 咨询真正接通 / 问题被受理
→ 获得可理解的法律信息
→ 判断是否需要正式程序
→ 保存并组织证据
→ 满足资格、时效与程序条件
→ 法律援助 / 调解 / 仲裁 / 诉讼申请提交
→ 申请被受理
→ 获得代理或进入程序
→ 作出调解 / 裁决 / 判决
→ 决定可执行
→ 工资、赔偿、复职或其他救济真正发生
```

必须长期保留这些状态差：

- `law exists != person knows it`
- `person knows harm != person knows the legal category`
- `hotline called != call answered`
- `question submitted != professional reviewed`
- `legal advice received != formal legal-aid application`
- `legal-aid application != eligibility approved`
- `lawyer assigned != claim won`
- `evidence exists != evidence preserved`
- `evidence uploaded != evidence authenticated / admitted`
- `case filed != case accepted`
- `judgment / award != money actually paid`

这比“有没有线上法律服务”更适合普通生活史。

## 二、互联网以前：法律帮助已经存在，但“找得到谁”本身就是基础设施问题

### 1. 1979 以后：减免费帮助存在，不等于形成统一入口

司法部法律援助中心后来整理的制度史指出，1979 年恢复律师制度以后，律师行业已经存在为经济困难当事人减、免收费的实践；但把“法律援助”作为一项全国性制度明确提出，是 1994 年初，此后北京、广州、上海、武汉、郑州等地逐步试点。

这里不能把后来制度史写成 1979 年普通人已经拥有统一、稳定、全国可用的法律援助系统。它只能证明：

1. **付不起律师费的人获得低费或免费帮助，并非互联网时代才出现；**
2. 早期真正的问题之一，是这种帮助分散在律师事务所、司法行政机构和地方试点中，普通人未必知道入口在哪里。

**证据**

- **B/C（司法部法律援助中心制度史整理，2019）**：1979 年恢复律师制度后存在减、免收费帮助；1994 年初明确提出建立法律援助制度并展开试点。  
  <https://www.moj.gov.cn/pub/sfbgw/jgsz/jgszzsdw/zsdwflyzzx/flyzzxzcxx/zcxxfyzl/201906/t20190624_188956.html>
- **B（全国政协资料，2002）**：1994 年初提出制度设想，至 2000 年已形成大量省、市、县级法律援助机构。  
  <https://www.cppcc.gov.cn/2011/10/27/ARTI1319707908609687.shtml>

### 2. 1994 不是“互联网带来法律援助”的起点

1994 年同时是中国全功能接入 Internet 的重要年份，但法律援助制度的提出是另一条制度史线索。两者时间接近，不能据此建立因果关系。

这正是本仓方法需要保留的边界：

> **institutional opening != digital opening**。

一个人能否获得法律帮助，首先取决于制度是否存在、费用与资格是否可承受、服务在不在本地；之后才轮到网站、电话或移动网络降低寻找和提交的摩擦。

## 三、1998–2003：148 / 12348 把分散机构压缩成一个“法律路由器”

### 1. 148 的真正变化不是“电话咨询”，而是机构复杂度开始向后台移动

1999 年 6 月的《光明日报》同期报道记录：山东东明县司法局于 1998 年 3 月 16 日开通 148 法律服务专用电话；到 1999 年中，全国地级、县级建制的平均开通率分别约 39.1% 与 64.6%，而仍有 11 个省区市开通率不足一半，4 个不足 20% 或尚未开通。

这条材料非常重要，因为它同时证明两件事：

- 148 已经从地方试点变成全国推广的法律服务入口；
- **全国推广 ≠ 全国同时可用**，地域差异仍然很大。

同期司法部门对 148 的解释也很具体：过去律师、公证、基层法律服务等入口分散，148 试图把它们“集中起来”，让普通人不必先知道具体机构内部结构。

本专题把这种入口称为 **legal router（法律路由器）**：

```text
普通人只知道“我遇到一个涉法问题”
→ 拨一个短号码
→ 后台判断它属于咨询 / 公证 / 法援 / 调解 / 其他渠道
→ 再把问题路由到真正能处理的人或机构
```

**证据**

- **B（同期新闻，光明日报 1999-06-22，新浪保留）**：148 起源、全国开通率与地区差异。  
  <https://news.sina.com.cn/china/9906/062213.html>

### 2. 一个统一号码仍然需要地方网络真正建成

上海的法律服务热线 1999 年初运行，到 2002 年 1 月改用全国统一号码 12348；当地律师协会同期资料记录，三年里接答来电 29 万余个、提供法律援助 1600 余件、解决纠纷 2300 余件。

广州则在 1999 年 6 月开通当地热线，到 2003 年 12 月改为 12348；同期报道记录此前累计来电来访 77,552 人次。

这些数字不能相互直接比较绩效，因为统计窗口、人口规模与业务口径不同。它们更适合证明：

> **统一命名是一个状态，地方真实接通、人员配置和案件转办能力是另一个状态。**

**证据**

- **A/B（上海律师协会转载同期文件，2002-01-09）**：16000148 转为全国统一 12348。  
  <https://www.lawyers.org.cn/info/b315d368a80d4f2283a0cb882c397f90>
- **B（南方日报同期报道，2003-12-01，新浪保留）**：广州 148 改 12348 与累计咨询统计。  
  <https://news.sina.com.cn/c/2003-12-01/10121224642s.shtml>

## 四、2003–2012：从“能拨通”到“能把文书和证据一起送过去”

### 1. 早期 Web 没有替代热线，而是叠在它上面

北京市司法局后来的 25 年工作史记录：1999 年设 148 办公室，2003 年起群众可以通过**网络、电话、现场**三种方式咨询；2005 年全年咨询量首次突破 10 万人次。

这类机构回顾不能单独证明 2003 年网页的 DOM、浏览器要求或每项功能细节，但足够确认一个制度转折：

```text
一个窗口 / 一个电话
→ 现场 + 电话 + Web 并行
```

**证据**

- **B/C（北京市司法局机构史）**：北京 12348/148 演变。  
  <https://sfj.beijing.gov.cn/sfj/sfdt/ywdt82/flfw93/325875591/index.html>

### 2. 2004–2009：远程法律咨询开始携带音频、视频和文件

2004 年《大连晚报》的同期报道已经出现利用网站进行音频、视频法律咨询的商业服务尝试。这里不能把商业演示当成大众采用率，但它证明“远程咨询”当时已经不只等于文本留言。

2009 年北京宣武司法局开通 148 网络视频咨询时，记者现场记录的新增能力更清楚：

- 咨询者与律师视频交流；
- 可以传送法律规定和文书格式；
- 咨询者可以展示证据材料；
- 律师可以初步判断证据是否有用、还缺什么。

这使电话时代最难远程处理的一块——“你手上那张纸到底是什么”——开始进入网络通道。

**证据**

- **B（同期新闻，大连晚报 2004-12-27，新浪保留）**：网上音视频律师咨询演示。  
  <https://news.sina.com.cn/s/2004-12-27/01534634193s.shtml>
- **B（同期新闻，中国广播网 2009-06-19，新浪保留）**：北京首个 148 网络视频咨询、文件传输与证据初判。  
  <https://news.sina.com.cn/c/2009-06-19/151115818205s.shtml>

### 3. 2009 同时代第一人称：知道“不给工资不对”，仍然可能不知道怎样把它变成一项可执行主张

2009 年《法制日报》采访的 60 多岁农民工刘永其说，自己干了活却拿不到钱，家里还等着钱办年货；法律援助律师反复强调欠条、工资条、工资卡、考勤记录、对工单等证据必须保存。

这不是一个“互联网改变一切”的材料。恰好相反，它提醒我们，在扩张阶段最基础的 **remedy friction（救济摩擦）** 仍然可能是：

- 不知道该找谁；
- 不知道哪种材料以后会成为证据；
- 人已经准备返乡，争议地却在另一个城市；
- 家庭急需现金，正式程序又需要时间。

**证据**

- **B/T1（同期采访，法制日报 2009-01-15，新浪保留）**：农民工讨薪与证据保存。  
  <https://news.sina.com.cn/o/2009-01-15/080515037302s.shtml>

这里形成了本专题的第二个核心概念：**evidence reserve（证据储备）**。

钱是未来选择的缓冲，证据也是。一个人今天保存工资卡、聊天记录、考勤、合同、照片，并不代表明天一定打官司；它首先是在保存一种以后“如果需要，我还能主张”的能力。

## 五、2005–2012 的“扩张型未来”：权利入口扩大，但并不意味着争议会自动消失

这一阶段可以把法律服务的扩张理解成一类新的可选性：

> 过去遇到纠纷可能只能问熟人、跑窗口或忍过去；现在电话、网页、视频开始让“先问一下”本身变得更便宜。

但扩张不能写成线性乐观史。

一个人要把“我觉得不公平”转成可执行 claim，仍然要完成：

```text
识别问题
→ 找对入口
→ 留证
→ 承担时间 / 交通 / 误工成本
→ 决定是否真的启动程序
```

所以这一阶段新增的不是“人人都更会维权”，而是 **claimability（可主张性）** 的上限提高：越来越多人拥有一种过去可能根本进不去的制度入口。

## 六、2015–2019 的“拥堵型未来”：从“找不到法律”转向“权利、时间、工作与再就业一起计算”

### 1. 2018：中国法律服务网把搜索、咨询、人员查询和办事进一步收进一张网络

2018 年 5 月 20 日，中国法律服务网正式上线运行。同期材料显示，它整合咨询、法律服务人员/机构查询、意见征集等功能；驻场人工服务团队 925 人，专家团队 70 人。网站允许用户留言咨询、跟踪进度，并提供部分在线办事指引。

这标志着“法律路由器”从电话号码进一步扩展为数据库和事务平台：

```text
不知道找谁
→ 搜问题 / 留言
→ 查律师或服务机构
→ 获取意见
→ 进入申请 / 办事指引
```

**证据**

- **A/B（2018-05-21，检察日报/最高检站）**：中国法律服务网正式上线。  
  <https://www.spp.gov.cn/spp/zdgz/201805/t20180521_379189.shtml>
- **B（北京青年报同期报道，中新网保留）**：留言咨询、个人中心跟踪、人工/智能咨询等功能。  
  <https://www.chinanews.com/gn/2018/05-21/8518433.shtml>

### 2. 但“网上有入口”没有消除现实救济的时间成本

2018 年苏州的法律援助报道显示，农民工可以通过 12348 法网、司法门户、微博微信和客户端进行网上申请、文书下载、咨询互动与“不见面审批”；同一报道也记录 16 名工人通过援助讨回拖欠半年、共 28 万元工资。

这说明网络可以压缩**申请和路由摩擦**，但真正拿到工资仍可能经过劳动仲裁、法院、执行与机构协调。

**证据**

- **B（法制日报 2018-01-27，人民网保留）**：苏州农民工法律援助与网上申请。  
  <https://legal.people.com.cn/n1/2018/0127/c42510-29790604.html>

### 3. 2019 同时代生命史：一项权利是否值得主张，会和“以后还找不找得到工作”一起计算

2019 年《工人日报》报道 56 岁农民工王大鹏：2015 年发生工伤后，公司支付医疗与部分费用，他却多年犹豫要不要继续索赔。报道记录的顾虑包括：

- 不懂相关法律；
- 没钱打官司；
- 担心程序太久耽误挣钱；
- 也担心主动索赔以后名声变“臭”、影响再就业。

直到 2019 年求助公共法律服务中心、获得法律援助后，他才最终取得一次性伤残就业补助、停工留薪期工资等共 6 万余元。

这条材料特别适合“拥堵型未来”。一个人不是只问“法律上我赢不赢”，而是同时计算：

```text
现在维权需要几个月？
+ 这几个月怎么赚钱？
+ 以后同一个劳动力市场还接不接受我？
+ 如果不主张，我今天少拿多少钱？
```

**证据**

- **B/T1（工人日报 2019-09-12，中新网/人民网保留）**：王大鹏工伤待遇与再就业顾虑。  
  <https://acftu.people.com.cn/n1/2019/0912/c67502-31350302.html>

所以：

> **rights on paper can coexist with a life in which exercising those rights is economically risky.**

纸面权利与现实可主张性必须分开。

## 七、2020–2022 的“偶发型未来”：远程法律服务从便利层变成程序连续性的 fallback

### 1. 2021：在线诉讼进入正式程序规则

最高人民法院 2021 年发布《人民法院在线诉讼规则》，自 8 月 1 日起施行。规则明确，当事人和其他诉讼参与人可以依托诉讼平台，通过互联网或专用网络在线完成全部或部分：

- 立案；
- 调解；
- 证据交换；
- 询问；
- 庭审；
- 送达等。

规则同时强调自愿适用、权利保障以及线上线下同等法律效力。

这和 2000s “网上问律师”是完全不同的制度层：

```text
online advice
!=
online formal procedure
```

**证据**

- **A（最高人民法院司法解释，2021）**：  
  <https://www.court.gov.cn/fabu/xiangqing/309551.html>

### 2. 2021 第一人称案例：咨询只有进入仲裁并兑现，才完成“建议→救济”

北京市 12348 公布的案例中，刘女士因拒绝加班被公司辞退，热线值班律师提示可以申请劳动仲裁并主张继续履行劳动合同、赔偿等。她随后确实申请仲裁，仲裁裁决继续履行劳动合同，并经协商获得 5 万元相关赔偿。

这个案例的价值不是证明“打 12348 都能赢”，而是完整展示了一条少见的可追踪链：

```text
问题
→ 热线咨询
→ 明确程序选择
→ 申请仲裁
→ 裁决
→ 协商支付
```

**证据**

- **A/B（司法部转载法治日报 2021-11-30）**：拒绝加班被辞退后的热线—仲裁—赔偿链。  
  <https://www.moj.gov.cn/pub/sfbgw/fzgz/fzgzggflfwx/fzgzggflfw/202111/t20211130_442736.html>

这使疫情及其前后阶段的数字化不能只理解成“少跑腿”。当现实窗口、跨城移动或面对面接触具有不确定性时，线上程序也成为一种 **institutional continuity infrastructure（制度连续性基础设施）**。

## 八、2023–2026 的“防守型未来”：未来不是“绝不会出事”，而是“出事时我还留着证据和入口”

### 1. 2023：“工作的证据我可都留着呢”

2023 年北京市西城区法院发布的新生代劳动纠纷案例中，一名 29 岁劳动者面对公司把 9 个月工作称作“实习”、拒付约定工资时，明确说自己把工作的证据都留着。

这当然不能代表所有年轻劳动者，但它与 2009 年律师反复教育农民工“工资条、考勤、对工单一定要留”的材料放在一起，非常有解释力：

- 2009 的材料重点是**事后才发现自己需要证据**；
- 2023 的材料出现了更明确的**事前/过程中的留证习惯**。

智能手机、聊天记录、电子工资记录等可能降低部分留证摩擦，但仍不能写成“有聊天截图就一定胜诉”。证据的真实性、关联性、完整性与程序要求仍是另一层状态。

**证据**

- **B/T1（人民法院报 2023-05-09，人民网保留）**：新生代劳动者主动留存工作证据。  
  <https://society.people.com.cn/n1/2023/0509/c1008-32681659.html>

这形成了 **evidence optionality（证据型选择权）**：

> 我今天不一定要起诉，但我不要让今天的沉默把明天的选择彻底关闭。

### 2. 2025：对平台劳动者，真正的防守型基础设施开始把多个机构重新捆回“一站式”入口

2025 年《工人日报》报道，一名外卖骑手受伤后因平台拒绝提供收入证明，保险理赔和民事赔偿受阻；他进入由工会、人社、司法等多个部门共建的权益保障服务中心后，通过三次调解，12 天解决原本按常规诉讼流程可能需要数月的争议。

这不是“云端取代法律”，而是成熟阶段的 **re-bundling（再捆绑）**：

```text
劳动关系 / 平台
+ 保险
+ 收入证明
+ 调解
+ 工会
+ 人社
+ 司法
```

普通人不必自己理解全部机构边界，服务中心承担部分路由与协调劳动。

**证据**

- **B/T1（工人日报 2025-06-10，人民网保留）**：新就业形态劳动者“云端解纷”案例。  
  <https://acftu.people.com.cn/n1/2025/0610/c67502-40497479.html>

### 3. 2025–2026：数字系统成熟以后，电话没有消失

北京市司法局公布的 2025 年 12348 数据显示：全年服务 152.41 万人次，其中电话服务 135.15 万人次，占 88.68%；智能服务占 11.32%。呼入总量约 223 万次，电话接通率 81.91%。

这些数据只代表北京 12348 的业务口径，不能推广到全国；但它足够否定一个简单的技术替代叙事：

> **网络、AI、App 成熟以后，电话仍可能是公共法律服务的主通道。**

对一个正在争吵、刚被辞退、不会操作复杂网站或只想先问一句“我该怎么办”的人来说，短号码的低认知负担仍然有价值。

**证据**

- **A（北京市司法局/北京市政府，2026-02-05，统计 2025 年服务）**：  
  <https://www.beijing.gov.cn/ywdt/gzdt/202602/t20260205_4493280.html>

## 九、四种未来的对照：法律服务改变的不是“会不会出事”，而是损失能否重新接回人生

| 时段 | 典型时间感 | 法律/通信基础设施的主要作用 | 仍然存在的瓶颈 |
|---|---|---|---|
| 2005–2012 扩张型 | 多一个入口就是多一种可能 | 热线、Web、视频让咨询和证据初判更容易到达 | 不懂程序、不会留证、地区覆盖和数字接入差异 |
| 2015–2019 拥堵型 | 权利、工作、住房、家庭和时间同时计算 | 全国/地方 12348 网络把查询、咨询和办事逐步整合 | 维权耗时、再就业顾虑、执行与支付仍在线下世界完成 |
| 2020–2022 偶发型 | 连“正常去窗口/开庭”都可能失去确定性 | 在线诉讼与远程服务成为制度连续性的 fallback | 技术接入、身份认证、证据、程序能力仍会制造差距 |
| 2023–2026 防守型 | 不假定不出事，而是预留退出和索赔能力 | 主动留证、一站式路由、多部门联动、线上线下冗余 | 平台劳动关系复杂、证明链仍长，数字化不能替代真正执行 |

这也修正了“防守型未来 = 只想要稳定”的过度简化。

另一种防守行为是：

> **我可以接受换工作、做平台劳动、租房或承担新的生活尝试，但我要尽量保存证明、合同、聊天记录和一个能找到援助的入口。**

这是一种以可退出、可索赔、可恢复为目标的风险管理。

## 十、海外比较：公共“法律/权利路由器”远早于 Web

### 1. 英国 Citizens Advice：1939 年开始，信息服务随社会危机改变问题类型

英国 Citizens Advice 的官方历史记录，1939 年战争爆发后首批 200 个 bureaux 开放，处理配给本丢失、无家可归、疏散、失踪亲属和债务等问题；1965 年全国咨询量达到 125 万，1970s 消费者保护成为重点，1980s 两次经济衰退又使贫困、债务和福利咨询增长。

曼彻斯特的地方史还记录：1970 年开始在 BBC Radio Manchester 固定播出信息栏目，1970s 使用便携式内部信息系统做社区外展，1981 年购买两台电脑计算 40 多类非缴费福利资格。

这说明：

- 普通人需要的并不是一本“完整法律百科”；
- 更重要的是在某次战争、失业、住房或福利变化发生时，**有一个能够识别问题并把它路由到正确制度的人和入口**；
- 计算机首先可以出现在后台，服务对象本人并不需要“数字自主”。

**证据**

- **A/C（Citizens Advice 官方历史）**：  
  <https://www.citizensadvice.org.uk/about-us/information/our-history/>
- **A/C（Citizens Advice Manchester 机构史）**：  
  <https://www.citizensadvicemanchester.org.uk/our-history>

### 2. 美国 Call For Action：广播 + 电话本身就是前互联网投诉网络

Call For Action 机构史记录，其 1963 年在纽约 WMCA Radio 起步，最初围绕住房问题建立全市电话转介系统，之后扩展到消费者投诉与调解，1969 年发展为全国网络。

这与中国 148 的相似之处，不是组织形式相同，而是底层问题相同：

```text
普通人只知道自己遇到麻烦
→ 一个媒体 / 电话入口把问题变成可分类记录
→ 工作人员识别应该找哪个机构或责任方
→ 转介 / 调解 / 追踪
```

**证据**

- **C/机构史（Call For Action）**：  
  <https://callforaction.org/call-for-action-history>

因此，“公共问题被一个短号码或公共信息机构路由”是现代城市社会的一种共同基础设施，不是 Internet 特有现象。

## 十一、什么是中国特有，什么更可能是现代社会的共同变化

### 更可能是共同变化

- 城市与劳动市场扩大以后，普通人越来越常与陌生雇主、房东、平台和机构发生契约关系；
- 权利文本增加以后，真正的瓶颈会从“有没有规则”转向“普通人能否理解、找到入口、保存证据并承担程序成本”；
- 电话、广播、数据库、Web 都可以充当权利路由基础设施；
- 数字化通常先降低信息与提交成本，再把问题推向认证、证据、责任划分和执行。

### 中国材料中尤其值得继续追踪

- 148 → 12348 的统一短号码怎样把律师、公证、法援、调解等司法行政资源重新组织；
- 农民工跨地区就业使争议地、户籍地、家庭和证据所在位置经常分离；
- 2010s 后实体、热线、网络“三平台”并行，而不是单一路径替代；
- 2020s 多部门“一站式”权益中心如何处理平台劳动、工伤、保险、收入证明等跨机构问题。

## 十二、重点矩阵：它改变“人怎么活着”的哪些部分

| 生活维度 | 本专题新增问题 |
|---|---|
| 教育 | 是否知道如何取得法律信息，是否需要专业语言能力 |
| 就业 | 工资、工伤、辞退争议能否真正进入仲裁/法援/法院 |
| 住房 | 租赁纠纷能否通过低成本入口获得判断与救济 |
| 婚姻家庭 | 家庭纠纷是否有可获得的咨询、调解和援助入口 |
| 迁移 | 人离开争议发生地以后，能否远程继续咨询、申请和参加程序 |
| 照护 | 工伤、残障、家庭责任会不会让长程序成本进一步放大 |
| 非正规劳动 | 无书面合同、现金工资、平台关系如何改变证明责任与留证劳动 |
| 长期中断 | 维权期本身可能成为工作中断；赔偿也可能决定能否重新进入生活 |
| 证件与记录 | 合同、工资卡、考勤、聊天、影像、身份证明、案号都是可执行性的组成部分 |
| 通信方式 | 现场 → 热线 → Web → 视频/文件传输 → 移动端 → 在线程序 |
| 信息获取 | “法条存在”与“我知道自己的问题属于哪条路径”必须区分 |
| 社交关系 | 亲友、工友、工会、社区和律师都可能成为桥接节点 |
| 未来预期 | 维权是否值得，要与未来收入、再就业和程序耗时一起计算 |
| 线上/线下身份 | 网站账号、实名认证和现实当事人/代理资格不能混同 |
| 平台消失与记忆 | 公开 Q&A 可能存活，但最终案件、证据、支付和执行状态常常不会公开保存 |

## 十三、证据等级与同时性

本专题继续区分：

- **A**：法律/司法解释、司法行政机关同期公告、制度文件、正式统计；
- **B**：同期报刊、记者采访、机构现场报道；
- **C**：多年后的机构史或参与者回忆；
- **D**：研究者机制重构。

个人材料另标：

- **T0**：当事人同期自发帖子/公开记录；
- **T1**：同期采访或正式案例中的当事人原话；
- **T2**：近时期回顾；
- **T3**：多年后回忆；
- **TX**：时间关系不清。

2009 刘永其、2019 王大鹏、2023 小李都只能证明“这种生活路径发生过、当事人当时怎样理解”，不能推成农民工或青年劳动者总体。

## 十四、反例与后见之明风险

### 风险 1：把法律现代化写成网站上线史

错误：

> 2000s 以后普通人开始获得法律服务。

更准确：

- 律师、法律援助、热线和线下机构早已存在；
- Web 主要改变寻找、远程咨询、材料传递和状态查询；
- 正式裁决与执行仍有自己的制度链。

### 风险 2：把“在线咨询”写成“在线解决”

一条留言答复可能只是第一步。没有后续证据时，不知道当事人是否看见、是否采纳、是否申请仲裁、是否胜诉、是否执行。

### 风险 3：把“数字化”理解成电话消失

2025 年北京 12348 的电话服务仍占大多数。成熟公共服务更可能是**渠道冗余**，而不是强迫所有人迁移到最新 App。

### 风险 4：把有证据理解成证据一定有效

聊天记录、截图、工资记录等是否真实、完整、关联、可采，要由具体程序判断。

### 风险 5：只写成功维权者

公开新闻天然偏向“讨回工资”“成功调解”。那些放弃、超时、证据不足、执行不到位或不愿承担再就业风险的人更难被留下。

这构成严重的 **remedy-success visibility bias（成功救济可见性偏差）**。

## 十五、尚未确定

1. 1980s–1990s 普通家庭通过报刊、广播、街道/单位获得法律咨询的具体日常路径，仍需要更多同时代材料；
2. 148/12348 各地区最初的接通率、服务时长、人员构成与城乡差异没有统一长时序；
3. 早期在线法律咨询中，有多少问题真正转入正式法援、仲裁、诉讼，缺少可连接的个案链；
4. 2000s 手机短信、QQ、论坛法律版与正式法律服务之间的关系仍较薄；
5. 在线诉讼的技术可用性与不同年龄、设备、数字能力群体的实际可执行性需要独立研究；
6. 败诉、撤回、和解后未支付、胜诉后执行困难等“没有漂亮结尾”的材料仍然不足。

## 十六、本轮对“普通人有多少种活法”的修正

过去我们很容易把人生选择写成：

```text
继续这份工作 / 换工作
继续这段租约 / 搬走
继续合作 / 退出
```

但现实中还有一个经常被漏掉的变量：**退出要不要自己吞下全部损失。**

一个工人被拖欠工资后，如果唯一现实选择是“不要了，赶紧找下一份”，和另一个能拨通热线、保存证据、申请仲裁、取得援助并拿回工资后再离开的人，表面上都叫“换工作”，实际拥有的自由并不一样。

所以普通生活的 optionality 还需要增加一层：

> **不是只有“我能不能选下一条路”，还要问“上一条路出问题时，我有没有办法把该带走的钱、记录和权利一起带走”。**

这就是本专题所说的 **claimability / 可主张性**。

法律文本决定权利可以被说成什么；电话、窗口、网站、律师、证据系统、仲裁、法院和执行机制共同决定——这项权利有没有机会真正重新进入一个人的生活。
