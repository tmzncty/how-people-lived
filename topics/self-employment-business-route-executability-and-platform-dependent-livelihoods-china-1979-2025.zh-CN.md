# 自雇、个体经营与“自己给自己造一份工作”：中国，1979—2025

> 状态：research note / comparative synthesis  
> 主题：就业、非正规劳动、个体经营、证件与记录、互联网平台、支付与结算、未来预期  
> 交叉旧网：`tmzncty/old-web-archaeology/docs/ONLINE_SHOP_SELLER_ONBOARDING_DISCOVERABILITY_ESCROW_RATING_AND_SETTLEMENT_STATE_GAPS_2003_2010.md`  
> 与既有专题的边界：本条目不是再次研究“主业 + 副业”。`multiple-jobholding-side-work-income-stacking-and-schedule-multiplexing-china-1989-2026.zh-CN.md` 与 `secondary-work-gig-routes-and-enacted-job-portfolios-china-1982-2026.zh-CN.md` 研究一个人如何同时执行多份劳动；这里研究的是**一个人何时、怎样成为经营主体，并自己承担找客、进货、收款、交付与持续经营的整条链**。

## 0. 核心问题：没有雇主以后，谁替你完成“工资前面的所有事情”？

“自己干”“开个小店”“开网店”“摆摊”“自由职业”看起来都像“不去给别人打工”。但对普通生活史来说，它们最重要的共同点不是“自由”，而是：原来由雇主、单位或组织替一个人解决的一批接口，被重新交给了个人或家庭。

受雇劳动的极简模型常常可以写成：

```text
获得岗位
→ 到岗
→ 完成劳动
→ 单位发工资
```

真正的个体经营则更接近：

```text
经营资格 / 可被允许做这件事
→ 启动资本
→ 场地或账号
→ 货源 / 技能 / 设备
→ 客户发现
→ 建立信任
→ 报价 / 展示
→ 订单
→ 支付
→ 履约 / 发货
→ 售后
→ 结算
→ 补货 / 再投资
→ 下一批客户
→ 继续经营或退出
```

任何一层断掉，“这个人理论上可以创业”都不等于“这条生活路线可以持续运行”。

因此新增一个核心概念：

> **business-route executability / 经营路线可执行性**：一个人能否把“我自己卖东西/提供服务”从想法推进到反复产生可用现金流，并让这条路线在制度、市场、技术与家庭时间上持续成立。

硬边界：

- `business activity exists ≠ legally recognized business`
- `license exists ≠ capital / premises / supply exist`
- `shop/account exists ≠ discoverable shop`
- `listing exists ≠ item actually available`
- `inquiry ≠ order`
- `order ≠ paid`
- `paid ≠ delivered`
- `delivered ≠ funds settled`
- `GMV ≠ seller income`
- `one profitable month ≠ durable livelihood`
- `platform account ≠ business sovereignty`

## 1. 1979—1981：先有卖东西的人，再有一种被制度承认的“活法”

### 1.1 章华妹个案：同一张小桌子，制度身份改变以后意义完全不同

改革开放后第一份个体工商业营业执照的历史，特别适合说明“证件不是纸面附属物，而可能改变一条生活路线能否公开执行”。

浙江省委党史研究室整理的资料记载：章华妹 1979 年底在温州解放北路家门口摆摊，销售小百货；1980 年 12 月 11 日，她取得温州市工商行政管理局编号 10101 的营业执照，执照列有姓名、地址、生产经营范围“小百货”、开业日期等信息，注册资本填写为 150 元。

来源：

- 浙江省委党史研究室 / 浙江日报历史整理，2011：《全国第一份个体工商户营业执照》：https://www.zjzzgz.gov.cn/art/2011/5/12/art_1413013_14827568.html
- 《人民日报》2018 对章华妹的回访：https://cpc.people.com.cn/n1/2018/1029/c419242-30367446.html
- 《学习时报》2022 对该执照与早期经历的整理：https://dangshi.people.com.cn/n1/2022/0325/c436975-32383852.html

证据等级：B/C。营业执照本身及官方档案叙述具有较强机构来源；关于她当时感受与生活细节的叙述多为几十年后回忆，必须保留回顾性标签。

回顾材料称，章华妹当时家中九口人、父亲工资不足以承担全部家庭开支，她没有进入原有工作分配路径；摆摊后每月可以获得二十多元收入。最重要的不是把这个极早个案写成“人人都可以经商”，而是看见前后的制度状态：

```text
同一人
+ 同一类小商品
+ 同一地点

领证前：公开经营存在被查、被罚或被没收的风险
领证后：经营活动获得可公开识别的合法身份
```

可以称为：

> **credentialed livelihood / 证件化生计**：一个人原本已经实际执行的谋生行为，因为获得一种正式证件和主体身份，才从高风险、难持续的灰色活动变成可以公开扩张、进货和规划的生活路线。

### 1.2 1981：个体经营不只是“允许摆摊”，而是一整套配套接口

1981 年 7 月的国务院《关于城镇非农业个体经济若干政策性规定》要求相关部门在资金、货源、场地、税收和市场管理等方面给予支持和便利。《人民日报》当时直接刊发了这项规定的消息。

北京市同年转发文件则明确把城镇待业青年列为发展个体经营的重要对象，并要求商业、物资、供销、房管、市容等部门在原材料、货源、场地、房屋等方面提供条件。

来源：

- 《人民日报》1981-07-16，第 2 版：https://cn.govopendata.com/renminribao/1981/7/16/2/
- 北京市人民政府，京政发〔1981〕106号：https://www.beijing.gov.cn/zhengce/zfwj/zfwj/szfwj/201905/t20190523_70565.html

证据等级：A（同期政策/报纸文本）。

这说明前互联网时代的“创业基础设施”已经必须同时包含：

- 主体资格；
- 场地；
- 货源；
- 银行/资金；
- 市场管理；
- 税收；
- 技术与业务指导。

互联网后来可以重做其中的“找客户、展示、联系、支付、信誉”部分，但它没有发明经营本身。

## 2. 2003—2005：网上商店把“店面”从城市地段改成账号、页面和物流节点

### 2.1 开网店真正新增的不是“卖东西”，而是远程找客

2003 年以后 C2C 平台把一些原本需要临街位置、市场摊位或熟人网络才能完成的动作搬到公共互联网：

```text
注册账号
→ 建店
→ 上传商品
→ 等搜索/浏览带来陌生顾客
→ 在线联系
→ 远程支付
→ 快递
```

2005 年《金陵晚报》刊出一篇由淘宝会员“猪脑子塞了”撰写的《淘宝卖家开店必修》，开头就从“注册”和会员名谈起，并明确把读者定位为“来开店赚钱”的卖家。它不是淘宝后台的官方手册，但作为同期用户教程，恰好说明开店已经形成可以公开教授的一套操作知识。

来源：

- 《淘宝卖家开店必修》，2005-07-19：https://news.sina.com.cn/s/2005-07-19/09006474272s.shtml

证据等级：B（同期用户教程，经报纸转载）。

同年新华网报道一名海南大学生郭耀华从 2004 年下半年休学一年经营淘宝店，随后开出网上分店，顾客跨越不同地区。报道数字和成功叙事有平台宣传背景，不能拿它代表普通卖家，但它证明一条此前少见的顺序已经能够真实出现：

```text
大学在读
→ 暂停学业
→ 经营网上店铺
→ 跨地域顾客
→ 商店成为主要收入来源
```

来源：新华网 2005-10-20 报道（新浪转载）：https://tech.sina.com.cn/i/2005-10-21/0903744919.shtml

证据等级：B；个案与平台就业数字不得外推。

### 2.2 信任与付款成为新的基础设施

早期陌生人交易有一个基本难题：卖家担心先发货收不到钱，买家担心先付款收不到货。后来对 2003 年首批支付宝担保交易的近同时代回顾记录了这样的状态：买家先把款交给第三方，卖家得到付款通知后发货，买家确认后资金再交付卖家。

来源：2009 年网络支付史报道的存档转载（作为 B/C 级近同时代回顾使用）：https://www.cnblogs.com/tony-net/archive/2009/10/02/1577447.html

这里最重要的生活史结论不是“支付宝何时伟大”，而是：

> **支付可信度本身决定一个陌生人能否成为你的顾客。**

这把经营基础设施从“店铺 + 现金”改造成了：

`店铺页面 + 平台账号 + 信用状态 + 支付中介 + 快递`。

## 3. 2006：你可以拥有自己的货，但不一定拥有自己的“被看见权”

### 3.1 招财进宝争议：经营者第一次大规模感受到排名本身就是生计接口

2006 年 5 月，淘宝推出“招财进宝”竞价推荐服务。同期《东方早报》报道，卖家可以付费购买推荐位，在关键词搜索中，付费金额等因素会影响商品排列位置；越靠前越容易先被买家看到。部分卖家随后组织抵制，6 月淘宝通过公开投票取消了该服务。

来源：

- 《卖家扬言集体下架 淘宝大幅降“推荐费”》，2006-05-30：https://news.sina.com.cn/c/2006-05-30/02459061654s.shtml
- 《淘宝“招财进宝”满月便夭折》，2006-06-12：https://news.sohu.com/20060612/n243677800.shtml
- 《淘宝网“招财进宝”夭折》，2006-06-13：https://business.sohu.com/20060613/n243710887.shtml

证据等级：B（同期媒体；争议双方的规模与归因需保留来源归属）。

另一篇同期报道观察到，一批卖家在所谓“罢市”日下架商品、提取支付宝余额并停止使用淘宝旺旺。具体参与店铺数在不同报道间存在差异，不能把某个媒体数字当成精确平台人口；但行动形式本身很清楚：**平台规则一变，店铺即使没有被删除，经营能力也会变化。**

来源：《淘宝网3万卖家昨天高挂歇业牌》，2006-06-02：https://news.sina.com.cn/o/2006-06-02/05499095863s.shtml

由此新增：

> **channel sovereignty / 渠道主权**：一个经营者究竟控制多少“被客户找到、成交、拿到钱”的关键通道？

平台店主拥有商品、照片、劳动甚至供应链，但搜索排序、展示位置、账号权限、支付与信用规则由平台控制。

因此：

> **storefront ownership ≠ channel sovereignty**

这也是互联网对自雇的一个反直觉变化：它降低了开店的前端成本，却可能把生计更深地绑定到一个自己无法控制的规则系统。

## 4. 2007—2010：“扩张型未来”出现一种新路线——学生可以直接变成商人，而不必先成为雇员

### 4.1 义乌的特殊生态：学校、批发市场、快递和平台叠成一个创业环境

2008 年《中国青年报》报道义乌工商职业技术学院时，记录到校内约有 200 多家网络商店、1200 多名学生参与网上创业，快递企业甚至进入校园服务。报道中的成功个案包括 2007 年开店、后来商品扩展到数百种的学生，以及月收入较高的少数店主。

来源：《义乌商职院：千余学生网上淘金年入2500万元》，2008-07-07：https://zqb.cyol.com/content/2008-07/07/content_2252821.htm

证据等级：B（同期媒体 + 学校/个案数据）。

必须强调 denominator：义乌紧邻大型小商品批发市场，学校又主动推动电子商务，这不是全国普通高校的典型环境。它的价值恰恰在于展示：

```text
近距离货源
+ 学校网络与宿舍空间
+ 公共互联网平台
+ 校园快递
+ 同学经验传播
= 一条特别低摩擦的学生经营路线
```

### 4.2 school-to-merchant bypass / “学校 → 雇员”不再是唯一桥梁

2009 年同期报道直接使用“自雇”一词。上海一些毕业生在求职困难背景下选择自由写作、家教、电脑服务社或网上商店。一名新网店店主明确说，面对毕业就业形势，他决定“自己干”，并利用父亲原有医药供应关系把产品直接卖给消费者。

来源：

- 《开网店做家教 大学生兴起“自雇”就业》，2009-02-20：https://edu.sina.com.cn/j/2009-02-20/1405165415.shtml
- 中国新闻网同源转载：https://www.chinanews.com.cn/edu/qzjy/news/2009/02-20/1572004.shtml

证据等级：B；文中淘宝新增卖家数字来自平台，不作为全国大学生自雇率。

这让扩张型未来增加了一条明确的序列变化：

```text
传统想象：
学校 → 求职 → 雇员 → 积累资本/经验 → 以后也许自己开店

新出现的可执行路线：
学校期间建店 → 有订单 → 毕业时继续经营 → 不进入普通招聘流程
```

可以称为：

> **school–merchant overlap / 学生—经营者重叠期**。

它不代表“创业比就业更容易”。大量店铺没有持续收入；平台、学校与媒体也会更愿意报道少数成功者。真正的新变化只是：**第一份稳定工作开始可能不是一个岗位，而是一套由本人运营的交易流程。**

## 5. 2015—2019：“拥堵型未来”——开店门槛下降以后，稀缺物从店面转成注意力

### 5.1 discoverability labor / 被发现本身成为劳动

2006 年付费排名争议已经预示了一个长期变化：当平台上店铺和商品足够多时，单纯“上线”越来越不能换来顾客。

2018—2019 年，平台公开强调直播、短视频、内容化成为新的成交入口。2018 年淘宝直播已经形成大规模产业活动；这些数字主要来自平台或平台采访，不能自动转换成“所有小卖家都必须直播”，但它们证明卖家竞争开始越来越依赖内容、粉丝与平台分发。

来源：中国新闻网，2018-12-17：https://www.chinanews.com/business/2018/12-17/8704728.shtml

2019 年《青年报·青春上海》关于淘宝 C 店小卖家的报道则记录，有卖家在“双十一”期间订单同比大幅下降，并把小店困境直接联系到“流量”与曝光。单个卖家视频与媒体采访不能代表全部 C 店，但它是很有价值的同期经营者体验。

来源：《“双十一”订单量减少80%！淘宝大玩家背后的小卖家，难！》，2019-11-17：https://www.why.com.cn/wx/article/2019/11/17/15739698921092792816.html

因此：

> **店铺稀缺 → 注意力稀缺。**

经营劳动不再只有采购、拍照、发货，还包括：

- 搜索排序；
- 评价与信誉维护；
- 推广；
- 内容生产；
- 直播；
- 粉丝维护；
- 跨平台导流。

这里可以称为 **merchant attention work / 商户注意力劳动**。

### 5.2 2019：经营主体身份又重新被法律明确化

《中华人民共和国电子商务法》自 2019 年 1 月 1 日起施行。第九条明确把通过互联网等信息网络销售商品或提供服务的自然人、法人和非法人组织纳入“电子商务经营者”；第十条原则上要求依法办理市场主体登记，同时列出自产农副产品、家庭手工业、便民劳务、零星小额交易等例外。

来源：全国人大，2018-08-31：https://www.npc.gov.cn/WZWSREL3pncmR3L25wYy9sZnp0L3JseXcvMjAxOC0wOC8zMS9jb250ZW50XzIwNjA4MjcuaHRt

证据等级：A。

这让 1980 年“营业执照把摆摊者变成可公开识别的经营主体”和 2019 年“平台内经营者被纳入正式电子商务经营者框架”形成一条很长的证件史：

> **数字店面没有消灭经营身份；它最终又需要与正式市场主体、纳税和平台记录重新对接。**

### 5.3 无货源店铺：低资本进入与规则依赖同时增强

2019 年《新快报》调查“无货源店铺”时，记录了一种低库存模式：经营者从其他平台/店铺收集商品信息，加价发布，买家下单后再向上家下单并由上家发货。报道同时指出平台不断调整规则限制批量复制、重复铺货等行为，并出现针对入门者的软件、培训和教材生意。

来源：人民网转载《新快报》，2019-11-25：https://it.people.com.cn/n1/2019/1125/c1009-31472087.html

证据等级：B。

它提供了很好的反例：

> **startup capital can fall while platform-rule dependence rises.**

不用租仓库、不先囤货，可以降低一部分进入成本；但商品信息、上家履约、平台规则和售后责任又形成新的依赖。低资本不等于低风险，更不等于可长期复制。

## 6. 2020—2022：“偶发型未来”——经营路线第一次被看成可以迅速切换的应急通道

### 6.1 摄影师 → 朋友圈卖货：客户关系可以被临时转换成销售渠道

2020 年 2 月，人民网采访武汉人像摄影师郝鑫（化名）。疫情发生后，他的摄影收入归零，同时仍有房贷和车贷；他转而在朋友圈销售化妆品赚取提成，并特别标注“深圳发货”，因为武汉物流受限。

来源：《“转行卖菜”“网上卖房”……这些行业的战“疫”故事》，人民网，2020-02-27：https://politics.people.com.cn/n1/2020/0227/c1001-31607777.html

证据等级：B（同期第一人称采访）。

这条材料说明应急自雇路线需要至少三种已有资产：

```text
旧职业积累的客户关系
+ 可远程发布信息的社交网络
+ 疫区外仍可工作的货源/物流
```

因此“网上卖货”不是从零启动的按钮。原来的摄影客户网络被临时转换成潜在买家，但物流边界仍然决定能不能真正交付。

### 6.2 settlement liquidity / 结算流动性：货卖掉仍不等于手里有钱

同年北京商报/人民网记录，小微商家面对物流、账期和现金流压力。水果店主李志强使用平台“0账期回款”功能，在一段时间内多次提前提取约 8000 元级别的货款，用于发货、雇人采摘和果树投入。

来源：《电商与小微的“共生”与“自救”》，2020-03-09：https://it.people.com.cn/n1/2020/0309/c1009-31622665.html

证据等级：B；政策/平台措施与个案体验都需要保留具体平台语境。

由此新增：

> **settlement liquidity / 结算流动性**：营业额只有在足够快地变成经营者可以再次支付工资、采购、运费和生活费的现金时，才真正具有生计意义。

所以：

> `sale completed ≠ merchant can reuse the money today`

一次危机可以让原本很少被注意的“结算延迟”突然成为生死接口。

## 7. 2023—2025：“防守型未来”——越来越多经营想象不是“一把梭哈创业”，而是低资本试运行

### 7.1 2023 摆摊材料：主业 + 微型经营，是对不可预测未来的一种测试

中国新闻网 2023 年调查年轻人摆摊时，记录了一个特别适合本项目的第一人称个案：乐乐此前餐饮创业失败、负债较高，重新进入受雇工作后，用 3500 元启动资金在下班后卖玩具。她解释选择玩具的一部分原因是价格低、耐储存，适合低本金尝试。

来源：《年轻人的地摊故事：有人还清200万负债，有人陷于精神内耗》，2023-03-25：https://www.chinanews.com.cn/cj/2023/03-25/9978454.shtml

证据等级：B（同期采访；极端债务与后续收入不可代表一般摆摊者）。

它和 2008 年“学生直接把网店想成未来主业”的扩张感不完全一样。2023 的这个路径更接近：

```text
保留主业工资
+ 小额投入
+ 可撤摊的设备/库存
+ 晚间经营
+ 先观察现金流
→ 再决定是否扩大
```

可以称为：

> **low-capital reversible enterprise / 低资本可逆经营**。

防守型未来中的“自己做点生意”并不总是追求成为企业家；它也可以只是给工资、储蓄和职业不确定性增加一个小型备用通道。

### 7.2 不要把“有退路”浪漫化成“零风险自由”

这条路线仍然可能消耗：

- 下班后的休息；
- 家庭时间；
- 车和储物空间；
- 进货资本；
- 天气与摊位稳定性；
- 平台账号和流量；
- 身体劳动；
- 失败后处理库存的时间。

因此与仓库既有副业研究互相校验：**第二收入和微型经营确实可以增加选项，但也可能把风险和运营劳动从组织转移给个人。**

## 8. 把四种未来放到同一个经营时间轴上

| 时段 | 经营想象 | 典型执行难题 | 时间感 |
|---|---|---|---|
| 2005–2012 扩张型 | 学生/年轻人可以跳过传统雇员阶段直接试开网店；互联网扩大客户半径 | 货源、拍照、信誉、支付、物流、平台规则 | “我现在试，做大了就可以走另一条路” |
| 2015–2019 拥堵型 | 开店技术门槛继续下降，但店铺与商品数量巨大 | 流量、排序、内容、广告、规则、主体登记 | “能开店不等于有人看见我” |
| 2020–2022 偶发型 | 原主业突然暂停时，社交关系和电商渠道可临时转成生计 | 物流中断、结算、供应链、现金流 | “先让现金流不断，再说长期路线” |
| 2023–2025 防守型 | 保留主业，同时用小额资本测试摊位/平台服务/小店 | 时间透支、获客、库存、收益不确定 | “不要先押上全部人生，先保留能退出的试验” |

这不是四个互斥群体，也不是时代人格。它们只是帮助比较同一种“自己经营”在不同制度和市场密度下承担什么功能。

## 9. 作品证据交叉：为什么《家有儿女》里“借 3000 元做购物网站”值得保留

仓库新方法文件 `fiction-as-ordinary-life-evidence-narrative-baselines-and-latent-identity-stacks.md` 已记录《家有儿女》第一季一个情节：夏雪向父母借 3000 元做一个想赚钱的购物网站，网站没有买家，后来又遇到被“黑”的剧情。

官方后来的 CCTV 剧集页可用于确认剧情内容：

- https://tv.cctv.com/2010/06/11/VIDE1354275076963801.shtml

这个 F1 证据**不能**证明 2004/2005 青少年普遍做电商，也不能证明剧中网站是一套真实上线的商城后台。它真正值得和 2005—2009 网店史放在一起的原因是：

> 到这一时期，“借一点启动钱 → 做网站 → 想靠流量卖东西 → 没买家 → 网站技术出问题”已经足够可理解，可以直接成为家庭情景喜剧的情节。

现实材料则告诉我们：真正可持续的网上经营还需要供应链、支付、排名、信用和物流。

因此：

> **narrative entrepreneurial legibility ≠ historical business executability**

作品保存“这种人生已经可想象”，制度史和经营史负责检验“这种人生究竟有多少人能做成”。

## 10. 海外前互联网对照：法国 Minitel 已经可以远程帮助一个人决定“怎样开公司”

1987 年法国《世界报》报道，Meurthe-et-Moselle 手工业商会推出 `3615 ACCT` Minitel 服务，潜在创业者可以远程查询未来企业的法律形式、贷款偿还和社会费用等信息；服务器建在 Nancy，但通过 Minitel 可以从法国其他地区访问。

来源：Le Monde, 1987-06-21, *Minitel pour artisans*：https://www.lemonde.fr/archives/article/1987/06/21/minitel-pour-artisans_4049954_1819218.html

这是非常重要的比较，因为它证明：

> **remote business guidance predates the Web.**

但 denominator 不能省略。1986 年 1 月法国约有 140 万台 Minitel，其中约 110 万台在家庭、30 万台在企业；1987 年底设备约 337.3 万台，相当于电话订户的 14%，France Télécom 当时估计可在家庭或工作地点接触终端的人约占 15 岁以上人口 20%。

来源：

- Le Monde, 1986-04-12：https://www.lemonde.fr/archives/article/1986/04/12/le-phenomene-minitel-en-1985-ce-n-etait-qu-un-pari-risque-en-1986-c-est-un-succes-industriel-et-commercial_3115720_1819218.html
- Le Monde, 1988-04-21（回顾 1987 年数据）：https://www.lemonde.fr/archives/article/1988/04/21/reflux-des-messageries-hausse-des-services-professionnels-le-deuxieme-souffle-du-minitel_4102726_1819218.html

与中国 2000 年代 C2C 的区别也很清楚：Minitel 例子主要把**行政/经营知识的搜索成本**降下来；淘宝式平台进一步把**顾客发现、联系、信用、支付、评价与结算**塞进同一个数字环境。共同变化不是“互联网发明创业”，而是远程通信系统不断重写经营过程中的搜索、信任和协调成本。

## 11. 经营主体的 identity stack

和作品研究里的 `latent identity stack` 可以直接连接。一个“店主”至少有几套并不完全重合的身份：

### 线下正式身份

- 自然人；
- 个体工商户 / 公司 / 其他主体；
- 营业执照；
- 税务与许可；
- 经营地址。

### 平台身份

- 登录账号；
- 实名/认证状态；
- 店铺；
- 类目权限；
- 信誉；
- 违规/冻结状态。

### 支付身份

- 银行账户；
- 支付账户；
- 待结算余额；
- 退款/争议/冻结状态。

### 社会身份

- 学生；
- “老板”；
- 摊主；
- 网商；
- 主业员工；
- 家庭经营成员。

一个人在现实里完全可能同时是：

> `公司职员 + 个体经营者 + 淘宝店主 + 支付宝收款人 + 晚间摊主`

因此“职业”不再总能由一格表格完整表达。

## 12. 这条线改变了我们对“人怎么活”的哪一点理解

以前容易把标准脚本写成：

```text
上学
→ 找到工作
→ 单位发工资
→ 换工作 / 晋升
→ 退休
```

这一轮增加了另一类真正长期存在的生命路线：

```text
没有岗位 / 不进入岗位 / 岗位不足以承担风险
→ 自己取得经营身份
→ 自己组织货源和客户
→ 自己承担现金流和失败
```

它在 1980 年并不依赖 Internet；到了 2000 年代，互联网降低了“找陌生顾客”和“远程交易”的成本；到平台高度成熟以后，个人又把新的生计控制权交给排名、账号、支付和平台规则；危机与就业拥堵时期，人们再把微型经营当成备用通道。

因此，自雇不是一条单向的“越来越自由”的历史。

更准确的变化是：

> **经营所需要的协调工作从街道、工商所、市场、电话和现金，逐步迁移到账号、搜索、即时通信、第三方支付、物流和平台治理；个人得到新的行动半径，同时也承担更多原本不属于普通雇员的风险。**

## 13. 证据边界、反例与待补

### 已知

- 1980—1981 的政策与营业执照材料明确证明，个体经营成为被正式承认和支持的城镇生计类别。
- 2005—2009 同期材料明确证明，网店已经能成为部分学生和毕业生的主要或备选职业路线。
- 2006 的竞价排名争议明确证明，平台展示规则可以直接成为卖家的经营条件。
- 2019 的电子商务法把平台内经营者等重新纳入正式电子商务经营主体框架。
- 2020 同期个案明确显示，在主业突然停止时，社交网络、电商支付/结算和物流可被当作应急生计设施。

### 不能推出

- 第一张执照不能代表 1980 年所有城市普通人都能轻松经营。
- 义乌高校案例不能代表全国大学生网店成功率。
- 淘宝公布的就业/卖家数量不是独立人口统计。
- 一家店月入数万不能代表网商中位收入。
- 2023 摆摊成功个案不能证明摆摊普遍可以还债或替代正式工作。
- “自由职业/自雇/个体户/平台卖家/摆摊”不是同一种法律或经济身份。

### 下一步高价值证据

1. 找到 1980s—1990s 同一个普通个体经营者的多时点原始材料：办照、进货、租/占场地、家庭用工、税费、关店或转业。
2. 找到 2003—2010 同一个普通淘宝卖家的完整纵向链：注册 → 第一个商品 → 第一单 → 支付 → 发货 → 评价 → 流量变化 → 是否迁平台/关店。
3. 优先寻找失败或长期低收入卖家，修正“创业报道只保存成功者”的选择偏差。
4. 把网店、摊位和家庭小店的每日时间预算做成可比较 life slice：进货、拍照、客服、打包、发货、等客、照护、睡眠。
5. 继续寻找 2018—2019 普通小卖家的同期日记/博客/视频文字稿，尤其是“流量越来越贵/我为什么关店”这类不依赖后来怀旧的第一人称材料。
6. 研究平台倒闭、账号封禁、支付冻结或物流停摆时，经营者怎样把客户和资金迁走；这会与 `platform disappearance / memory preservation` 形成另一条“生计可迁移性”问题。

### 饱和判断

本轮新增了一个与“副业”不同的生活路径类别——**作为经营主体而活**，并新增证件化生计、渠道主权、商户注意力劳动、结算流动性与低资本可逆经营等机制；因此不能计入“连续三轮无实质新增”的饱和序列。
