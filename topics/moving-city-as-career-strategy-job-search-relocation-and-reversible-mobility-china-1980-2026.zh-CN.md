# 什么时候“为了工作换一座城市”成为普通人生策略？

> **研究问题：一个普通人什么时候开始能够在身体尚未到达另一座城市之前，就把那里的工作、住房、面试与生活成本当成可比较的未来选项？**

这不是一篇“人口流动史”或“互联网招聘史”。

本专题关心的是一条更具体的生活史链条：

```text
听说另一座城市有机会
→ 能否在出发前获得足够信息
→ 能否远程申请
→ 是否必须为面试先旅行
→ 是否先拿 offer 再搬家
→ 人事档案/证件/住房如何接续
→ 到达后是否真的入职
→ 如果不适合，能不能再离开或回来
```

它与仓库已有专题有交叉，但研究单位不同：

- [`communication-and-the-cost-of-living-far-away.md`](communication-and-the-cost-of-living-far-away.md) 研究通信怎样降低离家生活的成本；
- [`searchable-city-routefinding-local-search-and-navigation-china-1983-2026.zh-CN.md`](searchable-city-routefinding-local-search-and-navigation-china-1983-2026.zh-CN.md) 研究陌生城市怎样变得可搜索、可计算；
- [`when-did-changing-jobs-become-normal.md`](when-did-changing-jobs-become-normal.md) 研究换雇主怎样从重大断裂变成常见职业动作；
- 本专题研究的是：**城市本身什么时候成为职业选择中的一个可操作变量。**

---

## 1. 先定义一个关键变量：mobility sequencing（迁移顺序）

“去外地找工作”至少可以有两种完全不同的顺序。

### Move-first search

```text
先离开原居地
→ 到目的地找住处/借住
→ 买报纸/去人才市场/问亲友
→ 投简历/面试
→ 找到工作或失败返乡
```

这种模式里，求职者在获得明确工作结果前就已经承担：

- 车费；
- 临时住宿；
- 吃饭；
- 陌生城市导航；
- 现金缓冲；
- 失去原地工作或家庭支持的风险。

### Search-first move

```text
在原地搜索异地岗位
→ 远程投递
→ 电话/网络沟通
→ 面试或部分面试
→ 获得较强录用信号/offer
→ 再决定是否搬家
```

后一种模式并不保证更容易找到工作。

它真正改变的是：**什么时候必须把身体和现金押到一座陌生城市。**

本专题把这称为：

## relocation commitment point（迁移承诺点）

即一个人必须在哪一步开始承担不可轻易撤回的迁移成本。

互联网的重要作用之一，不一定是“让更多人迁移”，而是把这个承诺点向后推：

> 先看更多机会、先被筛选、甚至先面试，再决定是否把身体搬过去。

## 2. 互联网以前：机会可以跨地区流动，但常常由组织、信件和人来搬运

不能把 1990 年代以前写成“没有全国招聘”。

问题在于，**信息和人是怎样移动的。**

### 2.1 1980s：企业可以跨地区找人，但这和今天个人在全国职位数据库里搜索不是一回事

1988 年国务院办公厅转发的劳动部、人事部意见明确允许外商投资企业面向社会公开招聘；本地区招聘不足时，可以跨地区招聘。在职职工被聘用时还涉及原单位支持、调转手续等。

来源：

- **A（同期政府文件）**：北京市政府保存的 1988 年文件及转发正文：<https://www.beijing.gov.cn/zhengce/zfwj/zfwj/bgtwj/201905/t20190523_73209.html>

这至少证明：

> **cross-region recruitment existed before mass Internet recruitment.**

但它不能证明普通求职者在家里就能轻易浏览全国空缺。

当时更常见的扩展方式可能包括：

- 用人单位去外地招人；
- 学校组织供需见面；
- 人才服务机构牵线；
- 报刊招聘；
- 信函询问；
- 熟人介绍；
- 求职者本人先到目标城市。

### 2.2 1988 北京高校毕业生：选择增加，但选择发生在一个实体集中场所里

北京日报后来利用本报图文数据库重刊的 1988 年材料显示，当年北京首次举行高校毕业生分配咨询会，1000 多家用人单位、50 多所高校近万名应届毕业生在天坛公园面对面洽谈，有的当场签订协议。

来源：

- **B+（后来的报史整理，但引用并展示 1988-04-28 原报材料）**：北京日报，2022，《大学生就业从“包办婚姻”到“自由恋爱”》：<https://news.bjd.com.cn/2022/03/17/10056344.shtml>

这个节点很重要，但不能写成“1988 年毕业生已经自由市场化就业”。

它更准确地说明：

- 分配制度正在出现“双向选择”接口；
- 求职信息和雇主被集中到一个地方；
- 选择半径扩大，但仍高度依赖校园、咨询会和现场接触。

也就是说：

> **choice expanded before search became remotely addressable.**

### 2.3 深圳：信件 → 接待 → 推荐岗位 → 常设人才市场

深圳市政府基于市档案馆资料整理的城市史材料称：1984 年深圳市人才服务公司成立，职责包括处理求职者信件、接待求职者和推荐岗位；1991 年开始筹建深圳市人才智力市场，后因需求增长于 1993 年搬迁。

来源：

- **B+（政府档案叙事，非本轮直接核到 1984 原件）**：深圳市政府，《五湖四海“揽”人才》：<https://www.sz.gov.cn/szstory/202212/content/mpost_10330832.html>

这给出了一条很清楚的前互联网混合链：

```text
远方求职者写信
→ 人才服务机构获得信息
→ 推荐/回复
→ 求职者到深
→ 现场接待/人才市场
```

远程信息已经存在，但**最终匹配仍强烈依赖实体到场**。

### 2.4 1988 珠三角“人才战”：有时是雇主移动，而不是求职者先移动

1988 年《人民日报》同期报道写到，珠三角一些地区会组织人员北上北京、上海、西安等人才密集地区招揽专业技术和管理人员；在正式调动受阻时，还出现借调、协作、咨询、“星期六工程师”等多种安排。

来源：

- **A/B（同期中央报纸报道）**：《人民日报》1988-07-30，《“人才战”促进了人才交流——珠江三角洲采访札记》：<https://cn.govopendata.com/renminribao/1988/7/30/3/>

这提醒我们不要把人才流动史写成单向的：

> **有时不是“人去找城市”，而是城市/企业去外地找人。**

## 3. 记录也要搬：身体迁移与制度迁移不是同一条线

1996 年《流动人员人事档案管理暂行规定》专门规定了辞职/辞退人员、解除劳动或聘用合同者、待业大中专毕业生、非国有企业聘用专业技术和管理人员等流动人员的人事档案管理。

来源：

- **A（法规文本，后由政府站保存）**：人发〔1996〕118 号：<https://www.beijing.gov.cn/zhengce/zhengcefagui/qtwj/201208/t20120817_776589.html>
- 对完整对象类别的另一政府保存版本：<https://www.hhsp.gov.cn/info/3121/309611.htm>

因此应把迁移拆成至少两条轨迹：

```text
body location
record / personnel-file location
```

这两条轨迹可以不同步。

一个人已经：

- 在深圳租房；
- 每天到公司上班；

并不自动意味着：

- 档案已经转到深圳；
- 新单位有权保管档案；
- 所有制度记录已经和身体一起完成迁移。

这里新增概念：

## record-body decoupling（记录—身体脱耦）

现代迁移很容易被地图和手机定位写成“一个点从 A 移到 B”。

真实人生更像：

```text
身体去了 B
档案可能仍在 A / 人才服务机构 C
户籍可能仍在 A
家人仍在 A
工资在 B
住房在 B
医疗/社保/资格记录按各自制度迁移
```

所以“换城市”从来不是一个单状态事件。

## 4. 1999–2004：招聘网站真正改变的是“在到达之前看见机会”

### 4.1 51job 的 2004 SEC 文件提供了一个少见的原始平台剖面

前程无忧 2004 年 IPO 招股文件称：

- 公司 1999 年建立 `www.51job.com`；
- 网站按城市提供招聘广告；
- 2004 年 6 月前，其纸质 `Career Post Weekly` 已覆盖 19 个城市；
- 纸质周刊的招聘广告也同步进入网站；
- 网站还有仅在线发布的招聘广告；
- 招聘广告通常按小时更新；
- 求职者可以搜索岗位、接收与偏好匹配的邮件、直接向雇主投递简历、组织和跟踪申请；
- 雇主可以通过 eHire 搜索候选人数据库并管理简历。

来源：

- **A（同期公司 SEC 申报文件；证明公司当时如何定义和运营其产品，不自动证明市场效果）**：51job 2004 F-1：<https://www.sec.gov/Archives/edgar/data/1295484/000114554904000896/u99016fv1.htm>

特别值得保留的是它的**混合媒介结构**。

2003 年公司收入中：

- print advertising：62.3%；
- online recruitment services：26.2%。

这不能直接换算成求职者使用比例，却足以阻止一个常见错误：

> **2004 年已有大型招聘网站 ≠ 纸质招聘和线下市场已经退出日常生活。**

恰恰相反，同一家公司正在把：

```text
地方报纸/招聘周刊
+
全国网站
+
招聘会信息
+
企业后台简历管理
```

组织成一套混合招聘基础设施。

### 4.2 “城市”开始成为数据库检索维度

2004 SEC 文件明确说 `51job.com` 的在线招聘广告是 **city-by-city** 提供，同时全国站让雇主接触“wide geographic area”的候选人。

这个变化可以命名为：

## labor-market addressability（劳动力市场可寻址化）

过去问外地工作可能是：

> “广州有没有认识的人说某厂在招？”

在线招聘逐渐允许变成：

> “把广州作为一个字段，列出现在数据库里符合条件的岗位。”

同样，求职者的简历也开始成为雇主可搜索的对象。

这不是单纯的信息量变大，而是**职业机会和人的职业属性都开始被数据库化**。

### 4.3 账号/简历数量不是“有这么多人成功跨城就业”

51job 文件称截至 2004-06-30，自网站推出以来约建立 690 万 job user accounts、发布约 460 万份简历。

这些数字只能按公司申报口径使用。

不能写成：

- 690 万独立个人；
- 460 万当时仍有效的求职者；
- 这些人都找到工作；
- 这些人都进行了跨城迁移。

平台可见的是 **accounts / resumés**；生活史真正需要的是 **people / outcomes / moves**。

## 5. 2005–2012 扩张型未来：目的地变多，但“海投”也把选择变成劳动

2008 年末《半月谈》对上百名应届毕业生的同期调查提供了非常好的生活尺度。

### 5.1 唐莎莎：20 天近 500 份网申

报道中的浙江大学城市学院应届生唐莎莎（化名）说，她曾在 20 天内网上投近 500 份简历，求职生活几乎只剩电脑、公交、马路、小饭店和招聘会。

来源：

- **B（同期记者调查中的第一人称自述）**：2008-12-30，中国新闻网转载《半月谈》：<https://www.chinanews.com.cn/edu/qzjy/news/2008/12-30/1508751.shtml>

这说明互联网把“能投多少地方”的上限大幅推高，但同时出现：

## application abundance / attention scarcity（申请充裕、注意稀缺）

一份简历可以低成本复制到几十、几百个岗位；

但：

- 求职者的注意力没有复制；
- 招聘者的审核时间没有复制；
- 面试时间没有复制；
- 一个身体最终仍只能去一个地方。

所以“选择更多”可能同时制造更大的筛选劳动。

### 5.2 在线投递并没有消灭实体招聘会

同一篇 2008 年报道记录广东研究生专场招聘会有 2 万余学生竞争约 4000 个岗位，有毕业生排队三四小时、面试约一分钟。

因此当时的真实路线不是：

```text
招聘会 → 被网站替代
```

而是：

```text
网站海投
+ 校园招聘
+ 大型招聘会
+ 电话追问
+ 多城市面试
```

这与 51job 2004 的“纸媒 + Web”混合结构相吻合。

### 5.3 “先落个脚”说明城市选择可以是临时而不是终局

东北大学毕业生刘文（化名）在寻找三个多月后去了江西某市一家企业，并把当时的策略概括为经济形势不好，先找一个落脚处。

同一报道中，华南农业大学毕业生王佳伶则表示短期未必要留在珠三角，也不强求高工资，但希望以后有机会尽快回广州。

这两条同期材料非常重要，因为它们反对一种今天常见的投射：

> **2008 的“去另一个城市”不一定意味着已经把那里想成长期归宿。**

城市可以是：

- 第一落脚点；
- 暂时就业地；
- 以后再跳回目标城市的中转站。

因此本专题新增：

## destination portfolio（目的地组合）

一个人并不是先从地图上选定“命运城市”，再一次性搬过去。

他/她可能同时保持：

- 广州：想回去；
- 江西某市：现在先工作；
- 老家：失败时可以返回；
- 其他招聘城市：继续投递。

人生地理从单一目的地，变成一组不同概率和时间尺度的选项。

## 6. “网上投了”仍然可能要求身体跨城面试

2008 年另一批同期就业材料显示，校园告示、招聘会、网上信息和跨城面试并存。

这意味着需要单独记录：

## interview travel tax（面试旅行税）

即使岗位信息和简历已经数字化，一个求职者仍可能承担：

- 城际车票/机票；
- 一晚或数晚住宿；
- 到陌生地点的本地交通；
- 请假或逃课；
- 多轮面试之间的等待。

因此：

> **remote discovery ≠ remote selection.**

这是 2000s 在线招聘最容易被后来的智能手机体验遮蔽的一点。

## 7. 2015–2019 拥堵型未来：城市越来越容易比较，却越来越像一个多变量优化题

到 2019 年，“去哪里工作”已经能同时和工资、发展、租房、落户、交通、伴侣与家庭安排一起比较。

### 7.1 小秦：北京先做 2–3 年，再看情况

2019 年《经济观察报》记录一名北京应届生小秦：在“回重庆还是留北京”“国企还是私企”等选择中，她最后决定先在北京工作 2–3 年，之后再看个人情况。

来源：

- **B（同期第一人称/记者访谈）**：2019-07-25，《毕业生去哪儿？新一线城市吸引力稳增》：<https://www.sohu.com/a/329322175_118622>

这是一种和“毕业后在单位干一辈子”完全不同的时间感：

> **city tenure itself becomes provisional.**

城市居住开始可以带有一个显式复审周期。

### 7.2 相同工资，也可能因为住房成本选择另一座城市

同一报道中的小姚（化名）拿到北京和郑州两个同水平薪酬 offer 后，因为北京租房成本和未来买房压力选择郑州。

这里“城市”已经不是职位附带的地址，而是一个家庭预算变量：

```text
工资
- 房租
- 通勤
- 买房预期
+ 职业发展
+ 家庭/伴侣距离
= 这个城市是否值得
```

这正是 **拥堵型未来** 的一个特征：

不是没有机会，而是每个机会带着越来越多需要自己协调的成本。

### 7.3 城市竞争政策也是制度接口，不等于个人已经迁入

2019 年大量“人才政策”“落户放宽”把城市本身包装成可比较的机会。

但研究时必须保持：

```text
policy announced
≠ person eligible
≠ application submitted
≠ approval
≠ actual residence
≠ long-term settlement
```

不要用城市“抢人”新闻直接替代真实迁移结果。

## 8. 2020–2022 偶发型未来：招聘流程第一次大规模把“面试”也推到远程，但物理迁移没有消失

### 8.1 2020 调查：远程面试从边缘能力变成大规模日常接口

2020 年 4 月《中国青年报》相关调查对 1923 名应届生记录：

- 92.2% 的受访者进行了线上求职；
- 82.4% 在线投过简历；
- 58.2% 参加过线上面试；
- 51.5% 参加过线上笔试；
- 27.2% 经历过线上录取；
- 69.8% 认为线上求职覆盖面更广、能打破地域限制；
- 69.8% 认为它省去来回奔波；
- 73.1% 认为需要提前调试网络和设备。

来源：

- **B（同期调查；样本不是全国毕业生概率样本，不能外推为总体比例）**：中国青年报，2020-04-02，界面转载：<https://www.jiemian.com/article/4204203.html>

这说明 2020 的关键变化不是“网上招聘突然发明了”。

专家在报道里也明确指出，以前已有在线报名、投递、筛选；疫情推动的是笔试、面试等更后端步骤也远程化。

于是迁移承诺点进一步后移：

```text
看岗位
→ 投简历
→ 笔试
→ 面试
```

都可能在身体仍位于另一座城市时完成。

### 8.2 新不平等：网络、设备和面试空间成为求职基础设施

线上面试省掉车票，却新增：

- 稳定宽带/移动网络；
- 电脑或合适手机；
- 摄像头/麦克风；
- 不被打断的室内空间；
- 对视频面试礼仪的熟悉。

所以：

> **travel-cost inequality can partly become network/device/space inequality.**

### 8.3 张梦：邮箱里已经有面试通知，身体仍然必须飞回上海

2020 年 8 月《中国青年报》记录，上海第二工业大学毕业生张梦（化名）疫情期间在河南老家，看到邮箱里 3 封面试通知后买机票回上海，只找到一间还剩两周租期的房间暂住，第二天开始在上海多个区跑面试。她最后在租房到期前 3 天敲定工作。

来源：

- **B（同期第一人称/记者跟访）**：中国青年报，2020-08-10，《就业季突围》：<https://zqb.cyol.com/html/2020-08/10/nw.D110000zgqnb_20200810_1-06.htm>

这是对“线上求职打破地域限制”最重要的反例之一。

它说明：

```text
remote application
+
email interview invitation
```

仍然可能在后一步重新变成：

```text
机票
+ 临时租房
+ 城市内跨区奔波
```

因此不能把数字化过程简单写成“地点不再重要”。

## 9. 2023–2026 防守型未来：迁移开始更像可逆实验，而不是一次性押注

### 9.1 2023 “回笼漂”：离开也不代表路线关闭

2023 年北京青年报/中国青年报客户端记录多名离开一线城市后又返回的人。

其中：

- 小红回山西后发现可选互联网岗位少、工资与社保条件不满足预期，后来再次北漂；
- 茜茜在老家待一年半后，于 2022 年 8 月通过线上面试拿到工作并重返上海；
- 叶子把新的自由职业/兼职尝试设置成一个月的收入验证期，失败则考虑重新应聘；
- 强子强调自己去北京的目的并非必然“扎根”，而是提升能力。

来源：

- **B（同期媒体对当事人的第一人称采访）**：2023-04-19，《“回笼漂”：曾逃离北上广深的年轻人又回来了》：<https://news.cyol.com/gb/articles/2023-04/19/content_OV0MwQuW5M.html>

这组材料允许我们提出：

## reversible migration（可逆迁移）

旧的叙事容易写成：

```text
离乡 → 大城市扎根
```

但真实路径可以是：

```text
大城市
→ 回老家试一段
→ 发现收入/社交/职业不匹配
→ 再去大城市
→ 换职业或再评估
```

“回来”不一定证明第一次离开失败；“再出去”也不一定证明一定要永久定居。

它们可能只是一个长期搜索过程里的两次采样。

### 9.2 防守型可选性需要现金缓冲

同一报道中，小红谈“回笼漂”时特别强调需要准备资金，在重新找到工作之前维持正常生活。

这说明可逆不是免费的。

要保留“可以再试一次”的未来，需要：

- 现金；
- 临时住房；
- 可搬运的数字账号/简历；
- 能重新建立工作关系的技能；
- 回退路径。

因此：

> **optionality is partly a balance-sheet property.**

### 9.3 2026 青年驿站：基础设施开始主动降低“先到城市再找”的沉没成本

2026 年上海普陀区政府材料记录一名 00 后硕士蒋明睿：从常州来沪求职，短住青年驿站，随后入职并转入保租房；他在来沪前两周通过网上搜索应届毕业生支持政策申请驿站。

同期上海青年驿站政策把符合条件者的单次免费住宿从不超过 3 天延长到 15 天。

来源：

- **A/B（政府发布的当期服务信息 + 当事人引语）**：上海市普陀区人民政府，2026-07-09：<https://www.shpt.gov.cn/yaowen/20260709/971292.html>
- **A（政府信息）**：上海市政府转金山区青年驿站说明，2026-03-25：<https://www.shanghai.gov.cn/nw15343/20260330/a206722f79854c4bb5eb635592df9298.html>

这代表一种新的 **relocation buffer（迁移缓冲层）**：

```text
面试通知/求职需求
→ 在线申请几天临时住所
→ 到城
→ 面试/等待结果
→ 找到工作后再进入长期租房
```

它并没有取消“move-first search”。

反而说明即使在 2026 年，仍有很多求职场景要求人先到城市，因此公共基础设施开始专门降低这段过渡期的住宿风险。

这是一种很典型的防守型未来：

> 不承诺你一定在这里成功，但减少你试一次的损失。

## 10. 跨国对照：Monster 说明“地点成为检索字段”不是中国特有

Monster Worldwide 2003 年提交给 SEC 的文件提供了一个很好的海外对照。

文件称 Monster 源自 1994 年的 Monster Board；到 2003 年，求职者可以按 location、job category、industry、keyword 搜索职位；还可以创建 Job Search Agent，以行业、地点和关键词等偏好周期扫描职位数据库，并把匹配机会发送到邮箱，即使用户当时离线。雇主也可以对简历数据库进行 geographic searches。

来源：

- **A（同期公司 SEC 文件；产品存在与公司统计口径的原始证据）**：Monster Worldwide 2003 S-3：<https://www.sec.gov/Archives/edgar/data/1020416/000104746903037619/a2121724zs-3a.htm>

这说明一个跨国共同机制：

## career geography becomes queryable（职业地理变得可查询）

人开始可以先写：

```text
location = New York / Boston / ...
```

再看有哪些岗位，而不是先去那座城市再发现谁在招人。

Monster 甚至会在用户离线时继续扫描数据库并通过 email 交付结果。

所以“异地机会在身体出发以前到达”并不是中国特有现象。

中国更值得比较的部分在于：

- 1980s–1990s 分配/双向选择/人才市场并存；
- 人事档案等记录接口与身体迁移不同步；
- 城市户籍、住房与招聘机会长期纠缠；
- 2000s 纸质招聘、人才市场和 Web 共存很久；
- 超大城市与新一线城市竞争，使“选工作”很快变成“选城市 + 住房 + 发展 + 家庭”的联合问题。

## 11. 这条历史改变了“普通人怎么活着”的哪一点？

最重要的变化不是“人越来越爱去大城市”。

而是：

### 11.1 城市从命运结果变成可以先比较的选项

早期更容易出现：

```text
组织分配/亲友链/先到达
→ 才逐渐知道当地机会
```

后来越来越可能：

```text
先看几十个城市的岗位
→ 比较工资与房租
→ 投递多个城市
→ 保持若干 offer/面试路线
→ 再决定身体去哪
```

### 11.2 “迁移”被拆成越来越多可延期的提交动作

数字招聘让以下步骤可以逐渐与身体移动分离：

- 获取职位信息；
- 投递简历；
- 初筛；
- 笔试；
- 一部分面试；
- offer 沟通。

但是这些步骤之后仍有：

- 实体到岗；
- 住房；
- 通勤；
- 档案/证件/社保；
- 伴侣与家庭；
- 长期城市归属。

### 11.3 人生脚本从“一次选择”变成一串可复审决策

2019 的“北京先做 2–3 年”，2023 的“回笼漂”，以及 2026 的短期求职住宿，都说明一个共同变化：

> **城市选择越来越可以被当成阶段性承诺，而不是永久身份。**

这并不意味着所有人都拥有这种自由。

它高度依赖：

- 职业是否能跨城搜索；
- 教育和技能；
- 家庭支持；
- 现金；
- 能否承受空窗期；
- 是否有照护责任；
- 行业是否集中在少数城市；
- 户籍/资格/档案等制度接口；
- 是否能获得临时住房。

## 12. 反例：不要把这条线写成“互联网解放了迁移”

### 反例 A：在线申请越容易，竞争池也可能越大

2008 年 20 天近 500 份网申并不是“500 个真实机会”。

低成本投递会产生：

- 海投；
- 招聘者注意力稀缺；
- 大量无回复；
- 求职者反复刷新和等待。

### 反例 B：很多工作不能靠一个全国白领门户找到

制造业普工、日结、家政、建筑、街边服务、熟人介绍、劳务派遣等劳动市场可能长期依赖：

- 线下市场；
- 中介；
- 老乡网络；
- 招工点；
- 电话；
- 后来的微信群/短视频等渠道。

不能拿 51job/Monster 的白领与受教育用户结构替代所有劳动者。

### 反例 C：remote search 不等于 remote work

2020 可以视频面试，不等于工作地点消失。

一旦录用，很多人仍必须：

- 到厂；
- 到医院；
- 到实验室；
- 到学校；
- 到办公室；
- 在当地租房。

### 反例 D：回乡不是失败，留大城市也不是进步指标

回乡可能是：

- 家庭照护；
- 房屋成本；
- 伴侣协调；
- 体制内机会；
- 生活方式选择；
- 疫情冲击后的风险管理。

再次出城也不是“终于醒悟”。

本专题只研究**什么路径可执行、什么成本改变了**，不把城市层级做成人生等级。

## 13. 历史可见性：网页最容易保存“机会”，最难保存“人到底搬没搬”

对于在线招聘史，公共 Web 最常留下的是：

- 职位页；
- 公司页；
- 搜索入口；
- 招聘首页；
- 帮助页；
- 城市频道。

真正决定生活结果的状态却往往在：

- 登录后的申请记录；
- 企业 eHire/ATS；
- email；
- 电话；
- 短信；
- 线下面试；
- offer；
- 火车/飞机；
- 租房；
- 入职登记。

所以很容易产生：

## opportunity-survival bias（机会幸存偏差）

档案里留下成千上万个“北京招聘”“上海招聘”页面，会让后人感觉当时任何人都面对一个巨大开放的全国市场。

但页面不能告诉我们：

- 岗位是否仍空缺；
- 简历是否被打开；
- 招聘者是否联系；
- 面试是否发生；
- offer 是否接受；
- 人是否真的搬过去；
- 到岗后一周是否又离开。

因此：

> **searchable future ≠ executable future.**

## 15. What we know / infer / do not yet know

### What we know

1. 1980s 中国已经存在跨地区招聘、人才服务、实体供需见面，不应把异地职业机会起点放到大众互联网之后。
2. 1990s 的人才流动已经需要专门的人事档案管理制度，说明身体移动与制度记录移动不是一回事。
3. 51job 2004 的同期公司文件直接证明全国 Web 招聘、城市化职位组织、在线简历、邮件匹配和企业后台审核已经形成规模，同时纸质招聘仍是重要业务。
4. 2008 的同期毕业生材料证明“海投 + 招聘会 + 多城落脚”共存，而不是 Web 单独替代线下。
5. 2020 年远程笔试/面试大规模扩张，确实能把部分求职步骤从地理移动中剥离，但同期张梦个案证明身体到城和临时住房仍可能是决定性成本。
6. 2023–2026 已能观察到可逆迁移、现金缓冲、短期求职住宿等降低“一次押注”风险的机制。
7. Monster 2003 的同期材料显示按 location 搜索岗位/简历与离线 job agent 是跨国共同的在线招聘机制，并非中国独有。

### What we can reasonably infer

1. 在线招聘的重要生活史意义之一，是把 **relocation commitment point** 向后推，而不是简单提高迁移率。
2. 当工作城市成为数据库字段，普通人可以同时保持多个目的地，形成 **destination portfolio**。
3. 2010s 后“先在某城工作几年再评估”越来越适合作为一种人生规划语言，但其社会分布仍需更多调查数据验证。
4. 2020s 的青年驿站之类政策可以被理解为 **relocation buffer**：基础设施开始降低跨城求职的短期沉没成本。

### What we do not yet know

1. 1990s 普通求职者“先到深圳再找”与“先通过信件/电话谈好再去”的比例如何。
2. 1999–2004 51job 普通用户具体使用的历史页面、浏览器、charset、查询字段与城市筛选 UI，在本轮没有取得经过验证的 archive capture。
3. 不同职业阶层的迁移顺序差异：大学毕业生、工厂工人、建筑工、服务业、家政、技术人员可能完全不同。
4. 一次典型跨城求职在 1995、2005、2015、2025 分别需要多少现金缓冲。
5. 有多少 online application 最终变成跨城 interview / offer / actual relocation。
6. 人事档案、户籍、社保、职业资格与身体迁移之间的具体时间差，仍需做制度接口 ledger。
7. 伴侣共同迁移、老人照护、孩子入学等怎样改变“职业城市”的可逆性。

## 16. 下一轮最值钱的证据

优先寻找一条**同一人的跨城求职全链**，尤其是 1998–2010：

```text
第一次听说职位
→ 看到哪张报纸/哪个网站
→ 在哪里上网
→ 投了哪座城市
→ 谁回电话/email
→ 为哪次面试买了票
→ 住在哪里
→ 花多少钱
→ 拿到/没拿到 offer
→ 是否回原地
→ 人事档案怎样处理
→ 最后实际在哪座城市工作
```

如果能再配一条 2023–2026 的相同 ledger，就能真正测量：

> **互联网和后来的视频招聘究竟消灭了多少“先把身体搬过去再赌”的成本，又把多少成本重新转移到了筛选劳动、住房、网络设备和职业不确定性上。**
