# 文学实践：人怎样写、传、读、听和记住作品

Status: research program / integration scaffold

这组研究把文学本身当作 ordinary life 的一部分。

文学不是只有“作品完成之后”才开始存在。它有纸张、邮资、书店、报刊、编辑部、图书馆、学校、宿舍、收音机、磁带、电脑、网吧、手机、平台和评论区；有写作者投入的时间，有投稿失败，有稿费，有借阅和传抄，也有偶然认识另一个创作者或读者的瞬间。

## 核心问题

研究一个时期的文学实践时，不只问“写了什么”，还要问：

- **谁能写**：识字、教育、职业、性别、阶层、空闲时间和设备怎样影响写作资格？
- **在哪里写**：书房、单位、宿舍、课堂、网吧、通勤途中、手机上分别制造怎样的文本？
- **怎样到达编辑/平台**：登门、邮寄、报刊地址、电话、电子邮件、BBS、博客、投稿系统、平台后台；
- **怎样获得收入或资源**：稿费、版税、单位工资、奖金、约稿、平台分成、打赏、商业合作；
- **怎样复制与传播**：手抄、刊刻、铅印、复印、盗版、磁带/CD、网页、下载、网盘、推荐算法；
- **谁能读到**：购买价格、图书馆/租书摊、学校教材、家庭藏书、广播电视覆盖、网络接入和平台门槛；
- **怎样形成社群**：文学社、读者来信、书评版、论坛、QQ群、评论区、弹幕、同人圈、创作者群；
- **作品怎样进入人生节点**：启蒙、考试、毕业、恋爱、离乡、工作、失业、婚姻、育儿、衰老和怀旧。

## 建议的长期时间线

### 手抄 / 刊刻世界

关注抄写劳动、纸墨成本、藏书、借书、书坊、科举与士人网络，以及口头表演与书面文本之间的往返。

### 近代报刊与印刷市场

关注报馆、副刊、连载、稿酬、职业作者、翻译、书店、邮政、广告、识字教育与城市公共阅读空间。

### 20世纪单位 / 学校 / 大众媒介世界

关注文学刊物、作协与单位制度、学校课文、广播朗诵、电影电视改编、新华书店、图书馆、租书摊、盗版与家庭阅读。

### 1980s–2000s：投稿地址与个人电脑之间

关注信封投稿、编辑通信、文学社、校园刊物、杂志征文、稿费、寻呼机/电话、电脑排版、网吧、BBS、个人主页、博客与网络文学早期平台。

### 2000s–2010s：社区创作与搜索时代

关注论坛、贴吧、QQ群、博客、同人站、视频网站、VOCALOID/UTAU、MP3 搜索与下载、弹幕、评论、二次创作，以及“作者和读者可能在同一个小社群里偶然遇见”的低距离创作关系。

### 2010s–现在：平台化写作与算法分发

关注网文平台、短视频、音乐平台、社交媒体、推荐系统、订阅、榜单、商业化、版权治理、创作者工具，以及生成式 AI 对写作和作者身份的再组织。

## 个案模板

一个 literary-practice case 可以使用以下字段：

```yaml

inference_limits:

```

正文至少回答四件事：

1. 这个实践在技术和制度上怎样真正运作；
2. 普通参与者需要付出什么钱、时间、技能和社会关系；
3. 它怎样改变作者与读者之间的距离；
4. 它怎样进入人的具体生活，而不是只改变“文学史”。

## 与作品研究的连接

文学实践页和作品页必须尽量双向连接。

例如：

- 一篇报刊连载小说不只分析故事，也要连接当时的报纸发行、订阅、邮政、识字率、稿费和读者来信；
- 一首网络歌曲不只分析歌词，也要连接创作软件、音源、视频网站、下载/收藏、评论社群、作者身份和非商业创作空间；
- 一部毕业题材作品不只说“青春与离别”，也要连接升学考试、班级组织、毕业纪念、同学关系的断裂与通信媒介；
- 一部网文不只分析类型套路，也要连接日更劳动、平台合约、榜单、付费阅读、章评和读者反馈。

## 方法底线

文学实践研究尤其容易被“后来成功者的回忆”支配。应主动寻找没有成名的人留下的材料：投稿启事、报刊地址、稿费标准、征文规则、读者来信、校园刊物、论坛存档、教程、软件界面、书店/租书价格、图书馆制度、平台帮助文档与普通创作者帖子。

目标不是只写“大作家怎样创作”，而是恢复：

> **一个普通人，在那个年代如果突然想写一点东西，他实际上能做什么？**

以及：

> **另一个普通人，如果想遇见这些文字、歌曲或故事，又要经过什么路径？**
