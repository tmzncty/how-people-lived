## 为什么要把这两条线接起来

`how-people-lived` 不应只把文学作品当作“过去生活的插图”，文学史也不应只剩作家、作品、流派和思潮的内部演进。

更完整的关系是：

> **文学史 = 被表现的生活史 + 制作、传播、阅读文学的实践史 + 文本与形式自身的历史。**

一部作品至少同时属于三个世界：

1. **作品中的生活世界**：人物怎样吃饭、劳动、通勤、恋爱、结婚、租房、通信、等待、考试、迁徙、消费、照料家人；什么事情需要解释，什么事情被默认成人人都懂。
2. **作品周围的文学实践**：谁有时间和能力写作，稿件怎样到达编辑部，谁支付稿费，书怎样印刷与运输，读者在哪里买、借、抄、听、背、追更、评论和转发。
3. **作品打开的可能生活**：文学不只记录现实，也提供人生脚本、情绪词汇、身份想象和可争论的未来。一个时代的人会通过文学学习怎样理解爱情、家庭、成功、失败、故乡、阶层、战争、死亡和“我是谁”。

因此，文学既是 ordinary-life archive 的一种材料，也是 ordinary life 本身的一部分。

## 与《人的文学世界》的关系

`The-Paper-Cosmos/docs/print/人的文学世界/` 已经形成一张以“人”为中心的文学地图：人—时间—空间—身体—语言—他人—共同体—制度/历史/权力—文学，并把阅读、接受与文献传承放进同一条时间链。

这套材料在 `The-Paper-Cosmos` 中继续承担**文学学习与考试主图**的职责；在本仓库中，则把其中能够进入社会史、生活史和媒介史的问题拆成可验证的研究单元。

这里不建立第二份会独立漂移的“文学史全文”。迁移采用 **bridge + decomposition**：

- 原长文保留为来源与理论骨架；
- 本仓库建立文学史索引、文学实践专题和作品个案；
- 当长文中的一个判断能够转化为具体历史问题时，在这里建立独立页面，并补入非虚构证据；
- 双向记录来源，避免若干月后两份文本各自演化而无法判断哪一份是准本。

## 三种研究入口

### A. 作品作为生活世界的证据

关注作品中“不需要解释”的东西：

- 一个电话、车票、旅店、厨房、学校、医院或办公室怎样运作；
- 一封信多久能到；
- 一个人为什么能或不能离开家乡；
- 什么职业、家庭结构和消费水平被当作可理解的背景；
- 什么行为在当时显得体面、危险、浪漫、丢脸、先进或不现实。

使用现有 `F1–F4` fiction-evidence 标签。作品是 **contextual / representational evidence**，不是统计样本。

### B. 文学作为日常实践

研究文学怎样被真实的人做出来和使用：

- **写作**：识字、纸笔、打字机、电脑、手机；业余写作者与职业作者；日记、书信、诗社、文学社、论坛、同人、网文、VOCALOID/网络歌词创作。
- **投稿与编辑**：邮寄投稿、编辑部地址、副刊、文学刊物、退稿与修改、电话/电子邮件/即时通信、平台后台。
- **收入与职业**：稿费、版税、单位体制、自由职业、平台分成、打赏、商业约稿，以及“写作能不能养活人”。
- **复制与传播**：手抄、刻印、印刷、报刊、单行本、广播、磁带/CD、盗版、BBS、博客、论坛、视频网站、流媒体与推荐算法。
- **获得作品**：买书、租书、借阅、图书馆、书摊、同学传阅、剪报、下载、网盘、搜索与订阅。
- **阅读/观看/聆听场景**：课堂、宿舍、家庭、车厢、单位、网吧、手机；独读、朗诵、听广播、追连载、弹幕和评论区。
- **读者反馈**：读者来信、票选、书评、文学批评、粉丝社群、论坛回复、私信与创作者偶遇。

这一层不再把“文学”看成悬在生活之上的作品集合，而是把它当作有设备、成本、劳动、场所、组织和人际关系的实践。

### C. 文学作为“可能生活”的制造器

作品还会反过来参与生活。

需要研究：

- 哪些人生路线第一次或反复被写成“可以想象”；
- 一代人怎样从作品里学习爱情、离别、毕业、远行、城市、故乡、成功、失败与死亡的表达方式；
- 作品如何成为共同记忆的索引，例如毕业季歌曲、电视剧台词、课文、流行小说、网络歌曲；
- 文学/文艺作品怎样形成“我当时是谁”的个人记忆接口。

这一层尤其适合和本仓库的 **life horizons / imagined futures / generational culture** 研究相接。

## 证据边界

必须长期保留以下区分：

- `作品中的家庭 ≠ 统计上的典型家庭`
- `情节发生 ≠ 现实中的发生频率`
- `文学中的工资/价格 ≠ 已验证的历史价格`
- `作者经验 ≠ 同时代所有人的经验`
- `创作意图 ≠ 读者实际接受`
- `后来的怀旧 ≠ 当年的感受`
- `经典化后的重要性 ≠ 当时普通读者的实际接触率`
- `今天还能看到的作品 ≠ 当时最常被消费的作品`

建议证据链：

> 作品/文学实践线索 → 明确它能支持什么类型的判断 → 用报刊、统计、档案、书业资料、作者/编辑回忆、读者材料、价格与发行数据校准 → 记录相符与偏离。

## 文学史不只按“作品年代”排

每一个时期都可以同时问六条线：

| 轴 | 问题 |
|---|---|
| 生产 | 谁能写？用什么写？需要多少时间、教育和经济余裕？ |
| 制度 | 宫廷、科举、书院、报馆、出版社、单位、协会、平台怎样组织写作者？ |
| 媒介 | 手抄、刻本、报刊、广播、电影、磁带、互联网、手机怎样改变文本？ |
| 流通 | 作品怎样到读者手里？速度、价格、覆盖范围和审查节点在哪里？ |
| 接受 | 谁在读/听/看？在什么场景？怎样讨论、记忆、模仿和改写？ |
| 生活世界 | 作品把哪些生活条件、关系和人生可能性视为无需解释？ |

这样，“印刷革命”“报刊与大众识字”“广播电影”“互联网写作”就不只是文学史背景，而会变成 `how-people-lived` 可以继续取证的生活史问题。

## 推荐的作品页最低结构

每个作品个案至少记录：

1. **作品与版本**：创作/发表/演出/播出时间，所用版本；
2. **历史位置**：作品讲的是哪个时期，作者写作时又处在哪个时期；
3. **文学实践**：它怎样被写出来、编辑、发表、发行、表演、传播和获得；
4. **预设读者/受众**：作品假定谁能够理解它；
5. **生活世界线索**：住房、劳动、交通、通信、教育、食物、衣着、家庭、身体、消费、制度；
6. **人生脚本与情感词汇**：作品让哪些未来、身份和关系变得可想象；
7. **现实校准**：至少一种非文学材料；
8. **接受与记忆**：当时怎样被读，后来怎样被记；
9. **推断边界**：明确哪些不能从作品推出；
10. **cross-links**：回链到相关 topic / place / source / data 页面。

## 一个更大的目标

最终希望得到的不是“文学作品附录”，而是一张双向图：

```text
真实生活条件 ───────► 文学实践 ───────► 作品
     ▲                    │               │
     │                    ▼               ▼
制度 / 技术 / 媒介 ◄── 读者与社群 ◄── 想象的生活
     │                                    │
     └──────────── 反馈进真实生活 ◄──────┘
```

人怎样生活，决定了什么样的文学能够被生产、传播和理解；文学又参与决定人怎样理解自己的生活。

这正是文学史与 `how-people-lived` 应该相遇的地方。
