# 文学与日常生活

文学进入这座仓库时，**同时指向两个方向**：

1. **重构一部作品所预设的生活世界**——那些当时的读者不需要被解释的基础设施、价格、家务劳动、出行时间、通信方式、制度与实际约束；
2. **把文学重构为一种被实践的生活**——人们怎样写、投稿、编辑、付印、购买、借阅、阅读、朗诵、收听、连载、下载、评论、记住并改写文本。

这两层还会衍生出第三层：文学也可以提供**人生脚本、情感词汇与可想象的未来**。作品并不只是映照生活；它本身可以成为人们理解毕业、爱情、家庭、工作、迁移、失败、成功、失去与身份的一部分。

这里的指导关系是：

> **文学史 = 被再现的生活 + 制作／流通／阅读文学的历史 + 文本与形式的历史。**

这**并不**把虚构作品当成人口样本。它扩展的是日常生活史的对象：文化生产、阅读与共同想象本身就是人怎样活着的一部分。

## 具体作品的生活世界注释

旧文学常常预设一个物质世界，而当时的读者无须解释就懂。

现代读者可能认得一场戏里的每一个词，却仍然错过它实际的运转逻辑，因为这场戏背后的基础设施、价格、出行时间、家务劳动与技术，已经从常识里消失了。

这个目录要重构那层缺失的东西。

### 追问一部文学作品时可以问的问题

#### 交通

- 当时实际存在哪些出行方式？
- 它们有多快？
- 多久一班？
- 有多贵？
- 哪些路线是刚开通的？
- 错过衔接会怎样？

#### 通信

- 人物能寄信、发电报、打电话或发消息吗？
- 回信要多久？
- 消息能比人跑得更快吗？
- 是什么体力劳动把消息变成了共享的信息？

#### 钱

- 相对于工资，这些价格意味着什么？
- 旅馆、马车、仆人、一顿饭或一张票，是寻常还是奢侈？

#### 住房

- 多少间房是合理的？
- 仆人、房客或孩子睡在哪里？
- 有取暖、自来水、燃气或电吗？

#### 饮食

- 食物多久必须买一次？
- 有冷藏吗？
- 谁做饭？
- 一顿饭背后藏着多少家务劳动？

#### 衣着

- 谁洗衣服、修补衣服？
- 多少套换洗衣物是合理的？
- 某件衣服值多少钱？

#### 时间

- 工作日有多长？
- 去“拜访某人”要在路上花多少时间？
- 实际可支配的无结构闲暇有多少？

#### 社会可能性

- 哪些行为在技术上可行、但在经济上不可及？
- 主人公的阶层允许他做什么，而普通人做不到？

### 追问作品周围的问题

作品本身只是一个节点。还要问：

- 什么样的人有可能写出这类文本？需要什么教育、时间与设备？
- 它经过哪些编辑、赞助人、出版商、剧院、广播机构、网站或平台才抵达读者？
- 写作、印刷、购买、借阅或访问它要花多少成本？
- 人们在哪里、和谁一起读、听或看它？
- 观众与创作者之间存在哪些反馈渠道？
- 它属于当时的大众文化、精英文化、校园文化、亚文化、回溯性的经典，还是其中几者的混合？
- 后人对这部作品的记忆，与它最初被接受的情形有什么不同？

## 规则

不要把文学压缩成历史插图。

目标恰恰相反：既保住作品作为文学的部分，又同时恢复**原文无须解释的物质预设**，以及**作品本身进入人们生活所经由的物质与社会实践**。

情节有它的基础设施，家庭有它隐藏的劳动，信息有它的带宽，文学本身也有它的生产与发行系统。把这些约束补回来，往往会让旧小说既更陌生、又更好懂——同时让文学史成为“人究竟怎样活着”的历史的一部分。
